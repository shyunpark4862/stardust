## 한 문단 소개

stardust는 배열, 선형대수, 데이터프레임을 처음부터 다시 만든 Python 라이브러리예요. 이 문단은 본문 서체와 줄 간격, 문단 사이 여백을 보여 주는 자리이고, 실제 소개 글은 나중에 써요. 영문과 숫자가 섞인 문장도 확인해요(C++20 core, Python 3.15, 12,424 golden outputs).

<Callout>
  이 페이지의 글은 모두 자리 채움이에요. 제목, 문단, 목록, 코드, 표, 콜아웃이 어떻게 보이는지만 확인해요.
</Callout>

## 설치

코드 블록은 Cascadia Code로 그려요. 합자(`!=`, `->`, `>=`)도 켜져 있어요.

```bash
python3.15 -m venv .venv
.venv/bin/pip install --no-build-isolation -e .
```

## 첫 예제

```python
import stardust as sd

x = sd.arange(12.0).reshape((3, 4))
y = sd.sin(x.T) @ x
x[x > 5] = 0.0
```

### 목록

- 첫째 항목은 한 줄이에요.
- 둘째 항목은 `sd.linalg`처럼 인라인 코드를 품어요.
  - 안쪽 목록의 들여쓰기와 간격.
- 셋째 항목은 [링크](/api/)를 품어요.
