## 한눈에 보기

점의 값만이 아니라 그 자리의 기울기까지 알고 있을 때가 있어요. 위치와 속도를 함께 잰 자료, 미분방정식의 풀이에서 얻은 값과 도함수 같은 것이에요. `KroghInterpolator`는 값과 도함수를 모두 맞추는 다항식 하나(**에르미트 보간**)를 만들어요.

$x = 0$에서 값 1, 기울기 0이고 $x = 1$에서 값 2, 기울기 0인 다항식을 만들어 볼게요. 자료가 넷이라 3차 다항식이에요. 같은 노드를 두 번 적고, 두 번째 자리에 기울기를 적어요.

```python
>>> import stardust as sd
>>> k = sd.interpolate.KroghInterpolator([0.0, 0.0, 1.0, 1.0], [1.0, 0.0, 2.0, 0.0])
>>> k
KroghInterpolator(nodes=4)
>>> k([0.0, 0.25, 0.5, 1.0])
array([    1.0, 1.15625,     1.5,     2.0], dtype=float64)
>>> k.derivative([0.0, 0.5, 1.0])
array([0.0, 1.5, 0.0], dtype=float64)
```

결과는 $1 + 3x^2 - 2x^3$이에요. 두 끝에서 기울기가 0이라 평평하게 출발해 평평하게 도착해요.

## 자료를 적는 법

`xi`의 항목 하나에 `yi`의 자료 하나가 짝이에요. 어떤 노드가 처음 나오면 그 자리의 값, 같은 노드가 두 번째로 나오면 1차 도함수, 세 번째면 2차 도함수, 이렇게 이어져요.

| `xi` | `yi` | 뜻 |
|---|---|---|
| `[a, b, c]` | $f(a), f(b), f(c)$ | 값만. 보통의 보간 다항식 |
| `[a, a, b, b]` | $f(a), f'(a), f(b), f'(b)$ | 양 끝의 값과 기울기. 3차 에르미트 |
| `[a, a, a, b]` | $f(a), f'(a), f''(a), f(b)$ | 한쪽은 2차 도함수까지 |
| `[a, a, a, a, a]` | $f(a), f'(a), \dots, f^{(4)}(a)$ | 한 점의 도함수만. 테일러 다항식 |

같은 노드는 서로 붙어 있어야 해요. 그 밖의 순서는 자유예요. 자료가 모두 $n$개면 $n - 1$차 이하의 다항식이고, 모든 조건을 맞추는 다항식은 하나뿐이에요.

한 점에서 도함수만 주면 테일러 다항식이 돼요. $e^x$의 0에서의 도함수는 모두 1이니, 다섯 번 적으면 4차 테일러 다항식이에요.

```python
>>> t = sd.interpolate.KroghInterpolator([0.0] * 5, [1.0] * 5)
>>> t(0.5)
1.6484375
>>> t(0.5) - (1 + 0.5 + 0.5**2 / 2 + 0.5**3 / 6 + 0.5**4 / 24)
0.0
```

노드를 되풀이하지 않으면 보통의 보간 다항식이라 [`BarycentricInterpolator`](/api/interpolate/BarycentricInterpolator/)와 같은 다항식이에요. 계산하는 방법이 달라서 끝자리는 다를 수 있어요.

```python
>>> sd.interpolate.KroghInterpolator([2.0, 0.0, 1.0], [2.0, 1.0, 3.0])(0.5)
2.375
>>> sd.interpolate.BarycentricInterpolator([2.0, 0.0, 1.0], [2.0, 1.0, 3.0])(0.5)
2.3749999999999996
```

같은 노드가 떨어져 있으면 무엇의 도함수인지 정할 수 없어 에러예요.

```python
>>> sd.interpolate.KroghInterpolator([0.0, 1.0, 0.0], [1.0, 2.0, 3.0])
Traceback (most recent call last):
    ...
ValueError: KroghInterpolator(): a repeated value of 'xi' must follow its equals: xi[2] = 0.0 repeats an earlier node that is not next to it
```

## 값과 도함수

부르면 값, `derivative(x, der=k)`는 $k$차 도함수, `derivatives(x, der=m)`은 0차부터 $m - 1$차까지를 첫 축에 쌓은 배열이에요. `der`를 주지 않으면 노드 수만큼이에요.

```python
>>> k.derivative(0.5, der=2)
0.0
>>> k.derivatives(0.5)
array([  1.5,   1.5,   0.0, -12.0], dtype=float64)
>>> k.derivatives([0.0, 1.0], der=2)
array([[1.0, 2.0],
       [0.0, 0.0]], dtype=float64)
```

세 방법은 같은 계산의 같은 단계를 읽으므로 비트까지 같아요. `k(x)`는 `k.derivatives(x)[0]`과, `k.derivative(x, der=1)`은 `k.derivatives(x)[1]`과 같아요.

```python
>>> k.derivative(0.5, der=1) == k.derivatives(0.5)[1], k(0.5) == k.derivatives(0.5)[0]
(True, True)
```

차수가 노드 수 이상이면 다항식의 차수보다 높으니 0이에요. NaN 평가점에서는 어느 차수든 NaN이에요.

```python
>>> k.derivative(0.5, der=4), k.derivative(float("nan"), der=4)
(0.0, nan)
```

## 여러 열을 한 번에: `axis`

같은 노드에서 여러 계열의 자료가 있으면 열로 묶어 줘요. `yi`의 `axis` 축이 노드를 따라가고 나머지 축이 계열이에요. 결과에서는 `axis` 자리에 평가점의 모양이 들어가고, `derivatives`는 그 앞에 차수 축이 붙어요.

```python
>>> Y = sd.asarray([[1.0, 0.0], [0.0, 1.0], [2.0, 0.0], [0.0, -1.0]])
>>> kb = sd.interpolate.KroghInterpolator([0.0, 0.0, 1.0, 1.0], Y)
>>> kb(0.5)
array([ 1.5, 0.25], dtype=float64)
>>> kb([0.25, 0.5, 0.75]).shape
(3, 2)
>>> kb.derivatives([0.25, 0.5, 0.75]).shape
(4, 3, 2)
```

열마다 같은 계산이라 한 열의 결과는 혼자 만든 것과 비트까지 같아요.

값은 complex128이어도 돼요. 실수부와 허수부를 따로 보간한 것과 같아요.

```python
>>> kc = sd.interpolate.KroghInterpolator([0.0, 0.0, 1.0], [1j, 1.0, 2.0])
>>> kc(0.5)
(0.75+0.75j)
```

## 결과의 모양

평가점이 수 하나면 Python `float`(값이 복소수면 `complex`), 배열이면 같은 모양의 배열이에요. 정수와 bool 평가점은 float64로 바꾸고, 복소수 평가점은 받지 않아요.

## 점이 많으면 불안정해요

`KroghInterpolator`는 다항식을 뉴턴 꼴(나눗셈 차분의 계수)로 적어 두고 계산해요. 이 꼴은 도함수 자료를 자연스럽게 다루지만, 노드가 많으면 계수가 반올림에 아주 민감해져요. 노드가 서른 개쯤을 넘으면 노드를 잘 골라도 오차가 커질 수 있어요.

체비쇼프 점에서 $1/(1 + 25x^2)$를 보간해 견줘 볼게요. 같은 다항식인데 노드가 61개면 `KroghInterpolator`의 오차가 크게 벌어져요.

```python
>>> def f(x):
...     return 1.0 / (1.0 + 25.0 * x * x)
>>> xs = sd.linspace(-1.0, 1.0, 2001)
>>> for n in (21, 41, 61):
...     xc = sd.cos(sd.pi * (2 * sd.arange(n) + 1) / (2 * n))
...     ek = float(sd.max(sd.abs(sd.interpolate.KroghInterpolator(xc, f(xc))(xs) - f(xs))))
...     eb = float(sd.max(sd.abs(sd.interpolate.BarycentricInterpolator(xc, f(xc))(xs) - f(xs))))
...     print(n, f"{ek:.1e}", f"{eb:.1e}")
21 1.5e-02 1.5e-02
41 2.9e-04 2.9e-04
61 5.0e-01 5.4e-06
```

경고는 내지 않아요. 도함수 자료가 없으면 [`BarycentricInterpolator`](/api/interpolate/BarycentricInterpolator/)를 쓰고, 도함수 자료가 있어도 점이 많으면 구간마다 3차식으로 잇는 [`CubicHermiteSpline`](/api/interpolate/CubicHermiteSpline/)이 안전해요. `KroghInterpolator`는 자료가 적고(열 개 남짓) 도함수 조건이 섞여 있을 때 알맞아요.

## 경계의 값

| 상황 | 결과 |
|---|---|
| 평가점이 NaN | NaN |
| 평가점이 inf나 −inf | 다항식이 가는 쪽의 ±inf(노드가 하나면 그 값). 자료가 노드 수보다 낮은 차수의 다항식이면 NaN일 수 있어요 |
| 값에 NaN이 하나라도 있음 | 모든 점에서 NaN |
| 노드가 하나 | 상수 다항식 |
| 노드 수 이상의 도함수 | 0 (NaN 점에서는 NaN) |
| 빈 평가점 배열 | 빈 배열 |

```python
>>> k(float("nan")), k(float("inf"))
(nan, -inf)
>>> sd.interpolate.KroghInterpolator([1.0], [3.0])(9.0)
3.0
>>> sd.interpolate.KroghInterpolator([1.0], [3.0])(float("inf"))
3.0
```

$1 + 3x^2 - 2x^3$은 $x \to \infty$에서 $-\infty$로 가요. 노드 셋의 자료가 상수라 다항식의 차수가 노드 수보다 낮으면, 무한대와 0의 곱이 생겨 NaN이에요.

```python
>>> sd.interpolate.KroghInterpolator([0.0, 1.0, 2.0], [1.0, 1.0, 1.0])(float("inf"))
nan
```

뉴턴 꼴의 계수는 모든 자료를 섞어 만들기 때문에, 자료에 NaN이 하나만 있어도 계수가 모두 NaN이 되어 노드에서도 NaN이에요. 결측값이 있으면 그 자료를 빼고 만들어요.

```python
>>> kn = sd.interpolate.KroghInterpolator([0.0, 1.0, 2.0], [1.0, float("nan"), 2.0])
>>> kn([0.0, 0.5, 2.0])
array([nan, nan, nan], dtype=float64)
```

## 한 번만 부를 때: `krogh_interpolate`

`krogh_interpolate(xi, yi, x)`는 객체를 만들어 한 번 부른 것과 비트까지 같아요. `der`를 주면 그 차수의 도함수, 차수의 시퀀스를 주면 차수마다의 결과 list예요.

```python
>>> sd.interpolate.krogh_interpolate([0.0, 0.0, 1.0, 1.0], [1.0, 0.0, 2.0, 0.0], 0.5)
1.5
>>> sd.interpolate.krogh_interpolate([0.0, 0.0, 1.0, 1.0], [1.0, 0.0, 2.0, 0.0], [0.25, 0.5], der=1)
array([1.125,   1.5], dtype=float64)
>>> sd.interpolate.krogh_interpolate([0.0, 0.0, 1.0, 1.0], [1.0, 0.0, 2.0, 0.0], 0.5, der=[0, 1, 2])
[1.5, 1.5, 0.0]
```

## 결과는 언제나 같아요

같은 자료(같은 순서), 같은 평가점이면 [스레드 수](/api/array/threads/)와 상관없이 언제나 같은 비트예요. 노드 순서는 준 그대로 써요. 순서를 바꾸면 반올림이 달라져 끝자리가 바뀔 수 있어요.

시험 자료에서 끝에서 끝의 오차는 계약 한계의 0.0039배 이하예요(1차 도함수 $4.3 \times 10^{-5}$배, 2차 $1.2 \times 10^{-5}$배). 계약 한계는 뉴턴 계수의 절댓값으로 정해지므로, 위처럼 불안정한 자료에서는 한계가 함께 커져서 오차의 크기를 미리 보여 줘요. 자세한 것은 [정확도와 성능](/internals/interpolate/accuracy-performance/)과 [무게중심 보간](/internals/interpolate/barycentric/)에 있어요.

## scipy·numpy를 아는 분께

- 이름과 메서드는 `scipy.interpolate.KroghInterpolator`, `krogh_interpolate`와 같아요. 같은 노드를 되풀이해 도함수를 주는 규칙도 같아요. 옵션(`axis`, `der`)은 키워드로만 받아요.
- 노드가 서른 개를 넘어도 경고를 내지 않아요. 결과는 계산하고, 정확도 계약이 오차의 크기를 보여 줘요.
- 값, `derivative(der=m)`, `derivatives()`의 $m$번 행이 비트까지 같아요. scipy는 값과 도함수를 따로 된 계산으로 구해서 끝자리가 서로 다를 수 있어요.
- 노드 수 이상의 도함수는 NaN 평가점에서 NaN이에요. scipy는 0이에요.
- 복소수 평가점은 `TypeError`예요. 0차원 결과는 Python `float`·`complex`예요.
