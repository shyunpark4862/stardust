## 한눈에 보기

**정규분포**는 값이 평균 둘레에 몰려 있고, 평균에서 멀어질수록 좌우 대칭으로 빠르게 드물어지는 분포예요. 밀도를 그리면 종 모양이라 "종 모양 곡선", 가우스가 연구해서 "가우스 분포"라고도 불러요.

정규분포가 흔한 까닭은 작고 서로 독립인 영향이 많이 더해진 값은 원래 영향이 어떤 분포든 거의 정규분포를 따르기 때문이에요(중심극한정리). 그래서 이런 곳에서 만나요.

- 측정 오차: 저울의 눈금 읽기, 온도계의 흔들림처럼 작은 오차가 여럿 겹친 값
- 생물의 크기: 키, 몸무게처럼 많은 유전자와 환경이 조금씩 더해진 값
- 평균과 합: 표본이 충분히 크면 표본 평균은 거의 정규분포를 따라요. 여론조사의 오차범위가 여기서 나와요.

정규분포는 두 수로 정해져요. 가운데를 정하는 평균 `mu`($\mu$)와 퍼진 정도를 정하는 표준편차 `sigma`($\sigma$)예요.

```python
>>> import stardust as sd
>>> H = sd.stats.Normal(mu=170.0, sigma=6.0)
>>> H.cdf(180.0)
0.9522096477271853
>>> H.ccdf(185.0)
0.006209665325776137
>>> H.icdf(0.9)
177.6893093932676
```

키가 평균 170cm, 표준편차 6cm인 정규분포를 따른다면, 180cm 이하인 사람은 약 95.2%, 185cm보다 큰 사람은 약 0.62%예요. 상위 10%는 약 177.7cm부터예요.

## 만들기와 매개변수

매개변수는 이름을 붙여서 줘요. 둘 다 기본값이 있어서 `Normal()`은 평균 0, 표준편차 1인 **표준정규분포**예요.

```python
>>> Z = sd.stats.Normal()
>>> Z
Normal(mu=0.0, sigma=1.0)
>>> H.mu, H.sigma
(170.0, 6.0)
```

| 매개변수 | 뜻 | 정의역 | 기본값 |
|---|---|---|:---:|
| `mu` | 평균, 분포의 가운데 | 유한한 실수 | 0 |
| `sigma` | 표준편차, 퍼진 정도 | 0보다 큰 유한한 실수 | 1 |

`sigma`는 분산이 아니라 표준편차예요. 분산이 4인 정규분포는 `sigma=2.0`이에요.

### 배열 매개변수

매개변수에 배열을 주면 정규분포 여러 개를 한꺼번에 다뤄요. 매개변수끼리, 그리고 입력과 [브로드캐스트](/api/stats/basics/#매개변수와-입력은-함께-브로드캐스트해요)해요.

```python
>>> W = sd.stats.Normal(sigma=sd.asarray([0.5, 1.0, 2.0]))
>>> W.pdf(0.0)
array([ 0.7978845608028654,  0.3989422804014327, 0.19947114020071635], dtype=float64)
```

표준편차가 절반이 되면 가운데 높이는 두 배가 돼요. 넓이가 1로 같아야 하니까요.

### 정의역 밖이면 NaN

`sigma`가 0 이하이거나, 어느 매개변수든 inf나 NaN이면 에러 대신 그 원소의 모든 메서드가 NaN이에요. 표준편차가 0인 정규분포(한 점에 몰린 분포)는 만들 수 없어요.

```python
>>> bad = sd.stats.Normal(mu=sd.asarray([0.0, sd.inf, 0.0, 0.0]), sigma=sd.asarray([0.0, 1.0, sd.inf, -2.0]))
>>> bad.pdf(0.0)
array([nan, nan, nan, nan], dtype=float64)
>>> bad.mean()
array([nan, nan, nan, nan], dtype=float64)
```

## 밀도와 누적분포

### 밀도

정규분포의 밀도는 이래요.

$$
f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

모양을 정하는 것은 지수 안의 $-(x-\mu)^2 / (2\sigma^2)$이에요. 평균에서의 거리가 제곱으로 들어가서, 멀어질수록 밀도가 아주 빨리 0으로 가요. 값이 나올 수 있는 범위(지지집합)는 실수 전체 $(-\infty, \infty)$예요.

```python
>>> Z.pdf(sd.asarray([0.0, 1.0, 2.0, 3.0]))
array([ 0.3989422804014327, 0.24197072451914337, 0.05399096651318806,
       0.0044318484119380075], dtype=float64)
>>> Z.support()
(-inf, inf)
```

### 누적분포

`cdf(x)`는 밀도 곡선 아래에서 왼쪽 끝부터 x까지의 넓이예요. 이 넓이는 초등함수로 적을 수 없어서 표준정규분포의 누적분포함수 $\Phi$로 나타내요.

$$
\mathrm{cdf}(x) = \Phi\!\left(\frac{x-\mu}{\sigma}\right), \qquad \Phi(z) = \frac{1}{2}\left[1 + \operatorname{erf}\!\left(\frac{z}{\sqrt 2}\right)\right]
$$

$z = (x-\mu)/\sigma$는 "x가 평균에서 표준편차 몇 개만큼 떨어져 있나"예요. 이것을 **표준 점수**(z 점수)라고 불러요. $\operatorname{erf}$는 [오차함수](/api/special/erf/)예요.

### 꼬리: `ccdf`와 log 메서드

평균에서 먼 위꼬리의 확률은 `ccdf`로 구해요. `1 - cdf(x)`는 x가 크면 자릿수를 잃고 0이 돼요([분포의 메서드](/api/stats/methods/#ccdf는-1---cdf가-아니에요)).

```python
>>> 1 - Z.cdf(10.0)
0.0
>>> Z.ccdf(10.0)
7.619853024160528e-24
```

확률이 float64로 나타낼 수 없을 만큼 작으면 로그로 구해요. 표준 점수가 −40인 아래꼬리의 확률은 약 $e^{-804.6}$이라 `cdf`는 0이지만, `logcdf`는 그 로그를 줘요. 표준 점수가 −10만이어도 마찬가지예요.

```python
>>> Z.cdf(-40.0), Z.logcdf(-40.0)
(0.0, -804.6084420137538)
>>> Z.logcdf(-1e5)
-5000000012.431864
>>> Z.pdf(40.0), Z.logpdf(40.0)
(0.0, -800.9189385332047)
```

### 분위수

`icdf(p)`는 아래에서 p만큼을 자르는 값이에요. 정규분포에서는 $\mu + \sigma\,\Phi^{-1}(p)$예요. 사분위수와 중앙값도 한 번에 구할 수 있어요.

```python
>>> H.icdf(sd.asarray([0.25, 0.5, 0.75]))
array([165.9530614988235,             170.0, 174.0469385011765], dtype=float64)
>>> Z.icdf(0.975)
1.9599639845400534
```

`Z.icdf(0.975) ≈ 1.96`은 "가운데 95%를 남기려면 평균에서 표준편차 1.96개만큼 양쪽으로"라는 뜻이에요. 95% 신뢰구간에 나오는 바로 그 1.96이에요.

위꼬리의 아주 작은 확률은 `iccdf`, 확률의 로그는 `ilogcdf`·`ilogccdf`로 거꾸로 풀어요.

```python
>>> Z.iccdf(1e-300)
37.0470962993612
>>> Z.ilogcdf(-1e5)
-447.1978936785251
>>> Z.ilogcdf(-1e300), Z.ilogccdf(-1e300)
(-1.4142135623730951e+150, 1.4142135623730951e+150)
```

확률의 로그가 float64의 끝(약 −1.8e308)에 가까워도 분위수는 유한한 값이에요. 로그가 −inf일 때만 ±inf예요.

`ilogcdf`에 `logcdf(mu)`의 값, 곧 float64로 반올림한 $\log\frac12$를 넣으면 중앙값 $\mu$가 나와요. 그래서 `ilogcdf(logcdf(mu))`가 $\mu$로 돌아와요. `ilogccdf`도 같아요.

```python
>>> H.ilogcdf(H.logcdf(170.0)), H.ilogccdf(H.logccdf(170.0))
(170.0, 170.0)
```

`p`가 0이면 −inf, 1이면 inf이고, [0, 1] 밖이면 NaN이에요.

```python
>>> Z.icdf(sd.asarray([0.0, 1.0, -0.1]))
array([-inf,  inf,  nan], dtype=float64)
```

### 직접 표준화하지 마세요

`Normal(mu=m, sigma=s).pdf(x)`는 수학으로는 `Normal().pdf((x - m) / s) / s`와 같아요. 하지만 `(x - m) / s`를 float64로 계산하면 표준 점수가 반올림되고, 밀도의 $e^{-z^2/2}$가 그 반올림 오차를 $z^2$배로 키워요. 표준 점수가 34쯤이면 마지막 세 자리가 틀려요. 분포 객체는 표준 점수를 반올림 없이 다뤄서 이런 손실이 없어요.

```python
>>> sd.stats.Normal(mu=1.3, sigma=0.7).pdf(25.1)
5.415037714417623e-252
>>> Z.pdf((25.1 - 1.3) / 0.7) / 0.7
5.415037714418383e-252
```

참값은 5.41503771441762417…e-252예요. 첫 줄이 맞고, 둘째 줄은 12번째 자리부터 틀려요. `cdf`, `ccdf`와 log 메서드도 같아요. 매개변수가 있는 분포 객체를 만들어 그대로 쓰세요.

## 요약값

정규분포의 요약값은 모두 매개변수로 바로 정해져요. 정의되지 않거나 발산하는 값이 없어요.

| 메서드 | 값 |
|---|---|
| `mean()`, `median()`, `mode()` | $\mu$ |
| `variance()` | $\sigma^2$ |
| `standard_deviation()` | $\sigma$ |
| `skewness()` | 0 (좌우 대칭) |
| `kurtosis()` | 0 (초과 첨도의 기준이 정규분포예요) |
| `entropy()` | $\tfrac12 \log(2\pi e \sigma^2)$ |

```python
>>> H.mean(), H.median(), H.mode()
(170.0, 170.0, 170.0)
>>> H.variance(), H.standard_deviation()
(36.0, 6.0)
>>> H.skewness(), H.kurtosis()
(0.0, 0.0)
>>> H.entropy()
3.2106980024327276
```

평균, 중앙값, 최빈값이 모두 $\mu$로 같아요. 좌우 대칭이고 봉우리가 하나이기 때문이에요. 분산이 같은 연속 분포 가운데 엔트로피가 가장 큰 것이 정규분포예요.

## 표본

`sample`로 정규분포를 따르는 난수를 뽑아요. 생성기 `rng`는 꼭 넘겨야 해요. 모양, 재현성, 생성기의 위치 같은 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> H.sample(5, rng=sd.random.default_rng(42))
array([164.10086808542556, 172.05687312731786, 164.84520119173104,
       168.77840817008175,  163.3736028626577], dtype=float64)
>>> x = H.sample(100_000, rng=sd.random.default_rng(1))
>>> round(float(sd.mean(x)), 1), round(float(sd.std(x)), 1)
(170.0, 6.0)
>>> round(sd.stats.skew(x), 2)
0.0
```

표본 10만 개의 평균, 표준편차, 왜도가 분포의 값(170, 6, 0)과 거의 같아요.

## 다른 분포와의 관계

### 표준화

$X$가 `Normal(mu, sigma)`를 따르면 $Z = (X - \mu)/\sigma$는 표준정규분포 `Normal()`을 따라요. 그래서 모든 정규분포의 확률은 표준정규분포 하나로 바꿔 생각할 수 있어요. 계산할 때는 위에서 본 대로 분포 객체를 그대로 쓰는 편이 정확해요.

```python
>>> H.cdf(180.0), Z.cdf((180.0 - 170.0) / 6.0)
(0.9522096477271853, 0.9522096477271853)
```

### 특수함수의 정규분포 함수

표준정규분포의 `cdf`와 `icdf`는 [`sd.special.ndtr`, `ndtri`](/api/special/ndtr/)와 같은 값을 내요. `logcdf`에 해당하는 특수함수는 `log_ndtr`예요(둘 다 1e-14 안에서 정확하지만, 마지막 자리가 다를 수 있어요). 확률 하나만 필요하면 그 함수들을, 밀도·분위수·표본 등을 함께 쓰려면 분포 객체를 쓰세요.

```python
>>> Z.cdf(1.96), sd.special.ndtr(1.96)
(0.9750021048517795, 0.9750021048517795)
>>> Z.icdf(0.975), sd.special.ndtri(0.975)
(1.9599639845400534, 1.9599639845400534)
```

### t 분포

자유도 `df`인 [t 분포](/api/stats/student-t/)는 정규분포보다 꼬리가 두껍고, `df`가 커질수록 표준정규분포에 가까워져요.

```python
>>> sd.stats.StudentT(df=30.0).cdf(1.96), sd.stats.StudentT(df=1000.0).cdf(1.96), Z.cdf(1.96)
(0.9703288435519748, 0.9748634075221256, 0.9750021048517795)
```

### 로그정규분포

$X$가 `Normal(mu, sigma)`를 따르면 $e^X$는 같은 `mu`, `sigma`의 [로그정규분포](/api/stats/lognormal/)를 따라요. 그래서 $P(e^X \le e^x) = P(X \le x)$예요.

```python
>>> import math
>>> sd.stats.LogNormal(mu=1.0, sigma=0.5).cdf(math.exp(1.7))
0.9192433407662289
>>> sd.stats.Normal(mu=1.0, sigma=0.5).cdf(1.7)
0.9192433407662289
```

### 카이제곱 분포

$Z$가 표준정규분포를 따르면 $Z^2$은 자유도 1인 [카이제곱 분포](/api/stats/chi-squared/)를 따라요. $P(Z^2 \le 4) = P(-2 \le Z \le 2)$예요. 표준정규 변수 k개의 제곱합은 자유도 k인 카이제곱 분포예요.

```python
>>> sd.stats.ChiSquared(df=1.0).cdf(4.0)
0.9544997361036416
>>> Z.cdf(2.0) - Z.cdf(-2.0)
0.9544997361036416
```

### 정규분포의 합

서로 독립인 두 정규 변수의 합도 정규분포예요. 평균도 분산(표준편차의 제곱)도 그대로 더해져요. 평균 1, 표준편차 3인 것과 평균 2, 표준편차 4인 것을 더하면 평균 3, 표준편차 $\sqrt{9 + 16} = 5$예요.

```python
>>> rng = sd.random.default_rng(0)
>>> s = sd.stats.Normal(mu=1.0, sigma=3.0).sample(1_000_000, rng=rng) + sd.stats.Normal(mu=2.0, sigma=4.0).sample(1_000_000, rng=rng)
>>> round(float(sd.mean(s)), 2), round(float(sd.std(s)), 2)
(3.0, 5.0)
```

### 다변량 정규분포

값이 벡터이고 성분끼리 상관이 있으면 [다변량 정규분포](/api/stats/multivariate-normal/)를 써요. 1차원 다변량 정규분포는 이 분포와 같아요. 공분산 행렬에는 분산($\sigma^2$)을 넣어요.

```python
>>> M = sd.stats.MultivariateNormal(mu=sd.asarray([0.0]), cov=sd.asarray([[4.0]]))
>>> M.pdf(sd.asarray([1.0])), sd.stats.Normal(sigma=2.0).pdf(1.0)
(0.17603266338214973, 0.17603266338214976)
```

두 분포는 밀도를 서로 다른 길로 계산해서 마지막 자리가 다를 수 있어요. 둘 다 오차 한계 안이에요.

## 정확도와 범위

정규분포는 매개변수와 입력의 정의역 전체가 보장 영역이에요. 어떤 `mu`, `sigma`, `x`에서든 모든 메서드가 [통계의 기본](/api/stats/basics/#정확도-약속)의 약속을 지켜요.

- `pdf`, `cdf`, `ccdf`, `logcdf`, `logccdf`와 요약값: 상대오차 1e-14 이하예요. 꼬리의 아주 작은 확률에서도 앞자리 14자리 정도가 맞아요.
- `logpdf`, `entropy`: 오차가 $10^{-14} \times \max(1, \lvert\text{값}\rvert)$ 이하예요.
- `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`: 입력의 반올림이 허용하는 만큼 정확해요. 결과가 0 근처로 지워지는 곳(예: `Normal(mu=1.5, sigma=2.0).icdf(0.2267)`)에서는 상대오차가 커질 수 있어요. 까닭은 [분포의 메서드](/api/stats/methods/#연속-분포의-역함수와-κ)에 있어요.

정밀한 참값과 비교해 실제로 잰 최대 오차는 모든 메서드에서 약 1e-15(약속의 단위로)예요.

값이 float64의 범위를 벗어나면 극한값을 내요. 결과가 가장 작은 float64(약 5e-324)보다 작으면 0이고, 그 근처의 아주 작은 수(서브노멀 수)도 그대로 내요. 결과가 가장 큰 float64(약 1.8e308)를 넘으면 inf예요.

```python
>>> Z.ccdf(38.0)
2.88542835e-316
>>> sd.stats.Normal(sigma=1e-309).pdf(0.0)
inf
>>> sd.stats.Normal(sigma=1e-309).logpdf(0.0)
710.5798552019554
```

`sigma=1e-309`의 가운데 밀도는 약 4e308이라 float64로 담을 수 없어서 inf예요. 그래도 그 로그(710.58)는 제대로 나와요.

## scipy를 아는 분께

- scipy 신형의 `scipy.stats.Normal(mu=..., sigma=...)`와 이름과 뜻이 같아요. 고전형 `scipy.stats.norm(loc, scale)`의 `loc`, `scale`이 각각 `mu`, `sigma`예요.
- `kurtosis()`는 0이에요. scipy 신형의 `Normal().kurtosis()`는 3이에요(`convention='excess'`를 주면 0).
- 결과는 Python `float`이거나 `sd.ndarray`예요. scipy는 `numpy.float64`를 돌려줘요.
- 꼬리와 매개변수가 있는 밀도에서 자릿수를 덜 잃어요(scipy 1.18.1과 비교).
  - `Normal(mu=1.3, sigma=0.7).pdf(25.1)`: scipy는 5.415037714418383e-252예요. 상대오차가 1.4e-13이에요.
  - `Normal().ccdf(38.0)`: 2.88542835e-316(서브노멀 수)이에요. scipy는 0.0이에요.
  - `Normal().ilogcdf(-1e5)`: -447.1978936785251이에요. scipy는 -447.19789367876837이라 상대오차가 5e-13쯤이에요. 두 값을 `logcdf`에 되돌려 넣으면 각각 −100000.00000000001과 −100000.0000001이 나와요.
- `sample`의 `rng`는 꼭 줘야 하고, 같은 시드라도 scipy·numpy와 값이 달라요([표본 뽑기](/api/stats/sample/)).
