## 어떤 분포인가요

**Gumbel 분포**는 "여러 값 가운데 가장 큰 값"이 따르는 분포예요. 매일의 강수량을 1년 동안 재서 그중 가장 큰 값만 모으면, 그 "연 최대 강수량"은 여러 해에 걸쳐 대략 Gumbel 분포를 따라요. 그래서 **극값 분포**(extreme value distribution)라고 불러요.

쓰이는 곳은 대부분 "드물지만 큰 일"을 다루는 분야예요.

- 수문과 기상: 연 최대 강수량, 하천의 연 최고 수위, 연 최대 풍속. 제방과 배수 시설을 "100년에 한 번 올 비"에 맞춰 설계할 때 써요.
- 신뢰성: 많은 부품 중 가장 약한 것이 먼저 망가지는 문제(이때는 최솟값형, 아래 참고).
- 기계학습: 범주형 표본을 뽑는 Gumbel-max 기법과, 선택 모형의 오차항.

꼬리가 지수함수처럼 줄어드는 분포(정규, 지수, 감마 등)에서 값을 $n$개 뽑아 최댓값을 취하면, $n$이 커질수록 그 최댓값의 분포가 (위치와 척도만 맞추면) Gumbel 모양에 가까워져요. 표본 평균이 정규분포로 모이는 것(중심극한정리)과 비슷한, 최댓값의 극한 법칙이에요.

```python
>>> import stardust as sd
>>> X = sd.stats.Gumbel()
>>> X.cdf(0.0)
0.36787944117144233
>>> X.mean()
0.5772156649015329
```

## 만들기와 매개변수

- `mu`: 위치. 밀도가 가장 높은 점(최빈값)이에요. 기본값 0.
- `sigma`: 척도. 0보다 커야 하고, 기본값 1.

```python
>>> sd.stats.Gumbel(mu=100.0, sigma=20.0)
Gumbel(mu=100.0, sigma=20.0)
>>> sd.stats.Gumbel(sigma=sd.asarray([1.0, 2.0])).mean()
array([0.5772156649015329, 1.1544313298030657], dtype=float64)
```

`mu`는 평균이 아니에요. 오른쪽 꼬리가 길어서 평균은 최빈값보다 $\gamma\sigma$(약 0.577·σ)만큼 오른쪽에 있어요. 매개변수가 정의역 밖이면(`sigma` ≤ 0, 무한대·NaN인 매개변수) 그 원소의 모든 결과가 NaN이에요.

```python
>>> sd.stats.Gumbel(sigma=-1.0).cdf(0.0)
nan
```

<Callout type="note" title="최댓값형만 있어요">
  Gumbel 분포에는 최댓값을 위한 것과 최솟값을 위한 것, 두 가지 방향이 있어요. `Gumbel`은 **최댓값형**(오른쪽 꼬리가 긴 쪽)뿐이에요. 최솟값형은 부호를 뒤집어 구해요(아래 [최솟값형](#최솟값형은-부호를-뒤집어서)).
</Callout>

## 밀도와 누적분포

$z = (x - \mu)/\sigma$라고 두면, 지지집합은 실수 전체이고

$$
F(x) = \exp\!\left(-e^{-z}\right), \qquad
f(x) = \frac{1}{\sigma}\, e^{-z}\exp\!\left(-e^{-z}\right), \qquad
F^{-1}(p) = \mu - \sigma\log(-\log p)
$$

예요. 누적분포에 지수가 두 번 겹쳐 있어서("이중 지수") 두 꼬리가 아주 다르게 생겼어요.

- **위꼬리**는 $1 - F(x) \approx e^{-z}$로, 지수분포처럼 줄어요.
- **아래꼬리**는 $F(x) = \exp(-e^{-z})$로, 훨씬 빨리 0이 돼요. $z = -10$이면 $e^{-e^{10}} = e^{-22026}$이에요.

```python
>>> X.ccdf(3.0)
0.048568007099546597
>>> X.cdf(-3.0)
1.892178694838293e-09
>>> X.cdf(-10.0)
0.0
>>> X.logcdf(-10.0)
-22026.465794806718
```

`cdf(-10.0)`은 float64로 나타낼 수 없을 만큼 작아서 0이지만, `logcdf`는 그 로그를 정확히 내요. 로그 자체가 float64 범위를 넘으면(z가 약 −710보다 작으면 $-e^{-z}$가 넘쳐요) `logcdf`도 −inf예요. 위꼬리는 그렇게 빨리 줄지 않아서 `logccdf`가 끝까지 값을 내요.

```python
>>> X.logcdf(-800.0)
-inf
>>> X.logccdf(1000.0)
-1000.0
```

분위수는 닫힌 꼴이에요. 0과 1에서는 지지집합의 끝이고, [0, 1] 밖은 NaN이에요.

```python
>>> X.icdf(0.5)
0.36651292058166435
>>> X.iccdf(1e-300)
690.7755278982137
>>> X.icdf(0.0), X.icdf(1.0), X.icdf(-0.1)
(-inf, inf, nan)
```

### 예: 재현 기간과 설계 강수량

어떤 지역의 연 최대 일강수량(mm)이 `Gumbel(mu=100, sigma=20)`을 따른다고 해 볼게요. "100년에 한 번 넘는 비"(100년 빈도 강수량)는 한 해에 넘을 확률이 1/100인 값이에요. 위꼬리 확률로 정하니 `iccdf`를 써요.

```python
>>> rain = sd.stats.Gumbel(mu=100.0, sigma=20.0)
>>> rain.iccdf(0.01)
192.0029845355316
>>> rain.iccdf(0.001)
238.14510141047433
>>> rain.ccdf(200.0)
0.00671529793215851
```

100년 빈도는 약 192mm, 1000년 빈도는 약 238mm예요. 200mm를 넘는 해는 확률 0.0067, 곧 평균 150년에 한 번꼴이에요.

## 요약값

$\gamma \approx 0.5772$는 오일러–마스케로니 상수, $\zeta(3) \approx 1.2021$은 리만 제타 함수의 값이에요.

| 메서드 | 값 |
|---|---|
| `mean()` | $\mu + \gamma\sigma$ |
| `median()` | $\mu - \sigma\log\log 2$ |
| `mode()` | $\mu$ |
| `variance()` | $\pi^2\sigma^2/6$ |
| `skewness()` | $12\sqrt6\,\zeta(3)/\pi^3 \approx 1.1395$ |
| `kurtosis()` | 12/5 (초과 첨도) |
| `entropy()` | $\log\sigma + \gamma + 1$ |

왜도와 첨도는 매개변수와 상관없이 늘 같아요. 모든 모멘트가 유한해요.

```python
>>> X.mode(), X.median(), X.mean()
(0.0, 0.36651292058166435, 0.5772156649015329)
>>> X.variance()
1.6449340668482264
>>> X.skewness(), X.kurtosis()
(1.1395470994046486, 2.4)
>>> X.entropy()
1.5772156649015328
```

최빈값 < 중앙값 < 평균 순서는 오른쪽 꼬리가 긴 분포의 전형이에요.

## 다른 분포와의 관계

### 일반화 극값 분포의 c = 0

[일반화 극값 분포](/api/stats/gev/)(GEV)는 Gumbel을 포함하는 더 넓은 가족이에요. `GEV(c=0)`이 정확히 `Gumbel`이에요(모든 메서드가 비트까지 같아요).

```python
>>> sd.stats.GEV(c=0.0, mu=1.0, sigma=2.0).cdf(3.0)
0.6922006275553464
>>> sd.stats.Gumbel(mu=1.0, sigma=2.0).cdf(3.0)
0.6922006275553464
```

자료의 최댓값이 위로 막혀 있는지, 꼬리가 거듭제곱으로 두꺼운지 모를 때는 GEV로 맞춰 보고 c가 0에 가까운지 보는 것이 보통이에요.

### 지수분포의 최댓값

지수분포 `Exponential()`에서 값을 $n$개 뽑은 최댓값을 $M_n$이라고 하면 $P(M_n \le x) = F_{\mathrm{Exp}}(x)^n$이에요. $M_n - \log n$의 분포는 $n$이 커질수록 표준 Gumbel로 다가가요.

```python
>>> import math
>>> E = sd.stats.Exponential()
>>> [E.cdf(1.0 + math.log(n)) ** n for n in (10, 1000, 1000000)]
[0.6874151466162174, 0.6921537780661359, 0.6922005807429532]
>>> X.cdf(1.0)
0.6922006275553464
```

거꾸로, $X$가 표준 Gumbel이면 $e^{-X}$는 지수분포를 따라요. 그래서 `X.cdf(x)`는 `E.ccdf(exp(-x))`와 같아요.

```python
>>> X.cdf(2.5), E.ccdf(math.exp(-2.5))
(0.9211936551755158, 0.9211936551755158)
```

### 최솟값형은 부호를 뒤집어서

최솟값이 따르는 Gumbel(최솟값형)은 최댓값형의 부호를 뒤집은 것이에요. $Y = -X$이고 $X$가 `Gumbel(mu=-m, sigma=s)`이면 $Y$는 위치 m, 척도 s인 최솟값형이에요. 그래서 최솟값형의 누적분포 $P(Y \le y)$는 `Gumbel(mu=-m, sigma=s).ccdf(-y)`예요.

```python
>>> Xneg = sd.stats.Gumbel(mu=-5.0, sigma=2.0)
>>> Xneg.ccdf(-3.0)
0.30779937244465366
```

위치 5, 척도 2인 최솟값형에서 $P(Y \le 3)$이 약 0.308이라는 뜻이에요. 분위수도 마찬가지로 `-Xneg.iccdf(p)`가 최솟값형의 `icdf(p)`예요.

### 로지스틱 분포

서로 독립인 표준 Gumbel 두 개의 차는 [표준 로지스틱 분포](/api/stats/logistic/)를 따라요.

## 정확도와 범위

Gumbel은 닫힌 꼴 분포라서 매개변수와 입력의 정의역 전체에서 정확도를 보장해요.

- 값 메서드와 요약값: 상대오차 1e-14 이하. 이중 지수로 아주 작아지는 아래꼬리의 `cdf`와 `logcdf`도 상대 정확도예요.
- `logpdf`, `entropy`: 오차가 1e-14·max(1, |값|) 이하예요.
- 역함수 넷: 상대오차가 1e-14에 입력에 대한 조건수를 곱한 값 이하예요.

값이 float64 범위를 넘는 곳에서는 극한값(0, 1, ±inf)을 내요. `logcdf(-800.0)`이 −inf인 것도 참값 $-e^{800}$의 크기가 float64 범위를 넘기 때문이에요.

구현은 [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.gumbel_r(loc, scale)`에 해당해요. 이름이 `mu`, `sigma`이고 키워드로만 받아요. `gumbel_l`(최솟값형)에 해당하는 클래스는 없어요. 위처럼 부호를 뒤집어 쓰세요.
- 위꼬리 로그가 깊어도 값을 내요. `Gumbel().logccdf(1000.0)`은 −1000.0이고 scipy 1.18.1의 `gumbel_r.logsf(1000.0)`은 −inf예요.
- `kurtosis()`는 초과 첨도(2.4)예요.
- 메서드 이름은 `sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`예요.
