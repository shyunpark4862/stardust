## 어떤 분포인가요

**이산 균등분포**(discrete uniform distribution)는 정해진 범위의 정수가 모두 같은 확률로 나오는 분포예요. 공정한 주사위가 대표적이에요. 1부터 6까지가 각각 1/6이에요.

- 주사위, 제비뽑기: 결과가 몇 개 있고 어느 것도 더 자주 나오지 않을 때
- 무작위 번호 고르기: 0부터 n − 1까지의 번호(배열의 인덱스 등) 중 하나를 고를 때
- 기준 모형: "아무 정보가 없으면 모든 경우가 똑같다"고 두고 비교할 때

범위는 **`low` 이상 `high` 미만**이에요. `high`는 들어가지 않아요. 그래서 주사위는 `DiscreteUniform(low=1, high=7)`이에요.

```python
>>> import stardust as sd
>>> die = sd.stats.DiscreteUniform(low=1, high=7)
>>> die.pmf(sd.arange(0.0, 8.0))
array([                0.0, 0.16666666666666666, 0.16666666666666666,
       0.16666666666666666, 0.16666666666666666, 0.16666666666666666,
       0.16666666666666666,                 0.0], dtype=float64)
>>> die.support()
(1.0, 6.0)
```

## 만들기와 매개변수: 반열린 구간 [low, high)

`low`와 `high`는 키워드로만 주고, 기본값이 없어요. 둘 다 정수이고 `low < high`여야 해요. 나오는 정수는 `low, low + 1, …, high − 1`이고 개수는 $N = \text{high} - \text{low}$예요.

`high`를 빼는 규칙은 Python의 `range(low, high)`, [`sd.random`의 `integers`](/api/random/integers/)와 같아요. 같은 두 수를 주면 나올 수 있는 정수의 범위도 같아요.

```python
>>> rng = sd.random.default_rng(3)
>>> rng.integers(1, 7, shape=8)
array([2, 3, 1, 1, 1, 1, 2, 6], dtype=int64)
>>> die.sample((8,), rng=rng)
array([6.0, 5.0, 6.0, 3.0, 6.0, 6.0, 2.0, 6.0], dtype=float64)
```

둘 다 1부터 6까지만 나오고 7은 나오지 않아요. 다만 `integers`는 int64 배열을, `sample`은 정수 값을 담은 float64 배열을 돌려줘요.

<Callout type="warn" title="주사위를 high=6으로 만들지 마세요">
  `DiscreteUniform(low=1, high=6)`은 1부터 5까지예요. 6이 나오지 않아요. 끝까지 넣고 싶으면 `high`를 하나 크게 주세요.
</Callout>

```python
>>> sd.stats.DiscreteUniform(low=1, high=6).pmf(6)
0.0
>>> sd.stats.DiscreteUniform(low=1, high=6).support()
(1.0, 5.0)
```

정의역 밖이면 에러 없이 NaN이에요. `low`와 `high`가 같으면 나올 정수가 없어서 NaN이고, `low`가 더 크거나 정수가 아니어도 NaN이에요. `high = low + 1`은 정수 하나만 나오는 분포예요.

```python
>>> sd.stats.DiscreteUniform(low=3, high=3).pmf(3)
nan
>>> sd.stats.DiscreteUniform(low=1.5, high=4).mean()
nan
>>> one = sd.stats.DiscreteUniform(low=0, high=1)
>>> one.pmf(0), one.mode(), one.variance()
(1.0, 0.0, 0.0)
```

배열을 주면 브로드캐스트해요.

```python
>>> D = sd.stats.DiscreteUniform(low=0, high=sd.asarray([2.0, 4.0, 10.0]))
>>> D.variance()
array([0.25, 1.25, 8.25], dtype=float64)
>>> D.cdf(sd.asarray([[0.0], [1.0]]))
array([[ 0.5, 0.25,  0.1],
       [ 1.0,  0.5,  0.2]], dtype=float64)
```

## 확률질량과 누적분포

$$
P(X = k) = \frac{1}{N} \quad (k = \text{low}, \dots, \text{high} - 1), \qquad
F(k) = \frac{\lfloor k \rfloor - \text{low} + 1}{N}
$$

범위 밖의 `pmf`는 0이고 `logpmf`는 −inf예요. 정수가 아닌 $k$의 `pmf`는 0, `cdf`는 그 아래 정수에서의 값이에요. 분위수는 `icdf(p)`가 cdf(k) ≥ p인 가장 작은 정수예요. 공통 규칙은 [분포의 메서드](/api/stats/methods/)에 있어요.

```python
>>> die.cdf(3), die.cdf(3.9), die.ccdf(3)
(0.5, 0.5, 0.5)
>>> die.pmf(2.5), die.logpmf(3)
(0.0, -1.791759469228055)
>>> die.icdf(sd.asarray([0.1, 1/6, 0.17, 0.5, 0.99]))
array([1.0, 1.0, 2.0, 3.0, 6.0], dtype=float64)
>>> die.icdf(0.0), die.icdf(1.0)
(1.0, 6.0)
>>> die.iccdf(0.5)
3.0
```

`icdf(1/6)`은 1이에요. cdf(1)이 정확히 1/6이라 1에서 이미 조건을 채워요. `icdf(0)`과 `icdf(1)`은 지지집합의 두 끝이에요.

## 요약값

$$
\mathrm{E}[X] = \frac{\text{low} + \text{high} - 1}{2}, \qquad
\mathrm{Var}[X] = \frac{N^2 - 1}{12}, \qquad
\text{초과 첨도} = -\frac{6(N^2 + 1)}{5(N^2 - 1)}, \qquad
H = \log N
$$

왜도는 대칭이라 0이에요. 첨도는 정규분포를 0으로 둔 초과 첨도이고, 늘 음수예요(꼬리가 없는 분포라서요).

```python
>>> die.mean(), die.variance(), die.standard_deviation()
(3.5, 2.9166666666666665, 1.707825127659933)
>>> die.skewness(), die.kurtosis()
(0.0, -1.2685714285714285)
>>> die.median()
3.0
>>> die.entropy()
1.791759469228055
```

**최빈값은 NaN이에요.** 모든 정수의 확률이 같아서 가장 큰 하나를 고를 수 없기 때문이에요. 정수가 하나뿐인 분포(`high = low + 1`)만 그 정수가 최빈값이에요. 그런 분포는 분산이 0이고 왜도·첨도가 NaN이에요.

```python
>>> die.mode()
nan
>>> one.skewness(), one.kurtosis()
(nan, nan)
```

## 표본

`sample`은 `rng`를 꼭 받아요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요. 범위의 폭이 $2^{64}$ 이상이면 뽑을 수 없어서 NaN이에요.

```python
>>> rng = sd.random.default_rng(0)
>>> die.sample((2, 5), rng=rng)
array([[5.0, 4.0, 3.0, 6.0, 1.0],
       [2.0, 3.0, 1.0, 6.0, 2.0]], dtype=float64)
```

## 다른 분포와의 관계

**연속 균등분포를 내림한 것이에요.** [`Uniform(a=low, b=high)`](/api/stats/uniform/)에서 뽑은 실수를 내림하면 `DiscreteUniform(low, high)`이에요. 그래서 누적분포가 $F(k) = \text{Uniform의 cdf}(\lfloor k \rfloor + 1)$이에요.

```python
>>> k = sd.asarray([1.0, 2.5, 6.0])
>>> die.cdf(k)
array([0.16666666666666666,  0.3333333333333333,                 1.0], dtype=float64)
>>> sd.stats.Uniform(a=1.0, b=7.0).cdf(sd.floor(k) + 1)
array([0.16666666666666666,  0.3333333333333333,                 1.0], dtype=float64)
```

**베타이항 분포의 특수한 경우예요.** [`BetaBinomial(n, a=1, b=1)`](/api/stats/beta-binomial/)은 0부터 n까지가 모두 같은 확률이라 `DiscreteUniform(low=0, high=n + 1)`과 같아요.

```python
>>> sd.stats.BetaBinomial(n=10, a=1.0, b=1.0).pmf(3)
0.09090909090909091
>>> sd.stats.DiscreteUniform(low=0, high=11).pmf(3)
0.09090909090909091
```

## 정확도와 범위

닫힌 꼴이라 정의역 전체에서 상대 1e-14 안이에요. 범위가 아주 넓어도 값이 나와요.

```python
>>> wide = sd.stats.DiscreteUniform(low=0, high=1e15)
>>> wide.pmf(123456789.0)
1e-15
>>> wide.icdf(0.3)
299999999999999.0
```

`high − low`가 float64 범위를 넘으면 NaN이에요.

```python
>>> sd.stats.DiscreteUniform(low=-1e308, high=1e308).pmf(0)
nan
```

구현은 [이산 분포의 수치 기법](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

scipy의 `randint(low, high)`와 같은 분포이고, 범위도 같은 [low, high)예요.

```python
>>> import scipy.stats
>>> float(scipy.stats.randint(1, 7).pmf(7)), float(scipy.stats.randint(1, 7).pmf(6))
(0.0, 0.16666666666666666)
>>> die.pmf(7), die.pmf(6)
(0.0, 0.16666666666666666)
```

- 이름이 `DiscreteUniform`이고, 매개변수는 키워드로만 받아요. `DiscreteUniform(1, 7)`은 `TypeError`예요.
- `ppf`·`isf`는 `icdf`·`iccdf`, `sf`는 `ccdf`예요. 분위수의 정의는 scipy와 같아요.
- 정수 표본이 필요하면 `sample` 대신 [`rng.integers(low, high)`](/api/random/integers/)를 쓰면 int64로 받아요.
