## 어떤 분포인가요

**파레토 분포**는 "작은 값은 아주 많고, 큰 값은 드물지만 엄청나게 큰" 자료를 나타내요. 경제학자 파레토가 "땅의 80%를 인구의 20%가 가진다"는 관찰에서 출발한 분포라서, 흔히 말하는 80/20 법칙의 바탕이에요.

- 소득과 재산: 일정 금액 이상의 고소득층 분포.
- 크기의 분포: 도시 인구, 회사 규모, 파일 크기, 웹 페이지 방문 수.
- 보험과 위험: 일정 금액을 넘는 대형 손해액, 재해 피해 규모.

두 가지 특징이 있어요.

1. 문턱이 있어요. 값은 늘 `scale` 이상이에요. "연소득 1억 원 이상인 사람들의 소득"처럼, 어떤 문턱 위만 보는 자료에 맞춰요.
2. 꼬리가 거듭제곱으로 줄어요. $x$를 넘을 확률이 $(\text{scale}/x)^b$예요. 지수분포나 정규분포의 꼬리는 $x$가 커지면 급격히 0이 되지만, 파레토의 꼬리는 $x$를 2배로 할 때마다 늘 같은 비율 $2^{-b}$만큼만 줄어요.

```python
>>> import stardust as sd
>>> X = sd.stats.Pareto(b=3.0, scale=2.0)
>>> X.support()
(2.0, inf)
>>> X.ccdf(4.0), X.ccdf(8.0)
(0.125, 0.015625)
```

## 만들기와 매개변수

- `b`: 모양. **꼬리 지수**라고도 해요. 0보다 커야 하고, 기본값이 없어서 꼭 줘야 해요. 작을수록 꼬리가 두꺼워요.
- `scale`: 척도. 0보다 커야 하고 기본값은 1이에요. 지지집합의 시작점이기도 해요.

```python
>>> sd.stats.Pareto(b=1.5)
Pareto(b=1.5, scale=1.0)
>>> sd.stats.Pareto()
Traceback (most recent call last):
    ...
TypeError: Pareto(): missing 1 required keyword-only argument: 'b'
```

<Callout type="warn" title="값은 scale부터 시작해요">
  `Pareto`의 지지집합은 $[\text{scale}, \infty)$예요. 0부터가 아니에요. `scale`보다 작은 x에서 `pdf`는 0, `cdf`는 0이에요. 0부터 시작하는 두꺼운 꼬리 분포가 필요하면, 파레토에서 `scale`을 뺀 꼴(Lomax 분포)은 $P(Y \le y) = $ `Pareto(b=b, scale=s).cdf(y + s)`로 옮겨 쓰세요.
</Callout>

매개변수는 배열이어도 돼요. 매개변수끼리, 그리고 입력과 브로드캐스트해요.

```python
>>> Y = sd.stats.Pareto(b=sd.asarray([1.0, 2.0, 3.0]))
>>> Y.ccdf(8.0)
array([      0.125,    0.015625, 0.001953125], dtype=float64)
```

`b`나 `scale`이 0 이하이거나 무한대·NaN이면 그 원소의 결과가 모두 NaN이에요.

```python
>>> sd.stats.Pareto(b=2.0, scale=-1.0).cdf(2.0)
nan
```

## 밀도와 누적분포

$x \ge \text{scale}$에서 $s = \text{scale}$이라고 두면

$$
P(X > x) = \left(\frac{s}{x}\right)^{b}, \qquad
F(x) = 1 - \left(\frac{s}{x}\right)^{b}, \qquad
f(x) = \frac{b\, s^{b}}{x^{b+1}}
$$

이고, $x$가 $s$보다 작으면 $f = 0$, $F = 0$이에요. 분위수도 닫힌 꼴이에요.

$$
F^{-1}(p) = s\,(1 - p)^{-1/b}, \qquad \text{iccdf}(q) = s\, q^{-1/b}
$$

```python
>>> X.pdf(2.0)
1.5
>>> X.pdf(1.999), X.cdf(1.999)
(0.0, 0.0)
>>> X.cdf(2.0)
0.0
>>> X.icdf(0.5)
2.5198420997897464
>>> X.iccdf(0.001)
20.0
>>> X.icdf(0.0), X.icdf(1.0)
(2.0, inf)
```

밀도는 시작점 `scale`에서 가장 높아요(높이 $b/s$). `icdf(0)`은 지지집합의 시작 `scale`이고 `icdf(1)`은 inf예요.

### 꼬리는 직선이에요

거듭제곱 꼬리는 로그를 취하면 직선이 돼요. $\log P(X > x) = b\log s - b\log x$라서, 가로축과 세로축을 모두 로그로 그리면 기울기가 $-b$인 직선이에요. 실제 자료가 파레토인지 볼 때 흔히 이렇게 그려 봐요.

### 꼬리와 시작점의 정확도

`ccdf`는 위꼬리를 직접 계산하고, `logccdf`는 확률이 float64로 나타낼 수 있는 범위 아래로 내려가도 값을 내요. 시작점 바로 위에서 `cdf`는 아주 작은 값인데, 이것도 `1 - ccdf`로 만들지 않고 상대 정확도로 계산해요.

```python
>>> X.ccdf(1e300)
0.0
>>> X.logccdf(1e300)
-2070.2471421529613
>>> X.iccdf(1e-300)
2e+100
>>> X.cdf(2.0000000001)
1.5000001239605566e-10
```

## 요약값

| 메서드 | 값 | 유한한 범위 |
|---|---|---|
| `mean()` | $\dfrac{b\,s}{b - 1}$ | $b > 1$ |
| `variance()` | $\dfrac{b\,s^2}{(b-1)^2(b-2)}$ | $b > 2$ |
| `skewness()` | $\dfrac{2(1+b)}{b-3}\sqrt{\dfrac{b-2}{b}}$ | $b > 3$ |
| `kurtosis()` | $\dfrac{6(b^3 + b^2 - 6b - 2)}{b(b-3)(b-4)}$ (초과 첨도) | $b > 4$ |
| `median()` | $s\,2^{1/b}$ | 모든 b |
| `mode()` | $s$ (지지집합의 시작) | 모든 b |
| `entropy()` | $\log(s/b) + 1/b + 1$ | 모든 b |

$k$차 모멘트는 $b > k$일 때만 유한해요. 꼬리가 두꺼울수록(b가 작을수록) 낮은 모멘트부터 무한해져요. 발산하는 모멘트는 inf이고, 그보다 낮은 모멘트가 이미 무한해서 정의할 수 없으면 NaN이에요.

```python
>>> Y = sd.stats.Pareto(b=sd.asarray([0.5, 1.0, 2.0, 3.0]))
>>> Y.mean()
array([inf, inf, 2.0, 1.5], dtype=float64)
>>> Y.variance()
array([ nan,  nan,  inf, 0.75], dtype=float64)
>>> X.skewness(), X.kurtosis()
(inf, inf)
>>> sd.stats.Pareto(b=4.0).kurtosis()
inf
```

`b = 3`이면 분산은 유한하지만 왜도(3차 모멘트)가 무한해서 inf, `b ≤ 2`이면 분산이 무한해서 왜도·첨도는 NaN이에요. 중앙값, 최빈값, 엔트로피는 모든 `b`에서 유한해요. 엔트로피는 미분 엔트로피라 음수가 될 수 있어요.

```python
>>> X.median(), X.mode(), X.mean()
(2.5198420997897464, 2.0, 3.0)
>>> sd.stats.Pareto(b=4.0).entropy()
-0.13629436111989063
```

<Callout type="warn" title="평균이 무한하면 표본 평균이 수렴하지 않아요">
  `b ≤ 1`이면 평균이 무한이에요. 이런 자료의 표본 평균은 표본을 늘려도 한 값으로 모이지 않고, 가끔 나오는 아주 큰 값 하나에 끌려 계속 커져요. `1 < b ≤ 2`이면 평균은 유한하지만 분산이 무한해서 표본 평균이 아주 느리게 모여요. 아래에서 `b = 1.1`(평균 11)은 표본 백만 개에서도 8 남짓이지만, `b = 3`(평균 1.5)은 천 개만으로도 거의 맞아요.
</Callout>

```python
>>> for b in (1.1, 3.0):
...     s = sd.stats.Pareto(b=b).sample(1000000, rng=sd.random.default_rng(1))
...     print(b, [round(float(sd.mean(s[:n])), 3) for n in (1000, 100000, 1000000)])
1.1 [5.05, 6.854, 8.184]
3.0 [1.468, 1.493, 1.499]
```

## 예: 80/20 법칙

"상위 20%가 전체의 80%를 가진다"가 정확히 성립하는 파레토는 $b = \log 5/\log 4 \approx 1.161$이에요. 파레토에서 상위 비율 $q$에 드는 사람이 가진 몫은 $q^{(b-1)/b}$이고, 문턱 $t$로 쓰면 $(t/s)^{1-b}$예요.

```python
>>> import math
>>> b = math.log(5) / math.log(4)
>>> W = sd.stats.Pareto(b=b)
>>> t = W.iccdf(0.2)
>>> t
4.0
>>> (t / 1.0) ** (1 - b)
0.8
```

상위 20%는 `scale`의 4배 이상을 가진 사람이고, 이들이 전체의 80%를 가져요. 이때 평균은 중앙값의 약 4배예요. 평균이 "보통 사람"을 대표하지 못하는 전형적인 경우예요.

```python
>>> W.median(), W.mean()
(1.8167414493210314, 7.212567439010783)
```

## 표본

`rng`를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> sd.stats.Pareto(b=1.5).sample(3, rng=rng)
array([1.2675947690557983, 1.1397899651933283,  25.93762594339311], dtype=float64)
```

세 값 중 하나가 나머지보다 스무 배 커요. 꼬리가 두꺼운 분포에서는 흔한 일이에요.

## 다른 분포와의 관계

### 로그를 취하면 지수분포

$X$가 `Pareto(b, scale=s)`이면 $\log(X/s)$는 척도 $1/b$인 [지수분포](/api/stats/exponential/)를 따라요. 그래서 파레토의 꼬리 확률은 지수분포의 꼬리 확률에 로그를 넣은 것과 같아요.

```python
>>> E = sd.stats.Exponential(scale=1 / 3)
>>> P3 = sd.stats.Pareto(b=3.0)
>>> P3.ccdf(2.0), E.ccdf(math.log(2.0))
(0.125, 0.125)
```

자료에서 `b`를 어림할 때도 이 관계를 써요. $\log(x_i/s)$의 평균이 지수분포의 평균 $1/b$이에요.

### 극값 분포

파레토처럼 꼬리가 거듭제곱인 값의 기간별 최댓값은 `c < 0`인 [일반화 극값 분포](/api/stats/gev/)로 모여요. 그 꼬리 지수가 $b = 1/|c|$예요.

### 로그정규와의 차이

[로그정규분포](/api/stats/lognormal/)도 오른쪽 꼬리가 길지만, 모든 모멘트가 유한하고 로그-로그 그림에서 꼬리가 점점 아래로 휘어요. 로그-로그 그림에서 꼬리가 직선이면 파레토, 휘면 로그정규 쪽이 더 맞아요.

## 정확도와 범위

파레토는 닫힌 꼴 분포라서 매개변수와 입력의 정의역 전체에서 정확도를 보장해요.

- 값 메서드와 요약값: 상대오차 1e-14 이하. 시작점 바로 위의 아주 작은 `cdf`와 먼 꼬리의 `ccdf`, `logccdf`도 마찬가지예요.
- `logpdf`, `entropy`: 오차가 1e-14·max(1, |값|) 이하.
- 역함수 넷: 상대오차가 1e-14에 입력에 대한 조건수를 곱한 값 이하.

값이 float64 범위를 넘으면 극한값을 내요. 예를 들어 `b`가 아주 작으면 분위수가 아주 커지고, 넘치면 inf예요.

```python
>>> sd.stats.Pareto(b=1e-3).icdf(0.5)
1.0715086071862517e+301
>>> X.ilogccdf(-1e4)
inf
```

구현은 [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.pareto(b, scale=s)`에 해당해요. `loc`이 없어요. 지지집합은 언제나 $[\text{scale}, \infty)$예요. scipy에서 `loc`으로 옮긴 파레토는 `Pareto(...)`의 결과에 직접 더하거나 입력에서 빼서 쓰세요.
- 모멘트의 발산 표시가 달라요. `Pareto(b=1).variance()`는 NaN(scipy 1.18.1은 inf), `Pareto(b=3).skewness()`와 `Pareto(b=4).kurtosis()`는 inf(scipy는 nan)예요. stardust는 그 모멘트가 발산하면 inf, 더 낮은 모멘트가 이미 무한해서 정의할 수 없으면 NaN을 내요.
- 깊은 꼬리의 로그를 내요. `Pareto(b=3, scale=2).logccdf(1e300)`은 −2070.247…이고 scipy의 `logsf`는 −inf예요.
- 시작점 바로 위의 작은 `cdf`가 정확해요. `Pareto(b=3, scale=2).cdf(2.0000000001)`은 1.5000001239605566e-10이고(참값 1.50000012396055647…e-10), scipy는 1.5000001241105565e-10으로 소수 열째 자리부터 달라요.
- `kurtosis()`는 초과 첨도예요.
