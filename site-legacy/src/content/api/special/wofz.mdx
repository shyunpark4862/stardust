## 한눈에 보기

`wofz`는 **Faddeeva 함수** w(z)를 계산해요. 복소수에서의 상보 오차함수 erfc에 $e^{-z^2}$을 곱해서 크기를 다듬은 함수예요. 이름의 "wofz"는 "w of z", 곧 w(z)라는 뜻이에요.

$$w(z) = e^{-z^2}\,\mathrm{erfc}(-iz) = e^{-z^2}\left(1 + \frac{2i}{\sqrt{\pi}}\int_0^z e^{t^2}\,dt\right)$$

erfc는 금방 아주 커지거나 아주 작아지고, $e^{-z^2}$은 그 반대로 움직여요. 둘을 따로 계산해서 곱하면 넘치거나(inf) 0이 되어 버리는 곳이 많지만, w(z)는 그 곱을 한 번에 계산해서 넓은 영역에서 적당한 크기의 값을 내요. 그래서 복소수 오차함수가 필요한 계산의 기본 도구로 쓰여요.

- 분광학: 스펙트럼 선의 모양. 원자의 열운동이 만드는 Gauss 모양과 충돌·수명이 만드는 Lorentz 모양을 합친 **Voigt 선 모양**이 w(z)의 실수부예요.
- 플라스마 물리: 플라스마 속 파동의 성질을 정하는 플라스마 분산 함수 $Z(\zeta) = i\sqrt{\pi}\,w(\zeta)$ (Im ζ > 0).
- 복사 전달, 천체물리: 별 대기의 흡수선 계산.
- 수학: 복소수 erf·erfc를 안정하게 계산하기, 실수 x의 Dawson 적분.

실수를 넣어도 결과는 복소수예요.

```python
>>> import stardust as sd
>>> sd.special.wofz(sd.asarray([0.0, 1.0, 2.0]))
array([                                   (1+0j),
       (0.36787944117144233+0.6071577058413937j),
       (0.01831563888873418+0.3400262170660662j)], dtype=complex128)
>>> sd.special.wofz(1 + 1j)
(0.3047442052569126+0.20821893820283163j)
```

## 실수축 위의 w(x)

z가 실수 x이면 w(x)의 실수부와 허수부는 각각 익숙한 함수예요.

$$\mathrm{Re}\,w(x) = e^{-x^2}, \qquad \mathrm{Im}\,w(x) = \frac{2}{\sqrt{\pi}}\,D(x)$$

D(x)는 **Dawson 적분** $D(x) = e^{-x^2}\int_0^x e^{t^2}dt$예요. 실수부는 종 모양으로 빠르게 0으로 가지만, 허수부는 $1/(\sqrt{\pi}\,x)$처럼 아주 천천히 줄어들어요.

stardust에는 Dawson 적분 함수가 따로 없어요. 위 식대로 `wofz`의 허수부로 계산하세요. 복소수 배열의 실수부와 허수부는 [`sd.real`, `sd.imag`](/api/array/complex/)로 꺼내요.

```python
>>> x = sd.asarray([0.5, 2.0])
>>> sd.imag(sd.special.wofz(x)) * sd.sqrt(sd.pi) / 2
array([ 0.4244363835020223, 0.30134038892379195], dtype=float64)
>>> sd.real(sd.special.wofz(x))
array([ 0.7788007830714049, 0.01831563888873418], dtype=float64)
>>> sd.exp(-x * x)
array([ 0.7788007830714049, 0.01831563888873418], dtype=float64)
```

첫째 줄이 D(0.5), D(2)예요.

## 허수축 위의 w(iy)

z = iy(순허수)이면 w는 실수가 되고, [`erfcx`](/api/special/erf/)(스케일한 상보 오차함수 $e^{y^2}\mathrm{erfc}(y)$)와 같아요.

$$w(iy) = e^{y^2}\,\mathrm{erfc}(y) = \mathrm{erfcx}(y)$$

```python
>>> sd.special.wofz(2j)
(0.2553956763105058+0j)
>>> sd.special.erfcx(2.0)
0.2553956763105058
```

이 관계에서 `wofz`가 왜 필요한지가 보여요. y = 30이면 $e^{900}$은 float64를 넘쳐서 `inf`, erfc(30)은 너무 작아서 `0.0`이 돼요. 따로 계산해서 곱하면 `inf × 0`이라 NaN이에요. `wofz`는 곱한 결과를 바로 계산하므로 정확한 값이 나와요.

```python
>>> sd.exp(30.0 ** 2) * sd.special.erfc(30.0)
nan
>>> sd.special.wofz(30j)
(0.018795888861416754+0j)
```

## Voigt 선 모양

스펙트럼 선은 두 가지 원인으로 퍼져요. 원자의 열운동은 Gauss 모양(폭 σ)을, 충돌과 들뜬 상태의 수명은 Lorentz 모양(반폭 γ)을 만들어요. 실제 선은 둘을 합친(합성곱한) **Voigt 모양**이고, w로 이렇게 써요.

$$V(x;\sigma,\gamma) = \frac{\mathrm{Re}\,w(z)}{\sigma\sqrt{2\pi}}, \qquad z = \frac{x + i\gamma}{\sigma\sqrt{2}}$$

```python
>>> x = sd.asarray([0.0, 1.0, 3.0])
>>> sigma, gamma = 1.0, 0.5
>>> z = (x + 1j * gamma) / (sigma * sd.sqrt(2.0))
>>> sd.real(sd.special.wofz(z)) / (sigma * sd.sqrt(2 * sd.pi))
array([0.27895547038929447,  0.2001796375908392, 0.02833640816219899], dtype=float64)
```

## erf·erfc와의 관계

복소수 erfc와 erfcx는 w를 90° 돌린 점에서의 값이에요.

$$\mathrm{erfc}(z) = e^{-z^2}\,w(iz), \qquad \mathrm{erfcx}(z) = w(iz)$$

[`erf`, `erfc`, `erfcx`](/api/special/erf/)도 복소수를 받으니, 그 값이 필요하면 그 함수를 바로 쓰면 돼요. 결과는 같아요.

```python
>>> z = 0.3 + 0.4j
>>> sd.special.erfcx(z)
(0.6552440614965639-0.2536125482724491j)
>>> sd.special.wofz(1j * z)
(0.6552440614965639-0.2536125482724491j)
```

## 대칭과 아래쪽 반평면

w에는 두 가지 대칭이 있어요.

$$w(-\bar z) = \overline{w(z)}, \qquad w(-z) = 2e^{-z^2} - w(z)$$

첫째는 왼쪽·오른쪽을 뒤집으면 켤레가 된다는 뜻이고, 둘째는 위쪽 반평면(Im z > 0)과 아래쪽 반평면(Im z &lt; 0)을 잇는 식이에요.

```python
>>> z = 1 + 2j
>>> sd.special.wofz(-z.conjugate()), sd.special.wofz(z).conjugate()
((0.2184926152748907-0.09299780939260187j), (0.2184926152748907-0.09299780939260187j))
>>> sd.special.wofz(-z)
(-26.476058778199207+30.30857111674331j)
>>> 2 * sd.exp(-z * z) - sd.special.wofz(z)
(-26.476058778199207+30.30857111674331j)
```

위쪽 반평면에서 w는 크기가 1 이하로 얌전해요. 아래쪽 반평면에서는 둘째 식의 $2e^{-z^2}$ 때문에 아주 빠르게 커질 수 있어요. 결과가 float64를 넘치면 `inf`가 돼요. 에러는 나지 않아요.

```python
>>> sd.special.wofz(sd.asarray([-1j, -26j, -30j]))
array([     (5.008980080762283-0j), (7.657724931490568e+293-0j),
                          (inf-0j)], dtype=complex128)
```

## 정확도

복소수의 오차는 실수부와 허수부를 따로 재지 않고 크기로 재요. 상대오차는 $|\text{계산값} - \text{참값}| / |\text{참값}|$이에요.

- **위쪽 반평면과 실수축(Im z ≥ 0)**: 상대오차 10⁻¹⁴ 이하. 앞 14자리쯤이 맞는다는 뜻이에요.
- **아래쪽 반평면(Im z &lt; 0)**: 여기서는 w가 0이 되는 점(영점)이 있어서, 영점 근처에서는 상대오차를 정의할 수 없어요. 대신 오차를 두 항의 크기에 대해 약속해요.

$$|\text{오차}| \le 10^{-14}\left(2\,|e^{-z^2}| + |w(-z)|\right)$$

  위의 대칭식 $w(z) = 2e^{-z^2} - w(-z)$에서 빼는 두 항의 크기예요. 두 항이 거의 같아서 서로 지워지는 곳에서는, 결과가 작아도 오차는 두 항의 크기를 기준으로 재요.

정의역 전체가 보장 영역이에요. 정확도를 재는 방법은 [특수함수의 기본](/api/special/basics/)에 있어요.

### 아주 큰 z에서 NaN이 나오는 곳

$e^{-z^2}$의 위상(복소수의 각도)은 $-2\,\mathrm{Re}\,z \cdot \mathrm{Im}\,z$예요. `wofz`는 이 곱을 반올림 없이 정확하게 다뤄서, $|z| = 10^{100}$ 근처에서도 아래쪽 반평면의 값이 맞아요. 하지만 $|\mathrm{Re}\,z \cdot \mathrm{Im}\,z|$가 float64가 나타낼 수 있는 범위를 넘으면(대략 $|z| > 10^{154}$이고 실수부와 허수부의 크기가 비슷할 때) 위상을 알 수 없어요. 위쪽 반평면에서는 w가 $i/(\sqrt{\pi}\,z)$에 가까워서 그 위상이 필요 없으니 값이 나오지만, 아래쪽 반평면에서는 $2e^{-z^2}$의 크기(2)만 알고 방향을 모르니 NaN이에요.

```python
>>> sd.special.wofz(complex(1e100, -1e100))
(1.3956469279427992+1.4325395814859103j)
>>> sd.special.wofz(complex(1e200, 1e200))
(2.8209479177387813e-201+2.8209479177387813e-201j)
>>> sd.special.wofz(complex(1e200, -1e200))
(nan+nanj)
```

## 특수값

| z | w(z) |
|:---:|---|
| `0` | `1` |
| `iy` (순허수) | `erfcx(y)`, 허수부는 정확히 0(부호는 Re z의 부호) |
| `±inf`, `inf·i`, 위쪽 반평면의 무한대 | `0` |
| `-inf·i` | `inf` |
| NaN이 섞인 값 | `nan + nan·i` |

```python
>>> sd.special.wofz(sd.asarray([sd.inf, -sd.inf, sd.nan]))
array([        0j,        -0j, (nan+nanj)], dtype=complex128)
>>> sd.special.wofz(complex(0.0, sd.inf)), sd.special.wofz(complex(0.0, -sd.inf))
(0j, (inf+0j))
```

실수축·허수축 위에서 0인 실수부나 허수부의 부호(+0인지 −0인지)는 z가 그 축으로 다가오는 방향에 맞춰 정해져요. 보통은 신경 쓸 일이 없지만, 결과를 다시 가지 자름이 있는 함수(예: [`lambertw`](/api/special/lambertw/)의 복소수 입력)에 넘길 때는 이 부호가 결과를 바꿀 수 있어요.

## 조심할 점

### 결과는 언제나 복소수예요

실수 배열을 넣어도 결과는 complex128이에요. 실수부만 필요하면 `sd.real(...)`로 꺼내세요. stardust 배열에는 `.real`, `.imag` 속성이 없고 함수로 꺼내요. Python 숫자를 넣으면 결과는 Python `complex`라서 `.real`, `.imag`를 쓸 수 있어요.

```python
>>> w = sd.special.wofz(1.0)
>>> type(w)
<class 'complex'>
>>> w.real
0.36787944117144233
```

### `out=`은 complex128 배열이어야 해요

결과가 복소수라서 float64 배열에는 쓸 수 없어요. `out=`의 나머지 규칙은 배열 영역의 [사칙연산](/api/array/arithmetic/)에서 설명한 것과 같아요.

```python
>>> buf = sd.empty(2, dtype=sd.complex128)
>>> sd.special.wofz(sd.asarray([0.0, 1.0]), out=buf) is buf
True
>>> sd.special.wofz(sd.asarray([0.0, 1.0]), out=sd.empty(2))
Traceback (most recent call last):
    ...
TypeError: wofz(): cannot implicitly convert complex128 to float64 (that would lose information); convert explicitly with astype
```

### 리스트는 받지 않아요

```python
>>> sd.special.wofz([0.0, 1.0])
Traceback (most recent call last):
    ...
TypeError: wofz(): 'z' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

| 함수 | 계산 | 복소수 | 언제 쓰나요 |
|---|---|:---:|---|
| `wofz(z)` | $e^{-z^2}\mathrm{erfc}(-iz)$ | 받아요 | Voigt 모양, 플라스마 분산 함수, Dawson 적분 |
| [`erfcx(z)`](/api/special/erf/) | $e^{z^2}\mathrm{erfc}(z) = w(iz)$ | 받아요 | 꼬리에서 넘치지 않는 erfc |
| [`erfc(z)`](/api/special/erf/) | $1 - \mathrm{erf}(z)$ | 받아요 | 정규분포의 꼬리, 복소수 erfc |
| [`erf(z)`](/api/special/erf/) | 오차함수 | 받아요 | 정규분포와 확산 |

`wofz`와 `erfcx`는 같은 함수를 90° 돌려 본 것이에요. 공식이 어느 쪽으로 적혀 있는지에 따라 고르면 돼요.

## scipy를 아는 분께

- 정의와 이름은 `scipy.special.wofz`와 같아요. 실수를 넣어도 결과가 complex인 것도 같아요. Python 숫자를 넣으면 numpy 스칼라가 아니라 Python `complex`가 나와요.
- `out=`은 keyword-only예요. 리스트는 받지 않아요.
- `dawsn`(Dawson 적분)과 `voigt_profile`은 없어요. 위의 식대로 `wofz`의 허수부와 실수부로 계산하세요.
- 아래쪽 반평면에서 $e^{-z^2}$의 위상을 정확하게 다뤄서, 아주 큰 z에서 값이 달라요. 예를 들어 `wofz(1e100-1e100j)`의 scipy 1.18.1 값은 크기(2)는 맞지만 방향이 틀려요(0.341 − 1.971i, 참값은 1.396 + 1.433i).
- 실수축·허수축 위에서 0인 부분의 부호는 도함수의 방향을 따라요. scipy의 부호와는 비트까지 같다고 보장하지 않아요.
