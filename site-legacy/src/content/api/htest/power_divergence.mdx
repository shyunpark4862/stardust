## 한눈에 보기

[`chisquare`](/api/htest/chisquare/)와 같은 것을 물어요. 범주마다 센 관측 빈도가 기대 빈도와 맞나요? 다른 점은 차이를 재는 자예요. Cressie와 Read(1984)는 흔히 쓰는 여러 통계량을 거듭제곱 $\lambda$ 하나로 묶었어요.

$$
2I^{\lambda} = \frac{2}{\lambda(\lambda + 1)} \sum_{i=1}^{k} O_i\left[\left(\frac{O_i}{E_i}\right)^{\lambda} - 1\right]
$$

- **귀무가설**: 범주마다의 확률이 기대한 값이에요.
- **대립가설**: 적어도 한 범주의 확률이 달라요.

어떤 $\lambda$든 귀무가설에서 빈도가 클 때 자유도 $k - 1 - \text{ddof}$의 카이제곱 분포를 따라요. 그래서 p값은 [`chisquare`](/api/htest/chisquare/)와 같은 방법으로 구해요.

```python
>>> import stardust as sd
>>> die = [8, 9, 12, 7, 11, 13]
>>> sd.htest.power_divergence(die)
PowerDivergenceResult(statistic=2.8, pvalue=0.730786, df=5)
>>> sd.htest.power_divergence(die, lambda_='log-likelihood')
PowerDivergenceResult(statistic=2.83378, pvalue=0.725594, df=5)
```

`lambda_=None`(기본값)은 Pearson의 카이제곱이라 `chisquare(die)`와 같아요. 우도비 검정(G 검정)의 값도 비슷해요. 빈도가 크고 관측이 기대에 가까우면 모든 $\lambda$의 값이 가까워요.

<Reference />

## `lambda_`: 통계량 고르기

| `lambda_` | $\lambda$ | 통계량 | 이름 |
|---|---|---|---|
| None, `'pearson'` | 1 | $\sum (O - E)^2/E$ | Pearson의 카이제곱 |
| `'log-likelihood'` | 0 | $2\sum O\log(O/E)$ | 우도비(G) 검정 |
| `'freeman-tukey'` | −1/2 | $4\sum (\sqrt{O} - \sqrt{E})^2$ | Freeman–Tukey |
| `'mod-log-likelihood'` | −1 | $2\sum E\log(E/O)$ | 수정 우도비 |
| `'neyman'` | −2 | $\sum (O - E)^2/O$ | Neyman의 카이제곱 |
| `'cressie-read'` | 2/3 | 위 식의 $\lambda = 2/3$ | Cressie–Read |

$\lambda = 0$과 $-1$은 위 식의 극한이에요. 이름 대신 실수를 직접 줄 수도 있어요.

```python
>>> for lam in ('pearson', 'log-likelihood', 'freeman-tukey', 'neyman', 'cressie-read', 0.5):
...     print(lam, sd.htest.power_divergence(die, lambda_=lam).statistic)
pearson 2.8000000000000003
log-likelihood 2.8337768768943423
freeman-tukey 2.8640076908698417
neyman 3.0133755133755136
cressie-read 2.8074174052036844
0.5 2.812551019938473
```

- **우도비(G) 검정**은 다항분포의 우도비 검정이라 이론적으로 자연스럽고, 범주를 합치거나 나눌 때 값이 더해지는 성질이 있어서 생태학, 유전학에서 흔히 써요.
- **Cressie–Read**($\lambda = 2/3$)는 Cressie와 Read가 작은 표본에서 카이제곱 근사가 가장 잘 맞는 값으로 권한 것이에요.
- $\lambda$가 클수록 기대보다 많이 나온 범주를, 작을수록(음수일수록) 기대보다 적게 나온 범주를 무겁게 봐요.

<Callout type="note" title="λ는 데이터를 보기 전에 골라요">
여러 $\lambda$로 계산해서 가장 작은 p값을 고르면 p값이 실제보다 작게 나와요. 어떤 통계량을 쓸지는 분석을 시작하기 전에 정해요.
</Callout>

## 관측이 0인 범주

관측 빈도가 0인 범주가 있으면 $\lambda$에 따라 통계량이 달라져요. 0에서의 값은 그 극한이에요.

- $\lambda > -1$(Pearson, G, Freeman–Tukey, Cressie–Read)이면 유한한 값이에요.
- $\lambda \le -1$(수정 우도비, Neyman)이면 $E/O$나 $1/O$가 끝없이 커져서 inf, p = 0이에요.

```python
>>> obs0 = [0, 5, 9, 6]
>>> for lam in ('log-likelihood', 'freeman-tukey', 'mod-log-likelihood', 'neyman'):
...     print(lam, sd.htest.power_divergence(obs0, lambda_=lam))
log-likelihood PowerDivergenceResult(statistic=12.768, pvalue=0.00516611, df=3)
freeman-tukey PowerDivergenceResult(statistic=22.5166, pvalue=5.0924e-05, df=3)
mod-log-likelihood PowerDivergenceResult(statistic=inf, pvalue=0, df=3)
neyman PowerDivergenceResult(statistic=inf, pvalue=0, df=3)
```

관측이 0인 범주가 흔하면 Neyman 쪽은 쓰지 않는 편이 좋아요.

```python
>>> g = sd.htest.power_divergence(die, lambda_='log-likelihood')
```

머리 오른쪽의 `Lambda`는 고른 통계량의 이름이에요(실수로 주면 그 값). 결과 객체의 공통 규칙은 [결과 객체 읽기](/api/htest/results/)에 있어요.

## 여러 표본을 한 번에

`axis`를 주면 그 축을 따라 범주를 읽고 나머지 축의 칸마다 따로 검정해요. `axis=None`(기본값)은 배열 전체를 범주로 펼쳐요. NaN은 `nan_policy`를 따라요. 공통 규칙은 [가설검정의 기본](/api/htest/basics/)에 있어요.

```python
>>> sd.htest.power_divergence([[8, 9, 12], [7, 11, 13]], axis=1, lambda_='log-likelihood').pvalue
array([ 0.6455771031292454, 0.38831504357834373], dtype=float64)
```

## 특수한 경우와 에러

- 범주가 하나이거나 자유도가 0 이하면 p값이 NaN이에요.
- 기대 빈도가 0 이하이거나 관측이 음수인 범주는 위 식 그대로 계산해요(뜻이 있는 값이 아닐 수 있어요).

```python
>>> sd.htest.power_divergence(die, ddof=5).pvalue
nan
>>> sd.htest.power_divergence(die, lambda_='g-test')
Traceback (most recent call last):
    ...
ValueError: power_divergence(): 'lambda_' must be 'pearson', 'log-likelihood', 'freeman-tukey', 'mod-log-likelihood', 'neyman' or 'cressie-read', not 'g-test'
>>> sd.htest.power_divergence(die, lambda_=True)
Traceback (most recent call last):
    ...
TypeError: power_divergence(): 'lambda_' must be None, a real number or one of 'pearson', 'log-likelihood', 'freeman-tukey', 'mod-log-likelihood', 'neyman', 'cressie-read', not bool
```

## 정확도

- 통계량과 p값은 Arb(구간 산술)로 계산한 참값과 견줘 25문제(관측 0의 극한, $\lambda$가 0과 −1 근처, 관측이 기대와 거의 같은 경우, 큰 표 포함)에서 통계량의 상대오차가 2.4e-16, p값이 6.7e-14 안이에요(정확도 약속의 0.024배와 0.017배).
- 관측이 기대에 아주 가까울 때도 자릿수를 지켜요. 예를 들어 기대 빈도가 10⁶이고 관측이 1만큼씩 다르면 G는 2e-6쯤인데, $O\log(O/E)$를 그대로 더하면 크기 10⁶의 항들이 서로 지워져서 앞자리가 사라져요. 여기서는 항마다 음이 아닌 꼴로 바꿔 더해요.

```python
>>> o, e = [1000001.0, 999999.0, 1000000.0], [1e6, 1e6, 1e6]
>>> sd.htest.power_divergence(o, e, lambda_='log-likelihood').statistic
2.0000000000003332e-06
>>> sd.htest.chisquare(o, e).statistic
2e-06
```

- 같은 입력이면 실행마다 같은 비트예요. 지금은 스레드 수와도 상관없이 같아요(약속은 아니에요).

## scipy를 아는 분께

scipy 1.18.1 기준이에요.

- `scipy.stats.power_divergence(f_obs, f_exp, lambda_=...)`와 같은 통계량, 같은 $\lambda$의 이름이에요. 기본 `axis`는 None이에요(scipy는 0). `ddof`는 키워드로만 받아요.
- 결과에 자유도 `df`가 있어요(scipy의 결과에는 없어요).
- 관측이 0인 범주에서 $-1 < \lambda < 0$(Freeman–Tukey 등)이면 유한한 극한, $\lambda < -1$이면 inf예요. scipy는 두 경우 0 × inf로 NaN을 내요. `[0, 5, 9, 6]`의 Freeman–Tukey는 여기서 22.52, scipy는 NaN이에요.
- 관측이 기대에 가까울 때 scipy는 자릿수를 잃어요. 위 정확도 절의 `o`, `e`에서 scipy의 G는 1.99978e-06(상대오차 1.1e-4)이에요. 기대 빈도 10⁶, 차 ±10⁻³의 G에서 상대오차 9.9e-8, $\lambda = 2/3$에서는 66배 틀리고 p값이 NaN이에요. $\lambda = 10^{-7}$에서 2.4e-8 틀려요.
