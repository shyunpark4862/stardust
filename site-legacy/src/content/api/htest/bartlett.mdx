## 무엇을 하나요

토마토 수확량에서 셋째 집단(h3)은 다른 품종이라 그루마다 들쭉날쭉해요. 표본 분산이 0.67, 0.57, 7.77이에요. 정말 흩어짐이 다른 걸까요, 표본이 작아서 우연히 이렇게 나온 걸까요?

**Bartlett의 검정**은 집단의 분산이 모두 같은지 물어요.

- 귀무가설: k개 집단의 모집단 분산이 모두 같아요(σ₁² = σ₂² = … = σₖ²).
- 대립가설: 적어도 한 집단의 분산이 달라요.

분산이 같은지(등분산성)는 그 자체로 궁금할 때도 있고(공정의 산포가 달라졌나), 분산분석의 가정을 살필 때도 봐요. 통계량은 합동 분산 $s_p^2 = \sum_i (n_i - 1) s_i^2 / (N - k)$의 로그와 집단 분산의 로그를 견줘요.

$$
T = \frac{(N - k) \ln s_p^2 - \sum_i (n_i - 1) \ln s_i^2}{C}, \qquad
C = 1 + \frac{1}{3(k - 1)} \left( \sum_i \frac{1}{n_i - 1} - \frac{1}{N - k} \right)
$$

합동 분산은 집단 분산들의 산술 평균이고, 분자는 그것과 기하 평균의 차이를 재요. 분산이 모두 같으면 두 평균이 같아 T가 0 근처이고, 다를수록 커져요. 귀무가설이 맞고 데이터가 정규분포면 T는 자유도 k − 1의 [카이제곱 분포](/api/stats/chi-squared/)를 따라요. C는 작은 표본의 보정이에요.

언제 무엇을 쓰나요.

| 검정 | 무엇을 견주나 | 정규분포에서 벗어날 때 |
|---|---|---|
| `bartlett` | 표본 분산 | 민감해요. 꼬리가 두꺼운 분포면 분산이 같아도 자주 기각해요 |
| [`levene`](/api/htest/levene/) | 중심(기본은 중앙값)에서의 절대 편차의 평균 | 강해요 |
| [`fligner`](/api/htest/fligner/) | 절대 편차의 순위 | 강해요 |

데이터가 정규분포에 가깝다고 믿을 근거가 있으면 Bartlett이 가장 힘이 세요. 그렇지 않으면 [`levene`](/api/htest/levene/)을 먼저 생각해요.

## 기본 사용

```python
>>> import stardust as sd
>>> g1 = [20.1, 21.4, 19.8, 22.0, 20.7, 21.1]
>>> g2 = [22.3, 23.1, 21.9, 24.0, 22.8, 23.4]
>>> h3 = [19.5, 23.2, 16.9, 22.8, 17.7, 21.4, 18.0, 24.1]
>>> r = sd.htest.bartlett(g1, g2, h3)
>>> r
BartlettResult(statistic=11.1117, pvalue=0.00386484, df=2)
```

p값 0.0039로 세 집단의 분산이 같다는 귀무가설을 버려요. 셋째 집단의 흩어짐이 뚜렷하게 커요. 이럴 때 평균을 견주려면 분산이 같다고 보지 않는 [`f_oneway(..., equal_var=False)`](/api/htest/f_oneway/#welch의-분산분석-equal_varfalse)나 [`alexandergovern`](/api/htest/alexandergovern/)을 써요.

## 결과 읽기

| 필드·메서드 | 뜻 |
|---|---|
| `statistic` | T 통계량. 0 이상이에요 |
| `pvalue` | 자유도 k − 1의 카이제곱 분포의 위쪽 꼬리 넓이 |
| `df` | 자유도 k − 1(`float`) |
| `summary()` | 검정을 표로 적은 글 |

```python
>>> print(r.summary())
                  Bartlett test of homogeneity of variances
==============================================================================
Statistic:                       11.11  No. Observations:              6, 6, 8
P-value:                       0.00386
Df:                                  2
==============================================================================
>>> t, p = r
>>> r.df
2.0
```

풀면 `(statistic, pvalue)` 둘이에요. 자유도는 필드로 읽어요.

## 정규분포에서 벗어난 데이터

Bartlett의 검정은 정규분포의 가정에 기대요. 흩어짐이 같은 세 집단의 셋째에 큰 값 하나(26.0)가 섞이면, 분산이 같은데도 기각해요. 중앙값에서의 편차를 쓰는 [`levene`](/api/htest/levene/)과 순위를 쓰는 [`fligner`](/api/htest/fligner/)는 이 값 하나에 휘둘리지 않아요.

```python
>>> g3 = [19.5, 20.2, 18.9, 20.8, 19.7, 20.4]
>>> o3 = g3 + [26.0]
>>> sd.htest.bartlett(g1, g2, g3).pvalue
0.9276532436934735
>>> sd.htest.bartlett(g1, g2, o3).pvalue
0.014973817889510674
>>> sd.htest.levene(g1, g2, o3).pvalue, sd.htest.fligner(g1, g2, o3).pvalue
(0.5446278467868454, 0.6968069695876931)
```

## axis와 배치

축을 주면 남은 축마다 검정해요.

```python
>>> S1 = sd.asarray([g1, [20.5, 20.9, 21.2, 20.0, 21.8, 20.6]])
>>> S2 = sd.asarray([g2, [21.9, 22.4, 21.5, 22.8, 22.1, 22.2]])
>>> S3 = sd.asarray([h3, [20.7, 21.3, 20.1, 20.9, 21.6, 20.3, 21.0, 20.8]])
>>> sd.htest.bartlett(S1, S2, S3, axis=1).pvalue
array([0.003864840222802362,   0.7401710070861897], dtype=float64)
```

## 특수한 경우

| 입력 | 결과 |
|---|---|
| 표본을 하나만 줌 | `TypeError` |
| 한 집단의 크기가 2보다 작음 | T, p값이 NaN |
| 한 집단이 상수(분산 0) | T, p값이 NaN |
| `'propagate'`에서 NaN이 있음 | 모든 필드가 NaN |

```python
>>> sd.htest.bartlett(g1, g2, [21.0, 21.0, 21.0])
BartlettResult(statistic=nan, pvalue=nan, df=2)
>>> sd.htest.bartlett(g1, g2, [21.0])
BartlettResult(statistic=nan, pvalue=nan, df=2)
>>> sd.htest.bartlett(g1)
Traceback (most recent call last):
    ...
TypeError: bartlett(): at least two samples are required, not 1
```

분산이 0인 집단은 $\ln s_i^2$가 −inf라 T를 정할 수 없어서 NaN으로 둬요.

## 정확도

- T의 상대오차는 $10^{-14}$ 안이에요(잰 최대 $1.7 \times 10^{-16}$). 분산이 거의 같으면 T의 분자가 큰 두 수의 차라서 상쇄로 자릿수를 잃기 쉬워요. 여기서는 분자를 상쇄가 없는 꼴 $\sum_i (n_i - 1)(d_i - \ln(1 + d_i))$로 바꿔 계산해요($d_i = s_i^2 / s_p^2 - 1$이고, 모든 항이 0 이상이에요). 분산의 차가 $10^{-9}$ 수준이어도 T가 정확해요.

```python
>>> base = [1.0, 2, 4, 7, 11, 16]
>>> twin = [x * (1 + 1e-9) for x in base[::-1]]
>>> shift = [x * (1 - 1e-9) + 0.5 for x in base]
>>> sd.htest.bartlett(base, twin, shift).statistic
1.8367349147061393e-17
```

참값(입력을 정확한 값으로 보고 80자리로 계산한 값)은 1.83673491470613952…e-17이라 마지막 자리까지 맞아요.

- p값은 카이제곱 분포의 위쪽 꼬리를 직접 계산해서 $10^{-14} \cdot \max(1, \kappa_p)$ 안이에요.
- 평균이 $10^8$처럼 큰 데이터도 분산의 자릿수를 지켜요.

참값은 Arb(구간 산술)로 만들었어요.

## scipy를 아는 분께

scipy 1.18.1의 `scipy.stats.bartlett`과 같은 검정이에요.

- 결과에 `df`(k − 1)가 있어요. `(statistic, pvalue)`로 푸는 것은 scipy와 같아요.
- 상수인 집단이 있으면 NaN이에요. scipy는 T = inf, p = 0을 내요. 크기가 1인 집단도 NaN이에요.
- 표본이 하나면 `TypeError`예요. scipy는 `ValueError`예요.
- scipy는 T를 로그의 차로 바로 계산해서 분산이 거의 같은 데이터에서 자릿수를 잃어요. 위의 `base`, `twin`, `shift`에서 scipy 1.18.1은 T = 0, p = NaN을 내요. 잰 문제(400개씩, 분산의 차 $10^{-9}$)에서 scipy의 T는 참값의 53배였고 R의 `bartlett.test`는 음수였어요.
- `axis`의 기본값이 None이에요(scipy는 0).
