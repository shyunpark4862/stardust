## 무엇을 묻나요

비료 세 가지로 키운 고추의 수확량(kg)이에요. 밭의 수가 비료마다 달라요.

```python
>>> import stardust as sd
>>> g1 = [27.0, 31.5, 25.2, 29.8, 33.1]
>>> g2 = [35.4, 38.0, 32.9, 36.7, 40.2, 34.1]
>>> g3 = [30.2, 28.7, 33.8, 31.0]
>>> sd.htest.kruskal(g1, g2, g3)
KruskalResult(statistic=8.89833, pvalue=0.0116883, df=2)
```

**Kruskal–Wallis 검정**은 모든 값을 합쳐 작은 것부터 순위 1..N을 매기고, 집단마다 순위의 평균을 봐요. 집단이 모두 같은 분포에서 나왔다면 어느 집단이든 순위의 평균이 전체 평균 $(N+1)/2$ 근처에 있어요. 집단의 순위 평균이 전체 평균에서 멀리 떨어질수록 통계량이 커져요.

$$
H = \frac{12}{N(N+1)} \sum_{i=1}^{k} n_i \left(\bar R_i - \frac{N+1}{2}\right)^2
$$

$\bar R_i$는 집단 $i$의 순위 평균이에요. 동점이 있으면 이 값을 $1 - \sum (t^3 - t)/(N^3 - N)$로 나눠요($t$는 같은 값 묶음의 크기). 귀무가설 아래에서 $H$는 자유도 $k - 1$의 카이제곱 분포에 가까워지고, p값은 그 위꼬리예요.

- **귀무가설**: 모든 집단이 같은 분포에서 나왔어요.
- **대립가설**: 적어도 한 집단이 다른 집단보다 큰 쪽(또는 작은 쪽)으로 치우쳤어요.

위의 p값 0.012는 비료에 따라 수확량이 다르다는 근거예요. 어느 비료가 다른지는 이 검정만으로는 알 수 없어요([사후 비교](#어느-집단이-다를까요)).

이런 때 써요.

- 독립인 집단 셋 이상을 견주는데 값이 정규분포를 따른다고 보기 어렵거나 이상값이 섞였을 때. 일원 분산분석 [`f_oneway`](/api/htest/f_oneway/)의 대신이에요.
- 값이 순서만 의미 있을 때(등급, 점수).

집단이 둘이면 [`mannwhitneyu`](/api/htest/mannwhitneyu/)의 정규 근사(연속성 보정 없이)와 같은 p값이에요.

```python
>>> sd.htest.kruskal(g1, g2)
KruskalResult(statistic=6.53333, pvalue=0.0105871, df=1)
>>> sd.htest.mannwhitneyu(g1, g2, method='asymptotic', use_continuity=False).pvalue
0.010587137334056949
```

공통 규칙은 [가설검정의 기본](/api/htest/basics/)에, 결과를 읽는 법은 [결과 객체 읽기](/api/htest/results/)에 있어요.

## 결과 읽기

| 필드 | 뜻 |
|---|---|
| `statistic` | 동점 보정이 든 $H$ |
| `pvalue` | 자유도 `df`의 카이제곱 분포에서 $H$ 이상일 확률 |
| `df` | 자유도 $k - 1$(float) |

```python
>>> r = sd.htest.kruskal(g1, g2, g3)
>>> stat, p = r
>>> r.df
2.0
>>> print(r.summary())
                         Kruskal-Wallis rank sum test
==============================================================================
Statistic:                       8.898  No. Observations:              5, 6, 4
P-value:                        0.0117
Df:                                  2
==============================================================================
```

둘로 풀리고(`statistic`, `pvalue`), `df`는 이름으로 읽어요. 대립가설에 방향이 없어서 `alternative`가 없어요.

## 동점이 있을 때

같은 값은 중간 순위를 나눠 가지고, $H$에 동점 보정이 들어가요. 동점이 있으면 순위가 덜 흩어져서 보정이 $H$를 조금 키워요.

```python
>>> sd.htest.kruskal([1, 2, 2, 3, 3], [3, 4, 4, 4, 5], [2, 3, 3, 4])
KruskalResult(statistic=7.39935, pvalue=0.0247316, df=2)
```

모든 값이 같으면 순위가 흩어지지 않아 $H$를 정할 수 없어서 NaN이에요. 표본 하나가 비어도 NaN이에요. 경고는 내지 않아요.

```python
>>> sd.htest.kruskal([1, 1, 1], [1, 1])
KruskalResult(statistic=nan, pvalue=nan, df=1)
```

## 카이제곱 근사의 품질

p값은 카이제곱 분포로 어림한 값이에요. 정확한 순열 분포는 계산하지 않아요. 표본이 커질수록 근사가 맞아 가고, 아주 작은 표본에서는 p값이 정확한 순열 p값과 다를 수 있어요. 작은 표본에서 정확한 p값이 필요하면 [`permutation_test`](/api/htest/permutation_test/)로 $H$의 순열 분포를 셀 수 있어요.

## 어느 집단이 다를까요

`kruskal`은 "모두 같다"를 버릴지만 알려 줘요. 짝마다 [`mannwhitneyu`](/api/htest/mannwhitneyu/)를 하고 [`multipletests`](/api/htest/multipletests/)로 여러 번 검정한 것을 보정하는 방법이 흔해요.

```python
>>> ps = [sd.htest.mannwhitneyu(g1, g2).pvalue,
...       sd.htest.mannwhitneyu(g1, g3).pvalue,
...       sd.htest.mannwhitneyu(g2, g3).pvalue]
>>> adj = sd.htest.multipletests(ps, method='holm')
>>> adj.pvalues_corrected
array([0.025974025974025976,   0.5555555555555556,   0.0380952380952381], dtype=float64)
>>> adj.reject
array([ True, False,  True], dtype=bool)
```

비료 2가 1과 3보다 수확량이 많고, 1과 3은 차이의 근거가 약해요. 평균을 견주는 사후 비교는 [`tukey_hsd`](/api/htest/tukey_hsd/)에 있어요.

## 여러 검정을 한 번에: `axis`

`axis`를 주면 그 축을 따라 표본을 읽고 나머지 축의 칸마다 따로 검정해요. 표본 축의 길이는 표본마다 달라도 돼요. 아래는 네 실험(행)에서 세 집단을 견주고, 실험마다 집단의 위치를 다르게 밀었어요.

```python
>>> rng = sd.random.default_rng(5)
>>> N = sd.stats.Normal()
>>> A = N.sample((4, 8), rng=rng)
>>> B = N.sample((4, 9), rng=rng) + sd.asarray([[0.0], [0.0], [1.0], [1.0]])
>>> C = N.sample((4, 7), rng=rng) + sd.asarray([[0.0], [1.0], [1.0], [2.0]])
>>> rb = sd.htest.kruskal(A, B, C, axis=1)
>>> rb.pvalue
array([  0.9952691623394727,   0.9713894810506966, 0.057607233195294316,
       0.006143862964739575], dtype=float64)
>>> rb.df
array([2.0, 2.0, 2.0, 2.0], dtype=float64)
```

셋째와 넷째 실험에서 집단의 위치를 밀어 둔 것이 p값에 보여요. 배치의 필드는 배치 모양의 배열이에요.

`nan_policy='omit'`은 줄마다 NaN을 빼고 남은 값으로 계산해요.

```python
>>> nan = float('nan')
>>> sd.htest.kruskal([1.0, 2.0, nan], [3.0, 4.0, 5.0], nan_policy='omit')
KruskalResult(statistic=3, pvalue=0.0832645, df=1)
```

## 정확도

$H$는 정수인 순위 합에서 상쇄 없는 꼴로 계산해요. 교과서의 꼴 $\frac{12}{N(N+1)}\sum R_i^2/n_i - 3(N+1)$은 큰 두 수를 빼서 N이 크면 자릿수를 잃는데, 이 꼴을 쓰지 않아요. 문제 6개에서 Arb(구간 산술)로 만든 참값에 견주어 $H$는 상대 5.3e-17, p값은 상대 3.5e-16 안이에요(N = 1100 포함).

## scipy를 아는 분께

`scipy.stats.kruskal`과 통계량(동점 보정 포함)과 p값의 정의가 같아요.

```python
>>> import scipy.stats
>>> scipy.stats.kruskal(g1, g2, g3)
KruskalResult(statistic=np.float64(8.89833333333334), pvalue=np.float64(0.011688303165722013))
```

다른 점이에요.

- 결과에 `df`가 있어요. 튜플로 풀면 scipy와 같이 둘이에요.
- 통계량: scipy와 R의 `kruskal.test`는 위의 빼는 꼴이라 N이 크면 상대 1e-13쯤 틀려요(N = 1100에서 3.2e-13). 위의 예에서도 끝자리가 달라요.
- 모든 값이 같으면 둘 다 NaN이에요. sd는 경고를 내지 않아요.
- `axis`의 기본값이 None이에요(scipy는 0).
- 표본 뒤의 옵션은 키워드로만 받아요.
