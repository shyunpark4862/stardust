## 한눈에 보기

한 표본 Kolmogorov–Smirnov(KS) 검정은 "이 표본이 내가 정한 이 분포에서 왔다고 봐도 되나요?"를 물어요. 분포는 모수까지 모두 정해져 있어야 해요(예: 평균 0, 표준편차 1인 정규분포).

- **귀무가설**: 표본이 `cdf`의 분포에서 왔어요.
- **대립가설**: 다른 분포에서 왔어요(`alternative='two-sided'`). 한쪽 방향은 [아래](#alternative-한쪽-검정)예요.

표본 50개가 표준정규분포에서 왔는지 물어요. 실제로는 평균이 0.3인 정규분포에서 뽑았어요.

```python
>>> import stardust as sd
>>> x = sd.stats.Normal(mu=0.3, sigma=1.0).sample(50, rng=sd.random.default_rng(4))
>>> r = sd.htest.ks_1samp(x, sd.stats.Normal())
>>> r
Ks1sampResult(statistic=0.149057, pvalue=0.195849, statistic_location=1.0324, statistic_sign=-1, method='exact')
```

$D = 0.149$, p = 0.20이라 표준정규분포에서 벗어났다는 근거가 모자라요. 평균이 0.3만큼 옮겨진 것은 표본 50개로 잡기에는 작은 차이예요.

## 통계량

표본의 **경험 분포 함수** $F_n(t)$는 $t$ 이하인 관측의 비율이에요. 관측마다 $1/n$씩 오르는 계단이에요. 표본이 $F$에서 왔다면 $F_n$은 $F$를 가까이 따라가요. KS 통계량은 둘 사이의 가장 큰 세로 거리예요.

$$
D = \sup_t \lvert F_n(t) - F(t) \rvert = \max(D^+, D^-), \qquad D^+ = \sup_t \bigl(F_n(t) - F(t)\bigr), \quad D^- = \sup_t \bigl(F(t) - F_n(t)\bigr)
$$

결과의 `statistic_location`은 $D$에 닿는 관측값이고, `statistic_sign`은 $D$가 $D^+$면 +1, $D^-$면 −1이에요. 여기서는 누적분포가 계단보다 위에 있어서(표본이 큰 쪽으로 옮겨져서) −1이에요.

```python
>>> r.statistic, r.statistic_location, r.statistic_sign
(0.14905681767238266, 1.0323965987371242, -1)
>>> d, p = r
>>> p
0.19584887319408734
```

$D$의 분포는 $F$가 연속이면 $F$가 무엇이든 같아요. 그래서 p값은 $n$과 $D$만으로 정해져요.

## 언제 쓰나요

- 모수가 미리 정해진 연속분포와 견줄 때 써요. 예를 들어 난수 생성기의 출력이 $[0, 1)$의 균등분포인지, 측정값이 사양서의 분포를 따르는지예요.
- 분포 전체의 모양을 한 번에 보지만, 가운데의 어긋남에 민감하고 꼬리의 어긋남에는 둔해요. 꼬리까지 고르게 보려면 [`cramervonmises`](/api/htest/cramervonmises/)나 [`anderson`](/api/htest/anderson/)이에요.
- 두 표본이 같은 분포인지는 [`ks_2samp`](/api/htest/ks_2samp/)예요.

<Callout type="warn" title="모수를 데이터에서 맞추면 p값이 틀려요">
평균과 표준편차를 그 표본에서 구해 `sd.stats.Normal(mu=평균, sigma=표준편차)`를 넘기면, 분포가 데이터에 맞춰져서 $D$가 작아지고 p값이 실제보다 커요. 모수를 모르는 분포족을 물으려면 [`shapiro`](/api/htest/shapiro/)(정규분포), [`anderson`](/api/htest/anderson/), 또는 다시 맞추기를 몬테카를로로 반영하는 [`goodness_of_fit`](/api/htest/goodness_of_fit/)을 써요.
</Callout>

```python
>>> m, s = sd.mean(x), sd.std(x, correction=1)
>>> sd.htest.ks_1samp(x, sd.stats.Normal(mu=m, sigma=s)).pvalue
0.9868896676390098
```

맞춘 분포로는 p = 0.99로 아주 잘 맞는 것처럼 보이지만, 이 값은 귀무분포를 따르지 않아요.

## `cdf`: 분포 객체나 함수

`cdf`에는 sd.stats의 분포 객체를 주는 것이 가장 쉬워요. 그 `cdf` 메서드를 써요.

```python
>>> u = sd.stats.Uniform(a=0.0, b=1.0).sample(20, rng=sd.random.default_rng(9))
>>> sd.htest.ks_1samp(u, sd.stats.Uniform(a=0.0, b=1.0))
Ks1sampResult(statistic=0.172832, pvalue=0.532484, statistic_location=0.377168, statistic_sign=1, method='exact')
```

누적분포를 함수로 줄 수도 있어요. 함수는 정렬한 표본을 배열 하나로 한 번만 받고, 같은 모양의 배열을 돌려줘야 해요. 그래서 원소마다 부르는 Python 함수가 아니라 배열을 받는 함수를 줘요.

```python
>>> sd.htest.ks_1samp(x, lambda v: sd.stats.Normal().cdf(v)).pvalue == r.pvalue
True
>>> sd.htest.ks_1samp(x, lambda v: 0.5)
Traceback (most recent call last):
    ...
ValueError: ks_1samp(): 'cdf' must return an array of the shape of its input (50,), not ()
>>> sd.htest.ks_1samp(x, 'norm')
Traceback (most recent call last):
    ...
TypeError: ks_1samp(): 'cdf' must be an sd.stats distribution object or a callable cdf(x), not str
>>> sd.htest.ks_1samp(x, sd.stats.Normal)

    ...
TypeError: ks_1samp(): 'cdf' must be an sd.stats distribution object (sd.stats.Normal(mu=0, sigma=1)) or a callable cdf(x), not the class Normal
```

분포 이름의 문자열, 분포 클래스, 따로 넘기는 모수(`args=`)는 받지 않아요. 모수는 분포 객체에 넣어요.

## `alternative`: 한쪽 검정

한쪽 검정은 표본이 한 방향으로 옮겨졌는지를 물어요. 방향의 이름은 누적분포를 기준으로 해요.

| `alternative` | 대립가설 | 통계량 | 표본은 |
|---|---|---|---|
| `'less'` | 어딘가에서 $F_{\text{표본}}(t) < F(t)$ | $D^-$ | 큰 쪽으로 치우쳐요 |
| `'greater'` | 어딘가에서 $F_{\text{표본}}(t) > F(t)$ | $D^+$ | 작은 쪽으로 치우쳐요 |

표본의 평균이 0.3만큼 크므로 `'less'`가 맞는 방향이에요.

```python
>>> sd.htest.ks_1samp(x, sd.stats.Normal(), alternative='less')
Ks1sampResult(statistic=0.149057, pvalue=0.0980054, statistic_location=1.0324, statistic_sign=-1, method='exact')
>>> sd.htest.ks_1samp(x, sd.stats.Normal(), alternative='greater').pvalue
0.9689317938885301
```

한쪽 검정의 p값은 언제나 Smirnov의 정확한 분포예요. 방향은 데이터를 보기 전에 정해요.

## `method`: 양쪽 검정의 분포

| `method` | p값 | 결과의 `method` |
|---|---|---|
| `'auto'`(기본값), `'exact'` | $D$의 정확한 분포 | `'exact'` |
| `'approx'` | 한쪽 꼬리 확률의 두 배(1에서 잘라요) | `'approx'` |
| `'asymp'` | $\sqrt{n}D$의 극한(Kolmogorov) 분포 | `'asymp'` |

```python
>>> for m in ('exact', 'approx', 'asymp'):
...     print(m, sd.htest.ks_1samp(x, sd.stats.Normal(), method=m).pvalue)
exact 0.19584887319408734
approx 0.19601085958505204
asymp 0.2165526933012572
```

정확한 분포를 쓰는 것이 기본이고 어떤 크기에서도 계산이 끝나요. `'approx'`는 꼬리에서 정확한 값에 아주 가깝고, `'asymp'`는 표본이 클 때의 근사라 n = 50에서는 0.02쯤 차이가 나요. 한쪽 검정에서는 `method`를 무시하고 결과의 `method`가 `'exact'`예요.

## 여러 표본을 한 번에

`axis`를 주면 그 축을 따라 표본을 읽고 나머지 축의 칸마다 따로 검정해요. `cdf`는 정렬한 배치 전체를 (..., n) 모양으로 한 번 받아요. 결과의 `method`는 줄마다의 이름을 배치 모양으로 담은 리스트예요. NaN은 `nan_policy`를 따라요. 공통 규칙은 [가설검정의 기본](/api/htest/basics/)에 있어요.

```python
>>> b = sd.stats.Normal().sample((3, 30), rng=sd.random.default_rng(10))
>>> rb = sd.htest.ks_1samp(b, sd.stats.Normal(), axis=1)
>>> rb.pvalue
array([0.19473243397080842, 0.19516532960483624,  0.4370143224019028], dtype=float64)
>>> rb.statistic_sign, rb.method
(array([-1,  1,  1], dtype=int64), ['exact', 'exact', 'exact'])
```

## 특수한 경우

- **빈 표본**은 `statistic`, `pvalue`, `statistic_location`이 NaN이고 `statistic_sign`은 0이에요.
- 값이 하나여도 정확한 분포로 계산해요.
- 이산분포의 누적분포를 줘도 계산은 하지만, 검정은 연속분포를 가정해요. 이산분포에서는 p값이 실제보다 커요.

```python
>>> sd.htest.ks_1samp([], sd.stats.Normal())
Ks1sampResult(statistic=nan, pvalue=nan, statistic_location=nan, statistic_sign=0, method='exact')
>>> sd.htest.ks_1samp([0.1], sd.stats.Normal()).pvalue
0.920344325445942
>>> sd.htest.ks_1samp(x, sd.stats.Normal(), method='asymptotic')
Traceback (most recent call last):
    ...
ValueError: ks_1samp(): 'method' must be 'auto', 'exact', 'approx' or 'asymp', not 'asymptotic'
```

## 정확도

- $D$는 Arb(구간 산술)로 계산한 참값과 견줘 19문제에서 상대오차가 7.1e-16 안이에요.
- 정확한 분포의 p값은 상대오차가 2e-13 안이고, p값이 1e-113, 1e-251처럼 깊은 꼬리에서도 0으로 떨어지지 않고 그 자릿수가 맞아요. 한쪽 꼬리는 양수 항의 합으로 계산해서 $n$이 커도 자릿수를 잃지 않아요.
- 약속이 느슨한 곳이 하나 있어요. 양쪽 검정에서 $n$이 약 1000을 넘고 $nD^2 < 6.5$인 곳은 정확한 분포의 계산량이 커서 Pelz–Good 근사($nD^2 < 3$)나 한쪽 꼬리의 두 배를 써요. n = 3000에서 상대오차가 Pelz–Good은 8e-9–5e-7, 한쪽 꼬리의 두 배는 1.4e-8 아래이고, $n$이 클수록 작아져요.
- 같은 입력이면 실행마다 같은 비트예요. 지금은 스레드 수와도 상관없이 같아요(약속은 아니에요).

## scipy를 아는 분께

scipy 1.18.1, R 4.6.2 기준이에요.

- `scipy.stats.ks_1samp(x, cdf)`와 같은 통계량, 같은 `alternative`와 `method`의 이름과 뜻이에요. `statistic_location`, `statistic_sign`도 같아요. 기본 `axis`는 None이에요(scipy는 0).
- `cdf`는 sd.stats의 분포 객체나 배열을 받는 함수예요. scipy의 분포 이름(`'norm'`)과 `args=()`는 받지 않아요. scipy의 `kstest`(한 표본과 두 표본을 고르는 함수)는 없고, 두 표본은 [`ks_2samp`](/api/htest/ks_2samp/)예요.
- 결과에 실제로 쓴 분포의 이름 `method`가 있어요.
- 양쪽 정확한 분포가 더 정확해요. scipy는 n > 140에서 Pelz–Good 근사로 넘어가서 p값의 상대오차가 n = 141에서 3.5e-6, n = 400에서 1.7e-7이에요. n ≤ 140에서도 정확한 분포를 1 − cdf로 계산해서 n = 100, $nD^2 = 4$에서 8e-12 틀려요.
- R의 `ks.test`는 n ≥ 100에서 기본으로 점근 분포를 써서 n = 141, 400에서 p값이 0.04쯤 다르고, 꼬리를 1 − cdf로 계산해서 깊은 꼬리(p = 1e-113 등)에서 0을 내요.
- 빈 표본은 경고 없이 NaN이에요.
