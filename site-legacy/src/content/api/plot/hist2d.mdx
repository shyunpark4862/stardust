## 한눈에 보기

점 2만 개를 산점도로 찍으면 가운데가 한 색으로 메워져, 점이 어디에 얼마나 몰려 있는지 알 수 없어요. 평면을 바둑판처럼 사각 칸으로 나누고 칸마다 들어온 점의 수를 세어 색으로 칠하면 그 안쪽이 보여요. [히스토그램](/api/plot/histogram/)이 수직선을 구간으로 나눠 막대의 높이로 개수를 보인다면, **2차원 히스토그램**은 평면을 칸으로 나눠 색으로 개수를 보여요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> N = sd.stats.Normal(mu=0.0, sigma=1.0)
>>> z1, z2 = N.sample(20000, rng=rng), N.sample(20000, rng=rng)
>>> x, y = z1, 0.6 * z1 + 0.8 * z2
>>> fig = sd.plot.hist2d(x, y).xlabel("$x$").ylabel("$y$")
```

<PlotImage name="hist2d-overview" alt="가로 40칸, 세로 40칸으로 나눈 2차원 히스토그램. 가운데 칸들이 빨갛고 바깥으로 갈수록 하늘색이며, 오른쪽 위로 기운 타원 모양이에요. 바깥의 빈 칸은 칠하지 않았어요." caption="짝 2만 개를 40 × 40칸에 센 그림. 가운데 칸에는 160개쯤이 들어 있고, 색띠가 색과 개수의 대응을 보여요." />

`x`와 `y`는 같은 길이의 수 배열이고, 같은 자리의 값끼리 짝이에요. 기본으로 가로와 세로를 40칸씩 나눠요. 칸의 색은 오른쪽 색띠로 읽어요. 색띠는 0에서 가장 많이 든 칸의 개수까지예요. 짝이 하나도 들지 않은 칸은 칠하지 않고 비워 둬요. 그래서 개수가 1인 칸(색띠의 가장 옅은 색)과 빈 칸이 구별돼요.

## 칸의 수: `bins`

`bins`에 수 하나를 주면 가로와 세로를 그 수만큼 나눠요. 방향마다 다르게 나누려면 `(가로, 세로)`로 줘요.

```python
>>> fig = sd.plot.hist2d(x, y, bins=(60, 12))
```

<PlotImage name="hist2d-bins" alt="가로 60칸, 세로 12칸으로 나눈 2차원 히스토그램. 칸이 세로로 길쭉해요." caption="bins=(60, 12). 가로로는 잘게, 세로로는 성기게 나눴어요." />

칸이 너무 많으면 칸마다 든 개수가 적어져 색이 얼룩덜룩해지고, 너무 적으면 모양이 뭉개져요. 짝이 수천 개면 20칸 안팎, 수만 개면 기본값 40칸 안팎이 무난해요.

칸은 상자를 같은 너비로 나눈 것이에요. 칸의 왼쪽과 아래 가장자리 위의 짝은 그 칸에 들어가고, 상자의 오른쪽 끝과 위쪽 끝에 놓인 짝은 마지막 칸에 들어가요. [`histogram`](/api/plot/histogram/)이 구간을 나누는 규칙과 같아요.

## 상자와 밀도: `range`, `density`

`range`를 주지 않으면 유한한 짝의 최솟값에서 최댓값까지를 나눠요. 멀리 떨어진 점 몇 개가 상자를 넓혀 버리면 정작 보고 싶은 가운데가 몇 칸에 뭉쳐요. `range=((x0, x1), (y0, y1))`로 상자를 직접 정하면 그 안만 나누고, 밖의 짝은 세지 않아요.

`density=True`면 개수 대신 밀도를 칠해요. 칸의 개수를, 센 짝의 수와 칸의 넓이로 나눈 값이에요. 칸의 넓이가 $\Delta x\,\Delta y$이고 센 짝이 $n$개일 때 개수가 $c$인 칸의 값은 $c / (n\,\Delta x\,\Delta y)$예요. 칸의 수를 바꿔도 값의 크기가 비슷하게 남고, 확률 밀도 함수와 같은 눈금으로 견줄 수 있어요.

```python
>>> fig = sd.plot.hist2d(x, y, bins=30, range=((-2, 2), (-2, 2)), density=True, cmap="viridis")
>>> fig = fig.line([-2, 2], [-1.2, 1.2], color="white")
```

<PlotImage name="hist2d-density" alt="가로와 세로가 -2에서 2까지인 상자를 30 × 30칸으로 나눈 밀도 그림. viridis 색띠로 가운데가 노랗고 가장자리가 짙은 보라이며, 흰 직선 y = 0.6x가 가운데를 지나가요." caption="상자를 −2에서 2까지로 정하고 밀도로 칠한 그림. 그 위에 직선 한 층을 겹쳤어요." />

이 자료는 `y`를 `0.6 * x`에 잡음을 더해 만들었으니, 짙은 칸들이 직선 $y = 0.6x$를 따라 늘어서요. 두 번째 줄처럼 같은 이름의 메서드를 이어 부르면 히스토그램 위에 선이나 점을 겹칠 수 있어요. 축이 `x`와 `y`의 값 그대로라 자리를 따로 바꿀 필요가 없어요.

## DataFrame의 열로 주기

`data=`에 DataFrame을 주면 `x`와 `y`를 열 이름으로 쓸 수 있어요.

```python
>>> df = sd.frame.DataFrame({"u": x, "v": y})
>>> fig = sd.plot.hist2d("u", "v", data=df, bins=25)
```

<Callout type="note" title="셀 수 없는 짝">
`x`나 `y` 가운데 하나라도 NaN이나 무한대인 짝은 빼고 세요. 남는 짝이 하나도 없으면 `ValueError`예요. 모든 짝이 한 점에 모여 있어 상자의 너비가 0이면, 그 값의 5 %(값이 0이면 0.5)만큼 양쪽으로 넓혀서 나눠요.
</Callout>

## 조심할 점

- 색띠는 칸 하나에 하나예요. 한 칸에 `hist2d`를 두 번 겹치면 색띠는 나중 것만 남아요. 무리마다 견주려면 [`facet`](/api/plot/facet/#개수를-칠하는-그림-hist2d-hexbin)으로 칸을 나눠요. 모든 칸이 같은 격자로 세고 같은 색 범위로 칠해요.
- 칸은 `x`와 `y`의 값을 같은 너비로 나눈 것이에요. 로그 축(`xscale('log')`, `yscale('log')`)에 그리면 칸마다 제 값의 자리에 서므로, 같은 너비의 칸이 로그 축에서는 너비가 다르게 보여요. 0 이하에 걸친 부분은 그리지 않아요. 로그 눈금에서 같은 너비로 보이는 칸이 필요하면 `sd.log10`으로 바꾼 값을 넘기거나, 그릴 축에 맞춰 세는 [`hexbin`](/api/plot/hexbin/#로그-축)을 써요.
- `range`의 두 구간은 작은 값을 앞에 적어요. 거꾸로 주면 `ValueError`예요.

  ```python
  >>> sd.plot.hist2d(x, y, range=((2, -2), (-2, 2)))
  Traceback (most recent call last):
      ...
  ValueError: hist2d(): 'range' must have x0 at most x1, not 2 and -2
  ```

- 점이 수백 개뿐이면 칸마다 든 개수가 너무 적어요. 그때는 [`scatter`](/api/plot/scatter/)가 알맞아요.
- 사각 칸은 가로·세로 방향으로 줄이 맞아 있어 대각선으로 늘어선 모양이 계단처럼 보일 수 있어요. 방향에 덜 치우친 칸이 필요하면 육각 칸으로 세는 [`hexbin`](/api/plot/hexbin/)을 써요.
- 이미 센 값의 표를 칠하려면 [`heatmap`](/api/plot/heatmap/), 함수 $f(x, y)$의 값을 칠하려면 [`density`](/api/plot/density/)예요.

## matplotlib을 아는 분께

- `plt.hist2d`와 같은 일을 해요. `bins`에 수 하나나 두 개를 주는 것과 `range`의 꼴이 같아요. 칸의 경계를 배열로 주는 꼴은 없어요.
- 빈 칸을 0의 색으로 칠하지 않고 비워 둬요(`cmin=1`을 준 것과 같아요).
- 색띠가 기본으로 붙어요. 개수 배열과 경계를 돌려주지 않고 `Figure`를 돌려줘요.
