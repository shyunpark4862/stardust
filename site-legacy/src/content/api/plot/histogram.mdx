## 한눈에 보기

어른 200명의 키를 재서 얼마나 퍼져 있는지 보고 싶어요. 값을 구간 열두 개로 나누고 구간마다 몇 명이 드는지 세어 막대로 세우면 **히스토그램**이에요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(1)
>>> x = sd.stats.Normal(mu=170.0, sigma=8.0).sample(200, rng=rng)
>>> fig = sd.plot.histogram(x, bins=12).xlabel("키 (cm)").ylabel("사람 수")
```

<PlotImage name="histogram-heights" alt="키 200개를 열두 구간으로 나눈 히스토그램. 170 cm 근처의 막대가 가장 높고 양쪽으로 낮아져요." caption="구간 열두 개의 히스토그램. 막대의 높이가 그 구간에 든 사람의 수예요." />

막대 하나가 구간 하나예요. 막대의 너비가 구간의 너비, 높이가 그 구간에 든 값의 수예요. 가운데 170 cm 근처가 가장 높고, 양 끝으로 갈수록 낮아지는 종 모양이 보여요.

## 막대의 높이는 `sd.histogram`의 값

그림이 수를 따로 세지 않아요. 같은 인자로 [`sd.histogram`](/api/array/histogram/)을 부르고, 그 결과를 그대로 막대로 세워요. 그래서 그림에서 읽은 높이와 계산으로 얻은 값이 언제나 같아요.

```python
>>> r = sd.histogram(x, bins=12)
>>> r.hist
array([ 2,  6,  8, 19, 32, 44, 30, 26, 10, 12,  7,  4], dtype=int64)
>>> float(r.bin_edges[0]), float(r.bin_edges[-1])
(149.73103307294582, 191.76723602076186)
```

위 그림의 여섯째 막대가 44, 첫 막대가 2예요. 막대들은 가장 작은 값 149.73에서 시작해 가장 큰 값 191.77에서 끝나요. `bins`, `range`, `density`는 `sd.histogram`의 같은 이름의 인자로 그대로 넘어가요. 그림의 수를 글이나 표에 적어야 할 때는 `sd.histogram`을 부르면 돼요.

한 가지만 달라요. `sd.histogram`은 `range` 없이 NaN이나 무한대를 받으면 범위를 정할 수 없어 에러를 내지만, 그림은 유한하지 않은 값을 먼저 빼고 세요.

```python
>>> y = sd.asarray([1.2, 2.5, float("nan"), 2.9, 3.1, float("inf")])
>>> sd.histogram(y, bins=3)
Traceback (most recent call last):
    ...
ValueError: histogram(): the data's range is not finite (NaN or inf); pass 'range'
>>> fig_y = sd.plot.histogram(y, bins=3)
>>> sd.histogram(y[sd.isfinite(y)], bins=3).hist
array([1, 0, 3], dtype=int64)
```

`fig_y`의 막대는 마지막 줄의 값, 곧 1, 0, 3이에요. 유한하지 않은 값이 그림에 섞여도 에러 없이 그리는 것은 다른 그림 함수와 같은 약속이에요.

## 구간의 수: `bins`

구간을 몇 개로 나누느냐에 따라 같은 자료가 꽤 다르게 보여요. 구간이 너무 적으면 모양이 뭉개지고, 너무 많으면 구간마다 든 값이 적어 들쭉날쭉해져요.

```python
>>> fig = sd.plot.grid([sd.plot.histogram(x, bins=5), sd.plot.histogram(x, bins=40)], ncols=2, width=160, labels="A")
```

<PlotImage name="histogram-bins" alt="같은 키 자료를 왼쪽은 구간 5개, 오른쪽은 구간 40개로 그린 두 히스토그램" caption="A는 구간 5개, B는 구간 40개예요. A는 봉우리의 모양이 잘 드러나지 않고, B는 막대마다 값이 적어 들쭉날쭉해요." />

정답인 구간의 수는 없어요. 값이 수백 개라면 10–30개 사이에서 몇 번 바꿔 보며 모양이 안정되는 수를 고르는 것이 보통이에요.

구간의 경계를 직접 정하고 싶으면 `bins`에 경계의 배열을 줘요. 5 cm마다 끊어 145, 150, …, 195를 경계로 쓰려면 이렇게 해요.

```python
>>> edges = sd.arange(145.0, 196.0, 5.0)
>>> fig = sd.plot.histogram(x, bins=edges).xlabel("키 (cm)")
>>> sd.histogram(x, bins=edges).hist
array([ 1,  4,  9, 33, 57, 44, 26, 16,  8,  2], dtype=int64)
```

경계의 배열은 `sd.ndarray`여야 해요. 파이썬 리스트를 주면 `TypeError`이니 `sd.asarray`로 바꿔 줘요. `range=(low, high)`는 `bins`가 int일 때 나눌 범위를 정해요. 이 범위 밖의 값은 세지 않아요.

## 밀도로 그리기: `density`

`density=True`면 막대의 높이가 개수 대신 밀도예요. 높이 × 너비, 곧 막대의 넓이를 모두 더하면 1이에요. 이렇게 그리면 확률밀도함수와 같은 눈금에 놓이므로, 분포의 밀도를 그 위에 겹쳐 견줄 수 있어요.

```python
>>> N = sd.stats.Normal(mu=170.0, sigma=8.0)
>>> fig = sd.plot.histogram(x, bins=15, density=True)
>>> fig = fig.distribution(N, label=r"$N(170,\ 8^2)$").xlabel("키 (cm)")
```

<PlotImage name="histogram-density" alt="키 자료의 밀도 히스토그램 위에 평균 170, 표준편차 8인 정규분포의 밀도 곡선을 겹친 그림" caption="밀도로 그린 히스토그램과, 자료를 뽑은 정규분포의 밀도. 막대가 곡선을 따라 오르내려요." />

[`fig.distribution`](/api/plot/distribution/)은 분포의 밀도를 같은 칸에 더해요. 표본의 막대는 밀도의 봉우리보다 높이 솟을 수 있어요(여기서는 가장 높은 막대가 0.059, 밀도의 봉우리가 0.050이에요). 세로축은 칸의 모든 층을 덮게 잡히므로 가장 높은 막대까지 보여요.

막대의 넓이를 모두 더하면 1인지 `sd.histogram`으로 확인할 수 있어요.

```python
>>> r = sd.histogram(x, bins=15, density=True)
>>> round(float(sd.sum(r.hist * sd.diff(r.bin_edges))), 12)
1.0
```

## 무리 나누기: `group`

투여량이 다른 세 무리의 반응을 견주어 볼게요. 자료가 `DataFrame`에 있으면 `data=`로 넘기고 열 이름으로 가리켜요. `group=`에 무리를 나누는 열을 주면 무리마다 다른 색의 막대를 겹쳐 그리고 범례를 붙여요.

```python
>>> rng = sd.random.default_rng(7)
>>> a = sd.stats.Normal(mu=5.0, sigma=1.0).sample(40, rng=rng)
>>> b = sd.stats.Normal(mu=6.2, sigma=1.3).sample(40, rng=rng)
>>> c = sd.stats.Normal(mu=7.8, sigma=0.9).sample(40, rng=rng)
>>> vals = sd.concat([a, b, c])
>>> df = sd.frame.DataFrame({"dose": ["control"] * 40 + ["low"] * 40 + ["high"] * 40, "response": vals})
>>> fig = sd.plot.histogram("response", data=df, group="dose", bins=12).xlabel("response").ylabel("count")
```

<PlotImage name="histogram-group" alt="control, low, high 세 무리의 반응을 같은 구간 위에 반투명 막대로 겹친 히스토그램" caption="세 무리의 히스토그램을 겹친 그림. 막대가 반투명이라 겹친 곳이 섞인 색으로 보여요." />

무리가 둘 이상이면 막대가 서로 가리지 않도록 불투명도 0.6으로 그려요. `alpha=`로 바꿀 수 있어요.

모든 무리가 **같은 구간**을 써요. `range`를 주지 않으면 그림이 모든 무리의 값을 합친 최솟값과 최댓값으로 범위를 잡고, 무리마다 그 범위를 `bins`개로 나눠 세요. 무리마다 경계가 다르면 막대를 나란히 견줄 수 없기 때문이에요. 그래서 한 무리의 막대 높이는 그 범위를 직접 준 `sd.histogram`과 같아요.

```python
>>> span = (float(sd.min(vals)), float(sd.max(vals)))
>>> sd.histogram(a, bins=12, range=span).hist
array([3, 5, 7, 8, 5, 9, 3, 0, 0, 0, 0, 0], dtype=int64)
```

control 무리(파란 막대)의 높이예요. 무리가 셋 이상이고 많이 겹치면 색이 섞여 읽기 어려워져요. 그럴 때는 [`ecdf`](/api/plot/ecdf/)의 계단을 겹치거나, [`facet`](/api/plot/facet/)으로 무리마다 칸을 나눠 같은 축에 늘어놓는 편이 나아요. `sd.plot.facet(df, "dose").histogram("response", bins=12)`처럼 불러요.

`group=`에는 열 이름 대신 값과 길이가 같은 라벨의 시퀀스를 줘도 돼요. 무리의 순서는 라벨이 처음 나온 순서이고, 그 순서대로 팔레트의 색을 받아요. 라벨이 `None`이나 NaN인 값은 어느 무리에도 들지 않아요.

## 색과 겹치기

`color=`로 막대의 색 하나를 정해요. 막대 안은 그 색을 옅게 칠하고 테두리는 그 색의 가는 선이에요. 색의 꼴(이름, `'#rrggbb'`, 튜플, `'C0'`)은 [기본 개념](/api/plot/basics/)에 있어요. `label=`을 주면 범례에 그 이름이 나와요.

이미 있는 그림에 히스토그램을 더하려면 메서드 `fig.histogram`을 불러요. 받는 인자는 모듈 함수와 같고, 그림 옵션(`width` 등)만 받지 않아요. 반대로 히스토그램 위에 다른 층을 얹을 수도 있어요. 평균의 자리에 세로선을 그어 볼게요.

```python
>>> m = float(sd.mean(x))
>>> fig = sd.plot.histogram(x, bins=12, color="gray").vline(m, style="--", color="C0", width=1.2).xlabel("키 (cm)")
```

<PlotImage name="histogram-mean" alt="회색 막대의 키 히스토그램 위에 평균의 자리를 점선 세로선으로 표시한 그림" caption="회색 히스토그램과 평균의 자리를 가리키는 점선." />

## 조심할 점

- 가중치(`sd.histogram`의 `weights`)는 받지 않아요. 가중치를 준 히스토그램은 `sd.histogram`으로 계산한 뒤 [`bar`](/api/plot/bar/)로 그려요.
- `density=True`와 `group=`을 함께 주면 무리마다 넓이가 1이에요. 무리의 크기가 달라도 모양만 견주게 되므로, 크기의 차이까지 보려면 개수로 그려요.
- `bins`가 int이고 값이 모두 같으면, `sd.histogram`처럼 그 값을 가운데 둔 폭 1의 범위를 나눠요.
- 막대는 0에서 시작해요. 그래서 막대가 있는 칸의 세로축은 늘 0을 포함해요.
- 변수 둘의 짝이 어디에 몰려 있는지를 세려면 [`hist2d`](/api/plot/hist2d/)나 [`hexbin`](/api/plot/hexbin/)이 평면을 칸으로 나눠 칸마다의 개수를 색으로 칠해요.

## matplotlib을 아는 분께

- 이름이 `hist`가 아니라 `histogram`이에요. 별칭은 없어요.
- `bins`에 `'auto'` 같은 규칙 이름을 줄 수 없어요. int나 경계의 배열만 받아요.
- 쌓은 막대(`stacked=True`)와 누적 히스토그램(`cumulative=True`)은 없어요. 누적 분포는 [`ecdf`](/api/plot/ecdf/)로 그려요.
- 무리 나누기는 `group=` 하나로 해요. 무리마다 따로 부르지 않아도 같은 구간과 범례가 함께 정해져요.
