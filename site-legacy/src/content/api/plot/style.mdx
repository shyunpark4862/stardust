## 네 가지 손잡이

그림의 생김새는 그림마다 주는 옵션 넷으로 정해요. 앞의 셋은 그림 전체에, 마지막 하나는 층 하나에 걸려요.

| 옵션 | 기본값 | 무엇을 정하나요 | 어디에 주나요 |
|---|---|---|---|
| `theme=` | `'paper'` | 축 선, 격자, 글자 크기, 선 굵기 | 그림을 만드는 함수, `Figure(...)` |
| `palette=` | `'jco'` | 층마다 차례로 주는 범주 색 | 그림을 만드는 함수, `Figure(...)` |
| `font=` | `'serif'` | 글꼴 벌 | 그림을 만드는 함수, `Figure(...)` |
| `cmap=` | `'cool'` | 값을 색으로 바꾸는 연속 색띠 | `contour`, `density`, `heatmap`, `hist2d`, `surface` 같은 층 |

모든 그림에 한꺼번에 거는 전역 설정은 없어요. 여러 그림을 같은 생김새로 맞추려면 옵션을 dict 하나에 담아 두고 그림마다 `**opts`로 넘겨요.

```python
>>> import stardust as sd
>>> opts = dict(theme="boxed", palette="okabe-ito", font="sans")
>>> fig = sd.plot.scatter([1, 2, 3], [2, 1, 3], **opts)
>>> fig = sd.plot.Figure(width=120, **opts).line([0, 1], [0, 1])
```

## 테마

테마는 축을 어떻게 두르고 글자와 선을 얼마나 크게 그릴지 정해요. 셋 모두 크기는 같고 축 선과 격자만 달라요.

| 테마 | 축 선 | 격자 |
|---|---|---|
| `'paper'` | 왼쪽과 아래 | 없음 |
| `'boxed'` | 네 변 모두 | 없음 |
| `'grid'` | 왼쪽과 아래 | 눈금마다 옅은 회색 선 |

세 테마가 함께 쓰는 크기예요. 글자 크기와 선 굵기는 pt예요.

| 무엇 | 크기 |
|---|---|
| 축 이름 | 8 pt |
| 눈금 숫자 | 7 pt |
| 제목 | 9 pt |
| 범례 | 7 pt |
| 칸 이름(A, B) | 10 pt, 굵게 |
| 층의 선 굵기 | 1.2 pt |
| 점의 크기 | 3.8 pt |
| 축 선 | 0.6 pt |

눈금은 축 바깥쪽으로 나고, 범례에는 테두리가 없어요. 축, 눈금, 글자의 색은 순검정보다 조금 옅은 검정이에요. 이 사이트의 다른 그림은 모두 기본 테마 `'paper'`예요. 아래는 같은 곡선을 `'boxed'`와 `'grid'`로 그렸어요.

```python
>>> x = sd.linspace(0, 5, 100)
>>> def sample(**options):
...     fig = sd.plot.Figure(width=80, **options)
...     for k in range(3):
...         fig = fig.line(x, sd.sin(x + k), label=f"$k = {k}$")
...     return fig.xlabel(r"$x$").ylabel(r"$\sin(x + k)$")
>>> fig = sample(theme="boxed")
```

<PlotImage name="style-boxed" alt="사인 곡선 셋이 네 변의 축 선으로 둘러싸인 칸 안에 있고 왼쪽 아래 구석에 k = 0, 1, 2 범례" caption="theme='boxed'는 칸의 네 변에 축 선을 그어요." />

```python
>>> fig = sample(theme="grid")
```

<PlotImage name="style-grid" alt="같은 사인 곡선 셋이 왼쪽과 아래 축 선만 있는 칸에 있고, 눈금마다 옅은 회색 가로세로 격자선이 깔림" caption="theme='grid'는 'paper'에 눈금마다의 옅은 격자선을 더해요. 격자선은 층보다 먼저 그려서 곡선 밑에 깔려요." />

## 팔레트

팔레트는 범주 색의 목록이에요. 칸에 층을 더할 때 `color=`를 주지 않으면 팔레트의 색을 차례로 받고, `group=`으로 나눈 무리도 차례로 받아요. 목록이 끝나면 처음부터 되풀이해요. `'C0'`–`'C9'`는 그 그림 팔레트의 0번–9번 색이에요.

| 이름 | 색 수 | 생김새 |
|---|---|---|
| `'jco'`(기본값) | 10 | 파랑, 노랑, 회색, 벽돌색으로 시작해요. R ggsci의 JCO 팔레트예요 |
| `'tableau'` | 10 | Tableau 10이에요 |
| `'deep'` | 10 | seaborn의 deep이에요 |
| `'bright'` | 7 | Paul Tol의 bright예요. 색각 이상이 있어도 서로 구별돼요 |
| `'okabe-ito'` | 8 | Okabe와 Ito의 팔레트예요. 색각 이상이 있어도 서로 구별돼요 |
| `'npg'` | 10 | ggsci의 Nature Publishing Group 꼴이에요 |
| `'aaas'` | 10 | ggsci의 Science(AAAS) 꼴이에요 |
| `'lancet'` | 9 | ggsci의 Lancet 꼴이에요 |
| `'nejm'` | 8 | ggsci의 NEJM 꼴이에요 |

```python
>>> names = ["jco", "tableau", "deep", "bright", "okabe-ito", "npg", "aaas", "lancet", "nejm"]
>>> cells = []
>>> for name in names:
...     f = sd.plot.Figure(palette=name)
...     for k in range(10):
...         f = f.scatter([k], [0], shape="s", size=11)
...     cells.append(f.title(name).yticks([]))
>>> fig = sd.plot.grid(cells, ncols=3, width=183, height=75)
```

<PlotImage name="style-palettes" alt="팔레트 아홉의 견본. 칸마다 네모 열 개가 가로로 늘어서고 위에 팔레트 이름. bright, okabe-ito, lancet, nejm은 끝에서 앞의 색이 다시 나옴" caption="칸마다 층 열 개를 차례로 그렸어요. 가로 위치 k의 네모가 그 팔레트의 'Ck' 색이에요. 색이 열 개보다 적은 팔레트는 처음 색부터 되풀이해요." />

선과 점은 팔레트의 색 그대로 그려요. 막대와 상자처럼 넓게 채우는 도형은 그 색을 흰색 쪽으로 옅게 한 색으로 채우고 원래 색의 가는 테두리를 둘러요. 점이 3천 개까지인 산점도는 점마다 가는 흰 테두리가 있어서 겹친 점이 서로 구별돼요.

`group=`은 무리가 처음 나온 순서대로 색을 받아요. 무리와 색을 고정하려면 무리마다 따로 그리며 `color=`를 주면 돼요.

## 글꼴

글꼴은 두 벌이에요. 영문, 한글, 수식이 한 벌로 맞춰져 있어요.

| `font` | 영문과 숫자 | 한글 | 수식 |
|---|---|---|---|
| `'serif'`(기본값) | TeX Gyre Termes(Times를 닮은 꼴) | KoPubWorld 바탕 | newtxmath |
| `'sans'` | TeX Gyre Heros(Helvetica를 닮은 꼴) | Apple SD Gothic Neo | newtxsf |

세리프는 논문 본문의 글꼴과 어울리고, 산세리프는 그림의 글자를 산세리프로 하라는 학술지에 맞춰요. 이 사이트의 다른 그림은 모두 `'serif'`예요.

```python
>>> fig = sample(font="sans").title("산세리프 글꼴")
```

<PlotImage name="style-sans" alt="사인 곡선 셋의 그림. 축 숫자, 범례의 수식, 한글 제목 '산세리프 글꼴'이 모두 산세리프" caption="font='sans'는 눈금 숫자, 수식, 한글이 모두 산세리프예요. 수식의 기울어진 x도 산세리프 꼴이에요." />

한글 글꼴은 이 컴퓨터에 설치된 글꼴을 써요. `'serif'`의 KoPubWorld 바탕은 사용자 글꼴 폴더(`~/Library/Fonts`)에, `'sans'`의 Apple SD Gothic Neo는 macOS에 들어 있어요. 영문과 수식 글꼴은 TeX Live에 들어 있어요.

## 연속 색띠

값을 색으로 바꾸는 층(`contour`, `density`, `heatmap`, `hist2d`, `hexbin`, `vectorfield`, `streamlines`, `surface`, `parametric_surface`)은 `cmap=`으로 연속 색띠를 받아요. 주지 않으면 어디서나 `'cool'`이에요. 색 막대(`colorbar=True`)도 같은 색띠로 그려요. 3D 칸에 곡면이 여럿이면 기본으로는 색띠 대신 곡면마다 팔레트의 색을 받아요([3D 칸](/api/plot/view3d/)).

| 이름 | 생김새 |
|---|---|
| `'cool'`(기본값) | 하늘색에서 보라를 거쳐 빨강. 양 끝이 어둡지 않아요 |
| `'spectral'` | 파랑, 초록, 노랑, 주황, 빨강의 무지개 꼴. 양 끝이 어둡지 않아요 |
| `'coolwarm'` | 파랑에서 연한 회색을 거쳐 빨강. 가운데 값이 기준인 자료에 맞아요 |
| `'sunrise'` | 파랑에서 분홍을 거쳐 노랑 |
| `'lagoon'` | 파랑에서 청록을 거쳐 연노랑 |
| `'viridis'` | 짙은 보라에서 노랑. 밝기가 고르게 늘어서 흑백으로 찍어도 순서가 읽혀요 |
| `'magma'` | 검정에서 보라, 주황을 거쳐 연노랑. 밝기가 고르게 늘어요 |
| `'cividis'` | 남색에서 노랑. 색각 이상이 있어도 순서가 읽혀요 |
| `'rdbu'` | 빨강에서 흰색을 거쳐 파랑. 낮은 값이 빨강이에요 |

```python
>>> maps = ["cool", "spectral", "coolwarm", "sunrise", "lagoon", "viridis", "magma", "cividis", "rdbu"]
>>> cells = [sd.plot.density(lambda x, y: x, 0, 1, 0, 1, cmap=m, colorbar=False).title(m).yticks([])
...          for m in maps]
>>> fig = sd.plot.grid(cells, ncols=3, width=183, height=95)
```

<PlotImage name="style-cmaps" alt="색띠 아홉의 견본. 칸마다 왼쪽 0에서 오른쪽 1로 색이 바뀌는 띠와 위에 색띠 이름" caption="f(x, y) = x를 density로 그려 색띠마다 0(왼쪽)에서 1(오른쪽)까지의 색을 보였어요." />

앞의 다섯(`cool`부터 `lagoon`)은 양 끝이 어둡지 않아서 음영을 입히는 3D 곡면에서도 어디서나 빛과 광택이 보여요. 흑백 인쇄나 색각 이상을 생각해야 하면 `'viridis'`나 `'cividis'`가 안전해요. 값이 0 같은 기준값의 위아래로 갈리는 자료에는 `'coolwarm'`이나 `'rdbu'`를 쓰고, 기준값이 가운데 오도록 `vmin`과 `vmax`를 대칭으로 줘요.

## matplotlib을 아는 분께

| matplotlib | sd.plot |
|---|---|
| `plt.style.use("seaborn")`, `rcParams` | 없어요. `theme=`, `palette=`, `font=`을 그림마다 줘요 |
| `axes.prop_cycle` | `palette=`. `'C0'`–`'C9'`가 그 팔레트의 색이에요 |
| `cmap="viridis"`(기본값) | `cmap=`의 기본값은 `'cool'`이에요. `'viridis'`도 있어요 |
| `matplotlib.colormaps`에 색띠를 더하기 | 없어요. 위 아홉만 받아요 |
| `ax.grid(True)` | `theme="grid"` |
