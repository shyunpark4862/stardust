## 무엇을 하나요

`fig.hline(y)`는 칸의 왼쪽 끝에서 오른쪽 끝까지 높이 `y`의 가로선을, `fig.vline(x)`는 아래 끝에서 위 끝까지 자리 `x`의 세로선을 그려요. 선의 길이는 자료가 아니라 칸이 정하므로, 축의 범위가 바뀌어도 언제나 칸을 가로질러요.

기준선은 자료가 아니라 표시라서, 색을 주지 않으면 팔레트의 색이 아니라 축 선과 같은 짙은 잉크색이고 굵기도 축 선과 같아요. 그래서 자료의 선보다 가늘게 보이고, 다음 층이 받을 팔레트의 색도 그대로예요.

## 한눈에 보기

시계열에 0의 기준선, 문턱값, 사건의 시점을 표시해요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(21)
>>> steps = sd.stats.Normal().sample(120, rng=rng)
>>> walk = sd.cumulative_sum(steps) * 0.3
>>> day = sd.arange(120.0)
>>> fig = sd.plot.line(day, walk, width=0.9)
>>> fig = fig.hline(0.0).hline(2.0, style="--", color="C3", label="threshold")
>>> fig = fig.vline(60.0, style=":", label="intervention")
>>> fig = fig.xlabel("day")
```

선 하나에 자리 하나예요. 여러 줄을 그으려면 메서드를 여러 번 불러요. 메서드는 `fig`를 돌려주므로 이어 쓸 수 있어요.

```python
>>> fig = sd.plot.line(day, walk)
>>> for level in (-2.0, -1.0, 1.0, 2.0):
...     fig = fig.hline(level, style=":", width=0.4)
```

## 축의 범위에 들어가요

기준선의 자리는 축의 범위를 잡을 때 자료처럼 들어가요. 자료가 모두 0보다 커도 `hline(0.0)`을 그으면 세로축이 0까지 내려와 선이 보여요. 문턱값이 자료에서 멀면 그만큼 축이 늘어나니, 보이고 싶지 않다면 [`ylim`](/api/plot/customize/)으로 범위를 정해 주세요. 범위를 정하면 그 밖의 기준선은 그리지 않아요.

함수 그림의 점근선이나 극한을 표시할 때도 써요.

```python
>>> fig = sd.plot.function(sd.tanh, -4, 4, label=r"$\tanh x$")
>>> fig = fig.hline(1.0, style="--").hline(-1.0, style="--").vline(0.0, width=0.3)
>>> fig = fig.xlabel(r"$x$")
```

## 로그 축

로그 축에서는 0 이하의 자리를 나타낼 수 없어서, 그런 기준선은 그리지 않고 축의 범위에도 넣지 않아요. 에러는 아니에요.

## 모듈 함수

`sd.plot.hline(y)`와 `sd.plot.vline(x)`도 있어요. 다른 모듈 함수처럼 새 그림을 만들고 그 선 하나만 그려요. 대개는 메서드로 다른 그림 위에 얹어 써요.

```python
>>> fig = sd.plot.vline(1.5, label="cut").line([0, 1, 2, 3], [0, 1, 4, 9])
>>> fig.shape
(1, 1)
```

## 조심할 점

- 자리에는 수 하나만 받아요. 리스트를 주면 `TypeError`예요.

```python
>>> sd.plot.line(day, walk).hline([1.0, 2.0])
Traceback (most recent call last):
    ...
TypeError: hline(): 'y' must be an int or a float, not list
```

- 칸의 한 부분에만 긋는 선분은 없어요. 두 점을 [`line`](/api/plot/line/)으로 이으면 돼요.
- 범주 축에서는 범주의 자리가 0, 1, 2, …라서 `vline(1.5)`가 둘째와 셋째 범주의 사이예요.

## matplotlib을 아는 분께

- `ax.axhline`, `ax.axvline`에 해당해요. 칸의 일부만 덮는 `xmin`, `xmax`는 없어요.
- `plt.hlines(y, xmin, xmax)`처럼 여러 선분을 한 번에 긋는 함수는 없어요. 선분은 `line`으로, 여러 기준선은 메서드를 여러 번 불러 그려요.
- 기본 색이 팔레트의 다음 색이 아니라 축 선과 같은 색이에요.
