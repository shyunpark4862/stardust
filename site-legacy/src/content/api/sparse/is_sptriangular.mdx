## 한눈에 보기

**아래 삼각 행렬**은 주대각선 위가 모두 0인 행렬, **위 삼각 행렬**은 주대각선 아래가 모두 0인 행렬이에요. `is_sptriangular`는 희소 행렬이 어느 쪽인지 `(lower, upper)` 두 bool로 알려 줘요.

```python
>>> import stardust as sd
>>> L = sd.sparse.csr_array(sd.asarray([[2.0, 0.0, 0.0],
...                                     [1.0, 3.0, 0.0],
...                                     [0.0, 4.0, 5.0]]))
>>> sd.sparse.is_sptriangular(L)
(True, False)
>>> sd.sparse.is_sptriangular(L.T)
(False, True)
```

`L`은 아래 삼각이라 `(True, False)`, 그 전치는 위 삼각이라 `(False, True)`예요.

## 네 가지 경우

| 결과 | 뜻 | 예 |
|---|---|---|
| `(True, False)` | 아래 삼각 | `tril(A)` |
| `(False, True)` | 위 삼각 | `triu(A)` |
| `(True, True)` | 둘 다예요(대각선 밖에 아무것도 없어요) | 대각 행렬, 빈 행렬 |
| `(False, False)` | 어느 쪽도 아니에요 | 삼중대각 행렬 |

```python
>>> lower, upper = sd.sparse.is_sptriangular(sd.sparse.eye_array(3))
>>> lower, upper
(True, True)
>>> T = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(4, 4))
>>> sd.sparse.is_sptriangular(T)
(False, False)
>>> sd.sparse.is_sptriangular(sd.sparse.csr_array((3, 3)))
(True, True)
```

결과는 보통의 tuple이라 위처럼 두 변수로 풀어 써요.

## 어디에 쓰나요: 삼각 풀이 고르기

삼각 행렬의 연립방정식은 분해 없이 차례로 대입해 풀 수 있어요. [`spsolve_triangular`](/api/sparse/spsolve_triangular/)는 어느 쪽 삼각인지 `upper=`로 꼭 받으므로, 행렬이 어떤 꼴인지 모를 때 먼저 확인해요.

```python
>>> b = sd.asarray([2.0, 4.0, 9.0])
>>> lower, upper = sd.sparse.is_sptriangular(L)
>>> if lower or upper:
...     x = sd.sparse.spsolve_triangular(L, b, upper=upper and not lower)
... else:
...     x = sd.sparse.spsolve(L, b)
>>> x
array([1.0, 1.0, 1.0], dtype=float64)
```

## 저장된 0도 세요

판정은 값이 아니라 **원소가 저장된 자리**(패턴)로 해요. 대각선 위에 0이 저장돼 있으면 값으로는 아래 삼각이어도 `lower`가 False예요. 저장된 0을 빼려면 먼저 `eliminate_zeros()`를 불러요.

```python
>>> Z = sd.sparse.csr_array((sd.asarray([1.0, 0.0]), sd.asarray([0, 2]), sd.asarray([0, 2, 2, 2])), shape=(3, 3))
>>> sd.sparse.is_sptriangular(Z)
(False, True)
>>> Z.eliminate_zeros()
>>> sd.sparse.is_sptriangular(Z)
(True, True)
```

형식(CSR, CSC, COO, DOK)과 상관없이 같은 결과이고, 정사각이 아니어도 돼요.

## 에러

밀집 배열을 주면 `TypeError`이고, 밀집 배열에서 같은 판정을 하는 함수를 알려 줘요. 1차원 희소 배열은 `ValueError`예요.

```python
>>> sd.sparse.is_sptriangular(L.toarray())
Traceback (most recent call last):
    ...
TypeError: is_sptriangular(): 'A' must be a sparse array, not ndarray; for a dense array use sd.linalg.bandwidth
>>> sd.sparse.is_sptriangular(sd.sparse.coo_array(sd.asarray([1.0, 2.0])))
Traceback (most recent call last):
    ...
ValueError: is_sptriangular(): 'A' must have 2 dimensions, got 1
```

## 밀집 배열의 짝: sd.linalg.bandwidth

밀집 행렬이 삼각인지는 [`sd.linalg.bandwidth(x)`](/api/linalg/bandwidth/)로 알아봐요. 결과의 `upper`가 0이면 아래 삼각, `lower`가 0이면 위 삼각이에요. 희소 쪽에서도 [`spbandwidth`](/api/sparse/spbandwidth/)가 같은 결과를 줘요.

```python
>>> bw = sd.linalg.bandwidth(L.toarray())
>>> bw.upper == 0, bw.lower == 0
(True, False)
```

## scipy를 아는 분께

- `scipy.sparse.linalg.is_sptriangular`와 같은 `(lower, upper)`를 돌려줘요.
- 아무것도 저장하지 않은 행렬은 `(True, True)`예요. scipy 1.18.1은 빈 CSR 행렬에서 예외를 내요.
- 이름공간이 평평해서 `sd.sparse.is_sptriangular`예요.
