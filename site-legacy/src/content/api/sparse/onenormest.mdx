## 한눈에 보기

행렬의 1-노름 $\lVert A\rVert_1$은 열마다 원소의 절댓값을 더한 값 가운데 가장 큰 것이에요. 원소가 보이는 행렬이면 계산이 쉬워요. 희소 배열은 [norm](/api/sparse/norm/)`(A, ord=1)`이 정확히 구해요.

```python
>>> n = 50
>>> L = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(n, n), format='csr')
>>> sd.sparse.norm(L, ord=1)
4.0
```

어려운 것은 원소가 보이지 않는 행렬이에요. 대표적인 것이 역행렬 $A^{-1}$이에요. 희소 행렬의 역행렬은 대개 밀집이라 만들기 비싸지만, 분해([splu](/api/sparse/splu/)) 한 번이면 $A^{-1}x$는 싸게 구할 수 있어요. `onenormest`는 이런 곱 몇 번으로 1-노름을 어림해요.

```python
>>> lu = sd.sparse.splu(L)
>>> inv = sd.sparse.LinearOperator(L.shape, lu.solve, rmatvec=lambda x: lu.solve(x, trans='T'))
>>> r = sd.sparse.onenormest(inv)
>>> r
OnenormestResult(est=325, v=None, w=None, n_iter=2, n_op=3)
```

곱 세 번(한 번에 두 열씩)으로 어림한 값이 325예요. 역행렬을 실제로 만들어 재도 끝자리만 다른 값이에요.

```python
>>> sd.linalg.matrix_norm(sd.linalg.inv(L.toarray()), ord=1)
324.9999999999977
```

## 어디에 쓰나요: 조건수

연립방정식 $Ax = b$를 풀 때 답이 입력의 작은 오차에 얼마나 민감한지를 조건수 $\kappa_1(A) = \lVert A\rVert_1\,\lVert A^{-1}\rVert_1$가 말해 줘요. $\lVert A\rVert_1$은 정확히, $\lVert A^{-1}\rVert_1$은 `onenormest`로 구하면 큰 희소 행렬의 조건수를 역행렬 없이 어림할 수 있어요.

```python
>>> sd.sparse.norm(L, ord=1) * r.est
1299.9999999999905
```

대략 $10^3$이라, 답의 상대오차가 입력의 상대오차보다 천 배쯤까지 커질 수 있다는 뜻이에요. 밀집 행렬이면 [sd.linalg.cond](/api/linalg/cond/)가 같은 것을 구해요.

## 어림은 하한이에요

`onenormest`는 실제로 곱해 본 열의 절댓값 합을 돌려주므로 **참값보다 크지 않아요.** 대개는 참값 그대로이지만, 가장 큰 열을 찾지 못하면 그보다 작은 값이에요.

```python
>>> rng = sd.random.default_rng(3)
>>> A = sd.sparse.random_array((300, 300), density=0.02, format='csr', rng=rng,
...                            data_sampler=lambda k: rng.random(k) - 0.5)
>>> sd.sparse.onenormest(A).est
3.2690236777028066
>>> sd.sparse.norm(A, ord=1)
3.597041419852835
```

이 행렬에서는 참값의 91%예요. `t`를 키우면 한 번에 더 많은 열을 보므로 어림이 좋아져요. `t`가 n 이상이면 모든 열을 곱해서 정확한 값이에요.

```python
>>> sd.sparse.onenormest(A, t=8).est
3.597041419852835
>>> sd.sparse.onenormest(A, t=300)
OnenormestResult(est=3.59704, v=None, w=None, n_iter=0, n_op=1)
```

조건수처럼 크기의 자릿수가 중요한 쓰임에는 기본값으로 대개 충분해요. 시험 행렬에서 가장 나쁜 어림도 참값의 76%예요.

## 결과 읽기

결과는 읽기 전용 결과 객체이고 언제나 `(est, v, w)`로 풀려요.

| 필드 | 뜻 |
|---|---|
| `est` | 1-노름의 어림값(float) |
| `v` | 어림값을 낸 열 j의 단위 벡터 $e_j$(float64). `compute_v=True`일 때만, 아니면 None |
| `w` | $w = Av$, 곧 A의 j번째 열. `compute_w=True`일 때만, 아니면 None |
| `n_iter` | 반복 수. t ≥ n의 정확한 계산이면 0 |
| `n_op` | $AX$와 $A^HX$의 곱의 수. t열 묶음 하나를 곱한 것이 1 |

`v`와 `w`가 있으면 어림값의 근거를 볼 수 있어요. $\lVert w\rVert_1 = \lVert Av\rVert_1$이 어림값이에요.

```python
>>> est, v, w = sd.sparse.onenormest(inv, compute_v=True, compute_w=True)
>>> int(sd.argmax(v))
24
>>> float(sd.sum(sd.abs(w)))
324.9999999999977
```

$L^{-1}$은 가운데의 두 열(24번과 25번)의 절댓값 합이 같고 가장 커요. 그 가운데 하나를 찾은 거예요.

```python
>>> print(sd.sparse.onenormest(inv, compute_v=True).summary())
                           1-Norm Estimate Results
==============================================================================
Estimate:                   325.000000  No. Iterations:                      2
Column:                             24  No. A X, A^H X:                      3
==============================================================================
```

## 같은 호출은 같은 어림값

어림은 처음에 ±1로 된 열을 무작위로 골라 출발해요. 그 난수는 호출마다 `sd.random.default_rng(0)`에서 뽑으므로 같은 입력이면 언제나 같은 어림값이에요. 고르는 값이 같은 열이 둘 이상이면 색인이 작은 쪽부터 봐요.

## 입력과 에러

희소 배열의 형식과 dtype, 저장된 0과 NaN, 결정성 같은 공통 규칙은 [기본 개념](/api/sparse/basics/)에 있어요.

- A는 정사각이어야 해요. 희소 배열, 2차원 밀집 배열, `LinearOperator`를 받아요.
- `LinearOperator`는 $A^H$의 곱도 필요해서 `rmatvec`이 있어야 해요.

  ```python
  >>> sd.sparse.onenormest(sd.sparse.LinearOperator(L.shape, lu.solve))
  Traceback (most recent call last):
      ...
  ValueError: onenormest(): the operator was made without 'rmatvec'
  ```

- `t`는 1 이상, `max_iter`는 2 이상이에요.

  ```python
  >>> sd.sparse.onenormest(L, t=0)
  Traceback (most recent call last):
      ...
  ValueError: onenormest(): 't' must be >= 1
  ```

- 0 × 0 행렬의 어림값은 0이에요.

## `norm`과 `onenormest`, 언제 무엇을

| 상황 | 쓸 것 |
|---|---|
| 원소가 보이는 희소 배열의 1-노름 | [norm](/api/sparse/norm/)`(A, ord=1)`. 정확하고, 저장된 원소를 한 번 읽으면 돼요 |
| 밀집 배열의 1-노름 | [sd.linalg.matrix_norm](/api/linalg/norms/)`(A, ord=1)` |
| 곱만 할 수 있는 연산자(역행렬, 행렬의 곱, 거듭제곱)의 1-노름 | `onenormest` |
| 큰 희소 행렬의 조건수 | `norm(A, ord=1) * onenormest(A의 역).est` |

## 정확도

어림값이라 정확도의 약속은 없어요. 언제나 참값 이하이고, 정방 시험 행렬 42개에서 26개가 참값과 같고, 가장 작은 비율(어림값 ÷ 참값)은 0.76이에요.

## scipy를 아는 분께

- `scipy.sparse.linalg.onenormest`와 같은 함수이고, Higham–Tisseur의 블록 어림 방법을 scipy와 같은 단계로 해요. t ≥ n이면 정확한 노름인 것도 같아요.
- 결과가 언제나 결과 객체 하나예요. scipy는 기본으로 float 하나를, `compute_v`·`compute_w`에 따라 `(est, v)`, `(est, w)`, `(est, v, w)`를 돌려줘요. 여기서는 `est, v, w = ...`로 풀거나 `.est`를 읽어요.
- 처음의 무작위 열이 고정되어 같은 호출은 같은 어림값이에요. scipy는 시드 없는 난수라 실행마다 다를 수 있어요.
- `itmax`는 `max_iter`예요. 인자는 `A`만 위치예요.
