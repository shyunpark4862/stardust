## 한눈에 보기

`make_lsq_spline`은 매듭 `t`를 정해 주면, 그 매듭의 $k$차 B-스플라인 가운데 자료에 가장 가까운 것을 골라요.

$$
\min_c \sum_i \bigl(w_i (y_i - f(x_i))\bigr)^2, \qquad f(x) = \sum_j c_j B_{j,k}(x)
$$

매듭이 몇 개 없으면 곡선이 표현할 수 있는 모양이 적어서 저절로 매끄러워요. 벌점은 없어요. 매듭의 수와 자리가 곧 매끄러움을 정해요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> x = sd.sort(rng.random(60)) * 10
>>> y = sd.sin(x) + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> a, b = float(sd.min(x)), float(sd.max(x))
>>> t = sd.concat([sd.full(3, a), sd.linspace(a, b, 6), sd.full(3, b)])
>>> t
array([0.09910608711773516, 0.09910608711773516, 0.09910608711773516,
       0.09910608711773516,   2.051185086006887,    4.00326408489604,
         5.955343083785192,   7.907422082674344,   9.859501081563495,
         9.859501081563495,   9.859501081563495,   9.859501081563495], dtype=float64)
>>> s = sd.smooth.make_lsq_spline(x, y, t)
>>> s

>>> s([2.0, 5.0, 8.0])
array([ 0.8966735696555964, -0.9983102570354632,  0.9909599548436704], dtype=float64)
```

## 매듭과 자료

계수 $c_j$는 매듭 $t_j$부터 $t_{j+k+1}$까지에서만 0이 아닌 B-스플라인 $B_{j,k}$의 계수예요. 그래서 계수마다 그 구간 안에 자료점이 있어야 정해져요. 정확히는 계수와 양수 무게의 점을 겹치지 않게 짝지어, $j$째 계수의 점이 $t_j \lt x \lt t_{j+k+1}$에 있어야 해요(**Schoenberg–Whitney 조건**). 이 조건이 깨지면 조용히 NaN을 내지 않고 에러예요.

```python
>>> tb = sd.concat([sd.full(4, a), sd.asarray([5.0, 5.001, 5.002, 5.003, 5.004]), sd.full(4, b)])
>>> sd.smooth.make_lsq_spline(x, y, tb)
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: make_lsq_spline(): the Schoenberg-Whitney conditions fail: no data point of positive weight in the support of B-spline 4 (the knots [5.0, 5.004])
```

x는 $t_k \le x \le t_{n_c}$ 안이어야 해요(바깥쪽 겹친 매듭 사이).

```python
>>> sd.smooth.make_lsq_spline(x, y, sd.concat([sd.full(4, 1.0), sd.full(4, b)]))
Traceback (most recent call last):
    ...
ValueError: make_lsq_spline(): 'x' must lie within the knots: t[k] <= x <= t[-k]
```

정렬되지 않은 x와 같은 x도 받아요. 결과는 입력의 순서와 무관해요.

```python
>>> perm = rng.permutation(60)
>>> s2 = sd.smooth.make_lsq_spline(x[perm], y[perm], t)
>>> float(sd.max(sd.abs(s2.c - s.c)))
0.0
```

## 무게

`w`는 잔차에 곱하는 무게예요. 최소화하는 양이 $\sum (w_i r_i)^2$이라 `w`는 점마다의 표준편차의 역수 $1/\sigma_i$로 줘요. [`smoothing_spline`](/api/smooth/smoothing_spline/)과 [`pspline`](/api/smooth/pspline/)의 `weights`($\sum w_i r_i^2$)와 뜻이 다르니 조심해요. `w`를 두 배로 하면 `weights`를 네 배로 한 것과 같아요.

```python
>>> w = sd.ones(60)
>>> w[:30] = 2.0
>>> p0 = sd.smooth.pspline(x, y, lam=0.0, n_segments=5, weights=w * w)
>>> sw = sd.smooth.make_lsq_spline(x, y, p0.spline.t, w=w)
>>> float(sd.max(sd.abs(sw.c - p0.spline.c)))
0.0
```

## 차수와 여러 열

`k`는 B-스플라인의 차수예요. 매듭의 양 끝은 보통 $k + 1$번 겹쳐요. 여러 열은 `axis`로 함께 맞춰요.

```python
>>> t1 = sd.concat([sd.full(1, a), sd.linspace(a, b, 8), sd.full(1, b)])
>>> sd.smooth.make_lsq_spline(x, y, t1, k=1)
BSpline(degree=1, knots=10, extrapolate=True)
>>> sd.smooth.make_lsq_spline(x, sd.stack([y, -y], axis=1), t)(5.0)
array([-0.9983102570354632,  0.9983102570354632], dtype=float64)
```

## 조심할 점

NaN과 ±inf는 에러예요. 결측값은 먼저 빼요. 옵션은 이름으로 줘요.

```python
>>> yn = y.copy()
>>> yn[0] = float('nan')
>>> sd.smooth.make_lsq_spline(x, yn, t)
Traceback (most recent call last):
    ...
ValueError: make_lsq_spline(): the input contains NaN
>>> sd.smooth.make_lsq_spline(x, y, t, 3)
Traceback (most recent call last):
    ...
TypeError: make_lsq_spline(): takes 3 positional arguments but 4 were given
```

같은 입력이면 스레드 수와 상관없이 같은 비트예요.

## scipy를 아는 분께

- `scipy.interpolate.make_lsq_spline(x, y, t, k, w, axis)`와 같은 문제와 같은 무게의 뜻이에요. `k`, `w`, `axis`는 이름으로만 받고 `method`, `check_finite`는 없어요.
- scipy는 줄지 않는 x만 받아요. sd는 정렬되지 않은 x와 같은 x를 받아요.
- Schoenberg–Whitney 조건을 양수 무게의 점으로 정확히 판정해서 깨지면 `LinAlgError`예요. scipy의 QR 길은 같은 입력에서 경고 없이 NaN 계수를 내요.
- `LSQUnivariateSpline(x, y, t_interior, w, k)`의 일은 `make_lsq_spline(x, y, t, w=w, k=k)`예요. `t`는 안쪽 매듭이 아니라 양 끝을 $k + 1$번 붙인 전체 매듭이에요.
