## 한눈에 보기

P-스플라인은 평활 스플라인을 가볍게 만든 것이에요. 매듭을 자료점마다 두지 않고 범위를 고른 간격의 구간 몇 개로 나눠 두고, 그 위의 B-스플라인 계수 $c$를 이렇게 골라요.

$$
\sum_i w_i \bigl(y_i - f(x_i)\bigr)^2 + \lambda \lVert D_d c \rVert^2
$$

$D_d$는 이웃한 계수의 $d$차 차분이에요(`diff_order`). 기본 $d = 2$는 $c_{j+1} - 2c_j + c_{j-1}$을 벌줘서, $\lambda$가 클수록 계수가 직선에 가까이 놓이고 곡선이 펴져요. 매듭이 적어도 벌점이 출렁임을 막아 주니 매듭의 수와 자리를 고민하지 않아도 돼요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> x = sd.sort(rng.random(60)) * 10
>>> y = sd.sin(x) + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> p = sd.smooth.pspline(x, y)
>>> p
PSplineResult(nobs=60, df=7.86536, lam=0.857122, n_segments=15)
>>> p.spline
BSpline(degree=3, knots=22, extrapolate=True)
>>> p.predict([2.0, 5.0, 8.0])
array([0.8434885659519396, -1.024841013743487, 0.8648877797354947], dtype=float64)
>>> p.n_segments, p.k, p.diff_order
(15, 3, 2)
```

## 매듭과 차수

`[xb, xe]`(기본은 x의 최솟값과 최댓값)를 `n_segments`개의 같은 구간으로 나누고, 그 경계와 바깥으로 $k$개씩 더 이어 놓은 점을 매듭으로 써요. 계수는 `n_segments + k`개예요. 기본 구간 수는 $\lceil \min(n/4, 40) \rceil$이라 점이 160개를 넘으면 늘지 않아요.

```python
>>> p.spline.t[:6], len(p.spline.c)
(array([-1.8529729117714169, -1.2022799121416996, -0.5515869125119822,
       0.09910608711773516,  0.7497990867474525,    1.40049208637717], dtype=float64), 18)
>>> big = sd.smooth.pspline(sd.linspace(0, 10, 100000), sd.sin(sd.linspace(0, 10, 100000)))
>>> big.n_segments, len(big.spline.c)
(40, 43)
```

구간 수를 늘리면 더 가는 굴곡을 표현할 수 있어요. 다만 매끄러움은 $\lambda$가 정하므로 구간 수에 아주 민감하지는 않아요.

```python
>>> for ns in (8, 15, 40):
...     q = sd.smooth.pspline(x, y, n_segments=ns)
...     print(ns, round(q.df, 3), round(float(q.scale), 4))
8 7.284 0.286
15 7.865 0.2864
40 8.281 0.2862
```

## λ

`lam`, `df`, `criterion`의 뜻과 찾는 법은 [`smoothing_spline`](/api/smooth/smoothing_spline/)과 같아요. 극한은 차분 벌점에서 나와요.

- $\lambda = \infty$이면 $D_d c = 0$이라 계수가 $d - 1$차 다항식 위에 놓여요. 기본 $d = 2$는 직선의 최소제곱이에요.
- $\lambda = 0$이면 벌점 없는 B-스플라인 최소제곱이에요. 무게가 1이면 같은 매듭의 [`make_lsq_spline`](/api/smooth/make_lsq_spline/)과 같은 비트예요. 자료가 없는 구간이 있으면 계수가 정해지지 않아 에러예요.

```python
>>> pi = sd.smooth.pspline(x, y, lam=float('inf'))
>>> round(pi.df, 6)
2.0
>>> p3 = sd.smooth.pspline(x, y, lam=float('inf'), diff_order=3)
>>> round(p3.df, 6)
3.0
>>> p0 = sd.smooth.pspline(x, y, lam=0.0)
>>> ls = sd.smooth.make_lsq_spline(x, y, p0.spline.t)
>>> bool(sd.all(p0.spline.c == ls.c))
True
>>> sd.smooth.pspline(sd.asarray([0.0, 0.1, 0.2, 0.3, 9.8, 9.9, 10.0]), sd.ones(7), lam=0.0, n_segments=10)
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: pspline(): lam=0 is the least-squares spline and its system is singular (an interval without data: the Schoenberg-Whitney conditions fail)
```

```python
>>> sd.smooth.pspline(x, y, df=6).lam
3.888586814385201
>>> pc = sd.smooth.pspline(x, y, criterion='cv')
>>> round(pc.df, 4), pc.status, pc.converged
(8.0035, 0, True)
```

## 범위

자료는 `[xb, xe]` 안에 있어야 해요. 범위를 넓혀 두면 나중에 그 범위 끝까지 같은 매듭의 곡선을 쓸 수 있어요.

```python
>>> sd.smooth.pspline(x, y, xb=0.0, xe=12.0).spline.t[-4:]
array([12.0, 12.8, 13.6, 14.4], dtype=float64)
>>> sd.smooth.pspline(x, y, xb=1.0)
Traceback (most recent call last):
    ...
ValueError: pspline(): 'x' must lie within [xb, xe] = [1.0, 9.859501081563495]
```

- 같은 입력이면 스레드 수와 상관없이 같은 비트예요.
- 여러 열(`axis`), 무게, `nan_policy`는 [`smoothing_spline`](/api/smooth/smoothing_spline/)과 같아요.

## R을 아는 분께

- `mgcv`의 `gam(y ~ s(x, bs="ps"))`와 같은 종류의 평활기예요. 매듭을 놓는 법과 $\lambda$를 고르는 기본 기준이 달라 값은 같지 않아요(GCV의 식은 같아요).
- R `smooth.spline`의 기본은 점이 많으면 매듭을 줄여요. 그런 쓰임에는 `pspline`이 가까워요.
