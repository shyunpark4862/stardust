## 한눈에 보기

`make_splrep`은 이런 스플라인을 찾아요.

$$
\sum_i \bigl(w_i (y_i - g(x_i))\bigr)^2 \le s \text{ 인 } k\text{차 스플라인 } g \text{ 가운데 가장 매끄러운 것}
$$

"가장 매끄럽다"는 매듭에서 $k$차 도함수가 뛰는 크기의 제곱합이 가장 작다는 뜻이에요. 매듭은 가장 적은 수에서 시작해, 잔차가 가장 큰 구간에 하나씩 더하며 늘려요. 잔차 제곱합이 `s` 가까이 내려오면 멈추고, 그 매듭에서 잔차 제곱합이 정확히 `s`(허용 0.1%)가 되도록 매끄러움을 맞춰요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> x = sd.sort(rng.random(60)) * 10
>>> y = sd.sin(x) + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> g = sd.smooth.make_splrep(x, y, s=5.4)
>>> g
BSpline(degree=3, knots=10, extrapolate=True)
>>> g.t
array([0.09910608711773516, 0.09910608711773516, 0.09910608711773516,
       0.09910608711773516,   5.569990763634657,   7.602089803599945,
         9.859501081563495,   9.859501081563495,   9.859501081563495,
         9.859501081563495], dtype=float64)
>>> float(sd.sum((y - g(x)) ** 2))
5.396248011896503
```

`s`를 정하는 기준은 잡음의 크기예요. 점마다 표준편차 $\sigma$의 잡음이 있고 `w`가 모두 1이면 잔차 제곱합의 기댓값이 $m\sigma^2$이라 `s`를 그 둘레로 줘요. 위 자료는 $m = 60$, $\sigma = 0.3$이라 $m\sigma^2 = 5.4$예요. 점마다 표준편차 $\sigma_i$가 다르면 `w = 1/σ`를 주고 `s`를 $m$ 둘레로 둬요.

## `s`와 매듭

```python
>>> for s in (0.0, 2.0, 5.4, 12.0, 40.0):
...     gs = sd.smooth.make_splrep(x, y, s=s)
...     print(s, len(gs.t), round(float(sd.sum((y - gs(x)) ** 2)), 4))
0.0 64 0.0
2.0 35 1.9984
5.4 10 5.3962
12.0 9 12.01
40.0 8 28.139
```

- `s = 0`이면 모든 점을 지나는 보간 스플라인이에요. [`make_interp_spline(x, y, k=k)`](/api/interpolate/make_interp_spline/)과 같은 비트예요.
- `s`가 아주 크면 매듭이 없는(양 끝만 겹친) $k$차 다항식이 돼요. 그 다항식의 잔차도 `s` 아래면 그대로 돌려줘요.

```python
>>> g0 = sd.smooth.make_splrep(x, y)
>>> gi = sd.interpolate.make_interp_spline(x, y)
>>> bool(sd.all(g0.c == gi.c))
True
```

매듭이 늘어 가는 과정은 [`generate_knots`](/api/smooth/generate_knots/)가 보여 줘요.

### `nest`와 닿지 않는 `s`

매듭은 `nest`개까지만 늘려요. 그 안에서 `s`에 닿지 못하면 그때의 스플라인을 내지 않고 에러예요.

```python
>>> sd.smooth.make_splrep(x, y, s=0.5, nest=12)
Traceback (most recent call last):
    ...
ValueError: make_splrep(): s = 0.5 cannot be reached with these knots: the least-squares spline on them has sum (w r)^2 = 4.3291006327501576 (more knots: a larger 'nest', or other 't')
```

### 매듭 주기: `t`

`t`를 주면 매듭을 고르지 않고, 그 매듭에서 잔차 제곱합이 `s`가 되도록 매끄러움만 맞춰요.

```python
>>> tt = g.t
>>> sd.smooth.make_splrep(x, y, s=8.0, t=tt).t.shape
(10,)
```

## 차수와 주기 조건

`k`는 1–5예요. `bc_type='periodic'`은 처음과 끝이 이어지는 주기 스플라인이고, 처음 값과 끝 값이 같아야 해요.

```python
>>> th = sd.linspace(0, 2 * sd.pi, 41)
>>> yp = sd.cos(th) + 0.05 * sd.sin(9 * th)
>>> gp = sd.smooth.make_splrep(th, yp, s=0.05, bc_type='periodic')
>>> gp(0.0), gp(2 * sd.pi)
(1.0019292373996194, 1.0019292373996194)
>>> gp(0.0, nu=1), gp(2 * sd.pi, nu=1)
(-4.9438375248330215e-05, -4.9438375248330215e-05)
>>> sd.smooth.make_splrep(x, y, k=6)
Traceback (most recent call last):
    ...
ValueError: make_splrep(): 'k' must be in [1, 5] (FITPACK's degrees), not 6
```

## 곡선: `make_splprep`

`make_splprep`은 x와 y가 따로 함수가 아닌 곡선(원, 나선, 손으로 그린 선)을 맞춰요. 점 $m$개의 좌표를 (d, m) 배열로 주면, 점마다 매개변수 $u$를 붙이고 좌표마다 $u$의 스플라인을 같은 매듭으로 맞춰요. 잔차는 점과 곡선 위의 점 사이 거리의 제곱을 모두 더한 것이에요. `u`를 주지 않으면 이웃한 점 사이의 거리(현의 길이)를 누적해 [0, 1]로 맞춘 값을 써요.

```python
>>> ang = sd.linspace(0, 1.5 * sd.pi, 30)
>>> P = sd.stack([sd.cos(ang), sd.sin(ang)], axis=0) + 0.02 * sd.cos(7 * ang)
>>> curve, u = sd.smooth.make_splprep(P, s=0.01)
>>> curve
BSpline(degree=3, knots=10, extrapolate=True)
>>> u[:4]
array([                0.0, 0.03231996389214381, 0.06396186920830535,
       0.09777130998319834], dtype=float64)
>>> curve([0.0, 0.5, 1.0])
array([[  1.0104380467849845,  -0.7232028105878193,  0.02374762948352903],
       [0.012577554297348964,   0.6985135063799561,  -0.9781091986342857]], dtype=float64)
>>> curve([0.0, 0.5, 1.0]).shape
(2, 3)
```

결과를 부르면 좌표가 첫 축이에요. 평가점이 셋이면 (2, 3)이에요.

## 무게와 입력

`w`는 잔차에 곱하는 무게라 최소화하는 양이 $\sum (w_i r_i)^2$이에요([`make_lsq_spline`](/api/smooth/make_lsq_spline/)과 같고, `smoothing_spline`의 `weights`와 달라요). x(`make_splprep`은 `u`)는 줄지 않아야 해요. 매듭을 놓는 규칙이 점의 순서에 기대므로 대신 정렬해 주지 않아요.

```python
>>> sd.smooth.make_splrep(x[::-1], y[::-1], s=5.4)
Traceback (most recent call last):
    ...
ValueError: make_splrep(): 'x' must be nondecreasing
>>> sd.smooth.make_splrep(x, y, t=g.t)
Traceback (most recent call last):
    ...
ValueError: make_splrep(): s = 0 is interpolation: 't', 'w' and 'nest' are not used
>>> sd.smooth.make_splrep(x, y, 5.4)
Traceback (most recent call last):
    ...
TypeError: make_splrep(): takes 2 positional arguments but 3 were given
```

`s = 0`(보간)에 `t`, `w`, `nest`를 함께 주면 에러예요.

## 조심할 점

- 같은 `s`라도 이 함수의 매듭과 옛 `splrep`의 매듭은 달라요. 두 방식은 매듭을 놓는 규칙이 달라서 다른 스플라인을 내요.
- 매듭을 고르는 일은 잔차 크기의 비교로 이루어져서, 자료를 아주 조금 바꿔도 매듭이 갈릴 수 있어요. 같은 입력이면 언제나 같은 비트예요.

## scipy를 아는 분께

- `scipy.interpolate.make_splrep`, `make_splprep`과 같은 뜻, 같은 인자예요(옵션은 이름으로만). 매듭을 놓는 규칙과 멈춤 규칙($\lvert \sum (w r)^2 - s\rvert \le 0.001 s$)이 scipy 1.18의 것이에요. 지금은 시험한 모든 자료에서 매듭이 scipy와 비트까지 같아요(약속은 아니에요). 주기 스플라인은 매듭이 같고, 매끄러움을 맞추는 근 찾기가 다른 데서 시작해 곡선이 $10^{-4}$ 크기로 다를 수 있어요(둘 다 멈춤 규칙 안이에요).
- `s`에 닿지 못하면 scipy는 경고와 함께 그때의 스플라인을 주지만 sd는 `ValueError`예요. scipy의 "최대 반복에 닿았다" 경고에 해당하는 일은 없어요(근 찾기가 이분으로 이어 가 언제나 끝나요).
- 옛 `splrep`, `splprep`, `UnivariateSpline`은 없어요. `splrep(x, y, w, s)`와 `splev`는 `make_splrep(x, y, w=w, s=s)`와 결과의 호출이에요. 같은 `s`에서 매듭이 달라요(시험 자료에서 `s = 12`의 매듭이 89개와 73개였어요). `splrep`은 무게를 주면 기본 `s`가 $m - \sqrt{2m}$이라 그 값을 직접 줘야 해요. `UnivariateSpline`의 기본 `s`는 $m$이고 여기는 0이에요.
