## 한눈에 보기

표본이 어떤 분포에서 왔는지 모를 때, 히스토그램은 구간을 어떻게 나누느냐에 따라 모양이 바뀌고 계단처럼 끊겨요. **핵밀도추정**(kernel density estimation, KDE)은 점마다 작은 종 모양의 밀도(핵)를 얹고 그것들을 평균 내어 매끄러운 밀도를 만들어요.

$$
\hat f(x) = \sum_j w_j\, K_h(x - x_j), \qquad K_h(z) = \frac{1}{h}\,\varphi\!\left(\frac{z}{h}\right)
$$

$\varphi$는 표준정규밀도, $w_j$는 합이 1인 무게(기본은 모두 $1/n$)예요. 종의 폭 $h$가 **대역폭**이에요. 좁으면 점마다 뾰족한 봉우리가 서고, 넓으면 봉우리가 뭉개져요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(3)
>>> a = sd.stats.Normal(mu=-2.0, sigma=0.6).sample(120, rng=rng)
>>> b = sd.stats.Normal(mu=1.5, sigma=1.0).sample(180, rng=rng)
>>> data = sd.concat([a, b])
>>> k = sd.smooth.kde(data)
>>> k
KDEResult(nobs=300, ndim=1, bw=0.606698, kernel='gaussian')
>>> k.pdf([-2.0, 0.0, 1.5])
array([ 0.1917068988634632, 0.10827078150540963, 0.21099739069922366], dtype=float64)
>>> k.cdf(0.0)
0.46558736937220147
```

자료는 두 정규분포를 섞은 것이에요. 대역폭은 기본 규칙(Scott)으로 골랐어요.

## 대역폭 `bw`와 `adjust`

`bw`에 규칙의 이름을 주면 자료에서 대역폭을 골라요. 수를 주면 그 수가 대역폭(핵의 표준편차) 그 자체예요. `adjust`는 고른 대역폭에 곱하는 수예요.

```python
>>> for rule in ('scott', 'silverman', 'nrd0', 'sj', 'isj', 'cv_ls'):
...     print(rule, round(sd.smooth.kde(data, bw=rule).bw, 4))
scott 0.6067
silverman 0.6426
nrd0 0.546
sj 0.3066
isj 0.3235
cv_ls 0.3109
>>> sd.smooth.kde(data, bw=0.3).bw
0.3
>>> round(sd.smooth.kde(data, adjust=0.5).bw, 4)
0.3033
```

규칙마다의 식과 고르는 법은 [대역폭 선택자](/api/smooth/bandwidth/)에 있어요. 정규분포 하나를 가정한 규칙(`'scott'`, `'silverman'`, `'nrd0'`, `'nrd'`)은 봉우리가 여럿인 자료에서 대역폭을 크게 잡는 편이고, `'sj'`, `'isj'`, 교차검증은 자료의 모양을 더 따라가요.

## 밀도 읽기: `pdf`, `logpdf`, `cdf`

`pdf(x)`는 밀도, `logpdf(x)`는 그 로그, `cdf(x)`는 누적분포(한 변수만)예요. 한 변수는 어떤 모양의 평가점이든 받아 같은 모양으로 돌려주고 수 하나는 float예요.

```python
>>> k.pdf(sd.linspace(-4, 4, 5))
array([0.011959602589327248,   0.1917068988634632,  0.10827078150540963,
        0.17760553852996488,  0.02068351187668941], dtype=float64)
>>> k.logpdf(40.0), k.pdf(40.0)
(-1693.1627154559008, 0.0)
>>> k.cdf([-10.0, 0.0, 10.0])
array([5.3916934587890766e-30,    0.46558736937220147,
                          1.0], dtype=float64)
```

밀도가 double로 0이 되는 먼 꼬리에서도 `logpdf`는 정확한 값을 내요. 가장 큰 항을 지수 밖으로 빼고 더하기 때문이에요. 꼬리의 확률을 비교하거나 우도를 더할 때는 `logpdf`를 써요.

`pdf`는 정의 그대로 모든 점의 핵을 더한 값이에요. 결과를 바꾸지 않는 것이 증명된 먼 항만 건너뛰어요. 그래서 꼬리에서도 상대오차가 작아요.

## 핵 `kernel`

한 변수에서는 다른 핵도 쓸 수 있어요. 어떤 핵이든 `bw`는 **핵의 표준편차**예요. 그래서 같은 `bw`면 핵이 달라도 곡선이 비슷하게 매끄러워요.

```python
>>> for kern in ('gaussian', 'epanechnikov', 'rectangular', 'triangular', 'biweight', 'cosine'):
...     kk = sd.smooth.kde(data, bw=0.4, kernel=kern)
...     print(kern, round(float(kk.pdf(0.0)), 5))
gaussian 0.10006
epanechnikov 0.0981
rectangular 0.09141
triangular 0.09863
biweight 0.0984
cosine 0.09858
```

가우스가 아닌 핵은 지지집합이 유한해서, 자료에서 멀리 떨어진 자리의 밀도가 정확히 0이에요.

## 격자 위의 값: `density`

그림을 그리거나 다른 계산에 넘기려면 고른 격자 위의 값이 필요해요. `density()`는 `DensityResult(x, density)`를 돌려줘요. 격자는 $[\min - \mathit{cut}\cdot h,\ \max + \mathit{cut}\cdot h]$의 `n`점이에요(`lower`, `upper`로 끝을 바꿔요).

```python
>>> d = k.density()
>>> d.x.shape, d.density.shape
((512,), (512,))
>>> float(d.x[0]), float(d.x[-1])
(-5.241523659516233, 6.57892212998879)
>>> xs, ys = k.density(n=5, lower=-3.0, upper=3.0)
>>> xs
array([-3.0, -1.5,  0.0,  1.5,  3.0], dtype=float64)
>>> ys
array([ 0.0949871457142528, 0.16962327242926029, 0.10827386536287507,
       0.21099217172725523, 0.07542379214845911], dtype=float64)
>>> k.pdf(xs)
array([0.09498630644856743, 0.16962659033505895, 0.10827078150540963,
       0.21099739069922366, 0.07542332637568842], dtype=float64)
```

기본 `binned=True`는 자료를 격자에 선형으로 나눠 얹고(구간화) FFT 합성곱으로 빠르게 구한 어림이에요. 격자점의 절대오차가 $\delta^2/(8\sqrt{2\pi}h^3) + \varphi(8.3)/h$ 이하예요($\delta$는 격자 간격). 꼬리의 아주 작은 값은 상대오차가 커요. 정확한 값이 필요하면 `binned=False`를 줘요. 격자점마다 `pdf`예요.

```python
>>> d2 = k.density(binned=False)
>>> float(sd.max(sd.abs(d2.density - d.density)))
9.7802729753238e-06
>>> bool(sd.all(d2.density == k.pdf(d2.x)))
True
```

`n`을 주지 않으면 한 변수 512점, 두 변수는 축마다 128점, 세 변수는 64점이에요. 한 변수에서 512보다 적게 청하면 512점에서 계산해 선형 보간해요. 여러 변수는 세 변수까지이고, `x`가 축마다 격자의 튜플, `density`가 (n, …, n) 배열이에요.

## 여러 변수

```python
array([[0.16000000000000003,                 0.0],
       [                0.0,                0.36]], dtype=float64)
>>> sd.smooth.kde(P, bw='cv_ml').bw
array([0.39094935206635517, 0.42088033738278813], dtype=float64)
```

(p,) 배열은 변수마다의 표준편차(대각 $H$), (p, p) 배열은 $H$ 그 자체예요. `marginal(dims)`은 고른 변수만의 밀도예요(가우스 핵에서 $H$의 부분 행렬).

```python
>>> m0 = k2.marginal(0)
>>> m0.ndim, round(m0.bw, 6), round(float(k2.covariance[0, 0]) ** 0.5, 6)
(1, 0.733742, 0.733742)
>>> gx, gy = k2.density(n=4).x
>>> gx
array([ -5.622655232460307, -1.4284189206625832,  2.7658173911351405,
         6.960053702932864], dtype=float64)
>>> k2.density(n=4).density.shape
(4, 4)
```

## 경계: `bounds`

양수만 나오는 자료(대기 시간, 소득)를 그대로 추정하면 0 왼쪽에도 밀도가 새어 나가고, 그만큼 0 근처가 낮아져요. `bounds=(lo, hi)`를 주면 경계 밖으로 나간 핵을 거울처럼 접어 안으로 돌려요. 밀도는 $\hat f(x) + \hat f(2\,lo - x) + \hat f(2\,hi - x)$이고 구간 밖은 0이에요.

```python
>>> e = sd.abs(sd.stats.Normal().sample(200, rng=rng))
>>> plain = sd.smooth.kde(e)
>>> refl = sd.smooth.kde(e, bounds=(0.0, float('inf')))
>>> plain.pdf([-0.2, 0.0, 0.5]), refl.pdf([-0.2, 0.0, 0.5])
(array([0.17641391502948686, 0.41853423028797676,  0.6641021983318443], dtype=float64), array([               0.0, 0.8370684605759535, 0.6792470546161116], dtype=float64))
>>> plain.cdf(0.0), refl.cdf(0.0)
(0.08201053624857602, 0.0)
>>> sd.smooth.kde(e, bounds=(0.5, float('inf')))
Traceback (most recent call last):
    ...
ValueError: kde(): every point must lie within 'bounds'
```

## 결과 읽기

| 필드 | 뜻 |
|---|---|
| `bw` | 한 변수는 핵의 표준편차(float), 여러 변수는 $\sqrt{\mathrm{diag}\,H}$ (p,) |
| `covariance` | 핵의 공분산 $H$ (p, p) |
| `factor` | `'scott'`·`'silverman'`의 인수 $f$(그 밖은 NaN) |
| `neff`, `nobs`, `ndim` | 유효 표본 수 $(\sum w)^2/\sum w^2$, 점의 수, 차원 |
| `kernel`, `bounds`, `weights` | 받은 값(무게는 합이 1로 맞춘 것) |

`KDEResult`는 분포 객체처럼 `pdf`, `logpdf`, `cdf`, `sample`을 쓰고 `summary()`는 없어요. `DensityResult`는 이름 붙은 튜플 `(x, density)`라 위처럼 풀어 쓸 수 있어요. 그 배열도 다른 결과의 배열처럼 쓰기 금지라, 고치려면 사본을 만들어요.

```python
>>> k.factor, k.neff, k.nobs, k.ndim
(0.3195771718380609, 300.0, 300, 1)
```

## scipy·statsmodels·sklearn·R을 아는 분께

- **자료의 꼴**: scipy의 `gaussian_kde(dataset)`은 (p, n)(점이 열)이고 sd는 (n, p)(점이 행)예요. statsmodels, sklearn, 그리고 sd의 다른 영역과 같은 꼴이에요.
- **수로 준 `bw`**: scipy의 수는 표본 표준편차에 곱하는 인수지만 sd의 수는 대역폭 그 자체예요(R, statsmodels, sklearn과 같아요). scipy의 `bw_method=f`는 한 변수에서 `bw=f * σ̂`, 여러 변수에서 `bw=f**2 * Σ̂`의 (p, p) 행렬이에요. `adjust`는 R·statsmodels와 같은 이름이에요.
- **규칙의 이름이 같아도 값이 달라요**: 같은 자료(표본 표준편차 1.226, n = 200)의 `'scott'`이 scipy 0.4249, sklearn 0.3466, statsmodels 0.3865, R `bw.nrd` 0.3895였어요. sd의 이름마다 식은 하나이고 [대역폭 선택자](/api/smooth/bandwidth/)에 있어요. 기본도 달라요: R은 `nrd0`, sklearn은 1.0, sd는 scipy처럼 `'scott'`이에요.
- **가우스가 아닌 핵의 눈금**: sd와 R은 `bw`가 핵의 표준편차예요. sklearn과 statsmodels는 지지집합의 반폭이라, 그쪽의 대역폭 $b$는 sd의 `bw` = $b/\sqrt5$(Epanechnikov), $b/\sqrt3$(rectangular, sklearn `'tophat'`), $b/\sqrt6$(triangular, sklearn `'linear'`), $b/\sqrt7$(biweight)이에요. sklearn의 `'cosine'`은 다른 꼴의 핵이고 sd의 `'cosine'`은 R의 것이에요. sklearn의 `'exponential'`은 없어요.
- scipy의 `evaluate`·`__call__`은 `pdf`, `resample`은 `sample(rng=…)`, `integrate_box_1d`는 `cdf`의 차, `set_bandwidth`는 `kde`를 다시 부르는 것이에요. `integrate_box`, `integrate_gaussian`, `integrate_kde`는 없어요.
- sklearn의 `score_samples(Y)`는 `logpdf(Y)`예요. `atol`·`rtol`의 어림은 없고 언제나 정확도 약속 안의 합이에요.
- statsmodels의 `KDEUnivariate(x).fit(kernel, bw, fft, gridsize, cut)`은 `kde(x, bw=…, kernel=…).density(n=gridsize, cut=cut, binned=fft)`예요. `clip`(자료를 버림)은 없고 `bounds`는 다른 뜻(반사)이에요. `KDEMultivariate`의 `'normal_reference'`는 sd의 규칙에 없어서 수로 줘요.
- R의 `density(x, bw, adjust, kernel, weights, n, from, to, cut)`은 `kde(x, bw=…, adjust=…, kernel=…, weights=…).density(n=n, lower=from, upper=to, cut=cut)`예요. R은 청한 `n`을 2의 거듭제곱으로 올려 계산하고 보간해요. sd는 512보다 많이 청하면 그 점 수 그대로 계산해요. R은 `'nrd0'` 같은 규칙에 무게를 주면 경고하고 무게를 뺀 대역폭을 쓰지만 sd는 `ValueError`예요.
