## 한눈에 보기

두 방법 모두 반복 하나에 벡터 몇 개만 들고 다니는 짧은 점화식이에요. 기저를 쌓지 않으므로 메모리가 반복 수와 무관해요.

| | [`cg`](/api/sparse/cg/) | [`bicgstab`](/api/sparse/bicgstab/) |
|---|---|---|
| 행렬 | 에르미트 양정치 | 정사각이면 무엇이든 |
| 반복 하나의 곱 | A 한 번(+ M 한 번) | A 두 번(+ M 두 번) |
| 줄이는 것 | 오차의 A-노름(Krylov 공간 위에서 최소) | 최소가 아님(BiCG에 한 걸음짜리 잔차 최소화를 곱함) |
| 무너짐 | 양정치면 없음 | $\rho$나 $\omega$가 0 근처면 status −10, −11 |
| 멈춤 | $\lVert r\rVert < \max(\text{rtol}\,\lVert b\rVert, \text{atol})$ | 같은 판정, 반 걸음의 $\lVert s\rVert$에서도 |
| 반복 상한 | 10n | 10n |

판정의 $r$은 점화식으로 갱신한 잔차예요. 매번 $b - Ax$를 다시 계산하지 않아요. 판정과 갱신의 순서는 scipy 1.18.1의 `iterative.py`와 같아요.

## 켤레 기울기법

A가 에르미트 양정치면 $Ax = b$의 해는 이차 함수 $\phi(x) = \tfrac12 x^{\mathsf H}Ax - \operatorname{Re}(b^{\mathsf H}x)$의 최솟점이에요. 켤레 기울기법(Hestenes–Stiefel 1952)은 이 함수를 서로 A-켤레인($p_i^{\mathsf H}Ap_j = 0$) 방향들을 따라 한 번씩 최소화해요. 방향이 켤레이므로 앞에서 최소화한 방향을 뒤의 걸음이 망치지 않고, $k$번째 반복점은 Krylov 공간 $x_0 + \mathcal K_k(A, r_0)$ 전체에서 오차의 A-노름 $\lVert x - x_*\rVert_A$를 가장 작게 하는 점이에요. 그래서 조건수 $\kappa$에 대해

$$
\lVert x_k - x_*\rVert_A \ \le\ 2\left(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\right)^{k}\lVert x_0 - x_*\rVert_A
$$

로 줄어요. 전처리기 M이 있으면 같은 일을 $M^{1/2}AM^{1/2}$에 대해 하는 것과 같고, 그 조건수가 작을수록 빨라요.

```cpp
// csrc/sparse/iterative.cpp
template <class T>
void cg(
    const Op<T>& A,
    const Op<T>& M,
    const T* b,
    const T* x0,
    int64_t n,
    double rtol,
    double atol_in,
    int64_t maxiter,
    Out<T>& o
) {
    const double bnrm2 = nrm2(b, n);
    const double atol = std::max(atol_in, rtol * bnrm2);
    if (bnrm2 == 0) {
        o.x.assign(b, b + n);
        o.history.push_back(0.0);
        return;
    }
    Vec<T> x = start(x0, n), r(n), z(n), p(n), q(n);
    residual(A, b, x, r, q);
    T rho_prev{};
    for (int64_t it = 0; it < maxiter; ++it) {
        const double rn = nrm2(r.data(), n);
        o.history.push_back(rn);
        if (rn < atol) {
            o.x = std::move(x);
            o.normr = rn;
            o.n_iter = it;
            return;
        }
        const T* zp = r.data();
        if (M.kind != Op<T>::Identity) {
            M.apply(r.data(), z.data());
            zp = z.data();
        }
        const T rho = dot(r.data(), zp, n);
        if (it > 0) aypx(dvd(rho, rho_prev), p.data(), zp, n);
        else std::memcpy(p.data(), zp, static_cast<std::size_t>(n) * sizeof(T));
        A.apply(p.data(), q.data());
        const T alpha = dvd(rho, dot(p.data(), q.data(), n));
        axpy(alpha, p.data(), x.data(), n);
        axpy(neg(alpha), q.data(), r.data(), n);
        rho_prev = rho;
    }
    o.normr = nrm2(r.data(), n);
    o.history.push_back(o.normr);
    o.x = std::move(x);
    o.status = maxiter;
    o.n_iter = maxiter;
}
```

- 잔차의 처음 값은 `residual`이 만들어요. x가 모두 0이면(x0를 주지 않으면) 곱 없이 b를 복사해요. scipy의 `b - matvec(x) if x.any() else b.copy()`와 같아요.
- 반복 첫머리에 $\lVert r\rVert$를 재고 판정해요. 멈추면 `n_iter`는 그때까지 마친 반복 수예요. 상한에 닿으면 마지막 잔차의 노름을 한 번 더 재고 status가 `max_iter`예요.
- $\rho_k = r^{\mathsf H}z$, $\beta = \rho_k/\rho_{k-1}$, $p \leftarrow z + \beta p$, $q = Ap$, $\alpha = \rho_k/(p^{\mathsf H}q)$, $x \mathrel{+}= \alpha p$, $r \mathrel{-}= \alpha q$예요. $p \leftarrow \beta p + z$는 `aypx`(실수는 `fma(β, p, z)`)이고 scipy의 `p *= beta; p += z`를 한 번에 해요. 반올림이 한 번 적어 끝자리가 다를 수 있어요.
- 내적·노름·갱신은 [반복법의 바탕](/internals/sparse/krylov/#결정적인-벡터-연산)의 결정적인 연산이에요.

점화식의 잔차와 참 잔차 $b - Ax$는 반올림 때문에 조금씩 갈라져요. 수렴한 결과를 다시 계산하면 시험 문제(rtol 10⁻⁵·10⁻¹⁰)에서 참 잔차가 판정의 1% 안이에요.

```python
>>> g = 30
>>> T = sd.sparse.diags_array([-sd.ones(g - 1), 2 * sd.ones(g), -sd.ones(g - 1)], offsets=[-1, 0, 1], format="csr")
>>> A = sd.sparse.kronsum(T, T, format="csr")
>>> b = sd.ones(g * g)
>>> r = sd.sparse.cg(A, b, rtol=1e-8)
>>> r.n_iter, r.normr                      # 점화식의 잔차
(55, 2.8712969464853343e-07)
>>> float(sd.linalg.vector_norm(b - A @ r.x))   # 다시 계산한 참 잔차
2.871295126868212e-07
```

## BiCGSTAB

A가 에르미트가 아니면 짧은 점화식으로 최소화하는 방법이 없어요(Faber–Manteuffel). BiCG는 A와 $A^{\mathsf H}$의 Krylov 공간을 함께 만들어 짧은 점화식을 되찾지만, $A^{\mathsf H}$의 곱이 필요하고 잔차가 들쭉날쭉해요. van der Vorst(1992)의 **BiCGSTAB**는 BiCG의 다항식에 한 걸음짜리 잔차 최소화를 곱해요. 반복 하나에서

1. BiCG의 걸음으로 반 걸음 가요. $\hat p = Mp$, $v = A\hat p$, $\alpha = \rho/(\tilde r^{\mathsf H}v)$, $s = r - \alpha v$.
2. $\hat s = Ms$, $t = A\hat s$로 $\lVert s - \omega t\rVert$를 가장 작게 하는 $\omega = (t^{\mathsf H}s)/(t^{\mathsf H}t)$를 골라요(GMRES(1)과 같은 한 걸음).
3. $x \mathrel{+}= \alpha\hat p + \omega\hat s$, $r = s - \omega t$.

$\tilde r$(그림자 잔차)은 처음 잔차로 고정하고, $\rho = \tilde r^{\mathsf H}r$, $\beta = (\rho_k/\rho_{k-1})(\alpha/\omega)$로 다음 방향 $p = r + \beta(p - \omega v)$를 만들어요. $A^{\mathsf H}$의 곱이 없는 대신 A의 곱이 두 번이에요.

```cpp
    // csrc/sparse/iterative.cpp
    for (int64_t it = 0; it < maxiter; ++it) {
        rn = nrm2(r.data(), n);
        o.history.push_back(rn);
        if (rn < atol) return finish(0, it, rn);
        const T rho = dot(rtilde.data(), r.data(), n);
        if (mag(rho) < rhotol) return finish(-10, it, rn);
        if (it > 0) {
            if (mag(omega) < omegatol) return finish(-11, it, rn);
            const T beta = mul(dvd(rho, rho_prev), dvd(alpha, omega));
            axpy(neg(omega), v.data(), p.data(), n);
            aypx(beta, p.data(), r.data(), n);
        } else {
            p = r;
        }
        const T* ph = p.data();
        if (M.kind != Op<T>::Identity) {
            M.apply(p.data(), phat.data());
            ph = phat.data();
        }
        A.apply(ph, v.data());
        const T rv = dot(rtilde.data(), v.data(), n);
        if (is_zero(rv)) return finish(-11, it, rn);
        alpha = dvd(rho, rv);
        axpy(neg(alpha), v.data(), r.data(), n);
        s = r;
        const double sn = nrm2(s.data(), n);
        if (sn < atol) {
            o.history.push_back(sn);
            axpy(alpha, ph, x.data(), n);
            return finish(0, it + 1, sn);
        }
        const T* sh = s.data();
        if (M.kind != Op<T>::Identity) {
            M.apply(s.data(), shat.data());
            sh = shat.data();
        }
        A.apply(sh, t.data());
        omega = dvd(dot(t.data(), s.data(), n), dot(t.data(), t.data(), n));
        axpy(alpha, ph, x.data(), n);
        axpy(omega, sh, x.data(), n);
        axpy(neg(omega), t.data(), r.data(), n);
        rho_prev = rho;
    }
```

- **무너짐.** $|\rho| < \varepsilon^2$이면 그림자와 잔차가 직교해 다음 방향을 만들 수 없어 status −10이에요. $|\omega| < \varepsilon^2$이거나 $\tilde r^{\mathsf H}v = 0$이면 −11이에요. 문턱 $\varepsilon^2$는 scipy가 원래의 Fortran 코드에서 이어받은 값이고, scipy 소스의 주석도 그 값이 뜻이 없다고 적어요. 같은 판정을 지켜 status를 scipy와 맞춰요.
- **반 걸음의 판정.** $s$의 노름이 이미 판정을 만족하면 $x \mathrel{+}= \alpha\hat p$만 하고 멈춰요. 그때 `n_iter`는 그 반복을 마친 것으로 세어 `it + 1`이에요.
- 갱신의 순서(x에 $\alpha\hat p$ 다음 $\omega\hat s$, 그 다음 r)는 scipy와 같아요. `p = r`과 `s = r`은 벡터 복사예요.

## scipy와 다른 점

- 내적과 노름의 합 순서가 numpy와 달라 끝자리부터 갈라지고, `aypx`가 scipy의 두 연산을 FMA 하나로 해요. CG처럼 안정한 점화식에서는 반복 수와 상태가 scipy와 같아요.
- **BiCGSTAB은 scipy 자신이 반올림에 민감해요.** 무작위 비대칭 행렬에서 b를 상대 10⁻¹⁶ 바꾼 scipy끼리도 잔차가 열 걸음 안에 10⁻¹ 상대만큼 갈라지고 반복 수가 54–71로 퍼져요. 그래서 scipy와 견준 기록 40개 가운데 반복 수가 다른 넷이 모두 bicgstab이에요. 셋(36 대 37, 64 대 61, 59 대 57)은 이 퍼짐 안이고, 하나(convdiff2d/40의 조인 허용오차, 41 대 40)는 반 걸음 판정에서 멈춘 반복을 `n_iter`가 세고 scipy의 `callback`은 세지 않는 차이예요. 상태는 모두 같아요. SuiteSparse 행렬에서도 상태는 같고 반복 수는 퍼져요(memplus 901 대 scipy 1,166, sherman3은 둘 다 ρ 무너짐).
- `callback`이 없어요. 반복점의 열이 필요하면 `max_iter`를 늘려 가며 부르거나 결과의 `normr`을 봐요.
