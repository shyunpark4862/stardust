## 무향 패턴

먼저 패턴이 대칭이고 대각이 없는지를 전치를 만들지 않고 한 번 훑어 봐요(행 $u$의 원소 $(u, v)$의 짝은 행 $v$에서 아직 쓰지 않은 다음 원소라서 행마다 커서 하나로 확인돼요). 그렇다면 입력의 CSR을 그대로 읽어요. 아니면 전치 패턴을 계수 정렬로 만들고 행마다 두 줄을 합치며 대각을 빼서 새 CSR을 만들어요. 어느 쪽이든 행 안의 이웃이 오름차순이고 한 번씩이라, 같은 두 노드 사이의 변은 하나예요.

`biconnected_components`는 변마다 번호가 필요해요. 행 순서로 훑으며 $(i, j)$, $i \lt j$인 원소를 만날 때마다 번호를 붙이면 번호가 곧 사전 순서예요. 반대 방향 원소 $(j, i)$에도 같은 번호를 줘야 하는데, 대칭 패턴의 성질로 따로 찾지 않아도 돼요.

```cpp
// csrc/graph/structure.cpp
Edges edges_of(const Simple& s) {
    // The entry (v, u) mirroring (u, v) is the next unseen entry of row v when the rows are scanned in
    // order: row v holds its columns ascending, and the rows u that hold v come in that same order.
    Edges e;
    e.id.resize(static_cast<size_t>(s.nnz()));
    e.lo.reserve(static_cast<size_t>(s.nnz() / 2));
    e.hi.reserve(static_cast<size_t>(s.nnz() / 2));
    std::vector<int64_t> cursor(s.ip, s.ip + s.n);
    for (int64_t u = 0; u < s.n; ++u) {
        for (int64_t k = s.ip[u]; k < s.ip[u + 1]; ++k) {
            const int64_t v = s.ix[k];
            const int64_t m = cursor[static_cast<size_t>(v)]++;
            if (v > u) {
                const int64_t id = e.count();
                e.lo.push_back(u);
                e.hi.push_back(v);
                e.id[static_cast<size_t>(k)] = id;
                e.id[static_cast<size_t>(m)] = id;
            }
        }
    }
    return e;
}
```

행을 $u = 0, 1, \ldots$ 차례로 훑으면 열 $v$에 놓인 원소 $(u, v)$들을 $u$의 오름차순으로 만나고, 행 $v$는 그 $u$들을 오름차순으로 저장하고 있어요. 그러니 열 $v$를 $m$번째로 만날 때의 반대 원소는 행 $v$의 $m$번째 원소예요. 행마다 커서(`cursor`) 하나면 돼요.

## 깊이 우선과 low 값

무향 그래프의 깊이 우선 트리에서 트리에 들지 않는 변은 모두 뒤 변이에요. 곧 한 노드와 그 조상을 이어요(두 가지를 가로지르는 변이 있으면 깊이 우선이 그 변을 따라 내려갔을 테니까요). Hopcroft와 Tarjan은 이 성질로 노드마다 두 값을 써요.

- $\mathrm{disc}(v)$: $v$를 처음 만난 차례.
- $\mathrm{low}(v)$: $v$의 부분 트리에서 뒤 변 하나로 닿을 수 있는 가장 이른 $\mathrm{disc}$.

부모 $p$와 자식 $v$의 트리 변에 대해 세 판정이 나와요.

1. $\mathrm{low}(v) \ge \mathrm{disc}(p)$이면 $v$의 부분 트리에서 $p$보다 위로 가는 변이 없어요. $p$를 지우면 그 부분 트리가 $p$의 조상들과 끊기니, $p$가 뿌리가 아니면 단절점이에요.
2. $\mathrm{low}(v) \gt \mathrm{disc}(p)$이면 부분 트리에서 $p$로 가는 변조차 트리 변 하나뿐이에요. 그 변을 지우면 끊기니 다리예요.
3. 뿌리는 자식이 둘 이상일 때만 단절점이에요. 서로 다른 자식의 부분 트리 사이에는 변이 없어서(가로지르는 변이 없으니까요) 뿌리를 지우면 갈라지고, 자식이 하나면 나머지가 그 하나의 부분 트리로 이어져 있어요.

판정 1이 서는 자리에서 이중 연결 요소 하나가 닫혀요. 변을 만나는 대로 스택에 쌓아 두면, 트리 변 $p$–$v$ 위에 쌓인 변이 바로 그 요소의 변이에요. $v$의 부분 트리 안에서 먼저 닫힌 요소들은 이미 빠져 나갔기 때문이에요.

```cpp
// csrc/graph/structure.cpp
Blocks blocks(const Simple& s, const Edges* e) {
    const int64_t n = s.n;
    Blocks out;
    out.articulation.assign(static_cast<size_t>(n), 0);
    if (e) out.component.assign(static_cast<size_t>(e->count()), -1);
    std::vector<int64_t> disc(static_cast<size_t>(n), -1), low(static_cast<size_t>(n)), next(static_cast<size_t>(n)),
        up(static_cast<size_t>(n)), stack, edges, up_edge(e ? static_cast<size_t>(n) : 0);
    stack.reserve(static_cast<size_t>(n));
    if (e) edges.reserve(static_cast<size_t>(e->count()));
    int64_t time = 0;
    for (int64_t r = 0; r < n; ++r) {
        if (disc[static_cast<size_t>(r)] >= 0) continue;
        disc[static_cast<size_t>(r)] = low[static_cast<size_t>(r)] = time++;
        next[static_cast<size_t>(r)] = s.ip[r];
        up[static_cast<size_t>(r)] = -1;
        stack.push_back(r);
        int64_t children = 0;
        while (!stack.empty()) {
            const int64_t u = stack.back();
            int64_t& k = next[static_cast<size_t>(u)];
            if (k < s.ip[u + 1]) {
                const int64_t v = s.ix[k], at = k++;
                if (v == up[static_cast<size_t>(u)]) continue;  // the tree edge back to the parent
                const int64_t dv = disc[static_cast<size_t>(v)];
                if (dv < 0) {
                    if (e) {
                        edges.push_back(e->id[static_cast<size_t>(at)]);
                        up_edge[static_cast<size_t>(v)] = e->id[static_cast<size_t>(at)];
                    }
                    up[static_cast<size_t>(v)] = u;
                    disc[static_cast<size_t>(v)] = low[static_cast<size_t>(v)] = time++;
                    next[static_cast<size_t>(v)] = s.ip[v];
                    stack.push_back(v);
                    if (u == r) ++children;
                } else if (dv < disc[static_cast<size_t>(u)]) {  // a back edge
                    if (e) edges.push_back(e->id[static_cast<size_t>(at)]);
                    low[static_cast<size_t>(u)] = std::min(low[static_cast<size_t>(u)], dv);
                }
                continue;
            }
            stack.pop_back();
            if (stack.empty()) break;
            const int64_t p = stack.back();
            low[static_cast<size_t>(p)] = std::min(low[static_cast<size_t>(p)], low[static_cast<size_t>(u)]);
            if (low[static_cast<size_t>(u)] >= disc[static_cast<size_t>(p)]) {
                if (p != r) out.articulation[static_cast<size_t>(p)] = 1;
                if (low[static_cast<size_t>(u)] > disc[static_cast<size_t>(p)]) {
                    out.bridges.push_back(std::min(p, u));
                    out.bridges.push_back(std::max(p, u));
                }
                if (e) {  // the edges pushed since the tree edge p - u, it included
                    const int64_t tree = up_edge[static_cast<size_t>(u)];
                    int64_t f;
                    do {
                        f = edges.back();
                        edges.pop_back();
                        out.component[static_cast<size_t>(f)] = out.count;
                    } while (f != tree);
                    ++out.count;
                }
            }
        }
        if (children >= 2) out.articulation[static_cast<size_t>(r)] = 1;
    }
    return out;
}
```

- 재귀 대신 명시적 스택이에요. 노드마다 다음에 볼 이웃의 자리(`next`)를 쥐어서, 스택 맨 위의 노드가 이웃 하나를 보고 나면 다음 바퀴에 그다음 이웃을 봐요. 경로 그래프처럼 깊이가 $n$인 탐색도 호출 스택을 쓰지 않아요.
- 부모로 돌아가는 트리 변은 부모 노드 번호로 건너뛰어요(`up`). 같은 두 노드 사이에 변이 하나뿐이라 이것으로 충분해요.
- $\mathrm{disc}(v) \lt \mathrm{disc}(u)$인 이미 만난 이웃이 뒤 변이에요. $\mathrm{disc}(v) \gt \mathrm{disc}(u)$인 이웃은 $u$의 후손이고, 그 변은 후손 쪽에서 이미 뒤 변으로 셌으니 건너뛰어요.
- 노드를 스택에서 내릴 때 부모의 low를 갱신하고 세 판정을 해요. 요소를 닫을 때는 변 스택에서 그 트리 변(`up_edge[u]`)이 나올 때까지 꺼내요.
- 뿌리는 번호 오름차순, 이웃도 오름차순이에요. 답이 하나라 이 순서는 결과를 바꾸지 않지만, 요소가 닫히는 차례(`out.count`)는 이 순서로 정해져요.

요소의 번호는 마지막에 다시 매겨요.

```cpp
            // csrc/graph/structure.cpp
            std::vector<int64_t> renumber(static_cast<size_t>(b.count), -1);
            label.resize(static_cast<size_t>(e.count()));
            int64_t c = 0;
            for (int64_t f = 0; f < e.count(); ++f) {
                int64_t& r = renumber[static_cast<size_t>(b.component[static_cast<size_t>(f)])];

```

변을 번호(사전 순서)대로 보며 처음 만난 요소에 0, 1, 2, … 를 주니 요소의 번호가 "가장 작은 변의 순서"가 돼요. 다리는 찾은 차례로 모았다가 $(i, j)$ 쌍으로 정렬해요.

## 코어 수

$k$-코어는 모든 노드의 차수가 $k$ 이상인 가장 큰 부분 그래프예요. 노드의 코어 수는 그 노드가 드는 $k$-코어의 가장 큰 $k$예요. Batagelj와 Zaversnik의 방법은 차수가 가장 작은 노드를 하나씩 떼어 내며 그때의 차수를 코어 수로 적어요. 노드를 차수별 통에 담아 두면 "가장 작은 차수의 노드"를 상수 시간에 얻어요.

```cpp
        // csrc/graph/structure.cpp
        int64_t top = 0;
        for (int64_t v = 0; v < n; ++v) {
            deg[v] = s.ip[v + 1] - s.ip[v];
            top = std::max(top, deg[v]);
        }
        std::vector<int64_t> bin(static_cast<size_t>(top) + 2, 0), pos(static_cast<size_t>(n)),
            vert(static_cast<size_t>(n));
        for (int64_t v = 0; v < n; ++v) ++bin[static_cast<size_t>(deg[v]) + 1];
        for (size_t d = 1; d < bin.size(); ++d) bin[d] += bin[d - 1];  // bin[d]: where degree d starts
        for (int64_t v = 0; v < n; ++v) {
            pos[static_cast<size_t>(v)] = bin[static_cast<size_t>(deg[v])]++;
            vert[static_cast<size_t>(pos[static_cast<size_t>(v)])] = v;
        }
        for (size_t d = bin.size() - 1; d > 0; --d) bin[d] = bin[d - 1];
        bin[0] = 0;
        for (int64_t i = 0; i < n; ++i) {
            const int64_t v = vert[static_cast<size_t>(i)];
            for (int64_t k = s.ip[v]; k < s.ip[v + 1]; ++k) {
                const int64_t u = s.ix[k];
                if (deg[u] > deg[v]) {
                    const int64_t du = deg[u], pu = pos[static_cast<size_t>(u)];
                    const int64_t pw = bin[static_cast<size_t>(du)], w = vert[static_cast<size_t>(pw)];
                    if (u != w) {
                        pos[static_cast<size_t>(u)] = pw;
                        vert[static_cast<size_t>(pu)] = w;
                        pos[static_cast<size_t>(w)] = pu;
                        vert[static_cast<size_t>(pw)] = u;
                    }
                    ++bin[static_cast<size_t>(du)];
                    --deg[u];
                }
            }
        }
```

- `bin[d]`는 차수 $d$인 노드들이 `vert`에서 시작하는 자리, `pos[v]`는 $v$의 자리예요. `vert`는 차수 오름차순으로 늘어서 있어요.
- `vert`를 앞에서부터 보며 $v$를 떼어 내요. 이웃 $u$의 차수가 $v$보다 크면 $u$를 자기 통의 맨 앞 노드 $w$와 맞바꾸고, 통의 시작을 하나 뒤로 미룬 뒤 $u$의 차수를 하나 줄여요. 맞바꾼 자리가 이제 차수 $d_u - 1$ 통의 맨 끝이라 `vert`의 정렬이 그대로 유지돼요. 모든 일이 상수 시간이라 전체가 $O(n + E)$예요.
- 차수가 $v$ 이하인 이웃은 줄이지 않아요. 그래서 떼어 낼 때의 차수가 줄지 않는 열을 이뤄요.

**정확성.** 떼어 낼 때의 차수를 $k_v$라고 해요.

- $v$를 떼는 순간 남은 노드들은 모두 차수가 $k_v$ 이상이에요($v$가 가장 작았으니까요). 남은 노드의 부분 그래프가 $v$를 품은 최소 차수 $k_v$ 이상의 부분 그래프이니 코어 수는 $k_v$ 이상이에요.
- 코어 수 $c$가 $k_v$보다 크다고 해 봐요. $v$가 드는 $c$-코어 $H$에서 처음 떼어지는 노드 $w$를 보면, 그때 $H$가 모두 남아 있으니 $w$의 차수는 $c$ 이상이고 $k_w \ge c$예요. $k$가 줄지 않는 열이니 그 뒤에 떼어지는 $v$도 $k_v \ge c$라 모순이에요.

대각은 읽기 전에 빠지니 자기 고리는 코어 수에 쓰이지 않아요.

```python
>>> core = sd.graph.core_number(A)
>>> core
array([2, 2, 2, 2, 2, 2, 2, 1, 1], dtype=int64)
>>> sd.nonzero(core >= 2)[0]
array([0, 1, 2, 3, 4, 5, 6], dtype=int64)
```

삼각형 0–1–2와 노드 3, 4, 5, 6이 2-코어이고, 다리로만 이어진 7과 8은 1-코어예요. 다리 2–3은 2-코어 안의 두 노드를 잇지만 코어는 차수만 보니 다리인지와는 상관이 없어요.
