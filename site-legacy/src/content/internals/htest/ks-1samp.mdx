## 한눈에 보기

한 표본 Kolmogorov–Smirnov 검정은 경험분포 Fₙ과 가설의 연속 분포 F의 가장 큰 차이를 봐요.

D⁺ = maxᵢ (i/n − F(x₍ᵢ₎)), D⁻ = maxᵢ (F(x₍ᵢ₎) − (i − 1)/n), D = max(D⁺, D⁻)

귀무가설에서 D⁺, D⁻, D의 분포는 F와 상관없고 n에만 달려 있어요(확률 적분 변환으로 균등분포의 문제가 돼요). 그래서 p값은 n과 d의 함수 셋이에요.

| 함수 | 뜻 | 쓰는 곳 |
|---|---|---|
| `smirnov_sf(n, d)` | P(D⁺ ≥ d) (= P(D⁻ ≥ d)) | 한쪽 검정, `method='approx'` |
| `kstwo_sf(n, d)` | P(D ≥ d) | 양쪽 검정의 `'exact'`(기본) |
| `kolmogorov_sf(x)` | lim P(√n·D ≥ x) | `method='asymp'` |

셋은 `csrc/htest/ks.hpp`에 있고 sd.stats의 공개 분포가 아니에요. 통계량은 `gof.cpp`의 `ks` 커널이 계산해요.

## 통계량

Python이 정렬한 표본에 대해 `cdf`를 한 번 부르고, 커널이 줄마다 D⁺와 D⁻를 한 번에 훑어요. 같은 값이면 먼저 나온 위치를 지켜요(`>`로 갱신해요). 양쪽 검정은 D⁺ > D⁻이면 D⁺, 같거나 작으면 D⁻이고, `statistic_location`은 그 값이 나온 관측, `statistic_sign`은 +1(D⁺)이나 −1(D⁻)이에요. scipy의 `_compute_d`와 같은 정의예요.

```cpp
            // csrc/htest/gof.cpp
            for (std::int64_t i = 0; i < n; ++i) {
                const double f = fs[static_cast<std::size_t>(i)];
                const double up = static_cast<double>(i + 1) / nn - f, dn = f - static_cast<double>(i) / nn;
                if (up > dp) dp = up, ip = i;
                if (dn > dm) dm = dn, im = i;
            }
```

## 한쪽 꼬리: Birnbaum–Tingey

Birnbaum과 Tingey(1951)는 P(D⁺ ≥ d)의 유한한 합을 줬어요.

P(D⁺ ≥ d) = d · Σ_(j=0)^(⌊n(1−d)⌋) C(n, j) · (1 − d − j/n)^(n−j) · (d + j/n)^(j−1)

항이 모두 양수라 더하는 동안 지워지는 것이 없어요. 문제는 항 하나의 크기예요. C(n, j)와 두 거듭제곱은 n이 크면 double을 넘거나 0이 되니 로그로 계산해야 하는데, 로그가 크기 n이라(예: (n − j)·log a) double의 로그에는 n ulp의 절대 오차가 있고 그 지수를 취한 항은 상대 n ulp가 틀려요. n = 10⁶이면 10⁻¹⁰이에요.

그래서 항의 로그를 double-double로 만들어요. log C(n, j)는 sd.special의 double-double `loggamma` 세 개, log a와 log b는 double-double `log`, 곱도 double-double이라 로그의 절대 오차가 2⁻¹⁰⁰ 크기이고 항이 1–2 ulp로 맞아요.

```cpp
// csrc/htest/ks.hpp
inline DD bt_log(double n, double j, DD c, DD nd, DD lgn, DD logd) {
    const DD a = (c - j) / n;
    if (!(a.hi > 0.0)) return {-std::numeric_limits<double>::infinity(), 0.0};
    const DD lc = lgn - dd::loggamma(DD{j + 1.0, 0.0}) - dd::loggamma(DD{n - j + 1.0, 0.0});
    DD l = lc + dd::log_pos(a) * (n - j);
    if (j == 0.0) return l;  // (j - 1) log d + log d = 0
    const DD b = (nd + j) / n;
    return l + dd::log_pos(b) * (j - 1.0) + logd;
}
```

c = n(1 − d)와 nd도 double-double이에요. a = (c − j)/n이 0에 가까운 마지막 항에서 c − j가 상쇄되기 때문이에요.

double-double 로그는 비싸서 모든 항에 쓰지 않아요. 먼저 double로 모든 항의 로그를 어림해 가장 큰 값 L_max를 찾고, L_max − 100 안의 항(e⁻¹⁰⁰ ≈ 3.7 × 10⁻⁴⁴배 이내)만 double-double로 다시 계산해 e^(L − L_max)로 더해요. 버린 항은 합의 반올림보다 훨씬 작아요. 남은 항이 2¹⁴개 이상이면 2048개씩의 고정된 덩어리로 나눠 병렬로 더하고 덩어리 순서로 합쳐요. 결과는 e^(L_max + log 합)이고, 서브노멀까지 0으로 자르지 않아요.

### 큰 n: 합을 적분으로

n이 크면 합에 들어가는 항이 수천 개의 j에 걸쳐 있어요. n ≥ 4096이면 먼저 합을 적분으로 바꿔 봐요(`smirnov_integral`). 항은 정수 j에서의 값이지만, log C(n, j)를 `loggamma`로 쓰면 항의 식은 실수 x에서도 뜻이 있는 해석 함수 T(x)예요. T가 두 끝(x = 0과 x = J)에서 그 도함수들까지 무시할 만큼 작으면, Euler–Maclaurin 공식의 끝 항이 모두 사라져 Σ_j T(j) = ∫₀ᴶ T(x)dx가 남고 나머지는 지수적으로 작아요. 그 크기는 Poisson의 합 공식으로 볼 수 있어요. 폭 σ의 종 모양이면 나머지는 e^(−2π²σ²)쯤이라, σ ≥ 30에서는 double로 보이지 않아요.

적분은 봉우리에서 시작하는 사다리꼴 격자예요. 봉우리는 log T의 도함수(디감마 두 개와 로그들, double)의 부호로 이분해서 찾고, 그 둘째 도함수에서 폭 σ를 얻어요. 걸음 σ/4에서 시작해 격자를 반으로 나눠 가며, 두 층의 값이 2⁻⁴⁴ 안에서 맞으면 멈춰요. 해석적이고 가우스 꼬리인 피적분 함수에서 사다리꼴 규칙의 오차는 1/h에 지수적으로 줄어서 몇 층이면 돼요. 층마다 봉우리에서 양쪽으로, 항이 가장 큰 항의 2⁻⁷⁰ 아래가 될 때까지 걸어요. 항은 double-double 로그에서 봉우리 값을 뺀 뒤 지수를 취해요.

봉우리가 끝에 있거나, σ < 30이거나, T(0)이 봉우리의 2⁻⁷⁰보다 크거나(첫 항이 합에 보이는 경우), 4096점 안에 두 층이 맞지 않으면 적분을 버리고 위의 합으로 가요. n = 3 × 10³–10⁶, nd² = 0.1–400에서 합과 견주면 상대 3 × 10⁻¹⁶ 안이고, n개의 항 대신 nd² ≥ 1에서 백 개쯤, nd² = 0.09에서 오천 개쯤의 점으로 끝나요.

## Kolmogorov의 극한

n → ∞에서 √n·D의 분포는 Kolmogorov 분포예요.

Q(x) = P(√n·D ≥ x) = 2Σ_(k≥1) (−1)^(k−1) e^(−2k²x²)

x ≥ 1에서는 이 교대 급수가 빠르게 수렴해요. x²를 `two_prod`로 hi + lo로 나누고 e^(−2k²x²) = e^(−2k²·hi)·(1 − 2k²·lo)로 계산해서, x가 커 e^(−2x²)가 아주 작은 깊은 꼬리에서도 지수의 인자의 반올림이 결과로 커지지 않아요. x < 1에서는 교대 급수가 천천히 수렴하고 1에 가까운 값을 빼야 해서, 야코비 세타 함수의 변환으로 얻는 다른 급수 1 − √(2π)/x · Σ e^(−(2k−1)²π²/(8x²))를 써요. 이쪽은 x가 작을수록 빨리 수렴해요.

### 두 배의 한쪽 꼬리

포함과 배제로 P(D ≥ d) = P(D⁺ ≥ d) + P(D⁻ ≥ d) − P(D⁺ ≥ d, D⁻ ≥ d) = 2·P(D⁺ ≥ d) − P(둘 다)예요.

- **d ≥ 1/2**: 두 점 s, t에서 [Fₙ(s) − F(s)] + [F(t) − Fₙ(t)]를 보면, s < t일 때 Fₙ(s) − Fₙ(t) ≤ 0이고 F(t) − F(s) ≤ 1, s > t일 때 Fₙ(s) − Fₙ(t) ≤ 1이고 F(t) − F(s) ≤ 0이라 언제나 1 이하예요. 그래서 D⁺ + D⁻ ≤ 1이고, d > 1/2이면 둘이 함께 d 이상일 수 없어요(d = 1/2은 확률 0의 경계예요). 2·P(D⁺ ≥ d)가 정확해요.
- **nd² ≥ 6.5**: 두 꼬리를 함께 넘는 확률은 한쪽 꼬리보다 훨씬 작아요. Arb로 n = 20–1000에서 재면 그 비율이 대략 e^(−6nd²)이라, nd² ≥ 6.5에서는 결과의 10⁻¹⁷ 아래예요. double의 반올림보다 작으니 버려도 결과가 바뀌지 않아요.

```python
>>> import stardust as sd
>>> N = sd.stats.Normal()
>>> rng = sd.random.default_rng(6)
>>> x = sd.stats.Normal(mu=1.3).sample(40, rng=rng)
>>> two = sd.htest.ks_1samp(x, N)
>>> one = sd.htest.ks_1samp(x, N, alternative='less')
>>> two.statistic_sign, 40 * two.statistic**2 >= 6.5
(-1, True)
>>> two.pvalue == 2 * one.pvalue
True
```

nd²가 작으면 두 꼬리를 함께 넘는 확률이 보여요. `method='approx'`는 언제나 2·P(D⁺ ≥ d)(1로 자른 값)라 그만큼 커요.

```python
>>> y = sd.stats.Normal(mu=0.2).sample(40, rng=rng)
>>> [sd.htest.ks_1samp(y, N, method=m).pvalue for m in ('exact', 'approx', 'asymp')]
[0.07456580400500085, 0.07456852373229633, 0.08608201632907635]
```

### Durbin 행렬

그 사이의 (n, d)에서는 Durbin(1973)의 행렬 표현을 Marsaglia, Tsang, Wang(2003)의 꼴로 써요. k = ⌈nd⌉, h = k − nd ∈ [0, 1), m = 2k − 1이라 하면

P(D < d) = n!/nⁿ · (Hⁿ)_(k,k)

이고 H는 m × m 행렬이에요. 대각선 아래(i − j + 1 ≥ 0)의 원소가 1/(i − j + 1)!이고, 첫 열과 마지막 행은 경계에서 h만큼 잘린 부분을 빼요.

H_(i,1) −= hⁱ/i!, H_(m,j) −= h^(m−j+1)/(m − j + 1)!, h > 1/2이면 H_(m,1) += (2h − 1)ᵐ/m!

```cpp
    // csrc/htest/ks.hpp
    for (std::int64_t i = 0; i < m; ++i)
        for (std::int64_t j = 0; j < m; ++j)
            if (i - j + 1 >= 0) at(i, j) = inv[static_cast<std::size_t>(i - j + 1)];
    for (std::int64_t i = 0; i < m; ++i) {
        at(i, 0) = at(i, 0) - hp[static_cast<std::size_t>(i + 1)] * inv[static_cast<std::size_t>(i + 1)];
        at(m - 1, i) = at(m - 1, i) - hp[static_cast<std::size_t>(m - i)] * inv[static_cast<std::size_t>(m - i)];
    }
    const DD g = h * 2.0 - 1.0;
    if (g.hi > 0.0) {
        DD gp{1.0, 0.0};
        for (std::int64_t i = 0; i < m; ++i) gp = gp * g;
        at(m - 1, 0) = at(m - 1, 0) + gp * inv[mz];
    }
```

Durbin은 경험분포가 띠 (F − d, F + d) 안에 머무는 확률을 이 행렬의 거듭제곱으로 썼어요.

계산은 세 가지를 지켜요.

- **double-double**: 행렬과 벡터가 모두 double-double이에요. 원소는 부호가 섞인 합이고, p값은 1 − P(D < d)로 얻으니 P가 1에 가까운 곳(작은 p값)에서 그 상쇄를 견뎌야 해요. double-double의 P에서 1을 빼면 10⁻¹⁶ 크기의 p값까지 상대 10⁻¹⁴를 지켜요.
- **벡터 하나**: Hⁿ을 행렬로 만들지 않고 단위 벡터 e_kᵀ에 H를 n번 곱해요. 걸음마다 일이 m²/2(H의 위쪽 대부분이 0이라 열 j는 j − 1행부터)라 모두 n·m²/2이에요. 걸음 t마다 t/n을 함께 곱하면 n번 뒤에 n!/nⁿ이 따라와요. 값이 2³⁰⁰을 넘거나 2⁻³⁰⁰ 아래로 가면 지수를 따로 떼어 둬요.
- **행마다의 axpy**: 벡터 × 행렬을 열마다 내적으로 하지 않고, 행 i의 vᵢ·H_(i,·)를 모든 열의 합에 더하는 axpy로 해요. 행렬과 벡터는 높은 부분과 낮은 부분을 따로 둔 배열이고, 곱의 반올림 오차는 FMA로, 합의 반올림 오차는 TwoSum으로 구해 열마다의 낮은 합에 모아요(Ogita, Rump, Oishi(2005)의 Dot2). 열마다 항을 더하는 순서는 여전히 행의 순서라, 열마다 double-double 합 하나로 차례로 더한 것과 같은 비트예요. 안쪽 고리의 열들은 서로 기대지 않아서 벡터화돼요.
- **병렬**: m이 96 이상이면 한 걸음의 열들을 32개씩의 고정된 묶음으로 스레드풀에 나눠요. 열마다의 합은 제 순서 그대로라 스레드 수와 상관없이 같은 비트예요.

```cpp
    // csrc/htest/ks.hpp
    auto columns = [&](std::size_t j0, std::size_t j1) {
        for (std::size_t j = j0; j < j1; ++j) sh[j] = 0.0, sl[j] = 0.0;
        for (std::size_t i = j0 == 0 ? 0 : j0 - 1; i < mz; ++i) {
            const double a = vh[i], b = vl[i];
            const double* __restrict hh = Hh.data() + i * mz;
            const double* __restrict hl = Hl.data() + i * mz;
            double* __restrict s = sh.data();
            double* __restrict c = sl.data();
            const std::size_t je = std::min(j1, i + 2);
            for (std::size_t j = j0; j < je; ++j) {
                const double p = a * hh[j];
                double e = std::fma(a, hh[j], -p);
                e = std::fma(a, hl[j], e);
                e = std::fma(b, hh[j], e);
                const double x = s[j] + p, bb = x - s[j];
                c[j] += ((s[j] - (x - bb)) + (p - bb)) + e;
                s[j] = x;
            }
        }
    };
```

한 걸음이 끝나면 열마다의 두 합을 double-double 하나로 정규화하고 t/n을 곱해 다음 벡터로 삼아요.

        }

일의 상한은 곱셈과 덧셈 4 × 10⁷번이에요. nd² < 6.5인 곳에서 이 상한은 n이 대략 1000일 때 닿아요.

### 큰 n: Pelz–Good

상한을 넘는 큰 n의 nd² < 6.5에서는 근사로 가요. nd² ≥ 3이면 두 배의 한쪽 꼬리(빠뜨린 확률이 1.4 × 10⁻⁸에서 2 × 10⁻¹⁶ 사이), 그 아래는 Pelz와 Good(1976)의 전개예요.

P(√n·D ≤ z) ≈ K₀(z) + K₁(z)/√n + K₂(z)/n + K₃(z)/n^(3/2)

K₀은 Kolmogorov 분포이고 K₁–K₃은 세타 급수 꼴의 보정이에요. scipy의 `_kolmogn_PelzGood`과 같은 항을 같은 순서로 계산해요. 이 영역은 정확도 계약이 느슨한 곳이에요. n = 3000에서 Arb와 견주면 Pelz–Good은 상대 8 × 10⁻⁹–5 × 10⁻⁷이고, n이 클수록 작아져요.

`method='exact'`도 이 근사로 넘어가요. 정확한 방법의 상한에서 `ValueError`를 내는 다른 검정과 달리, 여기서는 근사의 오차가 n과 함께 줄고 계산이 언제나 정해진 시간 안에 끝나니 값을 내요.

19문제 모두 계약 안이고 계약 대비의 최대는 0.07이에요. p값의 상대오차가 가장 큰 곳(2 × 10⁻¹³)은 p값의 d에 대한 조건수가 큰 꼬리예요. scipy의 `kstwo`는 n ≤ 140에서 Pomeranz의 점화식을 double로 계산해 1 − cdf를 하고(n = 100, nd² = 4에서 상대 8 × 10⁻¹²), n > 140에서 Pelz–Good(n = 141에서 4.4 × 10⁻⁶)과 nd² ≥ 2.2의 두 배 한쪽 꼬리(1.6 × 10⁻⁶)로 가요. 표의 scipy 열의 3.6 × 10⁻⁶이 그 자리예요.

## scipy를 아는 분께

- `cdf`는 sd.stats의 분포 객체나 호출 가능한 `cdf(x)`예요. 분포 이름 문자열과 `args=()`는 받지 않고, 두 표본은 `ks_2samp`이며 `kstest`는 없어요.
- 결과의 `method`에 쓴 분포(`'exact'`, `'approx'`, `'asymp'`)를 적어요. 한쪽 검정은 언제나 Smirnov의 정확한 분포라 `'exact'`예요. 배치면 줄마다의 이름을 배치 모양의 중첩 리스트로 줘요.
- 양쪽 `'exact'`는 n ≈ 1000까지 Durbin 행렬을 double-double로 계산하고, 그 위에서만 scipy와 같은 근사로 가요.
- 통계량, `statistic_location`, `statistic_sign`의 정의는 scipy와 같아요.
