## 한눈에 보기

[`barnard_exact`](/api/htest/barnard_exact/)와 [`boschloo_exact`](/api/htest/boschloo_exact/)는 2 × 2 표의 두 열을 두 이항 표본으로 봐요. 첫 열에서 $n_1$번 중 $x_1 = t_{00}$번, 둘째 열에서 $n_2$번 중 $x_2 = t_{01}$번 성공했어요. 귀무가설은 두 성공 확률이 같다는 것이고, 그 공통 확률 $\pi$는 모르는 값(장애 모수)이에요. 그래서 p값은 $\pi$마다의 "관측만큼 극단인 표의 확률"을 모든 $\pi$에 대해 본 최댓값이에요.

$$
p = \sup_{0 \le \pi \le 1} f(\pi),\qquad f(\pi) = \sum_{(x_1, x_2) \in \mathcal R}\binom{n_1}{x_1}\binom{n_2}{x_2}\,\pi^{s}(1 - \pi)^{N - s}
$$

($s = x_1 + x_2$, $N = n_1 + n_2$, $\mathcal R$은 기각역). 두 검정은 기각역 $\mathcal R$을 정하는 통계량만 달라요. 이 페이지의 계산은 `csrc/htest/nuisance.hpp`(최댓값)와 `csrc/htest/contingency.cpp`(기각역)에 있어요.

## Bernstein 꼴

$f$를 합 $s$로 묶으면 구조가 드러나요. 합이 $s$인 표들의 항은 모두 $\pi^s(1 - \pi)^{N - s}$를 가지므로

$$
f(\pi) = \sum_{s=0}^{N}\beta_s\,B_s(\pi),\qquad B_s(\pi) = \binom{N}{s}\pi^s(1-\pi)^{N-s},\qquad \beta_s = \sum_{\substack{(x_1, x_2) \in \mathcal R\\ x_1 + x_2 = s}}\frac{\binom{n_1}{x_1}\binom{n_2}{x_2}}{\binom{N}{s}}
$$

이에요. $B_s$는 이항 분포 Binomial$(N, \pi)$의 확률이고, $\beta_s$는 합이 $s$일 때 첫 칸의 초기하 분포에서 기각역에 든 확률이에요. 그래서 $0 \le \beta_s \le 1$이고 $f$는 차수 $N$인 다항식의 Bernstein 꼴이에요. 이 꼴이 좋은 까닭은 세 가지예요.

- 값이 모두 양수인 항의 합이라 상쇄가 없어요.
- 도함수도 $\beta$의 차분과 $B_s$의 합으로 바로 나와요(아래).
- $\beta$는 $\pi$와 상관없으므로 표 하나에 한 번만 만들면 돼요.

### β의 계산

합 $s$마다 초기하 항 $P(X_1 = x_1 \mid s)$를 최빈값의 log 확률(sd.stats `Hypergeometric`의 double-double log pmf)과 이웃의 정확한 비로 만들어요. 비 $(n_1 - x)(s - x)/\big((x + 1)(n_2 - s + x + 1)\big)$는 정수의 곱과 몫이라 double-double로 거의 정확해요. 곱이 길어져 값이 $2^{-600}$ 아래로 가면 2의 거듭제곱을 지수로 따로 들어서 깊은 꼬리의 항도 0이 되지 않아요. 기각역에 든 항을 보상 합으로 더해 $\log\beta_s$를 double-double로 둬요.

그다음 $\beta$를 가장 큰 값으로 나눠 1의 척도에서 계산해요. $\sup f \ge \max_s\beta_s B_s(s/N) \ge \max_s\beta_s/(2.5\sqrt N)$이므로, p값이 $10^{-10}$처럼 작은 표에서도 상대 정확도를 잃지 않아요.

### 기각역을 정확하게

Barnard의 통계량은 두 비율의 차의 Wald 통계량이에요. 합동 분산과 비합동 분산 모두, $D = x_1n_2 - x_2n_1$로 쓰면 $T^2$가 정수의 몫이에요.

$$
T^2_{\text{합동}} = \frac{D^2N}{n_1n_2\,s(N - s)},\qquad T^2_{\text{비합동}} = \frac{D^2n_1n_2}{x_1(n_1 - x_1)n_2^3 + x_2(n_2 - x_2)n_1^3}
$$

표끼리 견줄 때는 공통 인수($N/(n_1n_2)$, $n_1n_2$)를 빼고 분자와 분모를 교차해 곱한 128비트 정수를 견줘요. $n_1, n_2 \le 10^4$이면 넘치지 않고, 표의 수 상한이 그 범위를 지켜요.

```cpp
// csrc/htest/contingency.cpp
Wald wald(std::int64_t x1, std::int64_t x2, std::int64_t n1, std::int64_t n2, bool pooled) {
    const i128 D = static_cast<i128>(x1) * n2 - static_cast<i128>(x2) * n1;
    if (D == 0) return {0, 1, 0};
    i128 den;
    if (pooled) {
        const i128 s = x1 + x2, N = n1 + n2;
        den = s * (N - s);
    } else {
        const i128 a = static_cast<i128>(n1) * n1 * n1, b = static_cast<i128>(n2) * n2 * n2;
        den = static_cast<i128>(x1) * (n1 - x1) * b + static_cast<i128>(x2) * (n2 - x2) * a;
    }
    return {D * D, den, D > 0 ? 1 : -1};
}
```

정확한 비교가 필요한 까닭은 거울 표예요. $n_1 = n_2$이면 $(x_1, x_2)$와 $(n_1 - x_1, n_2 - x_2)$, $(x_2, x_1)$은 $|T|$가 수학적으로 같아요. 반올림한 $T$를 견주면 그런 표가 관측보다 1 ULP 작게 나와 기각역에서 빠질 수 있어요.

Boschloo는 표마다의 한쪽 Fisher p값이 기각역을 정해요. 합 $s$의 표에서 $P(X_1 \le x \mid s)$를 $P(X_1 = x \mid s)\cdot u_x$로 쓰고, $u_x = 1 + u_{x-1}\,P(x - 1)/P(x)$를 아래 끝부터 쌓아요. 비는 위와 같은 정확한 정수의 몫이고, $u_x \ge 1$이라 부분합을 현재 항에 대한 비로 들어도 상쇄가 없어요. 관측의 한쪽 p값의 $(1 + 10^{-13})$배 이하인 표가 기각역이에요(scipy의 허용오차). 양쪽 검정은 두 한쪽 p값 가운데 작은 쪽의 두 배를 1로 자르고, 두 쪽이 상대 $10^{-13}$ 안이면 `'greater'` 쪽을 써요.

### 구간의 상한

구간 $[a, b]$의 가운데를 $m$, 반폭을 $h$라 하면 테일러 정리에서

$$
f(\pi) \le f(m) + |f'(m)|\,h + \max\big(0, f''(m)\big)\frac{h^2}{2} + M_3\frac{h^3}{6},\qquad M_3 \ge \max_{[a,b]}|f'''|
$$

예요. 필요한 것은 $m$에서의 $f, f', f''$와 구간 위의 $|f'''|$의 상한이에요.

**도함수.** Bernstein 꼴의 도함수는 $\beta$의 차분이에요. $B_{N-1,s} = B_{N,s}\,(N - s)/\big(N(1 - \pi)\big)$를 쓰면

$$
f'(\pi) = \frac{1}{1 - \pi}\sum_s (N - s)(\beta_{s+1} - \beta_s)B_s(\pi) = \frac{1}{\pi}\sum_s s(\beta_s - \beta_{s-1})B_s(\pi)
$$

이고 $f''$, $f'''$도 같은 꼴(2·3차 차분과 $(N - s)(N - s - 1)\cdots$, 인수 $(1 - \pi)^{-2}$, $(1 - \pi)^{-3}$)이에요. $m \le 1/2$이면 $1/(1 - m)$ 쪽, 그 밖은 $1/m$ 쪽을 써서 인수가 2를 넘지 않게 해요. $B_s(m)$은 최빈값 $s_0 = \lfloor (N + 1)m \rfloor$의 double-double log pmf에서 비 $\frac{N - s}{s + 1}\cdot\frac{m}{1 - m}$의 점화식으로 양쪽으로 만들어요. 차분 합의 반올림은 같은 항의 절댓값 합에 $8u$를 곱한 만큼 위로 덮어요.

**셋째 도함수의 상한.** $|f'''| \le \text{인수}\cdot\sum_s w_s\,|\Delta^3\beta_s|\,\max_{[a,b]}B_s$예요. $\max_{[a,b]}B_s$는 $B_s$가 $\pi = s/N$에서 가장 크다는 데서 나와요. $s/N$이 구간 왼쪽이면 $B_s(a)$, 오른쪽이면 $B_s(b)$이고, 안에 있으면 Stirling의 상한 $B_s(s/N) \le \sqrt{N/(2\pi s(N - s))}\,e^{1/(12N)}$을 써요. 인수 $(1 - \pi)^{-3}$이나 $\pi^{-3}$은 구간의 끝에서 가장 크므로 구간 전체를 덮어요.

```cpp
        // csrc/htest/nuisance.hpp
        const double fac = low ? 1.0 / (1.0 - m) : 1.0 / m;
        const double e1 = 8.0 * kU * a1 * fac * (1.0 + 1e-10), e2 = 8.0 * kU * a2 * fac * fac * (1.0 + 1e-10);
        const double f1 = std::fabs(to_double(d1.value())) * fac + e1;
        const double f2 = to_double(d2.value()) * fac * fac + e2;
        const double M3 = third(a, bb);
        if (!std::isfinite(M3)) {
            p.u = kInf;
            return true;
        }
        p.u = fm * (1.0 + 8.0 * kU) + f1 * h + std::max(0.0, f2) * h * h / 2.0 + M3 * h * h * h / 6.0 + 1e-290;
        return true;
```

### 분기 한정

$[0, 1]$을 `n`개의 같은 구간으로 나눠 시작해요(`n`은 scipy의 격자 크기 인자예요). 구간마다 상한을 계산해 힙에 넣고, 상한이 가장 큰 구간을 꺼내 둘로 나눠요. 구간을 평가할 때마다 가운데 점의 $f$를 계산하므로 "본 값 가운데 가장 큰 값" $L$이 계속 올라가요. 모든 남은 구간의 상한이 $L(1 + 2^{-48})$ 아래가 되면 멈추고, $L$을 돌려줘요.

```cpp
        // csrc/htest/nuisance.hpp
        while (!heap.empty()) {
            const Piece p = heap.top();
            if (p.u <= L_ * tol) break;
            heap.pop();
            const double m = 0.5 * (p.a + p.b);
            if (!(p.a < m && m < p.b) || p.b - p.a < 1e-15) return DD{kNaN, 0.0};
            if (!push(p.a, m) || !push(m, p.b)) return DD{kNaN, 0.0};
        }
        return Lbest_.hi > 0.0 ? lbmax_ + dd::log(Lbest_) : DD{-kInf, 0.0};
```

돌려주는 값은 $f$를 실제로 계산한 값이라 반올림 몇 번 안의 $f$ 값이고, 멈춤 조건이 참 최댓값이 그보다 상대 $2^{-48}$ 넘게 크지 않음을 보증해요. 그래서 결과가 `n`에 거의 의존하지 않아요. `n`은 처음 격자의 크기일 뿐이에요.

```python

>>> for n in (1, 4, 32, 300):
...     print(n, sd.htest.barnard_exact(t, n=n).pvalue)
1 0.0682183093231946
4 0.0682183093231946
32 0.0682183093231946

>>> sd.htest.boschloo_exact(t)

>>> sd.htest.barnard_exact([[25, 2], [1, 22]])

```

마지막 표는 꼬리가 깊은 경우예요. $\beta$를 1의 척도로 옮겨 두었으므로 $10^{-11}$의 p값도 상대 정확도로 나와요.

### 상한과 퇴화한 표

- 표의 수 $(n_1 + 1)(n_2 + 1)$이 $10^7$을 넘으면 기각역을 만들지 않고 p값이 NaN이에요(통계량은 그대로 내요).
- 구간 평가의 수 × $(N + 1)$이 $4 \times 10^8$을 넘거나 구간의 폭이 $10^{-15}$ 아래로 가면 보증을 끝낼 수 없다는 뜻이라 p값이 NaN이에요.
- 0인 열은 scipy처럼 Barnard가 (NaN, 1), Boschloo가 (NaN, NaN)이에요.

## scipy와 다른 곳

scipy는 같은 $f$를 `shgo`(Sobol 표본, 처음 `n`점)로 최대화해요. 최적화가 봉우리를 놓쳐도 알려 주지 않아서, 무작위 2 × 2 표에서 scipy의 p값은 이 라이브러리보다 작게 나오는 일이 있어요(n = 64의 [[3, 8], [2, 2]] 비합동에서 $1.2 \times 10^{-7}$ 낮아요). 이 라이브러리보다 크게 나오는 일은 없었어요.

scipy는 기각역도 반올림한 Wald 통계량으로 정해요. 그래서 [[7, 12], [8, 3]]에서 거울 표 (3, 8)과 (8, 3)이 1 ULP 차이로 기각역에서 빠져 p값이 $9.5 \times 10^{-4}$(상대) 낮아요. Boschloo는 `shgo`로도 $5.8 \times 10^{-13}$ 안에서 같아요.
