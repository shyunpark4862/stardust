## 결론 (구역마다 Boost를 쓸지)
| 함수 | 구역 | 판단 | 근거 |
|---|---|---|---|
| `zeta` | x ≥ 0 | **Boost 쪽이 낫다** | 17–20배 빠르고 더 정확하다(1.1–2.0 대 3.3–24 ULP). x < 0은 Boost가 1.7e3 ULP라 우리 것을 둔다 |
| `k0`, `k1` | 전 구역 | **Boost 쪽이 낫다** | 4–5배 빠르고 같거나 더 정확하다(`k0`의 x < 2: 1.67 대 17.3 ULP) |
| `i0`, `i1` | 전 구역 | **Boost 쪽이 낫다** | 2–2.5배 빠르고 정확도는 비슷하다(2.2–3.5 ULP) |
| `expi` | x ≥ −700 | **Boost 쪽이 낫다** | 2–5.7배 빠르고 기준 안(≤ 4.7 ULP). x < −700(서브노멀 꼬리)은 Boost가 0을 내므로 우리 것을 둔다 |
| `lambertw`, `lambertw(k=-1)` | 분기점 밖 | **Boost 쪽이 낫다** | 3배 빠르고 정확도 같다(≤ 1.1 ULP). 분기점 근처는 Boost가 2e7 ULP라 우리 것을 둔다 |
| `kv` | \|ν\| < 50 | Boost 쪽이 낫다 | 2.4–6배 빠르고 기준 안(≤ 14 ULP). \|ν\| ≥ 50은 12배 빠르지만 2점이 45 ULP를 넘는다(81) |
| `iv` | \|ν\| < 5 | 비슷하다 | 속도 차이 없음 |
| `iv` | \|ν\| ≥ 5 | 정확도에서 걸린다 | 4–20배 빠르지만 17점이 45 ULP를 넘는다(최대 2.5e3) |
| `hyp1f1` | 보장 영역 | 우리 것 | Boost는 8배 빠르지만 136점이 45 ULP를 넘는다(최대 208) |
| `hyp1f1` | a < 0, x > 0 (느슨한 영역) | **Boost가 훨씬 낫다** | 우리는 2.3e13 ULP, 큰 \|a\|에서는 46점 중 39점이 inf나 엉뚱한 값. Boost는 모두 유한하고 최대 1.3e4 ULP(상대 약 3e-12). 1e-14는 못 지키지만 느슨한 영역의 잰 값이 3.9e-3에서 1e-12 수준으로 줄어든다 |
