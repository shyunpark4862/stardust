# Boost.Math를 부르는 구간 (S10)

사용자 결정(2026-11-14): 구간마다 Boost가 계약(1e-14, 특수값은 우리 규칙)을 참값 파일의 모든 점에서 지키고 1스레드에서 느리지 않을 때(10% 안은 같은 것)만 Boost로 바꾼다. 일부 점만 틀리면 구간을 잘게 나눈다. 구현은 `csrc/special/boost.hpp`와 각 Op, 설계는 docs/design/special.md §5.14다.

## 1. 구간 고르기
- `fails.py`: Boost가 계약을 넘는 참값 점이 어디에 몰려 있는지(입력 범위와 최악의 점).
- `rules.py`: 후보 규칙마다 "그 구간은 Boost, 나머지는 우리 것"으로 합친 결과의 계약 위반 수.
- 고른 규칙과, 그 구간 안 점 2e5개에서 잰 1스레드 ns(우리 / Boost):

| 함수 | Boost 구간 | 참값 중 Boost 몫 | 계약 위반 | 우리 ns | Boost ns | Boost / 우리 |
|---|---|---:|---:|---:|---:|---:|
| `zeta` | x > −60 | 97.6% | 0 | 95.4 | 13.7 | 0.14 |
| `i0`, `i1` | 전부 | 100% | 0 | 15.1, 16.4 | 7.6, 8.2 | 0.50 |
| `k0`, `k1` | 전부 | 100% | 0 | 23.5, 23.9 | 6.8, 7.3 | 0.29–0.30 |
| `iv` | \|ν\| < 30, x > 0 | 58.4% | 0 | 488.9 | 204.7 | 0.42 |
| `kv` | \|ν\| < 400, x > 0 | 92.4% | 0 | 975.1 | 138.7 | 0.14 |
| `expi` | x ≥ −700 | 99.5% | 0 | 26.1 | 12.3 | 0.47 |
| `lambertw` | \|x + 1/e\| ≥ 0.05 | 74.9% | 0 | 23.3 | 7.2 | 0.31 |
| `lambertw(k=-1)` | \|x + 1/e\| ≥ 0.05 | 66.7% | 0 | 57.1 | 17.7 | 0.31 |
| `digamma` | x > 0 | 70.9% | 0 | 9.5 | 9.0 | 0.95 |
| `gamma` | x > −170, 극점 제외 | 97.4% | 0 | 18.0 | 19.6 | 1.09 (10% 안) |
| `beta` | a, b > 0, a + b < 40 | 34.0% | 0 | 28.3 | 27.6 | 0.98 |
| `gammaincinv` | p ≥ 1e-300, 근 ≥ 1e-300 | 63.8% | 0 | 645.4 | 527.0 | 0.82 |
| `gammainccinv` | 전부(근이 정상 범위) | 100% | 0 | 595.8 | 294.1 | 0.49 |
| `betainc`, `betaincc` | a, b ≤ 6, 결과 정상 범위 | 37% | 0 | 570 | 146 | 0.26 |
| `betaincinv` | a, b ≥ 10 | 21.2% | 0 | 1490.8 | 1093.4 | 0.73 |
| `betainccinv` | a, b ≥ 1 | 29.7% | 0 | 2387.4 | 843.4 | 0.35 |
| `hyp1f1` | 느슨한 영역 전부, 보장 영역의 x ≥ 0이고 b < 11 | 33.7% | 0 | | | (Boost 약 8배 빠름, regions.md) |

- `betainc`는 처음 a, b ≤ 9로 골랐다가 `betaincc`(a, b ≤ 6)와 맞췄다. 두 구간이 다르면 한쪽만 Boost인 점에서 합이 1에서 3 ULP 넘게 벗어났다.
- 바꾸지 않은 것과 이유는 docs/design/special.md §5.14.

## 2. 바꾼 뒤 (bench/special/s10/)
1스레드 ns, 10⁶개 참값 표본 (전: bench/special/final/speed.md, 후: s10/speed.md), 최대 ULP (전: final/accuracy.md, 후: s10/accuracy.md):

| 함수 | ns 전 → 후 | 최대 ULP 전 → 후 |
|---|---|---|
| `zeta` | 95.4 → 17.7 | 24.2 → 44.7 |
| `i0`, `i1` | 15.6, 16.4 → 4.3, 4.7 | 3.97, 8.48 → 3.5, 3.47 |
| `k0`, `k1` | 24.4, 24.0 → 11.3, 11.4 | 17.3, 6.06 → 2.3, 2.13 |
| `kv` | 1625 → 873 | 8.14 → 22.2 |
| `iv` | 2032 → 1899 | 15.5 → 38.8 |
| `expi` | 26.1 → 12.2 | 13.6 → 4.69 |
| `lambertw`, `k=-1` | 21.3, 44.3 → 10.7, 18.2 | 0.91, 1.38 → 1.89, 2.63 |
| `gammaincinv`, `gammainccinv` | 423, 598 → 369, 302 | 6.69, 8.84 → 50.1, 37.5 |
| `betainc`, `betaincc` | 553, 550 → 403, 399 | 33.3, 18.6 → 16.7, 18.6 |
| `betaincinv`, `betainccinv` | 1100, 1628 → 1022, 1161 | 59, 20.3 → 59, 22 |
| `hyp1f1` | 1664 → 1435 | 보장 6.91 → 78.6, 느슨 2.3e13 → 2.2e3 (상대 3.9e-3 → 2.8e-13) |
| `digamma`, `gamma`, `beta` | 9.7, 19.6, 63.6 → 9.6, 20.0, 63.8 | 2.11, 6.24, 9.03 → 2.11, 10.2, 52.8 |

- 최대 ULP가 늘어난 곳(`zeta`, `gammaincinv`, `hyp1f1` 보장 영역, `beta`)도 테스트의 계약(상대 1e-14, κ나 포락선 배율)은 지킨다. ULP 한 칸은 상대 1.1e-16–2.2e-16이라 45 ULP를 넘어도 1e-14 안일 수 있다.
