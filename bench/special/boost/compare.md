# sd.special와 Boost.Math 비교

- Boost.Math: GitHub boostorg/math의 develop(커밋 4682f44, 2026-11-14에 받음), standalone 헤더. 정책은 모든 오류를 무시(값을 돌려준다)하고 `promote_double<false>`로 했다. 이 Mac(arm64)에서는 long double이 double이라 승격해도 같다. `clang++ -O3 -std=c++20`.
- 하네스: `boost_eval.cpp`(함수 하나를 원소마다 부른다), `drive.py`(참값 파일로 정확도, `bench/special/speed.py`와 같은 10⁶개 표본으로 속도).
- **정확도**: 참값 파일의 보장 영역 입력에서, `bench/special/accuracy.py`와 같은 척도(참값 대비 ULP, 포락선·κ 배율로 나눔)로 쟀다. sd 열은 `bench/special/final/accuracy.md`와 같다.
- **속도**: 원소당 ns, 1스레드. sd는 `bench/special/final/speed.md`의 1스레드 값(Python에서 10⁶개 배열 한 번 호출), Boost는 C++ 루프(같은 입력, 5번 중 가장 빠름). sd는 10스레드에서 이보다 5–10배 빠르지만 Boost는 원소별 함수라 여기서는 1스레드끼리만 비교한다.
- Boost에 없는 sd 함수는 비교하지 않았다: `erfcx ndtr log_ndtr ndtri rgamma betaln binom` Hurwitz `zeta`, e-스케일 Bessel 8개(`i0e`, `ive` 등), `hyp2f1`, 복소수 전부(`wofz loggamma`와 complex `erf erfc erfcx lambertw`), 리덕션.

## 읽는 법
- **정확도**: 보통 인자에서는 Boost가 매우 정확하다. `erf` 계열, `gammaln`, `digamma`, 0·1차 Bessel에서 Boost는 1.4–18 ULP이고 sd보다 낮은 것도 많다(`k0` 2.3 대 17.3, `y1` 17.9 대 46.4). Boost가 45 ULP를 넘는 곳은 우리 참값 파일이 일부러 넣은 어려운 점이다.
  - 서브노멀 꼬리를 0으로 낸다: `expit`(x ≈ −709…−740), `gamma`(x ≈ −172…−179), `expi`(x ≈ −709), `betaincc`(x → 1). sd는 사용자 결정(S1–S5)으로 참값을 낸다. scipy도 0이다.
  - 분기점: `lambertw`의 −1/e 근처 2e7 ULP(e·x + 1의 상쇄, scipy와 같은 문제).
  - 큰 인자: Airy의 x ≈ −1e11(1.5e16, 위상), `gammainc`의 a ≈ 1e6(5e5), `jv`·`yv`의 x ≈ 5e4, ν ≈ 900(2.5e4), `beta`의 큰 a, b(1.8e3), 음의 `zeta`(x ≈ −250, 1.7e3), `polygamma`의 n = 170(560), `hyp1f1`의 큰 \|x\|(208).
  - `ellipk`·`ellipe`: Boost는 모듈러스 k를 받고 sd(scipy)는 매개변수 m = k²를 받는다. m을 √m으로 바꾸는 반올림이 m → 1의 로그 특이점에서 커져서(9.8e13 ULP), 이 비교는 Boost의 오차가 아니다. m < 0(1,013점)은 Boost의 정의역 밖이다.
- **속도** (1스레드): 비교한 43개의 기하평균은 Boost / sd = 0.91로, Boost가 9% 빠르다. 20개는 sd가, 23개는 Boost가 빠르다.
  - Boost가 크게 빠른 곳: `hyp1f1` 8배, `iv`·`kv` 8배(sd는 큰 차수에서 O(ν)의 double-double 점화식), `zeta` 6배, `k0`·`k1` 3.5배, `lambertw` 2–3배, 불완전 베타와 역함수 2–3배. 여럿은 sd가 정확도 때문에 double-double을 쓰는 곳이다(초기하, 큰 차수 I·K, 불완전 베타).
  - sd가 크게 빠른 곳: `expn` 93배(표본에 n이 큰 점이 섞여 있다), `polygamma` 4.9배, `expit` 4.7배, `erf` 계열 2–2.9배(NEON + vForce 덩어리 커널), `jv`·`yv` 2.4배.
  - sd는 여러 스레드로 나눠 10스레드에서 5–10배 더 빨라진다. Boost는 원소별 함수라 따로 병렬화해야 한다.
- **범위**: sd 65개 중 Boost에 대응하는 것은 이 표의 함수들이다. 복소수 함수, `erfcx`·정규분포 함수, e-스케일 Bessel, `hyp2f1`, Hurwitz 제타는 Boost.Math에 없다.
