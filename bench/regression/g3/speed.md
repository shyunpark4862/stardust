# G3 속도: 정규화

`bench/regression/g3/speed.py`로 쟀다(2026-11-18, Apple M4 Pro, scikit-learn 1.9.1, numpy 2.5.4). 시간은 ms, 여러 번 가운데 가장 빠른 값이다(원래 출력은 `speed.log`). sd의 스레드는 `sd.set_num_threads`, scikit-learn 밑의 BLAS는 threadpoolctl로 같은 수로 정했다(scikit-learn의 `n_jobs`는 기본값 None).

- 데이터: X는 표준정규 (n, k), β는 표준정규 값 10개 외에 0, y = Xβ + 표준정규 잡음. 로지스틱의 y는 η = Xβ/2의 베르누이. alpha_max는 lasso의 해가 0이 되는 가장 작은 alpha다.
- ridge: `ridge(alpha=0.1)` / `Ridge(alpha=0.1·n)`(기본 해법 'auto'는 XᵀX의 Cholesky)과 `solver='svd'`.
- lasso, 엘라스틱 넷(l1_ratio 0.5): alpha = alpha_max/20 / `Lasso`, `ElasticNet`(기본값: `precompute=False`, `tol=1e-4`).
- 경로: alpha_max에서 1e-3·alpha_max까지 100개 / `lasso_path`(`precompute='auto'`: Gram).
- 5겹 CV: `lasso_cv(rng=…, alphas=격자)` / `LassoCV(alphas=같은 격자, cv=같은 겹)`.
- ridge GCV: `ridge_cv(cv='gcv', alphas=100개)` / `RidgeCV(alphas=같은 격자)`(효율적인 단일 관측 제외 교차검증).
- 로지스틱: alpha = 1e-3(`C` = 1/(n·alpha)). L1은 `LogisticRegression(l1_ratio=1, solver='saga')`와 `solver='liblinear'`(liblinear는 절편에도 벌점을 준다: 다른 문제), L2는 기본 lbfgs와 `solver='newton-cholesky'`. 모두 기본 `tol`.
- 괄호는 sd의 `n_iter`(경로는 합). '배'는 scikit-learn의 시간 / sd의 시간(1보다 크면 sd가 빠르다). '차이'는 계수의 최대 차이 / sd 계수의 최대 절댓값이다(sd는 Arb 참값과 1e-15 수준; `accuracy.md`).

- ridge는 XᵀX를 만들지 않고 QR(키가 크면 TSQR)과 R의 SVD로 푼다. 그래서 XᵀX의 Cholesky인 scikit-learn의 기본 해법보다 1스레드 5–11배 느리고, 같은 SVD 해법(`solver='svd'`)과는 0.8–1.3배다. 그 대신 alpha 여러 개와 GCV가 같은 분해 하나로 나온다(`ridge_cv` GCV 7–63배).
- lasso·엘라스틱 넷의 한 alpha는 Gram 한 번이 시간의 대부분이다(scikit-learn의 기본은 Gram 없이 잔차를 갱신한다). 경로와 CV는 (10⁴, 1000)에서 1스레드 0.6–0.7배인데, 0 아닌 계수가 수백 개인 작은 alpha마다 KKT 연마의 Cholesky(그 수의 세제곱)가 들기 때문이다.
- 정규화 GLM의 L2는 뉴턴법이고 반복마다 가중 Gram을 다시 만든다. lbfgs보다 느리지만 lbfgs의 계수는 기본 `tol`에서 3e-5–4e-4 다르다. newton-cholesky와는 1스레드 0.29–0.61배다.
