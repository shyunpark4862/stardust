# G5 정확도: 분위 회귀

`bench/regression/g5/accuracy.py`로 쟀다(2026-11-19; 원래 출력은 `accuracy.log`).

- 정확성: 문제마다 sd가 돌려준 기저 행을 유리수로 다시 풀었다(`tools/regref.py`의 `quantreg`, python-flint `fmpq_mat`; double 입력은 정확한 유리수다). 정확한 꼭짓점, 잔차, 목적함수, 최적성 증명서(잔차가 0인 행의 쌍대 변수가 [q − 1, q] 안에 있는 해가 있는가; 퇴화한 꼭짓점은 같은 x의 행을 합친 정확한 선형계획)와 유일성(그런 해가 열린 상자 안에 있는가)을 낸다.
  - '계수 오차'는 ‖params − 정확한 값‖/‖정확한 값‖, '목적함수 오차'는 상대오차, '기저 잔차'는 기저 행의 sd 잔차 / (\|y_i\| + \|x_i\|·\|params\|)의 최댓값이다.
  - '유일하지 않음'은 sd의 `nonunique` 수 / 정확한 판정의 수(쌍대 변수가 경계에서 10⁻¹⁴ 안인 것을 포함: median10의 q = 0.3은 double의 0.3 때문에 정확히는 여유 1.1×10⁻¹⁶로 유일하다).
- statsmodels: `QuantReg(y, Z).fit(q)`의 기본값(IRLS)과 정확한 꼭짓점의 거리(유일한 해만; 계수의 최대 차이 / 최대 계수)와 목적함수의 초과.
- 문제: R 대조의 문제들(`tests/regression/ref/quantreg_r.json`), 무작위 설계(n 50–5,000, k 2–10, 정규·t₂·지수 잡음, q 0.05–0.95), 5차 다항식(κ ≈ 10⁵), 더미 설계의 포아송 반응.

## R (quantreg 6.1): 가장 큰 상대 차이
R의 `summary.rq`는 eps = 2⁻²⁶을 y의 단위 그대로 쓰고 sd는 2⁻²⁶·max\|y_i\|다(G67). 참값은 `summary.rq` 본문의 eps 한 줄만 max\|y_i\|를 곱하게 바꿔 부른 것이다(y/max\|y_i\|로 부르면 나눗셈의 반올림이 'nid'를 4×10⁻¹³ 움직이고 정수 자료의 동률을 깬다).

|---|---:|---:|---:|---:|---:|
| engel | 1.0e-14 | 3.7e-15 | 3.6e-15 | 4.5e-15 | 3.6e-15 |

- br 계수: engel의 q = 0.75에서 1.0×10⁻¹⁴ 다른 것은 R 쪽의 기저 풀이 오차다(sd는 정확한 꼭짓점과 5.4×10⁻¹⁷).
- 'iid'·'ker'는 R의 `summary.rq`에 sd의 계수와 잔차를 넣어 sd의 꼭짓점에서 계산한 값과 비교했다(유일하지 않은 dummies60의 q = 0.75에서 R의 br은 계수 (4, 1, 3), sd는 사전식 최소점 (3, 2, 4)를 낸다; 목적함수는 같다).
- 'iid'의 차이 셋(stackloss q = 0.75의 7.6×10⁻², tails500 q = 0.99 Bofinger의 0.12, dummies60 q = 0.75의 R 0과 sd 1.38)은 모두 희소도의 중앙값 회귀(잔차의 순서 통계량 7개·5개·12개를 등간격 x에 회귀)가 유일하지 않은 경우다: R의 br과 sd의 규칙이 같은 목적함수의 다른 꼭짓점을 고른다. 그 중앙값 회귀가 유일한 모든 경우는 10⁻¹⁴ 안에서 같다.
- 'nid'는 R의 q ± h 다시 적합(br)이 sd와 같은 꼭짓점이라 모든 경우 7.8×10⁻¹⁴ 안이다.
