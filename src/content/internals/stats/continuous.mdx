분포 함수를 special 함수의 조합으로 만들면, 함수 하나하나는 정확해도 **조합하는 자리**에서 자릿수를 잃어요. 이 글은 그 자리를 막으려고 되풀이해서 쓰는 기법들을 하나씩 설명해요.

여기서 설명하는 것은 각 메서드의 **정의**, 곧 원소 하나를 계산하는 스칼라 함수예요. 배열을 받으면 같은 정의를 원소마다 부르기 전에, 같은 결과를 더 싸게 내는 묶음 커널이 먼저 시도해요. 그 커널은 오차 상한을 원소마다 세어서 예산 안인 원소만 맡고 나머지는 여기의 정의에 넘겨요. 그 구조는 [원소별 엔진과 빠른 경로](/internals/stats/engine/)에 있어요.

double-double은 값을 반올림하지 않은 두 double의 합 $hi + lo$($\lvert lo\rvert \le \tfrac12\,\text{ulp}(hi)$)로 들고 다니는 약 106비트 산술이에요. TwoSum과 FMA로 반올림 오차를 정확히 꺼내 다음 연산에 넘기는 방식은 [special의 수치 기법](/internals/special/techniques/)에 있어요.

## 표준화 변수를 double-double로

### 문제: z의 반올림이 z²배로 커져요

정규분포의 밀도는 $f(x) = e^{-z^2/2}/(\sigma\sqrt{2\pi})$, $z = (x - \mu)/\sigma$예요. $z$를 float64로 계산하면 빼기와 나누기에서 반올림이 두 번 생겨서 $z$에 상대오차 $\delta$(1 ULP 남짓)가 붙어요. 그 오차는 밀도로 이렇게 퍼져요.

$$
\frac{d\log f}{dz} = -z \quad\Longrightarrow\quad \frac{\Delta f}{f} \approx -z \cdot z\delta = -z^2 \delta
$$

$z = 30$이면 $z^2 = 900$이라, $z$가 1 ULP 틀리면 밀도가 900 ULP 틀려요. 밀도 함수 자체(`exp`)가 아무리 정확해도 소용이 없어요. 반올림은 이미 입력에서 생겼기 때문이에요.

이 증폭은 정규분포만의 일이 아니에요. 값이 $e^{-g(z)}$ 꼴이면 $z$의 상대오차는 $\lvert z\,g'(z)\rvert$배가 돼요. 지수분포의 $e^{-y}$($y = x/s$)는 $y$배라서 double의 바닥 근처 $y \approx 745$에서 745 ULP예요. 베이불의 $e^{-t}$, $t = (x/s)^c$는 $t$배이고, $t$ 자체가 $e^{c\log(x/s)}$라 지수의 반올림이 다시 $\lvert c\log(x/s)\rvert$배가 돼요.

### 정확한 입력에서 double-double z 만들기

해결은 $z$를 **반올림하지 않는** 거예요. $x$, $\mu$, $\sigma$는 정확한 double이므로, $x - \mu$는 TwoSum으로 오차 없이 두 double의 합이 되고, 그것을 $\sigma$로 나눈 몫은 FMA로 나머지를 정확히 꺼내 double-double로 만들 수 있어요.

```cpp
// csrc/stats/numeric.hpp
inline DD div(DD d, double s) {
    const double q = d.hi / s;
    if (!std::isfinite(q) || q == 0.0) return {q, 0.0};
    const double r = std::fma(-q, s, d.hi) + d.lo;  // d - q s (exact product, one rounding of the sum)
    return dd::quick_two_sum(q, r / s);
}

// z = (x - mu) / sigma as a double-double, for finite x, mu and sigma > 0.
// x - mu may overflow while z does not (sigma > 1): then (x/2 - mu/2) / (sigma/2).
inline DD standardize(double x, double mu, double sigma) {
    const DD d = dd::two_sum(x, -mu);
    if (std::isfinite(d.hi)) return div(d, sigma);
    return div(dd::two_sum(0.5 * x, -0.5 * mu), 0.5 * sigma);  // the halves are exact (sigma > 2^-1021 or z overflows)
}
```

`std::fma(-q, s, d.hi)`는 $d_{hi} - qs$를 반올림 한 번으로 계산하는데, $q$가 $d_{hi}/s$의 반올림이라 이 차는 정확히 double로 나타낼 수 있어요. 그래서 나머지 $r$의 오차는 $d_{lo}$를 더할 때의 반올림 하나뿐이고, 몫은 $2^{-104}$ 정도까지 맞아요. $x - \mu$가 넘치는 입력($x = 10^{308}$, $\mu = -10^{308}$, $\sigma = 10$)은 반씩 나눠 같은 계산을 해요.

### 밀도: 지수를 한 번에

밀도는 지수 전체 $z^2/2 + \log(\sigma\sqrt{2\pi})$를 double-double로 만들어 **한 번만** 지수화해요. 상수 $\log(\sigma\sqrt{2\pi})$를 따로 곱하면 반올림이 하나 더 생기기 때문이에요.

```cpp
// csrc/stats/dist/normal.hpp
inline DD neg_log_density(DD z, double sigma) {
    thread_local num::Memo memo;
    const DD c = memo.get(sigma, 0.0, [&] { return num::log_dd(sigma) + num::kLogSqrt2Pi; });
    return (z * z) * 0.5 + c;
}

static double pdf(double x, double mu, double sigma) {
    using namespace normal_detail;
    if (std::isinf(x)) return 0.0;
    const DD z = num::standardize(x, mu, sigma);
    if (std::fabs(z.hi) > kHugeZ) return 0.0;
    return num::exp_dd(-neg_log_density(z, sigma));
}
```

`exp_dd`는 $e^{hi + lo} = e^{hi}(1 + lo)$로 반올림 한 번에 지수화해요(`numeric.hpp`). $lo$가 $hi$의 ULP 아래라 둘째 항 $lo^2/2$는 아무것도 아니에요. `Memo`는 스레드마다 마지막 매개변수에 대한 상수를 기억하는 칸이에요. 매개변수가 스칼라인 흔한 호출에서 원소마다 같은 `log`를 되풀이하지 않게 해요. 같은 매개변수면 기억하든 안 하든 같은 비트가 나와요.

```python
>>> sd.stats.Normal(mu=-0.9, sigma=0.7).pdf(20.06)
1.1670539779076696e-195
```

여기서 $z = 29.94\ldots$예요. Arb(구간 산술)로 정확한 입력에서 계산한 참값은 $1.16705397790766958\ldots \times 10^{-195}$이고 stardust의 값은 그 반올림이에요. scipy 1.18.1의 `norm.pdf(20.06, -0.9, 0.7)`은 $1.1670539779078184 \times 10^{-195}$로 $1.3 \times 10^{-13}$(1149 ULP)이 틀려요.

`logpdf`는 같은 지수를 지수화하지 않고 `hi + lo`로 돌려줘요. $\lvert z\rvert > 10^{10}$이면 밀도는 0이고 지수의 double-double 정밀도는 쓸모가 없으므로 double로 계산해요.

### 누적분포: z.hi에서 계산하고 1차 보정

`ndtr`은 double 하나를 받아요. 그래서 $\Phi(z_{hi})$를 계산하고 낮은 부분을 1차 테일러 항으로 더해요.

$$
\Phi(z_{hi} + z_{lo}) = \Phi(z_{hi}) + \varphi(z_{hi})\,z_{lo} + O(z_{lo}^2)
$$

둘째 항이 이미 결과의 ULP 수준이라 셋째 항($z_{lo}^2$ 크기)은 아무것도 아니에요. 보정 항 자체는 $\varphi$를 몇 ULP로만 계산해도 돼요.

```cpp
// csrc/stats/dist/normal.hpp
inline double tail_z(DD z, bool upper) {
    if (upper) z = -z;
    if (std::isinf(z.hi)) return z.hi > 0.0 ? 1.0 : 0.0;
    const double v = ndtr(z.hi);
    return z.lo == 0.0 ? v : v + phi(z.hi) * z.lo;
}

// log P(Z <= z) (upper: log P(Z > z)); d log ndtr(z) / dz = phi(z) / ndtr(z).
inline double log_tail_z(DD z, bool upper) {
    if (upper) z = -z;
    if (std::isinf(z.hi)) return z.hi > 0.0 ? 0.0 : -kInf;
    const double v = log_ndtr(z.hi);
    if (z.lo == 0.0 || std::fabs(z.hi) > kHugeZ) return v;
    return v + std::exp(-0.5 * z.hi * z.hi - num::kLogSqrt2Pi.hi - v) * z.lo;
}
```

log 꼬리는 $\log\Phi$의 도함수 $\varphi/\Phi$를 곱해요. 깊은 꼬리에서 $\varphi$와 $\Phi$는 둘 다 언더플로하지만 그 비는 $\lvert z\rvert$ 정도라서, 지수끼리 먼저 빼서 $e^{-z^2/2 - \log\sqrt{2\pi} - \log\Phi}$로 만들어요.

### 같은 생각의 다른 변수들

여러 분포가 같은 자리에서 같은 방법을 써요.

| 분포 | 반올림하지 않는 변수 | 쓰는 곳 |
|---|---|---|
| 로그정규 | $z = (\log x - \mu)/\sigma$, $\log x$는 `dd::log_pos` | 정규와 같은 `tail_z`, 밀도는 정규 지수 $+ \log x$ |
| 라플라스 | $z$ | 밀도 $e^{-(\lvert z\rvert + \log 2\sigma)}$, 꼬리 $e^{-\lvert z\rvert}/2$ |
| 지수 | $y = x/s$ | 밀도 $e^{-y}/s$, 위꼬리 $e^{-y}$, 아래꼬리 $-\operatorname{expm1}(-y_{hi}) + e^{-y_{hi}}y_{lo}$ |
| 베이불 | $E = c\log(x/s)$, $t = e^E$ | 꼬리 $e^{-t}$, 밀도 지수 $\log c - \log s + (c - 1)\log y - t$ |
| 감마·카이제곱 | $y = x/s$ | `igam(a, y_hi)`에 $yP'(y)\cdot y_{lo}/y_{hi}$ 보정 |

감마의 1차 보정에는 불완전 감마가 함께 내는 `xderiv` $= yP'(y) = y^a e^{-y}/\Gamma(a)$를 써요. $P$의 $y$에 대한 상대 조건수가 $a$에 이르므로, $y$를 반올림하면 $a = 10^6$에서 $10^6$ ULP가 틀릴 수 있는 자리예요.

베이불은 한 단계가 더 있어요. $t = e^{E}$를 `exp(E.hi)`로 만들면 그 반올림(0.5 ULP)이 $e^{-t}$에서 다시 $t$배가 돼요. 그래서 $t > 4$이면 반올림의 잔차 $E - \log(\exp(E_{hi}))$를 double-double로 구해 $t$의 낮은 부분으로 접어 넣어요.

```cpp
// csrc/stats/dist/weibull.hpp
static T t_of(double x, double c, double s) {
    const num::DD e = e_of(weibull_detail::log_ratio(x, s), c);
    const double th = std::exp(e.hi);
    if (th == 0.0 || std::isinf(th)) return {num::DD{th, 0.0}, e};
    if (th > 4.0) {
        const num::DD r = e - num::log_dd(th);
        return {num::DD{th, th * (r.hi + r.lo)}, e};
    }
    return {num::DD{th, th * e.lo}, e};
}
```

`log_ratio(x, s)`는 $x/s$를 double-double로 만든 뒤 그 log를 구하고, 몫의 낮은 부분이 서브노멀이 되는 곳($x < 2^{-960}$)에서는 두 log를 따로 빼요. 이 $t$가 극값 분포(Gumbel, GEV)와 파레토·레일리에서도 같은 모양으로 쓰여요([극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)).

## 역함수: 뉴턴 한 단계

### 왜 필요한가: μ + σz와 exp(μ + σz)

정규분포의 `icdf(p)`는 $\mu + \sigma z$, $z = \texttt{ndtri}(p)$예요. `ndtri`의 $z$는 몇 ULP의 상대오차가 있어요. 이 오차가 결과로 갈 때 두 곳에서 커져요.

- **상쇄.** $\mu + \sigma z$에서 $\mu$와 $\sigma z$의 부호가 반대면 $z$의 상대오차가 $\lvert\sigma z/x\rvert$배가 돼요.
- **지수.** 로그정규의 $x = e^{\mu + \sigma z}$는 $z$의 상대오차를 $\lvert\sigma z\rvert$배로 키워요. $\sigma = 10$, $z = -15$면 150배예요.

그런데 분위수 자체의 조건수(확률 $p$를 상대 $\varepsilon$만큼 움직였을 때 $z$가 움직이는 상대 크기)는 꼬리에서 $1/\lvert z\rvert$ 정도뿐이에요. 문제는 함수가 아니라 계산 순서에 있다는 뜻이에요. 그래서 $z$를 double-double로 다듬어 넘겨요.

### 작은 쪽 확률의 로그에서 한 걸음

다듬는 방법은 작은 쪽 확률 $q = \min(p, 1 - p)$의 **로그**에서 뉴턴 한 걸음을 밟는 거예요. $\log\Phi$의 도함수가 $\varphi/\Phi$이므로

$$
z \leftarrow z + \frac{\log q - \log\Phi(z)}{(\varphi/\Phi)(z)}
$$

이에요. 로그에서 하는 이유는 꼬리에서 $\Phi$와 $\varphi$가 언더플로해도 그 로그와 비는 멀쩡하기 때문이에요. 이 걸음이 제대로 되려면 $\log\Phi(z)$가 $\log q$와 같은 정밀도여야 해요. 그런데 꼬리의 $\log\Phi(z) \approx -z^2/2$는 크기가 수백이라 double로는 몇 ULP의 절대오차가 결과를 흔들어요. 그래서 $z \le -1$에서는 $-z^2/2$를 `two_prod`로 정확히 두고 나머지만 double로 계산해요.

$$
\log\Phi(z) = -\frac{z^2}{2} + \log\!\left(\tfrac12\operatorname{erfcx}\!\left(-z/\sqrt2\right)\right), \qquad
\frac{\varphi}{\Phi}(z) = \frac{2}{\sqrt{2\pi}\,\operatorname{erfcx}(-z/\sqrt2)}
$$

둘째 항은 크기가 $\log\lvert z\rvert$뿐이라 double로 충분해요. 기울기도 $\varphi$와 $\Phi$의 지수 $-z^2/2$를 손으로 지운 꼴이에요(부동소수점에서 두 지수를 따로 계산해 빼면 큰 $\lvert z\rvert$에서 자릿수를 잃어요).

```cpp
// csrc/stats/dist/normal.hpp
inline DD log_ndtr_dd(double z) {
    return num::dd::two_prod(z, z) * -0.5 + std::log(0.5 * special::Erfcx::f(-z * special::kSqrtHalf));
}

inline DD quantile_small(double q, DD lq, bool flip) {
    const double z = q >= 0x1p-1000 ? ndtri(q) : special::NdtriExp::f(lq.hi);  // <= 0
    if (std::isinf(z)) return {flip ? -z : z, 0.0};
    DD lz;
    if (z <= -1.0) lz = log_ndtr_dd(z);
    else lz = {log_ndtr(z), 0.0};
    const double slope = z <= -1.0 ? 2.0 * num::kInvSqrt2Pi / special::Erfcx::f(-z * special::kSqrtHalf)
                                   : std::exp(-0.5 * z * z - num::kLogSqrt2Pi.hi - lz.hi);
    const DD d = lq - lz;
    const DD zz = num::dd::quick_two_sum(z, (d.hi + d.lo) / slope);
    return flip ? -zz : zz;
}
```

$\log q$와 $\log\Phi(z)$는 각자 자기 크기의 1 ULP 안이고 기울기는 약 $\lvert z\rvert$이므로, 걸음 뒤 $z$의 오차는 ULP$/\lvert z\rvert$ 정도예요. $q$가 $2^{-1000}$ 아래면 $q$ 자체가 비트를 잃었으므로 그 로그($\log q$, double-double)에서 출발점을 `ndtri_exp`로 구해요([ndtri_exp](/internals/special/distributions/)). `ilogcdf`도 같은 함수로 와요. $\log p > -\log 2$이면 다른 쪽 $1 - e^{\log p} = -\operatorname{expm1}(\log p)$가 작은 쪽이에요.

마지막으로 $x = \mu + \sigma z$를 `two_prod(sigma, z.hi) + sigma * z.lo + mu`의 double-double로 만들어 한 번 반올림해요(`locate`). 로그정규는 같은 double-double 지수를 `exp_dd`로 지수화해요(`from_z`). $\sigma z$가 넘치면 반씩 나눠 계산하고 두 배 해요.

### 언제 건너뛰나

한 걸음은 공짜가 아니에요(`erfcx`와 `log` 한 번씩). `ndtri`의 몇 ULP가 결과에서 커지지 않는 곳에서는 건너뛰어요.

```cpp
// csrc/stats/dist/normal.hpp
inline bool needs_step(double mu, double sigma, double z) {
    return std::fabs(sigma * z) > 4.0 * std::fabs(std::fma(sigma, z, mu)) || std::fabs(z) > 30.0;
}
```

증폭 $\lvert\sigma z/x\rvert$가 4 이하이면 `ndtri`의 몇 ULP가 많아야 네 배라서 `fma(sigma, z, mu)` 하나로 계약의 $10^{-14}$ 안이에요. 로그정규는 $\sigma\lvert z\rvert \le 4$일 때만 건너뛰어요.

```python
>>> sd.stats.LogNormal(sigma=10.0).icdf(1e-50)
1.3974591526236186e-65
```

$z = -14.93$이라 지수는 $-149$예요. Arb로 $\Phi^{-1}$을 정확히 풀어 만든 참값과 같아요. `exp(10 * ndtri(1e-50))`과 scipy 1.18.1의 `lognorm.ppf(1e-50, 10)`은 둘 다 $2.2 \times 10^{-14}$가 틀려요.

### 닫힌 꼴 분포의 역함수

닫힌 꼴 분포도 같은 생각으로 작은 쪽에서, 반올림을 피하는 꼴로 역함수를 만들어요.

| 분포 | `icdf(p)`의 계산 |
|---|---|
| 지수 | $-s\operatorname{log1p}(-p)$, `iccdf`는 $-s\log p$, `ilogcdf`는 $\log p < -700$이면 $s e^{\log p}$를 지수 안에서 |
| 균등 | $p \le \tfrac12$이면 `fma(p, w, a)`, 위는 `fma(-q, w, b)`($q = 1 - p$ 정확). 너비가 넘치면 반으로 |
| 라플라스 | $z = \log 2p$ 또는 $-\log 2(1 - p)$, 작은 쪽에서 |
| 코시 | $p \lt \tfrac14$이면 $z = -1/\tan(\pi p)$, $p \lt 10^{-300}$이면 $\sigma/(\pi p)$를 먼저 나눠서 |
| 베이불 | $x = s\exp(\log t/c)$, $\log t$는 $\log(-\log(1 - p))$의 double-double |

베이불의 $\log t$는 $p$에 따라 다른 꼴이에요. $p > \tfrac12$이면 $\log(-\log(1 - p))$에서 $1 - p$가 정확하고, $p \lt 2^{-60}$이면 $-\log(1 - p) = p + p^2/2 + \cdots$라 $\log t = \log p + p/2$예요. 나눗셈 $\log t / c$도 double-double이고(`num::div`), $\lvert\log t/c\rvert \ge 700$이면 $\log s$를 지수에 더해 한 번에 지수화해요. 근 자체가 서브노멀이어도 척도를 곱한 결과는 정규수일 수 있기 때문이에요.

## 작은 쪽 꼬리를 직접

`ccdf`는 $1 - \text{cdf}$가 아니에요. $1 - \text{cdf}$로 만들면 cdf가 $1 - 10^{-20}$일 때 결과가 통째로 0이 되고, $1 - 10^{-10}$일 때도 cdf의 반올림($10^{-16}$)이 꼬리의 $10^{-6}$이 돼요. 그래서 모든 분포가 이 규칙을 지켜요.

- **두 꼬리 중 작은 쪽을 직접 계산해요.** 큰 쪽은 $1 - \text{작은 쪽}$이에요. 작은 쪽이 $\tfrac12$ 이하라 빼기가 자릿수를 잃지 않아요.
- **log도 같아요.** 작은 쪽의 log는 $\log(\text{작은 쪽})$, 큰 쪽의 log는 $\operatorname{log1p}(-\text{작은 쪽})$이에요.

| 분포 | 작은 쪽 꼬리 |
|---|---|
| 정규·로그정규 | $\Phi(-\lvert z\rvert)$ (`ndtr`) |
| 지수 | 위 $e^{-y}$, 아래 $-\operatorname{expm1}(-y)$ |
| 라플라스 | $\tfrac12 e^{-\lvert z\rvert}$ |
| 코시 | $z \lt -1$이면 $\arctan(-1/z)/\pi$, 그 밖 $\tfrac12 + \arctan(z)/\pi$ |
| 베이불 | 위 $e^{-t}$, 아래 $-\operatorname{expm1}(-t_{hi}) + e^{-t_{hi}}t_{lo}$ |
| 균등 | $(x - a)/w$ 또는 $(b - x)/w$ |
| 감마·베타·t·F | special이 $(P, Q)$나 $(I, 1 - I)$의 작은 쪽을 직접 계산한 쌍 |

코시는 $\lvert z\rvert > 10^{150}$이면 작은 쪽이 마지막 비트까지 $1/(\pi\lvert z\rvert)$라서 $\sigma/\lvert x - \mu\rvert$에서 바로 만들어요. 이 값은 $z$ 자체가 double을 넘어도 있어요. $x - \mu$가 넘치면 반씩 나눠 $\sigma/\lvert x - \mu\rvert$를 만들어요.

```python
>>> X = sd.stats.Cauchy()
>>> X.cdf(-1e10)
3.183098861837907e-11
>>> 1.0 - X.ccdf(-1e10)
3.183098229442294e-11
>>> X.logcdf(-1e305)
-703.4331832490333
```

빼서 만든 둘째 값은 앞 일곱 자리만 맞아요. 셋째는 꼬리 자체($3 \times 10^{-306}$)는 아직 double이지만, 그 아래로 가도 같은 식($-\log\lvert z\rvert - \log\pi$)으로 log가 나와요.

log 꼬리의 큰 쪽에도 함정이 하나 있어요. 베이불의 아래꼬리 $1 - e^{-t}$는 $t \lt 2^{-60}$이면 그 log가 $\log t - t/2 + \cdots$인데, $\log t = E$는 이미 double-double로 있어요. 그래서 $1 - e^{-t}$를 만들지 않고 $E - t/2$를 돌려줘요. 지수분포의 $\log(1 - e^{-y})$도 $y \lt 2^{-60}$이면 $\log x - \log s$예요(몫 $x/s$가 서브노멀일 수 있기 때문이에요).

## 깊은 log 꼬리

꼬리가 double의 정규수 아래($2^{-1022}$, 서브노멀이면 비트가 줄어요)로 내려가면 그 log를 값에서 얻을 수 없어요. 값이 0이면 log는 $-\infty$가 되고, 서브노멀이면 비트 수만큼만 맞아요. 그런데 `logcdf`의 계약은 상대 $10^{-14}$예요. 그래서 분포마다 값을 거치지 않고 **log를 조각에서 직접** 만들어요. 감마·베타는 경계를 $2^{-1000}$, $2^{-960}$ 같은 여유 있는 문턱에 둬요.

### 정규: log_ndtr

정규분포는 special의 `log_ndtr`가 이미 이 일을 해요. $z \lt -1$에서 $\log\Phi(z) = -z^2/2 + \log(\tfrac12\operatorname{erfcx}(-z/\sqrt2))$로 언더플로 없이 계산해요([오차함수와 감마](/internals/special/erf-gamma/)). stats는 여기에 $z_{lo}$의 1차 보정만 더해요.

### 감마: 앞 인자의 지수와 급수·연분수의 log

불완전 감마는 "앞 인자 × 1 근처의 인수"예요([불완전 감마와 베타](/internals/special/incomplete/)).

$$
P(a, y) = D \cdot s, \qquad s = \sum_{n \ge 0} \frac{y^n}{(a+1)(a+2)\cdots(a+n)}, \qquad
Q(a, y) = \frac{aD}{\text{tail}}
$$

$D = y^a e^{-y}/\Gamma(a+1)$이고 tail은 Legendre 연분수 $y + 1 - a - \cfrac{1\cdot(1-a)}{y + 3 - a - \cdots}$의 값이에요. 앞 인자 $D$는 Stirling 꼴로 쓰면

$$
D = \frac{e^{-E}}{\sqrt{2\pi a}\,\Gamma^*(a)}, \qquad E = y - a - a\log\frac{y}{a} \ \ge 0
$$

이고, $\Gamma^*(a) = \Gamma(a)/(\sqrt{2\pi/a}\,(a/e)^a)$는 1 근처의 값이에요. 값이 언더플로하는 것은 $e^{-E}$ 때문뿐이에요. 그래서 log는

$$
\log P = -E - \log\!\big(\sqrt{2\pi a}\,\Gamma^*(a)\big) + \log s, \qquad
\log Q = -E - \log\!\big(\sqrt{2\pi a}\,\Gamma^*(a)\big) + \log\frac{a}{\text{tail}}
$$

이고, $E$는 double-double, 나머지는 크기가 작은 double이에요. special의 `igam_detail::log_tail`이 이것을 계산해요. 역함수의 깊은 반복이 쓰려고 만든 함수라서 목표 $\log t$를 받아 $\log(F/t)$를 돌려줘요. $E$와 $\log t$는 둘 다 $-740$ 근처일 수 있어서, 둘을 double-double로 먼저 빼고 나서 작은 항들을 더해요.

```cpp
// csrc/special/ops/incgamma.hpp
inline std::array<double, 2> log_tail(double a, double x, bool lower, dd::DD lt) {
    const dd::DD E = gamma_exponent(a, x);
    const dd::DD lr = -E - lt;
    const double ld = lr.hi + (lr.lo - std::log(std::sqrt(2.0 * kPi * a) * gamma_star(a)));
    if (lower) {
        double sum = 1.0, term = 1.0, ap = a;
        bool ended = false;
        for (int n = 0; n < kMaxTerms; ++n) {
            ap += 1.0;
            term *= x / ap;
            sum += term;
            if (term <= sum * 0x1p-56) {
                ended = true;
                break;
            }
        }
        if (!ended) return {kNaN, kNaN};
        return {ld + std::log(sum), a / (x * sum)};
    }
    // ... the continued fraction for tail, then ld + log(a / tail), and Q'/Q = -tail / x
}
```

둘째 반환값은 로그 도함수($P'/P$나 $Q'/Q$)예요. stats의 `logcdf`는 이것으로 $y_{lo}$의 1차 보정을 해요.

```cpp
// csrc/stats/dist/gamma.hpp (log_tail)
if (upper == !lower_small) {  // the small side is asked for
    if (small >= 0x1p-1000) return std::log(small);
    const auto [l, dl] = special::igam_detail::log_tail(a, y.hi, lower_small, DD{0.0, 0.0});
    return l + dl * y.lo;
}
return std::log1p(-small);
```

둘 다 Arb 참값(정칙화 불완전 감마의 log)과 같은 double이에요. scipy 1.18.1의 `gamma.logsf`, `gamma.logcdf`는 둘 다 $-\infty$예요. $y \lt 2^{-960}$이면 $y$의 double-double이 이미 비트를 잃었으므로 주항 $\log P = a\log y - \log\Gamma(a+1)$을 $\log y = \log x - \log s$에서 바로 만들어요(다음 항은 $ay/(a+1)$배라 아무것도 아니에요).

### 베타·t·F: 단위 접두로 비율만 얻기

불완전 베타 $I_x(a, b)$를 계산하는 special의 `ibeta`는 DiDonato와 Morris의 BRATIO(ACM TOMS 708)[1]의 구조를 따라요. 다섯 방법 가운데 셋이 깊은 꼬리에 관계해요. 모두 **앞 인자 $\mathcal B$ × 1 근처의 인수**라는 점이 핵심이에요.

$$
\mathcal B(a, b, x) = \frac{x^a y^b}{B(a, b)} = \text{factor}(a, b)\cdot e^{-E}, \qquad
E = a\,\mu\!\left(\tfrac{x(a+b)}{a} - 1\right) + b\,\mu\!\left(\tfrac{y(a+b)}{b} - 1\right), \quad \mu(t) = t - \log(1 + t)
$$

$y = 1 - x$이고, factor는 $\sqrt{ab/(2\pi(a+b))}\,\Gamma^*(a+b)/(\Gamma^*(a)\Gamma^*(b))$처럼 크기가 작은 값이에요. 감마와 마찬가지로 언더플로는 $e^{-E}$에만 있어요.

- **BPSER(거듭제곱급수).** $I_x(a, b) = \int_0^x t^{a-1}(1 - t)^{b-1}dt/B$에서 $(1 - t)^{b-1}$을 이항급수로 펼쳐 항마다 적분하면
  $$
  I_x(a, b) = \frac{x^a}{a\,B(a, b)}\sum_{n \ge 0}\frac{(1 - b)_n}{n!}\,\frac{a}{a + n}\,x^n
  $$
  이에요. 항의 비가 대략 $(n - b)x/n$이라 $x$가 작거나 $b \le 1$이면 빨리 수렴해요. 앞 인자로 쓰면 $I = \mathcal B \cdot y^{-b}\cdot\sum/a$예요.
- **BFRAC(연분수).** $I_x(a, b) = \mathcal B/(\beta_0 + \alpha_1/(\beta_1 + \alpha_2/(\beta_2 + \cdots)))$예요. $x$가 평균 $a/(a+b)$ 아래이면 빨리 수렴하고, $\beta_0 = a(\lambda + 1)/(a + 1) \ge \tfrac12$($\lambda = a - (a+b)x \ge 0$)이라 첫 분모가 0에 가까워지지 않아요.
- **BGRAT(감마 극한 둘레의 전개).** $a$가 크고 $b$가 작으면 질량이 $x = 1$ 바로 아래 폭 $1/a$에 몰리고, $a(1 - X)$는 모양 $b$인 감마 분포에 가까워져요. 그래서 $\nu = a + (b - 1)/2$, $z = -\nu\log x$로 두면
  $$
  I_x(a, b) = G\Big(Q(b, z) + \sum_{n \ge 1} d_n J_n\Big), \qquad G = \frac{\Gamma(a + b)}{\Gamma(a)\,\nu^b}
  $$
  이고 $J_n$은 $r = z^b e^{-z}/\Gamma(b)$에서 시작하는 점화식, $d_n$은 계수 점화식이에요. 첫 항이 감마 극한이고 나머지는 $1/\nu$의 거듭제곱으로 줄어드는 보정이에요.

세 방법의 세부(고르는 규칙, 앞 인자를 만드는 법, 수렴의 문턱)는 [불완전 감마와 베타](/internals/special/incomplete/)에 있어요.

stats가 더한 것은 **앞 인자를 1로 주는 것**이에요. special의 `bpser`와 `bfrac`는 앞 인자를 `Scaled`($m\cdot2^e$)로 받아 인수와 곱해요. 여기에 `scaled(1.0)`을 넘기면 결과는 인수 $I/\mathcal B$만 남아요. 그러면

$$
\log I = \underbrace{-E + \log\text{factor}(a, b)}_{\text{double-double}} + \log\frac{I}{\mathcal B}
$$

이고 어느 쪽도 언더플로하지 않아요.

```cpp
// csrc/stats/dist/beta.hpp
inline double log_lower_deep(double a, double b, DD x, DD y) {
    if (b <= 1.0 && a > 15.0 && y.hi < 1e-3) return special::ibeta_detail::log_bgrat(a, b, x, y);
    // BPSER's series in x stops at its cap for x next to 1; with b below the measured shapes
    // (1e-2) a deep tail there was 9e-4 off (a = 1, b = 1e-300, x = 1 - 1e-10): NaN
    if (b < 1e-3 && x.hi > 0.9) return kNaN;
    const special::Scaled unit = special::scaled(1.0);
    double ratio = (a > 1.0 && b > 1.0) ? special::ibeta_detail::bfrac(a, b, x, y, unit)
                                        : special::ibeta_detail::bpser(a, b, x, y, unit);
    // BFRAC's fraction gives NaN for shapes far beyond the guaranteed range (a = 1e281); the
    // power series does not, and for a small x it is a few terms
    if (!(ratio > 0.0 && std::isfinite(ratio)) && x.hi < 0.25) ratio = special::ibeta_detail::bpser(a, b, x, y, unit);
    if (!(ratio > 0.0 && std::isfinite(ratio))) return kNaN;
    const DD l = log_prefix(a, b, x, y);
    return l.hi + (l.lo + std::log(ratio));
}
```

고르는 규칙은 TOMS 708의 것을 따라요. $a, b > 1$이면 평균 아래에서 연분수, 그 밖은 급수예요. 예외가 BGRAT예요. $x$가 1에 붙으면($y \lt 10^{-3}$) BPSER의 급수는 $x^n$이 천천히 줄어서 약 $40/(1 - x)$항이 필요하고, 상한 $10^5$항에 걸려요. 음이항 분포의 `logccdf`가 바로 이 자리($k = 3.4 \times 10^7$, $p = 1.2 \times 10^{-4}$)를 지나서 BPSER로 계산하면 $7 \times 10^{-10}$이 틀려요. 그래서 $a > 15$, $b \le 1$, $y \lt 10^{-3}$이면 TOMS 708처럼 BGRAT를 써요. 문턱 위에서는 BPSER를 그대로 둬요. t의 깊은 꼬리($y \sim 2 \times 10^{-3}$)에서 잰 오차가 BPSER $2 \times 10^{-16}$, BGRAT $4 \times 10^{-16}$이었기 때문이에요.

BGRAT의 log판(`log_bgrat`)은 $Q(b, z)$가 언더플로하는 곳을 위한 거예요. $Q$와 $r$을 각자 log로 구하고(감마의 `log_tail`과 Stirling 꼴의 $\log r$), 급수를 $Q$로 나눈 배율에서 더해요.

$$
\log I = \log Q + \log G + \log\Big(1 + \frac{1}{Q}\sum_{n \ge 1} d_n J_n\Big)
$$

급수의 점화식은 $(Q, r)$에 대해 선형이라 $(1, r/Q)$를 넣어도 그대로 돌아요.

```cpp
// csrc/special/ops/incbeta.hpp
inline double log_bgrat(double a, double b, dd::DD x, dd::DD y) {
    const BgratArgs g = bgrat_args(a, b, x, y);
    const dd::DD z = g.z;
    if (!(z.hi > 0.0)) return -kInf;
    const auto [lq0, dlq] = igam_detail::log_tail(b, z.hi, false, dd::DD{0.0, 0.0});
    const double lq = lq0 + z.lo * dlq;
    const dd::DD Ez = gamma_exponent(b, z.hi) + (z.lo - b * (z.lo / z.hi));
    const double lr = std::log(b) - Ez.hi - (Ez.lo + std::log(std::sqrt(2.0 * kPi * b) * gamma_star(b)));
    const double sum = bgrat_series(b, g, 1.0, std::exp(lr - lq), 0.0);
    return lq + (std::log(bgrat_g(a, b, g.nu.hi)) + std::log(sum));
}
```

### t: 인자마저 언더플로할 때의 주항

t 분포의 꼬리는 $P(T \le t) = \tfrac12 I_x(\tfrac{\nu}{2}, \tfrac12)$, $x = \nu/(\nu + t^2)$예요. $x$와 $1 - x = t^2/(\nu + t^2)$는 special의 `t_arg`가 입력에서 따로 double-double로 만들어요(`stdtr`과 같아요). 그런데 $\lvert t\rvert$가 아주 크면 $x$ 자체가 double 아래로 내려가요. 그때는 BPSER의 첫 항만 남아요.

$$
\log P(T \le t) = \frac{\nu}{2}\log x - \log\frac{\nu}{2} - \log B\!\left(\tfrac{\nu}{2}, \tfrac12\right) - \log 2 + O(x), \qquad
\log x = -\log\!\left(1 + \frac{t^2}{\nu}\right)
$$

$\log(1 + t^2/\nu)$는 $t^2$이 넘치는 곳에서도 $2\log\lvert t\rvert - \log\nu + \operatorname{log1p}(\nu/t^2)$로 만들어요(`log1p_t2`). `stdtr`의 값이 $2^{-960}$ 이상이면 그 log를 쓰고, 그 아래에서 $\log x \lt -620$($x \lt 10^{-270}$)이면 이 주항을, 아니면 베타의 `log_lower_deep`을 써요.

```python
>>> sd.stats.StudentT(df=3.0).logcdf(-1e200)
-1381.4533323573828
>>> sd.stats.StudentT(df=1e-50).cdf(-1e300)
0.5
```

둘째는 보장 범위 밖이지만 주항이 왜 필요한지 보여요. 자유도가 아주 작으면 꼬리가 아주 무거워서 $t = -10^{300}$에서도 확률이 거의 $\tfrac12$예요. 그런데 $x = 10^{-650}$은 double 아래라 special의 `stdtr`은 0을 내요. 그래서 cdf도 $x \lt 2^{-960}$(`far`)이면 주항의 지수에서 만들어요. scipy 1.18.1은 0.0이에요.

$\log B(a, \tfrac12)$에는 함정이 하나 있어요. 큰 $a$에서 $\log\Gamma(a) - \log\Gamma(a + \tfrac12)$는 크기 $a\log a$인 두 항의 차라서, double-double로 빼도 $\log\Gamma$의 정확도가 문제예요. special의 `dd::log`는 지수화에 맞춘 함수라 정확도가 약 $2^{-64}$(잰 최악 $10^{-23}$)이고, $df = 10^{14}$에서는 그 오차가 결과의 $10^{-12}$가 돼요. 그래서 $a \ge 12$이면 큰 항을 손으로 지운 꼴을 써요.

$$
L(a) = \log\Gamma(a + \tfrac12) - \log\Gamma(a) - \tfrac12\log a
= \left(a\operatorname{log1p}(u) - \tfrac12\right) + S(a + \tfrac12) - S(a), \qquad u = \frac{1}{2a}
$$

$S$는 Stirling 급수 $\sum B_{2k}/(2k(2k-1)z^{2k-1})$이고, 두 $S$의 차는 항마다 $a^{1-2k}\operatorname{expm1}((1 - 2k)\operatorname{log1p}(u))$로 빼요. $a\operatorname{log1p}(u) - \tfrac12 = (2au - 1)/2 - a\mu(u)$도 상쇄 없는 꼴이에요(`big_l`). 결국 $\log B(a, \tfrac12) = \log\sqrt\pi - L(a) - \tfrac12\log a$예요.

### F: 작은 인자와 카이제곱 극한

F의 베타 인자는 $w = d_1x/(d_1x + d_2)$와 $v = 1 - w$예요. 이 중 하나가 $2^{-1000}$ 아래이면 double-double로 만든 값 자체가 서브노멀로 반올림됐거나 0이라서, 그 log를 입력에서 바로 만들어요($\log w = \log d_1 + \log x - \log d_2$). 그다음 special의 `ibeta_tiny`(작은 인자에서 거듭제곱으로 내려가는 갈래)로 쌍을 얻고, 아래꼬리가 double 아래면 주항 $I = w^a/(aB(a, b))$를 log로 써요. 다른 쪽 모양이 $2^{900}$ 이상이면 분포가 카이제곱 극한에 붙으므로 감마의 log 꼬리를 써요(`limit_log_tail`). $w$를 반올림해 넘기면 서브노멀 인자의 몇 비트만 남아서, log 꼬리가 그 비트 수만큼만 맞아요.

## 깊은 역함수

역함수도 같은 이유로 log 쪽에서 풀어야 하는 곳이 있어요. 두 경우예요.

- **확률이 $2^{-1000}$ 아래.** 확률 자체가 비트를 잃었으므로 그 log(double-double)를 목표로 삼아요.
- **근이 아주 작음.** 주항으로 어림한 근의 log가 $-40$ 아래($x \lt 4 \times 10^{-18}$)예요. special의 역함수는 근을 float64로 다루므로, 근이 아주 작으면 척도를 곱하기 전에 이미 비트를 잃어요.

어림은 아래꼬리의 주항에서 나와요. 감마는 $P \approx y^a/\Gamma(a + 1)$, 베타는 $I \approx x^a/(aB(a, b))$라서 근의 log는 $(\log p + \log\Gamma(a+1))/a$나 $(\log p + \log a + \log B)/a$예요.

```cpp
// csrc/stats/dist/beta.hpp (lower_root)
if (p >= kDeepP) {
    const double est = (lt.hi + std::log(a) + special::Betaln::f(a, b)) / a;  // log of the leading-term root
    if (est > -40.0) return {special::Betaincinv::f(a, b, p), DD{kNaN, 0.0}};
}
const DD lx = deep_log_inverse(a, b, lt);
return {num::exp_dd(lx), lx};
```

### 감마: deep_inverse

감마의 깊은 역함수는 목표 $\log t$(double-double)와 special의 `log_tail`로 뉴턴을 돌려요. 아래꼬리는 근이 아주 작으므로 $\log y$에서, 위꼬리는 근이 크므로 $y$에서 걸어요.

- **아래꼬리의 닫힌 꼴.** $P = \frac{y^a}{\Gamma(a+1)}\left(1 - \frac{ay}{a+1} + O(y^2)\right)$이므로
  $$
  \log y = \frac{\log t + \log\Gamma(a + 1)}{a} + \frac{y}{a + 1}
  $$
  이에요. $y \lt 10^{-9}$이면 둘째 항이 1차 보정으로 충분하고 셋째 항은 $2^{-60}$ 아래라 반복 없이 끝나요. 척도 $s$는 $\log s$로 지수에 더해서 `exp_dd` 한 번에 $sy$를 만들어요. $y$가 서브노멀이어도 $sy$는 정규수일 수 있기 때문이에요.
- **뉴턴.** 그 밖은 아래꼬리면 $y \leftarrow y\exp(-g/(y\,\partial_y\log P))$, 위꼬리면 $y \leftarrow y - g/\partial_y\log Q$($g = \log(F/t)$)예요. 위꼬리의 출발점은 $Q \approx y^{a-1}e^{-y}/\Gamma(a)$의 고정점 $y = -\log(t\,\Gamma(a)) + (a - 1)\log y$를 8번 돌린 값이에요.
- **상한.** 100걸음 안에 걸음이 $2^{-54}$ 아래로 떨어지면 끝이에요. 마지막 비트에서 순환하는 경우($2^{-48}$ 안)도 끝난 것으로 쳐요. 그 밖은 NaN이에요. 수렴하지 않은 마지막 반복값을 내지 않아요.

```python
>>> sd.stats.Gamma(a=3.0).ilogcdf(-2000.0)
5.366969756080818e-290
>>> sd.stats.Gamma(a=2.5).ilogccdf(-5000.0)
5012.495150022815
```

Arb로 이 근에서 정칙화 불완전 감마의 log를 계산해 목표와의 차를 근의 상대오차로 바꾸면 $7.5 \times 10^{-17}$과 $2.7 \times 10^{-17}$이에요. 첫째는 scipy 1.18.1의 `gamma.ppf(exp(-2000), 3)`이 0이에요($e^{-2000}$이 0으로 언더플로해요).

### 베타·t·F: deep_log_inverse

베타의 깊은 역함수는 처음부터 $\log x$를 풀어요.

- **급수.** $I = \frac{x^a}{aB(a, b)}(1 + cx + O(x^2))$, $c = a(1 - b)/(a + 1)$이므로 $\log x = (\log t + \log a + \log B)/a - cx/a$예요. $\lvert c\rvert x \lt 10^{-9}$이면 이것으로 끝이에요.
- **뉴턴.** 그 밖은 $\log x$에서 $\log I$에 대해 뉴턴을 돌려요. 기울기 $d\log I/d\log x = xf/I = \mathcal B/(yI)$는 앞 인자의 log에서 나와서, $I$가 double 아래여도 계산돼요. $\log I$는 위의 `log_lower_deep`이에요.
- **멈춤.** 걸음이 $2^{-54}\max(1, \lvert\log x\rvert)$ 아래가 되면 끝이에요. $\log x$ 자체의 간격이 그 $2^{-52}$배이고, $\log I$의 반올림 때문에 걸음이 그보다 훨씬 작아지지는 않아요. 100걸음 안에 거기 닿지 않으면 마지막 걸음이 $2^{-48}\max(1, \lvert\log x\rvert)$ 이하일 때만 근으로 받고, 아니면 NaN이에요. 감마의 깊은 역함수처럼 수렴하지 않은 값은 내지 않아요.

```cpp
// csrc/stats/dist/beta.hpp (deep_log_inverse의 뉴턴)
double lx = lx0.hi, step = kInf;
for (int it = 0; it < 100; ++it) {
    const double x = std::exp(lx);
    const DD xd{x, 0.0}, yd = dd::two_sum(1.0, -x);
    const double li = log_lower_deep(a, b, xd, yd);
    const DD lp = log_prefix(a, b, xd, yd);
    const double slope = std::exp(lp.hi - std::log(yd.hi) - li);
    const DD g = DD{li, 0.0} - lt;
    step = (g.hi + g.lo) / slope;
    lx -= step;
    if (std::fabs(step) <= 0x1p-54 * std::max(1.0, std::fabs(lx))) return DD{lx, 0.0};
}
if (!(std::fabs(step) <= 0x1p-48 * std::max(1.0, std::fabs(lx)))) return DD{kNaN, 0.0};
return DD{lx, 0.0};
```

t와 F는 베타 인자 $x$와 $1 - x$의 비로 원래 변수로 돌아가요.

$$
t = -\sqrt{\nu\,\frac{1 - x}{x}}, \qquad F = \frac{d_2}{d_1}\cdot\frac{w}{v}
$$

그래서 $\log x$와 함께 $\log(1 - x)$가 필요해요. 근이 $\tfrac12$ 아래면 $\log(1 - x) = \log(-\operatorname{expm1}(\log x))$로 충분해요($x \lt 2^{-60}$이면 $-x$). 근이 1에 가까우면 그렇지 않아요. 뉴턴은 $\log x$를 그 크기의 $2^{-54}$까지만 맞추는데, $\lvert\log x\rvert \approx 1 - x$가 작으니 이 절대오차가 $1 - x$에서는 상대 $2^{-54}/\lvert\log x\rvert$가 돼요. t의 근이 분포의 가운데에 가까운 곳, 곧 큰 자유도의 깊은 꼬리가 그래요. $\nu = 10^6$, $p \approx 10^{-305}$이면 $x = 1 - 1.4 \times 10^{-3}$이라, $\log x$에서 $1 - x$를 만들면 t가 $1.6 \times 10^{-14}$ 틀려요.

그래서 $x \gt \tfrac12$이면 $y = 1 - x$의 log에서 뉴턴을 한 번 더 돌려요(`deep_log_inverse_both`). 기울기는 $d\log I/d\log y = -(xf/I)(y/x) = -\mathcal B/(xI)$이고, 멈춤 규칙은 $\log y$에 대해 같아요. 그다음 $\log x$는 $1 - e^{\log y}$의 double-double log예요.

```cpp
// csrc/stats/dist/beta.hpp
inline LogPair deep_log_inverse_both(double a, double b, DD lt) {
    const DD lx = deep_log_inverse(a, b, lt);
    if (!(lx.hi == lx.hi)) return {lx, lx};
    if (lx.hi < -num::kLn2.hi) {  // x < 1/2: 1 - x is well defined from log x
        const double x = std::exp(lx.hi);
        return {lx, x < 0x1p-60 ? DD{-x, 0.0} : num::log_dd(-std::expm1(lx.hi))};
    }
    double ly = std::log(-std::expm1(lx.hi)), step = kInf;
    for (int it = 0; it < 100; ++it) {
        const double y = std::exp(ly);
        const DD yd{y, 0.0}, xd = dd::two_sum(1.0, -y);
        const double li = log_lower_deep(a, b, xd, yd);
        const DD lp = log_prefix(a, b, xd, yd);
        const double slope = -std::exp(lp.hi - std::log(xd.hi) - li);
        const DD g = DD{li, 0.0} - lt;
        step = (g.hi + g.lo) / slope;
        ly -= step;
        if (std::fabs(step) <= 0x1p-54 * std::max(1.0, std::fabs(ly))) {
            step = 0.0;
            break;
        }
    }
    if (!(std::fabs(step) <= 0x1p-48 * std::max(1.0, std::fabs(ly)))) return {DD{kNaN, 0.0}, DD{kNaN, 0.0}};
    return {dd::log(dd::two_sum(1.0, -std::exp(ly))), DD{ly, 0.0}};
}
```

t는 $\tfrac12(\log\nu - \log x + \log(1 - x))$의 double-double을 지수화해서 만들고, F는 $\log w - \log v + \log d_2 - \log d_1$의 지수예요.

```cpp
// csrc/stats/dist/t_f.hpp (StudentT의 깊은 역함수)
const beta_detail::LogPair r = beta_detail::deep_log_inverse_both(a, 0.5, lt + num::kLn2);
return -num::exp_dd((num::log_dd(df) - r.lx + r.ly) * 0.5);
```

## 작은 모양의 불완전 베타와 감마의 유한합

### a, b ≤ 6: Boost의 불완전 베타

special의 `betainc`·`betaincc`는 두 모양이 6 이하이면 Boost.Math의 `ibeta`·`ibetac`을 불러요. 그 구간에서 Boost가 계약을 지키면서 더 빠르기 때문이에요([불완전 감마와 베타](/internals/special/incomplete/)). 베타 분포의 cdf·ccdf도 이 구간에서 같은 함수를 직접 불러요. 입력 $x$를 그대로 넘기므로 들어가는 길에 반올림이 없어요. 결과가 $2^{-960}$ 아래면 Boost의 값을 버리고 double-double `ibeta`로 다시 계산해요. 서브노멀 바로 위에서는 Boost의 중간값이 서브노멀로 떨어져 자릿수를 잃기 때문이에요.

log 꼬리도 작은 쪽을 먼저 골라요. 평균 $a/(a+b)$를 보고 작아 보이는 쪽을 계산하고, 그 값이 $\tfrac12$을 넘으면 다른 쪽을 계산해요.

```cpp
// csrc/stats/dist/beta.hpp (Beta::log_tail)
if (small_shapes(a, b)) {
    bool lower_small = x * (a + b) < a;
    double small = lower_small ? special::Betainc::f(a, b, x) : special::Betaincc::f(a, b, x);
    if (small > 0.5) {
        lower_small = !lower_small;
        small = lower_small ? special::Betainc::f(a, b, x) : special::Betaincc::f(a, b, x);
    }
    if (small >= beta_detail::kDeep) return upper != lower_small ? std::log(small) : std::log1p(-small);
}
return beta_detail::log_tail(a, b, num::DD{x, 0.0}, num::dd::two_sum(1.0, -x), upper);
```

F의 log 꼬리도 같은 이유로 두 자유도가 12 이하이면 `fdtr`·`fdtrc`의 값에서 만들어요(special이 그 구간에서 Boost를 불러요. 베타 모양은 자유도의 절반이에요). 먼저 계산할 쪽은 $x \lt 1$이면 아래꼬리예요.

### 빠른 역함수: Boost의 betainc 위의 Halley

special의 `betaincinv`는 double-double `ibeta`와 그 도함수로 Halley 반복을 돌려요. 평가 한 번이 무거운 double-double 불완전 베타예요. 모양이 $[0.05, 6]$이고 목표가 $2^{-200}$ 이상이면, stats는 같은 반복을 Boost의 `betainc`·`betaincc` 위에서 돌려요(`fast_root`).

1. **같은 변수.** special의 역함수처럼 $p$와 $1 - p$ 중 작은 쪽을, $x$와 $1 - x$ 중 작은 쪽에서 풀어요. 출발점도 같은 AS 109[2]예요.
2. **도함수는 거칠어도 돼요.** $xF'(x) = x^a(1 - x)^{b-1}/B(a, b)$를 libm의 log로 double에서 만들어요. 도함수의 오차는 걸음이 떨어지는 곳을 2차로만 바꾸고 고정점을 바꾸지 않기 때문이에요.
3. **걸음.** $F$가 목표의 2배 안이면 Halley($F''/F' = (a-1)/x - (b-1)/(1-x)$), 멀면 $\log F$에 대한 뉴턴이에요(증가 쪽은 $\log x$에서).
4. **멈춤.** Halley는 3차 수렴이라, 걸음이 $x$의 $10^{-6}$ 아래가 되면 남는 오차는 $(a/x)^2\cdot\text{걸음}^3 \le 10^{-16}x$ 정도예요. 그래서 다시 평가하지 않고 끝내요.
5. **상한과 대비.** 8걸음 안에 끝나지 않거나, 걸음이 지금까지의 브래킷을 벗어나거나, $F$가 $2^{-960}$ 아래로 가면 실패로 돌아가 일반 경로(special의 역함수, 깊은 역함수)를 써요.

결과의 오차는 함수의 오차(Boost의 betainc)에 역함수의 조건수 $F/(xF')$를 곱한 것으로, double-double 경로와 같은 형태예요. 1스레드에서 원소 $10^5$개로 잰 원소당 시간은 `Beta(2, 3).icdf`가 169 ns(scipy 1.18.1은 387 ns), `Beta(2.5, 0.7).icdf`가 549 ns(scipy 652 ns)예요(`bench/stats/opt/b/results.md`, Apple M4 Pro). F는 $d_1/2$, $d_2/2$가 이 구간이면 같은 함수로 $w$나 $v$를 구해 $x = (d_2/d_1)\,w/v$로 돌아가요.

### 감마의 정수·반정수 모양: 유한합

$2a$가 정수이면(정수 자유도의 카이제곱이 모두 그래요) 위꼬리가 양의 항의 유한합이에요(DLMF 8.4.10, 8.4.14).

$$
Q(n, y) = e^{-y}\sum_{k \lt n}\frac{y^k}{k!}, \qquad
Q(n + \tfrac12, y) = \operatorname{erfc}(\sqrt y) + \frac{e^{-y}}{\sqrt{\pi y}}\sum_{k=1}^{n}\frac{y^k}{(\tfrac12)(\tfrac32)\cdots(k - \tfrac12)}
$$

합은 double-double Horner이고(비 $y/k$를 나눗셈의 나머지로 만들어서 $y_{hi} + y_{lo}$가 정확히 들어가요), 남는 것은 $e^{-y}$와 `erfc` 같은 libm 호출의 몇 ULP예요. 반올림을 세면 정수 모양 4, 반정수 모양 8 단위($2^{-53}$)예요. 쓰는 곳은 $a \le 30$, $a \le y \le 690$이에요. $y \ge a$면 중앙값이 평균 아래라 $Q$가 작은 쪽이고, $y \le 690$이면 $e^{-y}$가 여유 있는 정규수예요. 연분수를 돌리지 않으므로, 1스레드 원소당 시간이 `ChiSquared(7).cdf` 45 ns로 반정수가 아닌 `ChiSquared(4.5).cdf`의 107 ns보다 짧아요(scipy 1.18.1은 각각 66 ns, 73 ns, `bench/stats/opt/b/results.md`). 같은 모양의 위꼬리 역함수도 Boost의 출발점에서 Halley 한 걸음을 이 유한합 위에서 밟아요.

### 정확하지 않은 a − 1

감마 밀도의 log $(a - 1)\log y - y - \log\Gamma(a)$에서 $a \lt \tfrac12$이면 $a - 1.0$이 반올림돼요. $\log y$는 745까지 가므로 그 반올림이 39 ULP까지 커져요. 그래서 $(a - 1)\log y$를 `a log y - log y`로, 두 곱을 double-double로 써요. $\log\Gamma(a)$도 $\log\Gamma(1 + a) - \log a$로 계산해서 작은 $a$에서 큰 항을 반올림하지 않아요. 베이불의 $(c - 1)\log y$도 같은 이유로 $E - \log y$예요. $a \ge 13$에서는 앞 인자의 Temme 꼴 지수 $E$를 그대로 써서 $\log(aD/y)$로 밀도를 만들어요(`log_density_std`).

## 엔트로피와 모멘트의 상쇄

### 감마·베타·t·F의 엔트로피: 큰 항을 지운 묶음

감마 분포의 엔트로피는 $h = a + \log\Gamma(a) + (1 - a)\psi(a) + \log s$예요. 세 항은 각각 크기 $a\log a$인데 합은 $\tfrac12\log a$ 정도예요. $a = 10^6$이면 $10^7$ 크기의 항 셋을 더해 8을 얻는 셈이라 double로는 7자리를 잃어요. 그래서 큰 항을 **식에서** 지운 묶음을 만들어요.

$$
G(z) = \log\Gamma(z) - (z - 1)\psi(z) + z - \tfrac12\log z - \tfrac12\log 2\pi, \qquad
G_c(z) = -\log\Gamma(z) + (z - 2)\psi(z) - z + \tfrac32\log z + \tfrac12\log 2\pi
$$

Stirling 급수 $\log\Gamma(z) = (z - \tfrac12)\log z - z + \tfrac12\log 2\pi + S(z)$, $\psi(z) = \log z - \tfrac{1}{2z} - T(z)$($S = \sum B_{2k}/(2k(2k-1)z^{2k-1})$, $T = \sum B_{2k}/(2kz^{2k})$)를 넣으면 $\log z$와 $z$가 정확히 사라져요.

$$
G(z) = \tfrac12 - \tfrac{1}{2z} + S + (z - 1)T, \qquad G_c(z) = -\tfrac12 + \tfrac1z - S - (z - 2)T
$$

둘 다 $O(1)$이에요. $z \ge 12$에서는 이 급수(8항)를, 그 아래는 double-double $\log\Gamma$와 `digamma`를 직접 써요(작은 $z$에서는 큰 항이 없어요). 엔트로피는 이 묶음과 log들의 double-double 합이에요.

| 분포 | 엔트로피 |
|---|---|
| 감마 | $G(a) + \tfrac12\log a + \tfrac12\log 2\pi + \log s$ |
| 베타 | $G(a) + G(b) + G_c(a + b) + \tfrac12\log a + \tfrac12\log b - \tfrac32\log(a + b) + \tfrac12\log 2\pi$ |
| F | $G(a) + G(b) + G_c(c) - \tfrac12\log a + \tfrac32(\log b - \log c) + \tfrac12\log 2\pi + 2(\psi(c) - \psi(b))$ |
| t | $\tfrac12\log 2\pi + (a + \tfrac12)(\psi(a + \tfrac12) - \psi(a)) - L(a)$ ($a \ge 12$) |

$a = d_1/2$, $b = d_2/2$, $c = a + b$이에요. F와 t의 $\psi$ 차는 $z \ge 12$에서 점근 급수로 `log1p(h/z)`와 항마다의 `expm1`로 빼요(`digamma_diff_asym`). F는 자유도가 $10^{-2}$ 아래면 NaN이에요. 그곳에서는 `digamma`의 극($-2/d_1$, $-2/d_2$, 합에서 서로 지워져요)이 자릿수를 가져가서, 자유도가 작아질수록 값의 앞자리까지 틀려요.

```python
>>> sd.stats.Beta(a=1e5, b=2e5).entropy()
-5.63887126423342
>>> sd.stats.Gamma(a=1e10).entropy()
12.931863998141568
```

둘 다 Arb 참값과 같은 double이에요. scipy 1.18.1의 `beta.entropy(1e5, 2e5)`는 $-5.638871264178306$으로 $10^{-11}$이 틀려요.

### 베이불의 중심 모멘트: D_k

베이불의 모멘트는 $m_k = s^k\Gamma(1 + k/c)$예요. $c$가 크면 분포가 $s$ 둘레에 좁게 몰리고($X \approx s(1 + \log E/c)$), 중심 모멘트는 크기 1인 항들이 상쇄해 남은 것이에요. 분산 $\Gamma(1 + 2x) - \Gamma(1 + x)^2$($x = 1/c$)는 $O(x^2)$인데 항은 1 크기라서, $c = 10^5$이면 $10^{-10}$을 얻으려고 1끼리 빼요.

그래서 모멘트 비를 log 감마의 차로 써요.

$$
D_k = \log\Gamma(1 + kx) - k\log\Gamma(1 + x)
= \sum_{j \ge 2}\frac{(-1)^j\zeta(j)}{j}\big((kx)^j - kx^j\big) \qquad (kx \le 0.85)
$$

$\log\Gamma(1 + x) = -\gamma x + \sum_{j\ge2}(-1)^j\zeta(j)x^j/j$의 선형 항 $-\gamma kx$와 $+\gamma kx$가 **정확히** 지워져서 $D_k = O(x^2)$가 상대오차 없이 나와요. $\zeta(j) - 1$은 double-double 표(`coeffs/zeta_minus_one.hpp`)이고 합도 double-double이에요. $kx > 0.85$이면 급수가 느려지지만 그때는 $D_k$가 항 크기라 상쇄가 없으므로 double-double $\log\Gamma$의 차로 충분해요. $E_k = e^{D_k} - 1$로 두면

$$
\frac{\mu_2}{m_1^2} = E_2, \qquad \frac{\mu_3}{m_1^3} = E_3 - 3E_2, \qquad \frac{\mu_4}{m_1^4} = E_4 - 4E_3 + 6E_2
$$

이고 모두 double-double이에요(`expm1_full`). 왜도는 $c \approx 3.6$에서, 초과 첨도는 $c \approx 2.25$와 $5.77$에서 0을 지나요. $D_k > 600$이면 $E$가 넘치므로 $e^{-D_k}$로 배율을 바꿔 계산해요.

$x \to 0$에서 첨도의 분자는 $x^2$ 항까지 정확히 지워져 $O(x^4)$만 남아요. double-double로도 $x = 10^{-9}$에서 $10^{-14}$밖에 남지 않으므로, $\lvert x\rvert \lt 10^{-4}$에서는 $x = 0$ 둘레의 테일러 급수(Γ 꼴의 정확한 전개에서 얻은 7개 계수, 수렴 반지름 $\tfrac14$)를 써요. 왜도는 $\lvert x\rvert \lt 2^{-40}$에서 극한($\mp 12\sqrt6\,\zeta(3)/\pi^3$, 지수분포를 따르는 변수의 log의 왜도)과 그 기울기예요. 이 두 함수는 GEV의 왜도·첨도에도 그대로 쓰여요($x = c$, [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)).

```python
>>> sd.stats.Weibull(c=1000.0).kurtosis()
2.371234264109682
>>> sd.stats.Weibull(c=1e5).skewness()
-1.1394874345084645
>>> sd.stats.Weibull(c=1e5).variance()
1.6448910372477495e-10
```

Arb 참값과의 차는 0, 0, $7.9 \times 10^{-16}$이에요. 같은 점에서 scipy 1.18.1은 첨도 $2.3706$($2.5 \times 10^{-4}$ 틀림), 왜도 $-1.526$(34% 틀림), 분산 $1.9 \times 10^{-6}$ 틀림이에요.

평균 $s\Gamma(1 + 1/c)$에도 작은 함정이 있어요. $1/c$를 반올림하면 그 오차가 $\psi(1 + x)\,x$배로 커져서 $c = 0.013$에서 267 ULP예요(직접 잰 값). 그래서 $x = 1/c$를 double-double로 두고 $\Gamma(1 + x_{hi})(1 + \psi(1 + x_{hi})(x_{lo} + \text{반올림}))$으로 1차 보정해요(`gamma1`).

### 로그정규의 모멘트

로그정규의 모멘트는 $t = e^{\sigma^2} - 1$의 식이에요. $\sigma^2$을 `two_prod`로 정확히 두고 $t = \operatorname{expm1}(\sigma^2_{hi}) + e^{\sigma^2_{hi}}\sigma^2_{lo}$로 만들어요. 초과 첨도 $e^{4\sigma^2} + 2e^{3\sigma^2} + 3e^{2\sigma^2} - 6$은 작은 $\sigma$에서 상쇄하지만, $t$로 쓰면 양항 다항식 $t(16 + t(15 + t(6 + t)))$이 돼요. 왜도 $(t + 3)\sqrt t$도 같고, $\sigma^2 \lt 2^{-60}$이면 $\sqrt t = \sigma$로 바꿔요($\sigma^2$이 언더플로할 수 있어요). 평균·분산·표준편차는 $e^{\mu + \sigma^2/2}$ 같은 인수가 넘치면 log에서 더해 한 번에 지수화해요.

```python
>>> sd.stats.LogNormal(sigma=1e-5).kurtosis()
1.6000000002300001e-09
```

Arb 참값과의 차는 $1.3 \times 10^{-16}$이에요. scipy 1.18.1은 $1.6000001323845936 \times 10^{-9}$로 $8 \times 10^{-8}$이 틀려요.

### 베타의 첨도

베타의 초과 첨도는 $6\,[(a - b)^2(c + 1) - ab(c + 2)]/[ab(c + 2)(c + 3)]$이고 분자가 0을 지나요. 분자를 `two_sum`, `two_prod`로 만든 double-double로 계산해요. $ab$나 $a + b$가 double 범위 끝으로 가면 $6[(a/b + b/a - 2)(c + 1)/(c + 2) - 1]/(c + 3)$을 항마다 나눠서 계산해요(그런 모양에서는 분자의 0 지점이 멀어요).

```python
>>> sd.stats.Beta(a=1.0, b=0.32164).kurtosis()
-2.3254978976151865e-05
```

Arb 참값과 같아요. scipy 1.18.1은 $1.5 \times 10^{-11}$이 틀려요.

## 범위 밖 역함수의 근 검증

special 기반 분포의 역함수는 잰 모양 범위가 있어요. 그 밖은 값을 계산하지만, 반복이 틀린 근에 멈췄는지 알 수 없어요. 그래서 범위 밖에서는 **구한 근을 정방향으로 검증하고, 맞을 때만** 돌려줘요.

| 분포 | 검증 없이 내는 모양 범위 |
|---|---|
| 감마·카이제곱·역감마 | $a \in [10^{-6}, 10^6]$ |
| 베타 | $a, b \in [10^{-3}, 10^5]$ |
| t | $\nu \in [10^{-3}, 10^6]$ |
| F | $d_1, d_2 \in [10^{-3}, 10^5]$ |

검증은 근 $x$에서 정방향 log 꼬리 $l_f$를 계산해 목표 $l_t$와 비교하는 거예요.

```cpp
// csrc/stats/numeric.hpp
inline double accept_root(double x, double lf, double log_xf, double lt) {
    const double tol = 0x1p-50 * std::exp(log_xf - std::max(lf, lt)) + 1e-12 * std::max(1.0, std::fabs(lt));
    return std::fabs(lf - lt) <= tol ? x : std::numeric_limits<double>::quiet_NaN();
}
```

허용폭은 두 부분이에요.

- **근의 8 ULP만큼의 변화.** $x$가 $\Delta x$ 움직이면 $\log F$는 $(xf/F)\cdot\Delta x/x$만큼 움직여요. $2^{-50} = 8\cdot2^{-53}$에 이 기울기 $xf/F$(`log_xf` $= \log(x f(x))$에서)를 곱한 만큼은 근의 반올림이 낼 수 있는 차예요.
- **목표의 상대 $10^{-12}$.** 정방향 함수 자체의 오차를 위한 여유예요.

기울기는 꼬리와 목표 중 **큰 쪽**으로 나눠서 구해요. 꼬리가 목표보다 훨씬 작으면(언더플로해서 $-\infty$인 꼬리도) 자기 기울기를 키워서 스스로 허용폭을 넓히면 안 되기 때문이에요. 감마 계열은 여기에 해석적 상한을 더 둬요. $P \ge y^a e^{-y}/\Gamma(a + 1)$이므로 $yf/P \le a$이고, $Q$는 연분수의 첫 근사에서 $yf/Q \le y + 1$이에요. 그리고 서브노멀 근은 그 자체가 $2^{-1075}/x$만큼 반올림돼 있으므로 그만큼을 허용폭에 더해요.

근이 double 밖(0이나 inf)이면 그 방향의 마지막 double에서 꼬리를 재요. 아래꼬리는 $x$와 함께 커지므로, 근이 0이라는 것은 가장 작은 서브노멀에서의 꼬리가 이미 목표 이상이라는 뜻이에요. 그것이 성립할 때만 0을 내요(여유는 $10^{-9}\max(1, \lvert l_t\rvert)$).

```python
>>> sd.stats.Gamma(a=1e8).icdf(0.3)
99994755.75321469
>>> sd.stats.Beta(a=1.0, b=1e-300).icdf(1e-300)
0.6321205588285577
>>> sd.stats.Beta(a=1.0, b=1e-300).icdf(0.3)
nan
```

둘째와 셋째는 같은 분포예요. $b = 10^{-300}$이면 $F(x) = 1 - (1 - x)^b \approx -b\log(1 - x)$라서 $F = 10^{-300}$의 근은 $1 - 1/e$이고, 그 근에서 정방향 꼬리가 목표와 맞아 값을 내요. $F = 0.3$의 근은 $1 - e^{-3 \times 10^{299}}$로 1과 구별할 수 없는 곳인데, 그 근처($x > 0.9$, $b \lt 10^{-3}$)에서는 정방향 log 꼬리 자체를 계산하지 못해요(BPSER가 상한에 걸려서 NaN). 검증할 수 없으므로 NaN이에요.

### 아주 작은 모양과 아주 큰 모양

검증 말고도 모양의 양 끝에는 장치가 둘 더 있어요.

- **서브노멀 모양(감마).** $a \lt 2^{-1022}$이면 $a$ 자체가 비트를 잃었고, 불완전 감마의 조각($a/\text{tail}$, $\sqrt{2\pi a}$, $y/a$)도 마찬가지예요. 그런데 작은 모양에서는 $Q(a, y) = aE_1(y)(1 + O(a(1 + \log^2 y)))$라서 $Q$가 $a$에 비례해요. 그래서 기준 모양 $a_0 = 2^{-600}$에서 계산해 옮겨요: $Q(a, y) = (a/a_0)\,Q(a_0, y)$이고 상대 오차가 $2^{-570}$ 안이에요. $P = 1 - Q$는 1과 $2^{-1010}$ 안이에요. 역함수도 목표를 $\log(a/a_0)$만큼 옮겨 기준 모양에서 풀어요. $a \le a_0$에서 위꼬리 목표가 $1600a$ 이상이면 근이 $2^{-2300}$ 아래라 0이에요.
- **거대한 모양.** 감마의 $a > 2^{100}$, 베타의 두 모양이 모두 $2^{100}$ 초과면 분포의 상대 폭($1/\sqrt a$)이 $2^{-50}$ 아래라서 cdf가 이웃한 double 몇 개 사이에서 0에서 1로 바뀌어요. special의 불완전 함수도 그 근처에서 잰 적이 없어요. 그래서 cdf 계열과 역함수는 NaN이에요.

```python
>>> sd.stats.Gamma(a=5e-324).logccdf(1.0)
-745.9570038803834
```

$Q(a, 1) \approx a\,E_1(1) = 5 \times 10^{-324} \times 0.2194$의 log예요.

## 무한한 자유도

자유도가 inf인 t와 F는 극한 분포예요. `StudentT(df=inf)`는 표준정규, `F(dfn, dfd=inf)`는 $\chi^2(d_1)/d_1$, `F(dfn=inf, dfd)`는 $d_2/\chi^2(d_2)$, 곧 `InverseGamma(a=dfd/2, scale=dfd/2)`예요. t·F의 식에 inf를 넣어 계산하지 않고, 엔진이 그 매개변수를 알아보고 극한 분포의 메서드를 불러요. 그래서 모든 메서드가 극한 분포와 비트까지 같아요. 그 장치는 [원소별 엔진과 빠른 경로](/internals/stats/engine/#매개변수의-극한)에 있어요.

```python
>>> inf = float("inf")
>>> x = sd.asarray([-3.0, 0.5, 8.0])
>>> bool(sd.all(sd.stats.StudentT(df=inf).logpdf(x) == sd.stats.Normal().logpdf(x)))
True
>>> sd.stats.F(dfn=4.0, dfd=inf).ccdf(2.5), sd.stats.ChiSquared(df=4.0).ccdf(10.0)
(0.0404276819945128, 0.0404276819945128)
>>> sd.stats.F(dfn=inf, dfd=6.0).icdf(0.25), sd.stats.InverseGamma(a=3.0, scale=3.0).icdf(0.25)
(0.7652276358043044, 0.7652276358043044)
>>> sd.stats.ChiSquared(df=inf).cdf(1.0), sd.stats.F(dfn=inf, dfd=inf).mean()
(nan, nan)
```

극한이 연속 분포가 아니면 정의역 밖 그대로 NaN이에요. 카이제곱은 df와 함께 질량이 무한대로 달아나고, 두 자유도가 모두 inf인 F는 1에 몰린 점질량이에요.

## 분포마다의 경로

| 분포 | pdf·logpdf | cdf·ccdf | 깊은 log 꼬리 | 역함수 | 모멘트·엔트로피 |
|---|---|---|---|---|---|
| 정규 | double-double 지수를 한 번 지수화 | `ndtr(z_hi)` + $\varphi z_{lo}$ | `log_ndtr` + 1차 보정 | `ndtri`, 필요하면 log에서 뉴턴 한 걸음, `ndtri_exp` | 닫힌 꼴, 엔트로피 double-double |
| 로그정규 | 정규 지수 $+ \log x$ | 정규의 `tail_z` | 정규와 같음 | 정규의 $z$를 지수 안에서 $e^{\mu + \sigma z}$ | $t = e^{\sigma^2} - 1$의 양항 꼴 |
| 지수 | $e^{-y}/s$, $y$ double-double | $e^{-y}$, $-\operatorname{expm1}(-y)$ | $-y$, $\log x - \log s$ | $-s\log p$, $-s\operatorname{log1p}(-p)$ | 닫힌 꼴 |
| 균등 | $1/w$(너비가 넘치면 반으로) | $(x - a)/w$ | 두 log의 차 | `fma` 한 번 | 닫힌 꼴, 최빈값 NaN |
| 라플라스 | $e^{-(\lvert z\rvert + \log 2\sigma)}$ | $\tfrac12 e^{-\lvert z\rvert}$ | $z - \log 2$ | $\log 2p$ | 닫힌 꼴 |
| 코시 | 인수마다 $m\cdot2^e$ | $\arctan(-1/z)/\pi$ | $-\log\lvert z\rvert - \log\pi$ | $-1/\tan(\pi p)$, $\sigma/(\pi p)$ | 모멘트 NaN, 엔트로피 $\log 4\pi\sigma$ |
| 베이불 | $\log c - \log s + E - \log y - t$ | $e^{-t}$, $t$에 exp 잔차를 접음 | $E - t/2$, $-t$ | $s\exp(\log t/c)$ | $D_k$의 ζ 급수, Γ의 1차 보정 |
| 감마·카이제곱 | Temme 지수($a \ge 13$), $a\log y - \log y$ | `igam` + `xderiv` 보정, 반정수는 유한합 | `igam_detail::log_tail` | `gammaincinv`·`gammainccinv`, `deep_inverse`, 범위 밖 검증 | $G(a)$ 묶음 |
| 베타 | log 앞 인자 $- \log x - \log y$ | $a, b \le 6$은 Boost, 그 밖은 `ibeta` | 앞 인자 + BPSER·BFRAC 비율, log BGRAT | `fast_root`, `betaincinv`, `deep_log_inverse`, 범위 밖 검증 | $G(a) + G(b) + G_c(c)$, 첨도 분자 double-double |
| t | $l_0 - (a + \tfrac12)\log(1 + t^2/\nu)$, $L(a)$ | `stdtr`, 인자가 언더플로하면 주항 | 베타 경로, $x \lt 10^{-270}$이면 주항 | `stdtrit`, `deep_log_inverse_both`(근이 $\tfrac12$ 위면 $\log(1 - x)$에서 다시 뉴턴) | $L(a)$와 ψ 차의 급수 |
| F | 베타 앞 인자, 작은 인자는 log에서 | `fdtr`, `fdtrc` | 자유도 ≤ 12는 `fdtr`, 작은 인자, 카이제곱 극한, 베타 경로 | `fast_root`, `fdtri`, `deep_log_inverse_both` | $G$ 묶음 + ψ 차, 모멘트는 비의 곱 |

감마·베타·t·F·역감마의 밀도는 배열 입력에서 log 둘과 선형 항의 합 $k_1\log x_1 + k_2\log x_2 - \text{lin} + c$로 다시 쓴 묶음 커널이 먼저 맡아요. 스칼라 호출도 원소 하나짜리 커널이라 어느 길로 부르든 같은 비트예요. 커널이 오차 예산 안에서 답할 수 없는 원소(거대한 모양의 최빈값 근처, 먼 꼬리, 지지집합의 끝)만 위 표의 double-double 정의로 가요([원소별 엔진과 빠른 경로](/internals/stats/engine/)).

정확도는 Arb로 만든 참값과 대조해 재요. 보장 영역 안 87만 점의 최대가 계약 단위로 $9.2 \times 10^{-15}$이고, 같은 점에서 scipy 1.18.1은 꼬리에서 상대오차 1에 이르거나 inf를 내요(`bench/stats/t4/accuracy.md`, [정확도와 성능](/internals/stats/accuracy-performance/)).
