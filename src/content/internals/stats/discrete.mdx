## 한눈에 보기

이산 분포는 정수에만 확률이 있는 분포예요. 밀도 대신 점마다의 확률 pmf가 있고, 누적확률은 계단이에요. 그래서 연속 분포와 다른 문제가 셋 생겨요.

- **분위수는 방정식의 근이 아니라 계단의 위치예요.** `icdf(p)`는 $F(k) \ge p$인 가장 작은 정수 $k$예요. 뉴턴 반복 같은 연속 방법을 쓸 수 없고, 정수 위에서 찾아야 해요.
- **누적확률에 닫힌 꼴이 없는 분포가 있어요.** 이항·포아송·음이항은 불완전 베타·감마로 쓸 수 있지만, 초기하와 베타이항은 pmf를 직접 더해야 해요.
- **모멘트와 엔트로피가 지지집합 전체의 합이에요.** 지지집합이 무한하거나 아주 넓으면, 얼마나 더하고 언제 멈출지가 정확도와 시간을 함께 정해요.

코드는 두 층이에요. 모든 이산 분포가 함께 쓰는 부품(분위수 탐색, 꼬리 합, 엔트로피 합, 반복의 상한, 정수점 메모)은 `csrc/stats/discrete.hpp`에 있어요. 분포마다의 정의는 `csrc/stats/dist/discrete_basic.hpp`(이항, 베르누이, 포아송, 기하, 음이항)와 `csrc/stats/dist/discrete_more.hpp`(이산 균등, 초기하, 베타이항, 로그 급수, Zipf)에 있어요.

| 분포 | pmf | cdf·ccdf | 엔트로피 |
|---|---|---|---|
| [Binomial](/api/stats/binomial/) | 불완전 베타의 앞 인자(Loader 꼴) | [`bdtr`](/api/special/bdtr/)·`bdtrc`, log 꼬리는 불완전 베타 | 최빈값에서 바깥으로 합 |
| [Bernoulli](/api/stats/bernoulli/) | 닫힌 꼴 | 닫힌 꼴 | $\operatorname{entr}(p) + \operatorname{entr}(q)$ |
| [Poisson](/api/stats/poisson/) | 불완전 감마의 앞 인자 | [`pdtr`](/api/special/pdtr/)·`pdtrc`, log 꼬리는 불완전 감마 | 합, $\mu \ge 10^4$은 점근식 |
| [Geometric](/api/stats/geometric/) | $\exp((k-1)\log q + \log p)$ | $q^k$를 double-double 지수로 | 닫힌 꼴 |
| [NegativeBinomial](/api/stats/negative-binomial/) | 불완전 베타의 앞 인자 | [`nbdtr`](/api/special/nbdtr/)·`nbdtrc`, log 꼬리는 불완전 베타 | 합 |
| [Hypergeometric](/api/stats/hypergeometric/) | 전체 ≤ 120은 정확한 정수, 위는 이항 셋의 비 | 전체 ≤ 120은 정확한 정수, 위는 꼬리 합 | 합 |
| [DiscreteUniform](/api/stats/discrete-uniform/) | $1/(\text{high} - \text{low})$ | 닫힌 꼴 | $\log(\text{high} - \text{low})$ |
| [BetaBinomial](/api/stats/beta-binomial/) | double-double $\log\Gamma$ 넷 | 꼬리 합 | 합(단봉), 양 끝에서 합(단봉이 아닐 때) |

이 글은 공통 부품부터 설명하고, 그다음 pmf, 누적확률, 모멘트, 엔트로피 순서로 분포마다의 기법을 다뤄요. 메서드마다의 의미는 [분포의 메서드](/api/stats/methods/)에 있어요. 배열을 1024원소씩 묶어 처리하는 엔진과 정수점 메모 자체는 [원소별 엔진과 빠른 경로](/internals/stats/engine/)에 있어요.

## 분위수: 질주와 이분

### 무엇을 찾나요

이산 분포의 네 역함수는 모두 "조건을 만족하는 가장 작은 정수"예요.

| 메서드 | 찾는 것 |
|---|---|
| `icdf(p)` | $P(X \le k) \ge p$인 가장 작은 $k$ |
| `iccdf(q)` | $P(X > k) \le q$인 가장 작은 $k$ |
| `ilogcdf(t)` | $\log P(X \le k) \ge t$인 가장 작은 $k$ |
| `ilogccdf(t)` | $\log P(X > k) \le t$인 가장 작은 $k$ |

조건은 $k$에 대해 단조예요(거짓이다가 어느 점부터 참). 그래서 답은 이분 탐색으로 찾을 수 있어요. 결과는 정수인 float64이고, 지지집합이 무한하고 답이 가장 큰 double을 넘으면 `inf`예요.

```python
>>> X = sd.stats.Binomial(n=10, p=0.5)
>>> X.cdf(5)
0.623046875
>>> X.icdf(0.623046875)
5.0
>>> X.icdf(0.6230468750000001)
6.0
```

$F(5) = 638/1024$는 double로 정확해요. 목표가 정확히 그 값이면 5, 한 ULP 위면 6이에요. 계단 경계에서는 마지막 비트가 답을 바꿔요. 이 민감함이 아래의 [후방 오차 계약](#후방-오차-계약)이 필요한 이유예요.

### 어느 쪽 확률과 비교하나요

$p$를 그대로 $F(k)$와 비교하면 위꼬리에서 자릿수를 잃어요. $p = 1 - 10^{-12}$이면 double로 저장된 $p$에는 $1 - p$의 유효숫자가 네 자리 남짓밖에 없어요. 그래서 두 꼬리 중 작은 쪽에서 비교해요(`disc::icdf`, 발췌).

```cpp
// csrc/stats/discrete.hpp
template <class F>
double icdf(double p, const F& f) {
    if (!(p >= 0.0 && p <= 1.0)) return kNaN;
    if (p == 0.0) return f.lo;
    if (p == 1.0) return f.hi;
    if (p > 0.5) {
        const double q = 1.0 - p;  // exact
        return smallest(f.lo, f.hi, f.guess, [&](double k) { return f.ccdf(k) <= q; });
    }
    if (p >= kTinyP) return smallest(f.lo, f.hi, f.guess, [&](double k) { return f.cdf(k) >= p; });
    const double lp = std::log(p);
    return smallest(f.lo, f.hi, f.guess, [&](double k) { return f.logcdf(k) >= lp; });
}
```

- **$p > 1/2$**: $1 - p$는 Sterbenz 보조정리로 정확해요($p \in [1/2, 1]$이면 뺄셈에 반올림이 없어요). 조건 $F(k) \ge p$를 $P(X > k) \le 1 - p$로 바꿔서, 직접 계산한 위꼬리 `ccdf`와 비교해요. 위꼬리는 1 − cdf가 아니라 따로 계산하므로 꼬리에서도 상대 정확도가 있어요.
- **$p < 2^{-1000}$** (`kTinyP`): 확률이 서브노멀에 가까우면 `cdf`의 값 자체가 절대 정확도밖에 없어요. 그래서 log 쪽에서 $\log F(k) \ge \log p$로 비교해요.
- `iccdf`는 거울상이에요. `ilogcdf(t)`는 $t \le -\log 2$이면 log 쪽에서 직접, 그 위면 작은 쪽 확률 $-\operatorname{expm1}(t)$에 대한 `iccdf`로 넘겨요.

$p = 0$과 $p = 1$의 답인 `f.lo`, `f.hi`는 분포 족의 지지집합의 끝이에요. `support()`가 내는 값과 같고, 매개변수가 퇴화해 질량이 한 점에 모여도 줄이지 않아요. 포아송은 $\mu = 0$에서도 $[0, \infty)$, 기하는 $p = 1$에서도 $[1, \infty)$, 이항은 $p = 0$에서도 $[0, n]$이에요. 그래서 점질량의 `icdf(1)`은 그 점이 아니라 족의 위 끝이에요.

```python
>>> P = sd.stats.Poisson(mu=0)
>>> P.support(), P.icdf(0.5), P.icdf(1.0)
((0.0, inf), 0.0, inf)
```

음이항의 $n = 0$(기다릴 성공이 없으니 실패도 없어요)도 0의 점질량이에요. $n = 0$은 `valid`의 정의역 밖이라, 엔진의 극한 장치(`at_limit`)가 모든 메서드를 $p = 1$인 음이항의 값으로 보내요([원소별 엔진과 빠른 경로](/internals/stats/engine/)).

```cpp
// csrc/stats/dist/discrete_basic.hpp, NegativeBinomial
static bool at_limit(double n, double p) { return n == 0.0 && p > 0.0 && p <= 1.0; }
template <class M>
static double limit_in(double x, double, double) {
    return method_of<NegativeBinomial, M>(x, 1.0, 1.0);
}
template <class M>
static double limit_par(double, double) {
    return method_of<NegativeBinomial, M>(1.0, 1.0);
}
```

베타이항은 모양 $a$나 $b$가 $2^{-1021}$ 아래이면 0과 $n$의 두 점 분포예요($P(n) = a/(a + b)$). 이 모양은 `valid` 안에 있지만, 엔진이 `at_limit`을 먼저 물어서 같은 장치로 넘어가요. 값은 베타와 함께 쓰는 `two_point.hpp`에서 나와요([작은 모양의 두 점](/internals/stats/engine/#작은-모양의-두-점-two_point)). 분위수 탐색을 거치지 않고 `cdf`가 목표 이상이 되는 가장 작은 점을 바로 골라요. 지지집합은 여기서도 족의 것 $[0, n]$이라 `icdf(1)`은 $n$이에요.

```cpp
// csrc/stats/dist/discrete_more.hpp, BetaBinomial
static bool at_limit(double n, double a, double b) {
    return valid(n, a, b) && (a < two_point::kMinShape || b < two_point::kMinShape);
}
template <class M>
static double limit_in(double x, double n, double a, double b) {
    return two_point::in<M>(x, two_point::of_shapes(a, b, 0.0, n, true));
}
```

```python
>>> T = sd.stats.BetaBinomial(n=10, a=1e-310, b=3e-310)
>>> T.support(), T.icdf(0.75), T.icdf(0.76), T.icdf(1.0)
((0.0, 10.0), 0.0, 10.0, 10.0)
```

Zipf처럼 깊은 꼬리의 분위수가 아주 큰 분포는 한 단계 더 가요. $q$가 $2^{-1000}$ 아래이면 $\log q \approx -700$이고, 그 ULP는 $1.1 \times 10^{-13}$이에요. Zipf의 위꼬리는 $P(X > k) \approx k^{1-a}/((a-1)\zeta(a))$라서 $\log q$가 한 ULP 움직이면 분위수는 상대적으로 그 $1/(a-1)$배 움직여요. 그래서 이 분포는 `logccdf_dd`(위꼬리의 log를 double-double로)를 주고, 탐색은 $\log q$도 double-double로 만들어 두 쌍을 비교해요(`dd_le`).

이분 부분은 이래요.

```cpp
// csrc/stats/discrete.hpp, disc::smallest의 끝
for (int i = 0; b - a > 1.0; ++i) {
    if (i >= kMaxSearchSteps) return kNaN;  // not reached: the bracket halves each time
    const double m = std::floor(a + 0.5 * (b - a));
    if (m <= a || m >= b) break;  // past 2^53 no float64 lies between: b is the answer rounded
    if (pred(m)) b = m;
    else a = m;
}
return b;
```

중간점을 `(a + b)/2`가 아니라 `a + 0.5*(b − a)`로 만드는 것은 $a + b$가 double을 넘지 않게 하려는 거예요. 위로 질주하는 걸음이 $2^{1023}$을 넘으려 하면 가장 큰 double($1.797\ldots \times 10^{308}$)에서 조건을 한 번 시험해요. 거기서 참이면 답은 그 아래의 유한한 double이고, 거짓이면 `inf`예요. 그래서 참 분위수가 $4.9 \times 10^{307}$처럼 $2^{1023}$과 가장 큰 double 사이에 있어도 맞게 나와요.

```python
>>> sd.stats.Zipf(a=2.00008).iccdf(1.2e-308)
4.786751860406388e+307
>>> sd.stats.Zipf(a=1.01).iccdf(1e-300)
inf
```

### 시작점

평가 한 번은 불완전 함수 한 번이라 비싸요. 그래서 시작점이 답에 가까울수록 빨라요. 분포마다 `Fns`라는 작은 구조체가 `cdf`, `ccdf`, `logcdf`, `logccdf`, 지지집합의 끝 `lo`, `hi`, 시작점 `guess`를 묶어요. 기본 시작점은 평균의 floor예요.

- **넓은 분포**(표준편차 ≥ 8, `kWideSd`): 평균에서 꼬리의 분위수까지는 수천 칸일 수 있어요. 그래서 Cornish–Fisher 추정에서 시작해요.

  $$
  k_0 = \left\lfloor \mu + \sigma\left(z + \frac{\gamma_1 (z^2 - 1)}{6}\right) \right\rfloor
  $$

  $z$는 요청한 확률의 표준정규 분위수(`ndtri`, log 확률이면 `ndtri_exp`), $\gamma_1$은 왜도예요. 정규 근사에 왜도 보정을 한 항 더한 것이라, 대부분 두세 번의 평가로 답이 정해져요. 답 자체는 언제나 탐색이 정해요. 이항·포아송·음이항·초기하가 이것을 써요.
- **베타이항**: 넓은 베타이항은 베타 변수에 $n$을 곱하고 이항으로 번진 것이라, $n$ × 베타 분위수(`betaincinv`)에서 시작해요.
- **닫힌 꼴이 있는 분포**: 기하는 $\lceil \log U / \log q \rceil$($U$는 요청한 위꼬리), 이산 균등은 $\text{low} + \lceil pm \rceil - 1$에서 시작해요. 탐색은 이 점과 그 아래를 한 번씩 확인하고 끝나요.

기하의 배열 커널은 한 걸음 더 가요. $r = \log U/\log q$가 정수 $g - 1$, $g = \lceil r \rceil$ 어느 쪽과도 $64u\,(1/\lvert\log q\rvert + r)$보다 멀면, exp와 log의 몇 단위 오차로는 비교 결과가 바뀔 수 없어요. 그때는 두 번의 평가 없이 $g$를 바로 내요(`Geometric::inverse_kernel`).

### 후방 오차 계약

계단 경계에 붙은 목표에서는 cdf의 마지막 비트가 답을 정해요. 그런데 cdf 자체에 몇 ULP의 오차가 있으므로, "정확한 분위수"를 언제나 내겠다고 약속할 수 없어요. 그래서 이산 분위수의 계약은 **후방 오차**예요.

> 목표를 상대 $10^{-14}$ 안에서 움직였을 때의 정확한 분위수 중 하나를 내요. `icdf`·`iccdf`는 $p$와 $1 - p$ 중 작은 쪽에 대해, `ilogcdf`·`ilogccdf`는 입력 $t$ 자체에 대해서예요.

예를 들어 초기하 분포(전체 200, 성공 100, 뽑기 99)는 $k \leftrightarrow 99 - k$로 대칭이라 $F(49)$가 정확히 1/2이에요.

```python
>>> H = sd.stats.Hypergeometric(total=200, successes=100, draws=99)
>>> H.cdf(49)
0.49999999999999967
>>> H.median()
50.0
```

계산한 $F(49)$는 참값 1/2보다 $6.7 \times 10^{-16}$(상대) 작아요. 그래서 `median()` = `icdf(0.5)`는 50을 내요. 참 분위수는 49지만, 목표를 $0.5 \cdot (1 + 10^{-15})$로 움직이면 정확한 분위수가 50이므로 계약 안이에요. 계단 경계 바로 옆의 목표에서는 이렇게 이웃 정수도 맞는 답이에요. Zipf에서 $a \approx 1$처럼 분위수가 $10^{40}$을 넘으면 이웃 정수 사이의 cdf 차이가 cdf의 분해능보다 작아서, 그 폭만큼의 정수가 모두 허용돼요. 정답지에는 점마다 허용 구간 $[k_\text{min}, k_\text{max}]$가 들어 있고, 이 구간은 Arb(구간 산술)로 만든 참값에서 계산해요.

전체가 120 이하인 초기하는 아래에서 설명하는 정확한 정수 경로를 써서, 같은 꼴의 동점이 정확히 나와요.

```python
>>> H = sd.stats.Hypergeometric(total=10, successes=5, draws=5)
>>> H.cdf(2), H.median()
(0.5, 2.0)
```

### 한 칸 아래를 메서드의 double로

탐색은 정확한 비교로 계단을 찾지만, 사용자가 다시 넣는 목표는 대개 메서드가 반올림해 낸 double이에요. 반올림된 `cdf(k)`가 참 $F(k)$보다 조금 크면 탐색은 그 목표에 $k + 1$을 내요. 그래서 찾은 $k$에서 한 칸 아래를 같은 분포의 메서드로 다시 봐요(`disc::settle`). `icdf`는 `cdf(k - 1) >= p`이면, `iccdf`는 `ccdf(k - 1) <= q`이면 $k - 1$을 내고, log 꼴도 같아요. 그러면 `icdf(cdf(k)) == k`예요.

$k - 1$은 그것도 후방 오차 계약 안일 때만 내요. `icdf`의 계약은 $p > 1/2$이면 작은 쪽 $1 - p$에 대한 상대오차라서, 1 근처에서 반올림된 cdf는 $1 - p$에 견줘 멀리 벗어날 수 있어요. cdf의 double은 참값과 절대 $2^{-53}$ 남짓 다를 수 있고, 확인의 폭은 $10^{-15}(1 - p)$라서 $1 - p \lesssim 2^{-53}/10^{-15} \approx 0.11$이면 왕복이 $k + 1$로 남을 수 있어요. 드문 꼬리만의 일이 아니에요. `Binomial(n=1000, p=0.3)`에서는 cdf가 0.9655인 $k = 326$부터 422까지 50곳이 그래요. 포아송 $\mu = 0.0025$에서 `cdf(4)`는 $p = 1 - 7.8 \times 10^{-16}$으로 반올림되지만 `ccdf(4)`는 $8.1 \times 10^{-16}$이라 4는 계약 밖이고, 답은 5예요. 그래서 이때는 `ccdf(k - 1)`이 $(1 - p)(1 + 10^{-15})$ 이하인지도 봐요(`iccdf`의 $q > 1/2$는 cdf로 같아요). log 꼴은 $t$ 자체에 대한 계약이고 메서드의 반올림이 그 안이라 따로 보지 않아요. 작은 쪽(log 꼴은 $\lvert t\rvert$)이 $2^{-1000}$ 아래이면 그 꼬리의 double이 서브노멀이라 상대 정확하지 않으므로 옮기지 않아요. 비용은 메서드 호출 한두 번이에요. 기하 분포의 배열 커널이 평가 없이 바로 내는 $g$도 이 확인을 거쳐요.

```cpp
// csrc/stats/discrete.hpp
inline constexpr double kSettleSlack = 1e-15;
template <class D, class... P>
double settle(Inv which, double t, double k, P... p) {
    if (!(k == k) || std::isinf(k)) return k;
    const double km = k - 1.0;
    if (!(km >= D::support_lo(p...)) || km + 1.0 != k) return k;  // (past 2^53 k - 1 is no double)
    const bool log = which == Inv::ilogcdf || which == Inv::ilogccdf;
    if (!((log ? -t : std::min(t, 1.0 - t)) >= kTinyP) || t == -kInf) return k;  // (the ends are exact)
    switch (which) {
        case Inv::icdf:
            if (!(method_of<D, method::Cdf>(km, p...) >= t)) return k;
            return t <= 0.5 || method_of<D, method::Ccdf>(km, p...) <= (1.0 - t) * (1.0 + kSettleSlack) ? km : k;
        case Inv::iccdf:
            if (!(method_of<D, method::Ccdf>(km, p...) <= t)) return k;
            return t <= 0.5 || method_of<D, method::Cdf>(km, p...) >= (1.0 - t) * (1.0 - kSettleSlack) ? km : k;
        case Inv::ilogcdf: return method_of<D, method::Logcdf>(km, p...) >= t ? km : k;
        default: return method_of<D, method::Logccdf>(km, p...) <= t ? km : k;
    }
}
```

```python
>>> P = sd.stats.Poisson(mu=0.0025)
>>> p = P.cdf(4.0)
>>> p, P.ccdf(4.0)
(0.9999999999999992, 8.121084775250844e-16)
>>> P.icdf(p)
5.0
>>> P.iccdf(P.ccdf(4.0))
4.0
```

### 값을 모르는 cdf

꼬리 합이 상한을 넘으면 cdf는 NaN이에요(아래 [반복의 상한](#반복의-상한과-nan)). 탐색 도중 NaN을 만나면 분위수도 NaN이어야 하지만, NaN을 비교 함수에 그대로 넘기면 조건이 언제나 거짓이라 질주가 끝까지 가요. 그래서 탐색에 넘기는 `Memoized` 래퍼가 처음 NaN을 본 순간 `unknown`을 켜고, 그 뒤로는 아무것도 평가하지 않고 0을 돌려줘요. 탐색은 산술만으로 상한 안에 끝나고, `inverse()`가 마지막에 `unknown`을 보고 NaN을 내요. 같은 래퍼가 배열 호출에서 스레드별 cdf·ccdf 메모를 달아요([정수점 메모](/internals/stats/engine/)).

## pmf: 큰 항을 지우지 않는 꼴

### 그대로 쓰면 무엇을 잃나요

이항 pmf를 교과서대로 쓰면 이래요.

$$
\log P(X = k) = \log\Gamma(n+1) - \log\Gamma(k+1) - \log\Gamma(n-k+1) + k\log p + (n-k)\log q
$$

$n = 10^9$, $k$가 평균 근처이면 각 항의 크기는 $n\log n \approx 2 \times 10^{10}$인데, 합은 $-\tfrac12\log(2\pi npq) \approx -11$이에요. 열 자리가 지워지므로 double 항 다섯을 더하면 결과의 절대오차가 $2 \times 10^{10} \times 2^{-53} \approx 2 \times 10^{-6}$이에요. pmf는 이것을 지수화하므로 상대오차가 $10^{-6}$이에요.

### Stirling 정규화와 편차

해법은 Stirling 공식으로 큰 부분을 손으로 지우는 거예요. $\Gamma(z+1) = \sqrt{2\pi z}\,(z/e)^z\,e^{\delta(z)}$로 쓰면($\delta(z) = \log\Gamma^*(z)$는 Stirling 급수의 나머지, $1/(12z) - 1/(360z^3) + \dots$), 이항 pmf는 다음과 같아요.

$$
P(X = k) = \sqrt{\frac{n}{2\pi k(n-k)}}\;\exp\Bigl(\delta(n) - \delta(k) - \delta(n-k) - D(k; np) - D(n-k; nq)\Bigr)
$$

$$
D(x; M) = x\log\frac{x}{M} + M - x
$$

$D(x; M)$는 관측값 $x$와 기댓값 $M$ 사이의 **편차**(deviance)예요. 큰 항 $n\log n$은 대수적으로 정확히 지워져서 식에 남지 않고, 남는 것은 작은 $\delta$ 항과 음이 아닌 편차뿐이에요. 이 꼴은 Loader가 이항 확률을 계산하려고 제안한 것이에요[1]. Loader는 안장점 근사(saddle-point approximation)에서 이 식을 얻었는데, Stirling의 나머지 $\delta$를 정확히 넣으면 근사가 아니라 항등식이 돼요. 그래서 "안장점 꼴"이라고 불러요.

편차를 $t = (M - x)/x$로 쓰면

$$
D(x; M) = x\,\bigl(t - \log(1+t)\bigr) = x\,\mu(t), \qquad \mu(t) = t - \log(1 + t) \ge 0
$$

이에요. $\mu$는 Temme가 불완전 감마에 쓴 것과 같은 함수예요. stardust의 불완전 감마·베타 앞 인자(`csrc/special/prefix.hpp`)가 바로 이 꼴이고, 이항·음이항·포아송의 pmf는 그 앞 인자에 간단한 인자를 곱한 거예요(`discrete_basic.hpp` 첫머리).

$$
\binom{n}{k} p^k q^{n-k} = B(k, n-k; p)\,\frac{n}{k(n-k)}, \qquad
\frac{\mu^k e^{-\mu}}{k!} = D(k, \mu)
$$

여기서 $B(a, b; x) = x^a(1-x)^b/B(a, b)$, $D(a, x) = x^a e^{-x}/\Gamma(a+1)$이에요. 지수 $E$를 정확한 입력에서 double-double로 만들고 한 번에 지수화하는 과정은 [불완전 함수](/internals/special/incomplete/)에 자세히 있어요. 이 꼴은 정밀 경로(스칼라 정의)이고, 모든 원소가 결국 여기로 돌아올 수 있어요.

### 빠른 경로: 평균 근처를 float64로

배열에서는 대부분의 원소가 평균 근처에 있어요. 거기서는 $\lvert t \rvert$가 작아서 log 없이 급수로 $\mu(t)$를 쓸 수 있어요.

$$
\mu(t) = t^2 P(t), \qquad P(t) = \tfrac12 - t R(t), \qquad R(t) = \tfrac13 - \tfrac t4 + \tfrac{t^2}{5} - \cdots = \sum_{j \ge 0} \frac{(-t)^j}{j + 3}
$$

이항의 지수는 $E = D(k; np) + D(n-k; nq)$이고, $\Delta = np - k$라 두면 $t_1 = \Delta/k$, $t_2 = -\Delta/(n-k)$이므로

$$
E = \Delta^2\left(\frac{P(t_1)}{k} + \frac{P(t_2)}{n - k}\right)
$$

예요. `saddle::` 커널은 $\lvert t \rvert \le 1/8$에서 이것을 float64로 계산하되, 반올림 오차를 버리지 않고 two_prod·two_sum·fma로 꺼내 보정 항으로 남겨 둬요.

```cpp
// csrc/stats/dist/discrete_basic.hpp, saddle::
// R(t) = sum_{j >= 0} (-t)^j / (j + 3), |t| <= 1/8: 17 terms, the even and the odd ones as
// two Horner chains in t^2 (half the latency of one chain).
inline double series_r(double t) {
    constexpr double ce[9] = {1.0 / 3, 1.0 / 5, 1.0 / 7, 1.0 / 9, 1.0 / 11, 1.0 / 13, 1.0 / 15, 1.0 / 17, 1.0 / 19};
    constexpr double co[8] = {-1.0 / 4, -1.0 / 6, -1.0 / 8, -1.0 / 10, -1.0 / 12, -1.0 / 14, -1.0 / 16, -1.0 / 18};
    const double t2 = t * t;
    double e = ce[8], o = co[7];
    for (int j = 7; j >= 0; --j) e = e * t2 + ce[j];
    for (int j = 6; j >= 0; --j) o = o * t2 + co[j];
    return e + t * o;
}

// Binomial(n, p) at k: 13 <= k <= n - 13, n <= 2^53, 0 < p < 1 (ok false otherwise; the
// arithmetic is safe for any input). D = n p - k; r = n / (2 pi k (n - k)).
inline Parts binomial(double k, double n, double p) {
    const double m = n - k;
    const bool ok = k >= kStirlingMin && m >= kStirlingMin && n <= kLargest && p > 0.0 && p < 1.0 && std::floor(k) == k;
    const DD h = dd::two_prod(n, p);
    const DD a = dd::two_sum(h.hi, -k);
    const DD d = dd::two_sum(a.hi, a.lo + h.lo);
    const double s = stirling(n) - stirling(k) - stirling(m);
    return finish(d.hi, d.lo, k, m, s, n / (2.0 * special::kPi * (k * m)), ok);
}
```

$R$의 18번째 항은 $(1/8)^{17}/20 = 2^{-55}$보다 작아서 17항이면 충분해요. 짝수 항과 홀수 항을 $t^2$에 대한 두 Horner 사슬로 나누면 의존 사슬의 길이가 절반이 돼요. $\Delta = np - k$는 two_prod로 $np$를 정확히 만든 뒤 빼서 hi + lo 쌍으로 남겨 둬요. $\delta(z)$는 $z \ge 13$에서 Cephes의 Stirling 다항식으로 $1/156$보다 작은 값을 내요(`kStirlingMin` = 13).

이렇게 만든 $X = S - E = x_h + x_l$($S$는 $\delta$ 항의 합)의 오차 상한을 연산마다 세면, $X$는 $0.5u\,E + 1.1u$ 안이에요($u = 2^{-53}$). pmf는 $\sqrt r\,e^{x_h}(1 + x_l)$이고, vForce의 exp(2.5단위)와 곱셈의 오차를 더하면 상한이 $0.5E + 9.9$단위예요. pmf의 상대오차는 $E$의 절대오차라서 $E$에 비례하는 항이 남아요. 엔진의 빠른 경로 예산은 16단위($1.8 \times 10^{-15}$)이므로 $E \le 12$인 원소만 이 값을 쓰고, 나머지는 정밀 경로로 보내요. logpmf는 $X + \tfrac12\log r$이고 두 부분이 같은 부호라 상쇄가 없어서, 어떤 $E$에서도 결과의 8.1단위 안이에요.

| 조건 | 빠른 경로 | 그 밖 |
|---|---|---|
| $k$와 $n - k$가 13 이상, $n \le 2^{53}$ | float64 + 보정 항 | double-double 지수 |
| $\lvert t_1\rvert, \lvert t_2\rvert \le 1/8$ | 급수 $R(t)$ | `a_mu`(double-double log 포함) |
| pmf: $E \le 12$ / logpmf: 언제나 | 상한 $0.5E + 9.9$ / $8.1$단위 | 정밀 경로 |

음이항은 $a = n$, $b = k$, $c = n + k$, $\Delta = pk - qn$으로, 포아송은 항 하나($\Delta = \mu - k$, $E = \Delta^2 P(\Delta/k)/k$)로 같은 커널을 써요.

### 다른 분포의 pmf

- **기하**: $\log P(X = k) = (k-1)\log q + \log p$이고 $\log q = \log(1 - p)$는 $1 - p$를 two_sum으로 정확히 만든 double-double의 log예요. $k \ge 2^{1000}$에서 $k\log q$가 double을 넘으면 −inf로 정리해요(double-double 곱이 inf − inf가 되기 전에).
- **로그 급수**: $P(X = k) = p^k / (kL)$, $L = -\log(1 - p)$예요. 그대로 쓰면 $k = 1$에서 $\log p - \log L$이 상쇄해요. $p$가 작으면 $L \approx p$라 log pmf는 $-p/2$ 크기인데, 두 log는 각각 $\log p$ 크기예요. 그래서 $\log(L/p) = \operatorname{log1p}(L/p - 1)$을 따로 두고, $L/p - 1 = \sum_{j\ge1} p^j/(j+1)$를 $p < 1/64$에서는 급수로, 위에서는 $(L - p)/p$를 상쇄 없는 $-p - \log(1 - p)$ 꼴(`log1pmx_neg`)로 만들어요.

  ```python
  >>> sd.stats.LogSeries(p=1e-8).logpmf(1)
  -5.000000020833333e-09
  ```

  참값은 $-p/2 - 5p^2/24 = -5.0000000208333\ldots \times 10^{-9}$이에요.
- **Zipf**: $\log P(X = k) = -a\log k - \log\zeta(a)$예요. $a$가 크면 $\zeta(a) - 1 \approx 2^{-a}$라서 $\log\zeta(a)$를 $\zeta(a)$의 log로 구하면 1에 흡수돼요. 그래서 $\zeta(a) - 1 = \zeta(a, 2)$(Hurwitz 제타)가 1/2보다 작으면 $\operatorname{log1p}(\zeta(a, 2))$로 구해요.

  ```python
  >>> sd.stats.Zipf(a=53).logpmf(1)
  -1.1102230251410661e-16
  ```

  누적합에 쓰는 $k^{-a}$는 `exp(-a*log(k))`가 아니라 `pow`예요. $a\log k$를 double로 반올림하면 그 절대오차가 지수화에서 상대오차가 되어, $a = 9$에서 $6 \times 10^{-15}$이 되기 때문이에요.
- **베타이항**: $\log\Gamma(k+a) + \log\Gamma(n-k+b) - \log\Gamma(k+1) - \log\Gamma(n-k+1) + C$이고, 매개변수만의 상수 $C = \log\Gamma(n+1) - \log\Gamma(n+a+b) - \log B(a, b)$는 스레드별로 마지막 $(n, a, b)$에 대해 기억해요. 모든 $\log\Gamma$는 double-double이에요. 그래도 크기가 $n + a + b$에 비례하는 항끼리의 차라서 오차가 $n + a + b$에 비례해 커져요. 그래서 $n + a + b > 2^{35}$이면 pmf와 그것에 기대는 메서드(cdf, 분위수, 엔트로피)가 NaN이에요.

### 초기하: 이항 셋의 비와 정확한 정수

초기하 pmf $\binom{K}{k}\binom{N-K}{n-k}/\binom{N}{n}$은 아무 $p$에 대해서나 이항 pmf 셋의 비로 쓸 수 있어요.

$$
\frac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}} = \frac{b(k; K, p)\; b(n-k; N-K, p)}{b(n; N, p)}, \qquad b(j; m, p) = \binom{m}{j}p^j q^{m-j}
$$

$p$와 $q$의 거듭제곱이 위아래에서 정확히 지워지기 때문이에요. $p = n/N$으로 고르면 세 이항이 모두 자기 평균 근처에서 계산되어 편차가 작아요. 그래서 세 이항의 Loader 꼴을 log에서 더하고 빼요. 반올림된 $p$를 써도 항등식은 그대로 성립해요. 배열의 빠른 경로는 세 이항의 $X$를 two_sum으로 합치고 인자 $r = K(N-K)n(N-n)/(2\pi N k(K-k)(n-k)(N-K-n+k))$를 곱해요. 연산이 더 많아 상한이 $0.5E + 14.6$단위이므로 $E \le 2.5$(평균의 약 2.2 표준편차 안)에서만 빠른 경로를 써요.

전체 $N \le 120$에서는 pmf와 cdf를 정확한 128비트 정수의 비로 계산해요.

```cpp
// csrc/stats/dist/discrete_more.hpp, hyper_detail
// C(n, k) exactly for n <= 120 (the running product stays below C(120, 60) 120 < 2^128).
inline U choose(double nd, double kd) {
    if (kd < 0.0 || kd > nd) return 0;
    const int n = static_cast<int>(nd);
    const int k = static_cast<int>(std::min(kd, nd - kd));
    U r = 1;
    for (int i = 1; i <= k; ++i) r = r * static_cast<U>(n - k + i) / static_cast<U>(i);
    return r;
}
```

곱 `r * (n − k + i)`는 매 단계 $\binom{n-k+i}{i}\cdot i$라서 나눗셈이 언제나 나누어떨어져요. $\binom{120}{60} \approx 9.7 \times 10^{34}$에 120을 곱해도 $2^{128} \approx 3.4 \times 10^{38}$ 아래예요. cdf는 분자 $\sum_{j \le k}\binom{K}{j}\binom{N-K}{n-j}$를 정수로 더하고 분모로 한 번 나눠요. 위꼬리는 정수 뺄셈 $d - s$로 정확해요. 나눗셈 한 번의 반올림만 남으므로 결과는 1.5 ULP 안이고, 무엇보다 $F(k) = 1/2$ 같은 동점이 정확히 1/2로 나와요. log는 비가 1/2을 넘으면 $\operatorname{log1p}(-(d - a)/d)$로 구해 0 근처에서도 상대 정확도를 지켜요.

### 정수 위치의 함정: 최빈값

최빈값 공식은 대부분 "어떤 곱의 floor"예요. 이항은 $\lfloor (n+1)p \rfloor$인데, 곱을 double로 반올림하면 정수 바로 아래의 값이 그 정수로 올라가요.

```python
>>> (9 + 1) * 0.3
3.0
>>> sd.stats.Binomial(n=9, p=0.3).mode()
2.0
```

double `0.3`은 $0.29999999999999998889\ldots$이라 정확한 $(n+1)p$는 3보다 조금 작고, 참 최빈값은 2예요. 그래서 `two_prod`로 곱의 두 부분을 정확히 만들어 hi가 정수이면 lo의 부호를 봐요. lo = 0이면 곱이 정확히 정수, 곧 최빈값이 둘(그 정수와 하나 아래)이라 NaN이에요. 음이항은 나머지 $r = (n-1)q - mp$(가장 가까운 정수 $m$)를 정확한 곱으로 만들어 부호를 보고, 초기하는 $(n+1)(K+1)$과 $N+2$를 128비트 정수로 나눠 나머지를 봐요. 포아송은 정수 $\mu$에서 최빈값이 둘($\mu - 1$, $\mu$)이라 NaN이에요. 이항의 최빈값은 누적확률과 같은 한계를 써서, $n$이 $2^{52}$(`kMaxCount`, [아래](#반복의-상한과-nan))를 넘으면 NaN이에요($n = 2^{52}$ 자체는 값이 있어요).

## 누적확률

### 불완전 함수로 쓰는 분포

이항·포아송·음이항의 cdf는 special의 `bdtr`, `pdtr`, `nbdtr`과 그 보수(`bdtrc` 등)예요. 보수가 따로 있어서 위꼬리도 1 − cdf가 아니라 직접 계산해요. 그 안의 불완전 베타·감마는 [특수함수의 분포 함수](/internals/special/distributions/)에 있어요. log 꼬리는 연속 분포의 베타·감마와 같은 부품(`beta_detail::log_tail`, `gamma_detail::log_tail`)을 써서, 확률이 double의 정규수 아래로 내려가도 값이 있어요([연속 분포의 수치 기법](/internals/stats/continuous/)).

이 세 분포의 cdf는 정수 $k$를 불완전 함수의 모양 $k + 1$로 넘겨요. $k \ge 2^{53}$이면 $k + 1$이 double이 아니어서(반올림하면 $k$나 $k + 2$), 결과가 이웃 $k$의 cdf가 돼요. 차이는 pmf 하나예요. 그래서 그 pmf가 결과의 $2^{-56}$ 아래일 때만 값을 쓰고, 아니면 NaN이에요(`checked_past_counts`). 보장 영역에서 $k$가 $2^{53}$을 넘는 곳은 꼬리 깊숙한 곳이라 pmf가 0이에요.

포아송의 아주 먼 위꼬리($k > 2^{53}\mu$)는 불완전 감마의 지수가 double 범위를 넘어요. 거기서 위꼬리는 첫 항 $P(X = k+1)\,(1 + \mu/(k+2) + \cdots)$이고 둘째 항이 $2^{-53}$보다 작으므로 첫 항의 log를 써요. 음이항도 같은 방법으로 $P(X = k+1)/p$를 써요.

### 초기하와 베타이항: 비율 점화식 합

초기하와 베타이항은 cdf에 쓸 만한 불완전 함수가 없어요. 그래서 pmf를 더해요. 하지만 항마다 log pmf를 구하면 항 하나에 double-double $\log\Gamma$가 여럿 들어요. 대신 이웃 항의 비를 써요.

$$
\frac{P(j+1)}{P(j)} = \frac{(K-j)(n-j)}{(j+1)(N-K-n+j+1)} \quad (\text{초기하}), \qquad
\frac{(n-j)(j+a)}{(j+1)(n-j-1+b)} \quad (\text{베타이항})
$$

비는 네 인자의 곱과 몫이고, 각 인자는 정수(정확)이거나 정수 + 모양(two_sum으로 정확한 double-double)이에요. `Ratio4`가 이 넷을 담고, `tail_sum_dd`가 항을 double-double로 걸어요.

```cpp
// csrc/stats/discrete.hpp, disc::tail_sum_dd (발췌)
num::DD t{1.0, 0.0};
for (double j = k; dir > 0.0 ? j < last : j > last; j += dir) {
    const Ratio4 r = ratio(j);
    t = t * ((r.a1 * r.a2) / (r.b1 * r.b2));
    sum.add(t.hi);
    sum.c += t.lo;
    if (full) {
        if (t.hi < 1e-200) return -1.0;
    } else if (t.hi <= sum.s * 0x1p-60) {
        return sum.s + sum.c;
    }
}
if (last != end) return kNaN;  // the bound, with terms that still count beyond it
return sum.s + sum.c;
```

- 항은 첫 항에 대한 비 $t_j = P(j)/P(k)$로 다뤄요. 곱과 몫이 모두 double-double이라 한 걸음의 오차가 $2^{-104}$ 정도예요. float64 비를 쓰면 반올림이 걸음마다 쌓여 32항이면 $10^{-14}$에 닿는데, double-double이면 수천 항을 걸어도 log pmf에서 다시 맞출 필요가 없어요.
- 합은 Neumaier 보정 합이에요([아래](#neumaier-보정-합)). 항의 lo 부분은 보정 항에 바로 더해요.
- 항이 합의 $2^{-60}$ 아래로 떨어지면 멈춰요. 항이 바깥으로 갈수록 줄어드는 경우에만 이 규칙을 쓰고, 그렇게 되도록 아래처럼 시작점을 골라요.
- 항이 $2^{20}$개(`kMaxTailTerms`)를 넘어도 끝나지 않으면 NaN이에요. 잘린 합은 틀린 값이기 때문이에요.

합 전체의 log는 $\log P(\text{시작점}) + \log(\text{합})$이고, $\log P$는 double-double로 따로 계산해 둬요. 확률이 $10^{-300}$이어도 지수화하기 전까지 log가 double-double이라, log 크기 600에서 생기는 70 ULP의 지수화 오차가 없어요.

```python
>>> sd.stats.Hypergeometric(total=1000, successes=500, draws=500).logcdf(10)
-595.5646608186696
```

Arb로 만든 참값은 $-595.564660818669639\ldots$예요.

### 가장 큰 항에서 바깥으로

항이 바깥으로 갈수록 줄어들려면, 더하는 쪽의 가장 큰 항에서 시작해야 해요(`disc_sum::log_side`). 단봉 분포에서 아래꼬리 $P(X \le k)$를 더할 때

- $k$가 최빈값 $m$ 이하이면 가장 큰 항은 $k$예요. $k$에서 아래로 걸어요.
- $k > m$이면 그 쪽에 최빈값이 있어요. $[\text{lo}, m]$은 $m$에서 아래로, $(m, k]$는 $m + 1$에서 위로 걸어요. 두 합은 모두 줄어드는 항의 합이고, $P(m)$에 대한 비로 합쳐요.

위꼬리는 거울상이에요.

### 어느 쪽을 더하나요

$P(X \le k)$와 $P(X > k)$ 중 1/2 아래인 쪽을 직접 더하고, 다른 쪽은 1에서 그 값을 빼서 만들어요(`disc_sum::prob`). 1/2을 넘는 쪽을 더해서 빼면 작은 쪽의 자릿수를 잃어요. 어느 쪽이 작은지는 미리 모르므로 평균으로 어림해요. $k$가 평균보다 작으면 아래꼬리가 작다고 보고 먼저 더해요. 결과가 1/2을 넘으면(어림이 틀렸으면) 반대쪽을 다시 더해요.

최빈값이 아니라 평균으로 고르는 이유는 퍼진 분포 때문이에요. $a < 1$인 베타이항($n = 1831$)처럼 최빈값이 한쪽 끝에 붙고 질량이 넓게 퍼지면, 최빈값 기준으로 고른 쪽이 실제로는 0.992일 수 있어요. 그러면 1 − 0.992의 상쇄로 $4 \times 10^{-13}$이 틀려요.

한쪽 합이 상한을 넘어 NaN이면, 다른 쪽이 1/2 아래일 때는 그것으로 답해요. 1/2 위의 확률은 양의 항의 합이라 그대로 쓸 수 있지만, 그 log는 0 근처라서 시작한 log pmf의 절대오차가 그대로 남아요. 그래서 그 경우의 log는 NaN이에요.

### 단봉이 아닌 베타이항

베타이항은 $a + b \le 2$이면 단봉이 아니에요. 양 끝으로 갈수록 pmf가 다시 올라가는 U자형이거나, 한쪽으로만 줄어들어요.

pmf가 오르내리는 지점은 비 $P(k+1)/P(k)$가 1을 지나는 곳이에요. 비의 이차항이 지워져서 $k(2 - a - b) \ge n(1 - a) + b - 1$이라는 일차 부등식이 돼요(`BetaBinomial::turn`). 단봉이 아니면 각 쪽을 끝까지 모두 더해요(`full`). 항이 $10^{-200}$ 아래로 내려가면 double-double 비가 언더플로할 수 있으므로, 그때는 float64 비로 걸으면서 8항마다 double-double log pmf에서 항을 다시 맞추는 합(`full_sum`)으로 바꿔요. 이 합의 log도 double-double이에요. 끝에서 pmf가 올라가면 합이 첫 항보다 훨씬 커서, log를 float64로 반올림하면 확률에 $\lvert\log\rvert$ ULP가 남기 때문이에요.

### 로그 급수의 꼬리: Euler–Maclaurin

로그 급수의 위꼬리는

$$
P(X > k) = \frac{T(k)}{L}, \qquad T(k) = \sum_{j > k}\frac{p^j}{j} = p^{k+1}\,\Phi(p, 1, k+1), \qquad \Phi(p, 1, v) = \sum_{m \ge 0}\frac{p^m}{v + m}
$$

예요. $\Phi$는 Lerch의 초월 함수예요. 항이 $p^m$으로 줄어드므로 직접 더하면 $2^{-60}$까지 약 $42/(-\log p)$항이 필요해요. $p < 0.9$($-\log p > 0.1$)이면 416항 안에 끝나므로 직접 더해요(상한 512항). $p$가 1에 가까우면 항이 수만–수백만 개라, **Euler–Maclaurin 공식**으로 합을 적분으로 바꿔요.

$f(x) = e^{-wx}/(V + x)$, $w = -\log p$라 두면 Euler–Maclaurin 공식[3]은

$$
\sum_{m \ge 0} f(m) = \int_0^\infty f(x)\,dx + \frac{f(0)}{2} - \sum_{j \ge 1}\frac{B_{2j}}{(2j)!}\,f^{(2j-1)}(0)
$$

이에요($B_{2j}$는 Bernoulli 수). $f$와 그 도함수가 무한대에서 0이라 오른쪽 끝의 항이 없어요. 각 부분은 닫힌 꼴이에요.

- **적분**: $\int_0^\infty e^{-wx}/(V+x)\,dx = e^{Vw}E_1(Vw)$예요. $E_1$은 지수 적분이고, $e^x E_1(x)$는 연분수
  $$
  e^x E_1(x) = \cfrac{1}{x + 1 - \cfrac{1^2}{x + 3 - \cfrac{2^2}{x + 5 - \cdots}}}
  $$
  로 바로 나와요($x > 1$). $e^{Vw}$와 $E_1$을 따로 구하면 넘치거나 언더플로하지만 이 비율은 크기가 $1/x$ 정도라 안전해요. 연분수는 special의 `lentz_backward`로 계산해요([연분수와 Lentz 방법](/internals/special/techniques/)). $x \le 1$이면 $e^x \cdot E_1(x)$를 special의 `expn`으로 구해요.
- **도함수**: Leibniz 규칙으로 $f^{(n)}(0) = (-1)^n\,n!\,\frac1V\sum_{i \le n}\frac{w^{n-i}}{(n-i)!\,V^i}$이고, 합의 항이 모두 같은 부호라 상쇄가 없어요.
- **보정의 크기**: $j$번째 보정은 대략 $(h/2\pi)^{2j}(2j)!$로 줄어요($h = \max(w, 1/V)$). 앞의 항을 $V = k + 1 + M \ge 20$이 될 때까지 직접 더해 $1/V \le 0.05$로 만들고, $w \le 0.1$이므로 $h \le 0.1$이에요. 그러면 보정 10항으로 $2^{-60}$에 닿아요.

```cpp
// csrc/stats/dist/discrete_more.hpp, logser_detail::phi_em (발췌)
double s = 0.0, t = 1.0, V = v;
while (V < 20.0) {
    s += t / V;
    t *= p;
    V += 1.0;
}
double tail = exp_e1(V * lw) + 0.5 / V;
const double r = 1.0 / V;
double nfact = 1.0;  // n!
for (int j = 1; j <= 10; ++j) {
    const int n = 2 * j - 1;
    nfact *= (j == 1 ? 1.0 : double(n) * (n - 1));
    double poly = 0.0, c = 1.0;  // sum_{q <= n} lw^q / q! r^(n-q); c = lw^q / q!
    for (int q = 0; q <= n; ++q) {
        poly += c * std::pow(r, n - q);
        c *= lw / (q + 1);
    }
    const double d = -nfact * r * poly;  // f^(n)(0), n odd
    const double corr = kBernoulliOverFactorial[j - 1] * d;
    tail -= corr;
    if (std::fabs(corr) <= tail * 0x1p-60) break;
}
return s + t * tail;
```

다른 방법은 이 구간에서 쓸 수 없어요. $\Phi$를 초기하 함수 ${}_2F_1$로 바꾸는 변환 꼴은 항이 $e^{vw}$ 크기로 상쇄해서 $vw \approx 14$에서 결과가 음수가 돼요. $\Phi$의 점근 급수는 $vw = 30$에서도 $10^{-12}$밖에 맞지 않아요. Euler–Maclaurin은 모든 항의 부호와 크기가 통제되어 이런 문제가 없어요.

```python
>>> sd.stats.LogSeries(p=0.999).ccdf(5000)
0.00016564823190492754
```

Arb로 만든 참값은 $1.65648231904927536\ldots \times 10^{-4}$이에요. scipy 1.18.1의 `logser(0.999).sf(5000)`은 `0.00016564823190499524`로 상대 $4 \times 10^{-13}$이 틀려요.

아래꼬리 $P(X \le k)$는 위꼬리가 1/2 이하이거나 $k > 1000$이면 1 − 위꼬리이고, 아니면 pmf를 직접 더해요(1000항 이하).

### Zipf: 직접 합과 Hurwitz 차

Zipf의 위꼬리는 $P(X > k) = \zeta(a, k+1)/\zeta(a)$(Hurwitz 제타)예요. 아래꼬리는 다음처럼 나눠요.

- **$k \le 1000$**: $\sum_{j \le k} j^{-a}$를 작은 항부터($j = k$에서 1로) 더해 $\zeta(a)$로 나눠요.
- **$k > 1000$, 위꼬리가 작을 때** ($\zeta(a, k+1) \le \zeta(a)/4$): $(\zeta(a) - \zeta(a, k+1))/\zeta(a)$예요. 상쇄는 많아야 4/3배예요.
- **그 밖**: $a$가 1에 가까우면 $\zeta(a)$와 $\zeta(a, k+1)$이 모두 크고(약 $1/(a-1)$) 거의 같아서 차가 상쇄해요. 그래서 1000항을 직접 더하고, 나머지 $\zeta(a, M) - \zeta(a, K)$($M = 1001$, $K = k + 1$)는 Euler–Maclaurin 꼴로 차를 직접 만들어요. 주항은
  $$
  \frac{M^{1-a} - K^{1-a}}{a - 1} = \frac{M^{1-a}\,\bigl(1 - (K/M)^{1-a}\bigr)}{a - 1} = M^{1-a}\,\frac{-\operatorname{expm1}\bigl((1-a)\log(K/M)\bigr)}{a - 1}
  $$
  이고, `expm1`이라서 $a \to 1$에서도 상쇄가 없어요. 나머지 보정($q^{-a}/2$와 Bernoulli 항 셋)은 작아요.

```python
>>> sd.stats.Zipf(a=1.0001).cdf(1e8)
0.0018979852473547097
```

Arb로 만든 참값은 $0.00189798524735470985\ldots$예요.

위꼬리의 log는 $\log\zeta(a, k+1) - \log\zeta(a)$예요. $\zeta(a, q)$가 $2^{-1000}$ 아래로 언더플로하면 $-a\log q + \log\sum_j(1 + j/q)^{-a}$($a/q \ge 1$, 49항 이하)나 Euler–Maclaurin의 주항 꼴로 바로 log를 구해요. 분위수 탐색이 쓰는 `logccdf_dd`가 이 값이에요.

### 기하

$P(X > k) = q^k = \exp(k\log q)$이고, 지수 $k\log q$를 double-double로 만들어 지수화해요. 아래꼬리는 $-\operatorname{expm1}(e_h) - e^{e_h}e_l$이에요. 배열 커널은 스칼라 $p$에 대해 $\log q$, $\log p$를 chunk마다 한 번만 구해요.

## 모멘트

닫힌 꼴이 있으면 그대로 쓰되, 0 근처에서 상쇄하는 곳을 다시 써요.

- **이항의 첨도** $(1 - 6pq)/(npq)$: 분자가 $p = 0.211$, $0.789$에서 0을 지나요. $pq$와 분자를 double-double로 만들어요.
- **초기하의 왜도** $\dfrac{(N-2K)(N-2n)\sqrt{N-1}}{(N-2)\sqrt{nK(N-K)(N-n)}}$: $N = 2K$나 $N = 2n$이면 정확히 0이에요. 중심 모멘트의 합으로 만들면 $10^{-16}$이 남아요.
- **초기하의 첨도**: 분자
  $$
  (N-1)N^2\bigl(N(N+1) - 6K(N-K) - 6n(N-n)\bigr) + 6nK(N-K)(N-n)(5N-6)
  $$
  가 크게 상쇄해요(정확히 0이 되기도 해요). 그래서 이 괄호를 128비트 정수로 계산해요. 항이 $2^{124}$ 아래인 $N \le 2^{24}$까지 정확하고, 그 위는 NaN이에요. 첨도가 $1/\sigma^2$ 정도로 작아서 m₄/m₂² − 3으로는 의미 있는 자리가 남지 않기 때문이에요.
- **베타이항의 첨도**: 교과서 꼴 $m_4/m_2^2 - 3$은 0 근처에서 상쇄해요(초과 첨도 0.013에서 $4 \times 10^{-13}$). $s = a + b$, $d = b - a$로 두고 $s^2 - d^2 = 4ab$를 넣어 −3을 대수적으로 지우면
  $$
  \gamma_2 = \frac{d^2 A/4 - s^2 B/2}{ab\,n\,(s+2)(s+3)(s+n)}
  $$
  $$
  A = 36n^2 + 6s^3 + s^2(30n + 6) + s(30n^2 + 36n), \quad B = 6n^2 + 3ns^2 + s^3 + 3n^2 s + 6ns + 2s + 3s^2
  $$
  이에요. $A$와 $B$는 양항 다항식이고, 괄호 하나만 상쇄해요. $s$와 $d$를 two_sum으로 정확히 만들고 괄호를 double-double로 계산해서, 남는 것은 괄호 자체의 상쇄에 대한 $2^{-106}$뿐이에요.

  ```python
  >>> sd.stats.BetaBinomial(n=100, a=0.5, b=1.5).kurtosis()
  -0.000196078431372549
  >>> -1 / 5100
  -0.000196078431372549
  ```

  참값은 정확히 $-1/5100$이에요(유리수 pmf로 중심 모멘트를 정확히 더해 얻어요). scipy 1.18.1은 `-0.0001960784313723707`로 상대 $9 \times 10^{-13}$이 틀려요. 왜도는 닫힌 꼴이라 $a = b$에서 정확히 0이에요.
- **로그 급수**: 원모멘트은 $E[X^r] = pA_r/(Lw^r)$($w = 1 - p$, $A = 1, 1, 1+p, 1+4p+p^2$)예요. $p \le 1/2$에서는 $X$가 거의 언제나 1이라 원모멘트로 만든 중심 모멘트가 상쇄해요. 그래서 거기서는 중심 모멘트를 최빈값에서 바깥으로 직접 더해요(`disc_sum::central`, 200항 안팎). $p > 1/2$에서는 $L$이 커서 원모멘트을 써도 상쇄가 없어요. 분산의 $L - p$는 `log1pmx_neg`로 상쇄 없이 만들어요.
- **Zipf**: $\sum_k (k-\mu)^m k^{-a}$를 $k \le 1000$까지 보정 합으로 더하고, 나머지는 이항 전개 $\sum_j\binom{m}{j}(-\mu)^{m-j}\zeta(a - j, 1001)$로 Hurwitz 제타에 맡겨요. $\mu/1000$이 작아 이 전개는 거의 상쇄하지 않아요. $m$차 모멘트는 $a > m + 1$에서만 유한해요. 분산이 유한하고 그 모멘트가 발산하면 inf, 분산이 유한하지 않으면 NaN이에요.

```python
>>> Z = sd.stats.Zipf
>>> Z(a=3).kurtosis(), Z(a=4.5).kurtosis()
(nan, inf)
```

베타이항의 모멘트는 $a, b$가 $[2^{-150}, 2^{150}]$ 안에서만 계산해요(그 밖은 NaN). 다만 $2^{-1021}$ 아래의 모양은 위의 두 점 분포라, 모멘트도 그 분포의 닫힌 꼴이에요. 평균 $nq$, 분산 $n^2 q q_c$, 왜도 $(q_c - q)/\sqrt{q q_c}$, 첨도 $(1 - 6 q q_c)/(q q_c)$이고, 한쪽 질량이 0이면 분산 0, 왜도·첨도 NaN이에요.

```python
>>> T.mean(), T.variance(), T.skewness(), T.kurtosis()
(2.5, 18.75, 1.1547005383792517, -0.6666666666666666)
>>> sd.stats.BetaBinomial(n=10, a=1e-200, b=1.0).mean()
nan
```

`disc_sum::central`의 멈춤 규칙은 아래 엔트로피와 같아요. 상한은 4096항(`kMaxMomentTerms`)이에요.

## 엔트로피

### 최빈값에서 바깥으로

섀넌 엔트로피 $H = -\sum_k P(k)\log P(k)$(단위 nat)를 지지집합 위에서 더해요. 단봉 분포는 최빈값 $m$에서 양쪽으로 걸어요(`disc::entropy_sum`). 항 $t_k = P(k)/P(m)$은 비율 점화식(double-double)으로 계산하고, 항마다 float64 log 하나만 써요. 항마다 double-double log pmf를 새로 구하는 것보다 훨씬 가벼워요.

합의 꼴에도 요령이 있어요. $P(k) = t_k P(m)$이고 $\sum P(k) = 1$이므로 $P(m) = 1/(1 + \rho)$, $\rho = \sum_{k \ne m} t_k$예요. 그러면

$$
H = -\sum_k P(k)\bigl(\log P(m) + \log t_k\bigr) = \log(1 + \rho) + \frac{w}{1 + \rho}, \qquad w = \sum_k t_k(-\log t_k)
$$

이에요. 두 부분 모두 음이 아니고($t_k \le 1$), $\log P(m)$을 거치지 않으므로 그 반올림(크기의 한 ULP만큼의 절대오차)이 엔트로피의 오차로 들어오지 않아요. $\log P(m)$은 언제 멈출지를 정하는 데만 써요.

### Neumaier 보정 합

항이 많으면 합의 반올림이 쌓여요. 항 $n$개를 그냥 더하면 오차가 대략 $\sqrt n$ ULP(나쁘면 $n$ ULP)로 자라요. 음이항($p = 1.6 \times 10^{-4}$)은 항이 $10^6$개라 보정 없이 더하면 $2 \times 10^{-13}$이 틀려요.

보정 합은 덧셈 $s + x$마다 잃은 부분을 정확히 계산해 따로 모아요. Kahan의 방법은 $c = (s - t) + x$($t = \mathrm{fl}(s + x)$)인데, $\lvert x\rvert > \lvert s\rvert$이면 이 식이 잃은 부분을 정확히 주지 못해요. Neumaier[2]는 두 크기를 비교해 큰 쪽에서 빼요.

```cpp
// csrc/stats/discrete.hpp
struct KahanSum {
    double s = 0.0, c = 0.0;
    void add(double x) {
        const double t = s + x;
        c += std::fabs(s) >= std::fabs(x) ? (s - t) + x : (x - t) + s;
        s = t;
    }
    double value() const { return s + c; }
};
```

$\lvert s\rvert \ge \lvert x\rvert$이면 Dekker의 Fast2Sum 정리에 따라 $s - t$가 정확하고, $(s - t) + x$는 $s + x$의 반올림 오차 그 자체예요. 반대 경우는 역할을 바꿔요. 그래서 각 덧셈의 오차가 정확히 $c$에 모이고, 최종 오차는 항 수와 거의 무관하게 몇 ULP예요. 이름은 KahanSum이지만 Neumaier의 변형이에요. 꼬리 합(`tail_sum_dd`)도 같은 규칙을 써요.

### 언제 멈추나요: 꼬리 어림

지지집합이 무한하면 어디선가 멈춰야 해요. "이번 항이 합의 $2^{-60}$ 아래면 멈춘다"는 규칙은 항 하나만 봐요. 표준편차가 큰 분포에서는 그 뒤에 비슷한 크기의 항이 수만 개 남아 있어요. 음이항($n = 544$, $p = 10^{-4}$, 표준편차 $2.3 \times 10^5$)에서 그 규칙은 8.6 표준편차에서 멈추고, 남은 꼬리 때문에 엔트로피가 $5 \times 10^{-13}$이 틀려요.

그래서 남은 꼬리를 어림해요. 최빈값을 지난 뒤에는 이웃 항의 비 $r$이 계속 줄어드므로, 이번 항 $u$ 뒤의 나머지는 많아야 기하급수 $u r/(1 - r)$ 정도예요. 이것이 합의 $2^{-60}$ 아래일 때 멈춰요.

```cpp
// csrc/stats/discrete.hpp, disc::entropy_run (발췌)
if (!full && (dir > 0.0 ? k > mode + 1.0 : k < mode - 1.0)) {
    const double r = prev > 0.0 ? u / prev : 0.0;
    if (r < 1.0 && u * r <= (1.0 - r) * std::fabs(sums.h.s) * 0x1p-60) return true;
}
```

항이 $10^{-290}$ 아래로 내려가도 멈춰요. 줄어드는 걸음의 나머지는 그보다 작아요.

### 단봉이 아닐 때

$a + b \le 2$인 베타이항은 양 끝에서 골짜기 쪽으로 걸어요(`entropy_sum_ends`). 골짜기로 갈수록 비가 1로 올라가므로 기하급수 어림이 성립하지 않아요. 그래서 모든 점을 더하고(점이 $2^{25}$개를 넘으면 NaN), 각 쪽의 합을 그 끝의 pmf(double-double)로 되돌려요.

### 닫힌 꼴과 점근식

- **베르누이**: $\operatorname{entr}(p) + \operatorname{entr}(q)$, **기하**: 그것을 $p$로 나눈 것이에요. $q = 1 - p$는 two_sum으로 정확하고, log와 곱이 double-double이에요.
- **포아송** $\mu \ge 10^4$: 합 대신 점근식 $\tfrac12(1 + \log 2\pi\mu) - \frac{1}{12\mu} - \frac{1}{24\mu^2} - \frac{19}{360\mu^3}$을 써요. 첫 두 항은 double-double이에요.
- **로그 급수**: $-\log P(k) = kw + \log k + \log L$($w = -\log p$)이므로 $H = w\,E[X] + E[\log X] + \log L$이에요. $E[\log X] = T/L$, $T = \sum_k p^k\log k/k$예요. $w > 2^{-10}$이면 위의 합이에요. $p$가 1에 아주 가까우면 합이 $42/w$항 넘게 필요하므로, $T = -\partial_s \mathrm{Li}_s(e^{-w})\vert_{s=1}$를 다중로그의 $w = 0$ 둘레 전개[3]
  $$
  \mathrm{Li}_s(e^{-w}) = \Gamma(1-s)\,w^{s-1} + \sum_{n \ge 0}\zeta(s - n)\frac{(-w)^n}{n!}
  $$
  에서 얻어요. $s = 1$에서 두 극이 지워지고
  $$
  T = \frac{\log^2 w}{2} + \gamma\log w + C - \sum_{n \ge 1}\zeta'(1-n)\frac{(-w)^n}{n!}, \qquad C = \frac{\gamma^2}{2} + \frac{\pi^2}{12} + \gamma_1
  $$
  이 남아요($\gamma_1$은 첫 Stieltjes 상수). $n = 6$부터 $\lvert\zeta'(1-n)\rvert/n! < (2\pi)^{-n}$이라 다섯 항에서 끊으면 나머지가 $2^{-75}$ 아래예요. $\log w$와 $L$은 double-double이에요. $T/L$이 $H$의 대부분을 차지하는데, float64 $\log w$를 쓰면 $\log^2 w$에서 반올림이 두 번 들어가기 때문이에요.
- **베타이항의 두 점 분포**(모양 $< 2^{-1021}$): $-(q\log q + q_c\log q_c)$예요. 1에 가까운 질량의 log는 다른 쪽 작은 질량에서 `log1p`로 만들어서, $q$가 $10^{-308}$ 정도로 작아도 두 항이 상쇄 없이 나와요. 한쪽 질량이 0이면 합을 거치지 않고 정확히 0이에요.
- **Zipf**: $H = \log\zeta(a) + a S/\zeta(a)$, $S = \sum_k k^{-a}\log k$예요. $k < 10^4$은 작은 항부터 보정 합으로 더하고, 나머지는 $f(x) = x^{-a}\log x$의 Euler–Maclaurin 꼬리 $\int_K^\infty f + f(K)/2 - f'(K)/12 + f'''(K)/720$로 닫아요.

```python
>>> sd.stats.LogSeries(p=0.9999).entropy()
6.456272183407318
>>> sd.stats.Poisson(mu=1e5).entropy()
7.175400432352287
```

## 반복의 상한과 NaN

이산 분포의 메서드는 어떤 매개변수에서도 정해진 걸음 수 안에 끝나요. 합이 상한 안에 끝나지 않으면 잘린 합을 내지 않고 NaN을 내요. 잘린 합은 아무 표시 없는 틀린 값이기 때문이에요.

| 상한 | 값 | 무엇을 셈하나요 |
|---|---|---|
| `kMaxSearchSteps` | 1100 | 분위수 탐색의 한 방향 배증, 그리고 이분. double은 $2^{1024}$ 아래라 1025번의 배증이면 어떤 분위수에도 닿고, 이분은 많아야 1024 + 53번이에요 |
| `kMaxTailTerms` | $2^{20}$ | 꼬리 합(초기하, 베타이항)의 항 |
| `kMaxEntropyTerms` | $2^{25}$ | 엔트로피 합의 항 |
| `kMaxEntropyVariance` | $2^{42}$ | 분산이 이것을 넘으면 엔트로피 합을 시작하지 않아요(표준편차 $2^{21}$에서 $2^{25}$항은 16 표준편차) |
| `kMaxMomentTerms` | 4096 | 중심 모멘트 합의 항 |
| `kMaxCount` | $2^{52}$ | 이항의 $n$, 초기하의 전체. 그 위는 $n - k$, $k + 1$이 double이 아닐 수 있어요 |

보장 영역(이항 $n \le 10^6$, 포아송 $\mu \le 10^6$, 기하 $p \ge 10^{-9}$, 음이항 $n \in [0.1, 10^4]$·$p \ge 10^{-4}$, 초기하 전체 ≤ 3000, 베타이항 $n \le 2000$·$a, b \in [0.1, 100]$, 로그 급수 $p \ge 10^{-8}$, Zipf $a \le 60$)에서는 어느 상한에도 닿지 않아요. 가장 느린 호출은 `NegativeBinomial(n=1e4, p=1e-4).entropy()`이고, 항이 약 $1.9 \times 10^7$개라 0.23초쯤 걸려요.

```python
>>> sd.stats.Binomial(n=2.0**53, p=0.5).cdf(10.0)
nan
>>> sd.stats.Hypergeometric(total=2.0**25, successes=2.0**24, draws=1000).kurtosis()
nan
>>> sd.stats.NegativeBinomial(n=1, p=1e-7).entropy()
nan
```

음이항의 엔트로피는 오른쪽 꼬리가 $q^k$로 줄어서 $2^{-60}$까지 $42/p$걸음이 필요해요. $p < 2^{-20}$이면 그것만으로 상한을 넘으므로 시작하지 않아요. NaN이 되는 범위 전체는 [이산 분포 API](/api/stats/binomial/)의 각 페이지에 있어요.

## 정확도

보장 영역의 61만 점을 Arb(구간 산술)로 만든 참값과 대조하면, 값 메서드(pmf부터 엔트로피까지)의 최대 오차는 계약 단위로 $6.3 \times 10^{-15}$(`LogSeries.logccdf`)이고 분위수는 모든 점이 허용 구간 안이에요(`bench/stats/accuracy.md`). 엔트로피는 모든 분포에서 $4.5 \times 10^{-16}$ 이하예요. 같은 점에서 scipy 1.18.1은 꼬리에서 크게 틀리는 메서드가 있고(이항·음이항의 cdf 상대오차 1.0, 초기하의 cdf와 로그 급수의 logpmf inf, 초기하의 logpmf $2 \times 10^{293}$), 기하와 포아송의 `isf`는 4000점 가운데 1443점에서 참값이 유한한데 inf나 NaN을 내요. 메서드별 표와 속도는 [정확도와 성능](/internals/stats/accuracy-performance/)에 있어요.
