## 한눈에 보기

[`AAA`](/api/interpolate/AAA/)는 표본 $(z_i, f_i)$, $i = 1, \ldots, M$에서 무게중심 꼴의 유리식

$$
r(z) = \frac{\mathcal N(z)}{\mathcal D(z)} = \frac{\displaystyle\sum_{j=1}^m \frac{w_jf_j}{z - z_j}}{\displaystyle\sum_{j=1}^m \frac{w_j}{z - z_j}}
$$

을 만들어요. 지지점 $z_j$는 표본 가운데서 고르고 $f_j$는 그 표본의 값이에요. 무게 $w_j$가 0이 아니면 $r(z_j) = f_j$라서 지지점에서는 보간이고, 나머지 표본에서는 최소제곱의 뜻으로 가까워요. 분자와 분모는 각각 $m - 1$차 다항식을 $\ell(z) = \prod_j(z - z_j)$로 나눈 것이니, $r$은 $(m - 1, m - 1)$차 유리식이에요.

알고리즘은 Nakatsukasa, Sète, Trefethen(2018)의 것이고, 단계는 scipy 1.18.1의 것을 하나하나 그대로 따라가요. 실수 자료는 실수 연산(`dgesdd`, `dggev`), 복소수 자료는 복소수 연산(`zgesdd`, `zggev`)이에요.

## AAA의 걸음

### 표본 정리

```cpp
    // csrc/interpolate/aaa.cpp
    // the samples: finite values, sorted points, the first sample of a repeated point (numpy's unique)
    std::vector<std::int64_t> keep;
    for (std::int64_t i = 0; i < n; ++i)
        if (finitev(f[i])) keep.push_back(i);
    std::stable_sort(keep.begin(), keep.end(), [&](std::int64_t a, std::int64_t b) { return lessv(z[a], z[b]); });
    for (std::size_t i = 0; i < keep.size(); ++i)
        if (i == 0 || !samev(z[keep[i]], z[keep[i - 1]])) out.zs.push_back(z[keep[i]]), out.fs.push_back(f[keep[i]]);
    const std::int64_t M = static_cast<std::int64_t>(out.zs.size());
    if (M == 0) return;
    const std::vector<T>& Z = out.zs;
    const std::vector<T>& F = out.fs;
    const T mean = divr(np_sum(F.data(), M), static_cast<double>(M));
    double fmax = 0.0;
    for (const T& v : F) fmax = std::max(fmax, absv(v));
    const double atol = rtol * fmax;
    std::vector<T> R(M, mean);
```

값이 유한하지 않은 표본을 버리고, 점을 정렬하고(복소수는 실수부, 허수부 순), 같은 점은 처음 표본만 남겨요. numpy의 `unique`가 하는 일과 같아요. 출발점 $R$은 $f$의 평균이고 그 합은 numpy의 pairwise 합을 그대로 옮긴 `np_sum`이에요. 멈춤 기준 `atol`은 $\mathrm{rtol}\cdot\max\lvert f\rvert$이고 `rtol`의 기본은 $\varepsilon^{3/4}$($\varepsilon = 2^{-52}$)예요.

### 지지점 고르기

```cpp
    // csrc/interpolate/aaa.cpp
    for (std::int64_t m = 0; m < steps; ++m) {
        // the next support point: numpy's argmax of |f - R| over the other samples (a NaN wins)
        std::int64_t jj = -1;
        double best = -kInf;
        for (std::int64_t i = 0; i < M; ++i) {
            if (!mask[i]) continue;
            const double e = absv(subv(F[i], R[i]));
            if (e != e) {
                jj = i;
                break;
            }
            if (jj < 0 || e > best) best = e, jj = i;
        }
        zj.push_back(Z[jj]);
        fj.push_back(F[jj]);
        std::vector<T> c(M), a(M);
        for (std::int64_t i = 0; i < M; ++i) {
            c[i] = divv(T{1}, subv(Z[i], Z[jj]));
            a[i] = mulv(subv(F[i], F[jj]), c[i]);
        }
        C.push_back(std::move(c));
        A.push_back(std::move(a));
        mask[jj] = 0;
        const lint cols = m + 1;
        lint rows = 0;
        for (std::int64_t i = 0; i < M; ++i) rows += mask[i];
```

걸음마다 아직 지지점이 아닌 표본 가운데 $\lvert f_i - R_i\rvert$가 가장 큰 것을 지지점으로 더해요. 지금의 근사가 가장 크게 틀린 곳에 보간 조건을 하나 더 거는 욕심 많은 선택이에요. 같은 값이 여럿이면 앞의 것, NaN이 있으면 첫 NaN이에요. numpy `argmax`의 규칙이라 scipy와 같은 표본을 골라요.

지지점이 정해지면 모든 표본에서 Cauchy 열 $C_{ij} = 1/(z_i - z_j)$와 Loewner 열 $A_{ij} = (f_i - f_j)C_{ij}$를 하나씩 더해 둬요. 열은 걸음 사이에 다시 계산하지 않아요.

### 무게: 선형화된 최소제곱

지지점이 아닌 표본에서 $r(z_i) \approx f_i$이길 바라요. $f_i\mathcal D(z_i) - \mathcal N(z_i)$는 무게에 대해 선형이고

$$
f_i\mathcal D(z_i) - \mathcal N(z_i) = \sum_j \frac{w_j(f_i - f_j)}{z_i - z_j} = (Aw)_i
$$

예요. 그래서 $\lVert w\rVert_2 = 1$ 아래에서 $\lVert Aw\rVert_2$를 가장 작게 하는 $w$를 무게로 해요. 그 답이 $A$의 가장 작은 특이값에 딸린 오른쪽 특이벡터예요. 분모를 곱한 선형화라 $\lvert r - f\rvert$ 자체의 최소는 아니지만, 무게가 특이벡터 하나로 바로 나와요.

```cpp
        // csrc/interpolate/aaa.cpp
        wj.assign(static_cast<std::size_t>(cols), T{});
        if (rows >= cols) {
            if (!ill) {
                pack(false);
                svd('S', rows, cols, Am, s, vt, sc);
                if (s[0] / s[cols - 1] > ill_tol) ill = true;
            }
            if (ill) {
                col_norm.assign(static_cast<std::size_t>(cols), 0.0);
                for (lint j = 0; j < cols; ++j) {
                    double q = 0.0;
                    for (std::int64_t i = 0; i < M; ++i)
                        if (mask[i]) {
                            const T v = A[j][i];
                            if constexpr (std::is_same_v<T, double>) q += v * v;
                            else q += v.real() * v.real() + v.imag() * v.imag();
                        }
                    col_norm[j] = std::sqrt(q);
                    if (col_norm[j] == 0) col_norm[j] = 1.0;  // a zero column stays as it is (scipy: NaN)
                }
                pack(true);
                svd('S', rows, cols, Am, s, vt, sc);
            }
            double smin = s[0];
            for (double v : s) smin = std::min(smin, v);
            std::int64_t count = 0;
            for (lint r = 0; r < cols; ++r) {
                if (s[r] != smin) continue;
                for (lint j = 0; j < cols; ++j) {
                    const T v = conjv(vt[r + j * cols]);
                    wj[j] = count == 0 ? v : addv(wj[j], v);
                }
                ++count;
            }
            const double root = std::sqrt(static_cast<double>(count));
            for (lint j = 0; j < cols; ++j) wj[j] = divr(wj[j], root);
            if (ill)
                for (lint j = 0; j < cols; ++j) wj[j] = divr(wj[j], col_norm[j]);
        } else {
            pack(false);
            svd('A', rows, cols, Am, s, vt, sc);
            double smax = 0.0;
            for (double v : s) smax = std::max(smax, v);
            const double tol = smax * kEps * static_cast<double>(std::max(rows, cols));
            lint num = 0;
            for (double v : s) num += v > tol;
            const lint nm = cols - num;
            std::vector<T> q(static_cast<std::size_t>(nm));
            const double root = std::sqrt(static_cast<double>(nm));
            for (lint j = 0; j < cols; ++j) {
                for (lint r = 0; r < nm; ++r) q[r] = conjv(vt[(num + r) + j * cols]);
                wj[j] = divr(np_sum(q.data(), nm), root);
            }
        }
```

갈래는 셋이에요.

- **행이 열보다 많을 때.** 남은 표본의 행만 모은 $A$를 `gesdd`(`'S'`)로 분해해 $V^H$의 행 가운데 가장 작은 특이값의 것을 켤레로 가져와요. 같은 최솟값이 여럿이면 그 벡터들을 더해 $\sqrt{\text{개수}}$로 나눠요. scipy가 numpy로 하는 계산을 그대로 옮긴 것이에요.
- **조건이 나쁠 때.** $\sigma_1/\sigma_{\min} \gt 1/(3\varepsilon)$이 한 번 되면 그 뒤로는 열을 2-노름으로 나눈 행렬을 분해하고, 나온 무게를 다시 노름으로 나눠요. 열의 크기가 크게 다르면 작은 특이값의 벡터가 반올림에 묻히기 때문이에요. 이 전환은 한 번 일어나면 끝까지 이어져요.
- **행이 열보다 적을 때.** 표본이 거의 다 지지점이 된 끝 무렵이에요. `gesdd`(`'A'`)로 $V^H$ 전체를 구하고, numpy `matrix_rank`의 허용치 $\sigma_{\max}\,\varepsilon\max(\text{행}, \text{열})$로 센 랭크 뒤의 행들, 곧 영공간 기저를 모두 더해 $\sqrt{\text{크기}}$로 나눠요.

`gesdd`는 행렬을 Householder 반사로 이중대각으로 만든 뒤 분할 정복으로 특이값과 벡터를 구해요. 그 안의 일은 [SVD](/internals/linalg/svd/)에 있어요. 걸음마다 $M \times m$ 분해 한 번이 AAA의 시간 거의 전부예요.

### 근사와 멈춤

```cpp
// csrc/interpolate/aaa.cpp
        // the rational at every sample
        std::vector<T> wf(static_cast<std::size_t>(cols));
        for (lint j = 0; j < cols; ++j) wf[j] = mulv(wj[j], fj[j]);
        double max_error = 0.0;
        bool nan = false;
        for (std::int64_t i = 0; i < M; ++i) {
            T nn{}, dd{};
            for (lint j = 0; j < cols; ++j) {
                if (zerov(wj[j])) continue;
                nn = addv(nn, mulv(C[j][i], wf[j]));
                dd = addv(dd, mulv(C[j][i], wj[j]));
            }
            if (infnanv(dd)) dd = T{1}, nn = F[i];
            R[i] = divv(nn, dd);
            const double e = absv(subv(F[i], R[i]));
            if (e != e) nan = true;
            max_error = std::max(max_error, e);
        }
        if (nan) max_error = kNaN;
        out.errors.push_back(max_error);
        if (max_error <= atol) {
            out.converged = true;
            break;
        }
    }
    for (std::size_t j = 0; j < wj.size(); ++j)
        if (!zerov(wj[j])) out.zj.push_back(zj[j]), out.fj.push_back(fj[j]), out.wj.push_back(wj[j]);

```

모든 표본에서 $R_i = \mathcal N_i/\mathcal D_i$를 무게가 0인 열을 빼고 계산해요. 지지점 행은 $C$가 무한대라 분모가 유한하지 않으니 $f_i$ 그대로예요. $\max_i\lvert f_i - R_i\rvert$를 `errors`에 쌓고, 그것이 `atol` 이하면 `converged`를 참으로 하고 멈춰요. 아니면 $\min(\texttt{max\_terms}, M)$ 걸음에서 멈추고 `converged`가 거짓이에요. 경고는 내지 않아요. 끝에 무게가 0인 지지점을 빼요.

몫은 numpy의 것(복소수는 Smith 알고리즘), 합은 식이 주는 순서라 scipy와 다른 곳은 scipy가 BLAS로 하는 행렬 곱 $\mathcal N = C(wf)$, $\mathcal D = Cw$의 반올림뿐이에요. 지금은 시험 자료 넷에서 지지점이 scipy와 같은 순서로 같아요(약속은 아니에요). 오차가 반올림 크기까지 내려간 뒤의 걸음은 그 반올림이 다음 지지점을 고르니 갈릴 수 있어요.

## 극점과 영점: 화살촉 행렬 쌍

$r$의 극점은 $\mathcal D$의 영점이에요. $\ell(z)\mathcal D(z) = \sum_j w_j\prod_{k \ne j}(z - z_k)$는 $m - 1$차 다항식이지만, 라그랑주 기저에 맞춰 적혀 있어 계수를 꺼내 근을 구하면 조건이 나빠요. 대신 크기 $m + 1$의 행렬 쌍

$$
E = \begin{pmatrix} 0 & w_1 & \cdots & w_m \\ 1 & z_1 & & \\ \vdots & & \ddots & \\ 1 & & & z_m \end{pmatrix},\qquad B = \begin{pmatrix} 0 & & & \\ & 1 & & \\ & & \ddots & \\ & & & 1 \end{pmatrix}
$$

의 일반화 고유값, 곧 $\det(E - \lambda B) = 0$인 $\lambda$를 구해요. $\lambda$가 어떤 $z_k$와도 다르면 $E - \lambda B$의 오른쪽 아래 대각 블록 $\mathrm{diag}(z_k - \lambda)$가 가역이고, Schur 보수로

$$
\det(E - \lambda B) = -\prod_k(z_k - \lambda)\sum_j\frac{w_j}{z_j - \lambda} = (-1)^m\,\ell(\lambda)\,\mathcal D(\lambda)
$$

예요. 그래서 유한한 고유값은 $\ell\mathcal D$의 근, 곧 극점이에요. 다항식이 $m - 1$차이고 쌍의 크기는 $m + 1$이니, 적어도 두 고유값은 무한대예요($B$의 0인 대각에서 나와요). 첫 행을 $(wf)^{\mathsf T}$로 바꾸면 같은 계산이 $\mathcal N$의 영점, 곧 $r$의 영점을 줘요.

```cpp
// csrc/interpolate/aaa.cpp
// The finite generalized eigenvalues of the arrowhead pair (support points zj, first row top)
template <class T>
std::vector<cplx> arrowhead_eig(const std::vector<T>& zj, const std::vector<T>& top, linalg::Scratch& sc) {
    const lint m = static_cast<lint>(zj.size()), k = m + 1;
    std::vector<T> E(static_cast<std::size_t>(k * k), T{}), B(static_cast<std::size_t>(k * k), T{});
    for (lint j = 0; j < m; ++j) {
        E[0 + (1 + j) * k] = top[j];
        E[(1 + j) + 0 * k] = T{1};
        E[(1 + j) + (1 + j) * k] = zj[j];
        B[(1 + j) + (1 + j) * k] = T{1};
    }
    std::vector<cplx> w;
    if constexpr (std::is_same_v<T, double>) {
        std::vector<double> ar(k), ai(k), be(k);
        if (lapack::ggev(k, E.data(), k, B.data(), k, ar.data(), ai.data(), be.data(), sc) != 0)
            throw linalg::LinAlgError("the generalized eigenvalue problem did not converge");
        for (lint i = 0; i < k; ++i)
            if (be[i] != 0) w.push_back(cdiv(cplx(ar[i], ai[i]), cplx(be[i], 0.0)));
    } else {
        std::vector<cplx> al(k), be(k);
        if (lapack::ggev(k, E.data(), k, B.data(), k, al.data(), be.data(), sc) != 0)
            throw linalg::LinAlgError("the generalized eigenvalue problem did not converge");
        for (lint i = 0; i < k; ++i)
            if (!zerov(be[i])) w.push_back(cdiv(al[i], be[i]));
    }
    std::vector<cplx> out;
    for (const cplx& v : w)
        if (finitev(v)) out.push_back(v);
    return out;
}
```

`ggev`는 고유값을 $\alpha_i/\beta_i$의 짝으로 돌려줘요. $\beta_i = 0$이면 무한대예요. 코드는 $\beta_i \ne 0$인 것만 numpy처럼 나누고(실수는 $(\alpha^r + i\alpha^i)/\beta$를 복소수 몫으로), 몫이 유한한 것만 남겨요. scipy와 같은 행렬을 같은 Accelerate에 넘겨요. 공개 linalg API에는 일반화 고유값 함수가 없고, 이 래퍼는 이 영역의 내부 함수예요.

### `ggev` 안에서 하는 일

`dggev`(복소수는 `zggev`)는 벡터 없이(`jobvl = jobvr = 'N'`) 부르면 다음 순서로 고유값을 구해요. 두 행렬을 따로 다루면서도 $B^{-1}$을 만들지 않는 것이 요점이에요. $B$가 이 문제처럼 특이해도 무한한 고유값을 $\beta = 0$으로 정확히 다룰 수 있어요.

1. **척도 맞추기.** $E$와 $B$의 가장 큰 원소 크기가 안전한 범위 밖이면 각각 2의 거듭제곱에 가까운 배수로 줄이거나 늘려요(`dlange`, `dlascl`). 끝에서 $\alpha$와 $\beta$를 되돌려요.
2. **균형 잡기.** `dggbal`(`'P'`)이 행과 열을 같은 순열로 옮겨, 따로 떨어지는 고유값을 위아래 삼각 부분으로 몰아내요. 남는 가운데 블록 `ilo`–`ihi`만 반복에 들어가요. 원소의 크기를 바꾸는 척도 균형은 하지 않아요.
3. **$B$를 삼각으로.** 가운데 블록에서 $B = QR$(`dgeqrf`)을 구하고 같은 $Q^{\mathsf T}$를 $E$에 곱해요(`dormqr`). 이 문제의 $B$는 이미 대각이라 반사가 항등이에요.
4. **Hessenberg–삼각 꼴.** `dgghrd`가 $E$를 위 Hessenberg로, $B$는 위 삼각인 채로 줄여요. $E$의 한 열에서 아래 원소를 Givens 회전으로 지우면(행에 곱함) $B$의 대각 아래에 원소 하나가 생기고, 그것을 열에 곱하는 Givens 회전으로 다시 지워요(같은 회전을 $E$의 열에도 곱해요). 왼쪽과 오른쪽에 서로 다른 직교 변환을 곱하니 쌍의 고유값이 그대로예요.
5. **QZ 반복.** `dhgeqz`(`'E'`, 고유값만)가 Moler–Stewart의 QZ 반복을 해요. 이것은 $EB^{-1}$에 암시적 이중 이동 QR을 하는 것과 같지만 역행렬을 만들지 않아요. 한 번의 쓸기는 끝의 $2 \times 2$ 쌍에서 이동 둘을 정하고, 이동한 다항식의 첫 열로 Householder 반사를 만들어 왼쪽 위에 불룩한 원소를 만들고, 왼쪽 변환으로 $E$의 Hessenberg 꼴을, 오른쪽 변환으로 $B$의 삼각 꼴을 번갈아 되살리며 불룩한 원소를 오른쪽 아래로 밀어내요. $E$의 대각 아래 원소가 무시할 만큼 작아지면 문제를 둘로 나눠요(감축). $B$의 대각 원소가 0(또는 무시할 만큼 작은 값)이면 그것이 무한한 고유값이고, 회전으로 그 0을 끝으로 옮겨 $\beta = 0$으로 떼어 내요. 수렴이 더디면 가끔 예외 이동을 써요.
6. **고유값 읽기.** 끝에 남은 $1 \times 1$ 블록은 $\alpha = e_{jj}$, $\beta = b_{jj}$이고, $2 \times 2$ 블록은 `dlagv2`가 표준 꼴로 바꿔 켤레 복소수 짝 $\alpha^r \pm i\alpha^i$와 $\beta$를 줘요. 실수 자료에서 복소수 극점이 켤레 짝으로 나오는 까닭이에요. `zggev`는 복소수 단일 이동의 QZ(`zhgeqz`)라 $2 \times 2$ 블록이 없고 $\alpha$가 복소수예요.

## 유수와 Froissart 쌍

단순 극점 $p$ 근처에서 $r(z) \approx \mathcal N(p)/((z - p)\mathcal D'(p))$이니 유수는 $\mathcal N(p)/\mathcal D'(p)$, $\mathcal D'(p) = -\sum_j w_j/(p - z_j)^2$예요.

```cpp
// csrc/interpolate/aaa.cpp
template <class T>
std::vector<cplx> residues(
    const std::vector<T>& zj, const std::vector<T>& fj, const std::vector<T>& wj, const std::vector<cplx>& poles
) {
    const std::size_t m = zj.size();
    std::vector<cplx> out(poles.size());
    std::vector<cplx> fw(m);
    for (std::size_t j = 0; j < m; ++j) fw[j] = as_c(mulv(fj[j], wj[j]));
    for (std::size_t p = 0; p < poles.size(); ++p) {
        cplx num{0.0, 0.0}, dd{0.0, 0.0};
        for (std::size_t j = 0; j < m; ++j) {
            const cplx c = cdiv(cplx(1.0, 0.0), subv(poles[p], as_c(zj[j])));
            num = addv(num, mulv(c, fw[j]));
            dd = addv(dd, mulv(mulv(c, c), as_c(wj[j])));
        }
        out[p] = cdiv(num, cplx(-dd.real(), -dd.imag()));
    }
    return out;
}
```

오차가 반올림 크기에 이른 뒤에도 걸음을 더하면, 극점과 영점이 거의 같은 자리에 붙은 쌍이 생겨요. 이것을 Froissart 쌍이라 해요. 유수가 아주 작아 근사에는 거의 영향이 없지만, 극점 목록을 믿을 수 없게 만들어요. `clean_up`이 이것을 지워요.

```cpp
        double dist = kInf;
        for (std::int64_t i = 0; i < M; ++i) dist = std::min(dist, absv(subv(poles[p], as_c(zs[i]))));
        if (absv(res[p]) / dist < tol * gm) spurious.push_back(p);
    }
    const std::int64_t ni = static_cast<std::int64_t>(spurious.size());
    if (ni == 0) return 0;
    std::vector<char> drop(zj.size(), 0);
    for (std::size_t p : spurious) {
        std::size_t best = 0;
        double bd = kInf;
        for (std::size_t j = 0; j < zj.size(); ++j) {
            const double d = absv(subv(as_c(zj[j]), poles[p]));
            if (j == 0 || d < bd) bd = d, best = j;
        }
        drop[best] = 1;
    }
```

### 실수 커널의 한계

여기서는 무게가 주어진 것(계산한 무게 그대로)이고, 견주는 대상은 그 지지점·값·무게의 정확한 유리식 $r$이에요. $\lambda_j = w_j/(z - z_j)$로 두면 $\hat s_j = \lambda_j(1 + \theta_2)$(차와 나눗셈)이고, 분자의 fma 사슬이 항마다 많아야 $N$번, 분모의 덧셈이 $N - 1$번이라 $\hat{\mathcal N} = \sum\lambda_jf_j(1 + \theta^{(j)}_{N+2})$, $\hat{\mathcal D} = \sum\lambda_j(1 + \theta^{(j)}_{N+1})$이에요. $\mathcal N = r\mathcal D$를 써서

$$
\hat r - r = \frac{e_{\mathcal N}(1 + \delta) + r\mathcal D\delta - r\,e_{\mathcal D}}{\mathcal D + e_{\mathcal D}}
$$

이고, $\lvert e_{\mathcal N}(1 + \delta)\rvert \le \gamma_{N+3}\sum\lvert\lambda_jf_j\rvert$, $\lvert r\mathcal D\delta\rvert \le u\lvert r\rvert\sum\lvert\lambda_j\rvert$, $u + \gamma_{N+1} \le \gamma_{N+2}$라서

$$
\lvert\hat r - r\rvert \le \frac{\gamma_a\sum_j\lvert\lambda_jf_j\rvert + \gamma_b\lvert r\rvert\sum_j\lvert\lambda_j\rvert}{\lvert\sum_j\lambda_j\rvert - \gamma_c\sum_j\lvert\lambda_j\rvert},\qquad (a, b, c) = (N + 3, N + 2, N + 1)
$$

이에요. 분모 $\lvert\sum\lambda_j\rvert$가 $\sum\lvert\lambda_j\rvert$보다 훨씬 작은 곳, 곧 극점 근처가 이 한계의 조건이에요.

### 복소수 커널

```cpp
// csrc/interpolate/polyint.cpp
// 1 / (r + i m) without overflow or underflow in the squares: scaled by a power of two first
inline void cinv(double r, double m, double& ir, double& im) {
    const double big = std::max(std::fabs(r), std::fabs(m));
    if (big == 0 || !std::isfinite(big)) {  // 1/0 and 1/inf as IEEE's real division gives them
        ir = 1.0 / r;
        im = big == 0 ? -1.0 / m : -0.0 * m;
        return;
    }
    std::int64_t e = 0;
    split_exponent(big, e);  // big = f 2^e: (r, m) 2^-e has modulus in [0.5, sqrt 2), exactly
    const int k = static_cast<int>(-e);
    const double rs = std::ldexp(r, k), ms = std::ldexp(m, k);
    const double q = std::fma(rs, rs, ms * ms);
    ir = std::ldexp(rs / q, k);  // 1 / (r + i m) = conj(rs + i ms) / q 2^-e
    im = std::ldexp(-ms / q, k);
}

// (a + i b)(c + i d) with one fma per part
inline void cmul(double a, double b, double c, double d, double& re, double& im) {
    re = std::fma(a, c, -(b * d));
    im = std::fma(a, d, b * c);
}
```

역수 $1/(r + im)$은 $(r, m)$을 더 큰 성분의 지수만큼 2의 거듭제곱으로 맞춘 $(r', m')$에서 $\overline{(r' + im')}/(r'^2 + m'^2)$로 계산해요. 맞춘 크기가 $[0.5, \sqrt 2)$라 제곱이 넘치거나 언더플로하지 않고, 맞추기와 되돌리기는 정확해요. 곱은 실수부와 허수부마다 fma 하나예요.

```cpp
                double nr = 0.0, ni = 0.0;
                for (std::int64_t j = 0; j < m; ++j) {
                    const double fr = F.p[j * 2 * K + 2 * c], fi = F.p[j * 2 * K + 2 * c + 1];
                    nr = std::fma(lr[j], fr, nr);
                    nr = std::fma(-li[j], fi, nr);
                    ni = std::fma(lr[j], fi, ni);
                    ni = std::fma(li[j], fr, ni);
                }
                cmul(nr, ni, ir, im, row[2 * c], row[2 * c + 1]);
            }
```

점마다 $\lambda_j = w_j\cdot(1/(z - z_j))$를 만들며 분모를 더하고, 열마다 분자를 성분당 fma 둘로 더한 뒤 분모의 역수를 곱해요. 지지점 위의 점과 $\lambda_j$가 넘친 점은 가장 가까운 지지점의 값, 무한한 점은 극한 $\sum wf/\sum w$, NaN 점은 NaN이에요.

한계는 같은 꼴이고 상수만 커요. 차의 반올림이 $\lvert\hat z - z\rvert \le u\lvert z\rvert$, 역수가 $\gamma_5$, 곱이 $\sqrt 2\gamma_2$라 $\lvert\hat\lambda_j - \lambda_j\rvert \le \gamma_8\lvert\lambda_j\rvert$예요. 분자의 합은 성분마다 항당 fma 둘이라 $\sqrt 2\gamma_{2N} \le \gamma_{3N}$, 분모는 $\sqrt 2\gamma_{N-1} \le \gamma_{2N}$, 마지막의 역수와 곱이 $\gamma_7$이에요. 모아서 $\lvert r\rvert \le \lvert r\rvert\sum\lvert\lambda\rvert/\lvert\sum\lambda\rvert$로 $b$에 넣으면 $(a, b, c) = (3N + 16, 2N + 16, 2N + 8)$이에요.

AAA의 무게 자체에는 계약이 없어요. SVD가 고른 벡터라 미리 정할 "정확한 무게"가 없기 때문이에요. 그 대신 성질 둘을 봐요. 지지점에서는 값이 표본 그대로이고, 수렴한 객체는 표본에서 $\max_i\lvert r(z_i) - f_i\rvert \le \mathrm{rtol}\cdot\max\lvert f\rvert$예요.

## 결정성

AAA의 걸음은 차례 계산이고 이 영역의 스레드풀을 쓰지 않아요. SVD와 QZ는 Accelerate의 LAPACK이 계산하고, Accelerate의 스레드 모드가 같으면 같은 비트예요. 평가는 평가점 조각으로 나누고 점마다 같은 커널이라 스레드 수와 무관해요.
