## 한눈에 보기

이 쪽은 노드 $x_0, \ldots, x_{N-1}$ 전체를 지나는 함수 셋을 다뤄요. [`BarycentricInterpolator`](/api/interpolate/BarycentricInterpolator/)와 [`KroghInterpolator`](/api/interpolate/KroghInterpolator/)는 $N - 1$차 이하의 보간 다항식 하나를 서로 다른 꼴로 계산하고, [`FloaterHormannInterpolator`](/api/interpolate/FloaterHormannInterpolator/)는 낮은 차수의 국소 다항식을 섞은 유리식이에요. 무게중심 꼴과 Floater–Hormann, 그리고 [AAA](/internals/interpolate/aaa/)는 같은 꼴

$$
r(x) = \frac{\displaystyle\sum_j \frac{w_j}{x - x_j}\,y_j}{\displaystyle\sum_j \frac{w_j}{x - x_j}}
$$

을 쓰고 무게 $w_j$만 달라요. 그래서 평가 커널 하나를 함께 써요.

| 파일 | 하는 일 |
|---|---|
| `src/stardust/interpolate/_polyint.py` | `BarycentricInterpolator`, `KroghInterpolator`와 함수 꼴, 인자 검사, 도함수의 노드 값 쌓아 두기 |
| `src/stardust/interpolate/_aaa.py` | `FloaterHormannInterpolator`와 AAA가 함께 쓰는 유리식의 평가, 극점·유수·영점 |
| `csrc/interpolate/polyint.cpp` | 무게, 실수 평가 커널, 노드의 도함수 값, Krogh의 차분표와 평가, Floater–Hormann의 무게, 복소 평가 커널 |

세 가지를 약속으로 세워요.

1. **무게는 노드와 그 순서만의 함수예요.** 곱이 넘치지 않게 지수를 따로 세니 노드를 섞을 필요가 없고, 같은 입력은 언제나 같은 무게를 줘요.
2. **점 하나의 값은 커널 하나가 정해요.** 점을 여덟 개씩 묶어 계산하든 하나씩 계산하든, 배치의 열이 몇 개든, 어느 스레드에서 계산하든 점마다 같은 연산을 같은 순서로 해요.
3. **무게중심 다항식은 끝에서 끝의 오차 한계가 있어요.** 무게의 반올림까지 넣어, float 자료의 정확한 보간 다항식과 견준 한계예요.

값은 (노드, 열) 꼴의 행 우선 배열로 C++에 넘어가요. 복소수 값은 실수부와 허수부를 나란히 둔 double 두 열이에요. 노드와 무게가 실수면 모든 식이 값에 대해 실수 계수의 선형이라, 복소수 열 하나는 실수 열 둘과 같은 계산이에요.

## 보간 다항식을 적는 꼴

서로 다른 노드 $N$개를 지나는 $N - 1$차 이하의 다항식은 하나뿐이에요. 그것을 적는 꼴이 여럿이고, 꼴마다 계산의 성질이 달라요.

**Lagrange 꼴**은 $p(x) = \sum_j \ell_j(x)y_j$, $\ell_j(x) = \prod_{k \ne j}(x - x_k)/(x_j - x_k)$예요. 점마다 곱을 $N^2$번 해야 하고, 노드를 하나 더하면 모든 $\ell_j$가 달라져요.

$\ell(x) = \prod_k (x - x_k)$와 **무게** $w_j = 1/\prod_{k \ne j}(x_j - x_k)$를 두면 $\ell_j(x) = \ell(x)\,w_j/(x - x_j)$라서

$$
p(x) = \ell(x)\sum_j \frac{w_j}{x - x_j}\,y_j
$$

예요. 이것이 첫째 무게중심 공식이에요. 무게는 노드에만 달려 있어 한 번 구해 두면 점마다 $O(N)$이에요.

상수 1도 $N - 1$차 이하의 다항식이니 그 보간은 자기 자신이고, $\sum_j \ell_j(x) = 1$, 곧 $1 = \ell(x)\sum_j w_j/(x - x_j)$예요. 첫째 공식을 이것으로 나누면 $\ell(x)$가 사라져요.

$$
p(x) = \frac{\displaystyle\sum_j \frac{w_j}{x - x_j}\,y_j}{\displaystyle\sum_j \frac{w_j}{x - x_j}}
$$

이것이 **둘째(참) 무게중심 공식**이고 `BarycentricInterpolator`가 계산하는 꼴이에요. 분자와 분모에 같은 무게가 들어 있으니 **모든 무게에 같은 수를 곱해도 값이 같아요.** 이 성질 덕분에 무게를 아무 공통 배수로나 저장할 수 있어요.

**Newton 꼴**은 $p(x) = c_0 + c_1(x - x_0) + c_2(x - x_0)(x - x_1) + \cdots$이고 $c_k$는 나눗셈 차분이에요. 같은 노드를 되풀이해 도함수 자료를 넣는 Hermite 보간을 자연스럽게 담아서 `KroghInterpolator`가 이 꼴을 써요.

```python

>>> y = 1 / (1 + 25 * x * x)
>>> p = I.BarycentricInterpolator(x, y)
>>> p

>>> float(p(0.0)), float(p(0.95))

```

## 무게: 지수를 따로 세는 곱

무게의 곱은 쉽게 넘치거나 언더플로해요. 0부터 1000까지의 정수 노드 1001개면 가운데 노드의 무게 분모가 $500!^2$쯤이라 double의 범위($10^{308}$)를 훨씬 넘어요. 곱의 순서를 바꿔 큰 차와 작은 차를 번갈아 곱하면 넘침을 늦출 수 있지만, 그러면 무게가 곱한 순서에 달려요. 여기서는 순서를 입력 그대로 두고, 곱마다 지수를 따로 세서 넘침 자체를 없애요.

```cpp
// csrc/interpolate/polyint.cpp
// d = f 2^e with |f| in [0.5, 1): returns f and adds e to `exp` (d finite and nonzero)
inline double split_exponent(double d, std::int64_t& exp) {
    const auto b = std::bit_cast<std::uint64_t>(d);
    const int field = static_cast<int>((b >> 52) & 0x7ff);
    if (field == 0) {  // subnormal
        int k = 0;
        const double f = std::frexp(d, &k);
        exp += k;
        return f;
    }
    exp += field - 1022;
    return std::bit_cast<double>((b & ~(std::uint64_t{0x7ff} << 52)) | (std::uint64_t{1022} << 52));
}
```

`split_exponent`는 0이 아닌 유한한 $d$를 $d = f\cdot 2^e$, $\lvert f\rvert \in [0.5, 1)$로 나눠요. 정상 수는 지수 칸을 1022로 바꿔 끼우기만 하니 비트 연산이고, 비정상 수는 `frexp`로 나눠요. 어느 쪽이든 정확해요.

```cpp
    // csrc/interpolate/polyint.cpp
    split_range(n, n * n * 3, 64, [&](std::int64_t b, std::int64_t e) {
        for (std::int64_t j = b; j < e; ++j) {
            const double xj = X.p[j];
            double mant = 1.0;
            std::int64_t ex = 0;
            int since = 0;
            for (std::int64_t k = 0; k < n; ++k) {
                if (k == j) continue;
                const double d = xj - X.p[k];
                if (d == 0) {
                    dup[j] = std::max(j, k);
                    break;
                }
                mant *= split_exponent(d, ex);  // |mant| >= 2^-256 between the renormalizations: always normal
                if (++since == 256) {
                    mant = split_exponent(mant, ex);
                    since = 0;
                }
            }
            const double f = split_exponent(mant, ex);  // the product is f 2^ex, |f| in [0.5, 1)
            std::int64_t t = -ex;
            w[j] = split_exponent(1.0 / f, t);  // 1/f in (1, 2]: w_j = w[j] 2^t, |w[j]| in [0.5, 1)
            te[j] = t;
        }
    });
    std::int64_t bad = -1;
    for (std::int64_t j = 0; j < n; ++j)
        if (dup[j] >= 0 && (bad < 0 || dup[j] < bad)) bad = dup[j];
    if (bad >= 0) return nb::make_tuple(wrap(std::move(out)), bad);
    std::int64_t top = std::numeric_limits<std::int64_t>::min();
    for (std::int64_t j = 0; j < n; ++j) top = std::max(top, te[j]);
    for (std::int64_t j = 0; j < n; ++j) {
        const std::int64_t k = te[j] - top;  // <= 0; below -1100 the weight is 0 (2^-1074 of the largest)
        w[j] = k < -1100 ? 0.0 * w[j] : std::ldexp(w[j], static_cast<int>(k));
    }
    return nb::make_tuple(wrap(std::move(out)), std::int64_t{-1});
```

노드 $j$마다 차 $x_j - x_k$를 입력 순서로 돌며 가수 $f$끼리 곱하고 지수 $e$는 정수 `ex`에 더해요. 이것이 무게를 넘침 없이 정확히 정하는 까닭은 이래요.

- **2의 거듭제곱 척도는 반올림을 바꾸지 않아요.** 넘침과 언더플로가 없으면 $\mathrm{fl}(a\cdot 2^p \times b\cdot 2^q) = \mathrm{fl}(a \times b)\cdot 2^{p+q}$예요. 그래서 가수끼리 곱하고 지수를 따로 더한 결과는 "지수가 끝없는 53비트 곱"과 같은 비트예요.
- **가수의 곱은 언제나 정상 수예요.** 다시 맞춘 직후 곱은 $[0.5, 1)$에 있고, $[0.5, 1)$의 수를 256번 곱해도 $2^{-257}$ 위예요. 256번마다 `split_exponent`로 곱을 $[0.5, 1)$로 되돌리는데, 이 맞추기는 정확하니 맞추는 빈도가 결과를 바꾸지 않아요.
- 끝에 곱을 $f\cdot 2^{ex}$로 나누고 $1/f \in (1, 2]$를 한 번 반올림해요. 노드 $j$의 무게는 가수 `w[j]`와 지수 `te[j]`의 짝이에요.

모든 노드의 짝이 나오면 가장 큰 지수 `top`을 찾아 모든 무게에 같은 $2^{-\mathrm{top}}$을 곱해요. 그러면 가장 큰 무게의 크기가 $[0.5, 1)$에 놓여요. 둘째 공식은 공통 배수와 무관하니 이 배수는 값을 바꾸지 않아요. 가장 큰 무게보다 $2^{1021}$배쯤 넘게 작은 무게는 비정상 수가 되어 끝자리를 잃고, $2^{1100}$배 넘게 작은 무게는 0이에요. 노드 사이 거리가 $10^{300}$배 넘게 벌어진 자료에서나 생기는 일이에요.

같은 노드가 있으면 그 차가 정확히 0이라 바로 알아요. 커널은 처음 만난 반복 노드의 번호를 돌려주고 Python 층이 `ValueError`를 내요.


노드 1001개의 무게는 가장 큰 것과 가장 작은 것이 $10^{300}$배 가까이 벌어지지만 모두 유한한 정상 수예요.

$[0, 1, 3]$의 참 무게는 $1/((0 - 1)(0 - 3)) = 1/3$, $1/((1 - 0)(1 - 3)) = -1/2$, $1/((3 - 0)(3 - 1)) = 1/6$이에요. 가장 큰 크기가 이미 $0.5$라 배수는 1이에요.

## 평가 커널

평가는 실수 무게중심 커널 하나예요. `BarycentricInterpolator`는 `limit=false`로, Floater–Hormann과 실수 AAA는 `limit=true`로 같은 함수를 불러요.

```cpp
// csrc/interpolate/polyint.cpp
// one point of any column count; s: n doubles of scratch
void bary_point(const Bary& B, double v, double* row, double* s) {
    const std::int64_t n = B.n, D = B.Y.D;
    if (v != v) {
        std::fill(row, row + D, kNaN);
        return;
    }
    if (std::isinf(v)) {
        if (B.limit) std::memcpy(row, B.lim.data(), sizeof(double) * D);
        else std::fill(row, row + D, kNaN);
        return;
    }
    double den = 0.0;
    bool hit = false;
    for (std::int64_t j = 0; j < n; ++j) {
        const double d = v - B.x[j];
        hit |= d == 0;
        s[j] = B.w[j] / d;
        den += s[j];
    }
    if (hit || !std::isfinite(den)) {
        nearest_row(B, v, row);
        return;
    }
    for (std::int64_t c = 0; c < D; ++c) {
        double num = 0.0;
        const double* y = B.Y.p + c;
        for (std::int64_t j = 0; j < n; ++j) num = std::fma(s[j], y[j * D], num);
        row[c] = num / den;
    }
}
```

점 $x$마다 $s_j = w_j/(x - x_j)$를 노드 순서로 만들며 분모 $\sum s_j$를 더하고, 열마다 분자 $\sum s_jy_j$를 항마다 fma 하나로 더한 뒤 나눠요. 갈래는 셋이에요.

- **노드 위의 점.** 어떤 $x - x_j$가 정확히 0이면 그 노드의 값을 그대로 돌려줘요. 노드에서 오차가 0이에요.
- **노드에 아주 가까운 점.** $x - x_j$가 비정상 수 크기면 $s_j$가 넘쳐 분모가 유한하지 않아요. 그때도 가장 가까운 노드의 값이에요. 그 거리에서는 참 값과 노드 값의 차가 반올림보다 작아요.
- **무한한 점.** 다항식은 상수가 아니면 무한대로 가니 NaN이에요. 유리식은 분자와 분모의 차수가 같아 극한 $\sum w_jy_j/\sum w_j$가 있고, 만들 때 한 번 구해 둔 그 값을 돌려줘요.

열이 하나면 점 여덟 개를 한 번에 계산해요.

```cpp
// csrc/interpolate/polyint.cpp
// one column, eight points at a time: the same operations per point as bary_point
void bary_block8(const Bary& B, const double* v, double* out) {
    constexpr int L = 8;
    double num[L] = {}, den[L] = {};
    bool bad = false;
    for (int p = 0; p < L; ++p) bad |= !std::isfinite(v[p]);
    if (!bad) {
        for (std::int64_t j = 0; j < B.n; ++j) {
            const double xj = B.x[j], wj = B.w[j], yj = B.Y.p[j];
            for (int p = 0; p < L; ++p) {
                const double s = wj / (v[p] - xj);
                num[p] = std::fma(s, yj, num[p]);
                den[p] += s;
            }
        }
    }
    for (int p = 0; p < L; ++p) {
        if (bad || !std::isfinite(den[p])) {  // a node, an overflow or a point that is not finite
            std::vector<double> s(B.n);
            bary_point(B, v[p], out + p, s.data());
        } else {
            out[p] = num[p] / den[p];
        }
    }
}
```

안쪽 고리는 점마다 `bary_point`와 같은 연산을 같은 순서로 해요. 나눗셈 `wj / (v[p] - xj)` 여덟 개가 서로 독립이라 컴파일러가 NEON의 두 레인 나눗셈으로 만들어요. 여덟 점 가운데 하나라도 노드 위, 넘침, 유한하지 않은 점이면 그 점만 `bary_point`로 다시 계산해요. 결과는 묶음 안의 자리와 무관하게 같은 비트예요.

### 오차 한계

$u = 2^{-53}$, $\gamma_k = ku/(1 - ku)$로 두고, 반올림 $k$번의 곱 $\prod_i(1 + \delta_i)^{\pm 1}$($\lvert\delta_i\rvert \le u$)을 $1 + \theta_k$, $\lvert\theta_k\rvert \le \gamma_k$로 적어요(Higham의 보조정리 3.1). 무게, $s_j$, 곱에 언더플로가 없다고 둬요. $p$는 float 자료 $(x_j, y_j)$의 정확한 보간 다항식이고, $\Lambda(x) = \sum_j\lvert\ell_j(x)\rvert$는 Lebesgue 함수예요.

1. **무게.** 차 $N - 1$번, 곱 $N - 2$번(첫 곱 $1\cdot f$는 정확), 역수 한 번이 반올림이고 지수 처리는 정확해요. 그래서 $\hat w_j = c\,w_j(1 + \theta_{2N-2})$, $c = 2^{-\mathrm{top}}$이에요.
2. **$s_j$.** 차 하나와 나눗셈 하나가 더해져 $\hat s_j = c\,\lambda_j(1 + \theta_{2N})$, $\lambda_j = w_j/(x - x_j)$예요.
3. **합.** 분자의 fma 사슬에서 항 $j$는 많아야 $N$번 반올림돼요. 분모의 덧셈은 첫 덧셈 $0 + s_0$가 정확하니 항마다 많아야 $N - 1$번이에요. 그래서 $\hat{\mathcal N} = c\sum_j\lambda_jy_j(1 + \theta^{(j)}_{3N})$, $\hat{\mathcal D} = c\sum_j\lambda_j(1 + \theta^{(j)}_{3N-1})$이에요.
4. **$\ell(x)$를 곱하기.** $\ell(x)\lambda_j = \ell_j(x)$이고 $\sum_j\ell_jy_j = p(x)$, $\sum_j\ell_j = 1$이에요. 그래서 $\hat{\mathcal N}\ell/c = p + e_{\mathcal N}$, $\lvert e_{\mathcal N}\rvert \le \gamma_{3N}\sum_j\lvert\ell_jy_j\rvert$이고 $\hat{\mathcal D}\ell/c = 1 + e_{\mathcal D}$, $\lvert e_{\mathcal D}\rvert \le \gamma_{3N-1}\Lambda$예요.
5. **나눗셈.** $\hat p = (\hat{\mathcal N}/\hat{\mathcal D})(1 + \delta)$에서

$$
\hat p - p = \frac{e_{\mathcal N}(1 + \delta) + p\,\delta - p\,e_{\mathcal D}}{1 + e_{\mathcal D}}
$$

이에요. $\lvert e_{\mathcal N}(1 + \delta)\rvert \le \gamma_{3N+1}\sum\lvert\ell_jy_j\rvert$이고, $\Lambda \ge 1$이라 $u\lvert p\rvert \le u\Lambda\lvert p\rvert$, $u + \gamma_{3N-1} \le \gamma_{3N}$이에요. 모으면

$$
\lvert\hat p - p\rvert \le \frac{\gamma_{3N+1}\sum_j\lvert\ell_j(x)y_j\rvert + \gamma_{3N}\Lambda(x)\lvert p(x)\rvert}{1 - \gamma_{3N-1}\Lambda(x)}
$$

예요. 여덟 점 묶음과 열이 여럿인 길도 점마다 같은 연산 순서라 같은 한계예요.

이 한계는 Higham(2004)의 첫 차 꼴과 같은 모양이지만 $O(u^2)$ 항을 버리지 않은 완결된 한계예요. 오른쪽의 $\sum\lvert\ell_jy_j\rvert \le \Lambda\max\lvert y\rvert$라서 Lebesgue 함수가 조건수 노릇을 해요. 고른 노드는 $\Lambda$가 노드 수에 따라 지수로 커지고, 체비쇼프 점은 로그로만 커져요. 공식의 반올림은 어느 노드에서나 작고, 큰 오차는 노드 배치가 주는 조건에서 와요.

## 도함수

$p$의 도함수 $p'$도 $N - 2$차 이하의 다항식이니, 노드에서의 값 $p'(x_i)$만 알면 같은 무게로 무게중심 평가를 하면 돼요. 노드의 도함수 값은 미분 행렬 $D$로 나와요.

$$
p'(x_i) = \sum_j D_{ij}y_j,\qquad D_{ij} = \frac{w_j/w_i}{x_i - x_j}\ (j \ne i),\qquad D_{ii} = -\sum_{j \ne i}D_{ij}
$$

비대각은 $\ell_j'(x_i)$를 무게로 적은 것이고, 대각은 상수의 도함수가 0이라 각 행의 합이 0이어야 한다는 데서 나와요. $k$차 도함수의 노드 값은 $D^ky$예요.

```cpp
    // csrc/interpolate/polyint.cpp
    split_range(n, n * n * (4 + D), 16, [&](std::int64_t b, std::int64_t e) {
        std::vector<double> row(n);
        for (std::int64_t i = b; i < e; ++i) {
            double diag = 0.0;
            for (std::int64_t j = 0; j < n; ++j) {
                if (j == i) continue;
                row[j] = W.p[j] / ((X.p[i] - X.p[j]) * W.p[i]);
                diag += row[j];
            }
            row[i] = -diag;
            for (std::int64_t c = 0; c < D; ++c) {
                double acc = 0.0;
                for (std::int64_t j = 0; j < n; ++j) acc = std::fma(row[j], V.p[j * D + c], acc);
                o[i * D + c] = acc;
            }
        }
    });
```

행렬을 저장하지 않고 행마다 $D_{ij}$를 $w_j/((x_i - x_j)w_i)$의 연산 순서로 만들어 곧바로 $v \mapsto Dv$에 써요. Python 층은 차수마다의 노드 값을 객체에 쌓아 두고, 높은 차수는 바로 아래 차수에서 한 번 더 곱해요.

```python
    # src/stardust/interpolate/_polyint.py
    def _derivative_values(self, k, flat):
        """(q, K) values of the derivative of order k at the points."""
        n = self._xi.shape[0]
        if k == 0:
            return self._eval(self._y, flat)
        if k >= n:
            return _beyond(flat, self._y.shape[1], self._y.dtype)
        while len(self._nodal) < k:
            prev = self._y if not self._nodal else self._nodal[-1]
            self._nodal.append(_readonly(_core.bary_node_derivative(self._xi, self._wi, prev)))
        return self._eval(self._nodal[k - 1], flat)
```

$N$차 이상의 도함수는 0이고, NaN 점에서는 NaN이에요. 한 번의 $Dv$는 무게의 비와 차·곱·나눗셈으로 $\hat D_{ij} = D_{ij}(1 + \theta_{4N-1})$, 대각의 합이 $\theta_{5N-3}$, 곱의 합이 $N$번이라

$$
\lvert(\widehat{Dv})_i - (Dv)_i\rvert \le \gamma_{6N}\sum_{j \ne i}\lvert D_{ij}\rvert\,(\lvert v_j\rvert + \lvert v_i\rvert)
$$

예요. 앞 차수의 오차 $e$는 $\lvert D\rvert\lvert e\rvert$로 옮겨 가고, 평가는 계산한 노드 값의 보간 다항식에 대한 위의 한계에 $\sum_j\lvert\ell_j(x)\rvert\lvert e_j\rvert$를 더해요.

```python
>>> q.derivative(0.5), q.derivative(0.5, der=2), q.derivative(0.5, der=3)
(2.0, -3.0, 0.0)
>>> q.derivatives(0.5)
array([2.375,   2.0,  -3.0], dtype=float64)
```

$p(x) = 1 + 3.5x - 1.5x^2$이라 $p'(0.5) = 2$, $p''(0.5) = -3$이고 3차 도함수는 노드 셋의 $N$차라 0이에요.

## Krogh: Newton 꼴과 Hermite 자료

`KroghInterpolator`는 Newton 꼴의 계수 $c_k = f[x_0, \ldots, x_k]$를 만들어 두고 Horner로 평가해요. 같은 노드가 $s + 1$번 붙어 나오면 뒤의 값들은 도함수 자료예요. 나눗셈 차분은 겹친 노드에서 $f[x, x] = f'(x)$, $f[x, \ldots, x] = f^{(s)}(x)/s!$($x$가 $s + 1$개)로 이어지니, 이 꼴이 Hermite 보간을 그대로 담아요.

### 차분표

```cpp
    // csrc/interpolate/polyint.cpp
    split_range(D, n * n * 3 * D, 1, [&](std::int64_t b, std::int64_t e) {
        std::vector<double> V(n);
        for (std::int64_t col = b; col < e; ++col) {
            c[col] = Y.p[col];
            for (std::int64_t k = 1; k < n; ++k) {
                std::int64_t s = 0;
                while (s <= k && X.p[k - s] == X.p[k]) ++s;
                --s;
                V[0] = Y.p[k * D + col] / float_factorial(s);
                for (std::int64_t i = 0; i < k - s; ++i) {
                    const double den = X.p[i] - X.p[k];
                    V[i + 1] = s == 0 ? (c[i * D + col] - V[i]) / den : (V[i + 1] - V[i]) / den;
                }
                c[k * D + col] = V[k - s];
            }
        }
    });
```

열마다 따로, 노드 $k$를 하나씩 더해요. `s`는 $x_k$ 앞에 붙어 있는 같은 노드의 수예요. 작업 배열 $V$의 뜻을 따라가면 이래요.

- $s = 0$이면 $V_0 = f[x_k]$이고 $V_{i+1} = (c_i - V_i)/(x_i - x_k)$예요. 귀납으로 $V_i = f[x_0, \ldots, x_{i-1}, x_k]$이고, 끝의 $V_k = f[x_0, \ldots, x_k] = c_k$예요.
- $s \ge 1$이면 $V_0 = y_k/s! = f[x_k, \ldots, x_k]$($s + 1$개)이고 $V_{i+1} = (V_{i+1} - V_i)/(x_i - x_k)$는 앞 노드 차례에 남은 $V_{i+1}$을 써요. 그 값은 $x_k$가 하나 적은 차분이라, 이번 차례의 $V_i$는 $f[x_0, \ldots, x_{i-1}, x_k, \ldots, x_k]$($x_k$가 $s + 1$개)예요. 고리는 $i \lt k - s$까지라 끝의 $V_{k-s}$가 $c_k$예요.

같은 노드가 떨어져 나오면 이 점화식이 성립하지 않아요. 표를 만들기 전에 그런 노드를 찾아 Python 층이 `ValueError`로 알려요. $s!$는 scipy와 같이 171 이상에서 무한대예요.

### 평가와 중심 옮기기

값은 Newton 꼴의 Horner $b_{N-1} = c_{N-1}$, $b_k = c_k + (x - x_k)b_{k+1}$이에요(fma 하나). 도함수는 같은 걸음을 거듭해요.

```cpp
        // csrc/interpolate/polyint.cpp
        for (; i < e; ++i) {
            const double v = Q.p[i];
            for (std::int64_t k = 0; k + 1 < n; ++k) s[k] = v - X.p[k];
            for (std::int64_t col = 0; col < D; ++col) {
                for (std::int64_t k = 0; k < n; ++k) bb[k] = C.p[k * D + col];
                for (std::int64_t m = 0; m <= last; ++m) {
                    // pass m: the centres (x, ..., x, x_0, x_1, ...) with x in places 0 .. m - 1
                    for (std::int64_t k = n - 2; k >= m; --k) bb[k] = std::fma(s[k - m], bb[k + 1], bb[k]);
                    if (m >= first) o[(m - first) * plane + i * D + col] = m == 0 ? bb[0] : bb[m] * fact[m];
                }
            }
        }
```

$m$번째 걸음은 $k = N - 2, \ldots, m$에서 $b_k \leftarrow b_k + (x - x_{k-m})b_{k+1}$이에요. 걸음 0이 끝나면 $b$는 중심이 $(x, x_0, x_1, \ldots)$인 Newton 꼴의 계수예요. $p(z) = b_0 + (z - x)[b_1 + (z - x_0)[b_2 + \cdots]]$라서요. 걸음 1은 대괄호 안의 꼬리를 같은 방법으로 $x$ 중심으로 옮겨 중심이 $(x, x, x_0, \ldots)$가 되고, 걸음 $m$까지 하면 앞의 중심 $m + 1$개가 모두 $x$예요. 그러면 $b_m$은 $(z - x)^m$의 계수, 곧 $p^{(m)}(x)/m!$이에요. 그래서 `__call__`, `derivative(der=m)`, `derivatives()`의 $m$번 행이 모두 같은 걸음의 같은 값이라 비트까지 같아요.

값만 구하고 열이 하나면 점 여덟 개의 Horner를 나란히 해요. 점마다 같은 fma 사슬이에요. $N$차 이상의 도함수는 0이고 NaN 점에서는 NaN이에요.

```python

>>> c.reshape((4,)).tolist(), bad
```

$p(0) = 0$, $p'(0) = 1$, $p(1) = 1$, $p'(1) = 0$인 3차 Hermite 다항식은 $p(x) = x + x^2 - x^3$이라 $p(0.5) = 0.625$, $p'(0.5) = 0.25$, $p''(0.5) = -1$, $p'''(0.5) = -6$이에요. 차분표는 $[0, 1, 0, -1]$이에요.

### 오차

차분표의 값마다 정확한 자료의 선형 결합으로 펼치면, 항 하나는 단계마다 차 둘과 나눗셈 하나, 그리고 $s!$의 나눗셈 하나를 거쳐요. 그래서 $\lvert\hat c_k - c_k\rvert \le \gamma_{3k+2}\tilde C_k$예요. $\tilde C$는 같은 점화식을 $(\lvert a\rvert + \lvert b\rvert)/\lvert x_i - x_k\rvert$와 $\lvert y\rvert/s!$로 한 절댓값 표, 곧 펼친 항의 절댓값 합이에요. 결과가 비정상 수인 나눗셈은 절대 $2^{-1075}$씩 틀리니 같은 점화식으로 옮긴 바닥을 더해요.

평가는 계수 $c_j$에서 $b_m$까지 가는 길을 세어 봐요. 길은 $m + 1$번의 걸음에서 $j - m$번 자리를 옮기고 옮길 때마다 $(x - x_k)$를 하나 곱해요. 걸음마다 지나는 fma가 많아야 그 걸음에서 옮긴 수와 1 가운데 큰 것이라 모두 $m + 1 + (j - m)$ 이하, 차의 반올림이 $j - m$ 이하라 항마다 $2N - 1 - m$ 이하예요. 그래서

$$
\lvert\hat p^{(m)} - p^{(m)}\rvert \le m!\left(\gamma_{2N+1}\tilde A_m + 2^{-1074}\bigl((m + 1)\tilde A_m(1) + 1\bigr)\right)
$$

이고 $\tilde A_m$은 같은 걸음을 $\lvert\hat c\rvert$와 $\lvert x - x_k\rvert$로 한 값이에요. 끝에서 끝은 차분표의 한계를 같은 걸음으로 옮겨 더해요. 고른 점이 많은 Runge 자료에서는 $\tilde A$가 크게 자라는 것이 이 한계에 그대로 보여요. 경고 대신 계약이 그 크기를 말해요.

## Floater–Hormann

고른 노드의 다항식 보간은 $\Lambda$가 지수로 커져 양 끝에서 크게 출렁여요(Runge 현상). Floater와 Hormann(2007)은 연속한 노드 $d + 1$개를 지나는 $d$차 다항식 $p_i$들을 섞어요.

$$
r(x) = \frac{\sum_{i=0}^{N-1-d}\lambda_i(x)p_i(x)}{\sum_{i=0}^{N-1-d}\lambda_i(x)},\qquad \lambda_i(x) = \frac{(-1)^i}{(x - x_i)\cdots(x - x_{i+d})}
$$

이 유리식은 정확한 산술에서 실수축 위에 극점이 없고, 매끄러운 함수에서 $O(h^{d+1})$로 수렴해요. 무게중심 꼴로 바꾸면 무게가 닫힌 식이에요.

$$
w_k = (-1)^{k-d}\sum_{i \in J_k}\ \prod_{j=i,\ j \ne k}^{i+d}\frac{1}{\lvert x_k - x_j\rvert},\qquad J_k = \{i : k - d \le i \le k,\ 0 \le i \le N - 1 - d\}
$$

$d = N - 1$이면 보간 다항식이고 $d = 0$이면 $w_k = (-1)^k$(Berrut의 유리식)예요.

```cpp
    // csrc/interpolate/polyint.cpp
    split_range(n, n * (d + 1) * (d + 1) * 2, 64, [&](std::int64_t b, std::int64_t e) {
        for (std::int64_t k = b; k < e; ++k) {
            double acc = 0.0;
            for (std::int64_t i = std::max<std::int64_t>(k - d, 0); i < std::min(k + 1, n - d); ++i) {
                double prod = 1.0;
                for (std::int64_t j = i; j <= i + d; ++j)
                    if (j != k) prod *= std::fabs(X.p[k] - X.p[j]);
                acc += 1.0 / prod;
            }
            w[k] = (k - d) % 2 == 0 ? acc : -acc;
        }
    });
```

곱을 차례로, 합을 차례로 해요. 지금은 이 순서가 scipy와 같아 시험 자료에서 무게가 scipy와 비트까지 같아요(약속은 아니에요). 한 무게의 항은 모두 같은 부호예요. 항 하나는 차 $d$번, 곱 $d - 1$번, 역수 한 번이고, 같은 부호의 $d + 1$항을 더하는 데 항마다 많아야 $d$번이라

$$
\lvert\hat w_k - w_k\rvert \le \gamma_{3d}\lvert w_k\rvert
$$

예요. 평가는 위의 커널이고, 무게의 상대 오차가 $\lambda_j$에 그대로 곱해지니 끝에서 끝은 [AAA](/internals/interpolate/aaa/)의 유리식 한계에서 $(a, b, c)$에 $3d$를 더한 꼴이에요.

만들기 전에 Python 층이 표본을 정리해요.

```python

```

값이 유한하지 않은 표본을 버리고, 점을 안정 정렬하고, 같은 점이 있으면 `ValueError`, $d$가 남은 표본 수보다 작은지 봐요. 무게의 닫힌 식은 정렬된 노드를 가정해요.

## 병렬화와 결정성

| 일 | 나누는 단위 | 같은 비트인 까닭 |
|---|---|---|
| 무게중심 무게 | 노드 조각 | 노드마다 자기 곱이에요 |
| 평가 | 평가점 조각 | 점마다 같은 커널이에요(여덟 점 묶음도 점마다 같은 연산) |
| 노드의 도함수 값 | 노드 조각 | 행마다 자기 합이에요 |
| Krogh의 차분표 | 배치의 열 | 열마다 같은 점화식이에요 |
| Krogh의 평가 | 평가점 조각 | 점마다 같은 걸음이에요 |
| Floater–Hormann의 무게 | 노드 조각 | 노드마다 자기 합이에요 |

조각의 크기는 일의 양(노드 수, 점 수, 열 수)으로만 정해져요. 일이 float64 연산 $2^{15}$개 분량을 넘으면 스레드풀로 나누고 GIL을 놓아요. 그래서 같은 입력이면 스레드 수와 상관없이 같은 비트예요.

scipy는 무게의 넘침을 피하려고 노드를 무작위로 섞어 곱해서, 같은 노드라도 난수에 따라 무게의 끝자리가 달라요. 여기서는 지수를 따로 세니 섞을 까닭이 없어요. `add_xi`로 노드를 더한 뒤의 무게도 모든 노드로 처음부터 만든 객체의 무게와 같은 비트예요. 있던 무게를 고치지 않고 모든 노드로 다시 곱하기 때문이에요.
