## 한눈에 보기

[`rlm`](/api/regression/rlm/)은 이상점에 덜 흔들리는 직선(초평면)을 찾아요. 최소제곱은 잔차의 제곱을 더하므로 잔차가 큰 행 하나가 합을 지배해요. 강건 회귀는 큰 잔차를 덜 세게 세는 손실 ρ를 써서 그런 행의 영향을 줄여요. 방식은 둘이에요.

- `method='M'`(기본): 최소제곱에서 시작해서 잔차의 척도를 반복마다 다시 구하며 M 추정량에 다가가요. statsmodels `RLM(...).fit()`과 같은 추정이에요.
- `method='MM'`: 먼저 붕괴점 50%의 S 추정을 무작위 부분표본으로 찾고, 그 척도를 고정한 채 bisquare M 추정으로 효율을 올려요. R robustbase `lmrob`의 방식이에요.

코드는 두 층이에요.

- **Python 층** `src/stardust/regression/_robust.py`: 인자를 검사하고, ψ의 조율 상수를 커널의 세 수 `(c0, c1, c2)`로 바꾸고, MM이면 사용자의 `rng`에서 회귀마다 64비트 두 단어를 뽑아 커널에 넘겨요. 결과 객체 `RLMResult`도 여기 있어요.
- **네이티브 층** `csrc/regression/robust.cpp`: `stardust._core.regression.rlm_fit` 하나가 회귀 하나를 태스크 하나로 풀어요(선형 모형과 같은 배치 드라이버 `run_batch`).

행을 도는 합은 모두 n만으로 정한 4,096행 덩어리로 나눠 덩어리 순서대로 더하고, 중앙값은 선택(`nth_element`)으로 구해요. 덩어리는 $2^{16}$행부터 스레드풀에 나눠지지만, 나누는 자리가 n만으로 정해지므로 결과는 스레드 수와 상관없이 같은 비트예요.

## M 추정과 IRLS

### 목적함수와 추정방정식

잔차 $r_i(\beta) = y_i - x_i^{\mathsf T}\beta$를 척도 $s$로 나눈 $z_i = r_i/s$에 대해, M 추정량은

$$
\hat\beta = \arg\min_\beta \sum_i \rho\!\left(\frac{y_i - x_i^{\mathsf T}\beta}{s}\right)
$$

예요(Huber 1964). $\rho(z) = z^2/2$이면 최소제곱이에요. 미분해서 0으로 두면 추정방정식이 나와요. $\psi = \rho'$이라 하면

$$
F(\beta) = \sum_i \psi(z_i)\, x_i = 0 .
$$

### ψ, 가중치, ρ

세 가지 ψ가 있어요. 조율 상수의 기본값은 statsmodels의 `HuberT()`, `TukeyBiweight()`, `Hampel()`과 같은 Huber $t = 1.345$, bisquare $c = 4.685$, Hampel $(a, b, c) = (2, 4, 8)$이에요. Huber와 bisquare의 값은 정규분포 자료에서 최소제곱 대비 효율(점근 분산의 비)이 95%가 되는 값이에요. 수치 적분으로 재면 Huber 1.345는 0.9500003, bisquare 4.685는 0.9499974이고, Hampel (2, 4, 8)은 0.990이에요.

| `norm` | ψ(z) | 가중치 w(z) = ψ(z)/z | ψ′(z) |
|---|---|---|---|
| `'huber'` | $z$ ($\lvert z\rvert \le t$), $t\operatorname{sign}z$ | $1$, $t/\lvert z\rvert$ | $1$, $0$ |
| `'bisquare'` | $z(1 - u^2)^2$ ($\lvert z\rvert \le c$), $0$ | $(1 - u^2)^2$, $0$ | $(1 - u^2)(1 - 5u^2)$, $0$ |
| `'hampel'` | $z$, $a\operatorname{sign}z$, $a\frac{c - \lvert z\rvert}{c - b}\operatorname{sign}z$, $0$ | $1$, $a/\lvert z\rvert$, $\frac{a(c - \lvert z\rvert)}{\lvert z\rvert(c - b)}$, $0$ | $1$, $0$, $-a/(c - b)$, $0$ |

bisquare의 $u = z/c$예요. Huber는 큰 잔차의 영향을 일정한 크기 $t$로 자르고, bisquare와 Hampel은 아주 큰 잔차의 영향을 0으로 되돌려요(다시 내려가는 ψ). 다시 내려가는 ψ는 목적함수가 볼록하지 않아 시작점에 따라 다른 국소 해에 닿을 수 있어요. MM이 bisquare M 단계를 S 추정에서 시작하는 것도 이 때문이에요.

네 함수(ψ, 가중치, ρ, ψ′)는 `NormF`라는 작은 구조체에 있어요. bisquare의 ψ는 이렇게 계산해요(`csrc/regression/robust.cpp`).

```cpp
            case nBisquare: {
                if (!(az <= c)) return 0.0;
                const double u = z / c, t = (1.0 - u) * (1.0 + u);
                return z * t * t;
            }
```

$1 - u^2$를 $(1 - u)(1 + u)$로 계산해요. $\lvert u\rvert$가 1에 가까우면 `1 - u*u`는 `u*u`의 반올림 오차가 뺄셈의 상쇄로 커져요. 곱의 꼴에서는 $u$가 1/2과 1 사이면 $1 - u$가, $-1$과 $-1/2$ 사이면 $1 + u$가 정확하고(Sterbenz 보조정리), 남는 것은 곱의 반올림 한 번이에요. 조건을 `!(az <= c)`로 쓰면 NaN도 바깥 쪽(0)으로 가요.

### IRLS가 가중 최소제곱인 이유

추정방정식을 $\psi(z_i) = w(z_i)\, z_i$로 쓰면

$$
\sum_i w(z_i)\,(y_i - x_i^{\mathsf T}\beta)\, x_i = 0
$$

예요. 가중치 $w_i$를 고정하면 이것은 가중 최소제곱 $\min_\beta \sum_i w_i (y_i - x_i^{\mathsf T}\beta)^2$의 정규방정식 그대로예요. 그래서 직전 잔차로 가중치를 만들고, 가중 최소제곱을 풀고, 새 잔차로 가중치를 다시 만드는 반복(Iteratively Reweighted Least Squares, Holland–Welsch 1977)이 추정방정식의 고정점으로 가요. GLM의 IRLS(Fisher 득점법)와 같은 꼴이라 [GLM 구현](/internals/regression/glm/)의 부품을 함께 써요.

### 한 반복의 순서

`irls`의 한 반복은 statsmodels `RLM.fit`의 순서를 따라요.

1. 직전 잔차와 척도로 가중치 $w_i = w(r_i/s)$를 만들어요.
2. 가중 최소제곱으로 새 $\beta$를 풀어요.
3. 새 잔차 $r_i$와 그 척도 $s$를 구해요(아래 척도 절).
4. 목적함수 $D = \sum_i \rho(r_i/s)$를 double-double로 더해 수렴을 판정해요.

그래서 고정점은 추정방정식 $\sum_i \psi(r_i/s(\beta))\,x_i = 0$과 척도 규칙 $s(\beta)$를 함께 푼 해이고, statsmodels와 같은 해예요.

가중 최소제곱은 두 가지로 풀어요. 수렴 판정 전에는 GLM의 중간 반복과 같은 정규방정식 $X^{\mathsf T}WX\beta = X^{\mathsf T}Wy$예요. 행 덩어리마다 $\sqrt{w_i}x_i$를 모아 `dsyrk`·`dgemv`로 부분합을 만들고, 덩어리 순서대로 더한 뒤 Cholesky와 삼각 풀이 두 번으로 풀어요(`chol_wls`). 그 계수의 적합값 $X\beta$는 double로 구하고, 모든 열이 쓰이면 $X$를 놓인 그대로 읽는 `dgemv`를 $n$으로만 정한 덩어리마다 하나씩 불러요. 그래서 이 반복의 끝자리는 $X$의 메모리 순서(C·F)에 따라 다를 수 있어요(스레드 수와는 상관없어요). 마지막 계수는 아래의 QR이 정하므로 두 순서의 결과는 반올림 수준에서 같아요. 다음 중 하나면 정규방정식을 버리고 QR로 가요.

- $n \cdot k < 512$: 일이 작아 QR과 시간이 비슷해요.
- Cholesky가 실패하거나, 삼각 인수의 역조건수 어림 $\text{rc}$에서 $2^{-53}/\text{rc}^2 > 10^{-4}$일 때: 정규방정식의 상대오차는 대략 $u\,\kappa(X^{\mathsf T}WX) = u\,\kappa(U)^2$라 이 값이 $10^{-4}$를 넘으면 반복이 엉뚱한 곳으로 갈 수 있어요.
- 대각 원소가 열 노름의 $2 \cdot \text{rtol}$배 이하일 때: 선형 모형의 겹친 열 규칙이 그 열을 뺄 상황이에요.

판정 뒤의 반복과 마지막 반복은 선형 모형의 최소제곱 핵심(`lsq.hpp`의 `fit_one`, 가중치를 받는 QR과 증강 시스템의 반복 개선, 최대 3번)이에요. 정규방정식은 빠르지만 $\kappa^2 u$의 오차가 남으므로, 마지막 계수는 늘 반복 개선한 QR에서 나와요. 자세한 풀이는 [최소제곱 풀이](/internals/regression/least-squares/)에 있어요.

## 척도

$z = r/s$의 $s$는 잔차의 퍼짐을 재는 값이에요. 최소제곱의 표준편차는 이상점에 끌려가므로 강건한 척도를 써요. `scale_est`로 고를 수 있는 척도는 둘이에요.

### MAD

`'mad'`(기본)는 0을 중심으로 한 중앙 절대 편차예요.

$$
s = \operatorname{median}_i \frac{\lvert r_i\rvert}{\Phi^{-1}(3/4)}, \qquad \Phi^{-1}(3/4) = 0.6744897501960817 .
$$

나누는 수는 표준정규분포의 3/4 분위수예요. 오차가 정규분포면 $\lvert r\rvert$의 중앙값이 $\sigma\,\Phi^{-1}(3/4)$이므로, 나누면 $\sigma$의 일치 추정량이 돼요. 상수는 statsmodels `mad(center=0)`이 쓰는 scipy `norm.ppf(0.75)`의 double 그대로예요.

```cpp
double mad0(const double* r, lint n, double* buf) {
    if (n == 0) return kNaN;
    for (lint i = 0; i < n; ++i) buf[i] = std::fabs(r[i]) / kMadC;
    const lint mid = n / 2;
    std::nth_element(buf, buf + mid, buf + n);
    const double hi = buf[mid];
    if (n % 2) return hi;
    const double lo = *std::max_element(buf, buf + mid);
    return (lo + hi) / 2;
}
```

statsmodels는 정렬하지만 여기서는 선택으로 $O(n)$에 구해요. 짝수 n이면 `nth_element`가 가운데 위쪽 값을 `buf[mid]`에 두고 그 앞을 모두 작거나 같은 값으로 채우므로, 아래쪽 값은 앞 절반의 최댓값이에요. 평균을 `(lo + hi) / 2`로 내는 것은 numpy `median`과 같은 식이에요. 나눗셈을 선택 전에 원소마다 하는 것도 statsmodels와 같아요(`|r| / 0.6744…`의 중앙값). R `MASS::rlm`은 반올림한 상수 0.6745로 나눠서 척도가 $10^{-5}$ 정도 달라요.

### Huber 제안 2

`'huber'`는 Huber의 제안 2예요(Huber 1964; Huber 1981). $\chi(z) = \min(z^2, d^2)/2$, $d = 2.5$(고정)에 대해

$$
\sum_i \chi\!\left(\frac{r_i}{s}\right) = T, \qquad T = n \cdot \frac{n - \text{rank}}{n} \cdot \mathbb E\,\chi(Z), \qquad \mathbb E\,\chi(Z) = d^2 + (1 - d^2)\Phi(d) - \tfrac12 - d\,\phi(d)
$$

을 만족하는 $s$예요. $\mathbb E\,\chi(Z)$는 $Z$가 표준정규일 때의 기댓값(약 0.48878)이라, 오차가 정규분포면 $s$가 $\sigma$에 가까워져요. $\Phi(d)$는 `0.5 * std::erfc(-d / std::sqrt(2.0))`로 계산해요. $T$의 꼴은 statsmodels `HuberScale`의 식 그대로예요.

statsmodels `HuberScale()`은 이 방정식을 MAD에서 시작한 고정점 반복(`maxiter` 30, `tol` 1e-8)으로 풀어요. sd는 반복마다 정확히 풀어요. $t = 1/s^2$로 바꾸면

$$
f(t) = \sum_i \min(r_i^2 t,\, d^2)/2
$$

는 $t$에 대해 증가하고 오목한 조각별 일차함수예요. 행마다 $r_i^2 t < d^2$인 동안은 기울기 $r_i^2/2$로 오르다가 $d^2$에 닿으면 평평해지기 때문이에요. 오목한 증가 함수에 $t = 0$에서 뉴턴 걸음을 하면, 접선이 함수 위에 있으므로 걸음은 근을 넘지 않고 단조롭게 올라가요. 그리고 조각별 일차라서, 현재 조각이 근의 조각이면 그 걸음이 근에 정확히 닿아요. 걸음 하나는 지금의 안·밖 나눔에서 $f(t) = T$를 푸는 것이에요.

$$
t \leftarrow \frac{T - n_{\text{밖}}\, d^2/2}{\sum_{\text{안}} r_i^2 / 2}
$$

```cpp
        const double num = T - static_cast<double>(nout) * d2 * 0.5;
        const double den = 0.5 * (A.hi + A.lo);
        // the rows inside are all exactly 0: f stays n_out d^2/2 for every larger t, so below
        // T there is no root and the scale is 0 (an exact fit of the rows inside)
        if (!(den > 0.0)) return (num > 0.0 || !(t > 0.0)) ? 0.0 : 1.0 / std::sqrt(t);
        const double tn = num / den;
        if (!(tn > t)) break;
        t = tn;
```

$\sum_{\text{안}} r_i^2$는 덩어리마다 TwoProduct와 double-double 덧셈으로 더해요. 걸음이 더 오르지 않으면(`!(tn > t)`) 근이에요. 걸음은 보통 3–5번이에요.

안쪽 행의 잔차가 모두 정확히 0이면 분모가 0이에요. 그때 $f$는 $t$를 아무리 키워도 $n_{\text{밖}}d^2/2$에 머물러요. 그 값이 $T$보다 작으면(`num > 0`) 근이 없고, 척도는 0이에요. 안쪽 행이 정확히 맞는 완전 적합이라는 뜻이에요.

## 수렴 판정과 뉴턴 걸음

### 목적함수 판정

반복은 목적함수의 상대 변화가 `tol`(기본 1e-8) 아래가 되면 수렴(`converged=True`)으로 봐요.

```cpp
inline bool settled(DD a, DD b, double tol) {  // |b - a|/(|b| + 0.1) < tol
    const double d = (b.hi - a.hi) + (b.lo - a.lo);
    return std::fabs(d) / (std::fabs(b.hi) + 0.1) < tol;
}
```

$\lvert D - D_{\text{old}}\rvert/(\lvert D\rvert + 0.1)$은 GLM의 편차 판정과 같은 꼴이에요. statsmodels는 절대 변화 $\lvert D - D_{\text{old}}\rvert \le 10^{-8}$을 써요. 상대 변화라서 $y$의 단위를 바꿔도 같은 곳에서 멈춰요.

### IRLS가 느린 이유

IRLS는 선형으로 수렴해요. 한 번에 오차가 일정한 비율로만 줄어요. MAD 척도에서는 그 비율이 0.7에 이르기도 해요. n = 61, Huber의 한 문제에서 statsmodels는 `tol` 1e-15까지 89번 돌아요. 비율이 0.7이면 50번 돌아도 오차가 $0.7^{50} \approx 2\times10^{-8}$배로만 줄어서, 연마 없이 IRLS만 쓰면 수렴이 느린 문제는 `max_iter` 50에 닿아도 계수가 반올림 수준에 이르지 못해요.

### 척도까지 미분한 뉴턴 걸음

그래서 목적함수 판정 뒤에는 추정방정식 $F(\beta) = \sum_i \psi(z_i)x_i$를 뉴턴법으로 풀어요. 판정 전이라도 IRLS의 걸음 $\max_j\lvert\Delta\beta_j\rvert$가 직전 걸음의 1/2 아래로 줄지 않는 반복이 3번 이어지면(비율 1/2 이상이면 반올림까지 수십 번이 들어요) 그때부터 뉴턴 걸음으로 가요. GLM의 전환 판정과 같은 규칙이에요.

여기서 척도 $s$도 $\beta$의 함수예요. $z_i = r_i/s(\beta)$이고 $\partial r_i/\partial\beta = -x_i$이므로

$$
\frac{\partial z_i}{\partial \beta} = -\frac{1}{s}\left(x_i + z_i \nabla s\right), \qquad
F'(\beta) = -\frac1s\Bigl[X^{\mathsf T}\Psi'X + (X^{\mathsf T}\Psi' z)(\nabla s)^{\mathsf T}\Bigr]
$$

예요($\Psi' = \operatorname{diag}\psi'(z_i)$). 뉴턴 걸음 $\beta - F'^{-1}F$는

$$
\beta_{\text{new}} = \beta + s\,M^{-1}F, \qquad M = X^{\mathsf T}\Psi'X + (X^{\mathsf T}\Psi'z)(\nabla s)^{\mathsf T}
$$

이고, 척도 규칙마다 $\nabla s$가 달라요.

- MAD: 가운데 행 $m$에서 $s = \lvert r_m\rvert/C$이므로 $\nabla s = -\operatorname{sign}(r_m)\,x_m/C$예요. 짝수 n이면 가운데 두 행의 평균이에요. 가운데 행은 중앙값을 구할 때처럼 선택으로 찾아요.
- 제안 2: 근에서 $s^2 = \sum_{\text{안}} r_i^2/(2T - n_{\text{밖}}d^2)$이고, 안·밖 나눔이 그대로인 동안 미분하면 $\nabla s = -\sum_{\text{안}} r_i x_i / \bigl(s\,(2T - n_{\text{밖}}d^2)\bigr)$예요.
- 고정 척도(MM의 M 단계): $\nabla s = 0$이고 $M = X^{\mathsf T}\Psi'X$예요.

$\nabla s$ 항을 빼면 척도를 상수로 본 뉴턴이 되는데, 척도가 $\beta$와 함께 움직이는 규칙에서는 그 야코비안이 틀려서 걸음이 다시 선형 수렴이 돼요. 계산은 `newton_step`에 있어요. 부분합 덩어리에서 $X^{\mathsf T}\Psi'X$와 $X^{\mathsf T}\Psi'z$를 모으고, 랭크 1 갱신을 더한 뒤 $k\times k$ LU로 풀어요.

```cpp
    scale_grad(D, sr, r, s, K, g);
    for (lint a = 0; a < kk; ++a)
        for (lint b = 0; b < kk; ++b) M[a * kk + b] += u[a] * g[b];
```

$M$은 대칭이 아니므로(랭크 1 갱신 때문에) Cholesky 대신 LU(`getrf`·`getrs`)예요. $F$는 열마다 TwoProduct와 double-double로 더하고(`estimating`), 새 잔차는 Dot2(곱과 합을 double-double로 하고 한 번 반올림)라서, 해 근처에서 $F$가 거의 0이 되어도 그 값이 반올림 잡음에 묻히지 않아요.

### 걸음을 받는 조건과 멈춤

뉴턴 걸음은 두 조건을 모두 만족할 때만 받아요. $\lVert F\rVert_2$가 줄어야 하고, 새 척도가 원래 척도의 1/2–2배 안이어야 해요. 새 계수의 잔차와 척도에서 $F$를 다시 구해 비교하고, 어느 하나라도 어기면 그 반복은 반복 개선한 QR의 IRLS 걸음이에요. 그래서 해에서 멀거나 ψ의 조각(Huber의 꺾이는 점, 가운데 행)이 바뀌는 곳에서도 반복이 망가지지 않아요.

```cpp
constexpr double kNewtonScaleFactor = 2.0;
inline bool scale_kept(double sn, double s) {
    return sn > 0.0 && std::isfinite(sn) && sn <= kNewtonScaleFactor * s && s <= kNewtonScaleFactor * sn;
}
```

척도 조건은 $\lVert F\rVert$만으로는 막지 못하는 걸음을 막아요. 작은 $z$에서 $\psi(z) \approx z$라서, 척도가 커지기만 해도 $z_i = r_i/s$가 작아지고 $\lVert F\rVert$가 줄어요. 다시 내려가는 ψ는 모든 행을 $c$ 밖으로 보내면 $F = 0$이 돼요. 두 경우 모두 해에 다가간 것이 아닌데 $\lVert F\rVert$ 판정은 통과해요. 뉴턴 모형은 $s(\beta)$를 일차로 근사한 것이라, 척도가 몇 배씩 움직이는 걸음은 그 모형 밖이기도 해요.

판정 뒤의 반복은 계수가 반올림보다 크게 움직이는 동안 이어 가요. 다음 중 하나면 멈춰요(GLM과 같은 규칙).

- 이번 걸음이 $2^{-50}\lVert\beta\rVert_\infty$ 이하예요.
- 직전 두 걸음의 비 $q$로 내다본 남은 걸음의 합 $\text{step}\cdot q/(1 - q)$가 그 아래예요.
- $q \ge 1$, 곧 걸음이 더 줄지 않아요(반올림 잡음만 남았어요).

`converged`는 목적함수의 판정을 통과했고 이 연마가 위의 멈춤 가운데 하나로 끝났을 때만 True예요(척도가 0이 되어 멈춘 경우도 끝난 것으로 봐요). 판정 뒤 연마 중에 `max_iter`에 닿으면 False예요. 판정이 보장하는 것은 `tol`의 정밀도뿐이고, 반올림 수준의 계수는 연마가 끝나야 나오기 때문이에요.

마지막 반복의 최소제곱이 정규방정식이었으면 그 가중치로 반복 개선한 QR을 한 번 더 풀고 잔차와 척도를 다시 구해요. 그래서 계수는 `tol`의 정밀도가 아니라 해에 반올림 수준으로 가까워요. 참값 문제 19개에서 반복은 6–19번이고 계수 벡터의 상대오차는 $1.1\times10^{-16}$ 안이에요.

아래는 세로 이상점 6개가 있는 n = 61의 Huber 적합을 statsmodels와 견준 거예요. statsmodels는 `tol` 1e-15에서 1000번 상한에 닿고(값은 이미 수렴했어요), 기본값(절대 변화 1e-8)에서는 16번에 멈춰 계수가 $10^{-12}$ 정도 떨어져 있어요.

```python
>>> import numpy as np
>>> import statsmodels.api as sm
>>> rng = sd.random.default_rng(1)
>>> x = sd.stats.Normal().sample(61, rng=rng)
>>> y = 1.0 + 2.0 * x + sd.stats.Normal().sample(61, rng=rng)
>>> y = sd.where(sd.arange(61) < 6, y + 10.0, y)
>>> r = sd.regression.rlm(y, x)
>>> r.n_iter, r.converged
(15, True)
>>> X = sm.add_constant(np.asarray(x))
>>> s = sm.RLM(np.asarray(y), X, M=sm.robust.norms.HuberT()).fit(tol=1e-15, maxiter=1000)
>>> d = sm.RLM(np.asarray(y), X, M=sm.robust.norms.HuberT()).fit()
>>> s.fit_history["iteration"], d.fit_history["iteration"]
(1000, 16)
>>> p = np.asarray(r.params)
>>> bool(np.max(np.abs(p - s.params)) / np.max(np.abs(p)) < 1e-15)
True
>>> f"{float(np.max(np.abs(p - d.params)) / np.max(np.abs(p))):.1e}"
'5.8e-12'
>>> [(f.n_iter, f.converged) for f in (sd.regression.rlm(y, x, max_iter=m) for m in (8, 14, 15))]
[(8, False), (14, False), (15, True)]
```

같은 적합을 `max_iter`로 끊으면 연마까지 마치는 15번 전에는 `converged`가 False예요. 상한이 정확히 15이면 연마가 상한에서 끝나요. 멈춤 규칙이 성립했으므로 `n_iter`가 상한과 같아도 True예요. 상한에 닿았는지가 아니라, 판정과 연마가 끝났는지가 기준이에요.

### 척도가 0일 때

절반 넘는 잔차가 정확히 0이면(대부분의 행이 한 평면 위) MAD가 0이에요. 그때 `std_resid`는 잔차가 0인 행에 0, 나머지에 $\pm\infty$를 주고, 반복은 그 자리에서 멈춰 `converged=True`예요. 공분산은 극한값 0이라 `bse`가 0이고(statsmodels도 척도로 나눈 잔차를 0으로 봐요), t와 p는 [최소제곱](/internals/regression/least-squares/#완전-적합의-판정)처럼 NaN이에요. 가중치는 잔차가 0인 행에 1, 나머지에 0이에요(Huber의 $t/\lvert z\rvert$, bisquare와 Hampel의 바깥).

#### 반올림 수준의 완전 적합

잔차가 정확히 0이 되는 일은 드물어요. 절반 넘는 행이 한 직선 위에 있어도, IRLS는 그 행들의 잔차와 척도를 함께 0 쪽으로 몰아갈 뿐이고 정확히 0에는 닿지 못해요. $\beta$ 자체가 반올림된 값이라 직선 위의 행에도 반올림만큼의 잔차가 남기 때문이에요. 척도가 그 반올림 수준까지 내려가면 $r_i/s$는 반올림 잡음을 잡음으로 나눈 값이라, ψ도 가중치도 뉴턴 모형도 뜻을 잃어요. 거기서 받은 걸음은 $\lVert F\rVert$를 줄이면서 엉뚱한 곳으로 갈 수 있어요.

그래서 반복마다 척도를 정하는 행들의 잔차가 반올림 수준으로 0인지 봐요. 행 $i$의 잔차가

$$
\lvert r_i\rvert \le (k + 16)\,u\,\Bigl(\lvert y_i\rvert + \sum_c \lvert x_{ic}\rvert\,\lvert\beta_c\rvert\Bigr)
$$

이면 0으로 봐요. [분위 회귀](/internals/regression/quantile/)가 0 잔차의 허용오차로 쓰고 [최소제곱](/internals/regression/least-squares/#완전-적합의-판정)이 완전 적합을 가르는 식과 같아요. 직선 위의 행이라도 $\beta$를 반올림하는 것만으로 그 행의 $x_i^{\mathsf T}\beta$가 대략 이만큼 움직여요. 겹쳐서 계수가 없는 열(NaN)은 합에 들지 않아요.

```cpp
// (k + 16) u (|y_i| + sum_c |x_ic| |beta_c|); a NaN beta_c (a column without a coefficient)
// takes no part. At most the quick bound (k + 16) u (|y_i| + ||x_i||_1 ||beta||_inf).
inline double zero_tol_row(const Design& D, const double* y, lint i, const double* beta) {
    double xb = 0.0;
    for (lint c = 0; c < D.k; ++c)
        if (!std::isnan(beta[c])) xb += std::fabs(D.at(i, c) * beta[c]);
    return (static_cast<double>(D.k) + 16.0) * (0.5 * kEps) * (std::fabs(y[i]) + xb);
}
```

0으로 볼 행이 몇 개 있어야 하는지는 척도 규칙이 완전 적합에서 0을 내는 조건 그대로예요.

- MAD: 절반 넘게($\lfloor n/2\rfloor + 1$개).
- 제안 2: 0이 아닌 행이 $2T/d^2$ 이하. 그러면 $n_{\text{밖}}d^2/2 \le T$라 위의 척도 방정식에 근이 없어요.
- S의 M-척도: 0이 아닌 행이 $T$ 이하.

먼저 모든 행에서 가장 큰 허용치 하나로 $r$만 한 번 훑어 개수를 세고, 그 개수가 모자라면 바로 넘어가요. 완전 적합과 거리가 먼 반복은 이 한 번의 훑기만 비용으로 내요.

판정을 통과하면 척도를 0으로 두고 반복을 멈춰요(`converged=True`). 계수는 0으로 본 행들만의 최소제곱(가중치 1과 0, 반복 개선한 QR)으로 다시 풀어요. 그 풀이가 열을 잃으면 계수는 그대로예요. 결과는 잔차가 정확히 0인 완전 적합과 같은 꼴이고, 반복이 다가가던 극한이에요. 척도와 표준오차는 0, 가중치는 직선 위의 행(잔차가 위의 허용치 안)에 1, 나머지에 0이에요. Huber처럼 다시 내려가지 않는 ψ도 이 판정으로 완전 적합에서 멈춰요.

```python
>>> x = sd.arange(1.0, 11.0)
>>> y = sd.where(sd.arange(10) == 2, 50.0, sd.where(sd.arange(10) == 6, -20.0, 1.0 + 2.0 * x))
>>> for norm in ["huber", "bisquare", "hampel"]:
...     r = sd.regression.rlm(y, x, norm=norm)
...     print(norm, r.params.tolist(), r.scale, r.bse.tolist(), r.converged)
huber [1.0, 2.0] 0.0 [0.0, 0.0] True
bisquare [1.0, 2.0] 0.0 [0.0, 0.0] True
hampel [1.0, 2.0] 0.0 [0.0, 0.0] True
>>> r.weights.tolist()
[1.0, 1.0, 0.0, 1.0, 1.0, 1.0, 0.0, 1.0, 1.0, 1.0]
>>> sd.regression.rlm(y, x, method="MM", rng=sd.random.default_rng(0)).params.tolist()
[1.0, 2.0]
```

10행 가운데 8행이 $y = 1 + 2x$ 위에 있어요. MM은 S 추정의 다듬기와 고정점까지의 연마에서 M-척도의 규칙으로 같은 판정을 해요. S 척도가 0이 되면 M 단계 없이 그 계수를 내므로 `n_iter`는 0이에요. 제안 2(`scale_est='huber'`)는 이 자료에서 0이 아닌 행 2개가 $2T/d^2$보다 많아 완전 적합이 아니고, 척도 방정식의 근이 있어요.

#### 반복하지 않는 경우

반복을 시작하기 전에 답이 정해지는 세 경우가 있어요. 셋 다 `n_iter`는 0이고 `converged`는 True예요.

```cpp
    bool exact = rank > 0 && n == rank;
    if (op.intercept && kept[0] && rank > 0) {
        bool cy = true;
        for (lint i = 1; i < n && cy; ++i) cy = y[i] == y[0];
        if (cy) {
            exact = true;
            beta[0] = y[0];
            for (lint c = 1; c < k; ++c) beta[c] = kept[c] ? 0.0 : kNaN;
            resid_dd(D, y.data(), beta.data(), r.data(), nullptr);
        }
    }
```

- 반응이 모두 같으면(절편이 있을 때) 해는 정확히 $(y_0, 0, \dots, 0)$이고 척도는 0이에요. 시작 최소제곱은 이 해에 기울기 $10^{-33}$ 크기의 반올림을 남겨요. 그래서 OLS와 같이 정확한 해로 바꿔요. 척도가 0이고 `df_resid` > 0이면 결과의 `_perfect`가 t와 p를 절편까지 NaN으로 둬요(척도 0인 모든 적합에서 그래요, [최소제곱](/internals/regression/least-squares/#완전-적합의-판정)과 같은 규칙).
- 행 수 = 랭크이면 최소제곱의 해가 모든 행을 정확히 지나므로 그 해가 답이고 척도는 0이에요(MM에서는 이것이 S 계수예요). S의 척도 방정식은 $T = (n - p)b = 0$이라 그대로 풀면 0으로 나눠요. `df_resid`가 0이라 공분산은 $0/0$이고, 결과의 `cov_params()`가 NaN으로 둬요.
- 열이 없으면(랭크 0, 모든 열이 0) 반복할 계수가 없어요. 척도는 잔차, 곧 $y$ 자체의 척도예요. M은 MAD나 제안 2이고, MM은 $y$의 S 척도(M-척도)예요.

같은 이유로 제안 2의 `huber_scale`은 $T \le 0$(행 수 ≤ 랭크)이면 0을 내요. 방정식 $\sum\chi(r_i/s) = T$의 오른쪽이 0이면, 이 식을 만족하는 것은 모든 잔차가 0인 완전 적합뿐이고 그 척도는 0이기 때문이에요. 쓰인 행이 하나도 없으면(n = 0) 이 셋과 달리 NaN 결과에 `nobs` 0, `converged` False예요.

```python
>>> x8 = sd.arange(1.0, 9.0)
>>> c8 = sd.regression.rlm(sd.full(8, 3.0), x8)
>>> c8.params, c8.tvalues, c8.n_iter, c8.converged
(array([3.0, 0.0], dtype=float64), array([nan, nan], dtype=float64), 0, True)
>>> d2 = sd.regression.rlm(sd.asarray([1.0, 3.0]), sd.asarray([0.0, 1.0]), scale_est="huber")
>>> d2.params, d2.scale, d2.bse
(array([1.0, 2.0], dtype=float64), 0.0, array([nan, nan], dtype=float64))
>>> z0 = sd.regression.rlm(sd.asarray([1.0, 2.0, 4.0, 3.0, 10.0]), sd.zeros((5, 1)), intercept=False)
>>> z0.rank, z0.scale, z0.n_iter
(0, 4.447806655516806, 0)
```

## MM 추정

### 두 단계가 필요한 이유

M 추정은 $y$ 방향의 이상점(세로 이상점)에는 강하지만, $x$가 멀리 떨어진 행(지렛대점)이 무리를 지으면 최소제곱의 시작에서부터 끌려가요. 아래 예는 200행 가운데 20%를 $x = 5$, $y = -10$의 한 무리로 옮긴 자료예요. 참된 직선은 $1 + 2x$예요.

```python
>>> rng = sd.random.default_rng(7)
>>> x = sd.stats.Normal().sample(200, rng=rng)
>>> y = 1.0 + 2.0 * x + 0.5 * sd.stats.Normal().sample(200, rng=rng)
>>> x = sd.where(sd.arange(200) < 40, 5.0, x)
>>> y = sd.where(sd.arange(200) < 40, -10.0, y)
>>> [round(v, 4) for v in sd.regression.ols(y, x).params.tolist()]
[0.0908, -1.3808]
>>> [round(v, 4) for v in sd.regression.rlm(y, x).params.tolist()]
[-0.0063, -1.4791]
>>> m = sd.regression.rlm(y, x, method="MM", rng=sd.random.default_rng(0))
>>> [round(v, 4) for v in m.params.tolist()]
[0.9692, 2.0179]
>>> m.n_iter, m.converged, round(m.scale, 6), m.cov_type
(6, True, 0.650912, 'avar1')
```

MM 추정(Yohai 1987)은 두 단계예요.

1. **S 추정**(Rousseeuw–Yohai 1984): 잔차의 강건한 척도(M-척도)를 가장 작게 하는 $\beta$예요. 자료의 절반 가까이가 오염되어도 무너지지 않아요(붕괴점 50%). 하지만 효율이 낮고, 목적함수가 볼록하지 않아 무작위 탐색으로 찾아요.
2. **M 단계**: S 추정의 척도를 고정하고 S 계수에서 시작해, 효율 95%의 bisquare($c = 4.685061$, robustbase `lmrob.control()`의 `tuning.psi`)로 M 추정을 해요. 시작점이 좋은 국소 해의 골짜기 안에 있으므로 다시 내려가는 ψ도 안전해요.

### S 추정의 척도 방정식

S 추정의 척도는 정규화한 bisquare $\tilde\rho(u) = 1 - (1 - (u/c)^2)^3$($\lvert u\rvert > c$이면 1), $c = 1.54764$에 대해

$$
\frac{1}{n - p}\sum_i \tilde\rho\!\left(\frac{r_i}{s}\right) = b = \frac12, \qquad\text{곧}\qquad \sum_i \tilde\rho(r_i/s) = T = (n - p)\,b
$$

의 근이에요(robustbase의 `tuning.chi`와 `bb`). $c$는 $\mathbb E\,\tilde\rho(Z) = 1/2$이 되게 고른 값이라(수치 적분으로 0.5000013) 정규 자료에서 $s$가 $\sigma$에 맞고, $b = 1/2$이 붕괴점 50%를 줘요.

$g(s) = \sum_i\tilde\rho(r_i/s) - T$는 $s$에 대해 감소해요. $s \to 0$이면 0이 아닌 잔차의 수 $- T$, $s \to \infty$이면 $-T$예요. 그래서 0이 아닌 잔차가 $T$ 이하면 근이 없고 척도는 0이에요(robustbase의 "완전 적합"). 아니면 부호로 아는 괄호 $(0, \infty)$ 안에서 $g$와 $g'$을 한 번에 더하는 뉴턴법으로 풀어요(`mscale`). 걸음이 괄호를 벗어나면 이분하고, 끝을 아직 모르면 2배나 1/2배로 넓혀요. 후보를 고를 때는 상대 $10^{-10}$(robustbase의 `scale.tol`)까지, 최종 척도는 뉴턴 걸음이 $2^{-51}s$ 아래가 될 때까지 풀어요. 합은 double-double이에요.

### 후보: 기본 부분집합

S 추정의 탐색은 Salibian-Barrera–Yohai(2006)의 fast-S이고, 단계와 상수는 robustbase 0.99.7 `lmrob`의 기본값(`nResample` 500, `k.fast.s` 1, `best.r.s` 2, `k.max` 200, `refine.tol` 1e-7, `solve.tol` 1e-7, `mts` 1000)이에요. 열은 시작 최소제곱이 남긴 열 $p$개를 행 우선으로 꾸려 써요.

후보 $j$는 이렇게 만들어요(`candidate`).

1. 행을 무작위 순서로 뽑아, 앞서 고른 행들과 선형 독립인 행만 $p$개가 될 때까지 모아요(**기본 부분집합**). 독립 판정은 재직교화한 그람–슈미트(두 번 빼기)로, 앞 행들에 직교하는 성분의 노름이 그 행 노름의 $10^{-7}$(`solve.tol`)보다 클 때만 받아요. robustbase의 "nonsingular" 부분표본과 같은 효과예요. 1,000번(`mts`) 안에 못 모으면 그 후보는 버려요.
2. 그 $p$개 행을 정확히 지나는 해 $X_B\beta = y_B$를 LU로 풀어요.
3. robustbase의 첫 척도 $1.4826\cdot\operatorname{median}\lvert r_i\rvert$에서 한 걸음 개선해요(`k.fast.s` = 1). 한 걸음은 척도 한 걸음 $s \leftarrow s\sqrt{\sum_i\tilde\rho(r_i/s)/T}$과 그 척도에서 bisquare 가중치 $(1 - (r_i/(cs))^2)^2$의 가중 최소제곱 한 번이에요(`s_step`; robustbase의 `refine_fast_s`). 척도 걸음은 척도 방정식의 고정점 반복이라, $\sum\tilde\rho(r/s) = T$이면 $s$가 그대로예요.

행을 뽑는 난수는 Philox4×64-10([난수 생성기](/internals/random/generator/))이에요. 키는 Python 층이 회귀마다 `rng.integers(-2**63, 2**63 - 1, endpoint=True, shape=batch_shape + (2,))`로 뽑은 두 단어이고, 후보 $j$의 $t$번째 시도는 원소 $e = j\cdot2^{32} + t$의 첫 단어를 Lemire의 방법으로 $[0, n)$에 줄여 써요. 기각되면 같은 원소의 여분 단어를 써요(sd.random의 `integers`와 같은 규칙, [정수 뽑기](/internals/random/sampling/)).

```cpp
    for (int t = 0; t < kMts && static_cast<lint>(rows.size()) < p; ++t) {
        const std::uint64_t e = (static_cast<std::uint64_t>(j) << 32) | static_cast<std::uint64_t>(t);
        const lint i = static_cast<lint>(
            random::bounded(st.first(e), static_cast<std::uint64_t>(n), [&](std::uint64_t q) { return st.extra(e, q); })
        );
        if (std::find(rows.begin(), rows.end(), i) != rows.end()) continue;
```

Philox는 계수기를 키로 섞는 전단사라서 어떤 원소든 바로 계산할 수 있어요. 후보마다 자기 원소 구간을 쓰므로 후보 500개는 서로 독립이고 어떤 순서로 계산해도 같아요. 그래서 회귀 하나가 크면($n\cdot p\cdot 500 \ge 10^5$) 후보를 4개씩 묶어 스레드풀에 나눠 계산해요.

### 고르기: 가장 좋은 둘

후보를 계산한 뒤 고르는 일은 후보 순서대로 해요(`best_candidates`). 지금까지 남긴 둘 가운데 큰 척도를 $W$라 하면, 새 후보의 잔차에서 $\sum_i\tilde\rho(r_i/W) < T$인지만 먼저 봐요. $g$가 감소하므로 이것은 "이 후보의 척도가 $W$보다 작다"와 같아요. 그럴 때만 그 후보의 척도를 정확히 구해(`mscale`, 상대 $10^{-10}$) $W$를 바꿔요.

```cpp
        if (std::isfinite(worst)) {
            if (worst == 0.0) continue;
            const DD v = row_sum(n, [&](lint i) { return chi_s(r[i] / worst, kSChi); });
            if (!((v.hi - T) + v.lo < 0.0)) continue;
        }
```

척도를 구하는 후보는 보통 십여 개예요. 500개 모두에 척도를 풀면 (10⁵, 10)에서 4배 느려요. 순서대로 하는 이 단계는 결과가 계산 순서에 달려 있으므로 나누지 않아요.

### 다듬기와 고정점

남긴 두 후보는 robustbase처럼 척도 한 걸음과 가중 최소제곱을 번갈아 하며 다듬어요. $\lVert\Delta\beta\rVert < 10^{-7}\max(10^{-7}, \lVert\beta\rVert)$(`refine.tol`)이거나 200번(`k.max`)이면 멈추고, 척도가 작은 쪽을 골라요(같으면 앞의 것).

robustbase는 여기서 끝나지만 sd는 그 후보를 S 추정의 고정점까지 더 가져가요. 고정점은 $\beta$가 자기 잔차의 정확한 M-척도로 만든 가중치로 푼 가중 최소제곱의 해와 같아지는 점이에요. 이 조건은 추정방정식 $\sum_i\psi(r_i/s(\beta))\,x_i = 0$(ψ는 $\tilde\rho'$에 비례하는 $c = 1.54764$의 bisquare ψ, $s(\beta)$는 정확한 M-척도)과 같아요. 가중 최소제곱만 되풀이하면 이 고정점으로 비율 0.8–0.9의 선형 수렴을 해서 50–90번이 들어요. 그래서 반복마다 M 단계와 같은 꼴의 뉴턴 걸음을 먼저 해 보고, M과 같은 두 조건($\lVert F\rVert$가 줄고 새 척도가 1/2–2배 안)을 만족할 때만 받아요. 아니면 그 반복은 정규방정식의 가중 최소제곱이에요. 이 뉴턴의 척도 항 $(X^{\mathsf T}\Psi'z)(\nabla s)^{\mathsf T}$에서, M-척도의 기울기는 $\sum_i\tilde\rho(r_i/s) = T$를 음함수로 미분해 얻어요. 양변을 $\beta$로 미분하면 $\sum_i\tilde\rho'(z_i)\,(x_i + z_i\nabla s) = 0$이라

$$
\nabla s = -\frac{\sum_i\psi(z_i)\,x_i}{\sum_i\psi(z_i)\,z_i}
$$

예요(ψ는 $\tilde\rho'$에 비례하므로 비례 상수는 약분돼요). 분자가 $F$라서 고정점에서 0이 되고, 해 근처에서는 $X^{\mathsf T}\Psi'X$의 뉴턴과 같아요.

멈춤은 걸음이 $2^{-46}\lVert\beta\rVert_\infty$ 이하일 때, 또는 두 걸음의 비로 내다본 나머지가 그 아래일 때예요. $2^{-50}$이 아니라 $2^{-46}$인 것은 이 반복의 가중 최소제곱이 정규방정식이라 그 밑으로는 걸음이 정확하지 않기 때문이에요. 그 뒤 마지막 한 번을 반복 개선한 QR로 풀고 정확한 M-척도를 다시 구해요.

(10⁵, 10)에서 다듬기와 연마의 S 반복 합은 가중 최소제곱만이면 53번, 뉴턴 걸음을 섞으면 27번이에요. R의 문제 다섯 개에서는 36–77번과 18–39번이에요. Arb로 증명한 S 고정점(`tools/regref.py`의 `s_estimate`: $(\beta, s)$의 뉴턴과 Krawczyk 판정)까지의 거리는 R 문제 네 개(n ≤ 500)에서 계수 벡터 노름 상대로 가중 최소제곱만이면 $3.2\times10^{-15}$–$2.5\times10^{-14}$, 뉴턴 걸음을 섞으면 $1.9\times10^{-17}$–$1.2\times10^{-16}$이에요. 뉴턴 걸음을 섞으면 반복이 줄어 MM 전체의 시간도 줄어요.

### 큰 n: 묶음으로 하는 fast-S

n이 2,000보다 크고 $p < 400$이면 robustbase의 큰 n 방식(Salibian-Barrera–Yohai 2006의 5절, `lmrob.control()`의 `fast.s.large.n`, `groups` 5, `n.group` 400)이에요. 아래 단계는 robustbase를 `trace.lev = 4`로 돌린 추적 출력에 나오는 단계와 같아요.

1. 행 2,000개를 비복원으로 뽑아요. 같은 키의 원소 $2^{63} + t$($t = 0, \dots, 1999$)로 하는 부분 Fisher–Yates 섞기이고, 옮긴 자리만 해시 표에 적어 n 크기의 배열을 만들지 않아요. 후보의 원소는 $2^{63}$ 아래라서 둘이 겹치지 않아요.
2. 400행씩 다섯 묶음으로 나누고, 묶음마다 위의 탐색을 그 400행에서 해요(후보 500개, $T = (400 - p)/2$, 가장 좋은 둘). 묶음 $g$의 후보 $j$는 원소 $(g\cdot500 + j)\cdot2^{32} + t$를 써요.
3. 그 10개를 뽑은 2,000행 전체에서 자기 묶음의 척도로 한 걸음 개선하고, 2,000행의 M-척도로 가장 좋은 둘을 골라요(지금 남긴 것보다 작을 때만 바꿔요). R의 추적 출력에서도 이 단계는 "1 refinement"로 나와요.
4. 그 둘을 모든 행에서 위처럼 다듬고 연마해요.

모든 행에서 후보 500개로 하는 작은 n 방식과 견주면, 속도를 잰 세 문제에서 S 척도가 12자리까지 같고 테스트의 n = 6,000 지렛대 25%·40% 문제에서 $10^{-10}$ 안이에요. 시간은 묶음 방식이 훨씬 적게 들어요.

### 같은 비트

후보 $j$가 쓰는 원소, 묶음의 행을 뽑는 원소가 모두 키와 번호로만 정해지므로, 같은 상태의 `rng`면 같은 비트이고 스레드 수와 상관없어요. 키를 배치의 C 순서대로 두 단어씩 뽑으므로, 배치는 같은 `rng`로 하나씩 부른 것과 비트까지 같아요.

```python
>>> old = sd.get_num_threads()
>>> sd.set_num_threads(1)
>>> a = sd.regression.rlm(y, x, method="MM", rng=sd.random.default_rng(0)).params
>>> sd.set_num_threads(old)
>>> a.tolist() == m.params.tolist()
True
>>> Y = sd.stack([y, 2 * y])
>>> b = sd.regression.rlm(Y, x, method="MM", rng=sd.random.default_rng(3))
>>> g = sd.random.default_rng(3)
>>> c0 = sd.regression.rlm(Y[0], x, method="MM", rng=g)
>>> c1 = sd.regression.rlm(Y[1], x, method="MM", rng=g)
>>> b.params.tolist() == [c0.params.tolist(), c1.params.tolist()]
True
```

부분표본의 수가 R과 다르므로 robustbase와 S 계수가 같지는 않아요. 다른 난수로 다른 후보를 보면 같은 S 고정점이나 이웃한 국소 해에 닿아요.

### M 단계

M 단계는 M과 같은 `irls`예요. 꾸린 열에서 S 계수로 시작하고, 척도 규칙은 고정(`sFixed`, $\nabla s = 0$)이며, ψ는 `c`(기본 4.685061)의 bisquare예요. 결과의 `scale`은 S 추정의 척도이고, S 척도가 0이면(0이 아닌 잔차가 $T$ 이하, 또는 위의 반올림 수준 판정) M 단계 없이 S 계수를 내요(`n_iter` 0).

MM의 `converged`는 M 단계의 수렴만이 아니라 S 추정의 두 반복이 끝났는지도 봐요. 고른 후보의 다듬기가 `refine.tol`로 멈췄고(200번 상한이 아니라), 고정점까지의 연마도 멈춤 규칙으로 끝나야(그 상한이 아니라) True예요. M 단계는 S의 척도를 고정하고 S 계수에서 시작하므로, S가 덜 풀렸으면 M 단계가 수렴해도 그 해는 다른 척도와 시작점의 해이기 때문이에요. S의 반복 수는 따로 내지 않아요. `n_iter`는 M 단계의 반복 수예요.

## 공분산

### M: Huber의 H1

M의 공분산은 statsmodels `RLMResults.bcov_scaled`의 기본 `cov='H1'`이에요(Huber 1973; Huber 1981).

$$
V = K^2\,\frac{\frac{1}{n - \text{rank}}\sum_i\psi(z_i)^2}{m^2}\,s^2\,(X^{\mathsf T}X)^{-1}, \qquad m = \frac1n\sum_i\psi'(z_i), \qquad K = 1 + \frac{\text{rank}}{n}\,\frac{\operatorname{var}\psi'(z)}{m^2}
$$

$K$는 $p/n$이 작지 않을 때의 유한 표본 보정이고, $\operatorname{var}$는 $n$으로 나눠요. R `MASS`의 `summary.rlm`은 같은 식에서 분산을 $n - 1$로 나눠 그만큼 달라요. $(X^{\mathsf T}X)^{-1}$은 시작 최소제곱의 $(R^{\mathsf T}R)^{-1}$이에요(statsmodels는 `pinv`). ψ′와 ψ²의 합은 double-double이에요.

### MM: avar1

MM의 공분산은 robustbase 0.99.7 `.vcov.avar1`(`lmrob.control()`의 MM 기본)의 식이에요. M 단계의 잔차 $z_i = r_i/s$, S 잔차 $z_{0i} = r_{0i}/s$, M 단계의 bisquare ψ, S의 $\chi = \tilde\rho$에 대해

$$
\begin{aligned}
A &= s\,(X^{\mathsf T}\Psi'X)^{-1}, \qquad a = A\,X^{\mathsf T}\bigl(\psi'(z)\,z\bigr) \,/\, \operatorname{mean}\bigl(\chi'(z_0)\,z_0\bigr),\\
V &= A\,(X^{\mathsf T}\Psi^2X)\,A - \frac1n\Bigl[a\,\bigl(A X^{\mathsf T}(\psi\chi)\bigr)^{\mathsf T} + \bigl(A X^{\mathsf T}(\psi\chi)\bigr)a^{\mathsf T}\Bigr] + \frac1n\operatorname{mean}\bigl(\chi(z_0)^2 - b^2\bigr)\,a a^{\mathsf T}
\end{aligned}
$$

예요. 이 식은 MM 추정량의 영향함수에 S 척도의 영향을 더한 근사 $\hat\beta - \beta \approx \sum_i\bigl[A x_i\psi_i - a(\chi_i - b)/n\bigr]$의 공분산이에요(Croux–Dhaene–Hoorelbeke 2003). 척도를 고정된 상수로 본 샌드위치 $A(X^{\mathsf T}\Psi^2X)A$에, 척도가 S 잔차에서 추정되었다는 사실이 만드는 교차항과 척도 자신의 분산 항이 붙어요. $b^2$ 항의 꼴은 robustbase 코드 그대로예요.

robustbase는 $X^{\mathsf T}\Psi'X$를 만들어 `solve`로 역행렬을 구하므로 오차가 $\kappa(X)^2u$예요. sd는 합을 시작 최소제곱의 $R$로 얇은 Q의 좌표에서 만들어요. 행마다 $q_i = R^{-\mathsf T}x_i$(전진 대입)로 바꾸면 $X^{\mathsf T}DX = R^{\mathsf T}(Q^{\mathsf T}DQ)R$이므로, $Q^{\mathsf T}\Psi'Q$의 조건수에는 $\kappa(X)^2$이 들어 있지 않아요. 그 좌표에서 $V_Q$를 만든 뒤 $V = R^{-1}V_QR^{-\mathsf T}$로 되돌려요(삼각 풀이 두 번).

```cpp
            V[i * kk + j] = acc + (-(a[i] * Av2[j]) - Av2[i] * a[j] + mu4 * a[i] * a[j]) / dn;
```

스택 손실 자료(κ ≈ 10³)에서 $X^{\mathsf T}\Psi'X$를 직접 만들면 표준오차가 Arb 참값과 $8\times10^{-14}$ 다르고, Q 좌표에서는 $6.7\times10^{-16}$이에요.

$V$에 음의 고윳값이 있으면 robustbase의 `posdefify`를 따라요. `syevd`로 고윳값 분해를 하고, 음의 고윳값을 0으로 두고 다시 곱한 뒤, 대각 원소가 원래 값이 되게 행과 열을 같은 배율로 맞춰요.

### 추론과 평균의 구간

- 결과의 `scale`은 척도 $s$ 자체(표준편차 꼴)예요. `ols`·`glm`·`nls`의 `scale`이 $\hat\sigma^2$인 것과 달라요. 강건 척도는 MAD나 M-척도로 정의되는 퍼짐이라, 그것을 제곱한 값이 오차의 분산을 뜻하지 않기 때문이에요.
- t, p, 구간의 분포는 t(`df_resid`)이고, 그 자유도가 `df_resid_inference`예요(선형 모형과 같은 이름). `df_resid` = 0이면 공분산 전체가 NaN이에요.
- M 추정과 MM 추정은 $y$의 척도에 등변이에요. 그래서 $y$의 크기가 $[2^{-256}, 2^{256}]$ 밖이면 [선형 모형](/internals/regression/least-squares/#극단적인-척도)처럼 Python 층이 $y$를 2의 거듭제곱으로 나눈 문제를 풀고, 계수·`bse`·척도를 그 배수로 돌려놓아요. t와 구간은 적합의 단위에서 만들어요.
- `predict_interval`은 적합값의 신뢰구간 $x\hat\beta \pm t\cdot\text{se}$, $\text{se}^2 = xVx^{\mathsf T}$만 내요. 선형 모형과 같은 `_interval`이라 겹친 열과 NaN의 규칙도 같아요([회귀 영역의 구조](/internals/regression/overview/)). 새 관측의 예측 구간은 없어요. 그 구간에는 오차분포의 분산이 필요한데, 강건 적합은 오차분포를 가정하지 않고 척도도 그 분포의 표준편차가 아니에요.

```python
>>> rs = sd.regression.rlm(sd.asarray([1.0, 2.1, 2.9, 4.2, 4.8, 6.1]), sd.asarray([0.0, 1, 2, 3, 4, 5]))
>>> rs.scale, rs.df_resid_inference
(0.15273309649785163, 4.0)
>>> rs.predict_interval(sd.asarray([6.0]))
array([[ 6.477627064396706, 7.5449168619629985]], dtype=float64)
```

## 정확도

참값은 Arb(구간 산술)로 만들었어요(`tools/regref.py`의 `rlm`). 해의 ψ 조각과 척도의 행(MAD의 가운데 행, 제안 2의 안·밖)을 고정한 매끄러운 방정식을 뉴턴으로 풀고, 그 조각과 순서가 상자 전체에서 확실한지 본 뒤 Krawczyk 판정으로 근을 증명해요. MM은 S 계수와 척도를 고정한 M 단계(와 avar1)의 참값이에요.

| 비교 | 계수(벡터 상대) | 척도 | 표준오차 | 가중치(절대) |
|---|---:|---:|---:|---:|
| Arb, 19문제(ψ 3 × 척도 2 × 짝·홀 n, 절편 없음, n = 400, 스택 손실 ψ 3, MM 2) | $1.1\times10^{-16}$ | $1.4\times10^{-15}$ | $1.2\times10^{-15}$ | $1.1\times10^{-15}$ |
| statsmodels(`tol` 1e-15, `maxiter` 1000, `HuberScale(d=2.5, tol=1e-15)`), ψ 3 × 척도 2 | $2.3\times10^{-15}$ | $2.1\times10^{-15}$ | $1.3\times10^{-15}$ | $4.7\times10^{-15}$ |

척도의 오차는 가운데 잔차의 상쇄($\lvert r_m\rvert$가 $\lvert y\rvert$보다 작아요)에서 와요.

R(4.6.2)과는 이래요.

- `MASS::rlm(scale.est='proposal 2', k2=2.5, acc=1e-15)`: 계수 $4.1\times10^{-15}$, 척도 $1.7\times10^{-14}$ 안이고, 표준오차는 MASS가 var ψ′를 $n - 1$로 나누는 비를 맞추면 $10^{-14}$ 안이에요.
- `MASS::rlm(scale.est='MAD')`: 0.6745로 나누므로 척도가 $1.0$–$1.9\times10^{-5}$, 계수가 $3\times10^{-7}$–$3\times10^{-6}$ 달라요.
- robustbase의 M 단계(`lmrob..M..fit`, `rel.tol` 1e-15)와 `.vcov.avar1`을 같은 S 시작(Arb로 증명한 S 고정점)에서 부르면 계수 $1.1\times10^{-15}$, 표준오차 $7.2\times10^{-15}$ 안이에요. 스택 손실만 $1.5\times10^{-13}$인데, robustbase 쪽의 $\kappa^2u$예요.
- `lmrob` 자체(자기 부분표본, S의 `refine.tol` 1e-7; 큰 n의 n = 5,000 포함)와는 계수 $1.1\times10^{-9}$–$1.2\times10^{-7}$, 척도 $1.3\times10^{-8}$–$1.1\times10^{-5}$ 달라요. `lmrob`의 `scale`은 마지막 고정점 걸음의 값이라 자기 잔차의 정확한 M-척도와 그만큼 달라요. 같은 잔차의 M-척도는 R의 `find_scale`과 $10^{-10}$(R의 `scale.tol`) 안에서 같아요.

## 속도

M(Huber, bisquare)의 반복은 statsmodels처럼 반복마다 `pinv`(SVD)로 가중 최소제곱을 풀지 않고, 정규방정식(덩어리 `dsyrk`)으로 풀고 마지막에만 개선한 QR을 써요. 반복에는 목적함수 판정 뒤의 뉴턴 걸음이 들어 있어요. 계수는 statsmodels 기본값의 수렴 오차만큼($3\times10^{-15}$–$2.4\times10^{-14}$) 달라요.

MM은 Python 참조가 없어 R `lmrob`(기본값)과 견줘요. `lmrob`은 n > 2000이면 묶음 표본 알고리즘으로 후보를 고르고, 다듬기를 상대 10⁻⁷에서 멈춰요. 그래서 계수가 $10^{-8}$ 수준으로 달라요. sd의 시간은 대부분 모든 행에서의 S 다듬기와 고정점까지의 연마예요.

<Callout>
약속은 같은 스레드 수에서 실행마다 같은 비트예요. 지금은 M과 MM 모두 결과가 스레드 수와도 상관없이 같은 비트예요(약속은 아니에요). 행 합의 덩어리는 n으로만 정하고, MM의 후보는 키와 번호로 정한 Philox 원소를 쓰며, 후보를 고르는 단계는 후보 순서대로 해요. 테스트(`tests/regression/test_robust.py`의 `test_threads_bit_identical`, `test_batch_equals_loop`, `test_mm_rng_determinism`)가 1스레드와 10스레드, 배치와 하나씩 부른 것을 비트로 비교해요.
</Callout>

## 다른 구현과 비교

- **statsmodels `RLM`**: M의 추정, ψ, 상수, MAD, 제안 2의 방정식, H1이 같아요. 다른 곳은 멈추는 규칙(statsmodels는 목적함수의 절대 변화 1e-8에서 멈추고, sd는 상대 변화 판정 뒤 뉴턴 걸음으로 반올림까지 가요), 제안 2를 푸는 법(statsmodels는 고정점 반복 30번까지, sd는 반복마다 정확히), 가중 최소제곱(`pinv`와 정규방정식·QR)이에요. 기본값끼리는 그쪽의 수렴 오차만큼(속도를 잰 문제에서 $3\times10^{-15}$–$2.4\times10^{-14}$, 작은 문제에서 $10^{-7}$–$10^{-12}$) 달라요. statsmodels에는 MM이 없어요.
- **R `MASS::rlm`**: 제안 2(`k2 = 2.5`)는 같은 해이고, MAD는 상수 0.6745 때문에 달라요. `summary.rlm`의 표준오차는 var ψ′의 분모가 $n - 1$이에요.
- **R robustbase `lmrob`**: MM의 단계, 상수, avar1의 식이 같아요. 다른 곳은 부분표본의 난수(sd는 Philox 키), S를 고정점까지 연마하는 것(robustbase는 `refine.tol` 1e-7에서 멈춰요), avar1을 Q 좌표에서 만드는 것이에요. 그래서 같은 S 시작에서는 $10^{-15}$ 수준으로 같고, `lmrob` 자체와는 $10^{-9}$–$10^{-7}$ 달라요.
