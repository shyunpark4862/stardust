핵심은 네 가지예요.

1. **ridge는 분해 하나로 모든 alpha를 풀어요.** 해, 잔차 제곱합, 유효 자유도, GCV가 SVD에서 닫힌 꼴이에요. $X^{\mathsf T}X$를 만들지 않아요.
2. **좌표 하강은 활성 집합을 찾는 데 쓰고, 해는 연마가 정해요.** 쌍대 간격의 판정은 계수를 $\sqrt{\text{간격}}$ 남짓까지만 맞춰요. 연마는 활성 집합과 부호를 고정한 정상 조건을 직접 풀고, 그 해가 최소점임을 KKT 부등식으로 검사해요. 그래서 결과가 `tol`과 상관없이 반올림 수준이에요.
3. **연마한 해는 활성 집합과 부호에만 달려 있어요.** 그래서 경로의 해, 같은 alpha의 단독 적합, alpha를 준 순서가 달라도 비트까지 같아요.
4. **교차검증의 겹은 가중치예요.** 겹마다의 적합이 배치 하나가 되고, 각 적합은 그 행만으로 한 적합과 같아요.

## 목적함수와 좌표

목적함수는 scikit-learn의 `ElasticNet`과 같아요.

$$
\frac{1}{2\,s_w}\sum_i w_i\,(y_i - \beta_0 - x_i^{\mathsf T}\beta)^2 + \alpha\left(\rho\,\lVert S\beta\rVert_1 + \frac{1 - \rho}{2}\lVert S\beta\rVert_2^2\right),
\qquad s_w = \sum_i w_i .
$$

$\rho$는 `l1_ratio`(lasso 1, ridge 0)이고, $S = \operatorname{diag}(s_j)$는 `standardize=True`면 열의 모표준편차, 아니면 $I$예요. 절편 $\beta_0$는 벌점 밖이에요. 커널은 중심화·척도화한 좌표

$$
z_{ij} = \frac{x_{ij} - c_j}{s_j}, \qquad b_j = s_j\beta_j, \qquad \omega_i = \frac{w_i}{s_w}, \qquad v_i = y_i - c_y
$$

에서 다음을 풀어요.

$$
P(b) = \tfrac12\sum_i \omega_i\,(v_i - z_i^{\mathsf T}b)^2 + l_1\lVert b\rVert_1 + \tfrac{l_2}{2}\lVert b\rVert_2^2, \qquad l_1 = \alpha\rho,\ l_2 = \alpha(1 - \rho).
$$

$c_j$, $c_y$는 가중 평균이고 절편이 없으면 0이에요. 중심화하면 절편이 문제에서 빠져요. 계수를 구한 뒤 $\beta_j = b_j/s_j$와 $\beta_0 = c_y - \sum_j c_j\beta_j$로 되돌리고, 이 합은 Dot2(곱은 `fma`로 정확히, 합은 two-sum)로 더해요.

### 입력 준비와 정확한 중심화

가중치가 0보다 큰 행이 적합의 행이에요. 한 번 훑어 가중 평균과 상수 열(모든 값이 첫 행과 같은 열; 절편이 없으면 0인 열)을 찾고, 상수 열은 적합에서 빼요(계수 0). 이어 $\sqrt w\,[(x - c),\ y - c_y,\ 1]$의 Gram을 `dsyrk`로 한 번 만들어요. 마지막 열의 합 $S_a = \sum_i w_i(u_{ia} - c_a)$로

$$
G_{ab} - \frac{S_a S_b}{s_w}
$$

를 만들면 정확히 중심화한 Gram이에요. 평균을 double로 반올림한 것이 남지 않아요. 평균도 $c + S/s_w$로 고쳐요.

```cpp
// csrc/regression/penalized.cpp (build)
    // the exact centering: Gram of sqrt(w) (u - mean) = G - S1 S1^T / sw, S1 = the last column
    const lint yi = pc0, oi = pc0 + 1;
    std::vector<double> S1(static_cast<std::size_t>(pc0 + 1));
    for (lint a = 0; a <= pc0; ++a) S1[a] = op.intercept ? (cov ? Gq[oi * q + a] : Gq[q + a]) : 0.0;
    auto Gc = [&](lint a, lint b) {
        const double g = cov ? Gq[b * q + a] : (a == b ? Gq[a] : kNaN);
        return g - S1[a] * S1[b] / sw;
    };
    if (op.intercept) {
        for (lint a = 0; a < pc0; ++a) P.cx[P.cols[a]] += S1[a] / sw;
        P.cy += S1[yi] / sw;
    }
```

표준화의 척도 $s_j$는 이 중심화한 대각에서 나온 가중 모표준편차 $\sqrt{G^c_{jj}/s_w}$예요(glmnet과 같아요). 절편이 없으면 $c_j = 0$이라 RMS $\sqrt{\sum w x_j^2/s_w}$가 돼요. 중심화한 노름이 0인 열은 적합에서 빠져요. Gram의 행 덩어리는 열 수로만 정하고, 고정한 수의 슬롯이 덩어리를 차례로 누적한 뒤 슬롯을 순서대로 더해요. 그래서 스레드 수와 상관없는 비트예요.

## ridge: 분해 하나로 모든 alpha

### SVD의 닫힌 꼴

$l_1 = 0$, $l_2 = \alpha$인 문제의 정규방정식은 $A = \Omega^{1/2}Z$($m \times k$), $\tilde v = \Omega^{1/2}v$로

$$
(A^{\mathsf T}A + \alpha I)\,b = A^{\mathsf T}\tilde v
$$

예요. $A = QR$로 분해하고 $R$의 SVD $R = U\operatorname{diag}(s)V^{\mathsf T}$(`gesdd`)를 구하면 $A^{\mathsf T}A = V\operatorname{diag}(s^2)V^{\mathsf T}$, $A^{\mathsf T}\tilde v = V\operatorname{diag}(s)U^{\mathsf T}d_1$($d = Q^{\mathsf T}\tilde v$)이에요. $e = U^{\mathsf T}d_1$로 쓰면 모든 alpha에서

$$
b(\alpha) = V\operatorname{diag}\!\left(\frac{s_i}{s_i^2 + \alpha}\right)e, \qquad
\text{RSS}(\alpha) = \lVert d_2\rVert^2 + \sum_i\left(\frac{\alpha}{s_i^2 + \alpha}\right)^2 e_i^2, \qquad
\text{df}(\alpha) = \sum_i\frac{s_i^2}{s_i^2 + \alpha}
$$

가 닫힌 꼴이에요. $\text{RSS}$는 $\sum\omega r^2$ 단위이고, $\lVert d_2\rVert^2$은 $\tilde v$에서 열들의 공간 밖에 있는 부분이에요. $\text{df}$는 모자 행렬 $A(A^{\mathsf T}A + \alpha I)^{-1}A^{\mathsf T}$의 대각합이에요. 분해는 alpha와 상관없으니 한 번만 해요.

```cpp
// csrc/regression/penalized.cpp (ridge_one)
        for (lint i = 0; i < r; ++i) {
            const double s_ = sv[i] > cut ? sv[i] : 0.0;
            const double den = s_ * s_ + alpha;
            const double fi = s_ > 0.0 ? s_ / den : 0.0;
            const double shrink = s_ > 0.0 ? alpha / den : 1.0;
            rss += shrink * shrink * e[i] * e[i];
            df += s_ > 0.0 ? s_ * s_ / den : 0.0;
            const double coef = fi * e[i];
            if (coef != 0.0)
                for (lint j = 0; j < pc; ++j) b[j] += coef * Vt[j * ldvt + i];
        }
```

`cut` $= \max(m, k)\cdot 2u\cdot s_1$ 아래의 특이값은 0으로 봐요. alpha = 0에서 최소 노름 해가 되고, 그 방향의 계수는 0이에요. 행이 열보다 적으면 QR 없이 $A$의 SVD를 직접 해요.

닫힌 꼴이 SVD로 쓴 식 그대로임을 작은 문제에서 볼 수 있어요. 가중치가 없으면 $\Omega^{1/2}Z = (X - \bar x)/\sqrt n$이에요.

```python
>>> rng = sd.random.default_rng(7)
>>> X = sd.stats.Normal().sample((50, 6), rng=rng)
>>> y = X @ sd.asarray([2.0, -1.5, 0, 0, 0.8, 0]) + 0.5 * sd.stats.Normal().sample(50, rng=rng)
>>> r = sd.regression.ridge(y, X, alpha=0.5)
>>> Z = (X - sd.mean(X, axis=0)) / sd.sqrt(50.0)
>>> v = (y - sd.mean(y)) / sd.sqrt(50.0)
>>> U, s, Vt = sd.linalg.svd(Z)
>>> b = Vt.T @ ((s / (s**2 + 0.5)) * (U.T @ v))
>>> float(sd.max(sd.abs(r.params[1:] - b) / sd.max(sd.abs(b))))
8.15499667606973e-16
>>> r.df_model, float(sd.sum(s**2 / (s**2 + 0.5)))
(4.00455416952375, 4.0045541695237485)
```

### 키가 큰 설계는 TSQR

$\max(4096, 4k)$행 블록이 4개 이상이면 TSQR이에요(Demmel–Grigori–Hoemmen–Langou 2012[1]). 블록마다 QR(`geqrf`, 스레드풀)을 하고 $Q^{\mathsf T}\tilde v$를 같이 적용한 뒤, 블록들의 $R$을 쌓아 같은 방법으로 다시 QR해요. $R$ 아래로 떨어진 $\tilde v$의 성분은 제곱해 double-double로 더해 $\lVert d_2\rVert^2$에 넣어요. 블록은 크기로만 정해서 스레드 수와 상관없는 비트예요.

설계를 열 우선으로 꾸릴 때는 4,096행 덩어리를 64행 타일로 열마다 이어 써요. 한 행씩 쓰면 같은 행의 원소가 덩어리 길이(2의 거듭제곱, 32 KB)만큼 떨어져 몇 개의 캐시 집합에 몰려 서로 밀어내기 때문이에요. 원소의 계산은 같아 비트가 같아요.

### 조건이 나쁠 때의 개선

해의 조건수 $(s_1^2 + \alpha)/(s_{\min}^2 + \alpha)$가 $64k$를 넘으면 최대 3번 개선해요. 잔차

$$
r_i = (y_i - c_y) - \gamma' - \sum_j z_{ij}b_j
$$

를 OLS의 반복 개선처럼 double-double로 구해요([최소제곱 풀이](/internals/regression/least-squares/)). $y_i - c_y$와 $x_{ij} - c_j$는 two-sum으로 정확히, $z_{ij} = (x_{ij} - c_j)/s_j$와 모든 곱·합은 double-double이고, 기울기 $\sum w z_j r$과 $\sum w r$도 double-double로 더해 한 번 반올림해요.

```cpp
// csrc/regression/penalized.cpp (residual_pass_dd)
            const DD v = special::dd::two_sum(s.yv(i), -P.cy);
            DD r = v - DD{g0, 0.0};
            for (lint q = 0; q < a; ++q) {
                const DD u = special::dd::two_sum(rd(row + off[q]), -cA[q]);
                z[q] = sA[q] == 1.0 ? u : special::dd::operator/(u, sA[q]);
                r = r - z[q] * bA[q];
            }
            const DD wr = r * P.wt[t];
            acc[0] = acc[0] + wr;
            for (lint q = 0; q < a; ++q) acc[1 + q] = acc[1 + q] + wr * z[q];
            acc[a + 1] = acc[a + 1] + wr * r;
            acc[a + 2] = acc[a + 2] + wr * v;
```

보정 $(Z^{\mathsf T}\Omega Z + \alpha I)^{-1}g$는 같은 SVD로 풀어요. 그래서 고정점이 double로 반올림한 설계가 아니라 정확한 문제의 해이고, 한 번에 오차가 그 조건수 × $u$배 줄어요. 걸음이 $4u\lVert b\rVert$ 아래가 되거나 직전 걸음의 1/2 아래로 줄지 않으면 멈춰요. 조건수가 문턱 아래면 개선하지 않으니 조건이 좋은 문제의 비용은 그대로예요.

`bench/regression/g3/accuracy.md`에서 $n = 200$, $k = 8$, 중심화한 설계의 특이값이 1에서 $1/\kappa$까지인 문제의 ridge는 alpha $10^{-3}$, $10^{-8}$ 모두 $\kappa \le 10^6$에서 $2\times10^{-16}$ 안이고, 최소제곱에 가까운 $\kappa = 10^8$–$10^{10}$, alpha $10^{-12}$–$10^{-18}$에서 $1.7\times10^{-15}$ 안이에요(Arb 참값, 씨앗 2개의 최대).

## 좌표 하강

### 소프트 문턱으로 쓰는 한 좌표의 최소점

$b_j$ 하나만 움직이면 $P$는 $b_j$의 이차식에 $l_1\lvert b_j\rvert$를 더한 것이에요. $d_j = z_j^{\mathsf T}\Omega z_j$, $g_j = z_j^{\mathsf T}\Omega r$($r = v - Zb$)이라 하면, $b_j$를 뺀 부분 잔차와의 상관은 $g_j + d_j b_j$이고 최소점은

$$
b_j \leftarrow \frac{\mathcal S(g_j + d_j b_j,\ l_1)}{d_j + l_2}, \qquad \mathcal S(t, \lambda) = \operatorname{sign}(t)\,\max(\lvert t\rvert - \lambda,\ 0)
$$

예요. $\mathcal S$가 소프트 문턱이에요. 상관이 $l_1$ 아래면(정확히는 아래의 반올림 여유까지) 계수가 정확히 0이 돼요. 이 갱신을 열 순서로 되풀이하는 것이 순환 좌표 하강이에요(Friedman–Hastie–Höfling–Tibshirani 2007[2], Friedman–Hastie–Tibshirani 2010[3]). 무작위 순서는 쓰지 않아요.

```cpp
// csrc/regression/penalized.cpp (Solver::sweep)
        for (lint q = 0; q < cnt; ++q) {
            const lint j = list[q];
            const double dj = d[j];
            if (!(dj > 0.0)) continue;
            const double bj = b[j];
            const double g = cov ? c[j] - Gb[j] : cblas_ddot(static_cast<int>(m), Z.data() + j * m, 1, r.data(), 1);
            const double tmp = g + dj * bj;
            const double a = std::fabs(tmp) - l1;
            // the threshold within the gradient's rounding: g = c_j - (G b)_j (or z_j^T r) carries
            // a few u sqrt(d_j v'v) (|c_j| <= sqrt(d_j v'v)), so |tmp| - l1 at that size is the
            // threshold itself and the coefficient stays exactly 0 (a copy of an active column
            // has its gradient on l1 exactly; rounding left 1e-15 there). The KKT test's margin
            // (kKktAbs): the polish accepts every column this leaves at 0
            const double cut = l1 > 0.0 ? kKktAbs * std::sqrt(dj * vv) : 0.0;
            const double nb = a > cut ? std::copysign(a, tmp) / (dj + l2) : 0.0;
            if (nb != bj) {
                const double dl = nb - bj;
                if (cov) cblas_daxpy(static_cast<int>(pc), dl, G.data() + j * pc, 1, Gb.data(), 1);
                else cblas_daxpy(static_cast<int>(m), -dl, Z.data() + j * m, 1, r.data(), 1);
                b[j] = nb;
            }
            dmax = std::max(dmax, std::fabs(nb - bj));
            wmax = std::max(wmax, std::fabs(nb));
        }
```

$g_j$를 얻는 방법은 둘이에요(Friedman–Hastie–Tibshirani 2010의 두 갱신).

- **공분산 갱신**(열 1,024개 이하): $G = Z^{\mathsf T}\Omega Z$와 $c = Z^{\mathsf T}\Omega v$를 한 번 만들어 두고 $g_j = c_j - (Gb)_j$로 구해요. 계수가 바뀌면 $Gb$를 `daxpy` 한 번($O(k)$)으로 고쳐요. alpha 하나의 비용이 행 수와 상관없어요.
- **naive 갱신**(열이 그보다 많으면): $\Omega^{1/2}Z$를 열 우선으로 꾸려 두고 잔차 $r$을 갱신해요. $g_j$는 길이 $m$의 내적이에요. Gram의 대각과 합만 한 번에 더해요.

scikit-learn의 `Lasso`·`ElasticNet`은 기본으로 Gram을 쓰지 않고(`precompute=False`), glmnet은 열 500개 미만에서 공분산 갱신을 써요.

### 문턱의 반올림 여유

$g_j = c_j - (Gb)_j$는 크기가 $\sqrt{d_j\,v^{\mathsf T}\Omega v}$까지인 $c_j$(코시–슈바르츠로 $\lvert c_j\rvert \le \sqrt{d_j\,v^{\mathsf T}\Omega v}$)에서 비슷한 크기를 빼는 계산이라, 반올림이 $u\sqrt{d_j\,v^{\mathsf T}\Omega v}$의 몇 배예요. naive 갱신의 내적 $z_j^{\mathsf T}\Omega r$도 같은 크기의 반올림을 가져요. 그래서 $\lvert g_j + d_jb_j\rvert - l_1$이 그 크기 안이면, 상관이 문턱 위인지 아래인지를 반올림이 정해요. 갱신은 그 차가 $64u\sqrt{d_j\,v^{\mathsf T}\Omega v}$(`kKktAbs`) 이하면 계수를 0으로 둬요. 아래 연마의 비활성 부등식이 쓰는 절대 여유와 같은 값이라, 좌표 하강이 0으로 둔 열은 연마의 검사도 늘 통과해요. $l_1 = 0$(`l1_ratio = 0`)이면 문턱이 없으니 여유도 없어요.

이 여유가 필요한 대표적인 경우는 활성 열의 사본이에요. 똑같은 열 $x_j$, $x_{j'}$에서 $x_j$를 갱신하면 그 상관이 정확히 $l_1$에 놓이고, 바로 뒤 $x_{j'}$의 상관도 수학적으로 정확히 $l_1$이에요. 여유 없이 $a > 0$으로 자르면 반올림 한 번이 사본에 $10^{-15}$ 크기의 계수를 줄 수 있어요. 그러면 활성 집합에 똑같은 열이 둘 들어가 Gram 블록이 특이라 연마가 서지 못하고, `df_model`도 하나를 더 세요. 여유가 있으면 사본은 정확히 0이고, 연마가 사본 없는 활성 집합에서 서므로 해가 사본이 없는 설계의 해와 비트까지 같아요. 경로도 같은 연마로 끝나므로 경로의 해와 단독 적합이 비트까지 같아요. `standardize=True`에서도 같아요. 위 50행 자료에 첫 열의 사본을 앞에 붙이면 이래요.

여유보다 큰 계수는 그대로라, 문턱에서 잘 떨어진 해는 비트 하나 바뀌지 않아요. 정규화 GLM의 안쪽 좌표 하강도 같은 갱신이에요($v^{\mathsf T}\Omega v$ 자리에 작업 반응의 가중 분산).

여유는 반올림 크기의 값만 없애요. 정확히 겹친 열은 같은 부호로 나눈 모든 몫이 최소점이라(L1 노름과 예측이 같아요) 해가 하나가 아니에요. 좌표 하강이 원래 열과 사본 사이에서 다른 계수를 움직이면 사본의 상관이 $l_1$을 반올림보다 크게 넘을 수 있고, 그때 사본은 진짜 몫을 받아요. 그 활성 집합은 Gram 블록이 특이라 연마가 서지 못하므로, 결과는 좌표 하강이 멈춘 최소점이에요. 몫의 크기는 시작점(경로의 따뜻한 시작인지, 0에서 시작한 단독 적합인지)과 갱신 순서에 달려 있어요(아래 alpha = 0 절의 예).

### 활성 집합 스윕

glmnet의 활성 집합 순환과 같아요. 전체 스윕 한 번 뒤에 0 아닌 계수만 스윕하고, 그 변화가 작아지면(가장 큰 변화 ≤ `tol` × 가장 큰 계수) 다시 전체 스윕으로 돌아가요. 대부분의 열이 0인 lasso에서 스윕의 비용이 활성 열의 수로 줄어요. `n_iter`는 두 스윕을 모두 센 수이고 `max_iter`가 alpha마다의 상한이에요.

## 쌍대 간격과 수렴

### 간격

엘라스틱 넷은 증강한 자료 $[Z;\ \sqrt{l_2}I]$, $[v;\ 0]$의 lasso예요. lasso의 쌍대 문제는

$$
\max_\theta\ D(\theta) = \theta^{\mathsf T}\Omega v - \tfrac12\lVert\theta\rVert^2_\Omega \quad\text{s.t.}\quad \lVert \tilde Z^{\mathsf T}\Omega\theta\rVert_\infty \le l_1
$$

이고, 약한 쌍대성으로 어느 실현 가능한 $\theta$에서나 $P(b) - D(\theta) \ge P(b) - P(b^\ast) \ge 0$이에요. 지금의 잔차를 척도 $s = \min\bigl(1,\ l_1/\lVert Z^{\mathsf T}\Omega r - l_2 b\rVert_\infty\bigr)$로 줄인 점이 실현 가능하고, 그 간격은 $R^2 = \sum\omega r^2$, $\text{Ry} = \sum\omega r v$로

$$
\text{gap} = \tfrac12(R^2 + l_2\lVert b\rVert^2)(1 + s^2) + l_1\lVert b\rVert_1 - s\,\text{Ry}
$$

예요(scikit-learn `_cd_fast.pyx`의 꼴 A, Fercoq–Gramfort–Salmon 2015[4]). $R^2$과 $\text{Ry}$는 둘 다 $v^{\mathsf T}\Omega v$ 크기라서, 적합이 좋으면 서로 거의 지워져요. 그래서 $D = \sum\omega r(v - r)$(적합된 부분, $b^{\mathsf T}Z^{\mathsf T}\Omega r$)로 다시 써요. $\text{Ry} = R^2 + D$이므로

$$
\text{gap} = \tfrac12 R^2(1 - s)^2 + \tfrac12 l_2\lVert b\rVert^2(1 + s^2) + l_1\lVert b\rVert_1 - s\,D
$$

이고, 해에서 $s \to 1$이라 첫 항이 저절로 0이 돼요. 남는 항은 적합된 부분의 크기예요. ridge($l_1 = 0$)는 꼴 B $\lVert Z^{\mathsf T}\Omega r - l_2b\rVert^2/(2l_2) + b^{\mathsf T}Z^{\mathsf T}\Omega r - D$이고, alpha = 0은 기울기의 제곱 노름이에요.

```cpp
// csrc/regression/penalized.cpp (Solver::gap_from)
    double gap_from(double l1, double l2, double R2, double D) {
        double l2n = 0.0, l1n = 0.0, bx = 0.0;
        for (lint j = 0; j < pc; ++j) l2n += b[j] * b[j], l1n += std::fabs(b[j]), bx += b[j] * xta[j];
        if (l1 > 0.0) {
            double dn = 0.0;
            for (lint j = 0; j < pc; ++j) {
                xta[j] -= l2 * b[j];
                if (d[j] > 0.0) dn = std::max(dn, std::fabs(xta[j]));
            }
            const double s = dn > l1 ? l1 / dn : 1.0;
            return 0.5 * R2 * (1.0 - s) * (1.0 - s) + 0.5 * l2 * l2n * (1.0 + s * s) + l1 * l1n - s * D;
        }
        if (l2 > 0.0) {
            double q = 0.0;
            for (lint j = 0; j < pc; ++j) q += (xta[j] - l2 * b[j]) * (xta[j] - l2 * b[j]);
            return q / (2.0 * l2) + bx - D;
        }
        double dn2 = 0.0;
        for (lint j = 0; j < pc; ++j) dn2 += xta[j] * xta[j];
        return dn2;
    }
```

### 판정과 그것이 남기는 오차

판정은 scikit-learn과 같아요. 가장 큰 계수 변화가 `tol` × 가장 큰 계수 이하인 전체 스윕 뒤(와 시작할 때) 간격을 재고, 간격 ≤ `tol` × $\sum\omega v^2$이면 수렴이에요. scikit-learn의 `tol·‖y‖²`(그 목적함수는 이것의 $s_w$배)와 같은 판정이에요.

간격은 목적함수의 차이의 상한이에요. 활성 집합에서 목적함수가 $\mu$-강볼록이면 $\text{gap} \ge (\mu/2)\lVert b - b^\ast\rVert^2$이라, 계수는 대략 $\sqrt{2\,\text{gap}/\mu}$까지만 맞아요. 기본 `tol=1e-4`에서 잰 값이 $10^{-6}$–$10^{-4}$이고, 조건이 나쁘면($\mu$가 작으면) 0.3까지 가요. 그래서 판정에서 멈추지 않고 연마해요.

## KKT 연마

### 정상 조건을 직접 풀기

$P$는 볼록이라 KKT 조건이 최소점의 필요충분조건이에요.

$$
z_j^{\mathsf T}\Omega r - l_2 b_j = l_1\operatorname{sign}(b_j)\ \ (b_j \ne 0), \qquad \lvert z_j^{\mathsf T}\Omega r\rvert \le l_1\ \ (b_j = 0).
$$

0 아닌 계수의 집합 $A$와 그 부호 $\sigma$를 알면 첫 조건은 연립방정식이에요.

$$
(Z_A^{\mathsf T}\Omega Z_A + l_2 I)\,b_A = Z_A^{\mathsf T}\Omega v - l_1\sigma .
$$

연마는 좌표 하강이 찾은 $A$와 $\sigma$로 이것을 Gram 블록의 Cholesky로 풀어요. $A$가 비면(해가 모두 0) 풀 연립방정식이 없어서 Gram 블록을 만들지 않고 비활성 부등식만 봐요. 열 0개의 블록을 BLAS(`dsyrk`)에 넘기면 선행 차원 0이 잘못된 인자라 호출 자체가 거부되기 때문에, `active_gram`은 그 경우를 먼저 걸러요. LAPACK이 그 인자에서 어림한 1-노름 조건수가 $64a$($a = \lvert A\rvert$)를 넘으면 ridge와 같은 double-double 잔차로 최대 3번 개선해요. 1-노름 조건수는 2-노름 조건수보다 차원 $a$배까지 클 수 있어서 문턱에 $a$를 곱해요. 그다음 두 가지를 검사해요.

```cpp
// csrc/regression/penalized.cpp (polish)
    for (lint q = 0; q < a; ++q)
        if (l1 > 0.0 && !(bA[q] * sg[q] > 0.0)) return o;
    // the inactive columns' KKT conditions |z_j^T Omega r| <= l1
    std::vector<std::uint8_t> in(static_cast<std::size_t>(s.pc), 0);
    for (lint q = 0; q < a; ++q) in[A[q]] = 1;
    std::vector<double> grad(static_cast<std::size_t>(s.pc), 0.0);
    if (s.cov) {
        for (lint j = 0; j < s.pc; ++j) {
            if (in[j]) continue;
            double g = s.c[j];
            for (lint q = 0; q < a; ++q) g -= s.G[A[q] * s.pc + j] * bA[q];
            grad[j] = g;
        }
    } else {
        std::vector<double> r = s.rv;
        for (lint q = 0; q < a; ++q) cblas_daxpy(static_cast<int>(s.m), -bA[q], s.Z.data() + A[q] * s.m, 1, r.data(), 1);
        if (s.pc > 0)
            cblas_dgemv(CblasColMajor, CblasTrans, static_cast<int>(s.m), static_cast<int>(s.pc), 1.0, s.Z.data(),
                        static_cast<int>(s.m), r.data(), 1, 0.0, grad.data(), 1);
    }
    for (lint j = 0; j < s.pc; ++j) {
        if (in[j] || !(s.d[j] > 0.0)) continue;
        if (!(std::fabs(grad[j]) <= l1 * (1.0 + kKktRel) + kKktAbs * std::sqrt(s.d[j] * s.vv))) return o;
    }
```

1. **부호**: 푼 $b_A$의 부호가 모두 $\sigma$와 같아야 해요.
2. **비활성 부등식**: $A$ 밖의 열마다 $\lvert z_j^{\mathsf T}\Omega r\rvert \le l_1(1 + 10^{-9}) + 64u\sqrt{d_j\,v^{\mathsf T}\Omega v}$여야 해요. 오른쪽의 두 여유는 반올림의 몫이에요. 내적 $z_j^{\mathsf T}\Omega r$의 반올림은 $\lVert z_j\rVert\lVert v\rVert$에 비례하기 때문이에요. 절대 여유는 좌표 하강의 문턱 여유와 같은 값이라, 좌표 하강이 0으로 둔 열이 이 검사에서 걸리지 않아요.

둘 다 통과하면 그 해가 KKT 조건을 반올림 안에서 만족하는 최소점이고, 그것을 써요. $L_1$ 항이 없으면(`l1_ratio = 0`) 모든 열이 $A$이고 부호는 보지 않아요.

```python
[0.09999999999999991, -0.10000000000000007, 0.06192247524256919, 0.1000000000000001, 0.1000000000000004, -0.07682511541905127]
```

활성 열의 기울기는 정확히 $\pm\alpha$이고, 0인 열(셋째와 여섯째)은 $\alpha$ 아래예요. 0인 계수는 정확히 0이에요. 같은 자료의 scikit-learn `Lasso(alpha=0.1)`(기본 `tol=1e-4`)은 계수가 이 해와 $1.6\times10^{-6}$(최대 계수 대비) 다르고, `tol=1e-12`로 조이면 $6.7\times10^{-14}$예요. 결과의 `dual_gap`은 돌려준 해에서 잰 간격(위 목적함수 단위)이에요. scikit-learn 1.9.1의 `dual_gap_`도 n_samples로 나눈 같은 단위예요.

### 언제 연마하나

- **간격 판정을 통과했을 때.** 연마가 실패하면(alpha_max 바로 아래처럼 아직 활성 집합이 다르면) 허용오차를 $10^{-6}$배로 줄여 좌표 하강을 이어 간 뒤 다시 연마해요(최대 2번). 끝내 통과하지 못하면(똑같은 열이 둘이라 해가 하나가 아니고 Gram 블록이 특이한 경우 등) 좌표 하강의 해를 내요. 다시 도는 좌표 하강이 `max_iter`에 닿으면 거기서 멈추고, 연마하지 않은 마지막 반복의 계수와 그 간격을 내며 `converged`를 False로 둬요. 처음의 간격 판정을 통과했어도 그 해는 좁힌 허용오차에도, 연마한 해에도 이르지 못했기 때문이에요. 다시 도는 좌표 하강이 좁힌 판정을 통과했더라도, 그 사이에 `max_iter`를 다 써서 연마를 더 시도할 수 없으면 같은 이유로 False예요. `converged=True`는 언제나 "연마한 해, 또는 연마할 수 없음이 밝혀질 때까지 좁힌 해"라는 뜻이에요. 반복 수의 상한이 alpha마다라서 경로에서도 alpha마다 따로 정해져요.
- **좌표 하강 도중, 두 스윕 연달아 모든 계수의 부호가 같을 때**(활성 집합이 자리를 잡았을 때). 부호 꼴마다 한 번만 시도해요. 통과하면 그 해의 간격으로 수렴을 판정해요. 좌표 하강은 조건이 나쁜 활성 집합에서 선형으로만 수렴하는데, 연마는 그것을 한 번에 풀어요.

```cpp

            po = polish(s, src, P, op.intercept, l1, l2, op.refine_cond);
            // a failed polish means the iterate's active set or signs are not the solution's
            // yet (the gap test passed first): tighter coordinate descent, then again
            double t = op.tol;
            for (int retry = 0; retry < kPolishRetries && !po.ok && cd.n_iter < op.max_iter; ++retry) {
                t *= kRetryTol;
                const CDResult more = cd_solve(s, l1, l2, op.max_iter - cd.n_iter, t * s.vv, t);
                cd.n_iter += more.n_iter;
                cd.gap = more.gap;
                // the tighter sweeps reached max_iter: the last iterate, unpolished, and not
                // converged, though the first gap test had passed
                cd.converged = more.converged;
                if (!more.converged) break;
                po = polish(s, src, P, op.intercept, l1, l2, op.refine_cond);
            }
            // max_iter cut the retries before a polish took: not converged
            if (!po.ok && cd.n_iter >= op.max_iter) cd.converged = false;
        }
```

### 정확도

연마한 해를 개선하지 않으면 Gram 블록의 반올림이 오차를 정해요. 잰 값의 최대가 $8.6\times10^{-15}$이고(활성 집합이 작아 조건수 어림이 문턱 아래인 $\kappa = 10^2$, lasso alpha_max/20), 개선이 돈 칸은 $3\times10^{-16}$ 안이에요(설계 행렬의 조건수 $10^6$까지; 잔차를 double로 구해 개선하면 $2.4\times10^{-14}$). 개선은 조건수 어림이 문턱을 넘을 때만 돌므로 조건이 좋은 문제와 경로의 비용은 그대로예요.

## 경로와 따뜻한 시작

alpha를 큰 것부터 풀고 앞의 해에서 시작해요(따뜻한 시작). 결과는 준 순서로 돌려줘요. 공분산 갱신이면 alpha 하나의 비용이 행 수와 상관없어요(스윕 $O(k\,a)$, 연마 $O(a^3)$).

```cpp
// csrc/regression/penalized.cpp
std::vector<lint> path_order(const double* alphas, std::int64_t as, lint L) {
    std::vector<lint> ord(static_cast<std::size_t>(L));
    std::iota(ord.begin(), ord.end(), lint(0));
    std::stable_sort(ord.begin(), ord.end(),
                     [&](lint a, lint b) { return rd(reinterpret_cast<const std::byte*>(alphas) + a * as) >
                                                  rd(reinterpret_cast<const std::byte*>(alphas) + b * as); });
    return ord;
}
```

연마한 해는 $A$와 부호에만 달려 있어요. 그래서 시작점이 달라도 같은 활성 집합에 닿으면 같은 비트예요. 경로를 섞인 순서로 줘도, 하나씩 따로 적합해도 결과가 같아요.

```python

>>> path = sd.regression.lasso(y, X, alpha=alphas)
>>> all(path.params[i].tolist() == sd.regression.lasso(y, X, alpha=float(alphas[i])).params.tolist()

True
```

기본 격자는 scikit-learn과 같은 $\alpha_{\max}\,\epsilon^{i/(L-1)}$($\epsilon$ = `eps`, $L$ = 100)이에요. `eps`의 기본은 lasso·엘라스틱 넷이 $10^{-3}$, ridge가 $10^{-6}$이에요(이유는 아래). $\alpha_{\max}$는 해가 0이 되는 가장 작은 alpha로, 닫힌 꼴 $\max_j\lvert\sum_i w_i(x_{ij} - \bar x_j)(y_i - \bar y)\rvert/(s_w\,s_j\,\rho)$이에요. $b = 0$이 KKT 조건 $\lvert z_j^{\mathsf T}\Omega v\rvert \le l_1$을 모든 열에서 만족하는 가장 작은 $l_1$이 그것이기 때문이에요. ridge의 격자는 $\rho = 10^{-3}$으로 계산한 $\alpha_{\max}$에서 시작해요(glmnet이 alpha = 0에 쓰는 규칙).

ridge에는 해가 0이 되는 alpha가 없어서 이 $\alpha_{\max}$는 lasso의 $\alpha_{\max}$를 1,000배 한 값일 뿐이에요. 그래서 `eps`가 $10^{-3}$이면 격자의 작은 끝이 바로 lasso의 $\alpha_{\max}$이고, 신호가 뚜렷한 자료의 최적 alpha는 대개 그보다 작아 격자 끝에 걸려요. ridge는 (겹마다) SVD 하나로 모든 alpha를 닫힌 꼴로 풀므로 격자를 넓혀도 분해를 다시 하지 않아요. 그래서 ridge의 기본 `eps`는 $10^{-6}$이고, 격자가 lasso의 $\alpha_{\max}$보다 세 자릿수 아래까지 가요. 위 50행 자료에서 보면 이래요.

### alpha = 0

`ridge`, `lasso`, `elastic_net`의 alpha = 0은 `ols`에 맡기지 않아요. 벌점이 없으면 목적함수는 가중 최소제곱이고, 겹친 열이 있거나 열이 행보다 많으면 최소점이 하나가 아니에요. 세 함수 모두 그 가운데 노름이 가장 작은 해를 내요.

- **ridge**는 SVD의 닫힌 꼴에서 `cut` 아래의 특이값을 0으로 보므로, alpha = 0에서 바로 최소 노름 해예요. 똑같은 열 둘은 계수를 반씩 나눠 가져요. ridge의 해는 alpha → 0에서 이 해로 다가가므로 경로에서도 끊기지 않아요.
- **lasso·엘라스틱 넷**은 alpha = 0인 자리를 ridge 커널로 풀어 넣어요. 커널(`penalized_path`)은 경로를 큰 alpha부터 돌다가 alpha = 0인 자리에서 좌표 하강을 하지 않고 계수와 통계를 NaN으로 비워 둬요. alpha가 모두 0이면 좌표 하강에 쓸 Gram(`build`)도 만들지 않아요. 그다음 Python 층의 `_run`이 같은 y, X, 가중치로 ridge 커널을 alpha 0 하나에 대해 불러, 그 계수와 통계(잔차 제곱합, 교차검증의 시험 오차)를 그 자리에 넣어요. 수렴 표시는 True, `n_iter`는 0, `dual_gap`은 0이에요. 반복하지 않고 닫힌 꼴로 푼 정확한 최소점이니까요. `df_model`은 그 해의 0 아닌 계수의 수예요(아래). NaN인 회귀는 NaN 그대로예요.

```cpp
// csrc/regression/penalized.cpp (enet_one)
    Solver s;
    bool descent = false;  // an alpha > 0 (alpha = 0 is not solved here, below)
    for (lint l = 0; l < L && !descent; ++l) descent = rd(reinterpret_cast<const std::byte*>(alphas) + l * as) != 0.0;
    if (descent) build(src, P, op, s);
    const double rho = op.l1_ratio;
    const double tss = descent ? s.vv * P.sw : kNaN;
    for (const lint l : path_order(alphas, as, L)) {
        const double alpha = rd(reinterpret_cast<const std::byte*>(alphas) + l * as);
        const double l1 = alpha * rho, l2 = alpha * (1.0 - rho);
        if (alpha == 0.0) {
            // the minimum-norm least squares solution, ridge's at alpha = 0, which the Python layer
            // puts here: no coordinate descent (the path's zeros come last, so no warm
            // start depends on it)
            double* st = stats + l * pNStat;
            std::fill(st, st + pNStat, kNaN);
            st[pNobs] = double(P.m);
            st[pSumW] = P.sw;
            st[pIsNaN] = 0.0;
            st[pTss] = tss;
            std::fill(params + l * k, params + (l + 1) * k, kNaN);
            continue;
        }
```

`_run`은 단독 적합, 경로, 교차검증의 겹(학습 가중치와 시험 가중치를 그대로 넘겨요), 고른 alpha로 다시 맞추는 적합이 모두 거치는 곳이라, alpha = 0이 어디에 있든 같은 해예요. 교차검증이 배치의 회귀마다 다른 alpha를 골라 다시 맞출 때(alpha가 배치 모양의 배열)도 0인 자리만 갈아 끼워요. alpha = 0은 경로의 가장 작은 값이라 경로를 큰 것부터 풀 때 마지막이고, 그 자리를 건너뛰어도 다른 alpha의 따뜻한 시작은 그대로예요. 그래서 경로의 다른 자리는 따로 적합한 것과 비트까지 같아요. 좌표 하강을 돌지 않으니 시간도 ridge와 같아요. X (200, 400)에서 `lasso(alpha=0)`과 `ridge(alpha=0)`이 둘 다 5.7 ms예요.

좌표 하강에 맡기지 않는 이유는 두 가지예요. 해가 유일하지 않은 문제에서 좌표 하강은 최소점 가운데 시작점과 갱신 순서에 달린 하나에 멈춰요. 똑같은 열 둘이 이웃하면 먼저 갱신된 열이 계수를 다 받고 뒤 열은 0에 머물고, 사이에 다른 열이 있으면 같은 부호의 몫을 나눠 가질 수도 있어요. 그런 문제는 활성 집합의 Gram 블록이 특이라 연마도 서지 못하므로(위 언제 연마하나 절), 결과가 좌표 하강이 멈춘 점 그대로예요. 또 벌점이 0에 가까울수록 좌표 하강은 느려요. 아래 열 12개, 행 8개의 자료에서 lasso는 alpha = 10⁻²에 스윕 168번, 10⁻⁴에서 1,000번 상한에 닿아 수렴하지 못해요. 최소 노름 해는 하나뿐이고 시작점과 상관없으며, SVD 한 번이면 정확해요.

대가는 lasso 경로의 끝이에요. 최소제곱 해가 유일하면(열이 겹치지 않고 행이 열보다 많으면) 모든 최소점이 같으므로 alpha → 0+의 극한이 그 해이고 경로는 이어져요. 유일하지 않으면 작은 alpha의 lasso 해는 L1 노름이 작은 쪽의 최소점으로 다가가고, 좌표 하강은 그 가운데 다시 시작점에 달린 하나를 골라요. 그래서 경로가 0에서 끊길 수 있어요. 아래 자료는 첫 두 열이 똑같아요. alpha = 0.01의 lasso는 첫 열에 계수를 다 주고, alpha를 더 줄여도($10^{-8}$에서 1.9953298, 0) 그 꼴로 다가가요. alpha = 0은 ridge와 같이 반씩 나눠요. 같은 부호로 나누는 한 L1 노름과 예측은 같으므로 둘 다 최소제곱의 최소점이고, alpha = 0은 그 가운데 L2 노름이 가장 작은 쪽이에요.

`ols`처럼 겹친 열을 NaN으로 두지 않는 것은 이 결과들이 예측에 맞춘 것이기 때문이에요. 겹친 열의 계수가 NaN이면 예측도 쓸 수 없지만, 최소 노름 해는 모든 행의 예측이 최소제곱 적합값 그대로예요. 같은 이유로 이 결과에는 `rank`가 없어요. 겹친 열도 계수를 받아 빠지는 열이 없으므로(상수 열만 0) 셀 것이 쓰인 열의 수뿐이고, 모형의 실제 크기는 유효 자유도 `df_model`이 말해요. alpha = 0의 `df_model`은 ridge가 $\sum s^2/(s^2 + 0)$, 곧 `cut` 위의 특이값 수(랭크)이고, lasso·엘라스틱 넷은 0 아닌 계수의 수예요. 엘라스틱 넷의 식 $a - l_2\operatorname{tr}H^{-1}$(아래 유효 자유도 절)이 $l_2 = 0$에서 $a$이고, alpha > 0의 lasso와 같은 뜻이에요. 계수는 같은데 두 값이 다른 것은 열과 그 사본이 ridge에서는 랭크 1을 나누고, lasso에서는 0 아닌 계수 둘로 세어지기 때문이에요. `penalized_glm`의 alpha = 0은 다르게 `glm`에 맡겨요(아래 정규화 GLM 절). 벌점이 없는 GLM은 분리된 자료에서 최대우도 추정이 없을 수 있어서, 그 판정을 glm의 증명서로 해야 하기 때문이에요.

## 유효 자유도

`df_model`은 적합값이 $v$에 대해 갖는 선형 사상의 대각합이에요. 활성 집합 $A$에서

$$
\text{df} = \operatorname{tr}\, Z_A(Z_A^{\mathsf T}\Omega Z_A + l_2 I)^{-1}Z_A^{\mathsf T}\Omega = a - l_2\operatorname{tr}H^{-1}, \qquad H = Z_A^{\mathsf T}\Omega Z_A + l_2 I
$$

예요. $l_2 = 0$이면 $a$(lasso, Zou–Hastie–Tibshirani 2007[5])이고, $A$가 모든 열이면 ridge의 $\sum s^2/(s^2 + l_2)$예요. 엘라스틱 넷의 이 식은 Zou–Hastie 2005[6]의 것이에요. glmnet의 `df`는 0 아닌 계수의 수예요. $\operatorname{tr}H^{-1}$은 연마의 Gram 블록을 `potrf`·`potri`로 뒤집어 구해요. lasso·엘라스틱 넷의 alpha = 0도 $l_2 = 0$이라 $a$이고, 그 자리는 좌표 하강 없이 ridge 커널의 해로 채우므로 Python 층이 그 해의 0 아닌 계수를 세요(위 alpha = 0 절).

```cpp
// csrc/regression/penalized.cpp
double effective_df(std::vector<double> H, lint a, double l2) {
    if (a == 0) return 0.0;
    if (l2 == 0.0) return double(a);
    if (linalg::lapack::potrf('U', a, H.data(), a) != 0) return kNaN;
    if (linalg::lapack::potri_upper(a, H.data(), a) != 0) return kNaN;
    double tr = 0.0;
    for (lint q = 0; q < a; ++q) tr += H[q * a + q];
    return double(a) - l2 * tr;
}
```

```python
>>> e = sd.regression.elastic_net(y, X, alpha=0.3, l1_ratio=0.5)
>>> A = [j for j in range(6) if e.params[j + 1] != 0]
>>> A, e.df_model
([0, 1, 3, 4], 3.5031052435693835)
>>> H = Z[:, A].T @ Z[:, A] + 0.15 * sd.eye(4)
>>> 4 - 0.15 * float(sd.linalg.trace(sd.linalg.inv(H)))
3.503105243569383
```

## 교차검증

### 겹은 가중치

겹은 가중치로 나타내요. 겹 $q$의 학습 가중치는 $w\cdot[\text{fold} \ne q]$, 시험 가중치는 $w\cdot[\text{fold} = q]$예요. 가중치가 0인 행은 적합에 없는 것과 같으므로(행 선택, 평균, 척도 모두 가중치 > 0인 행으로 해요), 각 적합은 그 행만으로 한 적합과 같아요. 그래서 cv개의 적합이 배치 하나가 되고 겹마다 태스크 하나로 돌아요.

```python
# src/stardust/regression/_penalized.py (_cv)
        labels = _sd.asarray([i % cv for i in range(n)], dtype=_sd.int64)
        fold = _sd.take(labels, rng.permutation(n))
```

```python
# src/stardust/regression/_penalized.py (_cv, 같은 함수)
        test = _sd.where(fold == ks, 1.0, 0.0)  # (cv, 1..., n)
        tw = test * base
        trw = (1.0 - test) * base
        _, S = _run(func, kind, y, X, trw, grid, l1_ratio, "gaussian", intercept, standardize, max_iter, tol, tw=tw)
        sw = S[..., _TEST_SW]
        mse = S[..., _TEST_SSE] / sw  # (cv, batch..., L)
        empty = sw == 0.0
        if not bool(_sd.any(empty)):
            err = _sd.mean(mse, axis=0)
            se = _sd.std(mse, axis=0, correction=1) / math.sqrt(cv)
        else:
            # a fold whose test rows all have weight 0 measures nothing: out of the mean and
            # the standard error; a regression whose every row has weight 0 is NaN
            used = _sd.logical_not(empty)
            cnt = _sd.sum(_sd.where(used, 1.0, 0.0), axis=0)
            err = _sd.sum(_sd.where(used, mse, 0.0), axis=0) / cnt
            dev = _sd.where(used, mse - err, 0.0)
            se = _sd.sqrt(_sd.sum(dev * dev, axis=0) / (cnt - 1.0)) / _sd.sqrt(cnt)
```

겹의 크기는 많아야 1 차이가 나요(0, 1, …, cv − 1을 되풀이한 이름표를 순열로 섞어요). 순열은 [`rng.permutation(n)`](/api/random/permutation/) 하나라 스레드 수와 상관없고, 배치의 모든 회귀가 같은 겹을 써요. 격자는 모든 데이터에서 한 번 정해요(scikit-learn의 `LassoCV`와 같아요). 시험 행의 오차는 경로의 모든 alpha에 대해 시험 행의 덩어리마다 `dgemm`으로 예측을 만들어 $\sum w(y - \hat y)^2$을 순서대로 더해요.

- `cv_error`는 겹마다의 가중 평균 제곱오차의 평균이에요. 겹의 적합이 `max_iter`에 닿아 수렴하지 않았어도 그 계수의 예측으로 재요(그 겹의 수렴 표시는 쓰지 않아요). 결과의 `converged`는 고른 alpha로 모든 데이터를 다시 맞춘 적합의 것이에요.
- `cv_se`는 겹 오차의 표준편차(자유도 cv − 1)/$\sqrt{\text{cv}}$예요. glmnet의 `cvsd`는 겹 크기의 가중 평균을 써서, 겹 크기가 같을 때만 같아요.
- 가중치가 0인 행은 겹을 나눌 때도 그대로 남으므로, 어떤 겹은 시험 행의 가중치가 모두 0일 수 있어요. 그 겹은 잴 오차가 없어 평균 제곱오차가 $0/0$이에요. 그래서 그런 겹을 빼고, 시험 오차가 있는 겹의 수 $c'$로 평균과 표준편차/$\sqrt{c'}$를 구해요. 커널은 그 겹의 시험 행이 없으므로 예측의 `dgemm`을 부르지 않고 오차의 합을 0으로 둬요(행이 0개인 행렬곱은 BLAS가 거부해요). 모든 겹이 비는 것은 가중치가 모두 0일 때뿐이고, 그때는 쓰인 행이 없는 회귀의 NaN 결과(`nobs` 0)예요.

```python
>>> w12 = sd.where(sd.arange(50) < 12, 1.0, 0.0)
>>> cw = sd.regression.lasso_cv(y, X, weights=w12, rng=sd.random.default_rng(0), cv=20, alphas=5)
>>> bool(sd.all(sd.isfinite(cw.cv_error))), cw.nobs
(True, 12.0)
```

가중치가 있는 행이 12개뿐이라 20겹 가운데 적어도 8겹은 시험 오차가 없지만, 남은 겹으로 `cv_error`가 정해져요.

## GCV

`ridge_cv(cv='gcv')`는 겹 없이 일반화 교차검증(Golub–Heath–Wahba 1979[8])으로 골라요. 단일 관측 제외 교차검증의 회전 불변 판이고, ridge의 닫힌 꼴에서 바로 나와요.

$$
\text{GCV}(\alpha) = \frac{\text{RSS}(\alpha)}{\bigl(1 - (\text{df}(\alpha) + c_0)/m\bigr)^2}
$$

$\text{RSS}$는 위처럼 $\sum\omega r^2$ 단위(가중 평균 제곱잔차)이고, $c_0$는 절편이 있으면 1, $m$은 적합 행의 수예요. 위 SVD 식의 $\text{RSS}$와 $\text{df}$를 그대로 쓰니 alpha마다 $O(k)$예요.

```cpp
// csrc/regression/penalized.cpp (ridge_one)
        const double den = 1.0 - (df + c0) / nobs;
        st[pGcv] = rss / (den * den);
```

고른 alpha의 결과는 같은 SVD의 그 alpha 해를 그대로 써요(다시 적합하지 않아요).

```python
>>> g = sd.regression.ridge_cv(y, X, cv="gcv", alphas=sd.asarray([2.0, 0.5, 0.1]))
>>> fits = sd.regression.ridge(y, X, alpha=sd.asarray([2.0, 0.5, 0.1]))
>>> g.cv_error.tolist()
[3.7385912032799746, 1.1778327468314427, 0.35786290448921676]
>>> [float(fits.ssr[i] / 50 / (1 - (fits.df_model[i] + 1) / 50) ** 2) for i in range(3)]
[3.7385912032799693, 1.1778327468314405, 0.35786290448921587]
```

두 줄의 차이는 $\text{RSS}$를 닫힌 꼴로 구했는지, 적합값의 잔차를 double-double로 더했는지예요(`ssr`).

## 정규화 GLM

### 목적함수와 바깥 IRLS

`penalized_glm`은 이항 logit과 포아송 log(정준 링크)만 다뤄요. 목적함수는 glmnet과 같아요.

$$
F(\beta_0, \beta) = \frac{D(\beta_0, \beta)}{2\,s_w} + \alpha\left(\rho\lVert S\beta\rVert_1 + \frac{1 - \rho}{2}\lVert S\beta\rVert^2\right),
$$

$D$는 가중 편차 $\sum w_i d_i$예요. 바깥 반복은 [glm의 IRLS](/internals/regression/glm/)와 같은 이차 근사예요. 지금의 계수에서 작업 가중치 $W_i = w_iV(\mu_i)$와 작업 반응 $z_i = \eta_i + (y_i - \mu_i)/V(\mu_i)$를 만들면 편차는 $\sum W(z - \eta)^2$ 근처의 이차식이고, 그 이차식에 같은 벌점을 더한 문제를 같은 좌표 하강으로 풀어요(Friedman–Hastie–Tibshirani 2010의 3절). 안쪽 좌표 하강은 상대 쌍대 간격 $10^{-9}$, 스윕 1,000번이 상한이에요.

$\mu$는 `glm`의 logit 링크와 같은 sd.special `expit` 커널로 $\mu = \operatorname{expit}(\eta)$, $1 - \mu = \operatorname{expit}(-\eta)$를 구해요. 같은 $\eta$면 `glm`과 같은 $\mu$ 비트예요. 단위 편차 $2\operatorname{softplus}(\pm\eta)$의 $\log(1 + e^{-\lvert\eta\rvert})$는 둘 가운데 작은 쪽 $m = \operatorname{expit}(-\lvert\eta\rvert)$로 $-\operatorname{log1p}(-m)$이에요.

### Gram 한 번에 모든 합을

반복마다 한 번 훑어 $B = [\sqrt W\hat x_A,\ \sqrt W,\ \sqrt W\eta,\ u]$($\hat x = (x - c)/s$, $u = \sqrt{w/V}\,(y - \mu)$)의 Gram을 만들어요. 그러면 $W$로 중심화한 Gram, 기울기 $\sum w(\hat x - \hat c)(y - \mu)$, $\sum w(y - \mu)$, 작업 반응의 합이 모두 그것에서 나와요. $\sqrt W z = \sqrt W\eta + u$이기 때문이에요.

```cpp
// csrc/regression/penalized.cpp
struct WG {
    lint na = 0, q = 0;
    std::vector<double> G;
    double at(lint i, lint j) const { return G[static_cast<std::size_t>(j * q + i)]; }
    lint one() const { return na; }
    lint eta() const { return na + 1; }
    lint u() const { return na + 2; }
    double sW() const { return at(one(), one()); }
    double S(lint a) const { return at(a, one()); }
    double Hc(lint a, lint b) const { return at(a, b) - S(a) * S(b) / sW(); }
    double gc(lint a) const { return at(a, u()) - S(a) * at(one(), u()) / sW(); }
    double g0() const { return at(one(), u()); }
    double zbar() const { return (at(one(), eta()) + g0()) / sW(); }
};
```

열이 1,024개를 넘으면 naive 갱신을 위해 설계를 꾸려요. 그때는 $(p + 3)^2$ 크기의 Gram을 만들지 않아요($p$ = 4,000이면 128 MB예요). 좌표 하강은 꾸린 설계로 돌고, 연마의 KKT 검사와 마지막 값(쌍대 간격, 유효 자유도)에 필요한 것은 열마다의 합 세 개와 $[\sqrt W, \sqrt W\eta, u]$의 3×3 블록뿐이에요. 그래서 한 번 훑어 그것만 모아요(`wvec`, 메모리 $O(p)$).

```cpp
struct WV {
    lint na = 0;
    std::vector<double> v;  // S(a) | G(a, u) | G(a, a) | one.one, one.eta, one.u, eta.eta, eta.u, u.u
    double S(lint a) const { return v[static_cast<std::size_t>(a)]; }
    double gu(lint a) const { return v[static_cast<std::size_t>(na + a)]; }
    double daa(lint a) const { return v[static_cast<std::size_t>(2 * na + a)]; }
    double blk(int i) const { return v[static_cast<std::size_t>(3 * na + i)]; }
    double sW() const { return blk(0); }
    double g0() const { return blk(2); }
    double uu() const { return blk(5); }
    double zbar() const { return (blk(1) + g0()) / sW(); }
    double gc(lint a) const { return gu(a) - S(a) * g0() / sW(); }
    double Hcd(lint a) const { return daa(a) - S(a) * S(a) / sW(); }
};
```

비활성 열의 KKT 부등식은 열마다의 중심화한 기울기 `gc`와 대각 `Hcd`만 쓰고, 유효 자유도의 $H$는 활성 열의 Gram만 있으면 돼요(그것은 활성 열만 따로 `wgram`으로 만들어요). 공분산 갱신의 길(열 1,024개 이하)과 같은 식을 같은 합으로 계산하므로, 두 길이 내는 값의 뜻은 같아요.

### 걸음 반감과 수렴

$F$가 오르면($(F - F_{\text{old}})/(\lvert F\rvert + 0.1) \ge \text{tol}$) 또는 편차가 유한하지 않으면 걸음을 반씩 줄여요(최대 64번). $\lvert F - F_{\text{old}}\rvert/(\lvert F\rvert + 0.1) \lt \text{tol}$(기본 $10^{-8}$)이면 수렴이에요. glm의 편차 판정을 목적함수로 옮긴 꼴이에요.

### 뉴턴 연마

IRLS가 수렴하면 $A$와 부호를 고정한 매끄러운 문제를 뉴턴법으로 풀어요. 헤시안 $X_A^{\mathsf T}WX_A/s_w + l_2I$는 같은 Gram에서 나오고, 절편은 $W$로 중심화한 좌표라 블록이 나뉘어요. 걸음 반감도 같아요. 걸음이 $4u$ × 계수 크기 아래로 줄면 멈추고, 세 걸음째부터 걸음이 직전의 1/2 아래로 줄지 않으면 반올림의 바닥으로 보아 $\sqrt u$ × 크기 아래일 때만 통과해요.

```cpp
// csrc/regression/penalized.cpp (glm_one, try_polish)
                const double step_size = std::max(dmax, std::fabs(dg));
                const double scale = std::max(bmax, std::fabs(gam));
                if (step_size <= 4 * kU * scale) {
                    settled = true;
                    break;
                }
                // the steps stopped shrinking: at the rounding floor when they are that small
                if (step >= 2 && step_size >= 0.5 * prev) {
                    settled = step_size <= 0x1p-26 * scale;
                    break;
                }
                prev = step_size;
```

그다음 부호와 $A$ 밖 열의 KKT 부등식(선형과 같은 꼴, $v^{\mathsf T}\Omega v$ 자리에 편차/$s_w$)을 검사하고, 통과하면 그 해를 써요. 실패하면 안쪽 허용오차를 $10^{-6}$배로 줄여 IRLS를 이어 가요(최대 2번). $L_1$ 항이 없으면(`l1_ratio = 0`) 처음부터 매끄러운 문제라 뉴턴법으로 바로 풀고(정확한 안쪽 풀이의 IRLS와 같아요), 실패할 때만 IRLS예요. `n_iter`는 IRLS(또는 뉴턴) 반복 수이고, 어느 길로 가도 `max_iter`를 넘지 않아요. 처음의 뉴턴 걸음 수를 `max_iter`로 자르고, 상한에 잘리면 그 반복점이 목적함수를 줄인 점일 때 거기서 남은 반복으로 IRLS를 이어 가요($L_1$ 항이 없어 지켜야 할 부호가 없으니 그 점을 그대로 써도 돼요). 뉴턴이 반올림까지 못 간 것이 귀무 모형에서 다시 시작할 이유는 아니기 때문이에요.

```cpp
            if (!settled) {
                if (keep && newton_steps == steps && steps < kNewtonSteps && gp.valid && Fp <= objective(g, beta)) {
                    // the budget ran out on the way: the Newton iterate stands (no L1 term, so
                    // no sign to keep), IRLS goes on from it with what is left
                    beta = nbeta;
                    b0 = nb0;
                    std::swap(g, gp);
                }
                return false;
            }
```

연마가 실패해 다시 도는 IRLS가 `max_iter`에 닿아 연마가 끝내 서지 못하면 `converged`는 False예요(선형의 `lasso`·`elastic_net`과 같은 규칙).

`dual_gap`은 돌려준 계수에서의 이차 근사 문제의 쌍대 간격(목적함수 단위)이에요. 해에서 이차 근사와 목적함수의 기울기가 같으므로 최적성의 척도이지만, 목적함수 값 차이의 상한은 아니에요.

```python
>>> rng = sd.random.default_rng(3)
>>> Xb = sd.stats.Normal().sample((80, 2), rng=rng)
>>> eta = 0.3 + 0.8 * Xb[:, 0] - 0.5 * Xb[:, 1]
>>> yb = (rng.random(80) < 1 / (1 + sd.exp(-eta))).astype(sd.float64)
>>> q = sd.regression.penalized_glm(yb, Xb, family="binomial", alpha=0.02, l1_ratio=1.0)
>>> q.n_iter, q.converged, q.dual_gap
(4, True, 2.888739296709331e-17)
>>> q2 = sd.regression.penalized_glm(yb, Xb, family="binomial", alpha=0.02, l1_ratio=1.0, tol=1e-3)
>>> float(sd.max(sd.abs(q.params - q2.params) / sd.abs(q.params)))
1.3039...e-16
>>> [(f.n_iter, f.converged) for f in (sd.regression.penalized_glm(yb, Xb, family="binomial", alpha=0.02, l1_ratio=0.0,
...                                                              max_iter=m) for m in (2, 4, 6, 10))]

```

`l1_ratio = 0`에서 `max_iter`를 줄이면 `n_iter`가 그 상한에서 멈추고 `converged`가 False예요. 상한이 넉넉하면 6번에 끝나요. 상한이 정확히 6이어도 연마가 그 6번째에 끝나므로 True예요. 상한에 닿았는지가 아니라 판정과 연마가 끝났는지가 기준이고, 선형의 `lasso`·`elastic_net`도 같아요.

### 귀무 모형과 alpha = 0

귀무 모형은 가중 평균 $\bar y$의 절편만이에요(절편이 없으면 $\eta = 0$). $\bar y$가 경계(포아송 0, 이항 0이나 1)면 유한한 해가 없어 계수가 NaN이고 `converged=False`예요. 그래도 귀무 모형 $\mu = \bar y$는 $y$ 자체라 `null_deviance`는 0이에요(`glm`과 같아요).

`null_deviance`는 이 귀무 모형의 편차인데, 절편 $\eta_0 = \log\bar y$(이항은 $\operatorname{logit}\bar y$)에서 되돌린 $\mu$가 아니라 $\mu = \bar y$에서 바로 재요. $e^{\log\bar y}$나 $\operatorname{expit}(\operatorname{logit}\bar y)$는 반올림 때문에 $\bar y$와 정확히 같지 않아서, 그 $\mu$로 재면 $y$가 모두 같을 때도 편차가 0이 아니에요($y = 3$이면 $5\times10^{-31}$). 가중 평균 $\bar y$ 자체도 나눗셈의 반올림이 있으므로, 쓰인 행의 $y$가 모두 같으면 $\bar y$ 대신 그 값 $y_0$를 써요. 그러면 단위 편차가 행마다 정확히 0이라 `null_deviance`가 정확히 0이고, `deviance_ratio`는 $0/0$ = NaN이에요. 상수가 아닌 자료에서는 [`glm`](/api/regression/glm/)의 귀무 편차와 같은 값이에요.

```cpp
// csrc/regression/penalized.cpp (glm_one)
    double b0 = eta0;
    GlmState g, gn;
    glm_eval(src, P, fam, beta.data(), b0, g);
    // the null deviance at mu = ybar itself (exp(log ybar) or expit(logit ybar) round away
    // from it), with ybar the value of a constant y exactly: then it is 0 and deviance_ratio
    // 0/0, NaN; without the intercept the null model eta = 0 above
    double null_dev = g.dev;
    if (op.intercept) {
        bool constant = true;
        const double y0 = m > 0 ? src.yv(P.idx[0]) : 0.0;
        for (lint t = 1; t < m && constant; ++t) constant = src.yv(P.idx[t]) == y0;
        const double mu0 = constant ? y0 : ybar;
        const DD nd = dd_chunk_sum(m, [&](lint t) {
            const double y = src.yv(P.idx[t]);
            const double dv = fam == fBinomial ? (y == 1.0 ? -2.0 * std::log(mu0) : -2.0 * std::log1p(-mu0))
                                               : poisson_dev(y, mu0);
            return DD{P.wt[t] * dv, 0.0};
        });
        null_dev = nd.hi;
    }
```

```python
>>> x8 = sd.arange(8.0)
>>> c3 = sd.regression.penalized_glm(sd.full(8, 3.0), x8, family="poisson", alpha=0.1)
>>> c3.null_deviance, c3.deviance_ratio, c3.deviance
(0.0, nan, 5.259072701473411e-31)
>>> rp = sd.random.default_rng(4)
>>> Xp = sd.stats.Normal().sample((60, 2), rng=rp)
>>> yp = sd.floor(sd.exp(1.0 + 0.3 * Xp[:, 0]) + 2.0 * rp.random(60))
>>> pn = sd.regression.penalized_glm(yp, Xp, family="poisson", alpha=0.05).null_deviance
>>> pn == sd.regression.glm(yp, Xp, family="poisson").null_deviance

```

적합한 계수의 `deviance`는 $\mu = e^{\hat\eta}$에서 재므로 반올림 크기가 남을 수 있어요. 귀무 편차만 정확히 0이면 `deviance_ratio`가 NaN이 되는 데는 충분해요.

벌점이 없으면(alpha = 0) Python 층이 [`glm`](/api/regression/glm/)(`var_weights=weights`, 같은 `max_iter`·`tol`)을 불러 그 자리의 `params`, 편차, 귀무 편차, 반복 수, 수렴, `df_model`을 바꿔 넣어요. 분리 판정은 glm 커널의 증명서 그대로라, 분리면 `params`가 NaN, `separation=True`, $\eta$·$\mu$는 glm의 극한값, `dual_gap`은 NaN이에요. 분리가 없으면 결과가 `glm`과 비트까지 같아요. alpha > 0이면 목적함수가 계수의 크기와 함께 커지므로 분리된 자료에도 유한한 해가 있어($L_1$만이어도) 판정하지 않고 `separation`이 False예요. 커널은 alpha = 0에서도 돌고(경로의 따뜻한 시작은 그대로) 그 값은 버려요.

```python

>>> sd.regression.penalized_glm(yb, Xb, family="binomial", alpha=0.0).params.tolist() == g.params.tolist()
```

결과는 예측에 맞춘 것이라 표준오차와 p값이 없고, 진단(편차 잔차 등)과 강건 공분산도 두지 않아요.

## 결정성

행을 도는 모든 합은 크기로만 정한 덩어리를 순서대로 더하고(Gram은 고정 슬롯), 좌표 순서는 열 순서예요. 회귀 하나의 계산은 배치 안이든 밖이든 같아서 배치와 반복문이 비트까지 같고, 1스레드와 10스레드도 같아요. 테스트(`tests/regression/test_penalized.py`)가 7만 행의 lasso 경로, ridge, lasso_cv, 로지스틱에서 이를 봐요.

| (10⁴, 1000) | 10 | 0.10 / 1.4 | 1.7 | 0.78 | 1.6 | 9.4 | 7.3 / 1.7 | 0.052 / 0.86 |

- ridge는 QR과 SVD라 $X^{\mathsf T}X$의 Cholesky(scikit-learn의 기본)보다 1스레드 5–11배 느리고, 같은 SVD 해법과는 비슷해요. 그 대신 여러 alpha와 GCV가 분해 하나로 나와요(`ridge_cv` GCV 7–63배).
- lasso·엘라스틱 넷의 한 alpha는 Gram 한 번이 시간의 대부분이에요. (10⁴, 1000)의 경로와 CV가 1스레드에서 느린 것은 0 아닌 계수가 수백 개인 작은 alpha마다 연마의 Cholesky($a^3/3$)가 들기 때문이에요.
- 로지스틱 L2는 newton-cholesky와 같은 뉴턴법이지만 반복마다 Gram을 다시 만들고 Dot2로 $\eta$를 구해요. lbfgs는 더 빠르지만 계수가 기본 `tol`에서 $3\times10^{-5}$–$4\times10^{-4}$ 달라요. saga와 liblinear도 기본 `tol`에서 계수가 $10^{-5}$–$6\times10^{-3}$ 달라요(liblinear는 절편에도 벌점을 줘서 다른 문제예요).
