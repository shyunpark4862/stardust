## 한눈에 보기

여기의 값은 모두 커널이 푼 백색화한 문제의 것이에요. OLS는 그대로, WLS는 행마다 $\sqrt{w_t}$를 곱한 문제, GLS는 $L^{-1}$을 곱한 문제, GLM은 마지막 IRLS의 가중 최소제곱이에요. 가중치가 0인 행은 적합에 없으므로 행마다의 값이 0이고 합에서 빠져요. 자료에 NaN이 있는 회귀는 값이 NaN이에요. 이 규칙은 지렛대와 Cook 거리([추론과 진단](/internals/regression/inference/))와 같아요.

| 값 | 정의 | 계산 | 비용 |
|---|---|---|---|
| `vif` | $1/(1 - R_j^2)$ | 적합의 $R$, $R^{-1}$의 행 노름 | $O(nk + k^3)$ |
| `dffits` | $t_i\sqrt{h_i/(1 - h_i)}$ | 지렛대와 외적 스튜던트화 잔차 | 지렛대에 $O(n)$ |
| `dfbetas` | $(\hat\beta - \hat\beta_{(i)})_j / (s_{(i)}\sqrt{[(\tilde X^{\mathsf T}\tilde X)^{-1}]_{jj}})$ | 얇은 Q와 $R^{-1}$ | $O(nk^2)$, 메모리 $nk$ |
| GLM `leverage`, `cooks_distance`, `dffits`, `dfbetas` | 마지막 IRLS 문제의 같은 식, Pearson 잔차 | $\sqrt W X$의 얇은 Q | $O(nk^2)$ |
| `white_test()` | 보조 회귀의 $nR^2$와 F | 보조 열 $O(k^2)$개의 적합 하나 | $O(nk^4)$ |
| `goldfeld_quandt()` | 두 부분의 분산 비 | 0/1 가중치의 적합 둘 | $O(nk^2)$ |
| `reset_test()` | 거듭제곱 열을 더한 F | 확장 적합 하나 | $O(n(k + p)^2)$ |

$h_i$는 지렛대, $t_i$는 외적 스튜던트화 잔차, $s_{(i)}$는 행 $i$를 뺀 적합의 잔차 표준편차예요. 모두 결과 객체에 한 번 계산해 담아 두고 다시 읽을 때 재사용해요.

## 얇은 Q 방식

DFBETAS, GLM의 영향력, Type I의 순서 바꾸기, 내포 검사는 모두 적합과 같은 QR의 얇은 Q가 필요해요. 커널의 `fit`은 `hat_only=True, thin_q=True`로 부르면 적합과 같은 열 선택(겹친 열을 빼는 판정까지)과 같은 QR을 한 뒤, 계수를 풀지 않고 `orgqr`로 Q를 만들어 지렛대, Q, R, 쓰인 열을 내고 멈춰요.

```cpp
    // csrc/regression/linear.cpp
    if (pb.hat_only) {
        std::fill(o.hat, o.hat + n, 0.0);
        if (kk > 0) {
            hat_values();
            for (lint t = 0; t < m; ++t) o.hat[idx[t]] = hat[t];
        }
        if (o.qmat) {  // the thin Q, R and the kept columns, in their places
            std::fill(o.qmat, o.qmat + n * k, 0.0);
            std::fill(o.R, o.R + k * k, 0.0);
            std::fill(o.kept, o.kept + k, std::uint8_t(0));
            for (lint jj = 0; jj < kk; ++jj) {
                o.kept[K[jj]] = 1;
                for (lint t = 0; t < m; ++t) o.qmat[idx[t] * k + K[jj]] = Q[jj * m + t];
                for (lint ii = 0; ii <= jj; ++ii) o.R[K[ii] * k + K[jj]] = A[jj * m + ii];
            }
        }
        return 0;
```

결과는 계수와 같은 자리에 놓여요. 겹친 열의 Q 열과 R의 행·열, 적합 밖의 행은 0이에요. Python 쪽은 이것을 결과에 캐시해서 DFBETAS를 여러 번 읽어도 QR은 한 번이에요.

```python
# src/stardust/regression/_diagnostics.py
def _thin_q(r):
    """(hat, Q (..., n, k), R (..., k, k), kept (..., k)) of the fit's QR, in the fit's units
    (cached: one QR and one orgqr)."""

    def make():
        func, y, X, w, u, tol, _, _ = r._fitargs
        return tuple(_k.fit(func, y, X, w, u, r._intercept, tol, 0, 0, None, 0, -1, True, True))

    return r._cached("thin_q", make)
```

`_fitargs`는 적합할 때 복사해 둔 적합의 단위(열과 $y$를 2의 거듭제곱으로 옮긴 단위)의 $y$, $X$, 가중치예요. 그래서 R과 Q도 그 단위이고, 여기의 값은 모두 단위가 약분되는 비예요.

## VIF

### 보조 회귀 없이

열 $j$의 분산 팽창 인자는 그 열을 절편과 나머지 열에 회귀한 결정계수 $R_j^2$로 $\text{VIF}_j = 1/(1 - R_j^2)$예요. 정의대로 하면 보조 회귀를 $k$번 해야 해요. 적합의 삼각 인자 하나로 모두 구할 수 있어요.

보조 회귀의 잔차 제곱합을 $\text{RSS}_j = \lVert(I - P_{-j})\tilde x_j\rVert^2$($P_{-j}$는 열 $j$를 뺀 나머지 열, 절편 포함의 사영), 열 $j$를 중심화한 제곱합을 $\text{TSS}_j$라 하면 $1 - R_j^2 = \text{RSS}_j/\text{TSS}_j$예요. 그리고 분할 행렬의 역행렬(Schur 여인수)에서

$$
\big[(\tilde X^{\mathsf T}\tilde X)^{-1}\big]_{jj} = \frac{1}{\tilde x_j^{\mathsf T}(I - P_{-j})\tilde x_j} = \frac{1}{\text{RSS}_j}
$$

이라서

$$
\text{VIF}_j = \frac{\text{TSS}_j}{\text{RSS}_j} = \text{TSS}_j\,\big[(\tilde X^{\mathsf T}\tilde X)^{-1}\big]_{jj}
$$

예요. $\tilde X = QR$이면 $(\tilde X^{\mathsf T}\tilde X)^{-1} = R^{-1}R^{-\mathsf T}$이므로 $[(\tilde X^{\mathsf T}\tilde X)^{-1}]_{jj}$는 $R^{-1}$의 $j$행의 노름의 제곱이에요. 필요한 것은 삼각 역행렬 하나($O(k^3)$)와 열마다의 중심화한 제곱합($O(nk)$)이에요.

```python
    # src/stardust/regression/_diagnostics.py
    func, y, X, w, u, tol, _, _ = r._fitargs
    kept_model = r._raw[5]
    if r._intercept:
        R = r._raw[2]
        fx = r._xfactor()
        if fx is not None:  # back to the fit's units (powers of two, exact)
            R = R / _sd.expand_dims(fx, axis=-2)
        kept = kept_model
    else:
        _, _, R, kept = _k.fit(func, y, X, w, u, True, tol, 0, 0, None, 0, -1, True, True)
    Ui = _rinv(R, kept)
    diag = _sd.sum(Ui * Ui, axis=-1)  # (..., k1): [(X~^T X~)^-1]_jj with the intercept first
    # the centered sums of squares of the whitened columns
    if u is not None:
        ones = u
    elif w is not None:
        ones = _sd.sqrt(w)
    else:
        ones = None
    if ones is None:
        Xc = X - _sd.mean(X, axis=-2, keepdims=True)
        tss = _sd.sum(Xc * Xc, axis=-2)
    else:
        Xw = X if u is not None else X * _sd.expand_dims(ones, axis=-1)
        o = _sd.expand_dims(ones, axis=-1)
        coef = _sd.sum(o * Xw, axis=-2, keepdims=True) / _sd.sum(o * o, axis=-2, keepdims=True)
        Xc = Xw - o * coef
        tss = _sd.sum(Xc * Xc, axis=-2)
    v = diag[..., 1:] * tss
    v = _sd.where(kept[..., 1:], v, math.nan)
    if r._intercept:
        v = _sd.concat([_sd.full(tuple(v.shape[:-1]) + (1,), math.nan), v], axis=-1)
    else:
        v = _sd.where(kept_model, v, math.nan)
    return _nan_rows(r, v, 1)
```

- 중심화는 백색화한 절편 방향으로 해요. OLS는 보통의 평균, WLS는 $\tilde x_j$를 $\sqrt w$ 방향에 사영해 빼는 가중 평균, GLS는 $L^{-1}\mathbf 1$ 방향이에요. 가중 모형의 VIF가 가중 회귀의 보조 회귀와 같은 값이 되는 중심화예요(car `vif`의 가중 lm 값과 같아요).
- 절편이 없는 모형도 VIF는 절편을 넣은 보조 회귀의 값이에요. 그래서 절편을 넣은 설계를 `thin_q` 방식으로 한 번 더 분해해 R을 얻어요. 그 설계에서 겹치는 열(상수 열)은 NaN이에요.
- 절편 자리와 겹친 열은 NaN이에요. 나머지 열이 겹친 열을 빼고도 같은 열공간이라, 쓰인 열들의 VIF는 겹친 열을 뺀 모형의 값과 같아요.

```python
>>> rng = sd.random.default_rng(7)
>>> N = sd.stats.Normal()
>>> X0 = N.sample((30, 3), rng=rng)
>>> X = sd.concat([X0[:, :1], 0.8 * X0[:, :1] + 0.6 * X0[:, 1:2], X0[:, 2:]], axis=1)
>>> y = 1.0 + X @ sd.asarray([0.8, 0.0, -0.5]) + N.sample(30, rng=rng)
>>> r = sd.regression.ols(y, X)
>>> r.vif
array([               nan,  2.301711292721903, 2.2662826246698873,
        1.0390674857940545], dtype=float64)
>>> aux = sd.regression.ols(X[:, 1], X[:, [0, 2]])
>>> 1.0 / (1.0 - aux.rsquared)
2.266282624669886
>>> sd.regression.ols(y, X, intercept=False).vif
array([ 2.301711292721903, 2.2662826246698873, 1.0390674857940545], dtype=float64)
```

### 비교 대상

statsmodels의 `variance_inflation_factor(exog, idx)`는 열을 표준화한 뒤 그 열을 나머지 열에 OLS로 회귀해 $R^2$을 구해요(부를 때마다 회귀 하나). 설계의 조건수가 10⁴를 넘으면 경고하고, $R^2$을 $1 - 10^{-15}$에서 잘라요. 가중 모형에 백색화한 설계를 넘겨도 가중 중심화가 아니라 보통의 평균으로 중심화해서 값이 달라요. car의 `vif`는 계수 공분산을 상관 행렬로 바꾼 뒤 행렬식의 비($\det C_{11}\det C_{22}/\det C$, $C$는 그 상관 행렬, 여러 열의 항이면 GVIF)로 구하고, 겹친 계수가 있으면 멈추고 절편이 없으면 경고해요.

κ ≈ 10⁸인 설계에서 VIF의 상대오차는 1.4×10⁻¹⁰이고(Arb 참값 대비), 같은 문제에서 statsmodels는 4.4×10⁻³이에요. 여기의 오차는 $R^{-1}$의 반올림이 $\kappa$배로 커진 값이에요. statsmodels는 1에 가까운 $R_j^2$에서 $1 - R_j^2$를 빼므로 그 뺄셈에서 앞자리가 지워져요. 여기의 식은 그 뺄셈을 하지 않아요.

## DFFITS

DFFITS는 행 $i$를 뺐을 때 그 행의 적합값이 움직이는 양을 그 표준오차로 잰 값이에요. 외적 스튜던트화 잔차와 지렛대로 닫힌 식이 있어요.

$$
\text{DFFITS}_i = \frac{\hat y_i - \hat y_{i(i)}}{s_{(i)}\sqrt{h_i}} = t_i\sqrt{\frac{h_i}{1 - h_i}}
$$

$t_i$는 행을 뺀 적합 없이 내적 스튜던트화 잔차에서 바로 구해요([추론과 진단](/internals/regression/inference/)의 스튜던트화 잔차).

```python
    # src/stardust/regression/_linear.py
    @property
    def dffits(self):
        """t_i sqrt(h_i / (1 - h_i)) (..., n), t the external studentized residual (R's dffits,
        statsmodels' dffits[0]); 0 for the rows with weight 0."""

        def make():
            h = self.leverage
            return self.resid_studentized_external * _sd.sqrt(h / (1.0 - h))

        return self._cached("dffits", make)
```

R `dffits`, statsmodels `OLSInfluence.dffits[0]`과 같은 식이에요. 가중치가 0인 행은 지렛대와 백색화한 잔차가 0이라 값도 0이에요. 백색화한 잔차 $\sqrt{w_t}\,e_t$에 $+0.0$을 더해 두므로, 잔차가 음수인 행도 $-0.0$이 아니라 $+0.0$이에요.

## DFBETAS

### 행을 뺀 계수의 닫힌 식

$A = \tilde X^{\mathsf T}\tilde X$, $b = \tilde X^{\mathsf T}\tilde y$, $\hat\beta = A^{-1}b$라 하고, 행 $i$(백색화한 행 $\tilde x_i$, 열벡터로 써요)를 빼요. $A - \tilde x_i\tilde x_i^{\mathsf T}$의 역은 Sherman–Morrison 공식으로

$$
(A - \tilde x_i\tilde x_i^{\mathsf T})^{-1} = A^{-1} + \frac{A^{-1}\tilde x_i\tilde x_i^{\mathsf T}A^{-1}}{1 - h_i},
\qquad h_i = \tilde x_i^{\mathsf T}A^{-1}\tilde x_i
$$

이에요. 이것을 $b - \tilde x_i\tilde y_i$에 곱하면

$$
\begin{aligned}
\hat\beta_{(i)}
&= \hat\beta - A^{-1}\tilde x_i\tilde y_i + \frac{A^{-1}\tilde x_i\,(\tilde x_i^{\mathsf T}\hat\beta - h_i\tilde y_i)}{1 - h_i} \\
&= \hat\beta - \frac{A^{-1}\tilde x_i}{1 - h_i}\big[(1 - h_i)\tilde y_i - \tilde x_i^{\mathsf T}\hat\beta + h_i\tilde y_i\big]
= \hat\beta - \frac{A^{-1}\tilde x_i\,\tilde e_i}{1 - h_i}
\end{aligned}
$$

이고, $\tilde e_i = \tilde y_i - \tilde x_i^{\mathsf T}\hat\beta$는 백색화한 잔차예요. 행을 뺀 적합을 하지 않아도 계수의 변화가 나와요.

### 얇은 Q 하나로

$\tilde X = QR$이면 $\tilde x_i = R^{\mathsf T}q_i$($q_i$는 Q의 $i$행을 열벡터로 쓴 것)이고

$$
A^{-1}\tilde x_i = R^{-1}R^{-\mathsf T}R^{\mathsf T}q_i = R^{-1}q_i
$$

예요. 분모의 $\sqrt{[A^{-1}]_{jj}}$는 VIF와 같이 $R^{-1}$의 $j$행의 노름 $\lVert(R^{-1})_j\rVert$예요. 외적 스튜던트화 잔차 $t_i = \tilde e_i/(s_{(i)}\sqrt{1 - h_i})$를 쓰면 $\tilde e_i/((1 - h_i)s_{(i)}) = t_i/\sqrt{1 - h_i}$라서

$$
\text{DFBETAS}_{ij} = \frac{(\hat\beta - \hat\beta_{(i)})_j}{s_{(i)}\sqrt{[A^{-1}]_{jj}}}
= \frac{(R^{-1}q_i)_j}{\lVert(R^{-1})_j\rVert}\cdot\frac{t_i}{\sqrt{1 - h_i}}
$$

예요. 모든 행의 $(R^{-1}q_i)^{\mathsf T}$를 쌓은 것이 $M = QR^{-\mathsf T}$($n \times k$) 행렬곱 하나예요.

```python
    # src/stardust/regression/_diagnostics.py
    hat, Q, R, kept = _thin_q(r)
    Ui = _rinv(R, kept)
    nrm = _sd.sqrt(_sd.sum(Ui * Ui, axis=-1))  # (..., k)
    M = _sd.matmul(Q, _sd.matrix_transpose(Ui))  # (..., n, k): row i is (R^-1 q_i^T)^T
    t = r.resid_studentized_external
    f = t / _sd.sqrt(1.0 - hat)
    v = M * _sd.expand_dims(f, axis=-1) / _sd.expand_dims(nrm, axis=-2)
    return _sd.where(_sd.expand_dims(kept, axis=-2), v, math.nan)
```

필요한 것은 얇은 Q(적합과 같은 QR에 `orgqr` 한 번), $k \times k$ 삼각 역행렬, 행렬곱 하나예요. 결과가 $(n, k)$라 메모리도 $nk$예요. 겹친 열의 칸은 NaN이고, 가중치가 0인 행은 Q의 행이 0이라 0이에요.

```python
>>> i = 4
>>> keep = sd.arange(30) != i
>>> ri = sd.regression.ols(y[keep], X[keep])
>>> X1 = sd.concat([sd.ones((30, 1)), X], axis=1)
>>> d = sd.sqrt(sd.linalg.diagonal(sd.linalg.inv(X1.T @ X1)))
>>> (r.params - ri.params) / (ri.scale ** 0.5 * d)
array([ -0.1351251761513582,  0.20765257852616797, -0.04089855919961331,
         0.1994796567999233], dtype=float64)
>>> r.dfbetas[i]
array([-0.13512517615135783,  0.20765257852616786,  -0.0408985591996133,
        0.19947965679992297], dtype=float64)
>>> float(r.dffits[i])
-0.37871005034461974
```

행 하나를 빼고 다시 적합한 값과 반올림 수준에서 같아요. 위의 첫 줄은 `inv`로 $(X^{\mathsf T}X)^{-1}$을 만들어 빼는 정의 그대로의 계산이고, 큰 문제나 조건이 나쁜 문제에서는 쓰지 않는 길이에요.

### 비교 대상

R의 `lm.influence`도 같은 식이에요. `qr.Q`와 `qr.R`로 `t(backsolve(R, t(Q)))`(곧 $M$)를 만들어 $\tilde e_i/(1 - h_i)$를 곱하고, `dfbetas`가 그것을 $s_{(i)}$와 `chol2inv(R)`의 대각의 제곱근으로 나눠요. 다른 곳은 R의 두 처리예요. R은 $100\epsilon\cdot\operatorname{median}\lvert e\rvert$보다 작은 잔차를 0으로 두고, $h_i > 1 - 10\epsilon$인 행은 $h_i = 1$로 보아 계수 변화를 0으로 둬요. 여기서는 계산한 값을 그대로 써요.

statsmodels의 `OLSInfluence.dfbetas`는 행을 하나씩 뺀 OLS를 $n$번 적합하고(`_res_looo`), 두 계수 벡터를 빼요. 비용이 $O(n^2k^2)$이고, 거의 같은 두 벡터의 차라 앞자리가 지워져요. κ ≈ 10⁸인 문제에서 DFBETAS의 최대 상대오차가 여기는 2.3×10⁻⁸, statsmodels는 1.3×10⁻⁵이에요.

## GLM의 영향력

### 마지막 IRLS의 최소제곱

GLM의 적합은 마지막 IRLS 걸음에서 작업 반응 $z$를 가중치 $W$로 $X$에 회귀한 가중 최소제곱이에요([일반화 선형 모형의 IRLS](/internals/regression/glm/)). 영향력은 이 최소제곱 문제에 선형 모형의 식을 쓴 것이에요(Pregibon 1981의 한 걸음 근사). 가중치는 기대 정보의 것이에요.

$$
W_i = f_i\,\frac{m_i\,\mu'(\eta_i)^2}{V(\mu_i)}
$$

$m_i$는 `var_weights` × `trials`, $f_i$는 `freq_weights`, $\mu'$은 역링크의 도함수, $V$는 분산 함수예요. 링크마다 지워지는 항을 미리 지운 꼴로 계산해요(로그 링크의 감마는 $m_i$ 그대로, logit은 $m_i\,\mu_i(1 - \mu_i)$를 `expit` 두 개로).

```python
    # src/stardust/regression/_diagnostics.py
    fa = r._fitargs
    aux = fa["aux"]
    mvar = aux[..., 0, :] * aux[..., 2, :]
    f = aux[..., 1, :]
    mu, eta = r.fittedvalues, r.linear_predictor
    fam, link = r.family, r.link
    if link == "identity":
        W = mvar / (mu if fam == "poisson" else (mu * mu if fam == "gamma" else 1.0))
    elif link == "log":
        if fam == "gaussian":
            W = mvar * mu * mu
        elif fam == "poisson":
            W = mvar * mu
        elif fam == "gamma":
            W = mvar * _sd.ones(tuple(mu.shape))
        else:  # binomial log: mu / (1 - mu)
            W = mvar * mu / (1.0 - mu)
    elif link == "logit":
        from .. import special as _special

        W = mvar * _special.expit(eta) * _special.expit(0.0 - eta)
```

```python
    # src/stardust/regression/_diagnostics.py
    wt = W * f
    used = _sd.logical_and(mvar > 0.0, f > 0.0)
    wt = _sd.where(used, wt, 0.0)
    return _sd.where(_sd.isfinite(wt), wt, 0.0), f, used
```

이 가중치로 $\sqrt W X$를 `thin_q` 방식으로 분해해 지렛대, Q, R을 얻어요. 계수를 풀지 않으므로 $y$ 자리에는 0을 넘겨요. 작업 잔차에 $\sqrt{W_i}$를 곱하면 Pearson 잔차($\sqrt{m_i}(y_i - \mu_i)/\sqrt{V(\mu_i)}$)에 $\sqrt{f_i}$를 곱한 것이 돼요. 그래서 백색화한 잔차 자리에 $\tilde e_i = \sqrt{f_i}\,r^{P}_i$를 넣어요.

```python
    # src/stardust/regression/_diagnostics.py
    wt, f, used = _glm_weights(r)
    X = fa["X"]
    n = X.shape[-2]
    y0 = _sd.zeros((n,))
    hat, Q, R, kept = _k.fit("glm", y0, X, wt, None, r._intercept, fa["rtol"], 0, 0, None, 0, -1, True, True)
    e = _sd.sqrt(f) * r.resid_pearson
    e = _sd.where(used, e, 0.0)
    scale = r.scale
    sc = _expand(scale, 1) if isinstance(scale, _sd.ndarray) else scale
    rank = r._stat(r._I_RANK)
    rk = _expand(rank, 1) if isinstance(rank, _sd.ndarray) else rank
    om = 1.0 - hat
    cooks = e * e * hat / (sc * rk * om * om)
    if r._scale_fixed:
        sig = _sd.sqrt(_sd.full(tuple(e.shape), 1.0) * sc)
    else:
        S = _sd.sum(e * e, axis=-1, keepdims=True)
        df = r.df_resid
        dfx = _expand(df, 1) if isinstance(df, _sd.ndarray) else df
        sig = _sd.sqrt((S - e * e / om) / (dfx - f))
    dffits = e * _sd.sqrt(hat) / (sig * om)
    Ui = _rinv(R, kept)
    nrm = _sd.sqrt(_sd.sum(Ui * Ui, axis=-1))
    M = _sd.matmul(Q, _sd.matrix_transpose(Ui))
    fct = e / (om * sig)
    dfb = M * _sd.expand_dims(fct, axis=-1) / _sd.expand_dims(nrm, axis=-2)
```

$$
D_i = \frac{\tilde e_i^2\,h_i}{\phi\cdot\text{rank}\cdot(1 - h_i)^2}, \qquad
\text{DFFITS}_i = \frac{\tilde e_i\sqrt{h_i}}{s_{(i)}(1 - h_i)}, \qquad
s_{(i)}^2 = \frac{\sum_t \tilde e_t^2 - \tilde e_i^2/(1 - h_i)}{\text{df\_resid} - f_i}
$$

- 척도를 추정하는 모형(정규, 감마)은 $s_{(i)}$가 행 $i$를 뺀 Pearson 척도이고, 척도가 고정인 모형(이항, 포아송)은 $\sqrt\phi$예요. R 4.6의 `influence.measures`(glm)와 같은 규칙이에요.
- 빈도 가중치 $f_i$인 행은 같은 관측 $f_i$개라, 지렛대 $h_i$는 그 사본들이 나눠 가진 합이에요. 행을 뺄 때는 $f_i$개가 한꺼번에 빠지는 것으로 세어 $s_{(i)}$의 분모에서 $f_i$를 빼요.
- DFBETAS는 선형 모형의 식 그대로 $(R^{-1}q_i)_j\,\tilde e_i/((1 - h_i)\,s_{(i)}\lVert(R^{-1})_j\rVert)$예요.
- 분리된 적합은 지렛대까지 NaN이에요. 최대우도 추정이 없어서 가중치가 뜻이 없어요. 척도를 추정하는데 그 척도가 정확히 0(완전 적합)이면 Cook·DFFITS·DFBETAS가 $0/0$이라 NaN이에요.

```python
>>> rp = sd.random.default_rng(21)
>>> Xp = N.sample((40, 2), rng=rp)
>>> yp = sd.stats.Poisson(mu=sd.exp(0.5 + Xp @ sd.asarray([0.4, -0.3]))).sample(rng=rp)
>>> gp = sd.regression.glm(yp, Xp, family="poisson")
>>> float(sd.sum(gp.leverage)), gp.rank
(2.9999999999999996, 3)
>>> f = sd.where(sd.arange(40) == 3, 3.0, 1.0)
>>> gf = sd.regression.glm(yp, Xp, family="poisson", freq_weights=f)
>>> rows = sd.concat([sd.arange(40), sd.asarray([3, 3])])
>>> gr = sd.regression.glm(yp[rows], Xp[rows], family="poisson")
>>> float(gf.leverage[3]), 3.0 * float(gr.leverage[3])
(0.2503729694524213, 0.2503729694524214)
>>> gg = sd.regression.glm(y, X, family="gaussian")
>>> float(sd.max(sd.abs(gg.dfbetas - r.dfbetas)))

```

빈도 가중치 3인 행의 지렛대는 그 행을 세 번 넣은 자료에서 사본 하나의 지렛대의 세 배예요. 정규분포와 identity 링크의 GLM은 가중치가 모두 1이라 마지막 IRLS의 최소제곱이 곧 OLS이고, 영향력도 `ols`의 값과 반올림 수준에서 같아요.

### 비교 대상

R의 `hatvalues`, `cooks.distance`, `dffits`, `dfbetas`(glm)는 `glm`이 가진 작업 가중치(IRLS의 기대 정보)의 QR에서 같은 식으로 구해요. statsmodels의 `GLMInfluence`는 기본(`observed=True`)이 관측 정보의 헤세 행렬로 가중치를 만들어서, 정준 링크(logit, 포아송 log 등)에서는 같고 정준이 아닌 링크(probit, 감마 log 등)에서는 지렛대부터 달라요. `observed=False`면 여기와 같은 지렛대와 Cook 거리예요.

## White 검정

### 보조 열

White 검정은 잔차의 제곱 $\tilde e_t^2$를 상수, 설계의 열, 그 제곱과 서로의 곱에 회귀하는 보조 회귀예요. 오차의 분산이 설명변수의 어떤 이차 함수로든 변하면 보조 회귀의 $R^2$이 커져요.

$$
\text{LM} = n R^2_{\text{aux}} \sim \chi^2(\text{df}_{\text{aux}})
$$

$\text{df}_{\text{aux}}$는 보조 회귀의 `df_model`이고, 보조 회귀 자신의 F(`fvalue`, `f_pvalue`)도 함께 돌려줘요.

```python
    # src/stardust/regression/_diagnostics.py
    func, y, X, w, u, tol, _, _ = r._fitargs
    e = r._wresid()
    wa = None
    if u is not None:
        Z = (
            _sd.concat([_sd.expand_dims(u, axis=-1) * _sd.ones(tuple(X.shape[:-1]) + (1,)), X], axis=-1)
            if r._intercept
            else X
        )
    elif w is not None:
        sw = _sd.expand_dims(_sd.sqrt(w), axis=-1)
        Z = sw * X
        if r._intercept:
            Z = _sd.concat([_sd.broadcast_to(sw, tuple(Z.shape[:-1]) + (1,)), Z], axis=-1)
        wa = _sd.where(w > 0, 1.0, 0.0)  # the rows out of the fit stay out
    else:
        Z = X  # the constant is the auxiliary regression's intercept
    p = Z.shape[-1]
    cols = [Z]
    for i in range(p):
        zi = Z[..., i : i + 1]
        if cross_terms:
            cols.append(zi * Z[..., i:])
        else:
            cols.append(zi * zi)
    A = _sd.concat(cols, axis=-1)
    raw = _k.fit("white_test", e * e, A, wa, None, True, tol, 0, _REFINE_STEPS)
    a = OLSResult(raw, param_names=None, intercept=True, cov_type="nonrobust", batch=_batch_shape(raw))
    # no degree of freedom left in the auxiliary fit (more auxiliary columns than rows): it
    # passes through the data, R^2 = 1 says nothing, and lm is 0/0 like its F
    lm = _nan_where_no_df(a.nobs * a.rsquared, a.df_resid)
```

- 보조 회귀의 $Z$는 백색화한 설계예요. OLS는 $X$ 그대로이고 상수는 보조 회귀의 절편이에요. WLS는 $\sqrt w X$와 절편이 있으면 $\sqrt w$ 열 자체, GLS는 $L^{-1}X$와 $L^{-1}\mathbf 1$이에요. 백색화한 절편 열은 상수가 아니라서 그 열도 제곱과 곱에 들어가요.
- `cross_terms=True`는 $z_iz_j$($i \le j$)를 모두, `False`는 수준과 제곱만 넣어요. 열이 $p$개면 보조 열은 $p + p(p+1)/2$개예요.
- 가중치가 0인 행은 보조 회귀에서도 빠지도록 0/1 가중치를 줘요.
- 보조 회귀는 같은 커널로 반복 개선까지 해요. 그래서 R²가 0에 가까운 보통의 경우(이분산이 없을 때)에도 ESS와 R²가 정확해요.
- 보조 열이 쓰인 행만큼 있어 보조 회귀의 `df_resid`가 0이면, 보조 회귀가 자료를 정확히 지나 $R^2 = 1$이에요. 그 값은 이분산에 대해 아무것도 말하지 않으니 LM도 보조 회귀의 F처럼 0/0의 NaN으로 둬요(`_nan_where_no_df`). [Breusch–Pagan](/internals/regression/inference/)도 같아요.

### 겹치는 보조 열

보조 열에는 겹치는 것이 흔해요. 0/1 더미의 제곱은 더미 자신이고, 서로 배타적인 더미의 곱은 0이에요. 이런 열은 커널의 겹친 열 판정($\lvert R_{jj}\rvert \le \text{rtol}\,\lVert z_j\rVert$, 앞 열이 남아요)이 빼고, 보조 회귀의 자유도도 그만큼 줄어요.

열 두 개가 거의 같으면(차이가 $10^{-7}$ 정도) 그 제곱과 곱은 조건수가 $\kappa^2$인 열들이라, double에서는 정확한 값에서는 독립인 열도 겹친 열로 빠져요. 그때 자유도가 정확한 값보다 하나 적어요.

```python
>>> X0r = sd.regression.ols(y, X0)
>>> X0r.white_test()
WhiteTestResult(lm=8.07758, lm_pvalue=0.526347, fvalue=0.818805, f_pvalue=0.605929, df=9, df_num=9, df_denom=20)
>>> e2 = X0r.resid ** 2
>>> Z = sd.concat([X0, X0[:, :1] * X0, X0[:, 1:2] * X0[:, 1:], X0[:, 2:] * X0[:, 2:]], axis=1)
>>> a = sd.regression.ols(e2, Z)
>>> a.nobs * a.rsquared
8.077582154228203
>>> dummy = sd.where(sd.arange(30) % 2 == 0, 1.0, 0.0)
>>> Xd = sd.concat([X0[:, :2], sd.reshape(dummy, (30, 1))], axis=1)
>>> sd.regression.ols(y, Xd).white_test().df
8.0
>>> Xn = sd.concat([X0[:, :2], X0[:, 1:2] + 1e-7 * X0[:, 2:3]], axis=1)
>>> sd.regression.ols(y, Xn).white_test().df
8.0
```

더미 열의 제곱이 겹쳐 자유도가 9에서 8로 줄었어요. 마지막은 둘째와 셋째 열이 $10^{-7}$만큼 다른 설계라, 셋째 열의 제곱과 곱이 반올림으로 겹쳐 하나가 빠졌어요.

### 비교 대상

statsmodels의 `het_white(resid, exog)`는 exog에 상수 열이 있다고 가정하고 `np.triu_indices`로 모든 $x_ix_j$($i \le j$, 상수 열 포함)를 만들어 OLS(의사역행렬)로 풀어요. 상수와의 곱이 수준이 되고, 자유도는 의사역행렬의 랭크예요. `interaction_terms=False`는 `exog**2`라 수준이 빠지고 제곱만 남아요. 여기의 `cross_terms=False`는 White(1980)의 교과서 꼴인 수준과 제곱이에요. R에는 White 검정 함수가 따로 없고, `lmtest::bptest(m, ~ x1 * x2 + I(x1^2) + I(x2^2))`처럼 보조 식을 손으로 적어요.

## Goldfeld–Quandt 검정

### 나누기

적합에 쓰인 행을(`order_by`가 있으면 그 키로) 늘어놓고 앞 $n_1$행과, 그 뒤 `drop`행을 건너뛴 나머지로 나눠요. 두 부분을 같은 열로 따로 적합해 잔차 분산의 비를 봐요.

$$
F = \frac{\text{SSR}_2/\text{df}_2}{\text{SSR}_1/\text{df}_1} \sim F(\text{df}_2, \text{df}_1)
$$

행을 복사하거나 정렬하지 않아요. 행마다 쓰인 행 가운데의 자리(`pos`)를 매기고, 두 부분을 0/1 가중치로 고른 같은 적합 두 번으로 풀어요. 배치에서 회귀마다 쓰인 행 수가 달라도 한 번의 배치 호출이에요.

```python
    # src/stardust/regression/_diagnostics.py
    fn, y, X, w, u, tol, _, _ = r._fitargs
    n = y.shape[-1]
    used = _sd.ones(tuple(X.shape[:-1])) > 0 if w is None else w > 0
    used = _sd.broadcast_to(used, tuple(r._batch) + (n,)) if r._batch else used
    key = _order_key(r, func, order_by, X, n)
    usedf = _sd.where(used, 1.0, 0.0)
    m = _sd.sum(usedf, axis=-1)  # the fit's rows per regression
    if key is None:
        pos = _sd.cumulative_sum(usedf, axis=-1) - 1.0
    else:
        # rows out of the fit go last; a stable sort keeps the order of equal keys (R's order)
        kk = _sd.where(used, key, math.inf)
        order = _sd.argsort(kk, axis=-1, stable=True)
        rank = _sd.argsort(order, axis=-1, stable=True)
        pos = rank.astype(_sd.float64)
    mm = _expand(m, 1) if isinstance(m, _sd.ndarray) else m
    n1 = (
        float(n1_rows)
        if n1_rows is not None
        else _sd.floor(mm * n1_frac)
        if isinstance(mm, _sd.ndarray)
        else float(math.floor(mm * n1_frac))
    )
    dd = (
        float(d_rows)
        if d_rows is not None
        else (_sd.floor(mm * d_frac) if isinstance(mm, _sd.ndarray) else float(math.floor(mm * d_frac)))
    )
    part1 = _sd.logical_and(used, pos < n1)
    part2 = _sd.logical_and(used, pos >= n1 + dd)
    base = _sd.ones((n,)) if w is None else w
    stats = []
    for part in (part1, part2):
        wp = _sd.where(part, base, 0.0)
        raw = _k.fit(fn, y, X, wp, None, r._intercept, tol, 0, _REFINE_STEPS)
        a = WLSResult(raw, param_names=None, intercept=r._intercept, cov_type="nonrobust", batch=_batch_shape(raw))
        stats.append((a._ssr_s(), a.df_resid))
    (s1, df1), (s2, df2) = stats
    Fv = _div(_div(s2, df2), _div(s1, df1))
    bad = _either_zero(s1, s2, df1, df2)
    Fv = _sd.where(bad, math.nan, Fv) if isinstance(Fv, _sd.ndarray) else (math.nan if bad else Fv)
```

- 자리: `order_by`가 없으면 쓰인 행의 누적 개수, 있으면 키의 안정 정렬에서의 순위예요. 적합 밖의 행은 키를 $+\infty$로 두어 맨 뒤로 보내요. 같은 키는 원래 순서를 지켜요(R `order`와 같아요).
- `split`이 비율이면 $n_1 = \lfloor m\cdot\text{split}\rfloor$($m$은 쓰인 행 수), `drop`도 비율이면 $\lfloor m\cdot\text{drop}\rfloor$이에요.
- WLS는 부분마다 원래 가중치를 그대로 두고 나머지 행만 0으로 해요.
- 자유도는 부분마다의 `df_resid`(행 수 − 랭크)예요. 한 부분이 완전 적합(SSR이 정확히 0)이거나 자유도가 없으면 NaN이에요.
- `alternative='greater'`(기본)는 $P(F \ge f)$, `'less'`는 $P(F \le f)$, `'two-sided'`는 그 둘 가운데 작은 것의 두 배예요.
- GLS는 백색화 $L^{-1}$이 행을 섞어서, 행을 나누는 이 검정이 뜻이 없어 `ValueError`예요.

```python
>>> q = X0r.goldfeld_quandt()
>>> q
GoldfeldQuandtResult(fvalue=0.854269, pvalue=0.600719, alternative='greater', df_num=11, df_denom=11)
>>> p1, p2 = sd.regression.ols(y[:15], X0[:15]), sd.regression.ols(y[15:], X0[15:])
>>> p2.scale / p1.scale
0.8542691087689481
>>> q2 = X0r.goldfeld_quandt(order_by=0, drop=4)
>>> o = sd.argsort(X0[:, 0], stable=True)
>>> p1 = sd.regression.ols(y[o][:15], X0[o][:15])
>>> p2 = sd.regression.ols(y[o][19:], X0[o][19:])
>>> q2.fvalue, p2.scale / p1.scale, q2.df_num, q2.df_denom
(1.2786304368708996, 1.2786304368708996, 7.0, 11.0)
```

### 비교 대상

R `lmtest::gqtest(point = 0.5, fraction = 0)`은 기본이 같은 나누기예요. `fraction = f`는 가운데 $f$만큼을 빼는 것이라, 여기서는 `split = floor((0.5 − f/2)n)`, `drop = ceiling((0.5 + f/2)n + 0.01) − 1 − split`이 같은 검정이에요. R은 자유도를 랭크가 아니라 열 수 $k$로 세서, 부분에서 겹친 열이 생길 때만 달라요. 모형의 가중치는 쓰지 않아요(`lm.fit`).

statsmodels의 `het_goldfeldquandt`는 F값은 같지만 한쪽 p값에서 자유도의 순서가 뒤바뀌어 있어요. `'increasing'`은 `stats.f.sf(fval, df1, df2)`로, 분자가 둘째 부분인데 분자 자유도에 첫째 부분의 것을 넣어요. 두 부분의 행 수가 같으면 자유도가 같아 드러나지 않지만, 다르면 p값이 틀려요(n = 61, `split=10`이면 F(47, 6)의 p를 F(6, 47)로 구해요).

## RESET

### 거듭제곱 열

Ramsey의 RESET은 적합값의 거듭제곱 $\hat y^2, \hat y^3, \dots$(`kind='fitted'`) 또는 절편이 아닌 열마다의 거듭제곱(`kind='regressor'`)을 모형에 더하고, 더한 계수가 모두 0인지 F로 검정해요. 선형 모형의 함수꼴이 틀렸으면(빠진 이차 항, 곱 항) 거듭제곱 열이 설명력을 얻어요.

거듭제곱을 그대로 만들면 열의 크기가 거듭제곱만큼 벌어져 확장 설계의 조건수가 나빠지고, 크기가 $10^{100}$인 열의 세제곱은 double을 넘어요. 그래서 열마다 가장 큰 절댓값 근처의 2의 거듭제곱으로 나눠 크기 1 근처로 옮긴 뒤 거듭제곱해요. 2의 거듭제곱으로 나누는 것은 정확하고, 열에 상수를 곱해도 그 열의 계수가 0이라는 가설은 같아서 검정의 값이 바뀌지 않아요.

```python
# src/stardust/regression/_diagnostics.py
def _unit_scale(v, axis):
    """v divided by a power of two near its largest magnitude along `axis` (exact): the powers
    of the scaled values stay near 1, and the test does not change with a column's scale."""
    mx = _sd.max(_sd.abs(v), axis=axis, keepdims=True)
    e = _sd.where(mx > 0.0, _sd.ceil(_sd.log2(_sd.where(mx > 0.0, mx, 1.0))), 0.0)
    return v * (2.0 ** (0.0 - e))
```

- 적합값은 적합의 단위에서 가져와요(`fittedvalues / fy`). GLS는 원래 단위의 $X\hat\beta$를 거듭제곱한 뒤 $L^{-1}$로 백색화해요(설계의 열을 백색화하는 것과 같은 방법).
- 가중치가 0인 행의 값은 크기를 정하기 전에 0으로 둬서, 적합 밖의 행이 크기를 정하지 않게 해요.
- 확장 모형은 같은 가중치, 같은 `cov_type`, 같은 군집과 지연 수로 적합해요.

### 통계량

고전형이면 두 SSR의 F예요.

$$
F = \frac{(\text{SSR}_0 - \text{SSR}_1)/m}{\text{SSR}_1/\text{df}_1}
$$

$m$은 확장 모형에 남은 더한 열의 수예요. 더한 열이 겹친 열로 빠지면(0/1 더미의 거듭제곱은 더미 자신이에요) 자유도를 더하지 않아요. 강건 공분산이면 확장 모형의 공분산으로 더한 계수의 Wald F를 구해요. 배치에서 회귀마다 쓰인 열이 달라도 한 번에 풀도록, 검정하지 않는 좌표는 공분산에 단위 행렬을, 효과에 0을 채워요.

### 비교 대상

R `lmtest::resettest(power = 2:3, type = "fitted")`는 $y$를 `scale()`로 중심화하고 표준편차로 나눈 뒤 `lm.fit`으로 적합값을 다시 구해 거듭제곱해요. 크기를 1 근처로 옮기는 것은 같은 목적이에요. 다만 `lm.fit`은 모형의 가중치를 쓰지 않아서 WLS의 값이 다르고, 분모 자유도를 $n - (k + q)$로 열 수로 세요. `vcov`를 주면 `waldtest`로 Wald F예요. `type = "regressor"`는 모형 틀의 요인이 아닌 열을 모두 거듭제곱하는데, 가중 lm이면 모형 틀의 `(weights)` 열까지 들어가요.

statsmodels의 `linear_reset(res, power=3)`은 기본이 χ²(`use_f=False`)이고, `use_f=True`면 여기의 F와 같아요. 거듭제곱을 옮기지 않고 그대로 만들고, 모형 클래스를 가중치 없이 다시 불러서 WLS의 가중치를 버려요. `test_type='exog'`는 0/1 열을 미리 빼요. 여기서는 그런 열의 거듭제곱이 겹친 열로 빠지므로 결과의 자유도가 같아요.

## 정확도

Arb(구간 산술)로 만든 참값과 견준 원소마다의 최대 상대오차예요(`bench/regression/accuracy.md`의 `model_tests`). 참값은 정의대로 만들어요. VIF는 보조 회귀, DFFITS·DFBETAS는 행을 하나씩 뺀 적합 $n$번, White는 보조 회귀, Goldfeld–Quandt는 두 부분의 적합, RESET은 확장 적합이에요.

| 문제 | VIF | DFFITS | DFBETAS | White LM | GQ F | RESET F |
|---|---:|---:|---:|---:|---:|---:|
| OLS | 5.7e-16 | 1.2e-15 | 8.9e-14 | 5.3e-17 | 1.6e-16 | 1.1e-15 |
| WLS(가중치 0인 행) | 4.2e-16 | 1.7e-15 | 6.4e-15 | 1.2e-17 | 1.1e-16 | 6.6e-16 |
| 절편 없음 | 1.7e-16 | 2.6e-15 | 8.4e-15 | 1.8e-16 | 5.8e-17 | 4.7e-15 |
| 세 수준 요인의 항 | 7.3e-16 | 1.4e-14 | 4.5e-14 | 1.3e-16 | 1.2e-16 | 1.1e-15 |
| κ ≈ 10⁸ | 1.4e-10 | 2.6e-9 | 2.3e-8 | | 6.9e-17 | 6.6e-12 |
| κ ≈ 10⁸, statsmodels | 4.4e-3 | 4.7e-9 | 1.3e-5 | | 7.7e-11 | 9.4e-9 |

| GLM | 지렛대 | Cook | DFFITS | DFBETAS |
|---|---:|---:|---:|---:|
| 이항 logit | 1.0e-15 | 8.6e-16 | 4.9e-16 | 5.6e-14 |
| 이항 probit | 6.6e-16 | 8.4e-16 | 4.6e-16 | 2.4e-14 |
| 포아송 log | 2.1e-15 | 1.2e-13 | 5.8e-14 | 5.8e-14 |
| 감마 log | 9.4e-16 | 1.7e-14 | 8.0e-15 | 8.2e-15 |

- 조건이 좋은 문제는 모두 1.2×10⁻¹³ 안이에요. DFBETAS와 포아송의 Cook 거리처럼 10⁻¹⁴–10⁻¹³ 자리인 값은 0에 가까운 칸의 상대오차이고, 노름 상대오차로 재면 모두 10⁻¹⁵ 안이에요.
- κ ≈ 10⁸에서 VIF, DFFITS, DFBETAS는 $\kappa u$ 꼴이에요. $R^{-1}$과 지렛대가 설계의 반올림을 $\kappa$배로 키우기 때문이에요([추론과 진단](/internals/regression/inference/)의 지렛대). DFBETAS를 노름으로 재면 4.6×10⁻¹⁰이에요.
- Goldfeld–Quandt와 RESET은 반복 개선한 적합의 SSR로 만든 비라서 같은 κ에서도 $\kappa u$보다 훨씬 작아요(Goldfeld–Quandt는 반올림 수준이에요).
- κ ≈ 10⁸ 문제의 White 검정은 보조 설계의 조건수가 κ² ≈ 10¹⁶이라 보조 회귀가 열 하나를 빼고 자유도가 정확한 값보다 하나 적어요. 그래서 그 칸은 비워 뒀어요.
