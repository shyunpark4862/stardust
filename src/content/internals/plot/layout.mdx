## 축의 범위

사용자가 두 끝을 주면 그대로 써요. 주지 않으면 층들이 알려 주는 자료의 범위(`extent`)를 모으고 양쪽으로 4%씩 넓혀요. 층은 범위와 함께 넓히지 말아야 할 값(sticky)도 알려 줘요. 막대의 바닥이 그래서, 막대 그림의 축은 0에서 시작해요.

## 눈금: 확장 Wilkinson

### 몇 개를 바랄까

눈금의 수는 축의 길이로 정해요. 가로축은 36 bp마다 하나, 세로축은 30 bp마다 하나쯤이고, 2개에서 10개 사이예요. 가로축의 간격이 넓은 것은 숫자가 옆으로 늘어서기 때문이에요.

```python
# src/stardust/plot/_figure.py
def _wanted(axis, length):
    """How many ticks an axis of `length` bp asks for: one per 36 bp along x (labels are wide),
    one per 30 bp along y."""
    return max(2, min(10, round(length / (36.0 if axis == "x" else 30.0)) + 1))
```

### 점수로 고르기

이 바라는 수 m을 받아 실제 눈금을 고르는 것은 Talbot, Lin, Hanrahan의 확장 Wilkinson 알고리즘(2010)이에요. Wilkinson(1999)은 "좋은 눈금"을 몇 가지 성질의 점수로 적고 후보 가운데 가장 높은 것을 골랐는데, 확장판은 그 성질을 넷으로 정리하고 가중합으로 묶었어요.

후보 눈금은 시작 값 $a$, 간격 $\text{step}$, 개수 $k$로 정해지고, 간격은 $\text{step} = j\,q\,10^z$ 꼴이에요. $q$는 "좋은 수"의 목록 $Q = (1, 5, 2, 2.5, 4, 3)$에서 고르고 앞의 것일수록 좋아요. $j$는 건너뛰기예요. $j = 2$, $q = 1$이면 간격이 2이지만 "1의 배수를 하나 걸러"로 읽히므로 $q = 2$보다 덜 단순하다고 봐요. 네 점수는 이래요.

- **단순함** $s = 1 - \frac{i}{|Q|-1} - j + v$. $i$는 $q$의 순번(0부터)이고, $v$는 눈금에 0이 들면 1이에요.
- **덮기** $c = 1 - \frac{1}{2}\cdot\frac{(d_\text{hi} - b)^2 + (d_\text{lo} - a)^2}{(0.1\,(d_\text{hi} - d_\text{lo}))^2}$. 자료의 범위 $[d_\text{lo}, d_\text{hi}]$와 눈금의 범위 $[a, b]$가 어긋난 만큼 깎여요. 어긋남이 범위의 10%면 0.5를 잃어요.
- **밀도** $d = 2 - \max(r/r_t,\ r_t/r)$. $r = (k-1)/(b-a)$는 단위 길이당 눈금 간격의 수이고, $r_t = (m-1)/(\max(b, d_\text{hi}) - \min(a, d_\text{lo}))$는 바라는 값이에요. 바라는 밀도와 같으면 1이고, 두 배나 절반이면 0이에요.
- **읽기 쉬움**은 원 논문에서 숫자의 꼴, 글자 크기, 방향, 겹침을 따지는 점수예요. 여기서는 1로 두고, 겹침은 눈금을 고른 뒤 따로 다뤄요(아래).

점수는 가중치 $(0.25, 0.2, 0.5, 0.05)$의 합이에요. 원 논문의 기본값 그대로이고, 밀도가 가장 무거워요.

```python
# src/stardust/plot/_ticks.py
_Q = (1.0, 5.0, 2.0, 2.5, 4.0, 3.0)
_W = (0.25, 0.2, 0.5, 0.05)


def _simplicity(i, start, j, step):
    eps = 1e-10
    rem = math.fmod(start, step)
    zero = 1.0 if (abs(rem) < eps * step or abs(step - abs(rem)) < eps * step) and start <= 0.0 else 0.0
    return 1.0 - i / (len(_Q) - 1.0) - j + zero


def _coverage(lo, hi, a, b):
    r = 0.1 * (hi - lo)
    return 1.0 - 0.5 * ((hi - b) ** 2 + (lo - a) ** 2) / (r * r)


def _density(k, m, lo, hi, a, b):
    r = (k - 1.0) / (b - a)
    rt = (m - 1.0) / (max(b, hi) - min(lo, a))
    return 2.0 - max(r / rt, rt / r)
```

`_simplicity`의 0 항은 첫 눈금이 간격의 배수이고 0 이하인지를 봐요. 첫 눈금은 언제나 간격의 정수배로 만들므로, 이 조건은 "눈금이 놓인 격자가 0을 지나고 첫 눈금이 0 쪽에 있다"는 뜻이에요. 범위가 모두 음수면 모든 후보가 같은 1을 받아 고르는 데 영향이 없어요.

### 찾는 범위

원 논문은 $j, q, k, z$를 차례로 키우며 남은 후보가 얻을 수 있는 점수의 상한으로 가지를 쳐요. 여기서는 찾는 범위를 처음부터 좁게 잡고 모두 세요.

```python
# src/stardust/plot/_ticks.py
@functools.lru_cache(maxsize=1024)
def _linear(lo, hi, m):
    best, best_score = None, -1e30
    span = hi - lo
    for j in (1, 2):
        for i, q in enumerate(_Q):
            for k in range(max(2, m // 2), min(12, 2 * m) + 1):
                # the largest step of this (j, q) with k ticks inside the range, and the next finer
                zmax = math.floor(math.log10(span / ((k - 1) * j * q)) + 1e-9)
                for z in (zmax, zmax - 1):
                    step = j * q * 10.0**z
                    s0 = math.ceil(lo / step - 1e-9)
                    s1 = math.floor(hi / step + 1e-9) - (k - 1)
                    for s in range(s0, min(s1, s0 + 20) + 1):
                        a, b = s * step, (s + k - 1) * step
                        score = (
                            _W[0] * _simplicity(i, a, j, step)
                            + _W[1] * _coverage(lo, hi, a, b)
                            + _W[2] * _density(k, m, lo, hi, a, b)
                            + _W[3]
                        )
                        if score > best_score + 1e-12:
                            best_score, best = score, (a, step, k)
    if best is None:  # a range too narrow for two ticks of any step: its ends
        return (lo, hi)
    a, step, k = best
    decimals = max(0, -int(math.floor(math.log10(step) + 1e-9)) + 2)
    return tuple(round(a + n * step, decimals) + 0.0 for n in range(k))
```

- **건너뛰기**는 1과 2만 봐요.
- **개수** $k$는 바라는 수의 절반부터 두 배까지(12개까지)예요.
- **간격의 자릿수** $z$는 $k$개가 범위 안에 들어가는 가장 큰 것과 그다음 작은 것, 둘이에요. 더 작은 간격은 같은 $k$로 범위의 일부만 덮어 덮기 점수가 떨어져요.
- **시작 값**은 범위 안에 들어가는 것만, 앞에서 20개까지 봐요. 원 논문은 눈금이 자료의 범위 밖으로 나가는 것도 허락하지만(축을 눈금까지 늘린다), 여기서는 범위를 이미 4% 넓혀 두었으므로 범위 안의 눈금만 골라요. 축 선은 눈금에서 끝나지 않고 범위 끝까지 가요.
- 고른 눈금은 간격의 자릿수보다 두 자리 아래에서 반올림해요. `0.1 * 3`이 `0.30000000000000004`로 남지 않게 하려는 것이에요. `+ 0.0`은 `-0.0`을 `0.0`으로 바꿔요.
- 같은 (범위, 개수)는 고리를 돌며 여러 번 물으므로 `lru_cache`가 기억해요.

### 라벨의 꼴

라벨은 수식 꼴의 숫자예요(`"$-1.5$"`, 빼기표가 하이픈이 아니라 수식의 빼기). 한 축의 라벨은 모두 같은 소수 자릿수를 가져요. 모든 값을 정확히 쓰는 가장 작은 자릿수를 찾아요. 값이 아주 크거나 작으면(가장 큰 절댓값의 지수가 5 이상이거나 −4 이하) 라벨은 가수만 쓰고, 공통 10의 거듭제곱 `$\times10^{e}$`를 축 끝에 한 번 적어요. 세로축은 위 끝 위에, 가로축은 오른쪽 끝 옆에 놓아요.

```python
# src/stardust/plot/_ticks.py
def labels(values):
    """(labels, multiplier): the tick values as math-mode numbers with common decimals. When the
    values are very large or small, the labels are mantissas and multiplier is the shared
    "$\\times10^{e}$" (else None)."""
    big = max((abs(v) for v in values), default=0.0)
    e = 0
    if big != 0.0:
        ex = math.floor(math.log10(big) + 1e-12)
        if ex >= 5 or ex <= -4:
            e = ex
    scale = 10.0**e
    d = _decimals(values, scale)
    out = []
    for v in values:
        s = f"{v / scale:.{d}f}"
        if float(s) == 0.0:
            s = s.lstrip("-")
        out.append(f"${s}$")
    return out, (rf"$\times10^{{{e}}}$" if e else None)
```

로그 축은 10의 거듭제곱에 눈금을 두고 `$10^{k}$`로 적어요. 거듭제곱이 바라는 수보다 많으면 n개마다 하나만 남기고, 모두 남길 때는 사이에 2–9배의 작은 눈금을 둬요. 범위 안에 거듭제곱이 둘도 없으면 선형 눈금을 써요. `xticks('pi')`는 간격 π/16부터 16π까지의 아홉 가운데 눈금 수가 바라는 수에 가장 가까운 것을 골라 `$\frac{3\pi}{2}$` 꼴로 적어요.

## 여백 풀기

### 칸 하나의 여백

`_measure`는 그림 사각형의 크기 `pw × ph`를 받아 축을 고르고 네 여백을 돌려줘요.

- 왼쪽: 눈금 길이 + 눈금과 숫자 사이 + 가장 넓은 세로 눈금 숫자, 축 이름이 있으면 거기에 간격과 이름 상자의 높이(돌려 세우므로 높이가 너비가 돼요).
- 아래: 눈금 길이 + 간격 + 가로 눈금 숫자의 높이와 깊이, 축 이름이 있으면 그 상자.
- 첫 가로 라벨과 끝 가로 라벨은 가운데를 눈금에 맞추므로 축 끝 밖으로 반쯤 삐져나가요. 그 삐짐이 왼쪽·오른쪽 여백의 하한이에요. 세로 라벨의 위아래 삐짐도 같아요.
- 공통 10의 거듭제곱, 제목, 색 막대(밀도 그림), 칸 밖의 범례가 위·오른쪽·아래에 더해져요.

### 고리와 줄 맞춤

```python
    # src/stardust/plot/_figure.py
    def solve(pw, ph):
        """Margins of every column and row for plot sizes pw[c], ph[r]."""
        ms = [_measure(fig, fig._cells[r * nc + c], pw[c], ph[r], th, engine) for r in range(nr) for c in range(nc)]
        left = [max(ms[r * nc + c].left for r in range(nr)) for c in range(nc)]
        right = [max(ms[r * nc + c].right for r in range(nr)) for c in range(nc)]
        top = [max(ms[r * nc + c].top for c in range(nc)) + panel_h for r in range(nr)]
        bottom = [max(ms[r * nc + c].bottom for c in range(nc)) for r in range(nr)]
        return ms, left, right, top, bottom
```

여러 칸의 그림은 열마다 왼쪽·오른쪽 여백을 그 열의 가장 큰 값으로, 줄마다 위·아래 여백을 그 줄의 가장 큰 값으로 맞춰요. 그래서 같은 열의 칸은 왼쪽 축 선이 한 세로줄에 서고, 같은 줄의 칸은 아래 축 선이 한 가로줄에 서요. 칸 이름(A, B)이 있으면 그 높이를 모든 줄의 위 여백에 더해요.

칸의 너비는 그림의 너비에서 바깥 여백과 칸 사이 간격을 빼고 열의 수로 나눈 값이고, 그림 사각형의 너비는 거기서 열의 여백을 뺀 것이에요. 높이를 주지 않으면 그림 사각형의 높이는 첫 열의 너비의 0.75배(4:3)예요. 3D 칸만 있는 줄은 상자 투영의 비율을 따르되 1.25배를 넘지 않아요.

```python
    # src/stardust/plot/_figure.py
    pw = [max(cell_w - 40.0, 10.0)] * nc
    ph = shapes(pw) if H is None else [max((H - 2 * margin - gap * (nr - 1)) / nr - 30.0, 10.0)] * nr
    for _ in range(3):  # the ticks depend on the plot size, the margins on the ticks
        ms, left, right, top, bottom = solve(pw, ph)
        pw = [max(cell_w - left[c] - right[c], 10.0) for c in range(nc)]
```

첫 어림은 너비에서 40 bp, 높이에서 30 bp를 여백으로 떼어 둔 것이에요. 세 번을 돌면 눈금의 수와 여백이 서로를 따라 자리를 잡고, 마지막 `solve`가 그 크기에서 그릴 축과 여백을 정해요. 그림 사각형은 10 bp보다 작아지지 않아요. 고리가 셋으로 정해져 있어 배치 한 번의 일이 그림에 상관없이 한정돼요.

## 범례의 자리

`loc='best'`(기본)인 범례는 그림 사각형의 네 구석 가운데 그려진 것을 가리지 않는 곳에 들어가요. 무엇이 어디에 그려졌는지는 층들을 실제로 칠해 봐서 알아요.

```python
# src/stardust/plot/_figure.py
def _place_legend(cell, m, w, h, th, palette, engine):
    """A corner of the plot the layers leave empty for the legend, else 'top' or 'right'."""
    trial = _scene.Scene(w, h)
    fr = Frame(trial, 0.0, 0.0, w, h, m.xa, m.ya, th, palette, engine)
    for layer in cell.layers:
        layer.draw(fr)
    ink = Ink(trial.items, 0.0, 0.0, w, h)
    lw, lh = m.legend["w"], m.legend["h"]
    best = None
    for name in _CORNERS:
        bx, by = _corner(name, 0.0, 0.0, w, h, lw, lh)
        share = ink.share(bx - 3.0, by - 3.0, lw + 6.0, lh + 6.0)
        if best is None or share < best[0]:
            best = (share, name)
    if best[0] <= 0.004:
        return best[1]
    # no room inside: above the plot when one row holds it, else at the right
    one_row = sum(_HANDLE_W + 3.0 + b[0] for b in m.legend["boxes"]) + 8.0 * (len(m.legend["boxes"]) - 1)
    return "top" if one_row <= w else "right"
```

1. 층들을 그림 사각형 크기의 빈 장면에 그려요. 실제 그림과 같은 축과 같은 `draw`예요.
2. `Ink`가 그 장면을 2 bp 칸의 성긴 격자(bp당 0.5화소)에 검게 칠해요. 칠하는 것은 C++ 래스터라이저라서 채움, 획, 점 기호, 그림이 모두 그려지는 모양 그대로 잉크가 돼요. 획은 적어도 한 칸 굵기로 칠해 가는 선도 놓치지 않아요.
3. 구석 넷(오른쪽 위, 왼쪽 위, 오른쪽 아래, 왼쪽 아래 차례)에 범례 상자를 4 bp 안쪽으로 놓고, 둘레 3 bp를 더한 사각형에서 잉크가 묻은 칸의 몫을 세요.
4. 가장 깨끗한 구석의 몫이 0.4% 이하면 그 구석이에요. 아니면 칸 밖에 두는데, 범례가 한 줄에 들어가면 위, 아니면 오른쪽이에요.

범례가 칸 밖으로 나가면 그 칸의 여백이 늘고, 같은 열이나 줄의 다른 칸의 크기도 바뀌어요. 그래서 범례 하나가 밖으로 나갈 때마다 여백을 두 번 더 풀고, 바뀐 크기에서 다른 칸의 구석을 다시 봐요. 밖으로 나간 범례는 다시 들어오지 않으므로(위나 오른쪽에 둔 칸은 건너뛰어요) 이 고리는 많아야 세 번이에요.

같은 잉크 지도는 회귀선의 식처럼 칸 안에 놓을 글 한 줄(`fit`의 식과 $R^2$)의 자리도 골라요. 범례가 차지한 구석을 빼고 잉크가 가장 적은 구석이에요.

## 같은 비율의 칸

평면 곡선(`parametric`, `polar`), 음함수, 영역, 위상 그림의 칸은 자료의 한 단위가 가로와 세로에서 같은 길이여야 원이 원으로 보여요. 이런 칸은 `aspect`가 1이에요.

```python
    # src/stardust/plot/_figure.py
    if cell.aspect is not None and m.xa.scale == "linear" and m.ya.scale == "linear":
        # equal data units: the plot rectangle is the largest of the data's shape that fits
        k = min(pw / (m.xa.hi - m.xa.lo), ph / (m.ya.hi - m.ya.lo))
        fw, fh = (m.xa.hi - m.xa.lo) * k, (m.ya.hi - m.ya.lo) * k
        m.fit = (fw, fh)
        if fw < pw - 1e-9 or fh < ph - 1e-9:  # the ticks for the sides as they are drawn
            cx, cy = _axis(cell, "x", fw, th), _axis(cell, "y", fh, th)
            m.xa, m.ya = cx, cy
        pw, ph = fw, fh
```

범위를 넓혀 사각형을 채우지 않고, 사각형을 자료의 모양으로 줄여요. 줄어든 사각형의 변 길이로 눈금을 다시 고르고, 칸이 가진 자리의 가운데에 놓아요.
