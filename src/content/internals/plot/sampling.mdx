## 한눈에 보기

[`function`](/api/plot/function/), [`parametric`](/api/plot/parametric/), [`polar`](/api/plot/polar/)은 곡선 하나를 매개변수 t의 함수 $t \mapsto (x(t), y(t))$로 보고 같은 표본기를 써요. `function`은 $x(t) = t$, `polar`는 $(r(t)\cos t,\ r(t)\sin t)$예요. 표본기는 `src/stardust/plot/_sample.py` 한 파일이고, 그림 함수 쪽은 `_function.py`예요. C++는 쓰지 않아요. 모든 계산이 `sd` 배열 연산이고, 사용자 함수는 표본을 묶은 배열로 몇 번만 불러요.

표본기의 상수는 파일 머리에 모여 있어요.

```python
# src/stardust/plot/_sample.py
W0, H0 = 1000.0, 750.0
N0 = 256  # intervals of the first grid
DEPTH = 10  # halvings of a first-grid interval at most
CAP = 40000  # samples at most
BEND = math.tan(math.radians(4.0))  # a turn sharper than this asks for a midpoint
MIN_LEN = 1.5  # ... when the interval is longer than this on the screen
JUMP = 0.02 * H0  # a narrowest interval rising more than this is a break
PHI = 0.6180339887498949
```

거리와 각은 자료 좌표가 아니라 **기준 화면**에서 재요. 기준 화면은 가로 1000, 세로 750 단위(4:3)의 직사각형이고, 보이는 x 범위와 y 범위를 그 직사각형에 늘여 맞춰요. 그래서 같은 함수라도 y 범위가 좁으면 더 잘 꺾여 보이고 표본이 늘어요. 실제 그림의 크기(mm)는 표본에 들어가지 않아서, 같은 호출은 그림의 크기와 상관없이 같은 표본을 써요.

## 인자 읽기: `samples`와 `refine`

`knobs`는 함수를 받는 모든 그림이 함께 쓰는 검사예요. `samples`는 첫 격자의 점의 수(곡선은 3에서 200000까지, 기본 257 = `N0 + 1`), `refine`은 첫 격자의 한 구간을 반으로 나누는 횟수의 한계(0에서 `DEPTH` = 10까지, 기본 10)예요. 두 변수 그림에서는 `samples`가 쌍일 수 있고 `refine`의 한계가 1이에요([두 변수 함수의 표본](/internals/plot/fields/)).

```python
>>> import math
>>> f = lambda x: sd.sin(5 * x)
>>> [sd.plot.function(f, 0, 3, samples=n, refine=r).info[0].n for n, r in ((257, 0), (33, 0), (33, 10))]
[257, 33, 280]
```

`refine=0`이면 첫 격자가 곧 곡선이에요. 극점과 뜀을 가리는 일도 하지 않아요. 가장 좁은 구간까지 좁혀 본 적이 없으니 가파른 선분이 뜀인지 알 수 없기 때문이에요.

## 첫 격자: 황금비로 조금 흩기

첫 격자는 고른 격자에서 안쪽 점만 한 칸의 ±0.15만큼 옮긴 것이에요.

```python
# src/stardust/plot/_sample.py
def first_grid(a, b, n=N0):
    """n + 1 points of [a, b]: uniform, the inner ones shifted by up to 0.15 of a step by a fixed
    low-discrepancy sequence."""
    i = sd.arange(0.0, n + 1.0)
    shift = (i * PHI - sd.floor(i * PHI) - 0.5) * 0.3
    shift = sd.where((i > 0.0) & (i < float(n)), shift, 0.0)
    t = a + (b - a) * (i + shift) / n
    return sd.where(i == float(n), b, sd.where(i == 0.0, a, t))  # the ends exactly
```

$i$번째 점의 어긋남은 $(\{i\varphi\} - \tfrac12)\cdot 0.3$칸이에요. $\{\cdot\}$은 소수 부분, $\varphi = (\sqrt5 - 1)/2$이에요. 수열 $\{i\varphi\}$는 Weyl의 덧셈 수열(Kronecker 수열)이에요. 무리수 α에 대해 $\{i\alpha\}$는 [0, 1)에 고르게 퍼지고(Weyl의 고른 분포 정리), 세 거리 정리(Steinhaus 추측, Sós 1958)에 따르면 처음 N개의 점이 [0, 1)을 나누는 간격은 많아야 세 가지 길이예요. 황금비는 연분수 전개가 $[0; 1, 1, 1, \ldots]$로 모든 부분 몫이 가장 작은 수라, 어떤 N에서도 가장 긴 간격과 가장 짧은 간격의 비가 작게 머물러요. 그래서 이웃한 점의 어긋남이 규칙적으로 되풀이되지 않고 고르게 섞여요. 이 어긋남은 고정된 수열이라 결정적이에요. 같은 a, b, n이면 언제나 같은 격자예요.

흩는 까닭은 주기 함수와 격자가 발을 맞추는 일을 피하려는 것이에요. 주기가 격자 간격과 같은 함수를 고른 격자로 재면 모든 점에서 같은 값이 나와 곡선이 평평한 선이 돼요.

```python
>>> t = sd.linspace(0.0, 1.0, 257)
>>> float(sd.max(sd.abs(sd.sin(2 * math.pi * 256 * t)))) < 1e-12
True
>>> fig = sd.plot.function(lambda x: sd.sin(2 * math.pi * 256 * x), 0, 1, refine=0)
>>> [round(v, 2) for v in fig.info[0].ylim]
[-0.81, 0.81]
```

고른 격자 257점은 $\sin(2\pi\cdot256x)$를 0으로만 보지만, 흩은 격자는 같은 257점으로 진폭이 있다는 것을 알아봐요. 이 경우는 곡선의 모양을 제대로 그리지는 못하지만(진동이 격자보다 빠르니까요), 적어도 평평한 선이라는 틀린 그림은 피하고, 이어지는 나누기가 그 구간을 잘게 나눌 실마리가 돼요. 끝점 a와 b는 언제나 정확히 그 값이에요.

## 자동 범위: 분위수 규칙

`function`은 `ylim`을 주지 않으면 첫 격자의 값으로 y 범위를 골라요. 그 범위가 기준 화면의 세로가 되므로, 범위를 고른 뒤에 나누기를 시작해요.

```python
    # src/stardust/plot/_sample.py, robust_range
    q10, q50, q90 = (float(q) for q in sd.quantile(w, sd.asarray([0.1, 0.5, 0.9])))
    spread = q90 - q10
    if spread <= 0.0:
        spread = max(abs(q50), 1.0) * 1e-9
    clip_hi = hi - q90 > 4.0 * spread
    clip_lo = q10 - lo > 4.0 * spread
    return (q10 - spread if clip_lo else lo), (q90 + spread if clip_hi else hi), clip_lo, clip_hi
```

유한한 값 w의 10%, 50%, 90% 분위수(`sd.quantile`의 기본 `'linear'`)를 구하고, 가운데 80%의 폭을 퍼짐 $s = q_{90} - q_{10}$으로 둬요. 최댓값이 $q_{90}$보다 $4s$ 넘게 멀면 위쪽은 극점 둘레에서 달아난 몇 점이라고 보고 범위를 $q_{90} + s$에서 잘라요. 아래쪽도 같아요. 그렇지 않은 쪽은 최솟값과 최댓값 그대로예요. 이 규칙은 두 경우를 가려요.

- $\tan x$처럼 극점 근처의 몇 점만 크면 그 점들이 분위수를 움직이지 못해서 잘려요.
- $e^x$이나 $x^3$처럼 값이 꾸준히 크게 자라면 큰 값이 10%를 넘게 차지해서 $q_{90}$도 함께 커지고, 잘리지 않아요.

```python
>>> info = sd.plot.function(sd.exp, 0, 10).info[0]
>>> info.clipped, info.ylim[1] == math.exp(10)
((False, False), True)
>>> info = sd.plot.function(sd.tan, -3, 3).info[0]
>>> info.clipped, [round(v, 2) for v in info.ylim]
((True, True), [-9.52, 9.53])
```

함수를 여럿 주면 함수마다 범위를 구해 가장 넓게 합쳐요. 그 범위가 정해지면 나누기가 찾는 값을 위해 테두리를 하나 더 둬요.

```python
        # src/stardust/plot/_function.py, function
        yr = (lo, hi)
        # A side the first grid's values ran away on is cut there. The other sides may grow by
        # what the finer samples find (a peak between grid points), but not without bound: a pole
        # the grid stepped over must not take the axis.
        grow = 0.5 * (hi - lo)
        yclip = (lo if clipped[0] else lo - grow, hi if clipped[1] else hi + grow)
```

잘린 쪽은 그 자리가 끝이고, 잘리지 않은 쪽은 범위 폭의 절반까지 늘어날 수 있어요. 첫 격자 사이에 숨은 봉우리는 나누기가 찾아내면 축이 그만큼 넓어지지만, 첫 격자가 건너뛴 극점이 축 전체를 가져가지는 못해요. 곡선 층(`CurveLine`)은 자기 y 범위를 이 `yclip` 안으로 줄여서 배치에 알려요. 선 자체는 범위 밖으로도 이어지고 칸의 테두리에서 잘려 보여요.

## 나누기: 화면에서 꺾이는 각

`refine`의 고리는 한 바퀴마다 모든 구간을 한꺼번에 보고, 더 볼 구간의 가운데 점을 모아 함수를 한 번 불러요.

```python
        # src/stardust/plot/_sample.py, refine
        u, v = _screen(x, y, xr, yr)
        fin = sd.isfinite(u) & sd.isfinite(v)
        du, dv = u[1:] - u[:-1], v[1:] - v[:-1]
        dt = t[1:] - t[:-1]
        both = fin[1:] & fin[:-1]
        # a bend at an inner vertex: the turn between its two segments
        cross = du[:-1] * dv[1:] - dv[:-1] * du[1:]
        dot = du[:-1] * du[1:] + dv[:-1] * dv[1:]
        bend = (sd.abs(cross) > BEND * dot) & both[:-1] & both[1:]
        false1 = sd.zeros(1, dtype=sd.bool)
        at = sd.concat([false1, bend]) | sd.concat([bend, false1])  # either end of the interval bends
        long_ = (du * du + dv * dv) > MIN_LEN * MIN_LEN
        # out of sight: both ends far above or far below the view
        hidden = ((v[1:] > 2.0 * H0) & (v[:-1] > 2.0 * H0)) | ((v[1:] < -H0) & (v[:-1] < -H0))
        want = at & long_ & both & ~hidden
        want = want | (fin[1:] ^ fin[:-1])  # the edge of the domain
        want = want & (dt > hmin)
        if not bool(sd.any(want)):
            break
        tm = (t[:-1] + t[1:])[want] * 0.5
        if n + tm.shape[0] > cap:
            tm = tm[: cap - n]
        xm, ym = g(tm)
        t = sd.concat([t, tm])
        order = sd.argsort(t, stable=True)
        t, x, y = sd.take(t, order), sd.take(sd.concat([x, xm]), order), sd.take(sd.concat([y, ym]), order)
```

안쪽 꼭짓점마다 앞 선분 $d_1 = (\Delta u_1, \Delta v_1)$과 뒤 선분 $d_2$가 이루는 꺾임각 θ를 재요. $d_1 \times d_2 = \lvert d_1\rvert\lvert d_2\rvert\sin\theta$, $d_1\cdot d_2 = \lvert d_1\rvert\lvert d_2\rvert\cos\theta$이므로 $\lvert d_1\times d_2\rvert > \tan 4°\,(d_1\cdot d_2)$는 θ > 4°와 같아요. 각을 `atan2`로 구하지 않고 외적과 내적의 비교 하나로 끝내요. 선분이 90°보다 크게 꺾이면 내적이 음수라 언제나 참이에요. 한 구간은 아래가 모두 맞을 때 가운데 점을 받아요.

- 양 끝 가운데 한 곳이라도 4°보다 크게 꺾여요(`at`).
- 화면에서 1.5 단위보다 길어요(`long_`). 이미 짧은 선분은 꺾여 있어도 더 나눠 봐야 보이는 것이 없어요.
- 양 끝 값이 유한해요.
- 양 끝이 함께 보이는 범위에서 한 화면 높이 넘게 위나 아래에 있지 않아요(`hidden`). 극점의 양옆에서 범위 밖으로 달아난 곡선은 나눠도 보이지 않으니 표본을 쓰지 않아요.

한쪽 끝만 유한한 구간은 꺾임과 상관없이 나눠요(`fin[1:] ^ fin[:-1]`). 이것이 정의역 끝의 **이분**이에요. $\sqrt x$의 0처럼 정의역이 끝나는 자리를 끼고 있는 구간은 바퀴마다 반으로 줄어, 마지막에는 길이 hmin 안에서 정의역 끝을 가둬요. 선이 정의역 끝까지 닿는 까닭이에요.

나누기에는 두 한계가 있어요. 구간의 길이가 $h_{\min} = (b - a)/n_0/2^{\text{depth}}$ 이하면 더 나누지 않고, 표본이 `CAP` = 40000개(또는 첫 격자의 두 배 가운데 큰 쪽)에 닿으면 멈춰요. 첫 격자의 간격은 흩음 때문에 고른 간격의 0.7배에서 1.3배까지라, 가장 긴 구간이 hmin 아래로 내려오려면 depth + 1번 나눠야 해요. 그래서 고리는 depth + 2바퀴까지 돌아요. 새 점은 구간의 가운데라 결정적이고, 한 바퀴의 새 점을 모두 모아 `g(tm)`을 한 번 부르니 함수 호출은 많아야 depth + 3번이에요(첫 격자 한 번과 바퀴마다 한 번).

```python
>>> sizes = []
>>> def g(x):
...     sizes.append(x.shape[0])
...     return sd.tan(x)
>>> fig = sd.plot.function(g, -3, 3)
>>> sizes
[257, 4, 2, 2, 2, 2, 2, 2, 2, 2, 2, 1]
```

첫 격자 257점 뒤의 바퀴들은 두 극점 둘레의 구간만 반씩 줄여 가요. 나머지 곡선은 첫 격자로 이미 4°보다 덜 꺾여요. 아래 그림은 첫 격자를 17점으로 줄이고 같은 고리를 돌린 것이에요. 네모가 첫 격자, 작은 점이 나누기가 더한 표본이에요. 표본은 봉우리와 골짜기처럼 화면에서 꺾이는 곳에 모이고 곧은 비탈에는 거의 없어요.

## 끊는 자리: 극점과 뜀

나누기가 끝나면 가장 좁은 구간($\Delta t \le 2h_{\min}$) 가운데 아직 화면에서 크게 뛰는 것을 끊는 자리로 읽어요.

```python
    # src/stardust/plot/_sample.py, refine
    narrow = dt <= 2.0 * hmin
    # a narrowest interval that still jumps on the screen
    # (without refinement nothing was narrowed down: a steep segment is not known to be a break)
    brk = both & narrow & ((dv > JUMP) | (du > JUMP)) & (depth > 0)
    idx = [int(i) for i in sd.nonzero(brk)[0].tolist()]
    c.breaks, c.poles, c.jumps = idx, [], []
    last_t, last_kind = None, None
    for i in idx:
        v0, v1 = float(v[i]), float(v[i + 1])
        far = (v0 > 3.0 * H0 or v0 < -2.0 * H0) and (v1 > 3.0 * H0 or v1 < -2.0 * H0)
        at = 0.5 * (float(t[i]) + float(t[i + 1]))
        kind = c.poles if far else c.jumps
        # neighbouring narrow intervals around one pole or jump are one finding
        if last_t is not None and at - last_t <= 64.0 * hmin:
            if far and last_kind is c.jumps:
                c.poles.append(c.jumps.pop())
                last_kind = c.poles
        else:
            kind.append(at)
            last_kind = kind
        last_t = at
```

연속 함수는 구간을 반으로 줄일 때마다 양 끝의 차이도 줄어요. 끊긴 함수는 그렇지 않아요. 뜀이 든 구간은 양 끝에서 크게 꺾이므로 바퀴마다 나눠지고, hmin까지 좁아져도 차이가 그대로 남아요. 그래서 가장 좁은 구간에서 세로나 가로로 `JUMP` = 15 단위(화면 높이의 2%)보다 크게 뛰면 끊어요. $\tanh(50x)$처럼 가파르지만 이어진 함수는 좁혀 가는 사이에 차이가 줄어서 끊기지 않아요.

끊는 자리는 둘로 나눠요. 양 끝이 모두 보이는 범위에서 두 화면 높이 넘게 벗어나 있으면(기준 화면 좌표로 $v > 3H_0$ 또는 $v < -2H_0$) **극점**, 아니면 **뜀**이에요. 극점 하나 둘레에는 좁은 구간이 여럿 이어질 수 있어서, 앞의 자리와 64 hmin 안에 있는 것은 같은 것으로 묶어요. 묶음 안에서 한 번이라도 극점으로 보였으면 극점이에요. 자리는 구간의 가운데라 정밀도는 hmin, 곧 범위의 $1/(256\cdot 2^{10})$(약 $4\times10^{-6}$)이에요.

```python
>>> fig = sd.plot.function(sd.floor, -2.5, 2.5)
>>> [round(j, 4) for j in fig.info[0].jumps]
[-2.0, -1.0, -0.0, 1.0, 2.0]
>>> fig = sd.plot.function(sd.tan, -3, 3, asymptotes=True)
>>> [round(p, 4) for p in fig.info[0].poles]
[-1.5708, 1.5708]
```

선은 `cut`이 끊어요. 끊는 구간 사이에 NaN 점을 하나 넣으면 선 층은 거기서 획을 멈춰요(세로선을 긋지 않아요). 이웃한 끊는 구간들(극점 하나 둘레의 좁은 구간 여럿)은 한 번의 끊음으로 묶고, 그 사이의 표본은 어느 쪽 선에도 넣지 않아요.

### 정의되지 않는 구간

표본 가운데 유한하지 않은 것이 이어지는 구간마다, 그 앞의 마지막 유한한 표본에서 뒤의 첫 유한한 표본까지를 `undefined`에 적어요. 정의역 끝의 이분 덕분에 그 끝은 hmin 안의 자리예요.

```python
>>> info = sd.plot.function(sd.sqrt, -1, 4).info[0]
>>> [(round(a, 4), round(b, 4)) for a, b in info.undefined]
[(-1.0, 0.0)]
```

## 너무 빠른 진동: 띠

$\sin(1/x)$는 0 근처에서 어떤 표본으로도 따라갈 수 없을 만큼 빠르게 오르내려요. 나누기는 표본 상한까지 점을 더하고, 그 점을 그대로 이은 선은 칸 안을 뭉개진 얼룩으로 채워요. `_add_curve`는 표본이 4000개를 넘은 곡선에서 그런 곳을 찾아 선 대신 최솟값과 최댓값 사이의 띠로 그려요.

`oscillation`은 보이는 x 범위를 2000개의 열로 나눠요. 열마다 곡선이 오르다 내리거나 내리다 오르는 횟수(이웃한 두 차분의 부호가 바뀌는 횟수)를 세고, 그 열의 최솟값과 최댓값을 모아요. 세 번 넘게 뒤집히고 높이가 기준 화면에서 2 단위를 넘는 열이 바쁜 열이에요. 바쁜 열이 두 열 이하의 틈으로 이어지면 한 무리로 묶고, 세 열 이상인 무리만 띠가 돼요. 한두 열짜리는 선 자체가 보여 줄 수 있어요. 띠는 열 가운데마다 (최솟값, 최댓값)인 `Area` 층이고, 띠 안의 표본은 선에서 NaN으로 빼요. 띠가 된 구간은 `oscillating`에 적고, 그 안에서 찾은 뜀은 `jumps`에서 빼요.

```python
>>> fig = sd.plot.function(lambda x: sd.sin(1 / x), -0.5, 0.5)
>>> info = fig.info[0]
>>> info.n > 4000, [(round(a, 4), round(b, 4)) for a, b in info.oscillating]
(True, [(-0.0082, 0.0082)])
```

<PlotImage name="in-sampling-band" alt="−0.5에서 0.5까지의 sin(1/x). 0에 다가갈수록 오르내림이 빽빽해지고, 0 둘레의 아주 좁은 구간은 −1에서 1까지 채운 띠예요." caption="0 둘레 약 ±0.008의 바쁜 열들이 −1에서 1까지의 띠가 되고, 그 바깥은 표본을 이은 선이에요. 띠 둘레의 선도 빽빽해서 둘은 한 덩어리로 보여요." />

`parametric`과 `polar`는 띠를 찾지 않아요. 열 세기는 x 열마다 곡선의 오르내림을 세는 방법이라 `function`에만 붙어 있어요.

## 평면 곡선의 화면

`parametric`과 `polar`는 가로세로 같은 단위로 그리므로(칸의 `aspect` = 1), 기준 화면도 두 축을 같은 비율로 늘여요. 첫 격자 값의 x 범위와 y 범위를 구하고, 둘 가운데 기준 화면에서 더 넓게 차지하는 쪽에 맞춰 한 척도를 써요. 자동 범위의 분위수 규칙은 쓰지 않고, 첫 격자의 유한한 값 전체의 범위를 써요.

## `PlotInfo` 채우기

곡선마다 기록 하나를 그림의 `_infos`에 더하고, `Figure.info`가 그것을 튜플로 보여요.

```python
        # src/stardust/plot/_function.py, function
        e = self._cell.layers[-1].extent("y", False)
        cut = (clipped[0] or (e is not None and e[0] <= yclip[0]), clipped[1] or (e is not None and e[1] >= yclip[1]))
        jumps = tuple(j for j in c.jumps if not any(x0 <= j <= x1 for x0, x1 in osc))
        self._root._infos.append(
            PlotInfo(
                who,
                int(c.t.shape[0]),
                tuple(c.poles),
                jumps,
                None if e is None else (e[0], e[1]),
                cut,
                tuple(c.undefined),
                tuple(osc),
            )
        )
```

| 필드 | 채우는 곳 |
|---|---|
| `kind` | 그림 함수의 이름(`'function'`, `'parametric'`, `'polar'`) |
| `n` | 나누기가 끝난 뒤의 표본 수 |
| `poles`, `jumps` | 끊는 자리의 분류. 띠 안의 뜀은 빼요 |
| `ylim` | 곡선 층이 배치에 알리는 y 범위(`yclip` 안으로 줄인 값) |
| `clipped` | 분위수 규칙이 잘랐거나, 나누기가 찾은 값이 `yclip`의 끝에 닿았는지 |
| `undefined` | 유한하지 않은 값이 이어진 구간 |
| `oscillating` | 띠로 그린 구간 |

`ylim=`을 직접 주면 분위수 규칙을 쓰지 않고, 그 범위가 기준 화면이자 `yclip`이 돼요. `clipped`는 `(False, False)`에서 시작하고 곡선이 그 끝에 닿으면 참이 돼요. `parametric`과 `polar`의 기록은 `ylim`이 `None`, `clipped`가 `(False, False)`, `oscillating`이 비어 있어요.
