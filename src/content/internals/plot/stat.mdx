## 한눈에 보기

통계 그림과 결과 객체의 그림은 모두 `src/stardust/plot/_stat.py`에 있어요. 이 파일은 통계량을 스스로 정의하지 않아요. 그림이 보이는 수는 계산 영역이 낸 수이고, 그림은 그 수를 층으로 옮기기만 해요. 그래서 그림을 보고 읽은 값과 같은 자료로 계산 함수를 부른 값이 언제나 같아요.

| 그림 | 수를 내는 곳 | 그림이 하는 일 |
|---|---|---|
| [`histogram`](/api/plot/histogram/) | [`sd.histogram`](/api/array/histogram/)(`bins`, `range`, `density` 그대로) | 막대를 칸 경계에 세우기, 무리가 여럿이면 같은 칸 |
| [`ecdf`](/api/plot/ecdf/) | `sd.sort`와 비율 $i/n$ | 계단 선 |
| [`boxplot`](/api/plot/boxplot/) | [`sd.quantile`](/api/array/quantile/)(`'linear'`)의 사분위 | 수염(1.5 IQR 안의 가장 먼 값)과 그 밖의 점 |
| [`qq`](/api/plot/qq/) | 분포의 `icdf`, `sd.quantile` | 점과 사분위를 지나는 선 |
| [`distribution`](/api/plot/distribution/) | 분포의 `pdf`·`cdf`·`ccdf`·`pmf`·`icdf`·`support` | 연속은 함수 그림, 이산은 막대나 계단 |
| [`fit`](/api/plot/fit/) | 회귀 결과의 `predict`, `predict_interval` | 선과 띠, 식 |
| [`coefficients`](/api/plot/coefficients/) | 회귀 결과의 `params`, `conf_int` | 점과 가로 막대 |
| [`diagnostics`](/api/plot/diagnostics/) | `fittedvalues`, `resid`, `resid_studentized_internal`, `leverage` | 2 × 2 칸 |
| [`compare`](/api/plot/compare/) | 검정 결과의 `pvalue` | 괄호와 p값 |

받는 결과는 형이 아니라 가진 속성으로 가려요. `compare`는 `pvalue`가 있으면 되고, `fit`은 `params`와 `predict`가 있으면 돼요. 그래서 `sd.htest`와 `sd.regression`의 어느 결과든, 같은 속성을 가진 다른 객체든 받아요.

```python
>>> from stardust.plot import _stat
>>> rng = sd.random.default_rng(7)
>>> N = sd.stats.Normal(mu=0.0, sigma=1.0)
>>> a = 5.0 + N.sample(25, rng=rng)
>>> b = 6.0 + 1.2 * N.sample(25, rng=rng)
>>> c = 7.5 + N.sample(25, rng=rng)
>>> s = _stat.box_stats(a)
>>> [round(s[k], 4) for k in ("q1", "q2", "q3")]
[4.0536, 5.0962, 5.7834]
>>> [round(float(q), 4) for q in sd.quantile(a, sd.asarray([0.25, 0.5, 0.75]))]
[4.0536, 5.0962, 5.7834]
```

## 계산 영역에 맡기는 것

### 상자

`box_stats`는 NaN을 뺀 값을 정렬하고 `sd.quantile`로 사분위 $Q_1, Q_2, Q_3$을 구해요. 수염은 $[Q_1 - 1.5\,\mathrm{IQR},\ Q_3 + 1.5\,\mathrm{IQR}]$ 안의 값 가운데 가장 작은 것과 가장 큰 것까지예요(Tukey의 규칙). 울타리 자체가 아니라 그 안의 실제 값에서 멈춰요. 그 밖의 값은 점으로 찍어요. `points=True`면 모든 값을 점으로 찍어요.

### 히스토그램

```python
    # src/stardust/plot/_stat.py, histogram
    allx = _nonan(X)
    if range is None and allx.shape[0]:
        range = (float(sd.min(allx)), float(sd.max(allx)))  # one set of bins for every group
```

무리가 여럿이면 모든 무리의 최솟값과 최댓값으로 `range`를 한 번 정해 무리마다 `sd.histogram`에 같이 넘겨요. 무리마다 칸이 다르면 막대를 겹쳐 견줄 수 없기 때문이에요. 막대의 높이와 칸 경계는 `sd.histogram`이 돌려준 `hist`와 `bin_edges` 그대로예요. 무리가 여럿이면 겹친 막대가 비치도록 채움의 불투명도가 0.6이에요(하나면 1). `sd.histogram`이 낸 에러는 이름만 `histogram():`으로 바꿔 다시 내요.

### QQ 그림

```python
    # src/stardust/plot/_stat.py, qq
    p = (sd.arange(1.0, n + 1.0) - 0.5) / n
    q = dist.icdf(p)
```

정렬한 표본 $x_{(i)}$를 이론 분위수 $F^{-1}(p_i)$, $p_i = (i - \tfrac12)/n$에 대고 찍어요. 이 그림 위치(plotting position)는 Hazen의 것으로, i번째 순서 통계량이 차지하는 확률 구간 $[(i-1)/n,\ i/n]$의 가운데예요. 기준선은 R의 `qqline`처럼 표본의 사분위와 분포의 사분위, 두 점 $(F^{-1}(0.25), Q_1)$과 $(F^{-1}(0.75), Q_3)$을 지나요. 최소제곱 직선과 달리 꼬리의 몇 점에 끌리지 않아요. `dist`를 주지 않으면 표준정규 `sd.stats.Normal(mu=0.0, sigma=1.0)`이에요.

### 분포

`distribution`은 받침을 분위수로 잡아요. 기본 범위는 `icdf(0.001)`에서 `icdf(0.999)`까지이고, 받침의 끝이 유한하고 그 분위수에서 분위수 범위 폭의 25% 안에 있으면 받침의 끝을 써요(지수분포의 0처럼). 연속 분포는 그 범위로 [`function`](/api/plot/function/)을 불러 [곡선의 적응 표본](/internals/plot/sampling/)을 그대로 써요. 이산 분포(`pmf`가 있는 것)는 정수마다 막대(`kind='pdf'`)나 계단(`'cdf'`, `'sf'`)이에요.

## 무리와 범주 축

### 무리 나누기

`group=`이 있는 그림은 `split`으로 행을 무리로 나눠요. 무리의 순서는 값이 처음 나온 순서이고, 라벨이 `None`이거나 NaN인 행은 어느 무리에도 들지 않아요. `_each`가 무리마다 (행 번호, 색, 라벨)을 만들어요. 색은 팔레트에서 차례로 받고 라벨은 무리의 값이에요. 그래서 `group=`과 `color=`, `group=`과 `label=`을 함께 주면 에러예요. 둘이 같은 것을 정하려 하기 때문이에요.

### 범주 축의 자리

범주 축은 칸의 `xcats`(가로)나 `ycats`(세로) 목록이에요. `_categories`는 새 라벨을 목록 끝에 붙이고 라벨의 번호 0, 1, 2, …를 자리로 돌려줘요. 같은 칸에 `boxplot`과 `strip`을 겹치면 두 번째 호출은 이미 있는 라벨의 자리를 그대로 받으므로 상자와 점이 같은 자리에 서요. 축의 눈금은 이 목록이 정해요.

무리가 k개이면 한 범주 안에서 자리를 나눠요(dodge). `boxplot`은 상자의 폭 `width`를 k로 나누고 j번째 무리를 $(j - \tfrac{k-1}{2})\cdot \text{width}/k$만큼 옮겨요. 상자는 그 몫의 90% 폭이라 이웃한 상자 사이에 틈이 남아요. `strip`은 0.8/k씩 나눠요.

### `strip`의 흩음과 씨

```python
    # src/stardust/plot/_stat.py, strip
    for Y, cats, col, lab, j, k in _by_category(self, who, x, y, data, group, color, None):
        off = (j - (k - 1) / 2) * (0.8 / k)
        xs, ys = [], []
        for p, idx in cats:
            m = idx.shape[0]
            xs.append((gen.random(m) - 0.5) * (jitter / k) + (p + off))
            ys.append(sd.take(Y, idx))
```

점의 가로 자리는 범주의 자리에 폭 `jitter`/k의 고른 난수를 더한 것이에요. 난수는 `sd.random`의 생성기에서 받아요. `rng=None`이면 호출마다 `default_rng(0)`을 만들므로, 같은 자료로 부른 `strip`은 언제나 같은 그림이에요. 정수를 주면 그 씨의 생성기를 만들고, 생성기를 주면 그것을 그대로 써서 상태가 앞으로 가요.

```python
>>> vals = sd.concat([a, b, c])
>>> grp = ["control"] * 25 + ["low"] * 25 + ["high"] * 25
>>> sd.plot.strip(grp, vals).to_svg() == sd.plot.strip(grp, vals).to_svg()
True
```

## `compare`: 괄호 쌓기

`compare`는 그림이 이미 가진 범주 축 위에 괄호를 그려요. 검정을 고르거나 다시 계산하지 않고, 받은 결과의 `pvalue`를 글자로 바꾸기만 해요.

### 어느 쌍을, 어떤 순서로

`pvalue`가 수 하나이면 괄호 하나예요. 범주가 둘이면 그 둘을, 셋 이상이면 `groups=`가 고른 두 라벨을 이어요. `pvalue`가 k × k 행렬(다중 비교, 예를 들어 [`tukey_hsd`](/api/htest/tukey_hsd/))이면 범주가 정확히 k개여야 하고, 모든 쌍의 괄호를 그려요.

```python
        # src/stardust/plot/_stat.py, compare
        pv = p.tolist()
        pairs = sorted((j - i, i, j) for i in range(k) for j in range(i + 1, k))  # near pairs lowest
        for _, i, j in pairs:
            cell.layers.append(Bracket(float(i), float(j), level, p_text(float(pv[i][j]), format)))
            level += 1
```

쌍은 두 범주의 거리 j − i가 작은 것부터 차례로 층 번호 0, 1, 2, …를 받아요. 거리가 같으면 왼쪽 쌍이 먼저예요. 층 번호는 칸의 `headroom`에 이어지므로, `compare`를 여러 번 불러도 괄호가 겹치지 않고 다음 층에 서요.

### 축을 늘리기

괄호가 설 자리는 배치가 만들어요. 칸에 `headroom`이 있고 y축이 선형이며 사용자가 위쪽 범위를 정하지 않았으면, 배치는 자료의 y축을 먼저 잡은 뒤 위로 늘려요.

```python
    # src/stardust/plot/_figure.py
    if cell.headroom and m.ya.scale == "linear" and cell.ylim[1] is None:
        # room above the data for the brackets: the range grows so that they clear it
        # (the ticks stay those of the data: none beside the brackets)
        need = min(0.7, (13.0 * cell.headroom + 12.0) / ph)
        data = _axis(cell, "y", ph * (1.0 - need), th)
        m.ya.ticks, m.ya.labels, m.ya.mult = data.ticks, data.labels, data.mult
        m.ya.hi = m.ya.lo + (m.ya.hi - m.ya.lo) / (1.0 - need)
```

괄호 한 층은 13 bp이고 맨 위에 12 bp의 여백을 더해, 그 높이가 칸 높이 ph에서 차지하는 비율(많아야 70%)만큼 범위의 위쪽을 늘려요. 눈금은 늘리기 전, 자료만의 범위로 줄어든 높이에서 고른 것을 그대로 써요. 그래서 괄호 옆에는 눈금이 없어요. 괄호는 `Bracket.draw`가 칸의 위 가장자리에서 $9 + 13\,\ell$ bp 아래(ℓ은 층 번호)에 그어요. 층 0이 맨 위에 서고, 번호가 클수록 자료에 가까워요. 양 끝의 짧은 다리는 3 bp 아래로 내려오고, 글자는 괄호의 가운데 2 bp 위에 눈금 글자의 크기로 서요.

### p값의 꼴

```python
# src/stardust/plot/_stat.py
def p_text(p, fmt):
    """A p-value as text: 'p = 0.012' with summary()'s digits, or stars."""
    if fmt == "stars":
        return "ns" if not p <= 0.05 else "*" * (1 + (p <= 0.01) + (p <= 0.001))
    if p < 0.001:
        return r"$p < 0.001$"
    return f"$p = {p:.3f}$"
```

`'p'`는 `summary()`와 같은 소수 셋째 자리이고, 0.001보다 작으면 `p < 0.001`이에요. `'stars'`는 0.05, 0.01, 0.001을 넘을 때마다 별이 하나씩 늘어요. `not p <= 0.05`로 쓴 것은 NaN도 `ns`로 보내려는 것이에요.

```python
>>> _stat.p_text(0.0827, "p"), _stat.p_text(5e-6, "p"), _stat.p_text(0.004, "stars")
('$p = 0.083$', '$p < 0.001$', '**')
>>> r = sd.htest.tukey_hsd(a, b, c)
>>> fig = sd.plot.boxplot(grp, vals).strip(grp, vals, color="gray", alpha=0.6, size=2).compare(r)
```

## `fit`: 선과 띠

```python
    # src/stardust/plot/_stat.py, fit
    xs = sd.linspace(e[0], e[1], 101)
    X = sd.reshape(xs, (-1, 1))
    if band and hasattr(result, "predict_interval"):
        iv = result.predict_interval(X, alpha=alpha, kind="mean")
        cell.layers.append(_layers.Area(xs, iv[:, 0], iv[:, 1], _color.with_alpha(c, 0.2), None))
    cell.layers.append(_layers.Line(xs, result.predict(X), c, None, "-", None))
```

x의 범위는 칸에 이미 있는 층들의 x 범위를 합친 것이에요(그래서 산점도를 먼저 그려야 해요). 그 범위에 101점을 놓고 결과의 `predict`로 선을, `predict_interval(kind="mean")`으로 평균 반응의 신뢰 띠를 구해요. 단순 회귀에서 띠의 반폭은 $t_{1-\alpha/2,\,n-2}\, s\sqrt{1/n + (x - \bar x)^2 / S_{xx}}$이라 $\bar x$에서 가장 좁고 양 끝으로 갈수록 넓어지는 쌍곡선 꼴이에요. 개별 관측의 예측 구간이 아니라 평균의 구간이에요. 선의 색은 주지 않으면 칸의 마지막 층의 색이에요.

설명 변수가 하나인 모형만 받아요. `param_names`가 `['const', 이름]`이면 절편과 기울기, `[이름]` 하나이면 원점을 지나는 기울기예요. 식은 `.3g`의 유효숫자 셋으로 `$y = 1.61x + 1.29$`처럼 만들고, 결과에 `rsquared`가 있으면 `$R^2 = 0.858$`을 덧붙여 칸의 `note`에 둬요. 배치가 자료와 범례가 가장 적게 덮은 모서리를 골라 그 글을 놓아요.

```python
>>> x = sd.linspace(0.0, 10.0, 30)
>>> y = 1.5 * x + 2.0 + 2.0 * N.sample(30, rng=rng)
>>> res = sd.regression.ols(y, sd.reshape(x, (-1, 1)))
>>> res.param_names
['const', 'x1']
>>> fig = sd.plot.scatter(x, y).fit(res)
```

## `diagnostics`와 `pairs`: 여러 칸

두 그림은 칸 하나에 층을 얹는 메서드가 아니라 `Figure`를 만들어 돌려주는 함수예요. 그래서 그림 옵션 `**figure`를 받지 않고, 그 가운데 `width`, `height`, `font`, `theme`, `palette`만 이름으로 받아요. 너비의 기본은 두 단 너비인 183 mm예요.

`diagnostics`는 2 × 2 칸에 회귀 진단 넷을 그려요. 칸마다 공개 메서드를 부르는 것과 같아요.

| 칸 | 그리는 것 |
|---|---|
| (0, 0) Residuals vs fitted | `scatter(fittedvalues, resid)`와 0의 점선 |
| (0, 1) Normal Q–Q | `qq(resid_studentized_internal)` |
| (1, 0) Scale–location | `scatter(fittedvalues, sqrt(abs(표준화 잔차)))` |
| (1, 1) Residuals vs leverage | `scatter(leverage, 표준화 잔차)`와 0의 점선 |

`pairs`는 `DataFrame`의 수 열(`float64`, `int64`) k개로 k × k 칸을 만들어요. `group=`이 열 이름이면 그 열은 빼요. 대각선은 그 열의 `histogram`, 나머지 (i, j) 칸은 열 j를 가로, 열 i를 세로로 한 `scatter`(점 크기 2)예요. 축 이름은 맨 아래 행과 맨 왼쪽 열에만 붙이고, 칸마다 범례를 끈 뒤 무리가 있으면 오른쪽 위 칸에만 범례를 둬요. 무리의 색은 칸마다 같은 순서로 팔레트에서 받으므로 모든 칸에서 같은 무리가 같은 색이에요.

## 결정성

통계 그림에 들어가는 난수는 `strip`의 흩음 하나이고, 기본이 고정된 씨예요. 나머지는 계산 영역의 결정적인 결과를 옮겨요. 같은 기계, 같은 스레드 수, 같은 입력이면 같은 그림이에요.
