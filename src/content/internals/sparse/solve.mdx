## 특이 판정

판정은 분해 뒤에 한 번 해요(`splu`는 만들 때, `spsolve`·`inv`·`factorized`는 풀기 전). 셋 중 하나면 `LinAlgError("<함수>(): singular matrix")`예요.

1. Accelerate가 `SparseMatrixIsSingular`를 돌려줘요(구조적 특이).
2. 조건수를 추정하는 동안 한 풀이가 유한하지 않아요. `zeroTolerance = 0`이라 정확히 0인 피벗은 inf를 내고, 넘침도 여기에 들어요.
3. 추정한 1-노름 조건수 $\kappa_1 = \lVert A\rVert_1 \cdot \mathrm{est}(\lVert A^{-1}\rVert_1)$이 $\kappa_1\varepsilon \ge 1$이에요.

세 번째가 반올림 때문에 피벗이 정확히 0이 되지 않은 정확히 특이한 행렬을 잡아요. 그런 행렬은 영공간 방향으로 크기 1/ε 근처의 해를 내는데, 그것은 $\lVert A^{-1}\rVert$의 추정이 1/ε 크기라는 뜻이기도 해요. $\kappa_1\varepsilon \ge 1$이면 앞오차의 일반적인 한계 $\kappa\varepsilon$이 1을 넘으므로 해에 맞는 자리가 하나도 없다고 볼 수 있어요.

```cpp
// csrc/sparse/direct.cpp
template <class T>
std::unique_ptr<LuFactor> factor_typed(
    int64_t n, const NDArray& indptr, const NDArray& indices, const NDArray& data, bool csr, const std::string& func
) {
    auto out = std::make_unique<LuFactor>();
    out->dtype = data.dtype;
    out->n = n;
    const auto* ip = i64(indptr);
    const auto* ix = i64(indices);
    const auto* v = typed<T>(data);
    bool finite = true;
    double est = 0.0, anorm = 0.0;
    try {
        nb::gil_scoped_release unlocked;
        const auto a = sparse_solve::Csc::narrow(n, n, ip, ix, csr);
        auto lu = sparse_solve::Lu<T>::factor(a, v);
        anorm = norm1(n, ip, ix, v, csr);
        finite = inverse_norm1(lu, n, est);
        if constexpr (std::is_same_v<T, double>) out->real.emplace(std::move(lu));
        else out->complex_.emplace(std::move(lu));
    } catch (const sparse_solve::Error& e) { raise_failure(e, func); } catch (const std::length_error& e) {
        throw nb::value_error((func + "(): " + e.what()).c_str());
    }
    out->cond = anorm * est;
    if (!finite || !(out->cond * kEps < 1.0)) throw linalg::LinAlgError(func + "(): singular matrix");
    return out;
}
```

분해와 추정이 모두 GIL을 놓은 블록 안이에요. 조건을 `!(cond * kEps < 1.0)`으로 쓴 것은 추정이 NaN이어도 특이로 다루기 위해서예요. $\lVert A\rVert_1$은 열마다 원소 크기의 합 가운데 가장 큰 것이고, 저장된 CSC를 한 번 훑어 정확하게 계산해요.

### 1-노름 추정기 `lacn2`

$\lVert A^{-1}\rVert_1$을 정확히 알려면 $A^{-1}$의 모든 열을 풀어야 해요(풀이 n번). 그 대신 LAPACK의 1-노름 추정기 `dlacn2`·`zlacn2`(Hager 1984, Higham 1988)를 써요. 밀집 LU의 조건수 추정 `gecon`이 쓰는 것과 같은 루틴이고, linalg의 LAPACK 래퍼로 Accelerate의 LAPACK을 불러요.

1-노름 $\lVert C\rVert_1 = \max_{\lVert x\rVert_1 \le 1}\lVert Cx\rVert_1$은 볼록 함수의 최댓값이라 단위 공의 꼭짓점 $e_j$ 가운데 하나에서 나와요. Hager의 방법은 이 최대를 기울기 오르기로 찾아요.

1. $x = (1/n, \ldots, 1/n)$에서 시작해요.
2. $y = Cx$, $\xi = \operatorname{sign}(y)$, $z = C^{\mathsf H}\xi$를 계산해요. $z$가 $\lVert Cx\rVert_1$의 기울기예요.
3. $\max_j |z_j| \le z^{\mathsf H}x$면 더 오를 곳이 없어 멈춰요. 아니면 $x = e_j$($j = \arg\max_j |z_j|$)로 옮겨 2로 가요.
4. 부호 벡터가 되풀이되거나 추정이 늘지 않으면 멈추고, 반복은 많아야 5번이에요.
5. 끝으로 $x_i = (-1)^{i+1}\bigl(1 + \tfrac{i-1}{n-1}\bigr)$에 대해 $2\lVert Cx\rVert_1/(3n)$을 계산해 더 크면 그 값을 써요. 기울기 오르기가 놓치기 쉬운 행렬을 잡는 보조 시험이에요(Higham의 다듬기).

추정은 어떤 $x$에 대한 $\lVert Cx\rVert_1/\lVert x\rVert_1$이므로 언제나 참값의 **하한**이에요. 무작위 시작 벡터가 없으므로 같은 입력에 같은 추정을 내요. `lacn2`는 역방향 통신(reverse communication) 꼴이라 행렬을 받지 않고, 돌아올 때 `kase`로 무엇을 해 달라고 해요. $C = A^{-1}$이므로 "$x \leftarrow Cx$"는 A로 푸는 것이고 "$x \leftarrow C^{\mathsf H}x$"는 $A^{\mathsf H}$로 푸는 것이에요.

```cpp
// csrc/sparse/direct.cpp
// est(||A^-1||_1) by lacn2's reverse communication; false when a solve is not finite.
template <class T>
bool inverse_norm1(const sparse_solve::Lu<T>& lu, int64_t n, double& est) {
    using linalg::lint;
    std::vector<T> v(static_cast<std::size_t>(n)), x(static_cast<std::size_t>(n));
    std::vector<lint> isgn(static_cast<std::size_t>(n));
    lint isave[3] = {0, 0, 0};
    lint kase = 0;
    est = 0.0;
    for (;;) {
        linalg::lapack::lacn2<T>(static_cast<lint>(n), v.data(), x.data(), isgn.data(), est, kase, isave);
        if (kase == 0) return true;
        lu.solve(x.data(), 1, n, kase == 1 ? 'N' : 'H');
        if (!all_finite(x.data(), n)) return false;
    }
}
```

풀이는 보통 4–5번이에요. 우변이 하나인 풀이라 위의 전치 결함에 걸리지 않고, 실수 인수의 `'H'`는 그냥 전치 풀이예요. 같은 추정기의 자세한 설명과 밀집에서의 쓰임은 [행렬 지수의 구현](/internals/linalg/expm/)에도 있어요.

비공개 필드 `cond`로 추정을 볼 수 있어요. 작은 행렬에서 밀집으로 계산한 참값과 견주면 하한이라는 것이 보여요.

```python
>>> from stardust.sparse._direct import _Factor
>>> rng = sd.random.default_rng(1)
>>> A = sd.sparse.random_array((300, 300), density=0.02, rng=rng, format="csc") + sd.sparse.eye_array(300, format="csc") * 4.0
>>> _Factor(A, "splu").core.cond
10.603386972495814
>>> D = A.toarray()
>>> float(sd.linalg.matrix_norm(D, ord=1) * sd.linalg.matrix_norm(sd.linalg.inv(D), ord=1))
16.57662408569062
```

### 판정이 잡은 것과 놓치지 않은 것

정방 시험 행렬 모두에서 특이로 판정한 것은 정확히 특이한 행렬 모두예요. Neumann 라플라시안(1·2차원), 같은 열이 둘인 행렬, 행의 상쇄로 랭크가 모자란 행렬(밀집 κ₁ 3×10²⁴·3×10²⁸), 구조적으로 특이한 행렬 셋이에요. 특이가 아닌 행렬은 모두 풀었어요. 가장 나쁜 것은 조건수를 일부러 키운 삼중대각 행렬(κ₁ 추정 7.5×10¹⁴)과 near_singular/20(8×10⁸)이에요. 추정은 작은 행렬에서 밀집 κ₁의 1/10 이상이고 그 이하예요. SuiteSparse 행렬 가운데 sherman3(κ₁ 6.9×10¹⁶)과 cvxqp3(2.2×10¹⁶)은 κ₁ε ≥ 1이라 `LinAlgError`예요.

추정이 하한이라 κ₁을 낮게 볼 수는 있어요. 그래도 정확히 특이한 행렬은 영공간 방향의 해가 1/ε 크기로 커져 추정이 그 크기를 놓치지 않았고, 정확히 0인 피벗은 두 번째 조건이 잡아요.

## 반복 다듬기

모든 풀이(`spsolve`, `SparseLU.solve`, `factorized`, `inv`)에 반복 다듬기를 한 번 해요. 잔차를 같은 정밀도(float64)로 계산하는 고정 정밀도 다듬기예요.

$$
x_0 = \mathrm{solve}(b), \qquad r = b - \mathrm{op}(A)\,x_0, \qquad x = x_0 + \mathrm{solve}(r)
$$

```python
        # src/stardust/sparse/_direct.py, _Factor.solve
        if self.dtype == _sd.complex128 and b.dtype != _sd.complex128:
            b = b.astype(_sd.complex128)
        if self.core is None:
            return b.copy()
        x = self.core.solve(b, trans=trans, func=func)
        r = b - self._op(trans) @ x
        return x + self.core.solve(r, trans=trans, func=func)
```

잔차의 곱 `self._op(trans) @ x`는 이 라이브러리의 SpMV예요(행마다 열 번호 오름차순의 FMA 순차 합, [곱](/internals/sparse/products/)). $\mathrm{op}(A)$는 `'N'`이면 A, `'T'`면 $A^{\mathsf T}$, `'H'`면 복소에서 켤레 전치를 한 번 만들어 둔 것이에요.

왜 한 번이면 될까요? 문턱 0.01의 피벗은 $|l_{ij}|$를 100까지 허락하므로 원소가 자라고, 그만큼 LU의 역오차가 커질 수 있어요. 안장점 행렬 saddle/600x150에서 다듬기 없는 정규화 역오차 $\lVert b - A\hat x\rVert_\infty / (\lVert A\rVert_\infty\lVert\hat x\rVert_\infty + \lVert b\rVert_\infty)$가 404ε였어요. Skeel(1980)은 가우스 소거가 너무 불안정하지 않으면 같은 정밀도의 다듬기 한 번이 성분별로 역안정한 해를 준다는 것을 보였어요. 잔차를 정확하게 다시 재고 같은 인수로 고치는 한 걸음이 분해의 성장을 갚는 거예요. 한 번 다듬은 뒤에는 정방이고 특이가 아닌 시험 행렬 모두와 SuiteSparse 행렬 다섯에서 역오차가 0.50ε 이하예요. 비용은 풀이 하나와 SpMV 하나예요.

## 우변 다루기

C++의 `_LuFactor.solve`는 b를 열 우선의 연속 배열로 모아 Accelerate에 넘기고, 결과를 b의 모양(행 우선)으로 돌려놔요. b의 stride는 무엇이든 돼요.

```cpp
// csrc/sparse/direct.cpp
// b (n,) or (n, k) with any strides -> column-major columns of T (a complex b against a real
// factor: the k real parts, then the k imaginary parts).
template <class T, class B>
void gather(const NDArray& b, int64_t n, int64_t k, std::vector<T>& cols) {
    const int64_t s0 = b.strides[0] / static_cast<int64_t>(sizeof(B));
    const int64_t s1 = b.ndim == 2 ? b.strides[1] / static_cast<int64_t>(sizeof(B)) : 0;
    const auto* bp = reinterpret_cast<const B*>(b.data);
    constexpr bool split = std::is_same_v<T, double> && std::is_same_v<B, c128>;
    cols.resize(static_cast<std::size_t>(n * k * (split ? 2 : 1)));
    for (int64_t j = 0; j < k; ++j)
        for (int64_t i = 0; i < n; ++i) {
            const B v = bp[i * s0 + j * s1];
            if constexpr (split) {
                cols[static_cast<std::size_t>(j * n + i)] = v.real();
                cols[static_cast<std::size_t>((k + j) * n + i)] = v.imag();
            } else {
                cols[static_cast<std::size_t>(j * n + i)] = static_cast<T>(v);
            }
        }
}
```

실수 인수에 복소 우변을 주면 실수부 k열과 허수부 k열을 2k개의 실수 우변으로 함께 풀어요. A가 실수면 $A(x_r + i x_i) = b_r + i b_i$가 두 실수 계로 나뉘기 때문이에요. 복소 인수를 따로 만들지 않아도 되고, 밀집의 `sd.linalg.lu_solve`도 같아요(scipy의 `SuperLU.solve`는 이 경우 `TypeError`, `spsolve`는 A를 복소로 바꿔 분해해요). 풀이 뒤의 값이 하나라도 유한하지 않으면 `LinAlgError("<함수>(): singular matrix")`예요.

### `spsolve`의 희소 우변과 `inv`

`spsolve`는 희소 b도 받고, 그러면 결과도 희소예요(A가 CSR이면 CSR, 나머지는 CSC). b의 열을 크기만으로 정한 묶음으로 잘라 밀집으로 풀고, 묶음마다 정확한 0을 빼서 이어 붙여요.

```python
# src/stardust/sparse/_direct.py
def _block_columns(n):
    """Columns of a sparse right-hand side solved together: fixed by n alone (so the bits are),
    about 2^22 values a block, 1 to 64 columns."""
    return max(1, min(64, (1 << 22) // max(n, 1)))
```

한 묶음은 값 약 2²²개(32 MB)이고 1–64열이에요. 묶음의 열 수가 n으로만 정해지므로, 같은 열은 언제나 같은 묶음에서 같은 이웃과 함께 풀려 비트가 정해져요. 결과를 `csc_array(dense)`로 만들면 0이 아닌 값만 저장하므로 정확한 0이 빠지고 NaN은 남아요.

[`inv`](/api/sparse/inv/)는 이 길에 단위 행렬을 희소 우변으로 넣은 것이에요. 희소 행렬의 역행렬은 대개 거의 밀집이라 n²의 메모리가 들어요.

[`factorized`](/api/sparse/factorized/)는 `splu(A).solve`(묶인 메서드)이고, [`SparseLU`](/api/sparse/splu/)는 인수와 CSC 행렬을 쥔 객체예요. 한 인수를 여러 Python 스레드가 동시에 풀어도 같은 비트예요. 풀이는 GIL을 놓고, Accelerate에서 같은 인수로 다시 푸는 것은 결정적이에요.

## 정확도

직접 풀이의 계약은 정규화한 역오차 $\lVert b - A\hat x\rVert_\infty / (\lVert A\rVert_\infty\lVert\hat x\rVert_\infty + \lVert b\rVert_\infty) \le 4\varepsilon$이에요. 다듬기 한 번 뒤에 정방이고 특이가 아닌 시험 행렬 모두와 SuiteSparse 다섯에서 0.50ε 이하였어요. 우변 여럿과 `trans='T'`·`'H'`도 시험 행렬 넷과 SuiteSparse 다섯에서 계약 안이에요. n ≤ 2000의 작은 행렬 30점은 Arb(구간 산술)로 검증한 해와 견줘 앞오차가 $4\kappa_\infty(A)\varepsilon$ 안이고, 가장 큰 것이 $0.39\kappa_\infty\varepsilon$예요.

## scipy와 다른 점

- scipy의 `spsolve`는 구조적으로 특이한 행렬에 `MatrixRankWarning`과 NaN 배열을, `splu`는 `RuntimeError("Factor is exactly singular")`를 내요. 값으로 특이한 행렬은 경고 없이 큰 유한한 해를 내요(같은 열이 둘인 dupcol/40에서 크기 3×10¹⁹, 2차원 Neumann 라플라시안에서 5×10¹⁴). 여기서는 모두 `LinAlgError`예요.
- scipy의 SuperLU는 다듬기를 하지 않고 같은 시험 행렬에서 역오차가 0.10–4.4ε예요.
- scipy는 열이 하나인 희소 b와 1차원 희소 b에 밀집 결과를 주지만 여기서는 희소예요. 밀집 b가 (n, 1)이면 (n, 1)을 돌려줘요(scipy는 (n,)으로 펴요).
