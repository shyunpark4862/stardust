## 두 가지 만드는 길

만들기 함수는 결과를 둘 가운데 한 길로 만들어요.

- **표준 꼴을 바로 쓰기**: 원소가 놓일 순서를 미리 알면 `indptr`, `indices`, `data`를 정렬 없이 바로 채워요. `eye_array`, `kron`, CSR끼리·CSC끼리의 쌓기가 이 길이에요.
- **COO 원소를 잇고 필요하면 바꾸기**: 그 밖은 블록이나 대각의 원소를 좌표로 이어 COO를 만들고, 요청한 형식이면 [표준 꼴 만들기](/internals/sparse/conversion/)를 거쳐요. 중복의 합은 입력 순서예요.

모든 값은 입력의 값이거나 두 값의 배열의 곱(`kron`)이라, `toarray()`는 밀집 짝(`sd.eye`, `sd.tril`, `sd.triu`, `sd.block`, `sd.linalg.kron` …)의 결과와 비트까지 같아요. 다를 수 있는 것은 0의 부호뿐이에요. 데이터 인자는 희소 배열이나 밀집 `sd.ndarray`이고, 밀집은 0이 아닌 값만 고른 COO로 받아요. 리스트와 numpy 배열은 배열의 함수처럼 `TypeError`예요.

`format=None`이 고르는 형식은 scipy의 규칙이되, scipy가 DIA나 BSR을 고르는 자리는 CSR이에요(이 영역에 DIA·BSR이 없어요).

| 함수 | `format=None`의 결과 |
|---|---|
| `eye_array`, `diags_array`, `kron`, `kronsum` | CSR |
| `hstack`, `vstack`, `block_array` | 블록이 모두 CSR이면 CSR, 모두 CSC면 CSC, 아니면 COO |
| `block_diag`, `tril`, `triu`, `random_array` | COO |

## eye_array와 diags_array

`eye_array`는 대각이 하나뿐이라 줄 r의 원소가 많아야 하나예요. `indptr`은 −r₀부터 1씩 늘어나는 수열을 [0, 대각의 길이]로 자른 것이고, `indices`는 c₀부터의 연속한 수예요. 정렬도 커널도 없이 배열 함수 세 번으로 표준 꼴이 나와요.

```python
    # src/stardust/sparse/_construct.py
    length = max(0, min(m, n - k) if k >= 0 else min(m + k, n))
    r0, c0 = max(-k, 0), max(k, 0)
    indptr = _readonly(_sd.clip(_sd.arange(-r0, m + 1 - r0, dtype=_sd.int64), min=0, max=length))
    indices = _readonly(_sd.arange(c0, c0 + length, dtype=_sd.int64))
    data = _sd.ones(length, dtype=dtype)
```

```python
>>> import stardust as sd
>>> E = sd.sparse.eye_array(3, k=1)
>>> E.format, E.indptr.tolist(), E.indices.tolist()
('csr', [0, 1, 2, 2], [1, 2])
```

`diags_array`는 대각마다 (행, 열, 값)을 이어 붙여 CSR로 바꾸고, 정확한 0을 지워요. scipy가 DIA에서 CSR·COO로 바꿀 때 0을 저장하지 않기 때문이에요. 정수 대각은 배열의 승격 규칙대로 int64로 남아요.

```python
>>> D = sd.sparse.diags_array([sd.asarray([1.0, 2.0]), sd.asarray([3.0, 0.0, 5.0])], offsets=[1, 0])
>>> D.format, D.nnz, D.toarray().tolist()
('csr', 4, [[3.0, 1.0, 0.0], [0.0, 0.0, 2.0], [0.0, 0.0, 5.0]])
```

## random_array

`rng`(`sd.random.Generator`)는 기본값 없는 키워드예요. 시드 없는 무작위가 없어요. 자리의 수는 round(density × 크기)이고, C 순서의 위치를 `rng.choice(크기, 수, replace=False)`로 뽑아 행과 열로 나눠요. 뽑힌 순서 그대로의 COO라 정렬되어 있지 않아요. 값은 `data_sampler(n)`(위치 인자 하나로 불러요) 또는 dtype마다 정한 `rng` 호출이에요. float64는 `rng.random(n)`, complex128은 실수부 `random(n)` 다음 허수부 `random(n)`, int64는 `rng.integers`, bool은 `random(n)`의 0이 아닌 것이에요. 크기가 2⁶³ − 1을 넘으면 축마다 `integers`로 좌표를 뽑아 처음 나온 자리만 둬요.

```python
>>> r1 = sd.sparse.random_array((4, 5), density=0.3, rng=sd.random.default_rng(1))
>>> r2 = sd.sparse.random_array((4, 5), density=0.3, rng=sd.random.default_rng(1))
>>> r1.format, r1.nnz, r1.has_canonical_format
('coo', 6, False)
>>> r1.data.tolist() == r2.data.tolist() and r1.coords[1].tolist() == r2.coords[1].tolist()
True
```

같은 생성기 상태면 스레드 수와 상관없이 같은 배열이에요. 생성기가 numpy와 달라 scipy와 같은 값은 아니에요.

## kron: 정렬 없는 표준 꼴

kron(A, B)의 행 i·p + r은 A의 행 i와 B의 행 r에서 나와요. A의 행 i에 저장된 원소마다(열 오름차순) B의 행 r의 원소를 차례로 이으면 열 j·q + l이 저절로 오름차순이에요. 그래서 정렬 없이 표준 꼴 CSR이고, 결과 행마다 원소 수가 (A의 행 i의 수) × (B의 행 r의 수)라 `indptr`도 먼저 정해져요. 행 구간마다 병렬로 채워요.

```cpp
                    // csrc/sparse/construct.cpp
                    for (int64_t R = lo; R < hi; ++R) {
                        const int64_t i = R / p, r = R % p;
                        int64_t w = op[R];
                        for (int64_t s = ap[i]; s < ap[i + 1]; ++s)
                            for (int64_t t = bp[r]; t < bp[r + 1]; ++t) {
                                ox[w] = ai[s] * q + bi[t];
                                ov[w] = ops::Multiply::f(av[s], bv[t]);
                                ++w;
                            }
                    }
```

값은 배열의 곱 `ops::Multiply`라 bool × bool은 int64예요(배열의 `multiply`와 같아요). 저장된 0과 곱한 값, 곱해서 0이 된 값도 저장돼요. 밀집 `sd.linalg.kron`과는 0의 부호만 달라요.

```python
>>> A = sd.sparse.csr_array(sd.asarray([[1.0, 2.0], [0.0, 3.0]]))
>>> B = sd.sparse.csr_array(sd.asarray([[0.0, 1.0], [-1.0, 0.0]]))
>>> K = sd.sparse.kron(A, B)
>>> K.format, K.indptr.tolist(), K.indices.tolist()
('csr', [0, 2, 4, 5, 6], [1, 3, 0, 2, 3, 2])
>>> sd.linalg.kron(A.toarray(), B.toarray()).tolist()[3]
[-0.0, 0.0, -3.0, 0.0]
>>> K.toarray().tolist()[3]
[0.0, 0.0, -3.0, 0.0]
```

밀집은 0 × (−1)을 계산해 −0.0을 두지만, 희소는 A의 (1, 0)이 저장되지 않아 그 자리를 계산하지 않아요.

## kronsum: 값을 놓기

kronsum(A, B) = kron(I_n, A) + kron(B, I_m)이에요(A는 m × m, B는 n × n). 단위 행렬과 곱하지 않고 값을 바로 놓아요. A의 원소를 대각 블록마다, bᵢⱼ를 블록 (i, j)의 대각 m자리에 COO 좌표로 이은 뒤 CSR로 바꿔요. 겹치는 자리는 aₚₚ와 bᵢᵢ가 만나는 대각뿐이고, 표준 꼴 만들기가 입력 순서(A 쪽이 먼저)로 a + b 하나로 더해요. 마지막에 정확한 0을 지워 희소끼리의 `+`와 같은 패턴을 내요.

```python
    # src/stardust/sparse/_construct.py
    a, b = _as_2d_csr(A).tocoo(), _as_2d_csr(B).tocoo()
    (ra, ca), (rb, cb) = a.coords, b.coords
    base = _sd.arange(n, dtype=_sd.int64)[:, None] * m
    q = _sd.arange(m, dtype=_sd.int64)[None, :]
    na, nb = ra.shape[0], rb.shape[0]
    rows = _sd.concat([(base + ra[None, :]).reshape(n * na), (rb[:, None] * m + q).reshape(nb * m)])
    cols = _sd.concat([(base + ca[None, :]).reshape(n * na), (cb[:, None] * m + q).reshape(nb * m)])
```

1 × a를 곱하면 complex의 0 + inf·j가 NaN + inf·j로 바뀌고 a + 0이 허수부 −0.0을 +0.0으로 바꿔요. 값을 놓으면 그런 일이 없어, `sd.linalg.kronsum`과 0의 부호만 빼고 비트까지 같아요.

```python
>>> KS = sd.sparse.kronsum(A, B)
>>> KS.format, KS.toarray().tolist() == sd.linalg.kronsum(A.toarray(), B.toarray()).tolist()
('csr', True)
```

## 쌓기: hstack, vstack, block_array

블록이 모두 CSR(또는 모두 CSC)이고 빈 블록(None)이 없으면 줄을 잇는 두 커널로 표준 꼴을 바로 만들어요.

- `_stack_minor`: 줄 방향으로 나란한 블록들. 결과의 줄 r은 각 블록의 줄 r을 블록 순서로 잇되 색인에 블록의 시작 자리를 더한 것이에요. 블록 순서가 곧 색인 순서라 정렬이 필요 없어요.
- `_stack_major`: 위아래로 쌓인 블록들. 블록의 줄들을 차례로 이어요. 색인은 그대로이고 `indptr`만 블록의 시작만큼 옮겨요.

CSR의 `hstack`은 `_stack_minor`, `vstack`은 `_stack_major`, `block_array`는 행마다 `_stack_minor`를 한 뒤 그 결과들에 `_stack_major`예요. CSC는 두 커널의 역할이 바뀌어요. 그 밖(형식이 섞였거나 None이 있으면)은 블록의 COO 원소를 블록 순서(행 우선)로 이은 COO예요. 모양이 맞지 않으면 scipy의 글(`blocks[0,:] has incompatible row dimensions: ...`)의 `ValueError`예요.

```python
>>> H = sd.sparse.hstack([A, B])
>>> H.format, H.indices.tolist()
('csr', [0, 1, 3, 1, 2])
>>> sd.sparse.vstack([A, B.tocsc()]).format
'coo'
```

`block_diag`는 언제나 블록의 COO 원소를 대각을 따라 옮겨 이어요. 밀집 블록은 0이 아닌 값만이에요.

## tril, triu, find

`tril(A, k=)`·`triu(A, k=)`는 A의 COO 원소 가운데 col ≤ row + k(col ≥ row + k)인 것을 원소 순서 그대로, 중복까지 남겨요(`_band_coo`). 남는 것이 모두면 값만 복사해요. A가 표준 꼴이면 결과도 표준 꼴이라는 표시를 물려받아요.

`find(A)`는 중복을 더한 표준 꼴에서 0이 아닌 값의 `(row, col, data)`를 쓸 수 있는 새 밀집 배열 셋으로 돌려줘요. `nonzero()`와 인덱싱이 밀집 짝이에요.

```python
>>> sd.sparse.tril(sd.sparse.coo_array(sd.asarray([[1.0, 2.0], [3.0, 4.0]]))).toarray().tolist()
[[1.0, 0.0], [3.0, 4.0]]
>>> [x.tolist() for x in sd.sparse.find(A)]
[[0, 0, 1], [0, 1, 1], [1.0, 2.0, 3.0]]
```

## scipy를 아는 분께

- `eye_array`·`diags_array`의 scipy 기본 형식은 DIA, `kron`은 BSR이에요. 이쪽은 CSR이고 값은 scipy의 `format='csr'`과 같아요. scipy의 BSR은 B의 0까지 블록에 저장해요.
- scipy의 `kron`은 bool × bool이 bool이고, 한쪽이 아무것도 저장하지 않으면 dtype을 잃고 float64를 돌려줘요. 이쪽은 배열의 승격이에요.
- scipy의 `block_diag`는 밀집 블록의 모든 자리를 0까지 저장해요. 인자 이름도 `mats`예요(이쪽은 `sd.linalg.block_diag`와 같은 `arrays`).
- scipy의 `random_array`는 `data_sampler(size=n)`으로 부르고 `dtype=None`이면 float64로 바꿔요. 이쪽은 위치 인자 하나로 부르고 그 결과의 dtype을 둬요.
- scipy는 리스트와 numpy 배열 블록을 받아요. 이쪽은 희소 배열과 `sd.ndarray`만 받아요.
