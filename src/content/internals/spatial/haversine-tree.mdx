## 한눈에 보기

[`haversine`](/api/spatial/haversine/)은 (위도 $\varphi$, 경도 $\lambda$)를 라디안으로 받아 단위 구 위 두 점의 중심각을 돌려줘요. 이 거리로 가까운 이웃을 찾을 때 위도·경도 평면에 KD 트리를 바로 세울 수는 없어요. 경도는 $\pm\pi$에서 이어 붙어 있어 평면의 상자가 날짜 변경선 건너편의 이웃을 멀다고 보고, 중심각은 Minkowski 거리가 아니라서 상자까지의 거리가 하한이 되지도 않아요. sklearn은 이 거리에 `BallTree`를 써요.

sd는 다른 길을 가요. 점을 단위 구 위의 3차원 점으로 옮기면 두 점 사이의 직선 거리(현)가 중심각의 단조 함수라서, 이미 있는 KD 트리와 `euclidean` 커널로 후보를 고를 수 있어요. 돌려주는 거리와 넣을지·순서를 정하는 모든 판정은 `haversine`의 짝 커널(`cdist(metric='haversine')`의 그 원소와 같은 비트)이 하고, 트리는 후보를 고르기만 해요. 반올림 때문에 현의 순서와 `haversine`의 순서가 아주 조금 어긋날 수 있어서, 그 어긋남보다 넉넉한 여유로 고르고 그 여유가 이웃과 동점을 하나도 놓치지 않는다는 것을 증명해요.

1. `XA`와 `XB`의 행마다 $\cos\varphi$와 3차원 점 $\hat P = (\cos\varphi\cos\lambda, \cos\varphi\sin\lambda, \sin\varphi)$를 구해요. 이때 모든 점이 정의역 $\lvert\varphi\rvert \le \mathrm{fl}(\pi/2)$, $\lvert\lambda\rvert \le 8$ 안인지도 봐요.
2. 밖의 점이 하나라도 있으면 전수로 가요. 안이면 `XB`의 $\hat P$로 `leafsize` 10의 KD 트리를 만들어요.
3. `XA`의 행마다 트리를 내려가며 3차원 거리의 하한이 `cut(T)`보다 큰 노드를 쳐요. 남은 점은 원래의 (위도, 경도)로 `haversine`을 계산해 $(\hat d, \text{색인})$으로 판정해요.

`kneighbors`와 `radius_neighbors`는 `metric='haversine'`이고 $m_B \ge 128$, $m_A \ge 16$, $8k \le m_B$이면 이 길을 타요(그보다 작으면 트리를 만드는 비용이 찾기에서 아끼는 것보다 커요). 길은 빠르기만 바꾸고 답은 전수와 같아요.

```python
    # src/stardust/spatial/_neighbors.py
    if _use_tree(path, tp, ma, mb, A.shape[1], kc):
        out = _core._KDTree(B, 10).query(A, sd.arange(1, kc + 1, dtype=sd.int64), tp, ub)
```

## haversine 공식

구면 코사인 법칙 $\cos d = \sin\varphi_1\sin\varphi_2 + \cos\varphi_1\cos\varphi_2\cos\Delta\lambda$로 $d$를 구하면 작은 $d$에서 자릿수를 잃어요. $\cos d \approx 1 - d^2/2$라 $d = 10^{-8}$이면 $\cos d$가 1로 반올림되기 때문이에요. $1 - \cos x = 2\sin^2(x/2)$로 양변을 바꾸면 haversine 공식이 나와요.

$$
h = \sin^2\frac{\Delta\varphi}{2} + \cos\varphi_1\cos\varphi_2\,\sin^2\frac{\Delta\lambda}{2}, \qquad d = 2\arcsin\sqrt h
$$

$h = \sin^2(d/2)$이고, 작은 $d$에서는 두 항이 모두 작은 수의 제곱이라 상쇄가 없어요. 그래도 수치 문제가 두 곳에 남아요.

### 대척점

$d$가 $\pi$에 가까우면 $h$가 1에 가까워요. $\arcsin$은 1 둘레에서 기울기가 무한대라 $h$의 반올림 오차 $u$가 $d$에 $\sqrt{u}$ 크기로 들어가고, $d = \pi - \delta$에서 $h = \cos^2(\delta/2) \approx 1 - \delta^2/4$라 $\delta \lt 2\sqrt{u} \approx 2 \times 10^{-8}$이면 $h$가 아예 1로 반올림돼요. 커널은 $h \le 1/2$($d \le \pi/2$)일 때만 $2\arcsin\sqrt{h}$를 쓰고, 그보다 크면 $g = 1 - h$를 **빼지 않고** 직접 구해 $d = \pi - 2\arcsin\sqrt{g}$로 가요. $S = \varphi_1 + \varphi_2$로 두면

$$
\cos\varphi_1\cos\varphi_2 = \cos^2\frac{\Delta\varphi}{2} - \sin^2\frac{S}{2}
$$

이고(곱을 합으로 바꾸는 공식), 이것을 $1 - h$에 넣어 정리하면

$$
g = 1 - h = \cos^2\frac{\Delta\varphi}{2}\cos^2\frac{\Delta\lambda}{2} + \sin^2\frac{S}{2}\sin^2\frac{\Delta\lambda}{2}
$$

예요. 음이 아닌 두 항의 합이라 $1 - h$의 상쇄가 없고, $g \le 1/2$인 갈래에서 쓰므로 $\arcsin$의 기울기도 $\sqrt{2}$ 이하예요.

```python
>>> import math
>>> S = sd.spatial
>>> x, y = [0.5, 0.0], [-0.5 + 2.0**-30, math.pi]
>>> d = S.haversine(x, y)
>>> math.pi - d, 2.0**-30
(9.313225746154785e-10, 9.313225746154785e-10)
>>> h = math.sin((y[0] - x[0]) / 2)**2 + math.cos(x[0]) * math.cos(y[0]) * math.sin((y[1] - x[1]) / 2)**2
>>> h, math.pi - 2 * math.asin(math.sqrt(h))
(1.0, 0.0)
```

$y$는 $x$의 대척점에서 위도로 $2^{-30}$만큼 비킨 점이라 참 거리는 $\pi - 2^{-30}$이에요(경도 $\mathrm{fl}(\pi)$와 $\pi$의 차이는 2차로만 들어가요). $2\arcsin\sqrt{h}$를 그대로 쓰면 $h$가 1이 되어 이 차이가 통째로 사라져요.

### 날짜 변경선

경도 $\lambda_1 \approx -\pi$, $\lambda_2 \approx \pi$인 두 점은 서로 가까워요. 그런데 $\Delta\lambda = \mathrm{fl}(\lambda_2 - \lambda_1) \approx 2\pi$의 반올림 오차는 절대 $u\lvert\Delta\lambda\rvert/2$ 둘레이고, $\sin(\Delta\lambda/2) = \sin(\pi - \varepsilon) \approx \varepsilon$라 이 절대 오차가 작은 $\sin$ 값에 그대로 얹혀요. 상대오차가 약 $u\pi/d$로 $d$에 반비례해 커져요. 커널은 TwoSum으로 반올림 오차 $e$를 정확히 구해($\Delta\lambda + e = \lambda_2 - \lambda_1$가 정확히 서요) $\sin((\Delta\lambda + e)/2)$와 $\cos((\Delta\lambda + e)/2)$를 $e/2$의 1차까지 fma 하나씩으로 고쳐요. 남는 2차 항은 $e^2/8$ 아래라 무시할 만해요.

```python
>>> from decimal import Decimal, getcontext
>>> getcontext().prec = 60
>>> PI = Decimal("3.14159265358979323846264338327950288419716939937510582097494")
>>> l1, l2 = -3.1415926535897, 3.14159265358979
>>> float(2 * PI - (Decimal(l2) - Decimal(l1)))
9.661228789729306e-14
>>> S.haversine([0.0, l1], [0.0, l2])
9.661228789729306e-14
>>> 2 * math.asin(abs(math.sin((l2 - l1) / 2)))
9.6168198687443e-14
```

참값은 입력 double 두 개의 차이를 `decimal`로 정확히 구해 $2\pi$에서 뺀 것이에요(적도 위라 중심각이 곧 경도 차이예요). TwoSum 없이 $\mathrm{fl}(\lambda_2 - \lambda_1)$로 바로 구하면 상대 $4.6 \times 10^{-3}$을 잃어요.

$h$가 $2^{-968}$보다 작으면 사인 두 개를 $2^{600}$배 해(2의 거듭제곱이라 정확해요) 제곱의 언더플로 없이 다시 구하고 $2^{-600}$배로 되돌려요.

```cpp
// csrc/spatial/metric.hpp
inline double haversine_pair(double f1, double l1, double c1, double f2, double l2, double c2) {
    const SinCos a = sincos((f2 - f1) * 0.5);
    const double dl = l2 - l1, lv = dl + l1, bv = dl - lv;
    const double he = ((l2 - lv) + (-l1 - bv)) * 0.5;  // e / 2
    const SinCos b = sincos(dl * 0.5);
    const double bs = std::fma(he, b.c, b.s);
    const double cc = c1 * c2;
    const double h = a.s * a.s + cc * (bs * bs);
    if (h <= 0.5) {
        if (h >= kTiny) return 2.0 * std::asin(std::sqrt(h));
        const double x = a.s * 0x1p600, y = bs * 0x1p600;  // the careful path (h = 0 stays 0)
        return 2.0 * std::asin(std::sqrt(x * x + cc * (y * y)) * 0x1p-600);
    }
    const double bc = std::fma(-he, b.s, b.c);
    const double ss = std::sin((f1 + f2) * 0.5);
    const double ac = a.c * bc, sd_ = ss * bs;
    const double g = ac * ac + sd_ * sd_;
    return 0x1.921fb54442d18p+1 - 2.0 * std::asin(std::sqrt(g));
}
```

`lv`, `bv`, `he`의 세 줄이 Knuth의 TwoSum이에요. $\texttt{dl} = \mathrm{fl}(\texttt{l2} - \texttt{l1})$일 때 `(l2 - lv) + (-l1 - bv)`는 반올림 없이 정확한 오차 $e$이고, 0.5배도 정확해요. $\cos\varphi$는 행마다 한 번 구해 `c1`, `c2`로 받아요. 마지막 상수는 $\mathrm{fl}(\pi)$예요.

### 보조정리 H(커널의 오차)

**보조정리 H.** 정의역 $\lvert\varphi\rvert \le \mathrm{fl}(\pi/2)$, $\lvert\lambda\rvert \le 8$에서, libm의 sin·cos·asin이 상대 $2u$ 안이고 $\sqrt{\cdot}$가 올바르게 반올림된다고 하면(가정 L)

- 가까운 갈래($\hat h \le 1/2$): $\lvert\hat d - d\rvert \le 16u\,d + 2^{-99}$,
- 먼 갈래($\hat h \gt 1/2$): $\lvert\hat d - d\rvert \le 43u$

이고, 둘 다 $2^{-46}(1 + d) = 128u(1 + d)$ 안이에요.

*증명.* 가까운 갈래부터 봐요.

1. $\widehat{\Delta\varphi} = \mathrm{fl}(\varphi_2 - \varphi_1) = \Delta\varphi(1 + \delta)$, $\lvert\delta\rvert \le u$예요. 정의역에서 $\lvert\Delta\varphi/2\rvert \le \pi/2$이고 그 범위에서 $a\cot a \le 1$이라, 인자의 상대 섭동 $\delta$는 $\sin(\widehat{\Delta\varphi}/2)$에 상대 $u$ 안으로만 들어가요. libm의 $2u$를 더해 첫 성분의 상대오차가 $3u$ 안이에요.
2. $\Delta\lambda$는 TwoSum으로 정확하고, 1차 보정의 나머지는 $e^2/8 + u\lvert e\rvert$예요. $\lvert\lambda\rvert \le 8$이면 $\lvert\Delta\lambda\rvert \le 16$이라 $\lvert e\rvert \le 8u$이고 나머지는 $2^{-101}$ 아래예요.
3. $\sqrt{h} = \lVert(\sin(\Delta\varphi/2),\ \sqrt{\cos\varphi_1\cos\varphi_2}\,\sin(\Delta\lambda/2))\rVert$이고 $h$의 두 항이 모두 음이 아니에요. 성분마다의 상대오차(첫 성분 $3u$, 둘째 성분 $5.5u$)가 합과 $\sqrt{\cdot}$의 반올림을 거쳐 그대로 노름의 상대오차가 되어 $\lvert\mathrm{fl}(\sqrt{\hat h}) - \sqrt{h}\rvert \le 9.5u\sqrt{h} + 2^{-101}$이에요.
4. $\arcsin$의 기울기는 $\sqrt{1/2}$ 둘레까지 1.415 이하이고 $\arcsin x \ge x$예요. 그래서 $\sqrt{h}$의 상대오차가 $\arcsin$ 값의 상대오차를 1.415배 넘게 키우지 않아요. $\arcsin$ 자신의 $2u$와 그 반올림을 더하고 2배(정확)를 하면 $\lvert\hat d - d\rvert \le 16u\,d + 2^{-99}$예요.
5. $h \lt 2^{-968}$은 $2^{600}$배의 정확한 비율로 다시 구하므로 언더플로의 몫이 없어요. $h \ge 2^{-968}$에서 언더플로하는 항은 상대 $2^{-106}$ 아래예요.

먼 갈래($\hat h \gt 1/2$이라 $d \ge \pi/2 - O(u)$)는 절대오차로 봐요. $\sqrt{g} = \lVert(\cos(\Delta\varphi/2)\cos(\Delta\lambda/2),\ \sin(S/2)\sin(\Delta\lambda/2))\rVert$의 성분마다 $\widehat{\Delta\varphi}$와 $\hat S$의 반올림($\pi u$ 안)이 기울기 $1/2$로, libm이 $2u$, 곱이 $u$만큼 들어가 절대오차가 $7.6u$ 안이에요. 그래서 $\lvert\mathrm{fl}(\sqrt{\hat g}) - \sqrt{g}\rvert \le 12.6u$이고, $\arcsin$의 기울기 1.415, $\mathrm{fl}(\pi)$의 $0.55u$, 마지막 뺄셈의 $\pi u$를 더하면 $\lvert\hat d - d\rvert \le 43u$예요. ∎

이 영역이 `haversine`에 거는 정확도 계약은 $20u\,d$이고, Arb(구간 산술)로 만든 참값과 견준 최대는 그 계약 안이에요([정확도와 성능](/internals/spatial/accuracy-performance/)). 보조정리 H의 한계는 계약과 모양이 달라요. 가까운 갈래에서는 $d$가 $10^{-14}$보다 크면 계약보다 조이고, 먼 갈래에서는 $d \lt 2.15$일 때 계약보다 넉넉해요. 아래의 여유는 시험으로 지키는 계약이 아니라 가정 L만으로 증명되는 이 한계를 다시 네 배로 잡아 써요.

## 현과 중심각

단위 구 위의 점 $P(\varphi, \lambda) = (\cos\varphi\cos\lambda, \cos\varphi\sin\lambda, \sin\varphi)$로 옮기면 두 점의 현 $C = \lVert P(x) - P(y) \rVert$는

$$
C^2 = 2 - 2\,P(x)\cdot P(y) = 2 - 2(\cos\varphi_1\cos\varphi_2\cos\Delta\lambda + \sin\varphi_1\sin\varphi_2) = 4h
$$

예요(마지막 등호는 haversine 공식을 유도한 것과 같은 계산이에요). 그래서 $C = 2\sqrt{h} = 2\sin(d/2)$, $d = 2\arcsin(C/2)$이고, $d \in [0, \pi]$에서 $C$는 $d$의 늘어나는 함수예요. 이 항등식은 모든 실수 $\varphi, \lambda$에서 서요. 경도가 $2\pi$ 다른 두 표현은 같은 $P$로 가니 날짜 변경선도 저절로 이어져요. 정확한 산술이면 현으로 고른 $k$개가 중심각으로 고른 $k$개와 같다는 뜻이에요.

## 반올림 뒤의 어긋남

계산한 값에서는 현의 순서와 `haversine`의 순서가 어긋날 수 있어요. 오차의 출처는 셋이에요.

- **(H) `haversine` 커널.** 보조정리 H의 $\lvert\hat d - d\rvert \le 2^{-46}(1 + d)$예요.
- **(P) 옮기기.** $\hat P$의 성분마다 libm 값 하나나 둘과 곱 하나라 $\lvert\hat P_i - P_i\rvert \le (1 + 2u)^2(1 + u) - 1 \le 5.1u$이고 $\lVert\hat P - P\rVert \le 7.5u$예요.
- **(E) 3차원 `euclidean` 커널.** 깊이 3의 합이라 $\lvert\hat b - D\rvert \le \kappa D + 2^{-1074}$, $\kappa = \gamma_6/2 + u$예요.

옮기기는 `XA`와 `XB`의 행마다 한 번 해요. 트리의 점은 사인·코사인을 한 번에 구하는 `sincos`로, `haversine`에 넘기는 $\cos\varphi$는 `cdist`가 쓰는 `std::cos`로 따로 구해요. 앞의 것은 오차 (P)에만 들어가고, 뒤의 것은 거리의 비트를 `cdist`와 같게 해요.

```cpp
    // csrc/spatial/sphere.cpp
    run_tasks(chunks, split, [&](int64_t c) {
        for (int64_t i = c * kRowChunk, e = std::min(s.rows, (c + 1) * kRowChunk); i < e; ++i) {
            const double f = s.geo[2 * i], l = s.geo[2 * i + 1];
            if (!(std::fabs(f) <= kLatMax && std::fabs(l) <= kLonMax)) ok[static_cast<size_t>(c)] = 0;
            s.cosv[static_cast<size_t>(i)] = std::cos(f);
            const SinCos a = sincos(f), b = sincos(l);
            double* p = s.pts.data() + 3 * i;
            p[0] = a.c * b.c;
            p[1] = a.c * b.s;
            p[2] = a.s;
        }
    });
```

## 여유의 정리

점이 이겨야 하는 거리를 $T$라 할 때(kNN에서 힙이 덜 찼으면 상한, 찼으면 맨 위의 거리, 반경 질의에서는 $r$) 3차원의 문턱은

$$
t = \mathrm{fl}\bigl(\mathrm{fl}(T\cdot c) + 2^{-42}\bigr),\qquad
\mathrm{cut}(T) = \mathrm{fl}\Bigl(\mathrm{fl}\bigl(2\,\widehat{\sin}(t/2)\cdot c\bigr) + 2^{-46}\Bigr),\qquad c = 1 + 2^{-41}
$$

이고, $t \ge 3.14$이거나 $T = \infty$면 $\mathrm{cut}(T) = \infty$예요.

```cpp
// csrc/spatial/sphere.cpp
// The threshold a 3-D bound must exceed so that every point behind it has d^ > T (the top of this file).
inline double sphere_cut(double T) {
    constexpr double c = 1.0 + 0x1p-41;
    const double t = T * c + 0x1p-42;
    if (!(t < 3.14)) return kInf;
    return (2.0 * std::sin(t * 0.5)) * c + 0x1p-46;
}
```

상수는 증명한 오차를 모두 네 배 넘게 잡아요. 커널은 $2^{-46}$ 대신 $2^{-44}$, 옮기기는 $7.5u$ 대신 $2^{-48}$이에요. 그래서 libm의 sin·cos·asin이 가정 L보다 네 배 나빠도 증명이 서요.

**정리 4(단위 구의 여유).** $\hat d(x, y) \le T$이면, $\hat P(y)$를 담는 모든 상자(점 하나도 폭 0의 상자로 봐요)에서 $\hat P(x)$까지의 한계 $\hat b$는 $\mathrm{cut}(T)$ 이하예요. 거꾸로 말해 $\hat b \gt \mathrm{cut}(T)$인 노드와 점의 모든 $y$는 $\hat d \gt T$예요.

*증명.*

1. 보조정리 H를 네 배로 잡은 $\lvert\hat d - d\rvert \le 2^{-44}(1 + d)$와 $\hat d \le T$에서 $d \le T' = (T + 2^{-44})/(1 - 2^{-44}) \le T(1 + 2^{-43}) + 2^{-43}$이에요.
2. $\mathrm{fl}(T c) \ge Tc(1 - u) - 2^{-1075}$이고, $2^{-41} - 2u \ge 2^{-43}$, $2^{-42}(1 - u) \ge 2^{-43}$이라 $T' \le t$예요. 곧 $d \le t$예요.
3. $t \lt 3.14 \lt \pi$면 $d/2 \le t/2 \lt \pi/2$이고 $\sin$은 $[0, \pi/2]$에서 늘어나니 $C = 2\sin(d/2) \le 2\sin(t/2)$예요.
4. 옮기기 오차를 점마다 $2^{-48}$로 잡으면 $\lVert\hat P(x) - \hat P(y)\rVert \le C + 2^{-47}$이에요.
5. 상자에서 $\hat P(x)$에 가장 가까운 점은 $\hat P(y)$보다 멀지 않아요([상자 보조정리](/internals/spatial/kdtree/)). 3차원 커널의 계약으로 $\hat b \le (1 + \kappa)(2\sin(t/2) + 2^{-47}) + 2^{-1074}$이에요.
6. 계산한 $\sin$이 상대 $2^{-44}$ 안이면 $\mathrm{fl}(2\hat s\, c)(1 - u) \ge 2\sin(t/2)(1 - 2^{-44})(1 + 2^{-41})(1 - u)^2 \ge 2\sin(t/2)(1 + 2^{-42})$이고, $\kappa \approx 4u$는 $2^{-42}$보다 훨씬 작아 $(1 + \kappa)$배를 덮어요. 마지막 덧셈의 $2^{-46}(1 - u)$는 $(1 + \kappa)2^{-47} + 2^{-1074}$을 덮어요. 그래서 $\hat b \le \mathrm{cut}(T)$예요. ∎

친 노드의 점은 모두 $\hat d \gt T$로 **엄격히** 멀어서, 같은 $\hat d$에 색인이 작은 동점도 빠지지 않아요. 여유는 작은 $T$에서 단위 구 위 $2.4 \times 10^{-13}$ 남짓이에요. 지구 반지름 6371 km를 곱하면 2 µm가 안 되니, 여유 때문에 `haversine`을 더 계산하는 점은 거의 없어요.

```python
>>> c = 1 + 2**-41
>>> for T in (1e-6, 1e-3, 1.0):
...     t = T * c + 2**-42
...     print(T, (2 * math.sin(t / 2)) * c + 2**-46 - 2 * math.sin(T / 2))
```

## 찾기

트리는 `XB`의 $\hat P$로 만든 보통의 `KdTree`이고(`kd_build` 그대로), 잎 순서 자리마다 원래의 (위도, 경도, cos 위도)를 따로 쥐어 잎의 점과 `haversine`을 잴 때 이어 읽어요. kNN의 걸음은 [`KdSearch`](/internals/spatial/queries/)와 같고 다른 것은 셋이에요.

- 노드의 한계는 3차원 `euclidean` 커널의 거리이고 문턱은 `KdCut` 대신 `cut(T)`예요. 제곱합 지름길도 그대로 써서 합이 보통 범위이고 $\mathrm{above}(\mathrm{cut}(T))$보다 크면 $\sqrt{\cdot}$ 없이 쳐요.
- $\mathrm{cut}(T)$는 $\sin$ 하나가 들어 비싸요. $T$는 힙의 맨 위가 바뀔 때만 바뀌니 그때만 다시 구해 둬요(`retarget`).
- 잎의 점은 3차원 제곱합으로 먼저 거르고, 남은 점만 원래 행으로 `haversine_pair`를 불러 $(\hat d, j)$로 힙에 넣어요. 점 하나를 폭 0의 상자로 보면 이 거르기도 정리 4 그대로예요.

```cpp
    // csrc/spatial/sphere.cpp
    // T: the distance a point must beat; T1, above: its cut and the cut's squared-sum test (cached: the
    // cut takes a sine, and T only moves when the heap's top does).
    void retarget() {
        T_ = static_cast<int64_t>(heap_.size()) < k_ ? ub_ : heap_.front().first;
        T1_ = sphere_cut(T_);
        above_ = KdEuclid::above(T1_);
    }

    void offer(int64_t i) {
        const double* y = t_.data.data() + 3 * i;
        const double s = e_.raw(q_.p, y);
        if (KdEuclid::plain(s) && s > above_) return;  // d^ > T: neither below ub nor before the top
        const double* gy = g_.geo.data() + 3 * i;
        const std::pair<double, int64_t> e{
            haversine_pair(q_.f, q_.l, q_.c, gy[0], gy[1], gy[2]), t_.idx[static_cast<size_t>(i)]
        };
        if (static_cast<int64_t>(heap_.size()) < k_) {
            if (!(e.first < ub_)) return;
            heap_.push_back(e);
            std::push_heap(heap_.begin(), heap_.end());
            if (static_cast<int64_t>(heap_.size()) == k_) retarget();
        } else if (e < heap_.front()) {
            std::pop_heap(heap_.begin(), heap_.end());
            heap_.back() = e;
            std::push_heap(heap_.begin(), heap_.end());
            if (heap_.front().first != T_) retarget();
        }
    }
```

`haversine_pair`는 `cdist`가 부르는 것과 같은 인자 순서($x$가 `XA`의 행, $y$가 `XB`의 행)로 불러서 거리가 `cdist`의 그 원소와 같은 비트예요.

반경 질의(`Within`)는 $T = r$로 고정이라 cut을 한 번만 구해요. 노드마다 3차원 한계로 치고, 잎의 점은 제곱합으로 거른 뒤 $\hat d \le r$로 넣어요.

```cpp
    // csrc/spatial/sphere.cpp
    void visit(int64_t node) {
        const double s = b_.sum(q_.p, node);
        if (b_.beyond(s, q_.p, T1_, above_)) return;
        const KdNode& nd = t_.nodes[static_cast<size_t>(node)];
        if (nd.right >= 0) {
            visit(node + 1);
            visit(nd.right);
            return;
        }
        for (int64_t i = nd.start; i < nd.end; ++i) {
            const double sy = e_.raw(q_.p, t_.data.data() + 3 * i);
            if (KdEuclid::plain(sy) && sy > above_) continue;  // d^ > r
            const double* gy = g_.geo.data() + 3 * i;
            const double d = haversine_pair(q_.f, q_.l, q_.c, gy[0], gy[1], gy[2]);
            if (!(d <= r_)) continue;
            ++count_;
            if (out_) out_->push_back({t_.idx[static_cast<size_t>(i)], d});
        }
    }
```

`return_length=True`도 잎에서 하나씩 세요. 평면의 반경 질의처럼 먼 한계로 노드를 통째로 세려면 "현이 이만큼 작으면 `haversine`도 $r$ 이하"라는 반대 방향의 여유를 따로 증명해야 해서, 이 길에는 그 지름길이 없어요.

모양이 맞으면 트리 길의 답은 `cdist`를 (거리, 색인)으로 정렬한 것과 같아요. 아래는 구 위에 고르게 뿌린 점에서 $m_A = 64$, $m_B = 2000$, $k = 5$라 트리 길을 타요.

```python
>>> rng = sd.random.default_rng(4)
>>> def sphere_points(n):
...     return sd.stack([sd.asin(2 * rng.random(n) - 1), math.pi * (2 * rng.random(n) - 1)], axis=1)
>>> XA, XB = sphere_points(64), sphere_points(2000)
>>> res = S.kneighbors(XA, XB, k=5, metric="haversine")
>>> D = S.cdist(XA, XB, metric="haversine")
>>> order = sd.argsort(D, axis=1, stable=True)[:, :5]
>>> bool(sd.all(order == res.indices))
True
>>> bool(sd.all(sd.take_along_axis(D, order, axis=1) == res.distances))
True
```

안정 정렬은 같은 거리에서 열 번호가 작은 쪽을 먼저 두니 (거리, 색인)의 순서예요.

## 정의역을 벗어나면 전수로

여유의 증명은 정의역 $\lvert\varphi\rvert \le \mathrm{fl}(\pi/2)$, $\lvert\lambda\rvert \le 8$에서만 서요. 위도가 그보다 크면 위도 차의 반이 $\pi/2$를 넘어 보조정리 H의 1번 걸음($a\cot a \le 1$)이 무너지고, 경도가 크면 날짜 변경선 보정의 2차 항($\lvert e\rvert$에 비례)과 먼 갈래의 $\varphi_1 + \varphi_2$ 반올림이 입력의 크기와 함께 커져요. 그래서 옮기기를 하면서 모든 행을 검사하고, 하나라도 벗어나면 네이티브 함수가 `None`을 돌려 전수(`cdist`의 구동기로 블록마다 거리를 구해 고르는 길)가 답해요.

이 정의역은 흔히 쓰는 경도 범위 $[-\pi, \pi]$, $[0, 2\pi)$, $[-2\pi, 2\pi]$를 모두 담아요. 도 단위를 라디안으로 잘못 준 자료는 대개 정의역을 벗어나 전수로 가요. 답은 같고 느릴 뿐이에요.

```python
>>> deg = 180 / math.pi
>>> res_deg = S.kneighbors(XA * deg, XB * deg, k=3, metric="haversine")
>>> D_deg = S.cdist(XA * deg, XB * deg, metric="haversine")
>>> bool(sd.all(sd.argsort(D_deg, axis=1, stable=True)[:, :3] == res_deg.indices))
True
```

## 시험과 정확도

트리 길의 테스트는 결과를 전수와 색인·거리·`indptr`의 바이트까지 견줘요. 자료는 여유가 실제로 일을 하는 곳에 둬요. 퍼짐 $10^{-15}$–$10^{-6}$의 거의 같은 점과 중복, 좌표의 마지막 비트만 다른 점, 대척점에서 $10^{-14}$–$10^{-3}$ 비킨 점과 $\pi$ 바로 아래의 반경, 극(위도 $\pm\mathrm{fl}(\pi/2)$, 경도 $-8$–$8$), 날짜 변경선, 거울상이라 거리가 정확히 같은 동점, 계산한 거리와 그 앞뒤 double을 반경으로 준 1 ULP 껍질, 정의역 밖의 점, 그리고 극과 날짜 변경선 둘레에 무작위 군집을 만드는 hypothesis 시험이에요. 1, 3, 10스레드의 결과도 같아야 해요. cut의 여유를 지우고 상대 $2^{-50}$만큼 줄이면 이 시험 열 가운데 여섯이 실패해요. 여유가 장식이 아니라는 뜻이에요.

Arb(구간 산술)로 만든 참값에서는 단위 구 위의 점 집합 여섯(균등, 거의 같은 점의 군집, 대척점, 극, 날짜 변경선, 거울상의 동점)에서 돌려준 $k = 5$ 이웃이 계약 $20u$ 안의 참 이웃인지를 재요. 정확도 기준선에서 그 최대는 계약의 0.096이에요([정확도와 성능](/internals/spatial/accuracy-performance/)).
