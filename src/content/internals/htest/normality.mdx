## 한눈에 보기

네 검정은 모두 표본의 왜도와 첨도를 봐요. 정규분포는 왜도 0, 첨도 3이에요.

| 검정 | 통계량 | 귀무분포 | 최소 크기 |
|---|---|---|---|
| `skewtest` | 표본 왜도 √b₁의 정규화 변환 Z (D'Agostino 1970) | 표준 정규 | 8 |
| `kurtosistest` | 표본 첨도 b₂의 정규화 변환 Z (Anscombe와 Glynn 1983) | 표준 정규 | 5 |
| `normaltest` | K² = Z_skew² + Z_kurt² (D'Agostino와 Pearson 1973) | 자유도 2의 카이제곱 | 8 |
| `jarque_bera` | JB = n/6·(S² + (K − 3)²/4) | 자유도 2의 카이제곱 | |

D'Agostino의 셋은 커널 함수 `dagostino`(`kind` 0, 1, 2), Jarque–Bera는 `jarque_bera`이고(`csrc/htest/gof.cpp`), 넷 모두 같은 중심 적률의 합을 써요. 크기가 모자라거나 분산이 0(sd.stats `skew`의 규칙)이면 NaN이에요.

## 중심 적률의 합

`csrc/htest/normality.hpp`의 `central_sums`가 평균 m과 Σd², Σd³, Σd⁴(d = x − m)를 double-double로 만들어요. 먼저 합으로 double-double 평균을 만들고, 원소마다 d = x − m을 double-double로 뺀 뒤 그 거듭제곱을 double-double로 곱해 더해요. 아래의 `at(t)`는 원소 t를 단위로 옮긴 값이에요(다음 절).

```cpp
    // csrc/htest/normality.hpp
    auto sums234 = [&](std::int64_t c) {
        const std::int64_t t0 = c * kSumChunk, t1 = std::min(m, t0 + kSumChunk);
        DD a2{0.0, 0.0}, a3{0.0, 0.0}, a4{0.0, 0.0};
        for (std::int64_t t = t0; t < t1; ++t) {
            const DD d = DD{at(t), 0.0} - mean;
            const DD d2 = d * d;
            a2 = a2 + d2;
            a3 = a3 + d2 * d;
            a4 = a4 + d2 * d2;
        }
        part[c * 8 + 0] = a2.hi, part[c * 8 + 1] = a2.lo, part[c * 8 + 2] = a3.hi, part[c * 8 + 3] = a3.lo;
        part[c * 8 + 4] = a4.hi, part[c * 8 + 5] = a4.lo;
    };
```

덩어리는 4096원소이고 덩어리마다의 합을 덩어리 순서로 더해요. 꽉 찬 덩어리 둘은 NEON 레지스터의 두 칸에서 함께 계산하는데, 칸마다 이 스칼라 고리와 같은 연산을 같은 순서로 해서 비트가 같아요([줄과 병렬](/internals/htest/lanes/#neon의-double-double-합)).

Σd³처럼 부호가 섞인 합은 거의 대칭인 표본에서 크게 지워져요. 평균을 double로 반올림하면 d마다 평균의 반올림 오차 ε_m이 들어가고, Σd³에는 3ε_m·Σd²가 남아요. 오프셋 10⁸의 표본이면 ε_m이 10⁻⁸쯤이라 작은 왜도를 덮어요. double-double 평균과 편차에서는 이 오차가 10⁻²⁴ 크기로 줄어요.

### 척도와 상관없는 합

Σd⁴는 값의 네제곱이라 |x|가 10⁷⁷쯤을 넘으면 넘쳐 inf가 되고, 아주 작은 값에서는 서브노멀로 내려가 자릿수를 잃어요. 그래서 줄의 가장 큰 |x|가 2¹²⁰ 위이거나 2⁻¹²⁰ 아래이면, 그 지수 e로 모든 값에 2⁻ᵉ를 곱한 단위에서 합해요. 단위에서 가장 큰 값은 [1, 2)에 있어서 네제곱도 넘치지 않아요.

```cpp
// csrc/htest/normality.hpp
inline int scale_exponent(const double* x, std::int64_t m) {
    double big = 0.0;
    for (std::int64_t t = 0; t < m; ++t) big = std::max(big, std::fabs(x[t]));
    if (!(big > 0.0) || !std::isfinite(big)) return 0;
    const int e = std::ilogb(big);
    return (e > 120 || e < -120) ? e : 0;
}
```

2의 거듭제곱을 곱하는 것은 정확하고, double-double의 모든 걸음(더하기, 곱하기, 오차항)도 2의 거듭제곱 배만큼 정확히 옮겨져요. 합에서 만드는 왜도와 첨도는 같은 차수의 비(m₃/m₂^(3/2), m₄/m₂²)라서 단위를 되돌릴 필요도 없어요. 그래서 2의 거듭제곱을 곱한 표본은 원래 표본과 통계량·p값이 비트까지 같고, 범위 안의 줄은 단위로 옮기지 않으니 원래의 비트 그대로예요. |e|가 1020을 넘으면 2⁻ᵉ가 double을 벗어나므로 두 번에 나눠 곱해요.

```python
>>> import math
>>> u = [-3.0, -2.0, -1.5, -0.5, 0.0, 0.5, 1.7, 2.0, 3.0, 4.1]
>>> v = [math.ldexp(t, 900) for t in u]
>>> sd.htest.kurtosistest(v).statistic == sd.htest.kurtosistest(u).statistic
True
>>> w = [math.ldexp(t, -1000) for t in u]
>>> sd.htest.jarque_bera(w).pvalue == sd.htest.jarque_bera(u).pvalue
True
```

## skewtest: D'Agostino의 변환

표본 왜도 √b₁ = m₃/m₂^(3/2)(적률은 n으로 나눠요)는 정규 표본에서 평균 0이지만 분포가 정규보다 꼬리가 두꺼워요. D'Agostino(1970)는 Johnson의 S_U 꼴 변환으로 표준 정규에 가깝게 만들었어요.

Y = √b₁·√((n + 1)(n + 3)/(6(n − 2)))

β₂ = 3(n² + 27n − 70)(n + 1)(n + 3) / ((n − 2)(n + 5)(n + 7)(n + 9)), W² = −1 + √(2(β₂ − 1))

δ = 1/√(log W), α = √(2/(W² − 1)), Z = δ·log(Y/α + √((Y/α)² + 1))

Y는 √b₁을 표준화한 값이고 β₂는 √b₁의 첨도예요. 고친 곳은 둘이에요.

- **Z = δ·asinh(Y/α)**: log(y + √(y² + 1))은 asinh(y)인데, y < 0이면 y와 √(y² + 1)이 거의 지워져 상대오차가 커져요. `asinh`는 부호에 대칭으로 계산해요.
- **W² − 1**: W² − 1 = √(2(β₂ − 1)) − 2는 β₂가 3에 가까울 때(큰 n) 상쇄돼요. 분자를 유리화하면 W² − 1 = 2(β₂ − 3)/(√(2(β₂ − 1)) + 2)이고, β₂ − 3을 정리한 식 36(n³ − 5n² − 19n + 35)/((n − 2)(n + 5)(n + 7)(n + 9))로 직접 계산해요. log W도 ½·log1p(W² − 1)이에요.

```cpp
// csrc/htest/gof.cpp
double skewtest_z(double n, double b) {
    const double y = b * std::sqrt((n + 1.0) * (n + 3.0) / (6.0 * (n - 2.0)));
    // beta2 - 3 = 36 (n^3 - 5n^2 - 19n + 35) / ((n - 2)(n + 5)(n + 7)(n + 9)): W^2 - 1 without the
    // cancellation of -1 + sqrt(2 (beta2 - 1)) against 1
    const double b3 = 36.0 * (((n - 5.0) * n - 19.0) * n + 35.0) / ((n - 2.0) * (n + 5.0) * (n + 7.0) * (n + 9.0));
    const double w2m1 = 2.0 * b3 / (std::sqrt(2.0 * (b3 + 2.0)) + 2.0);  // W^2 - 1
    const double delta = 1.0 / std::sqrt(0.5 * std::log1p(w2m1));
    const double alpha = std::sqrt(2.0 / w2m1);
    return delta * std::asinh(y / alpha);
}
```

scipy 1.18.1은 y = 0이면 log 0을 피하려고 y를 1로 바꾸는데, 이 바꿈이 그대로 Z에 들어가서 왜도가 정확히 0인 표본에서 0이 아닌 Z를 내요. 여기서는 asinh(0) = 0이라 Z = 0, p = 1이에요.

```python
>>> import stardust as sd
>>> import scipy.stats as ss
>>> x = [-3.0, -2.0, -1.5, -0.5, 0.0, 0.5, 1.5, 2.0, 3.0]
>>> sd.stats.skew(x)
0.0
>>> sd.htest.skewtest(x)
SkewtestResult(statistic=0, pvalue=1)
>>> float(ss.skewtest(x).statistic)
1.018464355396213
```

## kurtosistest: Anscombe와 Glynn의 변환

표본 첨도 b₂ = m₄/m₂²의 평균과 분산은 정규 표본에서

E = 3(n − 1)/(n + 1), Var = 24n(n − 2)(n − 3)/((n + 1)²(n + 3)(n + 5))

이에요. x = (b₂ − E)/√Var로 표준화해도 b₂의 분포는 많이 기울어 있어서, Anscombe와 Glynn(1983)은 b₂의 왜도 √β₁(b₂)에서 A를 정하고 Wilson–Hilferty식 세제곱근 변환을 써요.

A = 6 + (8/√β₁)·(2/√β₁ + √(1 + 4/β₁))

Z = [(1 − 2/(9A)) − ((1 − 2/A)/(1 + x·√(2/(A − 4))))^(1/3)] / √(2/(9A))

두 곳이 상쇄돼요. 첫째는 b₂ − E로, 정규에 가까운 표본은 b₂가 E에 가까워요. 그래서 b₂를 double-double(Σd⁴·n/(Σd²)²)로 만들고 double-double E를 빼요.

둘째는 대괄호 안의 차예요. term₁ = 1 − t(t = 2/(9A))와 term₂ = (…)^(1/3)는 1에 가까운 두 값이라 Z가 0 근처일 때 지워져요. 세제곱의 차로 바꿔요.

term₁ − term₂ = (term₁³ − term₂³) / (term₁² + term₁·term₂ + term₂²)

term₂³ = (1 − 2/A)/(1 + xc)이고 1 − 2/A = 1 − 9t이니, (1 + xc)를 곱한 분자는

term₁³(1 + xc) − (1 − 9t) = 6t + 3t² − t³ + term₁³·x·c

예요. (1 − t)³ = 1 − 3t + 3t² − t³에서 1이 정확히 빠졌어요. 남은 항은 t의 크기이거나 x에 비례해서, Z가 0을 지날 때(x ≈ 0) 상쇄 없이 작아져요.

```cpp
    // csrc/htest/gof.cpp
    const double term1 = 1.0 - t;
    const double term2 = std::cbrt((1.0 - 2.0 / A) / denom);
    const double t13 = term1 * term1 * term1;
    // term1^3 (1 + x c) - (1 - 9t) = 6t + 3t^2 - t^3 + term1^3 x c
    const double num = ((6.0 + 3.0 * t - t * t) * t + t13 * x * c) / denom;
    const double diff13 = num / (term1 * term1 + term1 * term2 + term2 * term2);
    return diff13 / std::sqrt(t);
```

Z가 0을 지나는 곳에서 Z의 상대오차는 결국 b₂에 대한 조건수만큼 커요. b₂의 작은 상대오차가 0에 가까운 Z에서는 큰 상대오차가 되는 것이고, 이것은 식을 어떻게 써도 남는 문제의 성질이에요. 정확도 계약도 그 조건수를 넣은 꼴이에요.

1 + xc ≤ 0이면 세제곱근의 인자가 정의되지 않아서(아주 작은 b₂) Z는 NaN이에요.

## normaltest

K² = Z_skew² + Z_kurt²이고 p값은 `ChiSquared(df=2).ccdf(K²)`예요. 같은 줄의 적률로 두 Z를 한 번에 계산해요. 위의 대칭 표본에서는 Z_skew가 0이라 K²는 첨도의 Z²뿐이에요.

```python
>>> sd.htest.normaltest(x)
NormaltestResult(statistic=0.383742, pvalue=0.825413)
>>> sd.htest.normaltest(x).statistic == sd.htest.kurtosistest(x).statistic**2
True
```

## Jarque–Bera

JB = n/6·(S² + (K − 3)²/4)이고 S = m₃/m₂^(3/2), K = m₄/m₂², 적률은 n으로 나눠요. p값은 `ChiSquared(df=2).ccdf(JB)`예요. 닫힌 꼴 e^(−JB/2)와 수학적으로 같지만 sd.stats의 함수를 불러서 다른 p값과 같은 길을 지나요.

```cpp
// csrc/htest/normality.hpp
inline JarqueBera jarque_bera_of(double n, double s2, double s3, double s4, double mean) {
    constexpr double kNaN = std::numeric_limits<double>::quiet_NaN();
    const double mu2 = s2 / n;
    if (zero_variance(mu2, mean)) return {kNaN, kNaN};
    const double skew = (s3 / n) / (mu2 * std::sqrt(mu2));
    const double kurt = (s4 / n) / (mu2 * mu2);
    const double ek = kurt - 3.0;
    const double jb = n / 6.0 * (skew * skew + ek * ek / 4.0);
    return {jb, stats::method_of<stats::ChiSquared, stats::method::Ccdf>(jb, 2.0)};
}
```

이 함수는 합의 double 값(높은 부분)을 받아요. sd.regression의 `r.jarque_bera()`가 잔차에서 같은 `central_sums`를 불러 같은 네 값을 넘기기 때문이에요. 그래서 OLS의 `r.jarque_bera()`와 `sd.htest.jarque_bera(r.resid)`가 비트까지 같아요([영역의 구조](/internals/htest/overview/)). 잔차가 10⁸⁰ 크기여서 합이 단위의 값으로 넘어와도, JB는 같은 차수의 비라 그대로 같아요. K − 3도 double 뺄셈이지만, JB에서 (K − 3)²/4는 S²과 더해지는 양수 항이라 K − 3의 절대오차(K의 반올림 크기)가 결과에 주는 영향은 작아요.

D'Agostino 24문제의 통계량은 Arb 참값에 대해 최대 상대 5.1 × 10⁻¹⁶이고, 계약 대비는 0.029예요(통계량은 변환이 받는 적률에 대한 조건수를, p값은 거기에 p값의 조건수를 더 곱한 계약이에요). Jarque–Bera는 오프셋 10⁸의 표본에서 상대 2.3 × 10⁻¹⁵(계약 대비 0.23)예요. scipy 열의 큰 값에는 대칭 표본(왜도 0)에서 y = 0을 1로 바꾼 Z가 들어 있어요.

## scipy를 아는 분께

- 왜도가 정확히 0인 표본에서 `skewtest`는 Z = 0, p = 1이에요(scipy 1.18.1은 0이 아닌 Z).
- 크기가 모자라면(`skewtest`·`normaltest` n < 8, `kurtosistest` n < 5) 경고 없이 NaN이에요. scipy는 경고와 함께 NaN을 내요.
- 상수 표본은 NaN이에요(분산 0의 규칙은 sd.stats `skew`와 같아요).
- scipy는 적률을 그 크기 그대로 더해서, 위 `u`를 10⁸⁰배 하거나 10⁻¹⁰⁰배 한 표본의 `kurtosistest`·`jarque_bera`가 NaN이고 10⁻¹⁶⁰배에서는 `skewtest`도 NaN이에요. 여기서는 단위에서 합해 원래 표본과 같은 값을 내요(2의 거듭제곱 배가 아니면 각 값의 반올림만큼 달라요).
- 변환의 식과 `alternative`의 정의는 scipy와 같아요. 다른 것은 적률의 정밀도와 상쇄를 없앤 식의 모양뿐이에요.
