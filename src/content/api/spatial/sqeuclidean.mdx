## 한눈에 보기

`sqeuclidean`은 좌표마다 차이를 제곱해 더한 값이에요. [`euclidean`](/api/spatial/euclidean/)에서 마지막 제곱근만 뺀 것이라, (0, 0)과 (3, 4) 사이에서는 $3^2 + 4^2 = 25$예요.

```python
>>> import stardust as sd
>>> sd.spatial.sqeuclidean([0.0, 0.0], [3.0, 4.0])
25.0
```

## 무엇을 재나요

$$
d^2(u, v) = \sum_{i=1}^{n} (u_i - v_i)^2
$$

이름 그대로 유클리드 거리의 제곱(squared Euclidean)이에요. 통계와 기계 학습에는 거리보다 이 제곱합이 더 자주 나와요.

- **분산과 제곱합**: 점들이 평균에서 얼마나 퍼져 있는지는 평균까지의 제곱 거리의 합이에요.
- **k-평균 군집**: 각 점에서 자기 군집 중심까지의 제곱 거리 합을 줄이는 것이 목표예요.
- **가우스 커널**: 두 점의 닮은 정도 $e^{-d^2/(2\sigma^2)}$에 제곱 거리가 그대로 들어가요.
- **최소제곱**: 잔차의 제곱합이 예측과 관측 사이의 제곱 거리예요.

점 넷이 평균에서 퍼진 정도를 재 볼게요. 평균까지의 제곱 거리를 더한 값은 열마다의 분산(`correction=0`)을 더해 점의 수를 곱한 것과 같아요.

```python
>>> X = sd.asarray([[0.0, 0.0], [1.0, 0.0], [3.0, 0.0], [2.0, 2.0]])
>>> c = sd.mean(X, axis=0)
>>> sd.spatial.sqeuclidean(X, c)
array([2.5, 0.5, 2.5, 2.5], dtype=float64)
>>> sd.sum(sd.spatial.sqeuclidean(X, c)), 4 * sd.sum(sd.var(X, axis=0, correction=0))
(8.0, 8.0)
```

### 삼각 부등식은 성립하지 않아요

제곱하면 먼 거리가 더 크게 부풀어서, 엄밀한 뜻의 거리(metric)가 아니에요. 수직선 위의 0, 1, 2를 보면 0에서 2까지가 0에서 1을 거쳐 2로 가는 것보다 멀어요.

```python
>>> sd.spatial.sqeuclidean([0.0], [1.0]) + sd.spatial.sqeuclidean([1.0], [2.0])
2.0
>>> sd.spatial.sqeuclidean([0.0], [2.0])
4.0
```

그래서 거리의 성질을 모두 써야 하는 계산에는 [`euclidean`](/api/spatial/euclidean/)을 쓰세요. 거리의 크고 작음만 보는 일(가장 가까운 점 찾기, 거리로 정렬하기)에는 둘이 같은 답을 줘요.

## `euclidean`과의 관계

제곱근은 순서를 바꾸지 않으니, 어느 점이 더 가까운지는 `sqeuclidean`으로 견줘도 `euclidean`으로 견줘도 같아요. 이웃 찾기에서도 같은 이웃이 나오고 거리만 제곱이에요.

```python
>>> q = [[0.4, 0.3]]
>>> sd.spatial.kneighbors(q, X, k=3)
QueryResult(distances=array([[               0.5, 0.6708203932499369, 2.3345235059857505]], dtype=float64), indices=array([[0, 1, 3]], dtype=int64))
>>> sd.spatial.kneighbors(q, X, k=3, metric='sqeuclidean')
QueryResult(distances=array([[               0.25, 0.44999999999999996,                5.45]], dtype=float64), indices=array([[0, 1, 3]], dtype=int64))
```

드물게 아주 가까운 두 제곱합이 제곱근을 거친 뒤 같은 float64로 반올림될 수 있어요. 그러면 `euclidean`에서는 동점이 되어 색인이 작은 점이 먼저 오고, `sqeuclidean`에서는 제곱합이 작은 점이 먼저 와요.

보통 크기의 좌표에서는 `sqeuclidean`의 제곱근이 `euclidean`과 비트까지 같아요. 같은 제곱합에 제곱근을 씌운 것이 `euclidean`이기 때문이에요.

```python
>>> import math
>>> u, v = [0.3, 0.1, 0.7], [0.2, 0.9, 0.5]
>>> math.sqrt(sd.spatial.sqeuclidean(u, v)) == sd.spatial.euclidean(u, v)
True
```

## 넘침과 언더플로

`sqeuclidean`의 값은 거리의 제곱이라, 좌표가 $10^{154}$ 남짓을 넘으면 참값 자체가 float64의 최댓값 $1.8 \times 10^{308}$을 넘어요. 그때의 `inf`는 틀린 값이 아니라 담을 수 없는 참값을 나타낸 거예요. `euclidean`은 같은 짝에서 유한해요.

```python
>>> sd.spatial.sqeuclidean([1e154, 0.0], [0.0, 0.0])
1e+308
>>> sd.spatial.sqeuclidean([2e154, 0.0], [0.0, 0.0])
inf
>>> sd.spatial.euclidean([2e154, 0.0], [0.0, 0.0])
2e+154
```

반대로 아주 작은 차이는 제곱이 정상 범위 아래로 내려가도 크기를 맞춰 다시 계산하므로, 비정상 수(subnormal) 범위의 결과도 자릿수를 지켜요. 참값이 비정상 수의 가장 작은 값보다 작아지면 0이에요.

```python
>>> sd.spatial.sqeuclidean([1e-160, 0.0], [0.0, 0.0])
1e-320
>>> sd.spatial.sqeuclidean([1e-170, 0.0], [0.0, 0.0])
0.0
```

## 가중치 w

`w`를 주면 $\sum w_i (u_i - v_i)^2$예요. 가중 `euclidean`의 제곱이에요. 규칙은 다른 거리 함수와 같아서, 1차원, 길이 $n$, 유한하고 0 이상이어야 하고 키워드로만 받아요.

```python
>>> sd.spatial.sqeuclidean([0.0, 0.0], [3.0, 4.0], w=[4.0, 1.0])
52.0
```

## 배치, NaN, 빈 벡터

다른 거리 함수와 같아요. 마지막 축이 좌표이고 앞 축은 브로드캐스트돼요. NaN은 결과까지 퍼지고, 좌표가 0개면 0이에요.

```python
>>> sd.spatial.sqeuclidean(X, [0.0, 0.0])
array([0.0, 1.0, 9.0, 8.0], dtype=float64)
>>> sd.spatial.sqeuclidean([sd.nan], [0.0]), sd.spatial.sqeuclidean([], [])
(nan, 0.0)
```

점 집합의 모든 짝은 `metric='sqeuclidean'`으로 [`pdist`](/api/spatial/pdist/)나 [`cdist`](/api/spatial/cdist/)에서 구해요. 같은 짝은 `sqeuclidean(u, v)`와 비트까지 같아요.

```python
>>> sd.spatial.pdist(X, metric='sqeuclidean')
array([1.0, 9.0, 8.0, 4.0, 5.0, 5.0], dtype=float64)
```

## 정확도

상대오차는 좌표 수에 따라 정해지는 작은 한계 안이에요. 넘침과 언더플로가 걸리는 짝까지 넣은 시험 645짝에서 Arb(구간 산술)로 만든 참값과 견준 최대 오차는 3 ULP(한계의 0.68), 가중치를 주면 4 ULP(한계의 0.46)였어요.

## scipy·sklearn을 아는 분께

- 뜻과 `w`의 뜻은 `scipy.spatial.distance.sqeuclidean`과 같아요. `w`는 키워드로만 받고, NaN·inf 가중치는 `ValueError`예요.
- 결과가 정상 범위 아래로 내려가는 아주 작은 차이도 자릿수를 지켜요.
- sklearn의 `euclidean_distances(X, Y, squared=True)`는 `cdist(X, Y, metric='sqeuclidean')`예요. sklearn은 전개식 $\lVert x\rVert^2 + \lVert y\rVert^2 - 2x\cdot y$로 계산해 원점에서 먼 가까운 점들에서 자릿수를 잃지만, 이 라이브러리는 언제나 차이를 직접 제곱해 더해요.
- 복소수는 `TypeError`예요.
