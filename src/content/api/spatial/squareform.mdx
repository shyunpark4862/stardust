## 한눈에 보기

거리 행렬은 두 가지 꼴로 적을 수 있어요. 모든 칸을 담은 **정사각 행렬**과, 대각선 위 삼각형만 한 줄로 담은 **압축 꼴**이에요. [`pdist`](/api/spatial/pdist/)는 압축 꼴을 주고, `squareform`은 두 꼴을 오가요.

```python
>>> import stardust as sd
>>> y = sd.asarray([5.0, 10.0, 1.0, 5.0, 4.0, 9.0])
>>> M = sd.spatial.squareform(y)
>>> M
array([[ 0.0,  5.0, 10.0,  1.0],
       [ 5.0,  0.0,  5.0,  4.0],
       [10.0,  5.0,  0.0,  9.0],
       [ 1.0,  4.0,  9.0,  0.0]], dtype=float64)
>>> sd.spatial.squareform(M)
array([ 5.0, 10.0,  1.0,  5.0,  4.0,  9.0], dtype=float64)
```

길이 6인 압축 꼴은 점 네 개의 거리예요. 펼치면 대각선에 0을 채우고 위 삼각형과 아래 삼각형에 같은 값을 적은 4 × 4 행렬이 되고, 그 행렬을 다시 접으면 처음의 압축 꼴이에요.

## 방향은 입력의 차원으로

`force='no'`(기본값)이면 입력이 1차원일 때 펼치고, 2차원일 때 접어요. 방향을 못 박아 두고 싶으면 `force='tomatrix'`나 `force='tovector'`를 줘요. 그러면 반대 방향의 입력이 들어왔을 때 조용히 반대로 바꾸지 않고 `ValueError`를 내요.

```python
>>> sd.spatial.squareform(y, force="tomatrix").shape
(4, 4)
>>> sd.spatial.squareform(M, force="tomatrix")
Traceback (most recent call last):
    ...
ValueError: squareform(): force='tomatrix' needs a condensed vector, not a 2-D 'X'
```

## 펼치기: 압축 꼴에서 행렬로

압축 꼴의 길이는 점이 m개일 때 m(m − 1)/2예요. 길이에서 m을 거꾸로 구하므로, 그런 m이 없는 길이는 `ValueError`예요.

```python
>>> sd.spatial.squareform(sd.asarray([1.0, 2.0]))
Traceback (most recent call last):
    ...
ValueError: squareform(): the length of 'X' (2) is not d (d - 1) / 2 for any d
```

빈 압축 꼴은 점 하나의 거리 행렬, 곧 0 하나인 (1, 1) 행렬이에요.

```python
>>> sd.spatial.squareform(sd.asarray([], dtype=sd.float64))
array([[0.0]], dtype=float64)
```

펼친 행렬은 압축 꼴의 거의 두 배 메모리를 써요. 결과가 이 컴퓨터의 물리 메모리보다 크면 할당 전에 `MemoryError`예요.

## 접기: 행렬에서 압축 꼴로

`checks=True`(기본값)면 접기 전에 행렬이 거리 행렬답게 생겼는지 검사해요. 모든 i, j에서 M[i, j]와 M[j, i]가 **정확히** 같아야 하고, 대각선이 모두 0이어야 해요. 하나라도 어긋나면 `ValueError`예요.

```python
>>> sd.spatial.squareform(sd.asarray([[0.0, 1.0], [2.0, 0.0]]))
Traceback (most recent call last):
    ...
ValueError: squareform(): 'X' must be symmetric
>>> sd.spatial.squareform(sd.asarray([[1.0, 1.0], [1.0, 0.0]]))
Traceback (most recent call last):
    ...
ValueError: squareform(): 'X' must have a zero diagonal
```

NaN은 자기 자신과도 같지 않아서, 대각선 밖에 NaN이 있으면 대칭 검사를 통과하지 못해요. 이때는 메시지가 NaN 때문이라고 알려 줘요.

```python
>>> sd.spatial.squareform(sd.asarray([[0.0, sd.nan], [sd.nan, 0.0]]))
Traceback (most recent call last):
    ...
ValueError: squareform(): 'X' has NaN off the diagonal, so it is not symmetric
```

`checks=False`면 검사하지 않고 위 삼각형만 읽어요. 아래 삼각형과 대각선의 값은 보지 않아요. 행렬이 대칭인 것을 이미 알고 있고 검사 시간도 아끼고 싶을 때, 또는 반올림으로 아주 조금 어긋난 행렬을 위 삼각형 기준으로 접고 싶을 때 써요.

```python
>>> sd.spatial.squareform(sd.asarray([[0.0, 1.0], [2.0, 0.0]]), checks=False)
array([1.0], dtype=float64)
```

정사각이 아닌 행렬과 3차원 이상의 배열은 `checks`와 상관없이 `ValueError`예요. (1, 1) 행렬과 (0, 0) 행렬은 짝이 없으니 빈 압축 꼴이에요.

```python
>>> sd.spatial.squareform(sd.zeros((2, 3)))
Traceback (most recent call last):
    ...
ValueError: squareform(): 'X' must be square, not of shape (2, 3)
>>> sd.spatial.squareform(sd.zeros((1, 1)))
array([], dtype=float64)
```

## dtype을 지켜요

`squareform`은 거리를 계산하지 않고 값을 옮겨 적기만 해요. 그래서 float64로 바꾸지 않고 입력의 dtype(bool, int64, float64)을 그대로 지켜요. 펼칠 때 대각선은 그 dtype의 0(bool이면 `False`)이에요.

```python
>>> sd.spatial.squareform(sd.asarray([1, 2, 3]))
array([[0, 1, 2],
       [1, 0, 3],
       [2, 3, 0]], dtype=int64)
>>> sd.spatial.squareform(sd.asarray([True, False, True]))
array([[False,  True, False],
       [ True, False,  True],
       [False,  True, False]], dtype=bool)
```

bool의 압축 꼴은 "이 짝이 이웃인가"처럼 짝마다 예/아니오를 적은 것을 행렬로 볼 때 쓸모 있어요. 예를 들어 `pdist(X) <= r`을 펼치면 반경 r 안의 이웃 관계를 담은 인접 행렬이에요.

```python
>>> X = sd.asarray([[0.0, 0.0], [3.0, 4.0], [6.0, 8.0], [0.0, 1.0]])
>>> sd.spatial.squareform(sd.spatial.pdist(X) <= 5.0)
array([[False,  True, False,  True],
       [ True, False,  True,  True],
       [False,  True, False, False],
       [ True,  True, False, False]], dtype=bool)
```

## pdist와 함께 쓰기

`squareform(pdist(X))`는 [`cdist(X, X)`](/api/spatial/cdist/)와 비트까지 같아요. 펼치기와 접기는 값을 옮기기만 하므로 몇 번을 오가도 값이 바뀌지 않아요.

```python
>>> y = sd.spatial.pdist(X)
>>> bool(sd.all(sd.spatial.squareform(y) == sd.spatial.cdist(X, X)))
True
>>> bool(sd.all(sd.spatial.squareform(sd.spatial.squareform(y)) == y))
True
```

메모리가 빠듯하면 압축 꼴로 들고 다니다가 행렬이 꼭 필요한 곳에서만 펼치세요. 압축 꼴은 정사각 행렬의 반보다 조금 작아요.

## scipy를 아는 분께

- 동작은 scipy의 `squareform`과 같아요. 방향은 차원으로 정하고, `force`의 세 값, `checks`의 뜻, 빈 입력과 (1, 1)의 처리, dtype을 지키는 것이 모두 같아요.
- 대각선 밖의 NaN으로 대칭 검사에 걸리면 메시지가 NaN을 말해요. scipy는 "must be symmetric"뿐이에요.
- `force`, `checks`는 키워드로만 받아요.
- scipy의 `is_valid_dm`, `is_valid_y`, `num_obs_dm`, `num_obs_y`는 없어요. 검사는 `squareform` 안에 있어요. 점의 수는 행렬이면 `M.shape[0]`, 압축 꼴이면 `squareform(y).shape[0]`이나 길이 k에서 m = (1 + √(1 + 8k))/2예요.
