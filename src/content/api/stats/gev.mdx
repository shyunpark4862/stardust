하루 강수량을 1년 동안 재서 가장 큰 값 하나만 남기는 일을 여러 해 되풀이한다고 해 볼게요. 이렇게 모은 **기간별 최댓값**(block maxima)의 분포는, 원래 하루 강수량의 분포가 무엇이든, 기간이 충분히 길어질 때 (위치와 척도를 맞춘) 극한 모양이 있다면 딱 세 가지 중 하나로 모여요(Fisher–Tippett–Gnedenko 정리).

1. **위가 막힌 꼴**: 원래 값에 넘을 수 없는 상한이 있을 때(사람의 수명, 재료의 최대 강도). 최댓값도 그 상한을 넘지 못해요.
2. **Gumbel 꼴**: 원래 분포의 꼬리가 지수함수처럼 줄 때(정규, 지수, 감마).
3. **위꼬리가 두꺼운 꼴**: 원래 분포의 꼬리가 거듭제곱으로 줄 때(파레토, t, 보험 손해액, 금융 손실). 최댓값도 아주 큰 값이 꽤 자주 나와요.

**일반화 극값 분포**(GEV, generalized extreme value)는 이 셋을 모양 매개변수 `c` 하나로 묶은 분포예요. 자료가 어느 꼴인지 미리 알 필요 없이 GEV를 맞추고, 추정한 `c`의 부호로 꼴을 읽어요.

| `c` | 꼴 | 지지집합(`mu=0`, `sigma=1`) |
|---|---|---|
| `c > 0` | 위가 막힌 꼴(역 Weibull) | $(-\infty,\ 1/c]$ |
| `c = 0` | [Gumbel](/api/stats/gumbel/) | $(-\infty,\ \infty)$ |
| `c < 0` | 위꼬리가 두꺼운 꼴(Fréchet) | $[1/c,\ \infty)$ |

```python
>>> import stardust as sd
>>> sd.stats.GEV(c=0.5).support()
(-inf, 2.0)
>>> sd.stats.GEV(c=0.0).support()
(-inf, inf)
>>> sd.stats.GEV(c=-0.5).support()
(-2.0, inf)
```

## 만들기와 매개변수

- `c`: 모양. 기본값이 없어서 꼭 줘야 해요. 모든 유한한 실수를 받아요.
- `mu`: 위치. 기본값 0.
- `sigma`: 척도. 0보다 커야 하고, 기본값 1.

```python
>>> X = sd.stats.GEV(c=0.25, mu=1.0, sigma=2.0)
>>> X
GEV(c=0.25, mu=1.0, sigma=2.0)
>>> X.support()
(-inf, 9.0)
>>> sd.stats.GEV()
Traceback (most recent call last):
    ...
TypeError: GEV(): missing 1 required keyword-only argument: 'c'
```

막힌 끝은 $\mu + \sigma/c$예요. 위 예에서는 $1 + 2/0.25 = 9$예요. `c < 0`이면 같은 식이 아래 끝이 돼요.

매개변수는 배열이어도 되고, 서로, 그리고 입력과 브로드캐스트해요. 여러 `c`를 한 번에 비교할 때 편해요.

```python
>>> Y = sd.stats.GEV(c=sd.asarray([-0.5, 0.0, 0.5]))
>>> Y.support()
(array([-2.0, -inf, -inf], dtype=float64), array([inf, inf, 2.0], dtype=float64))
>>> Y.cdf(1.0)
array([0.6411803884299545, 0.6922006275553464, 0.7788007830714049], dtype=float64)
```

`sigma` ≤ 0이거나 매개변수 중 하나가 무한대·NaN이면 그 원소의 결과가 모두 NaN이에요.

```python
>>> sd.stats.GEV(c=0.5, sigma=0.0).cdf(1.0)
nan
>>> sd.stats.GEV(c=sd.inf).cdf(1.0)
nan
```

## 밀도와 누적분포

$z = (x - \mu)/\sigma$라고 두면, $1 - cz > 0$인 곳에서

$$
F(x) = \exp\!\left(-(1 - cz)^{1/c}\right), \qquad
f(x) = \frac{1}{\sigma}\,(1 - cz)^{1/c - 1}\exp\!\left(-(1 - cz)^{1/c}\right)
$$

이고, `c = 0`이면 $(1 - cz)^{1/c}$ 자리에 그 극한 $e^{-z}$가 들어가서 Gumbel의 $F(x) = \exp(-e^{-z})$가 돼요. 분위수는 닫힌 꼴이에요.

$$
F^{-1}(p) = \mu + \sigma\,\frac{1 - (-\log p)^{c}}{c} \qquad (c = 0\text{이면 } \mu - \sigma\log(-\log p))
$$

### c > 0: 위가 막혀요

`c = 0.5`이면 x = 2가 끝이에요. 그 위에서는 `cdf`가 1, `pdf`가 0이고, `icdf(1)`과 `iccdf(0)`이 그 끝이에요.

```python
>>> P = sd.stats.GEV(c=0.5)
>>> P.cdf(1.9), P.cdf(2.0), P.cdf(2.5)
(0.9975031223974601, 1.0, 1.0)
>>> P.ccdf(1.999)
2.4999996874994754e-07
>>> P.pdf(2.5), P.logpdf(2.5)
(0.0, -inf)
>>> P.icdf(1.0), P.iccdf(0.0)
(2.0, 2.0)
```

끝점에서 밀도가 어떻게 되는지는 `c`에 달렸어요. $c < 1$이면 0으로 줄고, $c = 1$이면 $1/\sigma$, $c > 1$이면 끝에서 무한대로 커져요.

```python
>>> sd.stats.GEV(c=0.5).pdf(2.0), sd.stats.GEV(c=1.0).pdf(1.0), sd.stats.GEV(c=2.0).pdf(0.5)
(0.0, 1.0, inf)
```

### c < 0: 아래가 막히고 위꼬리가 두꺼워요

`c = -0.5`이면 x = −2가 아래 끝이에요. 위꼬리는 $x^{1/c} = x^{-2}$처럼 거듭제곱으로 줄어서, x가 10배 커질 때 꼬리 확률이 100배만 작아져요. Gumbel의 지수 꼬리와 비교하면 아주 느려요.

```python
>>> Q = sd.stats.GEV(c=-0.5)
>>> Q.cdf(-2.0), Q.icdf(0.0)
(0.0, -2.0)
>>> Q.ccdf(1e10)
3.9999999984e-20
>>> Q.ccdf(1e11)
3.99999999984e-22
>>> Q.logccdf(1e300)
-1380.1647614353076
```

### c = 0: Gumbel과 같아요

`c = 0`이면 정확히 Gumbel 분포예요. 모든 메서드의 결과가 `Gumbel`과 비트까지 같아요.

```python
>>> G0 = sd.stats.GEV(c=0.0, mu=1.0, sigma=2.0)

>>> G0.pdf(3.0) == G.pdf(3.0), G0.icdf(0.99) == G.icdf(0.99), G0.mean() == G.mean()
```

## 요약값

$g_k = \Gamma(1 + kc)$($\Gamma$는 [감마 함수](/api/special/gamma/))라고 두면 이래요(`c = 0`이면 Gumbel의 값).

| 메서드 | 값 | 유한한 범위 |
|---|---|---|
| `mean()` | $\mu + \sigma(1 - g_1)/c$ | $c > -1$ |
| `variance()` | $\sigma^2(g_2 - g_1^2)/c^2$ | $c > -1/2$ |
| `skewness()` | 아래 식 | $c > -1/3$ |
| `kurtosis()` | 아래 식(초과 첨도) | $c > -1/4$ |
| `median()` | $\mu + \sigma(1 - (\log 2)^c)/c$ | 모든 c |
| `mode()` | $\mu + \sigma(1 - (1 + c)^{c})/c$, $c \ge 1$이면 위 끝 $\mu + \sigma/c$ | 모든 c |
| `entropy()` | $\log\sigma + \gamma(1 - c) + 1$ | 모든 c |

$\gamma \approx 0.5772$는 오일러–마스케로니 상수예요. 왜도와 첨도는 이래요($c > 0$이면 $\operatorname{sgn} c = 1$, $c < 0$이면 −1).

$$
\text{skewness} = -\operatorname{sgn}(c)\,\frac{g_3 - 3g_1g_2 + 2g_1^3}{(g_2 - g_1^2)^{3/2}}, \qquad
\text{kurtosis} = \frac{g_4 - 4g_1g_3 + 6g_1^2g_2 - 3g_1^4}{(g_2 - g_1^2)^2} - 3
$$

`c`가 음수로 갈수록 위꼬리가 두꺼워져서 높은 모멘트부터 차례로 발산해요. 발산하면 inf, 그보다 낮은 모멘트가 이미 무한해서 정의할 수 없으면 NaN이에요.

```python
>>> for c in (-1.0, -0.6, -0.4, -0.3, -0.25, -0.2):
...     X = sd.stats.GEV(c=c)
...     print(c, X.mean(), X.variance(), X.skewness(), X.kurtosis())
-1.0 inf nan nan nan
-0.6 2.0302659062628137 inf nan nan
-0.4 1.2229806220320427 14.832188487966427 inf inf
-0.3 0.9935177754918593 5.9245766349214035 13.483552403221148 inf
-0.25 0.9016668098607106 4.332924099598181 5.605138216895866 inf
-0.2 0.8211485686265169 3.3440355622978815 3.5350716046213955 45.091512125815775
```

- `c ≤ -1`: 평균이 +∞로 발산해서 inf, 분산 이상은 NaN이에요.
- `-1 < c ≤ -1/2`: 평균은 유한하고 분산이 inf, 왜도·첨도는 NaN이에요(분산이 무한하면 왜도·첨도를 정의할 수 없어요).
- `-1/2 < c ≤ -1/3`: 분산은 유한하고 왜도와 첨도가 inf예요.
- `-1/3 < c ≤ -1/4`: 첨도만 inf예요.
- `c > -1/4`: 모두 유한해요.

−1/3처럼 float64로 정확히 나타낼 수 없는 경계에서는 조심하세요. `c=-1/3`은 실제로 −1/3보다 아주 조금 큰 수라서, 왜도가 inf가 아니라 아주 큰 유한한 값이 돼요.

```python
>>> sd.stats.GEV(c=-1/3).skewness()
2.317933871960185e+16
```

나머지 요약값은 모든 `c`에서 유한해요. 최빈값은 `c ≥ 1`이면 밀도가 위 끝에서 가장 커서 그 끝이에요.

```python
>>> X = sd.stats.GEV(c=0.5)
>>> X.mean(), X.median(), X.mode()
(0.22754614909448398, 0.3348907776846045, 0.585786437626905)
>>> X.entropy()
1.2886078324507664
>>> sd.stats.GEV(c=2.0).mode()
0.5
```

## 다른 분포와의 관계

### Weibull과 지수분포 (c > 0)

`c > 0`이면 $1 - cz$가 모양 $1/c$인 [Weibull 분포](/api/stats/weibull/)를 따라요. 그래서 위가 막힌 꼴을 "역 Weibull"이라고도 불러요.

```python
>>> P = sd.stats.GEV(c=0.5)
>>> W = sd.stats.Weibull(c=2.0)
>>> P.cdf(0.5), W.ccdf(1 - 0.5 * 0.5)
(0.569782824730923, 0.569782824730923)
```

특히 `c = 1`이면 $1 - z$가 [지수분포](/api/stats/exponential/)라서, `GEV(c=1)`은 `1 - Exponential()`이에요. 평균 0, 분산 1, 왜도 −2예요.

```python
>>> E = sd.stats.Exponential()
>>> sd.stats.GEV(c=1.0).cdf(0.5), E.ccdf(0.5)
(0.6065306597126334, 0.6065306597126334)
>>> sd.stats.GEV(c=1.0).skewness()
-2.0
```

### 파레토와 같은 꼬리 (c < 0)

`c < 0`이면 위꼬리가 $x^{1/c}$로 줄어요. [파레토 분포](/api/stats/pareto/)의 `b = 1/|c|`와 같은 거듭제곱 꼬리예요. 파레토처럼 꼬리가 두꺼운 값의 최댓값이 이 꼴로 모여요.

## 정확도와 범위

GEV는 닫힌 꼴 분포라서 매개변수와 입력의 정의역 전체(모든 유한한 `c`)에서 정확도를 보장해요.

- 값 메서드와 요약값: 상대오차 1e-14 이하. `c`가 0에 아주 가까워도, 꼬리 깊은 곳에서도 마찬가지예요.
- `logpdf`, `entropy`: 오차가 1e-14·max(1, |값|) 이하. 왜도와 첨도도 값이 0을 지나서 같은 기준이에요.
- 역함수 넷: 상대오차가 1e-14에 입력에 대한 조건수를 곱한 값 이하예요. 결과가 0 근처로 상쇄되는 점에서는 이 조건수가 커져요.

값이 float64 범위를 넘는 곳에서는 극한값을 내요. 구현은 [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.genextreme(c, loc, scale)`에 해당하고, **`c`의 부호 규칙이 scipy와 같아요**(c = −ξ). R의 evd·extRemes 같은 패키지와 교과서의 ξ와는 반대예요.
- 이름이 `mu`, `sigma`이고 모두 키워드로만 받아요. `c`는 기본값이 없어요.
- 발산하는 모멘트를 다르게 표시해요. `GEV(c=-0.6).variance()`는 inf(scipy 1.18.1은 nan), `GEV(c=-0.4).skewness()`와 `GEV(c=-0.3).kurtosis()`도 inf(scipy는 nan)예요. stardust는 그 모멘트가 발산하면 inf, 더 낮은 모멘트가 이미 무한해서 정의할 수 없으면 NaN을 내요.
- 깊은 위꼬리의 로그를 내요. `GEV(c=-0.5).logccdf(1e300)`은 −1380.16…이고 scipy의 `genextreme.logsf(1e300, -0.5)`는 −inf예요.
- `kurtosis()`는 초과 첨도예요.
