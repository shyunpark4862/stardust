## 한눈에 보기

`sd.stats`의 단변량 분포(값이 실수 하나인 분포) 31개는 **모두 같은 메서드**를 가지고 있어요. 정규분포든 감마분포든 포아송분포든 `cdf`는 "x 이하일 확률"이고, `icdf`는 그 역이에요. 그래서 메서드의 뜻을 한 번 익혀 두면 어느 분포에서나 그대로 쓸 수 있어요. 이 페이지는 그 공통의 뜻과 규칙을 모아 두었어요. 각 분포의 문서는 그 분포에서 메서드가 어떤 모습인지에 집중해요.

| 메서드 | 돌려주는 것 | 한 줄 설명 |
|---|---|---|
| `pdf(x)` / `pmf(k)` | $f(x)$ / $P(X = k)$ | 밀도(연속), 확률질량(이산) |
| `cdf(x)` | $P(X \le x)$ | x 이하일 확률(누적분포함수) |
| `ccdf(x)` | $P(X > x)$ | x보다 클 확률(위꼬리) |
| `logpdf`, `logcdf`, `logccdf` | 위 값의 자연로그 | 값이 너무 작아 0이 될 때도 로그는 남아요 |
| `icdf(p)` | `cdf(x) = p`인 x | 아래에서 p만큼 자르는 값(분위수) |
| `iccdf(p)` | `ccdf(x) = p`인 x | 위에서 p만큼 자르는 값 |
| `ilogcdf(logp)`, `ilogccdf(logp)` | 확률의 로그에서 x | 아주 작은 확률의 분위수 |
| `support()` | `(lo, hi)` | 값이 나올 수 있는 범위의 두 끝 |
| `mean()`, `variance()`, `standard_deviation()` | | 평균, 분산, 표준편차 |
| `skewness()`, `kurtosis()` | | 왜도, 초과 첨도 |
| `median()`, `mode()` | | 중앙값, 최빈값 |
| `entropy()` | | 엔트로피(단위 nat) |
| `sample(shape, rng=...)` | | 표본 뽑기([표본 뽑기](/api/stats/sample/)) |

```python
>>> import stardust as sd
>>> X = sd.stats.Normal()
>>> X.pdf(0.0), X.cdf(1.96), X.ccdf(1.96)
(0.3989422804014327, 0.9750021048517795, 0.02499789514822043)
>>> X.icdf(0.975)
1.9599639845400536
>>> X.mean(), X.variance(), X.kurtosis()
(0.0, 1.0, 0.0)
```

입력을 받는 메서드(`pdf`부터 `ilogccdf`까지)는 원소별로 계산하고, 매개변수와 입력을 함께 브로드캐스트하고, `out=`을 받아요. 매개변수만 쓰는 메서드(`support`, 모멘트, `median`, `mode`, `entropy`)는 매개변수의 모양을 돌려줘요. 이 공통 규칙은 [통계의 기본](/api/stats/basics/)에 있어요.

## 두 기반 클래스

모든 단변량 분포는 두 클래스 가운데 하나를 물려받아요.

- `sd.stats.ContinuousDistribution`: **연속 분포** 21개(정규, 감마, t, …). 밀도 메서드가 `pdf`, `logpdf`예요.
- `sd.stats.DiscreteDistribution`: **이산 분포** 10개(이항, 포아송, …). 밀도 메서드가 `pmf`, `logpmf`예요.

나머지 메서드는 둘이 같아요. 어떤 분포가 연속인지 이산인지는 `isinstance`로 알 수 있어요.

```python
>>> isinstance(sd.stats.Gamma(a=2.0), sd.stats.ContinuousDistribution)
True
>>> isinstance(sd.stats.Poisson(mu=3.0), sd.stats.DiscreteDistribution)
True
>>> def density(X, x):
...     if isinstance(X, sd.stats.DiscreteDistribution):
...         return X.pmf(x)
...     return X.pdf(x)
>>> density(sd.stats.Poisson(mu=3.0), 2.0)
0.22404180765538773
```

두 클래스는 타입을 구별하는 데 쓰는 것이고, 직접 만들어 쓰는 분포가 아니에요. 다변량 분포와 행렬 분포는 메서드가 달라서 이 두 클래스를 물려받지 않아요.

## 밀도: `pdf`와 `pmf`

### 연속 분포의 밀도

연속 분포에서 값 하나가 **정확히** 나올 확률은 0이에요. 키가 정확히 170.000…cm일 확률은 없으니까요. 대신 "그 근처에 값이 얼마나 몰려 있는가"를 **확률밀도** $f(x)$로 나타내요. 구간에 들어갈 확률은 그 구간에서 밀도 곡선 아래의 넓이예요.

$$
P(a < X \le b) = \int_a^b f(x)\,dx
$$

밀도는 확률이 아니라서 1보다 클 수 있어요. 폭이 0.1인 구간에 고르게 퍼진 [균등분포](/api/stats/uniform/)의 밀도는 10이에요. 넓이(10 × 0.1)가 1이면 돼요.

```python
>>> sd.stats.Uniform(a=0.0, b=0.1).pdf(0.05)
10.0
```

### 이산 분포의 확률질량

이산 분포는 값이 띄엄띄엄해서, 값 하나가 나올 확률 $P(X = k)$가 0이 아니에요. 이것을 **확률질량**이라고 하고 `pmf(k)`로 구해요. 평균이 3인 [포아송분포](/api/stats/poisson/)에서 사건이 정확히 2번 일어날 확률은 약 22.4%예요.

```python
>>> P = sd.stats.Poisson(mu=3.0)
>>> P.pmf(2.0)
0.22404180765538773
```

### 로그 밀도: `logpdf`, `logpmf`

밀도의 자연로그예요. 밀도가 float64로 나타낼 수 없을 만큼 작아서 0이 되는 곳에서도 로그는 제대로 된 값이에요.

```python
>>> X = sd.stats.Normal()
>>> X.pdf(40.0)
0.0
>>> X.logpdf(40.0)
-800.9189385332047
```

로그 밀도는 데이터 여러 개의 **가능도**(likelihood)를 계산할 때 특히 필요해요. 서로 독립인 관측값들의 가능도는 밀도의 곱인데, 곱하는 수가 많아지면 곱은 금방 0으로 사라져요. 로그를 씌우면 곱이 합이 되어 사라지지 않아요.

```python
>>> data = X.sample(2000, rng=sd.random.default_rng(1))
>>> float(sd.prod(X.pdf(data)))
0.0
>>> float(sd.sum(X.logpdf(data)))
-2886.975248096208
```

## 누적확률: `cdf`와 `ccdf`

**누적분포함수** `cdf(x)`는 값이 x 이하일 확률 $P(X \le x)$예요. 밀도 곡선 아래에서 왼쪽 끝부터 x까지의 넓이이고, x가 커질수록 0에서 1로 올라가요. **위꼬리 확률** `ccdf(x)`는 x보다 클 확률 $P(X > x)$예요. 생존함수(survival function)라고도 불러요.

$$
\mathrm{cdf}(x) = P(X \le x), \qquad \mathrm{ccdf}(x) = P(X > x)
$$

### `ccdf`는 `1 - cdf`가 아니에요

수학으로는 $\mathrm{ccdf}(x) = 1 - \mathrm{cdf}(x)$예요. 하지만 컴퓨터에서 `1 - cdf(x)`로 계산하면 위꼬리에서 자릿수를 잃어요. x가 크면 `cdf(x)`가 1에 아주 가까워지고, float64는 1 근처에서 약 1.1e-16 간격으로만 수를 나타내기 때문이에요. `ccdf`는 위꼬리의 작은 넓이를 **직접** 계산해서, 꼬리 끝까지 앞자리 14자리 정도가 맞아요.

```python
>>> X = sd.stats.Normal()
>>> 1 - X.cdf(10.0)
0.0
>>> X.ccdf(10.0)
7.619853024160524e-24
```

구간의 확률도 마찬가지예요. 두 끝이 모두 위꼬리에 있으면 `cdf`의 차가 아니라 `ccdf`의 차로 계산하세요. 아래에서 참값은 6.21983198586583…e-16이에요. `cdf`의 차는 7% 넘게 틀려요.

```python
>>> X.cdf(9.0) - X.cdf(8.0)
6.661338147750939e-16
>>> X.ccdf(8.0) - X.ccdf(9.0)
6.219831985865831e-16
```

`logccdf`도 1 − cdf를 거치지 않아요. 아래꼬리에서 `ccdf`가 1에 가까울 때도 그 로그(0에 가까운 음수)를 상대오차로 정확하게 내요.

## 분위수: `icdf`와 `iccdf`

`icdf(p)`는 `cdf(x) = p`가 되는 x예요. "아래에서 p만큼을 자르는 값"으로, **분위수**라고 불러요. `icdf(0.5)`는 중앙값, `icdf(0.95)`는 95번째 백분위수예요. `iccdf(p)`는 거꾸로 `ccdf(x) = p`, 곧 "위에서 p만큼을 자르는 값"이에요.

```python
>>> X = sd.stats.Normal(mu=170.0, sigma=6.0)
>>> X.icdf(0.5)
170.0
>>> X.icdf(0.95)
179.86912176170884
>>> X.iccdf(0.05)
179.86912176170884
```

- p가 0이면 지지집합의 왼쪽 끝, 1이면 오른쪽 끝이에요(`iccdf`는 반대). 정규분포라면 −inf와 inf예요.
- p가 [0, 1] 밖이면 NaN이에요.
- 연속 분포에서 `icdf(cdf(x))`는 x로 돌아와요. 실수 계산이라 마지막 자리 하나쯤은 다를 수 있어요.

```python
>>> Z = sd.stats.Normal()
>>> Z.icdf(sd.asarray([0.0, 0.5, 1.0, 1.5]))
array([-inf,  0.0,  inf,  nan], dtype=float64)
>>> Z.icdf(Z.cdf(1.5))
1.4999999999999998
```

### 위꼬리의 분위수는 `iccdf`로

"위에서 1e-20만큼을 자르는 값"을 `icdf(1 - 1e-20)`로 구하면 안 돼요. `1 - 1e-20`은 float64에서 정확히 1.0이 되어서 오른쪽 끝(inf)이 나와요. `iccdf`는 위꼬리 확률을 그대로 받으니 이런 일이 없어요.

```python
>>> Z.icdf(1 - 1e-20)
inf
>>> Z.iccdf(1e-20)
9.262340089798405
```

### 로그 확률에서: `ilogcdf`, `ilogccdf`

확률이 float64로 나타낼 수 없을 만큼 작으면 확률의 **로그**를 받는 `ilogcdf(logp)`, `ilogccdf(logp)`를 써요. `logcdf`, `logccdf`의 역함수예요. `logp`는 0 이하여야 하고, 양수이면 NaN이에요. `logp`가 0이면 확률 1, −inf이면 확률 0에 해당하는 끝이에요.

```python
>>> Z.ilogcdf(-1e5)
-447.1978936785251
>>> Z.logcdf(-447.1978936785251)
-100000.00000000001
>>> Z.ilogcdf(sd.asarray([0.0, -sd.inf, 0.5]))
array([ inf, -inf,  nan], dtype=float64)
```

구한 값을 `logcdf`에 되돌려 넣으면, 마지막 자리 하나만 다른 −100000이 나와요.

## 지지집합: `support`

`support()`는 값이 나올 수 있는 범위의 두 끝 `(lo, hi)`예요. 연속 분포는 그 구간, 이산 분포는 나올 수 있는 가장 작은 정수와 가장 큰 정수예요. 끝이 없으면 ±inf예요.

```python
>>> sd.stats.Normal().support()
(-inf, inf)
>>> sd.stats.Gamma(a=2.0).support()
(0.0, inf)
>>> sd.stats.Uniform(a=2.0, b=6.0).support()
(2.0, 6.0)
>>> sd.stats.Binomial(n=10.0, p=0.3).support()
(0.0, 10.0)
>>> sd.stats.Geometric(p=0.2).support()
(1.0, inf)
```

지지집합은 **분포 족의 범위**예요. 매개변수 때문에 값이 한 점에 몰려도 줄어들지 않아요. 평균이 0인 포아송분포는 언제나 0이 나오지만 지지집합은 다른 포아송분포와 같은 (0, inf)이고, 성공 확률이 0인 이항분포도 (0, n)이에요. `icdf(1)`(이산 분포에서는 `iccdf(0)`도)은 이 지지집합의 오른쪽 끝이에요.

```python
>>> P0 = sd.stats.Poisson(mu=0.0)
>>> P0.support(), P0.icdf(0.5), P0.icdf(1.0)
((0.0, inf), 0.0, inf)
>>> sd.stats.Binomial(n=10.0, p=0.0).support()
(0.0, 10.0)
>>> sd.stats.Geometric(p=1.0).support()
(1.0, inf)
```

지지집합 밖의 입력에서는 이렇게 정해진 값을 내요.

| 메서드 | 왼쪽 끝보다 작은 x | 오른쪽 끝보다 큰 x |
|---|:---:|:---:|
| `pdf`, `pmf` | 0 | 0 |
| `logpdf`, `logpmf` | −inf | −inf |
| `cdf` / `ccdf` | 0 / 1 | 1 / 0 |
| `logcdf` / `logccdf` | −inf / 0 | 0 / −inf |

```python
>>> E = sd.stats.Exponential()
>>> E.pdf(-1.0), E.logpdf(-1.0), E.cdf(-1.0), E.ccdf(-1.0)
(0.0, -inf, 0.0, 1.0)
```

지지집합의 **끝점** 자체에서는 밀도의 값(또는 극한값)을 내요. 지수분포의 `pdf(0)`은 1이고, 모양이 1보다 작은 감마분포의 `pdf(0)`은 밀도가 무한대로 솟으니 inf예요.

```python
>>> E.pdf(0.0)
1.0
>>> sd.stats.Gamma(a=0.5).pdf(0.0)
inf
```

## 모멘트

분포의 모양을 몇 개의 숫자로 요약한 것이에요. 아래 식에서 $\mu$는 평균, $\sigma$는 표준편차예요.

| 메서드 | 식 | 뜻 |
|---|---|---|
| `mean()` | $\mu = E[X]$ | 평균. 분포의 무게중심 |
| `variance()` | $\sigma^2 = E[(X-\mu)^2]$ | 분산. 평균에서 퍼진 정도 |
| `standard_deviation()` | $\sigma$ | 표준편차. 분산의 제곱근이라 값과 단위가 같아요 |
| `skewness()` | $E[(X-\mu)^3]/\sigma^3$ | 왜도. 0이면 좌우 대칭, 양수면 오른쪽 꼬리가 길어요 |
| `kurtosis()` | $E[(X-\mu)^4]/\sigma^4 - 3$ | 초과 첨도. 정규분포가 0이고, 양수면 꼬리가 정규보다 두꺼워요 |

`kurtosis()`는 **초과 첨도**예요. 첨도 $E[(X-\mu)^4]/\sigma^4$에서 정규분포의 값 3을 뺀 것이라, 정규분포는 0이에요. 첨도가 필요하면 3을 더하세요.

```python
>>> sd.stats.Normal().kurtosis()
0.0
>>> sd.stats.Uniform(a=0.0, b=1.0).kurtosis()
-1.2
>>> sd.stats.Laplace().kurtosis() + 3
6.0
```

### 정의되지 않으면 NaN, 발산하면 inf

꼬리가 두꺼운 분포는 모멘트를 구하는 적분이 끝나지 않을 수 있어요. 그때의 규칙은 이래요.

- **평균**: 적분이 한쪽으로만 무한대로 가면 inf예요(값이 0 이상인 F분포의 `dfd ≤ 2`). 양쪽 꼬리가 모두 무한대라 $\infty - \infty$ 꼴이 되면 정해지지 않아서 NaN이에요(t분포의 `df ≤ 1`, 코시분포).
- **분산 이상**(분산, 표준편차, 왜도, 첨도): 분산이 유한한데 그 모멘트가 발산하면 inf예요. 분산부터 유한하지 않으면 NaN이에요. 다만 왜도처럼 양쪽 꼬리가 맞서는 모멘트는, 분산이 유한해도 정해지지 않으면 NaN이에요(대칭인 t분포의 왜도).

자유도가 바뀌면서 t분포의 모멘트가 어떻게 되는지 보면 규칙이 한눈에 보여요.

```python
>>> T = sd.stats.StudentT(df=sd.asarray([1.0, 2.0, 2.5, 3.5, 10.0]))
>>> T.mean()
array([nan, 0.0, 0.0, 0.0, 0.0], dtype=float64)
>>> T.variance()
array([               nan,                inf,                5.0,
       2.3333333333333335,               1.25], dtype=float64)
>>> T.skewness()
array([nan, nan, nan, 0.0, 0.0], dtype=float64)
>>> T.kurtosis()
array([nan, nan, inf, inf, 1.0], dtype=float64)
```

| `df` | 평균 | 분산 | 왜도 | 첨도 | 까닭 |
|:---:|:---:|:---:|:---:|:---:|---|
| 1 | NaN | NaN | NaN | NaN | 평균의 적분이 양쪽에서 발산해요 |
| 2 | 0 | inf | NaN | NaN | 분산이 발산하니 그 위는 정해지지 않아요 |
| 2.5 | 0 | 5 | NaN | inf | 분산은 유한하고, 4차 모멘트는 +∞로 발산해요. 3차 모멘트는 양쪽이 맞서요 |
| 3.5 | 0 | 2.33 | 0 | inf | 3차까지 유한하고, 4차는 발산해요 |
| 10 | 0 | 1.25 | 0 | 1 | 모두 유한해요 |

## 중앙값과 최빈값

### `median()`

값의 절반이 그 아래에 있는 점이에요. 연속 분포에서는 `cdf(x) = 1/2`인 x, 이산 분포에서는 `icdf(0.5)`예요. 평균과 달리 꼬리가 두꺼워도 언제나 있어요.

```python
>>> sd.stats.Cauchy().median()
0.0
>>> E = sd.stats.Exponential(scale=2.0)
>>> E.median(), E.mean()
(1.3862943611198906, 2.0)
```

지수분포처럼 오른쪽 꼬리가 긴 분포에서는 중앙값이 평균보다 작아요.

### `mode()`

밀도(이산 분포는 확률질량)가 가장 큰 점이에요. 그 점이 지지집합의 끝이어도, 거기서 밀도가 무한대로 솟아도 그 점이에요. 가장 큰 점이 **하나로 정해지지 않으면 NaN**이에요.

```python
>>> sd.stats.Gamma(a=sd.asarray([0.5, 3.0])).mode()
array([0.0, 2.0], dtype=float64)
>>> sd.stats.Uniform(a=0.0, b=1.0).mode()
nan
>>> sd.stats.Beta(a=sd.asarray([0.5, 2.0]), b=sd.asarray([0.5, 2.0])).mode()
array([nan, 0.5], dtype=float64)
>>> sd.stats.Poisson(mu=sd.asarray([2.0, 2.5])).mode()
array([nan, 2.0], dtype=float64)
```

- 모양이 0.5인 감마분포는 0에서 밀도가 inf로 솟으니 최빈값이 0이에요.
- 균등분포는 구간 전체에서 밀도가 같아서 하나로 정할 수 없어요.
- `Beta(a=0.5, b=0.5)`는 양 끝 0과 1에서 밀도가 똑같이 솟아서 둘 중 하나로 정할 수 없어요.
- 평균이 2인 포아송분포는 1과 2의 확률이 같아서(둘 다 $2e^{-2}$) 최빈값이 둘이에요.

## 엔트로피: `entropy()`

분포가 얼마나 **불확실한지**를 재는 값이에요. 값이 한곳에 몰려 있으면 작고, 넓게 퍼져 있으면 커요. 연속 분포는 **미분 엔트로피**, 이산 분포는 **섀넌 엔트로피**예요(아래 식). 단위는 자연로그를 쓰는 **nat**예요. 비트 단위가 필요하면 `log 2`로 나누세요.

$$
H = -\int f(x) \log f(x)\, dx \quad(\text{연속}), \qquad H = -\sum_k P(X=k) \log P(X=k) \quad(\text{이산})
$$

```python
>>> import math
>>> B = sd.stats.Bernoulli(p=0.5)
>>> B.entropy()
0.6931471805599453
>>> B.entropy() / math.log(2)
1.0
```

공정한 동전 던지기의 엔트로피는 1비트예요.

연속 분포의 엔트로피(미분 엔트로피)는 **음수가 될 수 있어요.** 밀도가 1보다 클 수 있기 때문이에요. 폭이 1보다 좁은 균등분포가 그 예예요.

```python
>>> sd.stats.Uniform(a=0.0, b=0.5).entropy()
-0.6931471805599453
```

데이터에서 엔트로피를 어림하는 함수는 [`entropy`](/api/stats/entropy/)(확률 벡터)와 [`differential_entropy`](/api/stats/differential-entropy/)(연속 표본)예요.

### 이산 분포의 분위수

계단 모양의 cdf에서는 `cdf(k) = p`가 되는 k가 없을 때가 대부분이에요. 그래서 이산 분포의 분위수는 이렇게 정해요.

- `icdf(p)`: `cdf(k) ≥ p`인 **가장 작은** 정수 k
- `iccdf(p)`: `ccdf(k) ≤ p`인 **가장 작은** 정수 k

평균이 3인 포아송분포에서 `cdf(2) ≈ 0.423`, `cdf(3) ≈ 0.647`이라서, 0.423보다 크고 0.647 이하인 p의 `icdf`는 모두 3이에요.

```python
>>> P.icdf(sd.asarray([0.3, 0.5, 0.6, 0.65]))
array([2.0, 3.0, 3.0, 4.0], dtype=float64)
>>> P.icdf(P.cdf(2.0))
2.0
>>> P.iccdf(0.5)
3.0
>>> P.icdf(sd.asarray([0.0, 1.0]))
array([0.0, inf], dtype=float64)
```

결과는 정수이지만 float64로 돌려줘요. 정수가 float64의 범위를 넘으면 inf예요. `icdf(0)`은 지지집합의 왼쪽 끝(포아송은 0)이고, `icdf(1)`은 오른쪽 끝(포아송은 inf)이에요.

### 중앙값, 최빈값, 점질량

- `median()`은 `icdf(0.5)`예요.
- `mode()`는 확률질량이 가장 큰 정수예요. 둘 이상이면 NaN이에요(위의 `Poisson(mu=2.0)`).
- 매개변수 때문에 값이 한 점에만 몰리면(`Binomial(p=0)`, `Poisson(mu=0)`, `Geometric(p=1)`처럼) 분산은 0이고, 왜도와 첨도는 0으로 나누는 꼴이라 NaN이에요.

```python
>>> D = sd.stats.Binomial(n=10.0, p=0.0)
>>> D.mean(), D.variance(), D.skewness()
(0.0, 0.0, nan)
```

### 정수여야 하는 매개변수

이항분포의 `n`처럼 정수만 뜻이 있는 매개변수에 정수가 아닌 값을 주면, 그 분포의 모든 메서드가 NaN이에요. 2.5를 2로 잘라 계산하는 일은 없어요.

```python
>>> sd.stats.Binomial(n=2.5, p=0.3).pmf(1.0)
nan
```

## 정확도

정확도의 기본 약속(보장 영역에서 상대오차 1e-14)은 [통계의 기본](/api/stats/basics/#정확도-약속)에 있어요. 메서드마다 재는 방법이 조금 달라요.

| 메서드 | 약속 |
|---|---|
| `pdf`, `pmf`, `cdf`, `ccdf`, `logcdf`, `logccdf`, 모멘트, `median`, `mode` | 상대오차 $10^{-14}$ |
| `logpdf`, `entropy` | $\lvert\text{오차}\rvert \le 10^{-14}\max(1, \lvert\text{값}\rvert)$ |
| `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`(연속) | $\lvert\Delta x / x\rvert \le 10^{-14}\max(1, \kappa)$ |
| `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`(이산) | 목표 확률을 상대 $10^{-14}$ 안에서 움직였을 때의 정확한 답 가운데 하나 |

이산 분포의 `logpmf`는 상대오차 $10^{-14}$이고, 이산 분포의 `entropy`는 연속 분포와 같은 혼합 기준이에요.

`logpdf`와 `entropy`는 값이 0을 지나서, 0 근처에서는 상대오차 대신 절대오차로 재요. 베이불분포의 왜도·첨도처럼 0을 지나는 모멘트도 같은 혼합 기준이고, 그런 곳은 각 분포의 문서에 적어 두었어요. `logcdf`, `logccdf`는 값이 0에 가까워져도 꼬리 쪽에서 정확해서 상대오차를 약속해요.

### 연속 분포의 역함수와 κ

역함수의 κ는 **입력이 조금 흔들릴 때 결과가 얼마나 크게 흔들리는가**를 나타내는 배율(상대 조건수)이에요. `icdf(p)`라면 $\kappa = \lvert p / (x f(x)) \rvert$, `ilogcdf(logp)`라면 $\kappa = \lvert \mathrm{logp} \cdot p / (x f(x)) \rvert$예요. 입력 p 자체도 float64로 저장되면서 마지막 자리가 이미 반올림되어 있으니, 그 반올림이 결과를 움직이는 만큼은 어떤 계산으로도 줄일 수 없어요. 그만큼은 오차로 허용한다는 약속이에요. 대부분의 곳에서 κ는 1 근처라 그냥 상대오차 1e-14예요.

κ가 커지는 대표적인 곳은 결과가 0 근처일 때예요. 평균이 1.5이고 표준편차가 2인 정규분포에서 `icdf(0.2267)`의 참값은 0.000482444523290923…인데, 결과는 13번째 자리부터 달라요.

```python
>>> sd.stats.Normal(mu=1.5, sigma=2.0).icdf(0.2267)
0.0004824445232910835
```

여기서 κ는 약 3100이에요. 0.2267을 float64로 저장할 때 생기는 반올림(약 1e-17)만으로도 x가 이 정도 움직여요. 그래서 약속의 단위로 재면 오차는 1e-16쯤이에요.

### 이산 분포의 역함수

이산 분포의 분위수는 정수라서 "몇 자리가 맞는다"로 잴 수 없어요. 대신 **목표 확률을 상대 1e-14 안에서 움직였을 때 나올 수 있는 정확한 답 가운데 하나**를 낸다고 약속해요(`icdf`·`iccdf`는 p와 1 − p 가운데 작은 쪽을, `ilogcdf`·`ilogccdf`는 logp를 움직여요). p가 계단의 경계에 거의 붙어 있으면 이웃한 정수도 맞는 답이에요.

## scipy를 아는 분께

- 메서드 이름은 scipy 신형(`scipy.stats.Normal` 등)과 같아요. 고전형과는 `sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`로 대응해요. 고전형의 `interval`, `expect`, `moment(n)`, `fit`은 없어요.
- `kurtosis()`는 초과 첨도예요. scipy 신형의 기본은 정규분포에서 3인 첨도예요.
- 정의되지 않거나 발산하는 모멘트가 다른 곳이 있어요(scipy 1.18.1의 고전형과 비교).
  - t분포 `df ≤ 1`의 평균: NaN이에요. scipy는 inf예요.
  - F분포 `dfd ≤ 2`의 분산: NaN이에요(평균부터 무한대예요). scipy는 inf예요.
  - F분포 `4 < dfd ≤ 6`의 왜도: inf예요. scipy는 NaN이에요.
  - F분포 `4 < dfd ≤ 8`의 첨도: inf예요. scipy는 NaN이에요.
- 최빈값이 하나로 정해지지 않으면 NaN이에요. scipy 신형은 `Uniform(a=0, b=1).mode()`에 0.5, `Binomial(n=9, p=0.5).mode()`에 5.0을 내요.
- 이산 분포의 `icdf(0)`은 지지집합의 왼쪽 끝이에요(포아송 0, 기하 1). scipy의 `ppf(0)`은 그보다 1 작은 값(포아송 −1, 기하 0)이에요. `iccdf(1)`과 `isf(1)`도 같은 차이가 있어요.
- 결과는 Python `float`이거나 `sd.ndarray`예요. `numpy.float64`가 아니에요.
