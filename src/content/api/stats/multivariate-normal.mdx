## 어떤 분포인가요

**다변량 정규분포**(multivariate normal distribution)는 정규분포를 여러 변수로 넓힌 분포예요. 사람의 키와 몸무게, 여러 주식의 하루 수익률, 센서 여러 개의 측정 오차처럼 함께 움직이는 값 여러 개를 한 번에 다룰 때 써요. 키가 큰 사람은 몸무게도 많이 나가는 편이라 두 값을 따로따로 정규분포로 두면 이 관계를 놓쳐요. 다변량 정규분포는 이런 관계까지 담아요.

분포는 두 가지로 정해요.

- **평균 벡터** `mu`: 각 변수의 평균이에요. 변수가 d개면 길이 d예요.
- **공분산 행렬** `cov`: d × d 행렬이에요. 대각 성분은 각 변수의 분산이고, (i, j) 성분은 변수 i와 j가 함께 커지고 작아지는 정도(공분산)예요. 양수면 함께 커지고, 음수면 하나가 커질 때 다른 하나가 작아지고, 0이면 서로 상관이 없어요.

키(cm)와 몸무게(kg)로 예를 들어 볼게요. 평균은 170cm와 65kg, 표준편차는 6cm와 8kg, 공분산은 30이라고 해요(상관계수로는 30 / (6 × 8) = 0.625예요).

```python
>>> import stardust as sd
>>> body = sd.stats.MultivariateNormal(mu=sd.asarray([170.0, 65.0]),
...                                    cov=sd.asarray([[36.0, 30.0], [30.0, 64.0]]))
>>> body.pdf(sd.asarray([170.0, 65.0]))
0.0042475312010431514
>>> body.pdf(sd.asarray([180.0, 75.0]))
0.0010220766569596631
>>> body.pdf(sd.asarray([160.0, 75.0]))
1.4240464164245462e-05
```

180cm·75kg과 160cm·75kg은 몸무게가 같고 키가 평균에서 10cm씩 떨어져 있어서, 변수를 따로 보면 똑같이 드문 값이에요. 그런데 밀도는 70배 넘게 차이 나요. 이 분포에서는 키가 크면 몸무게도 많이 나가는 쪽이 자연스럽고, 작은 키에 무거운 몸무게는 드물기 때문이에요.

이 관계는 밀도의 **등고선**에서 잘 보여요. 밀도가 같은 점을 이으면 타원이 되는데, 상관이 없으면 타원의 축이 좌표축과 나란하고(분산이 같으면 원이에요), 상관이 있으면 기울어진 타원이 돼요.

## 만들기와 매개변수

매개변수는 키워드로만 줘요. 기본값은 없어서 `mu`와 `cov`를 모두 줘야 해요. 둘 다 `sd.ndarray`여야 해요. 리스트나 tuple, numpy 배열은 `sd.asarray`로 바꿔서 넘겨요.

```python
>>> X = sd.stats.MultivariateNormal(mu=sd.asarray([0.0, 0.0]),
...                                 cov=sd.asarray([[1.0, 0.5], [0.5, 1.0]]))
>>> X
MultivariateNormal(mu=array([0.0, 0.0], dtype=float64), cov=array([[1.0, 0.5],
       [0.5, 1.0]], dtype=float64))
>>> X.mu
array([0.0, 0.0], dtype=float64)
>>> sd.stats.MultivariateNormal(sd.asarray([0.0, 0.0]), sd.eye(2))
Traceback (most recent call last):
    ...
TypeError: MultivariateNormal(): takes no positional arguments but 2 were given
>>> sd.stats.MultivariateNormal(mu=[0.0, 0.0], cov=sd.eye(2))
Traceback (most recent call last):
    ...
TypeError: MultivariateNormal(): 'mu' must be an sd.ndarray, not list
```

### 모양

`mu`의 마지막 축 길이 d가 변수의 수이고, `cov`의 마지막 두 축은 (d, d)여야 해요. 맞지 않으면 만들 때 `ValueError`예요.

```python
>>> sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=sd.eye(3))
Traceback (most recent call last):
    ...
ValueError: MultivariateNormal(): 'cov' must be (2, 2) on its last two axes (mu has 2 components), not (3, 3)
```

### 공분산은 아래 삼각만 읽어요

공분산 행렬은 대칭이라 아래 삼각(대각 포함)만 읽고 위 삼각은 보지 않아요. [`sd.linalg.cholesky`](/api/linalg/cholesky/)와 같은 규칙이에요. 아래 예에서 위 삼각의 99는 무시돼요.

```python
>>> odd = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=sd.asarray([[1.0, 99.0], [0.5, 1.0]]))
>>> odd.pdf(sd.asarray([0.3, -0.2])) == X.pdf(sd.asarray([0.3, -0.2]))
True
```

`covariance()`도 아래 삼각을 대칭으로 옮긴 행렬을 돌려줘요. 속성 `cov`만 준 행렬 그대로예요.

```python
>>> odd.covariance()
array([[1.0, 0.5],
       [0.5, 1.0]], dtype=float64)
>>> odd.cov
array([[ 1.0, 99.0],
       [ 0.5,  1.0]], dtype=float64)
```

### 양정치가 아니면 NaN

공분산 행렬은 **양정치**(positive definite)여야 해요. 어떤 방향으로든 분산이 0보다 커야 한다는 뜻이에요. 두 변수가 완전히 같이 움직여서(상관 1) 한 방향의 분산이 0이 되는 **특이 행렬**도 받지 않아요. 이런 행렬이나 NaN·inf가 든 `mu`를 주면 에러가 아니라, 그 분포의 모든 메서드가 NaN을 돌려줘요.

```python
>>> bad = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=sd.asarray([[1.0, 1.0], [1.0, 1.0]]))
>>> bad.pdf(sd.asarray([0.0, 0.0]))
nan
>>> bad.mean()
array([nan, nan], dtype=float64)
>>> bad.entropy()
nan
```

특이 공분산을 받는 옵션(scipy의 `allow_singular`)은 없어요. 변수 하나가 다른 변수의 일차결합이라면 그 변수를 빼고 남은 변수로 분포를 만드세요.

### 여러 분포를 한 번에: 배치

`mu`와 `cov`에 앞 축을 더하면 분포 여러 개를 한 객체에 담아요. 이 앞 축을 **배치**(batch) 축이라고 하고, 배치 축끼리는 [브로드캐스팅](/api/array/broadcasting/) 규칙을 따라요. 아래는 평균만 다른 분포 3개예요. `mu`는 (3, 2), `cov`는 (2, 2)라서 배치 모양은 (3,)이에요.

```python
>>> B = sd.stats.MultivariateNormal(mu=sd.asarray([[0.0, 0.0], [1.0, 1.0], [2.0, 2.0]]), cov=sd.eye(2))
>>> B.pdf(sd.asarray([0.0, 0.0]))
array([  0.15915494309189532,   0.05854983152431916, 0.0029150244650281935], dtype=float64)
>>> B.mean().shape
(3, 2)
>>> B.covariance().shape
(3, 2, 2)
```

점 하나에서 세 분포의 밀도를 한 번에 구했어요. 배치 중 일부만 정의역 밖이면 그 원소만 NaN이고 나머지는 정상으로 계산해요.

## 밀도

d개 변수의 다변량 정규분포의 밀도는 이래요.

$$
f(x) = \frac{1}{(2\pi)^{d/2}\,|\Sigma|^{1/2}} \exp\!\left(-\frac{Q}{2}\right),
\qquad Q = (x - \mu)^{\mathsf T}\,\Sigma^{-1}\,(x - \mu)
$$

$\Sigma$는 공분산 행렬, $|\Sigma|$는 그 행렬식이에요. $Q$는 **마할라노비스 거리**(Mahalanobis distance)의 제곱으로, 평균에서 얼마나 떨어졌는지를 "그 방향의 표준편차 몇 개만큼인지"로 잰 값이에요. 등고선의 타원은 $Q$가 같은 점을 이은 것이에요. d = 1이면 $Q = ((x - \mu)/\sigma)^2$이라 보통의 정규분포 밀도가 돼요.

### 입력의 모양

`pdf`와 `logpdf`의 입력 `x`는 마지막 축이 d인 `sd.ndarray`예요(리스트나 Python 실수는 `TypeError`예요). 앞 축은 배치 축과 브로드캐스트하고, 결과는 그 앞 축의 모양이에요. 앞 축이 없으면 Python `float`예요.

```python
>>> X.pdf(sd.asarray([[0.0, 0.0], [1.0, 1.0], [1.0, -1.0]]))
array([ 0.18377629847393068,  0.09435389770895922, 0.024871417406145686], dtype=float64)
>>> B.pdf(sd.zeros((4, 1, 2))).shape
(4, 3)
>>> X.pdf(sd.asarray([0.0, 0.0, 0.0]))
Traceback (most recent call last):
    ...
ValueError: pdf(): 'x' must have 2 components on its last axis, not 3
>>> X.pdf([0.0, 0.0])
Traceback (most recent call last):
    ...
TypeError: pdf(): 'x' must be an sd.ndarray, not list
```

둘째 예는 점 4개(4, 1, 2)를 배치 3개(3,)와 맞춰 (4, 3) 모양의 밀도를 구했어요. (1, 1)과 (1, −1)은 평균에서 떨어진 거리가 같지만, 상관이 양수라 같은 방향으로 함께 움직인 (1, 1)의 밀도가 4배쯤 커요.

### 먼 점은 `logpdf`로

평균에서 아주 먼 점의 밀도는 float64로 나타낼 수 있는 가장 작은 수보다 작아져서 0이 돼요. 우도(likelihood)를 곱하거나 비교할 때는 `logpdf`를 쓰세요. 밀도가 0으로 사라지는 곳에서도 log 값은 정확해요.

```python
>>> body.pdf(sd.asarray([170.0, 1000.0]))
0.0
>>> body.logpdf(sd.asarray([170.0, 1000.0]))
-11213.47423787152
```

성분에 ±inf가 있으면 밀도는 0(`logpdf`는 −inf), NaN이 있으면 NaN이에요.

```python
>>> X.pdf(sd.asarray([sd.inf, 0.0]))
0.0
>>> X.logpdf(sd.asarray([sd.inf, 0.0]))
-inf
>>> X.pdf(sd.asarray([sd.nan, 0.0]))
nan
```

## 누적확률 `cdf`

```text
X.cdf(x, /, *, atol=1e-6, return_error=False, max_points=None)
```

`cdf(x)`는 모든 성분이 동시에 `x` 이하일 확률 $P(X_1 \le x_1, \dots, X_d \le x_d)$예요. 밀도를 왼쪽 아래 모서리가 무한히 먼 직사각형 영역에서 적분한 값이에요.

```python
>>> X.cdf(sd.asarray([0.0, 0.0]))
0.3333333333333333
>>> body.cdf(sd.asarray([175.0, 70.0]))
0.6557379364062103
```

평균이 0이고 상관이 ρ인 2변량 정규분포에서 두 값이 모두 0 이하일 확률은 $\tfrac14 + \tfrac{\arcsin\rho}{2\pi}$로 알려져 있어요. ρ = 0.5이면 1/3이고, 첫 줄이 그 값이에요. 둘째 줄은 "키가 175cm 이하이면서 몸무게가 70kg 이하인 사람의 비율"이에요.

### 계산 방법과 오차: d ≤ 3과 d ≥ 4

이 적분은 변수의 수 d에 따라 두 가지로 계산해요.

- **d ≤ 3**: 1차원 적분으로 바꾼 정확한 공식을 써요. 결과는 앞자리 14자리 정도까지 맞고, 오차 추정은 0이에요.
- **d ≥ 4**: 적분 영역에 고르게 흩은 점에서 밀도를 평가해 평균을 내는 방법(준몬테카를로)으로 어림해요. 점을 늘려 가다가 오차 추정이 `atol`(기본 1e-6) 아래로 내려가면 멈춰요. 점을 고르는 시드가 고정돼 있어서 같은 입력이면 언제나 같은 값이에요. 스레드 수를 바꿔도 같아요.

`return_error=True`를 주면 `(값, 오차 추정)` 튜플을 돌려줘요.

```python
>>> X.cdf(sd.asarray([0.0, 0.0]), return_error=True)
(0.3333333333333333, 0.0)
```

모든 상관이 0.5인 d변량 정규분포에서 모든 성분이 0 이하일 확률은 정확히 1/(d + 1)이에요. d = 4이면 0.2예요.

```python
>>> C4 = sd.full((4, 4), 0.5) + 0.5 * sd.eye(4)
>>> X4 = sd.stats.MultivariateNormal(mu=sd.zeros(4), cov=C4)
>>> X4.cdf(sd.zeros(4), return_error=True)
(0.19999955726201604, 4.134126200329269e-07)
>>> X4.cdf(sd.zeros(4), return_error=True)
(0.19999955726201604, 4.134126200329269e-07)
>>> X4.cdf(sd.zeros(4), atol=1e-4, return_error=True)
(0.20000213018931096, 8.17461606315734e-06)
```

참값 0.2와의 차이는 4.4e-7로, 오차 추정 4.1e-7과 비슷한 크기예요. 두 번 불러도 같은 값이 나와요. `atol`을 느슨하게 주면 점을 덜 쓰는 대신 오차가 커져요.

- 오차 추정은 통계적인 값이에요(표준오차의 3배). 대부분 참오차보다 크지만, 일부 점에서는 참오차가 더 클 수 있어요. 그런 점에서도 참오차는 재 본 범위에서 오차 추정의 1.9배를 넘지 않아요.
- `max_points`는 밀도를 평가하는 횟수의 상한이에요. 기본값 `None`은 10⁶ × (변수의 수)예요. 상한에 닿으면 `atol`에 못 미쳐도 멈추고, 그때의 값과 오차 추정을 돌려줘요.

```python
>>> X4.cdf(sd.zeros(4), max_points=1000, return_error=True)
(0.20002376506644118, 0.00018468624043441387)
```

그래서 d ≥ 4에서 `return_error=False`로 값만 받을 때는, 필요한 정확도에 맞게 `atol`을 주고 가끔 오차 추정을 확인하는 것이 좋아요.

### 특수한 입력

- `x`의 성분이 +inf이면 그 변수는 조건에서 빠져요. 남은 변수의 주변분포(그 변수를 무시한 분포)의 cdf가 돼요.
- −inf인 성분이 하나라도 있으면 0, NaN이 있으면 NaN이에요(−inf보다 NaN이 먼저예요).
- 모든 성분이 +inf이면 1이에요.

```python
>>> X.cdf(sd.asarray([1.0, sd.inf]))
0.8413447460685429
>>> sd.stats.Normal().cdf(1.0)
0.8413447460685429
>>> X.cdf(sd.asarray([-sd.inf, 0.0]))
0.0
>>> X.cdf(sd.asarray([sd.nan, -sd.inf]))
nan
>>> X.cdf(sd.asarray([sd.inf, sd.inf]))
1.0
```

여러 점을 한 번에 넣을 수도 있어요. 배치와의 브로드캐스트는 `pdf`와 같아요.

```python
>>> X.cdf(sd.asarray([[0.0, 0.0], [1.0, 1.0], [-1.0, 2.0]]))
array([ 0.3333333333333333,  0.7452035868467497, 0.15850839416544282], dtype=float64)
```

### 꼬리 확률

아주 작은 확률도 0으로 뭉개지 않고 계산해요.

```python
>>> X.cdf(sd.asarray([-10.0, -10.0]))
4.416978231552918e-32
```

### 직사각형과 위쪽 영역의 확률

`cdf`는 "모든 성분이 x 이하"만 계산해요. 다른 영역은 `cdf`를 조합해서 구해요. 2변량에서 $a_1 < X_1 \le b_1$, $a_2 < X_2 \le b_2$일 확률은 포함–배제로 네 모서리의 cdf를 더하고 빼요.

```python
>>> X.cdf(sd.asarray([1.0, 1.0])) - X.cdf(sd.asarray([-1.0, 1.0])) \
...     - X.cdf(sd.asarray([1.0, -1.0])) + X.cdf(sd.asarray([-1.0, -1.0]))
0.49797177783920804
```

모든 성분이 x보다 클 확률 $P(X > x)$는 `1 - cdf(x)`가 아니에요. 다변량에서 `1 - cdf(x)`는 "성분 중 하나라도 x보다 클 확률"이에요. 대신 $-X$가 평균 $-\mu$, 같은 공분산의 정규분포라는 것을 써서 $P(X > x) = P(-X < -x)$로 구해요.

```python
>>> x = sd.asarray([1.0, 0.5])
>>> neg = sd.stats.MultivariateNormal(mu=-X.mean(), cov=X.covariance())
>>> neg.cdf(-x)
0.09747672021001677
```

<Callout type="note" title="cdf 말고는 없어요">
  다변량 분포에는 `ccdf`, `logcdf`, `icdf`처럼 단변량 분포에 있는 메서드가 없어요. 다변량에서는 "위꼬리"나 "분위수"가 하나로 정해지지 않기 때문이에요. 필요한 영역의 확률은 위처럼 `cdf`를 조합해서 구하세요.
</Callout>

### 인자 검사

`atol`은 유한한 양수(int나 float, numpy 정수도 돼요), `return_error`는 `True`나 `False`, `max_points`는 양의 정수나 `None`이어야 해요. 0, 음수, inf, NaN인 `atol`은 `ValueError`이고, float로 나타낼 수 없을 만큼 큰 int는 `OverflowError`예요.

```python

>>> X.cdf(sd.zeros(2), atol=float('inf'))
Traceback (most recent call last):

>>> X.cdf(sd.zeros(2), atol=10**400)
Traceback (most recent call last):

OverflowError: cdf(): 'atol' is out of range
>>> X.cdf(sd.zeros(2), return_error=1)
Traceback (most recent call last):

TypeError: cdf(): 'return_error' must be True or False, not int

```

## 요약값

| 메서드 | 값 | 모양 |
|---|---|---|
| `mean()` | $\mu$ | 배치 + (d,) |
| `covariance()` | $\Sigma$ | 배치 + (d, d) |
| `entropy()` | $\tfrac d2 (1 + \log 2\pi) + \tfrac12 \log\lvert\Sigma\rvert$ | 배치 |

```python
>>> body.mean()
array([170.0,  65.0], dtype=float64)
>>> body.covariance()
array([[36.0, 30.0],
       [30.0, 64.0]], dtype=float64)
>>> body.entropy()
6.4614173587022234
```

`mean()`과 `covariance()`는 배치가 없어도 배열이에요. `entropy()`는 미분 엔트로피이고 단위는 nat이에요. 배치가 없으면 Python `float`예요. 각 변수의 분산만 필요하면 공분산 행렬의 대각을 꺼내요([`diagonal`](/api/linalg/trace-diagonal/)).

```python
>>> sd.linalg.diagonal(body.covariance())
array([36.0, 64.0], dtype=float64)
```

단변량 분포의 `variance`, `skewness`, `kurtosis`, `median`, `mode`는 없어요. 다변량 정규분포의 최빈값과 성분별 중앙값은 모두 `mu`예요.

## 표본

`sample(shape, rng=...)`은 `shape` + 배치 모양 + (d,) 모양의 표본을 돌려줘요. 벡터 하나가 표본 하나예요. `shape`를 빼면 분포마다 벡터 하나라서 배치 모양 + (d,)예요. `rng`는 [`sd.random.default_rng`](/api/random/default_rng/)로 만든 생성기이고 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> body.sample(rng=sd.random.default_rng(1))
array([177.1635185623682, 65.75767946705913], dtype=float64)
>>> rng = sd.random.default_rng(1)
>>> body.sample(5, rng=rng)
array([[ 177.1635185623682,  65.75767946705913],
       [172.74231813591197,   60.8566560615154],
       [ 170.0101757732622,   62.9332002903539],
       [167.25921123710793, 55.276479254676076],
       [173.36873126709872,  63.38335122413653]], dtype=float64)
>>> B.sample((10, 4), rng=rng).shape
(10, 4, 3, 2)
```

표본을 많이 뽑아 평균과 [표본 공분산](/api/array/cov/)을 구하면 매개변수에 가까워요.

```python
>>> s = body.sample(100000, rng=sd.random.default_rng(2))
>>> sd.mean(s, axis=0)
array([170.01750888283058,  64.98143367662666], dtype=float64)
>>> sd.cov(s, rowvar=False, correction=1)
array([[35.859069484423564, 29.869087069523808],
       [29.869087069523808,  63.50571296901858]], dtype=float64)
```

표본과 `logpdf`로 등고선 그림의 타원을 확인해 볼 수도 있어요. 2변량에서 $Q \le r^2$인 타원이 담는 확률은 $1 - e^{-r^2/2}$라서, $r^2 = 2\log 2$인 타원 안에 표본의 절반쯤이 들어가야 해요. $Q$는 `logpdf`의 차로 구해요.

```python
>>> import math
>>> Y = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=sd.asarray([[1.0, 0.8], [0.8, 1.0]]))
>>> z = Y.sample(100000, rng=sd.random.default_rng(0))
>>> q = -2.0 * (Y.logpdf(z) - Y.logpdf(sd.zeros(2)))
>>> sd.mean(q <= 2.0 * math.log(2.0))
0.501
```

## 다른 분포와의 관계

d = 1이면 정규분포예요. `cov`가 분산이라 [`Normal`](/api/stats/normal/)의 `sigma`는 그 제곱근이에요.

```python
>>> one = sd.stats.MultivariateNormal(mu=sd.asarray([1.0]), cov=sd.asarray([[4.0]]))
>>> one.pdf(sd.asarray([2.0])), sd.stats.Normal(mu=1.0, sigma=2.0).pdf(2.0)
(0.17603266338214973, 0.17603266338214973)
>>> one.entropy(), sd.stats.Normal(mu=1.0, sigma=2.0).entropy()
(2.112085713764618, 2.112085713764618)
```

공분산이 대각이면 성분끼리 독립이라, 밀도는 각 성분의 정규 밀도의 곱이에요.

```python
>>> ind = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=sd.asarray([[1.0, 0.0], [0.0, 4.0]]))
>>> ind.pdf(sd.asarray([1.0, 1.0]))
0.042594751097613244
>>> sd.stats.Normal().pdf(1.0) * sd.stats.Normal(sigma=2.0).pdf(1.0)
0.04259475109761325
```

마지막 자리가 다른 것은 곱셈의 반올림 때문이에요.

- 주변분포: 변수 일부만의 분포도 정규분포이고, `mu`와 `cov`에서 그 변수의 성분만 꺼내면 돼요. 예를 들어 앞 두 변수만 보려면 `mu[:2]`, `cov[:2, :2]`로 새 분포를 만들어요. `cdf`에서는 빼려는 변수에 +inf를 넣어도 같아요.
- 다변량 t 분포: [`MultivariateT`](/api/stats/multivariate-t/)의 `df = inf`가 다변량 정규분포예요.
- 행렬 정규분포: [`MatrixNormal`](/api/stats/matrix-normal/)은 행렬의 원소를 한 줄로 늘어놓으면 다변량 정규분포예요.
- Wishart 분포: 평균이 0인 다변량 정규 표본 ν개로 만든 $\sum_i x_i x_i^{\mathsf T}$는 [`Wishart`](/api/stats/wishart/)(df=ν, scale=cov)를 따라요.

## 정확도와 범위

- `pdf`, `logpdf`, `entropy`: 공분산의 [조건수](/api/linalg/cond/) κ(cov) ≤ 1e9이고 d ≤ 100인 범위에서 보장해요. `pdf`는 상대오차 1e-14 이하, `logpdf`와 `entropy`는 |오차| ≤ 1e-14 · max(1, |값|)이에요(값이 0을 지나기 때문에 절대·상대를 섞은 기준이에요). κ = 1e9, d = 100에서 재 봐도 오차가 반올림 수준이에요. 거의 특이한 공분산에서도 정확도가 떨어지지 않아요.
- `cdf`, d = 2: P ≥ 1e-15이면 상관이 얼마든 상대 1e-14예요. 그보다 작은 확률에서는 상대오차가 대략 6 · 2.2e-16 · |ln P|로 천천히 커져요(P가 1e-300 근처에서 2.7e-13).
- `cdf`, d = 3: 음의 상관이 하나 이하이고 P ≥ 1e-15이거나, P ≥ 1e-10이고 문제가 잘 조건화돼 있으면(입력에 대한 상대 조건수 ≤ 100) 상대 1e-14예요. 그 밖에서는 재 본 최대 상대오차가 1.5e-13이에요.
- `cdf`, d ≥ 4: `atol`까지의 절대오차를 목표로 하는 통계적 어림이에요. 위의 오차 추정 설명을 참고하세요.
- 같은 입력이면 스레드 수와 상관없이 언제나 같은 비트예요.

어떻게 계산하는지는 [다변량 분포의 밀도](/internals/stats/multivariate/)와 [다변량 정규·t의 누적확률](/internals/stats/mvcdf/)에서 자세히 다뤄요.

## scipy를 아는 분께

- `scipy.stats.multivariate_normal(mean, cov)`에 해당해요. 평균의 이름은 `mu`이고 키워드로만 받아요. scipy는 매개변수와 `x`에 리스트도 받지만, sd는 `sd.ndarray`만 받아요. scipy의 `.mean`, `.cov` 속성 대신 `mean()`, `covariance()` 메서드가 있고, 속성 `mu`, `cov`는 준 값 그대로예요.
- `allow_singular`가 없어요. scipy 1.18.1은 특이 공분산에서 객체를 만들 때 `LinAlgError`를 내지만, sd는 객체를 만들고 모든 메서드가 NaN이에요.
- `pdf`의 결과 모양을 줄이지 않아요. scipy는 결과의 길이 1인 축을 없애지만, sd는 언제나 입력의 앞 축과 배치를 브로드캐스트한 모양이에요.
- `cdf`가 결정적이에요. scipy 1.18.1은 d ≥ 3에서 난수로 적분해 `rng`를 주지 않으면 부를 때마다 값이 조금씩 달라요(위의 d = 4 예에서 0.2000035, 0.1999963). sd의 기본 `atol`은 1e-6으로, scipy의 기본 `abseps=1e-5`보다 엄격해요.
- d = 2의 꼬리가 정확해요. 위의 `X.cdf([-10, -10])`를 scipy 1.18.1은 0.0으로, `[-5, -5]`(sd 8.247086432651666e-10)를 8.24708634716842e-10으로 계산해요.
- 조건수가 큰 공분산에서 `logpdf`가 정확해요. ρ = 1 − 2e-9(κ ≈ 1e9)인 2변량에서 x = (1, 0.99995)의 `logpdf`는 참값이 7.01813366608603인데 scipy 1.18.1은 7.018133666086312로 소수 열세째 자리부터 달라요. sd는 참값과 같아요.
- `lower_limit`, `logcdf`, `marginal`은 없어요.
