---
kind: function
title: Exponential
names: [Exponential]
group: 연속 분포
order: 7
signatures:
  - "sd.stats.Exponential(*, scale=1.0)"
summary: 무작위로 일어나는 사건을 처음 만날 때까지 기다리는 시간의 분포예요. 이미 기다린 시간과 상관없이 앞으로 기다릴 시간의 분포가 같은 '기억 없음' 성질이 있어요.
params:
  - name: scale
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 척도 매개변수이자 평균 대기 시간. 0보다 큰 유한한 실수이고 기본값은 1이에요. 단위 시간당 사건 수(rate)로 생각한다면 scale = 1 / rate예요. 0 이하, inf, NaN인 원소는 모든 메서드가 NaN이에요.
returns:
  type: Exponential
  desc: 지수분포 객체. pdf·cdf·icdf 같은 메서드, mean·variance 같은 요약값, sample을 가져요. scale은 읽기 전용 속성으로 준 값 그대로 남아요.
raises:
  - type: TypeError
    desc: scale을 위치로 넘겼을 때(Exponential(2.0)), rate처럼 모르는 키워드를 넘겼을 때, scale이 문자열·리스트·None·복소수이거나 complex128 배열일 때. 값이 정의역 밖인 것은 에러가 아니라 NaN이에요.
  - type: OverflowError
    desc: scale이 float로 바꿀 수 없을 만큼 큰 Python 정수일 때(10**400 등).
seeAlso: [gamma, chi-squared, weibull, laplace, geometric, poisson, methods, sample]

## 어떤 분포인가요

**지수분포**는 "무작위로 일어나는 사건을 처음 만날 때까지 기다리는 시간"의 분포예요. 콜센터에 전화가 평균 2분에 한 통씩 서로 무관하게 걸려 온다면, 지금부터 다음 전화까지의 시간이 척도 2인 지수분포를 따라요. 짧게 기다리는 일이 가장 흔하고, 오래 기다릴수록 드물어져요.

매개변수는 **척도** `scale` 하나이고, 이것이 평균 대기 시간이에요. 단위 시간당 사건 수인 **비율**(rate) $\lambda$로 생각한다면 `scale = 1 / λ`예요. 분당 0.5통이면 `scale=2.0`이에요.

이런 곳에서 써요.

- 손님, 요청, 전화가 도착하는 간격(대기행렬 모형)
- 마모되지 않고 갑자기 고장 나는 부품의 수명(고장률이 일정한 경우)
- 방사성 원자가 붕괴할 때까지의 시간(반감기 = `scale × ln 2`)
- 생존분석에서 위험률이 시간에 따라 변하지 않는 가장 간단한 모형

```python
>>> import stardust as sd
>>> W = sd.stats.Exponential(scale=2.0)
>>> W
Exponential(scale=2.0)
>>> W.ccdf(5.0)
0.0820849986238988
>>> W.median()
1.3862943611198906
>>> W.icdf(0.9)
4.605170185988092
```

5분 넘게 기다릴 확률은 약 8%예요. 절반의 경우는 1.39분 안에 오고, 90%의 경우는 4.6분 안에 와요. 평균(2분)보다 중앙값이 짧은 것은 가끔 아주 오래 기다리는 경우가 평균을 끌어올리기 때문이에요.

## 만들기와 매개변수

`scale`은 생략하면 1이에요. 줄 때는 이름을 붙여서 줘요. `rate`라는 매개변수는 없으니 비율을 알면 역수를 넣어요.

```python
>>> sd.stats.Exponential()
Exponential(scale=1.0)
>>> sd.stats.Exponential(2.0)
Traceback (most recent call last):
    ...
TypeError: Exponential(): takes no positional arguments but 1 was given
>>> sd.stats.Exponential(rate=0.5)
Traceback (most recent call last):
    ...
TypeError: Exponential(): unexpected keyword argument 'rate'
>>> sd.stats.Exponential(scale=1 / 0.5)
Exponential(scale=2.0)
```

`scale`은 0보다 큰 유한한 실수예요. 정의역 밖이면 에러 대신 모든 메서드가 NaN이에요.

```python
>>> sd.stats.Exponential(scale=0.0).mean()
nan
>>> sd.stats.Exponential(scale=-1.0).cdf(1.0)
nan
```

`scale`에 배열을 주면 원소마다 다른 지수분포가 되고, 메서드에 넣는 값과 [브로드캐스팅](/api/array/broadcasting/)해요.

```python
>>> sd.stats.Exponential(scale=sd.asarray([0.5, 1.0, 2.0])).pdf(0.0)
array([2.0, 1.0, 0.5], dtype=float64)
```

## 밀도와 누적분포

척도가 $\theta$인 지수분포의 밀도와 누적분포는 닫힌 꼴이에요.

$$
f(x) = \frac{1}{\theta} e^{-x/\theta}, \qquad F(x) = 1 - e^{-x/\theta}, \qquad 1 - F(x) = e^{-x/\theta}, \qquad x \ge 0
$$

분위수도 닫힌 꼴이라 $F^{-1}(p) = -\theta \ln(1 - p)$예요. 지지집합은 $[0, \infty)$이고, 음수에서 `pdf`와 `cdf`는 0이에요.

```python
>>> W.support()
(0.0, inf)
>>> W.pdf(1.0)
0.3032653298563167
>>> W.cdf(1.0), W.ccdf(1.0)
(0.3934693402873665, 0.6065306597126334)
>>> W.icdf(0.5)
1.3862943611198906
>>> W.pdf(-1.0)
0.0
```

### 기억 없음

지수분포의 가장 중요한 성질은 **기억 없음**(memorylessness)이에요. 이미 $s$만큼 기다렸어도, 앞으로 $t$ 넘게 더 기다릴 확률은 처음부터 $t$ 넘게 기다릴 확률과 같아요.

$$
P(X > s + t \mid X > s) = \frac{e^{-(s+t)/\theta}}{e^{-s/\theta}} = e^{-t/\theta} = P(X > t)
$$

```python
>>> W.ccdf(3.0 + 5.0) / W.ccdf(3.0)
0.08208499862389879
>>> W.ccdf(5.0)
0.0820849986238988
```

전화를 3분 기다렸다고 해서 곧 올 확률이 높아지지 않아요. 부품의 수명이라면 "오래 쓴 부품이나 새 부품이나 앞으로 고장 날 확률이 같다"는 뜻이라, 마모가 있는 부품에는 맞지 않아요. 그럴 때는 [베이불 분포](/api/stats/weibull/)나 [감마 분포](/api/stats/gamma/)를 써요.

### 0 근처와 꼬리

0 근처의 아주 작은 확률은 `1 - ccdf`로 만들면 사라져요. `cdf`는 $1 - e^{-x/\theta}$를 자릿수를 잃지 않게 직접 계산해요.

```python
>>> E = sd.stats.Exponential()
>>> 1 - E.ccdf(1e-20)
0.0
>>> E.cdf(1e-20)
1e-20
>>> E.icdf(1e-20)
1e-20
```

위꼬리는 `ccdf`가 float64 아래로 내려가면 `logccdf`로 받아요. 지수분포는 로그 위꼬리가 $-x/\theta$라서 아주 큰 값에서도 그대로 나와요.

```python
>>> E.ccdf(800.0)
0.0
>>> E.logccdf(800.0)
-800.0
>>> E.logccdf(1e300)
-1e+300
>>> E.iccdf(1e-300)
690.7755278982137
>>> E.ilogccdf(-1e300)
1e+300
```

메서드의 공통 의미는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

## 요약값

| 요약값 | 값 |
|---|---|
| `mean()` | $\theta$ |
| `variance()` | $\theta^2$ |
| `standard_deviation()` | $\theta$ |
| `skewness()` | $2$ |
| `kurtosis()` | $6$ |
| `median()` | $\theta \ln 2$ |
| `mode()` | $0$ |
| `entropy()` | $1 + \ln\theta$ |

평균과 표준편차가 같고, 왜도와 첨도는 척도와 상관없이 늘 2와 6이에요. 모양 매개변수가 없어서 모양이 하나뿐이기 때문이에요. `kurtosis()`는 정규분포를 0으로 두는 초과 첨도, `entropy()`는 미분 엔트로피(nat)예요.

```python
>>> Es = sd.stats.Exponential(scale=sd.asarray([0.5, 1.0, 2.0]))
>>> Es.mean()
array([0.5, 1.0, 2.0], dtype=float64)
>>> Es.variance()
array([0.25,  1.0,  4.0], dtype=float64)
>>> Es.median()
array([0.34657359027997264,  0.6931471805599453,  1.3862943611198906], dtype=float64)
>>> Es.skewness(), Es.kurtosis()
(array([2.0, 2.0, 2.0], dtype=float64), array([6.0, 6.0, 6.0], dtype=float64))
>>> Es.entropy()
array([0.3068528194400547,                1.0, 1.6931471805599454], dtype=float64)
```

중앙값 $\theta\ln 2$는 방사성 붕괴의 **반감기**예요. 탄소-14의 반감기 5730년에서 평균 수명(척도)은 $5730/\ln 2$이고, 원자 하나가 1만 년 뒤에도 남아 있을 확률은 이래요.

```python
>>> C14 = sd.stats.Exponential(scale=5730 / sd.log(2.0))
>>> C14.median()
5730.0
>>> C14.ccdf(10000.0)
0.2982924364237143
```

## 다른 분포와의 관계

### 감마·카이제곱·베이불의 특별한 경우

지수분포는 모양이 1인 [감마 분포](/api/stats/gamma/)이고, 모양이 1인 [베이불 분포](/api/stats/weibull/)이기도 해요. 척도가 2이면 자유도 2인 [카이제곱 분포](/api/stats/chi-squared/)예요.

```python
>>> x = sd.asarray([0.5, 2.0, 7.0])
>>> W.cdf(x)
array([0.22119921692859512,  0.6321205588285577,  0.9698026165776814], dtype=float64)
>>> sd.stats.Weibull(c=1.0, scale=2.0).cdf(x)
array([0.22119921692859512,  0.6321205588285577,  0.9698026165776814], dtype=float64)
>>> sd.stats.Gamma(a=1.0, scale=2.0).cdf(x)
array([0.22119921692859512,  0.6321205588285577,  0.9698026165776815], dtype=float64)
>>> sd.stats.ChiSquared(df=2).cdf(x)
array([0.22119921692859512,  0.6321205588285577,  0.9698026165776815], dtype=float64)
```

감마·카이제곱과 마지막 자리 하나가 다른 것은 서로 다른 식으로 계산하기 때문이에요. 모두 오차 한계 안이에요.

### 더하면 감마, 최솟값은 다시 지수

- 같은 척도 $\theta$인 지수분포 $n$개를 더하면 모양 $n$인 감마 분포예요. 전화 $n$통이 올 때까지의 시간이에요.
- 서로 독립인 지수분포의 **최솟값**은 다시 지수분포이고, 비율이 더해져요. 척도 2와 3인 두 대기 시간 중 먼저 끝나는 것은 비율 $1/2 + 1/3$, 곧 척도 1.2인 지수분포를 따라요. 두 창구 중 먼저 비는 쪽을 기다리는 시간이에요.

```python
>>> rng = sd.random.default_rng(9)
>>> a = sd.stats.Exponential(scale=2.0).sample(100000, rng=rng)
>>> b = sd.stats.Exponential(scale=3.0).sample(100000, rng=rng)
>>> sd.mean(sd.minimum(a, b))
1.1966831496279027
>>> 1 / (1 / 2 + 1 / 3)
1.2000000000000002
```

### 균등 난수에서 만들기

$U$가 0과 1 사이의 균등 난수이면 $-\theta \ln U$는 척도 $\theta$인 지수분포를 따라요. 역함수에 균등 난수를 넣는 방법이에요.

```python
>>> u = sd.random.default_rng(4).random(100000)
>>> e = -sd.log(u) * 2.0
>>> sd.mean(e)
1.9932188170923049
>>> sd.quantile(e, 0.5)
1.3846182951628285
```

### 포아송·기하·라플라스

- 사건 간격이 척도 $\theta$인 지수분포이면, 길이 $t$인 시간 동안 일어나는 사건 수는 평균 $t/\theta$인 [포아송 분포](/api/stats/poisson/)를 따라요.
- [기하 분포](/api/stats/geometric/)는 지수분포의 이산판이에요. 성공 확률이 $p = 1 - e^{-1/\theta}$인 시행에서 처음 성공할 때까지의 시행 횟수가 $k$를 넘을 확률이 $e^{-k/\theta}$로 같아요.
- 지수분포 두 개의 차는 [라플라스 분포](/api/stats/laplace/)예요.

```python
>>> sd.stats.Geometric(p=1 - sd.exp(-0.5)).ccdf(3.0)
0.22313016014842982
>>> W.ccdf(3.0)
0.22313016014842982
```

## 정확도와 범위

지수분포는 모든 메서드가 닫힌 꼴이라 **정의역 전체**에서 정확도를 보장해요. 척도와 입력이 float64로 나타낼 수 있는 어떤 값이어도 모든 메서드가 참값 대비 상대오차 1e-14 이하예요(`logpdf`와 `entropy`는 $10^{-14}\cdot\max(1, |\text{값}|)$). 보장 영역 안에서 메서드별로 잰 최대 오차는 6.1e-16이에요.

$x/\theta$가 float64 범위를 넘는 극단적인 경우에는 극한값을 내요.

```python
>>> sd.stats.Exponential(scale=1e-300).cdf(1e-300)
0.6321205588285577
>>> sd.stats.Exponential(scale=5e-324).ccdf(1.0)
0.0
>>> sd.stats.Exponential(scale=5e-324).logccdf(1.0)
-inf
```

마지막 줄의 참값은 $-1/(5\times10^{-324}) \approx -2\times10^{323}$이라 float64의 가장 큰 수를 넘어서 `-inf`예요.

계산 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에서 설명해요.

## scipy를 아는 분께

- `scipy.stats.expon`에 해당해요. 척도 이름 `scale`은 scipy와 같아요. 메서드 이름은 scipy의 새 분포 API를 따라요(`sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`).
- `loc`이 없어요. 지지집합은 언제나 $[0, \infty)$예요.
- `scale`은 키워드로만 받아요. `Exponential(2.0)`은 `TypeError`예요.
- `kurtosis()`는 초과 첨도예요(scipy `expon.stats(moments='k')`와 같은 6이에요).
- `x / scale`을 반올림하지 않고 계산해서, 그 몫이 클 때 scipy보다 정확해요. 예를 들어 `Exponential(scale=0.1).ccdf(70.0)`은 참값 대비 7.4e-17이고, scipy `expon.sf(70, scale=0.1)`은 3.9e-14가 틀려요.
- `sample`은 `rng`를 꼭 받아요. 값은 numpy·scipy와 달라요.
