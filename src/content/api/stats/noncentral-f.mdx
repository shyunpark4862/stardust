---
kind: function
title: NoncentralF
names: [NoncentralF]
group: 비중심 분포
order: 3
signatures:
  - "sd.stats.NoncentralF(*, dfn, dfd, nc)"
summary: 비중심 F 분포예요. 집단 사이에 실제 차이가 있을 때 분산분석이나 회귀의 F 통계량이 따르는 분포라서, F 검정의 검정력과 표본 크기를 계산할 때 써요. nc = 0이면 보통의 F 분포와 같아요.
params:
  - name: dfn
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 분자 자유도. 0보다 큰 실수예요(정수가 아니어도 돼요). inf이면 극한 분포 InverseGamma(a=dfd/2, scale=dfd/2)예요. 0 이하이거나 NaN이면, 그리고 두 자유도가 모두 inf이면 그 원소의 모든 결과가 NaN이에요. dfn이나 dfd가 2⁻¹⁰²¹(약 4.5e-308)보다 작은 양수이면 F처럼 밀도, 확률, 분위수, median, entropy, 표본이 NaN이에요(다른 자유도가 inf이면 극한 분포를 따라요).
  - name: dfd
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 분모 자유도. 0보다 큰 실수예요. inf이면 극한 분포인 비중심 카이제곱 χ'²(dfn, nc)/dfn이에요. 0 이하이거나 NaN이면 그 원소의 모든 결과가 NaN이에요.
  - name: nc
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 비중심 모수 λ. 0 이상인 유한한 실수예요. 0이면 중심 F 분포예요. 음수, inf, NaN이면 그 원소의 모든 결과가 NaN이에요.
returns:
  type: NoncentralF
  desc: 분포 객체. 지지집합은 [0, ∞)이고, pdf·cdf·icdf 같은 메서드와 mean·mode 같은 요약값, sample을 가져요. 매개변수 dfn, dfd, nc는 준 값 그대로인 읽기 전용 속성이에요.
raises:
  - type: TypeError
    desc: 매개변수를 위치 인자로 주었을 때, dfn·dfd·nc 가운데 하나를 빠뜨렸을 때, 매개변수가 실수나 sd.ndarray가 아닐 때(리스트, 문자열, 복소수 포함).
  - type: ValueError
    desc: 배열 매개변수끼리 브로드캐스트할 수 없을 때.
seeAlso: [f, noncentral-chi-squared, noncentral-t, chi-squared, methods, sample]

>>> F = sd.stats.NoncentralF(dfn=3, dfd=20, nc=5)

## 어떤 분포인가요

$X$가 자유도 $d_1$, 비중심 모수 $\lambda$인 [비중심 카이제곱](/api/stats/noncentral-chi-squared/) 변수이고, $V$가 자유도 $d_2$인 중심 카이제곱 변수이며 둘이 독립일 때

$$F = \frac{X / d_1}{V / d_2}$$

가 분자 자유도 $d_1$, 분모 자유도 $d_2$, 비중심 모수 $\lambda$인 비중심 F 분포를 따라요. 분자만 비중심이고 분모는 그대로라는 점이 핵심이에요. 효과는 분자에만 들어가고, 분모는 집단 안의 흩어짐(잡음)만 재기 때문이에요.

이런 곳에 써요.

- **분산분석의 검정력**: 집단 $k$개, 전체 표본 $N$개인 일원 분산분석에서 효과 크기를 $f$(집단 평균들의 표준편차를 집단 안 표준편차로 나눈 값)로 나타내면, F 통계량은 $d_1 = k - 1$, $d_2 = N - k$, $\lambda = f^2 N$인 비중심 F를 따라요.
- **회귀분석의 F 검정**: 설명 변수들이 한꺼번에 의미가 있는지 보는 전체 F 검정, 변수 묶음을 더했을 때의 부분 F 검정의 검정력도 같은 방식이에요.
- **실험 설계**: 원하는 검정력을 얻는 데 필요한 반복 수를 미리 정할 때 써요.

| `dfn` | 분자 자유도 $d_1$ | $0 < d_1 \le \infty$ (정수가 아니어도 돼요) |
| `dfd` | 분모 자유도 $d_2$ | $0 < d_2 \le \infty$ (둘 다 $\infty$는 안 돼요) |
| `nc` | 비중심 모수 $\lambda$ | $0 \le \lambda < \infty$ |

```python
>>> F.dfn, F.dfd, F.nc
(3, 20, 5)
```

키워드로만 받으니 순서를 헷갈릴 걱정은 없어요. 위치 인자로 주거나 하나를 빠뜨리면 `TypeError`예요.

```python
>>> sd.stats.NoncentralF(3, 20, 5)
Traceback (most recent call last):
    ...
TypeError: NoncentralF(): takes no positional arguments but 3 were given
>>> sd.stats.NoncentralF(dfn=3, dfd=20)
Traceback (most recent call last):
    ...
TypeError: NoncentralF(): missing 1 required keyword-only argument: 'nc'
>>> sd.stats.NoncentralF(dfn=3, dfd="20", nc=5)
Traceback (most recent call last):
    ...
TypeError: NoncentralF(): 'dfd' must be a real number or an sd.ndarray, not str
```

배열 매개변수는 서로 [브로드캐스트](/api/array/broadcasting/)하고, 브로드캐스트할 수 없는 모양이면 만들 때 `ValueError`예요. 값이 정의역 밖이면 에러 대신 그 원소의 결과가 NaN이에요. 자유도 하나가 `inf`이면 그 극한 분포예요([분모 자유도가 크면 비중심 카이제곱이에요](#분모-자유도가-크면-비중심-카이제곱이에요)). 두 자유도가 모두 `inf`이거나 `nc`가 `inf`이면 NaN이에요.

```python
>>> sd.stats.NoncentralF(dfn=sd.asarray([3.0, 0.0, 3.0, 3.0]), dfd=sd.asarray([20.0, 20.0, -1.0, 20.0]), nc=sd.asarray([5.0, 5.0, 5.0, -1.0])).cdf(2.0)
array([0.4031300850345886,                nan,                nan,
                      nan], dtype=float64)
>>> sd.stats.NoncentralF(dfn=3, dfd=sd.inf, nc=5).cdf(2.0)
0.4101075585254692
>>> sd.stats.NoncentralF(dfn=sd.inf, dfd=sd.inf, nc=5).cdf(2.0)
nan
```

## 밀도와 누적분포

비중심 카이제곱처럼, 이 분포도 분자 자유도가 $2j$씩 늘어난 분포들을 포아송 확률로 섞은 것이에요. 누적분포는 [정칙화된 불완전 베타 함수](/api/special/betainc/) $I$로 이렇게 쓰여요.

$$F(x) = \sum_{j=0}^{\infty} e^{-\lambda/2}\frac{(\lambda/2)^j}{j!}\; I_{y}\!\left(\frac{d_1}{2} + j,\ \frac{d_2}{2}\right), \qquad y = \frac{d_1 x}{d_1 x + d_2}$$

밀도도 같은 무게로 섞은 꼴이에요. $j = 0$ 항만 남기면 중심 F 분포예요.

지지집합은 $[0, \infty)$예요. 0에서의 밀도는 분자 자유도에 따라 달라요. $d_1 < 2$면 발산하고(inf), $d_1 = 2$면 양수, $d_1 > 2$면 0이에요. 지지집합 밖(음수)에서 `pdf`는 0, `cdf`는 0이에요.

```python
>>> F.support()
(0.0, inf)
>>> sd.stats.NoncentralF(dfn=sd.asarray([1.0, 2.0, 3.0]), dfd=20, nc=5).pdf(0.0)
array([               inf, 0.0820849986238988,                0.0], dtype=float64)
>>> F.pdf(-1.0), F.cdf(-1.0)
(0.0, 0.0)
```

`icdf`는 아래꼬리 확률을, `iccdf`는 위꼬리 확률을 거꾸로 풀어요.

```python
>>> F.icdf(0.95)
7.2491563539448105
>>> F.cdf(F.icdf(0.95))
0.95
>>> F.iccdf(0.01)
10.847465489316479
```

### 꼬리 확률

위꼬리 확률은 `1 - cdf`가 아니라 `ccdf`로 구하세요. 아주 작은 꼬리 확률도 앞자리가 맞게 나와요. 확률이 float64의 가장 작은 수보다 작아지는 곳에서는 `logcdf`, `logccdf`가 확률의 로그를 줘요.

```python
>>> F.ccdf(1e10)
3.0775143838582282e-89
>>> F.logccdf(1e300)
-6881.302720695611
>>> F.cdf(1e-100)
1.1763250821521466e-151
>>> F.logcdf(1e-320)
-1107.3810511877768
>>> F.iccdf(1e-200)
1.4087048492811802e+21
```

메서드 하나하나의 공통 의미는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

## 검정력 계산하기

세 집단을 비교하는 일원 분산분석으로 예를 들어 볼게요. 집단마다 20명씩, 전체 60명이고 유의수준은 5%예요. 효과가 없을 때의 분포(중심 F)에서 위꼬리 5%의 경계가 기준값이에요.

```python
>>> k, m = 3, 20
>>> N = k * m
>>> crit = sd.stats.F(dfn=k - 1, dfd=N - k).iccdf(0.05)
>>> crit
3.158842719260648
>>> sd.stats.NoncentralF(dfn=k - 1, dfd=N - k, nc=0).ccdf(crit)
0.05000000000000001
```

이제 효과 크기가 $f = 0.25$(흔히 "중간 크기"로 부르는 값)라고 해요. 비중심 모수는 $\lambda = f^2 N = 3.75$이고, 검정력은 비중심 F가 기준값을 넘을 확률이에요.

```python
>>> sd.stats.NoncentralF(dfn=k - 1, dfd=N - k, nc=0.25**2 * N).ccdf(crit)
0.37443107625635436
```

집단마다 20명으로는 37%밖에 안 돼요. 집단 크기를 배열로 주면 분모 자유도, 기준값, $\lambda$가 원소마다 달라져도 한꺼번에 계산돼요. 검정력 80%를 넘으려면 집단마다 53명이 필요해요.

```python
>>> ms = sd.asarray([20.0, 40.0, 52.0, 53.0, 60.0])
>>> Ns = k * ms
>>> cs = sd.stats.F(dfn=k - 1, dfd=Ns - k).iccdf(0.05)
>>> sd.stats.NoncentralF(dfn=k - 1, dfd=Ns - k, nc=0.25**2 * Ns).ccdf(cs)
array([0.37443107625635436,  0.6756744946707953,  0.7967328616673731,
        0.8048872853010696,  0.8546380910187601], dtype=float64)
```

<Callout type="warn" title="비중심 모수는 효과 크기가 아니에요">

`nc`에는 효과 크기 $f$가 아니라 전체 표본 크기를 곱한 $\lambda = f^2 N$을 넣어야 해요. 효과 크기를 $\eta^2$(설명된 분산의 비율)으로 받았다면 $f^2 = \eta^2 / (1 - \eta^2)$로 바꾼 다음 곱하세요.

</Callout>

## 요약값

| 요약값 | 식 | 유한한 조건 |
|---|---|---|
| `mean()` | $\dfrac{d_2 (d_1 + \lambda)}{d_1 (d_2 - 2)}$ | $d_2 > 2$ |
| `variance()` | $2\left(\dfrac{d_2}{d_1}\right)^2 \dfrac{(d_1 + \lambda)^2 + (d_1 + 2\lambda)(d_2 - 2)}{(d_2 - 2)^2 (d_2 - 4)}$ | $d_2 > 4$ |
| `skewness()` | 닫힌 꼴(길어서 생략) | $d_2 > 6$ |
| `kurtosis()` (초과 첨도) | 닫힌 꼴(길어서 생략) | $d_2 > 8$ |
| `median()` | 닫힌 꼴이 없어요. `icdf(0.5)`와 같아요 | |
| `mode()` | 밀도가 가장 큰 점. 아래 설명 | |
| `entropy()` | $-\int f \log f\,dx$ (nat) | |

```python
>>> F.mean(), F.variance()
(2.962962962962963, 5.109739368998628)
>>> F.standard_deviation()
2.260473262172908
>>> F.skewness()
1.959244585371711
>>> F.kurtosis()
7.585391906413483
>>> F.median()
2.4234834710663886
```

### 분모 자유도가 작아서 모멘트가 없을 때

모멘트가 유한한지는 분모 자유도 $d_2$에만 달려 있어요. 값이 언제나 0 이상이라 모멘트는 발산하면 $+\infty$예요. 그래서 발산하면 inf이고, 분산이 유한하지 않으면 분산으로 나누는 왜도와 첨도는 NaN이에요. 평균이 무한하면 평균 둘레로 재는 분산도 NaN이에요.

| 분모 자유도 | `mean` | `variance` | `skewness` | `kurtosis` |
|---|---|---|---|---|
| $d_2 \le 2$ | inf | NaN | NaN | NaN |
| $2 < d_2 \le 4$ | 값 | inf | NaN | NaN |
| $4 < d_2 \le 6$ | 값 | 값 | inf | inf |
| $6 < d_2 \le 8$ | 값 | 값 | 값 | inf |
| $d_2 > 8$ | 값 | 값 | 값 | 값 |

```python
>>> G = sd.stats.NoncentralF(dfn=3, dfd=sd.asarray([2.0, 3.0, 5.0, 7.0, 9.0]), nc=2)
>>> G.mean()
array([               inf,                5.0,  2.777777777777778,
       2.3333333333333335, 2.1428571428571432], dtype=float64)
>>> G.variance()
array([               nan,                inf, 28.395061728395063,
        8.711111111111112,  5.436734693877552], dtype=float64)
>>> G.skewness()
array([               nan,                nan,                inf,
       10.540925533894598,  4.722594824800764], dtype=float64)
>>> G.kurtosis()
array([               nan,                nan,                inf,
                      inf, 111.68590211833452], dtype=float64)
```

### mode

`mode()`는 밀도가 가장 큰 점이에요. 닫힌 꼴이 없어서 밀도의 도함수가 0이 되는 점을 풀어서 구하고, 보장 영역에서 상대 1e-14로 맞아요. 성질은 이래요.

- $d_1 < 2$면 0에서 밀도가 발산하므로 최빈값은 0이에요.
- $d_1 = 2$면 $\lambda \le 2$일 때 0이고, 그보다 크면 양수예요.
- $d_1 > 2$면 언제나 양수예요. $\lambda = 0$이면 중심 F의 최빈값 $\dfrac{d_1 - 2}{d_1}\cdot\dfrac{d_2}{d_2 + 2}$예요.

```python
>>> F.mode()
1.485115671004336
>>> sd.stats.NoncentralF(dfn=1, dfd=20, nc=5).mode()
0.0
>>> sd.stats.NoncentralF(dfn=2, dfd=20, nc=sd.asarray([0.0, 1.0, 2.0, 3.0, 5.0])).mode()
array([               0.0,                0.0,                0.0,
       0.6790836412919741,  1.694902913278496], dtype=float64)
>>> sd.stats.NoncentralF(dfn=3, dfd=20, nc=sd.asarray([0.0, 5.0, 15.0])).mode()
array([0.303030303030303, 1.485115671004336,  4.46838276633578], dtype=float64)
```

$\lambda$가 약 1.3e8을 넘으면 `mode()`는 NaN이에요. 보장 영역($\lambda \le 10^4$)보다 훨씬 바깥이에요.

```python
>>> sd.stats.NoncentralF(dfn=3, dfd=20, nc=2e8).mode()
nan
```

### entropy는 보장하지 않아요

`entropy()`는 미분 엔트로피(단위 nat)예요. 닫힌 꼴이 없어서 수치 적분으로 구하고, 다른 메서드와 달리 **1e-14 정확도를 약속하지 않아요.** 값은 대개 앞자리가 많이 맞지만 마지막 몇 자리는 믿지 마세요.

보장 영역 안에서도 NaN일 수 있어요. 분모 자유도가 아주 작아서(예: `dfd = 0.01`) 확률 질량의 일부가 float64로 나타낼 수 있는 가장 큰 수보다 멀리 퍼져 있을 때, 그리고 적분이 정해진 계산량 안에 끝나지 않을 때예요.

```python
>>> F.entropy()
1.989618774128096
>>> sd.stats.NoncentralF(dfn=3, dfd=0.01, nc=1).entropy()
nan
```

## 표본

`sample`은 이 분포를 따르는 난수를 뽑아요. `rng`에 [`sd.random.default_rng`](/api/random/default_rng/)로 만든 생성기를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(3)
>>> F.sample(rng=rng)
2.0577667422997346
>>> F.sample((4,), rng=rng)
array([2.0858006021749453,  1.354002792911061,  1.150755964739628,
        7.916021339316656], dtype=float64)
>>> s = F.sample((100000,), rng=rng)
>>> sd.mean(s), sd.var(s)
(2.958843214245383, 5.071218624052835)
```

표본의 평균과 분산이 위의 `mean()` 2.963, `variance()` 5.110에 가까워요.

`dfn`이나 `dfd` 가운데 하나라도 $2^{-1021}$(약 4.5e-308)보다 작으면 표본은 NaN이에요. 값 메서드와 같은 경계이고, `nc = 0`이어도 그래요. 중심 [`F`](/api/stats/f/)의 표본은 이 경계 아래에서도 극한값(0이나 inf)을 내서, 여기서는 `nc = 0`이어도 두 분포의 표본이 달라요. 다른 자유도가 inf이면 아래의 극한 분포에서 뽑아요.

```python
>>> sd.stats.NoncentralF(dfn=2**-1022, dfd=5, nc=0).sample(rng=sd.random.default_rng(0))
nan
>>> sd.stats.F(dfn=2**-1022, dfd=5).sample(rng=sd.random.default_rng(0))
0.0
```

## 다른 분포와의 관계

### nc = 0이면 중심 F예요

$\lambda = 0$이면 보통의 F 분포 [`F(dfn=d₁, dfd=d₂)`](/api/stats/f/)가 돼요. 밀도, 누적분포와 그 역함수, 모멘트, `median`, `mode`, `entropy`가 마지막 비트까지 같고, 같은 `rng` 상태에서 뽑은 표본도 같아요.

```python
>>> C = sd.stats.F(dfn=3, dfd=20)
>>> F0 = sd.stats.NoncentralF(dfn=3, dfd=20, nc=0)
>>> F0.cdf(1.5) == C.cdf(1.5), F0.pdf(1.5) == C.pdf(1.5), F0.icdf(0.3) == C.icdf(0.3)
(True, True, True)
>>> F0.mean(), F0.variance(), F0.mode()
(1.1111111111111112, 1.080246913580247, 0.303030303030303)
>>> C.mean(), C.variance(), C.mode()
(1.1111111111111112, 1.080246913580247, 0.303030303030303)
>>> F0.median() == C.median(), F0.kurtosis() == C.kurtosis()
(True, True)
>>> F0.sample((3,), rng=sd.random.default_rng(3))
array([0.6046383424697521, 0.6325493599286396, 0.6790133692085232], dtype=float64)
>>> C.sample((3,), rng=sd.random.default_rng(3))
array([0.6046383424697521, 0.6325493599286396, 0.6790133692085232], dtype=float64)
```

### 분모 자유도가 크면 비중심 카이제곱이에요

$d_2$가 커지면 분모 $V/d_2$가 1에 몰려서, $d_1 F$는 [비중심 카이제곱](/api/stats/noncentral-chi-squared/) $\chi'^2(d_1, \lambda)$에 가까워져요. 그래서 $P(F \le x) \approx P(X \le d_1 x)$예요. 그 극한인 `dfd = inf`는 비중심 카이제곱을 $d_1$로 나눈 분포와 똑같아요.

```python
>>> H = sd.stats.NoncentralF(dfn=3, dfd=1e8, nc=5)
>>> H.cdf(2.0)
0.4101075571584545
>>> sd.stats.NoncentralF(dfn=3, dfd=sd.inf, nc=5).cdf(2.0)
0.4101075585254692
>>> sd.stats.NoncentralChiSquared(df=3, nc=5).cdf(3 * 2.0)
0.4101075585254692
```

거꾸로 분자 자유도가 inf이면 분자 $\chi'^2(d_1, \lambda)/d_1$이 1에 몰려서 `nc`와 상관없이 $d_2/V$, 곧 [역감마 분포](/api/stats/inverse-gamma/) $\mathrm{InverseGamma}(d_2/2,\ d_2/2)$예요. 중심 F의 `dfn = inf`와 같아요.

```python
>>> sd.stats.NoncentralF(dfn=sd.inf, dfd=20, nc=5).cdf(2.0)
0.9681719426937951
>>> sd.stats.InverseGamma(a=10.0, scale=10.0).cdf(2.0)
0.9681719426937951
```

### 비중심 t의 제곱

[비중심 t](/api/stats/noncentral-t/) 변수를 제곱하면 분자 자유도 1인 비중심 F예요. `NoncentralT(df=ν, nc=δ)`의 $T^2$은 `NoncentralF(dfn=1, dfd=ν, nc=δ²)`를 따라요. 그래서 양측 t 검정의 검정력을 이 분포 하나로 계산할 수도 있어요.

### special 함수

누적분포와 그 역함수는 특수함수 [`sd.special.ncfdtr`, `ncfdtrc`, `ncfdtri`](/api/special/ncfdtr/)로도 구할 수 있어요. `cdf`, `ccdf`와 같은 값이에요. 특수함수 쪽은 인자 순서가 `(dfn, dfd, nc, x)`이고 밀도와 요약값은 없어요.

```python
>>> sd.special.ncfdtr(3, 20, 5, 2.0) == F.cdf(2.0)
True
```

## 정확도와 범위

**보장 영역**은 $0.01 \le d_1, d_2 \le 10^4$, $\lambda \le 10^4$이고, 확률은 1e-300까지예요. 이 안에서 `pdf`, `cdf`, `ccdf`와 그 log, 역함수 넷, 모멘트, `median`, `mode`가 참값 대비 1e-14 안이에요. 꼬리 확률도 상대오차로 재므로 아주 작은 확률도 앞자리 14자리 정도가 맞아요. `logpdf`처럼 값이 0을 지날 수 있는 것은 $|\text{오차}| \le 10^{-14}\max(1, |\text{값}|)$이고, 역함수는 입력의 조건수만큼 느슨해요(자세한 기준은 [분포 메서드 한눈에 보기](/api/stats/methods/)). 단 `entropy`는 보장하지 않아요.

작은 쪽 꼬리 확률이 1e-300보다 작아지는 $x$와, 1e-300보다 작은 확률을 주는 역함수는 보장 밖이에요. 값은 계산하지만 정확도를 약속하지는 않아요.

보장 영역 밖도 값을 계산해요. 다만 $\lambda$가 아주 커서 계산이 정해진 양 안에 끝나지 않는 곳과, 자유도가 너무 작아 그 절반을 float64로 정확히 나타낼 수 없는 곳에서는 NaN을 돌려줘요.

| 어디서 | NaN이 되는 것 |
|---|---|
| `nc`가 약 1.3e8 초과 | `pdf`, `logpdf`, `mode` |
| `nc`가 약 1.47e9 초과 | 평균 근처의 `cdf` 계열, 역함수, `median` |
| $d_1$이나 $d_2$가 $2^{-1021}$(약 4.5e-308) 미만이고 다른 자유도가 유한 | `pdf`, `cdf` 계열, 역함수, `median`, `entropy`, 표본 |
| `ilogcdf`, `ilogccdf`의 입력이 $-2^{62}$ 이하 | 결과 |

경계 바로 위의 아주 작은 $d_1$은 값이에요. 포아송 혼합의 $j = 0$ 항(무게 $e^{-\lambda/2}$)은 분자 자유도가 거의 0인 F라서 질량이 0 바로 위에 몰리고, $j \ge 1$ 항은 분자를 $d_1$로 나누니 아주 큰 값(여기서는 $10^{307}$ 근처)으로 밀려나요. 그래서 그 사이의 넓은 구간에서 `cdf`는 $e^{-\lambda/2}$예요.

```python
>>> G = sd.stats.NoncentralF(dfn=2**-1021, dfd=5, nc=2)
>>> G.cdf(1.0), G.ccdf(1.0), G.logcdf(1.0)
(0.36787944117144233, 0.6321205588285577, -1.0)
>>> G.cdf(1e300), G.median()
(0.3678794493570315, 1.8609659255940716e+307)
>>> sd.stats.NoncentralF(dfn=2**-1022, dfd=5, nc=2).cdf(1.0)
nan
```

평균과 분산은 이런 매개변수에서도 값이 나와요.

```python
>>> huge = sd.stats.NoncentralF(dfn=3, dfd=20, nc=2e8)
>>> huge.mean(), huge.cdf(7e7), huge.pdf(7e7)
(74074075.18518518, 0.5187326793024127, nan)
```

계산 방법은 [극값·수명·비중심 분포의 구현](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- scipy의 `scipy.stats.ncf(dfn, dfd, nc)`에 해당해요. 매개변수 이름은 같지만 **키워드로만** 받아요. `loc`, `scale`은 없어요.
- 메서드 이름이 달라요. `sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`예요.
- `kurtosis()`는 초과 첨도예요(`ncf.stats(moments='k')`와 같은 뜻).
- 발산하는 모멘트가 달라요. scipy는 발산하는 모멘트를 NaN으로 내지만, stardust는 $+\infty$로 발산하면 inf예요. $d_2 \le 2$의 평균, $2 < d_2 \le 4$의 분산, $4 < d_2 \le 6$의 왜도, $4 < d_2 \le 8$의 첨도가 그래요.
- 자유도 하나가 inf이면 극한 분포예요. scipy `ncf.cdf(2.0, 3, inf, 5)`와 `ncf.cdf(2.0, inf, 6, 5)`는 NaN이에요.
- 깊은 꼬리에서 scipy가 크게 틀리는 곳에서도 값이 맞아요. 예를 들어 `NoncentralF(dfn=300, dfd=5, nc=2500).cdf(0.02)`는 3.1652e-283인데, `scipy.stats.ncf.cdf(0.02, 300, 5, 2500)`은 4.348e-214예요(자릿수가 69개 틀려요).
