## 어떤 분포인가요

[이항 분포](/api/stats/binomial/)는 성공 확률 $p$가 정해진 시행을 $n$번 해서 성공한 횟수예요. 그런데 현실에서는 $p$ 자체가 대상마다 다를 때가 많아요. 선수마다 자유투 성공률이 다르고, 날마다 광고의 클릭률이 달라요. **베타이항 분포**(beta-binomial distribution)는 이 흔들림까지 담아서, 성공 횟수를 두 단계로 만들어요.

1. 먼저 성공 확률 $p$를 [베타 분포](/api/stats/beta/) `Beta(a, b)`에서 하나 뽑아요.
2. 그 $p$로 `Binomial(n, p)`를 따라 성공 횟수를 세요.

$p$가 흔들리는 만큼 결과가 이항 분포보다 더 넓게 퍼지는데, 이를 **과대산포**(overdispersion)라고 불러요. 이런 곳에서 써요.

- 집단마다 다른 성공률: 학교별 합격자 수, 병원별 회복 환자 수, 타자별 안타 수
- 과대산포가 있는 개수 자료: 이항 분포로는 분산이 너무 작게 나올 때
- 베이즈 추론의 예측분포: 성공률의 사전분포가 베타일 때, 다음 $n$번에서 나올 성공 횟수

```python
>>> import stardust as sd
>>> X = sd.stats.BetaBinomial(n=10, a=2.0, b=3.0)
>>> X.pmf(4)
0.13986013986013984
>>> X.mean(), X.variance()
(4.0, 6.0)
>>> sd.stats.Binomial(n=10, p=0.4).variance()
2.4
```

평균은 성공률이 0.4로 고정된 `Binomial(n=10, p=0.4)`와 같은 4인데, 분산은 2.4가 아니라 6이에요.

## 만들기와 매개변수

| 매개변수 | 뜻 | 정의역 |
|---|---|---|
| `n` | 시행 횟수 | 0 이상의 정수 |
| `a` | 성공률을 뽑는 베타 분포의 첫 모양 매개변수 | 0보다 큰 유한한 실수 |
| `b` | 베타 분포의 둘째 모양 매개변수 | 0보다 큰 유한한 실수 |

셋 다 키워드로만 주고 기본값이 없어요. 성공률의 평균은 $a/(a+b)$이고, $a + b$가 클수록 성공률이 그 평균 근처에 몰려요. 그래서 $a/(a+b)$는 "평균 성공률", $a + b$는 "성공률이 얼마나 일정한지"로 읽으면 돼요.

정의역 밖이면 에러 없이 NaN이에요. `n`이 정수가 아니거나 음수일 때, `a`나 `b`가 0 이하이거나 inf일 때예요. `n = 0`은 언제나 0이 나오는 분포예요.

```python
>>> sd.stats.BetaBinomial(n=10.5, a=1.0, b=1.0).pmf(0)
nan
>>> sd.stats.BetaBinomial(n=10, a=0.0, b=1.0).mean()
nan
>>> sd.stats.BetaBinomial(n=0, a=1.0, b=1.0).pmf(0)
1.0
>>> sd.stats.BetaBinomial(n=10, a=2.0, b=3.0)
BetaBinomial(n=10, a=2.0, b=3.0)
```

배열 매개변수는 서로 브로드캐스트해요. 아래는 평균 성공률을 0.4로 두고 $a + b$만 키운 셋이에요.

```python
>>> s = sd.asarray([1.0, 5.0, 50.0])
>>> sd.stats.BetaBinomial(n=10, a=0.4 * s, b=0.6 * s).variance()
array([             13.2,               6.0, 2.823529411764706], dtype=float64)
```

$a + b$가 커질수록 분산이 이항 분포의 2.4로 줄어들어요.

## 확률질량과 누적분포

성공률 $p$에 대해 이항 분포의 확률을 베타 분포로 평균 내면 이런 꼴이 나와요.

$$
P(X = k) = \int_0^1 \binom{n}{k} p^k (1-p)^{n-k} \,\frac{p^{a-1}(1-p)^{b-1}}{B(a, b)}\, dp
= \binom{n}{k}\frac{B(k + a,\ n - k + b)}{B(a, b)}
$$

$B$는 [베타 함수](/api/special/beta/)이고, $k = 0, 1, \dots, n$이에요. 누적분포 `cdf`는 닫힌 꼴이 없어서 이 확률을 더해서 구해요. 정수가 아닌 $k$의 `pmf`는 0, `cdf`는 그 아래 정수에서의 값이에요. 공통 규칙은 [분포의 메서드](/api/stats/methods/)에 있어요.

```python
>>> X.support()
(0.0, 10.0)
>>> X.pmf(sd.arange(0.0, 11.0))
array([ 0.06593406593406594,  0.10989010989010989,  0.13486513486513485,
        0.14385614385614387,  0.13986013986013984,  0.12587412587412586,
        0.10489510489510491,  0.07992007992007992,  0.05394605394605395,
       0.029970029970029972, 0.010989010989010988], dtype=float64)
>>> X.cdf(3), X.cdf(3.5), X.ccdf(8)
(0.45454545454545453, 0.45454545454545453, 0.04095904095904096)
>>> X.icdf(0.9), X.iccdf(0.01)
(7.0, 10.0)
```

`iccdf(0.01)`이 10이에요. 성공이 9번을 넘을 확률(10번 모두 성공할 확률)이 이미 1.1%라서, P(X > k) ≤ 0.01을 채우는 가장 작은 k는 10이에요.

꼬리 확률은 아주 작아도 상대 정확도를 지켜요. `ccdf`는 `1 - cdf`로 계산하지 않아서 1e-34 같은 값도 앞자리가 맞아요. 확률이 그보다 작아 float64에서 0이 되는 곳에서도 `logpmf`·`logccdf`는 값을 내요.

```python
>>> Y = sd.stats.BetaBinomial(n=2000, a=50.0, b=50.0)
>>> Y.ccdf(1900)
2.6544480522592042e-34
>>> Y.logpmf(0)
-167.3041007557629
```

## 요약값

$s = a + b$로 쓰면 이래요.

$$
\mathrm{E}[X] = \frac{na}{s}, \qquad
\mathrm{Var}[X] = \frac{nab\,(s + n)}{s^2(s + 1)} = n\frac{a}{s}\frac{b}{s}\cdot\frac{s + n}{s + 1}
$$

분산의 마지막 인수 $(s+n)/(s+1)$이 이항 분포보다 퍼지는 정도예요. 1 이상이고, $n = 1$이면 1이에요. 성공률이 한 번만 쓰이면 흔들려도 결과의 분포가 베르누이 그대로이기 때문이에요.

```python
>>> X.standard_deviation()
2.449489742783178
>>> X.skewness(), X.kurtosis()
(0.29160592175990213, -0.6904761904761905)
>>> X.median(), X.mode()
(4.0, 3.0)
>>> X.entropy()
2.2577232124962405
```

`kurtosis()`는 정규분포를 0으로 둔 초과 첨도예요. 왜도는 $a = b$이면 정확히 0이에요.

$a, b$가 1보다 작으면 성공률이 0이나 1 쪽에 몰려서 양 끝이 가장 커요. 두 끝의 확률이 같으면 최빈값을 하나로 정할 수 없어서 NaN이에요. $a = b = 1$도 모든 값의 확률이 같아서 NaN이에요.

```python
>>> sd.stats.BetaBinomial(n=10, a=0.5, b=0.5).mode()
nan
>>> sd.stats.BetaBinomial(n=10, a=0.5, b=0.8).mode()
0.0
>>> sd.stats.BetaBinomial(n=10, a=1.0, b=1.0).mode()
nan
```

## 다른 분포와의 관계

**이항 분포를 베타 분포로 섞은 것이에요.** 위의 적분을 그대로 계산해 보면 같은 값이 나와요. 0과 1 사이를 10만 칸으로 나눠 가운데 점에서 `Beta.pdf × Binomial.pmf`를 더해요.

```python
>>> m = 100000
>>> p = (sd.arange(0.0, m) + 0.5) / m
>>> w = sd.stats.Beta(a=2.0, b=3.0).pdf(p) / m
>>> sd.sum(w * sd.stats.Binomial(n=10, p=p).pmf(4))
0.13986013986013984
>>> X.pmf(4)
0.13986013986013984
```

**$a, b$가 크면 이항 분포에 가까워져요.** $a/(a+b) = p$로 두고 $a + b$를 키우면 성공률이 $p$에서 거의 흔들리지 않아서 `Binomial(n, p)`가 돼요.

```python
>>> for s in [10.0, 1e3, 1e6]:
...     print(sd.stats.BetaBinomial(n=10, a=0.4 * s, b=0.6 * s).pmf(4))
0.17504167658966419
0.24957721878109476
0.25082140189546387
>>> sd.stats.Binomial(n=10, p=0.4).pmf(4)
0.250822656
```

**$a = b = 1$이면 이산 균등분포예요.** 성공률이 [0, 1]에서 균등하면 0부터 $n$까지가 모두 $1/(n+1)$이에요. [`DiscreteUniform(low=0, high=n + 1)`](/api/stats/discrete-uniform/)과 같아요.

```python
>>> sd.stats.BetaBinomial(n=10, a=1.0, b=1.0).cdf(3)
0.36363636363636365
>>> sd.stats.DiscreteUniform(low=0, high=11).cdf(3)
0.36363636363636365
```

**$n = 1$이면 베르누이 분포예요.** 성공 확률은 $a/(a+b)$예요([`Bernoulli`](/api/stats/bernoulli/)).

```python
>>> sd.stats.BetaBinomial(n=1, a=2.0, b=3.0).mean()
0.4
```

## 정확도와 범위

$n \le 2000$이고 $a, b$가 0.1 이상 100 이하이면 모든 메서드가 참값과 상대 1e-14 안에서 맞아요(`logpmf`는 상대, `entropy`는 $10^{-14}\cdot\max(1, |값|)$ 안). 분위수는 목표 확률을 상대 1e-14 안에서 움직였을 때 나올 수 있는 정확한 답 중 하나예요.

그 밖에서도 값을 계산하지만 정확도는 보장하지 않아요. 구할 수 없는 값은 NaN이에요.

- $n + a + b$가 $2^{35}$을 넘으면 `pmf`를 포함한 확률이 NaN이에요.
- 누적확률을 구하는 데 더할 항이 $2^{20}$개를 넘으면(`n`이 1e9 정도이고 분포가 넓을 때) `cdf` 계열과 분위수가 NaN이에요.
- 모멘트(평균, 분산, 왜도, 첨도)는 $a$나 $b$가 $[2^{-150}, 2^{150}]$ 밖이면 NaN이에요. 다만 $2^{-1021}$보다 작은 모양은 아래의 두 점 분포라서 모멘트도 값이 있어요.

```python
>>> wide = sd.stats.BetaBinomial(n=1e9, a=0.5, b=0.5)
>>> wide.cdf(1e3)
0.0006368585760361907
>>> wide.cdf(5e8)
nan
>>> sd.stats.BetaBinomial(n=10, a=1e-200, b=1.0).mean()
nan
```

### 아주 작은 모양

모양이 0으로 가면 성공률이 0이나 1에 붙어서, 결과는 0번 아니면 $n$번 모두 성공이에요. 그래서 `a`나 `b`가 $2^{-1021}$(약 4.5e-308)보다 작으면 그 극한 분포를 써요. 질량이 0과 $n$ 두 점에만 있고, $n$에 $q = a/(a + b)$, 0에 $1 - q$가 놓여요. 모든 메서드와 표본이 이 분포의 값이에요. 평균은 $nq$, 분산은 $n^2 q(1 - q)$이고, `mode()`는 질량이 큰 점(두 질량이 같으면 NaN), `entropy()`는 두 질량의 엔트로피예요.

```python
>>> tiny = sd.stats.BetaBinomial(n=10, a=1e-310, b=3e-310)
>>> tiny.pmf(sd.asarray([0.0, 5.0, 10.0]))
array([0.75,  0.0, 0.25], dtype=float64)
>>> tiny.cdf(5.0), tiny.mean(), tiny.variance()
(0.75, 2.5, 18.75)
>>> tiny.mode(), tiny.entropy()
(0.0, 0.5623351446188083)
>>> tiny.sample(8, rng=sd.random.default_rng(1))
array([10.0,  0.0,  0.0, 10.0, 10.0, 10.0, 10.0,  0.0], dtype=float64)
>>> sd.stats.BetaBinomial(n=10, a=1e-310, b=1e-310).mode()
nan
```

다른 모양이 작지 않으면 한쪽 질량이 float64에서 0으로 반올림될 수 있어요. 그러면 한 점에 몰린 분포라서 분산과 엔트로피가 정확히 0이에요.

```python
>>> one = sd.stats.BetaBinomial(n=10, a=5e-324, b=2.0)
>>> one.pmf(0.0), one.variance(), one.entropy(), one.mode()
(1.0, 0.0, 0.0, 0.0)
```

구현은 [이산 분포의 수치 기법](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

scipy의 `betabinom(n, a, b)`와 같은 분포이고 매개변수 이름과 순서도 같아요. stardust는 키워드로만 받아요.

```python
>>> import scipy.stats
>>> float(scipy.stats.betabinom(10, 2, 3).pmf(4))
0.13986013986013976
>>> X.pmf(4)
0.13986013986013984
```

위꼬리는 다르게 나올 수 있어요. scipy의 `sf`는 1에서 누적확률을 빼는 방식이라 아주 작은 꼬리에서 자릿수를 잃어요.

```python
>>> float(scipy.stats.betabinom(2000, 50, 50).sf(1900))
1.7601475832407232e-12
>>> Y.ccdf(1900)
2.6544480522592042e-34
```

참값은 둘째 줄(약 2.65e-34)이에요. scipy의 값은 자릿수가 다 사라지고 남은 반올림 오차예요.

- `ppf`·`isf`는 `icdf`·`iccdf`, `sf`·`logsf`는 `ccdf`·`logccdf`예요. 분위수의 정의는 scipy와 같아요.
- scipy에는 없는 `mode()`가 있어요.
- 모양이 $2^{-1021}$보다 작으면 scipy와 달라요. `betabinom(10, 1e-310, 3e-310)`의 `pmf(0)`·`pmf(10)`, `cdf(5)`, `entropy()`가 scipy에서는 NaN이에요(평균 2.5와 분산 18.75는 같아요). stardust는 두 점 분포의 값 0.75, 0.25, 0.75, 0.5623이에요.
