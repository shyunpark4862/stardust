## 어떤 분포인가요

**이항 분포**(binomial distribution)는 **성공 확률이 `p`인 시도를 `n`번 했을 때 성공한 횟수**의 분포예요. 동전을 10번 던져 앞면이 몇 번 나오는지가 가장 쉬운 예예요. 두 가지를 가정해요.

- 시도끼리 서로 영향을 주지 않아요(독립).
- 매번 성공 확률이 `p`로 같아요.

"n번 중 몇 번"으로 셀 수 있는 일은 거의 다 이 분포로 다뤄요.

- **품질 관리**: 불량률 2%인 공정에서 50개를 뽑았을 때 불량이 몇 개 나올까요
- **전환율**: 방문자 200명 중 몇 명이 구매할까요
- **설문과 임상**: 응답자 중 찬성한 사람 수, 환자 중 약에 반응한 사람 수
- **신뢰성**: 서버 20대 중 동시에 고장 나는 대수

```python
>>> import stardust as sd
>>> X = sd.stats.Binomial(n=10, p=0.5)
>>> X.pmf(5)
0.24609375000000003
>>> X.cdf(3)
0.17187499999999997
>>> X.ccdf(7)
0.0546875
```

공정한 동전을 10번 던지면 앞면이 정확히 5번 나올 확률은 252/1024 ≈ 24.6%, 3번 이하일 확률은 176/1024 ≈ 17.2%, 7번보다 많을(8번 이상) 확률은 56/1024 ≈ 5.5%예요. 끝자리의 `…03`, `…97`은 실수 계산의 반올림이에요.

## 만들기와 매개변수

매개변수는 이름을 붙여서만 줘요. 둘 다 기본값이 없어요.

```python
>>> X
Binomial(n=10, p=0.5)
>>> X.n
10
>>> X.p
0.5
```

- `n`: 시도 횟수, **0 이상의 정수**예요. `10.0`처럼 정수 값인 실수는 괜찮아요.
- `p`: 성공 확률, **0 이상 1 이하**예요. 0과 1도 받아요(아래 점질량 절).

매개변수가 정의역 밖이면 에러 대신 그 원소의 모든 결과가 NaN이에요. 시도 횟수가 10.5번이라는 것은 뜻이 없고, 이런 값은 대개 `n * 0.8`처럼 계산한 값을 그대로 넘긴 실수예요. 몰래 내려서 계산하면 그 실수가 그럴듯한 숫자 뒤에 숨으니, NaN으로 바로 드러나게 해요.

```python
>>> sd.stats.Binomial(n=10.5, p=0.3).pmf(3)
nan
>>> sd.stats.Binomial(n=-1, p=0.3).mean()
nan
>>> sd.stats.Binomial(n=10, p=1.2).cdf(3)
nan
```

매개변수에 배열을 주면 원소마다 다른 분포가 되고, 메서드의 입력과 [브로드캐스트](/api/array/broadcasting/)해요. 아래는 시도 횟수가 10, 20, 40인 세 분포에서 성공이 정확히 5번일 확률이에요.

```python
>>> X = sd.stats.Binomial(n=sd.asarray([10, 20, 40]), p=0.5)
>>> X.pmf(5)
array([ 0.24609375000000003, 0.014785766601562503, 5.98454789724201e-07], dtype=float64)
>>> X.mean()
array([ 5.0, 10.0, 20.0], dtype=float64)
```

성공 확률 셋(열)과 경계 둘(행)을 엇갈려 한 번에 계산할 수도 있어요.

```python
>>> X = sd.stats.Binomial(n=10, p=sd.asarray([0.1, 0.5, 0.9]))
>>> X.cdf(sd.asarray([[2], [5]]))
array([[          0.9298091736,              0.0546875,
        3.7359999999999927e-07],
       [          0.9998530974,            0.623046875,
         0.0016349373999999981]], dtype=float64)
```

## 확률질량과 누적분포

`n`번 중 정확히 $k$번 성공할 확률(확률질량함수, pmf)은

$$
P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad k = 0, 1, \dots, n
$$

이에요. $\binom{n}{k}$는 `n`번 중 성공할 $k$번을 고르는 경우의 수([binom](/api/special/binom/))예요. 지지집합(확률이 0이 아닌 값)은 0부터 `n`까지의 정수예요.

```python
>>> X = sd.stats.Binomial(n=10, p=0.3)
>>> X.support()
(0.0, 10.0)
>>> X.pmf(3)
0.266827932
>>> X.pmf(3.5)
0.0
>>> X.pmf(-1)
0.0
>>> X.pmf(11)
0.0
>>> X.logpmf(11)
-inf
```

정수가 아닌 값이나 지지집합 밖에서 `pmf`는 0, `logpmf`는 −inf예요. 에러가 아니에요.

누적분포 `cdf(k)` = P(X ≤ k)는 pmf를 0부터 ⌊k⌋까지 더한 값이에요. 그래서 **정수가 아닌 k에서는 ⌊k⌋에서의 값**이에요. `ccdf(k)`는 P(X > k)예요.

```python
>>> X.cdf(3)
0.6496107184
>>> X.cdf(3.7)
0.6496107184
>>> X.ccdf(3.7)
0.3503892816
>>> X.cdf(-1)
0.0
>>> X.cdf(10)
1.0
```

<Callout type="warn" title="ccdf는 '초과'예요">
  `ccdf(k)`는 P(X > k), **k보다 많은** 경우의 확률이에요. "k번 **이상**"의 확률 P(X ≥ k)는 `ccdf(k - 1)`이에요. 검정의 p값은 대개 "관찰한 값 이상"이라서, 관찰한 횟수에서 1을 뺀 값을 넣어요.
</Callout>

### 분위수: 계단을 거꾸로 읽기

cdf가 계단이라서 `cdf(k) = p`를 정확히 푸는 `k`는 대개 없어요. 그래서 `icdf(p)`는 **cdf(k) ≥ p가 되는 가장 작은 정수 k**, `iccdf(p)`는 **ccdf(k) ≤ p가 되는 가장 작은 정수 k**예요. 결과는 정수 값을 담은 float64예요.

```python
>>> X.icdf(0.5)
3.0
>>> X.icdf(0.6496107184)
3.0
>>> X.icdf(0.6496107185)
4.0
>>> X.iccdf(0.35)
4.0
```

cdf(3) = 0.6496107184이니, p가 이 값 이하면 3이고 아주 조금이라도 넘으면 4예요. `iccdf(0.35)`가 4인 것은 ccdf(3) = 0.3504가 0.35보다 크고 ccdf(4)부터 0.35 이하이기 때문이에요. p가 0이나 1이면 지지집합의 양 끝, [0, 1] 밖이면 NaN이에요.

```python
>>> X.icdf(0.0)
0.0
>>> X.icdf(1.0)
10.0
>>> X.icdf(1.2)
nan
```

### 불량은 몇 개까지 나올까요

불량률이 2%인 공정에서 50개를 뽑아 검사해요.

```python
>>> B = sd.stats.Binomial(n=50, p=0.02)
>>> B.pmf(0)
0.3641696800871171
>>> B.ccdf(3)
0.017758080697971634
>>> B.iccdf(0.01)
4.0
>>> B.ccdf(4)
0.003209742026079391
```

불량이 하나도 없을 확률은 약 36%예요. 4개 이상일 확률은 `ccdf(3)` ≈ 1.8%예요. "정상 공정을 잘못 멈추는 일이 1% 아래가 되는 기준"은 `iccdf(0.01)` = 4라서, 불량이 4개보다 많으면(5개 이상) 멈추면 그 확률이 약 0.32%예요.

### 꼬리는 ccdf와 log 메서드로

`ccdf`는 `1 - cdf`로 계산하지 않고 위꼬리를 직접 구해요. cdf가 1에 아주 가까우면 `1 - cdf`는 자릿수를 다 잃어요.

```python
>>> B = sd.stats.Binomial(n=100, p=0.5)
>>> B.ccdf(90)
1.6610244897268266e-18
>>> 1 - B.cdf(90)
0.0
```

확률이 float64의 가장 작은 수(약 1e-308)보다도 작으면 `ccdf`도 0이 돼요. 그때는 `logccdf`가 그 로그를 직접 줘요. 역방향인 `ilogccdf`로 "log 확률이 −3000 이하가 되는 첫 k"도 구해요.

```python
>>> B = sd.stats.Binomial(n=10000, p=0.5)
>>> B.ccdf(9000)
0.0
>>> B.logccdf(9000)
-3687.042014558553
>>> B.ilogccdf(-3000.0)
8661.0
>>> B.iccdf(1e-300)
6831.0
>>> B.ccdf(6831)
6.09916189723916e-301
>>> B.ccdf(6830)
1.3154339457537044e-300
```

메서드 하나하나의 공통 뜻(cdf와 ccdf, 분위수, log 메서드)은 [분포의 메서드](/api/stats/methods/)에 모아 두었어요.

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()` | $np$ |
| `variance()` | $np(1-p)$ |
| `standard_deviation()` | $\sqrt{np(1-p)}$ |
| `skewness()` | $\dfrac{1-2p}{\sqrt{np(1-p)}}$ |
| `kurtosis()` | $\dfrac{1-6p(1-p)}{np(1-p)}$ (초과 첨도, 정규분포가 0) |
| `median()` | `icdf(0.5)` |
| `mode()` | $\lfloor (n+1)p \rfloor$, 둘이면 NaN |
| `entropy()` | $-\sum_k P(X=k)\log P(X=k)$ (nat) |

```python
>>> X = sd.stats.Binomial(n=10, p=0.3)
>>> X.mean()
3.0
>>> X.variance()
2.0999999999999996
>>> X.standard_deviation()
1.4491376746189437
>>> X.skewness()
0.27602622373694174
>>> X.kurtosis()
-0.12380952380952379
>>> X.median()
3.0
>>> X.mode()
3.0
>>> X.entropy()
1.779078784090063
```

왜도는 $p < 0.5$이면 양수(오른쪽 꼬리가 길어요), $p > 0.5$이면 음수예요. 엔트로피는 닫힌 꼴이 없어서 확률질량을 더해 구해요. 정의 그대로 더해도 같은 값이에요.

```python
>>> k = sd.arange(0, 11)
>>> q = X.pmf(k)
>>> -sd.sum(q * sd.log(q))
1.779078784090063
```

### 최빈값이 둘이면 NaN

$(n+1)p$가 정수이면 그 값과 하나 아래 값의 확률이 똑같아서 최빈값이 둘이에요. 이때 `mode()`는 둘 중 하나를 골라 주지 않고 NaN이에요.

```python
>>> sd.stats.Binomial(n=9, p=0.5).mode()
nan
>>> sd.stats.Binomial(n=9, p=0.5).pmf(sd.asarray([4, 5]))
array([0.24609374999999997, 0.24609374999999997], dtype=float64)
>>> sd.stats.Binomial(n=9, p=0.3).mode()
2.0
```

동전 9번에서는 앞면 4번과 5번이 똑같이 가장 흔해요. n = 9, p = 0.3이면 (n+1)p = 3이 정수라서 2와 3이 같을 것 같지만, 0.3은 float64로 정확히 0.3이 아니어서 (n+1)p가 3보다 아주 조금 작아요. 그래서 최빈값은 2 하나예요.

### 점질량: p = 0, p = 1, n = 0

`p = 0`이면 성공이 절대 없어서 X는 언제나 0이고, `p = 1`이면 언제나 `n`이에요. `n = 0`이면 시도를 안 했으니 언제나 0이에요. 값이 하나뿐인 분포라 분산은 0이고, 왜도와 첨도는 분산으로 나누는 값이라 정의되지 않아서 NaN이에요.

```python
>>> Z = sd.stats.Binomial(n=10, p=0.0)
>>> Z.pmf(0)
1.0
>>> Z.mean()
0.0
>>> Z.variance()
0.0
>>> Z.skewness()
nan
>>> Z.kurtosis()
nan
>>> Z.mode()
0.0
>>> Z.entropy()
0.0
>>> sd.stats.Binomial(n=0, p=0.3).pmf(0)
1.0
```

## 표본

`sample`은 이항 분포를 따르는 난수를 뽑아요. 생성기 `rng`를 꼭 줘야 하고, 값은 정수인 float64예요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> X = sd.stats.Binomial(n=10, p=0.3)
>>> X.sample(rng=rng)
3.0
>>> X.sample((8,), rng=rng)
array([3.0, 4.0, 4.0, 1.0, 1.0, 2.0, 5.0, 2.0], dtype=float64)
>>> x = X.sample((100000,), rng=sd.random.default_rng(7))
>>> sd.mean(x)
2.99948
>>> sd.var(x)
2.0905797296
```

표본 10만 개의 평균과 분산이 이론값 3과 2.1에 가까워요.

## 다른 분포와의 관계

**베르누이**: 시도가 한 번(`n = 1`)이면 [베르누이 분포](/api/stats/bernoulli/)예요. 반대로 이항 분포는 독립인 베르누이 `n`개의 합이에요.

```python
>>> sd.stats.Binomial(n=1, p=0.3).pmf(sd.asarray([0, 1]))
array([0.7000000000000001,                0.3], dtype=float64)
>>> sd.stats.Bernoulli(p=0.3).pmf(sd.asarray([0, 1]))
array([0.7, 0.3], dtype=float64)
```

**포아송 근사**: `n`이 크고 `p`가 작으면 평균 `np`인 [포아송 분포](/api/stats/poisson/)와 거의 같아요. 드문 사건의 횟수를 포아송으로 다루는 근거예요.

```python
>>> k = sd.arange(0, 6)
>>> sd.stats.Binomial(n=1000, p=0.003).pmf(k)
array([0.04956308282315555, 0.14913665844480106, 0.22415374391126824,
       0.22437857213986528, 0.16828392910489903, 0.10086908328293646], dtype=float64)
>>> sd.stats.Poisson(mu=3.0).pmf(k)
array([0.049787068367863944,  0.14936120510359183,  0.22404180765538773,
        0.22404180765538773,  0.16803135574154082,  0.10081881344492448], dtype=float64)
```

**베타 분포와 special 함수**: 이항 분포의 누적확률은 정칙화된 불완전 베타 함수와 같아요. $0 \le k < n$에서 $P(X \le k) = I_{1-p}(n-k,\ k+1)$이라서, [`Beta`](/api/stats/beta/)의 cdf로도, special의 [`bdtr`](/api/special/bdtr/)로도 같은 값이 나와요.

```python
>>> X.cdf(3)
0.6496107184
>>> sd.special.bdtr(3, 10, 0.3)
0.6496107184
>>> sd.stats.Beta(a=7, b=4).cdf(0.7)
0.6496107183999998
```

**음이항 분포**: "n + k번 안에 n번 이상 성공한다"와 "n번째 성공 전 실패가 k번 이하다"는 같은 사건이에요. 그래서 [음이항 분포](/api/stats/negative-binomial/)의 cdf는 이항 분포의 ccdf로 써져요.

```python
>>> sd.stats.NegativeBinomial(n=3, p=0.4).cdf(5)
0.6846054400000001
>>> sd.stats.Binomial(n=8, p=0.4).ccdf(2)
0.6846054400000001
```

뽑은 것을 되돌려 놓지 않는 추출이면 [초기하 분포](/api/stats/hypergeometric/), 성공 확률 자체가 대상마다 흔들리면 [베타이항 분포](/api/stats/beta-binomial/)를 써요.

## 정확도와 범위

- **보장 영역**: `n` ≤ 1e6, `p`는 [0, 1] 전체예요. 여기서 pmf, cdf, ccdf와 그 log, 모멘트는 참값 대비 상대오차 1e-14 이하예요(`entropy`는 오차가 1e-14·max(1, |값|) 이하). 위의 1.66e-18 같은 먼 꼬리에서도 마찬가지예요.
- **분위수**: `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`는 늘 위의 정의대로 정수를 찾아요. 목표 확률이 계단 경계에 아주 가깝다면(상대 1e-14 안), 그 오차만큼 움직였을 때의 답인 이웃 정수가 나올 수 있어요.
- **보장 영역 밖**: `n`이 1e6보다 커도 값을 계산하지만 정확도는 약속하지 않아요. 구할 수 없는 값은 틀린 숫자 대신 NaN이에요.
  - `n`이 2⁵²(약 4.5e15)보다 크면 cdf 계열(cdf, ccdf와 그 log), 분위수, `median`, `mode`가 NaN이에요. pmf와 평균, 분산은 값이 있어요.
  - `entropy`는 $np(1-p)$가 2⁴²(약 4.4e12)를 넘으면 NaN이에요.

```python
>>> X = sd.stats.Binomial(n=1e16, p=0.5)
>>> X.cdf(5e15)
nan
>>> X.pmf(5e15)
7.978845608028643e-09
>>> X.mean()
5000000000000000.0
>>> sd.stats.Binomial(n=1e15, p=0.5).entropy()
nan
>>> sd.stats.Binomial(n=1e12, p=0.5).entropy()
14.541301910609
```

모든 호출은 정해진 시간 안에 끝나요. 계산 방법은 [이산 분포의 구현](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.binom(n, p)`, `scipy.stats.Binomial(n=, p=)`와 같은 분포예요. 분위수 `icdf`, `iccdf`는 `binom.ppf`, `binom.isf`와 정의가 같아요.
- `icdf(0)`은 지지집합의 왼쪽 끝 0이에요. `binom.ppf(0, n, p)`는 −1이에요.
- `p = 0`, `p = 1`을 받아서 점질량이 돼요(왜도·첨도는 NaN). scipy 1.18.1의 `Binomial(n=10, p=0)`은 모든 값이 NaN이고, `binom.stats(10, 0, moments='k')`는 9.2e18을 내요.
- `cdf`는 정수가 아닌 k를 내려요. `binom.cdf(3.7, 10, 0.3)`도 그렇지만, `scipy.stats.Binomial(n=10, p=0.3).cdf(3.7)`은 0.8002로 내리지 않은 값을 내요(이 분포의 답은 0.6496).
- `kurtosis()`는 초과 첨도예요. `scipy.stats.Binomial`의 `kurtosis()`는 기본이 초과가 아닌 첨도(2.876)라 3만큼 달라요.
- `mode()`는 최빈값이 둘이면 NaN이에요. `scipy.stats.Binomial(n=9, p=0.5).mode()`는 5예요.
- 먼 꼬리에서 값이 있어요. `Binomial(n=10000, p=0.5).logccdf(9000)`은 −3687.04이고 `binom.logsf`는 −inf예요. `binom.isf(1e-100, 1000, 0.1)`은 1000을 내지만 답은 349예요.
