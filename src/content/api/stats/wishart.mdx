---
kind: function
title: Wishart
names: [Wishart]
group: 행렬 분포
order: 1
signatures:
  - "sd.stats.Wishart(*, df, scale)"
summary: 대칭 양의 정부호 행렬의 분포예요. 정규분포 표본으로 만든 산포 행렬(표본 공분산의 바탕)이 따르는 분포이고, 카이제곱 분포를 행렬로 넓힌 것이에요.
params:
  - name: df
    type: ndarray (...) 또는 Python 실수
    kind: keyword-only
    desc: 자유도. p − 1보다 큰 유한한 실수예요(p는 행렬의 크기, 정수가 아니어도 돼요). p − 1 이하, inf, NaN이면 그 분포의 모든 메서드가 NaN이에요.
  - name: scale
    type: ndarray (..., p, p)
    kind: keyword-only
    desc: 척도 행렬. 대칭 양의 정부호여야 하고 아래 삼각만 읽어요. 양의 정부호가 아니면 그 분포의 모든 메서드가 NaN이에요.
returns:
  type: Wishart
  desc: 분포 객체. 매개변수는 같은 이름의 읽기 전용 속성(df, scale)으로, 준 값 그대로 남아 있어요.
raises:
  - type: TypeError
    desc: 매개변수를 위치로 넘기거나 빠뜨렸을 때, scale이 sd.ndarray가 아닐 때(리스트, tuple, numpy 배열도 TypeError예요), df가 실수도 sd.ndarray도 아닐 때, 복소수일 때.
  - type: ValueError
    desc: scale이 2차원보다 작거나 마지막 두 축이 정사각이 아닐 때, df와 scale의 배치 축이 서로 브로드캐스트되지 않을 때.
seeAlso: [inverse-wishart, matrix-normal, multivariate-normal, chi-squared, gamma]

## 어떤 분포인가요

**Wishart 분포**는 값 하나하나가 **대칭 양의 정부호 행렬**인 분포예요. 이렇게 생각하면 쉬워요. 평균이 0이고 공분산이 V인 [다변량 정규분포](/api/stats/multivariate-normal/)에서 벡터 $z_1, \dots, z_\nu$를 뽑아

$$
S = \sum_{i=1}^{\nu} z_i z_i^{\mathsf T}
$$

를 만들면, 이 p × p 행렬 S가 자유도 ν, 척도 행렬 V인 Wishart 분포를 따라요. S를 ν로 나누면 (평균을 아는 경우의) 표본 공분산 행렬이에요. 그래서 Wishart 분포는

- 표본 공분산 행렬이 얼마나 흔들리는지 따질 때
- 베이즈 통계에서 정밀도 행렬(공분산의 역행렬)에 두는 사전분포로
- 여러 안테나·센서의 신호에서 만든 행렬을 다루는 신호처리에서

써요. p = 1이면 S는 정규 변수 제곱의 합이라 [카이제곱 분포](/api/stats/chi-squared/)예요. Wishart 분포는 카이제곱 분포를 행렬로 넓힌 것이에요.

```python
>>> import stardust as sd
>>> V = sd.asarray([[2.0, 0.5], [0.5, 1.0]])
>>> W = sd.stats.Wishart(df=5.0, scale=V)
>>> z = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=V).sample(5, rng=sd.random.default_rng(4))
>>> S = z.T @ z
>>> S
array([[22.511702444306334,  5.398708115315422],
       [ 5.398708115315422,  4.336240280814631]], dtype=float64)
>>> W.logpdf(S)
-8.86270454901022
```

`z`는 (5, 2)라 `z.T @ z`가 다섯 벡터의 $z_i z_i^{\mathsf T}$를 더한 2 × 2 행렬이에요. 이 행렬 하나가 `W`의 값 하나예요.

## 만들기와 매개변수

두 매개변수 모두 키워드로 꼭 줘야 해요.

- `df`: 자유도 ν. 위의 구성에서는 벡터의 수라 정수지만, **p − 1보다 큰 실수**면 무엇이든 돼요. p − 1 이하에서는 행렬이 특이해져서 밀도가 없어요(NaN이에요).
- `scale`: p × p 척도 행렬 V를 담은 `sd.ndarray`예요(리스트는 `TypeError`예요). 대칭 양의 정부호여야 하고 **아래 삼각만** 읽어요. `mean()`, `mode()`, `var()`도 아래 삼각을 대칭으로 옮긴 행렬에서 나와요. 양의 정부호가 아니면 NaN이에요.

```python
>>> W
Wishart(df=5.0, scale=array([[2.0, 0.5],
       [0.5, 1.0]], dtype=float64))
>>> sd.stats.Wishart(df=1.0, scale=V).mean()
array([[nan, nan],
       [nan, nan]], dtype=float64)
>>> sd.stats.Wishart(df=3.0, scale=sd.ones((2, 3)))
Traceback (most recent call last):
    ...
ValueError: Wishart(): 'scale' must be square on its last two axes, not (2, 3)
```

p = 2에서 `df = 1.0`은 p − 1 = 1 이하라 NaN이에요. inf나 NaN인 `df`도 NaN이에요.

### 배치

`df`의 모양 (...)과 `scale`의 앞 축 (...)이 서로 브로드캐스트해서 분포 여러 개를 만들어요. [`MultivariateNormal`의 배치](/api/stats/multivariate-normal/#여러-분포를-한-번에-배치)와 같은 규칙이에요.

```python
>>> Wb = sd.stats.Wishart(df=sd.asarray([2.0, 5.0, 20.0]), scale=V)
>>> Wb.mean().shape
(3, 2, 2)
>>> Wb.entropy()
array([4.793232263970892, 7.649972061236879,  10.16172211089421], dtype=float64)
```

## 밀도

p × p 대칭 양의 정부호 행렬 X에서의 밀도는 이래요.

$$
f(X) = \frac{|X|^{(\nu - p - 1)/2}\; e^{-\operatorname{tr}(V^{-1} X)/2}}{2^{\nu p / 2}\, |V|^{\nu/2}\, \Gamma_p\!\left(\frac{\nu}{2}\right)}
$$

$|X|$는 행렬식, $\operatorname{tr}$은 대각합, $\Gamma_p$는 다변량 감마 함수 $\Gamma_p(a) = \pi^{p(p-1)/4} \prod_{j=1}^{p} \Gamma\!\left(a + \tfrac{1 - j}{2}\right)$예요. p = 1이면 $V$가 수 $v$가 되고, 식이 [감마 분포](/api/stats/gamma/) Gamma(a = ν/2, scale = 2v)의 밀도가 돼요.

입력 `x`는 마지막 두 축이 (p, p)인 `sd.ndarray`이고(리스트는 `TypeError`예요), 앞 축은 배치와 브로드캐스트해요. `x`도 **아래 삼각만** 읽어요.

```python
>>> X = sd.asarray([[8.0, 2.0], [2.0, 5.0]])
>>> W.pdf(X)
0.0012189897719924936
>>> W.logpdf(X)
-6.709732819008364
>>> W.pdf(sd.asarray([[8.0, 99.0], [2.0, 5.0]]))
0.0012189897719924936
```

### 지지집합: 양의 정부호 행렬

`x`가 양의 정부호가 아니면 지지집합 밖이라 밀도는 0(`logpdf`는 −inf)이에요. 에러가 아니에요.

```python
>>> W.pdf(sd.asarray([[1.0, 2.0], [2.0, 1.0]]))
0.0
>>> W.logpdf(sd.asarray([[1.0, 2.0], [2.0, 1.0]]))
-inf
```

원소가 아무리 커도(float64의 최댓값이나 inf여도) `logpdf`는 값이나 −inf이고 NaN이 되지 않아요.

```python
>>> big = sd.asarray([[1e300, 0.0], [0.0, 1e300]])
>>> sd.stats.Wishart(df=3.0, scale=sd.eye(2)).logpdf(big)
-1e+300
>>> sd.stats.Wishart(df=3.0, scale=sd.eye(2)).logpdf(sd.asarray([[sd.inf, 0.0], [0.0, sd.inf]]))
-inf
```

## 요약값

행렬 분포의 요약값은 행렬이에요. 원소마다의 평균, 최빈값, 분산을 돌려줘요.

| 메서드 | 값 | 정의되지 않을 때 |
|---|---|---|
| `mean()` | $\nu V$ | |
| `mode()` | $(\nu - p - 1) V$ (ν ≥ p + 1) | ν < p + 1이면 NaN |
| `var()` | $\nu\,(V_{ij}^2 + V_{ii} V_{jj})$ (원소별 분산) | |
| `entropy()` | 미분 엔트로피(nat) | |

```python
>>> W.mean()
array([[10.0,  2.5],
       [ 2.5,  5.0]], dtype=float64)
>>> W.mode()
array([[4.0, 1.0],
       [1.0, 2.0]], dtype=float64)
>>> W.var()
array([[ 40.0, 11.25],
       [11.25,  10.0]], dtype=float64)
>>> W.entropy()
7.649972061236879
```

`var()`는 원소 하나하나의 분산이에요. 원소 쌍 사이의 공분산까지 담은 (p, p, p, p) 텐서는 돌려주지 않아요. ν < p + 1이면 밀도가 $|X| \to 0$으로 갈수록 커져서 가장 높은 점이 행렬 안에 없으므로 `mode()`가 NaN이에요.

```python
>>> sd.stats.Wishart(df=2.5, scale=V).mode()
array([[nan, nan],
       [nan, nan]], dtype=float64)
```

## 표본

`sample(shape, rng=...)`은 `shape` + 배치 + (p, p) 모양의 대칭 양의 정부호 행렬을 돌려줘요. `shape`를 빼면 분포마다 행렬 하나(배치 + (p, p))예요. 행렬 하나가 표본 하나이고, 결과는 정확히 대칭이에요. 정수가 아닌 `df`에서도 뽑을 수 있어요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> W.sample(rng=sd.random.default_rng(7))
array([[  22.42042549879541, -7.7970542326707175],
       [-7.7970542326707175,   6.530479962002012]], dtype=float64)
>>> ws = W.sample(100000, rng=sd.random.default_rng(6))
>>> ws.shape
(100000, 2, 2)
>>> sd.mean(ws, axis=0)
array([[10.014345602168664,  2.507525554209432],
       [ 2.507525554209432,  4.987416169779825]], dtype=float64)
>>> sd.var(ws, axis=0)
array([[39.932626191319294,    11.170615494155],
       [   11.170615494155,  9.950273278382419]], dtype=float64)
```

표본의 평균과 분산이 `mean()`, `var()`에 가까워요.

## 다른 분포와의 관계

**p = 1이면 감마·카이제곱 분포**예요. `scale = [[v]]`이면 [`Gamma`](/api/stats/gamma/)(a = ν/2, scale = 2v)이고, v = 1이면 [`ChiSquared`](/api/stats/chi-squared/)(df = ν)예요.

```python
>>> sd.stats.Wishart(df=6.0, scale=sd.asarray([[2.0]])).pdf(sd.asarray([[7.0]]))
0.06652283772712352
>>> sd.stats.Gamma(a=3.0, scale=4.0).pdf(7.0)
0.06652283772712352
```

- **역Wishart 분포**: X가 Wishart(ν, V)를 따르면 $X^{-1}$은 [`InverseWishart`](/api/stats/inverse-wishart/)(ν, $V^{-1}$)를 따라요.
- **다변량 정규분포**: 위의 구성처럼, 평균 0인 정규 표본의 $\sum z_i z_i^{\mathsf T}$가 Wishart 분포예요. 평균을 표본 평균으로 빼서 만든 산포 행렬은 자유도가 하나 줄어 Wishart(n − 1, V)예요.

## 정확도와 범위

- `logpdf`와 `entropy`는 척도 행렬의 [조건수](/api/linalg/cond/) κ(scale) ≤ 1e9, p ≤ 100에서 |오차| ≤ 1e-14 · max(1, |값|)이에요. 잰 값으로 κ = 1e9, p = 30, df = 1e8에서도 반올림 수준이에요.
- 자유도가 아주 커도 엔트로피가 정확해요. p = 1에서는 같은 분포인 감마 분포의 엔트로피와 같아요.

```python
>>> sd.stats.Wishart(df=1e8, scale=sd.asarray([[1.0]])).entropy()
10.975852488794162
>>> sd.stats.Gamma(a=5e7, scale=2.0).entropy()
10.975852488794162
```

- **자유도가 아주 큰 `logpdf`**: 위의 보장은 df ≤ 1e30까지예요(κ(scale) ≤ 1e9, p ≤ 100). 잰 값은 df = 1e30까지 9.4e-16 이하예요. 그보다 크면 계산에 남는 반올림 오차의 상한이 1e-14 · max(1, |값|)를 넘는 곳에서 틀린 숫자 대신 NaN이에요. 그 상한은 점 $X$를 $\mathrm{scale}\cdot\mathrm{df}$로 나눈 행렬이 단위행렬에서 얼마나 떨어져 있는지에 달려 있어서, NaN이 시작하는 자유도도 점마다 달라요.
  - 원소를 정확히 나타낸 점(scale = I인 Wishart의 평균 df·I와 최빈값)은 df = 1e46에서도 값이 나와요.
  - 원소가 반올림된 점(일반 scale의 평균과 최빈값, 한 ULP 옮긴 점)은 df가 약 1e31–3e35부터 NaN이에요.
  - 분포에서 뽑은 점은 df가 약 2.4e32–1e35부터예요.
  - 점이 분포의 폭보다 훨씬 멀면 `logpdf`의 크기가 오차의 상한보다 빨리 커져서 다시 값이 나와요.

  df ≤ 1e30에서는 이런 NaN이 나오지 않아요.

  ```python
  >>> W35 = sd.stats.Wishart(df=1e35, scale=sd.eye(2))
  >>> W35.logpdf(W35.mean())
  -124.33568016236136
  >>> W35.logpdf(W35.sample(rng=sd.random.default_rng(0)))
  nan
  ```

```python
>>> W30 = sd.stats.Wishart(df=1e30, scale=sd.asarray([[1.0]]))
>>> W30.logpdf(sd.asarray([[1e30]])), sd.stats.Gamma(a=5e29, scale=2.0).logpdf(1e30)
(-35.80428851839533, -35.80428851839533)
```

자세한 방법은 [행렬 분포](/internals/stats/matrix/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.wishart(df, scale)`와 이름과 메서드(`mean`, `mode`, `var`, `entropy`)가 같아요. 키워드로만 받고, 기본값이 없어요(scipy는 `scale=1`, `df=p`가 기본이에요). scipy는 `scale`과 `x`에 리스트와 수 하나도 받지만, sd는 `sd.ndarray`만 받아요.
- df ≤ p − 1이면 NaN이에요. scipy 1.18.1은 `ValueError`를 내요.
- `mode()`가 정의되지 않으면 NaN이에요. scipy 1.18.1은 `None`을 돌려줘요.
- 양의 정부호가 아닌 `x`의 `pdf`는 0이에요. scipy 1.18.1은 `LinAlgError`를 내요.
- 자유도가 큰 엔트로피가 달라요. 위의 df = 1e8, p = 1 예를 scipy 1.18.1은 10.975852489471436으로 계산해서 열째 자리부터 달라요.
