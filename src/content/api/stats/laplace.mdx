## 어떤 분포인가요

**라플라스 분포**(Laplace distribution)는 가운데 한 점에서 뾰족하게 솟고, 양쪽으로 똑같은 속도로 지수적으로 줄어드는 대칭 분포예요. 지수분포 둘을 등을 맞대어 붙인 모양이라 **이중 지수분포**(double exponential)라고도 불러요.

정규분포와 비교하면 두 가지가 달라요.

- 가운데가 더 뾰족해요. 작은 오차가 아주 자주 나와요.
- 꼬리가 더 두꺼워요. 정규의 꼬리는 $e^{-z^2/2}$로 줄지만, 라플라스는 $e^{-|z|}$로 줄어서 큰 오차도 더 자주 나와요.

이런 곳에 써요.

- 극단값이 섞인 오차: 정규분포로는 너무 드물게 보는 큰 오차가 실제로 자주 나오는 측정이나 금융 수익률
- 절대오차를 줄이는 추정: 오차가 라플라스 분포라고 두면, 가장 그럴듯한 위치는 평균이 아니라 중앙값이에요. 제곱 오차 대신 절대오차를 최소화하는 회귀(최소 절대 편차)가 이 가정에 해당해요.
- 두 지수분포의 차: 같은 지수분포를 따르는 독립인 대기 시간 둘의 차
- 차분 프라이버시: 통계값에 라플라스 잡음을 더해 개인 정보를 가리는 방법(라플라스 메커니즘)

```python
>>> import stardust as sd
>>> X = sd.stats.Laplace(mu=10.0, sigma=2.0)
>>> X.mean(), X.median(), X.mode()
(10.0, 10.0, 10.0)
>>> X.standard_deviation()
2.8284271247461903
```

## 만들기와 매개변수

| 매개변수 | 뜻 | 정의역 | 기본값 |
|---|---|---|---|
| `mu` | 위치(평균, 중앙값, 최빈값) | 유한한 실수 | 0.0 |
| `sigma` | 척도(평균 절대 편차) | 0보다 큰 유한한 실수 | 1.0 |

<Callout type="warn" title="sigma는 표준편차가 아니라 척도예요">
라플라스의 `sigma`는 밀도 $e^{-|x-\mu|/\sigma}$의 척도예요. 표준편차는 $\sqrt2\,\sigma$로, `sigma`보다 약 1.41배 커요. `sigma`가 직접 나타내는 것은 평균 절대 편차 $E|X - \mu|$예요.

표준편차가 s인 라플라스 분포가 필요하면 `sigma=s / math.sqrt(2)`로 만드세요. 이름이 정규분포와 같은 `mu`, `sigma`인 것은 위치와 척도 자리를 맞춘 것이고, 뜻이 같다는 말은 아니에요.
</Callout>

```python
>>> import math
>>> L = sd.stats.Laplace(sigma=1 / math.sqrt(2))
>>> L.standard_deviation()
1.0
>>> sd.stats.Laplace(sigma=2.0).variance()
8.0
```

매개변수는 읽기 전용 속성 `X.mu`, `X.sigma`로 돌려받아요. 배열로 주면 원소별로 계산하고 입력과도 [브로드캐스트](/api/array/broadcasting/)해요. 정의역 밖의 원소(0 이하의 `sigma`, 무한대나 NaN인 `mu`)는 에러 없이 NaN이에요.

```python
>>> sd.stats.Laplace(mu=sd.asarray([0.0, 5.0]), sigma=sd.asarray([[1.0], [-1.0]])).cdf(0.0)
array([[                  0.5, 0.0033689734995427335],
       [                  nan,                   nan]], dtype=float64)
```

## 밀도와 누적분포

지지집합은 실수 전체예요. $z = (x - \mu)/\sigma$로 두면

$$
f(x) = \frac{1}{2\sigma}\, e^{-|z|}, \qquad
F(x) = \begin{cases} \tfrac12 e^{z} & (z \le 0) \\[2pt] 1 - \tfrac12 e^{-z} & (z > 0) \end{cases}, \qquad
F^{-1}(p) = \begin{cases} \mu + \sigma \log(2p) & (p \le \tfrac12) \\[2pt] \mu - \sigma \log\big(2(1 - p)\big) & (p > \tfrac12) \end{cases}
$$

예요. 밀도는 $x = \mu$에서 꺾여요(미분할 수 없는 뾰족한 점). 가운데에서 한 척도 $\sigma$만큼 갈 때마다 밀도와 꼬리 확률이 $1/e$배로 줄어요.

```python
>>> X = sd.stats.Laplace()
>>> X.pdf(0.0)
0.5
>>> X.cdf(sd.asarray([-2.0, -1.0, 0.0, 1.0, 2.0]))
array([0.06766764161830635, 0.18393972058572117,                 0.5,
        0.8160602794142788,  0.9323323583816936], dtype=float64)
>>> X.icdf(sd.asarray([0.05, 0.25, 0.5, 0.75, 0.95]))
array([-2.3025850929940455, -0.6931471805599453,                 0.0,
        0.6931471805599453,  2.3025850929940446], dtype=float64)
```

사분위수가 $\pm\log 2 \approx \pm 0.693$이에요. 마지막 원소의 끝자리 차이는 0.95를 float64로 나타낼 때의 반올림이 $1 - p$에서 커진 것이에요. 각 메서드의 공통 의미는 [분포의 메서드](/api/stats/methods/)에 있어요.

```python
>>> L.ccdf(sd.asarray([1.0, 2.0, 4.0, 6.0]))
array([    0.1215583672171071,    0.02955287328097811,
        0.0017467446383230998, 0.00010324264590118104], dtype=float64)

array([  0.15865525393145707,  0.022750131948179212, 3.167124183311992e-05,
        9.86587645037698e-10], dtype=float64)
```

꼬리 확률은 작은 쪽을 직접 계산하므로, float64에서 0으로 내려가기 직전까지 상대 정확도를 지켜요. 그보다 먼 꼬리는 log 메서드로 받아요. 라플라스의 log 꼬리는 $-|z| - \log 2$인 직선이라 아주 먼 곳에서도 값이 나와요.

```python
>>> X.ccdf(40.0)
2.1241771276457944e-18
>>> X.ccdf(800.0), X.logccdf(800.0)
(0.0, -800.6931471805599)
>>> X.logpdf(1e300)
-1e+300
>>> X.ilogccdf(-800.0)
799.3068528194401
>>> X.icdf(1e-300), X.iccdf(1e-300)
(-690.0823807176538, 690.0823807176538)
>>> X.icdf(0.0), X.icdf(1.0)
(-inf, inf)
```

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()`, `median()`, `mode()` | $\mu$ |
| `variance()` | $2\sigma^2$ |
| `standard_deviation()` | $\sqrt2\,\sigma$ |
| `skewness()` | 0 |
| `kurtosis()` | 3 (초과 첨도) |
| `entropy()` | $1 + \log(2\sigma)$ |
| `support()` | `(-inf, inf)` |

```python
>>> X = sd.stats.Laplace(mu=10.0, sigma=2.0)
>>> X.variance(), X.standard_deviation()
(8.0, 2.8284271247461903)
>>> X.skewness(), X.kurtosis()
(0.0, 3.0)
>>> X.entropy()
2.386294361119891
```

`kurtosis()`는 **초과 첨도**예요. 정규분포를 0으로 둔 값이라, 라플라스의 3은 "정규보다 뾰족하고 꼬리가 두껍다"는 뜻이에요. 모든 모멘트가 유한하고, `sigma`에 상관없이 왜도는 0, 첨도는 3이에요.

`variance()`는 $2\sigma^2$이 float64를 넘으면 inf, 0으로 내려가면 0이에요(`Laplace(sigma=1e200).variance()`는 inf).

## 다른 분포와의 관계

**지수분포**: 가운데에서 잰 거리 $|X - \mu|$는 척도가 같은 [지수분포](/api/stats/exponential/) `Exponential(scale=sigma)`를 따라요. 그래서 오른쪽 꼬리는 지수분포 꼬리의 절반이에요.

```python
>>> X = sd.stats.Laplace(mu=10.0, sigma=2.0)
>>> E = sd.stats.Exponential(scale=2.0)
>>> X.ccdf(15.0), 0.5 * E.ccdf(5.0)
(0.0410424993119494, 0.0410424993119494)
```

**두 지수분포의 차**: 독립이고 같은 `Exponential(scale=s)`인 두 값의 차는 `Laplace(mu=0, sigma=s)`예요. 표본으로 보면 분위수가 $\pm\log 2$, $\pm\log 10$ 근처에 오고, 분산은 $2s^2 = 2$에 가까워요.

```python
>>> rng = sd.random.default_rng(11)
>>> E1 = sd.stats.Exponential()
>>> d = E1.sample((1_000_000,), rng=rng) - E1.sample((1_000_000,), rng=rng)
>>> sd.quantile(d, sd.asarray([0.05, 0.25, 0.5, 0.75, 0.95]))
array([    -2.2944436752391657,     -0.6920391758753552,
       -0.00010172464265006953,      0.6935610163204956,
             2.301380273270431], dtype=float64)
>>> float(sd.var(d))
1.9979622231220986
```

**정규분포, 코시 분포와의 비교**: 셋 다 위치 `mu`와 척도 `sigma`로 정하는 대칭 분포예요. 하지만 `sigma`의 뜻은 달라요. [정규](/api/stats/normal/)에서는 표준편차, 라플라스에서는 표준편차의 $1/\sqrt2$(평균 절대 편차), [코시](/api/stats/cauchy/)에서는 사분위범위의 절반이에요. 꼬리 두께는 정규, 라플라스, 코시 순으로 두꺼워져요. 라플라스는 모든 모멘트가 유한하지만, 코시는 평균조차 없어요.

## 정확도와 범위

라플라스 분포는 닫힌 꼴이 있는 분포라 매개변수와 입력의 정의역 전체가 보장 영역이에요.

- `pdf`, `cdf`, `ccdf`와 그 log, 모멘트, `median`, `mode`는 참값 대비 상대오차 $10^{-14}$ 안이에요. `ccdf`는 1 − `cdf`로 만들지 않아서 위꼬리도 상대 정확도예요.
- `logpdf`와 `entropy`는 오차가 $10^{-14} \cdot \max(1, |값|)$ 안이에요.
- `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`는 결과의 상대오차가 $10^{-14} \cdot \max(1, \kappa)$ 안이에요. $\kappa$는 입력이 조금 변할 때 결과가 얼마나 크게 변하는지 나타내는 조건수예요.
- 결과가 float64 범위를 넘으면 극한값(0, ±inf)이에요.
- NaN은 매개변수가 정의역 밖이거나 NaN일 때, 입력이 NaN일 때, `icdf`·`iccdf`의 확률이 [0, 1] 밖일 때, `ilogcdf`·`ilogccdf`의 입력이 양수일 때뿐이에요.

꼬리에서 자릿수를 지키는 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에 있어요.

## scipy를 아는 분께

- scipy의 `laplace(loc, scale)`과 `loc = mu`, `scale = sigma`로 대응해요. scipy의 `scale`도 표준편차가 아니라 같은 척도예요.
- `kurtosis()`는 초과 첨도라 고전형 `laplace.stats(moments='k')`의 3.0과 같아요.
- 확률이 float64 아래로 내려가는 먼 꼬리에서 scipy의 log 메서드는 −inf를 내요. 여기서는 정확한 값이 나와요.

  ```python
  >>> import scipy.stats as ss
  >>> sd.stats.Laplace().logccdf(800.0)
  -800.6931471805599
  >>> float(ss.laplace.logsf(800.0))
  -inf
  >>> sd.stats.Laplace().logpdf(800.0), float(ss.laplace.logpdf(800.0))
  (-800.6931471805599, -inf)
  ```
