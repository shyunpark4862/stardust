## 어떤 분포인가요

**로지스틱 분포**는 누적분포함수가 **로지스틱 곡선**(시그모이드라고도 하는 S자 곡선)인 분포예요.

$$
F(x) = \frac{1}{1 + e^{-(x-\mu)/\sigma}}
$$

이 곡선은 왼쪽 끝에서 0, 오른쪽 끝에서 1로 가면서 가운데 $\mu$에서 가장 가파르게 올라가요. 그래서 "어떤 값을 넘으면 일이 일어날 확률"이 점점 커지는 현상을 나타내기 좋아요.

- **로지스틱 회귀**: "공부 시간이 늘면 합격 확률이 어떻게 오르나"처럼, 입력에 따라 0과 1 사이의 확률이 S자로 바뀌는 모형이에요. 이 S자가 바로 로지스틱 분포의 누적분포예요.
- **승률 모형**: 체스의 Elo 점수는 두 선수의 점수 차를 이 곡선에 넣어 이길 확률을 정해요(아래 예제).
- **성장 곡선**: 처음에는 느리게, 중간에 빠르게, 끝에서는 포화하며 자라는 인구나 보급률.

밀도는 정규분포처럼 가운데가 볼록하고 좌우 대칭인 종 모양이에요. 다른 점은 **꼬리**예요. 정규분포의 꼬리는 $e^{-x^2/2}$로 아주 빨리 줄지만, 로지스틱의 꼬리는 $e^{-|x|}$로 줄어서 더 두꺼워요.

```python
0.5
>>> X.cdf(2.0)
0.8807970779778823
>>> X.pdf(0.0)
0.25
```

## 만들기와 매개변수

매개변수는 둘이고, 둘 다 키워드로만 줘요.

- `mu`: 위치. 분포 전체를 좌우로 옮겨요. 기본값 0.
- `sigma`: 척도. 분포를 좌우로 늘이거나 줄여요. 0보다 커야 하고, 기본값 1.

```python
>>> sd.stats.Logistic(mu=1.0, sigma=2.0)
Logistic(mu=1.0, sigma=2.0)
>>> sd.stats.Logistic(1.0, 2.0)
Traceback (most recent call last):
    ...
TypeError: Logistic(): takes no positional arguments but 2 were given
```

<Callout type="warn" title="sigma는 표준편차가 아니에요">
  정규분포의 `sigma`는 표준편차지만, 로지스틱의 `sigma`는 척도예요. 표준편차는 $\sigma\pi/\sqrt3 \approx 1.814\,\sigma$예요. 표준편차가 1인 로지스틱이 필요하면 `sigma`에 $\sqrt3/\pi$를 넣으세요.
</Callout>

```python
>>> import math
>>> sd.stats.Logistic(sigma=1.0).standard_deviation()
1.8137993642342178
>>> sd.stats.Logistic(sigma=math.sqrt(3) / math.pi).standard_deviation()
1.0
```

매개변수는 배열이어도 돼요. 매개변수끼리, 그리고 메서드의 입력과 [브로드캐스트](/api/array/broadcasting/)해요.

```python
>>> Y = sd.stats.Logistic(mu=sd.asarray([0.0, 1.0, 2.0]))
>>> Y.cdf(1.0)
array([0.7310585786300049,                0.5, 0.2689414213699951], dtype=float64)
>>> Y.mean()
array([0.0, 1.0, 2.0], dtype=float64)
```

매개변수가 정의역 밖이면(`sigma`가 0 이하, 무한대, NaN이거나 `mu`가 무한대, NaN이면) 에러가 아니라 그 원소의 모든 결과가 NaN이에요. 배열 매개변수의 한 원소가 잘못돼도 나머지는 정상으로 계산돼요.

```python
>>> sd.stats.Logistic(sigma=0.0).cdf(1.0)
nan
>>> sd.stats.Logistic(sigma=sd.asarray([1.0, -1.0])).pdf(0.0)
array([0.25,  nan], dtype=float64)
```

## 밀도와 누적분포

$z = (x - \mu)/\sigma$라고 두면 이래요. 지지집합(값이 나올 수 있는 범위)은 실수 전체예요.

$$
F(x) = \frac{1}{1 + e^{-z}}, \qquad
f(x) = \frac{e^{-z}}{\sigma\,(1 + e^{-z})^2} = \frac{F(x)\,(1 - F(x))}{\sigma}
$$

분위수(누적확률이 $p$가 되는 지점)는 닫힌 꼴이에요. 확률의 **로그 오즈**(log-odds)예요.

$$
F^{-1}(p) = \mu + \sigma \log\frac{p}{1-p}
$$

```python
>>> X.ccdf(2.0)
0.11920292202211755
>>> X.icdf(0.9)
2.1972245773362196
>>> X.iccdf(0.1)
2.197224577336219
>>> X.icdf(0.0), X.icdf(1.0), X.icdf(1.5)
(-inf, inf, nan)
```

`icdf(0.9)`와 `iccdf(0.1)`은 같은 지점(위꼬리 10%가 시작하는 곳)이라 마지막 자리 정도만 달라요. `icdf`는 0과 1에서 지지집합의 끝(−inf, inf)이고, [0, 1] 밖은 NaN이에요. 메서드마다의 뜻은 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

### 꼬리는 ccdf와 log 메서드로

`cdf(x)`가 1에 가까운 곳에서 `1 - cdf(x)`를 하면 자릿수가 사라져요. 위꼬리 확률은 `ccdf`로 직접 구하세요.

```python
>>> 1 - X.cdf(40.0)
0.0
>>> X.ccdf(40.0)
4.24835425529159e-18
```

꼬리가 더 깊어서 확률 자체가 double로 나타낼 수 있는 가장 작은 수 아래로 내려가면(약 −745보다 작은 로그), `cdf`는 0이 되지만 `logcdf`는 값을 그대로 내요. 로지스틱의 아래꼬리는 $e^{z}$와 거의 같아서 로그가 거의 $z$예요.

### 예: Elo 승률

체스의 Elo 점수에서 점수가 $R_A$, $R_B$인 두 선수가 붙으면, A가 이길 기대 확률은 $1/(1 + 10^{-(R_A - R_B)/400})$이에요. 밑을 $e$로 바꾸면 `sigma`가 $400/\ln 10 \approx 173.7$인 로지스틱의 누적분포예요.

```python
>>> elo = sd.stats.Logistic(sigma=400 / math.log(10))
>>> elo.cdf(200.0)
0.7597469266479578
>>> elo.icdf(0.9)
381.69700377572997
```

200점 높은 선수는 약 76% 확률로 이겨요. 이길 확률 90%를 기대하려면 약 382점 차이가 나야 해요.

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()`, `median()`, `mode()` | $\mu$ |
| `variance()` | $\pi^2\sigma^2/3$ |
| `standard_deviation()` | $\pi\sigma/\sqrt3$ |
| `skewness()` | 0 |
| `kurtosis()` | 6/5 (초과 첨도) |
| `entropy()` | $\log\sigma + 2$ |

모든 모멘트가 유한해서, 어떤 매개변수에서도 요약값이 inf나 NaN이 되지 않아요(매개변수가 정의역 밖일 때만 NaN이에요). `kurtosis()`는 정규분포를 0으로 두는 **초과 첨도**예요. 1.2라는 값은 정규분포보다 꼬리가 두껍다는 뜻이에요.

```python
>>> X.variance()
3.289868133696453
>>> X.skewness(), X.kurtosis()
(0.0, 1.2)
>>> X.entropy()
2.0
>>> sd.stats.Logistic(mu=3.0, sigma=0.5).median()
3.0
```

`entropy()`는 미분 엔트로피이고 단위는 nat예요.

## 다른 분포·함수와의 관계

### expit와 logit

표준 로지스틱(`mu=0`, `sigma=1`)의 `cdf`는 [`sd.special.expit`](/api/special/expit/), `icdf`는 `sd.special.logit`과 같아요.

```python
>>> X.cdf(-3.0), sd.special.expit(-3.0)
(0.04742587317756679, 0.04742587317756679)
>>> X.icdf(0.75), sd.special.logit(0.75)
(1.0986122886681096, 1.0986122886681096)
```

S자 곡선 하나만 필요하면 `expit`가 간단하고, 위치·척도가 있거나 밀도, 분위수, 요약값, 표본이 함께 필요하면 `Logistic`이 편해요.

### 정규분포와의 차이

표준편차를 1로 맞춘 로지스틱과 표준정규분포는 가운데에서는 비슷하지만, 꼬리에서는 크게 달라요. 4 표준편차 밖으로 나갈 확률이 로지스틱에서 약 22배, 6 표준편차 밖에서는 약 19,000배 커요.

```python
>>> L1 = sd.stats.Logistic(sigma=math.sqrt(3) / math.pi)
>>> N = sd.stats.Normal()
>>> L1.ccdf(4.0), N.ccdf(4.0)
(0.0007059940838289092, 3.167124183311992e-05)
>>> L1.ccdf(6.0), N.ccdf(6.0)
(1.8778180689650757e-05, 9.865876450376983e-10)
```

그래서 로지스틱 회귀(로짓)와 프로빗 회귀(정규분포의 누적분포를 쓰는 모형)는 가운데 자료에서는 거의 같은 결과를 내지만, 극단적인 관측에 대한 반응이 달라요.

### 두 Gumbel의 차

[Gumbel 분포](/api/stats/gumbel/)를 따르는 서로 독립인 두 값의 차 $G_1 - G_2$는 표준 로지스틱 분포를 따라요. 선택 모형(여러 선택지의 효용에 Gumbel 잡음을 더하는 모형)에서 두 선택지 중 하나를 고를 확률이 로지스틱 곡선이 되는 이유예요.

## 정확도와 범위

로지스틱은 닫힌 꼴 분포라서 **매개변수와 입력의 정의역 전체**에서 정확도를 보장해요.

- `pdf`, `cdf`, `ccdf`, `logcdf`, `logccdf`와 요약값: 정밀한 참값과의 상대오차가 1e-14 이하예요. 꼬리의 아주 작은 확률에서도 마찬가지예요.
- `logpdf`, `entropy`: 값이 0을 지나기 때문에 오차가 1e-14·max(1, |값|) 이하예요.
- `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`: 결과의 상대오차가 1e-14에 "입력이 마지막 자리만큼 흔들릴 때 결과가 흔들리는 배율"을 곱한 값 이하예요. 결과가 0 근처(`icdf(0.5)` 둘레)이면 이 배율이 커져요.

$z$가 double 범위를 넘는 극단적인 매개변수(아주 작은 `sigma` 등)에서도 NaN 대신 극한값을 내요.

```python
>>> sd.stats.Logistic(sigma=1e-300).cdf(1.0)
1.0
```

정확도의 일반 규칙은 [통계 영역의 기본](/api/stats/basics/)에, 구현은 [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.logistic(loc, scale)`에 해당해요. 이름이 `mu`, `sigma`이고 키워드로만 받아요.
- `kurtosis()`는 초과 첨도(1.2)예요. scipy의 `logistic.stats(moments='k')`도 초과 첨도라 같아요. scipy 1.18.1의 신형 `scipy.stats.Logistic`은 매개변수 없이 표준형만 만들고(위치·척도는 `2.0*Logistic() + 1.0`처럼 변환), `kurtosis()`의 기본이 보통 첨도라 4.2 근처(4.199999999992764)를 내요.
- 이 분포에서는 꼬리 값도 scipy와 거의 같아요(`logcdf(-800)`은 둘 다 −800).
- 메서드 이름은 `sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`예요. 리스트와 numpy 배열은 받지 않으니 `sd.asarray`로 바꿔서 넘기세요.
