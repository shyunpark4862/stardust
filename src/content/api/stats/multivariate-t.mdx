## 어떤 분포인가요

**다변량 t 분포**(multivariate t distribution)는 [다변량 정규분포](/api/stats/multivariate-normal/)와 모양이 비슷하지만 꼬리가 더 두꺼운 분포예요. 여러 자산의 수익률처럼 평소에는 정규분포처럼 보이다가 가끔 아주 큰 움직임이 함께 나타나는 자료, 이상값이 섞인 자료를 다룰 때 써요. 정규분포로 모형을 세우면 이런 극단값 하나가 결과를 크게 흔드는데, t 분포는 극단값을 "있을 법한 일"로 받아들여서 덜 흔들려요.

이 분포는 이렇게 만들 수 있어요. 다변량 정규분포 $Z \sim N(0, \Sigma)$와 자유도 ν인 카이제곱 변수 $V$를 따로 뽑아서

$$
X = \mu + Z \sqrt{\nu / V}
$$

로 두면 X가 다변량 t 분포를 따라요. 여기서 모든 성분에 같은 배율 $\sqrt{\nu/V}$가 곱해지므로, V가 작게 나오면 모든 성분이 함께 크게 흔들려요. 그래서 시장 전체가 출렁이는 날처럼 "모두 함께 극단적인" 상황을 잘 나타내요.

꼬리의 두께는 **자유도** `df`가 정해요. 작을수록 꼬리가 두껍고, 커질수록 다변량 정규분포에 가까워져서 `df = inf`이면 똑같아요.

```python
>>> import stardust as sd
>>> sh = sd.asarray([[1.0, 0.5], [0.5, 1.0]])
>>> T = sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=4.0)
>>> N = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=sh)
>>> T.pdf(sd.asarray([3.0, 3.0])), N.pdf(sd.asarray([3.0, 3.0]))
(0.002871504663655167, 0.0004555358998619421)
>>> T.pdf(sd.asarray([6.0, -6.0])), N.pdf(sd.asarray([6.0, -6.0]))
(3.628142429351286e-06, 9.887506975893557e-33)
```

중심에서 먼 (6, −6)에서 정규분포의 밀도는 1e-32 정도로 사실상 0이지만, t 분포는 1e-6이에요. "거의 일어나지 않는 일"과 "드물지만 일어나는 일"의 차이예요.

## 만들기와 매개변수

매개변수 셋은 모두 키워드로 꼭 줘야 해요. 모양과 배치 규칙은 [`MultivariateNormal`](/api/stats/multivariate-normal/)과 같아요. `mu`는 (..., d), `shape`는 (..., d, d)인 `sd.ndarray`이고(리스트는 `TypeError`예요), `shape`는 아래 삼각만 읽어요. `df`는 배치 모양 (...)의 배열이거나 Python 실수예요. 세 매개변수의 앞 축이 서로 브로드캐스트해요.

```python
>>> T
MultivariateT(mu=array([0.0, 0.0], dtype=float64), shape=array([[1.0, 0.5],
       [0.5, 1.0]], dtype=float64), df=4.0)
>>> T.df
4.0
```

아래는 자유도만 다른 분포 넷이에요. `df`가 (4,)라서 배치 모양이 (4,)예요.

```python
>>> Tb = sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=sd.asarray([1.0, 4.0, 30.0, sd.inf]))
>>> Tb.pdf(sd.asarray([3.0, 3.0]))
array([ 0.003920798031732139,  0.002871504663655167, 0.0008438027357315953,
       0.0004555358998619421], dtype=float64)
```

자유도가 커질수록 (3, 3)의 밀도가 정규분포의 값(마지막)으로 줄어들어요.

<Callout type="warn" title="shape는 공분산이 아니에요">
  `shape`는 분포가 퍼진 모양을 정하는 척도 행렬이고, 공분산 행렬은 그보다 df/(df − 2)배 커요. 자료의 표본 공분산을 그대로 `shape`에 넣으면 분포가 실제보다 넓어져요. 공분산이 S인 t 분포를 원하면 `shape = S * (df - 2) / df`로 주세요(df > 2일 때).
</Callout>

### 정의역 밖은 NaN

양정치가 아닌 `shape`, NaN·inf가 든 `mu`, 0 이하이거나 NaN인 `df`는 에러가 아니라 그 분포의 모든 메서드가 NaN이에요. 2⁻¹⁰²¹(약 4.5e-308)보다 작은 양수 `df`도 NaN이에요. 자유도의 절반을 float64로 정확히 나타낼 수 없는 범위이고, [`StudentT`](/api/stats/student-t/)와 같은 경계예요. 서브노멀 수뿐 아니라 가장 작은 정규 float64 2⁻¹⁰²²도 여기에 들어요.

```python
>>> sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=0.0).pdf(sd.zeros(2))
nan
>>> sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=1e-320).pdf(sd.zeros(2))
nan
>>> sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=2**-1022).entropy()
nan
```

## 밀도

자유도 ν, 위치 μ, 척도 행렬 Σ인 d변량 t 분포의 밀도는 이래요.

$$
f(x) = \frac{\Gamma\!\left(\frac{\nu + d}{2}\right)}{\Gamma\!\left(\frac{\nu}{2}\right) (\nu\pi)^{d/2}\,|\Sigma|^{1/2}}
\left(1 + \frac{Q}{\nu}\right)^{-\frac{\nu + d}{2}},
\qquad Q = (x - \mu)^{\mathsf T}\,\Sigma^{-1}\,(x - \mu)
$$

정규분포의 $e^{-Q/2}$ 대신 $Q$의 거듭제곱으로 줄어서 꼬리가 두꺼워요. 등고선은 정규분포처럼 $Q$가 같은 타원이에요. 입력 `x`의 모양, ±inf·NaN 성분의 처리는 `MultivariateNormal`과 같아요.

```python
>>> T.logpdf(sd.asarray([6.0, -6.0]))
-12.526789768116128
>>> T.pdf(sd.asarray([[0.0, 0.0], [3.0, 3.0]]))
array([ 0.18377629847393068, 0.002871504663655167], dtype=float64)
```

<Callout type="note" title="척도 행렬이 대각이어도 독립이 아니에요">
  다변량 정규분포에서는 공분산이 대각이면 성분끼리 독립이지만, t 분포는 그렇지 않아요. 모든 성분이 같은 배율 $\sqrt{\nu/V}$를 나눠 갖기 때문이에요. 그래서 밀도가 성분별 t 밀도의 곱과 달라요.
</Callout>

```python
>>> I = sd.stats.MultivariateT(mu=sd.zeros(2), shape=sd.eye(2), df=3.0)
>>> I.pdf(sd.asarray([3.0, 3.0]))
0.0012276513100518728
>>> sd.stats.StudentT(df=3.0).pdf(3.0) ** 2
0.0005277144981371758
```

## 누적확률 `cdf`

`cdf(x)`는 모든 성분이 동시에 `x` 이하일 확률이에요. 인자(`atol`, `return_error`, `max_points`)와 특수한 입력의 처리, 직사각형 영역을 구하는 법은 [`MultivariateNormal`의 cdf](/api/stats/multivariate-normal/#누적확률-cdf)와 같아요.

- **d ≤ 3**: 정확한 공식(1차원 적분)이라 오차 추정이 0이에요.
- **d ≥ 4**: 고정 시드의 준몬테카를로라 같은 입력이면 언제나 같은 값이에요. 정규분포보다 계산이 무거워서 정확도를 조금 낮춰도 되면 `atol=1e-4`처럼 주는 것이 좋아요.

```python
>>> T.cdf(sd.asarray([-3.0, -3.0])), N.cdf(sd.asarray([-3.0, -3.0]))
(0.0060638080515470014, 8.188966183219212e-05)
>>> T.cdf(sd.asarray([1.0, -0.5]), return_error=True)
CdfResult(value=0.298375895891548, error=0.0)
>>> C4 = sd.full((4, 4), 0.5) + 0.5 * sd.eye(4)
>>> T4 = sd.stats.MultivariateT(mu=sd.zeros(4), shape=C4, df=5.0)
>>> T4.cdf(sd.zeros(4), return_error=True)
CdfResult(value=0.19999998966404847, error=9.657092904981532e-07)
>>> T4.cdf(sd.ones(4), atol=1e-4, return_error=True)
CdfResult(value=0.5982492662448123, error=4.1533489600279674e-05)
```

두 변수가 모두 −3 이하일 확률이 정규분포보다 70배 넘게 커요. "함께 크게 떨어지는" 위험을 따질 때 이 차이가 중요해요. 셋째 예에서 원점은 대칭의 중심이라, 모든 상관이 0.5이면 자유도와 상관없이 확률이 1/(d + 1) = 0.2예요.

## 요약값

| 메서드 | 값 | 정의되지 않을 때 |
|---|---|---|
| `mean()` | $\mu$ (df > 1) | df ≤ 1이면 NaN |
| `covariance()` | $\Sigma \cdot \nu / (\nu - 2)$ (df > 2) | 1 < df ≤ 2이면 발산, df ≤ 1이면 NaN |
| `entropy()` | 아래 식 | |

공분산이 발산할 때(1 < df ≤ 2)는 성분마다 `shape`의 부호를 따라 +inf나 −inf이고, `shape`의 성분이 0인 곳은 0이에요. 평균조차 없는 df ≤ 1이면 NaN이에요. 단변량 [`StudentT`](/api/stats/student-t/)의 분산과 같은 규칙이에요.

```python
>>> T.mean()
array([0.0, 0.0], dtype=float64)
>>> T.covariance()
array([[2.0, 1.0],
       [1.0, 2.0]], dtype=float64)
>>> sd.stats.MultivariateT(mu=sd.zeros(2), shape=sd.eye(2), df=1.5).covariance()
array([[inf, 0.0],
       [0.0, inf]], dtype=float64)
>>> sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=1.0).mean()
array([nan, nan], dtype=float64)
```

df = 4이면 공분산이 `shape`의 4/2 = 2배예요. `shape`의 위 삼각은 여기서도 보지 않아서, `covariance()`는 아래 삼각을 대칭으로 옮긴 행렬에서 나와요. 엔트로피(미분 엔트로피, 단위 nat)는 이래요. ψ는 [디감마 함수](/api/special/digamma/)예요.

$$
H = \tfrac12 \log|\Sigma| + \log\frac{(\nu\pi)^{d/2}\,\Gamma\!\left(\frac{\nu}{2}\right)}{\Gamma\!\left(\frac{\nu+d}{2}\right)}
+ \frac{\nu + d}{2}\left[\psi\!\left(\tfrac{\nu+d}{2}\right) - \psi\!\left(\tfrac{\nu}{2}\right)\right]
$$

```python
>>> Tb.entropy()
array([ 4.694036030183455,  3.194036030183455, 2.7607026968501214,
        2.694036030183455], dtype=float64)
```

자유도가 커질수록 엔트로피가 정규분포의 값(마지막)으로 줄어요. 꼬리가 두꺼울수록 불확실성이 크다는 뜻이에요.

## 표본

`sample(shape, rng=...)`은 `shape` + 배치 + (d,) 모양이에요. `shape`를 빼면 분포마다 벡터 하나(배치 + (d,))예요. 위의 $\mu + Z\sqrt{\nu/V}$ 그대로 뽑아요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> T.sample(rng=sd.random.default_rng(3))
array([-0.046889303034321685,  -0.41565319769137493], dtype=float64)
>>> s = T.sample(100000, rng=sd.random.default_rng(3))
>>> s.shape
(100000, 2)
>>> sd.cov(s, rowvar=False, correction=1)
array([[ 2.007986637144399, 1.0273282844341858],
       [1.0273282844341858,  2.046816846562874]], dtype=float64)
```

표본 공분산이 `shape`가 아니라 `covariance()`의 값(2, 1, 1, 2)에 가까워요. 꼬리가 두꺼운 분포라 표본 공분산이 정규분포보다 천천히 수렴해요.

## 다른 분포와의 관계

`df = inf`는 다변량 정규분포예요. 이때 `shape`가 곧 공분산이에요.

```python
>>> Tinf = sd.stats.MultivariateT(mu=sd.zeros(2), shape=sh, df=sd.inf)
>>> x = sd.asarray([1.0, -0.5])
>>> Tinf.pdf(x), N.pdf(x)
(0.05722853182387338, 0.05722853182387338)
>>> Tinf.cdf(x), N.cdf(x)
(0.2960906343541754, 0.2960906343541754)
```

d = 1이면 Student t 분포예요. [`StudentT`](/api/stats/student-t/)에는 위치와 척도가 없어서, 위치 m과 척도 s(`shape`는 s²)를 직접 옮겨요.

```python
>>> one = sd.stats.MultivariateT(mu=sd.asarray([1.0]), shape=sd.asarray([[4.0]]), df=5.0)
>>> one.pdf(sd.asarray([2.0])), sd.stats.StudentT(df=5.0).pdf((2.0 - 1.0) / 2.0) / 2.0
(0.16395926566137325, 0.16395926566137325)
>>> one.cdf(sd.asarray([2.0])), sd.stats.StudentT(df=5.0).cdf(0.5)
(0.6808505641795355, 0.6808505641795355)
```

주변분포도 같은 자유도의 t 분포예요. `cdf`에서 +inf를 넣은 성분은 빠지고, 남은 성분은 같은 `df`의 t 분포로 계산해요.

```python
>>> I.cdf(sd.asarray([1.0, sd.inf])), sd.stats.StudentT(df=3.0).cdf(1.0)
(0.8044988905221148, 0.8044988905221148)
```

## 정확도와 범위

- `pdf`, `logpdf`, `entropy`: [`MultivariateNormal`](/api/stats/multivariate-normal/#정확도와-범위)과 같아요. κ(shape) ≤ 1e9, d ≤ 100에서 `pdf`는 상대 1e-14, `logpdf`·`entropy`는 |오차| ≤ 1e-14 · max(1, |값|)이에요. 자유도가 아주 커도(df = 1e9에서 재 봤어요) 정확도가 떨어지지 않아요.
- `cdf`, d = 2, 3: P ≥ 7e-13에서 상대 1e-14예요(재 본 최대 오차는 1.9e-15). d = 3에서 자유도가 1 이하이고 `x`가 척도보다 1e100배 넘게 크면 NaN이 나올 수 있어요.
- `cdf`, d ≥ 4: `atol`까지의 절대오차를 목표로 하는 통계적 어림이에요. 오차 추정은 표준오차의 3배이고, 참오차가 추정을 넘더라도 재 본 범위에서 1.9배 이하예요.
- 같은 입력이면 스레드 수와 상관없이 같은 비트예요.

자세한 방법은 [다변량 분포의 밀도](/internals/stats/multivariate/)와 [다변량 정규·t의 누적확률](/internals/stats/mvcdf/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.multivariate_t(loc, shape, df)`에 해당해요. 위치의 이름이 `loc`가 아니라 `mu`이고, 모든 매개변수를 키워드로 꼭 줘야 해요(scipy는 `df=1`이 기본값이에요). scipy는 `loc`, `shape`, `x`에 리스트도 받지만, sd는 `sd.ndarray`만 받아요.
- scipy 1.18.1의 `multivariate_t`에는 평균과 공분산을 구하는 메서드가 없어요. sd에는 `mean()`, `covariance()`가 있어요.
- `allow_singular`가 없고, 양정치가 아닌 `shape`는 NaN이에요.
- `cdf`가 결정적이에요. scipy 1.18.1은 난수로 적분해서 `random_state`를 주지 않으면 부를 때마다 값이 달라요(위의 `T.cdf([1, -0.5])`를 세 번 부르면 0.2983874, 0.2983843, 0.2983850이고, sd의 값은 0.2983759예요). sd는 d ≤ 3에서 정확한 공식을 써요.
- `lower_limit`, `marginal`은 없어요.
