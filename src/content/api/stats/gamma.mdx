title: Gamma
names: [Gamma]
group: 연속 분포

summary: 사건이 a번 일어날 때까지 기다리는 시간처럼, 0 이상이고 오른쪽으로 꼬리가 긴 양을 나타내는 감마 분포예요. 모양 a와 척도 scale로 정해요.
params:
  - name: a
    type: Python 실수 또는 ndarray
    kind: keyword-only

  - name: scale
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 척도 매개변수. 0보다 큰 유한한 실수이고 기본값은 1이에요. 비율(rate)로 생각한다면 scale = 1 / rate예요. 두 매개변수 중 하나라도 정의역 밖인 원소는 모든 메서드가 NaN이에요.
returns:
  type: Gamma
  desc: 감마 분포 객체. pdf·cdf·icdf 같은 메서드, mean·variance 같은 요약값, sample을 가져요. a, scale은 읽기 전용 속성으로 준 값 그대로 남아요.
raises:
  - type: TypeError
    desc: 매개변수를 위치로 넘겼거나 a를 빠뜨렸을 때, rate처럼 모르는 키워드를 넘겼을 때, 매개변수가 문자열·리스트·None·복소수이거나 complex128 배열일 때. 값이 정의역 밖인 것은 에러가 아니라 NaN이에요.
  - type: ValueError
    desc: a와 scale이 서로 브로드캐스트할 수 없는 모양의 배열일 때.
  - type: OverflowError
    desc: 매개변수가 float로 바꿀 수 없을 만큼 큰 Python 정수일 때(10**400 등).
seeAlso: [exponential, chi-squared, beta, inverse-gamma, poisson, weibull, methods, sample]

## 어떤 분포인가요

**감마 분포**는 0 이상이고 오른쪽으로 꼬리가 긴 양을 나타내는 분포예요. 가장 쉬운 그림은 "기다리는 시간"이에요. 콜센터에 전화가 평균 2분에 한 통씩 무작위로 걸려 온다면, 다음 전화까지 기다리는 시간은 [지수분포](/api/stats/exponential/)를 따르고, **세 번째 전화가 올 때까지** 기다리는 시간은 모양 3, 척도 2인 감마 분포를 따라요. 지수분포를 따르는 대기 시간 $a$개를 더한 것이 감마 분포예요.

매개변수는 둘이에요.

- **모양** `a`: 몇 번째 사건까지 기다리는지에 해당해요. 정수가 아니어도 돼요. 작으면 0 근처에 몰리고 꼬리가 길고, 크면 종 모양에 가까워져요.
- **척도** `scale`: 사건 사이의 평균 간격에 해당해요. 분포 전체를 가로로 늘이거나 줄여요. 단위 시간당 사건 수인 **비율**(rate)로 생각한다면 `scale = 1 / rate`예요.

기다리는 시간 말고도 이런 곳에서 써요.

- 강수량, 보험 청구액, 서비스 처리 시간처럼 양수이고 한쪽으로 치우친 양의 모형
- 베이즈 통계에서 포아송 비율이나 정규분포 정밀도(분산의 역수)의 사전분포
- 신뢰성 공학에서 부품 여럿이 차례로 고장 나는 시간

```python
>>> import stardust as sd
>>> W = sd.stats.Gamma(a=3, scale=2.0)
>>> W
Gamma(a=3, scale=2.0)
>>> W.cdf(5.0)
0.45618688411667035
>>> W.mean()
6.0
>>> W.icdf(0.9)
10.64464067566842
```

세 번째 전화가 5분 안에 올 확률은 약 46%이고, 평균 6분, 90%의 경우는 10.6분 안에 와요.

## 만들기와 매개변수

`a`는 꼭 줘야 하고, `scale`은 생략하면 1이에요. 둘 다 이름을 붙여서 넘겨요. `rate`라는 매개변수는 없어요.

```python
>>> sd.stats.Gamma(a=2.0)
Gamma(a=2.0, scale=1.0)
>>> sd.stats.Gamma(a=2.0, rate=0.5)
Traceback (most recent call last):
    ...
TypeError: Gamma(): unexpected keyword argument 'rate'
>>> sd.stats.Gamma(a=2.0, scale=1 / 0.5)
Gamma(a=2.0, scale=2.0)
```

두 매개변수 모두 0보다 큰 유한한 실수예요. 하나라도 정의역 밖이면 에러 대신 모든 메서드가 NaN이에요.

```python
>>> sd.stats.Gamma(a=0.0).mean()
nan
>>> sd.stats.Gamma(a=2.0, scale=-1.0).cdf(1.0)
nan
```

`a`와 `scale`에 배열을 주면 서로, 그리고 메서드에 넣는 값과 [브로드캐스팅](/api/array/broadcasting/)해요.

```python
>>> sd.stats.Gamma(a=sd.asarray([1.0, 2.0, 5.0]), scale=2.0).ccdf(10.0)
array([0.006737946999085467,   0.0404276819945128,   0.4404932850652124], dtype=float64)
```

### 척도는 가로로 늘이기만 해요

척도가 $\theta$이면 $X/\theta$는 척도 1인 감마 분포를 따라요. 그래서 `Gamma(a, scale=s).cdf(x)`는 `Gamma(a).cdf(x / s)`와 같아요.

```python
>>> sd.stats.Gamma(a=2.0, scale=3.0).cdf(6.0)
0.5939941502901619
>>> sd.stats.Gamma(a=2.0).cdf(2.0)
0.5939941502901619
```

## 밀도와 누적분포

모양 $a$, 척도 $\theta$인 감마 분포의 밀도는 이래요.

$$
f(x) = \frac{x^{a-1} e^{-x/\theta}}{\Gamma(a)\,\theta^{a}}, \qquad x \ge 0
$$

$\Gamma$는 [감마 함수](/api/special/gamma/)예요. 누적분포는 [정규화된 불완전 감마 함수](/api/special/gammainc/)로 $F(x) = P(a,\ x/\theta)$이고, 위꼬리는 $Q(a,\ x/\theta)$예요. 지지집합은 $[0, \infty)$예요.

```python
>>> G = sd.stats.Gamma(a=2.0, scale=3.0)
>>> G.support()
(0.0, inf)
>>> G.pdf(3.0)
0.12262648039048077
>>> G.cdf(3.0), G.ccdf(3.0)
(0.2642411176571153, 0.7357588823428847)
>>> G.icdf(0.5)
5.035040970049981
>>> G.iccdf(0.1)
11.669160509602287
```

0에서의 밀도는 모양이 정해요. $a < 1$이면 $x^{a-1}$이 발산해서 inf, $a = 1$이면 $1/\theta$, $a > 1$이면 0이에요.

```python
>>> sd.stats.Gamma(a=sd.asarray([0.5, 1.0, 2.0])).pdf(0.0)
array([inf, 1.0, 0.0], dtype=float64)
>>> sd.stats.Gamma(a=1.0, scale=4.0).pdf(0.0)
0.25
```

### 꼬리

위꼬리는 `ccdf`가 직접 계산해서 상대 정확도이고, float64 아래로 내려가면 `logccdf`, 0 근처의 아래꼬리는 `logcdf`로 받아요.

```python
>>> G3 = sd.stats.Gamma(a=3.0)
>>> G3.ccdf(800.0)
0.0
>>> G3.logccdf(800.0)
-787.3214237278233
>>> G3.logcdf(1e-200)
-1383.3428152656554
>>> G3.icdf(1e-300)
1.8171205928321398e-100
```

### 아주 작은 모양

모양이 아주 작으면 거의 모든 질량이 0에 바짝 붙어요. `a = 1e-3`이면 값이 1e-300 이하일 확률이 절반이 넘고, 중앙값은 1e-301 근처예요. 평균은 $a\theta$ = 0.001인데, 드물게 나오는 큰 값이 평균을 끌어올리기 때문이에요.

```python
>>> tiny = sd.stats.Gamma(a=1e-3)
>>> tiny.cdf(1e-300)
0.5014761980108866
>>> tiny.median()
5.244206408277985e-302
>>> tiny.mean()
0.001
>>> tiny.icdf(0.4)
0.0
```

마지막 줄의 40% 분위수는 참값이 약 1e-398이라 float64가 나타낼 수 있는 가장 작은 수(약 5e-324)보다 작아서 0이에요. 메서드의 공통 의미는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

## 요약값

| 요약값 | 값 |
|---|---|
| `mean()` | $a\theta$ |
| `variance()` | $a\theta^2$ |
| `skewness()` | $2/\sqrt{a}$ |
| `kurtosis()` | $6/a$ |
| `mode()` | $(a - 1)\theta$ ($a \ge 1$), $a < 1$이면 0 |
| `median()` | 닫힌 꼴이 없어요(`icdf(0.5)`) |
| `entropy()` | $a + \ln\theta + \ln\Gamma(a) + (1 - a)\psi(a)$ |

$\psi$는 [디감마 함수](/api/special/digamma/)예요. 모든 모양에서 모멘트가 유한해요. `kurtosis()`는 정규분포를 0으로 두는 초과 첨도, `entropy()`는 미분 엔트로피(nat)예요. $a < 1$이면 밀도가 0에서 발산하지만 그 점이 밀도가 가장 큰 점이라 `mode()`는 0이에요.

```python
>>> Gs = sd.stats.Gamma(a=sd.asarray([0.5, 1.0, 2.0, 10.0]), scale=2.0)
>>> Gs.mean()
array([ 1.0,  2.0,  4.0, 20.0], dtype=float64)
>>> Gs.variance()
array([ 2.0,  4.0,  8.0, 40.0], dtype=float64)
>>> Gs.mode()
array([ 0.0,  0.0,  2.0, 18.0], dtype=float64)
>>> Gs.median()
array([0.4549364231195722,  1.386294361119891, 3.3566939800333206,
        19.33742922942826], dtype=float64)
>>> Gs.skewness()
array([  2.82842712474619,                2.0,  1.414213562373095,
       0.6324555320336759], dtype=float64)
>>> Gs.kurtosis()
array([12.0,  6.0,  3.0,  0.6], dtype=float64)
>>> Gs.entropy()
array([0.7837571104739336, 1.6931471805599454,  2.270362845461478,
       3.2292013590409265], dtype=float64)
```

모양이 커질수록 왜도와 첨도가 0으로 가요. 감마 분포가 지수분포 여럿의 합이라, 중심극한정리대로 정규분포에 가까워지기 때문이에요. 그리고 언제나 최빈값 < 중앙값 < 평균이에요.

## 표본

`sample`은 감마 분포를 따르는 난수를 뽑아요. 난수 생성기 `rng`를 꼭 줘야 해요.

```python
>>> G.sample(3, rng=sd.random.default_rng(42))
array([ 2.076988460311627,  6.448693474216812, 2.3561238090774825], dtype=float64)
```

모양이 아주 작으면 표본 대부분이 0이에요. 위에서 본 것처럼 질량의 큰 부분이 float64가 나타낼 수 있는 가장 작은 수보다 작아서, 그 표본은 0으로 반올림되는 것이 맞아요.

```python
>>> tiny.sample(5, rng=sd.random.default_rng(42))
array([  6.396050364782383e-72,                     0.0,                     0.0,
       1.8505153361758806e-267,                     0.0], dtype=float64)
```

모양과 재현성의 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

## 다른 분포와의 관계

### 지수분포와 카이제곱은 특별한 경우

모양이 1이면 [지수분포](/api/stats/exponential/), 모양이 $k/2$이고 척도가 2이면 자유도 $k$인 [카이제곱 분포](/api/stats/chi-squared/)예요.

```python
>>> x = sd.asarray([0.5, 2.0, 7.0])
>>> sd.stats.Gamma(a=1.0, scale=3.0).cdf(x)
array([0.1535182751093859, 0.4865828809674077, 0.9030280321355949], dtype=float64)
>>> sd.stats.Exponential(scale=3.0).cdf(x)
array([0.15351827510938593,   0.486582880967408,  0.9030280321355949], dtype=float64)
>>> sd.stats.Gamma(a=2.5, scale=2.0).cdf(x)
array([0.007876706767370406,  0.15085496391539038,   0.7793596920632893], dtype=float64)
>>> sd.stats.ChiSquared(df=5).cdf(x)
array([0.007876706767370406,  0.15085496391539038,   0.7793596920632893], dtype=float64)
```

지수분포와는 마지막 한 자리가 다를 수 있어요. 두 분포가 서로 다른 식으로 계산하기 때문이고, 둘 다 오차 한계 안이에요.

### 더하면 모양이 더해져요

척도가 같은 독립인 감마 변수를 더하면 모양이 더해져요. $X \sim \mathrm{Gamma}(a_1, \theta)$, $Y \sim \mathrm{Gamma}(a_2, \theta)$이면 $X + Y \sim \mathrm{Gamma}(a_1 + a_2, \theta)$예요. 세 번째 전화까지의 시간이 첫 전화까지의 시간 셋의 합인 것과 같은 이야기예요.

```python
>>> rng = sd.random.default_rng(5)
>>> x1 = sd.stats.Gamma(a=2.0, scale=1.5).sample(100000, rng=rng)
>>> x2 = sd.stats.Gamma(a=3.0, scale=1.5).sample(100000, rng=rng)
>>> sd.quantile(x1 + x2, 0.9)
12.002840094574553
>>> sd.stats.Gamma(a=5.0, scale=1.5).icdf(0.9)
11.990384379078947
```

### 나누면 베타 분포

같은 표본으로 $X/(X + Y)$를 만들면 [베타 분포](/api/stats/beta/) $\mathrm{Beta}(a_1, a_2)$를 따라요. 척도는 상관없어요.

```python
>>> sd.mean(x1 / (x1 + x2))
0.3995059578294873
>>> sd.stats.Beta(a=2.0, b=3.0).mean()
0.4
```

### 포아송 분포와의 다리

모양이 정수 $m$이면 "사건이 $m$번 일어날 때까지의 시간이 $t$보다 짧다"는 "시간 $t$ 동안 사건이 $m$번 이상 일어난다"와 같은 말이에요. 그래서 `Gamma(a=m, scale=θ).cdf(t)`는 평균 $t/\theta$인 [포아송 분포](/api/stats/poisson/)의 `ccdf(m - 1)`과 같아요.

```python
>>> W.cdf(5.0)
0.45618688411667035
>>> sd.stats.Poisson(mu=5.0 / 2.0).ccdf(2.0)
0.45618688411667035
```

### 역수는 역감마 분포

$X \sim \mathrm{Gamma}(a, \theta)$이면 $1/X$는 척도 $1/\theta$인 [역감마 분포](/api/stats/inverse-gamma/)를 따라요.

```python
>>> sd.stats.InverseGamma(a=3.0, scale=2.0).cdf(0.5)
0.2381033055535443
>>> sd.stats.Gamma(a=3.0, scale=0.5).ccdf(2.0)
0.2381033055535443
```

### 함수 하나만 필요하면

척도 1인 감마 분포의 누적확률과 분위수는 [`sd.special.gammainc`, `gammaincc`, `gammaincinv`](/api/special/gammainc/)가 같은 값을 줘요. 척도가 있으면 값을 척도로 나눠서 넣고, 분위수에는 척도를 곱해요.

```python
>>> sd.special.gammainc(2.0, 3.0 / 3.0)
0.2642411176571153
>>> 3.0 * sd.special.gammaincinv(2.0, 0.5)
5.035040970049981
```

## 정확도와 범위

- **보장 영역**: 모양 $0 < a \le 10^6$(척도는 아무 양수)에서 모든 메서드가 참값 대비 상대오차 1e-14 이하예요. 위꼬리 `ccdf`와 아래꼬리 `cdf` 모두 아주 작은 확률까지 상대 정확도예요. `logpdf`와 `entropy`는 $10^{-14}\cdot\max(1, |\text{값}|)$, 역함수는 입력 확률에 대한 민감도만큼 더 허용해요([stats의 기본](/api/stats/basics/)).
- **잰 값**: 보장 영역 안에서 메서드별 잰 최대 오차는 `cdf`가 1.4e-15, `ccdf`가 1.8e-15, 가장 큰 `entropy`가 5.3e-15예요.
- **보장 영역 밖**: 모양이 $10^6$보다 커도 값을 계산하지만 정확도를 약속하지는 않아요.

값을 구할 수 없는 곳에서는 NaN이에요. 모든 호출은 정해진 시간 안에 끝나요.

- 모양이 $2^{100}$(약 1.3e30)을 넘으면 `cdf` 계열과 역함수가 NaN이에요. 밀도와 모멘트는 계산해요.
- 모양이 $[10^{-6}, 10^6]$ 밖이면 역함수는 구한 근을 다시 넣어 확인하고, 맞을 때만 값을 내요. 확률이 $2^{-1000}$보다 작은 깊은 꼬리의 역함수가 정해진 반복 안에 수렴하지 않을 때도 NaN이에요(모양이 1e12 이상일 때 나와요).
- 아주 작은 모양은 서브노멀(약 2.2e-308보다 작은 수)이어도 `cdf` 계열과 역함수가 값을 내요.

```python
>>> big = sd.stats.Gamma(a=2.0 ** 101)
>>> big.cdf(2.0 ** 101)
nan
>>> big.mean()
2.535301200456459e+30
>>> sd.stats.Gamma(a=5e-324).logccdf(1.0)
-745.9570038803834
>>> sd.stats.Gamma(a=1e-307).iccdf(5e-307), sd.stats.Gamma(a=1e-307).icdf(0.3)
(0.0037974640015846902, 0.0)
```

모양이 이렇게 작으면 아래꼬리의 분위수는 $p^{1/a}$ 꼴이라 $p < 1$이면 float64가 담을 수 있는 어떤 수보다도 작아서 0이에요. 위꼬리 확률 $5a$의 분위수는 0이 아닌 값이에요.

모양이 아주 작으면 위꼬리의 분위수도 0에 바짝 붙어요. 위꼬리 확률이 $c\cdot a$이면 근은 약 $e^{-c-\gamma}$($\gamma$는 오일러 상수)라서, $c = 700$이면 근이 약 5.5e-305예요. 이런 근도 float64로 나타낼 수 있으면 언제나 값을 내요. 가장 작은 양수(약 5e-324)의 절반보다 작으면 0이고, 척도가 크면 척도를 곱한 값이 float64 안에 들어올 수 있어서 그 값을 내요.

```python
>>> sd.stats.Gamma(a=1e-8).iccdf(700e-8), sd.stats.Gamma(a=1e-8).iccdf(760e-8)
(5.522262751657156e-305, 0.0)
>>> sd.stats.Gamma(a=1e-8, scale=1e300).iccdf(800e-8)
2.0527835228667717e-48
```

계산 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에서 설명해요.

## scipy를 아는 분께

- `scipy.stats.gamma`에 해당해요. 모양 이름 `a`와 `scale`은 scipy와 같아요. 메서드 이름은 scipy의 새 분포 API를 따라요(`sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`).
- `loc`이 없어요. 지지집합은 언제나 $[0, \infty)$예요.
- 매개변수는 키워드로만 받아요. `Gamma(2.0)`은 `TypeError`예요.
- `kurtosis()`는 초과 첨도예요(scipy `gamma.stats(a, moments='k')`와 같아요).
- 꼬리에서 scipy가 `-inf`를 내는 곳에서 값을 내요. `Gamma(a=3.0).logccdf(800.0)`은 −787.32이고 scipy `gamma.logsf(800, 3)`은 `-inf`예요.
- 모양이 $2^{100}$을 넘으면 `cdf`가 NaN이에요. scipy는 값을 내요.
- `sample`은 `rng`를 꼭 받아요. 값은 numpy·scipy와 달라요.
