## 어떤 분포인가요

**역Wishart 분포**(inverse Wishart distribution)는 행렬 X의 역행렬 $X^{-1}$이 [Wishart 분포](/api/stats/wishart/)를 따를 때 X의 분포예요. 값 하나하나가 대칭 양정치 행렬이에요.

가장 흔한 쓰임은 **공분산 행렬의 사전분포**예요. 다변량 정규분포의 공분산 Σ를 모를 때 "Σ는 대략 이런 행렬일 것"이라는 믿음을 역Wishart 분포로 두면, 자료를 본 뒤의 사후분포도 역Wishart 분포라서 계산이 간단해요. p = 1이면 분산 하나의 사전분포로 많이 쓰는 [역감마 분포](/api/stats/inverse-gamma/)예요.

```python
>>> import stardust as sd
>>> V = sd.asarray([[2.0, 0.5], [0.5, 1.0]])
>>> IW = sd.stats.InverseWishart(df=5.0, scale=V)
>>> X = sd.asarray([[0.6, 0.1], [0.1, 0.3]])
>>> IW.pdf(X)
2.5314417541304057
>>> IW.logpdf(X)
0.9287890037216534
```

## 만들기와 매개변수

매개변수, 배치, 정의역 규칙은 [`Wishart`](/api/stats/wishart/)와 같아요. `df`는 p − 1보다 큰 유한한 실수(Python 수나 배열), `scale`은 대칭 양정치 p × p 행렬을 담은 `sd.ndarray`이고(리스트는 `TypeError`예요) 아래 삼각만 읽어요. 요약값도 아래 삼각을 대칭으로 옮긴 행렬에서 나와요. 정의역 밖이면 에러가 아니라 그 분포의 모든 메서드가 NaN이에요.

```python
>>> IW
InverseWishart(df=5.0, scale=array([[2.0, 0.5],
       [0.5, 1.0]], dtype=float64))
>>> sd.stats.InverseWishart(df=0.5, scale=V).entropy()
nan
```

## 밀도

$$
f(X) = \frac{|\Psi|^{\nu/2}}{2^{\nu p/2}\,\Gamma_p\!\left(\frac{\nu}{2}\right)}\;
|X|^{-(\nu + p + 1)/2}\; e^{-\operatorname{tr}(\Psi X^{-1})/2}
$$

Ψ는 `scale`, ν는 `df`, $\Gamma_p$는 다변량 감마 함수예요([`Wishart`](/api/stats/wishart/#밀도)). 입력 `x`의 모양과 타입(`sd.ndarray`만 받아요), 아래 삼각만 읽는 것, 양정치가 아닌 `x`에서 밀도 0(`logpdf`는 −inf)인 것, 원소가 아무리 커도 `logpdf`가 NaN이 아닌 것은 `Wishart`와 같아요.

```python
>>> IW.pdf(sd.asarray([[1.0, 2.0], [2.0, 1.0]]))
0.0
>>> IW.logpdf(sd.asarray([[1e300, 0.0], [0.0, 1.0]]))
-2766.525855839214
```

반대로 원소가 아주 작아서 $\operatorname{tr}(\Psi X^{-1})$이 float64를 넘으면(서브노멀 대각 등) 밀도는 0, `logpdf`는 −inf예요. p = 1의 [`InverseGamma`](/api/stats/inverse-gamma/)와 같아요.

```python
>>> IW.logpdf(sd.asarray([[1e-310, 0.0], [0.0, 1.0]]))
-inf
>>> sd.stats.InverseGamma(a=2.5, scale=1.0).logpdf(1e-310)
-inf
```

### Wishart와의 관계

$X^{-1}$이 Wishart(ν, $\Psi^{-1}$)를 따르므로, 두 밀도는 변수 변환의 야코비안 $|X|^{-(p+1)}$만큼 달라요.

$$
f_{\mathrm{IW}}(X;\, \nu, \Psi) = f_{\mathrm{W}}(X^{-1};\, \nu, \Psi^{-1})\; |X|^{-(p+1)}
$$

```python
>>> W = sd.stats.Wishart(df=5.0, scale=sd.linalg.inv(V))
>>> W.pdf(sd.linalg.inv(X)) * sd.linalg.det(X) ** -3
2.531441754130406
```

p = 2라 지수가 −3이에요. 마지막 자리가 다른 것은 역행렬과 곱셈의 반올림이에요.

## 요약값

| 메서드 | 값 | 정의되지 않을 때 |
|---|---|---|
| `mean()` | $\Psi / (\nu - p - 1)$ (ν > p + 1) | 그 밖은 발산 |
| `mode()` | $\Psi / (\nu + p + 1)$ | |
| `var()` | 원소별 분산 (ν > p + 3, 아래 식) | p + 1 < ν ≤ p + 3이면 inf, ν ≤ p + 1이면 NaN |
| `entropy()` | 미분 엔트로피(nat) | |

원소별 분산은 이래요.

$$
\operatorname{Var}(X_{ij}) = \frac{(\nu - p + 1)\,\Psi_{ij}^2 + (\nu - p - 1)\,\Psi_{ii}\Psi_{jj}}{(\nu - p)(\nu - p - 1)^2(\nu - p - 3)}
$$

```python
>>> IW.mean()
array([[ 1.0, 0.25],
       [0.25,  0.5]], dtype=float64)
>>> IW.mode()
array([[  0.25, 0.0625],
       [0.0625,  0.125]], dtype=float64)
>>> IW.entropy()
0.11326605064607614
>>> sd.stats.InverseWishart(df=8.0, scale=V).var()
array([[ 0.10666666666666667, 0.026111111111111113],
       [0.026111111111111113,  0.02666666666666667]], dtype=float64)
```

### 꼬리가 두꺼워 모멘트가 발산해요

역Wishart 분포는 오른쪽 꼬리가 두꺼워서 자유도가 작으면 평균이나 분산이 무한대예요. 단변량 [`InverseGamma`](/api/stats/inverse-gamma/)와 같은 규칙이에요.

- `mean()`: ν ≤ p + 1이면 발산해요. 원소마다 `scale`의 부호를 따라 +inf나 −inf이고, `scale`의 원소가 0인 곳은 0이에요.
- `var()`: 평균은 유한하지만 분산이 발산하는 p + 1 < ν ≤ p + 3에서는 inf, 평균부터 발산하는 ν ≤ p + 1에서는 NaN이에요.

```python
>>> sd.stats.InverseWishart(df=3.0, scale=sd.asarray([[2.0, -0.5], [-0.5, 1.0]])).mean()
array([[ inf, -inf],
       [-inf,  inf]], dtype=float64)
>>> sd.stats.InverseWishart(df=3.0, scale=sd.eye(2)).mean()
array([[inf, 0.0],
       [0.0, inf]], dtype=float64)
>>> IW.var()
array([[inf, inf],
       [inf, inf]], dtype=float64)
>>> sd.stats.InverseWishart(df=3.0, scale=V).var()
array([[nan, nan],
       [nan, nan]], dtype=float64)
```

p = 2에서 ν = 5는 p + 1 < ν ≤ p + 3이라 평균은 유한하지만 분산이 inf예요.

## 표본

`sample(shape, rng=...)`은 `shape` + 배치 + (p, p) 모양의 대칭 양정치 행렬이에요. `shape`를 빼면 분포마다 행렬 하나(배치 + (p, p))예요. 행렬 하나가 표본 하나이고, 결과는 정확히 대칭이에요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> I8 = sd.stats.InverseWishart(df=8.0, scale=V)
>>> sd.mean(I8.sample(100000, rng=sd.random.default_rng(8)), axis=0)
array([[ 0.4010032207690723,  0.1004250818813093],
       [ 0.1004250818813093, 0.20014519419429508]], dtype=float64)
>>> I8.mean()
array([[0.4, 0.1],
       [0.1, 0.2]], dtype=float64)
```

### 공분산의 베이즈 갱신

평균이 0인 다변량 정규 자료 $z_1, \dots, z_n$의 공분산 Σ에 사전분포 InverseWishart(ν₀, Ψ₀)를 두면, 사후분포는 InverseWishart(ν₀ + n, Ψ₀ + Σᵢ zᵢzᵢᵀ)예요.

```python
>>> z = sd.stats.MultivariateNormal(mu=sd.zeros(2), cov=V).sample(50, rng=sd.random.default_rng(9))
>>> post = sd.stats.InverseWishart(df=4.0 + 50, scale=sd.eye(2) + z.T @ z)
>>> post.mean()
array([[1.7491886578591809, 0.5338264110260644],
       [0.5338264110260644, 1.0394203802433661]], dtype=float64)
```

참 공분산 V = [[2, 0.5], [0.5, 1]]을 몰라도, 표본 50개로 사후 평균이 그 근처까지 와요.

## 다른 분포와의 관계

**p = 1이면 역감마 분포**예요. `scale = [[s]]`이면 [`InverseGamma`](/api/stats/inverse-gamma/)(a = ν/2, scale = s/2)예요.

```python
>>> one = sd.stats.InverseWishart(df=6.0, scale=sd.asarray([[4.0]]))
>>> one.pdf(sd.asarray([[0.7]])), sd.stats.InverseGamma(a=3.0, scale=2.0).pdf(0.7)
(0.9568116496062866, 0.9568116496062866)
>>> one.entropy(), sd.stats.InverseGamma(a=3.0, scale=2.0).entropy()
(0.695157020726022, 0.695157020726022)
```

## 정확도와 범위

[`Wishart`](/api/stats/wishart/#정확도와-범위)와 같아요. κ(scale) ≤ 1e9, p ≤ 100에서 `logpdf`와 `entropy`는 |오차| ≤ 1e-14 · max(1, |값|)이고, `logpdf`의 이 보장은 df ≤ 1e30까지예요. 그보다 크면 반올림 오차의 상한이 기준을 넘는 곳에서 NaN이고, 그 자유도는 점마다 달라요. 원소가 반올림된 점은 df가 약 1e31–3e35부터, 분포에서 뽑은 점은 약 2.4e32–1e35부터예요. 역Wishart의 평균과 최빈값은 scale = I여도 원소가 반올림된 점이라 이 범위에 들어요. 가장 이른 것은 p = 10, κ(scale) = 1e4인 평균의 df ≈ 1e31이에요. df ≤ 1e30에서는 이런 NaN이 나오지 않아요. 자세한 방법은 [행렬 분포](/internals/stats/matrix/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.invwishart(df, scale)`에 해당해요. 클래스 이름은 `InverseWishart`이고, 키워드로만 받고 기본값이 없어요. scipy는 `scale`과 `x`에 리스트도 받지만, stardust는 `sd.ndarray`만 받아요.
- 평균이나 분산이 발산하면 inf나 NaN이에요. scipy 1.18.1은 `None`을 돌려줘요.
- df ≤ p − 1이면 NaN이에요. scipy 1.18.1은 `ValueError`를 내요.

**엔트로피가 달라요.** scipy 1.18.1의 `invwishart.entropy()`는 p ≥ 2에서 값이 틀려요. 위의 `IW`(df = 5, p = 2)를 scipy는 1.1529868214859942로 계산하는데, 엔트로피의 정의 $-E[\log f(X)]$를 표본으로 어림하면 stardust의 값 0.1132660…과 맞아요.

```python
>>> s = IW.sample(200000, rng=sd.random.default_rng(7))
>>> -sd.mean(IW.logpdf(s))
0.11323402715600685
```

표본 20만 개의 평균이라 표준오차가 0.006쯤이고, stardust의 값과는 그 안에서 맞고 scipy의 값과는 1 넘게 떨어져 있어요. p = 1에서는 두 값이 반올림 차이 안에서 같아요.
