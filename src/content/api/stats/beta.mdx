## 어떤 분포인가요

**베타 분포**는 0과 1 사이에 있는 값의 분포예요. 그래서 "확률이 얼마쯤일까", "비율이 얼마쯤일까"처럼 그 자체가 0과 1 사이인 양을 나타내는 데 잘 맞아요.

가장 흔한 쓰임은 성공 확률의 어림이에요. 광고를 200번 보여 줘서 30번 클릭됐다면 클릭률은 0.15쯤이겠지만, 200번으로는 0.12일 수도 0.19일 수도 있어요. 처음에 클릭률에 대해 아무것도 모른다고 두면(0과 1 사이의 균등분포), 클릭 $s$번과 비클릭 $f$번을 본 뒤의 클릭률은 $\mathrm{Beta}(s + 1,\ f + 1)$을 따른다고 볼 수 있어요(베이즈 추론). 성공을 볼수록 `a`가, 실패를 볼수록 `b`가 커지는 셈이에요.

- **베이즈 A/B 테스트**: 두 광고의 클릭률 분포를 비교할 때
- **비율의 모형**: 하루 중 일한 시간의 비율, 득표율, 불량률처럼 0과 1 사이인 양
- **순서통계량**: 0과 1 사이 균등 난수 $n$개 중 $k$번째로 작은 값의 분포
- **프로젝트 일정 추정(PERT)**: 최소·최빈·최대 시간으로 작업 시간을 어림할 때

```python
>>> import stardust as sd
>>> P = sd.stats.Beta(a=31.0, b=171.0)
>>> P.mean()
0.15346534653465346
>>> P.icdf(0.025), P.icdf(0.975)
(0.10725992725414965, 0.2061631949459787)
>>> P.ccdf(0.2)
0.04007256009710745
```

200번 중 30번 클릭된 광고의 클릭률은 95% 확률로 약 0.107에서 0.206 사이이고, 클릭률이 0.2를 넘을 확률은 약 4%예요.

## 만들기와 매개변수

두 모양 `a`, `b`를 꼭 이름을 붙여서 줘요. 기본값은 없어요. 둘 다 0보다 큰 유한한 실수예요.

```python
>>> B = sd.stats.Beta(a=2.0, b=5.0)
>>> B
Beta(a=2.0, b=5.0)
>>> B.a, B.b
(2.0, 5.0)
>>> sd.stats.Beta(a=0.0, b=1.0).mean()

>>> sd.stats.Beta(a=1.0, b=sd.inf).mean()

```

두 모양을 배열로 주면 서로, 그리고 메서드에 넣는 값과 [브로드캐스팅](/api/array/broadcasting/)해요. 두 광고 A, B의 클릭률 분포를 한 객체로 다룰 수 있어요.

>>> ab = sd.stats.Beta(a=sd.asarray([31.0, 45.0]), b=sd.asarray([171.0, 157.0]))

## 밀도와 누적분포

$$
f(x) = \frac{x^{a-1} (1 - x)^{b-1}}{B(a, b)}, \qquad 0 \le x \le 1
$$

$B(a, b)$는 넓이를 1로 맞추는 [베타 함수](/api/special/beta/)예요. 누적분포는 [정규화된 불완전 베타 함수](/api/special/betainc/) $F(x) = I_x(a, b)$예요. 지지집합은 $[0, 1]$이고, 그 밖에서 `pdf`는 0, `cdf`는 0 또는 1이에요.

```python
>>> B.support()
(0.0, 1.0)
>>> B.pdf(0.2)
2.4576000000000002
>>> B.cdf(0.2), B.ccdf(0.2)
(0.3446400000000002, 0.6553599999999997)
>>> B.icdf(0.5)
0.26444998329566005
>>> B.pdf(1.5), B.cdf(1.5)
(0.0, 1.0)
```

양 끝에서의 밀도는 모양이 정해요. 0에서는 $a < 1$이면 inf, $a = 1$이면 $b$, $a > 1$이면 0이에요. 1에서는 $a$와 $b$의 역할이 바뀌어요.

```python
>>> sd.stats.Beta(a=sd.asarray([0.5, 1.0, 2.0]), b=3.0).pdf(0.0)
array([inf, 3.0, 0.0], dtype=float64)
>>> sd.stats.Beta(a=2.0, b=sd.asarray([0.5, 1.0, 2.0])).pdf(1.0)
array([inf, 2.0, 0.0], dtype=float64)
```

### 양 끝의 꼬리

베타 분포의 꼬리는 0과 1 근처예요. 1 근처의 확률을 `1 - cdf`로 만들면 사라지니 `ccdf`를 쓰고, 0 근처의 아주 작은 확률은 `logcdf`로 받아요.

```python
>>> 1 - B.cdf(0.999999)
0.0
>>> B.ccdf(0.999999)
5.999995000862669e-30
>>> B.logpdf(1e-300)
-687.3743305165516
>>> sd.stats.Beta(a=2.5, b=0.7).logcdf(1e-200)
-1151.8689825187466
>>> B.icdf(1e-300)
2.5819888974716112e-151
```

1 바로 아래의 근은 float64로 1과 구별할 수 없으면 1이 돼요. `B.iccdf(1e-300)`의 참값은 $1 - 10^{-60}$ 정도라 1.0이에요. 메서드의 공통 의미는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

```python
>>> B.iccdf(1e-300)
1.0
```

## 요약값

| 요약값 | 값 |
|---|---|
| `mean()` | $\dfrac{a}{a + b}$ |
| `variance()` | $\dfrac{ab}{(a + b)^2 (a + b + 1)}$ |
| `skewness()` | $\dfrac{2 (b - a)\sqrt{a + b + 1}}{(a + b + 2)\sqrt{ab}}$ |
| `kurtosis()` | $\dfrac{6\left[(a - b)^2 (a + b + 1) - ab(a + b + 2)\right]}{ab(a + b + 2)(a + b + 3)}$ |
| `mode()` | 아래 규칙 |
| `median()` | 닫힌 꼴이 없어요(`icdf(0.5)`) |
| `entropy()` | $\ln B(a, b) - (a - 1)\psi(a) - (b - 1)\psi(b) + (a + b - 2)\psi(a + b)$ |

$\psi$는 [디감마 함수](/api/special/digamma/)예요. 지지집합이 유한해서 모든 모멘트가 언제나 유한해요. `kurtosis()`는 정규분포를 0으로 두는 초과 첨도라, 양 끝으로 갈라진 U자 분포에서는 음수예요. `entropy()`는 미분 엔트로피(nat)이고, 질량이 좁게 모일수록 음수가 돼요.

```python
>>> B.mean(), B.variance()
(0.2857142857142857, 0.025510204081632654)
>>> B.standard_deviation()
0.15971914124998499
>>> B.skewness(), B.kurtosis()
(0.5962847939999439, -0.12)
>>> B.median()
0.26444998329566005
>>> B.entropy()
-0.4845307149954882
```

모양을 바꿔 가며 보면 이래요. `Beta(a=1, b=1)`은 0과 1 사이의 균등분포라 엔트로피의 참값이 0이에요. 0 근처의 값은 절대오차 1e-14 안이라는 약속이라, 정확히 0이 아니라 아주 작은 수가 나올 수 있어요.

```python
>>> Bs = sd.stats.Beta(a=sd.asarray([0.5, 1.0, 2.0, 2.0]), b=sd.asarray([0.5, 1.0, 5.0, 2.0]))
>>> Bs.kurtosis()
array([               -1.5,                -1.2,               -0.12,
       -0.8571428571428571], dtype=float64)
>>> Bs.entropy()
array([ -0.24156447527049052, 9.698083058519828e-18,   -0.4845307149954882,
        -0.12509280256138886], dtype=float64)
```

### 최빈값의 규칙

`mode()`는 밀도가 가장 큰 점이에요. 그 점이 끝점이어도, 거기서 밀도가 발산해도 그 점을 돌려줘요. 가장 큰 점이 하나로 정해지지 않으면 NaN이에요.

| 모양 | `mode()` | 까닭 |
|---|---|---|
| $a > 1$, $b > 1$ | $\dfrac{a - 1}{a + b - 2}$ | 가운데의 봉우리 |
| $a \le 1 < b$, 또는 $a < 1 = b$ | 0 | 밀도가 0에서 가장 커요 |
| $b \le 1 < a$, 또는 $b < 1 = a$ | 1 | 밀도가 1에서 가장 커요 |
| $a < 1$, $b < 1$ | NaN | 양 끝에서 모두 발산해요 |
| $a = b = 1$ | NaN | 밀도가 평평해요(균등분포) |

```python
>>> M = sd.stats.Beta(a=sd.asarray([2.0, 1.0, 0.5, 1.0, 0.5, 1.0, 2.0]),
...                   b=sd.asarray([5.0, 2.0, 2.0, 0.5, 0.5, 1.0, 1.0]))
>>> M.mode()
array([0.2, 0.0, 0.0, 1.0, nan, nan, 1.0], dtype=float64)
```

## 표본

`sample`은 베타 분포를 따르는 난수를 뽑아요. 난수 생성기 `rng`를 꼭 줘야 해요. 두 광고의 클릭률을 함께 뽑아서 "B가 A보다 클릭률이 높을 확률"을 어림할 수 있어요.

```python
>>> B.sample(3, rng=sd.random.default_rng(42))
array([0.12084408259293464,  0.5417609763863296, 0.21657382785605558], dtype=float64)
>>> draws = ab.sample(100000, rng=sd.random.default_rng(7))
>>> draws.shape
(100000, 2)
>>> sd.mean(draws[:, 1] > draws[:, 0])
0.96168
```

B의 클릭률이 A보다 높을 확률은 약 96%예요. 매개변수가 (2,) 모양이라 결과의 마지막 축이 광고 둘이에요. 모양과 재현성의 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

## 다른 분포와의 관계

### 균등분포

`Beta(a=1, b=1)`은 0과 1 사이의 [균등분포](/api/stats/uniform/)예요.

```python
>>> x = sd.asarray([0.1, 0.5, 0.9])
>>> sd.stats.Beta(a=1.0, b=1.0).cdf(x)
array([0.1, 0.5, 0.9], dtype=float64)
>>> sd.stats.Uniform(a=0.0, b=1.0).cdf(x)
array([0.1, 0.5, 0.9], dtype=float64)
```

### 거울 대칭

$X \sim \mathrm{Beta}(a, b)$이면 $1 - X \sim \mathrm{Beta}(b, a)$예요. "성공 확률"을 "실패 확률"로 바꿔 보는 것과 같아요.

```python
>>> sd.stats.Beta(a=2.0, b=5.0).cdf(0.3)
0.5798249999999998
>>> sd.stats.Beta(a=5.0, b=2.0).ccdf(0.7)
0.579825
```

마지막 자리의 차이는 반올림 몇 번의 차이예요.

### 감마 분포의 비

척도가 같은 독립인 [감마 분포](/api/stats/gamma/) 변수 $X \sim \mathrm{Gamma}(a)$, $Y \sim \mathrm{Gamma}(b)$로 만든 $X/(X + Y)$는 $\mathrm{Beta}(a, b)$를 따라요. 감마 변수 여럿을 그 합으로 나누면 [디리클레 분포](/api/stats/dirichlet/)가 되는데, 디리클레 분포는 베타 분포를 범주 여럿으로 넓힌 것이에요.

### 순서통계량

0과 1 사이의 균등 난수 $n$개를 작은 순서로 늘어놓으면, $k$번째 값은 $\mathrm{Beta}(k,\ n - k + 1)$을 따라요. 10개 중 세 번째로 작은 값으로 확인해 볼게요.

```python
>>> u = sd.sort(sd.random.default_rng(11).random((100000, 10)), axis=1)
>>> third = u[:, 2]
>>> sd.mean(third)
0.27341274114543024
>>> sd.stats.Beta(a=3.0, b=8.0).mean()
0.2727272727272727
```

### 이항 분포와의 다리

같은 이야기를 이항 분포로 하면, "균등 난수 $n$개 중 $k$번째 값이 $p$ 이하"는 "$n$개 중 $p$ 이하인 것이 $k$개 이상"과 같아요. 그래서 `Beta(a=k, b=n-k+1).cdf(p)`는 [이항 분포](/api/stats/binomial/)의 `ccdf(k - 1)`과 같아요.

```python
>>> sd.stats.Beta(a=3.0, b=8.0).cdf(0.2)
0.3222004736
>>> sd.stats.Binomial(n=10, p=0.2).ccdf(2.0)
0.3222004736
```

성공 확률이 베타 분포를 따르는 이항 분포는 [베타이항 분포](/api/stats/beta-binomial/)예요.

### F 분포로 바꾸기

[F 분포](/api/stats/f/)를 따르는 $X$로 만든 $\dfrac{d_1 X}{d_1 X + d_2}$는 $\mathrm{Beta}(d_1/2,\ d_2/2)$를 따라요. 예제는 F 분포 페이지에 있어요.

### 함수 하나만 필요하면

누적확률과 분위수는 [`sd.special.betainc`, `betaincc`, `betaincinv`, `betainccinv`](/api/special/betainc/)가 같은 값을 줘요.

```python
>>> sd.special.betainc(2.0, 5.0, 0.2)
0.3446400000000002
>>> sd.special.betaincinv(2.0, 5.0, 0.5)
0.26444998329566
```

역함수는 같은 근을 다른 방법으로 찾아서 마지막 한두 자리가 다를 수 있어요. 둘 다 오차 한계 안이에요.

## 정확도와 범위

- **보장 영역**: 두 모양이 모두 $10^5$ 이하이면 모든 메서드가 참값 대비 상대오차 1e-14 이하예요. 0 근처의 `cdf`와 1 근처의 `ccdf` 모두 아주 작은 확률까지 상대 정확도예요. `logpdf`와 `entropy`는 $10^{-14}\cdot\max(1, |\text{값}|)$, 역함수는 입력 확률에 대한 민감도만큼 더 허용해요([stats의 기본](/api/stats/basics/)).
- **잰 값**: 보장 영역 안에서 메서드별 잰 최대 오차는 `cdf`·`ccdf`가 1.6e-15, 가장 큰 `entropy`가 7.4e-15예요.
- **보장 영역 밖**: 모양이 $10^5$보다 커도 값을 계산하지만 정확도를 약속하지는 않아요.

값을 구할 수 없는 곳에서는 NaN이에요. 모든 호출은 정해진 시간 안에 끝나요.

- 두 모양이 **모두** $2^{100}$(약 1.3e30)을 넘으면 `cdf` 계열과 역함수가 NaN이에요. 하나만 크면 계산해요.
- 모양이 $[10^{-3}, 10^5]$ 밖이면 역함수는 구한 근을 다시 넣어 확인하고, 맞을 때만 값을 내요. 확률이 $2^{-1000}$보다 작은 깊은 꼬리의 역함수가 정해진 반복 안에 수렴하지 않을 때도 NaN이에요.
- `logcdf`는 $b < 10^{-3}$이고 $x > 0.9$인데 아래꼬리가 아주 작을 때(float64 정규수 아래) NaN이에요. 이런 모양에서는 거의 모든 질량이 1에 바짝 붙어 있어요. `cdf` 자체는 값을 내요.

```python
>>> huge = sd.stats.Beta(a=2.0 ** 101, b=2.0 ** 101)
>>> huge.cdf(0.5)
nan
>>> huge.mean()
0.5
>>> edge = sd.stats.Beta(a=1.0, b=1e-300)
>>> edge.cdf(0.95)
2.99573227355399e-300
>>> edge.logcdf(0.95)
nan
```

계산 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에서 설명해요.

## scipy를 아는 분께

- `scipy.stats.beta`에 해당해요. 모양 이름 `a`, `b`는 scipy와 같아요. 메서드 이름은 scipy의 새 분포 API를 따라요(`sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`).
- `loc`, `scale`이 없어요. 지지집합은 언제나 $[0, 1]$이에요.
- `mode()`는 정해진 규칙의 값이에요. 최빈값이 하나로 정해지지 않으면 NaN이에요. scipy의 새 API(`make_distribution(beta)(a=1, b=1).mode()`)는 수치 최적화가 멈춘 점(0.62)을 내요.
- `kurtosis()`는 초과 첨도예요(scipy `beta.stats(a, b, moments='k')`와 같아요).
- 꼬리에서 scipy가 `-inf`를 내는 곳에서 값을 내요. `Beta(a=2.5, b=0.7).logcdf(1e-200)`은 −1151.87이고 scipy `beta.logcdf(1e-200, 2.5, 0.7)`은 `-inf`예요.
- `Beta(a=1, b=1).entropy()`는 9.7e-18이에요(scipy는 0.0). 둘 다 참값 0의 오차 한계 안이에요.
- 두 모양이 모두 $2^{100}$을 넘으면 `cdf`가 NaN이에요. scipy는 값을 내요.
- `sample`은 `rng`를 꼭 받아요. 값은 numpy·scipy와 달라요.
