---
kind: function
title: F
names: [F]
group: 연속 분포
order: 4
signatures:
  - "sd.stats.F(*, dfn, dfd)"
summary: 두 분산 추정값의 비가 따르는 F 분포예요. 여러 집단의 평균을 한 번에 비교하는 분산분석(ANOVA)과 회귀모형의 F 검정에 써요.
params:
  - name: dfn
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 분자의 자유도. 0보다 큰 실수예요(정수가 아니어도 돼요). inf이면 극한 분포예요(dfd/χ²(dfd), 곧 InverseGamma(a=dfd/2, scale=dfd/2)). 0 이하이거나 NaN인 원소, 그리고 두 자유도가 모두 inf인 원소는 모든 메서드가 NaN이에요.
  - name: dfd
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 분모의 자유도. dfn과 같은 정의역이에요. inf이면 극한 분포 χ²(dfn)/dfn이에요. 평균, 분산, 왜도, 첨도가 유한한지는 dfd가 정해요.
returns:
  type: F
  desc: F 분포 객체. pdf·cdf·icdf 같은 메서드, mean·variance 같은 요약값, sample을 가져요. dfn, dfd는 읽기 전용 속성으로 준 값 그대로 남아요.
raises:
  - type: TypeError
    desc: 매개변수를 위치로 넘겼거나 빠뜨렸을 때, 모르는 키워드를 넘겼을 때, 매개변수가 문자열·리스트·None·복소수이거나 complex128 배열일 때. 값이 정의역 밖인 것은 에러가 아니라 NaN이에요.
  - type: ValueError
    desc: dfn과 dfd가 서로 브로드캐스트할 수 없는 모양의 배열일 때.
  - type: OverflowError
    desc: 매개변수가 float로 바꿀 수 없을 만큼 큰 Python 정수일 때(10**400 등).
seeAlso: [chi-squared, student-t, beta, noncentral-f, methods, sample]

## 어떤 분포인가요

**F 분포**는 "두 분산의 비"가 따르는 분포예요. 정규분포에서 나온 두 무리의 흩어짐을 각각 어림해서 나누면, 두 무리의 참 분산이 같을 때 그 비는 1 근처에 모이고 가끔 크게 벗어나요. 그 벗어남의 정도를 재는 잣대가 F 분포예요.

정확히는, 서로 독립인 [카이제곱 분포](/api/stats/chi-squared/) 변수 $U \sim \chi^2_{d_1}$, $V \sim \chi^2_{d_2}$를 각자의 자유도로 나눠 비를 만들면

$$
X = \frac{U / d_1}{V / d_2}
$$

가 자유도 $(d_1, d_2)$인 F 분포를 따라요. 분자의 자유도가 `dfn`(numerator), 분모의 자유도가 `dfd`(denominator)예요. 값은 언제나 0 이상이고, 오른쪽으로 꼬리가 길어요.

이런 곳에서 써요.

- **분산분석(ANOVA)**: 세 가지 비료를 쓴 밭의 평균 수확량이 모두 같은지 한 번에 검정할 때. "집단 사이의 흩어짐 / 집단 안의 흩어짐"이 F 분포를 따라요.
- **회귀모형의 F 검정**: 설명 변수들이 모두 쓸모없는지(계수가 모두 0인지), 변수를 몇 개 더한 큰 모형이 작은 모형보다 나은지 비교할 때
- **두 분산의 비교**: 두 기계가 만든 부품의 무게 분산이 같은지 볼 때

```python
>>> import stardust as sd
>>> X = sd.stats.F(dfn=3, dfd=10)
>>> X
F(dfn=3, dfd=10)
>>> X.cdf(1.0)
0.5676627969783029
>>> X.icdf(0.95)
3.7082648190468435
```

`X.icdf(0.95)`는 자유도 (3, 10)인 F 분포의 위 5% 경계예요. F 통계량이 이 값보다 크면 유의수준 5%에서 "집단 평균이 모두 같다"는 가정을 버려요.

## 만들기와 매개변수

두 자유도 `dfn`, `dfd`를 꼭 이름을 붙여서 줘요. 기본값은 없어요. 둘 다 0보다 큰 실수이고, 정수가 아니어도 돼요.

```python
>>> X.dfn, X.dfd
(3, 10)
>>> sd.stats.F(3, 10)
Traceback (most recent call last):
    ...
TypeError: F(): takes no positional arguments but 2 were given
>>> sd.stats.F(dfn=0, dfd=10).cdf(1.0)
nan
>>> sd.stats.F(dfn=3, dfd=sd.inf).mean()
1.0
>>> sd.stats.F(dfn=sd.inf, dfd=sd.inf).mean()
nan
```

자유도 하나가 inf이면 그 극한 분포예요. 분모 자유도가 inf이면 분모 $V/d_2$가 정확히 1이 되어 $\chi^2(d_1)/d_1$이고, 분자 자유도가 inf이면 분자가 1이 되어 $d_2/\chi^2(d_2)$, 곧 [역감마 분포](/api/stats/inverse-gamma/) $\mathrm{InverseGamma}(d_2/2,\ d_2/2)$예요([분모 자유도가 크면 카이제곱](#분모-자유도가-크면-카이제곱)). 둘 다 inf이면 1 한 점에 몰려서 확률분포가 아니니 NaN이에요.

두 자유도에 배열을 주면 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 브로드캐스트할 수 없는 모양이면 만들 때 `ValueError`예요.

```python
>>> sd.stats.F(dfn=sd.asarray([1.0, 2.0, 4.0]), dfd=sd.asarray([[10.0], [30.0]])).iccdf(0.05)
array([[4.964602743730714, 4.102821015130401,  3.47804969076523],
       [4.170876785766692, 3.315829501013522, 2.689627573691418]], dtype=float64)
>>> sd.stats.F(dfn=sd.asarray([1.0, 2.0]), dfd=sd.asarray([1.0, 2.0, 3.0]))
Traceback (most recent call last):
    ...
ValueError: F(): shapes could not be broadcast together: (2,) (3,)
```

위의 표는 흔히 책 뒤에 실린 "F 분포표"의 한 조각이에요. 행이 분모 자유도, 열이 분자 자유도예요.

## 밀도와 누적분포

자유도가 $(d_1, d_2)$인 F 분포의 밀도는 이래요.

$$
f(x) = \frac{1}{x\,B\!\left(\frac{d_1}{2}, \frac{d_2}{2}\right)} \sqrt{\frac{(d_1 x)^{d_1}\, d_2^{\,d_2}}{(d_1 x + d_2)^{d_1 + d_2}}}, \qquad x \ge 0
$$

$B$는 [베타 함수](/api/special/beta/)예요. 누적분포는 [정규화된 불완전 베타 함수](/api/special/betainc/) $I$로

$$
F(x) = I_{w}\!\left(\frac{d_1}{2}, \frac{d_2}{2}\right), \qquad w = \frac{d_1 x}{d_1 x + d_2}
$$

예요. 지지집합은 $[0, \infty)$이고, 음수에서 `pdf`와 `cdf`는 0이에요.

```python
>>> X.support()
(0.0, inf)
>>> X.pdf(1.0)
0.40412281148856277
>>> X.ccdf(1.0)
0.4323372030216971
>>> X.iccdf(0.05)
3.708264819046845
```

0에서의 밀도는 분자 자유도가 정해요. $d_1 < 2$이면 inf, $d_1 = 2$이면 1, $d_1 > 2$이면 0이에요.

```python
>>> sd.stats.F(dfn=sd.asarray([1.0, 2.0, 3.0]), dfd=5.0).pdf(0.0)
array([inf, 1.0, 0.0], dtype=float64)
```

### 분산분석의 p값

세 가지 비료를 다섯 밭씩에 써서 수확량을 쟀어요. 집단 사이의 제곱합을 자유도 $3 - 1 = 2$로, 집단 안의 제곱합을 자유도 $15 - 3 = 12$로 나눠 비를 만들면 F 통계량이에요.

```python
>>> a = sd.asarray([12.0, 14.0, 11.0, 13.0, 15.0])
>>> b = sd.asarray([16.0, 18.0, 15.0, 17.0, 19.0])
>>> c = sd.asarray([13.0, 15.0, 14.0, 12.0, 16.0])
>>> groups = [a, b, c]
>>> grand = sd.mean(sd.concat(groups))
>>> ssb = sum(5 * (sd.mean(g) - grand) ** 2 for g in groups)
>>> ssw = sum(sd.sum((g - sd.mean(g)) ** 2) for g in groups)
>>> stat = (ssb / 2) / (ssw / 12)
>>> stat
8.666666666666668
>>> sd.stats.F(dfn=2, dfd=12).ccdf(stat)
0.004687259216589209
```

p값이 약 0.005라서 "세 비료의 평균 수확량이 모두 같다"는 가정을 버려요. F 검정은 언제나 위꼬리 하나만 봐요. 집단 평균이 서로 다를수록 분자가 커지기 때문이에요.

### 꼬리

`ccdf`는 위꼬리를 직접 계산해서 아주 작은 확률까지 상대 정확도예요. 그보다 작으면 `logccdf`, 아주 작은 확률의 분위수는 `iccdf`로 구해요.

```python
>>> X7 = sd.stats.F(dfn=3, dfd=7)
>>> X7.iccdf(1e-30)
1107308919.110723
>>> X7.ccdf(1107308919.110723)
1.000000000000001e-30
>>> X7.logccdf(1e300)
-2413.903705635252
>>> X.logcdf(1e-300)
-1035.7694256947732
>>> X.logpdf(1e300)
-4136.028012900508
```

`icdf(0)`은 0, `icdf(1)`은 inf이고, [0, 1] 밖의 확률은 NaN이에요. 메서드의 공통 의미는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

## 요약값

$d_1$, $d_2$를 두 자유도라 할 때

| 요약값 | 값 | 유한한 조건 |
|---|---|---|
| `mean()` | $\dfrac{d_2}{d_2 - 2}$ | $d_2 > 2$ |
| `variance()` | $\dfrac{2 d_2^2 (d_1 + d_2 - 2)}{d_1 (d_2 - 2)^2 (d_2 - 4)}$ | $d_2 > 4$ |
| `skewness()` | $\dfrac{(2 d_1 + d_2 - 2)\sqrt{8 (d_2 - 4)}}{(d_2 - 6)\sqrt{d_1 (d_1 + d_2 - 2)}}$ | $d_2 > 6$ |
| `kurtosis()` | $\dfrac{12\left[d_1 (5 d_2 - 22)(d_1 + d_2 - 2) + (d_2 - 4)(d_2 - 2)^2\right]}{d_1 (d_2 - 6)(d_2 - 8)(d_1 + d_2 - 2)}$ | $d_2 > 8$ |
| `mode()` | $\dfrac{d_1 - 2}{d_1}\cdot\dfrac{d_2}{d_2 + 2}$ | $d_1 > 2$, 그 밖은 0 |
| `median()` | 닫힌 꼴이 없어요(`icdf(0.5)`) | |
| `entropy()` | $\ln\dfrac{d_2}{d_1} + \ln B(a, b) + (1 - a)\psi(a) - (1 + b)\psi(b) + (a + b)\psi(a + b)$, $a = \frac{d_1}{2}$, $b = \frac{d_2}{2}$ | |

$\psi$는 [디감마 함수](/api/special/digamma/)예요. `kurtosis()`는 초과 첨도, `entropy()`는 미분 엔트로피(nat)예요. 모든 모멘트가 분모 자유도 $d_2$에만 조건이 걸리는 것은 분모의 카이제곱이 0 근처에 있을 확률 때문이에요. 분모가 0에 가까우면 비가 아주 커지고, $d_2$가 작을수록 그런 일이 잦아요.

```python
>>> X.mean(), X.variance()
(1.25, 1.9097222222222223)
>>> X.standard_deviation()
1.3819269959814167
>>> X.skewness(), X.kurtosis()
(4.221158824088691, 59.45454545454546)
>>> X.median(), X.mode()
(0.8450805765917135, 0.2777777777777778)
>>> X.entropy()
1.1976549872009679
```

### 모멘트가 없을 때: NaN과 inf

$d_2$가 작아지면 모멘트가 차례로 무한해져요. 분모 자유도를 배열로 주면 한눈에 볼 수 있어요.

```python
>>> Xs = sd.stats.F(dfn=3.0, dfd=sd.asarray([1.5, 3.0, 5.0, 7.0, 9.0, 20.0]))
>>> Xs.mean()
array([               inf,                3.0, 1.6666666666666667,
                      1.4, 1.2857142857142858, 1.1111111111111112], dtype=float64)
>>> Xs.variance()
array([               nan,                inf, 11.111111111111112,
        3.484444444444444, 2.2040816326530615,  1.080246913580247], dtype=float64)
>>> Xs.skewness()
array([               nan,                nan,                inf,
                     11.0,  5.003702332976757, 2.4435313546278805], dtype=float64)
>>> Xs.kurtosis()
array([               nan,                nan,                inf,
                      inf, 124.66666666666667, 11.448979591836734], dtype=float64)
```

규칙은 이래요.

- **평균**: F 분포는 0 이상이라 적분이 발산하면 $+\infty$로만 가요. 그래서 $d_2 \le 2$이면 평균은 NaN이 아니라 inf예요.
- **분산**: $2 < d_2 \le 4$이면 평균은 유한하고 제곱의 평균이 발산하니 inf예요. $d_2 \le 2$이면 평균부터 무한해서 "평균에서 떨어진 정도"를 말할 수 없으니 NaN이에요.
- **왜도**: $4 < d_2 \le 6$이면 분산은 유한하고 세제곱의 평균이 $+\infty$로 발산하니 inf예요. 분산이 유한하지 않으면($d_2 \le 4$) NaN이에요.
- **첨도**: $4 < d_2 \le 8$이면 분산은 유한하고 네제곱의 평균이 $+\infty$로 발산하니 inf예요. 분산이 유한하지 않으면($d_2 \le 4$) NaN이에요.

## 다른 분포와의 관계

### 카이제곱의 비

정의 그대로, 카이제곱 표본 둘을 각자의 자유도로 나눈 비는 F 분포를 따라요.

```python
>>> rng = sd.random.default_rng(3)
>>> u = sd.stats.ChiSquared(df=3).sample(100000, rng=rng)
>>> v = sd.stats.ChiSquared(df=10).sample(100000, rng=rng)
>>> r = (u / 3) / (v / 10)
>>> sd.mean(r)
1.2530766548223164
>>> sd.mean(r > X.icdf(0.95))
0.05106
```

표본 평균이 `X.mean()`의 1.25에 가깝고, 위 5% 경계를 넘는 비율이 약 5%예요.

### 베타 분포로 바꾸기

$X$가 F 분포를 따르면 $W = \dfrac{d_1 X}{d_1 X + d_2}$는 [베타 분포](/api/stats/beta/) $\mathrm{Beta}(d_1/2,\ d_2/2)$를 따라요. 누적분포 식에서 본 바로 그 변환이에요.

```python
>>> x = sd.asarray([0.5, 2.0, 7.0])
>>> sd.stats.F(dfn=4, dfd=6).cdf(x)
array([        0.26171875, 0.7863390254060808, 0.9809269525029634], dtype=float64)
>>> sd.stats.Beta(a=2.0, b=3.0).cdf(4 * x / (4 * x + 6))
array([        0.26171875, 0.7863390254060808, 0.9809269525029634], dtype=float64)
```

### 역수는 자유도를 바꾼 F

분자와 분모를 바꾸면 $1/X$는 자유도 $(d_2, d_1)$인 F 분포를 따라요. 그래서 $P(X \le x) = P(1/X \ge 1/x)$예요.

```python
>>> sd.stats.F(dfn=4, dfd=6).cdf(2.0)
0.7863390254060808
>>> sd.stats.F(dfn=6, dfd=4).ccdf(0.5)
0.7863390254060808
```

### t의 제곱

자유도 $\nu$인 [t 분포](/api/stats/student-t/)를 따르는 값의 제곱은 $F(1, \nu)$를 따라요. 그래서 t 검정의 양측 p값과 $F(1, \nu)$의 위꼬리가 같아요.

```python
>>> 2 * sd.stats.StudentT(df=7).ccdf(2.5)
0.04099221858575289
>>> sd.stats.F(dfn=1, dfd=7).ccdf(2.5 ** 2)
0.04099221858575289
```

### 분모 자유도가 크면 카이제곱

$d_2$가 커지면 분모 $V/d_2$가 1로 모여서, $d_1 X$가 자유도 $d_1$인 카이제곱 분포에 가까워져요. `dfd=inf`는 그 극한이라 카이제곱과 똑같아요.

```python
>>> sd.stats.F(dfn=3, dfd=1e5).cdf(x)
array([0.31772880416905747,  0.8883824771443609,  0.9998946180627202], dtype=float64)
>>> sd.stats.F(dfn=3, dfd=sd.inf).cdf(x)
array([0.31772966966378746,  0.8883897749052875,  0.9998947238182285], dtype=float64)
>>> sd.stats.ChiSquared(df=3).cdf(3 * x)
array([0.31772966966378746,  0.8883897749052875,  0.9998947238182285], dtype=float64)
```

거꾸로 분자 자유도 $d_1$이 커지면 분자 $U/d_1$이 1로 모여서, $X$가 $d_2/V$, 곧 역감마 분포 $\mathrm{InverseGamma}(d_2/2,\ d_2/2)$에 가까워져요. `dfn=inf`는 역감마 분포와 똑같아요.

```python
>>> sd.stats.F(dfn=sd.inf, dfd=6).cdf(x)
array([0.06196880441665896,  0.8088468305380582,  0.9904532609400744], dtype=float64)
>>> sd.stats.InverseGamma(a=3.0, scale=3.0).cdf(x)
array([0.06196880441665896,  0.8088468305380582,  0.9904532609400744], dtype=float64)
```

### 비중심 F 분포

집단 평균이 실제로 다를 때 F 통계량이 따르는 분포는 [비중심 F 분포](/api/stats/noncentral-f/)예요(검정력 계산). 비중심 모수가 0이면 이 분포와 같아요.

```python
>>> sd.stats.NoncentralF(dfn=3, dfd=10, nc=0.0).cdf(1.0)
0.5676627969783029
```

### 함수 하나만 필요하면

누적확률이나 분위수 하나만 필요하면 [`sd.special.fdtr`, `fdtrc`, `fdtri`](/api/special/fdtr/)도 같은 값을 줘요.

```python
>>> sd.special.fdtr(3, 10, 1.0)
0.5676627969783029
>>> sd.special.fdtrc(3, 10, 1.0)
0.4323372030216971
```

역함수 `fdtri`와 `F.icdf`는 같은 근을 다른 방법으로 찾아서 마지막 한두 자리가 다를 수 있어요. 둘 다 오차 한계 안이에요.

## 정확도와 범위

- **보장 영역**: 두 자유도가 모두 $10^5$ 이하이면 모든 메서드가 참값 대비 상대오차 1e-14 이하예요. 위꼬리 `ccdf`와 아래꼬리 `cdf` 모두 아주 작은 확률까지 상대 정확도예요. `logpdf`와 `entropy`는 $10^{-14}\cdot\max(1, |\text{값}|)$, 역함수는 입력 확률에 대한 민감도만큼 더 허용해요([stats의 기본](/api/stats/basics/)).
- **잰 값**: 보장 영역 안에서 메서드별 잰 최대 오차는 `cdf`가 2.3e-15, `ccdf`가 3.5e-15, 가장 큰 `entropy`가 9.2e-15예요.
- **보장 영역 밖**: 자유도가 $10^5$보다 커도 값을 계산하지만 정확도를 약속하지는 않아요.

값을 구할 수 없는 곳에서는 NaN이에요. 모든 호출은 정해진 시간 안에 끝나요.

- 두 자유도가 **모두** $2^{101}$(약 2.5e30)을 넘으면 `cdf` 계열과 역함수가 NaN이에요. 하나만 크면 계산해요.
- 자유도가 $2^{-1021}$(약 4.5e-308)보다 작으면 `pdf`, `cdf` 계열, 역함수, `median`, `entropy`, 표본이 NaN이에요. 자유도의 절반을 float64로 정확히 나타낼 수 없어요. 예외는 `dfn = inf`이고 `dfd`만 작은 경우예요. 이때는 값이 있는 역감마의 극한 분포라서 메서드와 표본이 값을 내요.
- 자유도가 $[10^{-3}, 10^5]$ 밖이면 역함수는 구한 근을 다시 넣어 확인하고, 맞을 때만 값을 내요. 확률이 $2^{-1000}$보다 작은 깊은 꼬리의 역함수가 정해진 반복 안에 수렴하지 않을 때도 NaN이에요.
- `entropy()`는 자유도 하나라도 $10^{-2}$보다 작으면 NaN이에요. 그 아래에서는 공식의 큰 항들이 서로 지워지면서 자릿수가 남지 않아요.
- `logpdf`는 두 자유도가 모두 $10^{15}$를 넘고 계산 중간의 베타 인자가 float64 범위 아래로 내려가면 NaN이에요.

```python
>>> sd.stats.F(dfn=2.0 ** 102, dfd=2.0 ** 102).cdf(1.0)
nan
>>> sd.stats.F(dfn=1e-3, dfd=10.0).entropy()
nan
>>> sd.stats.F(dfn=2**-1022, dfd=5.0).cdf(1.0), sd.stats.F(dfn=2**-1022, dfd=5.0).sample(rng=sd.random.default_rng(0))
(nan, nan)
```

계산 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에서 설명해요.

## scipy를 아는 분께

- `scipy.stats.f`에 해당해요. 메서드 이름은 scipy의 새 분포 API를 따라요(`sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`).
- `loc`, `scale`이 없고, 자유도는 키워드(`dfn`, `dfd`)로만 받아요.
- 자유도 하나가 inf이면 극한 분포(χ²(dfn)/dfn이나 역감마)예요. scipy `f(3, inf).cdf(2.0)`과 `f(inf, 6).cdf(2.0)`은 NaN이에요.
- 모멘트의 특수값이 달라요.
  - $d_2 \le 2$의 `variance()`는 NaN이에요(scipy `f.var`는 inf).
  - $4 < d_2 \le 6$의 `skewness()`와 $4 < d_2 \le 8$의 `kurtosis()`는 inf예요(scipy `f.stats(..., moments='sk')`는 NaN).
- `kurtosis()`는 초과 첨도예요(scipy `f.stats(..., moments='k')`와 같아요).
- 꼬리에서 scipy가 inf나 `-inf`를 내는 곳에서 값을 내요. `F(dfn=3, dfd=7).iccdf(1e-30)`은 1.107e9이고 scipy `f.isf(1e-30, 3, 7)`은 inf예요.
- 자유도가 $10^{-2}$보다 작으면 `entropy()`가 NaN이에요. scipy는 값을 내요.
- 자유도가 $2^{-1021}$보다 작으면 표본도 NaN이에요. scipy의 `f.rvs(2**-1022, 5)`는 0.0, `f.rvs(5, 2**-1022)`는 inf예요.
- `sample`은 `rng`를 꼭 받아요. 값은 numpy·scipy와 달라요.
