---
kind: function
title: NoncentralT
names: [NoncentralT]
group: 비중심 분포
order: 2
signatures:
  - "sd.stats.NoncentralT(*, df, nc)"
summary: 비중심 t 분포예요. 참 평균이 가정한 값과 다를 때 t 통계량이 따르는 분포라서, t 검정의 검정력과 표본 크기를 계산할 때 써요. nc = 0이면 보통의 t 분포와 같아요.
params:
  - name: df
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 자유도. 0보다 큰 실수예요(정수가 아니어도 돼요). inf이면 극한 분포인 정규분포 Normal(mu=nc)예요. 0 이하이거나 NaN이면 그 원소의 모든 결과가 NaN이에요. 2⁻¹⁰²¹(약 4.5e-308)보다 작은 양수이면 StudentT처럼 밀도, 확률, 분위수, median, entropy, 표본이 NaN이에요.
  - name: nc
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 비중심 모수 δ. 유한한 실수면 음수도 돼요. 0이면 중심 t 분포예요. inf나 NaN이면 그 원소의 모든 결과가 NaN이에요.
returns:
  type: NoncentralT
  desc: 분포 객체. 지지집합은 실수 전체이고, pdf·cdf·icdf 같은 메서드와 mean·mode 같은 요약값, sample이 있어요. 매개변수 df, nc는 준 값 그대로인 읽기 전용 속성이에요.
raises:
  - type: TypeError
    desc: 매개변수를 위치 인자로 주었을 때, df나 nc를 빠뜨렸을 때, 매개변수가 실수나 sd.ndarray가 아닐 때(리스트, 문자열, 복소수 포함).
  - type: ValueError
    desc: 배열 매개변수끼리 브로드캐스트할 수 없을 때.
seeAlso: [student-t, normal, noncentral-f, noncentral-chi-squared, methods, sample]

t 검정은 표본 평균이 가정한 값에서 얼마나 떨어졌는지를 표준오차 단위로 재요. 그 비율이 t 통계량이에요. 가정이 맞으면(효과가 없으면) t 통계량은 0을 중심으로 좌우 대칭인 [t 분포](/api/stats/student-t/)를 따라요. 그런데 참 평균이 가정과 다르면 분포가 한쪽으로 밀려나고 모양도 비대칭이 돼요. 이 밀려난 분포가 **비중심 t 분포**이고, 밀려난 정도를 나타내는 숫자가 **비중심 모수** $\delta$, 코드에서는 `nc`예요.

```python
>>> import stardust as sd
>>> T = sd.stats.NoncentralT(df=10, nc=2)
>>> T

>>> T.cdf(1.0)

>>> T.ccdf(1.0)
0.8414849404622883
>>> T.pdf(2.0)
0.35564363036162994
>>> T.mean()
2.167444615878287
>>> T.median()
2.0536911511184894
```

자유도 10, $\delta = 2$인 분포에서 값이 1 이하일 확률은 약 16%예요. 평균은 $\delta$보다 조금 크고, 중앙값은 그 사이에 있어요. 오른쪽 꼬리가 더 길기 때문이에요.

## 어떤 분포인가요

$Z$가 표준정규 변수, $V$가 자유도 $\nu$인 카이제곱 변수이고 둘이 독립일 때

$$T = \frac{Z + \delta}{\sqrt{V/\nu}}$$

가 자유도 $\nu$, 비중심 모수 $\delta$인 비중심 t 분포를 따라요. 분자의 정규 변수가 0이 아니라 $\delta$를 중심으로 흩어진다는 것만 보통의 t와 달라요. 분모가 함께 흔들리기 때문에, 분포는 $\delta$만큼 그대로 옮겨지는 것이 아니라 $\delta$ 쪽으로 늘어진 비대칭 모양이 돼요.

이런 곳에 써요.

- t 검정의 검정력과 표본 크기: 한 표본 t 검정(대응 표본 포함)에서 참 평균이 가정과 표준편차의 $d$배만큼 다르면, 표본 $n$개의 t 통계량은 자유도 $n - 1$, $\delta = d\sqrt{n}$인 비중심 t를 따라요. 두 독립 표본(집단마다 $n$개)이면 자유도 $2n - 2$, $\delta = d\sqrt{n/2}$예요.
- 효과 크기의 신뢰구간: 관측한 t 값이 어떤 $\delta$의 분포에서 가운데 95% 안에 드는지를 거꾸로 찾아 효과 크기의 구간을 만들어요.
- 품질 관리: 공정 능력 지수와 허용 한계(tolerance limit) 계산에 나와요.

```python
>>> nc = sd.asarray([0.0, 2.0, 5.0])
>>> sd.stats.NoncentralT(df=10, nc=nc).cdf(2.0)
array([   0.9633059826146299,    0.4809731528179072, 0.0027821090637209483], dtype=float64)
```

## 만들기와 매개변수

매개변수는 둘이고 둘 다 꼭 키워드로 줘야 해요. 기본값은 없어요.

| 매개변수 | 뜻 | 정의역 |
|---|---|---|
| `df` | 자유도 $\nu$ | $0 < \nu \le \infty$ (정수가 아니어도 돼요) |
| `nc` | 비중심 모수 $\delta$ | 유한한 실수 (음수도 돼요) |

카이제곱이나 F와 달리 `nc`는 음수도 돼요. 참 평균이 가정보다 작은 쪽으로 다르면 $\delta$가 음수예요.

```python
>>> T.df, T.nc
(10, 2)
>>> sd.stats.NoncentralT(df=10, nc=sd.asarray([-2.0, 0.0, 2.0])).median()
array([-2.0536911511184894,                 0.0,  2.0536911511184894], dtype=float64)
```

위치 인자로 주거나 하나를 빠뜨리면 `TypeError`예요. 복소수와 리스트도 받지 않아요.

```python
>>> sd.stats.NoncentralT(10, 2)
Traceback (most recent call last):
    ...
TypeError: NoncentralT(): takes 0 positional arguments but 2 were given
>>> sd.stats.NoncentralT(df=10)
Traceback (most recent call last):
    ...
TypeError: NoncentralT(): missing 1 required keyword-only argument: 'nc'
>>> sd.stats.NoncentralT(df=10, nc=2j)
Traceback (most recent call last):
    ...
TypeError: NoncentralT(): 'nc' must be a real number or an sd.ndarray, not complex
```

배열 매개변수는 서로 [브로드캐스트](/api/array/broadcasting/)하고, 브로드캐스트할 수 없는 모양이면 만들 때 `ValueError`예요. 값이 정의역 밖이면 에러 대신 그 원소의 결과가 NaN이에요. 자유도 `inf`는 그 극한인 정규분포 `Normal(mu=nc)`예요([자유도가 크면 정규분포에 가까워요](#자유도가-크면-정규분포에-가까워요)). 아래에서 마지막 원소는 `Normal(mu=1.0).cdf(0.0)`과 같아요.

```python
>>> sd.stats.NoncentralT(df=sd.asarray([-1.0, 0.0, 10.0, sd.inf]), nc=1).cdf(0.0)
array([                nan,                 nan, 0.15865525393145707,
       0.15865525393145707], dtype=float64)
```

## 밀도와 누적분포

지지집합은 실수 전체예요. 누적분포는 $T \le t$일 확률이고, 분모의 카이제곱 변수에 대해 평균을 내면 이렇게 쓸 수 있어요.

$$F(t) = P(T \le t) = \int_0^\infty \Phi\!\left(t\sqrt{v/\nu} - \delta\right) f_{\chi^2_\nu}(v)\,dv$$

$\Phi$는 표준정규분포의 누적분포예요. 밀도도 같은 꼴의 적분이에요. 닫힌 꼴은 없고, 무한급수나 적분으로만 쓸 수 있어요. 두 가지 성질은 기억해 두면 좋아요.

- 0에서의 값: $t = 0$이면 분모와 상관없이 $P(T \le 0) = P(Z + \delta \le 0) = \Phi(-\delta)$예요.
- 부호 대칭: $\delta$의 부호를 바꾸면 분포가 좌우로 뒤집혀요. `NoncentralT(df, -δ)`의 `cdf(-t)`는 `NoncentralT(df, δ)`의 `ccdf(t)`와 같고, 밀도도 거울에 비친 모양이에요.

```python
>>> T.support()
(-inf, inf)
>>> T.cdf(0.0)
0.022750131948179212
>>> sd.stats.Normal().cdf(-2.0)
0.022750131948179212
>>> Tm = sd.stats.NoncentralT(df=10, nc=-2)
>>> Tm.cdf(-1.0) == T.ccdf(1.0)
True
>>> Tm.pdf(-1.5) == T.pdf(1.5)
True
```

`icdf`는 아래꼬리 확률을, `iccdf`는 위꼬리 확률을 거꾸로 풀어요.

```python
>>> T.icdf(0.95)
4.3574751786644
>>> T.cdf(T.icdf(0.95))
0.95
>>> T.iccdf(0.01)
5.759328322580839
```

### 꼬리 확률

$\delta > 0$이면 왼쪽 꼬리가 아주 빨리 작아져요. 이런 작은 확률도 앞자리가 맞게 나와요. 위꼬리 확률은 `1 - cdf`가 아니라 `ccdf`로 구하세요. 확률이 float64의 가장 작은 수보다 작아지는 곳에서는 `logcdf`, `logccdf`가 확률의 로그를 줘요. 역함수도 아주 작은 확률이나 그 로그에서 풀 수 있어요.

```python
>>> T.cdf(-50.0)
6.191035767334898e-17
>>> T.logcdf(-1e30)
-688.9658698065726
>>> T.ccdf(1e5)
3.2059574069370666e-44
>>> T.logccdf(1e300)
-6892.77475764727
>>> T.icdf(1e-100)
-11983742051.769508
>>> T.ilogcdf(-500.0)
-6.213217366897075e+21
```

메서드 하나하나의 공통 의미는 [분포의 메서드](/api/stats/methods/)에 있어요.

## 검정력 계산하기

한 표본 t 검정을 예로 들어요. 표본 20개로 "평균이 0이다"를 양측, 유의수준 5%로 검정해요. 효과가 없으면 t 통계량은 자유도 19인 t 분포를 따르므로, 위꼬리 2.5%의 경계가 기준값이에요. $|t|$가 이 값을 넘으면 "유의하다"고 판단해요.

```python
>>> n = 20
>>> c = sd.stats.StudentT(df=n - 1).iccdf(0.025)
>>> c
2.0930240544083096
```

이제 참 평균이 표준편차의 0.5배만큼 다르다고 해요(효과 크기 $d = 0.5$). 그러면 t 통계량은 $\delta = d\sqrt{n}$인 비중심 t를 따라요. 검정력은 이 분포가 양쪽 기준값 밖으로 나갈 확률이에요.

```python
>>> delta = 0.5 * n ** 0.5
>>> P = sd.stats.NoncentralT(df=n - 1, nc=delta)
>>> P.ccdf(c) + P.cdf(-c)
0.5645044184390203
```

효과가 있어도 20개로는 56% 확률로만 잡아내요. 두 꼬리 가운데 반대쪽은 아주 작지만, 효과가 작을수록 무시할 수 없으니 양측 검정이면 둘 다 더하세요.

```python
>>> P.ccdf(c)
0.5644828966786231
>>> P.cdf(-c)
2.1521760397301805e-05
```

표본 크기를 배열로 주면 자유도, 기준값, $\delta$가 모두 원소마다 달라져도 한꺼번에 계산돼요. 검정력 80%를 넘는 가장 작은 표본은 34개예요(33개는 0.795예요).

```python
>>> ns = sd.asarray([20.0, 30.0, 34.0, 40.0, 60.0])
>>> cs = sd.stats.StudentT(df=ns - 1).iccdf(0.025)
>>> Q = sd.stats.NoncentralT(df=ns - 1, nc=0.5 * sd.sqrt(ns))
>>> Q.ccdf(cs) + Q.cdf(-cs)
array([0.5645044184390203,   0.75396471574379,  0.807777501279274,
        0.869398135023859,   0.96778858730494], dtype=float64)
```

효과 크기에 따라 검정력이 어떻게 변하는지를 표본 크기별로 그리면 이래요. $d = 0$에서는 셋 다 유의수준 0.05예요.

## 요약값

$T$의 $k$차 모멘트는 분자와 분모가 독립이라 두 기댓값의 곱이에요. $\nu > k$일 때만 유한해요.

$$E[T^k] = \left(\frac{\nu}{2}\right)^{k/2} \frac{\Gamma\!\left(\frac{\nu-k}{2}\right)}{\Gamma\!\left(\frac{\nu}{2}\right)}\, E\!\left[(Z+\delta)^k\right]$$

$E[(Z+\delta)^k]$는 $k = 1, 2, 3, 4$에서 $\delta$, $1 + \delta^2$, $\delta^3 + 3\delta$, $\delta^4 + 6\delta^2 + 3$이에요. 평균과 분산은 이래요.

$$\text{mean} = \delta\sqrt{\frac{\nu}{2}}\,\frac{\Gamma\!\left(\frac{\nu-1}{2}\right)}{\Gamma\!\left(\frac{\nu}{2}\right)} \quad (\nu > 1), \qquad \text{variance} = \frac{\nu(1 + \delta^2)}{\nu - 2} - \text{mean}^2 \quad (\nu > 2)$$

왜도는 $\nu > 3$, 초과 첨도(`kurtosis()`)는 $\nu > 4$에서 유한하고, 같은 모멘트들로 계산해요. 중앙값은 닫힌 꼴이 없고 `icdf(0.5)`와 같아요.

```python
>>> T.mean(), T.variance()
(2.167444615878287, 1.5521838371002237)
>>> T.standard_deviation()
1.2458667011764235
>>> T.skewness()
0.7236332940828669
>>> T.kurtosis()
1.8273295684844697
```

### 자유도가 작아서 모멘트가 없을 때

자유도가 작으면 꼬리가 무거워서 모멘트가 발산해요. 결과는 이렇게 정해져 있어요.

| 자유도 | `mean` | `variance` | `skewness` | `kurtosis` |
|---|---|---|---|---|
| $\nu \le 1$ | NaN | NaN | NaN | NaN |
| $1 < \nu \le 2$ | 값 | inf | NaN | NaN |
| $2 < \nu \le 3$ | 값 | 값 | NaN | inf |
| $3 < \nu \le 4$ | 값 | 값 | 값 | inf |
| $\nu > 4$ | 값 | 값 | 값 | 값 |

양쪽 꼬리가 모두 무거워서, 홀수 제곱의 기댓값(평균, 왜도)은 발산할 때 $+\infty$와 $-\infty$가 맞서 값이 정해지지 않아요. 그래서 NaN이에요. 짝수 제곱의 기댓값(분산, 첨도)은 언제나 양수라서 발산하면 inf예요. 다만 평균이 정해지지 않으면 평균 둘레로 재는 분산도 NaN이고, 분산이 유한하지 않으면 분산으로 나누는 왜도와 첨도는 NaN이에요.

```python
>>> dfs = sd.asarray([1.0, 1.5, 2.5, 3.5, 4.5])
>>> D = sd.stats.NoncentralT(df=dfs, nc=1)
>>> D.mean()
array([               nan,  2.562287814762313, 1.5115332961011207,
       1.3046530959345874, 1.2167608321211125], dtype=float64)
>>> D.variance()
array([               nan,                inf, 7.7152670947776825,
       2.9645469659349626,  2.119493077415938], dtype=float64)
>>> D.skewness()
array([              nan,               nan,               nan,
       4.448489759269108,  1.64080276193223], dtype=float64)
>>> D.kurtosis()
array([               nan,                nan,                inf,
                      inf, 22.897688587538614], dtype=float64)
```

### mode

`mode()`는 밀도가 가장 큰 점이에요. 닫힌 꼴은 없고, 보장 영역에서 상대 1e-14로 맞아요. $\delta = 0$이면 0이에요. 그 밖에는 $\delta$와 같은 부호이고 크기는 $|\delta|$보다 작은데, 자유도가 클수록 $\delta$에 가까워져요.

$|\delta|$가 $128\sqrt{1 + \nu}$보다 크면 NaN이에요. 자유도 9라면 그 경계가 약 404.8이에요. 보장 영역($|\delta| \le 100$)보다 훨씬 바깥이에요.

```python
>>> T.mode()
1.870207848753702
>>> sd.stats.NoncentralT(df=9, nc=sd.asarray([0.0, 2.0, 100.0, 400.0, 410.0])).mode()
array([               0.0, 1.8577452755208426,  94.86359479575242,
       379.47213349762666,                nan], dtype=float64)
```

### entropy는 보장하지 않아요

`entropy()`는 미분 엔트로피(단위 nat)예요. 닫힌 꼴이 없어서 수치 적분으로 구하고, 다른 메서드와 달리 1e-14 정확도를 약속하지 않아요. 값은 대개 앞자리가 많이 맞지만 마지막 몇 자리는 믿지 마세요. 적분이 정해진 계산량 안에 끝나지 않으면 NaN이에요.

```python
>>> T.entropy()
1.6038742415428793
```

## 표본

`sample`은 이 분포를 따르는 난수를 뽑아요. `rng`에 [`sd.random.default_rng`](/api/random/default_rng/)로 만든 생성기를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(7)
>>> T.sample(rng=rng)
9.204740946924648
>>> T.sample((4,), rng=rng)
array([-0.02318602061287422,  0.46108057107745154,   3.5023654311537222,
         0.6367240790236629], dtype=float64)
>>> s = T.sample((100000,), rng=rng)
>>> sd.mean(s), sd.var(s)
(2.1645174420720457, 1.536733285815022)
```

표본의 평균과 분산이 위의 `mean()` 2.1674, `variance()` 1.5522에 가까워요. 자유도가 $2^{-1021}$(약 4.5e-308)보다 작으면 표본은 NaN이에요. 값 메서드와 같은 경계예요.

## 다른 분포와의 관계

### nc = 0이면 중심 t예요

$\delta = 0$이면 보통의 t 분포 [`StudentT(df=ν)`](/api/stats/student-t/)가 돼요. 밀도, 누적분포와 그 역함수, 모멘트, `median`, `mode`, `entropy`가 마지막 비트까지 같고, 같은 `rng` 상태에서 뽑은 표본도 같아요.

```python
>>> S = sd.stats.StudentT(df=10)
>>> T0 = sd.stats.NoncentralT(df=10, nc=0)
>>> T0.cdf(1.5) == S.cdf(1.5), T0.pdf(1.5) == S.pdf(1.5), T0.icdf(0.3) == S.icdf(0.3)
(True, True, True)
>>> T0.mean(), T0.variance(), T0.kurtosis()
(0.0, 1.25, 1.0)
>>> S.mean(), S.variance(), S.kurtosis()
(0.0, 1.25, 1.0)
>>> T0.sample((3,), rng=sd.random.default_rng(3))
array([-0.06594138934693201, -0.13948622290998608,  -0.4270087759050241], dtype=float64)
>>> S.sample((3,), rng=sd.random.default_rng(3))
array([-0.06594138934693201, -0.13948622290998608,  -0.4270087759050241], dtype=float64)
```

### 제곱하면 비중심 F예요

$T^2$은 분자 자유도 1, 분모 자유도 $\nu$, 비중심 모수 $\delta^2$인 [비중심 F](/api/stats/noncentral-f/)를 따라요. $|T| \le t$와 $T^2 \le t^2$이 같은 사건이라서, 양측 확률을 F 분포 하나로 구할 수 있어요. 두 값은 마지막 자리만 달라요.

```python
>>> F1 = sd.stats.NoncentralF(dfn=1, dfd=10, nc=4)
>>> F1.cdf(1.5 ** 2)
0.3043014940752828
>>> T.cdf(1.5) - T.cdf(-1.5)
0.30430149407528284
```

### 자유도가 크면 정규분포에 가까워요

$\nu$가 커지면 분모 $\sqrt{V/\nu}$가 1에 몰려서, $T$는 평균 $\delta$, 표준편차 1인 [정규분포](/api/stats/normal/)에 가까워져요. 그 극한인 `df = inf`는 `Normal(mu=δ)`와 마지막 비트까지 같아요.

```python
>>> big = sd.stats.NoncentralT(df=1e6, nc=2)
>>> big.cdf(2.5)
0.6914619661828862
>>> sd.stats.NoncentralT(df=sd.inf, nc=2).cdf(2.5)
0.6914624612740131
>>> sd.stats.Normal(mu=2.0).cdf(2.5)
0.6914624612740131
```

### special 함수

누적분포와 그 역함수는 특수함수 [`sd.special.nctdtr`, `nctdtrc`, `nctdtrit`](/api/special/nctdtr/)로도 구할 수 있어요. `cdf`, `ccdf`와 같은 값이에요(`df = inf`의 정규분포 극한도 같아요). 특수함수 쪽은 밀도와 요약값이 없어요.

```python
>>> sd.special.nctdtr(10, 2, 1.0) == T.cdf(1.0)
True
```

## 정확도와 범위

**보장 영역**은 $0.1 \le \nu \le 10^5$, $|\delta| \le 100$이고, 확률은 1e-300까지예요. 이 안에서 `pdf`, `cdf`, `ccdf`와 그 log, 역함수 넷, 모멘트, `median`, `mode`가 참값 대비 1e-14 안이에요. 꼬리 확률도 상대오차로 재므로 아주 작은 확률도 앞자리 14자리 정도가 맞아요. `logpdf`처럼 값이 0을 지날 수 있는 것은 $|\text{오차}| \le 10^{-14}\max(1, |\text{값}|)$이고, 역함수는 입력의 조건수만큼 느슨해요(자세한 기준은 [분포의 메서드](/api/stats/methods/)). 단 `entropy`는 보장하지 않아요.

작은 쪽 꼬리 확률이 1e-300보다 작아지는 $t$와, 1e-300보다 작은 확률을 주는 역함수는 보장 밖이에요. 값은 계산하지만 정확도를 약속하지는 않아요.

보장 영역 밖도 값을 계산해요. 다만 계산이 정해진 양 안에 끝나지 않는 곳에서는 NaN을 돌려줘요.

| 어디서 | NaN이 되는 것 |
|---|---|
| $\lvert\delta\rvert$가 약 3.83e4 초과 | `cdf` 계열, 역함수, `median` |
| $\lvert\delta\rvert$나 $\lvert t\rvert$가 약 1e15 초과 | `pdf`, `logpdf` |
| $\nu < 2^{-1021}$(약 4.5e-308) | `pdf`, `cdf` 계열, 역함수, `median`, `entropy`, 표본 |
| $\lvert\delta\rvert > 128\sqrt{1+\nu}$ | `mode` |
| `ilogcdf`, `ilogccdf`의 입력이 $-2^{62}$ 이하 | 결과 |

$\lvert\delta\rvert$가 클 때 NaN인 곳은 분포의 가운데만이 아니에요. `NoncentralT(df=10, nc=3.9e4)`의 `cdf`는 $t \lesssim 10^3$에서 0, $t \gtrsim 3 \times 10^{151}$에서 1이고, 그 사이는 값이 1로 반올림되는 위꼬리까지 모두 NaN이에요. `ccdf`는 $0 < t \lesssim 10^{91}$과 $t < -3 \times 10^3$도 NaN이에요. 평균과 분산은 이런 매개변수에서도 값이 나와요.

```python
>>> huge = sd.stats.NoncentralT(df=10, nc=4e4)
>>> huge.mean(), huge.cdf(4e4), huge.pdf(4e4)
(43348.89231756574, nan, 4.386684216779493e-05)
```

자유도의 경계는 [`StudentT`](/api/stats/student-t/)와 같아요. 자유도의 절반을 float64로 정확히 나타낼 수 없는 $\nu < 2^{-1021}$이 NaN이에요. 그보다 조금 큰 자유도는 값을 내고, 그때 `median`이 inf인 것은 맞는 값이에요. $T = (Z + \delta)/\sqrt{V/\nu}$에서 $\nu$가 0에 가까우면 $V/\nu$의 거의 모든 확률이 0 근처에 몰려서, $T$는 $Z + \delta$의 부호를 따라 $\pm\infty$로 가요. $\delta = 1$이면 $T$가 $+\infty$일 확률이 $P(Z > -1) \approx 0.84$라서, 가운데 지점도 $+\infty$예요.

```python
>>> sd.stats.NoncentralT(df=2**-1022, nc=1.0).median()
nan
>>> tiny = sd.stats.NoncentralT(df=1e-300, nc=1.0)
>>> tiny.median(), tiny.cdf(0.0)
(inf, 0.15865525393145707)
```

계산 방법은 [극값·수명·비중심 분포의 구현](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- scipy의 `scipy.stats.nct(df, nc)`에 해당해요. 매개변수 이름은 같지만 키워드로만 받아요. `loc`, `scale`은 없어요.
- 메서드 이름이 달라요. `sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`예요.
- `kurtosis()`는 초과 첨도예요(`nct.stats(moments='k')`와 같은 뜻).
- 발산하는 모멘트가 달라요. $1 < \nu \le 2$의 분산과 $2 < \nu \le 4$의 첨도를 stardust는 inf로 내고, scipy는 NaN을 내요.
- 깊은 꼬리에서 scipy가 NaN을 내는 곳에서도 값을 내요. 예를 들어 `NoncentralT(df=100, nc=20).cdf(-10.0)`은 8.3362e-149인데, `scipy.stats.nct.cdf(-10.0, 100, 20)`은 NaN이에요.
- `df = inf`는 scipy처럼 정규분포예요.
- `df`가 $2^{-1021}$보다 작으면 NaN이에요. scipy는 값을 내요(`nct.cdf(1, 2**-1022, 1)`은 0.1587, `nct.ppf(0.5, 2**-1022, 1)`은 9.49e7).
