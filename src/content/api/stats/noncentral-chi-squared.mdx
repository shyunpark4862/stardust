---
kind: function
title: NoncentralChiSquared
names: [NoncentralChiSquared]
group: 비중심 분포
order: 1
signatures:
  - "sd.stats.NoncentralChiSquared(*, df, nc)"
summary: 비중심 카이제곱 분포예요. 효과나 신호가 있을 때 카이제곱 통계량이 따르는 분포라서, 카이제곱 검정의 검정력과 표본 크기를 계산하거나 잡음 속 신호의 에너지를 모형화할 때 써요. nc = 0이면 보통의 카이제곱 분포와 같아요.
params:
  - name: df
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 자유도 k. 0보다 큰 유한한 실수예요(정수가 아니어도 돼요). 0 이하, inf, NaN이면 그 원소의 모든 결과가 NaN이에요. nc > 0이면 2⁻¹⁰²¹(약 4.5e-308)보다 작은 양수도 값을 내요. 그때는 자유도 0의 극한이라 0에 확률 e^(−nc/2)의 점질량이 있어요. nc = 0이면 ChiSquared처럼 밀도, 확률, 분위수, median, entropy, 표본이 NaN이에요.
  - name: nc
    type: Python 실수 또는 ndarray
    kind: keyword-only
    desc: 비중심 모수 λ. 0 이상인 유한한 실수예요. 0이면 중심 카이제곱 분포예요. 음수, inf, NaN이면 그 원소의 모든 결과가 NaN이에요.
returns:
  type: NoncentralChiSquared
  desc: 분포 객체. 지지집합은 [0, ∞)이고, pdf·cdf·icdf 같은 메서드와 mean·mode 같은 요약값, sample이 있어요. 매개변수 df, nc는 준 값 그대로인 읽기 전용 속성이에요.
raises:
  - type: TypeError
    desc: 매개변수를 위치 인자로 주었을 때, df나 nc를 빠뜨렸을 때, 매개변수가 실수나 sd.ndarray가 아닐 때(리스트, 문자열, 복소수 포함).
  - type: ValueError
    desc: 배열 매개변수끼리 브로드캐스트할 수 없을 때.
seeAlso: [chi-squared, noncentral-f, noncentral-t, poisson, normal, methods, sample]

## 어떤 분포인가요

통계 검정은 "효과가 없다"는 가정(귀무가설) 아래에서 검정통계량이 따르는 분포를 기준으로 삼아요. 카이제곱 검정이라면 그 기준이 **중심** 카이제곱 분포 [`ChiSquared`](/api/stats/chi-squared/)예요. 그런데 실제로 효과가 있으면 같은 통계량이 **비중심** 카이제곱 분포를 따라요. 효과가 클수록 $\lambda$가 커지고 분포가 오른쪽으로 밀려나요. 그래서 이 분포는 "신호가 있을 때 통계량이 어떻게 흩어지는가"를 알려 줘요.

이런 곳에 써요.

- 검정력과 표본 크기: 효과가 정말 있을 때 검정이 그것을 잡아낼 확률(검정력)은, 중심 분포로 정한 기준값을 비중심 분포가 넘을 확률이에요. $\lambda$가 표본 크기에 비례하므로, 검정력이 원하는 값이 되는 표본 크기도 찾을 수 있어요. 적합도 검정, 독립성 검정, 표본이 클 때의 우도비 검정에 나와요.
- 신호 검출: 잡음만 있을 때 받은 신호의 에너지는 중심 카이제곱, 신호가 섞여 있으면 비중심 카이제곱을 따라요. $\lambda$는 신호의 세기예요.
- 무선 통신: 직접 오는 전파와 흩어진 전파가 섞인 수신 세기(라이스 페이딩)의 제곱은 자유도 2인 비중심 카이제곱 분포를 상수배한 것이에요.
- 금융: 금리 모형 가운데 하나(CIR 모형)에서 미래 금리의 분포가 비중심 카이제곱 분포를 상수배한 것이에요.

## 만들기와 매개변수

매개변수는 둘이고 둘 다 꼭 키워드로 줘야 해요. 기본값은 없어요.

| 매개변수 | 뜻 | 정의역 |
|---|---|---|
| `df` | 자유도 $k$ | $0 < k < \infty$ (정수가 아니어도 돼요) |

매개변수는 읽기 전용 속성으로 남고, 준 값이 그대로 보여요.

```python
>>> X.df, X.nc
(3, 2)
```

위치 인자로 주거나 하나를 빠뜨리면 `TypeError`예요. 리스트도 받지 않아요. 배열은 `sd.asarray`로 만드세요.

## 밀도와 누적분포

$Z_1, \dots, Z_k$가 서로 독립인 표준정규 변수일 때, 각각에 상수 $\mu_i$를 더해 제곱한 합

$$X = \sum_{i=1}^{k} (Z_i + \mu_i)^2, \qquad \lambda = \sum_{i=1}^{k} \mu_i^2$$

이 자유도 $k$, 비중심 모수 $\lambda$인 비중심 카이제곱 분포를 따라요. 분포는 $\mu_i$ 하나하나가 아니라 제곱합 $\lambda$에만 달려 있어요.

이 분포는 자유도가 $2j$씩 늘어난 중심 카이제곱 분포를 포아송 확률 $e^{-\lambda/2}(\lambda/2)^j/j!$로 섞은 것이에요. 밀도와 누적분포가 모두 이 혼합으로 쓰여요.

$$f(x) = \sum_{j=0}^{\infty} e^{-\lambda/2}\frac{(\lambda/2)^j}{j!}\, f_{\chi^2_{k+2j}}(x), \qquad F(x) = \sum_{j=0}^{\infty} e^{-\lambda/2}\frac{(\lambda/2)^j}{j!}\, P\!\left(\chi^2_{k+2j} \le x\right)$$

밀도는 변형 Bessel 함수 [$I_\nu$](/api/special/bessel-ik/)로 닫힌 꼴로도 쓸 수 있어요.

$$f(x) = \frac{1}{2}\, e^{-(x+\lambda)/2} \left(\frac{x}{\lambda}\right)^{k/4 - 1/2} I_{k/2-1}\!\left(\sqrt{\lambda x}\right), \qquad x > 0$$

지지집합은 $[0, \infty)$예요. 0에서의 밀도는 자유도에 따라 달라요. $k < 2$면 발산하고(inf), $k = 2$면 $e^{-\lambda/2}/2$, $k > 2$면 0이에요. 지지집합 밖(음수)에서 `pdf`는 0, `logpdf`는 −inf, `cdf`는 0이에요.

```python
>>> sd.stats.NoncentralChiSquared(df=sd.asarray([1.0, 2.0, 3.0]), nc=2).pdf(0.0)
array([                inf, 0.18393972058572117,                 0.0], dtype=float64)
>>> X.support()
(0.0, inf)
>>> X.pdf(-1.0), X.cdf(-1.0), X.logpdf(-1.0)
(0.0, 0.0, -inf)
```

`icdf`는 아래꼬리 확률을, `iccdf`는 위꼬리 확률을 거꾸로 풀어요. 아래는 "값의 90%가 그 아래에 있는 경계"와 "위로 5%만 남기는 경계"예요. 다시 `cdf`나 `ccdf`에 넣으면 마지막 자리 반올림 안에서 처음 확률로 돌아와요.

```python
>>> X.icdf(0.9)
10.047198516640966
>>> X.cdf(X.icdf(0.9))
0.9000000000000001
>>> X.iccdf(0.05)
12.283753723128017
>>> X.ccdf(X.iccdf(0.05))
0.04999999999999999
```

### 작은 꼬리 확률은 ccdf와 log 메서드로

위꼬리 확률은 `1 - cdf(x)`가 아니라 `ccdf(x)`로 구하세요. `cdf`가 1에 아주 가까우면 1에서 빼는 순간 자릿수가 모두 사라지지만, `ccdf`는 작은 꼬리를 직접 계산해서 앞자리가 그대로 맞아요.

```python
>>> X.ccdf(1000.0)
2.0461997569577234e-199
>>> 1 - X.cdf(1000.0)
0.0
```

확률이 float64로 나타낼 수 있는 가장 작은 수보다도 작아지면 `ccdf`도 0이 돼요. 그때는 확률의 로그를 주는 `logccdf`, `logcdf`를 쓰세요. 거꾸로 확률의 로그에서 경계를 구하는 `ilogccdf`, `ilogcdf`도 있어요.

```python
>>> X.ccdf(3000.0)
0.0
>>> X.logccdf(3000.0)
-1424.77969518522
>>> X.cdf(1e-100)
9.784177544915993e-152
>>> X.logcdf(1e-300)
-1038.4876954886333
>>> X.ilogccdf(-1000.0)
2125.9442626514415
```

메서드 하나하나의 공통 의미는 [분포의 메서드](/api/stats/methods/)에 있어요. 입력이 모두 Python 숫자면 결과는 Python `float`이고, 입력을 받는 메서드는 `out=`도 받아요.

## 검정력 계산하기

카이제곱 적합도 검정으로 예를 들어 볼게요. 범주가 4개인 자료가 "네 범주가 똑같이 25%"라는 가정에 맞는지 유의수준 5%로 검정해요. 자유도는 범주 수 − 1 = 3이에요.

먼저 효과가 없을 때의 분포(중심 카이제곱)에서 위꼬리 5%의 경계, 곧 기준값을 구해요. 통계량이 이 값을 넘으면 "유의하다"고 판단해요. 효과가 없으면 비중심 모수가 0이라서, 기준값을 넘을 확률은 정확히 유의수준 5%예요.

```python
>>> crit = sd.stats.ChiSquared(df=3).iccdf(0.05)
>>> crit
7.81472790325118
>>> sd.stats.NoncentralChiSquared(df=3, nc=0).ccdf(crit)
0.05
```

이제 효과가 있을 때를 생각해요. 실제 비율이 가정과 어긋난 정도를 효과 크기 $w$로 나타내면, 표본이 $n$개일 때 비중심 모수는 $\lambda = n w^2$이에요. $w = 0.3$, $n = 100$이면 $\lambda = 9$이고, 검정력은 비중심 분포가 기준값을 넘을 확률이에요.

```python
>>> sd.stats.NoncentralChiSquared(df=3, nc=100 * 0.3**2).ccdf(crit)
0.7112535997950423
```

효과가 있어도 표본 100개로는 71% 확률로만 잡아내요. 표본 크기를 여러 개 놓고 한꺼번에 계산하면, 검정력이 80%를 넘는 표본 크기를 고를 수 있어요.

```python
>>> n = sd.asarray([50.0, 100.0, 150.0, 200.0])
>>> sd.stats.NoncentralChiSquared(df=3, nc=n * 0.3**2).ccdf(crit)
array([0.39993749102344833,  0.7112535997950423,   0.884032726811765,
        0.9590732637512993], dtype=float64)
```

<Callout type="warn" title="비중심 모수는 효과 크기가 아니에요">

`nc`에는 효과 크기 $w$가 아니라 표본 크기를 곱한 $\lambda = n w^2$을 넣어야 해요. $w = 0.3$을 그대로 넣으면 표본이 몇 개든 검정력이 아주 낮게 나와요. 검정 방법마다 $\lambda$를 만드는 식이 다르니 그 검정의 식을 확인하세요.

</Callout>

## 요약값

| 요약값 | 식 |
|---|---|
| `mean()` | $k + \lambda$ |
| `variance()` | $2(k + 2\lambda)$ |
| `skewness()` | $\dfrac{2^{3/2}(k + 3\lambda)}{(k + 2\lambda)^{3/2}}$ |
| `kurtosis()` (초과 첨도) | $\dfrac{12(k + 4\lambda)}{(k + 2\lambda)^2}$ |
| `median()` | 닫힌 꼴이 없어요. `icdf(0.5)`와 같아요 |
| `mode()` | 밀도가 가장 큰 점. 아래 설명 |
| `entropy()` | $-\int f \log f\,dx$ (nat). 닫힌 꼴이 없어요 |

모든 모멘트가 유한해서 발산하는 경우는 없어요. `kurtosis()`는 정규분포가 0이 되는 초과 첨도예요.

```python
>>> X.mean(), X.variance()
(5.0, 14.0)
>>> X.standard_deviation()
3.7416573867739413
>>> X.skewness()
1.3744863869781825
>>> X.kurtosis()
2.693877551020408
>>> X.median()
4.137515123399117
```

### mode

`mode()`는 밀도가 가장 큰 점이고, 보장 영역에서 상대 1e-14로 맞아요. 닫힌 꼴은 없지만 성질은 이래요.

- $k < 2$면 0에서 밀도가 발산하므로 최빈값은 0이에요.
- $k = 2$면 $\lambda \le 2$일 때 0이고, 그보다 크면 양수예요.
- $k > 2$면 언제나 양수이고, $\lambda$가 크면 대략 $k + \lambda - 3$이에요. $\lambda = 0$이면 중심 카이제곱의 최빈값 $k - 2$예요.

```python
>>> X.mode()
2.132810814151749
>>> sd.stats.NoncentralChiSquared(df=2, nc=sd.asarray([1.0, 2.0, 4.0])).mode()
array([               0.0,                0.0, 2.7653163944337944], dtype=float64)
>>> sd.stats.NoncentralChiSquared(df=1, nc=10).mode()
0.0
>>> sd.stats.NoncentralChiSquared(df=3, nc=sd.asarray([0.0, 2.0, 8.0, 50.0])).mode()
array([              1.0, 2.132810814151749, 8.000003601113432,
                    50.0], dtype=float64)
```

### entropy는 보장하지 않아요

`entropy()`는 미분 엔트로피(단위 nat)예요. 닫힌 꼴이 없어서 수치 적분으로 구해요. 다른 메서드와 달리 1e-14 정확도를 약속하지 않아요. 값은 대개 앞자리가 많이 맞지만, 마지막 몇 자리는 믿지 마세요.

보장 영역 안에서도 NaN일 수 있어요. 자유도가 아주 작아서 확률질량의 일부가 float64로 나타낼 수 있는 가장 작은 수보다 0에 더 가까이 몰려 있을 때(예: `df = 0.01`이고 `nc`가 30 이하), 그리고 $\lambda$가 아주 커서 적분이 정해진 횟수 안에 수렴하지 않을 때(`df = 3.5`에서 `nc`가 약 7e7부터)예요. 이런 매개변수에서도 다른 메서드는 값을 내요.

```python
>>> X.entropy()
2.5375984422968276
>>> W = sd.stats.NoncentralChiSquared(df=0.01, nc=10)
>>> W.entropy()
nan
>>> W.mean()
10.01
```

## 표본

`sample`은 이 분포를 따르는 난수를 뽑아요. `rng`에 [`sd.random.default_rng`](/api/random/default_rng/)로 만든 생성기를 꼭 줘야 해요. 모양을 주지 않으면 Python `float` 하나, 주면 그 모양의 배열이에요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> X.sample(rng=rng)
5.213934059982348
>>> X.sample((4,), rng=rng)
array([ 3.355506339075342, 0.7725252822005075, 1.9769708832492823,
       4.1164301130025835], dtype=float64)
```

표본을 많이 뽑으면 평균과 분산이 $k + \lambda = 5$, $2(k + 2\lambda) = 14$에 가까워져요.

```python
>>> s = X.sample((100000,), rng=rng)
>>> sd.mean(s), sd.var(s)
(4.971803185458459, 13.80469243489249)
```

## 다른 분포와의 관계

### nc = 0이면 중심 카이제곱이에요

$\lambda = 0$이면 모든 $\mu_i$가 0이라서 보통의 카이제곱 분포 [`ChiSquared(df=k)`](/api/stats/chi-squared/)가 돼요. 밀도, 누적분포와 그 역함수, 모멘트, `median`, `mode`, `entropy`가 마지막 비트까지 같고, 같은 `rng` 상태에서 뽑은 표본도 같아요.

```python
>>> C = sd.stats.ChiSquared(df=3)
>>> X0 = sd.stats.NoncentralChiSquared(df=3, nc=0)
>>> X0.cdf(4.0) == C.cdf(4.0), X0.pdf(4.0) == C.pdf(4.0), X0.icdf(0.3) == C.icdf(0.3)
(True, True, True)
>>> X0.mean(), X0.variance(), X0.skewness(), X0.mode()
(3.0, 6.0, 1.632993161855452, 1.0)
>>> C.mean(), C.variance(), C.skewness(), C.mode()
(3.0, 6.0, 1.632993161855452, 1.0)
>>> X0.sample((3,), rng=sd.random.default_rng(3))
array([ 2.214623585265634,  2.061475382487205, 1.4602053032285602], dtype=float64)
>>> C.sample((3,), rng=sd.random.default_rng(3))
array([ 2.214623585265634,  2.061475382487205, 1.4602053032285602], dtype=float64)
```

### 포아송 혼합

위의 혼합 식을 직접 계산해도 마지막 자리의 반올림 말고는 같은 값이 나와요. 무게는 평균 $\lambda/2 = 1$인 [포아송 분포](/api/stats/poisson/)의 확률이고, 각 항은 자유도 $3 + 2j$인 카이제곱의 누적분포예요. 항 80개면 나머지는 무시할 만큼 작아요.

```python
>>> j = sd.arange(80)
>>> w = sd.stats.Poisson(mu=1.0).pmf(j)
>>> sd.sum(w * sd.stats.ChiSquared(df=3 + 2 * j).cdf(4.0))
0.4838813583880744
>>> X.cdf(4.0)
0.48388135838807445
```

### 자유도 1이면 옮긴 정규분포의 제곱이에요

$k = 1$이면 $X = (Z + \sqrt{\lambda})^2$이라서 $P(X \le x) = \Phi(\sqrt{x} - \sqrt{\lambda}) - \Phi(-\sqrt{x} - \sqrt{\lambda})$예요. $\Phi$는 표준정규분포 [`Normal`](/api/stats/normal/)의 누적분포예요. 두 값은 마지막 자리만 달라요. 빼는 계산에서 생기는 반올림 차이예요.

```python
>>> Z = sd.stats.Normal()
>>> x, mu = 4.0, 2.0 ** 0.5
>>> Z.cdf(x ** 0.5 - mu) - Z.cdf(-x ** 0.5 - mu)
0.720670648515344
>>> sd.stats.NoncentralChiSquared(df=1, nc=2).cdf(4.0)
0.7206706485153443
```

### 다른 비중심 분포와 special 함수

- 비중심 카이제곱 변수를 자유도로 나누고, 독립인 중심 카이제곱 변수를 자유도로 나눈 것으로 다시 나누면 [비중심 F](/api/stats/noncentral-f/)예요.
- 누적분포와 그 역함수는 특수함수 [`sd.special.chndtr`, `chndtrc`, `chndtrix`](/api/special/chndtr/)로도 구할 수 있어요. 분포 객체의 `cdf`, `ccdf`와 같은 값이에요. 특수함수 쪽은 인자 순서가 `(df, nc, x)`이고 밀도와 요약값은 없어요.

```python
>>> sd.special.chndtr(3, 2, 4.0) == X.cdf(4.0)
True
```

## 정확도와 범위

**보장 영역**은 $0.01 \le k \le 10^4$, $\lambda \le 10^4$이고, 확률은 1e-300까지예요. 이 안에서 `pdf`, `cdf`, `ccdf`와 그 log, 역함수 넷, 모멘트, `median`, `mode`가 참값 대비 1e-14 안이에요. 꼬리 확률도 상대오차로 재므로 아주 작은 확률도 앞자리 14자리 정도가 맞아요. `logpdf`처럼 값이 0을 지날 수 있는 것은 $|\text{오차}| \le 10^{-14}\max(1, |\text{값}|)$이고, 역함수는 입력의 조건수만큼 느슨해요(자세한 기준은 [분포의 메서드](/api/stats/methods/)). 단 `entropy`는 보장하지 않아요.

"확률 1e-300까지"는 이런 뜻이에요. 작은 쪽 꼬리 확률이 1e-300보다 작아지는 $x$(예: 위의 `X.logccdf(3000.0)`)와, 1e-300보다 작은 확률을 주는 역함수는 보장 밖이에요. 값은 계산하지만 정확도를 약속하지는 않아요.

보장 영역 밖도 값을 계산해요. 다만 $\lambda$나 자유도가 아주 크면 정해진 계산량 안에 끝나지 않는 곳이 있고, 그때는 오래 붙잡고 있지 않고 NaN을 돌려줘요.

| 어디서 | NaN이 되는 것 |
|---|---|
| `nc`가 약 2.33e9 초과 | 평균 근처부터 `cdf` 계열, 역함수, `median`(자유도 1부터 1e4까지 같은 경계예요) |
| `df`가 1.1e24 초과 | 평균 근처의 `cdf` 계열 |
| `df`와 `nc`가 함께 아주 클 때 | `pdf`, `logpdf` (`df`가 작으면 `nc = 1e300`에서도 값이 나와요) |
| `ilogcdf`, `ilogccdf`의 입력이 $-2^{62}$ 이하 | 결과 |
| 위 절의 경우 | `entropy` |

`nc`가 클 때 NaN인 곳은 평균을 둘러싼 띠이고, 띠는 `nc`와 함께 넓어져요. `nc = 2.4e9`이면 평균 $\pm 0.5\sqrt{nc}$는 NaN이고 $\pm\sqrt{nc}$는 값이 나오지만, `nc = 4e9`이면 평균 $\pm 120\sqrt{nc}$도 NaN이에요. 띠 밖의 먼 꼬리는 0이나 1이에요.

평균, 분산 같은 닫힌 꼴의 요약값은 이런 매개변수에서도 값이 나와요.

```python
>>> big = sd.stats.NoncentralChiSquared(df=3, nc=3e9)
>>> big.mean(), big.cdf(3e9), big.pdf(3e9)
(3000000003.0, nan, 3.641828101973597e-06)
>>> X.ilogccdf(-2.0 ** 62)
nan
```

### 아주 작은 자유도

[`ChiSquared`](/api/stats/chi-squared/)는 자유도가 $2^{-1021}$(약 4.5e-308)보다 작으면 자유도의 절반을 float64로 정확히 나타낼 수 없어서 `pdf`, `cdf` 계열, 역함수, `median`, `entropy`가 NaN이에요. `nc = 0`인 비중심 카이제곱도 같아요.

`nc > 0`이면 그런 자유도에서도 값을 내요. 이때의 분포는 자유도 $k \to 0$의 극한이에요. 위의 포아송 혼합에서 $j = 0$인 항(무게 $e^{-\lambda/2}$)은 자유도가 0으로 가는 카이제곱이라 질량이 모두 0으로 모이고, $j \ge 1$인 항은 자유도 $2j$인 보통의 카이제곱이에요. 그래서 0에 확률 $e^{-\lambda/2}$가 놓인 점질량과 $\chi^2_{2j}$($j \ge 1$)의 혼합이 돼요.

$$P(X = 0) = e^{-\lambda/2}, \qquad F(x) = e^{-\lambda/2} + \sum_{j=1}^{\infty} e^{-\lambda/2}\frac{(\lambda/2)^j}{j!}\, P\!\left(\chi^2_{2j} \le x\right), \quad x \ge 0$$

`cdf(0)`부터 점질량을 담아서 $e^{-\lambda/2}$이고, `ccdf(0)`은 그 나머지 $1 - e^{-\lambda/2}$, `logcdf(0)`은 $-\lambda/2$예요.

```python
>>> tiny = sd.stats.NoncentralChiSquared(df=2**-1022, nc=1.0)
>>> tiny.cdf(0.0), tiny.ccdf(0.0), tiny.logcdf(0.0)
(0.6065306597126334, 0.3934693402873666, -0.5)
>>> tiny.cdf(1.0)
0.7328798037968203
>>> sd.stats.NoncentralChiSquared(df=2**-1022, nc=0.0).cdf(1.0)
nan
```

나머지 메서드도 이 극한 분포의 값이에요.

- `pdf(0)`은 inf예요(점질량). $x > 0$의 밀도는 $j \ge 1$ 항의 합이고, `mode()`는 0이에요.
- 역함수는 목표 확률이 점질량 안에 들면 0이에요. `icdf(p)`는 $p \le e^{-\lambda/2}$, `iccdf(q)`는 $q \ge 1 - e^{-\lambda/2}$, `ilogcdf(t)`는 $t \le -\lambda/2$에서 0이에요. `median()`은 $e^{-\lambda/2} \ge 1/2$, 곧 $\lambda \le 2\log 2$이면 0이에요.
- `entropy()`는 −inf예요. 점질량이 있으면 유한한 미분 엔트로피가 없어요.
- 모멘트는 위의 표 그대로예요(평균 $k + \lambda$ 등).

```python
>>> tiny.pdf(0.0), tiny.pdf(1.0), tiny.mode()
(inf, 0.10395520767485422, 0.0)
>>> tiny.icdf(0.5), tiny.icdf(0.7)
(0.0, 0.7012971030005737)
>>> sd.stats.NoncentralChiSquared(df=2**-1022, nc=sd.asarray([1.0, 2.0])).median()
array([              0.0, 0.793445132040237], dtype=float64)
>>> tiny.entropy(), tiny.mean(), tiny.variance()
(-inf, 1.0, 4.0)
```

표본도 이 분포를 따라요. 점질량의 비율만큼(여기서는 약 60.65%) 정확히 0이 나와요. `nc = 0`이면 값 메서드처럼 표본도 NaN이에요.

```python
>>> rng = sd.random.default_rng(1)
>>> x = tiny.sample(100000, rng=rng)
>>> float(sd.mean(x == 0.0))
0.60826
>>> sd.stats.NoncentralChiSquared(df=2**-1022, nc=0.0).sample(rng=rng)
nan
```

`df = 0` 자체는 정의역 밖이라 NaN이에요(`ChiSquared`와 같아요).

계산 방법은 [극값·수명·비중심 분포의 구현](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- scipy의 `scipy.stats.ncx2(df, nc)`에 해당해요. 매개변수 이름은 같지만 키워드로만 받아요. `loc`, `scale`은 없어요.
- 메서드 이름이 달라요. `sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`예요. log 확률을 받는 역함수 `ilogcdf`, `ilogccdf`도 있어요.
- `kurtosis()`는 초과 첨도예요(`ncx2.stats(moments='k')`와 같은 값).
- 깊은 꼬리에서 scipy가 0을 내는 곳에서도 값을 내요. 예를 들어 `NoncentralChiSquared(df=1, nc=500).cdf(1e-50)`은 2.1297e-134인데, `scipy.stats.ncx2.cdf(1e-50, 1, 500)`은 0.0이고 `logcdf`는 −inf예요.
- `df`가 $2^{-1021}$보다 작고 `nc = 0`이면 NaN이에요. scipy는 값을 내요(`ncx2.cdf(1, 2**-1022, 0)`은 0.99999999999997). `nc > 0`이면 둘 다 값을 내요(`ncx2.cdf(1, 2**-1022, 1)`은 0.73287980379682). 다만 0에서는 달라요. stardust는 0의 점질량을 담아 `cdf(0)`이 $e^{-1/2} = 0.60653$, `pdf(0)`이 inf, `entropy()`가 −inf인데, scipy는 `ncx2.cdf(0, 2**-1022, 1)`이 0, `pdf`가 0, `entropy`가 1.1274이고 `ppf(0.5, 2**-1022, 1)`도 0이 아닌 5.5e-316이에요.
- `df = 0`은 NaN이에요. scipy도 `ncx2`에서 `df = 0`을 받지 않아요. 특수함수 [`sd.special.chndtr`](/api/special/chndtr/)는 `df = 0`(0에 몰린 분포)을 받아요.
- 엔트로피는 scipy와 마지막 몇 자리가 다를 수 있어요. `NoncentralChiSquared(df=3, nc=2).entropy()`는 2.5375984422968276이고 `scipy.stats.ncx2.entropy(3, 2)`는 2.5375984422967317이에요. 어느 쪽도 1e-14를 약속하는 값이 아니에요.
