## 한눈에 보기

분포의 **표본**은 그 분포를 따르는 무작위 값이에요. 정규분포의 표본이라면 평균 근처의 값이 자주 나오고 먼 값은 드물게 나와요. 표본은 이럴 때 써요.

- **시뮬레이션**: "하루 방문자 수가 포아송분포를 따른다면, 한 달 동안 서버가 넘칠 날이 며칠일까?"처럼 식으로 풀기 어려운 질문을 많이 뽑아 보고 세어서 답해요.
- **가짜 데이터**: 분석 방법을 시험해 볼 때, 정답을 알고 있는 데이터를 만들어요.
- **어림 계산**: 기댓값이나 확률을 표본의 평균으로 어림해요(몬테카를로 방법).

모든 분포는 같은 메서드로 표본을 뽑아요.

```python
X.sample(shape=None, /, *, rng)
```

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(42)
>>> X = sd.stats.Normal(mu=170.0, sigma=6.0)
>>> X.sample(rng=rng)
164.10086808542556
>>> X.sample(4, rng=rng)
array([172.05687312731786, 164.84520119173104, 168.77840817008175,
        163.3736028626577], dtype=float64)
```

`rng`에는 [`sd.random.default_rng`](/api/random/default_rng/)로 만든 **생성기**를 넘겨요. 첫 번째 인자는 결과의 모양이에요. 생략하면 Python `float` 하나, 정수 `4`면 원소 넷인 배열이에요.

표본을 많이 뽑아 히스토그램을 그리면 분포의 밀도 모양이 드러나요.

```python
>>> Z = sd.stats.Normal()
>>> x = Z.sample(100_000, rng=sd.random.default_rng(0))
>>> counts, edges = sd.histogram(x, bins=40, range=(-4.0, 4.0), density=True)
>>> float(sd.mean(x <= 1.0)), Z.cdf(1.0)
(0.84319, 0.8413447460685429)
```

표본 가운데 1 이하인 것의 비율(84.3%)이 `cdf(1.0)`(84.1%)과 거의 같아요. 표본이 많을수록 더 가까워져요.

## 생성기 `rng`는 꼭 넘겨요

`sample`은 난수를 직접 만들지 않고, 넘겨받은 생성기의 수열에서 꺼내 써요. `sd.random`에는 프로그램 전체가 함께 쓰는 숨은 생성기가 없어서, 생성기를 넘기지 않으면 `TypeError`예요. 이렇게 하면 코드만 보고도 난수가 어디서 오는지, 어떤 시드인지 알 수 있어요. 자세한 이유는 [난수의 기본](/api/random/basics/)에 있어요.

```python
>>> X.sample(3)
Traceback (most recent call last):
    ...
TypeError: sample() missing 1 required keyword-only argument: 'rng'
>>> X.sample(3, rng=42)
Traceback (most recent call last):
    ...
TypeError: sample(): 'rng' must be an sd.random.Generator (sd.random.default_rng(seed)), not int
```

`rng=`은 이름을 붙여서 넘겨요. 시드(정수)를 바로 넣을 수는 없고, numpy의 생성기도 받지 않아요. 언제나 `sd.random.default_rng(시드)`로 만든 생성기를 넘기세요.

## 결과의 모양

### `shape`: 숫자 하나 또는 배열

`shape`은 정수나 정수의 튜플이에요. 자리로만 넘겨요(`sample(3, rng=rng)`).

| `shape` | 매개변수가 모두 숫자일 때의 결과 |
|:---:|---|
| `None`(생략) | Python `float` 하나 |
| 정수 `n` | 길이 `n`인 1차원 배열 |
| 튜플 `(2, 3)` | 그 모양의 배열 |

```python
>>> rng = sd.random.default_rng(42)
>>> type(Z.sample(rng=rng))
<class 'float'>
>>> Z.sample((2, 3), rng=rng).shape
(2, 3)
>>> Z.sample(1, rng=rng)
array([-2.1076745327459503], dtype=float64)
>>> Z.sample(0, rng=rng)
array([], dtype=float64)
```

모양을 잘못 주면 에러예요.

```python
>>> Z.sample([2, 3], rng=rng)
Traceback (most recent call last):
    ...
TypeError: sample(): 'shape' must be an int or a tuple of ints, not list
>>> Z.sample(-1, rng=rng)
Traceback (most recent call last):
    ...
ValueError: sample(): 'shape' must be non-negative
```

빈 튜플 `()`도 `ValueError`예요. stardust에는 0차원 배열이 없어서, `()` 모양의 결과를 만들 수 없기 때문이에요. 표본 하나가 필요하면 `shape`을 생략하거나 `None`을 넣으세요. 생성기의 메서드 [`rng.random(shape)`](/api/random/random/)과 같은 규칙이에요.

```python
>>> Z.sample((), rng=rng)
Traceback (most recent call last):
    ...
ValueError: sample(): 'shape' must not be () (stardust has no 0-d arrays; None gives one sample)
>>> type(Z.sample(None, rng=rng))
<class 'float'>
```

### 매개변수가 배열이면: `shape` + 매개변수의 모양

매개변수가 배열이면 객체 하나가 분포 여러 개예요([통계의 기본](/api/stats/basics/)). 그때 결과의 모양은 **`shape` 뒤에 매개변수의 브로드캐스트 모양을 붙인 것**이에요. 아래는 평균이 0, 10, 20인 정규분포 셋에서 4개씩 뽑은 것이에요. 결과는 (4, 3)이고, 열 하나가 분포 하나예요.

```python
>>> Y = sd.stats.Normal(mu=sd.asarray([0.0, 10.0, 20.0]))
>>> s = Y.sample(4, rng=sd.random.default_rng(1))
>>> s.shape
(4, 3)
>>> s
array([[  1.1939197603947032,   10.457053022651998,    20.00169596221037],
       [ -0.4567981271486759,   10.561455211183123,   19.038062438185495],
       [0.025380113608530354,     9.50744485930661,   21.210202290099378],
       [ -0.2224503255015328,    10.60280479408333,    18.74458193771095]], dtype=float64)
```

`shape`을 생략하면 분포마다 하나씩, 매개변수와 같은 모양이 나와요. 매개변수가 모두 숫자이고 `shape`을 생략했을 때만 Python `float`예요.

```python
>>> Y.sample(rng=sd.random.default_rng(1))
array([1.1939197603947032, 10.457053022651998,  20.00169596221037], dtype=float64)
```

`shape`이 앞에 오니까, 첫 축을 따라 평균을 내면 분포별 평균이 나와요.

```python
>>> m = sd.mean(Y.sample(100_000, rng=sd.random.default_rng(2)), axis=0)
>>> [round(float(v), 1) for v in m]
[0.0, 10.0, 20.0]
```

숫자 매개변수와 배열 매개변수를 섞어도 돼요. 숫자는 브로드캐스트되어 모든 분포에 같이 쓰여요. 아래는 모양이 2로 같고 척도가 1과 100인 감마분포 둘이에요.

```python
>>> G = sd.stats.Gamma(a=2.0, scale=sd.asarray([1.0, 100.0]))
>>> G.sample(3, rng=sd.random.default_rng(3))
array([[ 1.595522740492922, 150.31100786381722],
       [ 1.131842495855226, 112.79416242749325],
       [2.8435560468607064,  170.7016833397115]], dtype=float64)
>>> G.mean()
array([  2.0, 200.0], dtype=float64)
```

## 값은 언제나 float64

표본은 언제나 float64예요. [이산 분포](/api/stats/methods/#이산-분포에서-달라지는-것)의 표본도 값은 정수이지만 float64로 돌려줘요. 이산 분포의 `icdf`와 같은 규칙이고, int64에 담기지 않는 아주 큰 값(Zipf 분포의 표본 등)과 inf도 그대로 담을 수 있어요. 정수 배열이 필요하면 [`astype`](/api/array/astype/)으로 바꾸세요.

```python
>>> B = sd.stats.Binomial(n=10.0, p=0.3)
>>> k = B.sample(5, rng=sd.random.default_rng(42))
>>> k
array([3.0, 3.0, 4.0, 4.0, 1.0], dtype=float64)
>>> k.astype(sd.int64)
array([3, 3, 4, 4, 1], dtype=int64)
```

값이 float64로 나타낼 수 없을 만큼 작으면 0이, 클 수 없을 만큼 크면 inf가 나오는 것이 맞는 경우도 있어요. 모양이 0.001인 감마분포는 질량의 절반 가까이가 float64의 가장 작은 수(약 5e-324)보다 작은 곳에 있어서, 표본의 절반 가까이가 0이에요.

```python
>>> sd.stats.Gamma(a=1e-3).sample(5, rng=sd.random.default_rng(0))
array([1.3409119681655297e-238,                     0.0,
         8.732387220230669e-16,                     0.0,
        9.814974694658457e-292], dtype=float64)
```

## 생성기의 위치가 나아가요

생성기는 자기 수열에서 어디까지 꺼냈는지 기억해요([난수의 기본](/api/random/basics/)). `sample`은 결과의 원소 하나마다 수열의 원소 하나를 써서, 부르고 나면 생성기의 위치 `rng.state["position"]`이 **결과의 원소 수만큼** 나아가요.

```python
>>> rng = sd.random.default_rng(42)
>>> rng.state["position"]
0
>>> _ = Z.sample(rng=rng)
>>> rng.state["position"]
1
>>> _ = Z.sample((2, 3), rng=rng)
>>> rng.state["position"]
7
```

이 컴퓨터의 메모리에 담을 수 없을 만큼 큰 모양을 달라고 하면 `MemoryError`예요. 수열에서 꺼내기 전에 알리므로 생성기의 위치는 그대로예요.

```python
>>> Z.sample(10 ** 12, rng=rng)
Traceback (most recent call last):
    ...
MemoryError: sample(): cannot allocate 8000000000000 bytes: more than this machine's physical memory
>>> rng.state["position"]
7
```

결과의 원소는 C 순서(마지막 축이 가장 빨리 바뀌는 순서)로 수열의 원소를 차례로 받아요. 매개변수가 셋인 분포에서 `sample(4)`를 부르면, 결과의 (i, j) 자리는 수열에서 $3i + j$번째 원소로 만들어요.

생성기의 다른 메서드(`rng.random`, `rng.integers` 등)도 **같은 수열**을 이어서 써요. 그래서 `rng.random()`을 먼저 부르면 그다음 `sample`은 수열의 1번 원소부터 써요.

```python
>>> Z.sample(2, rng=sd.random.default_rng(7))
array([ 1.6461003889112136, -2.0219457064672883], dtype=float64)
>>> rng = sd.random.default_rng(7)
>>> _ = rng.random()
>>> Z.sample(rng=rng)
-2.0219457064672883
```

## 같은 시드, 같은 순서면 같은 값

같은 시드로 만든 생성기에서 **같은 순서로** 뽑으면 언제나 같은 값이 나와요. 오늘 실행해도, 다른 컴퓨터에서 실행해도 같아요. 그리고 다음 두 가지는 값에 영향을 주지 않아요.

- **나눠 뽑기**: 다섯 개를 한 번에 뽑든, 두 개와 세 개로 나눠 뽑든 같은 값이에요.
- **[스레드](/api/array/threads/) 수**: 원소가 많으면 여러 코어가 나눠 계산하지만, 스레드 수를 몇으로 하든 비트 하나까지 같아요.

```python
>>> Z.sample(5, rng=sd.random.default_rng(7))
array([ 1.6461003889112136, -2.0219457064672883, -1.5405923819525573,
        0.6134277407601004,  -1.403564335032452], dtype=float64)
>>> rng = sd.random.default_rng(7)
>>> Z.sample(2, rng=rng), Z.sample(3, rng=rng)
(array([ 1.6461003889112136, -2.0219457064672883], dtype=float64), array([-1.5405923819525573,  0.6134277407601004,  -1.403564335032452], dtype=float64))
>>> n = sd.get_num_threads()
>>> a = Z.sample(1_000_000, rng=sd.random.default_rng(42))
>>> sd.set_num_threads(1)
>>> bool(sd.all(Z.sample(1_000_000, rng=sd.random.default_rng(42)) == a))
True
>>> sd.set_num_threads(n)
```

호출의 **순서**가 바뀌면 값도 바뀌어요. 같은 생성기에서 정규분포를 먼저 뽑고 포아송분포를 뽑는 것과, 그 반대 순서로 뽑는 것은 다른 결과예요. 코드의 한 부분이 다른 부분의 난수 순서에 영향을 주지 않게 하려면, [`spawn`](/api/random/spawn-state/)으로 서로 독립된 생성기를 나눠 쓰세요.

```python
>>> parent = sd.random.default_rng(42)
>>> rng_a, rng_b = parent.spawn(2)
>>> xa = Z.sample(3, rng=rng_a)
>>> xb = sd.stats.Poisson(mu=3.0).sample(3, rng=rng_b)
```

`rng_a`와 `rng_b`는 서로 다른 수열이라, 한쪽에서 몇 개를 뽑든 다른 쪽의 값은 달라지지 않아요.

## 뽑을 수 없으면 NaN

### 매개변수가 정의역 밖이면

매개변수가 정의역 밖이거나 NaN인 분포의 표본은 NaN이에요. 다른 메서드와 같은 규칙이에요. 배열 매개변수라면 그 원소의 표본만 NaN이고, 나머지는 정상으로 뽑혀요.

```python
>>> sd.stats.Normal(sigma=-1.0).sample(rng=sd.random.default_rng(0))
nan
>>> sd.stats.Normal(mu=sd.asarray([0.0, sd.nan])).sample(rng=sd.random.default_rng(0))
array([1.123350657710807,               nan], dtype=float64)
```

NaN인 원소도 수열의 원소를 하나 차지해요. 그래서 매개변수 하나가 잘못돼도 다른 원소의 값은 달라지지 않아요.

### 정해진 시간 안에 뽑을 수 없으면

표본을 뽑는 방법 가운데에는 후보를 뽑아 보고 조건에 맞지 않으면 다시 뽑는 것이 있어요. stardust는 이런 반복의 횟수를 모두 정해 두었고, 그 안에 뽑을 수 없는 매개변수에서는 틀린 값 대신 NaN을 내요. 보통 쓰는 매개변수에서는 일어나지 않아요. 예를 들면 표준편차가 65536을 넘는 초기하분포, 폭이 $2^{64}$ 이상인 이산 균등분포가 그래요.

```python
>>> sd.stats.Hypergeometric(total=1e12, successes=5e11, draws=5e11).sample(rng=sd.random.default_rng(0))
nan
>>> sd.stats.DiscreteUniform(low=0.0, high=2.0 ** 64).sample(rng=sd.random.default_rng(0))
nan
```

어떤 매개변수에서 이렇게 되는지는 각 분포의 문서에 있어요.

## 다변량·행렬 분포의 표본

값이 벡터나 행렬인 분포도 같은 `sample(shape, rng=...)`을 써요. 다른 점은 **벡터 하나, 행렬 하나가 표본 하나**라는 것이에요.

- 결과의 모양은 `shape` + 매개변수의 배치 모양 + 값 하나의 모양이에요. 값 하나의 모양은 다변량 분포가 `(d,)`, 행렬 분포가 `(p, p)`(행렬 정규는 `(n, p)`)예요.
- 생성기의 위치는 벡터·행렬의 개수만큼 나아가요. 성분의 개수가 아니에요.

```python
>>> M = sd.stats.MultivariateNormal(mu=sd.asarray([0.0, 0.0]), cov=sd.asarray([[1.0, 0.5], [0.5, 1.0]]))
>>> rng = sd.random.default_rng(0)
>>> M.sample(rng=rng).shape
(2,)
>>> v = M.sample(3, rng=rng)
>>> v.shape, rng.state["position"]
((3, 2), 4)
```

`M.sample(3)`은 2차원 벡터 3개라서 모양이 (3, 2)이고, 생성기는 1 + 3 = 4만큼 나아갔어요.

매개변수에 배치 축이 있으면 그 축이 `shape`과 값의 모양 사이에 들어가요. 평균 벡터 둘(모양 (2, 2))로 만든 분포에서 4개씩 뽑으면 (4, 2, 2)예요.

```python
>>> MB = sd.stats.MultivariateNormal(mu=sd.asarray([[0.0, 0.0], [10.0, 10.0]]), cov=sd.eye(2))
>>> MB.sample(4, rng=sd.random.default_rng(0)).shape
(4, 2, 2)
>>> W = sd.stats.Wishart(df=3.0, scale=sd.eye(2))
>>> W.sample(5, rng=sd.random.default_rng(0)).shape
(5, 2, 2)
>>> MN = sd.stats.MatrixNormal(mu=sd.zeros((2, 3)), rowcov=sd.eye(2), colcov=sd.eye(3))
>>> MN.sample(4, rng=sd.random.default_rng(0)).shape
(4, 2, 3)
```

다항분포의 표본도 개수이지만 float64예요. 각 행의 합은 `n`이에요. 디리클레분포의 표본은 각 행의 합이 1인 비율이에요.

```python
>>> Mn = sd.stats.Multinomial(n=10.0, p=sd.asarray([0.2, 0.3, 0.5]))
>>> c = Mn.sample(3, rng=sd.random.default_rng(0))
>>> c
array([[3.0, 2.0, 5.0],
       [2.0, 4.0, 4.0],
       [2.0, 1.0, 7.0]], dtype=float64)
>>> sd.sum(c, axis=1)
array([10.0, 10.0, 10.0], dtype=float64)
```

양의 정부호가 아닌 공분산처럼 매개변수가 잘못되면 그 벡터의 성분이 모두 NaN이에요.

```python
>>> bad = sd.stats.MultivariateNormal(mu=sd.asarray([0.0, 0.0]), cov=sd.asarray([[1.0, 2.0], [2.0, 1.0]]))
>>> bad.sample(rng=sd.random.default_rng(0))
array([nan, nan], dtype=float64)
```

## 표본은 분포를 정확히 따라요

모든 분포의 표본은 그 분포를 **정확히** 따르는 방법으로 뽑아요. 후보를 뽑아 확률에 맞게 받아들이거나 버리는 방법, 다른 분포의 표본을 조합하는 방법 등이고, 분포를 어림하는 근사는 쓰지 않아요. 그래서 꼬리의 드문 값도 정해진 확률대로 나와요. 분포마다 어떤 방법을 쓰는지는 [표본 뽑기의 구현](/internals/stats/sampling/)에 있어요.

## scipy를 아는 분께

- **같은 시드라도 값이 달라요.** 난수 생성기의 종류도, 분포마다 표본을 만드는 방법도 numpy·scipy와 달라요. numpy의 `default_rng(42).normal(size=3)`이나 scipy의 `Normal().sample(3, rng=42)`로 만든 값을 stardust로 다시 만들 수는 없어요.
- **`rng`는 꼭 줘야 해요.** scipy 신형의 `sample(shape=(), *, method=None, rng=None)`은 `rng`를 생략하거나 시드 정수, numpy 생성기를 받지만, 여기서는 `sd.random.default_rng`의 생성기만 받아요. `method=`는 없어요.
- 결과 모양의 규칙(`shape` + 매개변수의 브로드캐스트 모양)은 scipy 신형과 같아요. 기본값만 달라요. scipy 신형은 `shape=()`가 기본값이고 그것이 표본 하나인데, 여기서는 `shape=None`(생략)이 표본 하나이고 `()`는 `ValueError`예요.
- 이산 분포의 표본이 float64인 것은 scipy 신형과 같아요. numpy 생성기의 `binomial`, `poisson`은 int64예요.
- numpy의 `rng.normal(loc, scale, size)`, `rng.gamma(shape, scale, size)` 같은 분포 메서드는 `sd.random`의 생성기에 없어요. `sd.stats.Normal(mu=loc, sigma=scale).sample(size, rng=rng)`처럼 분포 객체에서 뽑아요.
- numpy·scipy가 약속하지 않는 것을 약속해요. 값이 스레드 수와 상관없고, 한 호출을 둘로 나눠 불러도 같은 값이에요.
