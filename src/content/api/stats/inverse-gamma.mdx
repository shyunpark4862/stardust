## 어떤 분포인가요

[감마 분포](/api/stats/gamma/)를 따르는 양수 $Y$의 역수 $1/Y$가 따르는 분포가 **역감마 분포**예요. 척도까지 붙이면

$$
X = \frac{\text{scale}}{Y}, \qquad Y \sim \text{Gamma}(a)
$$

예요. 감마 분포에서 0 근처의 값은 역수를 취하면 아주 큰 값이 되고, 감마 분포의 큰 값은 드물어서 역수가 0 근처에 오는 일도 드물어요. 그래서 역감마 분포는 0 근처가 거의 비어 있고 오른쪽 꼬리가 길어요. 꼬리는 $x^{-a-1}$처럼 거듭제곱으로 줄어서, 감마 분포의 지수 꼬리보다 훨씬 두꺼워요.

쓰이는 곳은 이래요.

- 베이즈 통계: 정규분포 자료의 분산에 대한 사전분포. 사전분포가 역감마이면 자료를 본 뒤의 사후분포도 역감마라서(켤레 사전분포) 계산이 닫힌 꼴로 끝나요(아래 예).
- 확률 과정: 브라운 운동이 처음으로 어떤 높이에 닿는 시간(레비 분포, `a = 1/2`).
- 꼬리가 두꺼운 양수 자료: 체류 시간, 강우 강도 등.

```python
>>> import stardust as sd
>>> X = sd.stats.InverseGamma(a=3.0, scale=2.0)
>>> X.cdf(1.0)
0.6766764161830634
>>> X.mean()
1.0
```

## 만들기와 매개변수

- `a`: 모양. 0보다 커야 하고, 기본값이 없어서 꼭 줘야 해요. 클수록 꼬리가 얇아지고 높은 모멘트까지 유한해요.
- `scale`: 척도. 0보다 커야 하고 기본값은 1이에요. 분포 전체를 `scale`배로 늘여요.

```python
>>> sd.stats.InverseGamma(a=2.5)
InverseGamma(a=2.5, scale=1.0)
>>> sd.stats.InverseGamma(a=sd.asarray([2.0, 3.0, 5.0]), scale=2.0).mean()
array([2.0, 1.0, 0.5], dtype=float64)
```

<Callout type="warn" title="감마의 scale과 역감마의 scale은 서로 역수예요">
  `InverseGamma`의 `scale`은 감마 분포의 비율(rate)에 해당해요. $Y$가 `Gamma(a=a, scale=θ)`이면 $1/Y$는 `InverseGamma(a=a, scale=1/θ)`예요. 베이즈 통계 책에서 역감마를 $\text{IG}(\alpha, \beta)$로 쓰면 그 $\beta$가 `scale`이에요.
</Callout>

`a`나 `scale`이 0 이하이거나 무한대·NaN이면 그 원소의 결과가 모두 NaN이에요.

```python
>>> sd.stats.InverseGamma(a=0.0).cdf(1.0)
nan
>>> sd.stats.InverseGamma(a=1.0, scale=0.0).cdf(1.0)
nan
```

## 밀도와 누적분포

$s = \text{scale}$이라고 두면 지지집합은 $(0, \infty)$이고

$$
f(x) = \frac{s^{a}}{\Gamma(a)}\, x^{-a-1} e^{-s/x}, \qquad
F(x) = Q\!\left(a, \frac{s}{x}\right), \qquad
P(X > x) = P\!\left(a, \frac{s}{x}\right)
$$

예요. $P$, $Q$는 정칙화된 아래·위 [불완전 감마 함수](/api/special/gammainc/)예요. $X \le x$는 $Y \ge s/x$와 같은 사건이라서, 역감마의 `cdf`는 감마의 `ccdf`이고 역감마의 `ccdf`는 감마의 `cdf`예요. 분위수는 닫힌 꼴이 없어서 수치로 구해요.

```python
>>> X.pdf(1.0)
0.5413411329464508
>>> X.ccdf(1.0)
0.32332358381693654
>>> X.pdf(0.0), X.cdf(0.0), X.pdf(-1.0)
(0.0, 0.0, 0.0)
>>> X.icdf(0.5)
0.7479262863802242
>>> X.icdf(0.0), X.icdf(1.0)
(0.0, inf)
```

### 꼬리

0 쪽은 $e^{-s/x}$ 때문에 아주 빨리 비어서, `cdf`가 금방 float64로 나타낼 수 있는 범위 아래로 내려가요. 오른쪽 꼬리는 $x^{-a}$에 비례해서 천천히 줄어요. 두 쪽 모두 log 메서드가 값을 내요.

>>> X.cdf(0.01)

### 예: 정규분포 분산의 사후분포

평균이 0으로 알려진 정규분포에서 값 10개를 재서 제곱합이 4.5였다고 해 볼게요. 분산 $\sigma^2$의 사전분포를 `InverseGamma(a=2, scale=1)`로 두면, 사후분포는 `a`에 표본 수의 절반을, `scale`에 제곱합의 절반을 더한 역감마예요.

$$
\sigma^2 \mid \text{자료} \sim \text{InverseGamma}\!\left(a_0 + \tfrac{n}{2},\ s_0 + \tfrac{1}{2}\textstyle\sum x_i^2\right)
$$

```python
>>> post = sd.stats.InverseGamma(a=2.0 + 10 / 2, scale=1.0 + 4.5 / 2)
>>> post
InverseGamma(a=7.0, scale=3.25)
>>> post.mean(), post.median(), post.mode()
(0.5416666666666666, 0.4872828856612694, 0.40625)
>>> post.icdf(0.025), post.iccdf(0.025)
(0.24886147745276468, 1.154790601107726)
```

분산의 사후 평균은 약 0.54이고, 95% 신용구간은 약 0.25에서 1.15예요. 오른쪽 꼬리가 길어서 구간이 평균을 중심으로 대칭이 아니에요.

## 요약값

| 메서드 | 값 | 유한한 범위 |
|---|---|---|
| `mean()` | $\dfrac{s}{a - 1}$ | $a > 1$ |
| `variance()` | $\dfrac{s^2}{(a-1)^2(a-2)}$ | $a > 2$ |
| `skewness()` | $\dfrac{4\sqrt{a - 2}}{a - 3}$ | $a > 3$ |
| `kurtosis()` | $\dfrac{30a - 66}{(a-3)(a-4)}$ (초과 첨도) | $a > 4$ |
| `median()` | $s / m_a$ ($m_a$는 `Gamma(a)`의 중앙값) | 모든 a |
| `mode()` | $\dfrac{s}{a + 1}$ | 모든 a |
| `entropy()` | $a + \log(s\,\Gamma(a)) - (1 + a)\,\psi(a)$ | 모든 a |

$\psi$는 [디감마 함수](/api/special/digamma/)예요. $k$차 모멘트는 $a > k$일 때만 유한해요. 발산하는 모멘트는 inf, 그보다 낮은 모멘트가 이미 무한해서 정의할 수 없으면 NaN이에요.

```python
>>> Z = sd.stats.InverseGamma(a=sd.asarray([1.0, 2.0, 3.0, 5.0]))
>>> Z.mean()
array([ inf,  1.0,  0.5, 0.25], dtype=float64)
>>> Z.variance()
array([                 nan,                  inf,                 0.25,
       0.020833333333333332], dtype=float64)
>>> X.skewness(), X.kurtosis()
(inf, inf)
>>> sd.stats.InverseGamma(a=5.0).skewness(), sd.stats.InverseGamma(a=5.0).kurtosis()
(3.4641016151377544, 42.0)
```

`a = 3`이면 분산은 유한하지만 3차 모멘트가 무한해서 왜도가 inf예요. `a ≤ 1`이면 평균부터 무한해요. 중앙값, 최빈값, 엔트로피는 모든 `a`에서 유한해요.

```python
>>> X.median(), X.mode()
(0.7479262863802242, 0.5)
>>> X.entropy()
0.695157020726022
```

## 다른 분포와의 관계

### 감마 분포: X = scale / Y

정의 그대로, `InverseGamma(a, scale=s)`의 `cdf(x)`는 `Gamma(a)`의 `ccdf(s / x)`이고, `icdf(p)`는 `s / Gamma(a).iccdf(p)`예요.

```python
>>> G = sd.stats.Gamma(a=3.0)
>>> X.cdf(0.5), G.ccdf(2.0 / 0.5)
(0.2381033055535443, 0.2381033055535443)
>>> X.icdf(0.9), 2.0 / G.iccdf(0.9)
(1.8147744500565022, 1.8147744500565022)
```

감마에 척도가 있으면 역수의 척도는 그 역수예요. `Gamma(a=3, scale=0.5)`의 역수는 `InverseGamma(a=3, scale=2)`예요.

```python
>>> G2 = sd.stats.Gamma(a=3.0, scale=0.5)
>>> X.cdf(0.8), G2.ccdf(1 / 0.8)
(0.5438131158833297, 0.5438131158833297)
```

중앙값도 같은 관계예요. 역수를 취해도 순서가 뒤집힐 뿐 가운데는 가운데라서, 역감마의 중앙값은 감마 중앙값의 역수(에 `scale`을 곱한 것)예요. 평균은 그렇지 않아요. $E[1/Y] \ne 1/E[Y]$라서, `X.mean()`은 `2 / G.mean()`(= 2/3)이 아니라 1이에요.

### 역카이제곱 분포

`InverseGamma(a=k/2, scale=1/2)`는 자유도 $k$인 [카이제곱 분포](/api/stats/chi-squared/)를 따르는 값의 역수예요(역카이제곱 분포).

```python
>>> K = sd.stats.InverseGamma(a=2.5, scale=0.5)
>>> K.cdf(0.5), sd.stats.ChiSquared(df=5).ccdf(1 / 0.5)
(0.8491450360846096, 0.8491450360846096)
```

척도를 $k/2$로 두면 $k/\chi^2_k$, 곧 분자 자유도가 무한대인 [F 분포](/api/stats/f/)예요. `F(dfn=inf, dfd=k)`는 `InverseGamma(a=k/2, scale=k/2)`와 같은 값을 내요.

```python
>>> sd.stats.F(dfn=sd.inf, dfd=6).cdf(2.0), sd.stats.InverseGamma(a=3.0, scale=3.0).cdf(2.0)
(0.8088468305380582, 0.8088468305380582)
```

### 레비 분포와 정규분포

`a = 1/2`인 역감마는 레비 분포예요. 특히 `InverseGamma(a=0.5, scale=0.5)`는 표준정규분포를 따르는 $Z$에 대해 $1/Z^2$의 분포라서, $P(1/Z^2 \le x) = P(|Z| \ge 1/\sqrt{x})$예요.

```python
>>> import math
>>> Lv = sd.stats.InverseGamma(a=0.5, scale=0.5)
>>> Lv.cdf(4.0), 2 * sd.stats.Normal().ccdf(1 / math.sqrt(4.0))
(0.6170750774519739, 0.6170750774519738)
```

두 값은 마지막 자리만 달라요. 서로 다른 함수로 같은 수를 계산해서 생기는 반올림 차이이고, 둘 다 상대 1e-14 안이에요. 레비 분포는 평균도 무한한, 꼬리가 아주 두꺼운 분포예요.

### 파레토와의 꼬리 비교

역감마의 오른쪽 꼬리는 $x^{-a}$에 비례해서, 꼬리 지수가 `b = a`인 [파레토 분포](/api/stats/pareto/)와 같은 빠르기로 줄어요. 그래서 모멘트가 유한한 범위도 같아요($k$차 모멘트는 $a > k$).

## 정확도와 범위

역감마의 누적분포와 분위수는 불완전 감마 함수와 그 역함수로 계산해요. 그래서 보장 영역은 감마 분포와 같아요.

- **보장 영역**: `a ≤ 1e6`(`scale`과 입력은 정의역 전체). 이 안에서 값 메서드와 요약값은 상대오차 1e-14 이하, `logpdf`와 `entropy`는 1e-14·max(1, |값|) 이하, 역함수 넷은 상대오차가 1e-14에 입력에 대한 조건수를 곱한 값 이하예요. 꼬리의 아주 작은 확률에서도 마찬가지예요.
- **보장 영역 밖**: 값을 계산하지만 정확도를 약속하지 않아요. 모든 호출은 정해진 시간 안에 끝나고, 구할 수 없는 값은 NaN이에요.

```python
>>> sd.stats.InverseGamma(a=1e7).median()
1.0000000333333344e-07
```

보장 영역 밖에서 NaN이 되는 곳은 이래요.

- `a`가 $2^{100}$(약 1.3e30)을 넘으면 누적분포 계열(`cdf`, `ccdf`와 그 log)과 역함수, `median`이 NaN이에요. 밀도와 평균 같은 닫힌 꼴 요약값은 값이 있어요.
- `a`가 [1e-6, 1e6] 밖이면 역함수는 구한 근을 누적분포에 다시 넣어 목표와 상대 1e-12 안에서 맞을 때만 값을 내고, 아니면 NaN이에요.
- 아주 큰 `a`(1e12 이상)에서 확률이 $2^{-1000}$(약 9.3e-302)보다 작은 깊은 꼬리의 역함수는, 반복이 정해진 횟수 안에 수렴하지 않으면 NaN이에요.

```python
>>> big = sd.stats.InverseGamma(a=2.0 ** 101)
>>> big.cdf(2.0 ** -101), big.icdf(0.5)
(nan, nan)
>>> big.pdf(2.0 ** -101), big.mean()
(1.6104765627345383e+45, 3.944304526105059e-31)
```

아주 작은 `a`($2^{-600}$ 이하)에서는 질량 거의 전부가 아주 큰 값에 몰려서, 많은 확률에서 분위수가 float64 범위를 넘어 inf예요. 역함수 넷과 `median`은 근이 float64로 나타낼 수 있는 범위 밖이면 끝에서 정해요. 가장 큰 float64 값에서도 누적확률이 목표에 못 미치면 inf, 가장 작은 양수에서 이미 목표를 넘으면 0이에요. `a`가 서브노멀(약 2.2e-308 미만)이거나 `scale`이 아주 작아도 마찬가지예요. 근이 float64 범위 안에 있으면 그 값을 내요. 근이 `scale`보다 몇백 자릿수 커도 마찬가지예요. 아래 `InverseGamma(a=1e-100, scale=1e-300)`의 분위수는 `scale`의 약 $5 \times 10^{347}$배예요.

`entropy()`는 `a`가 $2^{-1000}$보다 작으면 $1/a + \log(s/a) + 1 + \gamma$로 계산해요($\gamma$는 오일러 상수). $\log\Gamma(a) \approx -\log a$, $\psi(a) \approx -1/a - \gamma$를 위 식에 넣은 꼴이에요. 값은 거의 $1/a$라서 $1/a$가 float64 범위를 넘으면 inf예요.

```python
>>> sd.stats.InverseGamma(a=1e-300).median()
inf
>>> tiny = sd.stats.InverseGamma(a=5e-311, scale=5e-311)
>>> tiny.icdf(1e-310), tiny.median(), tiny.iccdf(1.0)
(6.0700216117316e-310, inf, 0.0)
>>> sd.stats.InverseGamma(a=1e-100, scale=1e-300).icdf(800e-100)
4.855870551499206e+47
>>> sd.stats.InverseGamma(a=1e-308, scale=1e-308).entropy(), tiny.entropy()
(1e+308, inf)
```

구현은 [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)에, 불완전 감마 함수 자체는 [불완전 감마와 베타](/internals/special/incomplete/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.invgamma(a, scale=s)`에 해당해요. **`loc`이 없어요.** 지지집합은 언제나 $(0, \infty)$예요.
- 모멘트의 발산 표시가 달라요. `InverseGamma(a=1).variance()`는 NaN(scipy 1.18.1은 inf), `InverseGamma(a=3).skewness()`와 `InverseGamma(a=4).kurtosis()`는 inf(scipy는 nan)예요. stardust는 그 모멘트가 발산하면 inf, 더 낮은 모멘트가 이미 무한해서 정의할 수 없으면 NaN을 내요.
- 깊은 꼬리의 로그를 내요. `InverseGamma(a=3, scale=2).logcdf(0.001)`은 −1985.49…, `logccdf(1e300)`은 −2072.04…이고 scipy의 `logcdf`, `logsf`는 둘 다 −inf예요.
- 아주 작은 모양에서도 분위수를 내요. `InverseGamma(a=5e-311, scale=5e-311).median()`은 inf, `icdf(1e-310)`은 6.0700216117316e-310이에요. scipy의 `median()`은 nan이고 `ppf(1e-310)`은 6.08022200639344e-310이라 셋째 자리부터 달라요. `InverseGamma(a=1e-100, scale=1e-300).icdf(800e-100)`은 4.855870551499206e+47이고 scipy의 `invgamma.ppf(800e-100, 1e-100, scale=1e-300)`은 inf예요.
- 깊은 꼬리의 분위수가 끝자리까지 맞아요. `InverseGamma(a=3, scale=2).iccdf(1e-300)`은 1.1006424162982089e+100이고(참값 1.10064241629820888…e+100), scipy의 `isf`는 1.1006424162981899e+100이에요.
- `kurtosis()`는 초과 첨도예요.
