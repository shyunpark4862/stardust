## 어떤 분포인가요

**카이제곱 분포**(chi-squared distribution, χ² 분포)는 "제곱한 오차를 모두 더한 값"의 분포예요. 표준정규분포를 따르는 서로 독립인 값 $Z_1, \dots, Z_k$가 있을 때

$$
Q = Z_1^2 + Z_2^2 + \cdots + Z_k^2
$$

는 자유도 $k$인 카이제곱 분포를 따라요. 제곱해서 더하니 언제나 0 이상이고, 더하는 개수(**자유도**, `df`)가 많을수록 값이 커지고 분포가 오른쪽으로 옮겨 가요.

"관측이 기대에서 얼마나 벗어났나"를 하나의 수로 모으면 대개 이런 제곱합이 돼서, 통계 검정에서 아주 자주 나와요.

- **적합도 검정**: 주사위를 60번 던져 나온 눈의 도수가 공평한 주사위의 기대(각 10번)와 맞는지
- **독립성 검정**: 교차표에서 두 범주형 변수(성별과 선호 제품 등)가 서로 관련이 있는지
- **분산의 신뢰구간**: 정규분포를 따르는 자료의 표본 분산으로 참 분산의 범위를 어림할 때
- **가능도비 검정**: 큰 표본에서 두 모형의 로그 가능도 차이의 두 배가 따르는 분포

```python
>>> import stardust as sd
>>> C = sd.stats.ChiSquared(df=3)
>>> C
ChiSquared(df=3)
>>> C.pdf(2.0)
0.20755374871029733
>>> C.icdf(0.95)
7.814727903251178
>>> C.cdf(7.814727903251178)
0.95
```

`C.icdf(0.95)`는 자유도 3인 카이제곱 분포의 위 5% 경계예요. 검정 통계량이 이 값보다 크면 유의수준 5%에서 가정을 버린다는 뜻의 **임계값**이에요.

## 만들기와 매개변수

매개변수는 자유도 `df` 하나예요. 기본값이 없어서 꼭 `df=`로 이름을 붙여 줘야 해요. `C.df`는 준 값을 그대로 돌려주는 읽기 전용 속성이에요.

```python
>>> C.df
3
>>> sd.stats.ChiSquared(3)
Traceback (most recent call last):
    ...
TypeError: ChiSquared.__init__() takes 1 positional argument but 2 were given
```

`df`는 0보다 큰 유한한 실수예요. 정수가 아니어도 돼요(제곱합으로 설명할 수는 없지만, 아래의 감마 분포로 보면 자연스러운 분포예요). 정의역 밖이면 에러 대신 모든 메서드가 NaN이에요.

```python
>>> sd.stats.ChiSquared(df=2.5).cdf(2.0)
0.5262112203566578
>>> sd.stats.ChiSquared(df=0).mean()
nan
>>> sd.stats.ChiSquared(df=sd.inf).mean()
nan
```

`df`에 배열을 주면 원소마다 다른 분포가 되고, 메서드에 넣는 값과 [브로드캐스팅](/api/array/broadcasting/)해요. 자유도별로 위 5% 임계값을 한 번에 구해 볼게요.

```python
>>> sd.stats.ChiSquared(df=sd.asarray([1.0, 2.0, 5.0, 10.0])).iccdf(0.05)
array([3.8414588206941254,  5.991464547107982, 11.070497693516353,
       18.307038053275146], dtype=float64)
```

`ChiSquared`에는 척도 매개변수가 없어요. 척도가 있는 꼴이 필요하면 [`Gamma`](/api/stats/gamma/)를 써요(아래의 관계 참고).

## 밀도와 누적분포

자유도가 $k$인 카이제곱 분포의 밀도는 이래요.

$$
f(x) = \frac{x^{k/2 - 1} e^{-x/2}}{2^{k/2}\,\Gamma(k/2)}, \qquad x \ge 0
$$

누적분포는 [정규화된 불완전 감마 함수](/api/special/gammainc/) $P$로 $F(x) = P\!\left(\frac{k}{2}, \frac{x}{2}\right)$예요. 지지집합은 $[0, \infty)$이고, 음수에서 `pdf`는 0, `cdf`는 0이에요.

```python
>>> C.support()
(0.0, inf)
>>> C.pdf(-1.0), C.cdf(-1.0)
(0.0, 0.0)
>>> C.logpdf(-1.0)
-inf
```

0에서의 밀도는 자유도에 따라 달라요. $k < 2$이면 $x^{k/2-1}$이 0에서 발산해서 inf, $k = 2$이면 1/2, $k > 2$이면 0이에요.

```python
>>> sd.stats.ChiSquared(df=sd.asarray([1.0, 2.0, 3.0])).pdf(0.0)
array([inf, 0.5, 0.0], dtype=float64)
```

### 적합도 검정의 p값

주사위를 60번 던졌더니 눈 1부터 6까지가 5, 8, 9, 8, 10, 20번 나왔어요. 공평한 주사위라면 각 눈의 기대 도수는 10이에요. (관측 − 기대)²/기대를 모두 더한 값이 검정 통계량이고, 눈이 여섯 개라 자유도는 6 − 1 = 5예요.

```python
>>> o = sd.asarray([5.0, 8.0, 9.0, 8.0, 10.0, 20.0])
>>> e = 10.0
>>> stat = sd.sum((o - e) ** 2 / e)
>>> stat
13.4
>>> sd.stats.ChiSquared(df=5).ccdf(stat)
0.019905220334774376
```

p값은 위꼬리 확률 `ccdf`예요. 약 0.02라서 유의수준 5%에서는 "공평한 주사위"라는 가정을 버려요.

### 분산의 신뢰구간

정규분포를 따르는 값 $n$개의 표본 분산이 $s^2$이면 $(n-1)s^2/\sigma^2$은 자유도 $n - 1$인 카이제곱 분포를 따라요. 그래서 참 분산 $\sigma^2$의 95% 신뢰구간은 양쪽에서 2.5%씩 잘라 만들어요.

```python
>>> x = sd.asarray([9.8, 10.4, 10.1, 9.6, 10.9, 10.2, 9.9, 10.5, 10.0, 10.6])
>>> n = x.shape[0]
>>> s2 = sd.var(x, correction=1)
>>> C9 = sd.stats.ChiSquared(df=n - 1)
>>> ((n - 1) * s2 / C9.icdf(0.975), (n - 1) * s2 / C9.icdf(0.025))
(0.07569876346295028, 0.5332564061630645)
```

표본 분산은 0.16이고, 참 분산은 95% 신뢰도로 약 0.076에서 0.53 사이예요. 카이제곱 분포가 비대칭이라 구간도 표본 분산을 가운데에 두지 않아요.

### 꼬리

카이제곱 검정의 p값은 대개 아주 작은 위꼬리예요. `1 - cdf`는 1 근처에서 자릿수를 잃으니 `ccdf`를 쓰고, 그보다 더 작아서 float64로 나타낼 수 없으면 `logccdf`를 써요.

```python
>>> 1 - C.cdf(100.0)
0.0
>>> C.ccdf(100.0)
1.5541594313896051e-21
>>> C.ccdf(2000.0)
0.0
>>> C.logccdf(2000.0)
-996.4248404973332
```

아래꼬리도 같아요. 0에 아주 가까운 값의 누적확률은 `logcdf`로 받고, 아주 작은 확률의 분위수도 `icdf`로 구할 수 있어요.

```python
>>> C.cdf(1e-300)
0.0
>>> C.logcdf(1e-300)
-1037.4876954886333
>>> C.icdf(1e-300)
2.4179879310247043e-200
```

`icdf(0)`은 0, `icdf(1)`은 inf이고, [0, 1] 밖의 확률은 NaN이에요. 메서드의 공통 의미는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 있어요.

```python
>>> C.icdf(0.0), C.icdf(1.0), C.icdf(-0.1)
(0.0, inf, nan)
```

## 요약값

| 요약값 | 값 |
|---|---|
| `mean()` | $k$ |
| `variance()` | $2k$ |
| `skewness()` | $\sqrt{8/k}$ |
| `kurtosis()` | $12/k$ |
| `mode()` | $\max(k - 2,\ 0)$ |
| `median()` | 닫힌 꼴이 없어요. 대략 $k\left(1 - \frac{2}{9k}\right)^3$ |
| `entropy()` | $\frac{k}{2} + \ln\!\left(2\,\Gamma\!\left(\frac{k}{2}\right)\right) + \left(1 - \frac{k}{2}\right)\psi\!\left(\frac{k}{2}\right)$ |

모든 자유도에서 모멘트가 유한해요. `kurtosis()`는 정규분포를 0으로 두는 초과 첨도이고, `entropy()`는 미분 엔트로피(nat)예요. 자유도가 2 이하이면 밀도가 0에서 가장 커서(발산하는 경우도 포함) `mode()`가 0이에요.

```python
>>> Cs = sd.stats.ChiSquared(df=sd.asarray([1.0, 2.0, 5.0, 50.0]))
>>> Cs.mean()
array([ 1.0,  2.0,  5.0, 50.0], dtype=float64)
>>> Cs.variance()
array([  2.0,   4.0,  10.0, 100.0], dtype=float64)
>>> Cs.mode()
array([ 0.0,  0.0,  3.0, 48.0], dtype=float64)
>>> Cs.median()
array([0.4549364231195722,  1.386294361119891,  4.351460191095526,
        49.33493673397683], dtype=float64)
>>> Cs.kurtosis()
array([12.0,  6.0,  2.4, 0.24], dtype=float64)
```

자유도가 커질수록 왜도와 첨도가 0으로 가요. 중심극한정리대로 제곱합이 정규분포에 가까워지기 때문이에요. 중앙값은 평균보다 조금 작고(오른쪽 꼬리가 길어요), 최빈값은 그보다 더 작아요.

```python
>>> C.standard_deviation()
2.449489742783178
>>> C.skewness()
1.632993161855452
>>> C.entropy()
2.0541199559354117
```

## 다른 분포와의 관계

### 정규분포의 제곱합

정의 그대로, 표준정규 표본 셋을 제곱해서 더하면 자유도 3인 카이제곱 분포를 따라요.

```python
>>> rng = sd.random.default_rng(1)
>>> z = sd.stats.Normal().sample((100000, 3), rng=rng)
>>> q = sd.sum(z ** 2, axis=1)
>>> sd.mean(q)
2.99645927964487
>>> sd.quantile(q, 0.95)
7.812520147334122
>>> C.icdf(0.95)
7.814727903251178
```

### 감마 분포의 특별한 경우

카이제곱 분포는 [감마 분포](/api/stats/gamma/)에서 모양 $a = k/2$, 척도 2로 둔 것이에요. `ChiSquared(df=k)`와 `Gamma(a=k/2, scale=2)`는 같은 분포라서 같은 값을 줘요. 왜도처럼 두 분포가 서로 다른 식으로 계산하는 요약값은 마지막 자리가 다를 수 있어요.

```python
>>> x = sd.asarray([0.5, 2.0, 7.0])
>>> sd.stats.ChiSquared(df=5).cdf(x)
array([0.007876706767370406,  0.15085496391539038,   0.7793596920632893], dtype=float64)
>>> sd.stats.Gamma(a=2.5, scale=2.0).cdf(x)
array([0.007876706767370406,  0.15085496391539038,   0.7793596920632893], dtype=float64)
```

그래서 자유도 2인 카이제곱은 척도 2인 [지수분포](/api/stats/exponential/)(`Gamma(a=1, scale=2)`)와 같아요.

```python
>>> sd.stats.ChiSquared(df=2).cdf(x)
array([0.22119921692859512,  0.6321205588285577,  0.9698026165776815], dtype=float64)
>>> sd.stats.Exponential(scale=2.0).cdf(x)
array([0.22119921692859512,  0.6321205588285577,  0.9698026165776814], dtype=float64)
```

마지막 자리 하나가 다른 것은 두 분포가 서로 다른 식으로 계산하기 때문이에요. 둘 다 오차 한계 안이에요.

### 포아송 분포와의 다리

자유도가 짝수 $2m$이면 위꼬리가 [포아송 분포](/api/stats/poisson/)의 누적확률과 같아요. 평균 $\mu$인 포아송 변수가 $m - 1$ 이하일 확률이 $P(\chi^2_{2m} > 2\mu)$예요.

```python
>>> sd.stats.ChiSquared(df=6).ccdf(2 * 2.5)
0.5438131158833297
>>> sd.stats.Poisson(mu=2.5).cdf(2.0)
0.5438131158833297
```

### t와 F의 재료

카이제곱 분포는 다른 검정 분포의 재료예요. 표준정규를 $\sqrt{\chi^2_\nu/\nu}$로 나누면 [t 분포](/api/stats/student-t/), 두 카이제곱을 각자의 자유도로 나눈 비는 [F 분포](/api/stats/f/)예요. 평균이 0이 아닌 정규분포의 제곱합은 [비중심 카이제곱 분포](/api/stats/noncentral-chi-squared/)이고, 비중심 모수가 0이면 이 분포와 같아요.

```python
>>> sd.stats.NoncentralChiSquared(df=3, nc=0.0).cdf(2.0)
0.4275932955291202
>>> C.cdf(2.0)
0.4275932955291202
```

### 함수 하나만 필요하면

누적확률이나 분위수 하나만 필요하면 [`sd.special.chdtr`, `chdtrc`, `chdtri`](/api/special/chdtr/)가 같은 값을 줘요. `chdtri`는 위꼬리 확률을 받는 역함수라 `iccdf`에 해당해요.

```python
>>> sd.special.chdtrc(3, 100.0)
1.5541594313896051e-21
>>> sd.special.chdtri(3, 0.05)
7.81472790325118
>>> C.iccdf(0.05)
7.81472790325118
```

## 정확도와 범위

- **보장 영역**: 자유도 $0 < k \le 2\times10^6$에서 모든 메서드가 참값 대비 상대오차 1e-14 이하예요. 위꼬리 `ccdf`와 아래꼬리 `cdf` 모두 아주 작은 확률까지 상대 정확도예요. `logpdf`와 `entropy`는 $10^{-14}\cdot\max(1, |\text{값}|)$, 역함수는 입력 확률에 대한 민감도만큼 더 허용해요([stats의 기본](/api/stats/basics/)).
- **잰 값**: 보장 영역 안에서 메서드별 잰 최대 오차는 `cdf`가 1.0e-15, `ccdf`가 1.2e-15, `entropy`가 1.6e-15예요.
- **보장 영역 밖**: 자유도가 2e6보다 커도 값을 계산하지만 정확도를 약속하지는 않아요.

값을 구할 수 없는 곳에서는 NaN이에요. 모든 호출은 정해진 시간 안에 끝나요.

- 자유도가 $2^{101}$(약 2.5e30)을 넘으면 `cdf` 계열과 역함수가 NaN이에요. 밀도와 모멘트는 계산해요.
- 자유도가 $2^{-1021}$(약 4.5e-308)보다 작으면 `pdf`, `cdf` 계열, 역함수, `median`, `entropy`가 NaN이에요. 자유도의 절반을 float64로 정확히 나타낼 수 없어요.
- 자유도가 $[2\times10^{-6}, 2\times10^6]$ 밖이면 역함수는 구한 근을 다시 넣어 확인하고, 맞을 때만 값을 내요. 확률이 $2^{-1000}$보다 작은 깊은 꼬리의 역함수가 정해진 반복 안에 수렴하지 않을 때도 NaN이에요(자유도가 2e12 이상일 때 나와요).

```python
>>> big = sd.stats.ChiSquared(df=2.0 ** 102)
>>> big.cdf(2.0 ** 102)
nan
>>> big.mean()
5.070602400912918e+30
```

계산 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에서 설명해요.

## scipy를 아는 분께

- `scipy.stats.chi2`에 해당해요. 메서드 이름은 scipy의 새 분포 API를 따라요(`sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`).
- `loc`, `scale`이 없어요. 척도가 필요하면 `Gamma(a=df/2, scale=2*s)`를 써요.
- `kurtosis()`는 초과 첨도예요(scipy `chi2.stats(df, moments='k')`와 같아요).
- 꼬리에서 scipy가 `-inf`를 내는 곳에서 값을 내요. `ChiSquared(df=3).logccdf(2000.0)`은 −996.42이고 scipy `chi2.logsf(2000, 3)`은 `-inf`, `logcdf(1e-300)`은 −1037.49이고 scipy는 `-inf`예요.
- 깊은 꼬리의 분위수도 정확해요. `ChiSquared(df=3).icdf(1e-300)`의 참값은 2.41798793102470446e-200인데, scipy `chi2.ppf(1e-300, 3)`은 2.4179879310247908e-200으로 상대오차가 3.6e-14예요.
- 자유도가 $2^{101}$을 넘으면 `cdf`가 NaN이에요. scipy는 값을 내요.
- `sample`은 `rng`를 꼭 받아요. 값은 numpy·scipy와 달라요.
