## 어떤 분포인가요

**디리클레 분포**(Dirichlet distribution)는 **합이 1인 비율 K개**의 분포예요. 값 하나하나가 (0.2, 0.3, 0.5)처럼 확률 벡터나 구성비예요.

- 선거 여론조사에서 세 후보의 지지율이 얼마인지 불확실할 때, 지지율 벡터의 분포
- 문서 하나가 여러 주제를 어떤 비율로 섞어 담는지(주제 모형)
- 다항분포의 확률 `p`를 모를 때 두는 **사전분포**. 개수를 관찰하면 사후분포도 디리클레 분포라 계산이 간단해요.

K = 2이면 비율 하나 x와 나머지 1 − x라서 [베타 분포](/api/stats/beta/)와 같아요. 디리클레 분포는 베타 분포를 범주 K개로 넓힌 것이에요.

매개변수 `alpha`는 K개의 양수예요. 두 가지로 읽으면 쉬워요.

- **비율**: 평균은 $\alpha_i / \alpha_0$이에요($\alpha_0 = \sum_i \alpha_i$). `alpha = (2, 3, 5)`이면 평균이 (0.2, 0.3, 0.5)예요.
- **크기** $\alpha_0$: 클수록 평균 근처에 몰리고, 작을수록 넓게 퍼져요. 모든 $\alpha_i$가 1보다 작으면 성분 하나가 대부분을 차지하는 "치우친" 벡터가 잘 나와요.

```python
>>> import stardust as sd
>>> for a in ([10.0, 10.0, 10.0], [1.0, 1.0, 1.0], [0.2, 0.2, 0.2]):
...     print(sd.stats.Dirichlet(alpha=sd.asarray(a)).sample(2, rng=sd.random.default_rng(1)))
[[0.40346806338187025 0.21943959104396557  0.3770923455741641]

 [0.25347961194198515 0.07108152359359045  0.6754388644644246]]

 [   0.3212450945449103  0.032645563080800195    0.6461093423742894]]
```

세 분포의 평균은 모두 (1/3, 1/3, 1/3)이에요. `alpha = (10, 10, 10)`의 표본은 고르게 나뉘고, `(1, 1, 1)`은 가능한 모든 비율이 똑같이 나올 수 있는 균등분포이고, `(0.2, 0.2, 0.2)`는 한두 성분에 몰려요.

## 만들기와 매개변수

`alpha`는 키워드로 꼭 줘야 하는 `sd.ndarray`이고, 마지막 축 길이 K가 성분의 수예요. 앞 축은 여러 분포를 담는 배치 축이에요.

```python
>>> D = sd.stats.Dirichlet(alpha=sd.asarray([2.0, 3.0, 5.0]))
>>> D
Dirichlet(alpha=array([2.0, 3.0, 5.0], dtype=float64))
>>> sd.stats.Dirichlet(alpha=sd.asarray([[1.0, 1.0], [2.0, 5.0]])).pdf(sd.asarray([0.3, 0.7]))
array([              1.0, 2.160899999999999], dtype=float64)
```

0 이하, inf, NaN인 성분이 하나라도 있으면 그 분포의 모든 메서드가 NaN이에요. 리스트는 `sd.asarray`로 바꿔서 넘겨요. Python 실수 하나도 받지 않아요(K가 정해지지 않으니까요).

```python
>>> sd.stats.Dirichlet(alpha=sd.asarray([0.0, 1.0, 1.0])).mean()
array([nan, nan, nan], dtype=float64)
>>> sd.stats.Dirichlet(alpha=2.0)

    ...
TypeError: Dirichlet(): 'alpha' must be an sd.ndarray, not float
>>> sd.stats.Dirichlet(alpha=[2.0, 3.0, 5.0])

    ...
TypeError: Dirichlet(): 'alpha' must be an sd.ndarray, not list
```

## 밀도

$$
f(x) = \frac{\Gamma(\alpha_0)}{\prod_i \Gamma(\alpha_i)} \prod_{i=1}^{K} x_i^{\alpha_i - 1},
\qquad x_i \ge 0,\ \sum_i x_i = 1
$$

$\Gamma$는 [감마 함수](/api/special/gamma/)예요. 앞의 분수는 넓이를 1로 맞추는 상수예요.

```python
>>> x = sd.asarray([0.2, 0.3, 0.5])
>>> D.pdf(x)
8.505
>>> D.logpdf(x)
2.140654225847825
>>> D.pdf(sd.asarray([[0.2, 0.3, 0.5], [0.1, 0.1, 0.8]]))
array([            8.505, 3.096576000000001], dtype=float64)
```

밀도가 1보다 클 수 있어요. 확률이 아니라 단위 넓이당 확률이고, 비율의 공간(아래)이 좁기 때문이에요.

### 지지집합: 합이 1인 K개 성분

입력 `x`는 **K개 성분을 모두** 담은 `sd.ndarray`예요. 마지막 성분을 빼고 K − 1개만 주면 `ValueError`예요. 값이 놓일 수 있는 곳(지지집합)은 성분이 모두 0 이상이고 합이 1인 점들이에요. 이런 점의 모임을 **단체**(simplex)라고 불러요.

- 음수 성분이 있거나, 합이 1에서 √eps · K(K = 3이면 약 4.5e-8)보다 많이 벗어나면 밀도는 0(`logpdf`는 −inf)이에요. 에러가 아니에요.
- 합이 그 안에서 벗어난 것은 반올림으로 보고, 준 `x`에서 그대로 계산해요.

```python
>>> D.pdf(sd.asarray([0.2, 0.3, 0.6]))
0.0
>>> D.pdf(sd.asarray([-0.1, 0.6, 0.5]))
0.0
>>> D.pdf(sd.asarray([0.2, 0.3, 0.5 + 1e-9]))
8.50500006804
>>> D.pdf(sd.asarray([0.2, 0.8]))
Traceback (most recent call last):
    ...
ValueError: pdf(): 'x' must have 3 components on its last axis, not 2
```

### 성분이 0인 경계

어떤 성분 $x_i$가 정확히 0이면 그 항 $x_i^{\alpha_i - 1}$의 극한값을 써요. $\alpha_i < 1$이면 밀도가 inf, $\alpha_i = 1$이면 그 항이 1, $\alpha_i > 1$이면 0이에요.

```python
>>> on_edge = sd.asarray([0.0, 0.4, 0.6])
>>> sd.stats.Dirichlet(alpha=sd.asarray([0.5, 0.5, 1.0])).pdf(on_edge)
inf
>>> sd.stats.Dirichlet(alpha=sd.asarray([1.0, 1.0, 1.0])).pdf(on_edge)
2.0
>>> sd.stats.Dirichlet(alpha=sd.asarray([2.0, 2.0, 2.0])).pdf(on_edge)
0.0
```

`alpha = (1, 1, 1)`은 단체 위의 균등분포라 어디서나 밀도가 2(= Γ(3))예요.

## 요약값

| 메서드 | 값 | 모양 |
|---|---|---|
| `mean()` | $\alpha_i / \alpha_0$ | 배치 + (K,) |
| `covariance()` | $\dfrac{\alpha_i \alpha_0 \delta_{ij} - \alpha_i \alpha_j}{\alpha_0^2(\alpha_0 + 1)}$ | 배치 + (K, K) |
| `entropy()` | 미분 엔트로피(nat) | 배치 |

$\delta_{ij}$는 i = j일 때 1, 아니면 0이에요.

```python
>>> D.mean()
array([0.2, 0.3, 0.5], dtype=float64)
>>> D.covariance()
array([[ 0.014545454545454545, -0.005454545454545455,  -0.00909090909090909],
       [-0.005454545454545455,  0.019090909090909092, -0.013636363636363636],
       [ -0.00909090909090909, -0.013636363636363636,  0.022727272727272728]], dtype=float64)
>>> D.entropy()
-1.461182024729135
```

합이 1로 묶여 있어서 대각 밖의 공분산은 모두 음수예요. 미분 엔트로피는 음수일 수 있어요. 최빈값을 돌려주는 `mode()`는 없어요.

## 표본

`sample(shape, rng=...)`은 `shape` + 배치 + (K,) 모양이고(`shape`를 빼면 분포마다 하나, 배치 + (K,)), 각 벡터는 단체 위의 점이에요. 합은 반올림 오차 안에서 1이에요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> s = D.sample(4, rng=sd.random.default_rng(0))
>>> s
array([[ 0.4236260394710768, 0.05710268823856508,  0.5192712722903583],
       [0.14317382882564805, 0.32287089685734854,  0.5339552743170034],
       [0.09608057341455473, 0.39335859205397894,  0.5105608345314663],
       [  0.382405127128945, 0.36111111686671993, 0.25648375600433515]], dtype=float64)
>>> sd.sum(s, axis=1)
array([1.0000000000000002,                1.0,                1.0,
                      1.0], dtype=float64)
```

## 다른 분포와의 관계

**K = 2이면 베타 분포**예요. 첫 성분이 [`Beta`](/api/stats/beta/)(a = α₁, b = α₂)를 따라요.

```python
>>> sd.stats.Dirichlet(alpha=sd.asarray([2.0, 5.0])).logpdf(sd.asarray([0.25, 0.75]))
0.8641747307351412
>>> sd.stats.Beta(a=2.0, b=5.0).logpdf(0.25)
0.8641747307351412
```

- **주변분포**: 성분 하나 $X_i$만 보면 $\mathrm{Beta}(\alpha_i, \alpha_0 - \alpha_i)$예요. 위 `D`의 첫 성분은 Beta(2, 8)이라 분산이 `covariance()`의 첫 대각과 같아요(0.014545…).
- **감마 분포**: 서로 독립인 $G_i \sim \mathrm{Gamma}(\alpha_i)$를 합으로 나눈 $(G_1, \dots, G_K)/\sum G$가 디리클레 분포를 따라요. `sample`도 이 방법으로 뽑아요.

### 다항분포와 함께: 베이즈 갱신

세 범주의 확률 `p`를 모른다고 해 볼게요. 아무 정보가 없으면 사전분포로 `Dirichlet(alpha=(1, 1, 1))`(균등)을 두고, [`Multinomial`](/api/stats/multinomial/)로 센 개수를 관찰하면 사후분포는 `alpha + 개수`인 디리클레 분포예요.

```python
>>> prior = sd.stats.Dirichlet(alpha=sd.asarray([1.0, 1.0, 1.0]))
>>> counts = sd.asarray([12.0, 30.0, 58.0])
>>> post = sd.stats.Dirichlet(alpha=prior.alpha + counts)
>>> post.mean()
array([ 0.1262135922330097, 0.30097087378640774,  0.5728155339805825], dtype=float64)
>>> sd.sqrt(sd.linalg.diagonal(post.covariance()))
array([0.032564096759705674, 0.044977281329092005, 0.048506333647814516], dtype=float64)
```

100번 중 12, 30, 58번을 본 뒤, 각 확률의 사후 평균은 약 0.126, 0.301, 0.573이고 사후 표준편차는 0.03–0.05예요.

## 정확도와 범위

`pdf`는 상대 1e-14, `logpdf`와 `entropy`는 |오차| ≤ 1e-14 · max(1, |값|)이에요. `alpha`가 아주 커서 엔트로피의 큰 항들이 서로 거의 지워지는 경우에도 정확해요.

```python
>>> sd.stats.Dirichlet(alpha=sd.asarray([1e6, 1e6, 1e6])).entropy()
-13.724164768780982
```

계산 방법은 [다변량 분포의 밀도](/internals/stats/multivariate/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.dirichlet(alpha)`와 이름이 같아요. 키워드로만 받아요. scipy는 `alpha`와 `x`에 리스트도 받지만, sd는 `sd.ndarray`만 받아요.
- 지지집합 밖의 `x`는 0이에요. scipy 1.18.1은 합이 1이 아닌 `x`나, alpha < 1인 성분이 0인 `x`에서 `ValueError`를 내요. sd는 각각 0과 inf를 돌려줘요.
- `x`는 K개 성분을 모두 줘야 해요. scipy는 마지막 성분을 뺀 K − 1개도 받아요.
- `var()`가 없어요. 성분별 분산은 `covariance()`의 대각이에요. `cov()`의 이름은 `covariance()`예요.
