과녁을 향해 화살을 쏜다고 해 볼게요. 가로 방향 오차와 세로 방향 오차가 서로 독립이고 각각 평균 0, 표준편차 $\sigma$인 정규분포를 따르면, 과녁 중심에서 화살까지의 거리 $R = \sqrt{X^2 + Y^2}$는 **레일리 분포**를 따라요. 레일리 분포의 `scale`이 바로 그 $\sigma$예요.

이렇게 "두 방향 성분이 정규분포인 벡터의 길이"는 곳곳에 있어요.

- 위치 오차: GPS 수신기의 수평 오차 반지름, 사격·투하 정밀도(원형 공산 오차, CEP).
- 바람과 파도: 동서·남북 성분이 정규분포인 풍속의 크기, 좁은 대역의 파도 높이.
- 무선 통신: 직접 경로 없이 여러 반사파가 섞인 신호의 세기(레일리 페이딩).
- 영상: 자기공명영상(MRI)의 배경 잡음 크기.

거리는 0 이상이고, 0 근처는 오히려 드물어요. 중심 바로 근처의 넓이가 작기 때문이에요. 밀도는 `scale`에서 가장 높고, 오른쪽 꼬리는 $e^{-x^2/(2\sigma^2)}$로 정규분포처럼 빠르게 줄어요.

```python
>>> import stardust as sd
>>> R = sd.stats.Rayleigh(scale=3.0)
>>> R.cdf(5.0)
0.7506477912227038
>>> R.mode()
3.0
```

## 만들기와 매개변수

매개변수는 `scale` 하나예요. 0보다 커야 하고 기본값은 1이에요. 성분 정규분포의 표준편차를 그대로 넣으면 돼요.

```python
>>> sd.stats.Rayleigh(scale=2.0)
Rayleigh(scale=2.0)
>>> sd.stats.Rayleigh(scale=sd.asarray([0.5, 1.0, 2.0])).mode()
array([0.5, 1.0, 2.0], dtype=float64)
```

<Callout type="note" title="이름은 scale이에요">
  레일리의 매개변수를 $\sigma$로 쓰는 책이 많지만, 0 이상에서 정의되는 다른 분포(지수, 감마, 베이불 등)처럼 이름이 `scale`이에요. `Rayleigh(sigma=...)`는 TypeError예요. 위치를 옮기는 매개변수도 없어서 지지집합은 언제나 $[0, \infty)$예요.
</Callout>

`scale`이 0 이하이거나 무한대·NaN이면 결과가 모두 NaN이에요.

```python
>>> sd.stats.Rayleigh(scale=0.0).cdf(1.0)
nan
```

## 밀도와 누적분포

$s = \text{scale}$이라고 두면, $x \ge 0$에서

$$
f(x) = \frac{x}{s^2}\, e^{-x^2/(2s^2)}, \qquad
F(x) = 1 - e^{-x^2/(2s^2)}, \qquad
P(X > x) = e^{-x^2/(2s^2)}
$$

이고, $x$가 음수이면 $f = 0$, $F = 0$이에요. 분위수도 닫힌 꼴이에요.

$$
F^{-1}(p) = s\sqrt{-2\log(1 - p)}, \qquad \text{iccdf}(q) = s\sqrt{-2\log q}
$$

```python
>>> R.pdf(-1.0), R.cdf(-1.0), R.pdf(0.0)
(0.0, 0.0, 0.0)
>>> R.ccdf(5.0)
0.24935220877729622
>>> R.icdf(0.5)
3.5322300675464238
>>> R.icdf(0.0), R.icdf(1.0)
(0.0, inf)
```

### 두 꼬리

0 근처에서 $F(x) \approx x^2/(2s^2)$로 아주 작아지고, 위꼬리는 $e^{-x^2/(2s^2)}$로 빨리 줄어요. `cdf`와 `ccdf`는 두 쪽 모두 상대 정확도로 계산하고, 확률이 float64로 나타낼 수 있는 범위 아래로 내려가면 log 메서드가 값을 내요.

```python
>>> R.cdf(1e-10)
5.555555555555556e-22
>>> R.logcdf(1e-200)
-923.9244089555144
>>> R.ccdf(120.0)
0.0
>>> R.logccdf(120.0)
-800.0
>>> R.icdf(1e-300)
4.2426406871192856e-150
```

### 예: 위치 오차의 반지름

GPS 수신기의 동서·남북 오차가 각각 표준편차 3m인 정규분포를 따른다고 해 볼게요. 수평 오차 반지름은 `Rayleigh(scale=3)`이에요.

```python
>>> R.cdf(5.0)
0.7506477912227038
>>> R.median()
3.5322300675464238
>>> R.icdf(0.95)
7.343240492042448
```

5m 안에 들 확률은 약 75%예요. 절반의 측정이 들어오는 반지름(CEP)은 약 3.53m, 95%가 들어오는 반지름은 약 7.34m예요. 정규분포 표본을 직접 뽑아 길이를 재 보면 같은 값 근처가 나와요.

```python
>>> rng = sd.random.default_rng(0)
>>> xy = sd.stats.Normal(sigma=3.0).sample((100000, 2), rng=rng)
>>> r = sd.sqrt(sd.sum(xy * xy, axis=1))
>>> float(sd.mean(r <= 5.0)), float(sd.median(r))
(0.74854, 3.5345519913338004)
```

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()` | $s\sqrt{\pi/2} \approx 1.2533\,s$ |
| `variance()` | $\dfrac{4 - \pi}{2}\, s^2$ |
| `skewness()` | $\dfrac{2\sqrt\pi\,(\pi - 3)}{(4 - \pi)^{3/2}} \approx 0.6311$ |
| `kurtosis()` | $-\dfrac{6\pi^2 - 24\pi + 16}{(4 - \pi)^2} \approx 0.2451$ (초과 첨도) |
| `median()` | $s\sqrt{2\log 2} \approx 1.1774\,s$ |
| `mode()` | $s$ |
| `entropy()` | $1 + \log\dfrac{s}{\sqrt2} + \dfrac{\gamma}{2}$ |

모든 모멘트가 유한하고, 왜도와 첨도는 `scale`과 상관없이 같아요. $\gamma \approx 0.5772$는 오일러–마스케로니 상수예요.

```python
>>> R.mean(), R.variance()
(3.759942411946501, 3.8628330588459305)
>>> R.skewness(), R.kurtosis()
(0.6311106578189372, 0.24508930068763807)
>>> R.entropy()
2.0406465308389037
```

## 표본

`rng`를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> R.sample(3, rng=rng)
```

## 다른 분포와의 관계

### 카이 분포와 카이제곱 분포

표준정규분포를 따르는 독립인 값 $k$개의 제곱합의 제곱근은 자유도 $k$인 **카이 분포**를 따라요. `Rayleigh(scale=1)`은 자유도 2인 카이 분포예요. 제곱하면 자유도 2인 [카이제곱 분포](/api/stats/chi-squared/)라서, 레일리의 누적분포는 카이제곱의 누적분포에 $x^2$을 넣은 것과 같아요.

```python
>>> R1 = sd.stats.Rayleigh()
>>> C = sd.stats.ChiSquared(df=2)
>>> R1.cdf(2.0), C.cdf(2.0 ** 2)
(0.8646647167633873, 0.8646647167633873)
```

`scale`이 $s$이면 $X/s$가 자유도 2인 카이 분포예요. 3차원 벡터의 길이(자유도 3인 카이 분포)는 맥스웰–볼츠만 분포라는 다른 분포예요.

### 지수분포와 베이불 분포

$X$가 `Rayleigh(scale=s)`이면 $X^2$은 척도 $2s^2$인 [지수분포](/api/stats/exponential/)예요(자유도 2인 카이제곱이 척도 2인 지수분포라서요). 또 레일리는 모양이 2이고 척도가 $s\sqrt2$인 [베이불 분포](/api/stats/weibull/)예요.

```python
>>> import math
>>> E = sd.stats.Exponential(scale=2 * 3.0 ** 2)
>>> W = sd.stats.Weibull(c=2.0, scale=3.0 * math.sqrt(2))
>>> R.ccdf(4.0), E.ccdf(4.0 ** 2), W.ccdf(4.0)
(0.41111229050718745, 0.41111229050718745, 0.4111122905071875)
```

마지막 값이 마지막 자리에서 다른 것은 두 분포가 같은 수를 다른 경로로 계산하기 때문이에요. 둘 다 상대 1e-14 안이에요.

### 정규분포

정의 그대로, 성분이 `Normal(sigma=s)`인 2차원 벡터의 길이예요(위의 표본 예). 성분의 평균이 0이 아니면(과녁 중심에서 벗어난 조준) 길이는 레일리가 아니라 라이스(Rice) 분포를 따라요.

## 정확도와 범위

레일리는 닫힌 꼴 분포라서 매개변수와 입력의 정의역 전체에서 정확도를 보장해요.

- 값 메서드와 요약값: 상대오차 1e-14 이하. 0 근처의 아주 작은 `cdf`와 먼 위꼬리의 `ccdf`도 마찬가지예요.
- `logpdf`, `entropy`: 오차가 1e-14·max(1, |값|) 이하.
- 역함수 넷: 상대오차가 1e-14에 입력에 대한 조건수를 곱한 값 이하.

`x/scale`이 float64 범위를 넘는 극단적인 값에서도 NaN 대신 극한값을 내요.

```python
>>> sd.stats.Rayleigh(scale=1e-200).ccdf(1e200)
0.0
```

구현은 [극값·수명·비중심 분포](/internals/stats/extreme-noncentral/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.rayleigh(scale=s)`에 해당해요. `loc`이 없어요. 지지집합은 언제나 $[0, \infty)$예요.
- 0 근처 아래꼬리의 로그를 내요. `Rayleigh(scale=3).logcdf(1e-200)`은 −923.924…이고 scipy 1.18.1의 `rayleigh.logcdf(1e-200, scale=3)`은 −inf예요.
- `kurtosis()`는 초과 첨도예요.
- 카이 분포(`scipy.stats.chi`)에 해당하는 클래스는 없어요. 자유도 2이면 `Rayleigh`, 그 밖에는 `ChiSquared`에 $x^2$을 넣어 쓰세요.
