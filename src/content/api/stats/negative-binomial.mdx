## 어떤 분포인가요

**음이항 분포**(negative binomial distribution)는 두 가지 얼굴이 있어요.

**1. 성공을 기다리는 분포.** 성공 확률이 `p`인 시도를 되풀이해서 `n`번째 성공이 나오면 멈추고, **그때까지 실패한 횟수**를 세요. 값은 0, 1, 2, …예요. [이항 분포](/api/stats/binomial/)가 "시도 횟수를 정해 두고 성공을 센다"면, 음이항 분포는 "성공 횟수를 정해 두고 실패를 센다"예요.

- **영업**: 계약 확률이 20%일 때 계약 3건을 얻기 전까지 거절을 몇 번 듣게 될까요
- **검사**: 불량품 2개를 찾을 때까지 정상품을 몇 개 지나칠까요
- **재시도**: 요청 5개를 모두 성공시킬 때까지 실패가 몇 번 쌓일까요

**2. 흩어짐이 큰 횟수 자료의 모형.** 매장별 방문자 수, 보험 청구 건수, 생물 종의 개체 수, 유전자의 읽힘 수처럼 **분산이 평균보다 훨씬 큰** 횟수 자료는 [포아송 분포](/api/stats/poisson/)(분산 = 평균)로 맞지 않아요. 음이항 분포는 `n`을 양의 실수로 두어 분산을 평균과 따로 맞출 수 있어서 이런 자료의 기본 모형이에요. 이때 `n`은 "성공 횟수"라기보다 흩어짐을 정하는 모양 매개변수예요.

```python
>>> import stardust as sd
>>> X = sd.stats.NegativeBinomial(n=3, p=0.2)
>>> X.pmf(0)
0.008
>>> X.pmf(5)
0.05505023999999999
>>> X.cdf(10)
0.49834781982719983
>>> X.mean()
12.000000000000002
```

계약 확률이 20%이면 처음 세 통에 연달아 계약할(거절 0번) 확률은 0.2³ = 0.8%예요. 계약 3건을 얻기까지 평균 12번 거절을 듣고, 10번 이하로 끝날 확률은 약 50%예요.

## 만들기와 매개변수

매개변수는 이름을 붙여서만 줘요. 둘 다 기본값이 없어요.

```python
>>> X
NegativeBinomial(n=3, p=0.2)
>>> X.n
3
```

- `n`: **0보다 큰 실수**예요. 정수일 필요가 없어요. 0 이하이거나 inf, NaN이면 NaN이에요.
- `p`: **0보다 크고 1 이하**예요. `p = 0`이면 성공이 영영 오지 않아 분포가 되지 않으므로 NaN이에요. `p = 1`은 실패 없이 끝나는 점질량이에요(아래 점질량 절).

```python
>>> sd.stats.NegativeBinomial(n=2.5, p=0.4).pmf(3)
0.14344091466523765
>>> sd.stats.NegativeBinomial(n=0, p=0.5).pmf(0)
nan
>>> sd.stats.NegativeBinomial(n=3, p=0.0).mean()
nan
>>> sd.stats.NegativeBinomial(n=-1, p=0.5).mean()
nan
```

special의 [`nbdtr`](/api/special/nbdtr/)은 `n = 0`과 `p = 0`에서도 극한값(1과 0)을 주지만, 분포 객체는 두 경우 모두 NaN이에요.

매개변수에 배열을 주면 원소마다 다른 분포가 되고, 입력과 [브로드캐스트](/api/array/broadcasting/)해요. 동전으로 앞면 1번, 3번, 10번을 얻을 때까지 뒷면이 2번 이하일 확률이에요.

```python
>>> X = sd.stats.NegativeBinomial(n=sd.asarray([1, 3, 10]), p=0.5)
>>> X.mean()
array([ 1.0,  3.0, 10.0], dtype=float64)
>>> X.cdf(2)
array([               0.875,                  0.5, 0.019287109374999997], dtype=float64)
```

## 확률질량과 누적분포

$q = 1 - p$라고 하면

$$
P(X = k) = \frac{\Gamma(k + n)}{\Gamma(n)\, k!}\, p^n q^k, \qquad k = 0, 1, 2, \dots
$$

예요. `n`이 정수이면 앞의 계수는 $\binom{k+n-1}{k}$, 곧 "마지막 시도(n번째 성공)를 빼고 앞의 $k + n - 1$번 중 실패 $k$번의 자리를 고르는 수"예요. `n`이 정수가 아니면 감마 함수로 이어 붙인 같은 식이에요.

지지집합은 0 이상의 모든 정수예요. 정수가 아닌 값과 음수에서 `pmf`는 0이고, `cdf`는 내림한 정수의 값이에요.

```python
>>> X = sd.stats.NegativeBinomial(n=3, p=0.2)
>>> X.support()
(0.0, inf)
>>> X.pmf(-1)
0.0
>>> X.pmf(2.5)
0.0
>>> X.cdf(2.5)
0.05792000000000001
>>> X.cdf(2)
0.05792000000000001
```

분위수 `icdf(p)`는 cdf(k) ≥ p인 가장 작은 정수, `iccdf(p)`는 ccdf(k) ≤ p인 가장 작은 정수예요. `icdf(0)`은 0, 위쪽 끝이 없어서 `icdf(1)`은 inf예요.

```python
>>> X.icdf(0.5)
11.0
>>> X.icdf(0.9)
22.0
>>> X.iccdf(0.05)
27.0
>>> X.icdf(0.0)
0.0
>>> X.icdf(1.0)
inf
```

계약 3건을 얻기 전 거절이 27번을 넘을 확률은 5% 이하예요. 거절 횟수의 상한을 정할 때 이렇게 써요.

### 꼬리와 log 메서드

`ccdf`는 `1 - cdf`로 계산하지 않아서 작은 위꼬리도 상대 정확도를 지켜요. 더 작아 float64로 나타낼 수 없으면 `logccdf`와 `ilogccdf`를 써요.

```python
>>> N = sd.stats.NegativeBinomial(n=3, p=0.5)
>>> N.ccdf(100)
5.282409836586199e-28
>>> N.logccdf(1e4)
-6915.823013682724
>>> N.iccdf(1e-100)
346.0
>>> N.ilogccdf(-1e4)
14451.0
```

메서드의 공통 뜻은 [분포의 메서드](/api/stats/methods/)에 있어요.

## 요약값

$q = 1 - p$라고 하면

| 메서드 | 값 |
|---|---|
| `mean()` | $nq/p$ |
| `variance()` | $nq/p^2$ |
| `standard_deviation()` | $\sqrt{nq}/p$ |
| `skewness()` | $\dfrac{2 - p}{\sqrt{nq}}$ |
| `kurtosis()` | $\dfrac{6}{n} + \dfrac{p^2}{nq}$ (초과 첨도) |
| `median()` | `icdf(0.5)` |
| `mode()` | $n > 1$이면 $\lfloor (n-1)q/p \rfloor$, 아니면 0. 둘이면 NaN |
| `entropy()` | $-\sum_k P(X=k)\log P(X=k)$ (nat) |

```python
>>> X = sd.stats.NegativeBinomial(n=2.5, p=0.4)
>>> X.mean()
3.75
>>> X.variance()
9.374999999999998
>>> X.standard_deviation()
3.061862178478972
>>> X.skewness()
1.3063945294843617
>>> X.kurtosis()
2.506666666666667
>>> X.median()
3.0
>>> X.mode()
2.0
>>> X.entropy()
2.364795230696287
```

분산 $nq/p^2$는 평균 $nq/p$를 $p$로 한 번 더 나눈 값이라 언제나 평균보다 커요($p < 1$일 때).

### 최빈값이 둘이면 NaN

$n > 1$이고 $(n-1)q/p$가 양의 정수이면 그 값과 하나 아래 값의 확률이 똑같아서 최빈값이 둘이에요. 이때 `mode()`는 NaN이에요. $n \le 1$이면 확률질량이 0에서 가장 크고 계속 줄어서 최빈값은 0이에요.

```python
>>> sd.stats.NegativeBinomial(n=3, p=0.5).mode()
nan
>>> sd.stats.NegativeBinomial(n=3, p=0.5).pmf(sd.asarray([1, 2]))
array([0.18749999999999992, 0.18749999999999992], dtype=float64)
>>> sd.stats.NegativeBinomial(n=1, p=0.5).mode()
0.0
>>> sd.stats.NegativeBinomial(n=0.5, p=0.1).mode()
0.0
```

### 점질량: p = 1

`p = 1`이면 모든 시도가 성공이라 실패는 언제나 0번이에요. 분산과 엔트로피는 0이고, 왜도와 첨도는 분산으로 나누는 값이라 NaN이에요.

```python
>>> Z = sd.stats.NegativeBinomial(n=3, p=1.0)
>>> Z.pmf(0)
1.0
>>> Z.mean()
0.0
>>> Z.variance()
0.0
>>> Z.skewness()
nan
>>> Z.kurtosis()
nan
>>> Z.mode()
0.0
>>> Z.entropy()
0.0
```

## 흩어짐이 큰 횟수: 평균과 n으로 만들기

횟수 자료의 모형으로 쓸 때는 대개 평균 $\mu$와 흩어짐 `n`으로 생각해요. 평균이 $\mu$가 되는 `p`는 $p = n/(n + \mu)$이고, 그러면 분산은

$$
\mathrm{Var}(X) = \mu + \frac{\mu^2}{n}
$$

이에요. 포아송의 분산 $\mu$에 $\mu^2/n$이 더 붙어요. `n`이 작을수록 더 흩어지고, `n` → ∞이면 포아송이 돼요. $1/n$을 흩어짐 매개변수(dispersion)라고 부르기도 해요.

```python
>>> mu, n = 4.0, 2.0
>>> X = sd.stats.NegativeBinomial(n=n, p=n / (n + mu))
>>> X.mean()
4.000000000000001
>>> X.variance()
12.000000000000002
>>> mu + mu**2 / n
12.0
>>> P = sd.stats.Poisson(mu=4.0)
>>> P.variance()
4.0
```

평균이 같은 4여도 0이 나올 확률과 10보다 클 확률이 포아송보다 훨씬 커요. 아무도 오지 않는 날과 아주 붐비는 날이 함께 많은, 실제 방문자 수 같은 자료에 맞는 모양이에요.

```python
>>> X.pmf(0)
0.11111111111111109
>>> P.pmf(0)
0.01831563888873418
>>> X.ccdf(10)
0.053951426404812576
>>> P.ccdf(10)
0.0028397661205137423
```

## 다른 정의에서 옮기기

음이항 분포는 같은 이름으로 여러 정의가 쓰여요. 다른 자료의 식이나 매개변수를 가져올 때 이렇게 옮겨요.

| 그 자료의 정의 | 이 페이지로 옮기기 |
|---|---|
| n번째 성공까지의 **시도 횟수** T (T ≥ n) | T = X + n. `X.pmf(t - n)`, `X.cdf(t - n)` |
| 실패 r번 전의 **성공 횟수**, 성공 확률 p | 역할을 바꿔 `NegativeBinomial(n=r, p=1 - p)` |
| 평균 μ와 흩어짐 n(또는 α = 1/n) | `NegativeBinomial(n=n, p=n / (n + mu))` |
| n = 1인 경우, 실패 횟수로 센 기하 분포 | `NegativeBinomial(n=1, p=p)` |

시도 횟수로 센 기하 분포(k ≥ 1)는 [`Geometric`](/api/stats/geometric/)이 따로 있어요. `Geometric(p)`의 k는 `NegativeBinomial(n=1, p)`의 k − 1과 같아요.

## 표본

`sample`은 음이항 난수를 정수인 float64로 뽑아요. 생성기 `rng`를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(3)
>>> sd.stats.NegativeBinomial(n=2.5, p=0.4).sample((8,), rng=rng)
array([ 1.0,  4.0,  2.0,  1.0, 10.0,  5.0,  2.0,  6.0], dtype=float64)
>>> x = sd.stats.NegativeBinomial(n=2.5, p=0.4).sample((100000,), rng=sd.random.default_rng(7))
>>> sd.mean(x)
3.75436
>>> sd.var(x)
9.4152209904
```

표본의 평균과 분산이 이론값 3.75와 9.375에 가까워요.

## 다른 분포와의 관계

**기하 분포**: `n = 1`이면 첫 성공 전의 실패 횟수라서, 1을 더하면 [기하 분포](/api/stats/geometric/)(시도 횟수)예요.

**이항 분포와 special 함수**: "n + k번 안에 n번 이상 성공한다"와 "n번째 성공 전 실패가 k번 이하다"는 같은 사건이에요. 그래서 cdf는 [이항 분포](/api/stats/binomial/)의 ccdf로 쓸 수 있고, special의 [`nbdtr`](/api/special/nbdtr/)과 같아요. 일반적으로는 정칙화된 불완전 베타 함수 $I_p(n,\ k+1)$이라서 정수가 아닌 `n`에서도 성립해요.

```python
>>> X = sd.stats.NegativeBinomial(n=3, p=0.4)
>>> X.cdf(5)
0.6846054400000001
>>> sd.special.nbdtr(5, 3, 0.4)
0.6846054400000001
>>> sd.stats.Binomial(n=8, p=0.4).ccdf(2)
0.6846054400000001
```

**포아송 분포와 감마 분포**: 평균을 고정하고 `n`을 키우면 [포아송 분포](/api/stats/poisson/)에 가까워져요(포아송 페이지에 예가 있어요). 또 포아송의 평균이 [감마 분포](/api/stats/gamma/)를 따라 대상마다 흔들리면, 그 횟수 전체는 음이항 분포가 돼요. 실수 `n`을 쓰는 과대산포 모형의 근거가 이것이에요.

## 정확도와 범위

- **보장 영역**: `n`이 [0.1, 1e4] 안이고 `p` ≥ 1e-4예요. 여기서 pmf, cdf, ccdf와 그 log, 모멘트는 참값 대비 상대오차 1e-14 이하이고(`entropy`는 오차가 1e-14·max(1, |값|) 이하), 위의 5.3e-28 같은 먼 꼬리에서도 마찬가지예요.
- **분위수**: 늘 위의 정의대로 정수를 찾아요. 목표 확률이 계단 경계에 아주 가깝다면(상대 1e-14 안), 그만큼 움직였을 때의 답인 이웃 정수가 나올 수 있어요.
- **보장 영역 밖**: 값을 계산하지만 정확도는 약속하지 않아요. 구할 수 없는 값은 틀린 숫자 대신 NaN이에요.
  - `n` < 2⁻¹²⁸(약 2.9e-39)이면 pmf, cdf 계열, 분위수, `median`, `entropy`가 NaN이에요. 평균, 분산 같은 모멘트와 `mode`는 값이 있어요.
  - `entropy`는 $nq/p^2$(분산)이 2⁴²(약 4.4e12)를 넘거나 `p` < 2⁻²⁰(약 9.5e-7)이면 NaN이에요.
  - k ≥ 2⁵³(약 9e15)인 곳의 pmf가 무시할 수 없는 크기이면 그곳의 cdf 계열과 분위수가 NaN이에요.

```python
>>> N = sd.stats.NegativeBinomial(n=2**-129, p=0.5)
>>> N.pmf(0)
nan
>>> N.mean()
1.4693679385278594e-39
>>> sd.stats.NegativeBinomial(n=1, p=2**-21).entropy()
nan
>>> sd.stats.NegativeBinomial(n=1, p=2**-21).mean()
2097151.0
```

모든 호출은 정해진 시간 안에 끝나요. 계산 방법은 [이산 분포의 구현](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.nbinom(n, p)`와 같은 정의예요(n번째 성공 전의 실패 횟수, 실수 `n`). numpy의 `Generator.negative_binomial`도 같은 정의로 뽑아요.
- `icdf(0)`은 지지집합의 왼쪽 끝 0이에요. `nbinom.ppf(0, n, p)`는 −1이에요.
- `p = 1`의 왜도와 첨도는 NaN이에요. `nbinom.stats(3, 1.0, moments='sk')`는 둘 다 inf예요.
- `mode()`가 있고 최빈값이 둘이면 NaN이에요. `scipy.stats.nbinom`에는 최빈값 메서드가 없어요.
- 먼 꼬리의 log 값이 있어요. `NegativeBinomial(n=3, p=0.5).logccdf(1e4)`는 −6915.82이고 `nbinom.logsf(1e4, 3, 0.5)`는 −inf예요.
