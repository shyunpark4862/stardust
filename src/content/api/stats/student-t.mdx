## 어떤 분포인가요

**t 분포**(Student t 분포)는 "표본이 적을 때, 표본 평균이 참 평균에서 얼마나 떨어질 수 있나"를 나타내는 분포예요. 정규분포를 따르는 값을 몇 개만 재서 평균을 내면, 그 평균의 흔들림을 재는 잣대인 표준편차도 같은 표본에서 어림해야 해요. 어림한 표준편차에도 오차가 있으니 불확실성이 한 겹 더 쌓이고, 그만큼 극단적인 값이 정규분포보다 자주 나와요. 그래서 모양은 0을 가운데 둔 종 모양인데 **꼬리가 더 두꺼워요.**

꼬리의 두께는 **자유도**(degrees of freedom, `df`)가 정해요. 표본이 `n`개면 보통 자유도는 `n - 1`이에요. 자유도가 커질수록 꼬리가 얇아져서 표준정규분포에 가까워져요.

이런 곳에서 써요.

- **t 검정**: "새 공정의 평균 무게가 목표와 다른가", "두 광고의 평균 체류 시간이 다른가"처럼 평균을 비교할 때의 p값
- **신뢰구간**: "평균은 95% 확률로 이 범위 안"이라고 말할 때 쓰는 임계값
- **회귀분석**: 회귀계수가 0과 다른지 보는 계수별 p값
- **두꺼운 꼬리 모형**: 가끔 큰 값이 튀는 자료(수익률, 측정 이상치)를 정규분포 대신 t 분포로 모형화할 때

```python
>>> import stardust as sd
>>> T = sd.stats.StudentT(df=5)
>>> T
StudentT(df=5)
>>> T.cdf(2.0)
0.9490302605850709
>>> T.icdf(0.975)
2.5705818356363146
```

`T.cdf(2.0)`은 "자유도 5인 t 분포에서 값이 2 이하일 확률"이고, `T.icdf(0.975)`는 거꾸로 "아래쪽 97.5%를 자르는 지점"이에요. 표본 6개로 평균의 95% 신뢰구간을 만들 때 쓰는 바로 그 2.571이에요.

## 만들기와 매개변수

매개변수는 `df` 하나이고, 기본값이 없어서 꼭 이름을 붙여 줘야 해요. 위치로 넘기면 `TypeError`예요.

```python
>>> sd.stats.StudentT(5)
Traceback (most recent call last):
    ...
TypeError: StudentT(): takes no positional arguments but 1 was given
>>> T.df
5
```

`T.df`는 준 값을 그대로 돌려주는 읽기 전용 속성이에요. 정수 5를 줬으면 5 그대로예요(계산은 float64로 해요).

### 정의역

`df`는 0보다 큰 실수예요. 정수가 아니어도 되니, 분산이 서로 다른 두 집단을 비교하는 Welch t 검정에서 나오는 `9.5` 같은 자유도도 그대로 넣으면 돼요. 정의역 밖이면 에러 대신 모든 메서드가 NaN을 돌려줘요.

```python
>>> sd.stats.StudentT(df=9.5).cdf(2.0)
0.9625568211260053
>>> sd.stats.StudentT(df=0).cdf(1.0)
nan
>>> sd.stats.StudentT(df=-1).mean()
nan
>>> sd.stats.StudentT(df=sd.inf).cdf(1.96)
0.9750021048517795
```

`df = inf`는 자유도가 무한대인 극한, 곧 [표준정규분포](/api/stats/normal/)예요. 모든 메서드가 `Normal()`과 마지막 비트까지 같은 값을 내요([자유도가 크면 정규분포](#자유도가-크면-정규분포)). 그래서 자유도를 배열로 다룰 때 "정규분포로 어림하는 경우"를 `sd.inf` 원소 하나로 함께 넣을 수 있어요.

### 배열 매개변수

`df`에 배열을 주면 원소마다 다른 t 분포가 돼요. 메서드에 넣는 값과 [브로드캐스팅](/api/array/broadcasting/)하니, 자유도 셋과 지점 둘의 모든 조합을 한 번에 계산할 수 있어요.

```python
>>> T3 = sd.stats.StudentT(df=sd.asarray([1.0, 5.0, 30.0]))
>>> T3.cdf(2.0)
array([0.8524163823495667, 0.9490302605850709, 0.9726874775185085], dtype=float64)
>>> T3.cdf(sd.asarray([[1.0], [2.0]]))
array([[              0.75, 0.8183912661754387, 0.8373456922869851],
       [0.8524163823495667, 0.9490302605850709, 0.9726874775185085]], dtype=float64)
```

행은 넣은 값(1과 2), 열은 자유도예요. 같은 값에서도 자유도가 클수록 누적확률이 커요. 꼬리가 얇아져서 확률이 가운데로 몰리기 때문이에요.

### 위치와 척도는 없어요

`StudentT`는 0을 가운데 둔 표준형만 있어요. 가운데가 `m`이고 척도가 `s`인 t 분포, 곧 $X = m + sT$가 필요하면 값을 표준화해서 넣어요. 누적확률은 $P(X \le x) = P\!\left(T \le \frac{x-m}{s}\right)$이고, 밀도는 $f_X(x) = f_T\!\left(\frac{x-m}{s}\right) / s$예요.

```python
>>> m, s = 10.0, 2.0
>>> T.cdf((13.0 - m) / s)
0.9030481598787634
>>> T.pdf((13.0 - m) / s) / s
0.062258672323177576
```

## 밀도와 누적분포

자유도가 $\nu$(뉴)인 t 분포의 밀도는 이래요.

$$
f(t) = \frac{\Gamma\!\left(\frac{\nu+1}{2}\right)}{\sqrt{\nu\pi}\;\Gamma\!\left(\frac{\nu}{2}\right)} \left(1 + \frac{t^2}{\nu}\right)^{-\frac{\nu+1}{2}}, \qquad -\infty < t < \infty
$$

$\Gamma$는 [감마 함수](/api/special/gamma/)예요. 앞의 분수는 넓이를 1로 맞추는 상수이고, 모양은 뒤의 $(1 + t^2/\nu)^{-(\nu+1)/2}$가 정해요. 정규분포의 $e^{-t^2/2}$는 꼬리에서 아주 빨리 0으로 가지만, 이 식은 $|t|$의 거듭제곱으로만 줄어서 꼬리가 두꺼워요. 지지집합(값이 나올 수 있는 범위)은 실수 전체예요.

```python
>>> T.support()
(-inf, inf)
>>> T.pdf(0.0)
0.37960668982249446
>>> T.cdf(2.0)
0.9490302605850709
>>> T.ccdf(2.0)
0.050969739414929154
>>> T.iccdf(0.025)
2.570581835636315
```

`ccdf`는 위꼬리 $P(T > t)$이고, `iccdf`는 그 역함수예요. 분포가 0을 중심으로 대칭이라 `T.ccdf(t)`는 `T.cdf(-t)`와 같고, `T.iccdf(p)`는 `-T.icdf(p)`와 같아요. 마지막 자리는 계산 경로가 달라 한 칸쯤 다를 수 있어요.

### t 검정의 p값

t 통계량이 `t`이면 양측 검정의 p값은 양쪽 꼬리의 넓이를 더한 값이에요. 대칭이라 한쪽 꼬리의 두 배예요.

```python
>>> t = 3.1
>>> 2 * sd.stats.StudentT(df=9).ccdf(abs(t))
0.012722455978201945
```

자유도 9(표본 10개)에서 t 통계량이 3.1이면 p값은 약 0.013이에요. 한쪽 방향만 묻는 단측 검정이면 두 배를 하지 않아요.

### 꼬리는 `ccdf`와 log 메서드로

위꼬리 확률을 `1 - cdf`로 만들면 안 돼요. `cdf`가 1에 아주 가까우면 1에서 빼는 순간 자릿수가 사라져요. `ccdf`는 위꼬리를 직접 계산해서 꼬리 끝까지 앞자리 14자리 정도가 맞아요.

```python
>>> T10 = sd.stats.StudentT(df=10)
>>> 1 - T10.cdf(20.0)
1.0730311084117261e-09
>>> T10.ccdf(20.0)
1.073031158602126e-09
>>> 1 - T10.cdf(1000.0)
0.0
>>> T10.ccdf(1000.0)
1.2304123550866355e-26
```

확률이 float64가 담을 수 있는 가장 작은 수(약 5e-324)보다 작아지면 `ccdf`도 0이 돼요. 그때는 확률의 로그를 직접 주는 `logccdf`, `logcdf`를 써요. 밀도도 마찬가지로 `logpdf`가 있어요.

```python
>>> T10.ccdf(1e100)
0.0
>>> T10.logccdf(1e100)
-2293.167357427724
>>> T.logcdf(-1e300)
-3451.627383255255
```

역함수도 꼬리 끝까지 가요. `icdf(1e-300)`처럼 아주 작은 확률의 분위수, 그리고 로그 확률을 받는 `ilogcdf`도 있어요.

```python
>>> T.icdf(1e-300)
-1.5683925590993378e+60
>>> T.ilogcdf(-1000.0)
-1.133316349017543e+87
```

### 끝점과 정의역 밖

`icdf(0)`과 `icdf(1)`은 지지집합의 양 끝인 `-inf`, `inf`예요. 확률이 아닌 값은 NaN이에요. `ilogcdf`는 0보다 큰 로그 확률이 NaN이에요.

```python
>>> T.icdf(0.0), T.icdf(1.0)
(-inf, inf)
>>> T.icdf(1.5)
nan
>>> T.ilogcdf(0.5)
nan
```

`cdf`, `ccdf`, `icdf` 등 메서드의 공통 의미와 `out=` 인자는 [분포 메서드 한눈에 보기](/api/stats/methods/)에 모아 두었어요.

## 요약값

| 요약값 | 값 | 조건 |
|---|---|---|
| `mean()` | $0$ | $\nu > 1$, 그 밖은 NaN |
| `variance()` | $\dfrac{\nu}{\nu-2}$ | $\nu > 2$, $1 < \nu \le 2$이면 inf, $\nu \le 1$이면 NaN |
| `skewness()` | $0$ | $\nu > 3$, 그 밖은 NaN |
| `kurtosis()` | $\dfrac{6}{\nu-4}$ | $\nu > 4$, $2 < \nu \le 4$이면 inf, $\nu \le 2$이면 NaN |
| `median()`, `mode()` | $0$ | |
| `entropy()` | $\frac{\nu+1}{2}\left[\psi\!\left(\frac{\nu+1}{2}\right) - \psi\!\left(\frac{\nu}{2}\right)\right] + \ln\!\left(\sqrt{\nu}\,B\!\left(\frac{\nu}{2}, \frac12\right)\right)$ | |

$\psi$는 [디감마 함수](/api/special/digamma/), $B$는 [베타 함수](/api/special/beta/)예요. `kurtosis()`는 정규분포를 0으로 두는 **초과 첨도**예요. `standard_deviation()`은 분산의 제곱근이고, `entropy()`는 미분 엔트로피(단위 nat)예요.

꼬리가 두꺼운 t 분포는 자유도가 작으면 모멘트가 차례로 사라져요. 자유도를 배열로 주면 한눈에 볼 수 있어요.

```python
>>> Ts = sd.stats.StudentT(df=sd.asarray([0.5, 1.0, 1.5, 2.5, 3.5, 5.0]))
>>> Ts.mean()
array([nan, nan, 0.0, 0.0, 0.0, 0.0], dtype=float64)
>>> Ts.variance()
array([               nan,                nan,                inf,
                      5.0, 2.3333333333333335, 1.6666666666666667], dtype=float64)
>>> Ts.skewness()
array([nan, nan, nan, nan, 0.0, 0.0], dtype=float64)
>>> Ts.kurtosis()
array([nan, nan, nan, inf, inf, 6.0], dtype=float64)
```

NaN과 inf는 뜻이 달라요.

- **NaN은 "정의되지 않는다"예요.** 자유도가 1 이하이면 꼬리가 너무 두꺼워서 양쪽 꼬리의 적분이 각각 $+\infty$와 $-\infty$로 가요. 둘을 더한 값이 정해지지 않으니 평균은 NaN이에요. 대칭이라 0일 것 같지만, 표본을 아무리 많이 모아도 표본 평균이 0으로 모이지 않아요. 왜도도 같은 이유로 $\nu \le 3$에서 NaN이에요.
- **inf는 "무한대로 발산한다"예요.** $1 < \nu \le 2$이면 평균은 0으로 정해지지만, 제곱의 평균인 분산은 양수만 더하므로 $+\infty$예요. 첨도도 $2 < \nu \le 4$에서 같은 이유로 inf예요.
- 분산이 유한하지 않으면 분산으로 나누는 왜도와 첨도는 NaN이에요.

```python
>>> T.standard_deviation()
1.2909944487358056
>>> T.median(), T.mode()
(0.0, 0.0)
>>> T.entropy()
1.627502672414396
```

## 표본

`sample`은 t 분포를 따르는 난수를 뽑아요. 난수 생성기 `rng`를 꼭 키워드로 줘야 해요. 같은 시드면 언제나 같은 값이 나와요.

```python
>>> rng = sd.random.default_rng(42)
>>> T.sample(3, rng=rng)
array([-0.7054203224711874, 0.5445955245963292, -1.2082316964797786], dtype=float64)
```

결과의 모양은 `shape` 뒤에 매개변수의 모양이 붙은 것이에요. 모양, 재현성, 스레드와의 관계는 [표본 뽑기](/api/stats/sample/)에서 설명해요.

## 다른 분포와의 관계

### 정규분포와 카이제곱에서 만들기

t 분포는 정의부터 다른 분포 둘의 조합이에요. $Z$가 표준정규분포, $V$가 자유도 $\nu$인 [카이제곱 분포](/api/stats/chi-squared/)를 따르고 서로 독립이면

$$
T = \frac{Z}{\sqrt{V/\nu}}
$$

는 자유도 $\nu$인 t 분포를 따라요. 표본 평균을 표본 표준편차로 나눈 t 통계량이 바로 이 꼴이에요. 표본으로 확인해 볼게요.

```python
>>> rng = sd.random.default_rng(0)
>>> z = sd.stats.Normal().sample(100000, rng=rng)
>>> v = sd.stats.ChiSquared(df=5).sample(100000, rng=rng)
>>> t = z / sd.sqrt(v / 5)
>>> sd.quantile(t, 0.975)
2.568596743774048
>>> T.icdf(0.975)
2.5705818356363146
```

표본 10만 개의 97.5% 분위수가 `icdf(0.975)`와 소수 둘째 자리까지 맞아요.

### 자유도 1은 Cauchy 분포

`df = 1`인 t 분포는 [Cauchy 분포](/api/stats/cauchy/)와 같아요. 평균이 정의되지 않는 대표적인 분포예요.

```python
>>> x = sd.asarray([0.5, 2.0, 7.0])
>>> sd.stats.StudentT(df=1).cdf(x)
array([0.6475836176504333, 0.8524163823495667, 0.9548327646991335], dtype=float64)
>>> sd.stats.Cauchy().cdf(x)
array([0.6475836176504333, 0.8524163823495667, 0.9548327646991335], dtype=float64)
```

### 자유도가 크면 정규분포

자유도가 커질수록 표준정규분포에 가까워지고, 자유도가 inf인 극한은 표준정규분포와 똑같아요.

```python
>>> sd.stats.StudentT(df=30).cdf(1.96)
0.9703288435519748
>>> sd.stats.StudentT(df=1e6).cdf(1.96)
0.9750019662073651
>>> sd.stats.StudentT(df=sd.inf).cdf(1.96)
0.9750021048517795
>>> sd.stats.Normal().cdf(1.96)
0.9750021048517795
>>> Ti = sd.stats.StudentT(df=sd.inf)
>>> Ti.icdf(0.975) == sd.stats.Normal().icdf(0.975), Ti.variance(), Ti.kurtosis()
(True, 1.0, 0.0)
```

자유도 30에서도 정규분포와 0.005쯤 차이가 나요. "표본이 30개 넘으면 정규분포를 써도 된다"는 말은 대략적인 기준이에요. 자유도를 알면 `StudentT`를 그대로 쓰는 편이 정확해요.

### t의 제곱은 F 분포

$T$가 자유도 $\nu$인 t 분포를 따르면 $T^2$은 자유도 $(1, \nu)$인 [F 분포](/api/stats/f/)를 따라요. 그래서 양측 p값은 F 분포의 위꼬리로도 구할 수 있어요.

```python
>>> 2 * sd.stats.StudentT(df=7).ccdf(2.5)
0.04099221858575289
>>> sd.stats.F(dfn=1, dfd=7).ccdf(2.5 ** 2)
0.04099221858575289
```

### 비중심 t 분포

가운데가 0에서 밀려난 [비중심 t 분포](/api/stats/noncentral-t/)는 효과가 있을 때 t 통계량이 따르는 분포예요(검정력 계산). 비중심 모수 `nc`가 0이면 `StudentT`와 같아요.

```python
>>> sd.stats.NoncentralT(df=5, nc=0.0).cdf(2.0)
0.9490302605850709
```

### 함수 하나만 필요하면

누적확률이나 분위수 하나만 필요하면 [`sd.special.stdtr`, `stdtrit`](/api/special/stdtr/)도 같은 값을 줘요. 분포 객체를 만들지 않아도 되고, 자유도와 값을 함께 배열로 넘길 수 있어요.

```python
>>> sd.special.stdtr(5, 2.0)
0.9490302605850709
>>> sd.special.stdtrit(5, 0.975)
2.5705818356363146
```

## 정확도와 범위

- **보장 영역**: 자유도 $0 < \nu \le 10^6$에서 모든 메서드가 참값 대비 상대오차 1e-14 이하예요. 꼬리의 아주 작은 확률(`1.23e-26` 같은 값)에서도 마찬가지예요. `logpdf`와 `entropy`는 값이 0을 지나갈 수 있어서 오차를 $10^{-14}\cdot\max(1, |\text{값}|)$로 재요. 역함수는 "입력 확률이 마지막 자리만큼 흔들릴 때 결과가 흔들리는 배율"만큼 더 허용해요. 자세한 계약은 [stats의 기본](/api/stats/basics/)에 있어요.
- **잰 값**: 보장 영역 안에서 메서드별로 잰 최대 오차는 `cdf`·`ccdf`가 1.5e-15, 가장 큰 `entropy`가 8.1e-15예요.
- **보장 영역 밖**: 자유도가 1e6보다 커도 값을 계산하지만 정확도를 약속하지는 않아요. 그래도 잰 점은 모두 1e-14 안이었어요. 자유도가 1e5 이상이고 확률이 $2^{-1000}$(약 9.3e-302)보다 작은 역함수의 깊은 꼬리도 `icdf`·`iccdf`가 3.2e-16, `ilogcdf`·`ilogccdf`가 2.8e-16이에요.

값을 구할 수 없는 곳에서는 엉뚱한 값을 내지 않고 NaN을 돌려줘요. 모든 호출은 정해진 시간 안에 끝나요.

- `df`가 $2^{-1021}$(약 4.5e-308)보다 작으면 `pdf`, `cdf` 계열, 역함수, `median`, `entropy`, 표본이 모두 NaN이에요. 자유도의 절반을 float64로 정확히 나타낼 수 없어요. 서브노멀 수(약 2.2e-308 미만)뿐 아니라 가장 작은 정규 float64 $2^{-1022}$도 여기에 들어요.

  ```python
  >>> Tt = sd.stats.StudentT(df=2**-1022)
  >>> Tt.cdf(1.0), Tt.median(), Tt.entropy()
  (nan, nan, nan)
  >>> Tt.sample(rng=sd.random.default_rng(0))
  nan
  >>> sd.stats.StudentT(df=2**-1021).cdf(1.0)
  0.5
  ```

- 확률이 $2^{-1000}$보다 작은 깊은 꼬리의 역함수가 정해진 반복 안에 수렴하지 않으면 NaN이에요.
- 자유도가 $[10^{-3}, 10^6]$ 밖이면 역함수(`icdf`, `iccdf`, `ilogcdf`, `ilogccdf`)는 구한 근을 다시 넣어 확률이 맞는지 확인하고, 맞을 때만 값을 내요. 맞지 않으면 NaN이에요.
- 근이 float64 범위를 넘으면 극한값이에요. 자유도가 아주 작으면 꼬리가 극단적으로 두꺼워서 1% 분위수도 float64 범위 밖이에요.

```python
>>> T4 = sd.stats.StudentT(df=1e-4)
>>> T4.cdf(-1e10)
0.49858579738938325
>>> T4.icdf(0.01)
-inf
```

자유도 1e-4에서는 값이 $-10^{10}$ 이하일 확률도 거의 절반이라, 아래 1%를 자르는 지점은 float64가 나타낼 수 없을 만큼 멀어요.

계산 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에서 설명해요.

## scipy를 아는 분께

- `scipy.stats.t`에 해당해요. 메서드 이름은 scipy의 새 분포 API를 따라요(`sf` → `ccdf`, `ppf` → `icdf`, `isf` → `iccdf`, `logsf` → `logccdf`).
- `loc`, `scale`이 없어요. 위치와 척도가 필요하면 `(x - m) / s`로 표준화해요.
- `df`는 키워드로만 받아요. `df = inf`는 scipy처럼 표준정규분포예요.
- `df ≤ 1`의 `mean()`은 NaN이에요(scipy `t.mean(1)`은 inf).
- `df`가 $2^{-1021}$보다 작으면 NaN이에요. scipy는 값을 내요: `t.cdf(1, 2**-1022)`는 0.5, `t.entropy(2**-1022)`는 4.49e307이에요.
- `kurtosis()`는 초과 첨도예요. scipy의 `t.stats(df, moments='k')`와 같고, 새 API의 `kurtosis()` 기본값(초과하지 않은 첨도, df = 5에서 9.0)보다 3 작아요.
- 꼬리에서 scipy가 0이나 `-inf`를 내는 곳에서 값을 내요. 예: `StudentT(df=10).logccdf(1e100)`은 −2293.17이고 scipy `t.logsf(1e100, 10)`은 `-inf`예요. `StudentT(df=3).logpdf(1e200)`은 −1840.87이고 scipy는 `-inf`예요.
- `StudentT(df=5).icdf(1e-300)`은 −1.57e60이고, scipy `t.ppf(1e-300, 5)`는 `inf`(부호까지 틀린 값)예요.
- `sample`은 `rng`를 꼭 받아요. 값은 numpy·scipy와 달라요.
