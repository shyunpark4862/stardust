## 어떤 분포인가요

**로그정규분포**(log-normal distribution)는 로그를 취하면 정규분포가 되는 양수 값의 분포예요. 값 X 자체가 아니라 log X가 종 모양으로 퍼져 있어요.

이런 분포는 여러 요인이 더해지지 않고 곱해질 때 나와요. 정규분포가 작은 효과들이 더해진 결과라면, 로그정규분포는 작은 효과들이 곱해진 결과예요. 곱은 로그를 취하면 합이 되니까요.

- 소득과 자산: 해마다 몇 퍼센트씩 오르내리는 것이 쌓인 값
- 주가: 하루하루의 수익률이 곱해진 미래 가격
- 입자와 결정의 크기: 부서지고 자라는 과정이 비율로 일어나는 경우
- 응답 시간, 잠복기, 수리 시간: 대부분은 짧고 가끔 아주 긴 값

모양은 0보다 큰 쪽에만 있고, 오른쪽으로 꼬리가 길게 늘어져요. 그래서 평균이 중앙값보다 커요. "평균 소득"이 "보통 사람의 소득"보다 높게 나오는 것과 같은 이유예요.

```python
>>> import stardust as sd
>>> X = sd.stats.LogNormal(mu=1.0, sigma=0.5)
>>> X.median()
2.718281828459045
>>> X.mean()
3.080216848918031
>>> X.mode()
2.117000016612675
```

중앙값은 $e^{\mu} = e$이고, 평균은 그보다 크고, 밀도가 가장 높은 점(최빈값)은 그보다 작아요. 오른쪽 꼬리가 긴 분포에서 늘 보이는 순서예요.

## 만들기와 매개변수

매개변수는 키워드로만 줘요. 둘 다 기본값이 있어서 `sd.stats.LogNormal()`은 log X가 표준정규분포인 로그정규분포예요.

| 매개변수 | 뜻 | 정의역 | 기본값 |
|---|---|---|---|
| `mu` | log X의 평균 | 유한한 실수 | 0.0 |
| `sigma` | log X의 표준편차 | 0보다 큰 유한한 실수 | 1.0 |

<Callout type="warn" title="mu와 sigma는 X의 평균과 표준편차가 아니에요">
`mu`와 `sigma`는 밑에 있는 정규분포, 곧 log X의 평균과 표준편차예요. X의 평균은 $e^{\mu + \sigma^2/2}$이고, `mu`는 X의 중앙값 $e^{\mu}$의 로그예요. "평균 100, 표준편차 20인 로그정규"를 원한다고 `LogNormal(mu=100, sigma=20)`을 쓰면 중앙값이 $e^{100} \approx 2.7 \times 10^{43}$인 전혀 다른 분포가 돼요.
</Callout>

X의 평균 m과 표준편차 s를 알고 있다면 이렇게 바꿔요.

$$
\sigma^2 = \log\!\left(1 + \frac{s^2}{m^2}\right), \qquad \mu = \log m - \frac{\sigma^2}{2}
$$

```python
>>> import math
>>> m, s = 100.0, 20.0
>>> sigma = math.sqrt(math.log1p((s / m) ** 2))
>>> mu = math.log(m) - sigma ** 2 / 2
>>> mu, sigma
(4.5855598294114515, 0.19804220043536505)
>>> X = sd.stats.LogNormal(mu=mu, sigma=sigma)
>>> X.mean(), X.standard_deviation()
(100.00000000000007, 20.000000000000018)
```

마지막 줄의 끝자리는 바꾸는 식의 반올림에서 와요. 분포는 받은 `mu`, `sigma` 그대로 정확하게 계산해요.

매개변수는 읽기 전용 속성으로 그대로 돌려받아요. 배열로 주면 메서드가 그 모양으로 원소별로 계산하고, 입력과도 [브로드캐스트](/api/array/broadcasting/)해요.

```python
>>> X = sd.stats.LogNormal(mu=sd.asarray([0.0, 1.0, 2.0]))
>>> X
LogNormal(mu=array([0.0, 1.0, 2.0], dtype=float64), sigma=1.0)
>>> X.sigma
1.0
>>> X.median()
array([              1.0, 2.718281828459045,  7.38905609893065], dtype=float64)
>>> X.cdf(sd.asarray([[1.0], [10.0]]))
array([[                 0.5,  0.15865525393145707, 0.022750131948179212],
       [  0.9893489006582998,   0.9036417751182644,   0.6188969618546742]], dtype=float64)
```

정의역 밖의 매개변수(0 이하의 `sigma`, 무한대나 NaN인 `mu`)는 에러가 아니라, 그 원소의 모든 결과가 NaN이에요. 배열의 다른 원소는 그대로 계산돼요.

```python
>>> sd.stats.LogNormal(mu=sd.asarray([0.0, 0.0, 0.0, float('nan')]),
...                    sigma=sd.asarray([1.0, 0.0, -1.0, 1.0])).median()
array([1.0, nan, nan, nan], dtype=float64)
```

## 밀도와 누적분포

지지집합(값이 나올 수 있는 범위)은 $x > 0$이에요. $z = (\log x - \mu)/\sigma$로 두면

$$
f(x) = \frac{1}{x\,\sigma\sqrt{2\pi}} \exp\!\left(-\frac{z^2}{2}\right), \qquad
F(x) = \Phi(z), \qquad
F^{-1}(p) = \exp\!\big(\mu + \sigma\,\Phi^{-1}(p)\big)
$$

예요. $\Phi$는 표준정규분포의 누적분포함수([ndtr](/api/special/ndtr/))예요. 누적확률은 log x의 정규 누적확률과 같고, 분위수는 정규분포의 분위수에 지수를 씌운 것이에요. 밀도에 붙은 $1/x$는 로그 눈금을 보통 눈금으로 바꿀 때 생기는 인수예요.

```python
>>> X = sd.stats.LogNormal(mu=1.0, sigma=0.5)
>>> X.pdf(2.0)
0.3304645659834839
>>> X.cdf(2.0), X.ccdf(2.0)
(0.26970493073490953, 0.7302950692650905)
>>> X.icdf(0.9)
5.159170355622592
>>> X.iccdf(0.1)
5.159170355622592
```

`icdf(0.9)`는 "값의 90%가 이 아래"인 점, `iccdf(0.1)`은 "값의 10%가 이 위"인 점이라 같은 점이에요. 각 메서드의 공통 의미는 [분포의 메서드](/api/stats/methods/)에 있어요.

0 이하에서는 밀도가 0, 누적확률이 0이에요. `icdf`는 0에서 0, 1에서 inf이고 [0, 1] 밖이면 NaN이에요.

```python
>>> X.cdf(sd.asarray([-1.0, 0.0, 1.0, 10.0]))
array([                 0.0,                  0.0, 0.022750131948179212,
           0.99540856824253], dtype=float64)
>>> Y = sd.stats.LogNormal()
>>> Y.pdf(0.0), Y.logpdf(0.0)
(0.0, -inf)
>>> Y.icdf(0.0), Y.icdf(1.0), Y.icdf(-0.1)
(0.0, inf, nan)
>>> Y.icdf(sd.asarray([0.025, 0.5, 0.975]))
array([0.14086349409321752,                 1.0,   7.099071384231331], dtype=float64)
```

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()` | $e^{\mu + \sigma^2/2}$ |
| `variance()` | $(e^{\sigma^2} - 1)\,e^{2\mu + \sigma^2}$ |
| `standard_deviation()` | $\sqrt{e^{\sigma^2} - 1}\;e^{\mu + \sigma^2/2}$ |
| `skewness()` | $(e^{\sigma^2} + 2)\sqrt{e^{\sigma^2} - 1}$ |
| `kurtosis()` | $e^{4\sigma^2} + 2e^{3\sigma^2} + 3e^{2\sigma^2} - 6$ (초과 첨도) |
| `median()` | $e^{\mu}$ |
| `mode()` | $e^{\mu - \sigma^2}$ |
| `entropy()` | $\mu + \tfrac12 + \log(\sigma\sqrt{2\pi})$ |
| `support()` | `(0.0, inf)` |

왜도와 첨도는 `sigma`에만 달려 있어요. `mu`를 바꾸는 것은 X에 상수 $e^{\mu}$를 곱하는 것이라 모양은 그대로이기 때문이에요. 반대로 엔트로피는 정규분포와 달리 `mu`에 달려 있어요. 값 전체를 $e^{\mu}$배로 늘이면 퍼진 정도도 그만큼 커지니까요.

```python
>>> X = sd.stats.LogNormal()
>>> X.mean(), X.variance()
(1.6487212707001282, 4.670774270471605)
>>> X.skewness(), X.kurtosis()
(6.184877138632555, 110.93639217631153)
>>> X.entropy()
1.4189385332046727
>>> sd.stats.LogNormal(mu=2.0).entropy()
3.4189385332046727
>>> sd.stats.LogNormal(sigma=sd.asarray([0.25, 0.5, 1.0, 2.0])).skewness()
array([ 0.778251635797484, 1.7501896550697182,  6.184877138632555,
         414.359343300147], dtype=float64)
```

`kurtosis()`는 초과 첨도예요. 정규분포가 0이 되도록 3을 뺀 값이라, `sigma = 1`에서도 이미 110을 넘어요.

<Callout type="warn" title="sigma가 크면 평균이 '보통 값'을 말해 주지 않아요">
`sigma`가 크면 평균이 아주 드문 큰 값에 끌려가요. `LogNormal(sigma=3)`의 평균은 약 90인데 중앙값은 1이고, 값이 평균을 넘을 확률은 7%도 안 돼요. 표본 평균도 이 드문 값을 만나기 전까지는 참 평균보다 한참 작게 나와요.

```python
>>> X = sd.stats.LogNormal(sigma=3.0)
>>> X.mean(), X.median()
(90.01713130052181, 1.0)
>>> X.ccdf(X.mean())
0.06680720126885807
>>> rng = sd.random.default_rng(3)
>>> float(X.sample((100,), rng=rng).mean())
18.104948930676596
```

표본 100개의 평균은 18 남짓이에요. 이런 자료는 평균보다 중앙값이나 log 값의 평균을 보는 편이 안정적이에요.
</Callout>

`sigma`가 커서 값이 float64를 넘으면 모멘트는 inf예요. `sigma = 40`이면 평균 $e^{800}$이 float64의 최댓값(약 $e^{709.8}$)을 넘어요. 이때도 중앙값은 1이고, 최빈값 $e^{-1600}$은 0으로 내려가요.

```python
>>> Z = sd.stats.LogNormal(sigma=40.0)
>>> Z.mean(), Z.variance(), Z.median(), Z.mode()
(inf, inf, 1.0, 0.0)
```

## 꼬리는 얼마나 두꺼운가요

로그정규분포의 꼬리는 지수분포 같은 얇은 꼬리와 거듭제곱으로 줄어드는 두꺼운 꼬리 사이에 있어서 헷갈려요.

- 지수분포보다 두꺼워요. 위꼬리 확률이 대략 $e^{-(\log x)^2/(2\sigma^2)}$로 줄어서, $e^{-x/\theta}$처럼 줄어드는 어떤 지수분포보다도 결국 느리게 줄어요. 그래서 모멘트생성함수 $E[e^{tX}]$는 $t > 0$이면 무한대예요.
- 거듭제곱 꼬리보다는 얇아요. [파레토 분포](/api/stats/pareto/)처럼 $x^{-b}$로 줄어드는 꼬리보다는 빨리 줄어서, 모든 차수의 모멘트 $E[X^k] = e^{k\mu + k^2\sigma^2/2}$가 유한해요.

다만 $E[X^k]$가 $k^2$에 따라 지수적으로 커지므로, 모멘트가 유한해도 `sigma`가 1을 넘으면 첨도처럼 높은 차수의 값은 금세 아주 커져요.

평균이 같은 지수분포와 비교하면 꼬리 차이가 뚜렷해요.

```python
>>> L = sd.stats.LogNormal()
>>> E = sd.stats.Exponential(scale=L.mean())
>>> L.ccdf(100.0), E.ccdf(100.0)
(2.0606433959717198e-06, 4.55730545361618e-27)
>>> L.ccdf(1000.0), E.ccdf(1000.0)
(2.4619120188155e-12, 3.8643938445313557e-264)
```

평균이 1.65로 같아도, 1000을 넘을 확률은 로그정규 쪽이 $10^{250}$배 넘게 커요.

## 표본

`sample`은 생성기 `rng`를 꼭 받아요. 모양과 재현 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(7)
>>> sd.stats.LogNormal(mu=3.0, sigma=0.4).sample((4,), rng=rng)
array([38.800772474377546,  8.946136091187258, 10.845638821199852,
        25.67123479317426], dtype=float64)
```

## 다른 분포와의 관계

**정규분포**: X가 `LogNormal(mu, sigma)`이면 log X는 [`Normal(mu=mu, sigma=sigma)`](/api/stats/normal/)예요. 그래서 누적확률은 log x에서의 정규 누적확률이고, 분위수는 정규 분위수의 지수예요.

```python
>>> X = sd.stats.LogNormal(mu=1.0, sigma=0.5)
>>> N = sd.stats.Normal(mu=1.0, sigma=0.5)
>>> X.cdf(4.0), N.cdf(math.log(4.0))
(0.7801170895122241, 0.780117089512224)
>>> X.icdf(0.9), math.exp(N.icdf(0.9))
(5.159170355622592, 5.159170355622593)
```

끝자리 차이는 `math.log`와 `math.exp`의 반올림이에요. 로그정규 쪽은 log와 exp를 거치며 생기는 오차까지 줄여서 계산해요.

**곱과 역수**: log를 취하면 곱은 합이 되므로, 로그정규는 곱셈에 대해 닫혀 있어요.

- 상수배: $aX$($a > 0$)는 `LogNormal(mu=mu + log(a), sigma=sigma)`
- 역수: $1/X$는 `LogNormal(mu=-mu, sigma=sigma)`
- 독립인 두 로그정규의 곱: `mu`끼리 더하고 `sigma`는 $\sqrt{\sigma_1^2 + \sigma_2^2}$

```python
>>> A = sd.stats.LogNormal(mu=0.5, sigma=0.8)
>>> B = sd.stats.LogNormal(mu=-0.5, sigma=0.8)
>>> A.ccdf(1 / 3.0), B.cdf(3.0)
(0.9771560506084528, 0.9771560506084528)
```

$P(X > 1/3) = P(1/X < 3)$이라 두 값이 같아요.

**감마 분포, 베이불분포**: 셋 다 양수 값을 다루는 오른쪽으로 치우친 분포라 자료에 맞출 때 자주 비교해요. 아주 먼 꼬리에서는 로그정규가 [감마](/api/stats/gamma/)보다도, 어떤 `c`의 [베이불](/api/stats/weibull/)보다도 두꺼워요. 베이불의 꼬리는 $e^{-(x/\text{scale})^c}$로 줄고, $x^c$는 결국 $(\log x)^2$보다 빨리 커지기 때문이에요.

## 정확도와 범위

로그정규분포는 닫힌 꼴이 있는 분포라 매개변수와 입력의 정의역 전체가 보장 영역이에요.

- `pdf`, `cdf`, `ccdf`와 그 log, 모멘트, `median`, `mode`는 참값 대비 상대오차 $10^{-14}$ 안이에요. 꼬리에서도 마찬가지예요. `ccdf`는 1 − `cdf`로 만들지 않아서 위꼬리의 아주 작은 확률도 자릿수를 잃지 않아요.
- `logpdf`와 `entropy`는 값이 0을 지나므로 오차가 $10^{-14} \cdot \max(1, |값|)$ 안이에요.
- `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`는 결과의 상대오차가 $10^{-14} \cdot \max(1, \kappa)$ 안이에요. $\kappa$는 입력이 조금 변할 때 결과가 얼마나 크게 변하는지 나타내는 조건수예요.
- 결과가 float64 범위를 넘으면 극한값이에요. 밀도와 확률은 0, 분위수와 모멘트는 inf나 0이에요(`LogNormal(mu=1e300).median()`은 inf).
- NaN은 매개변수가 정의역 밖이거나 NaN일 때, 입력이 NaN일 때, `icdf`·`iccdf`의 확률이 [0, 1] 밖일 때, `ilogcdf`·`ilogccdf`의 입력이 양수일 때뿐이에요.

꼬리에서 상대 정확도를 지키는 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에 있어요.

## scipy를 아는 분께

- scipy의 `lognorm(s, loc=0, scale)`과는 `s = sigma`, `scale = exp(mu)`로 대응해요. `loc`는 없어요. 이름이 `s`와 `scale`이라 헷갈리지만 뜻은 같아요.

  ```python
  >>> import scipy.stats as ss
  >>> sd.stats.LogNormal(mu=1.0, sigma=0.5).pdf(3.0)
  0.26083887270192596
  >>> float(ss.lognorm.pdf(3.0, 0.5, scale=math.exp(1.0)))
  0.260838872701926
  ```

- `kurtosis()`는 초과 첨도라 고전형 `lognorm.stats(s, moments='k')`와 같아요. `make_distribution`으로 만든 scipy 신형 분포의 `kurtosis()`는 기본값이 보통 첨도라 3만큼 커요(`sigma = 1`에서 113.94).
- 깊은 꼬리에서 scipy는 0을 내거나 자릿수를 잃는 곳이 있어요. `scale`이 아주 작거나 크면 x/scale을 거치며 오버플로나 언더플로가 나기 때문이에요.

  ```python
  >>> sd.stats.LogNormal(mu=-300.0, sigma=10.0).pdf(1.0)
  1.4736461348785474e-197
  >>> float(ss.lognorm.pdf(1.0, 10.0, scale=math.exp(-300.0)))
  0.0
  ```
