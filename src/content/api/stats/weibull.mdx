## 어떤 분포인가요

**베이불 분포**(Weibull distribution)는 0 이상인 값, 특히 **무언가가 고장 나거나 끝날 때까지의 시간**을 나타내는 분포예요. 신뢰성 공학에서 가장 많이 쓰는 수명 분포예요.

베이불 분포의 핵심은 **고장률**(hazard rate)이에요. 고장률은 "지금까지 멀쩡했던 것이 바로 다음 순간 고장 날 비율"로, $h(x) = f(x) / P(X > x)$예요. 베이불에서는 이것이 $x^{c-1}$에 비례해요. 그래서 모양 `c` 하나로 세 가지 상황을 나타내요.

- **`c < 1`, 고장률이 줄어요**: 초기 불량. 처음에 결함 있는 것들이 먼저 고장 나고, 살아남은 것은 점점 튼튼해 보여요.
- **`c = 1`, 고장률이 일정해요**: 우발 고장. 나이와 상관없이 고장 위험이 같아요. 이때는 [지수분포](/api/stats/exponential/)예요.
- **`c > 1`, 고장률이 늘어요**: 마모 고장. 오래 쓸수록 고장 나기 쉬워요.

그 밖에도 이런 곳에 써요.

- **풍속**: 풍력 발전 입지를 평가할 때 풍속 분포로 흔히 c ≈ 2인 베이불을 써요.
- **재료의 강도**: 사슬이 가장 약한 고리에서 끊어지듯, 많은 부분 중 가장 약한 곳에서 깨지는 강도. 베이불 분포는 아래가 0으로 막힌 값들의 **최솟값**이 따르는 극한 분포예요.
- **입자 크기, 강수량, 생존 시간** 같은 양수 자료를 맞출 때 감마·로그정규와 함께 후보로 써요.

```python
>>> import stardust as sd
>>> X = sd.stats.Weibull(c=1.5, scale=1000.0)
>>> X.mean(), X.median()
(902.7452929509342, 783.2197687746514)
>>> X.icdf(0.1)
223.0755256369171
```

모양 1.5, 척도 1000시간인 부품이라면 평균 수명은 약 903시간, 절반은 783시간 안에, 10%는 223시간 안에 고장 나요.

## 만들기와 매개변수

| 매개변수 | 뜻 | 정의역 | 기본값 |
|---|---|---|---|
| `c` | 모양(고장률이 늘어나는 정도) | 0보다 큰 유한한 실수 | 없음(꼭 줘야 해요) |
| `scale` | 척도(특성 수명) | 0보다 큰 유한한 실수 | 1.0 |

`c`는 기본값이 없어서 `sd.stats.Weibull()`은 `TypeError`예요. `scale`만 기본값 1이 있어요.

<Callout title="c와 scale은 교과서마다 이름이 달라요">
같은 두 매개변수를 교과서와 분야마다 다르게 불러요. 모양은 $k$, $\beta$, $m$으로, 척도는 $\lambda$, $\eta$, $\alpha$로 쓰기도 해요. 어느 쪽이든 누적분포가 $1 - e^{-(x/\lambda)^k}$ 꼴이면 `c = k`, `scale = λ`예요.

조심할 것은 **비율로 쓰는 꼴**이에요. $1 - e^{-(\lambda x)^k}$나 $1 - e^{-\lambda x^k}$처럼 쓰는 책도 있는데, 이때의 $\lambda$는 척도가 아니에요. 앞의 꼴이면 `scale = 1/λ`, 뒤의 꼴이면 `scale = λ ** (-1 / k)`예요. 여기서는 언제나 척도 `scale`을 받아요.
</Callout>

`scale`은 **특성 수명**이라는 뜻이 있어요. `c`가 무엇이든 $P(X \le \text{scale}) = 1 - e^{-1} \approx 0.632$예요. 곧 `scale`은 전체의 63.2%가 고장 나는 시점이에요.

```python
>>> sd.stats.Weibull(c=sd.asarray([0.5, 1.0, 2.0, 5.0])).cdf(1.0)
array([0.6321205588285577, 0.6321205588285577, 0.6321205588285577,
       0.6321205588285577], dtype=float64)
>>> X.cdf(1000.0)
0.6321205588285577
```

매개변수는 읽기 전용 속성 `X.c`, `X.scale`로 돌려받아요. 배열로 주면 원소별로 계산하고 입력과도 [브로드캐스트](/api/array/broadcasting/)해요. 정의역 밖의 원소(0 이하이거나 무한대이거나 NaN인 `c`나 `scale`)는 에러 없이 NaN이에요.

```python
>>> sd.stats.Weibull(c=sd.asarray([0.5, 0.0, -1.0, float('inf')])).mean()
array([2.0, nan, nan, nan], dtype=float64)
```

## 밀도와 누적분포

지지집합은 $x \ge 0$이에요. $t = (x/\text{scale})^c$로 두면

$$
f(x) = \frac{c}{x}\, t\, e^{-t}, \qquad
P(X > x) = e^{-t}, \qquad
F(x) = 1 - e^{-t}, \qquad
F^{-1}(p) = \text{scale}\cdot\big(-\log(1 - p)\big)^{1/c}
$$

예요. 고장률은 $h(x) = f(x) / P(X > x) = c\,t / x = (c/\text{scale})(x/\text{scale})^{c-1}$이에요.

```python
>>> W = sd.stats.Weibull(c=2.0)
>>> W.pdf(1.0), W.cdf(1.0), W.ccdf(1.0)
(0.7357588823428846, 0.6321205588285577, 0.3678794411714423)
>>> W.median()
0.8325546111576978
```

고장률을 직접 계산해 보면 `c`에 따라 줄거나, 일정하거나, 늘어요. 행은 x = 0.5, 1, 2이고 열은 c = 0.5, 1, 2예요.

```python
>>> c = sd.asarray([0.5, 1.0, 2.0])
>>> x = sd.asarray([[0.5], [1.0], [2.0]])
>>> W3 = sd.stats.Weibull(c=c)
>>> W3.pdf(x) / W3.ccdf(x)
array([[0.7071067811865476,                1.0,                1.0],
       [               0.5,                1.0,                2.0],
       [0.3535533905932738,                1.0,  3.999999999999999]], dtype=float64)
```

**x = 0에서의 밀도**는 `c`에 따라 갈려요. `c < 1`이면 0 근처로 갈수록 밀도가 무한히 커지고, `c = 1`이면 `1/scale`, `c > 1`이면 0이에요. 0보다 작은 x에서는 밀도도 누적확률도 0이에요.

```python
>>> sd.stats.Weibull(c=sd.asarray([0.5, 1.0, 3.0])).pdf(0.0)
array([inf, 1.0, 0.0], dtype=float64)
```

꼬리는 아주 작은 확률까지 상대 정확도로 나와요. 위꼬리는 $e^{-t}$라서 log를 취하면 $-t$로 단순해지고, 그래서 log 메서드는 확률이 float64 아래로 내려가도 정확하게 나와요. 아래꼬리도 마찬가지예요.

```python
>>> W.ccdf(25.0)

>>> W.ccdf(30.0), W.logccdf(30.0)
(0.0, -900.0)
>>> W.iccdf(1e-300)

>>> W.ilogccdf(-1e6)
1000.0
>>> W.logcdf(1e-170)
-782.8789316179756
>>> W.icdf(1e-20)
1e-10
```

메서드마다의 공통 의미는 [메서드 한눈에 보기](/api/stats/methods/)에 있어요.

## 요약값

$\Gamma$를 [감마 함수](/api/special/gamma/), $\gamma \approx 0.5772$를 오일러–마스케로니 상수, $g_k = \Gamma(1 + k/c)$라고 하면

| 메서드 | 값 |
|---|---|
| `mean()` | $\text{scale}\cdot g_1$ |
| `variance()` | $\text{scale}^2\,(g_2 - g_1^2)$ |
| `skewness()` | $(g_3 - 3g_1g_2 + 2g_1^3)\,/\,(g_2 - g_1^2)^{3/2}$ |
| `kurtosis()` | $(g_4 - 4g_1g_3 + 6g_1^2g_2 - 3g_1^4)\,/\,(g_2 - g_1^2)^2 - 3$ (초과 첨도) |
| `median()` | $\text{scale}\cdot(\log 2)^{1/c}$ |
| `mode()` | $\text{scale}\cdot\big((c-1)/c\big)^{1/c}$ ($c > 1$), 0 ($c \le 1$) |
| `entropy()` | $\gamma(1 - 1/c) + \log(\text{scale}/c) + 1$ |
| `support()` | `(0.0, inf)` |

`c ≤ 1`이면 밀도가 x = 0에서 가장 크므로(`c < 1`이면 거기서 발산해도) `mode()`는 0이에요.

```python
>>> Y = sd.stats.Weibull(c=sd.asarray([0.5, 1.0, 2.0, 3.6, 10.0]))
>>> Y.mean()
array([               2.0,                1.0, 0.8862269254527579,
       0.9011056832822893, 0.9513507698668733], dtype=float64)
>>> Y.skewness()
array([    6.618761213399377,                   2.0,     0.631110657818937,
       0.0005629389015492941,   -0.6376371339031445], dtype=float64)
>>> Y.kurtosis()
array([              84.72,                 6.0, 0.24508930068763804,
       -0.2832548163026564,  0.5701664835673939], dtype=float64)
>>> Y.mode()
array([               0.0,                0.0, 0.7071067811865476,
       0.9135701521236204, 0.9895192582062144], dtype=float64)
```

`c`에 따라 모양이 크게 바뀌어요.

- **왜도**는 `c`가 약 3.6일 때 0을 지나요. 이 근처의 베이불은 정규분포와 꽤 비슷한 대칭 모양이에요. 그보다 크면 왼쪽으로 치우쳐요(음의 왜도).
- **초과 첨도**는 `c`가 약 2.25와 5.77에서 0을 지나요.
- `c`가 아주 커지면 값이 `scale` 근처에 몰려서 분산은 $(\pi^2/6)(\text{scale}/c)^2$로 줄고, 왜도와 첨도는 [Gumbel 분포](/api/stats/gumbel/)를 뒤집은 값(약 −1.1395와 2.4)으로 다가가요.

```python
>>> Z = sd.stats.Weibull(c=1e6)
>>> Z.skewness(), Z.kurtosis()
(-1.1395411328045157, 2.3999710824642744)
>>> sd.stats.Gumbel().skewness(), sd.stats.Gumbel().kurtosis()
(1.1395470994046486, 2.4)
```

반대로 `c`가 0에 가까우면 $\Gamma(1 + 1/c)$가 폭발적으로 커져서, 평균은 아주 크지만 중앙값은 0에 붙어요. 평균이 float64를 넘으면 inf예요.

```python
>>> sd.stats.Weibull(c=0.01).mean()
9.332621544394326e+157
>>> sd.stats.Weibull(c=1e-20).mean()
inf
```

## 다른 분포와의 관계

**지수분포 (c = 1)**: `Weibull(c=1, scale=s)`는 [`Exponential(scale=s)`](/api/stats/exponential/)와 같은 분포예요. 고장률이 일정한 경우가 지수분포이고, 베이불은 그것을 "고장률이 시간에 따라 변하는" 쪽으로 넓힌 것이에요.

```python
>>> W1 = sd.stats.Weibull(c=1.0, scale=3.0)
>>> E = sd.stats.Exponential(scale=3.0)
>>> W1.pdf(2.0), E.pdf(2.0)
(0.17113903967753066, 0.17113903967753066)
>>> W1.mean(), E.mean(), W1.variance(), E.variance()
(3.0, 3.0, 9.0, 9.0)
>>> W1.icdf(0.9), E.icdf(0.9)
(6.907755278982138, 6.907755278982138)
```

그 거꾸로도 성립해요. X가 베이불이면 $(X/\text{scale})^c$는 `Exponential(scale=1)`이에요.

```python
>>> W = sd.stats.Weibull(c=3.0, scale=2.0)
>>> W.ccdf(1.5), sd.stats.Exponential().ccdf((1.5 / 2.0) ** 3)
(0.6558160112715016, 0.6558160112715016)
```

**레일리 분포 (c = 2)**: `Weibull(c=2, scale=s)`는 [`Rayleigh(scale=s / √2)`](/api/stats/rayleigh/)예요. 레일리의 `scale`은 $e^{-x^2/(2\,\text{scale}^2)}$에 들어가서, 베이불의 `scale`과 $\sqrt2$배 차이가 나요.

```python
>>> import math
>>> sd.stats.Weibull(c=2.0, scale=math.sqrt(2.0)).cdf(1.5), sd.stats.Rayleigh().cdf(1.5)
(0.6753475326416502, 0.6753475326416503)
```

끝자리 차이는 `math.sqrt(2.0)`의 반올림이에요.

**Gumbel 분포**: X가 베이불이면 $-\log X$는 위치가 $-\log(\text{scale})$, 척도가 $1/c$인 [Gumbel 분포](/api/stats/gumbel/)(최댓값형)예요. 베이불이 "최솟값"의 분포이고 Gumbel이 "최댓값"의 분포라서, 로그와 부호를 바꾸면 이어져요. 둘을 하나로 묶은 것이 [일반화 극값 분포](/api/stats/gev/)예요.

```python
>>> G = sd.stats.Gumbel(mu=-math.log(2.0), sigma=1 / 3)
>>> W.ccdf(1.5), G.cdf(-math.log(1.5))
(0.6558160112715016, 0.6558160112715016)
```

**감마분포, 로그정규분포**: 셋 다 양수 자료에 맞추는 오른쪽으로 치우친 분포예요. `c = 1`에서 베이불과 [감마](/api/stats/gamma/)(`a = 1`)는 둘 다 지수분포가 돼요. 아주 먼 꼬리는 [로그정규](/api/stats/lognormal/)가 어떤 `c`의 베이불보다도 두꺼워요.

## 정확도와 범위

베이불 분포는 닫힌 꼴이 있는 분포라 **매개변수와 입력의 정의역 전체**가 보장 영역이에요.

- `pdf`, `cdf`, `ccdf`와 그 log, `mean`, `variance`, `standard_deviation`, `median`, `mode`는 참값 대비 상대 오차 $10^{-14}$ 안이에요. `ccdf`는 1 − `cdf`로 만들지 않아서 위꼬리도 상대 정확도예요.
- `logpdf`, `entropy`, 그리고 0을 지나는 `skewness`와 `kurtosis`는 오차가 $10^{-14} \cdot \max(1, |값|)$ 안이에요. `c`가 아주 커서 중심 모멘트의 항들이 서로 거의 지워지는 곳에서도 이 기준을 지켜요.
- `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`는 결과의 상대 오차가 $10^{-14} \cdot \max(1, \kappa)$ 안이에요. $\kappa$는 입력이 조금 변할 때 결과가 얼마나 크게 변하는지 나타내는 조건수예요.
- 결과가 float64 범위를 넘으면 극한값이에요. 평균이 넘치면 inf(`Weibull(c=1e-20).mean()`), 중앙값이나 분산이 0 아래로 내려가면 0이에요.
- NaN은 매개변수가 정의역 밖이거나 NaN일 때, 입력이 NaN일 때, `icdf`·`iccdf`의 확률이 [0, 1] 밖일 때, `ilogcdf`·`ilogccdf`의 입력이 양수일 때뿐이에요.

모멘트의 상쇄를 피하는 방법과 꼬리 계산은 [연속 분포의 수치 기법](/internals/stats/continuous/)에 있어요.

## scipy를 아는 분께

- scipy의 `weibull_min(c, loc=0, scale)`과 `c`, `scale`이 그대로 대응해요. `loc`는 없어요. 위가 막힌 거울상 `weibull_max`에 해당하는 분포는 없어요.
- `kurtosis()`는 초과 첨도라 고전형 `weibull_min.stats(c, moments='k')`와 같아요.
- `c`가 크면 scipy의 왜도와 첨도는 항들의 상쇄로 자릿수를 잃어요. `c = 1e6`에서는 부호와 크기가 모두 틀려요.

  ```python
  >>> import scipy.stats as ss
  >>> sd.stats.Weibull(c=1e6).kurtosis()
  2.3999710824642744
  >>> [float(v) for v in ss.weibull_min.stats(1e6, moments='sk')]
  [368.4922775706471, -533638407.2585094]
  ```

- 아래꼬리의 log 확률에서 scipy는 확률이 float64 아래로 내려가면 −inf를 내요.

  ```python
  >>> sd.stats.Weibull(c=2.0).logcdf(1e-170)
  -782.8789316179756
  >>> float(ss.weibull_min.logcdf(1e-170, 2.0))
  -inf
  ```
