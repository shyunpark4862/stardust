## 어떤 분포인가요

**포아송 분포**(Poisson distribution)는 정해진 시간이나 공간에서 어떤 사건이 몇 번 일어나는지의 분포예요. 평균 횟수 `mu` 하나로 정해져요. 사건이 서로 독립적으로, 어느 순간에나 같은 비율로 드물게 일어난다고 가정해요.

- 고객 센터: 한 시간에 평균 4건 오는 문의가 이번 시간에 8건 넘게 올 확률
- 사고와 고장: 하루 평균 0.5건인 장애가 하루에 2건 이상 날 확률
- 방사선 계수: 1초 동안 검출기에 잡히는 입자의 수
- 결함 개수: 원단 1m²당 흠집 수, 책 한 쪽의 오타 수

이항 분포와 달리 위쪽 끝이 없어요. 이론상 1000번도 일어날 수 있고, 그 확률이 아주 작을 뿐이에요.

```python
>>> import stardust as sd
>>> X = sd.stats.Poisson(mu=4.0)
>>> X.pmf(0)
0.01831563888873418
>>> X.pmf(4)
0.19536681481316456
>>> X.cdf(2)
0.2381033055535443
>>> X.ccdf(8)
0.021363434487984157
```

평균 4건인 시간에 문의가 한 건도 없을 확률은 약 1.8%, 정확히 4건일 확률은 약 19.5%, 2건 이하일 확률은 약 23.8%, 8건보다 많을(9건 이상) 확률은 약 2.1%예요.

## 만들기와 매개변수

매개변수는 `mu` 하나이고, 이름을 붙여서 줘요. 기본값은 없어요.

```python
>>> X
Poisson(mu=4.0)
>>> X.mu
4.0
```

`mu`는 0 이상의 유한한 실수예요. 횟수의 평균이라서 정수가 아니어도 돼요(하루 평균 0.5건). 음수나 inf, NaN이면 에러 대신 그 원소의 모든 결과가 NaN이에요.

```python
>>> sd.stats.Poisson(mu=-1.0).pmf(0)
nan
>>> sd.stats.Poisson(mu=float('inf')).pmf(0)
nan
>>> sd.special.pdtr(5, sd.inf)
0.0
```

평균이 inf이면 확률이 모두 무한대 쪽으로 달아나 확률분포가 남지 않아서 NaN이에요. special의 [`pdtr`](/api/special/pdtr/)은 함수의 극한값 0을 주는 점이 달라요.

`mu`에 배열을 주면 원소마다 다른 분포가 되고, 입력과 [브로드캐스트](/api/array/broadcasting/)해요. 평균이 1, 4, 9인 세 분포(열)에서 0건과 4건의 확률(행)을 한 번에 구해요.

```python
>>> X = sd.stats.Poisson(mu=sd.asarray([1.0, 4.0, 9.0]))
>>> X.pmf(sd.asarray([[0], [4]]))
array([[   0.36787944117144233,    0.01831563888873418,
        0.00012340980408667956],
       [  0.015328310048810096,    0.19536681481316456,
           0.03373715519219602]], dtype=float64)
```

## 확률질량과 누적분포

$$
P(X = k) = e^{-\mu} \frac{\mu^k}{k!}, \qquad k = 0, 1, 2, \dots
$$

지지집합은 0 이상의 모든 정수예요. 정수가 아닌 값과 음수에서 `pmf`는 0, `logpmf`는 −inf이고, `cdf`는 내림한 정수의 값이에요.

```python
>>> X = sd.stats.Poisson(mu=4.0)
>>> X.support()
(0.0, inf)
>>> X.pmf(2.5)
0.0
>>> X.pmf(-1)
0.0
>>> X.logpmf(-1)
-inf
>>> X.cdf(2.5)
0.2381033055535443
```

분위수 `icdf(p)`는 cdf(k) ≥ p인 가장 작은 정수, `iccdf(p)`는 ccdf(k) ≤ p인 가장 작은 정수예요. 위쪽 끝이 없어서 `icdf(1)`과 `iccdf(0)`은 inf예요.

```python
>>> X.icdf(0.5)
4.0
>>> X.icdf(0.9)
7.0
>>> X.icdf(0.0)
0.0
>>> X.icdf(1.0)
inf
>>> X.iccdf(0.0)
inf
```

### 몇 건까지 대비할지 정하기

한 시간 평균 4건인 문의를 "99%의 시간에는 다 받을 수 있게" 준비하려면, 넘칠 확률 ccdf(k)가 1% 이하가 되는 가장 작은 k건까지 감당할 수 있어야 해요.

```python
>>> X.iccdf(0.01)
9.0
>>> X.ccdf(9)
0.008132242796933866
>>> X.ccdf(8)
0.021363434487984157
```

9건을 감당하면 넘치는 시간은 약 0.8%예요. 8건으로는 약 2.1%라 1%를 넘어요.

<Callout type="warn" title="ccdf는 '초과'예요">
  `ccdf(k)`는 P(X > k)예요. "k건 **이상**"의 확률은 `ccdf(k - 1)`이에요.
</Callout>

### 먼 꼬리는 ccdf와 log 메서드로

`ccdf`는 `1 - cdf`로 계산하지 않아서 아주 작은 위꼬리도 값이 있어요. 그보다 더 작아 float64로 나타낼 수 없으면 `logccdf`, `ilogccdf`를 써요.

```python
>>> P = sd.stats.Poisson(mu=3.0)
>>> P.ccdf(50)
7.335541660871681e-44
>>> 1 - P.cdf(50)
0.0
>>> P.ccdf(500)
0.0
>>> P.logccdf(500)
-2070.136313986432
>>> P.logpmf(500)
-2065.024314126101
>>> P.iccdf(1e-30)
39.0
>>> P.ilogccdf(-2000.0)
487.0
```

메서드의 공통 뜻은 [분포의 메서드](/api/stats/methods/)에 있어요.

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()` | $\mu$ |
| `variance()` | $\mu$ |
| `standard_deviation()` | $\sqrt{\mu}$ |
| `skewness()` | $1/\sqrt{\mu}$ |
| `kurtosis()` | $1/\mu$ (초과 첨도) |
| `median()` | `icdf(0.5)` |
| `mode()` | $\lfloor \mu \rfloor$, $\mu$가 1 이상의 정수이면 NaN |
| `entropy()` | $-\sum_k P(X=k)\log P(X=k)$ (nat) |

```python
>>> X = sd.stats.Poisson(mu=3.5)
>>> X.mean()
3.5
>>> X.variance()
3.5
>>> X.standard_deviation()
1.8708286933869707
>>> X.skewness()
0.5345224838248488
>>> X.kurtosis()
0.2857142857142857
>>> X.median()
3.0
>>> X.mode()
3.0
>>> X.entropy()
2.015172522512972
```

포아송 분포는 평균과 분산이 같아요. 실제 횟수 자료의 분산이 평균보다 훨씬 크면(과대산포) 포아송은 맞지 않고, 대신 [음이항 분포](/api/stats/negative-binomial/)를 써요. `mu`가 커지면 왜도와 첨도가 0으로 가서 정규분포에 가까워져요.

### 최빈값이 둘이면 NaN

`mu`가 1 이상의 정수이면 $\mu - 1$과 $\mu$의 확률이 똑같아서 최빈값이 둘이에요. 이때 `mode()`는 NaN이에요.

```python
>>> sd.stats.Poisson(mu=3.0).mode()
nan
>>> sd.stats.Poisson(mu=3.0).pmf(sd.asarray([2, 3]))
array([0.22404180765538773, 0.22404180765538773], dtype=float64)
>>> sd.stats.Poisson(mu=0.5).mode()
0.0
```

### 점질량: mu = 0

`mu = 0`이면 사건이 절대 일어나지 않아서 X는 언제나 0이에요. 분산과 엔트로피는 0이고, 왜도와 첨도는 분산으로 나누는 값이라 NaN이에요.

```python
>>> Z = sd.stats.Poisson(mu=0.0)
>>> Z.pmf(0)
1.0
>>> Z.variance()
0.0
>>> Z.skewness()
nan
>>> Z.kurtosis()
nan
>>> Z.mode()
0.0
>>> Z.entropy()
0.0
```

`support()`는 `mu = 0`이어도 포아송 분포 족의 지지집합 (0, inf)이에요. 그래서 `icdf(1)`도 그 위 끝 inf예요.

```python
>>> Z.support()
(0.0, inf)
>>> Z.icdf(1.0)
inf
>>> Z.icdf(0.5)
0.0
```

## 표본

`sample`은 포아송 난수를 정수인 float64로 뽑아요. 생성기 `rng`를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> sd.stats.Poisson(mu=4.0).sample((8,), rng=rng)
array([4.0, 4.0, 6.0, 5.0, 1.0, 2.0, 3.0, 6.0], dtype=float64)
>>> x = sd.stats.Poisson(mu=4.0).sample((100000,), rng=sd.random.default_rng(7))
>>> sd.mean(x)
4.00036
>>> sd.var(x)
3.9809398703999994
```

표본의 평균과 분산이 둘 다 4에 가까워요. 매개변수가 배열이면 결과의 마지막 축이 각 분포에 해당해요.

```python
>>> sd.stats.Poisson(mu=sd.asarray([1.0, 10.0])).sample((3,), rng=sd.random.default_rng(1))
array([[0.0, 8.0],
       [1.0, 3.0],
       [0.0, 9.0]], dtype=float64)
```

## 다른 분포와의 관계

**이항 분포의 극한**: 시도 횟수 `n`이 크고 성공 확률 `p`가 작으면 [이항 분포](/api/stats/binomial/)는 평균 $np$인 포아송 분포에 가까워요. "드문 사건의 횟수"를 포아송으로 다루는 근거예요.

**감마 분포와 special 함수**: 포아송의 누적확률은 정칙화된 상부 불완전 감마 함수예요.

$$
P(X \le k) = Q(k+1,\ \mu)
$$

그래서 모양이 $k+1$인 [감마 분포](/api/stats/gamma/)의 ccdf와도, special의 [`pdtr`](/api/special/pdtr/)과도 같아요. 사건 사이의 간격이 [지수분포](/api/stats/exponential/)라서, "$\mu$ 시간 안에 $k+1$번째 사건이 아직 오지 않았다"가 "$k$번 이하 일어났다"와 같은 사건이기 때문이에요.

```python
>>> X = sd.stats.Poisson(mu=3.5)
>>> X.cdf(5)
0.8576135530957784
>>> sd.special.pdtr(5, 3.5)
0.8576135530957784
>>> sd.stats.Gamma(a=6).ccdf(3.5)
0.8576135530957784
```

**음이항 분포의 극한**: 평균을 $\mu$로 두고 `n`을 키운 [음이항 분포](/api/stats/negative-binomial/) `NegativeBinomial(n, p=n/(n+mu))`는 포아송에 가까워져요. 음이항의 분산 $\mu + \mu^2/n$에서 과대산포 몫 $\mu^2/n$이 0으로 가기 때문이에요.

```python
>>> k = sd.arange(0, 6)
>>> sd.stats.NegativeBinomial(n=1e6, p=1e6 / (1e6 + 3)).pmf(k)
array([0.04978729240791944,   0.149361429141279,  0.2240416956316876,
        0.2240414715933763,  0.1680311036970665, 0.10081876303782016], dtype=float64)
>>> sd.stats.Poisson(mu=3.0).pmf(k)
array([0.049787068367863944,  0.14936120510359183,  0.22404180765538773,
        0.22404180765538773,  0.16803135574154082,  0.10081881344492448], dtype=float64)
```

## 정확도와 범위

- 보장 영역: `mu` ≤ 1e6이에요. 여기서 pmf, cdf, ccdf와 그 log, 모멘트는 참값 대비 상대오차 1e-14 이하이고(`entropy`는 오차가 1e-14·max(1, |값|) 이하), 위의 7.3e-44 같은 먼 꼬리에서도 마찬가지예요.
- 분위수: 늘 위의 정의대로 정수를 찾아요. 목표 확률이 계단 경계에 아주 가깝다면(상대 1e-14 안), 그만큼 움직였을 때의 답인 이웃 정수가 나올 수 있어요.
- 보장 영역 밖: `mu`가 1e6보다 커도 값을 계산하지만 정확도는 약속하지 않아요. 구할 수 없는 값은 틀린 숫자 대신 NaN이에요. k가 2⁵³(약 9e15) 이상인 곳의 pmf가 무시할 수 없는 크기이면 cdf 계열과 분위수가 NaN이에요. `mu`가 약 1e16에서 1e34 사이이면 평균 근처의 cdf 계열, 분위수, `median`이 여기에 걸려요. 그보다 `mu`가 크면 pmf 하나하나가 cdf의 반올림 오차보다 작아져서 다시 값이 나와요. pmf와 모멘트는 값이 있어요.

```python
>>> X = sd.stats.Poisson(mu=1e6)
>>> X.cdf(1001000)
0.8414656709634281
>>> X.median()
1000000.0
>>> sd.stats.Poisson(mu=1e17).cdf(1e17)
nan
>>> sd.stats.Poisson(mu=1e17).pmf(1e17)
1.26156626101008e-09
>>> sd.stats.Poisson(mu=1e17).mean()
1e+17
```

모든 호출은 정해진 시간 안에 끝나요. 계산 방법은 [이산 분포의 구현](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.poisson(mu)`와 같은 분포예요. 분위수 `icdf`, `iccdf`는 `poisson.ppf`, `poisson.isf`와 정의가 같아요.
- `icdf(0)`은 지지집합의 왼쪽 끝 0이에요. `poisson.ppf(0, mu)`는 −1이에요.
- `mu = 0`의 왜도와 첨도는 NaN이에요. `poisson.stats(0, moments='sk')`는 둘 다 inf예요. `support()`와 `icdf(1)`은 `poisson.support(0)`, `poisson.ppf(1, 0)`과 같은 (0, inf)와 inf예요.
- `mu = inf`는 NaN이에요. `poisson.cdf(5, inf)`는 극한값 0.0이에요.
- `mode()`가 있고 `mu`가 정수이면 NaN이에요. `scipy.stats.poisson`에는 최빈값 메서드가 없어요.
- 먼 꼬리에서 값이 있어요. `Poisson(mu=3.0).logccdf(500)`은 −2070.14이고 `poisson.logsf(500, 3)`은 −inf예요. `poisson.isf(1e-30, 3)`은 NaN이지만 답은 39예요.
