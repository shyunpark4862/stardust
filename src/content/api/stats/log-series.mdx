## 어떤 분포인가요

**로그 급수 분포**(logarithmic series distribution)는 1, 2, 3, …의 양의 정수에 놓이는 분포예요. 1이 가장 흔하고, 큰 값으로 갈수록 확률이 $p^k/k$ 꼴로 줄어들어요. $p$가 1에 가까우면 아주 큰 값도 드물지 않게 나와요.

이 분포는 "적어도 하나는 있는 것의 개수"를 셀 때 자주 나와요.

- **종 풍부도**: 채집한 곤충을 종별로 세면 한 마리만 잡힌 종이 가장 많고, 많이 잡힌 종은 드물어요. 피셔(R. A. Fisher)가 이 자료에 맞춘 분포가 로그 급수 분포예요.
- **구매 수량**: 한 번 살 때 고르는 상품 개수, 한 사람이 쓴 글의 수처럼 0은 세지 않는 개수
- **0을 뺀 음이항분포의 극한**: 아래 "다른 분포와의 관계"에서 실행으로 보여요.

```python
>>> import stardust as sd
>>> X = sd.stats.LogSeries(p=0.6)
>>> X.pmf(sd.arange(0.0, 6.0))
array([                 0.0,   0.6548140007623748,  0.19644420022871248,
        0.07857768009148498,  0.03535995604116824, 0.016972778899760753], dtype=float64)
>>> X.support()
(1.0, inf)
```

## 만들기와 매개변수

`p` 하나를 키워드로 줘요. 기본값은 없고, 정의역은 $0 < p < 1$이에요. $p$를 0이나 1로 주거나 그 밖이면 에러 없이 NaN이에요.

```python
>>> sd.stats.LogSeries(p=0.0).pmf(1)
nan
>>> sd.stats.LogSeries(p=1.0).mean()
nan
>>> sd.stats.LogSeries(p=sd.asarray([0.3, 0.6, 0.9])).mean()
array([ 1.201574250881627, 1.6370350019059372, 3.9086503371292673], dtype=float64)
```

## 확률질량과 누적분포

$$
P(X = k) = \frac{-1}{\log(1 - p)}\,\frac{p^k}{k}, \qquad k = 1, 2, 3, \dots
$$

앞의 $-1/\log(1-p)$는 합을 1로 맞추는 상수예요. $\sum_{k \ge 1} p^k/k = -\log(1-p)$라서 이런 이름이 붙었어요. 정수가 아닌 $k$의 `pmf`는 0, `cdf`·`ccdf`는 그 아래 정수에서의 값이에요. 공통 규칙은 [단변량 분포의 메서드](/api/stats/methods/)에 있어요.

```python
>>> X.cdf(3), X.cdf(3.5)
(0.9298358810825723, 0.9298358810825723)
>>> X.ccdf(10)
0.0008072987908066551
>>> X.icdf(0.9), X.iccdf(1e-6)
(3.0, 22.0)
```

`ccdf`는 위꼬리를 직접 더해서 구하기 때문에 아주 작아도 앞자리가 맞아요. `logccdf`는 그보다 더 작아 0이 되는 곳에서도 값이 있어요.

```python
>>> X.ccdf(1000)
2.313266037340522e-225
>>> X.logccdf(1000)
-517.2429855287196
```

## 요약값

$L = -\log(1-p)$로 쓰면 평균과 분산은 이래요.

$$
\mathrm{E}[X] = \frac{p}{(1-p)L}, \qquad
\mathrm{Var}[X] = \frac{p\,(L - p)}{(1-p)^2 L^2}
$$

```python
>>> X.mean(), X.variance()
(1.6370350019059372, 1.412703907299671)
>>> X.standard_deviation()
1.1885722137504608
>>> X.skewness(), X.kurtosis()
(3.0047928675442495, 13.65608279830817)
>>> X.median(), X.mode()
(1.0, 1.0)
>>> X.entropy()
1.0823292243236404
```

`kurtosis()`는 정규분포를 0으로 둔 초과 첨도예요. 최빈값은 언제나 1이에요. $P(X = k+1)/P(X = k) = p\,k/(k+1) < 1$이라 확률이 1에서부터 계속 줄어들기 때문이에요.

$p$가 1에 가까우면 평균이 커지지만, 중앙값은 그보다 훨씬 작아요. 대부분은 작은 값이고 드물게 아주 큰 값이 나와 평균을 끌어올리기 때문이에요.

```python
>>> Y = sd.stats.LogSeries(p=0.999999)
>>> Y.mean(), Y.median()
(72382.34126619757, 562.0)
>>> Y.pmf(1)
0.07238234126827897
```

## 다른 분포와의 관계

**0을 뺀 음이항분포의 극한이에요.** [`NegativeBinomial(n, p)`](/api/stats/negative-binomial/)에서 0이 나온 경우를 빼고(0이 아닐 확률 `ccdf(0)`으로 나누고) $n \to 0$으로 보내면 로그 급수 분포가 돼요. 이때 음이항의 성공 확률 $p_{\text{NB}}$와 로그 급수의 $p$는 $p = 1 - p_{\text{NB}}$ 관계예요.

```python
>>> k = sd.arange(1.0, 6.0)
>>> nb = sd.stats.NegativeBinomial(n=1e-10, p=0.4)
>>> nb.pmf(k) / nb.ccdf(0)
array([   0.654814000732376,  0.19644420023935713,  0.07857768009967175,
       0.035359956046030955,  0.01697277890251918], dtype=float64)
>>> X.pmf(k)
array([  0.6548140007623748,  0.19644420022871248,  0.07857768009148498,
        0.03535995604116824, 0.016972778899760753], dtype=float64)
```

$n$이 작을수록 더 가까워져요. 생태학에서 "종마다의 개체 수가 음이항분포를 따르고, 관찰되지 않은 종(0)은 셀 수 없다"는 모형이 이 극한으로 로그 급수가 돼요.

## 정확도와 범위

$p \ge 10^{-8}$이면 모든 메서드가 참값과 상대 1e-14 안에서 맞아요(`logpmf`는 상대, `entropy`는 $10^{-14}\cdot\max(1, |값|)$ 안). 분위수는 목표 확률을 상대 1e-14 안에서 움직였을 때 나올 수 있는 정확한 답 중 하나예요. 그보다 작은 $p$도 값을 계산하지만 정확도는 보장하지 않아요.

$p$가 아주 작으면 거의 언제나 1이 나와요. 이때 `logpmf(1)`은 0에 아주 가까운 음수 $-p/2$ 근처인데, 이 작은 값도 상대 정확도로 나와요.

```python
>>> Z = sd.stats.LogSeries(p=1e-8)
>>> Z.pmf(1)
0.9999999949999999
>>> Z.logpmf(1)
-5.000000020833333e-09
>>> Z.ccdf(1)
5.0000000083333336e-09
```

구현은 [이산 분포의 수치 기법](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

scipy의 `logser(p)`와 같은 분포이고 매개변수 이름도 같아요. stardust는 키워드로만 받아요(`LogSeries(p=0.6)`).

```python
>>> import scipy.stats
>>> float(scipy.stats.logser(0.6).pmf(1))
0.654814000762375
>>> X.pmf(1)
0.6548140007623748
```

$p$가 작을 때 `logpmf(1)`이 달라요. 참값은 $-p/2 - 5p^2/24 - \cdots$이고, $p = 10^{-8}$이면 $-5.0000000208\ldots \times 10^{-9}$예요.

```python
>>> float(scipy.stats.logser(1e-8).logpmf(1))
-5.000000093134948e-09
>>> Z.logpmf(1)
-5.000000020833333e-09
```

scipy의 값은 상대오차가 약 1.4e-8이에요.

- `ppf`·`isf`는 `icdf`·`iccdf`, `sf`·`logsf`는 `ccdf`·`logccdf`예요. 분위수의 정의는 scipy와 같아요.
- scipy에는 없는 `mode()`가 있어요(언제나 1).
