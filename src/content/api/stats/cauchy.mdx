## 어떤 분포인가요

**코시 분포**(Cauchy distribution)는 정규분포처럼 가운데가 볼록하고 좌우 대칭인 종 모양이에요. 그런데 꼬리가 아주 두꺼워서, 가운데에서 멀리 떨어진 값이 정규분포와는 비교가 안 될 만큼 자주 나와요. 그 결과 이 분포에는 **평균도 분산도 없어요.**

이런 상황에서 나와요.

- 회전하는 등대: 직선 해안에서 거리 $\sigma$만큼 떨어진 곳에 등대가 있고, 등대가 아무 방향으로나 고르게 빛을 쏜다고 해 볼게요. 빛이 해안에 닿는 위치는 코시 분포를 따라요. 빛이 해안과 거의 나란하게 나가면 아주 먼 곳에 닿기 때문에 극단값이 자주 생겨요.
- 두 정규 값의 비: 평균이 0인 독립 정규 값 둘을 나눈 값 $Z_1/Z_2$는 코시 분포예요. 분모가 0 근처에 오면 비가 아주 커져요.
- 공명과 스펙트럼선: 물리에서 공명 곡선(로런츠 곡선)의 모양이 코시 밀도와 같아요.
- 두꺼운 꼬리의 본보기: 평균이나 표준편차에 기댄 방법이 언제 무너지는지 보여 주는 대표적인 예로 써요.

```python
>>> import stardust as sd
>>> X = sd.stats.Cauchy()
>>> X.median(), X.mode()
(0.0, 0.0)
>>> X.mean(), X.variance()
(nan, nan)
```

## 만들기와 매개변수

| 매개변수 | 뜻 | 정의역 | 기본값 |
|---|---|---|---|
| `mu` | 위치(중앙값이자 최빈값) | 유한한 실수 | 0.0 |
| `sigma` | 척도 | 0보다 큰 유한한 실수 | 1.0 |

<Callout type="warn" title="sigma는 표준편차가 아니라 척도예요">
코시 분포에는 표준편차가 없으니, `sigma`는 표준편차일 수가 없어요. `sigma`는 분포가 퍼진 폭을 정하는 **척도**예요. 두 가지로 읽을 수 있어요.

- `mu - sigma`와 `mu + sigma`가 아래·위 사분위수예요. 값의 절반이 이 사이에 있어요.
- `mu ± sigma`에서 밀도가 봉우리 높이의 절반이에요(반치반폭).

이름이 `mu`, `sigma`인 것은 위치와 척도 자리를 정규분포와 맞춘 것이고, 뜻이 같다는 말은 아니에요. `mu`도 평균이 아니라 중앙값이에요.
</Callout>

```python
>>> Y = sd.stats.Cauchy(mu=3.0, sigma=2.0)
>>> Y.icdf(sd.asarray([0.25, 0.5, 0.75]))
array([1.0000000000000002,                3.0,                5.0], dtype=float64)
>>> Y.pdf(3.0), Y.pdf(5.0)
(0.15915494309189535, 0.07957747154594767)
>>> Y.mu, Y.sigma
(3.0, 2.0)
```

사분위수가 $3 \pm 2$이고, $x = 5$의 밀도가 봉우리 $x = 3$의 꼭 절반이에요. 첫 원소의 끝자리는 $\pi$를 float64로 반올림한 데서 와요(상대오차 $2 \times 10^{-16}$).

매개변수를 배열로 주면 원소별로 계산하고, 정의역 밖의 원소(0 이하의 `sigma`, 무한대나 NaN인 `mu`)는 NaN이에요. 에러는 나지 않아요.

```python
>>> sd.stats.Cauchy(sigma=sd.asarray([1.0, 0.0, -2.0])).pdf(0.0)
array([0.3183098861837907,                nan,                nan], dtype=float64)
```

## 밀도와 누적분포

지지집합은 실수 전체예요. $z = (x - \mu)/\sigma$로 두면

$$
f(x) = \frac{1}{\pi\sigma\,(1 + z^2)}, \qquad
F(x) = \frac12 + \frac{1}{\pi}\arctan z, \qquad
F^{-1}(p) = \mu + \sigma \tan\!\big(\pi(p - \tfrac12)\big)
$$

예요. 밀도는 $|z|$가 커질 때 $1/z^2$로만 줄어요. 정규분포의 $e^{-z^2/2}$와 비교하면 아주 느려요. 그래서 위꼬리 확률도 대략 $1/(\pi z)$로, 거리에 반비례해서 줄어요.

```python
>>> X = sd.stats.Cauchy()
>>> X.pdf(0.0)
0.3183098861837907
>>> X.cdf(-1.0), X.cdf(1.0)
(0.25, 0.75)
>>> X.ccdf(sd.asarray([3.0, 10.0, 100.0]))
array([ 0.10241638234956672, 0.031725517430553574, 0.003182992764908255], dtype=float64)
>>> sd.stats.Normal().ccdf(sd.asarray([3.0, 10.0, 100.0]))
array([0.0013498980316300944, 7.619853024160524e-24,                   0.0], dtype=float64)
```

정규분포에서는 거의 일어나지 않는 "100보다 큰 값"이 코시에서는 0.3% 확률로 나와요. 분위수도 그만큼 바깥에 있어요. 양쪽 5%를 자르는 점이 정규에서는 1.96인데 코시에서는 12.7이에요.

```python
>>> X.icdf(0.975), sd.stats.Normal().icdf(0.975)
(12.706204736174692, 1.9599639845400536)
>>> X.icdf(0.995)
63.656741162871526
```

### 모멘트가 왜 모두 NaN인가요

평균은 $E[X] = \int x f(x)\,dx$인데, 이 적분이 성립하려면 $\int |x| f(x)\,dx$가 유한해야 해요. 코시에서는 $|x| f(x)$가 멀리서 $1/(\pi |x|)$처럼 줄어서, 오른쪽 절반의 적분도 $+\infty$, 왼쪽 절반도 $-\infty$로 발산해요. $\infty - \infty$는 정할 수 없으니 평균은 **무한대가 아니라 정의되지 않아요.** 그래서 inf가 아니라 NaN이에요.

분산, 표준편차, 왜도, 첨도는 모두 평균을 중심으로 정의돼요($E[(X - E[X])^2]$ 등). 중심인 평균이 없으니 이 값들도 정의되지 않아 NaN이에요. $E[X^2]$ 자체는 $+\infty$로 발산하지만, 분산이 inf라고 말하려면 먼저 평균이 있어야 해요.

반면 중앙값, 최빈값, 엔트로피는 모멘트가 아니라서 잘 정해져요. 코시 분포의 "중심"과 "폭"이 필요하면 `median()`과 `sigma`(사분위범위의 절반)를 쓰세요.

<Callout type="warn" title="표본 평균은 참값으로 모이지 않아요">
보통은 표본이 많을수록 표본 평균이 참 평균에 가까워져요(큰 수의 법칙). 코시에는 참 평균이 없으니 이 법칙이 성립하지 않아요. 실제로 독립인 코시 값 n개의 평균은 다시 **같은 코시 분포**를 따라서, 백만 개를 평균해도 하나를 뽑은 것보다 나을 게 없어요. 표본 중앙값은 `mu`로 잘 모여요.

```python
>>> X = sd.stats.Cauchy()
>>> rng = sd.random.default_rng(0)
>>> for n in (100, 10_000, 1_000_000):
...     s = X.sample((n,), rng=rng)
...     print(n, float(s.mean()), float(sd.median(s)))
100 2.5224449844990424 -0.13765194391451513
10000 6.22442565333319 0.014326892053520456
1000000 -1.3789839421583658 0.0002479703273323656
```

표본 평균은 2.5, 6.2, −1.4로 오락가락하지만, 표본 중앙값([median](/api/array/quantile/))은 0으로 다가가요. 자료에 극단값이 섞여 있을 수 있다면 평균 대신 중앙값이나 분위수를 보세요.
</Callout>

## 표본

`sample`은 생성기 `rng`를 꼭 받아요. 모양과 재현 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> sd.stats.Cauchy(mu=3.0, sigma=2.0).sample((5,), rng=rng)
array([ 2.6916039279641004,  3.1765982298566353,   5.660719926867001,
         5.234043370148325, -4.2147137268215955], dtype=float64)
```

마지막 값처럼 중심 3에서 척도의 3.6배나 떨어진 값이 드물지 않게 섞여요.

## 다른 분포와의 관계

**t 분포**: 표준 코시 분포는 자유도 1인 [t 분포](/api/stats/student-t/)와 같아요. t 분포도 자유도가 1 이하이면 평균이 NaN이에요.

```python
>>> sd.stats.Cauchy().cdf(2.0), sd.stats.StudentT(df=1).cdf(2.0)
(0.8524163823495667, 0.8524163823495667)
>>> sd.stats.StudentT(df=1).mean()
nan
```

**두 정규 값의 비**: 독립인 표준정규 값 둘의 비는 표준 코시 분포라서, 사분위수가 ±1 근처에 와요.

```python
>>> rng = sd.random.default_rng(1)
>>> N = sd.stats.Normal()
>>> r = N.sample((1_000_000,), rng=rng) / N.sample((1_000_000,), rng=rng)
>>> sd.quantile(r, sd.asarray([0.25, 0.5, 0.75]))
array([   -1.0016171705911563, -0.0017689715160941562,
           1.0000046824964097], dtype=float64)
```

**정규분포, 라플라스 분포와의 비교**: 셋 다 위치와 척도가 있는 대칭 분포라 이름이 `mu`, `sigma`로 같아요. 하지만 `sigma`의 뜻은 저마다 달라요. [정규](/api/stats/normal/)에서는 표준편차, [라플라스](/api/stats/laplace/)에서는 표준편차의 $1/\sqrt2$, 코시에서는 사분위범위의 절반이에요. 꼬리는 정규, 라플라스, 코시 순으로 두꺼워져요.

## 정확도와 범위

코시 분포는 닫힌 꼴이 있는 분포라 매개변수와 입력의 정의역 전체가 보장 영역이에요.

- `pdf`, `cdf`, `ccdf`와 그 log, `median`, `mode`는 참값 대비 상대오차 $10^{-14}$ 안이에요. `ccdf`는 1 − `cdf`로 만들지 않아서 아주 먼 꼬리도 상대 정확도예요.
- `logpdf`와 `entropy`는 오차가 $10^{-14} \cdot \max(1, |값|)$ 안이에요.
- `icdf`, `iccdf`, `ilogcdf`, `ilogccdf`는 결과의 상대오차가 $10^{-14} \cdot \max(1, \kappa)$ 안이에요. $\kappa$는 입력이 조금 변할 때 결과가 얼마나 크게 변하는지 나타내는 조건수예요.
- $z = (x - \mu)/\sigma$가 float64를 넘을 만큼 먼 곳에서도 값이 나와요. 결과 자체가 float64를 넘으면 극한값(0, ±inf)이에요.
- 평균, 분산, 표준편차, 왜도, 첨도는 수학적으로 정의되지 않아서 언제나 NaN이에요. 그 밖의 NaN은 매개변수가 정의역 밖이거나 NaN일 때, 입력이 NaN일 때, `icdf`·`iccdf`의 확률이 [0, 1] 밖일 때, `ilogcdf`·`ilogccdf`의 입력이 양수일 때뿐이에요.

꼬리에서 상쇄를 피하는 방법은 [연속 분포의 수치 기법](/internals/stats/continuous/)에 있어요.

## scipy를 아는 분께

- scipy의 `cauchy(loc, scale)`과 `loc = mu`, `scale = sigma`로 대응해요.
- 모멘트는 scipy도 모두 NaN이고, `entropy`도 같은 $\log(4\pi\sigma)$예요. `kurtosis`가 초과 첨도인 것은 다른 분포와 같지만, 코시에서는 어느 쪽이든 NaN이에요.
- 아주 먼 꼬리의 밀도에서 scipy는 0을 내는 곳이 있어요. $1 + z^2$를 float64로 계산하면 $z^2$가 넘치기 때문이에요.

  ```python
  >>> import scipy.stats as ss
  >>> sd.stats.Cauchy().pdf(1e155)
  3.183098861838e-311
  >>> float(ss.cauchy.pdf(1e155))
  0.0
  ```
