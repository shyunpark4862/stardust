## 한눈에 보기

**노름**(norm)은 벡터나 행렬이 "얼마나 큰가"를 숫자 하나로 나타낸 값이에요. 숫자 하나의 크기는 절댓값으로 재지만, 숫자가 여러 개 모인 벡터는 무엇을 크기라고 할지부터 정해야 해요. 가장 익숙한 답은 화살표의 길이예요. 오른쪽으로 3, 위로 4만큼 간 화살표의 길이는 피타고라스 정리로 5예요.

```python
>>> import stardust as sd
>>> v = sd.asarray([3.0, 4.0])
>>> sd.linalg.vector_norm(v)
5.0
```

`vector_norm`은 원소들을 한 줄로 늘어선 벡터로 보고 크기를 재요. `matrix_norm`은 배열의 마지막 두 축을 행렬로 보고 재요. 기본값끼리는 같은 계산이에요. 모든 원소를 제곱해서 더한 뒤 제곱근을 구해요.

```python
>>> A = sd.asarray([[6.0, -4.0], [8.0, 3.0]])
>>> sd.linalg.matrix_norm(A)
11.180339887498949
>>> sd.linalg.vector_norm(A)
11.180339887498949
```

두 함수가 갈리는 곳은 `ord` 옵션이에요. `ord`는 "무엇을 크기라고 할지"를 고르는데, 벡터에 쓸 수 있는 종류와 행렬에 쓸 수 있는 종류가 달라요.

## 노름은 언제 쓰나요

노름은 "크기"나 "거리"를 재야 하는 거의 모든 곳에 나와요.

| 하고 싶은 일 | 쓰는 방법 |
|---|---|
| 두 점 사이의 거리 | `vector_norm(p - q)` |
| 계산 결과가 정답과 얼마나 다른지 | `vector_norm(계산값 - 정답)` |
| 연립방정식의 해가 얼마나 잘 맞는지 | `vector_norm(a @ x - b)` |
| 방향만 남기고 길이를 1로 맞추기 | `v / vector_norm(v)` |
| 반복 계산을 멈출 때 정하기 | 직전 값과의 차이의 노름이 충분히 작은지 확인 |
| 행렬이 벡터를 최대 몇 배로 늘이는지 | `matrix_norm(a, ord=2)` |

두 점 사이의 거리는 두 벡터의 차이의 노름이에요.

```python
>>> p = sd.asarray([4.0, 6.0])
>>> q = sd.asarray([1.0, 2.0])
>>> sd.linalg.vector_norm(p - q)
5.0
```

벡터를 자기 노름으로 나누면 방향은 같고 길이가 1인 벡터가 돼요.

```python
>>> v / sd.linalg.vector_norm(v)
array([0.6, 0.8], dtype=float64)
```

어떤 종류의 노름이든 다음 세 가지 성질을 지켜요. 모두 "크기"라는 말에서 기대할 만한 성질이에요.

- 노름은 0 이상이고, 모든 원소가 0일 때만 0이에요.
- 벡터를 2배 하면 노름도 2배가 돼요. $\|c\,x\| = |c|\,\|x\|$
- 두 벡터를 더한 것의 노름은 각 노름의 합을 넘지 않아요. $\|x + y\| \le \|x\| + \|y\|$ (돌아가는 길이 곧은 길보다 짧을 수 없다는 뜻이에요.)

## `vector_norm`의 `ord`: 크기를 재는 여러 방법

`ord`는 원소의 크기를 어떻게 하나로 합칠지를 정해요. 원소의 부호는 상관없어요. 언제나 절댓값을 써요.

| `ord` | 이름 | 계산 | `[3, -4]`의 값 |
|:---:|---|---|:---:|
| `2` (기본) | 유클리드 노름 | 제곱해서 더한 뒤 제곱근 | 5 |
| `1` | 맨해튼 노름 | 절댓값의 합 | 7 |
| `sd.inf` | 최대 노름 | 절댓값 중 가장 큰 것 | 4 |
| `-sd.inf` | | 절댓값 중 가장 작은 것 | 3 |
| `0` | | 0이 아닌 원소의 개수 | 2 |
| 그 밖의 수 `p` | p-노름 | 절댓값을 p제곱해서 더한 뒤 p제곱근 | |

```python
>>> w = sd.asarray([3.0, -4.0])
>>> sd.linalg.vector_norm(w)
5.0
>>> sd.linalg.vector_norm(w, ord=1)
7.0
>>> sd.linalg.vector_norm(w, ord=sd.inf)
4.0
>>> sd.linalg.vector_norm(w, ord=-sd.inf)
3.0
```

- `ord=2`는 곧은 길로 잰 길이예요. 특별한 이유가 없으면 이것을 써요.
- `ord=1`은 바둑판 모양 길을 따라 걸을 때의 거리예요. 가로로 3, 세로로 4를 가야 하니 7이에요. 오차를 잴 때 쓰면 큰 오차 하나에 덜 휘둘려요.
- `ord=sd.inf`는 "가장 나쁜 원소 하나"만 봐요. 오차 벡터에 쓰면 "어느 자리도 이 값보다 많이 틀리지 않았다"는 뜻이 돼요.

정확한 정의는 식 하나로 쓸 수 있어요. `p`가 `ord`예요.

$$\|x\|_p = \Bigl(\sum_i |x_i|^p\Bigr)^{1/p}$$

`p = 2`를 넣으면 유클리드 노름, `p = 1`을 넣으면 절댓값의 합이에요. `p`를 키울수록 가장 큰 원소가 합을 차지하는 몫이 커져서, 끝없이 키우면 가장 큰 절댓값만 남아요. 그래서 `ord=sd.inf`가 최댓값이에요.

```python
>>> sd.linalg.vector_norm(w, ord=3)
4.497941445275415
>>> sd.linalg.vector_norm(w, ord=10)
4.021974149822332
>>> sd.linalg.vector_norm(w, ord=100)
4.000000000000013
```

세 노름의 차이는 "노름이 정확히 1인 점"을 모아 보면 한눈에 보여요. 유클리드 노름에서는 원, `ord=1`에서는 마름모, `ord=sd.inf`에서는 정사각형이에요.

### `ord=0`과 음수 `ord`

`ord=0`은 0이 아닌 원소가 몇 개인지 세요. 결과는 개수이지만 다른 노름과 마찬가지로 float이에요.

```python
>>> sd.linalg.vector_norm(sd.asarray([3.0, 0.0, -4.0, 0.0]), ord=0)
2.0
```

음수 `ord`도 같은 식으로 계산해요. `ord=-1`이면 역수를 더한 뒤 다시 역수를 구해요.

```python
>>> sd.linalg.vector_norm(sd.asarray([3.0, 6.0]), ord=-1)
2.0
```

<Callout title="이름은 노름이지만 노름이 아닌 것들">
  `ord=0`, 1보다 작은 `ord`, 음수 `ord`, `-sd.inf`로 구한 값은 위에서 말한 세 가지 성질을 지키지 않아요. 예를 들어 벡터를 2배 해도 0이 아닌 원소의 개수는 그대로예요. 계산은 해 주지만 "크기"나 "거리"로 쓰기에는 맞지 않아요.
</Callout>

## `axis`: 여러 벡터의 노름을 한 번에

`axis`를 주지 않으면 배열이 몇 차원이든 모든 원소를 벡터 하나로 봐요. `axis`를 주면 그 축을 따라 늘어선 원소들이 벡터 하나가 되고, 벡터마다 노름이 하나씩 나와요. 2차원 배열에서 `axis=1`은 행마다, `axis=0`은 열마다예요.

```python
>>> pts = sd.asarray([[3.0, 4.0], [5.0, 12.0]])
>>> sd.linalg.vector_norm(pts)
13.92838827718412
>>> sd.linalg.vector_norm(pts, axis=1)
array([ 5.0, 13.0], dtype=float64)
>>> sd.linalg.vector_norm(pts, axis=0)
array([ 5.830951894845301, 12.649110640673518], dtype=float64)
```

<Fig caption="axis=1이면 행 하나하나가 벡터예요. 행마다 길이가 하나씩 나와요.">
  <ArrayFig name="pts" data={[[3, 4], [5, 12]]} tones={[['a', 'a'], ['b', 'b']]} axes note="shape (2, 2)" />
  <Op note="axis=1">→</Op>
  <ArrayFig name="vector_norm(pts, axis=1)" data={[[5], [13]]} tones={[['a'], ['b']]} note="shape (2,)" />
</Fig>

`axis`의 뜻과 규칙은 [`sd.sum`](/api/array/sum/)의 `axis`와 같아요. 음수는 뒤에서부터 세고, tuple이나 list로 여러 축을 한꺼번에 줄 수 있어요. 여러 축을 주면 그 축의 원소를 모두 모아 벡터 하나로 봐요.

`keepdims=True`를 주면 줄어든 축이 길이 1로 남아요. 결과를 원래 배열과 함께 계산할 때 필요해요. 예를 들어 각 행을 그 행의 길이로 나눠서 모든 행의 길이를 1로 맞출 수 있어요.

```python
>>> sd.linalg.vector_norm(pts, axis=1, keepdims=True)
array([[ 5.0],
       [13.0]], dtype=float64)
>>> unit = pts / sd.linalg.vector_norm(pts, axis=1, keepdims=True)
>>> unit
array([[                0.6,                 0.8],
       [0.38461538461538464,  0.9230769230769231]], dtype=float64)
>>> sd.linalg.vector_norm(unit, axis=1)
array([1.0, 1.0], dtype=float64)
```

## `matrix_norm`의 `ord`: 행렬의 크기를 재는 방법

행렬은 숫자가 네모로 놓인 표이기도 하지만, 벡터를 다른 벡터로 바꾸는 변환이기도 해요. 그래서 행렬의 크기는 두 가지로 볼 수 있어요. 원소가 얼마나 큰가, 그리고 벡터를 얼마나 크게 늘이는가예요.

`matrix_norm`의 `ord`는 아래 여덟 가지 가운데 하나여야 해요. 예로 쓰는 행렬은 위에서 만든 `A`예요. 몇몇 `ord`는 **특이값**(singular value)으로 정의돼요. 특이값은 행렬이 벡터를 늘이는 배율이고, 자세한 설명은 [특이값 분해](/api/linalg/svd/) 문서에 있어요.

<Fig caption="예제 행렬 A. 이 행렬의 특이값은 10과 5예요.">
  <ArrayFig name="A" data={[[6, -4], [8, 3]]} note="shape (2, 2)" />
</Fig>

| `ord` | 이름 | 계산 | `A`의 값 |
|:---:|---|---|:---:|
| `'fro'` (기본) | 프로베니우스 노름 | 모든 원소를 제곱해서 더한 뒤 제곱근 | 11.18… |
| `1` | 1-노름 | 열마다 절댓값을 더한 것 중 가장 큰 값 | 14 |
| `sd.inf` | 무한대 노름 | 행마다 절댓값을 더한 것 중 가장 큰 값 | 11 |
| `2` | 2-노름(스펙트럼 노름) | 가장 큰 특이값 | 10 |
| `'nuc'` | 핵 노름 | 특이값의 합 | 15 |
| `-1` | | 열마다 절댓값을 더한 것 중 가장 작은 값 | 7 |
| `-sd.inf` | | 행마다 절댓값을 더한 것 중 가장 작은 값 | 10 |
| `-2` | | 가장 작은 특이값 | 5 |

```python
>>> sd.linalg.matrix_norm(A, ord=1)
14.0
>>> sd.linalg.matrix_norm(A, ord=sd.inf)
11.0
>>> sd.linalg.matrix_norm(A, ord=2)
10.0
>>> sd.linalg.matrix_norm(A, ord='nuc')
15.0
```

### `'fro'`: 원소들의 크기

프로베니우스 노름은 행렬을 한 줄로 편 벡터의 유클리드 노름이에요. 변환이라는 뜻은 접어 두고 "원소가 전체적으로 얼마나 큰가"를 재요. 두 행렬이 얼마나 다른지 볼 때 `matrix_norm(a - b)`로 가장 흔히 써요. 계산도 가장 가벼워요.

$$\|A\|_F = \sqrt{\sum_{i,j} |a_{ij}|^2}$$

### `1`과 `sd.inf`: 열의 합, 행의 합

`ord=1`은 열마다 절댓값을 더해서 가장 큰 것을, `ord=sd.inf`는 행마다 절댓값을 더해서 가장 큰 것을 골라요.

둘 다 덧셈과 비교만으로 구할 수 있어서 빨라요. 뜻은 바로 다음에 나오는 2-노름과 닮았어요. 벡터의 크기를 `ord=1`(또는 `ord=sd.inf`)인 `vector_norm`으로 잴 때, 행렬이 벡터를 최대 몇 배로 늘이는지가 바로 이 값이에요.

### `2`: 벡터를 가장 크게 늘이는 배율

행렬 `A`에 벡터 `x`를 곱하면 새 벡터 `A @ x`가 나와요. 길이가 몇 배가 되는지는 `x`의 방향에 따라 달라요. 그 배율 가운데 가장 큰 값이 2-노름이에요.

$$\|A\|_2 = \max_{x \ne 0} \frac{\|A x\|_2}{\|x\|_2}$$

`A`에 길이가 1인 벡터 셋을 곱해 볼게요.

```python
>>> sd.linalg.vector_norm(A @ sd.asarray([1.0, 0.0]))
10.0
>>> sd.linalg.vector_norm(A @ sd.asarray([0.0, 1.0]))
5.0
>>> sd.linalg.vector_norm(A @ sd.asarray([0.6, 0.8]))
7.211102550927978
```

방향에 따라 5배에서 10배까지 늘어나요. 어느 방향을 넣어도 10배를 넘지 않고, 5배보다 덜 늘어나지도 않아요. 가장 큰 배율 10이 `ord=2`, 가장 작은 배율 5가 `ord=-2`예요.

```python
>>> sd.linalg.matrix_norm(A, ord=2)
10.0
>>> sd.linalg.matrix_norm(A, ord=-2)
5.0
```

이 둘의 비 `10 / 5`가 [조건수](/api/linalg/cond/)예요. 2-노름과 핵 노름은 특이값을 구해야 해서 다른 `ord`보다 계산이 훨씬 무거워요.

### `'nuc'`: 특이값의 합

핵 노름은 모든 특이값을 더한 값이에요. 행렬의 [랭크](/api/linalg/matrix_rank/)를 낮추고 싶은 최적화 문제에서 "랭크 대신 줄일 값"으로 자주 써요.

## 여러 행렬을 한 번에

`matrix_norm`은 언제나 마지막 두 축을 행렬로 봐요. 3차원 이상의 배열은 행렬 여러 개를 쌓은 것(배치)으로 보고, 행렬마다 노름을 하나씩 돌려줘요. 그래서 `axis` 옵션이 없어요.

```python
>>> stack = sd.asarray([[[3.0, 0.0], [0.0, 4.0]],
...                     [[6.0, -4.0], [8.0, 3.0]]])
>>> stack.shape
(2, 2, 2)
>>> sd.linalg.matrix_norm(stack, ord=2)
array([ 4.0, 10.0], dtype=float64)
```

`keepdims=True`면 행렬이었던 두 축이 길이 1로 남아요.

```python
>>> sd.linalg.matrix_norm(stack, ord=2, keepdims=True).shape
(2, 1, 1)
>>> sd.linalg.matrix_norm(A, keepdims=True)
array([[11.180339887498949]], dtype=float64)
```

정사각 행렬이 아니어도 돼요.

```python
>>> sd.linalg.matrix_norm(sd.asarray([[1, -2, 3], [-4, 5, -6]]), ord=1)
9.0
```

## 조심할 점

### 같은 `ord=1`이라도 두 함수의 뜻이 달라요

`vector_norm`에 행렬을 넣으면 행렬을 한 줄로 편 벡터로 봐요. 그래서 `ord=1`은 모든 원소의 절댓값 합이에요. `matrix_norm`의 `ord=1`은 열 합의 최댓값이에요. `ord=2`와 `ord=sd.inf`도 마찬가지로 서로 다른 값이에요.

```python
>>> sd.linalg.vector_norm(A, ord=1)
21.0
>>> sd.linalg.matrix_norm(A, ord=1)
14.0
>>> sd.linalg.vector_norm(A, ord=2)
11.180339887498949
>>> sd.linalg.matrix_norm(A, ord=2)
10.0
```

| `ord` | `vector_norm(A, ord=…)` | `matrix_norm(A, ord=…)` |
|:---:|---|---|
| `1` | 모든 원소의 절댓값 합 | 열 합의 최댓값 |
| `2` | 모든 원소의 제곱합의 제곱근 (`'fro'`와 같음) | 가장 큰 특이값 |
| `sd.inf` | 절댓값이 가장 큰 원소 | 행 합의 최댓값 |

### 결과는 언제나 실수예요

정수 배열이나 bool 배열을 넣어도 결과는 float64예요. 복소수 배열의 노름도 실수예요. 복소수 원소는 그 크기(절댓값)로 계산해요.

```python
>>> sd.linalg.vector_norm(sd.asarray([3, 4]))
5.0
>>> sd.linalg.vector_norm(sd.asarray([3+4j, 12j]))
13.0
```

남는 축이 없으면 배열이 아니라 Python `float`이에요. 정수를 넣어도 실수가 나오는 것은 `sd.linalg`의 모든 함수에 공통이에요. [선형대수의 기본](/api/linalg/basics/) 문서에 정리돼 있어요.

### 아주 큰 값도 넘치지 않아요

직접 제곱해서 더하면 중간에 값이 넘쳐서 `inf`가 될 수 있어요. `1e200`의 제곱은 float64에 담을 수 없기 때문이에요. `vector_norm`과 `matrix_norm`은 결과 자체를 담을 수 있으면 바른 값을 돌려줘요.

```python
>>> big = sd.asarray([1e200, 1e200])
>>> sd.sqrt(sd.sum(big * big))
inf
>>> sd.linalg.vector_norm(big)
1.414213562373095e+200
```

노름이 필요하면 직접 계산하지 말고 이 두 함수를 쓰세요.

### NaN과 inf

`vector_norm`은 NaN과 inf를 검사하지 않고 그대로 계산해요. NaN이 하나라도 있으면 결과가 NaN이고, inf가 있으면 inf예요. `ord=0`만 예외예요. NaN도 "0이 아닌 원소"로 세요.

```python
>>> sd.linalg.vector_norm(sd.asarray([1.0, sd.nan]))
nan
>>> sd.linalg.vector_norm(sd.asarray([1.0, sd.inf]))
inf
>>> sd.linalg.vector_norm(sd.asarray([1.0, sd.nan]), ord=0)
2.0
```

`matrix_norm`은 `ord`에 따라 달라요. 덧셈만으로 구하는 `'fro'`, `1`, `-1`, `sd.inf`, `-sd.inf`는 NaN을 그대로 전파해요. 특이값이 필요한 `2`, `-2`, `'nuc'`는 계산 전에 검사해서 `ValueError`를 내요.

```python
>>> bad = sd.asarray([[1.0, sd.nan], [0.0, 1.0]])
>>> sd.linalg.matrix_norm(bad)
nan
>>> sd.linalg.matrix_norm(bad, ord=2)
Traceback (most recent call last):
    ...
ValueError: matrix_norm(): 'x' contains NaN or infinity
```

<Callout type="warn" title="같은 함수인데 ord에 따라 에러가 나기도, 안 나기도 해요">
  NaN이 섞인 행렬의 노름을 구할 때 `ord='fro'`에서는 `nan`이 조용히 나오고, `ord=2`에서는 에러가 나요. `ord`를 바꾸면서 코드를 고칠 때 이 차이를 기억해 두세요. 어떤 함수가 검사하는지는 [실패와 에러](/api/linalg/errors/) 문서에 모아 뒀어요.
</Callout>

### 빈 배열의 노름은 0이에요

원소가 하나도 없으면 어떤 `ord`에서도 결과는 `0.0`이에요. 에러가 아니에요.

```python
>>> sd.linalg.vector_norm(sd.asarray([]))
0.0
>>> sd.linalg.matrix_norm(sd.zeros((0, 3)), ord=2)
0.0
```

### `ord`에 쓸 수 있는 값

`vector_norm`의 `ord`는 숫자만 받아요. `'fro'` 같은 문자열, `None`, `True`는 `TypeError`예요.

```python
>>> sd.linalg.vector_norm(v, ord='fro')
Traceback (most recent call last):
    ...
TypeError: vector_norm(): 'ord' must be an int or a float, not str
```

`matrix_norm`의 `ord`는 표에 있는 여덟 가지뿐이에요. 벡터와 달리 `3` 같은 다른 숫자는 쓸 수 없어요. 문자열은 소문자로 정확히 써야 해요.

```python
>>> sd.linalg.matrix_norm(A, ord=3)
Traceback (most recent call last):
    ...
ValueError: matrix_norm(): 'ord' must be 'fro', 'nuc', 1, -1, 2, -2, inf or -inf, not 3
>>> sd.linalg.matrix_norm(A, ord=None)
Traceback (most recent call last):
    ...
TypeError: matrix_norm(): 'ord' must be a str, an int or a float, not NoneType
```

`1.0`이나 `2.0`처럼 값이 같은 실수는 받아요.

### 옵션은 이름을 붙여서, 입력은 배열로

`ord`, `axis`, `keepdims`는 반드시 이름과 함께 써야 해요. `vector_norm(v, 1)`처럼 자리로 넘기면 `TypeError`예요. 리스트도 받지 않아요. 먼저 [`sd.asarray`](/api/array/asarray/)로 배열을 만드세요.

```python
>>> sd.linalg.vector_norm([3.0, 4.0])
Traceback (most recent call last):
    ...
TypeError: vector_norm(): 'x' must be an sd.ndarray, not list
```

`matrix_norm`에는 2차원 이상의 배열만 넣을 수 있어요.

```python
>>> sd.linalg.matrix_norm(v)
Traceback (most recent call last):
    ...
ValueError: matrix_norm(): 'x' must have at least 2 dimensions, got 1
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 다른 점 |
|---|---|---|
| 벡터의 길이, 두 점 사이의 거리 | `vector_norm` | 원소를 한 줄의 벡터로 봐요. `axis`로 방향을 골라요. |
| 행렬의 크기, 행렬이 늘이는 최대 배율 | `matrix_norm` | 마지막 두 축을 행렬로 봐요. `ord`가 여덟 가지로 정해져 있어요. |
| 원소 하나하나의 절댓값 | [`sd.abs`](/api/array/sign/) | 숫자 하나로 줄이지 않고 같은 모양의 배열을 돌려줘요. |
| 길이의 제곱 | [`vecdot(x, x)`](/api/linalg/vecdot/) | 제곱근을 구하지 않은 값이에요. 큰 값에서는 넘칠 수 있어요. |
| 특이값 전부 | [`svdvals`](/api/linalg/svd/) | `ord=2`는 그중 가장 큰 것, `'nuc'`는 합, `-2`는 가장 작은 것이에요. |
| 행렬이 계산 오차를 얼마나 키우는지 | [`cond`](/api/linalg/cond/) | 가장 큰 배율과 가장 작은 배율의 비예요. |
| 0이 아닌 원소의 개수 | [`sd.count_nonzero`](/api/array/count_nonzero/) | `ord=0`과 같은 수를 정수로 돌려줘요. |

## numpy·scipy를 아는 분께

- `np.linalg.norm`처럼 벡터와 행렬을 한 함수로 다루는 함수는 없어요. `vector_norm`과 `matrix_norm` 둘로 나뉘어 있고, 인자의 이름과 기본값은 `np.linalg.vector_norm`, `np.linalg.matrix_norm`과 같아요.
- 결과가 숫자 하나면 numpy 스칼라가 아니라 Python `float`이에요.
- 아주 크거나 작은 값에서 중간 계산이 넘치지 않아요. `vector_norm(asarray([1e200, 1e200]))`은 `1.414e200`이에요. numpy는 `inf`를 돌려줘요.
- `matrix_norm`의 `ord`가 `2`, `-2`, `'nuc'`일 때 NaN이나 inf가 있으면 `ValueError`예요. numpy는 `LinAlgError`("SVD did not converge")를 내요.
- `ord=True`, `ord=None`은 `TypeError`예요. `matrix_norm`의 표에 없는 `ord`는 `ValueError`예요.
- 리스트와 numpy 배열은 받지 않아요. `sd.asarray`로 먼저 바꾸세요.
