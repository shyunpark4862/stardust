## 한눈에 보기

`outer`는 두 벡터에서 **가능한 모든 쌍의 곱**을 만들어 행렬로 돌려줘요. 구구단 표를 떠올리면 돼요. 세로에 놓인 수와 가로에 놓인 수를 하나씩 골라 곱한 값이 표의 한 칸이에요.

```python
>>> import stardust as sd
>>> x = sd.asarray([1.0, 2.0, 3.0])
>>> y = sd.asarray([4.0, 5.0])
>>> sd.linalg.outer(x, y)
array([[ 4.0,  5.0],
       [ 8.0, 10.0],
       [12.0, 15.0]], dtype=float64)
```

결과의 **i행 j열**은 `x[i] * y[j]`예요. 수식으로는 이렇게 써요.

$$
(x \otimes y)_{ij} = x_i\, y_j
$$

길이가 `M`인 벡터와 `N`인 벡터를 넣으면 `M`행 `N`열의 행렬이 나와요. 두 벡터의 길이는 달라도 돼요.

벡터 두 개에서 숫자 하나가 나오는 내적([`vecdot`](/api/linalg/vecdot/))과 방향이 반대예요. 내적은 같은 자리끼리만 곱해서 **모두 더하고**, 외적은 모든 쌍을 곱해서 **더하지 않고 펼쳐 놓아요.**

## 결과 읽는 법: 행은 `x1`, 열은 `x2`

결과의 각 행은 `x2`에 `x1`의 원소 하나를 곱한 것이고, 각 열은 `x1`에 `x2`의 원소 하나를 곱한 것이에요.

| | `y[0] = 4` | `y[1] = 5` |
|:---:|:---:|:---:|
| **`x[0] = 1`** | 1 × 4 = 4 | 1 × 5 = 5 |
| **`x[1] = 2`** | 2 × 4 = 8 | 2 × 5 = 10 |
| **`x[2] = 3`** | 3 × 4 = 12 | 3 × 5 = 15 |

두 인자의 순서를 바꾸면 행과 열이 바뀌어요. `outer(y, x)`는 `outer(x, y)`의 전치(행과 열을 맞바꾼 것)예요.

```python
>>> sd.linalg.outer(y, x)
array([[ 4.0,  8.0, 12.0],
       [ 5.0, 10.0, 15.0]], dtype=float64)
```

## 어디에 쓰나요

### 모든 조합의 표 만들기

단가가 세 가지, 수량이 두 가지일 때 가능한 모든 조합의 금액을 한 번에 구할 수 있어요.

```python
>>> price = sd.asarray([500.0, 1200.0, 800.0])
>>> qty = sd.asarray([1.0, 10.0])
>>> sd.linalg.outer(price, qty)
array([[  500.0,  5000.0],
       [ 1200.0, 12000.0],
       [  800.0,  8000.0]], dtype=float64)
```

### 가장 단순한 행렬: 랭크 1

외적으로 만든 행렬은 모든 행이 `x2`의 배수이고, 모든 열이 `x1`의 배수예요. 서로 다른 방향의 행이 하나뿐이라는 뜻이고, 이런 행렬을 **랭크 1** 행렬이라고 해요([`matrix_rank`](/api/linalg/matrix_rank/)).

```python
>>> sd.linalg.matrix_rank(sd.linalg.outer(x, y))
1
```

랭크 1 행렬은 행렬을 쌓는 벽돌 같은 것이에요. 어떤 행렬이든 랭크 1 행렬 몇 개의 합으로 쓸 수 있고, [특이값 분해](/api/linalg/svd/)가 바로 그 벽돌들을 찾아 주는 분해예요.

외적으로 만든 행렬을 벡터에 곱하면 계산이 단순해져요. $(x \otimes y)\,v = x\,(y \cdot v)$, 즉 `y`와 `v`의 내적을 구해 `x`에 곱한 것과 같아요.

```python
>>> v = sd.asarray([1.0, 1.0])
>>> sd.linalg.outer(x, y) @ v
array([ 9.0, 18.0, 27.0], dtype=float64)
>>> x * sd.linalg.vecdot(y, v)
array([ 9.0, 18.0, 27.0], dtype=float64)
```

### 한 방향으로 투영하는 행렬

벡터 `d`와 자기 자신의 외적을 `d`의 길이의 제곱으로 나누면, **어떤 벡터든 `d` 방향의 성분만 남기는 행렬**이 돼요.

$$
P = \frac{d \otimes d}{d \cdot d}
$$

```python
>>> d = sd.asarray([1.0, 1.0])
>>> P = sd.linalg.outer(d, d) / sd.linalg.vecdot(d, d)
>>> P
array([[0.5, 0.5],
       [0.5, 0.5]], dtype=float64)
>>> P @ sd.asarray([3.0, 1.0])
array([2.0, 2.0], dtype=float64)
```

점 `(3, 1)`을 대각선 방향 `(1, 1)` 위로 수직으로 내린 자리가 `(2, 2)`예요.

## 벡터 여러 쌍을 한꺼번에

2차원 이상의 배열을 넣으면 **마지막 축이 벡터**이고, 그 앞의 축은 "몇 번째 벡터인가"를 나타내는 배치 축이에요. 같은 자리의 벡터끼리 외적을 구해서 행렬을 쌓아 돌려줘요.

```python
>>> xs = sd.asarray([[1.0, 2.0, 3.0], [0.0, 1.0, 0.0]])
>>> ys = sd.asarray([[4.0, 5.0], [7.0, 8.0]])
>>> r = sd.linalg.outer(xs, ys)
>>> r.shape
(2, 3, 2)
>>> r[0]
array([[ 4.0,  5.0],
       [ 8.0, 10.0],
       [12.0, 15.0]], dtype=float64)
>>> r[1]
array([[0.0, 0.0],
       [7.0, 8.0],
       [0.0, 0.0]], dtype=float64)
```

`r[i]`는 `outer(xs[i], ys[i])`예요. `xs`의 모든 행과 `ys`의 모든 행을 조합하는 것이 **아니에요.** 벡터 축(마지막 축)끼리만 모든 쌍을 만들고, 배치 축은 같은 자리끼리 짝지어요.

배치 축은 [브로드캐스팅](/api/array/broadcasting/)으로 맞춰요. 한쪽이 벡터 하나면 다른 쪽의 모든 벡터와 짝지어요.

```python
>>> sd.linalg.outer(xs, y).shape
(2, 3, 2)
>>> sd.linalg.outer(sd.ones((5, 1, 3)), sd.ones((2, 4))).shape
(5, 2, 3, 4)
```

| `x1` | `x2` | 배치 축 맞추기 | 벡터 축 | 결과 |
|:---:|:---:|---|:---:|:---:|
| `(3,)` | `(2,)` | 없음 | 3과 2 | `(3, 2)` |
| `(2, 3)` | `(2, 2)` | `(2,)`와 `(2,)` → `(2,)` | 3과 2 | `(2, 3, 2)` |
| `(2, 3)` | `(2,)` | `(2,)`와 `()` → `(2,)` | 3과 2 | `(2, 3, 2)` |
| `(5, 1, 3)` | `(2, 4)` | `(5, 1)`과 `(2,)` → `(5, 2)` | 3과 4 | `(5, 2, 3, 4)` |
| `(3, 3)` | `(2, 4)` | `(3,)`과 `(2,)` → 안 맞음 | | 에러 |

배치 축이 맞지 않으면 `ValueError`예요. 메시지에는 배치 축의 모양만 나와요.

```python
>>> sd.linalg.outer(sd.ones((3, 3)), sd.ones((2, 4)))
Traceback (most recent call last):
    ...
ValueError: outer(): batch shapes do not broadcast: (3,) (2,)
```

<Callout type="warn" title="2차원 배열을 넣어도 펴지 않아요">

2차원 배열 두 개를 넣었을 때 "모든 원소를 한 줄로 편 다음 외적"을 기대했다면 결과가 달라요. `outer`는 행마다 따로 계산해요. 모든 원소 쌍의 곱이 필요하면 먼저 `sd.reshape(x, (-1,))`로 1차원으로 펴서 넣으세요.

</Callout>

## 결과의 dtype: 정수를 넣어도 float64

`sd.linalg`의 함수는 언제나 실수(float64)나 복소수(complex128)로 계산해요. 정수나 bool 벡터를 넣어도 결과는 float64예요.

```python
>>> a = sd.asarray([1, 2, 3])
>>> b = sd.asarray([4, 5])
>>> sd.linalg.outer(a, b)
array([[ 4.0,  5.0],
       [ 8.0, 10.0],
       [12.0, 15.0]], dtype=float64)
```

정수 결과가 필요하면 배열 영역의 연산을 쓰세요. 세로로 세운 `a`에 `b`를 곱하면 브로드캐스팅으로 같은 표가 **정수로** 나와요. [`sd.tensordot`](/api/array/tensordot/)에 `axes=0`을 줘도 같아요.

```python
>>> a[:, None] * b
array([[ 4,  5],
       [ 8, 10],
       [12, 15]], dtype=int64)
>>> sd.tensordot(a, b, axes=0)
array([[ 4,  5],
       [ 8, 10],
       [12, 15]], dtype=int64)
```

| 입력 | `sd.linalg.outer` | `x1[:, None] * x2`, `sd.tensordot(x1, x2, axes=0)` |
|:---:|:---:|:---:|
| bool | float64 | int64 |
| int64 | float64 | int64 |
| float64 | float64 | float64 |
| complex128 | complex128 | complex128 |

### 복소수: 켤레를 취하지 않아요

복소수 벡터도 **적힌 값 그대로** 곱해요. 어느 쪽 인자도 켤레 복소수(허수부의 부호를 바꾼 수)로 바꾸지 않아요. 첫째 인자의 켤레를 쓰는 [`vecdot`](/api/linalg/vecdot/)과 다른 점이에요.

```python
>>> z = sd.asarray([1 + 2j, 3j])
>>> w = sd.asarray([2 + 0j, 1 - 1j])
>>> sd.linalg.outer(z, w)
array([[(2+4j), (3+1j)],
       [    6j, (3+3j)]], dtype=complex128)
```

복소수 벡터에서는 둘째 벡터의 켤레를 곱한 $x\,y^{H}$(원소로는 $x_i\,\overline{y_j}$)가 필요할 때가 많아요. 그럴 때는 [`sd.conj`](/api/array/complex/)를 직접 써요. 자기 자신과 이렇게 외적하면 대각선이 실수이고 대각선 건너편끼리 서로 켤레인 에르미트 행렬이 돼요.

```python
>>> sd.linalg.outer(z, sd.conj(z))
array([[(5+0j), (6-3j)],
       [(6+3j), (9+0j)]], dtype=complex128)
```

## 조심할 점

### NaN과 inf는 검사하지 않고 그대로 계산해요

`outer`는 곱하기만 하는 함수라서 입력에 NaN(숫자가 아님)이나 inf(무한대)가 있어도 에러를 내지 않아요. 그 원소가 들어간 칸만 NaN이나 inf가 되고, 0과 inf를 곱한 칸은 NaN이에요.

```python
>>> sd.linalg.outer(sd.asarray([1.0, sd.nan]), sd.asarray([0.0, sd.inf]))
array([[0.0, inf],
       [nan, nan]], dtype=float64)
```

곱이 float64가 담을 수 있는 범위(약 1.8 × 10³⁰⁸)를 넘는 칸은 에러 없이 inf가 돼요.

```python
>>> sd.linalg.outer(sd.asarray([1e200, 1.0]), sd.asarray([1e200, 2.0]))
array([[   inf, 2e+200],
       [1e+200,    2.0]], dtype=float64)
```

### 아주 큰 정수는 끝자리가 달라질 수 있어요

정수도 float64로 바꿔서 곱하기 때문에, 약 2⁵³(9 × 10¹⁵)을 넘는 정수는 정확히 담지 못할 수 있어요.

```python
>>> sd.linalg.outer(sd.asarray([2**53 + 1]), sd.asarray([1]))
array([[9007199254740992.0]], dtype=float64)
>>> sd.asarray([2**53 + 1])[:, None] * sd.asarray([1])
array([[9007199254740993]], dtype=int64)
```

### 결과가 금방 커져요

길이 `M`과 `N`의 벡터에서 원소 `M × N`개짜리 행렬이 나와요. 길이 10만인 벡터 두 개의 외적은 원소가 100억 개(80GB)예요. 외적으로 만든 행렬을 다시 벡터에 곱할 생각이라면 행렬을 만들지 말고 `x * vecdot(y, v)`처럼 계산하세요.

### 빈 벡터

길이 0인 벡터를 넣으면 그 방향의 크기가 0인 빈 행렬이 나와요. 에러가 아니에요.

```python
>>> sd.linalg.outer(sd.zeros(0), x)
array([], shape=(0, 3), dtype=float64)
>>> sd.linalg.outer(x, sd.zeros(0)).shape
(3, 0)
```

### 배열만 받아요

리스트나 Python 숫자는 받지 않아요. 먼저 [`asarray`](/api/array/asarray/)로 배열로 바꾸세요. 벡터에 숫자 하나를 곱하려는 것이라면 `x * 2.0`이면 돼요.

```python
>>> sd.linalg.outer(x, [4.0, 5.0])
Traceback (most recent call last):
    ...
TypeError: outer(): 'x2' must be an sd.ndarray, not list
>>> sd.linalg.outer(x, 2.0)
Traceback (most recent call last):
    ...
TypeError: outer(): 'x2' must be an sd.ndarray, not float
```

## 비슷한 함수와의 차이

"곱"이라는 이름이 붙은 계산이 여럿이라 헷갈리기 쉬워요. 길이 3인 `x`와 길이 2인 `y`를 넣었을 때를 기준으로 정리하면 이래요.

| 계산 | 하는 일 | 결과 | 정수 입력 | 복소수 |
|---|---|:---:|:---:|---|
| `sd.linalg.outer(x, y)` | 모든 쌍의 곱을 표로 | `(3, 2)` 행렬 | float64 | 켤레 없음 |
| [`sd.linalg.vecdot(x, y)`](/api/linalg/vecdot/) | 같은 자리끼리 곱해서 더하기 | 숫자 하나 (길이가 같아야 해요) | float64 | `x`의 켤레 |
| [`sd.linalg.cross(x, y)`](/api/linalg/cross/) | 둘 모두에 직각인 벡터 | 길이 3 벡터 (둘 다 길이 3이어야 해요) | float64 | 켤레 없음 |
| [`sd.linalg.kron(A, B)`](/api/linalg/kron/) | 행렬의 원소마다 다른 행렬을 통째로 곱해 붙이기 | 더 큰 행렬 | float64 | 켤레 없음 |
| `x[:, None] * y` | 브로드캐스팅으로 같은 표 | `(3, 2)` 행렬 | int64 유지 | 켤레 없음 |
| [`sd.tensordot(x, y, axes=0)`](/api/array/tensordot/) | 모든 쌍의 곱 | `(3, 2)` 행렬 | int64 유지 | 켤레 없음 |
| [`x @ y`](/api/array/matmul/) | 행과 열을 짝지어 곱하고 더하기 | 숫자 하나 (길이가 같아야 해요) | int64 유지 | 켤레 없음 |

### `kron`과의 관계

외적은 [크로네커 곱](/api/linalg/kron/)의 특별한 경우예요. `x`를 세로 한 줄짜리 행렬 `(M, 1)`로, `y`를 가로 한 줄짜리 행렬 `(1, N)`으로 놓고 `kron`을 하면 `outer(x, y)`와 같은 행렬이 나와요. 둘 다 가로 한 줄로 놓으면 같은 값들이 한 줄로 이어져요.

```python
>>> sd.linalg.kron(sd.reshape(x, (3, 1)), sd.reshape(y, (1, 2)))
array([[ 4.0,  5.0],
       [ 8.0, 10.0],
       [12.0, 15.0]], dtype=float64)
>>> sd.linalg.kron(sd.reshape(x, (1, 3)), sd.reshape(y, (1, 2)))
array([[ 4.0,  5.0,  8.0, 10.0, 12.0, 15.0]], dtype=float64)
```

### `@`와의 관계

세로 한 줄 `(M, 1)`과 가로 한 줄 `(1, N)`의 행렬곱도 같은 표예요. 반대로 가로 한 줄과 세로 한 줄을 곱하면 내적이 돼요. 순서에 따라 외적과 내적이 갈려요.

```python
>>> sd.reshape(x, (3, 1)) @ sd.reshape(y, (1, 2))
array([[ 4.0,  5.0],
       [ 8.0, 10.0],
       [12.0, 15.0]], dtype=float64)
```

### `tensordot(axes=0)`과 배치

1차원 벡터 두 개에서는 `sd.tensordot(x, y, axes=0)`이 `outer`와 같은 표를 줘요. 2차원 이상에서는 달라요. `tensordot`은 배치를 짝짓지 않고 **모든 축을 조합**해요.

```python
>>> sd.linalg.outer(xs, ys).shape
(2, 3, 2)
>>> sd.tensordot(xs, ys, axes=0).shape
(2, 3, 2, 2)
```

## numpy·scipy를 아는 분께

- **2차원 이상의 입력을 펴지 않아요.** `np.outer`는 입력을 1차원으로 편 다음 계산하고, `np.linalg.outer`는 1차원만 받아요. `sd.linalg.outer`는 마지막 축을 벡터로 보고 앞쪽 축을 배치로 브로드캐스팅해요.
- **정수와 bool 입력의 결과가 float64예요.** numpy는 정수를 유지해요.
- 켤레를 취하지 않는 것은 `np.outer`와 같아요.
- 리스트와 numpy 배열, Python 숫자는 받지 않아요(`TypeError`). `out=` 인자도 없어요.
