## 한눈에 보기

**행렬식**(determinant)은 정사각 행렬 하나에 숫자 하나를 짝지은 값이에요. `det`이 그 값을 구해요.

```python
>>> import stardust as sd
>>> a = sd.asarray([[3.0, 1.0], [1.0, 2.0]])
>>> sd.linalg.det(a)
5.0
```

2×2 행렬이면 대각선끼리 곱해서 뺀 값이에요. 위 예는 `3×2 - 1×1 = 5`예요.

`slogdet`은 같은 값을 **부호**와 **절댓값의 로그** 둘로 나눠서 돌려줘요. 행렬이 커서 행렬식이 숫자에 담기지 않을 만큼 크거나 작을 때 써요.

```python
>>> sd.linalg.slogdet(a)
SlogdetResult(sign=1.0, logabsdet=1.6094379124341005)
```

부호는 `+1`, 절댓값의 로그는 `log(5)`예요.

## 행렬식은 무엇을 말해 주나요

행렬은 벡터를 다른 벡터로 옮기는 변환이에요. 평면 위의 도형을 행렬로 옮기면 도형이 늘어나거나 기울어져요. 이때 **넓이가 몇 배가 되는지**가 행렬식이에요. 3×3 행렬이면 부피가 몇 배가 되는지예요.

| 행렬 | 하는 일 | 행렬식 | 뜻 |
|:---:|---|:---:|---|
| `[[2, 0], [0, 3]]` | 가로로 2배, 세로로 3배 늘려요 | 6 | 넓이가 6배가 돼요 |
| `[[1, 1], [0, 1]]` | 옆으로 기울여요 | 1 | 모양은 바뀌어도 넓이는 그대로예요 |
| `[[0, 1], [1, 0]]` | 가로와 세로를 맞바꿔요 | -1 | 넓이는 그대로인데 거울에 비친 것처럼 뒤집혀요 |
| `[[1, 2], [2, 4]]` | 모든 점을 한 직선 위로 눌러요 | 0 | 넓이가 사라져요 |

```python
>>> sd.linalg.det(sd.asarray([[2.0, 0.0], [0.0, 3.0]]))
6.0
>>> sd.linalg.det(sd.asarray([[0.0, 1.0], [1.0, 0.0]]))
-1.0
>>> sd.linalg.det(sd.asarray([[1.0, 2.0], [2.0, 4.0]]))
0.0
```

이 가운데 가장 중요한 것은 마지막 줄이에요.

- **행렬식이 0이면** 변환이 평면을 직선이나 점으로 눌러 버려요. 눌린 것은 되돌릴 수 없어서 [역행렬](/api/linalg/inv/)이 없어요. 이런 행렬을 **특이 행렬**(singular matrix)이라고 해요. 이 행렬이 계수인 연립방정식은 해가 없거나 해가 끝없이 많아요.
- **행렬식이 0이 아니면** 역행렬이 있고, 연립방정식의 해가 정확히 하나예요.
- **부호가 음수면** 변환이 방향을 뒤집어요. 시계 방향으로 놓인 세 점이 반시계 방향이 돼요.

### 정확한 정의와 성질

2×2 행렬의 행렬식은 이래요.

$$\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$$

더 큰 행렬은 한 행을 따라 작은 행렬식들로 풀어 써서 정의해요. 3×3이면 이렇게 돼요.

$$\det\begin{pmatrix} a & b & c \\ d & e & f \\ g & h & i \end{pmatrix} = a(ei - fh) - b(di - fg) + c(dh - eg)$$

이 정의대로 계산하면 행렬이 커질수록 계산량이 감당할 수 없이 늘어나요. 그래서 `det`은 행렬을 삼각 행렬들의 곱으로 바꾼 뒤 대각선을 곱하는 방법을 써요. 결과는 같지만 중간에 나눗셈이 들어가서, 정수만 든 행렬에서도 마지막 자리에 반올림 오차가 생길 수 있어요.

알아 두면 쓸모 있는 성질들이에요. $A$와 $B$는 N×N 행렬이에요.

| 성질 | 식 |
|---|:---:|
| 곱의 행렬식은 행렬식의 곱 | $\det(AB) = \det(A)\det(B)$ |
| 역행렬의 행렬식은 역수 | $\det(A^{-1}) = 1 / \det(A)$ |
| 전치해도 그대로 | $\det(A^{\mathsf T}) = \det(A)$ |
| 행렬 전체를 c배 하면 c의 N제곱 배 | $\det(cA) = c^N \det(A)$ |
| 두 행을 맞바꾸면 부호가 바뀜 | |
| 삼각 행렬이면 대각선 원소의 곱 | |
| 고유값을 모두 곱한 값 | |

```python
>>> b = sd.asarray([[2.0, 0.0], [1.0, 1.0]])
>>> sd.linalg.det(b)
2.0
>>> sd.linalg.det(a @ b)
10.0
>>> sd.linalg.det(2 * a)
20.0
>>> sd.linalg.det(sd.asarray([[2.0, 1.0, 0.0], [0.0, 3.0, 5.0], [0.0, 0.0, 4.0]]))
24.0
```

넷째 성질을 눈여겨보세요. 2×2 행렬을 2배 하면 행렬식은 2배가 아니라 4배예요. 가로와 세로가 모두 2배가 되니 넓이는 4배이기 때문이에요. 이 성질 때문에 **큰 행렬의 행렬식은 쉽게 터무니없이 크거나 작아져요.** `slogdet`이 있는 이유예요.

## `slogdet`: 숫자에 담기지 않는 행렬식

float64가 담을 수 있는 수는 크기가 대략 $10^{-324}$에서 $10^{308}$ 사이예요. 넓어 보이지만 행렬식은 이 범위를 금방 벗어나요. 대각선에 `0.5`만 있는 행렬을 생각해 볼게요. 행렬식은 `0.5`를 N번 곱한 값이에요.

```python
>>> sd.linalg.det(sd.eye(4) * 0.5)
0.0625
>>> sd.linalg.det(sd.eye(400) * 0.5)
3.8725919148493183e-121
>>> sd.linalg.det(sd.eye(1100) * 0.5)
0.0
```

1100×1100이 되자 결과가 `0.0`이에요. 진짜 값은 0이 아니라 $0.5^{1100} \approx 10^{-331}$인데, 너무 작아서 0으로 뭉개졌어요. 이 행렬은 특이 행렬과 거리가 멀어요. 단위행렬에 0.5를 곱했을 뿐이에요. 반대로 대각선이 `2.0`이면 `inf`가 돼요.

```python
>>> sd.linalg.det(sd.eye(1100) * 2.0)
inf
```

`slogdet`은 행렬식을 **부호**(sign)와 **절댓값의 자연로그**(logabsdet)로 나눠서 돌려줘요. 로그는 아주 크거나 작은 수를 평범한 크기의 수로 바꿔 주니 넘칠 일이 없어요.

```python
>>> sd.linalg.slogdet(sd.eye(1100) * 0.5)
SlogdetResult(sign=1.0, logabsdet=-762.4618986159212)
>>> sd.linalg.slogdet(sd.eye(1100) * 2.0)
SlogdetResult(sign=1.0, logabsdet=762.4618986159212)
```

두 값과 행렬식의 관계는 이래요.

$$\det(A) = \text{sign} \times e^{\,\text{logabsdet}}$$

로그는 음수에 쓸 수 없어서 부호를 따로 떼어 둔 것이에요. `sign`은 행렬식이 양수면 `1.0`, 음수면 `-1.0`, 0이면 `0.0`이에요.

### 결과 꺼내기

결과는 이름이 붙은 튜플이에요. 필드 이름으로 꺼내도 되고, 두 변수로 풀어 받아도 돼요.

```python
>>> m = sd.asarray([[1.0, 2.0], [3.0, 4.0]])
>>> sd.linalg.det(m)
-2.0
>>> r = sd.linalg.slogdet(m)
>>> r.sign
-1.0
>>> r.logabsdet
0.6931471805599455
>>> sign, logabsdet = sd.linalg.slogdet(m)
>>> sign
-1.0
```

행렬식이 `-2`라서 부호는 `-1.0`, 로그는 `log(2)`예요. 값이 작을 때는 둘을 다시 합쳐서 행렬식을 되찾을 수 있어요. 로그와 지수를 거치면서 마지막 자리가 조금 달라질 수 있어요.

```python
>>> import math
>>> sign * math.exp(logabsdet)
-2.0000000000000004
```

### 언제 `slogdet`을 쓰나요

- **행렬이 클 때.** 수십 행을 넘어가면 행렬식이 넘치거나 0으로 뭉개질 수 있어요.
- **어차피 로그가 필요할 때.** 통계의 정규분포 가능도, 정보량 같은 식에는 행렬식이 아니라 행렬식의 로그가 나와요. `math.log(det(x))`로 구하면 `det`이 먼저 넘쳐 버리니, 처음부터 `slogdet(x).logabsdet`을 쓰세요.
- **행렬식끼리 곱하거나 나눌 때.** 로그를 더하고 빼면 넘치지 않아요.

행렬이 작고 값 자체가 필요하면 `det`이 더 간단해요.

## 여러 행렬을 한 번에

3차원 이상의 배열은 행렬 여러 개를 쌓은 것으로 보고, 행렬마다 값을 하나씩 계산해요. 모양이 `(..., N, N)`이면 결과의 모양은 `(...)`이에요.

```python
>>> stack = sd.asarray([[[1.0, 2.0], [3.0, 4.0]],
...                     [[2.0, 0.0], [0.0, 3.0]],
...                     [[1.0, 2.0], [2.0, 4.0]]])
>>> sd.linalg.det(stack)
array([-2.0,  6.0,  0.0], dtype=float64)
>>> r = sd.linalg.slogdet(stack)
>>> r.sign
array([-1.0,  1.0,  0.0], dtype=float64)
>>> r.logabsdet
array([0.6931471805599455,  1.791759469228055,               -inf], dtype=float64)
```

행렬 하나를 넣으면 결과는 배열이 아니라 Python 숫자예요. 행렬을 하나만 쌓은 `(1, N, N)` 배열을 넣으면 길이 1인 배열이에요.

```python
>>> sd.linalg.det(sd.ones((1, 2, 2)))
array([0.0], dtype=float64)
```

## 조심할 점

### 특이 행렬에서 에러가 나지 않아요

행렬식이 0인 것은 실패가 아니라 정상적인 답이에요. 그래서 `det`은 `0.0`을, `slogdet`은 부호 `0.0`과 로그 `-inf`를 돌려줘요. [`inv`](/api/linalg/inv/)나 [`solve`](/api/linalg/solve/)가 특이 행렬에서 `LinAlgError`를 내는 것과 달라요.

```python
>>> s = sd.asarray([[1.0, 2.0], [2.0, 4.0]])
>>> sd.linalg.det(s)
0.0
>>> sd.linalg.slogdet(s)
SlogdetResult(sign=0.0, logabsdet=-inf)
```

### `det(x) == 0`으로 특이 행렬을 가려내지 마세요

수학적으로는 특이 행렬인데 계산 결과가 정확히 0이 아닐 때가 많아요. 중간 계산의 반올림 오차 때문이에요. 아래 행렬은 둘째 행이 첫째 행의 3배라서 행렬식이 0이어야 해요.

```python
>>> t = sd.asarray([[1.0, 2.0], [3.0, 6.0]])
>>> sd.linalg.det(t)
-3.3306690738754696e-16
>>> sd.linalg.det(t) == 0
False
```

그렇다고 "아주 작으면 특이"라고 볼 수도 없어요. 행렬식의 크기는 원소의 크기와 행렬의 크기에 따라 얼마든지 달라져요. 아래 행렬은 단위행렬에 0.1을 곱한 것이라 특이 행렬과 거리가 먼데도 행렬식은 아주 작아요.

```python
>>> sd.linalg.det(sd.eye(10) * 0.1)
1.0000000000000006e-10
```

<Callout type="warn" title="행렬식의 크기는 '특이에 얼마나 가까운가'를 말해 주지 않아요">
  행렬이 특이한지, 특이에 가까운지 알고 싶으면 행렬식 대신 [`matrix_rank`](/api/linalg/matrix_rank/)나 [`cond`](/api/linalg/cond/)를 쓰세요. 위의 `t`는 `matrix_rank(t)`가 `1`이고 `cond(t)`가 `1e16`을 넘어서 특이 행렬임이 드러나요. `sd.eye(10) * 0.1`은 랭크가 `10`, 조건수가 `1.0`이에요.
</Callout>

```python
>>> sd.linalg.matrix_rank(t)
1
>>> sd.linalg.cond(sd.eye(10) * 0.1)
1.0
```

### 정수 행렬의 결과도 실수예요

정수 행렬의 행렬식은 수학적으로 정수이지만, 결과는 float이고 마지막 자리가 어긋날 수 있어요.

```python
>>> k = sd.asarray([[1, 2, 3], [4, 5, 6], [7, 8, 10]])
>>> sd.linalg.det(k)
-3.000000000000001
```

정수 값이 필요하면 `round`로 반올림하세요. 단, 값이 $2^{53}$(약 $9 \times 10^{15}$)을 넘으면 float64가 정수를 정확히 담지 못해요.

```python
>>> round(sd.linalg.det(k))
-3
```

### 복소수 행렬

복소수 행렬의 행렬식은 복소수예요. `slogdet`의 `sign`은 `+1`이나 `-1` 대신 **크기가 1인 복소수**가 되고, `logabsdet`은 언제나 실수예요.

```python
>>> z = sd.asarray([[3+4j, 0], [0, 1]])
>>> sd.linalg.det(z)
(3+4j)
>>> sd.linalg.slogdet(z)
SlogdetResult(sign=(0.6+0.8j), logabsdet=1.6094379124341003)
```

행렬식 `3+4j`의 크기가 5라서 로그는 `log(5)`, 부호는 `3+4j`를 5로 나눈 `0.6+0.8j`예요.

### 정사각 행렬만, NaN과 inf는 에러

행과 열의 수가 다르면 행렬식이 정의되지 않아요.

```python
>>> sd.linalg.det(sd.ones((2, 3)))
Traceback (most recent call last):
    ...
ValueError: det(): 'x' must be square in its last two dimensions, got 2x3
```

NaN이나 inf가 하나라도 있으면 계산하지 않고 에러를 내요.

```python
>>> sd.linalg.det(sd.asarray([[1.0, sd.nan], [0.0, 1.0]]))
Traceback (most recent call last):
    ...
ValueError: det(): 'x' contains NaN or infinity
```

리스트는 받지 않아요. [`sd.asarray`](/api/array/asarray/)로 먼저 배열을 만드세요.

```python
>>> sd.linalg.det([[1.0, 2.0], [3.0, 4.0]])
Traceback (most recent call last):
    ...
TypeError: det(): 'x' must be an sd.ndarray, not list
```

### 빈 행렬의 행렬식은 1이에요

0×0 행렬의 행렬식은 `1`이에요. 아무것도 곱하지 않은 곱은 1이라는 약속을 따른 것이에요. `slogdet`은 부호 `1.0`, 로그 `0.0`이에요.

```python
>>> sd.linalg.det(sd.zeros((0, 0)))
1.0
>>> sd.linalg.slogdet(sd.zeros((0, 0)))
SlogdetResult(sign=1.0, logabsdet=0.0)
```

### 연립방정식을 행렬식으로 풀지 마세요

행렬식의 비로 해를 구하는 공식(크라메르 공식)이나 `det`으로 역행렬을 만드는 방법은 손으로 2×2, 3×3을 풀 때나 쓸 만해요. 느리고 오차도 커요. 연립방정식은 [`solve`](/api/linalg/solve/)로 푸세요.

## 비슷한 함수와의 차이

| 알고 싶은 것 | 쓸 것 | 이유 |
|---|---|---|
| 행렬식의 값 (작은 행렬) | `det` | 값을 바로 돌려줘요. |
| 행렬식의 로그, 큰 행렬의 행렬식 | `slogdet` | 넘치거나 0으로 뭉개지지 않아요. |
| 행렬이 특이한가 | [`matrix_rank`](/api/linalg/matrix_rank/) | 반올림 오차를 감안해서 판단해요. |
| 특이에 얼마나 가까운가, 결과를 믿어도 되는가 | [`cond`](/api/linalg/cond/) | 원소의 크기와 상관없는 지표예요. |
| 연립방정식의 해 | [`solve`](/api/linalg/solve/) | 행렬식을 거치지 않고 바로 풀어요. |

`det`과 `slogdet`을 나란히 놓으면 이래요.

| | `det` | `slogdet` |
|---|---|---|
| 돌려주는 것 | 행렬식 하나 | `sign`과 `logabsdet` 둘 |
| 아주 큰·작은 행렬식 | `inf`나 `0.0`이 돼요 | 바르게 나와요 |
| 특이 행렬 | `0.0` | `sign=0.0`, `logabsdet=-inf` |
| 복소수 행렬 | 복소수 | `sign`은 복소수, `logabsdet`은 실수 |

## numpy·scipy를 아는 분께

- 행렬 하나의 결과는 numpy 스칼라가 아니라 Python `float`·`complex`예요.
- NaN이나 inf가 있으면 `ValueError`예요. numpy는 `nan`을 돌려줘요.
- 정수·bool 행렬도 받고 결과는 float64예요.
- `slogdet`의 결과 필드는 `sign`, `logabsdet`으로 numpy와 같아요.
- 리스트와 numpy 배열은 받지 않아요. `sd.asarray`로 먼저 바꾸세요.
- 반올림 오차의 모양이 달라서 마지막 자리가 numpy와 다를 수 있어요.
