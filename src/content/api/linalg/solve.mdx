## 설명

함수의 동작을 길게 풀어 쓰는 자리예요. 이 글은 자리 채움이고, 실제 설명은 나중에 써요.

<Callout type="warn">
  `solve`는 언제나 일반 LU로 풀어요. 행렬의 구조는 옵션이 아니라 함수 이름으로 골라요.
</Callout>

<Reference />

## 예제

```python
import stardust as sd

a = sd.asarray([[2.0, 1.0], [1.0, 3.0]])
b = sd.asarray([1.0, 2.0])
sd.linalg.solve(a, b).tolist()   # [0.19999999999999996, 0.6000000000000001]
```

## 참고

구현에 대한 짧은 메모나 다른 라이브러리와 다른 점을 적는 자리예요.
