## 설명

옵션이 여럿인 함수가 어떻게 보이는지 확인하는 견본이에요.

## 예제

```python
import stardust as sd

u = sd.asarray([[2.0, 1.0], [0.0, 3.0]])
sd.linalg.solve_triangular(u, sd.asarray([4.0, 3.0]), upper=True)
```
