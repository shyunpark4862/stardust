## 한눈에 보기

"수학 점수가 80점 이상인 학생만", "비가 온 날만"처럼 조건에 맞는 행만 남기는 것은 표를 다룰 때 가장 자주 하는 일이에요. 엑셀의 필터나 SQL의 `WHERE`와 같아요.

방법은 두 단계예요. 먼저 컬럼을 비교해서 행마다 `True`/`False`가 든 bool Series를 만들고, 그 Series를 대괄호에 넣어요. 이렇게 행을 고르는 데 쓰는 bool Series를 **마스크(mask)**라고 해요.

```python
>>> import stardust as sd
>>> df = sd.frame.DataFrame({
...     "name": ["Ann", "Ben", "Cho", "Dan", "Eve"],
...     "math": [90, 72, None, 85, 64],
...     "eng": [88, 95, 70, None, 81],
... })
>>> df
  name  math   eng
0  Ann    90    88
1  Ben    72    95
2  Cho  <NA>    70
3  Dan    85  <NA>
4  Eve    64    81
>>> df["math"] >= 80
0     True
1    False
2     <NA>
3     True
4    False
Name: math, dtype: bool
>>> df[df["math"] >= 80]
  name  math   eng
0  Ann    90    88
3  Dan    85  <NA>
```

<Fig caption="마스크가 True인 0번과 3번 행만 남아요. 점수가 비어 있는 2번 행은 비교 결과가 NA라서 버려져요.">
  <FrameFig name='df["math"] >= 80' data={[true, false, null, true, false]} rowTones={['a', 'm', 'm', 'a', 'm']} />
  <Op note="df[mask]">→</Op>
  <FrameFig columns={['name', 'math', 'eng']} index={[0, 3]} data={[['Ann', 90, 88], ['Dan', 85, null]]} rowTones={['a', 'a']} />
</Fig>

남은 행은 원래 라벨을 그대로 가져가요. 위 결과의 라벨이 `0, 3`인 것도 그래서예요.

마스크를 쓸 수 있는 곳은 네 군데예요.

| 쓰는 곳 | 결과 |
|---|---|
| `df[mask]` | 조건에 맞는 행의 DataFrame |
| `df.loc[mask, 열]` | 조건에 맞는 행에서 고른 열 ([loc과 iloc](/api/frame/loc-iloc/)) |
| `s[mask]`, `s.loc[mask]` | 조건에 맞는 행의 Series |
| 위의 것을 `=` 왼쪽에 | 조건에 맞는 행에만 대입 ([대입과 복사](/api/frame/assign/)) |

```python
>>> df.loc[df["math"] >= 80, "name"]
0    Ann
3    Dan
Name: name, dtype: string
>>> math = df["math"]
>>> math[math < 80]
1    72
4    64
Name: math, dtype: int64
```

## 조건 여러 개 합치기

조건 두 개를 함께 걸려면 마스크끼리 `&`(그리고), `|`(또는)로 합치고, 뒤집으려면 `~`(아니다)를 붙여요. 결과도 마스크예요([논리와 비트 연산](/api/frame/logical/) 참고).

```python
>>> df[(df["math"] >= 80) & (df["eng"] >= 80)]
  name  math  eng
0  Ann    90   88
>>> df[(df["math"] >= 80) | (df["eng"] >= 90)]
  name  math   eng
0  Ann    90    88
1  Ben    72    95
3  Dan    85  <NA>
>>> df[df["name"] != "Ann"]
  name  math   eng
1  Ben    72    95
2  Cho  <NA>    70
3  Dan    85  <NA>
4  Eve    64    81
```

<Callout type="warn" title="조건마다 괄호를 쳐요">

Python에서 `&`, `|`는 `>=`, `==`보다 먼저 계산돼요. 그래서 `df["math"] >= 80 & df["eng"] >= 80`은 `80 & df["eng"]`부터 계산하고, 남은 비교를 이어 붙이다가 Series 전체를 `True`/`False` 하나로 바꾸려 해요. Series는 진릿값이 없어서 `TypeError`예요. 비교 하나하나를 괄호로 감싸요.

Python의 `and`, `or`, `not`도 같은 이유로 쓸 수 없어요. 행마다 따로 계산하는 `&`, `|`, `~`를 써요.

```python
>>> df["math"] >= 80 & df["eng"] >= 80
Traceback (most recent call last):
    ...
TypeError: the truth value of a Series is ambiguous
>>> (df["math"] >= 80) and (df["eng"] >= 80)
Traceback (most recent call last):
    ...
TypeError: the truth value of a Series is ambiguous
```

</Callout>

## 마스크가 `NA`인 행은 버려요

값이 비어 있는 행(`NA`)을 비교하면 결과도 `NA`예요. 비어 있는 점수가 80 이상인지 아닌지 알 수 없기 때문이에요([NA와 NaN](/api/frame/na/) 참고). 마스크 값이 `NA`인 행은 `False`처럼 버려요.

이 규칙에는 함정이 하나 있어요. `NA`를 `~`로 뒤집어도 `NA`라서, 조건으로 거른 행과 그 반대로 거른 행을 합쳐도 전체가 되지 않아요. 아래에서 Cho(점수 없음)는 어느 쪽에도 없어요.

```python
>>> passed = df["math"] >= 80
>>> df[passed]
  name  math   eng
0  Ann    90    88
3  Dan    85  <NA>
>>> df[~passed]
  name  math  eng
1  Ben    72   95
4  Eve    64   81
```

<Fig caption="NA인 2번 행은 마스크를 뒤집어도 NA라서 두 결과 모두에서 빠져요.">
  <FrameFig name="passed" data={[true, false, null, true, false]} rowTones={['a', '', 'g', 'a', '']} />
  <FrameFig name="~passed" data={[false, true, null, false, true]} rowTones={['', 'a', 'g', '', 'a']} />
</Fig>

비어 있는 행을 어느 쪽에 넣을지는 직접 정해요. `fillna`로 `NA`를 `True`나 `False`로 채우거나, `isna()`로 비어 있는 행을 따로 골라요([fillna](/api/frame/fillna/), [결측값 찾기](/api/frame/isna/)).

```python
>>> df[passed.fillna(True)]
  name  math   eng
0  Ann    90    88
2  Cho  <NA>    70
3  Dan    85  <NA>
>>> df[df["math"].isna()]
  name  math  eng
2  Cho  <NA>   70
```

`|`, `&`는 3값 논리를 따라서 한쪽만으로 답이 정해지면 `NA`가 사라져요. 위의 `(df["math"] >= 80) | (df["eng"] >= 90)`에서 Dan은 영어 점수가 비어 있지만 수학 조건이 `True`라서 남았어요. `True | NA`는 `True`이기 때문이에요.

### NaN은 결측이 아니라 값이에요

float 컬럼의 NaN은 `NA`와 달라요. NaN은 "숫자가 아님"을 뜻하는 평범한 float 값이고, NaN과의 비교는 `!=` 말고는 언제나 `False`예요(`NA`가 아니에요). 그래서 NaN 행은 조건으로 거르면 빠지지만, `~`로 뒤집은 마스크에는 들어가요.

```python
>>> f = sd.frame.Series([1.5, float("nan"), None, 4.0])
>>> f > 1
0     True
1    False
2     <NA>
3     True
dtype: bool
>>> f[~(f > 1)]
1    NaN
dtype: float64
```

NaN 행은 `isnan()`으로, `NA` 행은 `isna()`로 골라요.

```python
>>> f[f.isnan()]
1   NaN
dtype: float64
>>> f[f.isna()]
2   <NA>
dtype: float64
```

## 마스크는 라벨로 짝을 지어요

마스크와 대상은 위치가 아니라 라벨로 행을 맞춰요. 마스크의 `True`는 "같은 라벨의 행을 남겨라"라는 뜻이에요. 그래서 마스크의 행 순서가 달라도 결과는 같아요.

```python
>>> price = sd.frame.Series([1200, 800, 3000], index=["apple", "banana", "cherry"], name="price")
>>> mask = sd.frame.Series([True, False, True], index=["cherry", "banana", "apple"])
>>> price[mask]
apple     1200
cherry    3000
Name: price, dtype: int64
```

<Fig caption="마스크의 순서는 cherry, banana, apple이지만 라벨끼리 짝을 지어요. 결과는 대상의 순서를 따라요.">
  <FrameFig name="price" index={['apple', 'banana', 'cherry']} data={[1200, 800, 3000]} rowTones={['a', 'm', 'a']} />
  <FrameFig name="mask" index={['cherry', 'banana', 'apple']} data={[true, false, true]} rowTones={['a', 'm', 'a']} />
  <Op note="price[mask]">→</Op>
  <FrameFig index={['apple', 'cherry']} data={[1200, 3000]} rowTones={['a', 'a']} />
</Fig>

보통은 마스크를 같은 표의 컬럼에서 만들기 때문에 라벨이 저절로 같아요. 라벨로 맞추는 규칙은 다른 곳에서 만든 마스크를 쓸 때나, 중간에 정렬한 마스크를 쓸 때 행이 엉뚱하게 짝지어지는 것을 막아 줘요.

```python
>>> df[passed.sort_values()]
  name  math   eng
0  Ann    90    88
3  Dan    85  <NA>
```

### 라벨의 집합이 같아야 해요

마스크와 대상의 라벨은 순서만 다를 뿐 똑같은 집합이어야 해요. 대상의 행 중 마스크에 없는 것이 있거나, 마스크에만 있는 라벨이 있으면 `ValueError`예요. 덕분에 엉뚱한 표에서 만든 마스크를 쓰면 조용히 넘어가지 않고 에러로 드러나요.

```python
>>> price[sd.frame.Series([True, False], index=["apple", "banana"])]
Traceback (most recent call last):
    ...
ValueError: the mask's labels must be the index's labels
>>> price[sd.frame.Series([True, True, True, True], index=["apple", "banana", "cherry", "durian"])]
Traceback (most recent call last):
    ...
ValueError: the mask's labels must be the index's labels
```

거른 결과에서 만든 마스크도 원래 표에 그대로 쓸 수 없어요. 라벨 집합이 달라졌기 때문이에요.

```python
>>> df[passed.iloc[:3]]
Traceback (most recent call last):
    ...
ValueError: the mask's labels must be the index's labels
```

정수 라벨과 문자열 라벨은 짝을 지을 수 없어서 `TypeError`예요.

```python
>>> price[sd.frame.Series([True, False, True])]
Traceback (most recent call last):
    ...
TypeError: cannot align int64 labels with string labels
```

### 라벨이 겹칠 때

대상의 라벨이 겹쳐 있으면, 라벨만으로는 어느 행끼리 짝인지 정할 수 없어요. 이때는 마스크의 라벨이 대상과 순서까지 똑같아야 하고, 그러면 위치대로 짝을 지어요.

```python
>>> dup = sd.frame.Series([10, 20, 30], index=[1, 1, 2])
>>> dup[sd.frame.Series([True, False, True], index=[1, 1, 2])]
1    10
2    30
dtype: int64
>>> dup[sd.frame.Series([True, False, True], index=[2, 1, 1])]
Traceback (most recent call last):
    ...
ValueError: the mask's labels must be the index's labels
```

이 규칙은 Series끼리 계산할 때의 정렬(alignment)과 같아요. 자세한 것은 [라벨과 정렬](/api/frame/alignment/)에 있어요.

## 마스크가 될 수 있는 것

마스크는 dtype이 `bool`인 Series만 돼요. 다른 dtype의 Series는 `TypeError`예요.

```python
>>> df[sd.frame.Series([1, 0, 1, 0, 1])]
Traceback (most recent call last):
    ...
TypeError: a mask must be a bool Series, got dtype int64
```

bool 리스트, bool numpy 배열, stardust bool 배열도 라벨이 없어서 마스크가 될 수 없어요. bool 리스트는 `df[...]`에서 컬럼 이름 목록으로 읽혀 `TypeError`가 나요.

```python
>>> df[[True, False, True, False, True]]
Traceback (most recent call last):
    ...
TypeError: column names must be str, not bool
```

위치로 고르는 `.iloc`은 마스크를 받지 않아요. 마스크는 `df[...]`, `s[...]`, `.loc`에서만 써요.

```python
>>> df.iloc[passed]
Traceback (most recent call last):
    ...
IndexError: cannot select rows by position with Series; use an int, a slice or a list of ints
```

## 결과의 Index

거른 결과의 행 라벨은 언제나 남은 라벨로 만든 `Index`예요. 라벨이 `0, 1, 2…`(RangeIndex)인 표에서 걸러도 int64 `Index`가 되고, 남은 라벨이 우연히 이어져 있어도 RangeIndex로 돌아가지 않아요.

```python
>>> df[passed].index
Index([0, 3], dtype=int64)
```

맞는 행이 하나도 없으면 빈 결과예요. 컬럼과 dtype은 그대로예요.

```python
>>> df[df["eng"] > 100]
Empty DataFrame
Columns: [name, math, eng]
Index: []
>>> price[price > 5000]
Series([], Name: price, dtype: int64)
```

거른 뒤 라벨을 `0, 1, 2…`로 다시 매기고 싶을 수 있지만, 위치로 고를 때는 `.iloc`을 쓰면 되므로 다시 매길 필요가 없는 경우가 많아요. 라벨과 위치가 어긋나는 점은 [loc과 iloc](/api/frame/loc-iloc/)에 있어요.

## 조건에 맞는 행에 대입하기

마스크를 `=`의 왼쪽에 쓰면 조건에 맞는 행만 고쳐요. 마스크가 `NA`인 행은 고르지 않은 것이라 그대로 남아요.

```python
>>> score = sd.frame.Series([90, None, 60, 85], name="score")
>>> score[score < 70] = 70
>>> score
0      90
1    <NA>
2      70
3      85
Name: score, dtype: int64
>>> df.loc[df["math"] < 70, "math"] = 70
>>> df["math"]
0      90
1      72
2    <NA>
3      85
4      70
Name: math, dtype: int64
```

DataFrame에서는 `df.loc[mask, "열"] = 값`처럼 열을 하나 골라요. `df[mask] = 값`은 `TypeError`예요. 넣을 수 있는 값과 dtype 규칙은 [대입과 복사](/api/frame/assign/)에 있어요.

## 조심할 점

- 조건마다 괄호를 쳐서 `(a >= 1) & (b >= 2)`처럼 써요. `and`, `or`, `not`은 `TypeError`예요.
- `NA` 행은 `m`과 `~m` 양쪽에서 빠져요. 빈 값을 어느 쪽에 넣을지 `fillna`로 정해요.
- NaN 행은 `~m` 쪽에 들어가요. NaN과의 비교는 `NA`가 아니라 `False`예요.
- 길이가 다른 표에서 만든 마스크는 쓸 수 없어요. 라벨 집합이 같아야 해요.

## 비슷한 기능과의 차이

| 하고 싶은 일 | 쓰는 것 |
|---|---|
| 조건으로 행 거르기 | `df[mask]` |
| 비어 있는 행만 지우기 | [`dropna`](/api/frame/dropna/) (`df[df["a"].notna()]`와 같은 일) |
| 라벨 목록으로 행 고르기 | [`.loc[labels]`](/api/frame/loc-iloc/) |
| 위치로 행 고르기 | [`.iloc[positions]`](/api/frame/loc-iloc/) |

배열에도 bool 마스크가 있지만 성격이 달라요. [배열의 인덱싱](/api/array/indexing/)에서 마스크는 같은 모양의 bool 배열이고 위치로 짝을 지어요. 결과는 고른 값을 모은 1차원 배열이에요. 데이터프레임의 마스크는 bool Series이고 라벨로 짝을 지어요. 결과는 행을 고른 표이고, 컬럼과 라벨이 남아요. 배열에는 결측값이 없어서 마스크 값이 `NA`인 경우도 데이터프레임에만 있어요.

## pandas를 아는 분께

- 마스크와 대상의 라벨 집합이 같아야 해요. pandas 3.1.1은 마스크에만 있는 라벨을 조용히 무시해요. 마스크에 빠진 라벨이 있을 때는 pandas도 에러(`IndexingError`)예요.
- bool 리스트나 bool numpy 배열은 마스크가 아니에요. pandas의 `df[[True, False, ...]]`, `s.iloc[np_bool_array]`는 여기서 에러예요. 라벨이 있는 bool Series만 받아요.
- 마스크가 `NA`인 행을 버리는 것은 pandas의 nullable `boolean` 마스크와 같아요. stardust는 dtype이 언제나 `bool`이고 `NA`를 담을 수 있어서, 비교 결과를 그대로 마스크로 써요. pandas의 `object` dtype 마스크처럼 `None`이 섞여서 에러가 나는 경우는 없어요.
- 거른 결과의 Index는 언제나 `Index`예요. pandas 3.1.1은 남은 라벨이 일정한 간격이면 RangeIndex로 돌려줘요(`s[s > 15]`가 `RangeIndex(start=1, stop=4, step=1)`이 되기도 해요).
