## 한눈에 보기

`DataFrame`은 **행과 열로 된 표**예요. 엑셀 시트 한 장을 떠올리면 돼요. 열(컬럼)마다 이름이 있고, 한 컬럼 안의 값은 모두 같은 종류예요. 행마다 라벨이 붙어 있어요. 컬럼 하나를 떼어 내면 [Series](/api/frame/series/)예요.

판매 기록, 학생 성적표, 도시별 기온처럼 "한 줄에 한 건, 칸마다 다른 항목"인 데이터를 다룰 때 써요. 가장 흔한 만드는 법은 **컬럼 이름을 키로, 그 컬럼의 값 목록을 값으로 하는 dict**예요.

```python
>>> import stardust as sd
>>> df = sd.frame.DataFrame({
...     "fruit": ["apple", "banana", "cherry"],
...     "price": [1200, 800, 1500],
...     "qty": [3, None, 7],
... })
>>> df
    fruit  price   qty
0   apple   1200     3
1  banana    800  <NA>
2  cherry   1500     7
```

<Fig caption="dict의 키가 컬럼 이름, 값 목록이 컬럼이 돼요. 컬럼마다 dtype이 따로 있어요.">
  <FrameFig name="df" columns={['fruit', 'price', 'qty']} dtypes={['string', 'int64', 'int64']}
    data={[['apple', 1200, 3], ['banana', 800, null], ['cherry', 1500, 7]]} />
</Fig>

컬럼마다 dtype이 따로 정해져요. `qty`에는 빈칸(`NA`)이 있지만 int64 그대로예요.

```python
>>> df.dtypes
{'fruit': string, 'price': int64, 'qty': int64}
>>> df.shape
(3, 3)
```

`df.dtypes`, `df.shape` 같은 속성은 [모양, 이름, dtype](/api/frame/attributes/)에, 컬럼과 행을 골라내는 법은 [대괄호로 고르기](/api/frame/selection/)에 있어요. 파일에서 표를 읽을 때는 [`read_csv`](/api/frame/read_csv/)를 써요.

## 무엇으로 만들 수 있나요

| 넣는 것 | 예 | `columns=` |
|---|---|---|
| 컬럼의 dict | `{"a": [1, 2], "b": ["x", "y"]}` | 고를 컬럼 (선택) |
| 행 dict의 리스트 | `[{"a": 1, "b": "x"}, {"a": 2}]` | 고를 컬럼 (선택) |
| 행 리스트의 리스트 | `[[1, "x"], [2, "y"]]` | **필요** |
| 2차원 numpy 배열, `sd.ndarray` | `np.array([[1, 2], [3, 4]])` | **필요** |
| DataFrame | `sd.frame.DataFrame(df)` | 고를 컬럼 (선택) |
| 아무것도 주지 않음 | `sd.frame.DataFrame()` | 컬럼 이름 (선택) |

데이터가 컬럼 단위로 모여 있으면 dict, 한 건씩(행 단위로) 모여 있으면 행의 리스트를 써요. 어느 쪽이든 결과는 컬럼 단위로 저장되고, 컬럼마다 dtype을 따로 정해요.

## 컬럼의 dict에서

dict의 순서가 컬럼 순서예요. 값으로는 리스트, 튜플, `range`, 1차원 numpy 배열, 1차원 `sd.ndarray`, [Series](/api/frame/series/), 그리고 스칼라 하나를 쓸 수 있어요. 각 컬럼의 dtype은 [Series를 만들 때와 같은 규칙](/api/frame/series/)으로 정해요: 숫자는 `bool < int64 < float64`로 넓히고, str만 있으면 `string`, `None`은 `NA`예요.

```python
>>> import numpy as np
>>> sd.frame.DataFrame({
...     "city": ("Seoul", "Busan"),
...     "temp": np.array([12.5, 15.0], dtype=np.float32),
...     "rain": [True, False],
... }).dtypes
{'city': string, 'temp': float64, 'rain': bool}
```

컬럼끼리 길이가 같아야 해요. **스칼라 하나는 모든 행에 같은 값**으로 채워져요. 다만 리스트가 하나도 없이 스칼라만 있으면 행 수를 알 수 없어서 에러예요(`index=`를 주면 돼요).

```python
>>> sd.frame.DataFrame({"fruit": ["apple", "kiwi"], "store": "east"})
   fruit store
0  apple  east
1   kiwi  east
>>> sd.frame.DataFrame({"a": [1, 2], "b": [1]})
Traceback (most recent call last):
    ...
ValueError: DataFrame(): all columns must have the same length
>>> sd.frame.DataFrame({"a": 1, "b": 2})
Traceback (most recent call last):
    ...
ValueError: DataFrame(): cannot make a DataFrame from scalars alone; give at least one column as a list
```

컬럼 이름은 **str**이어야 해요. 한 컬럼 안에 str과 숫자가 섞이면 Series처럼 `TypeError`예요.

```python
>>> sd.frame.DataFrame({2024: [1, 2]})
Traceback (most recent call last):
    ...
TypeError: DataFrame(): column names must be str, not int
>>> sd.frame.DataFrame({"code": ["A1", 7]})
Traceback (most recent call last):
    ...
TypeError: DataFrame(): str values cannot be mixed with int values (there is no object dtype)
```

## Series를 담은 dict: 라벨로 맞춰요

dict의 값이 Series이면 **위치가 아니라 라벨로** 행을 맞춰요. 같은 라벨끼리 같은 행에 놓여요. 이것을 정렬(alignment)이라고 해요.

```python
>>> price = sd.frame.Series([1200, 800], index=["apple", "banana"])
>>> stock = sd.frame.Series([5, 9], index=["banana", "apple"])
>>> sd.frame.DataFrame({"price": price, "stock": stock})
        price  stock
apple    1200      9
banana    800      5
```

라벨이 서로 다르면 두 라벨을 합쳐요. 순서는 **앞 Series의 라벨을 먼저, 뒤 Series에만 있는 라벨을 그 뒤에** 붙여요. 한쪽에 없는 칸은 `NA`예요.

```python
>>> stock = sd.frame.Series([9, 4], index=["apple", "kiwi"])
>>> sd.frame.DataFrame({"price": price, "stock": stock})
        price  stock
apple    1200      9
banana    800   <NA>
kiwi     <NA>      4
```

<Fig caption="라벨이 같은 값끼리 한 행이 돼요. 앞 Series의 라벨 순서를 먼저 따르고, 뒤에만 있는 kiwi를 끝에 붙여요.">
  <FrameFig name="price" index={['apple', 'banana']} data={[1200, 800]} rowTones={['1', '2']} />
  <FrameFig name="stock" index={['apple', 'kiwi']} data={[9, 4]} rowTones={['1', '3']} />
  <Op>→</Op>
  <FrameFig columns={['price', 'stock']} index={['apple', 'banana', 'kiwi']}
    data={[[1200, 9], [800, null], [null, 4]]} rowTones={['1', '2', '3']} />
</Fig>

맞추려면 라벨이 각 Series 안에서 고유해야 해요. 같은 라벨이 두 번 있으면 어느 행과 짝지을지 정할 수 없어서 에러예요. int 라벨과 str 라벨도 맞출 수 없어요. 정렬의 규칙 전체는 [라벨과 정렬](/api/frame/alignment/)에 있어요.

```python
>>> twice = sd.frame.Series([1, 2], index=["apple", "apple"])
>>> sd.frame.DataFrame({"price": price, "n": twice})
Traceback (most recent call last):
    ...
ValueError: DataFrame(): cannot align indexes with duplicate labels
>>> sd.frame.DataFrame({"price": price, "n": sd.frame.Series([1, 2])})
Traceback (most recent call last):
    ...
TypeError: DataFrame(): cannot align string labels with int64 labels
```

Series와 리스트를 함께 넣으면 리스트는 맞춘 결과의 행 순서대로 들어가요. Series의 이름은 쓰지 않고 dict의 키가 컬럼 이름이 돼요.

## 행의 리스트에서

데이터가 한 건씩 들어올 때는 행의 리스트로 만들어요. 행 하나를 **dict**로 쓰면 키가 컬럼 이름이에요. 어떤 행에 없는 키의 칸은 `NA`이고, 컬럼 순서는 키가 처음 나온 순서예요.

```python
>>> sd.frame.DataFrame([
...     {"name": "kim", "math": 90},
...     {"name": "lee", "art": 75},
... ])
  name  math   art
0  kim    90  <NA>
1  lee  <NA>    75
```

행 하나를 **리스트나 튜플**로 쓰면 컬럼 이름이 없으니 `columns=`가 꼭 필요해요. 행마다 값의 개수가 컬럼 수와 같아야 해요.

```python
>>> sd.frame.DataFrame([["kim", 90], ("lee", 85)], columns=["name", "math"])
  name  math
0  kim    90
1  lee    85
>>> sd.frame.DataFrame([["kim", 90], ["lee"]], columns=["name", "math"])
Traceback (most recent call last):
    ...
ValueError: DataFrame(): every row must have 2 values, one per column
>>> sd.frame.DataFrame([["kim", 90]])
Traceback (most recent call last):
    ...
ValueError: DataFrame(): 'columns' is required to name the columns of row or 2-D array data
```

행 단위로 받은 값은 먼저 컬럼으로 모은 뒤, 컬럼마다 리스트와 같은 규칙으로 dtype을 정해요. 그래서 한 행 안에 str과 숫자가 섞여도 괜찮고, 한 컬럼 안에서는 섞이면 안 돼요. 행이 dict와 리스트가 섞이거나, 숫자만 늘어놓은 리스트(`[1, 2, 3]`)는 행이 아니라서 받지 않아요.

```python
>>> sd.frame.DataFrame([1, 2, 3])
Traceback (most recent call last):
    ...
TypeError: DataFrame(): a DataFrame from a list needs rows: all dicts, or all lists/tuples
```

## 2차원 배열에서

2차원 numpy 배열이나 `sd.ndarray`에서도 만들 수 있어요. 행 리스트처럼 `columns=`가 꼭 필요해요. 값은 **언제나 복사**하고, dtype은 [Series](/api/frame/series/)가 배열을 받을 때와 같은 규칙으로 컬럼마다 정해요. `object` 배열이면 컬럼마다 따로 추론해요.

```python
>>> sd.frame.DataFrame(np.array([[1, 2], [3, 4]], dtype=np.int32), columns=["x", "y"])
   x  y
0  1  2
1  3  4
>>> sd.frame.DataFrame(sd.asarray([[0.5, 1.0], [1.5, 2.0]]), columns=["x", "y"]).dtypes
{'x': float64, 'y': float64}
>>> sd.frame.DataFrame(np.array([["kim", 90]], dtype=object), columns=["name", "math"]).dtypes
{'name': string, 'math': int64}
```

numpy의 float 배열에 든 NaN은 `NA`가 아니라 NaN 값으로 들어와요([NA와 NaN](/api/frame/na/)).

## `columns=`: 고르고, 순서를 정하고, 채우기

컬럼 이름이 이미 있는 입력(dict, 행 dict의 리스트, DataFrame)에 `columns=`를 주면 **그 컬럼만 그 순서로** 골라요. 데이터에 없는 이름은 값이 모두 `NA`인 컬럼이 돼요(dtype은 `dtype=`이 있으면 그것, 없으면 float64).

```python
>>> data = {"fruit": ["apple", "kiwi"], "price": [1200, 900], "qty": [3, 4]}
>>> sd.frame.DataFrame(data, columns=["qty", "fruit", "note"])
   qty  fruit  note
0    3  apple  <NA>
1    4   kiwi  <NA>
```

`columns=`는 고유한 str의 리스트(나 튜플)여야 해요. str 하나를 그대로 주면 글자로 쪼개지 않고 `TypeError`예요.

```python
>>> sd.frame.DataFrame(data, columns="fruit")
Traceback (most recent call last):
    ...
TypeError: DataFrame(): column names must be given as a list, not str
>>> sd.frame.DataFrame(data, columns=["fruit", "fruit"])
Traceback (most recent call last):
    ...
ValueError: DataFrame(): column names must be unique
```

## 행 라벨: `index=`

`index=`로 행 라벨을 줘요. 규칙은 [Series의 `index=`](/api/frame/series/)와 같아요: 라벨은 int나 str이고, NA는 안 되고, 중복은 괜찮아요. 개수는 행 수와 같아야 해요.

```python
>>> sd.frame.DataFrame({"temp": [12.5, 15.0]}, index=["Seoul", "Busan"])
       temp
Seoul  12.5
Busan  15.0
>>> sd.frame.DataFrame({"temp": [12.5, 15.0]}, index=["Seoul"])
Traceback (most recent call last):
    ...
ValueError: DataFrame(): column 'temp' has 2 values, but 'index' has 1 labels
```

스칼라만 있는 dict도 `index=`가 있으면 행 수를 알 수 있어서 만들 수 있어요.

```python
>>> sd.frame.DataFrame({"open": True, "fee": 0}, index=["mon", "tue"])
     open  fee
mon  True    0
tue  True    0
```

**Series를 담은 dict와 DataFrame에서는** `index=`가 라벨을 붙이는 것이 아니라, 그 라벨 순서로 행을 **골라서 다시 배열**해요. 없는 라벨의 행은 `NA`예요. [`reindex`](/api/frame/reindex/)와 같은 일이에요.

```python
>>> sd.frame.DataFrame({"price": price}, index=["banana", "melon"])
        price
banana    800
melon    <NA>
```

## `dtype=`: 모든 컬럼을 한 종류로

`dtype=`은 모든 컬럼에 적용돼요. [Series의 `dtype=`](/api/frame/series/)처럼 **명시적 변환**이라서, 먼저 컬럼마다 추론한 뒤 [`astype`](/api/frame/astype/)으로 바꿔요. 손실이 있어도 바꿔요.

```python
>>> sd.frame.DataFrame({"a": [1, 2], "b": [0.5, 2.7]}, dtype="int64")
   a  b
0  1  0
1  2  2
```

컬럼마다 다른 dtype을 주는 dict는 받지 않아요. 만든 뒤에 `df.astype({"b": "float64"})`처럼 [`astype`](/api/frame/astype/)에 dict를 줘요.

```python
>>> sd.frame.DataFrame({"a": [1, 2]}, dtype={"a": "float64"})
Traceback (most recent call last):
    ...
TypeError: DataFrame(): 'dtype' must be sd.bool, sd.int64, sd.float64 or sd.string (or their names), not dict
```

## DataFrame에서 DataFrame 만들기

DataFrame을 넣으면 같은 컬럼과 라벨의 DataFrame이에요. `columns=`, `index=`, `dtype=`을 함께 주면 위에서 설명한 대로 고르고, 다시 배열하고, 바꿔요. 새 DataFrame은 원본과 값을 함께 쓰지만, 한쪽을 고치면 고친 쪽만 바뀌어요([대입과 복사](/api/frame/assign/)).

```python
>>> df2 = sd.frame.DataFrame(df, columns=["fruit", "price"])
>>> df2["price"] = [0, 0, 0]
>>> df["price"].tolist()
[1200, 800, 1500]
```

## 빈 DataFrame

아무것도 주지 않으면 행도 컬럼도 없는 표예요. `columns=`만 주면 행이 없는 컬럼을 만들 수 있어요. 이때 컬럼의 dtype은 `dtype=`이 있으면 그것, 없으면 float64예요.

```python
>>> sd.frame.DataFrame()
Empty DataFrame
Columns: []
Index: []
>>> empty = sd.frame.DataFrame(columns=["name", "score"])
>>> empty.shape
(0, 2)
>>> empty.dtypes
{'name': float64, 'score': float64}
```

## 조심할 점

### Series 하나로는 만들 수 없어요

`sd.frame.DataFrame(s)`는 `TypeError`예요. dict로 감싸서 컬럼 이름을 정해 줘요.

```python
>>> s = sd.frame.Series([90, 85], name="math")
>>> sd.frame.DataFrame(s)
Traceback (most recent call last):
    ...
TypeError: DataFrame(): cannot make a DataFrame from Series
>>> sd.frame.DataFrame({s.name: s})
   math
0    90
1    85
```

### `if df:`는 쓸 수 없어요

Series처럼 `bool(df)`는 `TypeError`예요. 행이 없는지는 `len(df) == 0`으로 봐요. `len(df)`는 행 수예요.

```python
>>> bool(sd.frame.DataFrame())
Traceback (most recent call last):
    ...
TypeError: the truth value of a DataFrame is ambiguous
>>> len(df)
3
```

### 주 인자 말고는 키워드로 줘요

`data`만 위치로 주고, `index`, `columns`, `dtype`은 이름을 붙여요.

```python
>>> sd.frame.DataFrame([[1, 2]], ["a", "b"])
Traceback (most recent call last):
    ...
TypeError: DataFrame.__init__() takes from 1 to 2 positional arguments but 3 were given
```

### 컬럼 이름과 라벨은 대입으로 바꿀 수 없어요

`df.columns = [...]`, `df.index = [...]`는 없어요. 다른 이름이 필요하면 `columns=`로 새로 만들거나, 새 컬럼을 대입해요.

```python
>>> df.columns = ["f", "p", "q"]
Traceback (most recent call last):
    ...
AttributeError: property 'columns' of 'DataFrame' object has no setter
```

### pickle로 저장할 수 있어요

값은 비트까지 그대로이고(`NA`, NaN, `-0.0`), 라벨과 컬럼 이름도 함께 저장돼요. 일부만 잘라 낸 DataFrame은 자기 행만 저장해요.

```python
>>> import pickle
>>> pickle.loads(pickle.dumps(df))
    fruit  price   qty
0   apple   1200     3
1  banana    800  <NA>
2  cherry   1500     7
```

| 하고 싶은 일 | 쓸 것 |
|---|---|
| 컬럼 여러 개의 표 | `DataFrame` |
| 컬럼 하나 | [`Series`](/api/frame/series/) |
| CSV 파일을 표로 | [`read_csv`](/api/frame/read_csv/) |
| 표 여러 개를 위아래로 잇기 | [`concat`](/api/frame/concat/) |
| 두 표를 키로 붙이기 | [`merge`](/api/frame/merge/) |
| 표를 숫자 행렬로 | [`to_array`](/api/frame/to-array/), [`to_numpy`](/api/frame/to-numpy/) |
| 컬럼마다 다른 dtype으로 | 만든 뒤 [`astype`](/api/frame/astype/)에 dict |

`index=`의 뜻은 입력에 따라 달라요.

| 입력 | `index=`를 주면 |
|---|---|
| 리스트, 배열, 스칼라를 담은 dict, 행의 리스트, 2차원 배열 | 그 라벨을 **붙여요** (개수가 같아야 함) |
| Series를 담은 dict, DataFrame | 그 라벨로 행을 **다시 배열해요** (없는 라벨은 NA) |

## pandas를 아는 분께

- 행 리스트나 2차원 배열에는 `columns=`가 꼭 필요해요. pandas처럼 `0, 1, …`이라는 컬럼 이름을 붙이지 않아요. 컬럼 이름은 str뿐이고, 겹치면 안 돼요.
- `sd.frame.DataFrame(s)`(Series 하나)와 `[1, 2, 3]`(숫자의 리스트)는 받지 않아요.
- Series를 담은 dict는 라벨이 다르면 앞 Series의 라벨 순서에 뒤에만 있는 라벨을 붙여요. pandas는 합친 라벨을 정렬해요. int 라벨과 str 라벨을 함께 맞추면 pandas는 섞어서 붙이지만 여기서는 `TypeError`예요.
- 행 길이가 다르면 `ValueError`예요. pandas는 경고와 함께 NaN으로 채워요.
- dtype은 컬럼마다 리스트의 규칙대로예요. `[True, 2]`인 컬럼은 int64예요(pandas는 object). `NA`가 있는 정수 컬럼도 int64로 남아요.
- `dtype=`은 손실이 있어도 바꿔요. `pd.DataFrame({"b": [3.5]}, dtype="int64")`는 `ValueError`지만 여기서는 `3`이에요.
- `df.dtypes`는 Series가 아니라 `{컬럼 이름: dtype}` dict예요.
- `bool(df)`는 `ValueError`가 아니라 `TypeError`예요.
- `copy=` 인자는 없어요. 배열은 언제나 복사하고, DataFrame에서 만든 DataFrame은 고친 쪽만 바뀌어요.
