## 한눈에 보기

"어떤 과일이 가장 많이 팔렸나", "설문에서 어떤 답이 몇 번 나왔나"처럼 **값마다 개수를 세는 일**은 데이터를 처음 볼 때 가장 먼저 하는 일 가운데 하나예요. `value_counts()`가 그 일을 해요. 결과는 값과 그 개수가 나란히 있는 표예요. 스프레드시트의 피벗 테이블로 "개수"를 세는 것과 같아요.

```python
>>> import stardust as sd
>>> fruit = sd.frame.Series(["plum", "pear", "kiwi", "pear", "kiwi", "pear"], name="fruit")
>>> vc = fruit.value_counts()
>>> vc
  fruit  counts
0  pear       3
1  kiwi       2
2  plum       1
```

기본으로 **많이 나온 값부터** 늘어놓아요. 맨 윗줄이 가장 많이 나온 값(최빈값)이에요.

```python
>>> vc["fruit"].iloc[0]
'pear'
>>> vc.loc[0, "counts"]
3
```

## 결과는 언제나 DataFrame이에요

`value_counts()`는 Series에 쓰든 DataFrame에 쓰든 언제나 **DataFrame**을 돌려줘요. 컬럼은 둘이에요.

- **값 컬럼**: 센 값이에요. 이름은 원래 Series의 이름이고, 이름이 없으면 `values`예요.
- **`counts` 컬럼**: 그 값이 나온 횟수(int64)예요.

```python
>>> vc.columns
Index(['fruit', 'counts'], dtype=string)
>>> sd.frame.Series([3, 1, 3, 2, 1, 3]).value_counts()
   values  counts
0       3       3
1       1       2
2       2       1
```

`values`와 `counts`는 배열의 [`sd.unique_counts`](/api/array/unique/)가 돌려주는 두 필드의 이름과 같아요. 같은 일을 하는 기능이라 이름도 같아요. 다만 순서가 달라요. `sd.unique_counts`는 값의 크기순이고, `value_counts`는 개수순이에요.

```python
>>> sd.unique_counts(sd.asarray([3, 1, 3, 2, 1, 3]))
UniqueCountsResult(values=array([1, 2, 3], dtype=int64), counts=array([2, 1, 3], dtype=int64))
```

### 왜 값이 라벨이 아니라 컬럼일까요

값을 행 라벨로 삼아 `counts` Series 하나로 돌려주는 방법도 생각할 수 있어요. 하지만 stardust의 라벨([Index](/api/frame/index/))은 int64와 문자열만 될 수 있어요. 실수나 bool은 라벨이 될 수 없어요. 그래서 float 컬럼이나 bool 컬럼의 개수를 셀 수 없게 돼요. 값을 일반 컬럼에 두면 어떤 dtype이든 똑같은 모양으로 셀 수 있어요.

```python
>>> paid = sd.frame.Series([True, False, True, True], name="paid")
>>> paid.value_counts()
    paid  counts
0   True       3
1  False       1
```

라벨은 언제나 0부터 시작하는 RangeIndex예요. [`groupby`](/api/frame/groupby/)의 결과도 같은 모양(키 컬럼 + 결과 컬럼, RangeIndex)이라서 두 결과를 같은 방법으로 다룰 수 있어요.

## 행의 순서

| 옵션 | 순서 |
|---|---|
| `sort=True, descending=True` (기본값) | 개수가 많은 것부터 |
| `sort=True, descending=False` | 개수가 적은 것부터 |
| `sort=False` | 값이 데이터에 처음 나타난 순서 |

```python
>>> fruit.value_counts(descending=False)
  fruit  counts
0  plum       1
1  kiwi       2
2  pear       3
>>> fruit.value_counts(sort=False)
  fruit  counts
0  plum       1
1  pear       3
2  kiwi       2
```

`descending`은 [`sort_values`](/api/frame/sort_values/)나 배열의 [`sd.sort`](/api/array/sort/)와 같은 이름의 옵션이에요. 기본값만 `True`(많이 나온 값부터)로 달라요.

### 개수가 같으면 처음 나타난 순서

개수가 같은 값끼리는 **데이터에 처음 나타난 순서**를 지켜요. 방향을 바꿔도 마찬가지예요. 그래서 같은 데이터면 언제나 같은 순서가 나와요.

```python
>>> tie = sd.frame.Series(["kiwi", "pear", "apple", "pear", "kiwi", "plum"])
>>> tie.value_counts()
  values  counts
0   kiwi       2
1   pear       2
2  apple       1
3   plum       1
>>> tie.value_counts(descending=False)
  values  counts
0  apple       1
1   plum       1
2   kiwi       2
3   pear       2
```

## 비율로 보기: `normalize`

`normalize=True`를 주면 개수 대신 **전체에서 차지하는 비율**을 `proportion` 컬럼(float64)으로 줘요. 비율을 모두 더하면 1이에요.

```python
>>> fruit.value_counts(normalize=True)
  fruit  proportion
0  pear    0.500000
1  kiwi    0.333333
2  plum    0.166667
>>> fruit.value_counts(normalize=True)["proportion"].tolist()
[0.5, 0.3333333333333333, 0.16666666666666666]
```

## `NA`와 NaN

**`NA`는 기본으로 세지 않아요.** `dropna=True`(기본값)에서는 `NA`를 빼고 세요. **NaN은 언제나 세요.** NaN은 결측값이 아니라 float 값이라서, 여러 NaN이 하나의 값으로 묶여 세어져요([NA와 NaN](/api/frame/na/)).

```python
>>> r = sd.frame.Series([2.5, None, float("nan"), 1.0, float("nan"), None, 2.5, None])
>>> r.value_counts()
   values  counts
0     2.5       2
1     NaN       2
2     1.0       1
```

`dropna=False`를 주면 `NA`도 한 종류로 세요. `NA` 줄도 다른 값과 **같은 순서 규칙**을 따라요. 위 데이터에서 `NA`가 세 번으로 가장 많으니 맨 위에 오고, `sort=False`이면 처음 나타난 자리(2.5 다음)에 와요.

```python
>>> r.value_counts(dropna=False)
   values  counts
0    <NA>       3
1     2.5       2
2     NaN       2
3     1.0       1
>>> r.value_counts(dropna=False, sort=False)
   values  counts
0     2.5       2
1    <NA>       3
2     NaN       2
3     1.0       1
```

비율의 분모는 센 값의 개수예요. `dropna=True`이면 `NA`를 뺀 5개, `dropna=False`이면 8개 전부예요.

```python
>>> r.value_counts(normalize=True)
   values  proportion
0     2.5         0.4
1     NaN         0.4
2     1.0         0.2
```

같은 값으로 묶는 규칙(NaN끼리 같음, `-0.0`과 `0.0`은 같고 먼저 나온 쪽을 보여 줌, `NA`끼리 같음)은 [`unique_values`](/api/frame/unique_values/)와 같아요.

## DataFrame: 값의 조합을 세기

DataFrame의 `value_counts()`는 **여러 컬럼 값의 조합**마다 개수를 세요. 첫 인자 `subset`에 셀 컬럼을 주고, 주지 않으면 모든 컬럼의 조합을 세요.

```python
>>> shop = sd.frame.DataFrame({
...     "city": ["Seoul", "Busan", "Seoul", "Seoul", "Busan"],
...     "fruit": ["pear", "kiwi", "pear", "kiwi", "kiwi"],
...     "qty": [2, 1, 3, 1, 1],
... })
>>> shop.value_counts(["city", "fruit"])
    city fruit  counts
0  Seoul  pear       2
1  Busan  kiwi       2
2  Seoul  kiwi       1
>>> shop.value_counts("city")
    city  counts
0  Seoul       3
1  Busan       2
```

<Fig caption="city와 fruit 값의 조합이 같은 행(같은 색)끼리 묶어 세요. 개수가 같은 두 조합은 처음 나타난 순서를 지켜요.">
  <FrameFig name="shop" columns={['city', 'fruit']} data={[['Seoul', 'pear'], ['Busan', 'kiwi'], ['Seoul', 'pear'], ['Seoul', 'kiwi'], ['Busan', 'kiwi']]} rowTones={['1', '2', '1', '3', '2']} />
  <Op note='value_counts(["city", "fruit"])'>→</Op>
  <FrameFig columns={['city', 'fruit', 'counts']} data={[['Seoul', 'pear', 2], ['Busan', 'kiwi', 2], ['Seoul', 'kiwi', 1]]} rowTones={['1', '2', '3']} />
</Fig>

키 컬럼이 `subset` 순서대로 먼저 오고 `counts`가 맨 뒤에 와요. [`groupby(...).size()`](/api/frame/groupby-agg/)와 같은 개수를 세지만 행 순서가 달라요. `groupby`는 키 값의 순서로, `value_counts`는 개수의 순서로 늘어놓아요.

```python
>>> shop.groupby(["city", "fruit"]).size()
    city fruit  size
0  Busan  kiwi     2
1  Seoul  kiwi     1
2  Seoul  pear     2
```

DataFrame에서 `dropna=True`이면 키 컬럼 가운데 **하나라도** `NA`인 행을 세지 않아요.

```python
>>> d2 = sd.frame.DataFrame({"city": ["Seoul", None, "Seoul", None], "fruit": ["pear", "kiwi", "pear", None]})
>>> d2.value_counts()
    city fruit  counts
0  Seoul  pear       2
>>> d2.value_counts(dropna=False)
    city fruit  counts
0  Seoul  pear       2
1   <NA>  kiwi       1
2   <NA>  <NA>       1
```

## 조심할 점

### 컬럼 이름이 `counts`와 겹치면 에러예요

결과에 `counts`(또는 `proportion`) 컬럼을 새로 만들기 때문에, 값 컬럼의 이름이 그와 같으면 `ValueError`예요. 같은 이름의 컬럼이 둘인 표는 만들 수 없어요. Series의 이름을 바꾸거나, DataFrame이면 `subset`으로 그 컬럼을 빼세요.

```python
>>> sd.frame.Series([1, 1], name="counts").value_counts()
Traceback (most recent call last):
    ...
ValueError: value_counts(): the value column cannot be named 'counts'
>>> sd.frame.DataFrame({"a": [1, 1], "counts": [2, 2]}).value_counts()
Traceback (most recent call last):
    ...
ValueError: value_counts(): a key column cannot be named 'counts'
```

### 방향은 `descending`으로

정렬 방향의 이름은 `descending`이에요. `ascending`은 없어요.

```python
>>> fruit.value_counts(ascending=True)
Traceback (most recent call last):
    ...
TypeError: Series.value_counts() got an unexpected keyword argument 'ascending'. Did you mean 'descending'?
```

bool 옵션(`normalize`, `sort`, `descending`, `dropna`)은 `True`나 `False`만 받아요. 모두 이름을 붙여서 줘요. Series의 `value_counts()`에는 자리로 주는 인자가 없어요.

```python
>>> fruit.value_counts(normalize=1)
Traceback (most recent call last):
    ...
TypeError: value_counts(): 'normalize' must be True or False, not int
```

### 줄 하나를 고르면 1행짜리 DataFrame이에요

결과가 DataFrame이라서 `.iloc[0]`으로 줄 하나를 고르면 1행짜리 DataFrame이 나와요. 값 하나가 필요하면 컬럼을 먼저 고르거나 `.loc[행, 컬럼]`을 써요.

```python
>>> vc.iloc[0]
  fruit  counts
0  pear       3
>>> vc["fruit"].iloc[0]
'pear'
```

### 빈 Series

빈 Series의 결과는 컬럼만 있고 행이 없는 DataFrame이에요.

```python
>>> sd.frame.Series([], dtype="string").value_counts()
Empty DataFrame
Columns: [values, counts]
Index: []
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 다른 점 |
|---|---|---|
| 값마다 개수, 많은 것부터 | `value_counts()` | 값 컬럼 + `counts` 컬럼의 DataFrame이에요. |
| 서로 다른 값만 크기순으로 | [`unique_values()`](/api/frame/unique_values/) | 개수 없이 값만 줘요. `NA`도 맨 뒤에 넣어요. |
| 종류가 몇 개인지 | [`nunique()`](/api/frame/unique_values/) | 숫자 하나예요. `value_counts()`의 행 수와 같아요(`dropna`가 같을 때). |
| 그룹마다 행 수 | [`groupby(...).size()`](/api/frame/groupby-agg/) | 키 값의 순서이고, 컬럼 이름이 `size`예요. 다른 집계와 함께 쓸 수 있어요. |
| 배열에서 값마다 개수 | [`sd.unique_counts`](/api/array/unique/) | 값의 크기순이에요. 결과는 두 배열의 namedtuple이에요. |

## pandas를 아는 분께

- **결과가 언제나 DataFrame이에요.** pandas는 값을 Index로 삼은 Series를 돌려줘요. stardust의 Index에는 float와 bool을 쓸 수 없어서, 값을 일반 컬럼으로 둬요. DataFrame의 `value_counts()`도 MultiIndex 대신 키 컬럼들과 `counts` 컬럼이에요.
- **개수 컬럼의 이름이 `counts`예요.** pandas는 `count`예요. 비율은 둘 다 `proportion`이에요. 이름 없는 Series의 값 컬럼은 `values`예요.
- 정렬 방향은 `ascending` 대신 `descending`이고 기본값은 `True`예요. pandas의 `ascending=True`가 `descending=False`예요.
- **NaN을 값으로 세요.** pandas는 NaN을 결측으로 보고 기본으로 빼요. 위의 `r`에서 pandas는 `NaN`과 `None`을 함께 빼고, `dropna=False`이면 둘을 합쳐 5로 세요.
- **`NA` 줄도 같은 순서 규칙을 따라요.** stardust는 개수가 같으면 처음 나타난 순서, `sort=False`면 처음 나타난 자리예요. pandas는 dtype에 따라 달라요. 기본 dtype(float64, object, str)에서는 같은 규칙이지만, nullable dtype(`Int64`, `Float64`, `boolean`)에서는 `dropna=False`일 때 개수가 같은 값들 가운데 NA를 뒤에 두고, `sort=False`여도 NA를 맨 뒤에 둬요.
- DataFrame의 `subset`은 positional-only예요. `bins` 인자는 없어요.
