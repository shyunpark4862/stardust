## 한눈에 보기

`interpn(points, values, xi)`는 [`RegularGridInterpolator`](/api/interpolate/RegularGridInterpolator/)`(points, values)(xi)`를 한 줄로 쓴 함수예요. 격자와 평가점을 한꺼번에 주고 값을 받아요.

```python
>>> import stardust as sd
>>> lat = sd.asarray([0.0, 1.0, 2.0])
>>> lon = sd.asarray([0.0, 1.0, 2.0, 3.0])
>>> T = sd.asarray([[10.0, 12.0, 15.0, 11.0],
...                 [11.0, 14.0, 18.0, 13.0],
...                 [ 9.0, 13.0, 16.0, 12.0]])
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 1.5], [1.0, 2.0]])
array([14.75,  18.0], dtype=float64)
>>> sd.interpolate.interpn((lat, lon), T, (0.5, 1.5))
14.75
```

결과는 객체를 만들어 부른 것과 비트까지 같아요.

```python
>>> xi = [[0.5, 1.5], [1.7, 0.2]]
>>> a = sd.interpolate.interpn((lat, lon), T, xi, method='nearest')
>>> b = sd.interpolate.RegularGridInterpolator((lat, lon), T, method='nearest')(xi)
>>> bool(sd.all(a == b))
True
```

## 객체와 함수 가운데 무엇을 쓰나요

`interpn`은 부를 때마다 격자를 검사하고 값을 복사해요. `cubic`과 `quintic`은 스플라인 계수를 구하는 연립방정식도 그때마다 풀어요. 같은 격자에서 값을 여러 번 읽으면 `RegularGridInterpolator`를 한 번 만들어 두고 부르는 편이 빨라요. 한 번 읽고 끝나는 계산에는 `interpn`이 짧아요.

| 상황 | 알맞은 것 |
|---|---|
| 평가점이 한 번에 다 있고 한 번 읽으면 끝나요 | `interpn` |
| 같은 격자를 여러 번 나눠 읽어요 | `RegularGridInterpolator` |
| 도함수가 필요해요(`nu`) | `RegularGridInterpolator` (`interpn`은 `nu`를 받지 않아요) |
| 같은 격자를 여러 방법으로 견줘요 | `RegularGridInterpolator`를 만들고 `method=`를 바꿔 불러요 |

## 인자

인자의 뜻은 `RegularGridInterpolator`와 같아요. 방법마다의 성질, 평가점의 꼴, 격자 밖과 결측값의 규칙은 그 페이지에 자세히 있어요. 짧게 정리하면 이래요.

- `method`는 `'linear'`(기본), `'nearest'`, `'slinear'`, `'cubic'`, `'quintic'`, `'pchip'`이에요.
- 격자 밖의 점은 기본이 에러예요. `bounds_error=False`면 `fill_value`(기본 NaN)를 쓰고, `fill_value=None`이면 끝 조각을 늘여요.
- 좌표에 NaN이 있는 평가점은 언제나 NaN이에요.

```python
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 3.5]])
Traceback (most recent call last):
    ...
ValueError: interpn(): one of the requested xi is out of bounds in dimension 1
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 3.5]], bounds_error=False)
array([nan], dtype=float64)
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 3.5]], bounds_error=False, fill_value=None)
array([9.75], dtype=float64)
>>> sd.interpolate.interpn((lat, lon), T, [[float('nan'), 1.0]])
array([nan], dtype=float64)
```

에러 메시지는 `interpn()`으로 시작해요.

```python
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 1.5]], method='cubic')
Traceback (most recent call last):
    ...
ValueError: interpn(): method 'cubic' needs at least 4 points per dimension, not 3 in dimension 0
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 1.5, 0.0]])
Traceback (most recent call last):
    ...
ValueError: interpn(): the points in 'xi' have dimension 3, but the grid has dimension 2
```

## 매끄러운 자료에서는 고차 방법

자료가 매끄러운 함수의 값이면 `cubic`이나 `quintic`이 `linear`보다 훨씬 정확해요. $f(x, y) = x^2 + 3y$처럼 축마다 3차 이하인 다항식은 `cubic`이 정확히 되살려요.

```python
>>> xx = sd.linspace(0, 2, 5)
>>> yy = sd.linspace(0, 1, 4)
>>> F = sd.reshape(xx, (5, 1)) ** 2 + 3 * sd.reshape(yy, (1, 4))
>>> pts = [[0.75, 0.5], [1.9, 0.1]]
>>> sd.interpolate.interpn((xx, yy), F, pts)
array([             2.125, 3.9499999999999993], dtype=float64)
>>> sd.interpolate.interpn((xx, yy), F, pts, method='cubic')
array([            2.0625, 3.9099999999999997], dtype=float64)
>>> 0.75**2 + 1.5, 1.9**2 + 0.3
(2.0625, 3.9099999999999997)
```

## 1차원 자료

축 하나짜리 격자도 돼요. 이때 `linear`는 자료 범위 안에서 [`sd.interp`](/api/array/interp/)와 비트까지 같아요.

```python
>>> fp = sd.asarray([1.0, 4.0, 2.0, 8.0])
>>> xq = sd.asarray([0.3, 1.7, 2.25])
>>> sd.interpolate.interpn((lon,), fp, xq)
array([1.9, 2.6, 3.5], dtype=float64)
>>> sd.interp(xq, lon, fp)
array([1.9, 2.6, 3.5], dtype=float64)
```

1차원 꺾은선이라면 `sd.interp`가 더 간단해요. `interpn`은 격자 밖을 에러로 다루고, `sd.interp`는 끝값으로 잘라요.

## 조심할 점

### 옵션은 이름으로 줘요

`points`, `values`, `xi`만 자리로 줘요.

```python
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 1.5]], 'linear')
Traceback (most recent call last):
    ...
TypeError: interpn(): takes 3 positional arguments but 4 were given
```

### 도함수는 받지 않아요

`interpn`에는 `nu`가 없어요. 도함수는 `RegularGridInterpolator`를 만들어 `nu=`로 불러요.

```python
>>> sd.interpolate.interpn((lat, lon), T, [[0.5, 1.5]], nu=(1, 0))
Traceback (most recent call last):
    ...
TypeError: interpn(): unexpected keyword argument 'nu'
```

## scipy·numpy를 아는 분께

- `method='splinef2d'`는 없어요. 2차원 격자의 스플라인은 `method='cubic'`이 같은 일을 해요.
- 옵션은 이름으로만 받아요. 방법 이름은 소문자 정식 이름만 받아요.
- `RegularGridInterpolator`와 다른 점(직접 푸는 `cubic`·`quintic`, NaN 평가점은 NaN, 무한한 눈금은 에러 등)이 그대로 적용돼요. 자세한 것은 [`RegularGridInterpolator`](/api/interpolate/RegularGridInterpolator/)의 마지막 절에 있어요.
