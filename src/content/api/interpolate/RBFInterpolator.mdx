---
title: RBFInterpolator
names: [RBFInterpolator]
group: 흩어진 점
order: 1
signatures:
  - "sd.interpolate.RBFInterpolator(y, d, /, *, neighbors=None, smoothing=0.0, kernel='thin_plate_spline', epsilon=None, degree=None)"
  - "rbf(x, /)"
summary: 아무 데나 흩어진 점의 값(관측소의 기온, 시추공의 깊이)으로 매끄러운 곡면을 만들어요. 점마다 거리에 따라 줄어드는 함수(방사 기저 함수)를 놓고 다항식을 더해 모든 점을 지나게 해요. 핵의 종류, 모양 인자, 평활, 가까운 이웃만 쓰는 국소 보간을 골라요.
params:
  - name: y
    type: ndarray, 수의 시퀀스, numpy 배열
    kind: positional-only
    desc: "자료점. (n, m) 배열이고 행 하나가 m차원 점 하나예요. 1차원 자료도 (n, 1)로 줘요. 모든 좌표가 유한해야 하고 점이 1개 이상이어야 해요."
  - name: d
    type: ndarray, 수의 시퀀스, numpy 배열
    kind: positional-only
    desc: "자료점마다의 값. 첫 축의 길이가 n이고 나머지 축은 함께 다루는 여러 값(배치)이에요. float64나 complex128이고 모두 유한해야 해요."
  - name: neighbors
    type: int 또는 None
    kind: keyword-only
    desc: "None(기본값)이면 모든 자료점으로 곡면 하나를 만들어요. k면 평가점마다 가장 가까운 k개 자료점만으로 그 자리의 곡면을 만들어요(1 이상, n보다 크면 n)."
  - name: smoothing
    type: float 또는 (n,) 배열
    kind: keyword-only
    desc: "평활 정도(유한, 0 이상). 0이면 모든 자료점을 정확히 지나고, 크면 점을 대강 따라가는 매끄러운 곡면이에요. 배열이면 점마다 따로예요. 기본값 0."
  - name: kernel
    type: str
    kind: keyword-only
    desc: "방사 기저 함수의 종류. 'linear', 'thin_plate_spline', 'cubic', 'quintic', 'multiquadric', 'inverse_multiquadric', 'inverse_quadratic', 'gaussian'. 기본값 'thin_plate_spline'."
  - name: epsilon
    type: float 또는 None
    kind: keyword-only
    desc: "모양 인자(유한한 양수). 거리에 곱해 핵의 폭을 정해요. 앞의 네 핵은 None이면 1이고, 뒤의 네 핵은 꼭 줘야 해요."
  - name: degree
    type: int 또는 None
    kind: keyword-only
    desc: "더하는 다항식의 차수. −1이면 다항식 없음이에요. None이면 핵마다의 최소 차수(0 이상)예요. 핵의 최소보다 낮으면 에러예요."
returns:
  type: RBFInterpolator
  desc: "보간 객체. (…, m) 평가점으로 불러 (…) + d의 나머지 모양의 값을 받아요. 공개 속성은 없어요."
raises:
  - type: TypeError
    desc: "y·d가 수의 배열이 아닐 때, y가 복소수일 때, kernel이 문자열이 아닐 때, neighbors·degree가 int가 아닐 때, smoothing이 bool일 때, epsilon이 실수가 아닐 때, 옵션을 자리로 주거나 없는 인자(solver)를 줄 때."
  - type: ValueError
    desc: "y가 2차원이 아니거나 점이나 좌표가 없을 때, y나 d에 NaN·inf가 있을 때, d의 행 수가 n과 다를 때, kernel의 이름이 틀렸을 때(대문자 포함), 뒤의 네 핵에 epsilon이 없을 때, epsilon이 0 이하이거나 유한하지 않을 때, smoothing이 음수이거나 모양이 틀렸을 때, degree가 핵의 최소보다 낮을 때, 다항식의 항이 자료점(이웃)보다 많을 때, neighbors가 1보다 작을 때."
  - type: sd.linalg.LinAlgError
    desc: "연립방정식이 풀리지 않을 때. 같은 자료점이 둘 있고 그 smoothing이 0일 때(두 점의 번호를 말해요), 자료점이 다항식을 정하지 못할 때(직선 위의 점에 degree 1), 그 밖에 특이한 계일 때. neighbors를 주면 부를 때 그 평가점의 번호를 말해요."
  - type: MemoryError
    desc: "풀어야 할 (n + q) × (n + q) 계가 이 기계의 물리 메모리보다 클 때(q는 다항식의 항 수)."
seeAlso: [NearestNDInterpolator, RegularGridInterpolator, basics]

## 무엇을 만드나요

**방사 기저 함수**(radial basis function, RBF)는 한 점에서의 거리에만 달린 함수 $\varphi(r)$예요. 자료점 $y_j$마다 이 함수를 하나씩 놓고, 무게 $a_j$를 곱해 더한 뒤 낮은 차수의 다항식 $p$를 더해요.

$$
s(x) = \sum_{j=1}^{n} a_j\, \varphi\big(\varepsilon \lVert x - y_j \rVert\big) + p(x)
$$

$\lVert x - y_j \rVert$는 유클리드 거리, $\varepsilon$은 모양 인자(`epsilon`)예요. 무게 $a_j$와 다항식의 계수는 $s$가 모든 자료점을 지나도록($s(y_i) = d_i$) 연립방정식을 풀어 정해요. 다항식의 몫까지 정하려고 $\sum_j a_j q(y_j) = 0$(차수 이하의 모든 다항식 $q$에 대해)을 함께 둬요.

어느 차원의 점이든 거리만 쓰므로, 2차원 지도의 점, 3차원 공간의 점, 변수가 다섯인 실험 조건 어디에나 같은 방법이 통해요.

## 자료점 `y`와 값 `d`

`y`는 (n, m) 배열이에요. 행 하나가 점 하나, 열이 좌표예요. 1차원 자료도 열 하나짜리 2차원 배열로 줘요.

```python
>>> sd.interpolate.RBFInterpolator([0.0, 1.0, 2.0], [1.0, 2.0, 3.0])
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'y' must have 2 dimensions (points, coordinates), not 1
>>> sd.interpolate.RBFInterpolator([[0.0], [1.0], [2.0], [4.0]], [1.0, 2.0, 0.0, 3.0])([[0.5], [3.0]])
array([1.7172162239562994, 0.9598874605555456], dtype=float64)
```

`d`의 첫 축은 점의 수와 같아야 해요. 좌표와 값은 모두 유한해야 해요. 계수를 연립방정식으로 한꺼번에 구하므로 NaN 하나가 곡면 전체를 망가뜨리기 때문이에요. 결측값이 있는 점은 먼저 빼고 만들어요.

```python
>>> sd.interpolate.RBFInterpolator(pts, vals[:5])
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'd' must have one row per data point (30), not 5
>>> v2 = vals.copy()
>>> v2[0] = float('nan')
>>> sd.interpolate.RBFInterpolator(pts, v2)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'd' must be finite
```

`d`가 2차원 이상이면 뒤의 축은 같은 자료점의 여러 값이에요. 복소수 값도 받아요.

```python
>>> D2 = sd.stack([vals, 2 * vals, -vals], axis=1)
>>> rv = sd.interpolate.RBFInterpolator(pts, D2)
>>> rv([0.5, 0.5])
array([ 1.2458544466783013,  2.4917088933566025, -1.2458544466783013], dtype=float64)
>>> rv(q).shape
(3, 3)
>>> sd.interpolate.RBFInterpolator(pts, vals + 1j * vals)([0.5, 0.5])
(1.2458544466783013+1.2458544466783013j)
```

## 부르기: 평가점 `x`

평가점은 마지막 축이 좌표인 (…, m) 배열이에요. 결과는 앞의 모양 (…)에 값의 나머지 모양이 붙어요. 점 하나(1차원 배열)에 값이 스칼라면 Python `float`이에요.


좌표에 NaN이 있는 평가점은 NaN이에요. 좌표가 inf면 식을 그대로 계산하는데, 대부분의 핵에서 무한대끼리 빼게 되어 NaN이 나와요.

## 핵 `kernel`

$r = \varepsilon \lVert x - y_j \rVert$일 때 여덟 가지 핵이 있어요.

| `kernel` | $\varphi(r)$ | `epsilon` | 기본 `degree` |
|---|---|---|---|
| `'linear'` | $-r$ | 기본 1 | 0 |
| `'thin_plate_spline'`(기본) | $r^2 \log r$ | 기본 1 | 1 |
| `'cubic'` | $r^3$ | 기본 1 | 1 |
| `'quintic'` | $-r^5$ | 기본 1 | 2 |
| `'multiquadric'` | $-\sqrt{1 + r^2}$ | 꼭 줘요 | 0 |
| `'inverse_multiquadric'` | $1/\sqrt{1 + r^2}$ | 꼭 줘요 | 0 |
| `'inverse_quadratic'` | $1/(1 + r^2)$ | 꼭 줘요 | 0 |
| `'gaussian'` | $e^{-r^2}$ | 꼭 줘요 | 0 |

앞의 넷은 거리의 거듭제곱 꼴이라 척도를 바꿔도 곡면의 모양이 같아요. 그래서 `epsilon`이 필요 없고, 주어도 결과가 반올림 차이로만 달라요. 기본인 `thin_plate_spline`은 2차원에서 휘어지는 데 드는 에너지가 가장 작은 곡면(얇은 판을 점에 맞춰 구부린 모양)이라 지형이나 기상 자료의 기본값으로 알맞아요.

알맞은 `epsilon`은 자료점 사이의 거리에 달려요. 대략 (1 / 이웃한 점 사이의 거리) 둘레에서 시작해 봐요. 너무 작으면 핵들이 서로 비슷해져 연립방정식이 나빠지고(조건수가 커져요) 결과의 정확도가 떨어져요. `epsilon`은 유한한 양수여야 해요.

```python
>>> sd.interpolate.RBFInterpolator(pts, vals, kernel='gaussian', epsilon=0.0)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'epsilon' must be finite and positive, not 0.0
```

## 다항식 `degree`

더하는 다항식의 차수예요. 다항식이 있으면 자료가 그 차수의 다항식일 때 정확히 되살리고, 자료 범위 밖에서 그 다항식의 추세를 따라가요. 기본 `thin_plate_spline`은 1차라서 평면 자료를 정확히 되살려요.

```python
>>> lin = 2.0 + 3.0 * pts[:, 0] - pts[:, 1]
>>> sd.interpolate.RBFInterpolator(pts, lin)([[2.0, 2.0], [5.0, -3.0]])
array([6.000000000000003, 20.00000000000002], dtype=float64)
>>> 2 + 3 * 2.0 - 2.0, 2 + 3 * 5.0 + 3.0
(6.0, 20.0)
```

가우스 핵의 기본은 0차(상수)라서 자료에서 멀어지면 상수로 내려앉아요. `degree=1`이면 평면의 추세를 따라가요.

```python
>>> sd.interpolate.RBFInterpolator(pts, lin, kernel='gaussian', epsilon=3.0)([[2.0, 2.0], [5.0, -3.0]])
array([ 3.032986434713542, 3.0329864342983703], dtype=float64)
>>> sd.interpolate.RBFInterpolator(pts, lin, kernel='gaussian', epsilon=3.0, degree=1)([[2.0, 2.0], [5.0, -3.0]])
array([  6.00000000000005, 20.000000000000078], dtype=float64)
```

핵마다 연립방정식이 풀린다고 보장되는 최소 차수가 있어요(위 표의 기본 `degree`). 그보다 낮으면 에러예요. 가우스, 역다중이차, 역이차 핵은 다항식 없이(`degree=-1`)도 돼요.

```python
>>> sd.interpolate.RBFInterpolator(pts, vals, degree=0)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'degree' must be at least 1 for kernel 'thin_plate_spline' (the system may not be solvable below it), not 0
>>> sd.interpolate.RBFInterpolator(pts, vals, kernel='gaussian', epsilon=3.0, degree=-1)([0.5, 0.5])
1.2533861038500949
>>> sd.interpolate.RBFInterpolator(pts, vals, kernel='gaussian', epsilon=3.0, degree=-2)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'degree' must be at least -1, not -2
```

$m$차원의 $k$차 다항식은 항이 $\binom{k + m}{m}$개예요. 자료점이 그보다 적으면 정할 수 없어요. 자료점이 다항식을 정하지 못하는 배치(2차원의 점이 모두 한 직선 위에 있는데 1차 다항식)도 에러예요.

```python
>>> sd.interpolate.RBFInterpolator(pts[:5], vals[:5], degree=2)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): at least 6 data points are required for 'degree' 2 in 2 dimensions, not 5
>>> line = sd.stack([sd.linspace(0, 1, 6), sd.linspace(0, 1, 6)], axis=1)
>>> sd.interpolate.RBFInterpolator(line, sd.ones(6))
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: RBFInterpolator(): the monomials of degree 1 at the data points do not have full column rank (2/3): the system is singular
>>> sd.interpolate.RBFInterpolator(line, sd.ones(6), kernel='linear')([[0.5, 0.2]])
array([1.0], dtype=float64)
```

```python
>>> for s in (0.0, 1e-3, 0.1, 10.0):
```

`smoothing`은 점마다 다르게 줄 수도 있어요. 믿을 만한 점은 작게, 잡음이 큰 점은 크게 줘요. 수 하나나 길이 n의 배열이고, 유한하며 0 이상이어야 해요.

```python
>>> sd.interpolate.RBFInterpolator(pts, vals, smoothing=-1.0)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'smoothing' must be finite and 0 or more, not -1.0
>>> sd.interpolate.RBFInterpolator(pts, vals, smoothing=sd.ones(3))
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): 'smoothing' must be a number or an array of shape (30,), not (3,)
```

### 같은 자리의 두 점

같은 좌표에 자료점이 둘 있으면 `smoothing=0`으로는 풀 수 없어요. 두 점을 모두 정확히 지날 수 없기 때문이에요(값이 같아도 연립방정식이 특이해요). 에러가 두 점의 번호를 말해 줘요. 중복을 빼거나 평균을 내거나, `smoothing`을 양수로 줘요.

```python
>>> dup = sd.concat([pts, pts[3:4]])
>>> sd.interpolate.RBFInterpolator(dup, sd.concat([vals, vals[3:4]]))
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: RBFInterpolator(): data points 3 and 30 are equal and their smoothing is 0: the system is singular
>>> sd.interpolate.RBFInterpolator(dup, sd.concat([vals, vals[3:4] + 0.1]), smoothing=1e-3)([pts[3]]), vals[3]
(array([0.9911667599782751], dtype=float64), 0.9424754246814784)
```

## 가까운 이웃만: `neighbors`

기본은 모든 자료점으로 연립방정식 하나를 풀어요. 점이 $n$개면 $(n + q) \times (n + q)$ 행렬이라 점이 1만 개만 되어도 행렬 하나가 800 MB예요. `neighbors=k`를 주면 평가점마다 가장 가까운 $k$개 자료점만으로 작은 곡면을 만들어 그 자리의 값을 계산해요. 점이 많을 때 메모리와 시간이 크게 줄어요.

```python
>>> rn = sd.interpolate.RBFInterpolator(pts, vals, neighbors=10)
>>> rn
RBFInterpolator(points=30, dimensions=2, kernel='thin_plate_spline', neighbors=10)
>>> rn(q)
array([ 1.252947211763459, 1.2016291509899828, 0.3673091599969802], dtype=float64)
>>> float(sd.max(sd.abs(rn(pts) - vals)))
6.661338147750939e-16
```

한 평가점의 값은 그 점의 이웃 $k$개로 만든 `RBFInterpolator`의 값과 비트까지 같아요. 이웃은 [`KDTree`](/api/spatial/KDTree/)로 찾고, 거리가 같은 이웃은 번호가 작은 점이 먼저예요. 그래서 다른 평가점이 무엇이든, 평가점의 순서나 스레드 수가 어떻든 같은 값이에요. 같은 이웃 집합을 가진 평가점들은 한 번 푼 계수를 함께 써요.

```python
>>> idx = sd.spatial.KDTree(pts).query([0.5, 0.5], k=10).indices
>>> sd.interpolate.RBFInterpolator(pts[idx], vals[idx])([0.5, 0.5]) == rn([0.5, 0.5])
True
```

이웃 집합이 평가점마다 바뀌므로 곡면은 이웃이 바뀌는 경계에서 조금 뛰어요. 매끄러움이 중요하면 $k$를 넉넉히(수십 개) 줘요. $k$가 자료점의 수 이상이면 전역 곡면과 비트까지 같아요.

```python
>>> bool(sd.all(sd.interpolate.RBFInterpolator(pts, vals, neighbors=30)(q) == rbf(q)))
True
>>> sd.interpolate.RBFInterpolator(pts, vals, neighbors=2)
Traceback (most recent call last):
    ...
ValueError: RBFInterpolator(): at least 3 neighbors are required for 'degree' 1 in 2 dimensions, not 2
```

`neighbors`가 있으면 좌표에 NaN이나 inf가 있는 평가점은 이웃을 정할 수 없어 NaN이에요. 국소 연립방정식이 풀리지 않으면 부를 때 `LinAlgError`이고 그 평가점의 번호를 말해요.

```python
>>> rn([[float('nan'), 0.5], [float('inf'), 0.5], [0.5, 0.5]])
array([              nan,               nan, 1.252947211763459], dtype=float64)
```

## 정확도와 결정성

연립방정식은 대칭 부정치 행렬의 분해(Bunch–Kaufman $LDL^\mathsf{T}$)로 풀어요. 정확한 참값과 견준 시험에서 풀이와 평가의 반올림 오차는 핵마다 보장하는 한계의 0.015–0.055배였어요. 다만 끝에서 끝의 오차는 연립방정식의 조건수가 정해요. `epsilon`이 작은 가우스 핵처럼 핵들이 서로 비슷한 계는 조건수가 커서 결과가 자료의 반올림보다 훨씬 크게 흔들릴 수 있어요. 이것은 계산 방법이 아니라 문제 자체의 성질이에요. 한계와 증명은 [정확도와 성능](/internals/interpolate/accuracy-performance/)에 있어요.

전역 연립방정식의 분해는 LAPACK에 맡겨요. 그래서 `neighbors` 없이 만든 곡면은 같은 기계에서 같은 스레드 수일 때 실행마다 같은 비트예요. `neighbors=k`의 값은 이웃 집합만으로 정해지므로 스레드 수와도 상관없이 같은 비트예요.

## 조심할 점

### 자료점 근처에서만 믿어요

곡면은 자료점 사이를 매끄럽게 메우지만, 자료점에서 멀리 떨어진 곳의 값은 다항식 부분과 핵의 꼬리가 정해요. 관측소 바깥의 넓은 지역으로 늘이는 데는 쓰지 않아요.

### 좌표의 척도를 맞춰요

거리는 모든 좌표를 같은 무게로 더해요. 한 축은 미터, 다른 축은 킬로미터처럼 척도가 다르면 큰 축이 거리를 다 차지해요. 좌표를 비슷한 범위로 바꾼 뒤 만들어요.

### 옵션은 이름으로 줘요

```python
>>> sd.interpolate.RBFInterpolator(pts, vals, 10)
Traceback (most recent call last):
    ...
TypeError: RBFInterpolator(): takes 2 positional arguments but 3 were given
```

## scipy·numpy를 아는 분께

- 옵션은 이름으로만 받아요. `kernel`은 소문자 정식 이름만 받아요(scipy는 대문자도 받아요).
- 음수 `smoothing`, 0이나 음수의 `epsilon`은 `ValueError`예요. scipy는 받아요.
- `degree`가 핵의 최소보다 낮으면 `-1`을 포함해 `ValueError`예요. scipy는 0 이상이면 경고하고 `-1`은 말없이 받아요.
- 같은 자료점이 있고 `smoothing`이 0이면 `LinAlgError`예요. scipy는 에러 없이 값을 내요. 자료점이 다항식을 정하지 못하면(직선 위의 점에 `degree=1`) 풀기 전에 `LinAlgError`예요. scipy는 이때 아주 큰 값을 말없이 낼 수 있어요.
- `d`에 NaN이나 inf가 있으면 `ValueError`예요. scipy는 NaN 결과를 내요.
- 평가점은 (…, m) 배열을 받아요. scipy는 (Q, m)만 받아요. 점 하나에 스칼라 값이면 Python 스칼라예요.
- `neighbors`가 있을 때 유한하지 않은 평가점은 NaN이에요. scipy는 `ValueError`예요. 이웃의 동점은 언제나 작은 번호가 먼저라 결과가 실행마다 같아요.
- `neighbors`가 자료점의 수 이상이면 전역 곡면과 비트까지 같아요.
- 공개 속성(`y`, `d`, `kernel`, `epsilon` 등)은 없어요.
- 옛 `Rbf`는 없어요. `Rbf(x, y, z, function='gaussian', epsilon=e)`는 `RBFInterpolator(points, values, kernel='gaussian', epsilon=...)`로 바꿔 써요. `Rbf`의 `epsilon`은 거리를 나누는 수라서 같은 곡면을 얻으려면 그 역수를 줘요(핵의 이름도 다를 수 있어요).
