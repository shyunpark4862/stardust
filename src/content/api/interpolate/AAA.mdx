## 한눈에 보기

함수를 많은 자리에서 재 두었는데, 그 함수를 짧은 식으로 적어 두고 싶다고 해 볼게요. 다항식은 극점(값이 무한대로 가는 자리)이 가까이 있거나 뾰족한 곳이 있으면 항이 아주 많이 필요해요. **유리식**(다항식 나누기 다항식)은 그런 함수도 적은 항으로 따라가요. `AAA`는 표본에서 좋은 유리식을 알아서 찾아 줘요.

$[-1, 1]$의 1000개 자리에서 잰 $\tan(1.5x)$를 근사해 볼게요. 이 함수는 $x = \pi/3 \approx 1.047$에 극점이 있어서 구간 끝 가까이에서 가파르게 올라가요.

```python
>>> import stardust as sd
>>> import math
>>> x = sd.linspace(-1.0, 1.0, 1000)
>>> r = sd.interpolate.AAA(x, sd.tan(1.5 * x))
>>> r
AAA(support_points=8, converged=True)
>>> r(0.3), math.tan(0.45)
(0.48305506561268824, 0.4830550656165784)
>>> xs = sd.linspace(-1.0, 1.0, 3001)
>>> float(sd.max(sd.abs(r(xs) - sd.tan(1.5 * xs))))
4.668931907758633e-12
```

표본 1000개 가운데 8개만 골라 만든 유리식이 구간 전체에서 $5 \times 10^{-12}$ 안으로 맞아요.

## 무엇을 계산하나요

`AAA`가 만드는 유리식은 [`BarycentricInterpolator`](/api/interpolate/BarycentricInterpolator/)와 같은 무게중심 꼴이에요. 고른 표본의 자리 $z_j$를 **지지점**, 거기서의 값 $f_j$를 **지지값**이라 해요.

$$
r(z) = \frac{\displaystyle\sum_{j=1}^{m} \frac{w_j}{z - z_j}\, f_j}{\displaystyle\sum_{j=1}^{m} \frac{w_j}{z - z_j}}
$$

지지점이 $m$개면 분자와 분모가 $m - 1$차인 유리식이에요. 다항식 보간과 다른 점은 무게 $w_j$를 노드의 식으로 정하지 않고 자료에 맞춰 고른다는 것이에요.

알고리즘은 걸음마다 지지점을 하나씩 더해요.

1. 지금의 유리식과 표본의 차 $|f - r|$이 가장 큰 표본을 새 지지점으로 골라요(처음에는 표본의 평균과 견줘요).
2. 지지점이 아닌 모든 표본에서 $f \cdot (\text{분모}) - (\text{분자})$가 가장 작아지도록 무게를 최소제곱으로 골라요(무게 벡터의 길이는 1로 둬요). 차 $f - r$을 분모로 곱해 무게에 대해 선형으로 만든 것이라 한 번의 특이값 분해로 풀려요.
3. 모든 표본에서 $|f - r| \le \mathrm{rtol} \cdot \max|f|$이면 멈춰요. 아니면 1로 돌아가요.

지지점에서는 값을 그대로 지나고, 나머지 표본은 근사해요. 그래서 `AAA`는 모든 표본을 지나는 보간이 아니라 표본에 맞추는 **근사**예요. 멈출 때는 모든 표본에서 차가 `rtol` 기준 안에 들어와 있어요.

이름 AAA는 adaptive Antoulas–Anderson의 머리글자예요. Nakatsukasa, Sète, Trefethen이 제안한 알고리즘이에요.

## 걸음마다 줄어드는 오차: `errors`, `converged`

`errors`는 걸음마다 모든 표본에서의 가장 큰 차 $\max|f - r|$이에요. 길이가 걸음 수이고, 마지막 값이 다 만든 유리식의 오차예요. `converged`는 `rtol` 기준을 채워서 멈췄는지예요.

```python
>>> r.converged, r.errors.shape
(True, (8,))
>>> r.errors
array([     28.20283989434344,      8.745299087123358,
           0.2076086096040033,   0.003586350545638939,
        4.480672548012876e-05, 2.2671476251900913e-07,
       1.0027836339077112e-09,  4.665823283289683e-12], dtype=float64)
```

매끄러운 함수는 걸음마다 오차가 몇 자릿수씩 줄어요. 뾰족한 곳이 있는 $|x|$는 더 많은 걸음이 들고 줄어드는 모양도 들쭉날쭉해요.

```python
>>> e = sd.interpolate.AAA(x, sd.exp(x))
>>> e, e.errors[-1]
(AAA(support_points=6, converged=True), 4.800604358479177e-13)
>>> a = sd.interpolate.AAA(x, sd.abs(x))
>>> a, a.errors[-1]
(AAA(support_points=39, converged=True), 6.891015535970269e-13)
```

## 멈춤 기준: `rtol`, `max_terms`

`rtol`은 얼마나 정확해야 멈출지예요. 기본값은 $\varepsilon^{3/4} \approx 1.8 \times 10^{-12}$($\varepsilon = 2^{-52}$)이라 반올림보다 조금 위까지 맞춰요. 거친 근사로 충분하면 크게 해서 지지점을 줄여요.

```python
>>> e3 = sd.interpolate.AAA(x, sd.exp(x), rtol=1e-3)
>>> e3, e3.errors
(AAA(support_points=3, converged=True), array([   2.3504023872876028,  0.033241857785917706, 0.0003010858210690248], dtype=float64))
```

`max_terms`는 걸음 수(지지점 수)의 한계예요. 그 안에 기준을 채우지 못하면 거기서 멈추고 `converged`가 `False`예요. 경고는 내지 않으니 결과를 쓰기 전에 `converged`를 확인해요.

```python
>>> a20 = sd.interpolate.AAA(x, sd.abs(x), max_terms=20)
>>> a20, a20.errors[-1]
(AAA(support_points=20, converged=False), 7.023978026270139e-05)
```

`rtol=0`이면 기준을 채울 수 없으니 언제나 `max_terms`(또는 표본 수)까지 가요. 반올림 크기까지 내려간 뒤의 걸음은 반올림을 맞추느라 가짜 극점을 만들기 쉬워요. 아래의 `clean_up`이 그것을 지워요.

## 지지점과 무게: 속성

| 속성 | 뜻 | 타입 |
|---|---|---|
| `support_points` | 고른 지지점. 고른 순서예요 | 읽기 전용 (m,) 배열, 자료가 실수면 float64 |
| `support_values` | 지지점에서의 표본 값 | 읽기 전용 (m,) 배열 |
| `weights` | 무게중심 무게 | 읽기 전용 (m,) 배열 |
| `errors` | 걸음마다의 $\max\lvert f - r\rvert$ | 읽기 전용 float64 배열 |
| `converged` | `rtol` 기준을 채워 멈췄는지 | `bool` |

```python
>>> r.support_points[:4]
array([               -1.0,                 1.0,  0.8258258258258258,
       -0.9719719719719719], dtype=float64)
>>> r.support_values[:4]
array([-14.10141994717172,  14.10141994717172,  2.900017686066505,
       -8.824588989307683], dtype=float64)
>>> r(r.support_points[0]) == r.support_values[0]
True
```

`tan(1.5x)`의 첫 두 지지점은 값이 가장 큰 양 끝이에요. 지지점에서는 지지값을 비트까지 그대로 돌려줘요.

## 극점, 유수, 영점

유리식의 극점을 보면 함수의 성질을 읽을 수 있어요. `poles()`는 유한한 극점, `residues()`는 극점마다의 유수, `roots()`는 유한한 영점이에요. 모두 complex128 배열이고, 순서는 계산이 내놓은 순서예요.

```python
>>> r.poles()
array([(-430.24328040447705+0j),     (6.2056505054334+0j),
        (-6.115264080524804+0j),  (3.1462079963705905+0j),
       (-3.1453096668207987+0j),  (1.0471975511969502+0j),
       (-1.0471975511967444+0j)], dtype=complex128)
>>> r.residues()
array([(-10172.572759639668+0j),  (-1.797426977924216+0j),
        (-1.702074839938547-0j), (-0.6789333452925383-0j),
       (-0.6768199749143329+0j), (-0.6666666666828277+0j),
       (-0.6666666666733001-0j)], dtype=complex128)
```

$\tan(1.5x)$의 극점은 $x = \pi/3 + 2k\pi/3$이고 유수는 모두 $-2/3$이에요. 표본 구간 $[-1, 1]$에 가까운 극점 $\pm\pi/3 \approx \pm 1.0472$와 그 유수는 거의 정확하고, 먼 극점일수록 거칠어요. 맨 앞의 $-430$은 자료와 상관없는 먼 극점이에요.

이렇게 근사한 극점 덕분에 표본 범위를 조금 벗어나 극점 너머까지도 함수를 따라가요. $x = 1.2$는 극점 $\pi/3$ 너머에 있어요.

```python
>>> r(1.2), math.tan(1.8)
(-4.286261678680649, -4.286261674628062)
```

## 복소평면에서

평가점 `z`에 복소수를 주면 복소수 결과예요. 실수축의 표본으로 만든 유리식도 복소평면에서 함수를 이어 가요.

```python
>>> import cmath
>>> r(0.3 + 0.2j), cmath.tan(1.5 * (0.3 + 0.2j))
((0.43347776310280833+0.35231161762748037j), (0.4334777631134705+0.35231161763488983j))
```

## 가짜 극점 지우기: `clean_up`

반올림이나 잡음까지 맞추려고 하면 유리식이 아주 가까이 붙은 극점과 영점의 짝을 만들 수 있어요. 이런 짝을 **Froissart 쌍**이라 해요. 극점의 유수가 아주 작아서 함수의 모양을 크게 바꾸지는 않지만, 표본 사이에 극점이 끼어 그 둘레의 값을 망치고 극점을 읽을 때도 방해가 돼요.

`clean_up=True`(기본)면 만든 뒤 이런 극점을 찾아, 극점마다 가장 가까운 지지점을 빼고 남은 표본으로 무게를 다시 맞춰요. 유수의 크기를 극점에서 가장 가까운 표본까지의 거리로 나눈 값이 `clean_up_tol` × ($\lvert y \rvert$의 기하평균)보다 작으면 가짜로 봐요. 기본 문턱 $10^{-13}$은 반올림이 만든 짝만 잡아요.

`clean_up=False`로 만든 뒤 `clean_up()`을 부르면 지운 쌍의 수를 돌려줘요. 아래는 $10^{-6}$ 크기의 잡음이 섞인 $e^x$를 `rtol=0`으로 30걸음까지 맞춘 경우예요. 잡음이 만든 짝은 기본 문턱으로는 잡히지 않고, 문턱을 잡음 크기로 키우면 잡혀요.

```python
>>> rng = sd.random.default_rng(3)
>>> noisy = sd.exp(x) + 1e-6 * (rng.random(1000) - 0.5)
>>> b = sd.interpolate.AAA(x, noisy, rtol=0.0, max_terms=30, clean_up=False)
>>> b
AAA(support_points=30, converged=False)
>>> float(sd.max(sd.abs(b(x) - sd.exp(x))))
0.001177063248686272
>>> b.clean_up()
0
>>> b.clean_up(clean_up_tol=1e-6)
8
>>> b
AAA(support_points=22, converged=False)
>>> float(sd.max(sd.abs(b(x) - sd.exp(x))))
8.47065565448002e-05
```

여덟 쌍을 지우자 참 함수 $e^x$와의 차가 열 배 넘게 줄었어요. 지울 쌍이 없으면 0을 돌려주고 객체는 그대로예요. `clean_up()`은 객체를 고치는 메서드라 지운 뒤의 지지점과 무게가 객체에 남아요.

잡음이 있는 자료는 처음부터 `rtol`을 잡음 크기쯤으로 주는 편이 더 좋아요. 잡음을 맞추기 전에 멈추므로 가짜 극점이 생기지 않고 지지점도 적어요.

```python
>>> g = sd.interpolate.AAA(x, noisy, rtol=1e-6)
>>> g, float(sd.max(sd.abs(g(x) - sd.exp(x))))
(AAA(support_points=4, converged=True), 1.4233402185759303e-06)
```

## 표본: `x`, `y`

값이 NaN이나 inf인 표본은 버리고 남은 표본으로 만들어요. 표본은 자리 순서로 정렬해서 쓰고(복소수는 실수부, 허수부 순), 같은 자리가 되풀이되면 처음 표본만 써요.

```python
>>> dup = sd.interpolate.AAA([0.0, 1.0, 1.0, 2.0, 3.0], [1.0, 3.0, 99.0, 2.0, 0.0])
>>> dup, dup(1.0)
(AAA(support_points=3, converged=True), 3.0)
```

값이 모두 같으면 지지점 하나로 바로 멈춰요. 상수 유리식이라 극점도 영점도 없어요.

```python
>>> k1 = sd.interpolate.AAA(x, sd.ones(1000))
>>> k1, k1.errors, k1(5.0), k1.poles(), k1.roots()
(AAA(support_points=1, converged=True), array([0.0], dtype=float64), 1.0, array([], dtype=complex128), array([], dtype=complex128))
```

## 결과의 모양

평가점이 수 하나면 Python `float`(자료나 평가점이 복소수면 `complex`), 배열이면 같은 모양의 배열이에요.

```python
>>> r(sd.asarray([[0.1, 0.2], [0.3, 0.4]])).shape
(2, 2)
```

## 경계의 값

| 상황 | 결과 |
|---|---|
| 평가점이 지지점 | 그 지지값 그대로 |
| 평가점이 NaN | NaN |
| 평가점이 inf나 −inf | 극한 $\sum w_j f_j / \sum w_j$ |
| 값이 유한하지 않은 표본 | 버려요 |

## 계산의 크기

걸음마다 (표본 수) × (지금까지의 지지점 수) 행렬의 특이값 분해를 한 번 해요. 그래서 시간은 거의 표본 수와 걸음 수로 정해져요. 표본 수천 개, 지지점 수십 개면 금방이에요. 극점과 영점은 크기가 (지지점 수 + 1)인 일반화 고유값 문제를 풀어 구해요. 시간이 지지점 수의 세제곱에 비례하므로 `max_terms`를 아주 크게 하면 `poles()`가 오래 걸려요. 극점, 유수, 영점은 처음 부를 때 한 번 구해 객체에 담아 둬요.

## 결과는 언제나 같아요

같은 표본, 같은 옵션이면 같은 기계에서 같은 스레드 수일 때 언제나 같은 비트예요. 지지점을 고를 때 차가 같은 표본이 여럿이면 앞의 표본을 골라요. 무게와 극점은 LAPACK의 특이값 분해와 고유값 계산으로 구해요.

시험 자료에서 평가의 오차는 계산한 지지점·값·무게의 정확한 유리식 대비 계약 한계의 0.31배 이하예요. 수렴했다면 표본에서의 차는 언제나 $\mathrm{rtol} \cdot \max|f|$ 이하예요. 자세한 것은 [정확도와 성능](/internals/interpolate/accuracy-performance/)과 [AAA](/internals/interpolate/aaa/)에 있어요.

## 조심할 점

### 보간이 아니라 근사예요

지지점이 아닌 표본은 지나지 않아요. 모든 표본을 지나야 하면 [`FloaterHormannInterpolator`](/api/interpolate/FloaterHormannInterpolator/)나 [`BarycentricInterpolator`](/api/interpolate/BarycentricInterpolator/)를 써요. 표본에 잡음이 있으면 기본 `rtol`로는 잡음까지 맞추려고 해서 지지점이 많아지고 가짜 극점이 생겨요. 잡음의 크기쯤으로 `rtol`을 키워요.

### 표본 밖에서는 극점을 조심해요

유리식은 표본이 없는 곳에 극점을 둘 수 있어요. 실수축의 표본으로 만들었어도 표본 범위 밖의 실수축이나 복소평면에 극점이 있을 수 있으니, 범위 밖에서 쓸 때는 `poles()`를 확인해요.

### `converged`를 확인해요

`max_terms`에 이르러도 경고는 없어요. `converged`가 `False`면 `errors[-1]`이 기준보다 커요.

## scipy·numpy를 아는 분께

- 이름, 메서드, 속성은 `scipy.interpolate.AAA`와 같고 알고리즘의 단계도 그대로예요. 지금은 시험 자료에서 scipy와 같은 지지점을 같은 순서로 골라요(약속은 아니에요). 오차가 반올림 크기까지 내려간 뒤의 걸음은 반올림에 따라 갈릴 수 있어요.
- `max_terms`에 이르러도 `RuntimeWarning`을 내지 않고 `converged`가 `False`예요. scipy는 마지막 걸음에서 기준을 채워도 경고하지만, 여기서는 기준을 채웠으면 `True`예요.
- `clean_up()`은 지운 수를 돌려주고 경고는 내지 않아요. 인자 이름은 생성자와 같은 `clean_up_tol`이에요. scipy의 메서드는 `cleanup_tol`이라, 그 이름을 주면 `TypeError`예요.
- `rtol`과 `clean_up_tol`이 음수이거나 유한하지 않으면 `ValueError`예요. scipy는 검사하지 않아요. 유한한 표본이 없으면 `ValueError`예요(scipy는 빈 배열의 `argmax` 에러).
- 옵션은 키워드로만 받아요. `AAA(x, y, 1e-3)`은 `TypeError`예요.
- 0차원 결과는 Python `float`·`complex`예요.
