## 무엇을 하나요

토마토 수확량의 세 집단에서 셋째 집단(h3)이 유난히 들쭉날쭉해 보여요. **Levene의 검정**은 집단의 분산이 모두 같은지 물어요.

- 귀무가설: k개 집단의 모집단 분산(흩어짐)이 모두 같아요.
- 대립가설: 적어도 한 집단의 흩어짐이 달라요.

생각은 간단해요. 값마다 제 집단의 중심 $c_i$에서 떨어진 거리 $z_{ij} = \lvert x_{ij} - c_i \rvert$를 구하면, 흩어짐이 큰 집단일수록 거리가 커요. 그러니 거리의 평균이 집단마다 같은지 [일원 분산분석](/api/htest/f_oneway/)으로 검정하면 돼요.

$$
W = \frac{N - k}{k - 1} \cdot \frac{\sum_i n_i (\bar z_i - \bar z)^2}{\sum_i \sum_j (z_{ij} - \bar z_i)^2}
$$

$\bar z_i$는 집단 i의 거리의 평균, $\bar z$는 모든 거리의 평균이에요. 귀무가설에서 W는 자유도 (k − 1, N − k)의 [F 분포](/api/stats/f/)를 근사로 따라요.

중심은 `center`로 골라요.

| `center` | 중심 | 이름과 성질 |
|---|---|---|
| `'median'`(기본) | 중앙값 | Brown–Forsythe 판. 치우친 분포나 꼬리가 두꺼운 분포에서도 잘 버텨요 |
| `'mean'` | 평균 | Levene의 원래 검정. 대칭이고 꼬리가 적당한 분포에서 힘이 세요 |
| `'trimmed'` | 절삭 평균 | 양 끝을 `proportiontocut`만큼 잘라 낸 평균. 꼬리가 두꺼운 분포에 맞아요 |

데이터가 정규분포에 가까우면 [`bartlett`](/api/htest/bartlett/)이 더 힘이 세지만, 정규분포에서 벗어나면 Bartlett은 분산이 같아도 자주 기각해요. 분포를 잘 모르면 기본값(중앙값)의 Levene이 무난해요. 순위를 쓰는 [`fligner`](/api/htest/fligner/)도 같은 목적의 검정이에요.

## 기본 사용

```python
>>> import stardust as sd
>>> g1 = [20.1, 21.4, 19.8, 22.0, 20.7, 21.1]
>>> g2 = [22.3, 23.1, 21.9, 24.0, 22.8, 23.4]
>>> h3 = [19.5, 23.2, 16.9, 22.8, 17.7, 21.4, 18.0, 24.1]
>>> r = sd.htest.levene(g1, g2, h3)
>>> r
LeveneResult(statistic=14.7985, pvalue=0.000189569, df_num=2, df_denom=17)
```

p값 0.0002로 세 집단의 흩어짐이 같다는 귀무가설을 버려요.

Levene의 검정은 정말로 "중앙값에서의 거리"의 분산분석이에요. 거리를 직접 만들어 [`f_oneway`](/api/htest/f_oneway/)에 주면 같은 값이 나와요.

```python
>>> z = [abs(sd.asarray(g) - sd.median(sd.asarray(g))) for g in (g1, g2, h3)]
>>> sd.htest.f_oneway(*z)
FOnewayResult(statistic=14.7985, pvalue=0.000189569, df_num=2, df_denom=17)
```

## 결과 읽기

| 필드·메서드 | 뜻 |
|---|---|
| `statistic` | W 통계량. 0 이상이에요 |
| `pvalue` | F 분포의 위쪽 꼬리 넓이 |
| `df_num` | 분자 자유도 k − 1(`float`) |
| `df_denom` | 분모 자유도 N − k(`float`) |
| `summary()` | 검정을 표로 적은 글. 머리에 쓴 중심(`Center:`)이 있어요 |

```python
>>> print(r.summary())
                   Levene test of homogeneity of variances

P-value:                      0.000190  Center:                         median
Df Num:                              2
Df Denom:                           17
==============================================================================
>>> w, p = r
>>> r.df_num, r.df_denom
(2.0, 17.0)
```

## center와 proportiontocut

```python
>>> sd.htest.levene(g1, g2, h3, center='mean')
LeveneResult(statistic=14.8342, pvalue=0.000187123, df_num=2, df_denom=17)
>>> sd.htest.levene(g1, g2, h3, center='trimmed', proportiontocut=0.25)
LeveneResult(statistic=14.817, pvalue=0.000188296, df_num=2, df_denom=17)
```

`'trimmed'`는 집단마다 양 끝에서 int(n · `proportiontocut`)개씩 잘라 낸 가운데 값들의 평균을 중심으로 써요. 기본값 0.05에서는 20개보다 작은 집단은 하나도 자르지 않아서 `'mean'`과 같아요. 위에서 0.25는 6개짜리 집단에서 하나씩, 8개짜리에서 둘씩 잘라요. `proportiontocut`은 `center='trimmed'`일 때만 써요.

```python
>>> sd.htest.levene(g1, g2, h3, center='trimmed').statistic == sd.htest.levene(g1, g2, h3, center='mean').statistic
True
>>> print(sd.htest.levene(g1, g2, h3, center='trimmed', proportiontocut=0.25).summary().splitlines()[4])
Df Num:                              2  Proportion Cut:                   0.25
>>> sd.htest.levene(g1, g2, h3, center='trim')
Traceback (most recent call last):
    ...
ValueError: levene(): 'center' must be 'median', 'mean' or 'trimmed', not 'trim'
>>> sd.htest.levene(g1, g2, h3, center='trimmed', proportiontocut=0.5)
Traceback (most recent call last):
    ...
ValueError: levene(): 'proportiontocut' must be >= 0 and < 0.5
```

## 이상값에 강해요

흩어짐이 같은 세 집단의 셋째에 큰 값 하나(26.0)가 섞여도, 중앙값을 중심으로 쓰는 Levene은 휘둘리지 않아요. 표본 분산을 바로 쓰는 [`bartlett`](/api/htest/bartlett/)은 이 값 하나 때문에 기각해요.

```python
>>> o3 = [19.5, 20.2, 18.9, 20.8, 19.7, 20.4, 26.0]
>>> sd.htest.levene(g1, g2, o3).pvalue
0.5446278467868456
>>> sd.htest.bartlett(g1, g2, o3).pvalue
0.014973817889510674
```

## 특수한 경우

| 입력 | 결과 |
|---|---|
| 표본을 하나만 줌 | `TypeError` |
| 한 집단이 비었음 | W, p값이 NaN |
| 모든 집단에서 거리 $z_{ij}$가 집단마다 상수 | W, p값이 NaN(분모가 0이에요) |
| `'propagate'`에서 NaN이 있음 | 모든 필드가 NaN |

```python
>>> sd.htest.levene([2.0, 4], [3.0, 5], [5.0, 7])
LeveneResult(statistic=nan, pvalue=nan, df_num=2, df_denom=3)
>>> sd.htest.levene(g1, [], h3)
LeveneResult(statistic=nan, pvalue=nan, df_num=2, df_denom=11)
```

원소가 둘인 집단은 두 값 모두 중앙값에서 같은 거리에 있어요. 모든 집단이 그러면 거리의 흩어짐이 0이라 W를 정할 수 없어요.

## 정확도

- W의 상대오차는 $10^{-14}$ 안이고(잰 최대 $3.0 \times 10^{-16}$), p값은 $10^{-14} \cdot \max(1, \kappa_p)$ 안이에요.
- 중심과 거리를 반올림 오차가 거의 없게 구해요. 크기가 짝수인 집단의 중앙값은 두 가운데 값의 정확한 반이라, 두 가운데 값이 중앙값에서 정확히 같은 거리로 남아요. 평균이 $10^8$인 데이터도 거리의 자릿수를 지켜요.

참값은 Arb(구간 산술)로 만들었어요.

## scipy를 아는 분께

scipy 1.18.1의 `scipy.stats.levene`과 같은 검정이에요. `center`, `proportiontocut`의 뜻과 절삭의 개수(int(p · n))도 같아요.

- 결과에 `df_num`, `df_denom`이 있어요. scipy의 결과는 `statistic`, `pvalue`뿐이에요. `(statistic, pvalue)`로 푸는 것은 같아요.
- 표본이 하나면 `TypeError`예요. scipy는 `ValueError`예요.
- 평균이 $10^8$인 잰 문제에서 scipy는 W가 상대 $1.5 \times 10^{-11}$, R의 `car::leveneTest`는 $8.4 \times 10^{-9}$ 틀렸어요. 여기서는 $10^{-16}$ 수준이에요.
- `axis`의 기본값이 None이에요(scipy는 0).
