## 무엇을 묻는 검정인가요

공장 A에서는 10일 동안 사고가 30건, 공장 B에서는 12일 동안 18건 났어요. 하루당 사고율은 A가 3.0건, B가 1.5건이에요. 두 공장의 사고율이 같은데 우연히 이만큼 차이가 났을까요?

드물게 일어나는 사건의 횟수는 흔히 포아송 분포를 따라요. k₁ ~ Poisson(λ₁n₁), k₂ ~ Poisson(λ₂n₂)이고 λ가 단위 크기당 발생률이에요.

- **귀무가설**: λ₁ − λ₂ = diff (기본값 0, 두 발생률이 같음)
- **대립가설**: λ₁ − λ₂ ≠ diff, < diff(`'less'`), > diff(`'greater'`)

E-test는 표준화한 차

$$
T = \frac{k_1/n_1 - k_2/n_2 - d}{\sqrt{k_1/n_1^2 + k_2/n_2^2}}
$$

를 통계량으로 써요. p값은 귀무가설을 만족하도록 추정한 두 발생률 아래에서, 가능한 모든 횟수의 쌍 (x₁, x₂) 가운데 T가 관측만큼 극단인 쌍의 확률을 더한 값이에요. 정규 근사가 아니라 포아송 분포를 그대로 더하므로, 횟수가 작을 때도 쓸 수 있어요.

## 기본 사용

```python
>>> r = sd.htest.poisson_means_test(30, 10.0, 18, 12.0)
>>> r
PoissonMeansTestResult(statistic=2.30089, pvalue=0.0213527)
>>> T, p = r
```

p = 0.021이라 유의수준 0.05에서 두 공장의 사고율이 다르다고 봐요. A의 사고율이 더 높다는 방향을 처음부터 물었다면 한쪽 검정이에요.

```python
>>> sd.htest.poisson_means_test(30, 10.0, 18, 12.0, alternative='greater').pvalue
0.009243788265411751
```

`summary()`는 머리에 개수와 크기를 함께 적어요.

```python
>>> print(r.summary())
                         Poisson means test (E-test)
==============================================================================
Statistic:                       2.301  Alternative:                 two-sided
P-value:                        0.0214  Counts:                         30, 18
                                        Sizes:                          10, 12
==============================================================================
```

## 차가 diff인지

"A의 사고율이 B보다 하루 0.5건 넘게 높은가"는 `diff=0.5`, `alternative='greater'`로 물어요. 귀무가설은 λ₁ − λ₂ = 0.5이고, 통계량의 분자에서 0.5를 빼요.

```python
>>> sd.htest.poisson_means_test(30, 10.0, 18, 12.0, diff=0.5, alternative='greater')
PoissonMeansTestResult(statistic=1.53393, pvalue=0.058184)
```

`diff`는 0 이상이어야 해요. 첫째 과정이 더 작다는 가설을 세우려면 두 과정의 순서를 바꿔서 줘요.

## 퇴화한 입력

두 횟수가 모두 0이면 T = 0이고 p값은 1이에요. 귀무가설 아래에서 추정한 둘째 발생률 (k₁ + k₂ − diff·n₁)/(n₁ + n₂)가 0 이하가 되면 검정할 수 없어 (0, 1)을 돌려줘요.

```python
>>> sd.htest.poisson_means_test(0, 10.0, 0, 12.0)
PoissonMeansTestResult(statistic=0, pvalue=1)
>>> sd.htest.poisson_means_test(2, 10.0, 0, 12.0, diff=1.0)
PoissonMeansTestResult(statistic=0, pvalue=1)
```

## 입력과 에러

횟수는 int, 크기는 양의 실수예요. 크기에는 정수가 아닌 값(관찰한 날수 9.5 등)도 돼요.

```python
>>> sd.htest.poisson_means_test(30, 9.5, 18, 12.0).pvalue
0.014147455252614283
>>> sd.htest.poisson_means_test(1.5, 10.0, 2, 12.0)
Traceback (most recent call last):
    ...
TypeError: poisson_means_test(): 'k1' must be an int, not float
>>> sd.htest.poisson_means_test(3, 0.0, 2, 12.0)
Traceback (most recent call last):
    ...
ValueError: poisson_means_test(): 'n1' must be positive and finite
>>> sd.htest.poisson_means_test(3, 10.0, 2, 12.0, diff=-1)
Traceback (most recent call last):
    ...
ValueError: poisson_means_test(): 'diff' must be non-negative and finite
```

p값은 근사 없이 모든 결과의 확률을 더해요. 더하는 걸음은 횟수의 제곱근에 비례해서 수천억 번의 횟수도 계산하지만, 2·10⁷걸음을 넘으면(횟수가 조 단위) `ValueError`예요. 걸음이 그보다 훨씬 많을 것이 분명하면 더하기 전에 바로 알려 줘요.

```python
>>> sd.htest.poisson_means_test(10**13, 1.0, 10**13 + 10**5, 1.0)
Traceback (most recent call last):
    ...
ValueError: poisson_means_test(): the counts are too large for the exact sum (it needs more than 2e+07 steps)
```

이만큼 큰 횟수에서는 통계량을 표준정규분포에 견준 p값이 정확한 값과 거의 같아요.

## 다른 검정과 고르기

- diff = 0이면, 횟수의 합 k₁ + k₂를 조건으로 k₁이 Binomial(k₁ + k₂, n₁/(n₁ + n₂))를 따른다는 조건부 검정([binomtest](/api/htest/binomtest/))도 쓸 수 있어요(아래 예). E-test는 보통 그보다 검정력이 커요.
- 개수가 아니라 "n번 중 k번"의 비율이면 [test_proportions_2indep](/api/htest/test_proportions_2indep/)예요.

```python
>>> sd.htest.binomtest(30, 48, p=10.0 / 22.0).pvalue
0.02008247898762943
```

## 정확도

p값의 합은 가능한 모든 결과를 다 더해요. 남은 확률이 합의 2⁻⁶⁰ 아래가 될 때까지 더해서 버리는 부분이 반올림보다 작아요. Arb(구간 산술)로 T를 정확히 견주고 포아송 꼬리를 더한 참값과 견주면, p값은 시험한 13문제에서 상대 3.5e-16 안이에요(4.6e-21 같은 깊은 꼬리 포함, 계약 대비 0.035).

## scipy를 아는 분께

- 같은 E-test이고 통계량은 반올림 크기까지 같아요. p값은 scipy와 다를 수 있어요. scipy는 두 합을 포아송 분포의 [ppf(1e-10), ppf(1 − 1e-16)] 범위로 잘라 깊은 꼬리에서 p값을 낮게 내요(시험한 문제에서 9000배까지). 또 격자의 T와 관측의 T를 다른 부동소수 식으로 계산해, 관측과 같은 결과를 빠뜨리기도 해요. 여기서는 모든 결과를 더하고 같은 T는 같게 판정해요.
- `k1`, `n1`, `k2`, `n2`는 위치로만, 나머지는 키워드로만 받아요.

```python
>>> import scipy.stats
>>> float(scipy.stats.poisson_means_test(26, 2.89, 30, 5.86, alternative='less').pvalue)
0.9812573909586674
>>> sd.htest.poisson_means_test(26, 2.89, 30, 5.86, alternative='less').pvalue
0.981912903261572
```

이 예에서 scipy의 p값은 관측과 같은 극단의 결과를 빠뜨려 6.6e-4 낮아요.
