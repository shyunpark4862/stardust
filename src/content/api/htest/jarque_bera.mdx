## 한눈에 보기

정규분포의 왜도는 0, 첨도는 3이에요. Jarque–Bera 검정은 표본의 왜도 $S$와 첨도 $K$가 이 두 값에서 벗어난 크기를 하나로 모아요.

$$
\mathrm{JB} = \frac{n}{6}\left(S^2 + \frac{(K - 3)^2}{4}\right)
$$

- **귀무가설**: 표본이 정규분포에서 왔어요(왜도 0, 첨도 3).
- **대립가설**: 정규분포에서 오지 않았어요.

정규분포의 표본이면 JB는 표본이 클 때 자유도 2의 카이제곱 분포를 따라요. p값은 그 위 꼬리 $P(\chi^2_2 \ge \mathrm{JB})$예요. 계량경제학에서 회귀 잔차의 정규성을 볼 때 흔히 써요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(2)
>>> lap = sd.stats.Laplace().sample(200, rng=rng)
>>> nor = sd.stats.Normal(mu=50.0, sigma=5.0).sample(200, rng=sd.random.default_rng(3))
>>> sd.htest.jarque_bera(nor)
JarqueBeraResult(statistic=0.119595, pvalue=0.941955)
>>> sd.htest.jarque_bera(lap)
JarqueBeraResult(statistic=58.6824, pvalue=1.80833e-13)
```

정규분포의 표본은 p = 0.94, 꼬리가 두꺼운 Laplace 분포의 표본은 p = 1.8e-13이에요.

## 통계량

$S$와 $K$는 보정하지 않은 표본 왜도와 첨도예요. [`sd.stats.skew`](/api/stats/skew-kurtosis/)와 `sd.stats.kurtosis(x, fisher=False)`의 값이에요(`kurtosis`의 기본은 3을 뺀 값이라 그대로 $K - 3$이에요).

```python
>>> n = 200
>>> S, K3 = sd.stats.skew(lap), sd.stats.kurtosis(lap)
>>> n / 6 * (S**2 + K3**2 / 4)
58.68240478684658
>>> jb, p = sd.htest.jarque_bera(lap)
>>> jb
58.68240478684658
>>> sd.stats.ChiSquared(df=2).ccdf(jb) == p
True
```

정규분포의 표본에서 $\sqrt{n/6}\,S$와 $\sqrt{n/24}\,(K - 3)$은 표본이 클 때 서로 독립인 표준정규분포에 가까워져요. JB는 이 둘의 제곱합이라 자유도 2의 카이제곱 분포에 가까워져요.

## 언제 쓰나요

- 표본이 수백 개 이상이고 정규성을 왜도와 첨도로 판단하고 싶을 때 써요. 회귀 잔차의 진단이 대표적이에요.
- 카이제곱 근사는 표본이 클 때의 이야기예요. 표본이 수십 개쯤이면 근사가 거칠고, 특히 꼬리가 얇은 분포에 힘이 약해요. 그런 표본에는 [`shapiro`](/api/htest/shapiro/)나 왜도와 첨도를 정규분포 쪽으로 변환해서 쓰는 [`normaltest`](/api/htest/normaltest/)가 나아요.

```python
>>> uni = sd.stats.Uniform(a=0.0, b=1.0).sample(100, rng=rng)
>>> sd.htest.jarque_bera(uni).pvalue
0.050469738886538947
>>> sd.htest.normaltest(uni).pvalue, sd.htest.shapiro(uni).pvalue
(1.1266719794907497e-07, 0.0011788491817025495)
```

균등분포의 표본 100개에서 `jarque_bera`는 겨우 p = 0.05인데, `normaltest`와 `shapiro`는 분명히 기각해요.

- 왜도와 첨도 가운데 어느 쪽이 문제인지는 [`skewtest`](/api/htest/skewtest/), [`kurtosistest`](/api/htest/kurtosistest/)로 따로 봐요.

## 회귀 잔차와 함께

[`ols`](/api/regression/ols/), [`wls`](/api/regression/wls/), [`gls`](/api/regression/gls/) 결과의 [`r.jarque_bera()`](/api/regression/diagnostics/)는 이 함수와 같은 계산이고 같은 클래스의 결과를 돌려줘요. OLS의 잔차를 넘기면 비트까지 같아요. 잔차가 1e80처럼 아주 큰 크기여도 같아요.

```python
>>> x = sd.stats.Uniform(a=0.0, b=10.0).sample(80, rng=sd.random.default_rng(4))
>>> y = 1.0 + 0.5 * x + sd.stats.Laplace().sample(80, rng=sd.random.default_rng(5))
>>> r = sd.regression.ols(y, x)
>>> r.jarque_bera()
JarqueBeraResult(statistic=7.38208, pvalue=0.024946)
>>> tuple(sd.htest.jarque_bera(r.resid)) == tuple(r.jarque_bera())
True
>>> type(r.jarque_bera()) is sd.regression.JarqueBeraResult
True
```

- 가중 회귀와 GLS의 `r.jarque_bera()`는 모형이 실제로 푸는 문제의 잔차(`wresid`)로 계산해요. 같은 값을 얻으려면 `sd.htest.jarque_bera(r.wresid)`예요.
- 점이 모두 모형 위에 놓이는 완전 적합에서는 `r.jarque_bera()`가 잔차를 0으로 보고 NaN을 내요. `sd.htest.jarque_bera(r.resid)`는 남은 반올림 크기의 잔차를 그대로 표본으로 보고 계산해요.

```python
>>> xp = sd.arange(10.0)
>>> pf = sd.regression.ols(1.0 + 0.3 * xp, xp)
>>> pf.jarque_bera()
JarqueBeraResult(statistic=nan, pvalue=nan)
>>> sd.htest.jarque_bera(pf.resid).pvalue
0.8607339117911235
```

## 여러 표본을 한 번에

`axis`를 주면 그 축을 따라 표본을 읽고 나머지 축의 칸마다 따로 검정해요. NaN은 `nan_policy`를 따라요. 공통 규칙은 [가설검정의 기본](/api/htest/basics/)에 있어요.

```python
>>> b = sd.stats.Normal().sample((3, 500), rng=sd.random.default_rng(6))
>>> sd.htest.jarque_bera(b, axis=1).pvalue
array([ 0.8926703845460937, 0.24796691521517575,  0.2608450279880083], dtype=float64)
>>> v = [1.2, 0.4, float('nan'), 2.2, 1.9, 0.8, 1.1]
>>> sd.htest.jarque_bera(v), sd.htest.jarque_bera(v, nan_policy='omit')
(JarqueBeraResult(statistic=nan, pvalue=nan), JarqueBeraResult(statistic=0.421799, pvalue=0.809855))
```

## 특수한 경우

- **모든 값이 같으면**(분산이 0이면) 왜도와 첨도가 정해지지 않아 NaN이에요. 분산이 반올림 크기밖에 안 되는 거의 상수인 표본도 [`sd.stats.skew`](/api/stats/skew-kurtosis/)와 같은 기준으로 NaN이에요. 값이 하나뿐인 표본도 NaN이에요.
- 표본 크기의 아래 한계는 따로 없어요. 값이 둘이어도 계산하지만, 카이제곱 근사가 뜻이 없는 크기예요.

```python
>>> sd.htest.jarque_bera([3.0] * 10), sd.htest.jarque_bera([1.0])
(JarqueBeraResult(statistic=nan, pvalue=nan), JarqueBeraResult(statistic=nan, pvalue=nan))
>>> sd.htest.jarque_bera([5.0] * 9 + [5.000000000000001])
JarqueBeraResult(statistic=nan, pvalue=nan)
>>> sd.htest.jarque_bera([1.0, 2.0])
JarqueBeraResult(statistic=0.333333, pvalue=0.846482)
```

## 정확도

- 통계량은 평균을 뺀 2·3·4차 합을 정확하게 모아서 계산해요. Arb(구간 산술)로 만든 참값과 견줘 7문제(오프셋 10⁸, 상수, n = 2 포함)에서 상대오차가 2.3e-15 안이고, p값은 1.1e-15 안이에요.
- p값은 자유도 2의 카이제곱 분포의 위 꼬리를 직접 계산해요.
- 같은 입력이면 실행마다 같은 비트이고, 회귀의 `r.jarque_bera()`와도 같은 비트예요. 지금은 스레드 수와도 상관없이 같아요(약속은 아니에요).
- 모든 값에 같은 수를 곱해도 통계량은 반올림 차이 안에서 그대로예요. 네제곱하면 float64를 넘는 1e300배나 서브노멀인 1e-310배의 데이터도 2의 거듭제곱 단위로 옮겨 계산해서 NaN이나 0이 되지 않아요.

## scipy를 아는 분께

scipy 1.18.1, statsmodels 0.15.0 기준이에요.

- `scipy.stats.jarque_bera(x)`와 같은 통계량과 p값이에요. statsmodels의 `jarque_bera(resid)`가 돌려주는 넷 가운데 앞의 둘과도 같아요(왜도와 첨도는 [`sd.stats.skew`](/api/stats/skew-kurtosis/)와 `kurtosis(fisher=False)`로 따로 구해요).
- 분산이 0이거나 반올림 크기인 표본은 NaN이에요. 값 아홉 개가 5.0이고 하나가 5.000000000000001인 표본에서 scipy는 JB = 22.7, p = 1.2e-5를 내요. 마지막 자리 하나의 차이가 정규성의 근거가 되는 셈이에요.
- 결과는 namedtuple이 아니라 결과 객체예요. 둘로 풀리지만 튜플끼리의 비교, 해시, `_asdict()`는 없어요.
