## 무엇을 하나요

논문에 두 반의 시험 결과가 이렇게 실려 있어요. 원자료는 없고 요약값만 있어요.

| 반 | 평균 | 표준편차 | 학생 수 |
|---|---|---|---|
| 새 교재 | 72.4 | 8.1 | 40 |
| 옛 교재 | 68.9 | 9.3 | 35 |

[`ttest_ind`](/api/htest/ttest_ind/)의 t 검정은 두 표본에서 평균, 표준편차, 크기만 써요. 그래서 이 여섯 수로 같은 검정을 할 수 있어요. 묻는 것도 같아요.

- 귀무가설: 두 모집단의 평균이 같아요.
- 대립가설: 두 평균이 달라요(`alternative`로 한쪽을 고를 수 있어요).

통계량, 자유도, 신뢰구간의 식은 [`ttest_ind`](/api/htest/ttest_ind/#무엇을-하나요)와 같아요. Student의 검정은 두 분산을 합친 합동 분산을, Welch의 검정(`equal_var=False`)은 따로 어림한 두 분산을 써요.

이런 때 써요.

- 논문, 보고서, 다른 프로그램이 낸 요약값만 있을 때
- 원자료가 너무 커서 평균과 분산만 따로 모아 둔 경우

원자료가 있으면 [`ttest_ind`](/api/htest/ttest_ind/)를 써요. NaN 처리, 절삭(`trim`), 재표본 p값(`method`)은 원자료가 있어야 할 수 있어요.

## 기본 사용

```python
>>> import stardust as sd
>>> r = sd.htest.ttest_ind_from_stats(72.4, 8.1, 40, 68.9, 9.3, 35)
>>> r
TtestIndFromStatsResult(statistic=1.74222, pvalue=0.0856814, df=73)
>>> r.conf_int()
array([-0.5037917941166397,    7.50379179411664], dtype=float64)
```

새 교재 반이 평균 3.5점 높지만, p값이 0.086이라 유의수준 0.05에서는 차이가 우연이 아니라고 말하기 어려워요. 평균 차의 95% 구간(−0.5점에서 7.5점)에 0이 들어 있다는 것도 같은 이야기예요.

Welch의 검정은 자유도가 정수가 아니에요.

```python
>>> sd.htest.ttest_ind_from_stats(72.4, 8.1, 40, 68.9, 9.3, 35, equal_var=False)
TtestIndFromStatsResult(statistic=1.72613, pvalue=0.0888654, df=67.9979)
```

## 원자료의 검정과 같아요

같은 표본의 요약값을 주면 [`ttest_ind`](/api/htest/ttest_ind/)와 같은 결과예요. 표준편차는 n − 1로 나눈 표본 표준편차여야 해요. `sd.std`의 기본값은 n으로 나누는 `correction=0`이라서 `correction=1`을 꼭 줘요.

```python
>>> a = sd.asarray([251.2, 249.8, 252.1, 250.6, 251.9, 250.3, 252.4, 251.0])
>>> b = sd.asarray([249.1, 250.2, 248.7, 249.9, 250.8, 248.9, 249.6])
>>> s = sd.htest.ttest_ind_from_stats(float(sd.mean(a)), float(sd.std(a, correction=1)), 8,
...                                   float(sd.mean(b)), float(sd.std(b, correction=1)), 7)
>>> s
TtestIndFromStatsResult(statistic=3.56201, pvalue=0.00347552, df=13)
>>> sd.htest.ttest_ind(a, b)
TtestIndResult(statistic=3.56201, pvalue=0.00347552, df=13)
```

마지막 자리는 다를 수 있어요. 요약값 자체가 이미 반올림된 수라서예요. 논문의 요약값은 보통 소수 한두 자리로 반올림되어 있으니, 그 자릿수만큼 결과도 거칠어요.

## 결과 읽기

| 필드·메서드 | 뜻 |
|---|---|
| `statistic` | t 통계량. `mean1`이 더 크면 양수예요 |
| `pvalue` | p값. `alternative`의 방향으로 잰 꼬리 넓이예요 |
| `df` | 자유도(`float`). Student는 `nobs1 + nobs2 - 2`, Welch는 Welch–Satterthwaite 식이에요 |
| `conf_int(alpha=0.05)` | 평균 차 `mean1 - mean2`의 1 − alpha 신뢰구간 |
| `summary(alpha=0.05)` | 검정을 표로 적은 글 |

```python
>>> print(r.summary())
                         Two-sample t-test (Student)
==============================================================================
Statistic:                       1.742  Alternative:                 two-sided
P-value:                        0.0857  No. Observations:               40, 35
Df:                                 73
==============================================================================
                     [0.025     0.975]
------------------------------------------------------------------------------
mean difference      -0.504      7.504
==============================================================================
>>> t, p = r
>>> round(t, 5), round(p, 5)
(1.74222, 0.08568)
```

한쪽 검정도 같아요. `'greater'`는 "첫 평균이 더 크다"가 대립가설이에요.

```python
>>> g = sd.htest.ttest_ind_from_stats(72.4, 8.1, 40, 68.9, 9.3, 35, alternative='greater')
>>> g.pvalue
0.04284070323946906
>>> g.conf_int()
array([0.15313014097442013,                 inf], dtype=float64)
```

## 여러 비교를 한 번에

여섯 인자는 서로 [브로드캐스트](/api/array/broadcasting/)되는 배열이어도 돼요. 세 학교의 새 교재 반을 같은 옛 교재 반 하나와 견주려면 첫 표본의 세 인자에 길이 3의 배열을 줘요. 결과는 배치예요.

```python
>>> rb = sd.htest.ttest_ind_from_stats([72.4, 70.1, 75.0], [8.1, 7.5, 9.0], [40, 38, 41], 68.9, 9.3, 35)
>>> rb
TtestIndFromStatsResult(batch shape (3,))
>>> rb.pvalue
array([ 0.08568140647893813,   0.5444468732605908, 0.004905265782776903], dtype=float64)
>>> rb.df
array([73.0, 71.0, 74.0], dtype=float64)
>>> rb.conf_int().shape
(3, 2)
>>> sd.htest.ttest_ind_from_stats([72.4, 70.1], [8.1, 7.5, 9.0], 40, 68.9, 9.3, 35)
Traceback (most recent call last):
    ...
ValueError: ttest_ind_from_stats(): the arguments could not be broadcast together: (2,), (3,), (1,), (1,), (1,), (1,)
```

인자가 모두 실수면 결과의 필드가 Python `float`이고, 하나라도 배열이면 길이 1이어도 배열이에요.

```python
>>> sd.htest.ttest_ind_from_stats([72.4], 8.1, 40, 68.9, 9.3, 35).statistic
array([1.7422209493671992], dtype=float64)
```

## 요약값에는 없는 옵션

원자료가 없으니 `axis`, `nan_policy`, `keepdims`, `trim`, `method`가 없어요. 요약값을 키워드로 줄 수도 없어요.

## 특수한 경우

검정할 수 없는 요약값은 에러가 아니라 NaN이에요.

| 입력 | 결과 |
|---|---|
| 두 표준편차가 모두 0 | t, p값이 NaN, `conf_int()`는 폭 0의 (차, 차) |
| 크기가 0 이하 | t, p값, `df`가 NaN |
| Welch에서 크기가 1 이하 | t, p값, `df`가 NaN |
| 평균이 NaN | t, p값이 NaN |

```python
>>> z = sd.htest.ttest_ind_from_stats(1.0, 0.0, 5, 2.0, 0.0, 6)
>>> z, z.conf_int()
(TtestIndFromStatsResult(statistic=nan, pvalue=nan, df=9), array([-1.0, -1.0], dtype=float64))
>>> sd.htest.ttest_ind_from_stats(1.0, 1.0, 1, 2.0, 1.0, 6, equal_var=False)
TtestIndFromStatsResult(statistic=nan, pvalue=nan, df=nan)
```

Student의 검정에서 크기가 1인 표본은 [`ttest_ind`](/api/htest/ttest_ind/#특수한-경우)처럼 분산을 0으로 봐요. 그 표본의 `std`는 쓰이지 않아요.

## 정확도

- t, `df`, p값, 구간의 정확도는 [`ttest_ind`](/api/htest/ttest_ind/#정확도)와 같아요. t의 상대오차가 $10^{-14}$ 안이고, p값은 $10^{-14} \cdot \max(1, \kappa_p)$ 안이에요.
- 두 평균의 차는 반올림 없이 구해요. 그래서 평균이 $10^8$처럼 크고 차가 작아도 차의 자릿수를 잃지 않아요.
- 이 정확도는 준 요약값을 정확한 값으로 볼 때의 것이에요. 요약값이 반올림되어 있으면 그 반올림이 결과의 오차를 정해요.

참값은 Arb(구간 산술)로 만들었어요.

## scipy를 아는 분께

scipy 1.18.1의 `scipy.stats.ttest_ind_from_stats`와 같은 검정이에요.

- 결과에 `df`와 `conf_int()`가 있어요. scipy의 결과는 `statistic`, `pvalue`뿐이라 자유도와 구간을 직접 구해야 해요. `(statistic, pvalue)`로 푸는 것은 scipy와 같아요.
- 결과의 클래스는 `ttest_ind`와 같은 꼴이에요(scipy는 `Ttest_indResult` namedtuple).
- 두 표준편차가 0이면 NaN이에요. scipy는 평균이 다르면 t = ±inf, p = 0을 내요.
- 요약값은 위치로만, 옵션은 키워드로만 받아요.
