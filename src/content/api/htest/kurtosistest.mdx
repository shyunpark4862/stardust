## 한눈에 보기

**첨도**는 분포의 꼬리가 얼마나 두꺼운지를 재는 수예요. 정규분포의 첨도는 3이에요. 첨도가 3보다 크면 평균에서 멀리 떨어진 값이 정규분포보다 자주 나오고(꼬리가 두꺼움), 3보다 작으면 드물게 나와요(꼬리가 얇음). `kurtosistest`는 표본의 첨도가 3에서 우연이라고 보기 어려울 만큼 떨어졌는지를 물어요.

- **귀무가설**: 표본이 나온 분포의 첨도가 정규분포와 같아요(3).
- **대립가설**: 첨도가 3이 아니에요(`alternative='two-sided'`). 한쪽만 물으려면 `'less'`(꼬리가 얇음)나 `'greater'`(꼬리가 두꺼움)예요.

세 표본은 모두 좌우 대칭이에요. Laplace 분포는 꼬리가 두껍고, 균등분포는 꼬리가 없다시피 해요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(2)
>>> lap = sd.stats.Laplace().sample(200, rng=rng)
>>> uni = sd.stats.Uniform(a=0.0, b=1.0).sample(100, rng=rng)
>>> nor = sd.stats.Normal(mu=50.0, sigma=5.0).sample(200, rng=sd.random.default_rng(3))
>>> sd.htest.kurtosistest(lap)
KurtosistestResult(statistic=4.13012, pvalue=3.6258e-05)
>>> sd.htest.kurtosistest(uni)
KurtosistestResult(statistic=-5.64826, pvalue=1.6208e-08)
>>> sd.htest.kurtosistest(nor)
KurtosistestResult(statistic=0.551007, pvalue=0.581629)
```

Laplace 표본의 $Z$는 양수(꼬리가 두꺼움), 균등분포 표본의 $Z$는 음수(꼬리가 얇음)이고 둘 다 p값이 아주 작아요. 정규분포의 표본은 p = 0.58이에요.

## 통계량

표본 첨도는 편차의 네제곱 평균을 분산의 제곱으로 나눈 값이에요.

$$
b_2 = \frac{m_4}{m_2^{2}}, \qquad m_k = \frac{1}{n}\sum_{i=1}^{n} (x_i - \bar x)^k
$$

[`sd.stats.kurtosis`](/api/stats/skew-kurtosis/)는 기본으로 3을 뺀 값(초과 첨도)을 주고, `fisher=False`면 $b_2$ 그대로예요. 정규분포에서 뽑은 표본의 $b_2$는 평균이 3이 아니라 $3(n - 1)/(n + 1)$이고 분포도 오른쪽으로 치우쳐 있어요. 그래서 먼저 표준화하고,

$$
x = \frac{b_2 - \dfrac{3(n - 1)}{n + 1}}{\sqrt{\dfrac{24n(n - 2)(n - 3)}{(n + 1)^2 (n + 3)(n + 5)}}}
$$

Anscombe와 Glynn(1983)의 세제곱근 변환으로 남은 치우침을 펴서, 정규분포의 표본이면 거의 표준정규분포를 따르는 $Z$로 바꿔요. $Z$의 부호는 $b_2 - 3$의 부호와 같아요. p값은 표준정규분포의 꼬리예요.

```python
>>> sd.stats.kurtosis(lap), sd.stats.kurtosis(uni, fisher=False)
(2.6532049856457123, 1.8111619461877309)
```

Laplace 분포의 이론적인 초과 첨도는 3, 균등분포의 첨도는 1.8이에요. 표본의 값이 그 근처에 있어요.

## 언제 쓰나요

- 꼬리의 두께만 보고 싶을 때 써요. 이상값이 정규분포에서 예상하는 것보다 자주 나오는지 같은 물음이에요.
- 좌우 치우침은 [`skewtest`](/api/htest/skewtest/)가 봐요. 둘을 하나로 합친 것이 [`normaltest`](/api/htest/normaltest/)예요.
- 치우친 분포는 첨도도 함께 커지는 일이 흔해서, 치우친 표본에서 이 검정이 작은 p값을 내도 꼬리만의 문제라고 단정하기 어려워요.

## `alternative`: 한쪽 검정

꼬리가 두꺼운 쪽만 걱정된다면 `'greater'`예요. 이상값이 많은 데이터를 의심할 때 흔한 경우예요.

```python
>>> sd.htest.kurtosistest(lap, alternative='greater').pvalue
1.8129018267176866e-05
>>> sd.htest.kurtosistest(uni, alternative='greater').pvalue
0.9999999918959867
>>> sd.htest.kurtosistest(uni, alternative='less').pvalue
8.104013394219986e-09
```

균등분포의 표본은 꼬리가 얇은 쪽이라 `'greater'`로는 p값이 1에 가깝고, `'less'`로는 아주 작아요. 방향은 데이터를 보기 전에 정해요.

## 결과 읽기

결과는 `statistic`(Z)과 `pvalue`이고, 둘로 풀 수 있어요. 필드는 읽기만 해요.

```python
>>> z, p = sd.htest.kurtosistest(lap)
>>> z
4.130115921183136
>>> print(sd.htest.kurtosistest(uni, alternative='less').summary())
                         Anscombe-Glynn kurtosis test
==============================================================================
Statistic:                      -5.648  Alternative:                      less
P-value:                      8.10e-09  No. Observations:                  100
==============================================================================
```

결과 객체의 공통 규칙은 [결과 객체 읽기](/api/htest/results/)에 있어요.

## 여러 표본을 한 번에

`axis`를 주면 그 축을 따라 표본을 읽고 나머지 축의 칸마다 따로 검정해요. NaN은 `nan_policy`를 따라요. 공통 규칙은 [가설검정의 기본](/api/htest/basics/)에 있어요.

```python
>>> b = sd.stats.Laplace().sample((3, 100), rng=sd.random.default_rng(5))
>>> sd.htest.kurtosistest(b, axis=1).pvalue
array([  0.02829081664303428, 0.0037797706494407416,   0.03645493030547453], dtype=float64)
```

## 작은 표본과 특수한 경우

- **값이 5개 미만**이면 NaN이에요. 경고는 내지 않아요.
- Anscombe–Glynn 근사는 n이 20을 넘는 표본을 위해 만든 것이라, 그보다 작은 표본의 p값은 대략의 값으로 읽어요.
- **모든 값이 같으면**(분산이 0이면) NaN이에요. 기준은 [`sd.stats.skew`](/api/stats/skew-kurtosis/)와 같아요.

```python
>>> sd.htest.kurtosistest([1.0, 2.0, 3.0, 4.0])
KurtosistestResult(statistic=nan, pvalue=nan)
>>> sd.htest.kurtosistest([1.0, 2.0, 3.0, 4.0, 6.0])
KurtosistestResult(statistic=0.0362598, pvalue=0.971075)
>>> sd.htest.kurtosistest([2.0] * 30)
KurtosistestResult(statistic=nan, pvalue=nan)
```

<Callout type="note" title="Z가 0 근처일 때의 자릿수">
표본 첨도가 그 기댓값에 아주 가까우면 $Z$가 0 근처가 되고, 그때 $Z$의 상대오차는 $b_2$의 마지막 자리 오차가 커진 만큼이에요. 입력의 반올림이 이미 정하는 크기라 어떤 방법으로도 줄일 수 없어요. p값은 1 근처라 영향이 없어요.
</Callout>

## 정확도

- $Z$와 p값은 Anscombe–Glynn의 변환식을 Arb(구간 산술)로 계산한 참값과 견줘 정확도 약속 안이에요. `skewtest`·`kurtosistest`·`normaltest` 24문제에서 통계량의 상대오차가 5.1e-16, p값이 2.2e-14 안이에요(오프셋 10⁸, 깊은 꼬리 포함). 약속은 $Z$가 0을 지나는 곳에서 위 상자의 조건수를 곱한 크기예요.
- 변환식 안에서 비슷한 두 수의 차가 나오는 곳은 식을 바꿔 써서 자릿수를 지켜요.
- 같은 입력이면 스레드 수와 상관없이 같은 비트예요.
- 모든 값에 같은 수를 곱해도 통계량은 반올림 차이 안에서 그대로예요. 네제곱하면 float64를 넘는 1e300배나 서브노멀인 1e-310배의 데이터도 2의 거듭제곱 단위로 옮겨 계산해서 NaN이나 0이 되지 않아요.

## scipy를 아는 분께

scipy 1.18.1 기준이에요.

- `scipy.stats.kurtosistest(a)`와 같은 변환이에요. 기본 `axis`는 None이에요(scipy는 0).
- 평균이 10⁸만큼 떨어진 데이터에서 scipy는 적률의 반올림 때문에 통계량이 7.7e-10–2.8e-8 틀려요. 여기서는 편차의 합을 정확하게 모아요.
- n < 5와 상수 표본은 경고 없이 NaN이에요. 데이터는 위치로만, 옵션은 키워드로만 받아요.
