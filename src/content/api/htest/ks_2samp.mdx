## 한눈에 보기

두 표본 Kolmogorov–Smirnov(KS) 검정은 "두 표본이 같은 분포에서 왔다고 봐도 되나요?"를 물어요. 평균이 같은지가 아니라 분포 전체(위치, 퍼짐, 모양)가 같은지를 봐요.

- **귀무가설**: 두 표본이 같은 연속분포에서 왔어요.
- **대립가설**: 다른 분포에서 왔어요(`alternative='two-sided'`). 한쪽 방향은 [아래](#alternative-한쪽-검정)예요.

평균은 같고 표준편차가 1과 2로 다른 두 정규분포에서 50개씩 뽑았어요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(3)
>>> a = sd.stats.Normal().sample(50, rng=rng)
>>> b = sd.stats.Normal(sigma=2.0).sample(50, rng=rng)
>>> r = sd.htest.ks_2samp(a, b)
>>> r
Ks2sampResult(statistic=0.22, pvalue=0.178587, statistic_location=-1.65478, statistic_sign=-1, method='exact')
```

$D = 0.22$, p = 0.18이에요. 퍼짐의 차이는 경험 분포 함수가 양 끝에서 조금씩 벌어지는 꼴이라 KS가 잡기 어려운 편이에요([아래](#언제-쓰나요)).

## 통계량

두 표본의 경험 분포 함수 $F_1$, $F_2$는 각각 $t$ 이하인 관측의 비율이에요. KS 통계량은 둘 사이의 가장 큰 세로 거리예요.

$$
D = \sup_t \lvert F_1(t) - F_2(t) \rvert = \max(D^+, D^-), \qquad D^+ = \sup_t \bigl(F_1(t) - F_2(t)\bigr), \quad D^- = \sup_t \bigl(F_2(t) - F_1(t)\bigr)
$$

$D$는 언제나 $1/\mathrm{lcm}(n_1, n_2)$의 정수배예요. `statistic_location`은 $D$에 처음 닿는 값이고, `statistic_sign`은 $D$가 $D^+$면 +1, $D^-$면 −1이에요. 여기서는 b의 누적분포가 위에 있어서 −1이에요.

```python
>>> r.statistic, r.statistic_location, r.statistic_sign
(0.22, -1.6547791806592174, -1)
>>> d, p = r
>>> d * 50
11.0
```

귀무가설에서 두 표본을 합친 100개의 값을 50개씩 나누는 모든 방법은 같은 확률이에요. p값은 그 가운데 관측한 $D$ 이상이 나오는 비율이고, 정확히 계산해요.

## 언제 쓰나요

- 두 표본의 분포가 어떤 식으로든 다른지 물을 때 써요. 분포의 꼴을 가정하지 않아요.
- 위치(중앙값)가 옮겨졌는지만 물으면 [`mannwhitneyu`](/api/htest/mannwhitneyu/)나 [`ttest_ind`](/api/htest/ttest_ind/)가 더 힘이 있어요. 반대로 그 둘은 위치가 같고 퍼짐만 다른 차이를 보지 못해요.
- KS는 가운데의 차이에 민감하고 꼬리의 차이에 둔해요. 꼬리와 퍼짐의 차이에는 [`cramervonmises_2samp`](/api/htest/cramervonmises_2samp/), [`anderson_ksamp`](/api/htest/anderson_ksamp/), [`epps_singleton_2samp`](/api/htest/epps_singleton_2samp/)가 흔히 더 힘이 있어요.

같은 두 표본에 여러 검정을 하면 이렇게 나와요.

```python
>>> sd.htest.ttest_ind(a, b).pvalue, sd.htest.mannwhitneyu(a, b).pvalue
(0.4169380550577354, 0.8985164449208333)
>>> sd.htest.ks_2samp(a, b).pvalue, sd.htest.cramervonmises_2samp(a, b).pvalue
(0.17858668181221735, 0.08598779354261932)
>>> sd.htest.anderson_ksamp([a, b]).pvalue, sd.htest.epps_singleton_2samp(a, b).pvalue
(0.03291797011365928, 0.0011324766342762516)
```

위치를 보는 두 검정은 차이를 모르고, 분포를 보는 검정은 KS, Cramér–von Mises, Anderson–Darling, Epps–Singleton 순으로 p값이 작아져요. 어떤 검정을 쓸지는 데이터를 보기 전에 정해요. 여러 검정을 해 보고 가장 작은 p값을 고르면 p값이 실제보다 작게 나와요.

## `alternative`: 한쪽 검정

| `alternative` | 대립가설 | 통계량 | data1은 |
|---|---|---|---|
| `'less'` | 어딘가에서 $F_1(t) < F_2(t)$ | $D^-$ | 큰 쪽으로 치우쳐요 |
| `'greater'` | 어딘가에서 $F_1(t) > F_2(t)$ | $D^+$ | 작은 쪽으로 치우쳐요 |

새 공정의 제품(`new`)이 옛 공정(`old`)보다 수명이 길어졌는지 물으면, `new`가 큰 쪽으로 치우쳤는지라 `ks_2samp(new, old, alternative='less')`예요.

```python
>>> old = sd.stats.Exponential(scale=10.0).sample(30, rng=sd.random.default_rng(12))
>>> new = sd.stats.Exponential(scale=16.0).sample(30, rng=sd.random.default_rng(13))
>>> sd.htest.ks_2samp(new, old, alternative='less')
Ks2sampResult(statistic=0.366667, pvalue=0.0172901, statistic_location=18.594, statistic_sign=-1, method='exact')
>>> sd.htest.ks_2samp(new, old).pvalue
0.03458008496333449
```

방향은 데이터를 보기 전에 정해요.

## `method`: 정확한 분포와 점근

| `method` | p값 | 결과의 `method` |
|---|---|---|
| `'auto'`(기본값) | 큰 표본이 10000개 이하면 정확, 넘으면 점근 | `'exact'` 또는 `'asymp'` |
| `'exact'` | $D$의 정확한 분포 | `'exact'` |
| `'asymp'` | 양쪽은 한 표본 KS 분포의 $n = \mathrm{round}(n_1 n_2/(n_1 + n_2))$, 한쪽은 Hodges의 식 | `'asymp'` |

```python
>>> sd.htest.ks_2samp(a, b, method='asymp')
Ks2sampResult(statistic=0.22, pvalue=0.152586, statistic_location=-1.65478, statistic_sign=-1, method='asymp')
```

정확한 분포는 두 표본의 크기가 수천 개여도 보통 금방 끝나요. 계산량이 상한(작업 10⁹번)을 넘는 입력에서 `method='exact'`는 `ValueError`로 `'asymp'`를 알려 줘요. `'auto'`가 정확을 고르는 범위는 언제나 상한 안이에요.

## 동점이 있을 때

값에 동점이 있으면 경험 분포 함수가 같은 값에서 한 번에 여러 칸 올라요. 이때 `'exact'`(와 그것을 고른 `'auto'`)는 **관측한 동점을 조건으로 한** 정확한 분포예요. 두 표본을 합친 값의 묶음은 그대로 두고 어느 표본에 속하는지만 모든 방법으로 바꿔서, 같은 값의 묶음 끝에서만 $D$를 봐요.

```python
>>> x = [1, 2, 2, 3, 3, 3]
>>> y = [2, 3, 4, 4, 5]
>>> rt = sd.htest.ks_2samp(x, y)
>>> rt
Ks2sampResult(statistic=0.6, pvalue=0.108225, statistic_location=3, statistic_sign=1, method='exact')
>>> rt.pvalue == 25 / 231
True
```

p = 25/231은 정확한 유리수를 반올림한 값이에요. 동점을 무시한 분포를 쓰면 이 값이 0.238이 되어 크게 달라요. 동점이 없으면 두 분포는 같아요.

## 여러 표본을 한 번에

`axis`를 주면 그 축을 따라 표본을 읽고, 나머지 축은 두 표본 사이에서 브로드캐스트해서 칸마다 따로 검정해요. 두 표본의 표본 축 길이는 달라도 돼요. 방법은 줄마다 그 크기로 고르고, 결과의 `method`는 줄마다의 이름을 담은 리스트예요. 공통 규칙은 [가설검정의 기본](/api/htest/basics/)에 있어요.

```python
>>> B = sd.stats.Normal().sample((3, 40), rng=sd.random.default_rng(14))
>>> C = sd.stats.Normal(sigma=1.5).sample((3, 30), rng=sd.random.default_rng(15))
>>> rb = sd.htest.ks_2samp(B, C, axis=1)
>>> rb.pvalue, rb.method
(array([0.17506382575409365,  0.2037547852342292,  0.4003596953167422], dtype=float64), ['exact', 'exact', 'exact'])
```

## 특수한 경우

- **빈 표본**이 있으면 `statistic`, `pvalue`, `statistic_location`이 NaN이고 `statistic_sign`은 0이에요.
- NaN은 `nan_policy`를 따라요. `'omit'`은 표본마다 NaN을 빼요.

## 정확도

- $D$는 정수 꼴로 세어 한 번 반올림한 값이라 Arb(구간 산술)와 정확한 정수 셈으로 만든 참값과 견줘 상대오차가 8.5e-17 안이에요(25문제).
- 정확한 분포의 p값은 확률을 양수로만 더해서 상대오차가 5.3e-16 안이에요. 완전히 갈린 두 표본의 깊은 꼬리(p = 2.9e-133), 동점의 조건부 분포, 997 × 1000이나 2000 × 1500 같은 큰 표본도 포함해요.
- 점근 p값도 같은 약속 안이에요(약속 대비 0.0067).
- 같은 입력이면 실행마다 같은 비트예요. 지금은 스레드 수와도 상관없이 같아요(약속은 아니에요).

## scipy를 아는 분께

scipy 1.18.1, R 4.6.2 기준이에요.

- `scipy.stats.ks_2samp(data1, data2)`와 같은 통계량, 같은 `alternative`와 `method`의 이름과 뜻이에요. `'auto'`의 문턱(10000)도 같아요. 기본 `axis`는 None이에요(scipy는 0). 결과에 쓴 분포의 이름 `method`가 있어요.
- 동점이 있을 때의 `'exact'`가 달라요. scipy는 동점을 무시한 분포라 위 `x`, `y`에서 0.238이에요. 여기서는 R의 `ks.test(x, y, exact = TRUE)`와 같은 조건부 분포이고, R과 1.1e-15 안에서 같아요.
- scipy는 정확한 계산이 double의 범위를 넘으면 경고와 함께 점근으로 넘어가요. 여기서는 넘치지 않아서 `'auto'`가 고른 정확한 분포를 끝까지 계산해요.
- scipy의 점근 양쪽 p값은 n > 140에서 한 표본 분포의 근사를 써서 3000 × 2500에서 4.8e-8, 12000 × 1100에서 3.0e-7 틀려요. R의 점근은 다른 식(Kolmogorov의 극한)이라 0.02–0.03쯤 다르고, R의 정확한 p값은 깊은 꼬리(2.9e-133)에서 0이에요.
- 빈 표본은 경고 없이 NaN이에요. scipy도 NaN이지만 경고(`SmallSampleWarning`)를 내요.
