## 무엇을 묻는 검정인가요

새 광고를 20명에게 보여 줬더니 7명이 눌렀어요. 지금까지의 광고는 누르는 비율이 20%였어요. 새 광고의 비율이 정말 다른 걸까요, 아니면 20%인 광고라도 20명 중 7명쯤은 우연히 나올 수 있을까요?

이항 검정은 이 질문에 바로 답해요. 성공 확률이 p인 시도를 n번 하면 성공 횟수 X는 이항 분포 Binomial(n, p)를 따라요. 그 분포에서 관측한 k만큼, 또는 그보다 더 극단적인 결과가 나올 확률이 p값이에요.

- **귀무가설**: 성공 확률이 p예요.
- **대립가설**: 성공 확률이 p와 달라요(`'two-sided'`), p보다 작아요(`'less'`), p보다 커요(`'greater'`).

## 기본 사용

```python
>>> r = sd.htest.binomtest(7, 20, p=0.2)
>>> r
BinomtestResult(k=7, n=20, alternative='two-sided', statistic=0.35, pvalue=0.0982217)
>>> r.statistic, r.pvalue
(0.35, 0.09822172861346874)
```

`statistic`은 표본 비율 k/n = 0.35이고, p값은 0.098이에요. 유의수준 0.05에서는 귀무가설을 기각하지 못해요. 20명은 20%와 35%를 가르기에 적은 수라는 뜻이에요.

새 광고가 "더 낫다"는 것만 궁금했다면 한쪽 검정이에요. 한쪽 p값은 P(X ≥ 7)이에요.

```python
>>> sd.htest.binomtest(7, 20, p=0.2, alternative='greater').pvalue
0.08669251356740028
>>> float(sd.stats.Binomial(n=20, p=0.2).ccdf(6))
0.08669251356740028
```

한쪽 p값은 꼬리 확률 그대로예요. `'less'`는 P(X ≤ k), `'greater'`는 P(X ≥ k)예요. 대립가설은 자료를 보기 전에 정해요. 자료를 보고 나서 p값이 작아지는 쪽을 고르면 p값의 뜻이 사라져요.

## 양쪽 p값은 어떻게 정하나요

이항 분포는 p ≠ 0.5이면 좌우가 대칭이 아니에요. 그래서 한쪽 p값을 두 배 하는 방법은 쓰지 않고, **관측한 결과보다 확률이 크지 않은 결과를 모두 더해요**(위 그림의 진한 막대). 관측과 같은 쪽의 꼬리 전체에 더해, 반대쪽에서 확률질량이 관측의 확률 이하인 결과들을 더하는 꼴이에요.

이때 "이하"는 (1 + 10⁻⁷)배의 여유를 두고 판정해요. 수학적으로 확률이 같은 두 결과가 반올림 때문에 한쪽만 들어가는 일을 막아 줘요. R의 `binom.test`와 같은 규칙이에요.

```python
>>> X = sd.stats.Binomial(n=20, p=0.2)
>>> float(X.cdf(0) + X.ccdf(6))
0.09822172861346874
```

P(X = 0) = 0.0115와 P(X ≥ 7)의 합이에요. 위의 p값과 같은 값이에요.

## 신뢰구간

`r.conf_int()`는 성공 확률의 신뢰구간을 (2,) 배열 [아래 끝, 위 끝]으로 돌려줘요. `alpha`는 유의수준이고 구간의 신뢰수준은 1 − alpha예요.

```python
>>> r.conf_int()
array([0.15390920478454115,  0.5921885345328282], dtype=float64)
>>> r.conf_int(alpha=0.1)
array([0.1773109175744491, 0.5580345113154888], dtype=float64)
```

95% 구간 [0.154, 0.592]가 0.2를 품고 있어요. 0.05의 양쪽 검정이 기각하지 못한 것과 맞아요. 90% 구간은 더 좁아요.

`method`로 구간을 만드는 방법을 골라요.

| method | 구간 | 성질 |
|---|---|---|
| `'exact'`(기본값) | Clopper–Pearson. 이항 꼬리를 뒤집은 구간이에요 | 어떤 p에서도 포함 확률이 1 − alpha 이상이에요. 그만큼 조금 넓어요 |
| `'wilson'` | Wilson의 점수 구간. 정규 근사의 이차식을 푼 구간이에요 | 포함 확률이 평균적으로 1 − alpha에 가깝고 더 좁아요 |
| `'wilsoncc'` | 연속성 보정을 더한 Wilson 구간 | `'wilson'`보다 넓고 보수적이에요 |

```python
>>> r.conf_int(method='wilson')
array([0.1811918241010821, 0.5671457233147638], dtype=float64)
>>> r.conf_int(method='wilsoncc')
array([0.16308667971630933,  0.5905104338485733], dtype=float64)
```

방법이 더 필요하면(Jeffreys, Agresti–Coull 등) [proportion_confint](/api/htest/proportion_confint/)를 써요. 같은 k와 n이면 `'exact'`, `'wilson'`, `'wilsoncc'`의 구간이 비트까지 같아요.

```python
>>> bool(sd.all(r.conf_int(method='wilson') == sd.htest.proportion_confint(7, 20, method='wilson')))
True
```

구간은 검정의 `alternative`를 따라요. 한쪽 검정의 구간은 한 끝이 0이나 1이에요.

```python
>>> sd.htest.binomtest(7, 20, p=0.2, alternative='greater').conf_int()
array([0.1773109175744491,                1.0], dtype=float64)
>>> sd.htest.binomtest(7, 20, p=0.2, alternative='less').conf_int()
array([               0.0, 0.5580345113154888], dtype=float64)
```

`'greater'`의 구간 [0.177, 1]은 "성공 확률이 적어도 0.177"이라는 뜻이에요. 0.2가 안에 있으니 한쪽 검정도 기각하지 못해요.

## 결과 읽기

| 필드 | 뜻 |
|---|---|
| `k`, `n` | 준 성공 횟수와 시도 횟수 (`int`) |
| `alternative` | 준 대립가설 (`str`) |
| `statistic` | 표본 비율 k/n (`float`) |
| `pvalue` | p값 (`float`) |

필드는 읽기 전용이에요. scipy와 같이 결과가 튜플로 풀리지 않아요. 필드를 이름으로 읽어요.

```python
>>> stat, p = r
```

`summary()`는 머리에 통계량과 p값, 호출의 설명을, 아래에 신뢰구간(`alpha`, 방법은 `'exact'`)을 보여 줘요.

## 끝에 있는 경우

k = 0이나 k = n도 그대로 계산해요. 1000번 중 한 번도 성공하지 않았으면 p = 0.5의 양쪽 p값은 2·0.5¹⁰⁰⁰이에요. 이 값은 double의 정규 범위 아래쪽에 가까워도 상대오차를 지켜요.

```python
>>> sd.htest.binomtest(0, 1000).pvalue
1.8665272370064378e-301
>>> sd.htest.binomtest(0, 20, p=0.2).conf_int()
array([                0.0, 0.16843347098308534], dtype=float64)
```

p = 0이나 1은 결과가 하나뿐인 분포예요. 그 결과와 같으면 p값이 1, 다르면 0이에요.

```python
>>> sd.htest.binomtest(0, 10, p=0.0).pvalue, sd.htest.binomtest(3, 10, p=0.0).pvalue
(1.0, 0.0)
```

## 다른 검정과 고르기

- 시도가 많고 성공도 실패도 넉넉하면 [proportions_ztest](/api/htest/proportions_ztest/)의 정규 근사도 비슷한 답을 줘요. 이항 검정은 언제나 정확하니 하나의 비율에는 이것을 먼저 써요.
- 두 집단의 비율을 견주려면 [test_proportions_2indep](/api/htest/test_proportions_2indep/)나 2 × 2 분할표의 [fisher_exact](/api/htest/fisher_exact/)를 써요.
- 성공의 비율이 아니라 "중앙값(분위수)이 q인가"를 묻는다면 [quantile_test](/api/htest/quantile_test/)예요. 안에서는 같은 이항 꼬리를 써요.

## 정확도

p값과 세 구간의 끝은 Arb(구간 산술)로 만든 참값과 상대 4e-16 안이에요(깊은 꼬리 2⁻⁹⁹⁹ 포함). 계약은 상대 1e-14이고, 시험한 문제에서 계약 대비 가장 큰 값이 0.039예요.

## scipy를 아는 분께

- 같은 검정이고 양쪽 p값의 규칙도 scipy 1.18.1의 것이에요. 값은 끝자리 몇 개까지 같아요(아래 예). 차이는 반올림 크기이고, 시험한 문제에서 scipy의 p값은 n = 10⁵에서 상대 5.9e-14까지 벗어나요.
- 결과에 `proportion_estimate`가 없어요. `statistic`과 같은 값이라 하나만 둬요.
- 신뢰구간은 `proportion_ci(confidence_level=0.95)` 대신 `conf_int(alpha=0.05)`예요. 돌려주는 것도 `ConfidenceInterval(low, high)`가 아니라 (2,) 배열이에요. `method`의 이름(`'exact'`, `'wilson'`, `'wilsoncc'`)은 같아요.
- `k`와 `n`은 위치로만, 나머지는 키워드로만 받아요.

```python
>>> import scipy.stats
>>> s = scipy.stats.binomtest(7, 20, p=0.2)
>>> s.pvalue, r.pvalue
(np.float64(0.09822172861346881), 0.09822172861346874)
>>> float(s.proportion_ci().low), float(r.conf_int()[0])
(0.15390920478454118, 0.15390920478454115)
```
