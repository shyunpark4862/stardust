## 무엇을 구하나요

설문에서 20명 중 7명이 "그렇다"고 했어요. 표본 비율은 0.35예요. 그런데 다른 20명을 뽑았다면 비율은 0.25나 0.45였을 수도 있어요. **신뢰구간**은 "참 비율이 이 범위 안에 있다고 해도 무리가 없다"는 범위예요. 95% 신뢰구간은 같은 방법으로 구간을 되풀이해 만들면 그중 95%가 참 비율을 품도록 만든 구간이에요.

```python
>>> sd.htest.proportion_confint(7, 20, method='wilson')
array([0.1811918241010821, 0.5671457233147638], dtype=float64)
```

참 비율은 0.18에서 0.57 사이쯤이라고 말할 수 있어요. 20명은 적은 수라 구간이 넓어요.

비율의 구간은 방법이 여럿이에요. 개수가 정수라서 "정확히 95%를 품는 구간"을 만들 수 없기 때문이에요. 방법마다 포함 확률을 맞추는 방식이 달라요.

## 방법 고르기

| method | 구간 | 언제 |
|---|---|---|
| `'normal'`(기본값) | Wald 구간 q ± z·√(q(1 − q)/n), q = count/nobs. [0, 1]로 잘라요 | 계산이 단순해요. n이 크고 q가 0·1에서 멀 때만 써요 |
| `'agresti_coull'` | 성공과 실패에 z²/2씩 더한 비율로 만든 Wald 구간. [0, 1]로 잘라요 | Wald 구간을 간단히 고친 꼴이에요 |
| `'exact'` | Clopper–Pearson. 이항 꼬리 확률이 alpha/2가 되는 p를 양쪽에서 찾은 구간(베타 분포의 분위수)이에요 | 포함 확률이 언제나 1 − alpha 이상이어야 할 때 |
| `'wilson'` | Wilson의 점수 구간. 정규 근사의 검정을 뒤집은 이차식의 두 근이에요. [0, 1]로 잘라요 | 일상적인 기본 선택으로 좋아요. 작은 n에서도 포함 확률이 1 − alpha에 가까워요 |
| `'wilsoncc'` | 연속성 보정을 더한 Wilson 구간 | Wilson보다 보수적인 구간이 필요할 때 |
| `'jeffreys'` | Beta(count + ½, nobs − count + ½)의 분위수. 베이즈의 Jeffreys 사전분포로 얻는 구간이에요 | 짧고 포함 확률이 1 − alpha에 가까워요 |
| `'binom_test'` | 양쪽 [binomtest](/api/htest/binomtest/)가 기각하지 않는 p의 범위 | 이항 검정과 똑같이 판정하는 구간이 필요할 때 |

기본값이 `'normal'`인 것은 statsmodels의 기본값을 따른 것이에요. 작은 표본이나 끝에 가까운 비율에서는 `'wilson'`이나 `'exact'`를 골라 줘요.

```python
>>> for m in ['normal', 'agresti_coull', 'exact', 'wilson', 'wilsoncc', 'jeffreys', 'binom_test']:
...     print(f"{m:14s}", [round(v, 4) for v in sd.htest.proportion_confint(7, 20, method=m).tolist()])
normal         [0.141, 0.559]
agresti_coull  [0.1799, 0.5684]
exact          [0.1539, 0.5922]
wilson         [0.1812, 0.5671]
wilsoncc       [0.1631, 0.5905]
jeffreys       [0.1723, 0.5678]
binom_test     [0.1668, 0.5764]
```

### 0이나 nobs에 가까운 개수

방법의 차이는 개수가 끝에 가까울 때 커요. 20명 중 아무도 "그렇다"고 하지 않았을 때를 봐요.

```python
>>> for m in ['normal', 'exact', 'wilson', 'jeffreys']:
...     print(f"{m:9s}", [round(v, 4) for v in sd.htest.proportion_confint(0, 20, method=m).tolist()])
normal    [0.0, 0.0]
exact     [0.0, 0.1684]
wilson    [0.0, 0.1611]
jeffreys  [0.0, 0.1166]
```

Wald 구간은 표준오차 √(q(1 − q)/n)가 q = 0에서 0이라 폭이 0인 구간 [0, 0]이 돼요. "참 비율이 정확히 0"이라는 뜻이 되어 버려요. 다른 방법은 0이 관측돼도 비율이 0.1 넘게 있을 수 있다고 말해 줘요. 위 그림에서 `'normal'`의 포함 확률이 양 끝에서 떨어지는 까닭이에요.

드문 사건도 같아요. 10만 번 중 2번이면 Wald 구간의 아래 끝은 음수라서 0으로 잘려요.

```python
>>> sd.htest.proportion_confint(2, 100000, method='normal')
array([                  0.0, 4.771779930484276e-05], dtype=float64)
>>> sd.htest.proportion_confint(2, 100000, method='wilson')
array([5.484738516524052e-06, 7.292683754201225e-05], dtype=float64)
```

### 'binom_test' 구간

`'binom_test'`는 [binomtest](/api/htest/binomtest/)의 양쪽 p값이 alpha보다 큰 p를 모은 범위예요. count/nobs에서 시작해 양쪽으로 가면서 처음으로 기각되는 곳이 구간의 끝이에요. 양쪽 p값을 쓰므로 alpha를 나누지 않아요. 그래서 이 구간 안의 p₀로 `binomtest(count, nobs, p=p₀)`를 하면 기각하지 않고, 바로 밖이면 기각해요.

```python
>>> lo, hi = sd.htest.proportion_confint(7, 20, method='binom_test')
>>> sd.htest.binomtest(7, 20, p=float(hi) - 1e-6).pvalue > 0.05
True
>>> sd.htest.binomtest(7, 20, p=float(hi) + 1e-6).pvalue > 0.05
False
```

이항 검정의 양쪽 p값은 p₀에 대해 단조롭지 않고 계단처럼 오르내려요. 그래서 채택하는 p₀가 한 구간으로 이어지지 않을 때가 있는데, 이 방법은 count/nobs를 품은 이어진 부분의 끝을 줘요.

## 한쪽 구간

`alternative='less'`는 [0, 위 끝]이고 "참 비율이 위 끝보다 크지 않다"는 구간이에요. `'greater'`는 [아래 끝, 1]이에요. 한쪽 구간은 그 꼬리에 alpha를 다 두므로, 95% 한쪽 구간의 위 끝은 90% 양쪽 구간의 위 끝과 같아요.

```python
>>> sd.htest.proportion_confint(7, 20, method='exact', alternative='less')
array([               0.0, 0.5580345113154888], dtype=float64)
>>> sd.htest.proportion_confint(7, 20, method='exact', alpha=0.1)
array([0.1773109175744491, 0.5580345113154888], dtype=float64)
```

이름의 방향은 같은 이름의 검정과 짝이에요. `binomtest(7, 20, p=p₀, alternative='less')`가 기각하지 않는 p₀의 범위가 `alternative='less'` 구간이에요.

## 여러 구간을 한 번에

count와 nobs는 배열도 받고 서로 브로드캐스트해요. 결과의 모양은 (브로드캐스트한 모양, 2)예요.

```python
>>> sd.htest.proportion_confint([3, 7, 12], 20, method='wilson')
array([[0.052368745896216616,   0.3604188647407569],
       [  0.1811918241010821,   0.5671457233147638],
       [  0.3865815007622532,   0.7811934676271829]], dtype=float64)
>>> sd.htest.proportion_confint(sd.asarray([[3, 7], [12, 20]]), 20, method='exact').shape
(2, 2, 2)
```

구간이 하나면 (2,) 배열이라 두 값으로 풀려요.

```python
>>> low, upp = sd.htest.proportion_confint(7, 20, method='wilson')
>>> float(low), float(upp)
(0.1811918241010821, 0.5671457233147638)
```

nobs가 0인 칸은 비율을 정할 수 없어 [NaN, NaN]이에요. 에러가 아니어서 배열의 다른 칸은 그대로 계산돼요.

```python
>>> sd.htest.proportion_confint([3, 0], [20, 0], method='wilson')
array([[0.052368745896216616,   0.3604188647407569],
       [                 nan,                  nan]], dtype=float64)
```

## 정확도

구간의 끝은 Arb(구간 산술)로 만든 참값과 견줘요. 시험한 52문제에서 가장 큰 상대오차가 9.5e-15이고(Jeffreys의 0 근처 끝), 계약 대비 0.052예요. `'binom_test'`의 끝은 정확한 유리수 참값과 1 ulp 안이에요.

## statsmodels를 아는 분께

- 방법의 이름이 scipy에 있는 것은 scipy의 이름이에요. statsmodels의 `'beta'`는 `'exact'`예요. `'wilsoncc'`는 scipy의 연속성 보정 Wilson이에요. 나머지(`'normal'`, `'agresti_coull'`, `'jeffreys'`, `'binom_test'`)는 statsmodels의 이름 그대로예요.
- `alternative`는 `'less'`·`'greater'`이고 방향이 statsmodels와 반대예요. statsmodels의 `'larger'`는 [0, 위 끝]이지만 여기의 `'greater'`는 [아래 끝, 1]이에요(scipy `binomtest(...).proportion_ci()`의 방향이에요).
- 결과가 `(low, upp)` 튜플이 아니라 (…, 2) 배열이에요. 구간 하나는 똑같이 `low, upp = ...`로 풀려요.
- `count`는 정수 값만 받아요. nobs = 0은 에러가 아니라 NaN이에요.
- `'binom_test'`의 구간이 다를 수 있어요. 양쪽 p값이 단조롭지 않은 곳에서 statsmodels의 근 찾기는 채택 영역 바깥의 다른 교차점에 닿기도 해요. 48번 중 48번이 성공한 경우가 그래요.

```python
>>> from statsmodels.stats.proportion import proportion_confint as sm_confint
>>> [round(float(v), 5) for v in sm_confint(48, 48, method='binom_test')]
[0.92675, 1.0]
>>> [round(v, 5) for v in sd.htest.proportion_confint(48, 48, method='binom_test').tolist()]
[0.93007, 1.0]
```
