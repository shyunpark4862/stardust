## 무엇을 하나요

[`cg`](/api/sparse/cg/)는 A가 양정치일 때만 맞아요. 대칭이어도 음의 고유값이 섞인 **부정** 행렬은 그릇 모양이 아니라 말안장 모양이라 "바닥"이 없기 때문이에요. 그런 행렬은 생각보다 흔해요.

- **제약이 걸린 문제**: 에너지 $\tfrac12 x^{\mathsf H}Ax - b^{\mathsf H}x$를 조건 $Cx = d$ 아래에서 최소화하면 라그랑주 승수 λ와 함께 안장점 계 $\begin{bmatrix} A & C^{\mathsf H} \\ C & 0 \end{bmatrix}\begin{bmatrix} x \\ \lambda \end{bmatrix} = \begin{bmatrix} b \\ d \end{bmatrix}$가 나와요. 이 행렬은 언제나 부정이에요.
- **옮긴 계**: $A - \sigma I$는 σ가 A의 고유값 사이에 있으면 부정이에요. 파동 방정식(헬름홀츠 방정식)의 $-\Delta u - k^2 u = f$, 고유벡터를 다듬는 역반복이 이런 꼴이에요.

MINRES(minimal residual)는 에르미트 행렬이면 부정이어도 써요. k번 반복한 점은 크릴로프 공간 $\{b, Ab, \dots, A^{k-1}b\}$ 안에서 잔차 ‖b − Ax‖가 가장 작은 점이에요. A가 에르미트라서 기저를 세 항 점화식(Lanczos)으로 만들 수 있고, [`gmres`](/api/sparse/gmres/)와 달리 벡터를 쌓아 두지 않아 메모리가 반복 수와 상관없이 일정해요.

## 기본 사용: 옮긴 계

가장자리가 0인 30 × 30 판의 라플라시안 A(고유값 0.02–7.98)에서 0.5를 뺀 $A - 0.5I$를 풀어요. 고유값 900개 가운데 32개가 음수가 돼요. `shift=0.5`로 주면 행렬을 따로 만들지 않아요.

```python
>>> n = 30
>>> T = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(n, n))
>>> A = sd.sparse.kronsum(T, T)
>>> b = sd.ones(n * n)
>>> ev = sd.linalg.eigvalsh(A.toarray())
>>> int(sd.sum(ev < 0.5))
32
>>> r = sd.sparse.minres(A, b, shift=0.5, rtol=1e-10)
>>> r
MinresResult(converged=True, status=0, n_iter=79, normr=3.07933e-06, x=<array of shape (900,)>)
>>> r.message
'a solution to Ax = b was found, given rtol'
>>> x_direct = sd.sparse.spsolve(A - 0.5 * sd.sparse.eye_array(n * n), b)
>>> float(sd.max(sd.abs(r.x - x_direct))) < 1e-6
True
```

## 멈춤 판정이 cg와 달라요

`minres`의 `rtol`은 잔차를 ‖b‖가 아니라 **‖A‖·‖x‖**에 견줘요. 반복마다 잔차의 어림 φ로 두 가지를 보고, 둘 가운데 하나가 `rtol` 이하면 멈춰요.

| 판정 | 뜻 | `message` |
|---|---|---|
| φ / (‖A‖·‖x‖) ≤ rtol | 계 Ax = b가 rtol만큼 풀렸어요 | `'a solution to Ax = b was found, given rtol'` |
| ‖Ar‖ / (‖A‖·φ) ≤ rtol | 해가 없을(특이할) 때의 최소제곱 해예요 | `'a least-squares solution was found, given rtol'` |

‖A‖·‖x‖는 대개 ‖b‖보다 훨씬 커요. 그래서 같은 `rtol`이어도 `minres`는 `cg`보다 일찍, 더 큰 잔차에서 멈춰요. 기본값 `rtol=1e-05`로 위 문제를 풀면 잔차가 ‖b‖ = 30의 0.6%쯤이고, 최대 79쯤인 해에서 0.6만큼 틀려요.

```python
>>> r5 = sd.sparse.minres(A, b, shift=0.5)
>>> r5.n_iter, round(r5.normr / 30, 4)
(63, 0.0057)
>>> round(float(sd.max(sd.abs(r5.x - x_direct))), 2)
0.59
```

**cg와 같은 정확도를 원하면 `rtol`을 몇 자리 더 작게 줘요.** 위에서 `rtol=1e-10`이 그런 예예요. `atol`은 없어요.

이 판정 말고도 다음 까닭으로 멈출 수 있어요. 모두 `status` 0이고 `converged=True`이니 `message`를 봐요.

| `message` | 뜻 |
|---|---|
| `'beta1 = 0: the exact solution is x0'` | 처음 잔차가 0이에요 |
| `'beta2 = 0: if M = I, b and x are eigenvectors'` | 첫 반복에서 공간이 닫혔어요(b가 고유벡터) |
| `'reasonable accuracy achieved, given eps'` | ε·‖A‖·‖x‖가 ‖b‖ 이상이 되어, 반올림의 한계에 닿았어요 |
| `'the estimate of cond(A) has exceeded 0.1/eps'` | 조건수의 어림이 너무 커요. 답을 믿기 어려워요 |
| `'the right-hand side is zero: x = 0'` | b가 0이에요 |

상한에 닿으면 `status`가 `max_iter`이고 `converged=False`, `message`는 `'the iteration limit was reached'`예요.

## 안장점 계

판의 온도를 "평균 온도가 0"이라는 조건 아래에서 구해요. 조건 $\mathbf 1^{\mathsf T}x = 0$의 승수 λ를 미지수로 더하면 901 × 901 안장점 계가 돼요.

```python
>>> N = n * n
>>> c = sd.sparse.csr_array(sd.ones((1, N)))
>>> K = sd.sparse.block_array([[A, c.T], [c, None]], format='csr')
>>> K
<csr_array of shape (901, 901), float64, 6180 stored elements>
>>> f = sd.linspace(0.0, 2.0, N)
>>> rhs = sd.concat([f, sd.asarray([0.0])])
>>> r = sd.sparse.minres(K, rhs, rtol=1e-10)
>>> r.converged, r.n_iter
(True, 65)
>>> abs(float(sd.sum(r.x[:N]))) < 1e-6, round(float(r.x[N]), 6)
(True, 1.0)
```

마지막 성분이 승수 λ = 1이고, 앞의 900개의 합이 0이에요. K는 음의 고유값 하나와 양의 고유값 900개를 가진 부정 행렬이에요.

## 대칭이 아닌 행렬을 주면

<Callout type="warn" title="minres는 A가 대칭인지 검사하지 않아요">
대칭이 아닌 A를 주면 MINRES의 점화식이 맞지 않아, 맞지 않는 x를 `converged=True`로 돌려줄 수 있어요. 잔차의 어림만 보고 판정하기 때문이에요. A가 에르미트인지 확신이 없으면 `(A - A.conj().T).count_nonzero()`로 먼저 확인해요.
</Callout>

바람이 부는 판(대류가 있는 확산)의 행렬은 대칭이 아니에요. `minres`는 수렴했다고 하지만 참 잔차는 ‖b‖ = 30보다 커요.

```python
>>> D1 = sd.sparse.diags_array([-1.0, 1.0], offsets=[-1, 0], shape=(n, n))
>>> C = A + 1.5 * sd.sparse.kron(sd.sparse.eye_array(n), D1)
>>> r = sd.sparse.minres(C, b)
>>> r.converged, r.message
(True, 'a solution to Ax = b was found, given rtol')
>>> round(float(sd.linalg.vector_norm(b - C @ r.x)), 2)
81.46
```

대칭이 아니면 [`gmres`](/api/sparse/gmres/)나 [`bicgstab`](/api/sparse/bicgstab/)을 써요.

## 어림값: norma, conda, normar, normx

`minres`는 반복 중에 만든 작은 삼중대각 행렬에서 몇 가지 크기를 어림해 결과에 넣어요. 판정에 쓰는 값들이에요.

```python
>>> r = sd.sparse.minres(A, b, shift=0.5, rtol=1e-10)
>>> round(r.norma, 3), round(r.conda, 3), round(r.normx, 2)
(47.718, 7.298, 767.7)
>>> round(float(sd.linalg.cond((A - 0.5 * sd.sparse.eye_array(N)).toarray())), 1)
2861.8
```

- `normr`: 잔차의 어림 φ. 수렴한 결과에서는 참 잔차와 가까워요.
- `norma`: ‖A‖의 어림. 크릴로프 공간에서 본 크기라 반복이 쌓이며 커져요.
- `conda`: 조건수의 어림. 반복이 본 고유값만으로 셈해서 참값보다 훨씬 작을 수 있어요(위에서 7.3 대 2,862).
- `normar`: ‖Ar‖의 어림. 마지막 반복보다 한 걸음 늦게 셈해서, 정확히 풀린 계에서도 0이 아닐 수 있어요.
- `normx`: x의 노름이에요(어림이 아니에요).

## 전처리기 M

M은 **양정치**여야 해요. A − shift·I가 부정이어도 M은 양정치예요. `minres`는 반복 중에 $r^{\mathsf H}Mr$를 계산하므로, 이 값이 음수로 나오면 M이 양정치가 아님을 알아채요. 처음 잔차에서 드러나든 반복 중에 드러나든 메시지는 `'the preconditioner is not positive definite'`예요. M이 양정치면 이 값은 음수가 될 수 없으므로 원인은 언제나 M이에요.

```python
>>> sd.sparse.minres(A, b, M=-sd.sparse.eye_array(N))
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: minres(): the preconditioner is not positive definite
>>> d = sd.ones(N)
>>> d[::7] = -1.0
>>> sd.sparse.minres(A, b, M=sd.sparse.diags_array(d))
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: minres(): the preconditioner is not positive definite
```

`LinAlgError`는 `ValueError`의 하위 클래스라 `except ValueError`로도 잡혀요. 대각이 모두 양수인 행렬의 Jacobi 전처리기(대각의 역수)는 양정치라 안전해요. 대각에 음수가 있는 부정 행렬이면 대각의 절댓값의 역수를 써요.

## 조건수가 아주 크면

`minres`는 잔차를 점화식의 어림 φ로 판정해요. 조건수 κ가 아주 크면 반올림 때문에 어림과 참 잔차의 간격이 ε·κ·‖A‖‖x‖ 크기까지 벌어질 수 있어요. 시험 행렬 가운데 κ가 10¹⁰인 것에서는 `rtol=1e-10`으로 "a solution was found"에 멈췄는데 참 상대 잔차가 7×10⁻²였어요. 조건수가 큰 계라면 `b - (A @ r.x - shift * r.x)`를 직접 계산해 확인해요.

## 입력과 에러

`atol`은 없어요.

```python
>>> sd.sparse.minres(A, b, atol=1e-8)
Traceback (most recent call last):
    ...
TypeError: minres(): unexpected keyword argument 'atol'. Did you mean 'rtol'?
>>> sd.sparse.minres(A, b, shift=sd.inf)
Traceback (most recent call last):
    ...
ValueError: minres(): 'shift' must be finite
```

나머지 입력 규칙(b와 x0은 `sd.ndarray`, NaN·inf는 `ValueError`, 복소수면 complex128)은 [반복법의 기본](/api/sparse/iterative/#입력)과 같아요.

## scipy를 아는 분께

- `scipy.sparse.linalg.minres`(Paige–Saunders)와 같은 알고리즘과 판정이에요. `status`는 scipy의 `info`이고, 어느 판정으로 멈췄는지는 `message`에 있어요(scipy는 `show=True`일 때만 인쇄해요).
- `norma`, `conda`, `normar`, `normx`를 결과에 넣었어요. scipy가 `show=True`로 인쇄하는 `Anorm`, `Acond`, `Arnorm`, `ynorm`과 같은 값이에요.
- 양정치가 아닌 전처리기는 scipy의 `ValueError` 대신 `sd.linalg.LinAlgError`예요(`ValueError`의 하위 클래스라 `except ValueError`는 그대로 돼요). 메시지는 scipy의 `'indefinite preconditioner'`에 해당해요. scipy는 반복 중에 드러난 경우를 `'non-symmetric matrix'`라고 하지만 그 원인도 M이라서, 여기서는 두 경우가 같은 메시지예요.
- `maxiter`는 `max_iter`, `callback`·`show`·`check`는 없어요. `shift`가 유한한지 검사해요.
- 반올림에 민감한 부정 행렬에서는 뒷부분의 반복 수가 scipy와 조금 다를 수 있어요. 상태는 같아요.
