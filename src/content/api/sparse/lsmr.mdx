## 무엇을 하나요

[`lsqr`](/api/sparse/lsqr/)과 같은 문제를 풀어요. 최소제곱 해 $\min_x \lVert Ax - b\rVert^2$(damp > 0이면 $+\ \text{damp}^2\lVert x - x_0\rVert^2$)이고, A는 아무 모양이어도 되며, 랭크가 모자라면 x0에 가장 가까운 해에 다가가요.

차이는 반복마다 무엇을 줄이느냐예요. 최소제곱 해는 정규방정식 $A^{\mathsf H}(b - Ax) = 0$을 만족하는 점이에요. 그래서 $\lVert A^{\mathsf H}r\rVert$가 "해에서 얼마나 먼가"를 재는 자연스러운 잣대예요.

- LSQR은 정규방정식에 [`cg`](/api/sparse/cg/)를 쓴 것과 같아요. ‖r‖은 반복마다 줄지만 ‖Aᴴr‖은 크게 오르내려요.
- LSMR(Fong–Saunders)은 정규방정식에 [`minres`](/api/sparse/minres/)를 쓴 것과 같아요. **‖Aᴴr‖이 반복마다 줄고**, ‖r‖도 줄어요.

두 방법 모두 같은 Golub–Kahan 쌍대각화로 기저를 만들고, 반복마다 A와 Aᴴ의 곱을 한 번씩 해요. 끝까지 풀면 같은 답이에요. 판정을 느슨하게 해서 일찍 멈출 때 LSMR의 x가 더 안정적이에요.

## 기본 사용

300 × 60 희소 행렬로 최소제곱을 풀어요. 열마다 크기를 1부터 1,000까지 다르게 해서 조건수가 1,200쯤이에요.

```python
>>> rng = sd.random.default_rng(5)
>>> A = sd.sparse.random_array((300, 60), density=0.08, format='csr', rng=rng)
>>> A = A @ sd.sparse.diags_array(10.0 ** sd.linspace(0, 3, 60))
>>> b = sd.stats.Normal().sample(300, rng=rng)
>>> round(float(sd.linalg.cond(A.toarray())))
1223
>>> r = sd.sparse.lsmr(A, b)
>>> r
LsmrResult(converged=False, status=7, n_iter=60, normr=15.6523, x=<array of shape (60,)>)
>>> r.message
'the iteration limit was reached'
```

기본 상한 min(m, n) = 60에 닿았어요. 반올림이 없다면 크기 60인 문제는 60번 안에 끝나지만, 실제로는 조건수가 크면 그보다 오래 걸려요. 상한을 늘려요.

```python
>>> r = sd.sparse.lsmr(A, b, max_iter=1000)
>>> r.converged, r.status, r.n_iter
(True, 2, 211)
>>> r.message
'the least-squares solution is good enough, given atol'
```

밀집 최소제곱 [`sd.linalg.lstsq`](/api/linalg/lstsq/)의 답과 견줘 봐요. 잔차는 최솟값과 다섯째 자리까지 같지만, x는 3%쯤 달라요.

```python
>>> ref = sd.linalg.lstsq(A.toarray(), b).solution
>>> resid = lambda x: round(float(sd.linalg.vector_norm(b - A @ x)), 4)
>>> resid(r.x), resid(ref)
(15.3753, 15.3751)
>>> rel = lambda x: f'{float(sd.linalg.vector_norm(x - ref) / sd.linalg.vector_norm(ref)):.0e}'
>>> rel(r.x)
'3e-02'
>>> r10 = sd.sparse.lsmr(A, b, atol=1e-10, btol=1e-10, max_iter=1000)
>>> r10.n_iter, rel(r10.x)
(405, '1e-06')
```

최소제곱의 잔차는 해 근처에서 아주 평평해서, 잔차가 거의 최소여도 x는 조건수만큼 틀릴 수 있어요. 기본 `atol=1e-6`은 "A의 값이 여섯 자리쯤 믿을 만하다"는 뜻의 판정이에요. x 자체가 정확해야 하면 `atol`과 `btol`을 줄여요.

<Callout type="warn" title="기본 max_iter가 짧아요">
`lsmr`의 기본 상한은 min(m, n)이라 `lsqr`(2n)보다 짧아요. 조건수가 큰 문제에서는 판정에 닿기 전에 끊기기 쉬우니 `converged`를 꼭 보고, 모자라면 `max_iter`를 늘려요.
</Callout>

## ‖Aᴴr‖이 반복마다 줄어요

같은 문제를 `lsqr`과 `lsmr`로 k번에서 멈춰 보고, 그 x의 ‖Aᴴr‖을 직접 계산해요. 계산은 늘 같은 순서라 `max_iter=k`의 결과가 k번째 반복의 점이에요. 판정을 끄려고 `atol=btol=0`으로 둬요.

```python
>>> def gap(f, k):
...     x = f(A, b, atol=0.0, btol=0.0, max_iter=k).x
...     return round(float(sd.linalg.vector_norm(A.T @ (b - A @ x))), 1)
>>> [gap(sd.sparse.lsqr, k) for k in (20, 30, 40)]
[247.3, 2041.8, 146.0]
>>> [gap(sd.sparse.lsmr, k) for k in (20, 30, 40)]
[100.3, 72.9, 36.5]
```

`lsqr`은 30번째 반복의 ‖Aᴴr‖이 20번째보다 여덟 배 커요. `lsmr`은 꾸준히 줄어요.

판정 2(‖Aᴴr‖ ≤ atol·‖A‖·‖r‖)가 바로 이 값을 보므로, LSMR은 판정을 통과하는 시점이 예측하기 쉽고 통과한 뒤의 x도 매끄러워요. 큰 문제를 느슨한 허용오차(`atol=1e-3` 같은)로 빨리 풀고 싶을 때 `lsmr`이 알맞아요.

## 멈춤 판정

`lsqr`과 같은 판정과 `status`예요.

| `status` | 판정 |
|---|---|
| 0 | b = 0(또는 x0이 이미 답) |
| 1 | ‖r‖ ≤ btol·‖b‖ + atol·‖A‖·‖x‖ (계가 풀렸어요) |
| 2 | ‖Aᴴr‖ ≤ atol·‖A‖·‖r‖ (최소제곱 해예요) |
| 3 | cond(A)의 어림 ≥ conlim |
| 4, 5, 6 | 1, 2, 3과 같지만 반올림의 한계(ε)로 |
| 7 | 반복이 `max_iter`에 닿았어요 |

`converged`는 `status`가 0, 1, 2, 4, 5일 때 True예요. 메시지와 허용오차를 고르는 법은 [`lsqr`](/api/sparse/lsqr/#멈춤-판정-atol-btol-conlim)에 있어요. `status` 0의 메시지만 조금 달라요.

```python
>>> sd.sparse.lsmr(A, sd.zeros(300)).message
'the exact solution is x = 0, or x = x0 if x0 was given'
```

## damp와 x0

`damp > 0`이면 $\lVert Ax - b\rVert^2 + \text{damp}^2\lVert x - x_0\rVert^2$를 최소화해요. 정규화가 조건수를 줄여서 반복도 줄어요.

```python
>>> rd = sd.sparse.lsmr(A, b, damp=10.0, max_iter=1000)
>>> rd.converged, rd.n_iter
(True, 115)
>>> round(rd.normx, 3), round(r.normx, 3)
(0.203, 0.774)
```

반복이 211번에서 115번으로 줄고, 벌점 때문에 x가 작아졌어요.

x0의 뜻은 [`lsqr`](/api/sparse/lsqr/#시작점-x0)과 같아요.

## 결과 읽기

| 필드 | 뜻 |
|---|---|
| `x` | 해 (n,). 쓰기 금지 배열이에요 |
| `converged` | `status`가 0, 1, 2, 4, 5인지 |
| `status` | 위 표의 0–7 |
| `message` | 멈춘 까닭 |
| `n_iter` | 반복 수 |
| `normr` | ‖b − Ax‖의 어림 |
| `normar` | ‖Aᴴr‖의 어림 |
| `norma`, `conda` | ‖A‖와 cond(A)의 어림(반복이 본 부분에서) |
| `normx` | ‖x‖ |

`lsqr`과 달리 `normr_damped`와 `var`는 없어요. 결과는 scipy의 여덟 값으로 풀려요.

```python
>>> x, istop, itn, normr, normar, norma, conda, normx = sd.sparse.lsmr(A, b, max_iter=1000)
>>> istop, itn
(2, 211)
```

## 입력과 에러

입력 규칙은 [`lsqr`](/api/sparse/lsqr/#입력과-에러)과 같아요. 전처리기 `M`이 없고, `LinearOperator`라면 `rmatvec`이 있어야 해요.

```python
>>> sd.sparse.lsmr(A, b, maxiter=100)
Traceback (most recent call last):
    ...
TypeError: lsmr(): unexpected keyword argument 'maxiter'. Did you mean 'max_iter'?
```

## scipy를 아는 분께

- `scipy.sparse.linalg.lsmr`과 같은 알고리즘과 판정이에요. `status`가 `istop`, `n_iter`가 `itn`이에요.
- `maxiter`는 `max_iter`이고 기본값(min(m, n))은 scipy와 같아요. `show`가 없어요.
- 결과는 scipy의 `(x, istop, itn, normr, normar, norma, conda, normx)`로 풀려요. 필드 이름도 같아요.
- 반복이 수백 번인 문제에서는 반올림의 차이로 반복 수가 scipy와 조금 다를 수 있어요. 상태는 같아요.
