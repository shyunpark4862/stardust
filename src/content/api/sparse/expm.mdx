## 한눈에 보기

행렬 지수 $e^A$는 수의 지수 $e^x = 1 + x + x^2/2! + \cdots$를 행렬로 넓힌 것이에요.

$$e^A = I + A + \frac{A^2}{2!} + \frac{A^3}{3!} + \cdots$$

선형 미분방정식 $x'(t) = A\,x(t)$의 해가 $x(t) = e^{tA}x(0)$이라서, 시간에 따라 변하는 시스템의 미래 상태를 한 번에 구할 때 써요. 무엇을 계산하는지, 어디에 쓰는지는 밀집 행렬의 [expm](/api/linalg/expm/) 페이지가 예와 함께 설명해요.

`sd.sparse.expm`은 같은 계산을 희소 배열에 해요. 받은 것과 같은 형식의 희소 배열을 돌려줘요.

```python
>>> N = sd.sparse.csr_array(sd.asarray([[0.0, 1.0], [0.0, 0.0]]))
>>> E = sd.sparse.expm(N)
>>> E
<csr_array of shape (2, 2), float64, 3 stored elements>
>>> E.toarray()
array([[1.0, 1.0],
       [0.0, 1.0]], dtype=float64)
```

$N^2 = 0$이라 급수가 $I + N$에서 끝나요. 결과의 (1, 0)은 0이라서 저장되지 않아요.

정수 행렬도 받아요. 결과는 float64예요. $\begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix}$의 지수는 1라디안만큼 돌리는 회전 행렬이에요.

```python
>>> J = sd.sparse.csr_array(sd.asarray([[0, 1], [-1, 0]]))
>>> J.dtype
int64
>>> sd.sparse.expm(J).toarray()
array([[ 0.5403023058681398,  0.8414709848078964],
       [-0.8414709848078965,  0.5403023058681398]], dtype=float64)
```

$\cos 1 = 0.5403\ldots$, $\sin 1 = 0.8415\ldots$이에요.

## 결과는 대개 거의 밀집이에요

A가 희소해도 $e^A$는 거의 언제나 밀집에 가까워요. 급수의 $A^2, A^3, \ldots$이 거듭될수록 0이 아닌 자리가 퍼지기 때문이에요. 그래프로 말하면 $A^p$의 (i, j)는 i에서 j로 가는 길이 p의 길이고, 이어진 그래프에서는 언젠가 모든 쌍이 이어져요.

점 50개가 한 줄로 이어진 라플라시안(저장 148개)의 지수는 원소 2,500개가 모두 0이 아니에요.

```python
>>> n = 50
>>> L = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(n, n), format='csr')
>>> L.nnz
148
>>> E = sd.sparse.expm(-L)
>>> E
<csr_array of shape (50, 50), float64, 2500 stored elements>
>>> float(sd.min(sd.abs(E.data)))
5.8100401423193274e-58
```

멀리 떨어진 원소는 $10^{-58}$처럼 아주 작지만 0은 아니라서 모두 저장돼요. 그래서 n이 크면 결과에 n²개의 원소가 들고, 계산하는 동안에도 그만큼의 메모리가 들어요.

<Callout type="tip" title="벡터에 곱한 값만 필요하면 expm_multiply">
  미분방정식의 해 $e^{tA}x_0$처럼 $e^A$를 벡터(나 몇 개의 열)에 곱한 결과만 필요하면 [expm_multiply](/api/sparse/expm_multiply/)를 쓰세요. $e^A$를 만들지 않고 A와 벡터의 곱만으로 계산해서, 메모리가 n²이 아니라 n에 비례해요.
</Callout>

결과가 희소하게 남는 경우도 있어요. 대각 행렬의 지수는 대각의 지수 그대로이고, 블록 대각 행렬은 블록마다의 지수라서 블록 밖이 0으로 남아요. 위·아래 삼각 행렬은 삼각으로 남아요.

```python
>>> D = sd.sparse.diags_array(sd.asarray([0.0, 1.0, -1.0]), format='csc')
>>> R = sd.sparse.expm(D)
>>> R
<csc_array of shape (3, 3), float64, 3 stored elements>
>>> R.diagonal()
array([               1.0, 2.718281828459045, 0.3678794411714423], dtype=float64)
```

## 형식과 dtype

희소 배열의 형식과 저장된 0의 공통 규칙은 [기본 개념](/api/sparse/basics/)에 있어요.

- 결과의 형식은 입력의 형식이에요. CSR이면 CSR, CSC면 CSC, COO면 COO, DOK면 DOK예요. 위의 `D`가 CSC라서 결과도 CSC예요.
- 값이 정확히 0인 원소는 결과에 저장하지 않아요.
- bool과 int64는 float64로, 복소수는 complex128로 계산해요.
- 0 × 0 행렬의 지수는 0 × 0이에요.
- 같은 입력이면 형식과 sd의 스레드 수와 상관없이 같은 비트의 결과예요. 안에서 연립방정식을 한 번 푸는 단계는 [직접 풀이](/api/sparse/spsolve/)와 같은 조건(분해의 스레드 설정이 같을 때)에서 같은 비트예요.

## 시간이 있는 문제

$x(t) = e^{tA}x(0)$에서 시간 $t$는 지수 안에 넣어요. `expm(t * A)`이지 `t * expm(A)`가 아니에요. 같은 A로 여러 시각을 볼 때도 시각마다 `expm(t * A)`를 따로 계산해야 하는데, 그럴 때는 시각의 구간을 한 번에 받는 [expm_multiply](/api/sparse/expm_multiply/)의 `start`, `stop`, `num`이 편해요.

## 조심할 점

### 값이 너무 커지면 inf예요

$e^{800}$은 float64의 최댓값(약 $1.8\times10^{308}$)보다 커요. 결과가 넘치는 원소는 경고 없이 inf예요.

```python
>>> big = sd.sparse.csr_array(sd.asarray([[800.0, 0.0], [1.0, 800.0]]))
>>> sd.sparse.expm(big).toarray()
array([[inf, 0.0],
       [inf, inf]], dtype=float64)
```

### 희소 배열만 받아요

밀집 배열은 밀집 `sd.linalg.expm`을 쓰라는 `TypeError`예요. 반대로 `sd.linalg.expm`에 희소 배열을 주면 이 함수를 짚어요.

```python
>>> sd.sparse.expm(L.toarray())
Traceback (most recent call last):
    ...
TypeError: expm(): 'A' must be a sparse array, not ndarray; for a dense array use sd.linalg.expm
>>> sd.linalg.expm(L)
Traceback (most recent call last):
    ...
TypeError: expm(): 'x' must be an sd.ndarray, not csr_array; for a sparse array use sd.sparse.expm
```

### 정사각이어야 하고, NaN과 inf는 받지 않아요

```python
>>> sd.sparse.expm(sd.sparse.csr_array((2, 3)))
Traceback (most recent call last):
    ...
ValueError: expm(): 'A' must be square, got 2x3
>>> sd.sparse.expm(sd.sparse.csr_array(sd.asarray([[sd.nan, 0.0], [0.0, 1.0]])))
Traceback (most recent call last):
    ...
ValueError: expm(): 'A' contains NaN or infinity
```

## `sd.linalg.expm`과 언제 무엇을

두 함수는 같은 방법(크기를 줄여 Padé 근사를 하고 다시 제곱하는 방법)에 같은 선택(근사의 차수, 제곱 수, 삼각 행렬의 보정, 큰 노름의 처리)을 해요. 값은 반올림 차이 안에서 같아요.

```python
>>> dense = sd.linalg.expm((-L).toarray())
>>> float(sd.max(sd.abs(dense - E.toarray()))) < 1e-15
True
```

| 상황 | 쓸 것 |
|---|---|
| 행렬이 작거나 이미 밀집이에요 | [sd.linalg.expm](/api/linalg/expm/). 여러 행렬을 한 번에(배치) 계산할 수도 있어요 |
| 희소 행렬이고 결과도 희소하게 남을 거예요(블록 대각, 삼각, 거듭제곱이 0이 되는 행렬) | `sd.sparse.expm` |
| 희소 행렬이지만 결과는 밀집이에요 | n² 원소가 메모리에 들어가면 어느 쪽도 돼요. 희소 형식으로 들고 있을 이득은 없어요 |
| $e^{A}$를 벡터에 곱한 값만 필요해요 | [expm_multiply](/api/sparse/expm_multiply/) |

## 정확도

Arb(구간 산술)로 만든 참값과 견주어 결과 원소의 오차가 $10\,\varepsilon\,\max(1, \lVert A\rVert_1)\,\max|e^A|$ 안이에요($\varepsilon = 2^{-52}$). 크기를 줄이고 다시 제곱하는 동안의 반올림이 $\lVert A\rVert_1$에 비례해 쌓이므로 이런 꼴이에요. 시험 행렬에서 잰 가장 큰 오차는 이 단위로 2.4예요. 같은 점에서 scipy는 4.8, R의 Matrix 패키지는 4.2, 밀집 `sd.linalg.expm`은 3.5예요.

## scipy를 아는 분께

- `scipy.sparse.linalg.expm`과 같은 함수예요. `sd.sparse.expm`으로 불러요.
- 결과는 언제나 입력의 형식이에요. scipy는 계산의 경로에 따라 형식이 달라요.
- 밀집 배열은 받지 않아요(`sd.linalg.expm`을 써요). NaN·inf는 `ValueError`예요.
- 삼각 행렬은 대각과 첫 부대각을 정확한 식으로 다시 써서, 대각 값이 아주 가까울 때도 정확해요. 예를 들어 `[[10, 1], [0, 10 + 1e-12]]`의 (0, 1) 원소는 상대오차 9×10⁻¹⁶이고 scipy는 2×10⁻⁵예요.
- 고유값이 −10⁴⁰ 근처인 행렬의 지수는 0이에요(scipy는 단위 행렬).
