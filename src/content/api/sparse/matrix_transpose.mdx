## 한눈에 보기

**전치**(transpose)는 행렬의 행과 열을 바꾸는 일이에요. 원래 i행 j열의 원소가 j행 i열로 가요. `matrix_transpose(A)`는 `A.T`와 같은 결과를 함수로 쓰는 방법이에요.

```python
>>> import stardust as sd
>>> A = sd.sparse.csr_array(sd.asarray([[0.0, 2.0, 0.0],
...                                     [3.0, 0.0, 4.0]]))
>>> At = sd.sparse.matrix_transpose(A)
>>> At
<csc_array of shape (3, 2), float64, 3 stored elements>
>>> At.toarray()
array([[0.0, 3.0],
       [2.0, 0.0],
       [0.0, 4.0]], dtype=float64)
```

## CSR의 전치는 CSC예요

CSR은 행마다 저장된 원소를 모아 두는 형식이고, CSC는 열마다 모아 두는 형식이에요. CSR 행렬의 행은 전치의 열이므로, CSR의 세 배열을 그대로 CSC로 읽으면 전치가 돼요. 그래서 `matrix_transpose`는 값을 복사하지 않고 같은 배열을 나누는 CSC를 돌려줘요. CSC의 전치는 마찬가지로 CSR이에요.

```python
>>> A.T
<csc_array of shape (3, 2), float64, 3 stored elements>
>>> sd.sparse.matrix_transpose(A.tocsc())
<csr_array of shape (3, 2), float64, 3 stored elements>
```

COO와 DOK의 전치는 같은 형식이에요.

```python
>>> sd.sparse.matrix_transpose(A.tocoo())
<coo_array of shape (3, 2), float64, 3 stored elements>
>>> sd.sparse.matrix_transpose(A.todok())
<dok_array of shape (3, 2), float64, 3 stored elements>
```

값을 나누므로, 원래 행렬의 값 배열 `data`를 바꾸면 전치에도 보여요. 아래에서 `B`의 값을 바꾸면 `Bt`에도 그 값이 보여요. 따로 쓰려면 전치를 `copy()`로 복사해요.

```python
>>> B = A.copy()
>>> Bt = B.T
>>> B.data[0] = 20.0
>>> Bt.toarray()[1, 0]
20.0
```

## 같은 일을 하는 세 가지

희소 배열에서 2차원 전치는 세 가지로 쓸 수 있고 모두 같은 결과예요. 배열 영역과 같은 이름들이에요.

| 쓰는 법 | 뜻 |
|---|---|
| `sd.sparse.matrix_transpose(A)` | 함수 |
| `A.T`, `A.mT` | 속성 |
| `A.transpose()` | 메서드 |

전치는 행렬 곱에서 자주 써요. 정규방정식의 `Aᵀ A`나 `Aᵀ b`가 그 예예요.

```python
>>> (At @ A).toarray()
array([[ 9.0,  0.0, 12.0],
       [ 0.0,  4.0,  0.0],
       [12.0,  0.0, 16.0]], dtype=float64)
```

## 1차원과 밀집 배열은 받지 않아요

전치는 2차원 행렬의 일이라서 1차원 희소 배열은 `ValueError`예요. 밀집 배열의 `sd.matrix_transpose`와 같은 규칙이에요.

```python
>>> sd.sparse.matrix_transpose(sd.sparse.coo_array(sd.asarray([1.0, 2.0])))
Traceback (most recent call last):
    ...
ValueError: matrix_transpose(): the array must have at least 2 dimensions, got 1
```

밀집 배열은 `TypeError`예요. 밀집 배열은 [`sd.matrix_transpose`](/api/array/permute_dims/)로 전치해요.

```python
>>> sd.sparse.matrix_transpose(A.toarray())
Traceback (most recent call last):
    ...
TypeError: matrix_transpose(): 'A' must be a sparse array, not ndarray
>>> sd.matrix_transpose(A.toarray())
array([[0.0, 3.0],
       [2.0, 0.0],
       [0.0, 4.0]], dtype=float64)
```

## scipy를 아는 분께

- `scipy.sparse.matrix_transpose`와 같아요.
- 1차원 희소 배열의 `.T`와 `.mT`도 `ValueError`예요. scipy(와 numpy)의 1차원 `.T`는 자기 자신을 돌려줘요. `A.transpose()`는 1차원이면 자기 자신이에요.
