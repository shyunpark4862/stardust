## 한눈에 보기

행렬 $A$에 곱해도 방향이 바뀌지 않고 길이만 $\lambda$배가 되는 벡터 $v$가 고유벡터, 그 배율 $\lambda$가 고유값이에요($A v = \lambda v$). 고유값과 고유벡터가 무엇인지는 밀집 행렬의 [eigh](/api/linalg/eigh/) 페이지가 처음부터 설명해요.

`eigsh`는 같은 문제를 **크고 희소한 대칭 행렬**에서 풀어요. 이런 행렬에서는 n개의 고유값이 모두 필요한 일이 드물어요. 가장 작은 몇 개(진동의 낮은 음, 그래프의 덩어리 구조)나 가장 큰 몇 개(분산이 큰 방향)만 있으면 돼요. `eigsh`는 원하는 k개만 구해요.

줄 위에 점 100개가 이어진 그래프의 라플라시안으로 해 봐요. 대각이 2, 바로 옆이 −1인 삼중대각 행렬이에요. 저장된 원소는 298개뿐이에요.

```python
>>> n = 100
>>> L = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(n, n), format='csr')
>>> L
<csr_array of shape (100, 100), float64, 298 stored elements>
>>> w, v = sd.sparse.eigsh(L, k=3, which='SA')
>>> w
array([0.0009674354160238588, 0.0038688057328112473,  0.008701304061962366], dtype=float64)
>>> v.shape
(100, 3)
```

`which='SA'`는 값이 가장 작은 쪽이에요. 이 행렬의 고유값은 $\lambda_j = 2 - 2\cos\big(j\pi/(n+1)\big)$로 알려져 있어서 바로 견줄 수 있어요.

```python
>>> j = sd.arange(1, 4)
>>> 2 - 2 * sd.cos(j * sd.pi / (n + 1))
array([ 0.000967435416023843, 0.0038688057328113423,  0.008701304061962789], dtype=float64)
```

열네 자리쯤 맞아요. 고유벡터는 줄이 떠는 모양이에요. 가장 작은 고유값의 벡터가 반 파장, 그다음이 한 파장, 그다음이 한 파장 반이에요.

## 왜 몇 개만 구하나요

밀집 행렬의 [eigh](/api/linalg/eigh/)는 n × n 배열 전체를 받아 고유값 n개를 모두 구해요. n = 10⁴이면 배열 하나가 800MB이고, n = 10⁶이면 담을 수조차 없어요. 그런데 그런 행렬도 희소하면 저장은 원소 수에 비례하고, 행렬과 벡터의 곱 `A @ x`도 빨라요.

`eigsh`는 이 곱만 써요. 시작 벡터에 A를 거듭 곱해서 얻은 벡터 몇십 개(`ncv`개)가 펼치는 작은 공간을 만들고, 그 안에서 작은 고유값 문제를 풀어요. 양 끝의 고유값은 이런 공간에 빨리 잡혀요. 원하는 k개가 충분히 정확해질 때까지, 덜 쓸모 있는 방향을 버리고 공간을 다시 키우는 일(재시작)을 되풀이해요.

그래서 비용은 대략 "곱의 수 × 곱 하나의 비용"이고, 메모리는 n × `ncv`의 벡터 묶음이에요. n × n은 어디에도 생기지 않아요. 결과의 `n_op`가 곱의 수, `n_iter`가 재시작 수예요.

```python
>>> r = sd.sparse.eigsh(L, k=3, which='SA')
>>> r.n_op, r.n_iter
(626, 37)
```

밀집 배열을 그대로 줘도 돼요. 행렬이 이미 밀집이고 고유값이 몇 개만 필요할 때 쓸 수 있어요.

## `which`: 어느 쪽 고유값을 구할지

| `which` | 고르는 고유값 |
|---|---|
| `'LM'`(기본값) | 절댓값이 가장 큰 k개 |
| `'SM'` | 절댓값이 가장 작은 k개 |
| `'LA'` | 값이 가장 큰 k개 |
| `'SA'` | 값이 가장 작은 k개 |
| `'BE'` | 양 끝에서 반씩(k가 홀수면 큰 쪽이 하나 더) |

```python
>>> sd.sparse.eigsh(L, k=3, which='LA').eigenvalues
array([3.9912986959380334, 3.9961311942671727, 3.9990325645839535], dtype=float64)
>>> sd.sparse.eigsh(L, k=4, which='BE').eigenvalues
array([0.0009674354160286487, 0.0038688057328084935,     3.99613119426722,
       3.9990325645839726], dtype=float64)
```

이 행렬은 고유값이 모두 양수라 `'LM'`과 `'LA'`, `'SM'`과 `'SA'`가 같은 것을 골라요. 음수 고유값이 있는 행렬에서는 달라요. 가장 음수인 고유값은 `'SA'`로, 0에 가장 가까운 고유값은 `'SM'`으로 구해요.

<Callout type="tip" title="작은 고유값은 sigma로 구하세요">
  `'SA'`와 `'SM'`도 되지만, 작은 고유값은 대개 서로 가까이 모여 있어서 반복이 많이 들어요. 바로 아래의 `sigma=0`을 쓰면 같은 고유값을 훨씬 적은 반복으로 구해요.
</Callout>

## `sigma`: 지정한 값 근처의 고유값

`sigma`를 주면 그 값에 가까운 고유값을 찾아요. 안에서는 A 대신 $(A - \sigma I)^{-1}$에 곱해요. 이 행렬의 고유값은 $1/(\lambda - \sigma)$라서, $\sigma$에 가까운 $\lambda$일수록 절댓값이 아주 커져요. 그래서 `which='LM'`(기본값)이 곧 "$\sigma$에 가장 가까운 것"이 되고, 그런 고유값은 금방 잡혀요.

```python
>>> r = sd.sparse.eigsh(L, k=3, sigma=0)
>>> r.eigenvalues
array([0.0009674354160238701,  0.003868805732811313,  0.008701304061962843], dtype=float64)
>>> r.n_op, r.n_iter
(21, 1)
```

`which='SA'`로 626번 곱하던 것이 21번이 됐어요. 대신 처음에 $A - \sigma I$를 한 번 분해(LU)하고, 곱마다 그 분해로 연립방정식을 풀어요. 분해가 싸게 되는 희소 행렬이면 거의 언제나 이득이에요.

스펙트럼의 안쪽, 예를 들어 1 근처의 고유값도 같은 방법으로 구해요. 양 끝만 잘 잡는 보통의 반복으로는 얻기 어려운 고유값이에요.

```python
>>> sd.sparse.eigsh(L, k=3, sigma=1.0).eigenvalues
array([0.9643007502033492, 1.0180118380533556, 1.0726729360293454], dtype=float64)
```

`sigma`에서 본 크기로 고르므로 `which`도 그 뜻이 바뀌어요. 예를 들어 `which='LA'`는 $1/(\lambda - \sigma)$가 큰 것, 곧 $\sigma$ 바로 위의 고유값이에요.

`sigma`가 정확히 고유값이면 $A - \sigma I$가 특이라서 풀 수 없어요. 그때는 `LinAlgError`예요. 고유값과 아주 조금만 다른 값을 주면 돼요.

```python
>>> import math
>>> sd.sparse.eigsh(L, k=3, sigma=2 - 2 * math.cos(50 * math.pi / 101))
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: eigsh(): singular matrix
```

### `mode`: `sigma`를 쓰는 다른 방식

`mode`는 `sigma`가 있을 때만 뜻이 있어요. 기본값 `'normal'`이 위의 방식이에요. `'buckling'`은 구조물의 좌굴 문제처럼 A가 양반정치이고 M은 양정치가 아니어도 되는 일반화 문제에서 $(A - \sigma M)^{-1} A$를 쓰고, `'cayley'`는 $(A - \sigma M)^{-1}(A + \sigma M)$를 써요. 셋 모두 $\sigma$ 근처의 같은 고유값을 돌려주고, 수렴의 빠르기만 문제에 따라 달라요. 고를 이유가 없으면 `'normal'`이에요.

```python
>>> sd.sparse.eigsh(L, k=3, sigma=1.0, mode='cayley').eigenvalues
array([0.9643007502033492, 1.0180118380533556, 1.0726729360293454], dtype=float64)
>>> sd.sparse.eigsh(L, k=3, mode='cayley')
Traceback (most recent call last):
    ...
ValueError: eigsh(): mode='cayley' needs 'sigma'
```

## `M`: 일반화 고유값 문제

유한요소법의 진동 문제처럼 $A x = \lambda M x$ 꼴의 문제가 있어요. A는 강성, M은 질량 행렬이에요. `M=`으로 M을 주면 이 문제를 풀어요. M은 에르미트이고 양정치여야 해요(검사하지는 않아요).

```python
>>> M = sd.sparse.diags_array([1 / 6, 4 / 6, 1 / 6], offsets=[-1, 0, 1], shape=(n, n), format='csr')
>>> w, v = sd.sparse.eigsh(L, k=3, M=M, sigma=0)
>>> w
array([0.0009675914297267632,  0.003871301952008867,  0.008713941170580053], dtype=float64)
```

이때 고유벡터는 보통의 직교가 아니라 **M에 대해 직교**해요. $V^T M V = I$예요.

```python
>>> float(sd.max(sd.abs(v.mT @ (M @ v) - sd.eye(3)))) < 1e-14
True
>>> float(sd.max(sd.abs(L @ v - (M @ v) * w))) < 1e-14
True
```

`sigma` 없이 M만 주면 곱마다 M으로 연립방정식을 풀어요. M의 역을 곱하는 더 싼 방법(예를 들어 대각 M의 나눗셈)을 알면 `Minv=`로 줄 수 있어요. 마찬가지로 `sigma`가 있을 때 $(A - \sigma M)^{-1}$을 곱하는 방법을 직접 주려면 `OPinv=`예요. 둘 다 [LinearOperator](/api/sparse/linearoperator/)나 행렬로 줘요.

## 결과 읽기

결과는 읽기 전용 결과 객체예요. 둘로 풀면 고유값과 고유벡터이고, 필드로 읽으면 수렴의 사정도 함께 볼 수 있어요.

```python
>>> r = sd.sparse.eigsh(L, k=3, sigma=0)
>>> r
EigshResult(converged=True, status=0, n_iter=1, n_converged=3, eigenvalues=[0.000967435, 0.00386881, 0.0087013])
>>> print(r.summary())
                          Lanczos Eigenvalue Results
==============================================================================
Converged:                        True  No. Restarts:                        1
Status:                              0  No. OP x:                           21
                                        No. Converged:                       3
Message:                                    the 3 wanted eigenvalues converged
==============================================================================
                value
------------------------------------------------------------------------------
[0]          0.000967
[1]          0.003869
[2]          0.008701
==============================================================================
```

| 필드 | 뜻 |
|---|---|
| `eigenvalues` | 고유값 (k,), float64. 작은 것부터 |
| `eigenvectors` | 고유벡터 (n, k). `i`번째 열이 `eigenvalues[i]`의 짝 |
| `converged` | k개가 모두 수렴했는지(`status == 0`) |
| `status` | 0(모두 수렴), 1(반복 상한), 3(재시작에서 쓸 수 있는 이동이 없었어요, 더 큰 `ncv`가 도울 수 있어요), −9999(부분공간을 더 늘릴 수 없었어요) |
| `message` | `status`의 글 |
| `n_iter` | 재시작 수 |
| `n_converged` | 돌려준 고유값의 수 |
| `n_op` | 곱(`sigma`가 있으면 풀이)의 수 |

고유벡터의 성질은 정의 그대로 확인해요. `v * w`는 각 열에 그 열의 고유값을 곱해요.

```python
>>> w, v = r
>>> float(sd.max(sd.abs(L @ v - v * w))) < 1e-14
True
>>> float(sd.max(sd.abs(v.mT @ v - sd.eye(3)))) < 1e-14
True
```

고유벡터의 부호(복소수면 위상)는 정해져 있지 않아요. `v`가 고유벡터면 `-v`도 고유벡터예요. 다른 결과와 견줄 때는 위처럼 성질을 보거나 부호를 맞춘 뒤에 견줘요.

### 고유값만 필요하면

`return_eigenvectors=False`이면 고유벡터를 구하지 않아요. 결과의 꼴은 그대로이고 `eigenvectors`만 None이라, 똑같이 둘로 풀려요.

```python
>>> w, v = sd.sparse.eigsh(L, k=3, which='SA', return_eigenvectors=False)
>>> v is None
True
>>> w
array([ 0.008701304061962366, 0.0038688057328112473, 0.0009674354160238588], dtype=float64)
```

이때는 고유값이 계산에서 나온 순서 그대로라 오름차순이 아닐 수 있어요(위에서는 큰 것부터예요). 순서가 필요하면 `sd.sort(w)`로 정렬해요.

## 수렴하지 않을 때

반복이 `max_iter`번의 재시작 안에 끝나지 않으면 에러가 아니라 `converged=False`인 결과를 돌려줘요. 그때까지 수렴한 고유값만 결과에 들어요.

```python
>>> r = sd.sparse.eigsh(L, k=3, which='SA', max_iter=5)
>>> r
EigshResult(converged=False, status=1, n_iter=6, n_converged=0, eigenvalues=[])
>>> r.message
'the iteration limit was reached: 0 of 3 eigenvalues converged'
```

상한에 걸리면 `n_iter`가 `max_iter`보다 하나 커요. 마지막 재시작 뒤의 수렴 판정까지 센 수라서 그래요.

결과를 쓰기 전에 `r.converged`를 확인하세요. 수렴하지 않을 때 해 볼 것은 이래요.

- 작은 고유값이나 안쪽의 고유값이면 `sigma`를 써요. 가장 효과가 커요.
- `ncv`를 키워요. 부분공간이 넓으면 가까이 모인 고유값을 잘 가려요. `status=3`이면 특히 그래요.
- `max_iter`를 늘려요.
- 정확도를 덜 바라도 되면 `tol`을 키워요. 고유값 $\theta$는 그 잔차의 어림이 `tol`·$\max(\varepsilon^{2/3}, |\theta|)$ 이하일 때 수렴한 것으로 봐요($\varepsilon = 2^{-52}$). 0(기본값)이면 `tol`이 $\varepsilon$이에요.

## 시작 벡터와 결정성

반복은 시작 벡터 하나에서 출발해요. `v0=None`(기본값)이면 `sd.random.default_rng(0)`으로 뽑은 고정된 벡터를 써서, **같은 호출은 언제나 같은 비트의 결과**예요. 행렬의 형식(CSR, CSC, COO, DOK, 밀집), 같은 곱을 하는 `LinearOperator`, sd의 스레드 수와도 상관없이 같아요.

```python
>>> a = sd.sparse.eigsh(L, k=3).eigenvalues
>>> b = sd.sparse.eigsh(L.tocsc(), k=3).eigenvalues
>>> c = sd.sparse.eigsh(L.toarray(), k=3).eigenvalues
>>> bool(sd.all(a == b)), bool(sd.all(a == c))
(True, True)
```

다른 시작 벡터에서는 반복의 길이와 끝자리가 달라요. 값은 `tol`이 허락하는 만큼 같아요. `rng=`로 생성기를 주거나 `v0=`로 벡터를 직접 줘요.

```python
>>> d = sd.sparse.eigsh(L, k=3, rng=sd.random.default_rng(5)).eigenvalues
>>> float(sd.max(sd.abs(a - d))) < 1e-12
True
```

`sigma`를 쓸 때의 분해는 이 라이브러리의 희소 LU라서, 그 비트는 분해의 스레드 설정이 같을 때 같아요([직접 풀이](/api/sparse/spsolve/)의 결정성과 같아요).

## 행렬 없이 곱만으로

`eigsh`가 A에게 바라는 것은 `A @ x`뿐이에요. 행렬을 만들기 어렵거나 메모리에 담기 싫으면, 벡터를 받아 곱을 돌려주는 함수를 [LinearOperator](/api/sparse/linearoperator/)로 감싸서 줘요. 위의 라플라시안을 행렬 없이 쓰면 이래요.

```python
>>> def lap(x):
...     y = 2 * x
...     y[1:] = y[1:] - x[:-1]
...     y[:-1] = y[:-1] - x[1:]
...     return y
...
>>> op = sd.sparse.LinearOperator((n, n), lap)
>>> sd.sparse.eigsh(op, k=3)
EigshResult(converged=True, status=0, n_iter=32, n_converged=3, eigenvalues=[3.9913, 3.99613, 3.99903])
```

`sigma`나 `M`과 함께 쓰면 역을 곱해야 하는데, 함수로 준 연산자는 분해할 수 없어요. 그때는 곱마다 반복법([gmres](/api/sparse/gmres/))으로 연립방정식을 풀어서 느려요. 역을 곱하는 좋은 방법을 알면 `OPinv=`나 `Minv=`로 주세요.

## 복소 에르미트 행렬

A(또는 M, `v0`)가 복소수면 에르미트 문제로 풀어요. 고유값은 여전히 실수(float64)이고 고유벡터는 complex128이에요.

```python
>>> sh = sd.sparse.diags_array(sd.ones(n - 1), offsets=1, shape=(n, n), format='csr')
>>> H = (L + 1j * (sh - sh.T) * 0.5).tocsr()
>>> r = sd.sparse.eigsh(H, k=3, which='LA')
>>> r.eigenvalues
array([4.234986351822727, 4.231742521194547, 4.226339623811934], dtype=float64)
>>> r.eigenvectors.dtype
complex128
```

복소 문제에서는 두 가지가 달라요.

- 고유값이 작은 것부터 정렬되어 나오지 않을 수 있어요(위에서는 큰 것부터예요). 순서가 필요하면 `sd.argsort(r.eigenvalues)`로 고유벡터의 열도 함께 정렬해요.
- `which='BE'`와 `'normal'` 밖의 `mode`는 쓸 수 없어요(`ValueError`).

## 입력과 에러

희소 배열의 형식과 dtype, 저장된 0과 NaN, 결정성 같은 공통 규칙은 [기본 개념](/api/sparse/basics/)에 있어요.

- `k`는 n보다 작아야 해요. 고유값이 모두 필요하면 밀집 `eigh`를 쓰라는 메시지예요.

  ```python
  >>> sd.sparse.eigsh(L, k=100)
  Traceback (most recent call last):
      ...
  ValueError: eigsh(): 'k' must be < n = 100 for 'A' of shape (100, 100); for all eigenvalues use sd.linalg.eigh(A.toarray())
  ```

- `which`, `mode`는 정해진 문자열만 받아요.

  ```python
  >>> sd.sparse.eigsh(L, which='LR')
  Traceback (most recent call last):
      ...
  ValueError: eigsh(): 'which' must be 'LM', 'SM', 'LA', 'SA' or 'BE', not 'LR'
  ```

- 시작 벡터는 0이 아니어야 해요.

  ```python
  >>> sd.sparse.eigsh(L, v0=sd.zeros(n))
  Traceback (most recent call last):
      ...
  ValueError: eigsh(): 'v0' must not be zero
  ```

- 리스트는 받지 않아요. 희소 배열, `sd.ndarray`, `LinearOperator`로 줘요.

  ```python
  >>> sd.sparse.eigsh([[2.0, 1.0], [1.0, 2.0]])
  Traceback (most recent call last):
      ...
  TypeError: eigsh(): 'A' must be a sparse array, an sd.ndarray or a LinearOperator, not list
  ```

- 저장된 값에 NaN이나 inf가 있으면 `ValueError`예요.
- `Minv`는 M이 있고 `sigma`가 없을 때만, `OPinv`는 `sigma`가 있을 때만 받아요. 다른 자리면 `ValueError`예요.
- 대칭인지는 검사하지 않아요. 대칭이 아닌 행렬을 주면 결과에 뜻이 없어요. 대칭이 아니면 [eigs](/api/sparse/eigs/)를 써요.

## `eigh`와 `eigsh`, 언제 무엇을

| 상황 | 쓸 것 |
|---|---|
| 고유값이 모두(또는 대부분) 필요해요 | [sd.linalg.eigh](/api/linalg/eigh/)(`A.toarray()`) |
| n × n 밀집 배열이 메모리에 넉넉히 들어가고, 고유값이 많이 필요해요 | `sd.linalg.eigh` |
| 크고 희소한 행렬에서 양 끝의 몇 개만 필요해요 | `eigsh` |
| 안쪽의 특정 값 근처의 몇 개가 필요해요 | `eigsh(sigma=...)` |
| 행렬은 없고 곱하는 함수만 있어요 | `eigsh(LinearOperator)` |
| 대칭이 아니에요 | [eigs](/api/sparse/eigs/), 밀집이면 [sd.linalg.eig](/api/linalg/eig/) |

두 함수의 고유값은 반올림 차이 안에서 같아요. `eigh`는 고유값 전체를 정확히 한 번에 구하는 직접 방법이고, `eigsh`는 원하는 것만 `tol`까지 다듬는 반복 방법이에요. `sd.linalg.eigh`에 희소 배열을 주면 `eigsh`를 짚는 `TypeError`예요.

```python
>>> sd.linalg.eigh(L)
Traceback (most recent call last):
    ...
TypeError: eigh(): 'a' must be an sd.ndarray, not csr_array; for a sparse array use sd.sparse.eigsh
```

## 정확도

고유값과 잔차를 Arb(구간 산술)로 만든 참값과 견줘요. 약속은 이래요.

- 고유값의 오차 $|\hat\lambda - \lambda| \le 1000\,\varepsilon\,\lVert A\rVert_2$($\varepsilon = 2^{-52}$).
- 잔차 $\lVert A v - \lambda M v\rVert$도 $1000\,\varepsilon\,\lVert A\rVert_2$ 안, 직교성 $\lVert V^H M V - I\rVert$는 $1000\,k\,\varepsilon$ 안.

시험 문제(대칭 17개의 양 끝과 직사각 셋)에서 잰 가장 큰 고유값 오차는 한계의 절반, $497\,\varepsilon\lVert A\rVert_2$예요. 1차원 라플라시안 n = 1000의 `'LA'`로, 재시작을 762번 하는 동안 반올림이 쌓인 경우예요. 대부분의 문제는 이보다 훨씬 작아요. 재시작이 많을수록 오차가 커지므로, 정확도가 중요하면 `sigma`로 반복을 줄이는 것이 도움이 돼요.

## scipy를 아는 분께

- `scipy.sparse.linalg.eigsh`와 같은 함수예요. `sd.sparse.linalg` 없이 `sd.sparse.eigsh`예요.
- 계산 방법(ARPACK의 암시적 재시작 Lanczos)을 scipy가 돌리는 순서 그대로 해서, 같은 `v0`이면 대개 반복 수와 상태가 scipy와 같아요. 겹친 고유값처럼 반올림에 민감한 문제에서는 scipy 자신이 `v0`의 한 ulp에 따라 흔들리는 폭 안에서 달라요.
- `v0=None`이 고정된 시작 벡터예요. scipy는 시드 없는 난수라 실행마다 결과가 달라요. `rng=`로 생성기를 줄 수 있어요.
- 인자는 `A`만 위치이고 나머지는 키워드예요. `maxiter`는 `max_iter`예요.
- 수렴하지 않으면 `ArpackNoConvergence` 예외 대신 `converged=False`인 결과에 수렴한 쌍을 담아요. `ArpackError`, `ArpackNoConvergence`는 없어요. 시작 벡터가 연산자의 영공간에 있으면(scipy의 `ArpackError` −9) `ValueError`예요.
- `return_eigenvectors=False`여도 결과의 꼴이 같아요. scipy는 배열 하나를 돌려주지만 여기서는 `(w, None)`으로 풀려요.
- k ≥ n이면 scipy는 경고와 함께 밀집 계산으로 넘어가지만(희소 행렬에는 `TypeError`), 여기서는 `sd.linalg.eigh`를 짚는 `ValueError`예요.
- `sigma` 없이 `mode`를 주면 scipy는 조용히 무시하지만 여기서는 `ValueError`예요. `sigma`가 고유값이면 scipy는 `RuntimeError`, 여기서는 `LinAlgError`예요.
