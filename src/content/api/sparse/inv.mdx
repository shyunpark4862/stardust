## 한눈에 보기

`inv(A)`는 $AX = I$를 만족하는 행렬 $X = A^{-1}$를 희소 배열로 돌려줘요.

```python
>>> import stardust as sd
>>> D = sd.sparse.diags_array(sd.asarray([2.0, 4.0, 5.0]))
>>> Di = sd.sparse.inv(D)
>>> Di
<csr_array of shape (3, 3), float64, 3 stored elements>
>>> Di.toarray()
array([[ 0.5,  0.0,  0.0],
       [ 0.0, 0.25,  0.0],
       [ 0.0,  0.0,  0.2]], dtype=float64)
```

대각 행렬의 역행렬은 대각 원소의 역수를 놓은 대각 행렬이라 희소한 채로 남아요. 하지만 이것은 드문 경우예요. 대부분의 희소 행렬은 역행렬이 꽉 차요.

## 희소 행렬의 역행렬은 대개 꽉 차요

가장 간단한 희소 행렬인 삼중대각 행렬을 볼게요. 대각선 셋에만 값이 있는데, 역행렬은 25칸이 모두 0이 아니에요.

```python
>>> T5 = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(5, 5))
>>> T5.nnz
13
>>> sd.sparse.inv(T5)
<csr_array of shape (5, 5), float64, 25 stored elements>
```

이유는 이렇게 생각할 수 있어요. $A^{-1}$의 $j$번째 열은 $Ax = e_j$(j번째 칸만 1인 우변)의 해예요. 격자로 치면 한 점에만 열을 가했을 때의 온도 분포인데, 열은 이웃을 타고 모든 점으로 퍼지니까 해의 모든 원소가 0이 아니에요.

행렬이 커지면 이 차이가 감당할 수 없게 돼요. 1000 × 1000 삼중대각 행렬은 원소 2,998개를 저장하지만 역행렬은 100만 개예요.

```python
>>> n = 1000
>>> T = sd.sparse.diags_array([-1.0, 2.0, -1.0], offsets=[-1, 0, 1], shape=(n, n))
>>> T.nnz, sd.sparse.inv(T).nnz
(2998, 1000000)
```

$n = 10^5$이면 역행렬은 원소 $10^{10}$개, 80GB예요. 행렬 자체는 몇 MB인데도요.

## 역행렬 대신 풀이를 쓰세요

수식의 $A^{-1}b$는 거의 언제나 "$Ax = b$의 해"라는 뜻이에요. 역행렬을 만들지 않고 [spsolve](/api/sparse/spsolve/)로 풀면 저장도 계산도 훨씬 적어요.

```python
>>> b = sd.ones(5)
>>> sd.sparse.spsolve(T5, b)
array([2.5000000000000004,  4.000000000000001,                4.5,
                      4.0,                2.5], dtype=float64)
>>> sd.sparse.inv(T5) @ b
array([2.4999999999999996,                4.0,                4.5,
       3.9999999999999996,                2.5], dtype=float64)
```

답은 반올림만큼 다르고, 들인 품은 크게 달라요. `inv`는 우변 n개를 푸는 것과 같은 일을 하고 그 결과를 n²칸에 담아요. `spsolve`는 우변 하나만 풀어요.

| 수식 | 이렇게 쓰지 말고 | 이렇게 쓰세요 |
|:---:|---|---|
| $A^{-1}b$ | `inv(A) @ b` | `spsolve(A, b)` |
| $A^{-1}B$ | `inv(A) @ B` | `spsolve(A, B)` (B는 밀집이나 희소) |
| $A^{-1}$를 여러 번 곱하기 | `Ai = inv(A)` 뒤 `Ai @ b` | `lu = splu(A)` 뒤 `lu.solve(b)` |
| $A^{-1}$의 열 몇 개 | `inv(A)[:, j]` | 단위 벡터를 우변으로 `spsolve` |

역행렬의 한 열만 필요하면 그 열에 해당하는 단위 벡터를 우변으로 풀면 돼요.

```python
>>> e2 = sd.sparse.eye_array(5, format="csc")[:, 2:3]
>>> sd.sparse.spsolve(T5, e2).toarray()
array([[0.5000000000000001],
       [1.0000000000000002],
       [               1.5],
       [               1.0],
       [               0.5]], dtype=float64)
```

## 역행렬이 희소한 경우

역행렬이 희소하게 남는 행렬도 있어요. 대각 행렬, 순열 행렬, 블록 대각 행렬이 그래요. 블록 대각 행렬의 역행렬은 블록마다의 역행렬을 같은 자리에 놓은 것이라, 블록 밖은 0이에요.

```python
>>> blocks = sd.sparse.block_diag([sd.sparse.csr_array(sd.asarray([[2.0, 1.0], [1.0, 2.0]])),
...                                sd.sparse.csr_array(sd.asarray([[4.0, 1.0], [1.0, 4.0]]))])
>>> blocks.format
'coo'
>>> sd.sparse.inv(blocks)
<csc_array of shape (4, 4), float64, 8 stored elements>
>>> P = sd.sparse.csr_array(sd.eye(4)[sd.asarray([2, 0, 3, 1])])
>>> bool(sd.all(sd.sparse.inv(P).toarray() == P.T.toarray()))
True
```

순열 행렬의 역행렬은 전치예요. 결과에서 정확히 0인 원소는 저장하지 않으므로, 역행렬이 희소하면 결과도 희소해요.

## 결과의 형식과 dtype

결과의 형식은 `A`를 따라요. `A`가 CSR이면 CSR, 그 밖(CSC, COO, DOK)이면 CSC예요.

```python
>>> sd.sparse.inv(D.tocoo())
<csc_array of shape (3, 3), float64, 3 stored elements>
```

정수 행렬도 결과는 float64예요. 복소 행렬이면 complex128이에요.

```python
>>> sd.sparse.inv(sd.sparse.csr_array(sd.asarray([[1, 2], [3, 4]]))).toarray()
array([[-2.0,  1.0],
       [ 1.5, -0.5]], dtype=float64)
```

## 밀집 짝 `sd.linalg.inv`

밀집 배열의 짝은 [`sd.linalg.inv`](/api/linalg/inv/)예요. 역행렬이 거의 꽉 찰 것을 알면 처음부터 밀집 배열로 바꿔 `sd.linalg.inv`를 쓰는 편이 자연스러워요. 결과를 희소 배열로 담아도 저장이 줄지 않기 때문이에요. 두 함수는 푸는 방법이 달라서 마지막 자리가 다를 수 있어요.

```python
>>> sd.linalg.inv(sd.asarray([[1.0, 2.0], [3.0, 4.0]]))
array([[-1.9999999999999996,  0.9999999999999998],
       [ 1.4999999999999998, -0.4999999999999999]], dtype=float64)
```

희소 배열을 `sd.linalg.inv`에 주거나 밀집 배열을 `sd.sparse.inv`에 주면 쓸 함수를 알려 주는 `TypeError`예요.

```python
>>> sd.sparse.inv(sd.eye(2))
Traceback (most recent call last):
    ...
TypeError: inv(): 'A' must be a sparse array, not ndarray; for a dense array use sd.linalg.inv
>>> sd.linalg.inv(D)
Traceback (most recent call last):
    ...
TypeError: inv(): 'x' must be an sd.ndarray, not csr_array; for a sparse array use sd.sparse.inv
```

## 조심할 점

### 특이 행렬은 `LinAlgError`

판정은 [spsolve](/api/sparse/spsolve/#특이-행렬은-linalgerror)와 같아요. 정확히 0인 피벗뿐 아니라 조건수가 $2^{52}$ 이상인 행렬도 특이로 봐요.

```python
>>> sd.sparse.inv(sd.sparse.csr_array(sd.asarray([[1.0, 2.0], [2.0, 4.0]])))
Traceback (most recent call last):
    ...
stardust.linalg.LinAlgError: inv(): singular matrix
```

<Callout type="warn" title="메모리를 먼저 헤아려 보세요">

`inv`의 결과는 대개 n²개의 원소를 저장해요. 희소 배열은 원소마다 값과 자리(열 번호)를 함께 저장하므로, 꽉 찬 희소 배열은 같은 크기의 밀집 배열보다 더 많은 메모리를 써요. 행이 수만 개를 넘는 행렬에 `inv`를 부르기 전에 정말 역행렬 전체가 필요한지 생각해 보세요.

</Callout>

### 빈 행렬

0 × 0 행렬의 역행렬은 0 × 0이에요.

```python
>>> sd.sparse.inv(sd.sparse.csr_array((0, 0)))
<csr_array of shape (0, 0), float64, 0 stored elements>
```

## scipy를 아는 분께

- `scipy.sparse.linalg.inv`와 같이 단위 행렬을 희소 우변으로 풀어서 만들고, 결과의 형식(CSR이면 CSR, 나머지는 CSC)과 정확한 0을 빼는 규칙도 같아요.
- scipy는 `A`가 CSC나 CSR이 아니면 `SparseEfficiencyWarning`을 내지만, 여기에는 경고가 없고 어느 형식이든 그대로 받아요.
- 특이 행렬은 `LinAlgError`예요. scipy는 정확히 특이하면 `RuntimeError("Factor is exactly singular")`이고, 값으로 특이하면 경고 없이 큰 값을 돌려줘요.
