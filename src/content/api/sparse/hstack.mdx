## 한눈에 보기

`hstack`은 행렬을 옆으로 나란히 붙여요(h는 horizontal, 가로). 블록의 행 수는 같아야 하고, 결과의 열 수는 블록들의 열 수를 더한 것이에요.

```python
>>> import stardust as sd
>>> A = sd.sparse.csr_array(sd.asarray([[1.0, 2.0], [0.0, 3.0]]))
>>> B = sd.sparse.csr_array(sd.asarray([[4.0], [5.0]]))
>>> H = sd.sparse.hstack([A, B])
>>> H
<csr_array of shape (2, 3), float64, 5 stored elements>
>>> H.toarray()
array([[1.0, 2.0, 4.0],
       [0.0, 3.0, 5.0]], dtype=float64)
```

`hstack(blocks)`는 블록 한 줄짜리 [`block_array([blocks])`](/api/sparse/block_array/)와 같아요. 위아래로 잇는 것은 [`vstack`](/api/sparse/vstack/)이에요.

## 행 수가 같아야 해요

블록의 행 수가 다르면 `ValueError`예요. 메시지의 `blocks[0,1]`은 블록 한 줄짜리 격자에서 1번째 블록이라는 뜻이에요.

```python
>>> C = sd.sparse.csr_array(sd.asarray([[6.0, 0.0]]))
>>> sd.sparse.hstack([A, C])
Traceback (most recent call last):
    ...
ValueError: hstack(): blocks[0,:] has incompatible row dimensions: blocks[0,1].shape[0] is 1, expected 2
```

## 블록에 쓸 수 있는 것

블록은 희소 배열, 밀집 `sd.ndarray`, `None`이에요. 밀집 배열은 0이 아닌 값만 저장해요. 블록은 리스트 하나에 담아 넘겨요.

```python
>>> sd.sparse.hstack([A, sd.asarray([[7.0], [0.0]])]).toarray()
array([[1.0, 2.0, 7.0],
       [0.0, 3.0, 0.0]], dtype=float64)
>>> sd.sparse.hstack(A)
Traceback (most recent call last):
    ...
TypeError: hstack(): 'blocks' must be a list or a tuple, not csr_array
```

### 1차원 블록은 한 행이에요

1차원 희소 배열은 한 행(1 × n)으로 봐요. 그래서 1차원 배열 둘을 `hstack`하면 1차원이 아니라 1 × (n₁ + n₂)의 2차원 결과예요.

```python
>>> v1 = sd.sparse.coo_array(sd.asarray([1.0, 0.0, 2.0]))
>>> v2 = sd.sparse.coo_array(sd.asarray([0.0, 3.0, 0.0]))
>>> sd.sparse.hstack([v1, v2])
<coo_array of shape (1, 6), float64, 3 stored elements>
```

## 결과의 형식

`format=None`이면 블록이 모두 CSR일 때 CSR, 모두 CSC일 때 CSC, 그 밖에는 COO예요. 형식이 같은 CSR끼리, CSC끼리는 압축된 줄을 그대로 이어 붙여요.

```python
>>> sd.sparse.hstack([A.tocsc(), B.tocsc()])
<csc_array of shape (2, 3), float64, 5 stored elements>
>>> sd.sparse.hstack([A, B.tocoo()])
<coo_array of shape (2, 3), float64, 5 stored elements>
>>> sd.sparse.hstack([A, B.tocoo()], format='csr')
<csr_array of shape (2, 3), float64, 5 stored elements>
```

`dtype=None`이면 블록들의 dtype을 배열의 규칙으로 승격하고, `dtype`을 주면 그 dtype으로 바꿔요.

## 어디에 쓰나요: 열 붙이기

설계 행렬에 절편 열(1로 채운 열)을 붙이는 것처럼, 희소 행렬에 열을 더할 때 써요.

```python
>>> X = sd.sparse.csr_array(sd.asarray([[0.0, 2.0], [1.0, 0.0], [0.0, 0.0]]))
>>> sd.sparse.hstack([sd.ones((3, 1)), X]).toarray()
array([[1.0, 0.0, 2.0],
       [1.0, 1.0, 0.0],
       [1.0, 0.0, 0.0]], dtype=float64)
```

## 밀집 배열의 짝: sd.concat

밀집 배열을 옆으로 잇는 것은 [`sd.concat(arrays, axis=1)`](/api/array/concat/)이에요. 같은 2차원 블록이면 `hstack(...).toarray()`와 값이 비트까지 같아요.

```python
>>> D = sd.concat([A.toarray(), B.toarray()], axis=1)
>>> bool(sd.all(D == H.toarray()))
True
```

1차원 배열은 다르게 다뤄요. `sd.concat`은 1차원 배열을 이어 1차원을 돌려주지만, `hstack`은 1차원 블록을 한 행으로 봐서 2차원을 돌려줘요.

## scipy를 아는 분께

- `scipy.sparse.hstack`과 같은 꼴과 결과 형식이에요. 1차원 블록을 한 행으로 보는 것도 같아요.
- 블록은 희소 배열, `sd.ndarray`, `None`이에요. 리스트와 numpy 배열은 `TypeError`예요.
