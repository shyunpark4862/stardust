## 한눈에 보기

`unique_values`는 배열에 나오는 **서로 다른 값**을 작은 것부터 한 번씩만 모아요. 겹치는 값은 하나만 남아요.

```python
>>> import stardust as sd
>>> x = sd.asarray([3, 1, 3, 2, 1, 3])
>>> sd.unique_values(x)
array([1, 2, 3], dtype=int64)
```

값만이 아니라 다른 정보도 필요할 때가 많아요. 그래서 네 가지 함수가 있고, 필요한 만큼 골라 쓰면 돼요.

| 함수 | 돌려주는 것 |
|---|---|
| `unique_values` | `values` 배열 하나 |
| `unique_counts` | `values`, `counts` |
| `unique_inverse` | `values`, `inverse_indices` |
| `unique_all` | `values`, `indices`, `inverse_indices`, `counts` |

네 함수의 `values`는 언제나 같아요. 넷째 함수 `unique_all`이 모든 정보를 한꺼번에 줘요.

```python
>>> sd.unique_all(x)
UniqueAllResult(values=array([1, 2, 3], dtype=int64), indices=array([1, 3, 0], dtype=int64), inverse_indices=array([2, 0, 2, 1, 0, 2], dtype=int64), counts=array([2, 1, 3], dtype=int64))
```

## 네 가지 정보

같은 `x`로 각 필드가 무엇인지 볼게요.

| 필드 | 뜻 | 길이 | 위 예 |
|---|---|---|---|
| `values` | 서로 다른 값, 오름차순 | 고유한 값의 수 | `[1, 2, 3]` |
| `counts` | 각 값이 나온 횟수 | 고유한 값의 수 | `[2, 1, 3]`: 1은 두 번, 2는 한 번, 3은 세 번 |
| `indices` | 각 값이 **처음** 나온 자리 | 고유한 값의 수 | `[1, 3, 0]`: 1은 1번 자리, 2는 3번 자리, 3은 0번 자리에서 처음 나와요 |
| `inverse_indices` | `x`의 각 원소가 `values`의 몇 번째인지 | `x`와 같은 모양 | `[2, 0, 2, 1, 0, 2]`: 첫 원소 3은 `values[2]` |

`indices`, `inverse_indices`, `counts`는 모두 int64예요.

### 값마다 개수 세기: `unique_counts`

가장 자주 쓰는 함수예요. 어떤 값이 몇 번 나왔는지 표로 만들 때 써요.

```python
>>> sd.unique_counts(x)
UniqueCountsResult(values=array([1, 2, 3], dtype=int64), counts=array([2, 1, 3], dtype=int64))
```

가장 많이 나온 값(최빈값)은 `counts`가 가장 큰 자리의 값이에요.

```python
>>> c = sd.unique_counts(x)
>>> c.values[sd.argmax(c.counts)]
3
```

### 원래 배열 되살리기: `unique_inverse`

`inverse_indices`는 "원소마다 `values`의 몇 번째 값인가"예요. 그래서 **`values`를 `inverse_indices`로 인덱싱하면 원래 `x`가 그대로 돌아와요.**

```python
>>> u = sd.unique_inverse(x)
>>> u.inverse_indices
array([2, 0, 2, 1, 0, 2], dtype=int64)
>>> u.values[u.inverse_indices]
array([3, 1, 3, 2, 1, 3], dtype=int64)
```

이 성질은 값을 **0부터 시작하는 번호로 바꿀 때** 쓸모가 있어요. 예를 들어 상품 코드 `[1005, 2310, 1005, 4200]`을 `[0, 1, 0, 2]`로 바꾸면, 번호를 칸 번호로 삼아 [`bincount`](/api/array/bincount/)로 세거나 다른 배열의 자리로 쓸 수 있어요.

```python
>>> codes = sd.asarray([1005, 2310, 1005, 4200])
>>> sd.unique_inverse(codes).inverse_indices
array([0, 1, 0, 2], dtype=int64)
```

### 처음 나온 자리: `indices`

`indices`로 `x`를 인덱싱하면 `values`와 같은 값이 나와요. 각 값이 처음 등장한 자리이기 때문이에요.

```python
>>> a = sd.unique_all(x)
>>> a.indices
array([1, 3, 0], dtype=int64)
>>> x[a.indices]
array([1, 2, 3], dtype=int64)
```

"처음 나온 순서대로" 고유한 값을 늘어놓고 싶을 때도 `indices`를 써요. `indices`를 정렬한 다음 그 자리의 값을 꺼내면 돼요.

```python
>>> x[sd.sort(a.indices)]
array([3, 1, 2], dtype=int64)
```

## 결과는 namedtuple이에요

`unique_values`를 뺀 셋은 namedtuple(이름 붙은 tuple)을 돌려줘요. 필드 이름으로 꺼내도 되고, tuple처럼 풀어도 돼요.

| 함수 | 결과 타입 | 필드 순서 |
|---|---|---|
| `unique_counts` | `UniqueCountsResult` | `values`, `counts` |
| `unique_inverse` | `UniqueInverseResult` | `values`, `inverse_indices` |
| `unique_all` | `UniqueAllResult` | `values`, `indices`, `inverse_indices`, `counts` |

```python
>>> vals, counts = sd.unique_counts(x)
>>> vals
array([1, 2, 3], dtype=int64)
>>> counts
array([2, 1, 3], dtype=int64)
```

<Callout type="warn" title="unique_all의 필드 순서">

  `unique_all`을 풀 때는 순서를 조심하세요. `values, indices, inverse_indices, counts` 순서예요. `counts`가 맨 끝이라서 `values, counts, ... = sd.unique_all(x)`처럼 쓰면 엉뚱한 값을 받아요. 헷갈리면 `a.counts`처럼 이름으로 꺼내는 편이 안전해요.

</Callout>

## 여러 차원의 배열은 펴서 봐요

2차원 이상의 배열을 넣으면 **모든 원소를 한 줄로 편 다음** 고유한 값을 찾아요. 행별·열별로 따로 찾거나, 겹치는 행을 찾는 기능은 없어요.

```python
>>> m = sd.asarray([[2, 1], [1, 5]])
>>> sd.unique_values(m)
array([1, 2, 5], dtype=int64)
```

`indices`는 편 배열에서의 자리예요. 반면 `inverse_indices`는 **`x`와 같은 모양**이라, 되살리기가 여러 차원에서도 그대로 돼요.

```python
>>> um = sd.unique_all(m)
>>> um.indices
array([1, 0, 3], dtype=int64)
>>> um.inverse_indices
array([[1, 0],
       [0, 2]], dtype=int64)
>>> um.values[um.inverse_indices]
array([[2, 1],
       [1, 5]], dtype=int64)
```

`indices`의 `3`은 편 배열 `[2, 1, 1, 5]`의 3번 자리, 즉 `m[1, 1]`이에요.

## NaN은 하나의 값으로 쳐요

NaN(숫자가 아님)은 원래 자기 자신과도 같지 않은 값이에요(`nan == nan`은 `False`). 그래도 고유한 값을 셀 때 NaN마다 따로 세면 결과가 쓸모없어지기 때문에, stardust는 **모든 NaN을 하나의 값**으로 묶어요. 정렬할 때처럼 NaN은 가장 큰 값으로 쳐서 맨 끝에 와요.

```python
>>> f = sd.asarray([2.0, sd.nan, 1.0, sd.nan])
>>> sd.unique_values(f)
array([1.0, 2.0, nan], dtype=float64)
>>> sd.unique_counts(f)
UniqueCountsResult(values=array([1.0, 2.0, nan], dtype=float64), counts=array([1, 1, 2], dtype=int64))
```

"NaN이 몇 개인가"가 `counts`의 마지막 칸에 나와요. 무한대는 NaN이 아니라서 따로 세요.

```python
>>> sd.unique_values(sd.asarray([sd.inf, -sd.inf, sd.nan, 1.0]))
array([-inf,  1.0,  inf,  nan], dtype=float64)
```

## `-0.0`과 `0.0`은 같은 값이에요

실수에는 `0.0`과 `-0.0`이 따로 있지만, 비교하면 같은 값이에요. 그래서 하나로 묶여요. 이때 결과에 보이는 것은 **먼저 나온 쪽**이에요.

```python
>>> sd.unique_values(sd.asarray([-0.0, 0.0]))
array([-0.0], dtype=float64)
>>> sd.unique_values(sd.asarray([0.0, -0.0]))
array([0.0], dtype=float64)
>>> sd.unique_counts(sd.asarray([0.0, -0.0, 0.0]))
UniqueCountsResult(values=array([0.0], dtype=float64), counts=array([3], dtype=int64))
```

같은 값으로 묶인 원소 중에서는 언제나 처음 나온 원소를 보여 줘요. `indices`가 가리키는 바로 그 원소예요.

## bool과 복소수

어떤 dtype이든 받아요. bool은 `False`, `True` 순서예요. 복소수는 크고 작음이 없지만, 결과를 늘어놓기 위해 **실수부를 먼저, 같으면 허수부를** 비교한 순서로 정렬해요.

```python
>>> sd.unique_values(sd.asarray([True, False, True]))
array([False,  True], dtype=bool)
>>> sd.unique_values(sd.asarray([1 + 1j, 1 - 1j, 0j, 1 + 1j]))
array([    0j, (1-1j), (1+1j)], dtype=complex128)
```

실수부나 허수부 중 하나라도 NaN인 복소수는 모두 NaN 하나로 묶여 맨 끝에 와요.

## 조심할 점

### 결과의 길이는 데이터에 따라 달라요

`values`의 길이는 실제로 나온 값의 수예요. 나오지 않은 값의 칸은 없어요. 0부터 일정한 범위의 정수를 언제나 같은 길이로 세고 싶다면 [`bincount`](/api/array/bincount/)의 `minlength`가 맞아요.

### 옵션이 없어요

네 함수는 배열 하나만 받아요. `axis`처럼 방향을 고르는 옵션이나, NaN을 따로 셀지 고르는 옵션은 없어요.

```python
>>> sd.unique_values([1, 2, 2])
Traceback (most recent call last):
    ...
TypeError: unique_values(): 'x' must be an sd.ndarray, not list
```

### 빈 배열

빈 배열을 넣으면 모든 필드가 빈 배열이에요.

```python
>>> sd.unique_counts(sd.asarray([], dtype=sd.int64))
UniqueCountsResult(values=array([], dtype=int64), counts=array([], dtype=int64))
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 다른 점 |
|---|---|---|
| 값을 크기순으로 늘어놓기 | `sort` | 겹치는 값도 모두 남겨요. 모양을 유지하고 축을 골라요. |
| 0, 1, 2, … 정수의 개수 | `bincount` | 나오지 않은 값도 0으로 칸이 있어요. 0 이상의 정수만 받아요. |
| 구간별 개수 | `histogram` | 값이 아니라 구간으로 묶어 세요. |
| 값이 정렬된 목록의 몇 번째인지 | `searchsorted` | `values`가 이미 있을 때 다른 값들의 자리를 찾아요. |

`sort`와 비교하면 차이가 분명해요.

```python
>>> sd.sort(x)
array([1, 1, 2, 3, 3, 3], dtype=int64)
>>> sd.unique_values(x)
array([1, 2, 3], dtype=int64)
```

## numpy를 아는 분께

- **NaN을 하나로 묶어요.** numpy의 `np.unique`(기본값)와 같지만, `np.unique_values`, `np.unique_counts`, `np.unique_inverse`, `np.unique_all`은 NaN을 서로 다른 값으로 봐서 NaN이 여러 번 나와요. stardust의 `unique_*`는 네 함수 모두 하나로 묶어요.
- 묶인 값 중 **처음 나온 원소**를 보여 줘요. 그래서 `-0.0`과 `0.0` 중 무엇이 보일지가 정해져 있어요(numpy는 정해져 있지 않아요).
- `np.unique` 자체와 `return_counts=`, `axis=`, `equal_nan=` 같은 옵션은 없어요. 네 함수 중에서 고르세요.
- `inverse_indices`는 `x`와 같은 모양이에요(numpy 2와 같아요).
- 결과 타입 이름은 `UniqueCountsResult`처럼 numpy와 같지만, stardust의 타입이에요.
