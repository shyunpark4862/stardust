## 한눈에 보기

stardust는 자주 쓰는 값 다섯 개를 이름으로 제공해요.

| 이름 | 값 | 타입 | 뜻 |
|---|---|---|---|
| `sd.e` | `2.718281828459045` | `float` | 자연상수 e, 자연로그의 밑 |
| `sd.pi` | `3.141592653589793` | `float` | 원주율 π |
| `sd.inf` | `inf` | `float` | 양의 무한대 |
| `sd.nan` | `nan` | `float` | NaN(Not a Number, 숫자가 아님) |
| `sd.newaxis` | `None` | `NoneType` | 인덱싱에서 길이 1인 축을 넣는 표시 |

```python
>>> import stardust as sd
>>> sd.pi
3.141592653589793
>>> sd.e
2.718281828459045
>>> sd.inf
inf
>>> sd.nan
nan
>>> print(sd.newaxis)
None
```

다섯 모두 배열이 아니라 **평범한 Python 값**이에요. 앞의 넷은 Python `float`이고, `sd.newaxis`는 Python의 `None` 그 자체예요. 그래서 Python 숫자를 쓸 수 있는 곳이면 어디든 쓸 수 있어요.

```python
>>> type(sd.pi)
<class 'float'>
>>> sd.newaxis is None
True
```

## `pi`와 `e`

### `pi`: 원주율

원의 둘레와 지름의 비, 약 3.14159예요. 각도를 다룰 때 가장 많이 써요. stardust의 삼각함수는 각도를 라디안으로 받기 때문에, 도(°) 단위를 라디안으로 바꿀 때 `π / 180`을 곱해요([삼각함수](/api/array/trig/) 참고).

```python
>>> deg = sd.asarray([0.0, 90.0, 180.0])
>>> deg * sd.pi / 180
array([               0.0, 1.5707963267948966,  3.141592653589793], dtype=float64)
>>> sd.cos(sd.pi)
-1.0
```

배열과 계산하면 배열이, Python 숫자와 계산하면 Python 숫자가 나와요.

```python
>>> sd.asarray([1, 2]) * sd.pi
array([3.141592653589793, 6.283185307179586], dtype=float64)
>>> r = 2.0
>>> sd.pi * r ** 2
12.566370614359172
```

### `e`: 자연상수

자연로그의 밑, 약 2.71828이에요. `sd.exp(x)`는 e의 x제곱이고, `sd.log`는 그 반대예요([지수와 로그](/api/array/exp-log/) 참고).

```python
>>> sd.exp(1.0) == sd.e
True
>>> sd.log(sd.asarray([1.0, sd.e, sd.e ** 2]))
array([0.0, 1.0, 2.0], dtype=float64)
```

e의 거듭제곱을 계산할 때는 `sd.e ** x`보다 `sd.exp(x)`를 쓰세요. 결과가 거의 같지만 `exp`가 더 정확해요.

### 정확히 그 값은 아니에요

π와 e는 끝없이 이어지는 수라서, 컴퓨터의 실수에는 **가장 가까운 근삿값**이 들어 있어요. 그래서 수학적으로 0이어야 할 `sin(π)`가 아주 작은 수로 나와요.

```python
>>> sd.sin(sd.pi)
1.2246467991473532e-16
```

잘못된 것이 아니라 실수 계산의 자연스러운 오차예요. 결과를 0과 비교해야 한다면 `== 0` 대신 "충분히 작은가"(`sd.abs(값) < 1e-12`)로 비교하세요.

## `inf`: 무한대

`sd.inf`는 어떤 실수보다 큰 값이에요. 음의 무한대는 `-sd.inf`예요. 실수 배열에 담을 수 있고, 비교도 기대대로 동작해요.

```python
>>> sd.inf > 1e308
True
>>> -sd.inf < -1e308
True
>>> sd.asarray([sd.inf, -sd.inf, 1.0])
array([ inf, -inf,  1.0], dtype=float64)
```

### 어디서 나오나요

계산 결과가 실수로 나타낼 수 있는 범위를 넘거나, 0이 아닌 수를 0으로 나누면 무한대가 돼요. stardust는 이때 에러를 내지 않아요.

```python
>>> sd.asarray([1.0, -1.0]) / 0
array([ inf, -inf], dtype=float64)
>>> sd.log(0.0)
-inf
>>> sd.finfo(sd.float64).max * 10
inf
```

<Callout type="warn" title="Python의 1 / 0은 에러예요">

배열 연산과 `sd` 함수는 0으로 나누면 `inf`를 주지만, Python 숫자끼리의 `/`는 Python 자신의 규칙대로 `ZeroDivisionError`예요. 무한대가 필요하면 `1.0 / 0` 대신 `sd.inf`를 쓰거나 `sd.divide`를 쓰세요.

```python
>>> 1.0 / 0
Traceback (most recent call last):
    ...
ZeroDivisionError: division by zero
>>> sd.divide(1.0, 0.0)
inf
```

</Callout>

### 어디에 쓰나요

"한쪽 경계가 없다"를 나타낼 때 편해요. 예를 들어 `clip`으로 아래쪽만 자르고 위쪽은 그대로 두려면 위 경계에 `sd.inf`를 줘요.

```python
>>> sd.clip(sd.asarray([-5.0, 0.5, 7.0]), min=0.0, max=sd.inf)
array([0.0, 0.5, 7.0], dtype=float64)
```

가장 작은 값을 찾아 나가는 반복문의 시작값으로도 자주 써요. 어떤 값과 비교해도 `sd.inf`보다는 작으니까요.

```python
>>> best = sd.inf
>>> for cost in [7.0, 3.0, 5.0]:
...     best = min(best, cost)
>>> best
3.0
```

### 무한대끼리의 계산

무한대에서 무한대를 빼거나, 무한대에 0을 곱한 결과는 정할 수 없어서 NaN이 돼요.

```python
>>> sd.inf - sd.inf
nan
>>> sd.inf * 0
nan
```

무한대인지 확인하려면 `sd.isinf`, 무한대도 NaN도 아닌 보통 수인지 확인하려면 `sd.isfinite`를 써요([특수값 판별](/api/array/isnan/) 참고).

```python
>>> sd.isinf(sd.asarray([sd.inf, -sd.inf, sd.nan, 1.0]))
array([ True,  True, False, False], dtype=bool)
>>> sd.isfinite(sd.asarray([sd.inf, -sd.inf, sd.nan, 1.0]))
array([False, False, False,  True], dtype=bool)
```

## `nan`: 숫자가 아님

NaN은 "숫자로 정할 수 없는 결과"를 나타내는 특별한 실수 값이에요. 0을 0으로 나누거나, 음수의 제곱근을 구하거나, 무한대에서 무한대를 빼면 나와요. stardust는 이런 계산에서 에러를 내지 않고 그 자리를 NaN으로 채워요.

```python
>>> sd.asarray([0.0]) / 0
array([nan], dtype=float64)
>>> sd.sqrt(sd.asarray([-1.0, 4.0]))
array([nan, 2.0], dtype=float64)
```

데이터에서 **빠진 값**이나 **잘못된 값**을 표시하는 데도 써요. 예를 들어 음수가 나오면 안 되는 측정값에서 음수를 NaN으로 바꿔 두는 식이에요.

```python
>>> x = sd.asarray([3.0, -1.0, 8.0])
>>> clean = sd.where(x < 0, sd.nan, x)
>>> clean
array([3.0, nan, 8.0], dtype=float64)
```

### NaN은 계산에 퍼져요

NaN이 섞인 계산의 결과는 NaN이에요. "모르는 값"에 무엇을 더해도 모르는 값이니까요. 그래서 NaN이 하나라도 있으면 합이나 평균도 NaN이 돼요.

```python
>>> sd.nan + 1
nan
>>> sd.mean(clean)
nan
```

NaN을 빼고 나머지로 계산하려면 이름이 `nan`으로 시작하는 함수를 써요([NaN을 건너뛰는 집계](/api/array/nan-reductions/) 참고).

```python
>>> sd.nanmean(clean)
5.5
```

### NaN은 자기 자신과도 같지 않아요

가장 흔한 함정이에요. NaN은 **어떤 값과 비교해도 같지 않아요.** 자기 자신과도요. 크기 비교(`<`, `>`)도 언제나 `False`예요.

```python
>>> sd.nan == sd.nan
False
>>> sd.nan != sd.nan
True
>>> sd.nan > 1
False
```

그래서 `== sd.nan`으로 NaN을 찾으면 **하나도 찾지 못해요.** 에러도 나지 않아서 알아채기 어려워요. NaN인지는 반드시 `sd.isnan`으로 확인하세요.

```python
>>> clean == sd.nan
array([False, False, False], dtype=bool)
>>> sd.isnan(clean)
array([False,  True, False], dtype=bool)
```

<Fig caption="== sd.nan은 NaN 자리에서도 False라서 아무것도 못 찾아요. isnan은 NaN 자리만 True예요.">
  <ArrayFig name="clean" data={['3.0', 'nan', '8.0']} tones={['', 'b', '']} />
  <Op note="== sd.nan">→</Op>
  <ArrayFig data={[false, false, false]} tones={['m', 'm', 'm']} note="모두 False" />
  <Op note="sd.isnan">→</Op>
  <ArrayFig data={[false, true, false]} tones={['m', 'b', 'm']} note="NaN 자리만 True" />
</Fig>

`isnan`의 결과를 마스크로 쓰면 NaN을 빼거나 다른 값으로 바꿀 수 있어요. NaN이 몇 개인지도 셀 수 있어요.

```python
>>> clean[~sd.isnan(clean)]
array([3.0, 8.0], dtype=float64)
>>> sd.where(sd.isnan(clean), 0.0, clean)
array([3.0, 0.0, 8.0], dtype=float64)
>>> sd.count_nonzero(sd.isnan(clean))
1
```

같은 이유로 "두 배열이 같은가"를 `==`로 확인하면 NaN이 있는 자리는 언제나 다르다고 나와요.

```python
>>> clean == clean
array([ True, False,  True], dtype=bool)
```

<Callout title="리스트의 in은 다르게 동작해요">

Python 리스트의 `in`은 값을 비교하기 전에 "같은 객체인가"를 먼저 봐요. 그래서 `sd.nan in [sd.nan]`은 `True`지만, 따로 만든 NaN이 든 리스트에서는 `False`예요. 이 차이에 기대지 말고 NaN 판별은 언제나 `sd.isnan`이나 `math.isnan`으로 하세요.

</Callout>

### 정수 배열에는 NaN을 담을 수 없어요

NaN과 무한대는 실수에만 있는 값이에요. 정수 배열에 넣으려 하면 `TypeError`예요. 빠진 값을 NaN으로 표시하려면 배열을 먼저 실수로 바꿔야 해요.

```python
>>> counts = sd.asarray([1, 2, 3])
>>> counts[0] = sd.nan
Traceback (most recent call last):
    ...
TypeError: cannot implicitly convert float64 to int64 (that would lose information); convert explicitly with astype
>>> counts = counts.astype(sd.float64)
>>> counts[0] = sd.nan
>>> counts
array([nan, 2.0, 3.0], dtype=float64)
```

반대로 실수 배열을 `astype`으로 정수로 바꾸면, NaN은 `0`, 무한대는 int64가 담을 수 있는 가장 큰(작은) 값이 돼요. 에러 없이 바뀌므로 바꾸기 전에 `isnan`, `isinf`로 확인해 두는 것이 좋아요.

```python
>>> sd.asarray([sd.nan, sd.inf, -sd.inf]).astype(sd.int64)
array([                   0,  9223372036854775807, -9223372036854775808], dtype=int64)
```

### 정렬과 최댓값에서의 NaN

`sd.sort`는 NaN을 가장 큰 값으로 보고 맨 끝에 놓아요. `sd.max`, `sd.min`은 NaN이 하나라도 있으면 NaN을 돌려줘요. NaN을 건너뛰려면 `sd.nanmax`, `sd.nanmin`을 써요.

```python
>>> sd.sort(sd.asarray([2.0, sd.nan, 1.0]))
array([1.0, 2.0, nan], dtype=float64)
>>> sd.min(sd.asarray([3.0, sd.nan, 1.0]))
nan
>>> sd.nanmin(sd.asarray([3.0, sd.nan, 1.0]))
1.0
```

## `newaxis`: 길이 1인 축 넣기

`sd.newaxis`는 대괄호 인덱싱 안에서 쓰는 표시예요. 그 자리에 **길이 1인 축을 새로 끼워 넣어요.** 값은 그대로이고 모양만 바뀌어요.

```python
>>> v = sd.asarray([1, 2, 3])
>>> v[:, sd.newaxis]
array([[1],
       [2],
       [3]], dtype=int64)
>>> v[sd.newaxis, :]
array([[1, 2, 3]], dtype=int64)
```

가장 많이 쓰는 곳은 [브로드캐스팅](/api/array/broadcasting/)이에요. 1차원 배열 하나를 세로로 세워 원래 배열과 계산하면 "모든 짝"의 결과가 표로 나와요. 아래는 모든 원소 쌍 사이의 거리예요.

```python
>>> sd.abs(v[:, sd.newaxis] - v)
array([[0, 1, 2],
       [1, 0, 1],
       [2, 1, 0]], dtype=int64)
```

여러 개를 쓰거나 다른 인덱스와 섞어 쓸 수도 있어요.

```python
>>> m = sd.zeros((2, 3))
>>> m[:, sd.newaxis, :].shape
(2, 1, 3)
>>> m[..., sd.newaxis].shape
(2, 3, 1)
>>> m[sd.newaxis, :, sd.newaxis].shape
(1, 2, 1, 3)
```

`sd.newaxis`는 `None`이라서 `v[:, None]`이라고 써도 똑같아요. 하지만 `sd.newaxis`라고 쓰면 "여기에 축을 넣는다"는 뜻이 코드에 드러나서 읽기 좋아요.

```python
>>> v[:, None].shape
(3, 1)
```

인덱싱의 다른 규칙은 [인덱싱과 대입](/api/array/indexing/)에 있어요. 축 번호로 축을 넣고 싶다면 `sd.expand_dims(v, axis=1)`도 같은 일을 해요.

## 조심할 점

### 상수는 배열이 아니에요

`sd.pi`, `sd.nan` 등은 Python `float`라서 그것만으로 계산하면 결과도 Python 숫자예요. 배열이 필요하면 배열과 함께 계산하거나 `sd.full`로 채운 배열을 만들어요.

```python
>>> type(sd.pi * 2)
<class 'float'>
>>> sd.full((2, 2), sd.nan)
array([[nan, nan],
       [nan, nan]], dtype=float64)
```

### NaN 판별은 `isnan`으로만

`x == sd.nan`, `x != sd.nan`은 원하는 결과를 주지 않아요. NaN인지 확인하는 방법은 `sd.isnan`(배열과 숫자 모두), Python 숫자 하나라면 `math.isnan`도 돼요.

### `newaxis`는 `None`과 구별되지 않아요

`sd.newaxis`가 `None` 그 자체이므로, `x[None]`도 축을 넣는 인덱싱이에요. 변수에 담긴 값이 우연히 `None`이면 에러 없이 축이 하나 생겨 버리니, 인덱스로 쓰는 변수가 `None`이 되지 않게 조심하세요.

```python
>>> idx = None
>>> v[idx].shape
(1, 3)
```

## 비슷한 기능과의 차이

| 하고 싶은 일 | 쓸 것 | 비고 |
|---|---|---|
| NaN인지 확인 | `sd.isnan(x)` | `x == sd.nan`은 언제나 False |
| 무한대인지 확인 | `sd.isinf(x)` | `+inf`, `-inf` 모두 True |
| 보통 수인지 확인 | `sd.isfinite(x)` | NaN과 무한대가 아니면 True |
| 가장 큰 유한한 실수 | `sd.finfo(sd.float64).max` | `sd.inf`와 달리 실제 수 |
| e의 거듭제곱 | `sd.exp(x)` | `sd.e ** x`보다 정확해요 |
| 길이 1인 축 넣기 (축 번호로) | `sd.expand_dims(x, axis=...)` | `x[..., sd.newaxis]`와 같은 일 |

`sd.pi`, `sd.e`는 Python 표준 라이브러리의 `math.pi`, `math.e`와 같은 값이고, `sd.inf`, `sd.nan`도 `math.inf`, `math.nan`, `float('inf')`, `float('nan')`과 같은 값이에요. 어느 것을 써도 결과는 같아요.

## numpy를 아는 분께

- 값과 타입은 numpy의 `np.e`, `np.pi`, `np.inf`, `np.nan`, `np.newaxis`와 같아요(Python `float`, `None`).
- 상수는 이 다섯뿐이에요. `NaN`, `NAN`, `Inf`, `PINF`, `NINF`, `NZERO`, `euler_gamma` 같은 별칭과 추가 상수는 없어요. 음의 무한대는 `-sd.inf`로 써요.
- stardust의 배열 연산은 0으로 나누기나 범위를 넘는 계산에서 **경고를 내지 않아요.** 조용히 `inf`나 `nan`이 돼요. numpy의 `errstate`에 해당하는 기능은 없어요.
