## 한눈에 보기

`asarray`는 리스트 같은 데이터를 stardust 배열(`sd.ndarray`)로 바꿔요. stardust의 거의 모든 함수는 stardust 배열만 받기 때문에, 계산을 시작하려면 먼저 데이터를 배열로 바꿔야 해요. 그래서 stardust를 쓸 때 가장 먼저, 가장 자주 부르는 함수예요.

```python
>>> import stardust as sd
>>> sd.asarray([1, 2, 3])
array([1, 2, 3], dtype=int64)
```

리스트 안에 리스트를 넣으면 2차원 배열이 돼요. 바깥 리스트의 원소 하나가 한 행이에요.

```python
>>> x = sd.asarray([[1, 2, 3], [4, 5, 6]])
>>> x
array([[1, 2, 3],
       [4, 5, 6]], dtype=int64)
>>> x.shape
(2, 3)
```

## 무엇을 넣을 수 있나요

`asarray`가 받는 것은 네 가지예요.

| 넣는 것 | 예 | 결과 |
|---|---|---|
| 리스트, 튜플 (중첩 가능) | `[1, 2, 3]`, `[(1, 2), (3, 4)]` | 값을 복사한 새 배열 |
| `range` | `range(4)` | `[0, 1, 2, 3]`을 담은 새 배열 |
| stardust 배열 | `sd.asarray(x)` | `x` 그 자신 (복사하지 않아요) |
| 메모리를 내어 주는 객체 | numpy 배열, `bytes`, `memoryview` | 가능하면 메모리를 함께 쓰는 배열 |

리스트와 튜플의 원소로는 Python의 `bool`, `int`, `float`, `complex`와 stardust 배열을 쓸 수 있어요. 아래 마지막 예처럼 배열을 담은 리스트는 그 배열을 하나씩 행으로 쌓은 배열이 돼요.

```python
>>> sd.asarray((1, 2))
array([1, 2], dtype=int64)
>>> sd.asarray(range(4))
array([0, 1, 2, 3], dtype=int64)
>>> rows = [sd.asarray([1, 2]), sd.asarray([3, 4])]
>>> sd.asarray(rows)
array([[1, 2],
       [3, 4]], dtype=int64)
```

반대로 문자열, `None`, 제너레이터 같은 것은 받지 않아요.

```python
>>> sd.asarray("abc")
Traceback (most recent call last):
    ...
TypeError: asarray(): cannot convert an object of type 'str' to an array
>>> sd.asarray([1, None])
Traceback (most recent call last):
    ...
TypeError: asarray(): cannot store an object of type 'NoneType' in an array (only bool, int, float and complex)
>>> sd.asarray(n * n for n in range(3))
Traceback (most recent call last):
    ...
TypeError: asarray(): cannot convert an object of type 'generator' to an array
```

- 문자열과 `None`: 배열은 숫자와 참·거짓만 담아요. 빠진 값이 있는 표 형태의 데이터는 데이터프레임(`sd.frame`)이 다뤄요.
- 제너레이터, 집합, 딕셔너리: 길이를 미리 알 수 없거나 순서가 없어서 받지 않아요. `list(...)`로 감싸서 넘기면 돼요.
- 리스트 안의 `range`: `range`는 맨 바깥에서만 받아요. `[range(3)]`처럼 리스트 안에 넣으면 `TypeError`예요.

## 원소 종류(dtype)는 어떻게 정해지나요

배열의 원소는 모두 같은 종류여야 해요. stardust 배열의 원소 종류(dtype)는 참·거짓을 담는 `sd.bool`, 정수를 담는 `sd.int64`, 실수를 담는 `sd.float64`, 복소수를 담는 `sd.complex128` 네 가지예요. 각각 Python의 `bool`, `int`, `float`, `complex`에 대응해요. 자세한 설명은 [원소 종류(dtype)](/api/array/dtypes/)에 있어요.

`dtype`을 주지 않으면 `asarray`가 원소를 모두 훑어보고, 그 가운데 가장 넓은 종류로 맞춰요. 좁은 쪽부터 `bool < int64 < float64 < complex128` 순서예요.

```python
>>> sd.asarray([True, False])
array([ True, False], dtype=bool)
>>> sd.asarray([True, 1])
array([1, 1], dtype=int64)
>>> sd.asarray([1, 2.5])
array([1.0, 2.5], dtype=float64)
>>> sd.asarray([1, 2.5, 1j])
array([  (1+0j), (2.5+0j),       1j], dtype=complex128)
```

<Fig caption="실수가 하나라도 섞이면 전체가 float64가 돼요. 정수 1은 실수 1.0으로 바뀌어 들어가요.">
  <ArrayFig name="[1, 2.5]" data={[1, 2.5]} tones={['', 'a']} note="int, float" />
  <Op>→</Op>
  <ArrayFig name="asarray" data={['1.0', '2.5']} tones={['a', 'a']} note="float64" />
</Fig>

<Callout type="warn" title="정수만 넣으면 정수 배열이에요">
  `sd.asarray([1, 2, 3])`은 int64 배열이에요. 여기에 나중에 `x[0] = 0.5`처럼 실수를 넣으려 하면 에러가 나요. 실수 계산에 쓸 배열이라면 `[1.0, 2.0, 3.0]`처럼 쓰거나 `dtype=sd.float64`를 주세요.
</Callout>

원소가 하나도 없으면 종류를 짐작할 근거가 없어서 float64로 정해요.

```python
>>> sd.asarray([])
array([], dtype=float64)
>>> sd.asarray([[]]).shape
(1, 0)
```

## `dtype`으로 종류 정하기

원하는 종류가 있으면 `dtype=`으로 직접 정해요. dtype 객체(`sd.float64`)나 그 이름(`"float64"`)을 쓸 수 있어요.

```python
>>> sd.asarray([1, 2, 3], dtype=sd.float64)
array([1.0, 2.0, 3.0], dtype=float64)
>>> sd.asarray([1, 2, 3], dtype="float64")
array([1.0, 2.0, 3.0], dtype=float64)
```

`dtype`을 직접 정하면 "값이 조금 달라져도 괜찮으니 이 종류로 바꿔 달라"는 뜻으로 받아요. 그래서 정보를 잃는 변환도 그대로 해요.

```python
>>> sd.asarray([1.7, -1.7], dtype=sd.int64)
array([ 1, -1], dtype=int64)
>>> sd.asarray([0, 2, -1, 0.0], dtype=sd.bool)
array([False,  True,  True, False], dtype=bool)
```

- 실수 → 정수: 소수점 아래를 버려요(0에 가까운 쪽으로). `1.7`은 `1`, `-1.7`은 `-1`이에요. 반올림이 아니에요.
- 무엇이든 → bool: 0이면 `False`, 0이 아니면 `True`예요.
- 정수로 바꿀 때 NaN(숫자가 아님)은 `0`이 되고, int64가 담을 수 없는 큰 값은 int64의 최댓값이나 최솟값이 돼요.

[`astype`](/api/array/astype/)과 같은 규칙이에요. 규칙 전체는 [원소 종류(dtype)](/api/array/dtypes/)에 정리돼 있어요.

다만 복소수를 실수나 정수로 바꾸는 변환은 해 주지 않아요. 허수부가 통째로 사라지기 때문이에요. 실수부가 필요하면 `sd.real`로 직접 꺼내요.

```python
>>> sd.asarray([1 + 0j], dtype=sd.float64)
Traceback (most recent call last):
    ...
TypeError: asarray(): cannot convert complex128 to float64: the imaginary part would be lost (take the real part explicitly)
```

`dtype`에는 위의 네 가지만 쓸 수 있어요. Python의 `float`나 `"float32"` 같은 다른 이름은 받지 않아요.

```python
>>> sd.asarray([1, 2], dtype=float)
Traceback (most recent call last):
    ...
TypeError: asarray(): 'dtype' must be sd.bool, sd.int64, sd.float64 or sd.complex128 (or their names), not float
```

## 복사할까요, 함께 쓸까요

이미 stardust 배열인 것을 넣으면 `asarray`는 새 배열을 만들지 않고 받은 것을 그대로 돌려줘요. 이름 *as array*에 담긴 "배열로 본다"는 뜻 그대로예요.

```python
>>> x = sd.asarray([1.0, 2.0, 3.0])
>>> y = sd.asarray(x)
>>> y is x
True
```

`y`와 `x`가 같은 배열이므로, `y`를 고치면 `x`도 바뀌어요. 이 성질 덕분에 배열일 수도, 리스트일 수도 있는 입력을 받는 함수의 첫 줄에 `x = sd.asarray(x)`를 부담 없이 쓸 수 있어요. 이미 배열이면 비용이 들지 않아요.

복사할지 말지는 `copy` 인자로 정해요.

| `copy` | 뜻 |
|---|---|
| `None` (기본값) | 꼭 필요할 때만 복사해요. |
| `True` | 언제나 복사해요. 결과를 고쳐도 원본은 그대로예요. |
| `False` | 절대 복사하지 않아요. 복사 없이는 안 되면 `ValueError`예요. |

```python
>>> z = sd.asarray(x, copy=True)
>>> z is x
False
>>> z[0] = 99.0
>>> x
array([1.0, 2.0, 3.0], dtype=float64)
```

<Callout type="tip" title="배열을 복사하는 방법">
  stardust에는 `array`나 `copy` 함수가 따로 없어요. 독립된 복사본이 필요하면 `sd.asarray(x, copy=True)`나 메서드 `x.copy()`를 써요.
</Callout>

`copy=None`일 때 복사가 꼭 필요한 경우는 넣는 것에 따라 달라요.

- 리스트, 튜플, `range`: 언제나 복사해요. Python 객체를 배열의 메모리로 옮겨 적어야 하기 때문이에요. 그래서 `copy=False`는 에러예요.
- stardust 배열: `dtype`이 같으면 복사하지 않아요. 다른 `dtype`을 요청하면 변환한 새 배열을 만들어요.
- numpy 배열 등: 원소 종류가 stardust와 같으면 복사하지 않아요. 다음 절에서 설명해요.

메모리를 함께 쓰는 배열과 복사본의 차이는 [뷰와 복사](/api/array/views/)에 자세히 있어요.

```python
>>> sd.asarray([1, 2], copy=False)
Traceback (most recent call last):
    ...
ValueError: asarray(): copy=False, but a list or tuple can only be converted by copying
>>> sd.asarray(x, dtype=sd.int64, copy=False)
Traceback (most recent call last):
    ...
ValueError: asarray(): copy=False, but a dtype conversion requires a copy
```

## numpy 배열 가져오기

numpy 배열을 넣으면 `asarray`는 될 수 있으면 메모리를 복사하지 않고 그대로 빌려 써요. 큰 데이터도 거의 비용 없이 가져와요.

```python
>>> import numpy as np
>>> n = np.array([1.0, 2.0, 3.0])
>>> a = sd.asarray(n)
>>> a
array([1.0, 2.0, 3.0], dtype=float64)
```

메모리를 함께 쓰기 때문에 한쪽을 고치면 다른 쪽에서도 보여요.

```python
>>> n[0] = 99.0
>>> a
array([99.0,  2.0,  3.0], dtype=float64)
>>> a.base is n
True
```

<Fig caption="a는 자기 메모리가 없어요. n의 메모리를 들여다보는 창이에요. a.base가 그 주인을 알려 줘요.">
  <ArrayFig name="n (numpy)" data={['99.0', '2.0', '3.0']} tones={['b', '', '']} note="메모리의 주인" />
  <Op note="같은 메모리">⇄</Op>
  <ArrayFig name="a (stardust)" data={['99.0', '2.0', '3.0']} tones={['b', 'g', 'g']} note="a.base is n" />
</Fig>

메모리를 빌려 쓸 수 있는 것은 numpy 배열의 원소 종류가 stardust의 네 종류와 정확히 같을 때예요. 그 밖의 종류는 값을 잃지 않고 넓힐 수 있으면 복사하면서 바꾸고, 그럴 수 없으면 받지 않아요.

| numpy의 종류 | 처리 |
|---|---|
| `bool`, `int64`, `float64`, `complex128` | 복사 없이 메모리를 함께 써요. |
| `int8`·`int16`·`int32`, `uint8`·`uint16`·`uint32` | 값을 잃지 않으므로 int64로 넓혀서 복사해요. |
| `float16`·`float32` | float64로 넓혀서 복사해요. |
| `complex64` | complex128로 넓혀서 복사해요. |
| `uint64`, 문자열, 날짜 등 | `TypeError`예요. |

```python
>>> small = np.array([1, 2], dtype=np.int32)
>>> sd.asarray(small)
array([1, 2], dtype=int64)
>>> sd.asarray(small, copy=False)
Traceback (most recent call last):
    ...
ValueError: asarray(): copy=False, but this buffer can only be converted by copying
```

`uint64`는 들어 있는 값이 작더라도 받지 않아요. int64가 담을 수 없는 값이 있을 수 있는 종류이기 때문이에요. numpy 쪽에서 `n.astype(np.int64)`로 먼저 바꿔서 넘기세요.

```python
>>> sd.asarray(np.array([1, 2], dtype=np.uint64))
Traceback (most recent call last):
    ...
TypeError: asarray(): uint64 buffers cannot be converted to int64 without loss
```

numpy 배열이 읽기 전용이면 그 메모리를 빌려 쓰는 stardust 배열도 읽기 전용이에요. 값을 고치려 하면 `ValueError`가 나요.

<Callout title="반대 방향: stardust 배열을 numpy로">
  `np.asarray(a)`를 쓰면 돼요. 이쪽도 복사 없이 메모리를 함께 써요.
</Callout>

## 조심할 점

### 숫자 하나는 배열이 될 수 없어요

stardust에는 차원이 0인 배열이 없고, 숫자 하나는 Python 숫자로 다뤄요([배열의 기본](/api/array/basics/) 참고). 그래서 숫자 하나를 `asarray`에 넣으면 에러예요.

```python
>>> sd.asarray(5)
Traceback (most recent call last):
    ...
ValueError: asarray(): 0-dimensional arrays are not supported: a scalar is already the result (stardust has no 0-d arrays)
```

원소가 하나뿐인 배열을 원하면 리스트로 감싸세요.

```python
>>> sd.asarray([5])
array([5], dtype=int64)
```

### 줄마다 길이가 같아야 해요

배열은 반듯한 직사각형 모양이어야 해요. 행마다 길이가 다르면 `ValueError`예요.

```python
>>> sd.asarray([[1, 2], [3]])
Traceback (most recent call last):
    ...
ValueError: asarray(): inhomogeneous nested sequence: expected every level to match shape (2, 2)
```

### 아주 큰 정수

int64는 약 ±9.2 × 10¹⁸까지 담아요. Python의 `int`는 그보다 큰 수도 다루지만, 정수 배열에는 담을 수 없어서 `OverflowError`가 나요.

```python
>>> sd.asarray([2**70])
Traceback (most recent call last):
    ...
OverflowError: asarray(): Python int too large to convert to int64
```

같은 리스트에 실수가 섞여 있으면 결과가 float64 배열이라서 문제가 없어요. 큰 정수는 가장 가까운 실수로 바뀌어 들어가요.

```python
>>> sd.asarray([2**70, 0.5])
array([1.1805916207174113e+21,                    0.5], dtype=float64)
```

실수로도 담을 수 없을 만큼 큰 정수(약 $1.8 \times 10^{308}$ 이상)는 float64 배열에도 넣을 수 없어서 `OverflowError`예요.

```python
>>> sd.asarray([10**400, 0.5])
Traceback (most recent call last):
    ...
OverflowError: asarray(): Python int too large to convert to float64
```

### 함수에 리스트를 바로 넘길 수는 없어요

stardust의 계산 함수는 리스트를 알아서 배열로 바꿔 주지 않아요. 먼저 `asarray`로 바꿔서 넘겨요.

```python
>>> sd.sum([1, 2, 3])
Traceback (most recent call last):
    ...
TypeError: sum(): 'x' must be an sd.ndarray, not list
>>> sd.sum(sd.asarray([1, 2, 3]))
6
```

함수가 리스트를 조용히 받아 주면 편해 보이지만, 그때마다 보이지 않는 변환과 복사가 일어나요. 변환을 `asarray` 한 곳에서만 하면 그 자리가 코드에 드러나요.

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 |
|---|---|
| 이미 있는 데이터를 배열로 바꾸기 | `asarray` |
| 0이나 1, 정한 값으로 채운 새 배열 만들기 | [`zeros`, `ones`, `full`](/api/array/filled/) |
| 일정한 간격의 수열 만들기 | [`arange`](/api/array/arange/), [`linspace`](/api/array/linspace/) |
| 이미 있는 배열의 원소 종류만 바꾸기 | [`astype`](/api/array/astype/) |
| 배열의 독립된 복사본 만들기 | `x.copy()` 또는 `asarray(x, copy=True)` |
| PyTorch, JAX 등 다른 라이브러리의 배열 가져오기 | [`from_dlpack`](/api/array/from_dlpack/) |

`asarray(x, dtype=...)`과 `astype(x, ...)`은 둘 다 종류를 바꾸지만 종류가 이미 같을 때의 기본 동작이 달라요. `astype`은 언제나 새 배열을 만들고, `asarray`는 받은 배열을 그대로 돌려줘요.

## numpy를 아는 분께

- `np.array`에 해당하는 함수는 없고 `asarray` 하나만 있어요. `np.array(x)`처럼 언제나 복사하려면 `copy=True`를 주세요.
- 숫자 하나(`np.asarray(5)`)는 0차원 배열이 되지 않고 에러예요.
- dtype은 네 가지뿐이에요. `int32`나 `float32` 배열은 가져올 때 int64, float64로 넓어져요.
- 문자열, `None`, 임의의 객체를 담는 `object` 배열은 없어요.
- 줄 길이가 다른 리스트는 numpy처럼 `ValueError`예요.
