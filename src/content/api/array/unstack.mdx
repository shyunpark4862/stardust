## 한눈에 보기

`unstack`은 배열을 한 축을 따라 한 장씩 떼어 내서 tuple에 담아 돌려줘요. 기본값 `axis=0`은 2차원 배열을 행마다 나눠요.

```python
>>> import stardust as sd
>>> m = sd.asarray([[1, 2, 3], [4, 5, 6]])
>>> sd.unstack(m)
(array([1, 2, 3], dtype=int64), array([4, 5, 6], dtype=int64))
```

`axis=1`이면 열마다 나눠요.

```python
>>> sd.unstack(m, axis=1)
(array([1, 4], dtype=int64), array([2, 5], dtype=int64), array([3, 6], dtype=int64))
```

조각의 수는 나누는 축의 길이와 같고, 각 조각은 원래 모양에서 그 축을 뺀 모양이에요. `(2, 3)`을 `axis=1`로 나누면 길이 2인 1차원 배열 세 개가 나와요.

## 언제 쓰나요

가장 흔하게는 열을 하나씩 따로 변수에 나눠 받을 때 써요. 결과가 tuple이라 여러 변수에 한 번에 풀어 담을 수 있어요.

```python
>>> points = sd.asarray([[0, 0], [1, 2], [3, 5]])
>>> xs, ys = sd.unstack(points, axis=1)
>>> xs
array([0, 1, 3], dtype=int64)
>>> ys
array([0, 2, 5], dtype=int64)
```

`(점 개수, 2)` 모양의 점 목록에서 x 좌표와 y 좌표를 따로 꺼냈어요. `points[:, 0]`, `points[:, 1]`로 하나씩 꺼내도 같지만, 열이 많을수록 `unstack` 한 줄이 간단해요.

반복문에 쓸 수도 있어요. 3차원 배열을 "표 여러 장"으로 보고 한 장씩 처리하는 식이에요.

```python
>>> t = sd.reshape(sd.arange(8), (2, 2, 2))
>>> for page in sd.unstack(t):
...     print(sd.sum(page))
6
22
```

## `stack`의 반대예요

[`stack`](/api/array/concat/)은 같은 모양의 배열 여러 개를 새 축을 따라 쌓고, `unstack`은 한 축을 따라 나눠서 그 축을 없애요. 같은 `axis`로 나눴다가 다시 쌓으면 원래 배열이 돼요.

```python
>>> parts = sd.unstack(m, axis=1)
>>> sd.stack(parts, axis=1)
array([[1, 2, 3],
       [4, 5, 6]], dtype=int64)
```

`unstack`의 결과는 tuple이라 `stack`에 그대로 넘길 수 있어요. 조각 몇 개만 고르거나 순서를 바꾼 다음 다시 쌓을 수도 있어요.

```python
>>> c0, c1, c2 = sd.unstack(m, axis=1)
>>> sd.stack([c2, c0], axis=1)
array([[3, 1],
       [6, 4]], dtype=int64)
```

## 조각은 원본과 메모리를 함께 써요

조각은 값을 복사한 것이 아니라 원본의 일부를 보여 주는 **뷰**예요. 조각을 고치면 원본도 바뀌어요.

```python
>>> r0, r1 = sd.unstack(m)
>>> r0.base is m
True
>>> r0[0] = 100
>>> m
array([[100,   2,   3],
       [  4,   5,   6]], dtype=int64)
```

독립된 조각이 필요하면 각 조각에 `.copy()`를 쓰세요. 뷰는 [뷰와 복사](/api/array/views/)에서 자세히 다뤄요.

뒤의 예제를 위해 값을 되돌려 둘게요.

```python
>>> m[0, 0] = 1
```

## 조심할 점

### 1차원 배열은 숫자로 나뉘어요

stardust에는 차원이 0인 배열이 없어요. 1차원 배열을 나누면 각 조각은 축이 하나도 남지 않으므로, 배열 대신 Python 숫자가 돼요.

```python
>>> sd.unstack(sd.asarray([1, 2, 3]))
(1, 2, 3)
>>> type(sd.unstack(sd.asarray([1.5, 2.5]))[0])
<class 'float'>
```

숫자는 원본과 이어져 있지 않아요. 받은 값을 바꿔도 원본은 그대로예요.

### 반복문만 필요하다면 배열을 그대로 돌려도 돼요

첫 축을 따라 하나씩 꺼내는 것은 `for row in m`으로도 돼요. 결과는 `sd.unstack(m)`과 같아요. `unstack`은 다른 축을 따라 나누거나, 조각을 tuple로 받아 두어야 할 때 쓰세요.

```python
>>> for row in m:
...     print(row.tolist())
[1, 2, 3]
[4, 5, 6]
```

### 길이 0인 축

나누는 축의 길이가 0이면 빈 tuple이 나와요.

```python
>>> sd.unstack(sd.zeros((0, 3)))
()
```

### `axis`는 정수 하나, 이름을 붙여서

`axis`에는 int 하나만 써요. 한 번에 여러 축을 따라 나눌 수는 없어요. `sd.unstack(m, 1)`처럼 자리로 넘기면 `TypeError`이고, 범위를 벗어난 축 번호는 `ValueError`예요.

```python
>>> sd.unstack(m, axis=(0,))
Traceback (most recent call last):
    ...
TypeError: unstack(): 'axis' must be an int, not tuple
>>> sd.unstack(m, axis=2)
Traceback (most recent call last):
    ...
ValueError: unstack(): axis 2 is out of bounds for an array of dimension 2
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 한 축을 따라 한 장씩 나누기 | `unstack` | 나눈 축이 조각에서 사라져요. |
| 한 장만 꺼내기 | 인덱싱 `m[i]`, `m[:, j]` | 조각 하나만 필요할 때는 이쪽이 간단해요. |
| 원하는 구간으로 자르기 | 슬라이싱 `m[:, 1:3]` | 축이 남아요. 몇 개씩 묶어 자를 수 있어요. |
| 조각을 다시 쌓기 | `stack` | `unstack`의 반대예요. |
| 조각을 길게 잇기 | `concat` | 새 축을 만들지 않아요. |

`m[:, 0:1]`처럼 길이 1인 구간으로 자르면 축이 남아서 `(2, 1)` 모양이 되지만, `unstack`의 조각은 축이 빠진 `(2,)` 모양이에요. 열을 세로 모양 그대로 두고 싶다면 슬라이싱을, 1차원 벡터로 받고 싶다면 `unstack`이나 `m[:, 0]`을 쓰세요. 인덱싱과 슬라이싱은 [인덱싱과 대입](/api/array/indexing/)에 자세히 있어요.

## numpy를 아는 분께

- numpy 2.1의 `np.unstack`과 같아요. 조각은 뷰예요.
- 1차원 배열의 조각은 Python 숫자예요. numpy는 0차원 배열을 돌려줘요.
- `axis`는 keyword-only이고 int만 받아요.
- `np.split`, `np.array_split`, `np.hsplit` 같은 나누기 함수는 없어요. 구간을 정해 자르려면 슬라이싱을 쓰세요.
