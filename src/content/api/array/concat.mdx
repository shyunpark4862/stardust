## 한눈에 보기

두 함수 모두 배열 여러 개를 하나로 합쳐요. 차이는 **차원이 그대로인가, 하나 늘어나는가**예요.

- `concat`은 이미 있는 축을 따라 **길게 이어요.** 차원 수는 그대로예요.
- `stack`은 **새 축을 하나 만들어** 그 축을 따라 쌓아요. 차원 수가 하나 늘어요.

길이 3인 1차원 배열 두 개로 비교해 볼게요.

```python
>>> import stardust as sd
>>> p = sd.asarray([1, 2, 3])
>>> q = sd.asarray([4, 5, 6])
>>> sd.concat([p, q])
array([1, 2, 3, 4, 5, 6], dtype=int64)
>>> sd.stack([p, q])
array([[1, 2, 3],
       [4, 5, 6]], dtype=int64)
```

<Fig caption="concat은 뒤에 이어서 길이 6인 1차원 배열을, stack은 위아래로 쌓아서 2행 3열짜리 2차원 배열을 만들어요.">
  <ArrayFig name="p" data={[1, 2, 3]} tones={['a', 'a', 'a']} />
  <ArrayFig name="q" data={[4, 5, 6]} tones={['b', 'b', 'b']} />
  <Op note="concat">→</Op>
  <ArrayFig data={[1, 2, 3, 4, 5, 6]} tones={['a', 'a', 'a', 'b', 'b', 'b']} note="shape (6,)" />
  <Op note="stack">→</Op>
  <ArrayFig data={[[1, 2, 3], [4, 5, 6]]} tones={[['a', 'a', 'a'], ['b', 'b', 'b']]} note="shape (2, 3)" />
</Fig>

두 함수 모두 배열들을 **list나 tuple 하나로 묶어서** 넘겨요. `sd.concat(p, q)`가 아니라 `sd.concat([p, q])`예요.

## `concat`: 있는 축을 따라 잇기

`axis`로 어느 축을 따라 이을지 골라요. 기본값 `axis=0`은 2차원에서 **아래로 이어 붙이기**(행 추가)예요.

```python
>>> a = sd.asarray([[1, 2], [3, 4]])
>>> b = sd.asarray([[5, 6]])
>>> sd.concat([a, b])
array([[1, 2],
       [3, 4],
       [5, 6]], dtype=int64)
```

`axis=1`은 **옆으로 이어 붙이기**(열 추가)예요.

```python
>>> c = sd.asarray([[7], [8]])
>>> sd.concat([a, c], axis=1)
array([[1, 2, 7],
       [3, 4, 8]], dtype=int64)
```

<Fig caption="axis=0이면 행이 늘어나고(2행 + 1행 = 3행), axis=1이면 열이 늘어나요(2열 + 1열 = 3열).">
  <ArrayFig name="concat([a, b])" data={[[1, 2], [3, 4], [5, 6]]} tones={[['a', 'a'], ['a', 'a'], ['b', 'b']]} note="(2, 2) + (1, 2) → (3, 2)" />
  <ArrayFig name="concat([a, c], axis=1)" data={[[1, 2, 7], [3, 4, 8]]} tones={[['a', 'a', 'b'], ['a', 'a', 'b']]} note="(2, 2) + (2, 1) → (2, 3)" />
</Fig>

### 모양 규칙

이어 붙이는 축의 길이는 달라도 돼요. 결과에서는 그 축의 길이가 모두 더해져요. 대신 **이어 붙이는 축 밖의 길이는 모두 같아야** 해요. 아래로 이으려면 열 수가, 옆으로 이으려면 행 수가 같아야 해요.

```python
>>> sd.concat([a, b], axis=1)
Traceback (most recent call last):
    ...
ValueError: concat(): all arrays must have the same shape except along axis 1; got (2, 2) and (1, 2)
```

`a`는 2행, `b`는 1행이라 옆으로 나란히 놓을 수 없어요.

차원 수도 같아야 해요. 1차원 배열을 2차원 배열에 행으로 붙이려면, 먼저 `(1, n)` 모양으로 만들어 줘야 해요.

```python
>>> sd.concat([a, sd.asarray([9, 9])])
Traceback (most recent call last):
    ...
ValueError: concat(): all arrays must have the same shape except along axis 0; got (2, 2) and (2,)
>>> sd.concat([a, sd.expand_dims(sd.asarray([9, 9]), axis=0)])
array([[1, 2],
       [3, 4],
       [9, 9]], dtype=int64)
```

길이 1인 축을 넣는 방법은 [길이 1인 축 넣고 빼기](/api/array/squeeze/)에 있어요.

### `axis=None`: 모두 펴서 한 줄로

`axis=None`을 주면 각 배열을 행 순서로 **한 줄로 편 다음** 이어요. 이때는 모양이 서로 달라도 상관없어요.

```python
>>> sd.concat([a, c], axis=None)
array([1, 2, 3, 4, 7, 8], dtype=int64)
>>> sd.concat([a, sd.asarray([9, 9])], axis=None)
array([1, 2, 3, 4, 9, 9], dtype=int64)
```

## `stack`: 새 축을 만들어 쌓기

`stack`은 같은 모양의 배열 여러 개를 **새 축을 따라** 쌓아요. 배열 `n`개를 쌓으면 그 새 축의 길이가 `n`이 돼요. `axis`는 **결과에서 새 축이 놓일 자리**예요.

```python
>>> sd.stack([p, q], axis=0)
array([[1, 2, 3],
       [4, 5, 6]], dtype=int64)
>>> sd.stack([p, q], axis=1)
array([[1, 4],
       [2, 5],
       [3, 6]], dtype=int64)
```

<Fig caption="axis=0은 각 배열이 한 행이 되고, axis=1은 각 배열이 한 열이 돼요.">
  <ArrayFig name="stack(axis=0)" data={[[1, 2, 3], [4, 5, 6]]} tones={[['a', 'a', 'a'], ['b', 'b', 'b']]} note="shape (2, 3)" />
  <ArrayFig name="stack(axis=1)" data={[[1, 4], [2, 5], [3, 6]]} tones={[['a', 'b'], ['a', 'b'], ['a', 'b']]} note="shape (3, 2)" />
</Fig>

`axis=1`은 실제로 자주 써요. x 좌표와 y 좌표가 따로 있을 때 `(점 개수, 2)` 모양의 점 목록으로 묶을 수 있어요.

```python
>>> xs = sd.asarray([0.0, 1.0, 2.0])
>>> ys = sd.asarray([5.0, 7.0, 9.0])
>>> sd.stack([xs, ys], axis=1)
array([[0.0, 5.0],
       [1.0, 7.0],
       [2.0, 9.0]], dtype=float64)
```

2차원 배열을 쌓으면 3차원이 돼요. 같은 크기의 표 여러 장을 한 묶음으로 만들 때 써요.

```python
>>> sd.stack([a, a, a]).shape
(3, 2, 2)
>>> sd.stack([a, a, a], axis=2).shape
(2, 2, 3)
```

### 모양 규칙

`stack`은 `concat`보다 엄격해요. **모든 배열의 모양이 완전히 같아야** 해요. 쌓는다는 것은 같은 크기의 판을 겹쳐 놓는 일이라, 한 장이라도 크기가 다르면 안 돼요.

```python
>>> sd.stack([p, sd.asarray([4, 5])])
Traceback (most recent call last):
    ...
ValueError: stack(): all arrays must have the same shape; got (3,) and (2,)
```

결과는 차원이 하나 늘어나므로 `axis`는 결과 배열을 기준으로 세요. 1차원 배열을 쌓으면 결과가 2차원이라 `axis`는 0, 1(또는 -1, -2)을 쓸 수 있어요.

```python
>>> sd.stack([p, q], axis=2)
Traceback (most recent call last):
    ...
ValueError: stack(): axis 2 is out of bounds for an array of dimension 2
```

## `concat`과 `stack`, 무엇을 쓸까요

| 구분 | `concat` | `stack` |
|---|---|---|
| 차원 수 | 그대로 | 하나 늘어나요 |
| 모양 조건 | 이어 붙이는 축 밖의 길이만 같으면 돼요 | 모양이 완전히 같아야 해요 |
| `axis`의 뜻 | 입력 배열의 축 | 결과 배열에서 새 축의 자리 |
| `axis=None` | 모두 펴서 한 줄로 이어요 | 받지 않아요 |
| `(3,)` 두 개 | `(6,)` | `(2, 3)` |
| `(2, 2)` 두 개 | `(4, 2)` | `(2, 2, 2)` |

헷갈릴 때는 이렇게 생각하면 쉬워요. **같은 종류의 데이터를 뒤에 더 붙이는** 일이면 `concat`이에요(1월 기록 뒤에 2월 기록 잇기). **따로 있던 것들을 묶어 한 덩어리로 만드는** 일이면 `stack`이에요(키 배열과 몸무게 배열을 한 표의 두 열로 묶기).

사실 `stack`은 "각 배열에 길이 1인 축을 넣은 다음 `concat`"과 같아요.

```python
>>> sd.concat([sd.expand_dims(p, axis=0), sd.expand_dims(q, axis=0)])
array([[1, 2, 3],
       [4, 5, 6]], dtype=int64)
```

<Callout type="tip" title="여러 줄을 하나씩 모을 때">

  반복문 안에서 결과를 하나씩 만들어 모을 때는, 매번 `concat`으로 붙이지 말고 Python 리스트에 담아 두었다가 마지막에 한 번만 `sd.stack(rows)`나 `sd.concat(rows)`를 부르세요. 매번 붙이면 그때마다 전체를 새로 복사해서 아주 느려져요.

</Callout>

## 결과의 dtype

원소 종류가 다른 배열을 합치면 **가장 넓은 종류**로 맞춰요. 넓이의 순서는 `bool < int64 < float64 < complex128`이에요.

```python
>>> sd.concat([p, sd.asarray([0.5])])
array([1.0, 2.0, 3.0, 0.5], dtype=float64)
>>> sd.concat([p, sd.asarray([True, False])])
array([1, 2, 3, 1, 0], dtype=int64)
```

정수 배열에 실수가 하나만 섞여도 결과 전체가 실수예요. 특히 원소가 없는 `sd.asarray([])`는 float64라서, 정수 배열과 이으면 결과가 실수가 돼요.

```python
>>> sd.concat([p, sd.asarray([])])
array([1.0, 2.0, 3.0], dtype=float64)
```

## 결과는 언제나 새 배열이에요

두 함수 모두 원소를 옮겨 담은 **새 배열**을 만들어요. 배열이 하나뿐이어도 복사해요. 결과를 고쳐도 입력 배열은 바뀌지 않아요.

```python
>>> joined = sd.concat([p])
>>> joined[0] = 100
>>> p
array([1, 2, 3], dtype=int64)
```

## 조심할 점

### 배열은 list나 tuple로 묶어서

`arrays`에는 **`sd.ndarray`만 담은 list나 tuple**을 넘겨요. 배열을 따로따로 넘기거나, 배열 하나를 통째로 넘기거나, 제너레이터를 넘기면 에러예요.

```python
>>> sd.concat(p, q)
Traceback (most recent call last):
    ...
TypeError: concat(): incompatible function arguments. The following argument types are supported:
    ...
>>> sd.concat(a)
Traceback (most recent call last):
    ...
TypeError: concat(): 'arrays' must be a list or tuple of sd.ndarray, not ndarray
>>> sd.concat(r for r in [p, q])
Traceback (most recent call last):
    ...
TypeError: concat(): 'arrays' must be a list or tuple of sd.ndarray, not generator
```

목록 안에 리스트나 숫자가 섞여도 안 돼요. 먼저 `sd.asarray`로 바꾸세요.

```python
>>> sd.concat([p, [4, 5]])
Traceback (most recent call last):
    ...
TypeError: concat(): 'arrays' must hold sd.ndarray only, not list
>>> sd.concat([p, sd.asarray([4, 5])])
array([1, 2, 3, 4, 5], dtype=int64)
```

빈 목록은 합칠 것이 없어서 `ValueError`예요. 결과의 모양과 dtype을 정할 수 없기 때문이에요.

```python
>>> sd.stack([])
Traceback (most recent call last):
    ...
ValueError: stack(): need at least one array
```

### `axis`는 정수 하나, 이름을 붙여서

`axis`에는 int 하나만 써요. tuple은 받지 않고, `stack`은 `None`도 받지 않아요. `sd.concat([a, b], 1)`처럼 자리로 넘기는 것도 안 돼요.

```python
>>> sd.concat([a, b], axis=(0,))
Traceback (most recent call last):
    ...
TypeError: concat(): 'axis' must be an int, not tuple
>>> sd.stack([p, q], axis=None)
Traceback (most recent call last):
    ...
TypeError: stack(): 'axis' must be an int, not NoneType
```

### 브로드캐스팅은 없어요

원소끼리 계산하는 함수와 달리, 이어 붙이는 함수는 길이 1인 축을 늘려 주지 않아요. 모양이 규칙대로 정확히 맞아야 해요. 예를 들어 `(2, 2)` 배열 옆에 같은 값으로 된 열을 붙이려면 그 열을 `(2, 1)` 모양으로 직접 만들어야 해요. 필요하면 [`broadcast_to`](/api/array/broadcast_to/)로 늘린 다음 붙이세요.

```python
>>> sd.concat([a, sd.broadcast_to(sd.asarray([[0]]), (2, 1))], axis=1)
array([[1, 2, 0],
       [3, 4, 0]], dtype=int64)
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 있는 축을 따라 잇기 | `concat` | 차원 수 그대로 |
| 새 축을 만들어 쌓기 | `stack` | 차원 수 하나 늘어남 |
| 쌓인 배열을 다시 나누기 | `unstack` | `stack`의 반대예요. 배열들의 tuple을 돌려줘요. |
| 같은 배열을 여러 번 이어 붙이기 | `tile` | 배열 하나를 되풀이해요. |
| 원소마다 여러 번 되풀이 | `repeat` | `[1, 1, 2, 2]`처럼 원소 단위로 되풀이해요. |

[`unstack`](/api/array/unstack/)은 `stack`의 반대예요. `sd.stack(sd.unstack(x, axis=k), axis=k)`는 `x`와 같은 배열이 돼요. 같은 배열을 이어 붙이는 일은 `concat([x, x, x])`로도 되지만 [`tile`](/api/array/repeat/)이 더 간단해요.

## numpy를 아는 분께

- `concat`은 numpy의 `np.concatenate`(numpy 2의 `np.concat`)에 해당해요.
- **`arrays`는 `sd.ndarray`의 list나 tuple만** 받아요. 리스트가 섞이거나 제너레이터를 넘기면 `TypeError`예요.
- `axis`는 keyword-only예요. `np.concatenate([a, b], 1)`처럼 자리로 넘길 수 없어요.
- `out=`, `dtype=`, `casting=` 인자는 없어요. dtype은 언제나 승격 규칙대로 정해져요.
- `np.vstack`, `np.hstack`, `np.dstack`, `np.column_stack`, `np.block`은 없어요. 아래로 잇기는 `concat(..., axis=0)`, 옆으로 잇기는 `concat(..., axis=1)`, 1차원 배열들을 열로 묶기는 `stack(..., axis=1)`로 써요.
- `np.split` 계열은 없어요. 축을 따라 하나씩 나누는 것은 `unstack`, 원하는 구간으로 자르는 것은 슬라이싱으로 해요.
