## 한눈에 보기

`maximum`은 두 배열을 같은 자리끼리 비교해서 큰 값을, `minimum`은 작은 값을 골라요. 결과는 입력과 같은 모양의 배열이에요.

```python
>>> import stardust as sd
>>> a = sd.asarray([1, 5, 3])
>>> b = sd.asarray([4, 2, 3])
>>> sd.maximum(a, b)
array([4, 5, 3], dtype=int64)
>>> sd.minimum(a, b)
array([1, 2, 3], dtype=int64)
```

## 숫자 하나와 비교하기: 아래나 위를 막기

한쪽에 숫자 하나를 주면 "이 값보다 작아지지 않게"(`maximum`), "이 값보다 커지지 않게"(`minimum`) 막는 효과가 나요.

```python
>>> x = sd.asarray([-3.0, 2.0, -0.5, 7.0])
>>> sd.maximum(x, 0.0)
array([0.0, 2.0, 0.0, 7.0], dtype=float64)
>>> sd.minimum(x, 5.0)
array([-3.0,  2.0, -0.5,  5.0], dtype=float64)
```

`maximum(x, 0)`은 "음수는 0으로, 양수는 그대로"예요. 이름이 반대로 느껴질 수 있으니 주의하세요. <strong>아래를 막을 때 `maximum`, 위를 막을 때 `minimum`</strong>을 써요. "0과 비교해서 큰 쪽을 고르면, 0보다 작은 값은 0이 된다"고 생각하면 헷갈리지 않아요.

| 하고 싶은 일 | 쓸 것 |
|---|---|
| 0보다 작아지지 않게 | `sd.maximum(x, 0)` |
| 100보다 커지지 않게 | `sd.minimum(x, 100)` |
| 0과 100 사이로 | `sd.minimum(sd.maximum(x, 0), 100)` 또는 `sd.clip(x, min=0, max=100)` |

아래와 위를 함께 막는 일은 [`clip`](/api/array/clip/)이 한 번에 해 줘요.

### 모양이 다른 두 배열

모양이 다르면 [브로드캐스팅](/api/array/broadcasting/) 규칙으로 맞춰요. 행마다 아래 한계를 다르게(첫 행 3, 둘째 행 5) 준 예예요.

```python
>>> m = sd.asarray([[1, 5, 2], [4, 3, 6]])
>>> sd.maximum(m, sd.asarray([[3], [5]]))
array([[3, 5, 3],
       [5, 5, 6]], dtype=int64)
```

모양을 맞출 수 없으면 `ValueError`예요.

```python
>>> sd.maximum(a, sd.asarray([1, 2]))
Traceback (most recent call last):
    ...
ValueError: maximum(): shapes could not be broadcast together: (3,) (2,)
```

## `max`와 헷갈리지 마세요

이름이 비슷한 [`max`](/api/array/min-max/)는 다른 일을 해요.

- `sd.maximum(a, b)`는 **두 배열**을 같은 자리끼리 비교해요. 결과의 크기는 입력과 같아요.
- `sd.max(a)`는 **배열 하나** 안에서 가장 큰 값을 찾아요. 결과는 값 하나(또는 축을 줄인 배열)예요.

```python
>>> sd.max(m)
6
>>> sd.max(m, axis=0)
array([4, 5, 6], dtype=int64)
>>> sd.maximum(m[0], m[1])
array([4, 5, 6], dtype=int64)
```

둘째와 셋째의 결과가 같은 것은 우연이 아니에요. `max(m, axis=0)`은 "열마다 위아래 원소 중 가장 큰 것"인데, 행이 둘뿐이면 "첫 행과 둘째 행을 자리마다 비교한 큰 값"과 같아요. 결과는 같아도 하는 일은 달라요. `max`는 배열 하나를 한 방향으로 줄이고, `maximum`은 두 배열을 같은 자리끼리 비교해요.

<Fig caption="max(m, axis=0)은 배열 하나를 열마다 줄여요. 진한 칸이 열마다 가장 큰 값이에요.">
  <ArrayFig name="m" data={[[1, 5, 2], [4, 3, 6]]} tones={[['', 'b', ''], ['b', '', 'b']]} axes />
  <Op note="max, axis=0">→</Op>
  <ArrayFig name="sd.max(m, axis=0)" data={[4, 5, 6]} tones={['b', 'b', 'b']} />
</Fig>

| | `sd.maximum(a, b)` | `sd.max(a)` |
|---|---|---|
| 받는 배열 | 두 개 | 한 개 |
| 하는 일 | 같은 자리끼리 비교 | 배열 안에서 가장 큰 값 찾기 |
| 결과의 크기 | 입력과 같음 | 값 하나, 또는 `axis`만큼 줄어든 배열 |
| 옵션 | `out` | `axis`, `keepdims` |
| 비슷한 짝 | `add` (두 배열을 더하기) | `sum` (배열 하나를 다 더하기) |

`sd.max(a, b)`처럼 `max`에 배열 두 개를 넣거나, `sd.maximum(a)`처럼 `maximum`에 배열 하나만 넣으면 `TypeError`예요. 에러가 나면 둘 중 어느 것이 필요한지 다시 생각해 보세요.

### Python의 `max`와도 달라요

Python 내장 함수 `max`도 이름이 같지만, 배열에 쓰면 뜻대로 되지 않아요. 두 배열을 넣으면 `TypeError`이고, 1차원 배열 하나를 넣으면 답은 나오지만 원소를 하나씩 꺼내서 비교하므로 느려요. 2차원 배열에는 에러가 나요.

```python
>>> max(a, b)
Traceback (most recent call last):
    ...
TypeError: the truth value of an array is ambiguous; use any() or all()
>>> max(m)
Traceback (most recent call last):
    ...
TypeError: the truth value of an array is ambiguous; use any() or all()
```

배열에는 언제나 `sd.maximum`이나 `sd.max`를 쓰세요.

## 입력과 결과의 종류

결과의 dtype은 두 입력의 dtype을 승격한 것, 곧 둘을 모두 담을 수 있는 쪽으로 맞춘 것이에요. 정수와 실수를 섞으면 실수가 돼요.

```python
>>> sd.maximum(a, 2.5)
array([2.5, 5.0, 3.0], dtype=float64)
```

| `x1`, `x2` | 결과 |
|---|---|
| bool, bool | bool |
| bool, int64 | int64 |
| int64, int64 | int64 |
| int64, float64 | float64 |
| complex128가 섞임 | `TypeError` |

bool끼리는 bool로 남아요. `False`를 `True`보다 작은 값으로 보므로, bool의 `maximum`은 "하나라도 참", `minimum`은 "둘 다 참"과 같아요.

```python
>>> t = sd.asarray([True, False, False])
>>> u = sd.asarray([False, False, True])
>>> sd.maximum(t, u)
array([ True, False,  True], dtype=bool)
```

복소수에는 크고 작음이 없어서 `TypeError`예요. 크기로 비교하고 싶다면 `sd.abs`로 크기를 먼저 구하세요.

```python
>>> sd.maximum(sd.asarray([1j]), 0)
Traceback (most recent call last):
    ...
TypeError: maximum(): not supported for complex128 and int64
```

두 입력이 모두 Python 숫자면 결과도 Python 숫자예요.

```python
>>> sd.maximum(3, 7)
7
>>> sd.maximum(3, 7.0)
7.0
```

## `out`: 결과를 기존 배열에 쓰기

`out=`에 배열을 주면 그 배열에 결과를 적어요. 입력과 같은 배열을 줘도 돼요. "음수를 0으로"를 제자리에서 하려면 이렇게 써요.

```python
>>> y = sd.asarray([-2, 3, -1])
>>> sd.maximum(y, 0, out=y)
array([0, 3, 0], dtype=int64)
>>> y
array([0, 3, 0], dtype=int64)
```

결과의 dtype이 `out`의 dtype으로 손실 없이 바뀔 수 있어야 해요. 정수 배열에 실수 결과를 담을 수는 없어요.

```python
>>> sd.maximum(y, 0.5, out=y)
Traceback (most recent call last):
    ...
TypeError: maximum(): cannot implicitly convert float64 to int64 (that would lose information); convert explicitly with astype
```

## 조심할 점

### NaN이 있으면 결과도 NaN이에요

두 값 중 하나라도 NaN(숫자가 아님)이면 그 자리의 결과는 NaN이에요. "모르는 값과 비교한 결과는 모른다"는 뜻이에요. NaN이 아닌 쪽을 골라 주지 않아요.

```python
>>> p = sd.asarray([1.0, sd.nan, 3.0, sd.nan])
>>> q = sd.asarray([2.0, 0.0, sd.nan, sd.nan])
>>> sd.maximum(p, q)
array([2.0, nan, nan, nan], dtype=float64)
```

NaN을 무시하고 나머지 한쪽을 고르고 싶다면 [`isnan`](/api/array/isnan/)과 [`where`](/api/array/where/)로 직접 골라요. 둘 다 NaN인 자리만 NaN으로 남아요.

```python
>>> sd.where(sd.isnan(p), q, sd.where(sd.isnan(q), p, sd.maximum(p, q)))
array([2.0, 0.0, 3.0, nan], dtype=float64)
```

배열 하나에서 NaN을 빼고 가장 큰 값을 찾는 일은 [`nanmax`](/api/array/nan-reductions/)가 해요.

### `0.0`과 `-0.0`

실수에는 `0.0`과 `-0.0`이 따로 있어요. 값으로는 같지만(`0.0 == -0.0`은 참), 부호가 달라요. stardust는 두 0을 비교할 때 `-0.0`을 더 작은 쪽으로 쳐요. 그래서 넣는 순서와 상관없이 `maximum`은 `0.0`, `minimum`은 `-0.0`을 돌려줘요.

```python
>>> sd.maximum(0.0, -0.0)
0.0
>>> sd.maximum(-0.0, 0.0)
0.0
>>> sd.minimum(0.0, -0.0)
-0.0
```

부호는 보통 눈에 띄지 않지만, 그 0으로 나누면 차이가 드러나요.

```python
>>> 1 / sd.maximum(sd.asarray([-0.0]), 0.0)
array([inf], dtype=float64)
>>> 1 / sd.minimum(sd.asarray([0.0]), -0.0)
array([-inf], dtype=float64)
```

Python 내장 `max(-0.0, 0.0)`은 두 값을 같다고 보고 먼저 나온 `-0.0`을 돌려줘요. 순서에 따라 결과가 바뀌는 셈이에요. `sd.maximum`은 순서에 영향을 받지 않아요.

### 리스트는 받지 않아요

입력은 배열이나 Python 숫자여야 해요. 리스트는 먼저 [`asarray`](/api/array/asarray/)로 바꾸세요.

```python
>>> sd.maximum(a, [1, 2, 3])
Traceback (most recent call last):
    ...
TypeError: maximum(): 'x2' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `maximum`과 다른 점 |
|---|---|---|
| 배열 안에서 가장 큰 값 | `max`, `min` | 배열 하나를 줄여요. |
| 가장 큰 값의 위치 | `argmax`, `argmin` | 값 대신 위치를 돌려줘요. |
| NaN을 빼고 가장 큰 값 | `nanmax`, `nanmin` | 배열 하나를 줄이면서 NaN을 건너뛰어요. |
| 아래와 위를 함께 막기 | `clip` | `minimum(maximum(x, lo), hi)`를 한 번에 해요. |
| 조건에 따라 고르기 | `where` | 크기 비교가 아닌 어떤 조건으로도 고를 수 있어요. |
| 어느 쪽이 큰지만 알기 | `greater` (`>`) | 값 대신 참·거짓을 돌려줘요. |

## numpy를 아는 분께

- NaN은 numpy의 `maximum`, `minimum`처럼 결과로 퍼져요. NaN을 무시하는 `fmax`, `fmin`은 없어요. 대신 `where`와 `isnan`을 쓰세요.
- `maximum(0.0, -0.0)`은 순서와 상관없이 `0.0`, `minimum`은 `-0.0`으로 정해져 있어요.
- 복소수는 `TypeError`예요. numpy처럼 사전순으로 비교하지 않아요.
- `maximum.reduce` 같은 ufunc 메서드는 없어요. `sd.max`를 쓰세요.
- `out`은 keyword-only이고 `where=` 인자는 없어요. 입력이 모두 Python 숫자면 결과는 Python 숫자예요.
