## 한눈에 보기

- **`any`**: 참인 원소가 **하나라도** 있으면 `True`
- **`all`**: **모든** 원소가 참이면 `True`

주로 비교 연산의 결과(bool 배열)와 함께 써요. 네 사람의 점수가 있을 때, 60점 미만이 한 명이라도 있는지, 모두 50점 이상인지 물어볼게요.

```python
>>> import stardust as sd
>>> scores = sd.asarray([72, 85, 58, 91])
>>> scores < 60
array([False, False,  True, False], dtype=bool)
>>> sd.any(scores < 60)
True
>>> sd.all(scores >= 50)
True
```

결과는 평범한 Python `bool`이라서 `if` 문에 바로 쓸 수 있어요.

```python
>>> if sd.any(scores < 60):
...     print("재시험 대상이 있어요")
재시험 대상이 있어요
```

### 왜 `any`와 `all`이 필요할까요

배열을 `if` 문에 그대로 넣으면 에러가 나요. `scores < 60`은 원소 네 개짜리 배열인데, 그것이 "참"인지는 "하나라도 참이면 참"으로 볼지 "모두 참이어야 참"으로 볼지에 따라 달라지기 때문이에요. stardust는 짐작하지 않고 에러를 내요. 에러 메시지도 `any()`나 `all()`을 쓰라고 알려 줘요.

```python
>>> bool(scores < 60)
Traceback (most recent call last):
    ...
TypeError: the truth value of an array is ambiguous; use any() or all()
```

## `axis`: 행마다, 열마다 검사하기

`axis`를 주면 그 방향으로만 검사해요. `axis`와 `keepdims`의 뜻은 [`sum`](/api/array/sum/)과 똑같아요(자세한 것은 [배열의 기본](/api/array/basics/)).

```python
>>> b = sd.asarray([[True, False, True], [True, True, True]])
>>> sd.all(b, axis=1)
array([False,  True], dtype=bool)
>>> sd.any(b, axis=0)
array([True, True, True], dtype=bool)
```

```python
>>> b.all(axis=0)
array([ True, False,  True], dtype=bool)
```

## 무엇을 참으로 볼까요

`any`와 `all`은 bool 배열만 받는 것이 아니에요. **어떤 dtype이든 받고, 0이 아닌 값을 참으로** 봐요. 기준은 모든 dtype에서 `x != 0` 하나예요.

| dtype | 거짓인 값 | 참인 값 |
|---|---|---|
| bool | `False` | `True` |
| int64 | `0` | 0이 아닌 모든 정수(음수 포함) |
| float64 | `0.0`, `-0.0` | 0이 아닌 모든 실수, `inf`, **NaN** |
| complex128 | `0j` | 실수부나 허수부 중 하나라도 0이 아닌 값 |

```python
>>> sd.any(sd.asarray([0, 0, 3]))
True
>>> sd.all(sd.asarray([1, 2, -3]))
True
>>> sd.all(sd.asarray([0.5, 0.0]))
False
>>> sd.any(sd.asarray([0j, 0j]))
False
```

### NaN은 참이에요

NaN(숫자가 아님)은 0이 아니므로 **참**이에요. "모르는 값이니 거짓"이라고 생각하기 쉬운데 그렇지 않아요.

```python
>>> sd.any(sd.asarray([0.0, -0.0, sd.nan]))
True
>>> sd.all(sd.asarray([sd.nan, 1.0]))
True
```

## 빈 배열: `any`는 False, `all`은 True

원소가 하나도 없으면 `any`는 `False`, `all`은 `True`예요. 에러가 아니에요.

```python
>>> sd.any(sd.asarray([]))
False
>>> sd.all(sd.asarray([]))
True
```

`all`이 `True`인 것이 이상해 보일 수 있어요. 이렇게 생각해 보세요. `all`은 "거짓인 원소가 **하나도 없는가**"를 묻는 것과 같아요. 빈 배열에는 거짓인 원소가 하나도 없으니 `True`예요. 마찬가지로 `any`는 "참인 원소가 하나라도 있는가"라서 빈 배열이면 `False`예요. 이렇게 정해 두면 배열을 둘로 나눠 각각 검사한 다음 합쳐도 결과가 같다는 규칙이 한쪽이 비어 있을 때도 지켜져요.

<Callout type="warn" title="비어 있으면 all은 그냥 통과해요">

조건으로 걸러 낸 배열에 `all`을 쓸 때, 걸러 낸 결과가 비어 있으면 검사할 것도 없이 `True`가 나와요. "모든 값이 올바르다"고 믿기 전에 원소가 실제로 있었는지(`.size`)도 확인하세요.

</Callout>

축을 따라 검사할 때 그 축의 길이가 0이어도 같은 규칙이에요.

```python
>>> sd.all(sd.zeros((2, 0)), axis=1)
array([True, True], dtype=bool)
>>> sd.any(sd.zeros((2, 0)), axis=1)
array([False, False], dtype=bool)
```

## NaN이 하나라도 있는지 확인하기

데이터에 NaN이 섞여 있는지 확인하는 일은 아주 흔해요. 이때는 [`isnan`](/api/array/isnan/)으로 NaN인 자리를 `True`로 표시한 다음 `any`를 써요.

```python
>>> v = sd.asarray([1.0, sd.nan, 3.0])
>>> sd.isnan(v)
array([False,  True, False], dtype=bool)
>>> sd.any(sd.isnan(v))
True
```

행마다 NaN이 있는지도 같은 방법으로 알 수 있어요.

```python
>>> m = sd.asarray([[1.0, 2.0], [sd.nan, 4.0]])
>>> sd.any(sd.isnan(m), axis=1)
array([False,  True], dtype=bool)
```

<Callout type="warn" title="x == nan으로는 NaN을 찾을 수 없어요">

NaN은 자기 자신을 포함해 어떤 값과도 같지 않아요. 그래서 `v == sd.nan`은 언제나 모두 `False`이고, `sd.any(v == sd.nan)`은 NaN이 있어도 `False`예요. NaN은 반드시 `sd.isnan`으로 찾으세요.

</Callout>

```python
>>> sd.any(v == sd.nan)
False
```

`inf`까지 포함해서 "모든 값이 평범한 숫자인가"를 확인하려면 `sd.all(sd.isfinite(v))`를 써요.

```python
>>> sd.all(sd.isfinite(v))
False
```

## 조심할 점

### Python의 `any`, `all`과 헷갈리지 마세요

Python에는 내장 함수 `any`, `all`이 따로 있어요. 1차원 배열에서는 답이 같지만, 원소를 하나씩 꺼내서 보기 때문에 훨씬 느려요. 2차원 배열에서는 행을 하나씩 꺼내서 참·거짓을 물어보므로 위에서 본 에러가 나요.

```python
>>> any(sd.asarray([0, 0, 3]))
True
>>> any(b)
Traceback (most recent call last):
    ...
TypeError: the truth value of an array is ambiguous; use any() or all()
```

배열에는 언제나 `sd.any`, `sd.all`(또는 `x.any()`, `x.all()`)을 쓰세요.

### 옵션의 타입

`axis`, `keepdims`는 이름을 붙여서 써야 하고, `keepdims`에는 `True`나 `False`만 쓸 수 있어요.

```python
>>> sd.any(b, keepdims=1)
Traceback (most recent call last):
    ...
TypeError: any(): 'keepdims' must be True or False, not int
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `any`·`all`과 다른 점 |
|---|---|---|
| 참인 원소가 **몇 개**인지 | `count_nonzero` | 있는지 없는지가 아니라 개수를 세요. |
| 참인 원소가 **어디** 있는지 | `nonzero` | 참인 자리를 모두 돌려줘요. |
| 두 배열을 자리마다 "그리고"·"또는" | `logical_and`, `logical_or` | 배열을 줄이지 않고 같은 자리끼리 계산해요. |
| 두 배열이 모든 자리에서 같은지 | `sd.all(a == b)` | `==`로 자리마다 비교한 다음 `all`로 묶어요. |

`sd.logical_and(a, b)`는 **두 배열의 같은 자리끼리** "그리고"를 계산해서 같은 모양의 배열을 돌려주고, `sd.all(x)`는 **배열 하나의 원소들을** "그리고"로 묶어서 줄여요. [`logical_and`, `logical_or`](/api/array/logical/)를 참고하세요.

```python
>>> sd.logical_and(sd.asarray([True, False]), sd.asarray([True, True]))
array([ True, False], dtype=bool)
```

## numpy를 아는 분께

- 0이 아닌 값을 참으로 보고 NaN이 참인 것은 numpy와 같아요.
- 모든 축을 검사한 결과는 `np.bool_`이 아니라 Python `bool`이에요.
- `out=`, `where=` 인자는 없어요. `axis`, `keepdims`는 keyword-only예요.
- 배열에 `bool()`을 쓰면 원소가 하나뿐이어도 언제나 `TypeError`예요. numpy는 원소가 하나면 받아 줘요.
