## 한눈에 보기

`max`는 배열에서 **가장 큰 값**을, `min`은 **가장 작은 값**을 찾아요. 아무 옵션 없이 부르면 모든 원소 가운데 하나를 돌려줘요.

```python
>>> import stardust as sd
>>> t = sd.asarray([[3, 7, 1], [8, 2, 5]])
>>> sd.max(t)
8
>>> sd.min(t)
1
```

`axis`를 주면 그 방향으로만 찾아요. 2차원 배열에서 `axis=0`은 **열마다**, `axis=1`은 **행마다**의 결과예요.

```python
>>> sd.max(t, axis=0)
array([8, 7, 5], dtype=int64)
>>> sd.max(t, axis=1)
array([7, 8], dtype=int64)
```

<Fig caption="axis=0이면 열마다, axis=1이면 행마다 가장 큰 값을 골라요.">

  <Op note="axis=0">→</Op>
  <ArrayFig name="sd.max(t, axis=0)" data={[8, 7, 5]} tones={['b', 'b', 'b']} note="shape (3,)" />

같은 일을 하는 메서드도 있어요.

```python
>>> t.min(axis=0)
array([3, 2, 1], dtype=int64)
```

가장 큰 값과 가장 작은 값의 차이(범위)도 바로 구할 수 있어요.

```python
>>> sd.max(t) - sd.min(t)
7
```

## `axis`와 `keepdims`

`axis`와 `keepdims`의 뜻은 [`sum`](/api/array/sum/)과 똑같아요. `axis`는 "줄여서 없앨 축"이고, tuple이나 list로 여러 축을 한꺼번에 줄일 수 있어요. `keepdims=True`면 줄인 축이 길이 1로 남아요. 자세한 설명은 `sum` 문서와 [배열의 기본](/api/array/basics/)에 있어요.

`keepdims=True`는 결과를 원래 배열과 다시 계산할 때 쓸모가 있어요. 예를 들어 각 행의 값을 "그 행의 최솟값은 0, 최댓값은 1"이 되게 고쳐 볼게요.

```python
>>> lo = sd.min(t, axis=1, keepdims=True)
>>> hi = sd.max(t, axis=1, keepdims=True)
>>> (t - lo) / (hi - lo)
array([[0.3333333333333333,                1.0,                0.0],
       [               1.0,                0.0,                0.5]], dtype=float64)
```

`lo`와 `hi`가 `(2, 1)` 모양으로 남아 있어서 `t`의 각 행과 짝이 맞아요. 이유는 [브로드캐스팅](/api/array/broadcasting/)에 있어요.

## 결과의 dtype

결과는 **입력과 같은 dtype**이에요. 실수 배열이면 실수, 정수 배열이면 정수, bool 배열이면 bool이에요. 모든 축으로 찾으면 Python 숫자(`bool`, `int`, `float`)가 나와요.

```python
>>> sd.max(sd.asarray([2.5, -1.0, 7.25]))
7.25
>>> sd.max(sd.asarray([True, False]))
True
```

bool에서는 `False`가 `True`보다 작아요. 그래서 bool 배열의 `max`는 "하나라도 참인가", `min`은 "모두 참인가"와 같은 답을 내요. 다만 그 뜻이라면 [`any`와 `all`](/api/array/any-all/)을 쓰는 편이 읽기 쉬워요.

## `max`와 `maximum`은 달라요

이름이 비슷해서 가장 많이 헷갈리는 짝이에요.

- **`sd.max(x)`**: 배열 **하나** 안에서 가장 큰 값을 찾아요. 배열이 줄어들어요.
- **[`sd.maximum(a, b)`](/api/array/maximum/)**: 배열 **두 개**의 같은 자리끼리 비교해서 큰 쪽을 골라요. 모양이 그대로예요.

```python
>>> a = sd.asarray([1, 5, 3])
>>> b = sd.asarray([4, 2, 6])
>>> sd.maximum(a, b)
array([4, 5, 6], dtype=int64)
>>> sd.max(a)
5
```

  <ArrayFig name="sd.max(a)" data={[5]} tones={['b']} note="Python 숫자 5" />

`sd.max(a, b)`처럼 배열을 두 개 넘기면 `TypeError`예요. `sd.max`는 배열 하나만 받고, 나머지 옵션은 이름을 붙여야 하기 때문이에요. 에러 메시지는 `max(): incompatible function arguments.`로 시작하고, 받을 수 있는 인자의 목록을 보여 줘요. 두 배열을 비교하려던 것이라면 `sd.maximum`을 쓰세요.

`maximum`은 배열과 숫자를 비교할 수도 있어요. "4보다 작은 값은 4로 올린다" 같은 일에 써요.

```python
>>> sd.maximum(t, 4)
array([[4, 7, 4],
       [8, 4, 5]], dtype=int64)
```

### Python의 `max`, `min`과도 달라요

Python에는 내장 함수 `max`, `min`이 따로 있어요. 1차원 배열에는 내장 `max`를 써도 답이 나오지만, 원소를 하나씩 꺼내서 비교하기 때문에 훨씬 느려요.

```python
>>> max(sd.asarray([1, 5, 3]))
5
```

2차원 배열에서는 에러가 나요. 내장 `max`는 배열을 **행 단위로** 꺼내서 서로 비교하려 하는데, 행끼리 비교한 결과(bool 배열)를 참·거짓 하나로 볼 수 없기 때문이에요. 내장 `max(a, b)`로 두 배열을 비교하려 해도 같은 에러예요.

```python
>>> max(t)
Traceback (most recent call last):
    ...
TypeError: the truth value of an array is ambiguous; use any() or all()
>>> max(a, b)
Traceback (most recent call last):
    ...
TypeError: the truth value of an array is ambiguous; use any() or all()
```

배열에는 언제나 `sd.max`·`sd.min`(배열 하나 안에서)이나 `sd.maximum`·`sd.minimum`(두 배열 사이)을 쓰세요.

## 조심할 점

### 빈 배열에서는 에러예요

`sum`의 빈 배열은 `0`, `prod`는 `1`이지만, `max`와 `min`에는 그런 "시작값"이 없어요. 비교할 원소가 하나도 없으면 가장 큰 값도 정할 수 없어서 `ValueError`예요.

```python
>>> sd.max(sd.asarray([]))
Traceback (most recent call last):
    ...
ValueError: max(): undefined for an empty array (or along an empty axis)
```

축을 따라 찾을 때도, 줄일 축의 길이가 0이면 에러예요. 모양 `(2, 0)`인 배열에서 `axis=1`로 찾으면 두 행 모두 비교할 원소가 없어요.

```python
>>> sd.min(sd.zeros((2, 0)), axis=1)
Traceback (most recent call last):
    ...
ValueError: min(): undefined for an empty array (or along an empty axis)
```

반대로 **결과 자체가 비어 있으면** 에러가 아니에요. 모양 `(0, 3)`인 배열에서 `axis=1`로 찾으면, 행이 하나도 없으니 답할 자리도 없어서 빈 배열이 나와요.

```python
>>> sd.max(sd.zeros((0, 3)), axis=1)
array([], dtype=float64)
```

<Callout type="warn" title="걸러 낸 결과가 비면 에러가 나요">

조건으로 걸러 낸 배열(`v[v > 100]` 같은)의 최댓값을 구할 때, 맞는 원소가 하나도 없으면 `ValueError`가 나요. 비어 있을 수 있는 배열이라면 크기(`.size`)가 0인지 먼저 확인하세요.

</Callout>

### NaN이 하나라도 있으면

NaN(숫자가 아님)은 다른 값과 크기를 비교할 수 없어요. 그래서 NaN이 하나라도 있으면 `max`와 `min`의 결과도 NaN이에요.

```python
>>> v = sd.asarray([1.0, sd.nan, 3.0])
>>> sd.max(v)
nan
>>> sd.min(v)
nan
```

NaN을 빼고 찾으려면 [`nanmax`, `nanmin`](/api/array/nan-reductions/)을 써요.

```python
>>> sd.nanmax(v)
3.0
```

### 복소수는 받지 않아요

복소수에는 크고 작음이 없어요. 복소수 배열을 넣으면 `TypeError`예요.

```python
>>> z = sd.asarray([3 + 4j, 1 - 1j])
>>> sd.max(z)
Traceback (most recent call last):
    ...
TypeError: max(): not supported for complex128
```

크기(원점에서의 거리)가 가장 큰 값을 찾으려던 것이라면 `sd.abs`로 크기를 먼저 구해요.

```python
>>> sd.max(sd.abs(z))
5.0
```

### 옵션은 이름을 붙여서

`axis`와 `keepdims`는 이름과 함께 써야 해요. `sd.max(t, 0)`이 아니라 `sd.max(t, axis=0)`이에요. 숫자를 자리로 넘기면 위에서 본 것과 같은 `TypeError`가 나요.

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `max`·`min`과 다른 점 |
|---|---|---|
| 가장 큰·작은 값이 **어디** 있는지 | `argmax`, `argmin` | 값이 아니라 위치를 돌려줘요. |
| 두 배열을 자리마다 비교해 큰·작은 쪽 고르기 | `maximum`, `minimum` | 배열 둘을 받아서 같은 모양의 배열을 돌려줘요. |
| 값을 범위 안으로 자르기 | `clip` | 범위를 벗어난 값을 경계값으로 바꿔요. |
| NaN을 빼고 찾기 | `nanmax`, `nanmin` | NaN을 건너뛰어요. |
| 큰 값 몇 개를 차례로 | `sort` | 전부를 늘어놓아요. 하나만 필요하면 `max`가 훨씬 빨라요. |

[`argmax`, `argmin`](/api/array/argmin/)은 짝을 이루는 함수예요. 가장 큰 값이 몇 번째 원소인지가 궁금하면 그쪽을 보세요.

## numpy를 아는 분께

- 이름은 `min`, `max`뿐이에요. `amin`, `amax`라는 별칭은 없어요.
- `initial=` 인자가 없어서 빈 배열(또는 길이 0인 축)은 언제나 `ValueError`예요. `out=`, `where=`도 없어요.
- 복소수는 numpy처럼 사전순으로 비교하지 않고 `TypeError`예요.
- NaN은 numpy처럼 퍼져요.
- `axis`, `keepdims`는 keyword-only예요. 모든 축으로 찾은 결과는 Python 숫자예요.
