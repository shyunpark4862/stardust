## 한눈에 보기

두 벡터의 **내적**(dot product)은 같은 자리의 값끼리 곱해서 모두 더한 수예요. `vecdot`은 이 내적을 계산해요.

```python
>>> import stardust as sd
>>> u = sd.asarray([1.0, 2.0, 3.0])
>>> v = sd.asarray([4.0, 5.0, 6.0])
>>> sd.vecdot(u, v)
32.0
```

`1×4 + 2×5 + 3×6 = 32`예요. 1차원 배열끼리면 남는 축이 없어서 결과는 Python 숫자예요.

`vecdot`은 2차원 이상에서 더 쓸모가 있어요. 배열을 **벡터 여러 개를 모아 둔 것**으로 보고, 같은 자리의 벡터끼리 내적을 **한꺼번에** 계산해요. 기본값 `axis=-1`은 마지막 축을 따라 내적해요. 2차원 배열이라면 **행마다**예요.

```python
>>> m = sd.asarray([[3.0, 4.0], [1.0, 0.0], [0.0, 2.0]])
>>> n = sd.asarray([[1.0, 1.0], [2.0, 5.0], [1.0, 3.0]])
>>> sd.vecdot(m, n)
array([7.0, 2.0, 6.0], dtype=float64)
```

`sd.sum(m * n, axis=-1)`과 같은 값이에요. `vecdot`은 곱한 중간 배열을 따로 만들지 않아요.

## `axis`: 어느 방향의 벡터끼리

`axis`는 **내적해서 없앨 축**이에요. `axis=0`이면 **열마다** 내적해요.

```python
>>> sd.vecdot(m, n, axis=0)
array([ 5.0, 10.0], dtype=float64)
```

`3×1 + 1×2 + 0×1 = 5`, `4×1 + 0×5 + 2×3 = 10`이에요. 결과의 모양은 원래 모양에서 `axis`번째 숫자를 지운 것이에요. `(3, 2)`에서 첫째를 지우면 `(2,)`, 둘째를 지우면 `(3,)`이에요.

`axis`에는 정수 하나만 쓸 수 있어요. 여러 축을 한꺼번에 줄이고 싶으면 [tensordot](/api/array/tensordot/)이나 `sd.sum(x1 * x2, axis=(...))`을 쓰세요.

## 모양이 다른 두 배열

두 배열의 모양이 달라도 [브로드캐스팅](/api/array/broadcasting/)으로 맞출 수 있으면 계산해요. 예를 들어 벡터 하나를 행렬의 **모든 행과** 내적할 수 있어요.

```python
>>> w = sd.asarray([1.0, 1.0])
>>> sd.vecdot(m, w)
array([7.0, 1.0, 2.0], dtype=float64)
```

`w`가 세 행 모두에 쓰여서 행마다의 합이 나왔어요. 각 행이 상품의 판매 개수이고 `w`가 가격이라면, 결과는 행마다의 매출이에요.

<Callout type="warn" title="내적하는 축은 늘어나지 않아요">

다른 축은 브로드캐스팅되지만, **내적하는 축 자체는 두 배열에서 길이가 정확히 같아야** 해요. 한쪽 길이가 1이어도 늘려 주지 않아요.

</Callout>

```python
>>> sd.vecdot(m, sd.asarray([1.0, 1.0, 1.0]))
Traceback (most recent call last):
    ...
ValueError: vecdot(): 'x1' and 'x2' must have the same size along the axis, got 2 and 3
>>> sd.vecdot(sd.asarray([[1.0, 2.0]]), sd.asarray([[1.0], [1.0]]))
Traceback (most recent call last):
    ...
ValueError: vecdot(): 'x1' and 'x2' must have the same size along the axis, got 2 and 1
```

첫째 예는 행의 길이가 2인데 길이 3인 벡터를 줬어요. 열마다 내적하려던 것이라면 `axis=0`을 주세요.

## 쓰임새: 길이와 각도

벡터를 자기 자신과 내적하면 **길이의 제곱**이 나와요. 각 행을 점의 좌표로 보면, 원점에서 각 점까지의 거리를 한 번에 구할 수 있어요.

```python
>>> sd.vecdot(m, m)
array([25.0,  1.0,  4.0], dtype=float64)
>>> sd.sqrt(sd.vecdot(m, m))
array([5.0, 1.0, 2.0], dtype=float64)
```

점 `(3, 4)`까지의 거리는 5예요. 두 벡터의 내적을 두 길이의 곱으로 나누면 **방향이 얼마나 비슷한지**(코사인 유사도)가 나와요. 1이면 같은 방향, 0이면 직각이에요.

```python
>>> e = sd.asarray([1.0, 0.0])
>>> sd.vecdot(m, e) / sd.sqrt(sd.vecdot(m, m))
array([0.6, 1.0, 0.0], dtype=float64)
```

가로축 방향 `e`와 비교했어요. `(1, 0)`은 가로축과 같은 방향(1.0), `(0, 2)`는 직각(0.0)이에요. `e`의 길이는 1이라서 나누지 않았어요.

## 복소수: 첫째 인자의 켤레를 써요

복소수 배열에서는 `vecdot`이 **첫째 인자 `x1`을 켤레 복소수로 바꾼 다음** 곱하고 더해요. 켤레 복소수는 허수부의 부호를 바꾼 수예요(`1+2j`의 켤레는 `1-2j`). 즉 `vecdot(x1, x2)`는 `sum(conj(x1) * x2)`예요.

```python
>>> z = sd.asarray([1 + 2j, 3j])
>>> sd.vecdot(z, z)
(14+0j)
>>> sd.sum(sd.conj(z) * z)
(14+0j)
```

켤레를 쓰는 이유는 복소수 벡터의 길이 때문이에요. 복소수 `a+bj`의 크기의 제곱은 `a² + b²`인데, 이 값은 자기 자신이 아니라 **켤레와 곱해야** 나와요. 그래서 `vecdot(z, z)`는 언제나 0 이상의 실수(허수부 0)가 되고, 실수 벡터의 "길이의 제곱"과 뜻이 같아요. 위의 `14`는 `|1+2j|² + |3j|² = 5 + 9`예요.

### `@`와 결과가 달라요

<Callout type="warn" title="복소수에서 vecdot과 @는 다른 계산이에요">

[`@`(`matmul`)](/api/array/matmul/)는 켤레를 취하지 않고 적힌 값 그대로 곱해요. 실수 배열에서는 두 결과가 같지만, 복소수 배열에서는 달라요.

</Callout>

```python
>>> z @ z
(-12+4j)
```

| 계산 | 뜻 | `z = [1+2j, 3j]`일 때 |
|---|---|---|
| `sd.vecdot(z, z)` | `sum(conj(z) * z)` | `(14+0j)` |
| `z @ z` | `sum(z * z)` | `(-12+4j)` |

### 인자 순서가 결과를 바꿔요

켤레는 **첫째 인자에만** 적용해요. 그래서 복소수에서는 두 인자를 바꾸면 결과가 서로의 켤레가 돼요.

```python
>>> p = sd.asarray([1 + 2j, 3j])
>>> q = sd.asarray([2 + 0j, 1 - 1j])
>>> sd.vecdot(p, q)
(-1-7j)
>>> sd.vecdot(q, p)
(-1+7j)
```

실수 배열에서는 순서가 상관없어요.

## 결과의 dtype: 언제나 실수나 복소수

정수나 bool 배열을 넣어도 결과는 **float64**예요. 복소수가 하나라도 있으면 complex128이에요.

```python
>>> sd.vecdot(sd.asarray([1, 2, 3]), sd.asarray([4, 5, 6]))
32.0
>>> sd.vecdot(sd.asarray([True, False]), sd.asarray([True, True]))
1.0
```

정수 배열끼리 `@`를 쓰면 정수 결과가 나오는 것과 달라요. `vecdot`은 `sd.linalg`의 함수이기도 해서, 선형대수 함수들처럼 언제나 실수나 복소수로 계산해요.

```python
>>> sd.asarray([1, 2, 3]) @ sd.asarray([4, 5, 6])
32
```

| 입력 | `sd.vecdot` | `@` |
|---|---|---|
| bool | float64 | int64 |
| int64 | float64 | int64 |
| float64 | float64 | float64 |
| complex128 | complex128 (`x1`의 켤레) | complex128 (켤레 없음) |

실수로 계산하니까 아주 큰 정수에서는 끝자리가 정확하지 않을 수 있어요. float64는 약 2⁵³(9 × 10¹⁵)을 넘는 정수를 정확히 담지 못해요.

```python
>>> sd.vecdot(sd.asarray([2**53 + 1]), sd.asarray([1]))
9007199254740992.0
```

정확한 정수 결과가 필요하면 `@`나 `sd.sum(x1 * x2, axis=-1)`을 쓰세요.

## `sd.linalg.vecdot`과 같은 함수예요

`vecdot`은 배열 영역(`sd`)과 선형대수 영역(`sd.linalg`) 양쪽에 있어요. 이름만 두 군데 있을 뿐 **같은 함수**라서, 어느 쪽으로 불러도 결과와 에러가 똑같아요.

```python
>>> sd.linalg.vecdot is sd.vecdot
True
```

## 조심할 점

### 빈 벡터와 NaN

내적할 축의 길이가 0이면 더할 것이 없어서 결과는 `0.0`이에요. NaN(숫자가 아님)이 하나라도 섞이면 결과는 NaN이에요. 0을 곱해도 NaN은 사라지지 않아요.

```python
>>> sd.vecdot(sd.zeros(0), sd.zeros(0))
0.0
>>> sd.vecdot(sd.asarray([1.0, sd.nan]), sd.asarray([0.0, 0.0]))
nan
```

### `axis`는 정수 하나

tuple이나 `None`은 받지 않아요. 이름을 붙여서 `axis=`로 넘겨야 하고, 차원 범위 밖의 축은 `ValueError`예요.

```python
>>> sd.vecdot(m, n, axis=(0,))
Traceback (most recent call last):
    ...
TypeError: vecdot(): 'axis' must be an int, not tuple
>>> sd.vecdot(u, v, axis=1)
Traceback (most recent call last):
    ...
ValueError: vecdot(): axis 1 is out of bounds for an array of dimension 1
```

### 배열만 받아요

리스트나 숫자는 받지 않아요. 먼저 [`asarray`](/api/array/asarray/)로 바꾸세요.

```python
>>> sd.vecdot(u, [1, 2, 3])
Traceback (most recent call last):
    ...
TypeError: vecdot(): 'x2' must be an sd.ndarray, not list
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `vecdot`과 다른 점 |
|---|---|---|
| 행렬곱, 행렬과 벡터의 곱 | `@` (`sd.matmul`) | 행과 열을 짝지어요. 켤레를 취하지 않고, 정수는 정수로 계산해요. |
| 여러 축을 짝지어 줄이기, 모든 조합 | `sd.tensordot` | 남은 축을 모두 조합해요. 브로드캐스팅하지 않아요. |
| 같은 자리끼리 곱한 뒤 더하기 | `sd.sum(x1 * x2, axis=...)` | 여러 축을 줄일 수 있고, 정수는 정수로 남아요. 켤레는 직접 `sd.conj`로 해요. |
| 벡터의 길이 | `sd.linalg.vector_norm` | `sqrt(vecdot(x, x))`를 바로 구해 줘요. |

## numpy를 아는 분께

- `np.vecdot`처럼 첫째 인자의 켤레를 써요.
- **정수와 bool 입력의 결과가 float64예요.** numpy는 정수를 유지해요.
- `axis`는 keyword-only이고 int 하나만 받아요.
- 1차원끼리의 결과는 numpy 스칼라가 아니라 Python `float`·`complex`예요.
- `sd.linalg.vecdot`과 같은 객체예요.
