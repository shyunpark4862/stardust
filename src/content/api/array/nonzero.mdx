## 한눈에 보기

`nonzero`는 배열에서 **0이 아닌 원소가 몇 번 자리에 있는지** 찾아요.

```python
>>> import stardust as sd
>>> x = sd.asarray([0, 3, 0, 5, 7])
>>> sd.nonzero(x)
(array([1, 3, 4], dtype=int64),)
```

1, 3, 4번 자리의 원소가 0이 아니에요. 결과는 배열이 아니라 **배열 하나를 담은 tuple**이에요(끝의 쉼표를 보세요). 축마다 위치 배열을 하나씩 주기 때문이에요([아래](#여러-차원-배열은-축마다-위치를-따로-줘요) 참고). 1차원 배열이라면 `[0]`으로 꺼내 쓰면 돼요.

```python
>>> sd.nonzero(x)[0]
array([1, 3, 4], dtype=int64)
```

## 조건에 맞는 원소의 위치 찾기

`nonzero`는 비교 결과(bool 배열)에 가장 많이 써요. bool 배열에서는 `True`가 0이 아닌 값이라, **조건이 참인 자리**를 찾는 셈이에요.

```python
>>> temps = sd.asarray([12, 7, 30, 18])
>>> temps > 10
array([ True, False,  True,  True], dtype=bool)
>>> sd.nonzero(temps > 10)[0]
array([0, 2, 3], dtype=int64)
```

"10도가 넘은 날은 0, 2, 3번째 날"이라는 뜻이에요.

</Fig>

## 여러 차원 배열은 축마다 위치를 따로 줘요

2차원 배열에서 원소 하나의 위치는 (행, 열) 두 숫자예요. `nonzero`는 이 두 숫자를 **행 번호 배열 하나, 열 번호 배열 하나**로 나눠서 tuple에 담아 줘요. 그래서 결과 tuple의 길이는 언제나 `x`의 차원 수와 같아요.

```python
>>> m = sd.asarray([[0, 2, 0],
...                 [4, 0, 6]])
>>> rows, cols = sd.nonzero(m)
>>> rows
array([0, 1, 1], dtype=int64)
>>> cols
array([1, 0, 2], dtype=int64)
```

같은 자리끼리 짝지어 읽어요. 0이 아닌 원소는 `(0, 1)`, `(1, 0)`, `(1, 2)` 세 곳이에요.

<Fig caption="rows와 cols를 같은 자리끼리 짝지으면 0이 아닌 원소의 (행, 열)이 돼요.">

  <Op note="nonzero">→</Op>
  <ArrayFig name="rows" data={[0, 1, 1]} tones={['b', 'b', 'b']} note="행 번호" />

(행, 열) 쌍의 목록이 필요하면 두 배열을 짝지어요.

```python
>>> list(zip(rows.tolist(), cols.tolist()))
[(0, 1), (1, 0), (1, 2)]
```

위치는 **행을 먼저, 같은 행 안에서는 열 순서로** 늘어놓아요. 배열을 왼쪽 위부터 한 줄씩 읽어 가는 순서예요. 3차원이면 배열 세 개가 나와요.

```python
>>> cube = sd.reshape(sd.arange(8), (2, 2, 2))
>>> sd.nonzero(cube % 3 == 0)
(array([0, 0, 1], dtype=int64), array([0, 1, 1], dtype=int64), array([0, 1, 0], dtype=int64))
```

## 결과로 다시 인덱싱하기

결과 tuple을 그대로 인덱스로 쓰면 **0이 아닌 원소의 값**을 꺼낼 수 있어요. tuple의 k번째 배열이 k번 축의 위치가 되기 때문이에요.

```python
>>> m[sd.nonzero(m)]
array([2, 4, 6], dtype=int64)
>>> m[rows, cols]
array([2, 4, 6], dtype=int64)
```

두 줄은 같은 뜻이에요. 인덱싱 규칙은 [인덱싱과 대입](/api/array/indexing/)에 있어요.

그 자리에 값을 쓰는 것도 돼요.

```python
>>> v = sd.asarray([1, 0, 2])
>>> v[sd.nonzero(v)] = 9
>>> v
array([9, 0, 9], dtype=int64)
```

<Callout type="tip" title="값만 필요하면 마스크로 바로">
  조건에 맞는 **값**만 필요하면 `nonzero`를 거칠 필요가 없어요. `m[m != 0]`이나 `temps[temps > 10]`처럼 bool 배열로 바로 인덱싱하면 같은 결과가 나와요. `nonzero`는 **위치 자체**가 필요할 때 쓰세요.
</Callout>

앞의 `m[sd.nonzero(m)]`과 같은 값이 나와요.

```python
>>> m[m != 0]
array([2, 4, 6], dtype=int64)
```

## 무엇이 0이 아닌가요

기준은 `x != 0`이에요. dtype마다 풀어 쓰면 아래와 같아요.

| dtype | 0이 아닌 것으로 치는 것 |
|---|---|
| bool | `True` |
| int64 | 0이 아닌 정수 |
| float64 | `0.0`, `-0.0`이 아닌 값. **NaN도 0이 아니에요.** 아주 작은 수도 0이 아니에요. |
| complex128 | 실수부나 허수부 중 하나라도 0이 아닌 값 |

```python
>>> sd.nonzero(sd.asarray([0.0, sd.nan, -0.0, 1e-300]))
(array([1, 3], dtype=int64),)
>>> sd.nonzero(sd.asarray([0j, 1j, 1 + 0j]))
(array([1, 2], dtype=int64),)
```

<Callout type="warn" title="NaN 자리도 나와요">

  실수 배열을 바로 `nonzero`에 넣으면 NaN(숫자가 아님)의 자리도 결과에 들어가요. "값이 있는 칸"을 찾으려는 것이었다면 `sd.nonzero((x != 0) & ~sd.isnan(x))`처럼 조건을 직접 쓰세요.

</Callout>

## 조심할 점

### 0이 아닌 원소가 없으면 빈 배열

0이 아닌 원소가 하나도 없으면 에러 없이 빈 배열을 담은 tuple이 나와요.

```python
>>> sd.nonzero(sd.zeros(3))
(array([], dtype=int64),)
```

### 배열만 받아요

리스트나 숫자는 받지 않아요. `axis` 같은 옵션도 없어요.

```python
>>> sd.nonzero([1, 0])
Traceback (most recent call last):
    ...
TypeError: nonzero(): 'x' must be an sd.ndarray, not list
```

### 개수만 필요하면

위치 배열의 길이로 개수를 셀 수도 있지만, 개수만 필요하면 [`count_nonzero`](/api/array/count_nonzero/)가 더 간단하고 빨라요. 축별 개수도 구할 수 있어요.

```python
>>> len(sd.nonzero(m)[0])
3
>>> sd.count_nonzero(m)
3
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `nonzero`와 다른 점 |
|---|---|---|
| 조건에 맞는 원소의 값 | `x[mask]` | 위치를 거치지 않고 값을 바로 꺼내요. |
| 0이 아닌 원소의 개수 | `count_nonzero` | 위치 대신 개수를 돌려줘요. `axis`를 고를 수 있어요. |
| 조건에 따라 값 고르기 | `where` | `sd.where(cond, a, b)`는 모양을 유지한 채 원소마다 둘 중 하나를 골라요. 위치를 돌려주지 않아요. |
| 처음으로 참인 자리 하나 | `argmax` | bool 배열의 `argmax`는 처음 나온 `True`의 자리예요. 다만 `True`가 하나도 없어도 `0`이 나오니 조심하세요. |
| 위치로 값 꺼내기 | `take` | 위치를 받아서 값을 꺼내요. `nonzero`의 반대 방향이에요. |

처음에 본 `x`로 `where`와 `argmax`를 써 보면 차이가 보여요. `where`는 `x`와 같은 모양의 값을, `argmax`는 자리 하나를 돌려줘요.

```python
>>> sd.where(x != 0, x, -1)
array([-1,  3, -1,  5,  7], dtype=int64)
>>> sd.argmax(x != 0)
1
```

## numpy를 아는 분께

- 동작은 numpy의 `np.nonzero`와 같아요. 위치는 행 우선(C 순서)으로 늘어놓아요.
- `x.nonzero()` 메서드, `np.argwhere`, `np.flatnonzero`는 없어요. (행, 열) 쌍이 필요하면 `zip`으로 짝짓고, 편 배열의 위치가 필요하면 `sd.nonzero(sd.ravel(x))[0]`을 쓰세요.
- 인자가 하나인 `np.where(cond)`(= `nonzero`)는 없어요. `sd.where`는 언제나 인자 셋이에요.
- 리스트를 받지 않아요. `sd.ndarray`만 받아요.
