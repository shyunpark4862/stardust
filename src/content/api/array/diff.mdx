## 한눈에 보기

`diff`는 **이웃한 두 원소의 차이**를 구해요. 각 자리에서 "뒤의 값 - 앞의 값"을 계산해요.

```python
>>> import stardust as sd
>>> d = sd.asarray([1, 4, 9, 16, 25])
>>> sd.diff(d)
array([3, 5, 7, 9], dtype=int64)
```

`4 - 1 = 3`, `9 - 4 = 5`, … 이에요. 원소가 5개면 이웃한 짝은 4개뿐이라서 결과가 한 칸 짧아져요.

<Fig caption="이웃한 두 칸마다 뒤의 값에서 앞의 값을 빼요. 5칸에서 짝은 4개라서 결과는 4칸이에요.">
  <ArrayFig name="d" data={[1, 4, 9, 16, 25]} tones={['a', 'a', '', '', '']} />
  <Op note="diff">→</Op>
  <ArrayFig name="sd.diff(d)" data={[3, 5, 7, 9]} tones={['b', '', '', '']} note="3 = 4 - 1" />
</Fig>

`d[1:] - d[:-1]`(둘째부터 끝까지에서 처음부터 끝 하나 전까지를 빼기)과 같은 계산이에요.

```python
>>> d[1:] - d[:-1]
array([3, 5, 7, 9], dtype=int64)
```

### 언제 쓰나요

값이 얼마나 바뀌었는지가 궁금할 때 써요. 날마다의 주가에 쓰면 전날 대비 변화가 나와요.

```python
>>> prices = sd.asarray([100.0, 102.0, 99.0, 105.0])
>>> sd.diff(prices)
array([ 2.0, -3.0,  6.0], dtype=float64)
```

변화를 전날 값으로 나누면 변화율이 돼요.

```python
>>> sd.diff(prices) / prices[:-1]
array([                 0.02, -0.029411764705882353,   0.06060606060606061], dtype=float64)
```

## `n`: 차이의 차이

`n`을 주면 차이 구하기를 n번 거듭해요. `n=2`는 차이의 차이예요. 매번 한 칸씩 짧아지므로 결과는 n칸 짧아져요.

```python
>>> sd.diff(d, n=2)
array([2, 2, 2], dtype=int64)
```

`d`는 제곱수 `1, 4, 9, 16, 25`예요. 차이는 `3, 5, 7, 9`로 늘어나고, 그 차이는 `2`로 일정해요. 위치에서 한 번 차이를 구하면 속도, 한 번 더 구하면 가속도가 되는 것과 같은 관계예요.

<Fig caption="n=2는 차이를 한 번 더 구해요. 매번 한 칸씩 짧아져요.">
  <ArrayFig name="d" data={[1, 4, 9, 16, 25]} note="5칸" />
  <Op note="n=1">→</Op>
  <ArrayFig name="sd.diff(d)" data={[3, 5, 7, 9]} note="4칸" />
  <Op note="한 번 더">→</Op>
  <ArrayFig name="sd.diff(d, n=2)" data={[2, 2, 2]} tones={['b', 'b', 'b']} note="3칸" />
</Fig>

`n`이 원소 수 이상이면 남는 짝이 없어서 빈 배열이 나와요. 에러는 아니에요.

```python
>>> sd.diff(d, n=5)
array([], dtype=int64)
```

`n`은 0 이상의 정수여야 해요. 음수는 `ValueError`, 정수가 아니면(`1.0`, `True` 포함) `TypeError`예요.

```python
>>> sd.diff(d, n=-1)
Traceback (most recent call last):
    ...
ValueError: diff(): 'n' must be non-negative
>>> sd.diff(d, n=1.0)
Traceback (most recent call last):
    ...
TypeError: diff(): 'n' must be an int, not float
```

### `n=0`이면 `x` 그 자체예요

`n=0`이면 차이를 한 번도 구하지 않으므로 `x`를 그대로 돌려줘요. 복사본이 아니라 `x`라는 바로 그 배열이에요. 이때는 `prepend`, `append`를 줘도 붙이지 않아요.

```python
>>> sd.diff(d, n=0) is d
True
>>> sd.diff(d, n=0, prepend=0) is d
True
```

<Callout type="warn" title="n=0의 결과를 고치면 원래 배열이 바뀌어요">

`n=0`의 결과는 `x`와 같은 객체라서, 결과의 원소를 바꾸면 `x`도 바뀌어요. `n`을 변수로 받아 쓰는 코드에서 결과를 고쳐 써야 한다면 `.copy()`로 복사본을 만드세요.

</Callout>

## `axis`: 어느 방향으로 뺄까요

기본값 `axis=-1`은 마지막 축이에요. 2차원 배열이라면 각 행 안에서 왼쪽에서 오른쪽으로 차이를 구해요. `axis=0`이면 각 열 안에서 위에서 아래로 구해요.

```python
>>> x = sd.asarray([[1, 2, 3], [4, 5, 6]])
>>> sd.diff(x)
array([[1, 1],
       [1, 1]], dtype=int64)
>>> sd.diff(x, axis=0)
array([[3, 3, 3]], dtype=int64)
```

<Fig caption="axis=0: 열마다 아래 칸에서 위 칸을 빼요. 행이 하나 줄어요.">
  <ArrayFig name="x" data={[[1, 2, 3], [4, 5, 6]]} tones={[['a', '', ''], ['a', '', '']]} axes note="shape (2, 3)" />
  <Op note="axis=0">→</Op>
  <ArrayFig name="sd.diff(x, axis=0)" data={[[3, 3, 3]]} tones={[['b', '', '']]} note="shape (1, 3)" />
</Fig>

`sum`과 달리 축이 사라지지 않고 그 축의 길이만 n만큼 줄어요. `axis`에는 정수 하나만 쓸 수 있어요. `None`이나 tuple은 `TypeError`예요.

```python
>>> sd.diff(x, axis=None)
Traceback (most recent call last):
    ...
TypeError: diff(): 'axis' must be an int, not NoneType
```

## `prepend`, `append`: 앞뒤에 값을 붙이고 빼기

`prepend`는 `x`의 앞에, `append`는 뒤에 값을 붙인 다음 차이를 구해요. 붙인 만큼 결과가 길어져요.

```python
>>> sd.diff(d, prepend=0)
array([1, 3, 5, 7, 9], dtype=int64)
>>> sd.diff(d, append=36)
array([ 3,  5,  7,  9, 11], dtype=int64)
```

첫째 예는 `[0, 1, 4, 9, 16, 25]`의 차이예요. 결과가 원래 배열과 같은 길이가 되고, 첫 값은 `d[0] - 0 = 1`이에요.

### 누적 값을 하루하루의 값으로 되돌리기

`prepend=0`은 누적된 값을 원래 값으로 되돌릴 때 특히 쓸모가 있어요. 날마다 그날까지의 누적 방문자 수가 기록돼 있다면, 그날 하루의 방문자 수는 이렇게 구해요.

```python
>>> total = sd.asarray([3, 7, 12, 12, 20])
>>> sd.diff(total, prepend=0)
array([3, 4, 5, 0, 8], dtype=int64)
```

길이가 그대로라서 날짜와 짝이 맞아요. 이 계산은 [누적 합](/api/array/cumulative/)을 정확히 되돌려요. 그래서 결과를 다시 누적하면 원래 값이 돌아와요.

```python
>>> sd.cumulative_sum(sd.diff(total, prepend=0))
array([ 3,  7, 12, 12, 20], dtype=int64)
```

### 무엇을 붙일 수 있나요

- Python 숫자는 그 축 방향으로 한 칸 붙여요. 2차원 배열이면 그 숫자로 채운 한 줄을 붙여요.
- 배열은 여러 칸을 붙일 수 있어요. [`concat`](/api/array/concat/)으로 이어 붙이는 것과 같아서, `x`와 차원 수가 같고 붙이는 축 말고는 모양이 같아야 해요.
- 리스트는 받지 않아요(`TypeError`). 먼저 `sd.asarray`로 바꾸세요.

```python
>>> sd.diff(d, prepend=sd.asarray([0, 0]))
array([0, 1, 3, 5, 7, 9], dtype=int64)
>>> sd.diff(x, axis=0, prepend=0)
array([[1, 2, 3],
       [3, 3, 3]], dtype=int64)
```

2차원 배열의 각 행 앞에 서로 다른 값을 붙이려면, 붙일 배열도 2차원이어야 해요. 1차원 배열을 주면 차원 수가 맞지 않아 에러예요.

```python
>>> sd.diff(x, axis=1, prepend=sd.asarray([0, 10]))
Traceback (most recent call last):
    ...
ValueError: diff(): 'prepend' must have as many dimensions as 'x' (2), not 1
>>> sd.diff(x, axis=1, prepend=sd.asarray([[0], [10]]))
array([[ 1,  1,  1],
       [-6,  1,  1]], dtype=int64)
```

에러 메시지는 "`x`가 2차원이니 붙이는 배열도 2차원이어야 한다"는 뜻이에요. `(2, 1)` 모양의 세로 배열로 주면 각 행 앞에 하나씩 붙어요.

붙이는 값의 종류가 다르면 [dtype 승격](/api/array/dtypes/) 규칙을 따라요. 정수 배열에 실수를 붙이면 결과는 실수예요.

```python
>>> sd.diff(sd.asarray([1, 2]), prepend=0.5)
array([0.5, 1.0], dtype=float64)
```

`n`이 2 이상이어도 `prepend`와 `append`는 처음에 한 번만 붙여요.

```python
>>> sd.diff(d, prepend=0, n=2)
array([2, 2, 2, 2], dtype=int64)
```

## 결과의 dtype

빼기는 [`subtract`](/api/array/arithmetic/)의 규칙을 따라요. 정수는 정수, 실수는 실수, 복소수는 복소수이고, bool은 int64가 돼요. `True`를 1, `False`를 0으로 보고 빼기 때문이에요.

```python
>>> sd.diff(sd.asarray([True, True, False, True]))
array([ 0, -1,  1], dtype=int64)
```

`True`에서 `False`로 바뀐 곳은 `-1`, `False`에서 `True`로 바뀐 곳은 `1`, 그대로인 곳은 `0`이에요. 그래서 조건이 켜진 곳과 꺼진 곳을 구별해서 찾을 수 있어요.

## 조심할 점

### 정수의 차이도 넘칠 수 있어요

차이가 int64 범위(약 ±9.2 × 10¹⁸)를 넘으면 에러 없이 반대쪽 끝으로 넘어가요.

```python
>>> sd.diff(sd.asarray([-1, 2**63 - 1]))
array([-9223372036854775808], dtype=int64)
```

`(2⁶³ - 1) - (-1) = 2⁶³`이어야 하는데, 이 값은 int64의 가장 큰 값보다 1 커서 가장 작은 음수로 넘어갔어요. 아주 큰 정수를 다룬다면 `x.astype(sd.float64)`로 바꾼 다음 계산하세요.

```python
>>> sd.diff(sd.asarray([-1, 2**63 - 1]).astype(sd.float64))
array([9.223372036854776e+18], dtype=float64)
```

### NaN은 이웃한 두 칸에 퍼져요

NaN(숫자가 아님)이 하나 있으면 그 앞과의 차이, 그 뒤와의 차이가 모두 NaN이 돼요. 그래서 결과에 NaN이 두 개 생겨요.

```python
>>> sd.diff(sd.asarray([1.0, sd.nan, 3.0, 4.0, 6.0]))
array([nan, nan, 1.0, 2.0], dtype=float64)
```

### 원소가 하나 이하면 빈 배열이에요

이웃한 짝이 없으면 결과는 빈 배열이에요. 에러가 아니에요.

```python
>>> sd.diff(sd.asarray([5]))
array([], dtype=int64)
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `diff`와 다른 점 |
|---|---|---|
| 처음부터 쌓인 합 | `cumulative_sum` | `diff`와 반대 방향의 계산이에요. |
| 두 배열을 자리마다 빼기 | `subtract` 또는 `-` | 배열 둘을 받아서 같은 자리끼리 빼요. `diff`는 배열 하나 안에서 이웃끼리 빼요. |
| 이어 붙이기만 | `concat` | 붙이기만 하고 빼지 않아요. |

## numpy를 아는 분께

- bool 배열의 결과가 int64예요. numpy의 `np.diff`는 bool에서 "다른가"(`not_equal`)를 계산해서 bool을 돌려줘요. stardust는 `subtract`의 규칙대로 `True - False = 1`, `False - True = -1`이에요.
- `axis`, `n`, `prepend`, `append`는 keyword-only예요. `axis`와 `n`은 int만 받아요.
- `prepend`, `append`에 리스트는 받지 않아요. 배열이나 Python 숫자만 받아요.
- `n=0`이면 numpy처럼 `x` 자신을 돌려줘요. `prepend`, `append`를 붙이지 않는 것도 numpy와 같아요.
