## 한눈에 보기

$y$를 $x$의 식으로 풀 수 없는 곡선도 식 $F(x, y) = 0$ 하나로 그릴 수 있어요. 하트 곡선 $(x^2 + y^2 - 1)^3 - x^2 y^3 = 0$을 그려 볼게요.

```python
>>> heart = lambda x, y: (x * x + y * y - 1) ** 3 - x * x * y**3
>>> fig = sd.plot.implicit(heart, -1.5, 1.5, -1.3, 1.5)
```

사각형 $[-1.5, 1.5] \times [-1.3, 1.5]$ 안에서 식이 0인 점들을 찾아 이어요. 칸은 가로와 세로의 한 단위가 같은 길이예요.

## 무엇을 그리나요

`implicit(f, x0, x1, y0, y1)`은 $f(x, y) = $ `level`인 점들의 곡선이에요. 함수는 사각형 위의 격자에서 계산하고, 이웃한 격자점 사이에서 $f - \text{level}$의 부호가 바뀌는 칸을 찾아 곡선 조각을 이어요. 곡선이 사각형의 변에서 끝나면 거기서 끊기고, 닫힌 곡선은 닫힌 채로 그려져요.

`f`는 같은 모양의 배열 둘 `x`, `y`를 받는 원소별 함수예요. 첫 호출에서는 격자 전체를 2차원 배열로 한 번 받고, 그 뒤에는 다시 잴 점들을 열 모양 `(n, 1)` 배열로 받아요.

```python
>>> shapes = []
>>> def circle(x, y):
...     shapes.append(tuple(x.shape))
...     return x * x + y * y - 1
>>> fig = sd.plot.implicit(circle, -2, 2, -2, 2)
>>> shapes
[(241, 321), (47296, 1), (2244, 1)]
```

첫 호출이 $321 \times 241$점의 격자(행이 $y$, 열이 $x$)이고, 둘째가 곡선 가까이를 다시 잰 점들, 셋째가 곡선 위의 점을 다듬는 계산이에요. 모양에 기대지 않고 원소마다 계산하면 어떤 모양이든 맞아요.

### 곡선 위의 점을 다듬기

격자의 칸 하나에서 곡선이 변을 지나는 자리는 먼저 양 끝 값의 직선 보간으로 어림하고, 그 자리에서 함수를 한 번 더 계산해 할선법 한 걸음으로 다듬어요. 그래서 곡선의 점은 격자 간격보다 훨씬 정확히 곡선 위에 놓여요.

## level: 다른 값의 곡선

`level`을 주면 $f(x, y) = $ `level`인 곡선이에요. 같은 식의 여러 값을 겹치면 등고선과 비슷해지는데, 곡선마다 색과 범례를 따로 정할 수 있어요. 값이 많으면 [contour](/api/plot/contour/)가 수준을 고르고 숫자를 붙여 줘요.

```python
>>> q = lambda x, y: x * x - x * y + y * y
>>> fig = sd.plot.implicit(q, -2, 2, -2, 2, level=1, label="$1$")
>>> fig = fig.implicit(q, -2, 2, -2, 2, level=2, label="$2$")
>>> fig = fig.implicit(q, -2, 2, -2, 2, level=3, label="$3$").legend(loc="right")
```

## 교차점과 뾰족점: refine

격자가 성기면 곡선의 두 가지가 한 칸에서 만나는 교차점이나, 곡선이 급히 꺾이는 곳이 뭉개져요. 그래서 기본값(`refine=1`)은 곡선이 지나거나 가까이 지나는 칸과 그 둘레만 가로세로 4배로 다시 재요. 곡선에서 먼 칸은 다시 재지 않으니 계산은 곡선 둘레의 띠만큼만 늘어요. 데카르트의 엽선 $x^3 + y^3 = 3xy$를 거친 격자(`samples=41`)로 그려서 견줘 볼게요.

```python
>>> folium = lambda x, y: x**3 + y**3 - 3 * x * y
>>> a = sd.plot.implicit(folium, -3, 3, -3, 3, samples=41, refine=0)
>>> b = sd.plot.implicit(folium, -3, 3, -3, 3, samples=41)
>>> fig = sd.plot.grid([a, b], ncols=2, labels="A", width=183)
```

<PlotImage name="implicit-folium" alt="두 개의 데카르트 엽선. 왼쪽은 고리 끝이 각진 꺾인 선이고, 오른쪽은 매끈해요" caption="같은 41 × 41 격자예요. A(refine=0)는 고리의 끝이 각지게 꺾여요. B(기본)는 곡선 둘레만 4배로 다시 재서 고리의 끝이 매끈해요." scale={1} />

다시 잴 띠가 격자의 35%를 넘으면(어디서나 곡선이 지나는 함수) 다시 재지 않고 격자를 그대로 써요. 그때는 `samples`로 격자 자체를 촘촘히 해요.

## 정의되지 않는 곳

함수가 NaN을 돌려주는 점이 꼭짓점인 칸에서는 곡선을 잇지 않아요. 값이 있는 곳의 곡선만 그려져요.

```python
>>> fig = sd.plot.implicit(lambda x, y: y * y - sd.log(x), -1, 3, -2, 2)
```

$\log x$는 $x \le 0$에서 정의되지 않으니, 곡선 $y^2 = \log x$는 $x \ge 1$ 쪽에만 그려져요.

곡선이 사각형 안에 없으면 빈 칸이 돼요. 에러가 아니에요.

```python
>>> fig = sd.plot.implicit(lambda x, y: x * x + y * y + 1, -1, 1, -1, 1)
```

## 조심할 점

- **부호가 바뀌어야 찾아요.** 곡선은 $f - \text{level}$의 부호가 바뀌는 곳에서 찾아요. $(x^2 + y^2 - 1)^2 = 0$처럼 0에 닿기만 하고 부호가 바뀌지 않는 식은 곡선을 거의 그리지 못해요. 식을 $x^2 + y^2 - 1 = 0$처럼 부호가 바뀌는 꼴로 써요.
- **격자보다 작은 고리는 놓칠 수 있어요.** 격자 칸보다 작은 닫힌 곡선은 네 꼭짓점의 부호가 같아 보이지 않을 수 있어요. `samples`를 늘려요.
- **범위는 그대로예요.** 칸의 범위는 준 사각형이고, 곡선이 없는 곳도 줄이지 않아요.
- 부등식 $f(x, y) > 0$의 영역을 칠하려면 [region](/api/plot/region/)이에요. 곡선을 매개변수로 쓸 수 있으면 [parametric](/api/plot/parametric/)이 더 정확해요.
