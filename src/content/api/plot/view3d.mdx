## 3D 칸이란

`sd.plot`에서 3D로 그리는 함수는 넷이에요.

| 함수 | 그리는 것 |
|---|---|
| [`surface`](/api/plot/surface/) | 곡면 $z = f(x, y)$ |
| [`parametric_surface`](/api/plot/parametric_surface/) | 매개변수 곡면 $(x(u, v),\ y(u, v),\ z(u, v))$ |
| [`curve3d`](/api/plot/curve3d/) | 공간 곡선 $(x(t),\ y(t),\ z(t))$ |
| [`scatter3d`](/api/plot/scatter3d/) | 3D 점 $(x_i, y_i, z_i)$ |

이 가운데 하나를 처음 그린 칸은 **3D 칸**이 돼요. 3D 칸에는 2D 칸의 가로축·세로축 대신 **상자 축**이 서요. 자료를 담은 상자를 비스듬히 내려다보고, 상자의 모서리에 눈금을 붙여요. 같은 칸에 다른 3D 층을 메서드로 더하면 한 상자 안에 함께 그려져요.

```python
>>> import math
>>> hill = lambda x, y: sd.exp(-(x**2 + y**2))
>>> r = lambda t: 2 - t / (3 * math.pi)
>>> fig = sd.plot.surface(hill, -2, 2, -2, 2)
>>> fig = fig.curve3d(lambda t: r(t) * sd.cos(t), lambda t: r(t) * sd.sin(t),
...                   lambda t: sd.exp(-r(t)**2) + 0.03, 0, 6 * math.pi, color="black")
>>> fig = fig.scatter3d([0.0], [0.0], [1.03], color="C3", size=6)
>>> fig = fig.xlabel("$x$").ylabel("$y$").zlabel("$z$").title("산을 오르는 길")
```

한 칸에 곡면이 하나뿐이면 곡면은 높이에 따라 색띠 `'cool'`(아래 하늘색, 가운데 보라, 위 빨강)로 칠해져요. 곡선과 점은 2D 그림처럼 팔레트의 색을 차례로 받거나 `color=`로 준 색이에요.

## 상자와 축

### 상자의 비율

상자의 모양은 무엇을 그리는지에 따라 둘 중 하나예요.

- **곡면 $z = f(x, y)$가 든 칸**: 상자의 가로·세로·높이가 1 : 1 : 0.72예요. $x$, $y$, $z$가 저마다의 척도를 가져요. 높이의 단위가 $x$, $y$와 아주 달라도(예: $x$는 미터, $z$는 온도) 곡면이 납작해지거나 치솟지 않아요.
- **매개변수 곡면, 공간 곡선, 3D 점만 든 칸**: 상자가 자료의 비율을 따라요. 세 축에서 자료의 한 단위가 같은 길이라서 구는 둥글게, 원환면은 납작하게 보여요.

`surface`를 한 번이라도 더한 칸은 앞의 상자를 써요.

### 축과 눈금

상자의 여섯 면 가운데 보는 사람에게서 먼 세 면에는 눈금 자리마다 옅은 격자선과 테두리를 그려요. 면을 칠하지는 않아요. 눈금은 세 모서리에 붙어요.

- $x$와 $y$: 상자의 바닥에서 보는 사람 쪽에 가까운 두 모서리
- $z$: 상자의 왼쪽에 서 있는 세로 모서리

눈금의 수는 모서리가 화면에 그려진 길이에 맞춰 정해요. 비스듬히 보여 짧게 그려진 모서리에는 눈금이 적고, 거의 정면으로 보여 아주 짧은 모서리에는 눈금을 달지 않아요. 두 축이 만나는 꼭짓점에서 눈금 숫자가 서로 닿으면 나중 것을 빼요. 눈금 숫자가 아주 크거나 작으면 2D 축처럼 공통 10의 거듭제곱을 축 이름 옆에 한 번 적어요.

축 이름은 [`xlabel`](/api/plot/customize/), `ylabel`, `zlabel`로, 칸의 제목은 `title`로 붙여요. 이름은 눈금 숫자 바깥에 서요. $z$의 이름은 눕히지 않고 바로 세워 적고, 그 너비만큼 왼쪽 여백이 늘어나요.

### 범위

세 축의 범위는 자료가 정해요. 곡면의 높이는 값의 대부분이 있는 범위로 잡고, 극점처럼 몇 점만 멀리 달아나면 그 부분은 상자의 면에서 잘라요. 높이의 범위를 직접 정하려면 `surface`의 `zlim=(low, high)`을 줘요. 곡면 없이 점이 든 칸은 2D 그림처럼 자료의 범위를 4%씩 넓혀서, 가장 바깥의 점이 상자의 모서리 위에 놓이지 않아요.

2D 칸의 축 설정 `xlim`, `ylim`, `xscale`, `yscale`, `xticks`, `yticks`는 3D 칸에 없어요. 부르면 에러예요.

```python
>>> fig.xlim(-1, 1)
Traceback (most recent call last):
    ...
ValueError: xlim(): a 3D cell has no such axis setting; its ranges are those of the data
```

### 그림의 크기

3D 칸 하나뿐인 그림에서 `height`를 주지 않으면 높이는 상자가 화면에 비친 모양을 따라요. 상자가 칸의 그림 자리를 빈틈없이 채우고 눈금과 이름은 그 둘레의 여백에 서요.

```python
>>> fig.width, round(fig.height, 2)
(89.0, 86.49)
```

[`grid`](/api/plot/figure/)로 3D 칸과 2D 칸을 한 줄에 두면 두 칸의 그림 자리가 위아래로 맞춰져요. 3D 칸끼리 한 줄에 두면 상자의 모양이 달라도 제목이 한 높이에 서요.

## 시점: azimuth와 elevation

3D 칸은 상자를 한 방향에서 본 그림이에요. 그 방향을 두 각(도)으로 정해요.

- **`azimuth`**(방위각): 보는 사람이 상자 둘레의 어느 쪽에 서 있는지예요. $+x$ 방향을 0°로 하고 $+y$ 쪽으로 돌수록 커져요. −60°는 $+x$와 $-y$ 사이, 곧 오른쪽 앞에서 보는 방향이에요.
- **`elevation`**(고도): 바닥면에서 얼마나 위로 올라가 내려다보는지예요. 0°는 바닥과 같은 높이에서 옆으로, 90°는 바로 위에서 보는 방향이에요. −90°부터 90°까지 받고, 음수는 아래에서 올려다보는 방향이에요.

보는 사람의 방향을 단위 벡터로 쓰면 이래요.

$$
(\cos e \cos a,\ \cos e \sin a,\ \sin e) \qquad (a = \text{azimuth},\ e = \text{elevation})
$$

### 주지 않으면 알아서 골라요

두 각의 기본값은 `None`이고, 주지 않은 각은 그림마다 알아서 골라요. 후보는 방위각 여덟(±30°, ±60°, ±120°, ±150°)과 고도 셋(18°, 30°, 42°)이에요. 상자의 축을 정면으로 보는 방위각(0°, ±90°, 180°)은 눈금 숫자가 서로 겹치므로 후보에 없어요.

후보마다 그 방향에서 본 장면을 성기게 그려 보고 점수를 매겨요.

- 곡면은 **넓이 가운데 보이는 몫**이 점수예요. 다른 부분에 가린 곳은 세지 않고, 옆으로 누워 보이는 면(보는 방향과 거의 나란한 면)은 조금만 세요.
- 곡선과 점은 화면에 **얼마나 넓게 퍼지는지**가 점수예요. 납작한 점 구름을 옆에서 보아 한 줄로 겹치게 하는 방향은 점수가 낮아요.

점수가 가장 높은 방향을 고르는데, 기준 방향(−60°, 30°)이 조금 앞서서 출발해요. 그래서 어느 방향에서 봐도 비슷한 곡면은 대개 (−60°, 30°)에서 보이고, 한쪽 면이 다른 쪽에 가리는 곡면만 다른 방향에서 보여요. 한 각만 주면 그 각은 그대로 두고 다른 각만 골라요.

```python
>>> saddle = lambda x, y: x**3 - 3 * x * y**2
>>> a = sd.plot.surface(saddle, -1, 1, -1, 1).title("default")
>>> b = sd.plot.surface(saddle, -1, 1, -1, 1, azimuth=30, elevation=18)
>>> b = b.title("azimuth=30, elevation=18")
>>> c = sd.plot.surface(saddle, -1, 1, -1, 1, azimuth=-60, elevation=55)
>>> c = c.title("azimuth=-60, elevation=55")
>>> g = sd.plot.grid([a, b, c], ncols=3, width=183)
```

고른 방향은 장면이 바뀌면(층을 더하면) 그릴 때 다시 골라요. 그림을 여러 장 같은 방향에서 보이고 싶으면 두 각을 모두 주세요.

### 원근: perspective

`perspective=True`(기본값)는 상자에서 조금 떨어진 한 점에서 본 원근 그림이에요. 가까운 모서리가 먼 모서리보다 조금 길게 보여요. `perspective=False`는 직교 투영이에요. 무한히 먼 곳에서 본 것처럼 상자의 나란한 모서리가 화면에서도 나란하고, 같은 길이는 어디서나 같은 길이로 보여요. 길이를 눈으로 견줘야 하는 그림에 써요.

## 한 칸에 여러 층

3D 칸에 층을 더하는 법은 2D와 같아요. 모듈 함수가 돌려준 그림에 같은 이름의 메서드로 더해요. 곡면, 곡선, 점을 섞어도 돼요.

곡면은 **깊이 버퍼**로 그려요. 화면의 점마다 가장 가까운 것을 남기므로, 서로 뚫고 지나가는 곡면도 교선을 따라 옳게 갈려요. 층을 준 순서와 무관해요.

```python
>>> fig = sd.plot.surface(lambda x, y: x**2 - y**2, -1, 1, -1, 1)
>>> fig = fig.surface(lambda x, y: 0.5 * x + 0.3 * y, -1, 1, -1, 1, alpha=0.6)
```

<PlotImage name="view3d-layers" format="png" alt="파란 말안장 곡면 x² − y²과 노란 반투명 평면이 서로 뚫고 지나가요. 평면 아래로 내려간 안장의 부분이 노란 평면을 통해 비쳐 보여요." caption="곡면이 둘이면 저마다 팔레트의 색을 받아요. 노란 평면은 alpha=0.6이라 그 뒤와 아래의 안장이 비쳐요." />

- **색**: 곡면이 하나면 높이에 따른 색띠, 둘 이상이면 곡면마다 팔레트의 색(조금 옅게)을 차례로 받아요. 색이 정해지는 때는 칸을 그릴 때라서, 곡면을 하나 더하면 앞의 곡면도 팔레트의 색으로 칠해져요. `cmap=`이나 `color=`를 주면 그것이 우선이에요.
- **시점**: 그 칸의 첫 3D 층이 시점(`azimuth`, `elevation`, `perspective`)을 정해요. 뒤에 더한 층의 시점 인자는 쓰이지 않아요.
- **상자와 범위**: 모든 층의 자료를 함께 담도록 잡아요.
- **곡선과 점의 앞뒤**: 곡선과 점도 깊이를 견줘요. 곡면 뒤의 부분은 가려지고, 곡선끼리 엇갈리는 곳이나 곡선과 점이 겹치는 곳에서도 보는 사람에게 가까운 것이 위에 와요. 더한 순서와 무관해요.

한 칸에 2D 그림과 3D 그림을 함께 둘 수는 없어요. 2D 층이 있는 칸에 3D 층을 더해도, 3D 칸에 2D 층(`line`, `scatter`, `function` 등)을 더해도 에러예요. 나란히 보이려면 [`grid`](/api/plot/figure/)로 칸을 나눠요.

```python
>>> sd.plot.line([0, 1], [0, 1]).surface(saddle, -1, 1, -1, 1)
Traceback (most recent call last):
    ...
ValueError: surface(): the cell already holds a 2D plot
>>> sd.plot.surface(saddle, -1, 1, -1, 1).line([0, 1], [0, 1])
Traceback (most recent call last):
    ...
ValueError: line(): the cell already holds a 3D plot
```

### 범례

3D 칸도 범례를 그려요. `label=`을 준 [`curve3d`](/api/plot/curve3d/)와 [`scatter3d`](/api/plot/scatter3d/), 그리고 `scatter3d`의 `group=`이 나눈 무리가 범례에 들어요. 범례는 상자를 가리지 않게 상자의 오른쪽 밖에 서요. 곡면은 범례에 들지 않아요.

```python
>>> t2 = lambda t: t / (4 * math.pi)
>>> fig = sd.plot.curve3d(sd.cos, sd.sin, t2, 0, 8 * math.pi, label="helix")
>>> fig = fig.curve3d(lambda t: 0 * t, lambda t: 0 * t, t2, 0, 8 * math.pi, color="gray", label="axis")
>>> fig = fig.scatter3d([1.0, 1.0], [0.0, 0.0], [0.0, 2.0], color="C3", size=6, label="ends")
```

<PlotImage name="view3d-legend" format="png" alt="세로로 선 파란 나선과 그 가운데를 지나는 회색 곧은 선, 나선의 양 끝에 빨간 점 둘. 나선이 회색 선의 앞을 지날 때는 나선이, 뒤를 지날 때는 회색 선이 위에 보여요. 상자의 오른쪽 밖에 helix, axis, ends 세 줄의 범례가 있어요." caption="이름을 준 곡선 둘과 점이 범례에 들었어요. 나선과 가운데 축은 깊이를 견줘서, 나선이 축의 앞을 지나는 곳과 뒤를 지나는 곳이 갈려요." />

범례를 없애려면 `fig.legend(loc=None)`이에요.

## 빛과 음영

곡면의 밝기는 고정된 빛 셋이 정해요.

- **주광**: 왼쪽 위 앞에서 비추는 가장 센 빛
- **보조광**: 주광의 반대쪽에서 비추는 약한 빛. 주광이 닿지 않는 쪽이 검게 꺼지지 않게 해요
- **테두리광**: 뒤쪽 위에서 비추는 빛. 곡면의 윤곽을 살려요

여기에 고른 바탕 밝기와, 주광의 넓은 광택과 또렷한 반사광, 보조광의 넓은 광택이 얹혀요. 밝기는 화면의 점마다 법선을 삼각형 안에서 보간해 계산하므로(Phong 음영) 격자의 칸이 각져 보이지 않아요. 곡면의 **두 면을 똑같이** 밝혀요. 뫼비우스 띠처럼 앞뒤가 이어진 곡면이나, 아래에서 올려다본 곡면도 어둡게 꺼지지 않아요.

빛의 방향과 세기는 인자로 받지 않아요. 시점을 바꾸면 빛은 보는 사람을 따라 돌아요. 곡면을 어느 방향에서 보든 같은 쪽에서 빛이 와요.

곡면 위의 **격자선**(`mesh`)은 곡면 제 색을 어둡게 한 가는 선이에요. 곡면에 가린 부분은 그리지 않아요. 바닥 등고선(`surface`의 `contours`)도 같은 깊이 검사를 받아요.

## 반투명: alpha

`surface`와 `parametric_surface`는 `alpha=`(0보다 크고 1 이하, 기본값 1)로 불투명도를 받아요. 반투명한 곡면은 뒤의 것이 비쳐 보여요.

- 불투명한 것을 먼저 그리고, 화면의 점마다 그 앞에 놓인 반투명 조각(곡면과 격자선)을 가까운 것부터 깊이 순서로 12겹까지 모아 얹어요. 반투명 곡면 여럿이 겹치거나 서로 뚫고 지나가도, 준 순서와 무관하게 옳은 순서로 비쳐요.
- 비스듬히 보이는 반투명 면은 더 불투명해져요. 빛이 그 면을 지나는 길이가 길기 때문이에요. 그래서 반투명한 구의 가장자리가 진하게 보여 윤곽이 살아요.

곡선과 점은 `alpha` 인자가 없어요.

## 그림으로 굽는 부분과 벡터인 부분

3D 칸의 내용(곡면, 격자선, 곡선, 점)은 깊이 버퍼가 그린 **그림 한 장**이에요. 상자의 뒤쪽 면과 격자, 축의 모서리와 눈금, 모든 글자는 **벡터**예요. SVG와 PDF에는 둘이 겹쳐 들어가요.

```python
>>> svg = fig.to_svg()
>>> svg.count("<image")
1
```

- 그림의 해상도는 내보낼 때의 `dpi`(기본값 300)예요. `fig.save("saddle.pdf", dpi=600)`은 곡면을 600 dpi로 구워 넣고, 글자와 축은 그대로 벡터예요. PNG는 전체를 그 dpi로 한 번에 구워요.
- 화면의 한 화소를 3 × 3의 점으로 나눠 재고 평균하므로 곡면의 가장자리와 격자선이 계단지지 않아요.
- 그림에서 곡면이 없는 자리는 투명해서 뒤쪽 면의 격자와 바탕이 비쳐요.
- 노트북에서는 3D 칸이 있는 그림을 200 dpi의 PNG 한 장으로 보여요.
- 같은 기계, 같은 스레드 수, 같은 입력이면 같은 바이트예요. 화면을 고정한 높이의 띠로 나눠 스레드에 나눠 주므로 지금은 스레드 수를 바꿔도 같은 그림이에요(약속은 아니에요).

내보내기의 나머지는 [그림 내보내기](/api/plot/export/)에 있어요.

<Callout type="note" title="돌려 보기는 없어요">
`sd.plot`의 그림은 파일과 노트북 안의 정지 그림이에요. 창을 띄워 마우스로 상자를 돌려 보는 기능은 없어요. 시점을 주지 않아도 장면에 맞는 방향을 고르는 것은 이 때문이에요. 다른 방향이 필요하면 `azimuth`, `elevation`을 바꿔 다시 그려요.
</Callout>

## matplotlib을 아는 분께

| matplotlib (`mpl_toolkits.mplot3d`) | sd.plot |
|---|---|
| `fig.add_subplot(projection='3d')` | 3D 층을 처음 그린 칸이 3D 칸이 돼요 |
| `ax.view_init(elev=30, azim=-60)` | `elevation=`, `azimuth=` 인자. 주지 않으면 장면에 맞게 골라요(기준 방향은 matplotlib의 기본과 같은 (−60°, 30°)) |
| `ax.set_proj_type('ortho')` | `perspective=False` |
| 도형을 깊이로 정렬해 덮어 그려요. 교차하는 곡면이나 곡면을 지나는 곡선이 엉뚱하게 가려질 수 있어요 | 화면의 점마다 깊이를 견줘요. 교차하는 곡면이 교선을 따라 옳게 갈려요 |
| `ax.set_zlim(...)` | `surface`의 `zlim=` |
| `ax.set_xlim(...)`, `ax.set_xscale(...)` | 없어요. $x$, $y$의 범위는 자료가 정해요 |
| `ax.legend()` | `label=`이나 `group=`을 주면 상자 오른쪽 밖에 범례가 서요 |
| `ax.set_box_aspect(...)` | 상자의 비율은 자동이에요(곡면은 1 : 1 : 0.72, 나머지는 자료의 비율) |
| `LightSource`로 빛을 바꿔요 | 빛은 고정이에요 |
| 창에서 마우스로 돌려 봐요 | 돌려 보기가 없어요 |
