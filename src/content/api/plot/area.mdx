## 무엇을 하나요

`area(x, y1, y2)`는 점 $(x_i, y1_i)$를 이은 곡선과 $(x_i, y2_i)$를 이은 곡선 사이를 칠해요. `y2`를 주지 않으면 0과의 사이, 곧 곡선 아래의 넓이예요. 테두리 없이 반투명한 칠만 그리므로 대개 [`line`](/api/plot/line/)과 함께 써요.

## 한눈에 보기

곡선과 그 둘레의 띠를 그려요. 띠를 먼저, 선을 나중에 부르면 선이 띠 위에 그려져요. 층은 부른 차례로 쌓여요.

```python
>>> import stardust as sd
>>> x = sd.linspace(0.0, 10.0, 200)
>>> mid = sd.sin(x) * sd.exp(-x / 6)
>>> half = 0.15 + 0.03 * x
>>> fig = sd.plot.area(x, mid - half, mid + half, color="C0", label="band")
>>> fig = fig.line(x, mid, color="C0", label="estimate")
>>> fig = fig.xlabel(r"$t$")
```

<PlotImage name="area-band" alt="감쇠하는 사인 곡선이 파란 선으로 그려지고, 그 둘레에 오른쪽으로 갈수록 넓어지는 옅은 파란 띠가 있는 그림" caption="area로 띠를 칠하고 line으로 가운데 곡선을 얹었어요. 둘 다 color='C0'을 줘서 색을 맞췄어요." />

`color`를 주지 않으면 `area`도 선처럼 팔레트의 다음 색을 받아요. 띠를 그 선과 같은 색으로 하려면 둘 다 같은 `'C0'`, `'C1'`처럼 팔레트의 번호를 주면 돼요. 띠의 범례 기호는 칠한 네모예요.

## 곡선 아래의 넓이

`y2`의 기본값은 0이에요. 정규분포의 밀도 아래에서 $|z| < 1.96$인 부분만 칠해 보아요. 칠할 범위의 `x`만 따로 만들어 넘기면 돼요.

```python
>>> N = sd.stats.Normal()
>>> z = sd.linspace(-4.0, 4.0, 300)
>>> inner = sd.linspace(-1.96, 1.96, 150)
>>> fig = sd.plot.line(z, N.pdf(z), color="black", width=0.8)
>>> fig = fig.area(inner, N.pdf(inner), color="C0", alpha=0.4)
>>> fig = fig.text(0.0, 0.15, "95\\%").xlabel(r"$z$").ylabel(r"$\varphi(z)$")
>>> round(N.cdf(1.96) - N.cdf(-1.96), 4)
0.95
```

<PlotImage name="area-normal" alt="표준정규분포의 종 모양 밀도 곡선이 검은 선으로 그려지고, -1.96에서 1.96까지 곡선 아래가 파랗게 칠해져 가운데에 95%라고 적힌 그림" caption="y2를 주지 않으면 곡선과 0 사이를 칠해요. 칠할 구간의 x만 따로 넘겼어요." />

`y2`에 수 하나를 주면 0 대신 그 높이와의 사이예요. 배열을 주면 두 곡선 사이이고, 어느 쪽이 위인지는 상관없어요. 두 곡선이 서로 엇갈리면 엇갈리는 곳에서 칠이 한 점으로 좁아졌다가 다시 넓어져요.

## 두 곡선 사이와 겹친 칠

반투명한 칠끼리 겹치면 겹친 곳의 색이 섞여 보여요. 두 분포의 밀도를 함께 칠하면 겹친 부분이 드러나요.

```python
>>> t = sd.linspace(-4.0, 7.0, 300)
>>> a = sd.stats.Normal(mu=0.0, sigma=1.0).pdf(t)
>>> b = sd.stats.Normal(mu=2.5, sigma=1.4).pdf(t)
>>> fig = sd.plot.area(t, a, label="control").area(t, b, label="treated")
>>> fig = fig.line(t, a, color="C0", width=0.8).line(t, b, color="C1", width=0.8)
```

<PlotImage name="area-overlap" alt="왼쪽의 파란 종 모양과 오른쪽의 노란 종 모양 두 밀도가 반투명하게 칠해져 가운데에서 겹친 그림" caption="area 둘은 팔레트의 첫 두 색을 받았고, 선은 같은 번호의 색으로 맞췄어요. 겹친 곳은 두 칠이 섞여 보여요." />

`area`는 `group=`을 받지 않아요. 무리마다 칠하려면 무리마다 `fig.area(...)`를 불러요.

## NaN에서는 칠이 끊겨요

`x`, `y1`, `y2` 가운데 하나라도 NaN이나 무한대인 점은 빼고, 칠은 그 자리에서 끊겨 조각으로 나뉘어요. 유한한 점이 하나뿐인 조각은 넓이가 없어서 칠하지 않아요.

```python
>>> x = sd.linspace(-2.0, 2.0, 81)
>>> y = sd.where(sd.abs(x) < 0.5, float("nan"), x * x)
>>> fig = sd.plot.area(x, y)
```

가운데 $|x| < 0.5$가 비고 양쪽 두 조각만 칠해져요.

## 조심할 점

- `x`는 정렬하지 않아요. 주어진 차례로 위 곡선을 따라가고 아래 곡선을 거꾸로 돌아와 닫아요. `x`가 뒤섞여 있으면 칠이 꼬이니 정렬해서 주세요.
- 축의 범위는 `y1`과 `y2`를 모두 넣어 잡아요. `y2=0`이면 0이 범위에 들어가지만, 막대와 달리 0 아래에도 여유를 조금 둬요.
- 함수의 부등식 $f(x, y) > 0$인 영역을 칠하려면 [`region`](/api/plot/region/)이 있어요. 회귀선의 신뢰 띠는 [`Figure.fit`](/api/plot/fit/)이 계산까지 해서 그려요.

## matplotlib을 아는 분께

- `plt.fill_between(x, y1, y2)`에 해당해요. 기본 `alpha`가 0.3이고 테두리 선은 없어요.
- `where=`나 `interpolate=` 인자는 없어요. 칠하지 않을 곳은 NaN으로 두거나, 칠할 구간의 `x`만 넘겨요.
