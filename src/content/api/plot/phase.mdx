## 한눈에 보기

복소 함수 $w = f(z)$는 입력도 출력도 평면이라 그래프를 그대로 그릴 수 없어요. 위상 그림은 입력 평면의 점마다 출력 $w$의 **방향**(편각)을 색상으로 칠해요. 영점 셋과 극점 둘이 있는 유리 함수를 그려 볼게요.

$$
f(z) = \frac{(z^2 - 1)(z - 2 - i)^2}{z^2 + 2 + 2i}
$$

```python
>>> f = lambda z: (z * z - 1) * (z - 2 - 1j) ** 2 / (z * z + 2 + 2j)
>>> fig = sd.plot.phase(f, -3, 3, -3, 3)
>>> fig = fig.xlabel(r"$\mathrm{Re}\,z$").ylabel(r"$\mathrm{Im}\,z$")
```

## 색 읽기

색상은 $w$의 편각 $\arg w$예요. 양의 실수 방향이 빨강이고, 편각이 커지면 노랑, 초록, 청록(음의 실수), 파랑, 자홍을 지나 다시 빨강으로 돌아와요. 항등 함수 $f(z) = z$를 그리면 이 색 바퀴가 그대로 보여요.

```python
>>> fig = sd.plot.phase(lambda z: z, -2, 2, -2, 2)
```

<PlotImage name="phase-identity" alt="원점을 중심으로 한 색 바퀴. 오른쪽이 빨강, 위가 연두, 왼쪽이 청록, 아래가 보라이고, 원점으로 갈수록 좁아지는 동심원 띠가 겹쳐 있어요" caption="f(z) = z예요. 색은 편각(오른쪽이 빨강, 시계 반대 방향으로 노랑, 초록, 청록, 파랑, 자홍), 동심원의 띠는 크기가 1, 1/2, 1/4, …, 2가 되는 경계예요." />

이 색으로 영점과 극점을 읽어요.

- **영점**: 둘레를 시계 반대 방향으로 한 바퀴 돌 때 색이 빨강 → 노랑 → 초록 → 청록 → 파랑 → 자홍 순서로 돌아요.
- **극점**: 같은 방향으로 돌 때 색이 반대 순서로 돌아요.
- **차수**: 한 바퀴 도는 동안 색이 몇 바퀴 도는지가 영점이나 극점의 차수예요. 위의 유리 함수에서 $2 + i$는 색이 두 바퀴 도는 이중 영점이에요.

색은 실수 배열과 연결되지 않으니 색 막대를 붙이지 않아요.

## 밝기의 띠: contours

`contours=True`(기본)이면 크기 $|w|$에 따라 밝기의 띠를 그려요. $|w|$가 2의 거듭제곱($\dots, \tfrac12, 1, 2, 4, \dots$)인 곳에서 어두워졌다가, 두 배가 될 때까지 점점 밝아지기를 되풀이해요. 그래서 띠의 경계는 크기의 등고선이고, 영점 쪽으로는 크기가 줄며 띠가 촘촘해지고 극점 쪽으로는 크기가 커지며 촘촘해져요. 띠의 밝은 쪽이 $|w|$가 큰 쪽이라, 띠를 보고 영점과 극점을 가릴 수도 있어요.

`contours=False`면 편각의 색만 칠해요. 크기가 한없이 바뀌는 진성 특이점 둘레처럼 띠가 너무 빽빽한 곳에서는 색만 보는 편이 읽기 쉬워요.

```python
>>> fig = sd.plot.phase(lambda z: sd.exp(1 / z), -1, 1, -1, 1, contours=False)
```

$e^{1/z}$는 원점이 진성 특이점이라 원점 가까이에서 색이 끝없이 돌아요.

## 받는 함수

`f`는 complex128 배열 하나를 받아요. 화소 전체의 격자를 한 번에 넘기므로 원소별로 계산하는 함수여야 해요. 산술 연산, `sd.exp`, `sd.log`, `sd.sin`, `sd.sqrt` 같은 함수가 복소수를 받아요. 실수 배열을 돌려주면 허수부 0인 복소수로 봐요(편각이 0 또는 π라 빨강과 청록만 나와요).

```python
>>> fig = sd.plot.phase(sd.sin, -4, 4, -2, 2, height=50)
```

<PlotImage name="phase-sine" alt="가로로 긴 위상 그림. 가로축 위 −π, 0, π에 영점이 있고 그 사이의 ±π/2 근처에서 색이 크게 바뀌어요" caption="sin z의 영점은 실수축 위의 0, ±π이고 모두 단순 영점이에요. 허수부가 커지면 크기가 지수적으로 커져서 위아래로 밝기의 띠가 가로로 늘어서요." />

다른 함수 그림과 달리 `phase`의 `f`는 **수 하나를 돌려주면 에러**예요. 상수 함수는 `lambda z: 0 * z + c`처럼 배열로 돌려줘요.

화소의 값이 NaN이면 투명하게 비우고, 0이면 검정, 무한대면 흰색이에요.

## 칸과 화소

칸은 실수부와 허수부의 한 단위가 같은 길이예요. 그래서 원은 원으로, 편각은 실제 각대로 보여요. 사각형이 정사각형이 아니면 위의 사인처럼 `height`를 맞춰 빈 곳을 줄여요. `samples`는 화소 수이고(기본 $480 \times 360$), 적응형으로 더 쪼개지 않으므로 `refine`은 받지 않아요. 표본은 화소의 가운데 점이에요.

## 조심할 점

- **띠가 빽빽하면 얼룩이 돼요.** 크기가 빨리 변하는 곳은 띠가 화소보다 좁아져요. `samples`를 늘리거나 `contours=False`로 색만 봐요.
- **가지 자름이 색의 경계로 보여요.** `sd.log`, `sd.sqrt`처럼 여러 값을 갖는 함수는 음의 실수축에서 값이 뛰어서, 거기에 색이 갑자기 바뀌는 선이 생겨요. 함수의 성질이 아니라 주값을 고른 결과예요.
- **함수는 배열을 받아야 해요.** `cmath`의 함수는 쓸 수 없어요.
- 실수 값의 크기만 보고 싶으면 `lambda x, y: sd.abs(f(x + 1j * y))`를 [density](/api/plot/density/)로 그려요.
