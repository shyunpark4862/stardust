## 한눈에 보기

시험 점수를 나이, 소득, 키로 설명하는 회귀를 하고 계수를 그려요. 설명 변수는 모두 평균 0, 표준편차 1로 맞춘 값이에요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(11)
>>> N = sd.stats.Normal(mu=0.0, sigma=1.0)
>>> age, income, height = (N.sample((80,), rng=rng) for _ in range(3))
>>> score = 1.0 + 0.8 * age - 0.5 * income + 0.05 * height + N.sample((80,), rng=rng)
>>> df = sd.frame.DataFrame({"age": age, "income": income, "height": height, "score": score})
>>> r = sd.regression.ols(df["score"], df[["age", "income", "height"]])
>>> r.param_names
['const', 'age', 'income', 'height']
>>> fig = sd.plot.coefficients(r).xlabel("coefficient")
```

## 무엇을 하나요

`coefficients`는 결과의 `params`(점)와 `conf_int(alpha=alpha)`(가로 막대)를 계수마다 한 줄로 그려요. 세로축은 범주 축이고 범주는 계수의 이름이에요. 0에는 회색 세로 파선이 있어서, 구간이 그 선을 지나는지가 곧 "그 계수가 유의수준 `alpha`에서 0과 다른가"예요.

그림의 수는 결과의 수 그대로예요.

```python
>>> [round(v, 3) for v in r.params.tolist()]
[0.929, 0.927, -0.468, -0.044]
>>> [round(v, 3) for v in r.conf_int()[1].tolist()]
[0.648, 1.207]
```

위 그림의 age 줄은 점이 0.927, 막대가 0.648에서 1.207까지예요.

절편은 기본으로 빼요. 절편은 "모든 설명 변수가 0일 때의 반응"이라 다른 계수와 뜻이 다르고, 크기도 달라서 함께 그리면 축이 넓어져 다른 계수가 작아 보이기 때문이에요.

## 구간과 절편: alpha, intercept

`alpha=0.01`이면 99% 구간이라 막대가 길어져요. `intercept=True`면 `const` 줄이 맨 위에 붙어요. `color`로 색을 정해요.

```python
>>> fig = sd.plot.coefficients(r, intercept=True, alpha=0.01, color="C3")
```

## 이름과 단위

줄의 이름은 `param_names`를 글자 그대로 적어요. `x_1`처럼 LaTeX 특수 문자가 든 이름도 숨겨서 그대로 보여요. 표가 아니라 배열로 회귀했으면 이름이 `x1`, `x2`, …예요. 이름을 수식으로 보이고 싶으면 [`yticks`](/api/plot/customize/)로 라벨을 바꿔요. 줄의 자리는 맨 아래 줄이 0, 그 위가 1, …이라서, 계수가 `x1`, `x2` 둘이면 `fig.yticks([0.0, 1.0], labels=["$x^2$", "$x$"])`처럼 아래 줄부터 적어요.

계수는 그 변수의 단위에 따라 크기가 정해져요. 나이를 해로 재든 달로 재든 효과는 같은데 계수는 12배 차이가 나요. 단위가 다른 계수를 한 축에 놓고 길이를 견주면 오해하기 쉬워요. 위 예처럼 설명 변수를 표준화(평균을 빼고 표준편차로 나누기)해서 회귀하면 계수끼리 크기를 견줄 수 있어요.

## 받는 결과

`coefficients`는 결과의 형을 보지 않고 `params`와 `conf_int`가 있는지로 가려요. [`ols`](/api/regression/ols/), [`wls`](/api/regression/wls/), [`gls`](/api/regression/gls/), [`rlm`](/api/regression/rlm/), [`quantreg`](/api/regression/quantreg/), [`glm`](/api/regression/glm/)의 결과가 그래요. 설명 변수의 수에는 제한이 없어요.

[`glm`](/api/regression/glm/)의 계수는 링크 척도의 값이에요. 로지스틱 회귀라면 로그 오즈비, 포아송 회귀라면 로그 비율이에요. 그래서 "효과 없음"은 여기서도 0이에요.

```python
>>> counts = sd.round(sd.exp(0.3 + 0.4 * age - 0.2 * income))
>>> g = sd.regression.glm(counts, sd.stack([age, income], axis=1), family="poisson")
>>> fig = sd.plot.coefficients(g).xlabel("log rate ratio")
```

[`ridge`](/api/regression/ridge/), [`lasso`](/api/regression/lasso/) 같은 벌점 회귀의 결과는 신뢰구간(`conf_int`)이 없어서 `TypeError`예요.

## 조심할 점

- 메서드로 두 모형의 계수를 겹치면, 같은 이름의 계수는 같은 줄에 놓여 점과 막대가 겹쳐요. 두 모형을 견주려면 [`grid`](/api/plot/figure/)로 그림 둘을 나란히 두는 편이 읽기 쉬워요.
- 구간은 결과의 `conf_int`라서 회귀에서 고른 표준오차(`cov_type`)를 따라요. 이분산에 강한 표준오차로 회귀했으면 막대도 그 구간이에요.
- 계수가 많으면(수십 개) 세로로 빽빽해져요. 그림의 `height`를 늘려요.

## matplotlib을 아는 분께

- matplotlib에서는 `ax.errorbar(params, range(k), xerr=..., fmt="o")`로 그리고 라벨과 0의 선을 손으로 붙여요. R의 `coefplot`이나 `dotwhisker` 패키지가 그리는 그림과 같은 것이에요.
- 절편은 기본으로 빠져요(`intercept=True`로 넣어요).
