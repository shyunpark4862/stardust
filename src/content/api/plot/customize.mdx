## 한눈에 보기

그림 함수가 돌려준 그림에 제목, 축 이름, 범위, 눈금, 범례를 더해요. 메서드는 모두 `fig` 자신을 돌려주므로 한 줄로 이어 써요.

```python
>>> import math
>>> import stardust as sd
>>> x = sd.linspace(-math.pi, math.pi, 300)
>>> fig = sd.plot.line(x, sd.sin(x), label=r"$\sin x$")
>>> fig = fig.line(x, sd.sin(x) - sd.sin(3 * x) / 3, style="--", label=r"$\sin x - \frac{1}{3}\sin 3x$")
>>> fig = (fig.title("사인 급수")
...           .xlabel(r"$x$").ylabel(r"$f(x)$")
...           .xticks("pi").ylim(-1.5, 1.5))
```

고치는 메서드는 그 칸의 설정만 바꿔요. 여러 칸의 그림에서는 `fig[0, 1].xlabel(...)`처럼 칸을 골라 고쳐요([Figure와 칸](/api/plot/figure/)). 같은 메서드를 다시 부르면 앞의 값을 덮어써요.

## 제목과 축 이름

`title`, `xlabel`, `ylabel`은 칸의 위, 아래, 왼쪽에 글자를 붙여요. 세로축 이름은 90° 돌려 세워요. 글자는 LaTeX 원문이라 수식과 한글을 섞어 써요([글자는 LaTeX 원문이에요](/api/plot/basics/#글자는-latex-원문이에요)).

```python
>>> fig = sd.plot.scatter([1, 2, 3], [2.0, 3.5, 3.9]).xlabel(r"시간 $t$ (s)").ylabel(r"$\|v\|$ (m/s)")
>>> fig.xlabel(3)
Traceback (most recent call last):
    ...
TypeError: xlabel(): 'text' must be a str, not int
```

여백은 붙인 글자의 실제 크기를 재서 정해요. 그림의 바깥 크기는 그대로이고 축이 둘러싼 그림 영역이 그만큼 줄어요. 글자가 그림 밖으로 잘리지 않아요.

`zlabel`은 3D 칸의 세로축(z) 이름이에요. 3D 칸은 `title`, `xlabel`, `ylabel`, `zlabel`, `legend`만 받아요. 상자의 범위는 자료가 정하므로 범위, 척도, 눈금을 고치는 메서드는 `ValueError`예요([3D 칸](/api/plot/view3d/)).

```python
>>> sd.plot.surface(lambda x, y: x * y, -1, 1, -1, 1).xlim(0, 1)
Traceback (most recent call last):
    ...
ValueError: xlim(): a 3D cell has no such axis setting; its ranges are those of the data
```

## 범위: xlim, ylim

범위를 주지 않으면 칸에 그린 모든 층의 자료를 덮고 양쪽으로 범위의 4%씩 넓혀요. 막대와 히스토그램의 바닥(0)처럼 자료가 딱 붙어야 하는 쪽은 넓히지 않아요.

`xlim(low, high)`는 가로 범위를 정해요. 한쪽 끝만 정하려면 다른 쪽에 `None`을 줘요. `None`인 끝은 자료에 맞춰 정해져요.

```python
>>> fig = sd.plot.line([0, 1, 2, 3], [0, 1, 4, 9]).ylim(0, None)
>>> fig = fig.xlim(2, 1)
Traceback (most recent call last):
    ...
ValueError: xlim(): 'low' must be less than 'high'
```

범위 밖의 선과 채움은 칸의 테두리에서 잘려요. 점은 자르지 않아요. 범위 안의 점은 테두리에 걸려도 기호가 온전히 보이고, 범위 밖의 점은 그리지 않아요.

```python
>>> fig = sd.plot.scatter([1.85, 3, 4, 5.1], [3, 1.9, 4, 3]).line([1, 6], [1, 6]).xlim(2, 5).ylim(2, 5)
```

점 넷 가운데 범위 안의 $(4, 4)$ 하나만 찍히고, 선은 칸의 테두리에서 잘려요.

한 칸에 세로축을 둘 두는 `fig.twin()`의 보기에서는 `ylabel`, `ylim`, `yscale`, `yticks`가 오른쪽 축을 고쳐요([두 y축과 작은 그림](/api/plot/twin-inset/)). 여러 칸의 범위를 서로 맞추는 일은 [`grid`](/api/plot/figure/)의 `sharex`, `sharey`가 해요.

## 척도: xscale, yscale

`'log'`는 로그 척도예요. 값이 10배 늘 때마다 같은 길이만큼 가요. 눈금은 10의 거듭제곱($10^{-3}$, $10^{0}$, $10^{3}$)이에요. 거듭제곱이 많으면 몇 개씩 건너뛰어 적고, 하나도 건너뛰지 않을 때는 그 사이에 2, 3, …, 9배 자리의 짧은 보조 눈금이 서요. 범위 안에 10의 거듭제곱이 둘도 들지 않으면 보통의 숫자 눈금을 써요.

로그 축에서 0 이하의 값은 그리지 않아요(선은 그 자리에서 끊겨요). 로그 축에 `xlim`을 주려면 두 끝이 양수여야 해요.

로그 축의 눈금을 `xticks`로 직접 줄 때, 값이 모두 10의 거듭제곱이면 $10^k$ 꼴로 적고, 아닌 값이 하나라도 있으면(1, 2, 4, 8처럼) 모두 보통의 숫자로 적어요. 한 축에 두 꼴이 섞이지 않아요.

## 눈금: xticks, yticks

눈금은 축의 길이에 맞춰 알아서 골라요. 1, 5, 2, 2.5 같은 읽기 쉬운 간격 가운데, 되도록 0을 지나고 범위를 잘 덮고 너무 빽빽하지도 성기지도 않은 것을 골라요. 눈금은 범위 안에만 서요. 한 축의 눈금 숫자는 소수점 아래 자릿수가 모두 같아요. 가로축의 이웃한 숫자가 서로 닿으면 눈금 수를 줄여요.

값이 아주 크거나 작으면(눈금의 가장 큰 값이 $10^5$ 이상이거나 $10^{-3}$보다 작으면) 축 끝에 공통 10의 거듭제곱을 한 번 적고 눈금에는 앞자리만 적어요.

직접 고를 때는 `xticks(values)`예요. `labels=`를 주면 값 대신 그 글자를 적어요. 범위 밖의 값은 빠져요. `xticks("pi")`는 범위에 맞춰 π의 배수를 골라 $\frac{\pi}{2}$, $\pi$, $2\pi$처럼 적어요.

```python
>>> n = sd.asarray([10.0, 30, 100, 300, 1000, 3000, 10000])
>>> t = 2e-6 * n * sd.log(n)
>>> a = sd.plot.line(n, t, label=r"$n \log n$").scatter(n, t, color="C0")
>>> a = a.line(n, 3e-8 * n * n, style="--", label=r"$n^2$")
>>> a = a.xscale("log").yscale("log").xlabel(r"$n$").ylabel("시간 (s)")
>>> b = sd.plot.scatter([1, 2, 3, 4, 5], [2.1e5, 3.9e5, 6.2e5, 7.8e5, 1.01e6]).xlabel("dose (mg)")
>>> c = sd.plot.bar(["A", "B", "C"], [3, 1, 2]).yticks([0, 1, 2, 3], labels=["none", "low", "mid", "high"])
>>> fig = sd.plot.grid([a, b, c], ncols=3, width=183)
```


## 범례: legend

층에 `label=`로 이름을 주거나 `group=`으로 무리를 나누면 범례가 저절로 생겨요. 이름이 같은 층은 범례에 한 번만 나와요. `legend`는 그 범례의 자리, 제목, 열 수를 정해요.

| `loc` | 자리 |
|---|---|
| `'best'`(기본값) | 그려진 것을 가리지 않는 칸 안의 구석. 그런 구석이 없으면 칸 밖(한 줄에 들어가면 위, 아니면 오른쪽) |
| `'upper right'`, `'upper left'`, `'lower left'`, `'lower right'` | 칸 안의 그 구석 |
| `'top'`, `'bottom'` | 칸 위나 아래. 칸의 너비에 들어가는 만큼 한 줄에 늘어놓고 넘치면 줄을 바꿔요 |
| `'right'` | 칸 오른쪽. 그만큼 그림 영역이 좁아져요 |
| `None` | 범례를 그리지 않아요 |

`'best'`는 칸에 그려진 선, 점, 채움을 실제로 칠해 보고 범례 상자가 아무것도 덮지 않는 구석을 골라요. 구석에 둘 수 없을 때 칸 밖으로 나가는 것도 배치가 알아서 해요. 이 페이지 맨 위의 그림과 바로 위 그림의 왼쪽 칸은 `legend`를 부르지 않았고, 범례가 곡선이 지나지 않는 구석에 섰어요. 자리를 고정하고 싶으면 이름을 줘요.

```python
>>> xs = sd.linspace(0, 1, 50)
>>> def powers(**kw):
...     f = sd.plot.Figure(width=60)
...     for k in range(1, 5):
...         f = f.line(xs, xs ** k, label=f"$x^{k}$")
...     return f.legend(**kw).title(kw["loc"])
>>> fig = sd.plot.grid([powers(loc="top"), powers(loc="right"),
...                     powers(loc="upper left", title="power", ncols=2)], ncols=3, width=183)
```

<PlotImage name="customize-legends" alt="같은 곡선 넷(x, x^2, x^3, x^4)을 그린 칸 셋. 왼쪽은 범례가 칸 위에 한 줄로, 가운데는 칸 오른쪽에 세로로, 오른쪽은 칸 안 왼쪽 위에 'power' 제목과 두 열로 놓임" caption="왼쪽부터 loc='top', loc='right', loc='upper left'에 title='power'와 ncols=2를 준 범례예요." />

```python
>>> fig.legend(loc="center")
Traceback (most recent call last):
    ...
ValueError: legend(): 'loc' must be 'best', 'top', 'right', 'bottom', 'upper right', 'upper left', 'lower left' or 'lower right', not 'center'
```

범례의 이름과 제목도 LaTeX 원문이에요. `group=`의 무리 값처럼 자료에서 온 이름은 특수 문자를 알아서 숨겨요.

3D 칸의 범례는 언제나 상자의 오른쪽 밖에 서요. `loc=None`으로 없앨 수 있어요.

## 조심할 점

- **고치는 메서드는 그 칸만 고쳐요.** 칸이 여럿인 그림에서 `fig.xlabel(...)`은 첫 칸에 붙어요. 모든 칸에 붙이려면 `for cell in fig.axes:`로 돌아요.
- **범위를 주면 자동 범위를 쓰지 않아요.** 함수 그림의 극점 둘레를 잘라 주는 자동 범위도 `ylim`을 주면 꺼져요([function](/api/plot/function/)).
- **눈금 값을 줘도 범위는 그대로예요.** 범위 밖의 눈금은 빠질 뿐 범위를 늘리지 않아요. 눈금을 모두 보이려면 `xlim`도 함께 줘요.
- **로그 축과 음수.** 0 이하의 값이 든 자료를 로그 축으로 그리면 그 점들이 말없이 빠져요. 자료가 양수인지 먼저 봐요.

## matplotlib을 아는 분께

| matplotlib | sd.plot |
|---|---|
| `ax.set_title`, `ax.set_xlabel`, `ax.set_ylabel` | `fig.title`, `fig.xlabel`, `fig.ylabel` |
| `ax.set_xlim(left=2)` | `fig.xlim(2, None)` |
| `ax.set_xscale('symlog')` | 없어요. `'linear'`와 `'log'`만 |
| `ax.set_xticks(v, labels=s)` | `fig.xticks(v, labels=s)` |
| π 눈금은 `FuncFormatter`로 직접 | `fig.xticks("pi")` |
| `ax.legend(loc='best', frameon=...)` | `fig.legend(loc='best')`. 범례에 테두리가 없어요 |
| `bbox_to_anchor`로 칸 밖에 | `loc='top'`, `'right'`, `'bottom'` |
