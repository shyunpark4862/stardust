## 한눈에 보기

분포 객체를 넘기면 그 분포의 모양을 그려요. 연속 분포는 밀도의 곡선, 이산 분포는 확률의 막대예요.

```python
>>> import stardust as sd
>>> gam = sd.stats.Gamma(a=2.0, scale=1.0)
>>> binom = sd.stats.Binomial(n=20, p=0.3)
>>> fig = sd.plot.grid([sd.plot.distribution(gam).xlabel("$x$"),
...                     sd.plot.distribution(binom).xlabel("$k$")],
...                    ncols=2, width=160)
```

## 무엇을 하나요

`distribution`은 [`sd.stats`](/api/stats/basics/)의 분포 객체에서 함수를 꺼내 그려요.

| `kind` | 연속 분포 | 이산 분포 |
|---|---|---|
| `'pdf'` | `dist.pdf`의 곡선 | `dist.pmf`의 막대 |
| `'cdf'` | `dist.cdf`의 곡선 | `dist.cdf`의 계단 |
| `'sf'` | `dist.ccdf`의 곡선 | `dist.ccdf`의 계단 |

연속 분포의 곡선은 [`function`](/api/plot/function/)과 같은 방법으로 그려요. 곡선이 빨리 휘는 곳에 표본을 더 두므로 봉우리가 뾰족해도 매끈해요. 그래서 그 그림이 한 일이 [`fig.info`](/api/plot/function/)에 남아요. 이산 분포는 `[a, b]` 안의 정수 k마다 값을 하나씩 계산해요. 막대는 k를 가운데에 두고, 계단은 k에서 오른쪽으로 다음 정수까지 이어져요(누적분포가 오른쪽 연속이니까요). 값이 정수에만 있으므로 가로 눈금도 정수에만 놓여요. 위 그림의 눈금은 0, 5, 10이에요.

그림의 수는 분포 객체가 주는 수 그대로예요.

```python
>>> fig = sd.plot.distribution(binom)
>>> float(binom.pmf(6.0))
0.19163898275344257
```

위 막대 그림에서 k = 6의 막대 높이가 이 값이에요.

## 범위: a와 b

`a`, `b`를 주지 않으면 가로 범위는 분포의 0.001 분위수에서 0.999 분위수까지예요. 확률의 99.8%가 그 안에 있어요. 다만 받침의 끝이 이 분위수 가까이 있으면 끝까지 그려요. 감마 분포는 0.001 분위수가 0.045쯤이지만 받침이 0에서 시작하므로 0부터 그려요.

```python
>>> fig = sd.plot.distribution(gam)
>>> round(float(gam.icdf(0.001)), 3), round(float(gam.icdf(0.999)), 3)
(0.045, 9.233)
>>> fig.info[0].kind
'function'
```

꼬리가 두꺼운 분포는 0.999 분위수가 아주 멀어요. 정규분포와 자유도가 작은 t 분포를 겹쳐 보면, 그대로 두면 자유도 1의 t 분포(코시 분포)가 범위를 ±318까지 넓혀요. 그럴 때 `a`, `b`로 범위를 정해요.

```python
>>> t1 = sd.stats.StudentT(df=1.0)
>>> round(float(t1.icdf(0.999)), 1)
318.3
>>> fig = sd.plot.distribution(sd.stats.Normal(mu=0.0, sigma=1.0), a=-5, b=5, label="$N(0, 1)$")
>>> fig = fig.distribution(sd.stats.StudentT(df=3.0), a=-5, b=5, label="$t_3$")
>>> fig = fig.distribution(t1, a=-5, b=5, label="$t_1$").xlabel("$x$")
```

<PlotImage name="distribution-tails" alt="−5에서 5까지 세 밀도 곡선. 파란 표준정규분포가 가운데에서 가장 높고 양 끝에서 가장 빨리 0에 붙고, 노란 t3과 회색 t1은 봉우리가 낮고 꼬리가 두꺼워요. 오른쪽 위에 범례가 있어요." caption="세 분포를 메서드로 겹쳤어요. 자유도가 작을수록 봉우리가 낮고 꼬리가 두꺼워요. 범위를 −5에서 5로 정해 세 곡선의 모양을 견줄 수 있게 했어요." />

곡선마다 범위를 따로 잡으므로, 메서드로 겹칠 때 범위를 주지 않으면 곡선의 길이가 서로 달라요. 견주려는 곡선에는 같은 `a`, `b`를 주세요.

## 누적분포와 생존함수

`kind='cdf'`는 $P(X \le x)$, `kind='sf'`는 $P(X > x) = 1 - P(X \le x)$예요. 생존함수는 `1 - cdf`를 빼서 구하지 않고 분포의 `ccdf`를 불러서, 꼬리의 아주 작은 확률도 정확해요.

```python
>>> N = sd.stats.Normal(mu=0.0, sigma=1.0)
>>> fig = sd.plot.distribution(N, kind="cdf", label="cdf").distribution(N, kind="sf", label="sf")
>>> fig = sd.plot.distribution(binom, kind="cdf")
```

이산 분포의 누적분포는 정수에서 뛰는 계단이에요.

## 자료와 견주기

표본의 히스토그램을 밀도로(`density=True`) 그리고 그 위에 모형의 밀도를 겹치면, 모형이 자료를 따르는지 눈으로 볼 수 있어요. [`histogram`](/api/plot/histogram/)의 막대 높이는 [`sd.histogram`](/api/array/histogram/)이 주는 밀도라, 곡선과 같은 단위예요.

```python
>>> model = sd.stats.Gamma(a=3.0, scale=2.0)
>>> x = model.sample((300,), rng=sd.random.default_rng(1))
>>> fig = sd.plot.histogram(x, bins=20, density=True, alpha=0.5, label="sample")
>>> fig = fig.distribution(model, color="C1", label="Gamma(3, 2)").xlabel("$x$").ylabel("density")
```

<PlotImage name="distribution-histogram" alt="옅은 파란 막대의 히스토그램 위에 노란 감마 분포의 밀도 곡선이 겹쳐 있어요. 곡선이 막대의 윤곽을 대체로 따라가요." caption="Gamma(a=3, scale=2)에서 뽑은 표본 300개의 히스토그램과 그 분포의 밀도예요. 막대가 곡선을 둘레로 오르내리는 정도가 표본의 흔들림이에요." />

표본의 막대는 밀도의 봉우리보다 높이 솟을 수 있어요. 밀도가 바라는 세로 범위는 봉우리까지이지만, 같은 칸의 다른 층이 더 높으면 세로축이 그 층까지 넓어져요. 그래서 가장 높은 막대도 잘리지 않아요.

모형을 자료로 추정했다면 그 추정값으로 분포 객체를 만들어 넘기면 돼요. 겹쳐 본 뒤에는 [`qq`](/api/plot/qq/)로 꼬리까지 보거나, [`ks_1samp`](/api/htest/ks_1samp/) 같은 적합도 검정으로 수를 확인하세요.

## 밀도의 세로 범위

밀도 그림에서 가장 보고 싶은 것은 봉우리예요. 그래서 `kind='pdf'`의 세로축은 0에서 시작해 봉우리의 조금 위까지 가요. 꼬리가 길어 가로 범위가 넓은 분포도 봉우리가 잘리지 않아요. 로그정규분포는 0.999 분위수가 22쯤이라 봉우리가 왼쪽 끝에 좁게 몰리지만, 봉우리 0.658까지 다 보여요.

```python
>>> ln = sd.stats.LogNormal(mu=0.0, sigma=1.0)
>>> fig = sd.plot.distribution(ln)
>>> fig.info[0].clipped
(False, False)
>>> round(fig.info[0].ylim[1], 3)
0.658
```

밀도가 범위의 끝에서 한없이 커지는 분포는 봉우리가 없어요. 모양 매개변수가 1보다 작은 감마 분포가 그래요. 이럴 때는 [`function`](/api/plot/function/)이 극점을 다루는 방법 그대로, 곡선의 대부분이 잘 보이는 범위에서 자르고 `fig.info`의 `clipped`에 잘랐다고 남겨요. `clipped`의 둘째 값이 위쪽, 첫째 값이 아래쪽이에요.

```python
>>> fig = sd.plot.distribution(sd.stats.Gamma(a=0.5, scale=1.0)).xlabel("$x$")
>>> fig.info[0].clipped
(False, True)
```

<PlotImage name="distribution-pole" alt="왼쪽 끝 0에서 칸의 위 끝까지 솟았다가 오른쪽으로 빠르게 내려가 0에 붙는 감마 분포의 밀도 곡선" caption="Gamma(a=0.5)의 밀도는 0에서 한없이 커져요. 세로 범위를 곡선의 대부분이 보이는 데서 잘랐어요." />

자른 높이를 바꾸려면 [`ylim`](/api/plot/customize/)으로 세로 범위를 수로 정해요. `'cdf'`와 `'sf'`는 0과 1 사이의 값이라 범위를 따로 맞추지 않아요.

## 에러

```python
>>> sd.plot.distribution(3)

    ...
TypeError: distribution(): 'dist' must be an sd.stats distribution, not int
>>> sd.plot.distribution(gam, kind="pmf")
Traceback (most recent call last):
    ...
ValueError: distribution(): 'kind' must be 'pdf', 'cdf' or 'sf', not 'pmf'
>>> sd.plot.distribution(gam, a=3, b=1)
Traceback (most recent call last):
    ...
ValueError: distribution(): 'a' must be less than 'b'
>>> sd.plot.distribution(sd.stats.Normal(mu=sd.asarray([0.0, 1.0]), sigma=1.0))
Traceback (most recent call last):
    ...
ValueError: distribution(): a batch of distributions cannot be drawn; give one
```

이산 분포의 확률질량은 `kind='pdf'`로 그려요. `'pmf'`라는 값은 없어요.

## 조심할 점

- 매개변수가 배열인 분포(예: `Normal(mu=sd.asarray([0.0, 1.0]), sigma=1.0)`)는 `ValueError`예요. 분포마다 객체를 따로 만들어 메서드로 겹쳐요.
- 밀도의 세로 범위는 칸에 못 박지 않아요. 봉우리가 더 높은 밀도나 히스토그램을 같은 칸에 그리면 그리는 차례와 상관없이 세로축이 가장 높은 층까지 넓어져요. 범위를 고정하려면 [`ylim`](/api/plot/customize/)을 줘요.
- 다변량 분포(`MultivariateNormal` 등)는 `icdf`가 없어서 받지 않아요. 두 변수의 밀도는 `pdf`를 두 변수 x, y의 함수로 감싸 [`density`](/api/plot/density/)나 [`contour`](/api/plot/contour/)로 그려요.
- 이산 분포의 정수 눈금은 눈금을 정하지 않은 칸에만 놓아요. [`xticks`](/api/plot/customize/)로 먼저 준 눈금이 있으면 그대로 둬요.
- 이산 분포의 `a`, `b`가 정수가 아니면 그 안의 정수만 그려요. `a=-0.5, b=6.5`는 0부터 6까지예요.

## matplotlib을 아는 분께

- matplotlib에는 분포를 받는 함수가 없어서 `x = np.linspace(...)`와 `ax.plot(x, dist.pdf(x))`로 범위와 점을 손으로 정해요. `distribution`은 범위와 표본을 알아서 골라요. Mathematica의 `Plot[PDF[dist, x], ...]`에서 범위까지 정해 주는 것과 비슷해요.
- 이산 분포를 `plot`으로 이으면 정수 사이에 없는 값이 이어져 보이는데, 여기서는 막대와 계단으로 그려요.
