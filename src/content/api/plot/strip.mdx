## 한눈에 보기

투여량이 다른 세 무리에서 반응을 40번씩 쟀어요. 상자 그림처럼 요약하지 않고 값을 하나도 빼지 않고 다 보고 싶을 때 **점 흩기 그림**(strip plot)을 그려요. 첫 인자가 범주, 둘째 인자가 값이에요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> a = sd.stats.Normal(mu=5.0, sigma=1.0).sample(40, rng=rng)
>>> b = sd.stats.Normal(mu=6.2, sigma=1.3).sample(40, rng=rng)
>>> c = sd.stats.Normal(mu=7.8, sigma=0.9).sample(40, rng=rng)
>>> df = sd.frame.DataFrame({"dose": ["control"] * 40 + ["low"] * 40 + ["high"] * 40, "response": sd.concat([a, b, c])})
>>> fig = sd.plot.strip("dose", "response", data=df).ylabel("response")
```

<PlotImage name="strip-dose" alt="control, low, high 세 범주마다 값 40개를 점으로 찍어 옆으로 조금씩 흩은 그림" caption="세 무리의 값 120개를 모두 찍은 그림. 점을 옆으로 조금씩 흩어서 같은 높이의 값도 겹치지 않아요." />

점의 세로 자리가 값이고, 가로 자리는 범주의 자리에서 조금씩 비껴 있어요. 가로로 비낀 양에는 아무 뜻이 없어요. 같은 범주 안에서 비슷한 값의 점이 한 자리에 포개지지 않게 하려는 것뿐이에요.

## 흩는 폭: `jitter`

`jitter`는 점을 옆으로 흩는 폭이에요. 범주 사이의 간격이 1이므로, 기본값 0.2는 범주의 자리에서 왼쪽과 오른쪽으로 0.1씩이에요. 0이면 한 줄로 찍어요.

```python
>>> fig = sd.plot.grid([sd.plot.strip("dose", "response", data=df, jitter=0.0),
...                     sd.plot.strip("dose", "response", data=df, jitter=0.6)], ncols=2, width=160, labels="A")
```

<PlotImage name="strip-jitter" alt="같은 자료를 왼쪽은 흩지 않고 한 줄로, 오른쪽은 넓게 흩어 찍은 두 그림" caption="A는 jitter=0, B는 jitter=0.6이에요. A는 비슷한 값의 점이 포개져 수를 세기 어렵고, B는 점이 넓게 퍼져요." />

흩는 폭은 값이 많을수록 넓게 주는 편이 좋아요. 다만 1에 가까우면 이웃한 범주의 점과 닿아요.

## 같은 호출은 같은 그림: `rng`

가로 자리는 난수로 정해요. `rng=None`(기본값)이면 부를 때마다 씨 0의 생성기를 만들어 쓰므로, 같은 자료로 부르면 몇 번을 불러도 점이 같은 자리에 놓여요. 같은 기계, 같은 스레드 수, 같은 입력이면 저장한 파일도 같은 바이트예요.

```python
>>> s1 = sd.plot.strip("dose", "response", data=df).to_svg()
>>> s2 = sd.plot.strip("dose", "response", data=df).to_svg()
>>> s1 == s2
True
```

다른 배치를 보고 싶으면 `rng`에 다른 씨(int)를 줘요. [`sd.random`](/api/random/default_rng/)의 생성기를 줄 수도 있는데, 그러면 그 생성기에서 난수를 꺼내 쓰므로 생성기의 상태가 나아가요. 같은 생성기로 두 번 부르면 두 그림의 점 배치가 달라요.

```python
>>> sd.plot.strip("dose", "response", data=df, rng=5).to_svg() == s1
False
>>> g = sd.random.default_rng(5)
>>> t1 = sd.plot.strip("dose", "response", data=df, rng=g).to_svg()
>>> t2 = sd.plot.strip("dose", "response", data=df, rng=g).to_svg()
>>> t1 == t2
False
```

## 상자 그림과 함께

점 흩기 그림은 [`boxplot`](/api/plot/boxplot/)과 잘 어울려요. 상자가 사분위를 요약하고, 점이 값의 수와 몰린 곳을 보여요. 같은 칸에 메서드 `fig.strip`으로 더해요. 점이 상자를 가리지 않게 회색에 반투명으로 작게 찍어요.

```python
>>> fig = sd.plot.boxplot("dose", "response", data=df)
>>> fig = fig.strip("dose", "response", data=df, color="gray", alpha=0.5, size=2.0).ylabel("response")
```

<PlotImage name="strip-box" alt="세 범주의 상자 그림 위에 회색 반투명 점으로 모든 값을 흩어 찍은 그림" caption="상자 그림 위에 얹은 점 흩기 그림." />

두 층이 같은 범주 축을 함께 써요. 범주의 라벨이 같으면 같은 자리에 놓이고, 나중 층에 새 라벨이 있으면 오른쪽에 이어 붙어요.

## 무리 나누기: `group`

`group=`을 주면 범주 안에서 무리마다 점 무더기를 나란히 세우고, 무리마다 다른 색과 범례를 붙여요. 열 이름 대신 값과 길이가 같은 라벨의 시퀀스를 줘도 돼요.

```python
>>> sex = (["F"] * 20 + ["M"] * 20) * 3
>>> fig = sd.plot.strip("dose", "response", data=df, group=sex).ylabel("response")
```

<PlotImage name="strip-group" alt="세 범주마다 F와 M 두 무리의 점 무더기가 나란히 선 그림" caption="범주마다 무리 둘의 점이 나란히 서요." />

무리가 k개면 범주 하나의 너비 0.8을 k로 나눠 무리마다 자리를 주고, 흩는 폭도 `jitter/k`로 줄여서 이웃한 무리의 점과 섞이지 않게 해요.

## 점의 꼴

`color=`는 점의 색, `size=`는 점의 지름(pt), `alpha=`는 불투명도예요. 점의 모양은 동그라미 하나예요. 다른 모양이 필요하면 [`scatter`](/api/plot/scatter/)를 써요.

## 조심할 점

- 가로 자리는 뜻이 없어요. 점이 범주의 왼쪽에 몰려 보여도 난수가 그렇게 나온 것일 뿐이에요.
- 값이 수천 개면 점이 너무 빽빽해서 흩어도 겹쳐요. 그럴 때는 [`boxplot`](/api/plot/boxplot/)이나 [`histogram`](/api/plot/histogram/)이 나아요.
- `x`에 수를 주면 수를 글자로 바꿔 범주로 써요. 수의 크기대로 자리를 잡지 않아요.

## matplotlib을 아는 분께

- matplotlib에는 이 그림이 따로 없어서 `scatter`에 흩은 가로 자리를 직접 만들어 넣어요. 여기서는 범주와 값만 주면 돼요. seaborn의 `stripplot`, ggplot2의 `geom_jitter`에 해당해요.
- 흩는 난수는 전역 상태를 쓰지 않아요. 기본이 고정한 씨라서 난수의 씨를 따로 맞추지 않아도 같은 호출은 같은 그림이에요.
