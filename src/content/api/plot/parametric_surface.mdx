## 한눈에 보기

`parametric_surface(fx, fy, fz, u0, u1, v0, v1)`은 매개변수 $(u, v)$가 직사각형 $[u_0, u_1] \times [v_0, v_1]$을 훑을 때 점

$$
\big(x(u, v),\ y(u, v),\ z(u, v)\big)
$$

가 그리는 곡면이에요. 아래는 큰 반지름 2, 작은 반지름 1의 원환면(도넛)이에요. $u$는 큰 원을 따라, $v$는 관의 단면을 따라 한 바퀴씩 돌아요.

```python
>>> import math
>>> fig = sd.plot.parametric_surface(
...     lambda u, v: (2 + sd.cos(v)) * sd.cos(u),
...     lambda u, v: (2 + sd.cos(v)) * sd.sin(u),
...     lambda u, v: sd.sin(v),
...     0, 2 * math.pi, 0, 2 * math.pi)
```

<PlotImage name="parametric-surface-torus" format="png" alt="원환면(도넛). 높이에 따라 아래는 하늘색, 위는 빨강이고, 곡면 위에 큰 원을 따라 도는 선과 관을 감싸는 선이 격자를 이뤄요. 상자는 가로세로 6, 높이 2로 납작해요." caption="원환면. 상자가 자료의 비율(6 : 6 : 2)을 따르므로 도넛이 제 모양으로 보여요." />

그래프 $z = f(x, y)$는 한 $(x, y)$에 높이가 하나뿐이라 구, 원환면, 띠처럼 겹쳐 접히는 곡면을 그릴 수 없어요. 매개변수 곡면은 이런 곡면을 그려요. 그래프로 쓸 수 있는 곡면은 [`surface`](/api/plot/surface/)가 더 간단해요.

## 함수 셋 넘기기

`fx`, `fy`, `fz`는 저마다 배열 둘 `(u, v)`를 받아 같은 모양의 배열을 돌려줘요. 격자의 점을 모두 모아 함수마다 **배열 한 번으로** 불러요. 수 하나를 돌려주면 상수예요. 평면 $z = 0$ 위의 원판은 `lambda u, v: 0.0`을 `fz`로 쓰면 돼요.

```python
>>> calls = []
>>> def fx(u, v):
...     calls.append(u.shape)
...     return sd.cos(u) * sd.sin(v)
>>> fig = sd.plot.parametric_surface(fx, lambda u, v: sd.sin(u) * sd.sin(v),
...                                  lambda u, v: sd.cos(v), 0, 2 * math.pi, 0, math.pi)
>>> calls
[(121, 121)]
```

위는 단위 구예요. 매끈한 곡면이라 첫 격자(121 × 121) 한 번으로 끝났어요.

## 상자는 자료의 비율

`parametric_surface`, [`curve3d`](/api/plot/curve3d/), [`scatter3d`](/api/plot/scatter3d/)만 든 칸의 상자는 자료의 비율을 따라요. 세 축에서 자료의 한 단위가 같은 길이라서 구는 둥글고 원환면은 납작해요. 같은 칸에 [`surface`](/api/plot/surface/)를 더하면 상자는 그래프의 비율(1 : 1 : 0.72)이 되고 세 축이 저마다의 척도를 가져요.

## 색과 매개변수 선

- 아무것도 주지 않으면 칸에 곡면이 하나일 때 높이 $z$에 따른 색띠 `'cool'`이에요. 여럿이면 곡면마다 팔레트의 색이에요.
- `cmap=`은 높이 $z$에 따른 색띠, `color=`는 한 색이에요. 둘을 함께 주면 에러예요.
- `mesh`는 곡면 위의 **매개변수 선**이에요. $u$가 일정한 선과 $v$가 일정한 선이 저마다 24칸으로 고르게 깔려요. 원환면에서는 큰 원과 관의 단면이 격자선이 돼요. 정수를 주면 그 칸 수, `False`면 선이 없어요.

`surface`의 `zlim`과 바닥 등고선 `contours`는 그래프에만 있어서 받지 않아요.

## 두 면을 똑같이 밝혀요

곡면의 앞면과 뒷면을 똑같이 밝혀요. 뫼비우스 띠처럼 앞뒤가 이어진 곡면도 한쪽이 어둡게 꺼지지 않아요.

```python
>>> fig = sd.plot.parametric_surface(
...     lambda u, v: (1 + v / 2 * sd.cos(u / 2)) * sd.cos(u),
...     lambda u, v: (1 + v / 2 * sd.cos(u / 2)) * sd.sin(u),
...     lambda u, v: v / 2 * sd.sin(u / 2),
...     0, 2 * math.pi, -1, 1, color="C1")
```

## 표본: samples와 refine

표본을 고르는 법은 [`surface`](/api/plot/surface/#표본-samples와-refine)와 같아요. $(u, v)$의 첫 격자(기본 121 × 121)에서 재고, 꺾이는 칸과 정의역의 가장자리(꼭짓점의 일부만 값이 있는 칸)만 4 × 4로 나눠 다시 재요. 다시 잰 칸이 아직 모자라면 한 번 더 나눠 첫 격자의 16배까지 촘촘해져요. 칸의 40%가 넘게 모자라면 격자 전체를 3배로 다시 재요.

| 인자 | 기본값 | 뜻 |
|---|---|---|
| `samples` | 121 × 121 | 첫 격자의 점의 수. 수 하나(두 방향 같게)나 `(u 방향, v 방향)`, 3–2000 |
| `refine` | 2 | 모자란 칸을 다시 나누는 횟수의 한계. 한 번에 4 × 4. `0`이면 첫 격자만 써요 |

`samples`의 쌍은 매개변수의 두 방향이에요. 한쪽으로 길게 늘어난 띠는 긴 쪽에 점을 더 주면 고르게 보여요(`samples=(241, 41)` 등).

## 다른 층과 겹치기

같은 칸에 메서드로 곡면, 곡선, 점을 더해요. 반투명한 곡면 안에 다른 것을 넣어 보이려면 `alpha`를 줘요.

```python
>>> sphere = (lambda u, v: sd.cos(u) * sd.sin(v), lambda u, v: sd.sin(u) * sd.sin(v),
...           lambda u, v: sd.cos(v))
>>> fig = sd.plot.parametric_surface(*sphere, 0, 2 * math.pi, 0, math.pi, alpha=0.3)
>>> fig = fig.curve3d(lambda t: 0.6 * sd.cos(t), lambda t: 0.6 * sd.sin(t),
...                   lambda t: t / (4 * math.pi) - 0.5, 0, 4 * math.pi)
```

반투명 곡면과 깊이, 시점의 규칙은 [3D 칸과 시점](/api/plot/view3d/)에 있어요.

## 조심할 점

- 닫힌 곡면(구, 원환면)은 매개변수의 끝이 맞물리도록 범위를 정확히 줘요. 원환면의 $u$를 $[0, 6]$으로 주면 $2\pi$까지 닿지 않아 한 조각이 빠져요.
- 매개변수가 한 점으로 모이는 곳(구의 극 $v = 0, \pi$)에서는 격자의 칸이 아주 좁아져요. 그림에는 문제가 없지만 매개변수 선이 그 점에 모여 촘촘해 보여요.
- 높이 범위는 값의 대부분으로 잡으므로, 몇 점만 아주 멀리 달아나는 곡면은 그 부분이 상자의 면에서 잘려요.

## matplotlib을 아는 분께

matplotlib에서는 `u, v = np.meshgrid(...)`로 격자를 만들고 `X, Y, Z`를 계산해 `plot_surface(X, Y, Z)`에 넘겨요. `parametric_surface`는 세 함수와 범위를 받아 격자를 스스로 정하고, 꺾이는 곳과 가장자리만 더 촘촘히 재요. 교차하거나 스스로 겹치는 곡면(클라인 병 등)도 깊이 버퍼로 옳게 가려져요. matplotlib처럼 상자의 비율을 `set_box_aspect`로 맞출 필요가 없어요. 자료의 비율이 기본이에요.
