## 한눈에 보기

변수 넷 사이의 상관계수를 구했어요. 4 × 4 행렬의 수 열여섯 개를 표로 읽는 것보다, 칸마다 값을 색으로 칠하면 어느 짝이 강하게 얽혀 있는지 바로 보여요. 이런 그림이 **열지도**(heat map)예요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(2)
>>> N = sd.stats.Normal(mu=0.0, sigma=1.0)
>>> z1, z2, z3 = N.sample(100, rng=rng), N.sample(100, rng=rng), N.sample(100, rng=rng)
>>> h, w, a, s = z1, 0.8 * z1 + 0.6 * z2, z3, -0.7 * z3 + 0.7 * z2
>>> r = sd.corrcoef(sd.stack([h, w, a, s]))
>>> names = ["height", "weight", "age", "score"]
>>> fig = sd.plot.heatmap(r, xlabels=names, ylabels=names, cmap="rdbu", vmin=-1, vmax=1, annotate=".2f")
```

<PlotImage name="heatmap-corr" alt="height, weight, age, score 네 변수의 상관 행렬 열지도. 대각선은 짙은 파랑, height와 weight는 파랑, age와 score는 빨강이에요." caption="상관 행렬의 열지도. 파랑이 양의 상관, 빨강이 음의 상관이고, 칸마다 그 값을 적었어요." />

행렬의 0번 행이 맨 위, 0번 열이 맨 왼쪽이에요. 표를 읽는 순서 그대로예요. 대각선은 자기 자신과의 상관이라 1이고, height와 weight, age와 score의 칸이 짙어요. 칸의 수는 `sd.corrcoef`가 낸 값을 소수 둘째 자리까지 적은 것이에요(`annotate=".2f"`).

```python
>>> [[round(v, 2) for v in row] for row in r.tolist()]
[[1.0, 0.81, 0.07, 0.01], [0.81, 1.0, 0.01, 0.47], [0.07, 0.01, 1.0, -0.68], [0.01, 0.47, -0.68, 1.0]]
```

## 색띠: `cmap`, `vmin`, `vmax`

값을 색으로 바꾸는 규칙이 **색띠**예요. `vmin`의 값이 색띠의 한 끝, `vmax`의 값이 다른 끝의 색이고, 그 사이는 고르게 이어져요. `vmin`, `vmax`를 주지 않으면 유한한 값의 최솟값과 최댓값을 써요.

상관 행렬처럼 0을 가운데 두고 양쪽을 견주는 값에는 가운데가 밝고 양 끝이 다른 색인 색띠(`'rdbu'`, `'coolwarm'`, `'spectral'`)를 쓰고, `vmin=-1, vmax=1`처럼 0을 가운데 두어요. 그래야 같은 색이 같은 크기의 상관을 뜻해요. 앞의 그림이 그렇게 그린 것이에요.

크기만 있는 값(개수, 농도)에는 한쪽으로 고르게 밝아지는 색띠가 알맞아요. 상점 넷의 요일별 손님 수를 기본 색띠로 칠해 볼게요.

```python
>>> visits = [[120, 135, 128, 140, 190, 260, 240],
...           [ 80,  85,  90,  88, 110, 150, 170],
...           [200, 210, 205, 215, 230, 180, 120],
...           [ 60,  58,  65,  70,  95, 140, 155]]
>>> days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
>>> fig = sd.plot.heatmap(visits, xlabels=days, ylabels=["A", "B", "C", "D"], cmap="viridis").ylabel("store")
```

<PlotImage name="heatmap-visits" alt="상점 A부터 D까지의 요일별 손님 수 열지도. A, B, D는 주말 칸이 밝고 C는 평일 칸이 밝아요." caption="요일별 손님 수. 오른쪽의 색띠가 색과 값의 대응을 보여요." />

`cmap`을 주지 않으면 `'cool'`이에요. 고를 수 있는 색띠는 아홉 개이고, 모양은 [스타일](/api/plot/style/) 페이지에서 견줘 볼 수 있어요. `colorbar=False`면 오른쪽의 색띠를 빼요. 칸 안에 값을 적었다면 색띠가 없어도 읽을 수 있어요.

## 칸 안의 수: `annotate`

`annotate=True`면 칸마다 값을 적어요. 값마다 따로 유효숫자 세 자리로 적으므로, 0.807과 0.00869가 함께 있으면 `0.807`, `0.00869`예요. 작은 값 하나 때문에 다른 칸의 자릿수가 길어지지 않아요. 글자 색은 칸의 색이 밝으면 검정, 어두우면 흰색이에요.

```python
>>> fig = sd.plot.heatmap(visits, xlabels=days, ylabels=["A", "B", "C", "D"], annotate=True, colorbar=False)
```

<PlotImage name="heatmap-annotate" alt="요일별 손님 수 열지도의 칸마다 그 수를 적은 그림. 색띠는 없어요." caption="칸마다 값을 적고 색띠를 뺀 그림." />

모든 칸을 같은 꼴로 적고 싶으면 `annotate`에 Python의 수 서식을 문자열로 줘요. `format(값, 서식)`이 받는 서식 그대로이고, [`bar`](/api/plot/bar/)의 `annotate`와 같아요.

| `annotate` | 0.807 | 1234.5 |
|---|---|---|
| `True` | 0.807 | $1.23\times10^{3}$ |
| `'.2f'` | 0.81 | 1234.50 |
| `'.0%'` | 81% | 123450% |
| `',.0f'` | 1 | 1,234 |

앞의 상관 행렬은 `'.2f'`로 모든 칸을 소수 둘째 자리에 맞췄어요. 비율의 표는 `'.0%'`가 알맞아요.

```python
>>> share = [[0.42, 0.35, 0.23], [0.18, 0.31, 0.51]]
>>> fig = sd.plot.heatmap(share, xlabels=["A", "B", "C"], ylabels=["2025", "2026"], annotate=".0%", colorbar=False)
```

<PlotImage name="heatmap-percent" alt="2행 3열 열지도의 칸마다 42%, 35%, 23%, 18%, 31%, 51%가 적힌 그림" caption="비율을 annotate='.0%'로 적은 그림." />

수의 서식이 아닌 문자열은 `ValueError`예요.

```python
>>> sd.plot.heatmap(share, annotate="{:.2f}")
Traceback (most recent call last):
    ...
ValueError: heatmap(): 'annotate' is not a format spec for numbers: '{:.2f}'
```

칸이 많으면 글자가 칸보다 커져 겹쳐요. 칸 안의 수는 행과 열이 열 개 안팎일 때까지 쓰는 편이 좋아요.

## 라벨과 축

`xlabels`는 열마다, `ylabels`는 행마다(위에서부터) 붙일 라벨이에요. 문자열의 리스트나 튜플이고 길이가 열·행의 수와 같아야 해요. 라벨은 LaTeX 원문이라 수식을 쓸 수 있어요(`r"$x_1$"`). 주지 않으면 행과 열의 번호예요.

축 전체의 이름은 `fig.xlabel`, `fig.ylabel`로 붙여요. 칸의 자리는 행과 열의 번호이고, 칸 하나의 너비와 높이가 1이에요. 그래서 열지도 위에 다른 층을 얹을 때는 열 번호 j, 행 번호 i인 칸의 가운데가 (j, 행의 수 − 1 − i)예요.

## NaN인 칸

NaN인 칸은 칠하지 않고 비워 둬요. `annotate=True`여도 수를 적지 않아요. 색띠의 범위는 유한한 값만으로 정해요.

```python
>>> grid = [[1.0, 2.0, float("nan")], [4.0, 5.0, 6.0]]
>>> fig = sd.plot.heatmap(grid, annotate=True)
```

<PlotImage name="heatmap-nan" alt="2행 3열 열지도에서 오른쪽 위 칸만 비어 있는 그림" caption="NaN인 오른쪽 위 칸은 비어 있어요." />

## 조심할 점

- 열지도는 이미 계산한 값의 격자를 그려요. 함수 f(x, y)의 값을 색으로 보이려면 [`density`](/api/plot/density/)가 알맞아요. 함수를 받아 표본을 알아서 고르고, 축이 x와 y의 값이에요.
- 모든 값이 같으면 그 값을 가운데 두고 ±0.5를 색띠의 범위로 써요.
- 자료의 짝 (x, y)가 평면의 어느 칸에 몇 개 드는지 세어 칠하려면 [`hist2d`](/api/plot/hist2d/)가 세기까지 해 줘요. 열지도는 이미 센 표를 받아요.
- 칸은 정사각형으로 고정되지 않고, 그림의 크기에 맞춰 늘어나요. 칸을 정사각형에 가깝게 하려면 `width`와 `height`를 행과 열의 수에 맞춰 줘요.

## matplotlib을 아는 분께

- `imshow`·`pcolormesh`에 해당하는 이름은 `heatmap` 하나예요. 0번 행이 위인 것은 `imshow`의 기본과 같아요.
- 칸 안의 수와 색띠가 인자 하나씩이라 따로 그리지 않아도 돼요.
- 색띠는 이름으로만 골라요. 색의 목록으로 만든 색띠나 `Normalize`·로그 척도는 없어요. 로그 척도가 필요하면 `sd.log10`으로 바꾼 값을 칠해요.
