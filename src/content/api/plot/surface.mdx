## 한눈에 보기

`surface(f, x0, x1, y0, y1)`은 직사각형 $[x_0, x_1] \times [y_0, y_1]$ 위에서 높이가 $z = f(x, y)$인 곡면을 그려요. 함수를 그대로 넘기면 돼요. 격자를 만들거나 값을 미리 계산할 필요가 없어요.

```python
>>> ripple = lambda x, y: sd.cos(2 * sd.hypot(x, y)) * sd.exp(-(x**2 + y**2) / 6)
>>> fig = sd.plot.surface(ripple, -3, 3, -3, 3).xlabel("$x$").ylabel("$y$").zlabel("$z$")
```

<PlotImage name="surface-ripple" format="png" alt="가운데가 솟고 둘레로 물결이 퍼지며 잦아드는 곡면. 높이에 따라 아래는 하늘색, 가운데는 보라, 위는 빨강이고 곡면 위에 어두운 격자선이 있어요." caption="물결 cos(2r)·exp(−r²/6), r = √(x² + y²). 곡면이 하나뿐이라 높이에 따른 색띠 'cool'로 칠했어요." />

곡면은 고정된 빛으로 음영을 받고, 곡면 위에는 $x$와 $y$가 고른 격자선이 깔려요. 둘레에는 눈금이 달린 상자 축이 서요. 상자, 시점, 빛, 출력은 [3D 칸과 시점](/api/plot/view3d/)에 따로 정리해 두었어요.

## 함수 넘기기

`f`는 배열 둘을 받는 함수예요. `surface`는 격자의 점을 모두 모아 `f`를 **배열 한 번으로** 불러요. 점마다 따로 부르지 않으므로 `sd.sin`, `sd.exp`, 산술 연산처럼 배열을 받는 연산으로 써요.

```python
>>> shapes = []
>>> def wave(x, y):
...     shapes.append(x.shape)
...     return sd.sin(x) * sd.cos(y)
>>> fig = sd.plot.surface(wave, -3, 3, -3, 3)
>>> shapes
[(121, 121)]
```

매끈한 곡면은 첫 격자 121 × 121 한 번으로 끝나요. 더 촘촘히 재야 하는 곳이 있으면 그 칸들의 점만 모아 한두 번 더 불러요([아래](#표본-samples와-refine)).

- 수 하나를 돌려주면 상수 함수예요. `lambda x, y: 0.5`는 높이 0.5의 평면이에요.
- 정의되지 않는 점에서는 NaN을 돌려줘요. 그 자리에는 곡면이 없어요.
- 리스트를 돌려주거나 다른 모양의 배열을 돌려주면 에러예요.

```python
>>> sd.plot.surface(lambda x, y: x[0], 0, 1, 0, 1)
Traceback (most recent call last):
    ...
ValueError: surface(): 'f' must return an array of its arguments' shape (121, 121), not (121,)
```

## 색: cmap과 color

색은 셋 가운데 하나로 정해요.

- **아무것도 주지 않으면**: 칸에 곡면이 하나일 때 높이에 따른 색띠 `'cool'`이에요. 곡면이 여럿이면 곡면마다 팔레트의 색을 차례로 받아요.
- **`cmap=`**: 높이에 따른 색띠예요. 상자의 바닥 높이가 색띠의 한 끝, 천장 높이가 다른 끝이에요.
- **`color=`**: 곡면 전체가 한 색이고 음영만 달라요. 모양만 보이고 싶거나 곡면 여럿을 색으로 가를 때 써요.

색띠는 `'cool'`, `'spectral'`, `'coolwarm'`, `'sunrise'`, `'lagoon'`(양 끝이 밝은 것), `'viridis'`, `'magma'`, `'cividis'`(밝기가 고르게 변하는 것), `'rdbu'`(가운데가 흰 발산형)가 있어요. 견줘 보는 그림은 [색과 테마](/api/plot/style/)에 있어요.

## 격자선과 바닥 등고선: mesh와 contours

`mesh`는 곡면 위의 격자선이에요. 기본은 한 방향 24칸이고, 정수를 주면 그 칸 수, `False`면 격자선이 없어요. 격자선은 곡면 제 색을 어둡게 한 가는 선이고 곡면에 가린 부분은 그리지 않아요.

`contours`는 상자의 바닥에 그리는 등고선이에요. 곡면을 위에서 본 지도를 바닥에 깔아 높이를 읽기 쉽게 해요. `True`면 수준을 14개쯤, 정수를 주면 그만큼쯤 골라요. 수준은 눈금처럼 고운 값(0.2, 0.4, …)이고, 등고선은 그 높이의 곡면과 같은 색이에요.

```python
>>> wave = lambda x, y: sd.sin(x) * sd.cos(y)
>>> a = sd.plot.surface(wave, -3, 3, -3, 3, color="C0")
>>> b = sd.plot.surface(wave, -3, 3, -3, 3, cmap="viridis", mesh=12)
>>> c = sd.plot.surface(wave, -3, 3, -3, 3, mesh=False, contours=True)
>>> g = sd.plot.grid([a, b, c], ncols=3, width=183)
```

<PlotImage name="surface-options" of="g" format="png" alt="같은 곡면 sin x cos y를 세 가지로 그렸어요. 왼쪽은 파란 한 색에 음영과 격자선, 가운데는 높이에 따라 보라에서 노랑으로 가는 색에 성긴 격자선, 오른쪽은 격자선 없이 높이 색을 입히고 상자의 바닥에 같은 색의 등고선을 깔았어요." caption="왼쪽부터 color='C0', cmap='viridis'와 mesh=12, mesh=False와 contours=True." />

`contours`는 그래프 $z = f(x, y)$에만 있어요. [`parametric_surface`](/api/plot/parametric_surface/)는 받지 않아요.

## 높이의 범위와 극점

높이 축의 범위는 곡면의 값에서 정해요. 값의 대부분이 있는 범위보다 몇 점만 아주 멀리 달아나면(극점) 그쪽만 잘라서, 극점 하나가 상자를 다 차지해 나머지 곡면이 바닥에 납작하게 붙는 일이 없어요. 잘린 곡면은 상자의 천장(또는 바닥)에서 끝나요. 범위의 위와 아래로 함께 벗어나는 조각(극점을 가로지르는 조각)은 그리지 않아서 극점에 벽이 서지 않아요.

범위를 직접 정하려면 `zlim=(low, high)`를 줘요. 곡면은 그 범위에서 잘리고, 색띠도 그 범위에 맞춰요.

정의역이 직사각형이 아닌 함수는 바깥에서 NaN을 돌려주면 돼요. `sd.sqrt(1 - x**2 - y**2)`는 원판 밖에서 NaN이에요. 곡면은 값이 있는 곳까지만 그려지고, 그 경계는 [아래](#표본-samples와-refine)의 다시 재기가 따라가서 들쭉날쭉하지 않아요.

```python
>>> pole = lambda x, y: 1 / (x**2 + y**2)
>>> a = sd.plot.surface(pole, -1, 1, -1, 1)
>>> b = sd.plot.surface(pole, -1, 1, -1, 1, zlim=(0, 4))
>>> c = sd.plot.surface(lambda x, y: sd.sqrt(1 - x**2 - y**2), -1.2, 1.2, -1.2, 1.2)
>>> g = sd.plot.grid([a, b, c], ncols=3, width=183)
```

<PlotImage name="surface-edges" of="g" format="png" alt="세 곡면. 왼쪽은 원점에서 무한대로 치솟는 1/(x² + y²)가 위가 잘린 굴뚝처럼 보여요. 가운데는 같은 곡면을 높이 0에서 4까지만 보여 굴뚝이 더 넓게 열려 있어요. 오른쪽은 반구가 원판 가장자리까지 매끈하게 내려와요." caption="왼쪽은 높이 범위를 알아서 잡았고, 가운데는 zlim=(0, 4)를 줬어요. 오른쪽은 원판 밖에서 NaN인 반구예요." />

## 표본: samples와 refine

`surface`는 먼저 첫 격자(기본 121 × 121점, 120 × 120칸)에서 `f`를 재요. 그다음 네 꼭짓점만으로는 모자란 칸을 골라 그 칸만 4 × 4로 나눠 다시 재요. 모자란 칸은 셋이에요.

- **꺾이는 칸**: 네 꼭짓점의 법선이 크게 벌어진 칸. 곡면이 그 칸 안에서 휘거나 꺾여요.
- **극점의 옆구리**: 높이 범위의 경계가 지나는 칸. 곡면이 상자의 천장에서 잘리는 선이 매끈해져요.
- **정의역의 가장자리**: 꼭짓점의 일부만 값이 있는 칸. 값이 없는 꼭짓점을 값이 있는 쪽으로 옮겨 가장자리 위에 놓아요.

다시 잰 칸 가운데 아직 모자란 칸은 한 번 더 나눠요. 가장 촘촘한 곳은 첫 격자의 16배예요. 단계마다 새 점을 모두 모아 `f`를 한 번 부르므로 호출은 몇 번뿐이에요. 촘촘한 칸과 성긴 칸이 맞닿는 변은 서로 맞춰서 곡면에 틈이 생기지 않아요. 칸의 40%가 넘게 모자란 곡면(어디나 거친 곡면)은 골라 재는 대신 격자 전체를 가로세로 3배로 한 번 다시 재요.

```python
>>> shapes.clear()
>>> def pole(x, y):
...     shapes.append(x.shape)
...     return 1 / (x**2 + y**2)
>>> fig = sd.plot.surface(pole, -1, 1, -1, 1)
>>> shapes[0], len(shapes) < 30
((121, 121), True)
```

첫 호출이 첫 격자이고, 그 뒤의 호출은 원점 둘레의 몇 칸과 격자선의 점만 받아요.

| 인자 | 기본값 | 뜻 |
|---|---|---|
| `samples` | 121 × 121 | 첫 격자의 점의 수. 수 하나(두 방향 같게)나 `(x 방향, y 방향)`, 3–2000 |
| `refine` | 2 | 모자란 칸을 다시 나누는 횟수의 한계. 한 번에 4 × 4. `0`이면 첫 격자만 써요 |

매끈한 곡면은 기본값으로 충분해요. 아주 잔물결이 많은 곡면은 `samples`를 키우고, 그리는 시간을 줄이고 싶으면 `refine=0`으로 첫 격자만 써요. 모든 함수 그림이 같은 두 인자를 받아요([표본 고르기](/api/plot/sampling/)).

## 값의 배열로 그리기

함수 자리에 이미 계산한 높이의 2차원 배열을 줄 수 있어요. 잰 값이나 시뮬레이션의 결과처럼 식이 없는 곡면을 그릴 때 써요. `Z[j, i]`는 직사각형을 고르게 나눈 격자의 점 $(x_i, y_j)$의 높이이고, 첫 줄이 `y0`이에요. `sd.meshgrid(x, y, indexing="xy")`의 격자에서 계산한 값이 그대로 맞아요.

```python
>>> x = sd.linspace(-3.0, 3.0, 25)
>>> y = sd.linspace(-3.0, 3.0, 25)
>>> X, Y = sd.meshgrid(x, y, indexing="xy")
>>> Z = ripple(X, Y)
>>> Z.shape
(25, 25)
>>> fig = sd.plot.surface(Z, -3, 3, -3, 3)
```

<PlotImage name="surface-values" format="png" alt="맨 위 그림과 같은 물결 곡면이지만 봉우리와 물결의 마루가 각져 있어요. 높이에 따른 색과 격자선은 같아요." caption="25 × 25점의 높이 배열로 그린 곡면이에요. 점 사이는 평평한 조각으로 이으므로 성긴 격자에서는 마루가 각져요." />

값만 있으면 다시 잴 수 없어요. 곡면은 준 격자 그대로이고, `samples`와 `refine`을 함께 주면 에러예요. 색, 격자선, 바닥 등고선, `zlim`, 높이 범위를 잡는 법은 함수일 때와 같아요. NaN인 값의 자리에는 곡면이 없어요.

```python
>>> sd.plot.surface(Z, -3, 3, -3, 3, refine=0)
Traceback (most recent call last):
    ...
ValueError: surface(): 'samples' and 'refine' are for a function; the values given are the grid
```

고르지 않은 격자나 흩어진 점 $(x_i, y_i, z_i)$의 곡면은 받지 않아요. 흩어진 점은 [`scatter3d`](/api/plot/scatter3d/)로 찍어요.

## 곡면 여럿과 다른 층

메서드 `fig.surface(...)`로 같은 칸에 곡면을 더해요. 곡면이 서로 뚫고 지나가도 교선을 따라 옳게 갈리고, `alpha`를 주면 반투명이에요. 곡면 위에 [`curve3d`](/api/plot/curve3d/)로 길을, [`scatter3d`](/api/plot/scatter3d/)로 점을 얹을 수도 있어요. 보기와 규칙은 [3D 칸과 시점](/api/plot/view3d/#한-칸에-여러-층)에 있어요.

```python
>>> fig = sd.plot.surface(lambda x, y: x**2 - y**2, -1, 1, -1, 1)
>>> fig = fig.surface(lambda x, y: 0 * x + 0.2, -1, 1, -1, 1, color="gray", mesh=False)
```

시점(`azimuth`, `elevation`, `perspective`)은 칸의 첫 층의 것이 쓰여요. 이미 2D 그림이 있는 칸에는 더할 수 없고, 곡면이 있는 칸에 2D 그림을 더할 수도 없어요.

## 조심할 점

- 높이 축은 $x$, $y$와 따로 척도를 가져요. 상자는 언제나 1 : 1 : 0.72라서 높이가 0.001만큼 변하는 곡면도 상자를 꽉 채워요. 높이의 실제 크기는 $z$ 눈금으로 읽어요.
- 칸의 크기보다 잔 무늬(한 칸에 여러 번 출렁이는 함수)는 첫 격자가 놓칠 수 있어요. 다시 재기는 첫 격자에서 모자라 보이는 칸만 고르므로, 첫 격자가 출렁임을 전혀 보지 못하면 더 재지 않아요. 그럴 때는 `samples`를 키워요.
- 정의되지 않는 곳은 NaN으로 알려 줘요. 그 자리는 비워 두고, 둘레의 가장자리를 따라 더 촘촘히 재요.

## matplotlib을 아는 분께

- matplotlib의 `plot_surface(X, Y, Z)`는 격자 `X`, `Y`와 값 `Z`를 받아요. `surface`는 함수와 범위를 받아 격자를 스스로 정하고, 필요한 곳만 더 촘촘히 재요. 값의 배열 `Z`도 받지만 `X`, `Y` 대신 직사각형의 범위를 주고, 격자는 그 직사각형을 고르게 나눈 것으로 봐요.
- `rstride`, `cstride`(그리는 격자의 성김)는 없고, 격자선의 칸 수는 `mesh`, 표본의 수는 `samples`가 정해요. 격자선은 삼각형의 변이 아니라 $x$, $y$가 고른 선이라 표본을 촘촘히 해도 격자선의 수는 그대로예요.
- 높이에 따른 색은 `cmap`, 한 색은 `color`예요. 둘 다 주면 에러예요. `facecolors`처럼 다른 값으로 칠하는 꼴은 없어요.
- `ax.contour(..., zdir='z', offset=...)`로 바닥에 등고선을 그리던 것은 `contours=True`예요.
- 교차하는 곡면을 깊이로 옳게 그려요. matplotlib처럼 곡면 조각의 그리는 순서 때문에 앞뒤가 뒤바뀌는 일이 없어요.
