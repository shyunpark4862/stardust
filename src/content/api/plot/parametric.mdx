## 한눈에 보기

$x$와 $y$를 같은 매개변수 $t$의 함수로 주면, $t$가 구간을 지나는 동안 점 $(x(t), y(t))$가 그리는 곡선이 나와요. 리사주 곡선 $x = \sin 3t$, $y = \sin 4t$를 한 주기 그려 볼게요.

```python
>>> import math
>>> fig = sd.plot.parametric(lambda t: sd.sin(3 * t), lambda t: sd.sin(4 * t), 0, 2 * math.pi)
>>> info = fig.info[0]
>>> info.kind, info.n
('parametric', 543)
```

<PlotImage name="parametric-lissajous" alt="x = sin 3t, y = sin 4t의 리사주 곡선. 정사각형 안에서 여러 번 교차하는 닫힌 곡선이에요" caption="t를 0에서 2π까지 움직인 리사주 곡선이에요. 가로와 세로의 한 단위가 같은 길이라 곡선이 찌그러지지 않아요." />

곡선이 꺾이는 끝자락에 표본이 모여서 257점에서 시작한 표본이 543점이 되었어요. 표본을 고르는 법은 `function`과 같지만, 꺾임을 $y$ 하나가 아니라 평면 위의 곡선 모양으로 재요([함수 그림의 표본](/api/plot/sampling/)).

## 무엇을 그리나요

`fx`와 `fy`는 각각 $t$의 배열을 받아 같은 모양의 배열을 돌려주는 함수예요. 그림은 두 함수를 같은 $t$로 함께 불러요. 원은 `sd.cos`과 `sd.sin`을 그대로 넘기면 돼요.

```python
>>> fig = sd.plot.parametric(sd.cos, sd.sin, 0, 2 * math.pi)
```

$y = f(x)$로 쓸 수 없는 곡선, 예를 들어 같은 $x$에서 두 번 이상 지나가거나 되돌아가는 곡선을 그릴 때 써요. 바퀴 위의 한 점이 그리는 사이클로이드 $x = t - \sin t$, $y = 1 - \cos t$는 뾰족한 곳(첨점)이 있는 곡선이에요.

```python
>>> fig = sd.plot.parametric(
...     lambda t: t - sd.sin(t), lambda t: 1 - sd.cos(t), 0, 6 * math.pi, height=26
... )
>>> fig.height
26.0
```

## 같은 비율의 칸

`parametric`의 칸은 자료의 한 단위가 가로와 세로에서 같은 길이예요. 원은 원으로, 정사각형은 정사각형으로 보여요. 그러려고 범위를 넓히지 않고, 칸의 그림 사각형을 자료의 모양에 맞게 줄여요. 그래서 위의 사이클로이드처럼 납작한 곡선은 기본 크기(가로 89 mm, 칸의 가로세로 비 4:3)에서 위아래에 빈 곳이 남아요. 그림 옵션 `height`(mm)를 자료의 모양에 맞게 주면 빈 곳이 줄어요.

범위는 `function`과 같은 규칙으로 잡아요. $x$와 $y$ 저마다 처음 격자의 값 대부분이 있는 띠를 보고, 그보다 몇 배나 멀리 달아난 값이 있는 쪽만 빼요. 값이 한없이 커지는 $t$가 있어도 그 값이 축을 다 차지하지 않아요. 데카르트의 엽선 $x = 3t/(1 + t^3)$, $y = 3t^2/(1 + t^3)$는 $t = -1$에서 달아나요.

```python
>>> fx = lambda t: 3 * t / (1 + t**3)
>>> fy = lambda t: 3 * t * t / (1 + t**3)
>>> fig = sd.plot.parametric(fx, fy, -20, 20)
>>> [round(p, 3) for p in fig.info[0].poles]
[-1.0]
>>> fig = fig.xlim(-3, 3).ylim(-3, 3)
```

극점은 찾아서 선을 끊어요. `info.poles`의 값은 그 자리의 $t$예요. 자동 범위는 "값의 대부분"을 $t$를 고르게 나눈 표본에서 세요. 이 곡선은 $t$의 구간 $[-20, 20]$의 대부분에서 원점 가까이에 머물러서, 자동 범위가 원점 둘레만 잡고 고리의 바깥쪽을 잘라요. 보고 싶은 곳이 따로 있으면 위처럼 `xlim`, `ylim`으로 정해요.

## 겹치기

메서드로 같은 칸에 다른 곡선을 더해요. 같은 비율의 칸은 그대로 남으므로, `function`으로 더한 직선도 같은 비율로 그려져요. 원과 그 접선을 함께 그려 볼게요.

```python
>>> fig = sd.plot.parametric(sd.cos, sd.sin, 0, 2 * math.pi, label="circle")
>>> fig = fig.function(lambda x: math.sqrt(2) - x, -0.5, 2, style="--", label="tangent")
>>> [i.kind for i in fig.info]
['parametric', 'function']
```

<PlotImage name="parametric-tangent" alt="단위원과 점 (√2/2, √2/2)에서의 접선. 접선은 파선이고 오른쪽 위에 범례가 있어요" caption="원과 그 접선 y = √2 − x예요. 칸의 비율이 1:1이라 접선이 원에 정확히 한 점에서 닿는 모양으로 보여요." />

같은 칸에 함수 그림을 여럿 겹치면 `fig.info`에 곡선마다 기록이 더해져요. `parametric`의 기록은 `ylim`이 `None`이고 `clipped`가 언제나 `(False, False)`예요.

## 표본과 정의역

`samples`와 `refine`의 뜻은 `function`과 같아요. 선을 끊는 곳, 정의역의 끝을 좁히는 것도 같아요. $x$나 $y$가 NaN인 $t$에서는 선을 비워 두고, `info.undefined`에 그 $t$ 구간을 적어요.

```python
>>> fig = sd.plot.parametric(lambda t: t, lambda t: sd.sqrt(1 - t * t), -2, 2)
>>> [(round(u, 4), round(v, 4)) for u, v in fig.info[0].undefined]
[(-2.0, -1.0), (1.0, 2.0)]
```

## 조심할 점

- **자동 범위는 달아나는 값을 빼요.** $t$의 대부분이 머무는 곳을 기준으로 삼으므로, 곡선의 일부가 잘려 보이면 `xlim`, `ylim`으로 정해요.
- **칸의 비율은 1:1이에요.** 납작하거나 길쭉한 곡선은 `height`를 맞춰 빈 곳을 줄여요. 여기서 `width=`는 선의 굵기예요. 그림의 너비는 `sd.plot.Figure(width=...)`에 메서드로 그려서 정해요.
- **t의 방향은 보이지 않아요.** 곡선이 어느 쪽으로 지나가는지는 그림에 나타나지 않아요. 방향을 보이고 싶으면 [annotate](/api/plot/text-annotate/)로 화살표를 더해요.
- 공간 곡선 $(x(t), y(t), z(t))$는 [curve3d](/api/plot/curve3d/)예요.
