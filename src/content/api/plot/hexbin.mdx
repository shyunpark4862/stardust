## 한눈에 보기

점이 수만 개인 자료는 산점도로 찍으면 한 덩어리가 돼요. 평면을 칸으로 나눠 칸마다 점의 수를 세면 어디에 몰려 있는지 보이는데, `hexbin`은 그 칸을 벌집처럼 맞물린 **육각형**으로 잡아요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> N = sd.stats.Normal(mu=0.0, sigma=1.0)
>>> z1, z2 = N.sample(20000, rng=rng), N.sample(20000, rng=rng)
>>> x, y = z1, 0.6 * z1 + 0.8 * z2
>>> fig = sd.plot.hexbin(x, y).xlabel("$x$").ylabel("$y$")
```

<PlotImage name="hexbin-overview" alt="육각 칸으로 센 그림. 가운데 육각형들이 빨갛고 바깥으로 갈수록 하늘색이며, 오른쪽 위로 기운 타원 모양이에요. 바깥의 빈 육각형은 그리지 않았어요." caption="짝 2만 개를 육각 칸에 센 그림. 가로로 육각형 30개가 놓이고, 가운데 칸에는 300개쯤이 들어 있어요." />

짝마다 가운데가 가장 가까운 육각형에 들어가요. 색은 그 육각형에 든 짝의 수이고, 색띠는 0에서 가장 많이 든 칸의 개수까지예요. 짝이 하나도 들지 않은 육각형은 그리지 않아요.

<Reference />

## 왜 육각형인가요

사각 칸으로 세는 [`hist2d`](/api/plot/hist2d/)와 하는 일은 같아요. 다른 것은 칸의 모양이에요.

- 사각 칸은 이웃이 두 가지예요. 변을 맞댄 넷은 가깝고 모서리만 닿은 넷은 $\sqrt{2}$배 멀어요. 육각 칸은 이웃 여섯이 모두 같은 거리에 있어요.
- 육각형은 평면을 빈틈없이 덮는 정다각형 가운데 원에 가장 가까워요. 칸 안의 점들이 가운데에서 멀리 벗어나지 않아서, 칸의 가운데가 그 안의 점들을 더 잘 대신해요.
- 사각 칸은 가로줄과 세로줄이 눈에 띄어, 대각선으로 늘어선 자료가 계단처럼 보여요. 육각 칸은 줄이 세 방향으로 나 있어 그런 치우침이 덜해요.

그 대신 칸의 경계가 축의 눈금과 나란하지 않아서, "x가 1에서 1.5 사이인 칸"처럼 칸을 값의 구간으로 읽기는 어려워요. 구간으로 읽어야 하면 `hist2d`가 알맞아요.

## 칸의 크기: `size`

`size`는 가로로 놓이는 육각형의 수예요. 상자의 너비를 `size`로 나눈 것이 육각형 하나의 너비예요. 수가 클수록 칸이 작아져요.

```python
>>> fig = sd.plot.hexbin(x, y, size=12, cmap="magma")
```

<PlotImage name="hexbin-size" alt="가로로 육각형 12개가 놓인 그림. magma 색띠로 가운데 육각형이 밝은 노랑이고 바깥은 검정에 가까워요." caption="size=12. 칸이 커져 칸마다 든 개수가 늘었어요(가장 많은 칸이 1,700개쯤)." />

칸이 크면 칸마다 개수가 넉넉해 색이 매끄럽지만 모양이 뭉개지고, 칸이 작으면 모양은 자세하지만 개수가 적은 칸의 색이 들쭉날쭉해요. 짝이 수만 개면 기본값 30 안팎에서 시작해요.

세로로 놓이는 육각형의 수는 따로 정하지 않아요. 가로세로 비가 4 : 3인 칸에서 정육각형으로 보이도록 세로 간격을 맞춰요. 기본 크기의 그림이 그 비에 가까워요. `width`와 `height`로 그림의 비를 많이 바꾸면 육각형이 그만큼 위아래나 옆으로 늘어나 보여요. 개수를 세는 방식은 그대로예요.

## 상자: `range`

`range`를 주지 않으면 유한한 짝의 최솟값에서 최댓값까지가 상자예요. `range=((x0, x1), (y0, y1))`로 상자를 정하면 그 안의 짝만 세요(끝 값 포함). 멀리 떨어진 점 몇 개 때문에 칸이 커지는 것을 막거나, 한 부분을 크게 볼 때 써요.

```python
>>> fig = sd.plot.hexbin(x, y, size=20, range=((0, 3), (0, 3)))
>>> fig = fig.line([0, 3], [0, 1.8], color="black", label="$y = 0.6x$")
```

<PlotImage name="hexbin-range" alt="가로와 세로가 0에서 3까지인 상자만 육각 칸으로 센 그림. 왼쪽 아래 구석이 붉고 오른쪽 위로 갈수록 옅어지며, 검은 직선 y = 0.6x가 그 위를 지나가요." caption="오른쪽 위 사분면만 센 그림. 그 위에 직선 한 층을 겹쳤어요." />

육각형의 가운데는 상자의 왼쪽 아래 구석에서 시작해 늘어서요. 그래서 상자의 가장자리에 걸친 육각형은 상자 밖으로 반쯤 나와요. 그 육각형도 상자 안의 짝만 센 것이에요.

같은 이름의 메서드를 이어 부르면 육각 칸 위에 선이나 점을 겹칠 수 있어요. 축은 `x`와 `y`의 값 그대로예요. `data=`에 DataFrame을 주고 `x`와 `y`를 열 이름으로 써도 돼요.

```python
>>> df = sd.frame.DataFrame({"u": x, "v": y})
>>> fig = sd.plot.hexbin("u", "v", data=df, size=20)
```

## 로그 축

`hexbin`은 그릴 축에 맞춰 세요. [`xscale('log')`나 `yscale('log')`](/api/plot/customize/)를 준 축에서는 값의 로그(10진)를 같은 간격으로 나눠 육각형을 놓아요. 그래서 로그 축에서도 육각형이 정육각형으로 보이고 크기가 모두 같아요. 축의 척도는 `hexbin`보다 앞에 정하든 뒤에 정하든 같아요. 여러 자릿수에 걸쳐 퍼진 양수 자료에 써요.

```python
>>> fig = sd.plot.hexbin(10.0 ** x, 10.0 ** y, size=24).xscale("log").yscale("log")
```

<PlotImage name="hexbin-log" alt="두 축이 모두 로그 눈금인 육각 칸 그림. 가로와 세로 모두 10의 거듭제곱으로 눈금이 서고, 크기가 같은 정육각형들이 오른쪽 위로 기운 타원 모양으로 모여 있어요." caption="10의 x제곱과 10의 y제곱을 두 로그 축에 센 그림. 값의 로그로 나눴으므로 육각형이 모두 같은 크기의 정육각형이고, 모양은 맨 위의 그림과 같아요." />

로그 축에서 0 이하의 값은 자리가 없으므로 그런 짝은 세지 않아요. `range`의 아래 끝이 0 이하이면 가장 작은 양수 값부터 나눠요.

<Callout type="note" title="셀 수 없는 짝">
`x`나 `y` 가운데 하나라도 NaN이나 무한대인 짝은 빼고 세요. 남는 짝이 하나도 없으면 `ValueError`예요.
</Callout>

## 조심할 점

- 밀도로 바꾸는 인자는 없어요. 색은 언제나 개수예요. 넓이로 나눈 밀도가 필요하면 [`hist2d`](/api/plot/hist2d/)의 `density=True`를 써요.
- 색띠는 칸 하나에 하나예요. 한 칸에 `hexbin`을 두 번 겹치면 색띠는 나중 것만 남아요. 무리마다 견주려면 [`facet`](/api/plot/facet/#개수를-칠하는-그림-hist2d-hexbin)으로 칸을 나눠요. 모든 칸이 같은 격자로 세고 같은 색 범위로 칠해요.
- 육각 칸은 선형 축에서는 값을, 로그 축에서는 값의 로그를 같은 간격으로 나눈 것이에요. 로그 축의 육각형 하나는 값으로 보면 오른쪽 위로 갈수록 넓은 범위를 덮어요.
- `range`의 두 구간은 작은 값을 앞에 적어요. 거꾸로 주면 `ValueError`예요.
- 점이 수백 개뿐이면 [`scatter`](/api/plot/scatter/)가 알맞아요.

## matplotlib을 아는 분께

- `plt.hexbin`의 `gridsize`가 `size`예요. 가로의 수만 받고 `(가로, 세로)` 꼴은 없어요.
- `extent=(x0, x1, y0, y1)` 대신 `range=((x0, x1), (y0, y1))`예요. [`hist2d`](/api/plot/hist2d/)와 같은 꼴이에요.
- 빈 육각형은 그리지 않아요(`mincnt=1`을 준 것과 같아요). 색띠가 기본으로 붙어요.
- 칸의 값은 개수뿐이에요. `C`와 `reduce_C_function`으로 다른 값을 모으는 것, `bins='log'`는 없어요.
- 로그 축의 칸은 `plt.hexbin(xscale='log', yscale='log')`처럼 값의 로그로 나눠요. 여기서는 인자 대신 칸의 축 척도를 따라요.
