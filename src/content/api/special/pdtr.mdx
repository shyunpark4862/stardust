## 한눈에 보기

**포아송 분포**(Poisson distribution)는 정해진 시간이나 공간 안에서 사건이 몇 번 일어나는지를 나타내는 분포예요. 사건이 서로 영향을 주지 않고, 평균적으로 일정한 빠르기로 아무 때나 일어난다면, 그 횟수는 포아송 분포를 따라요. 분포를 정하는 값은 **평균 사건 수** `m` 하나예요.

이런 곳에 써요.

- 운영과 용량 계획: 콜센터에 1분 동안 들어오는 전화 수, 매장에 1시간 동안 오는 손님 수
- 이상 탐지: 평소 하루 2건이던 서버 오류가 오늘 9건이면 "우연"이라 볼 수 있는지
- 품질 관리: 천 1미터에 생기는 흠, 웨이퍼 한 장의 결함 수
- 드문 사건의 확률: 보험 사고 건수, 교차로의 월별 사고 수, 방사선 검출기에 잡히는 입자 수

두 함수가 짝이에요.

- `pdtr(k, m)`: 사건 수 X가 `k` 이하일 확률 P(X ≤ k), 곧 **누적분포함수**(cdf)
- `pdtrc(k, m)`: X가 `k`보다 클 확률 P(X > k), 곧 **생존함수**(survival function). 끝의 `c`는 보수(complement)라는 뜻이에요.

```python
>>> import stardust as sd
>>> sd.special.pdtr(2, 3.0)
0.42319008112684364
>>> sd.special.pdtrc(2, 3.0)
0.5768099188731564
>>> sd.special.pdtr(0, 3.0)
0.04978706836786394
```

평균 3건인 사건이 2건 이하로 일어날 확률은 약 42%, 3건 이상일 확률은 약 58%예요. 한 건도 일어나지 않을 확률은 $e^{-3} \approx 0.0498$이에요.

## 포아송 분포의 정의

평균이 $m$인 포아송 분포에서 사건이 정확히 $j$번 일어날 확률은

$$
P(X = j) = e^{-m} \frac{m^j}{j!}, \qquad j = 0, 1, 2, \dots
$$

이고, `pdtr`은 이것을 0부터 $k$까지 더한 값이에요.

$$
\mathrm{pdtr}(k, m) = \sum_{j=0}^{\lfloor k \rfloor} e^{-m} \frac{m^j}{j!}
$$

$\lfloor k \rfloor$는 $k$를 내린 정수예요. 이 합은 [정칙화된 불완전 감마 함수](/api/special/gammainc/)와 정확히 같아요.

$$
\mathrm{pdtr}(k, m) = Q(k + 1,\ m) = \texttt{gammaincc}(k+1,\ m), \qquad
\mathrm{pdtrc}(k, m) = \texttt{gammainc}(k+1,\ m)
$$

```python
>>> sd.special.gammaincc(3.0, 3.0)
0.42319008112684364
>>> sd.special.gammainc(3.0, 3.0)
0.5768099188731564
```

그래서 `k`가 커도 항을 하나하나 더하지 않고 바로 계산해요.

## 콜센터: 몇 통이 올까요

콜센터에 1분에 평균 3통의 전화가 와요. 상담원 수를 정하려고 확률 몇 가지를 구해 봐요.

```python
>>> sd.special.pdtr(2, 3.0)
0.42319008112684364
>>> sd.special.pdtrc(5, 3.0)
0.08391794203130344
```

1분 동안 2통 이하가 올 확률은 약 42%예요. 둘째 줄은 **5통보다 많이**, 곧 6통 이상 올 확률이에요. 약 8%라서, 상담원이 5명이면 1분 중 8% 정도는 대기가 생긴다는 뜻이에요.

<Callout type="warn" title="pdtrc는 '초과'예요">
  `pdtrc(k, m)`은 P(X > k), **k보다 큰** 경우의 확률이에요. "k건 **이상**"의 확률 P(X ≥ k)는 `pdtrc(k - 1, m)`이에요. 하나 차이지만 꼬리에서는 확률이 몇 배씩 달라져요. 예를 들어 `pdtrc(6, 3.0)`은 7통 이상의 확률이라 약 3.4%예요.
</Callout>

## 이상 탐지: 오늘의 오류는 우연일까요

평소 하루 평균 2건이던 서버 오류가 오늘 9건 났어요. 평소와 같다면 9건 이상이 나올 확률은 이래요.

```python
>>> sd.special.pdtrc(8, 2.0)
0.00023744732826116183
```

약 0.024%, 만 번에 두세 번 있을 일이라 무언가 달라졌다고 의심할 만해요. 9건 이상이니 `k`에는 8을 넣었어요.

### 위꼬리는 `pdtrc`로 직접

`pdtrc`을 `1 - pdtr`로 계산해도 될 것 같지만, 꼬리에서는 자릿수를 잃어요. `pdtr`이 1에 아주 가까워지면 1에서 뺀 값의 오차가 커져요. float64는 1 근처에서 약 1.1e-16 간격으로만 수를 담을 수 있기 때문이에요.

```python
>>> 1 - sd.special.pdtr(8, 2.0)
0.00023744732826114223
>>> sd.special.pdtrc(30, 2.0)
3.769552855325798e-26
>>> 1 - sd.special.pdtr(30, 2.0)
0.0
```

첫 줄은 앞 열세 자리만 맞고, 31건 이상처럼 먼 꼬리에서는 아예 0이 돼요. `pdtrc`은 1에서 빼지 않고 위꼬리를 직접 계산해서 이런 값도 앞자리 14자리 정도가 맞아요. 수많은 서버나 지역을 한꺼번에 감시하며 가장 드문 것부터 순위를 매길 때는 이 차이가 중요해요.

## 정확히 k번일 확률

이 영역에는 "정확히 k번"의 확률을 주는 함수가 따로 없어요. 누적확률의 차이로 구하면 돼요. `k - 1`이 음수가 되는 `k = 0`에서도 `pdtr(-1, m) = 0`이라 식이 그대로 맞아요.

```python
>>> k = sd.arange(0, 7)
>>> sd.special.pdtr(k, 2.0) - sd.special.pdtr(k - 1, 2.0)
array([0.13533528323661267,  0.2706705664732256, 0.27067056647322507,
       0.18044704431548364, 0.09022352215774176, 0.03608940886309675,
       0.01202980295436562], dtype=float64)
```

평균 2인 포아송 분포는 1번과 2번이 똑같이 가장 흔해요(약 27%). 이론으로는 두 값이 정확히 같지만 마지막 자리가 조금 달라요. 두 누적확률을 빼는 과정의 반올림 때문이에요.

## 정수 인자: `k`는 내림해요

사건 수는 정수라서, `k`에 정수가 아닌 값을 주면 **내림해서** P(X ≤ ⌊k⌋)로 계산해요. "2.7건 이하"는 "2건 이하"와 같은 뜻이기 때문이에요.

```python
>>> sd.special.pdtr(2.7, 3.0)
0.42319008112684364
>>> sd.special.pdtr(2.0, 3.0)
0.42319008112684364
```

음수 `k`도 같은 뜻으로 받아요. 사건 수가 음수일 수는 없으니 누적확률은 0, 위꼬리는 1이에요.

```python
>>> sd.special.pdtr(-1, 3.0)
0.0
>>> sd.special.pdtrc(-1, 3.0)
1.0
```

그래서 `pdtr`을 실수 `k`의 함수로 그리면 정수마다 한 칸씩 뛰는 계단이 돼요.

      { v: 8, label: '8' },
      { v: 10, label: '10' },
      { v: 12, label: '12' },
    ]}
    yTicks={[
      { v: 0.25, label: '0.25' },
      { v: 0.5, label: '0.5' },
      { v: 0.75, label: '0.75' },
      { v: 1, label: '1' },
    ]}
  />
</Fig>

`m`은 정수일 필요가 없는 0 이상의 실수예요. `m = 0`이면 사건이 절대 일어나지 않으니 누적확률이 언제나 1이고, `m`이 무한대이면 유한한 `k`의 누적확률은 0이에요.

```python
>>> sd.special.pdtr(3, 0.0)
1.0
>>> sd.special.pdtr(3, sd.inf)
0.0
```

## 평균을 거꾸로 구하려면

이 영역에는 포아송 분포의 역함수가 따로 없어요. 하지만 `pdtr(k, m) = gammaincc(k+1, m)`이니, `m`에 대해 푼 값은 [`gammainccinv`](/api/special/gammainc/)로 바로 구해요.

예를 들어 한 달 동안 사고가 2건 났을 때, 월 평균 사고 수의 95% **상한**은 "평균이 그만큼이면 2건 이하가 나올 확률이 5%밖에 안 되는" 값이에요.

```python
>>> m_upper = sd.special.gammainccinv(3, 0.05)
>>> m_upper
6.29579362187199
>>> sd.special.pdtr(2, m_upper)
0.049999999999999996
```

2건을 봤다면 평균은 95% 신뢰도로 약 6.3건 이하예요. 첫 인자가 `k + 1 = 3`인 점을 놓치지 마세요.

## 이항 분포와의 관계

시행 횟수 `n`이 크고 성공 확률 `p`가 작으면, 성공 횟수의 [이항 분포](/api/special/bdtr/)는 평균 `n * p`인 포아송 분포와 거의 같아져요. 그래서 "드물게 일어나는 일의 횟수"에 포아송 분포를 써요.

```python
>>> sd.special.bdtr(3, 1000, 0.002)
0.8573042389046867
>>> sd.special.pdtr(3, 2.0)
0.857123460498547
```

부품 1000개 중 불량률 0.2%일 때 불량이 3개 이하일 확률이, 평균 2인 포아송 분포로 소수 셋째 자리까지 맞아요. 시행 횟수를 정확히 알면 `bdtr`이 정확하고, 횟수를 셀 수 없이 "평균 몇 건"만 알면 `pdtr`을 써요.

## 여러 값을 한 번에

인자는 배열이어도 되고 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 오류 경보의 문턱을 정하려고 문턱마다 오경보 확률(평소인데 문턱을 넘을 확률)을 한 번에 볼게요.

```python
>>> thresholds = sd.asarray([4, 5, 6, 7])
>>> sd.special.pdtrc(thresholds - 1, 2.0)
array([   0.142876539501453, 0.052653017343711146, 0.016563608480614434,
       0.004533805526248867], dtype=float64)
```

평균 2건인 날에 4건 이상에서 경보를 울리면 14%의 날에 오경보가 나고, 7건 이상으로 올리면 0.5% 정도로 줄어요. 정수 배열도 float64로 계산하고, 결과는 언제나 float64예요. 결과를 미리 만든 배열에 받으려면 `out=`을 써요([특수함수의 기본](/api/special/basics/)).

## 정확도

- **보장 영역**: `k`가 1e4(1만) 이하인 범위
- **`pdtr`, `pdtrc`**: 정밀한 참값과의 상대오차가 1e-14 이하예요. 앞자리 14자리 정도가 맞는다는 뜻이고, `3.77e-26` 같은 먼 꼬리에서도 마찬가지예요.

잰 최대 오차는 `pdtr` 4.2, `pdtrc` 13 ULP예요. 1e-14가 약 45 ULP이니 약속보다 한참 작아요. ULP는 [특수함수의 기본](/api/special/basics/)에서 풀어 놓았어요. 범위 밖(`k`가 1만 초과)도 값을 계산하지만 정확도를 약속하지는 않아요.

## 특수값

| 입력 | 결과 | 뜻 |
|---|:---:|---|
| `k`가 정수가 아님 | `⌊k⌋`로 계산 | P(X ≤ k)의 뜻 그대로예요 |
| `k < 0` | 0 (`pdtrc`은 1) | 사건 수는 음수가 될 수 없어요 |
| `k = inf` | 1 (`pdtrc`은 0) | |
| `m = 0` | 1 (`pdtrc`은 0) | 사건이 일어나지 않아요 |
| `m = inf` | 0 (`pdtrc`은 1) | |
| `m < 0` | NaN | 평균은 0 이상이어야 해요 |
| 인자 중 NaN | NaN | |

## 조심할 점

### 인자 순서: `k`가 먼저

`pdtr(k, m)`은 사건 수 경계 `k`가 앞, 평균 `m`이 뒤예요. 다른 분포 함수처럼 "모양을 정하는 값이 앞"이라고 생각하면 거꾸로 넣기 쉬워요. 바꿔 넣어도 에러 없이 다른 값이 나와요.

```python
>>> sd.special.pdtr(2, 3.0)
0.42319008112684364
>>> sd.special.pdtr(3.0, 2)
0.857123460498547
```

### 값 때문에는 에러가 나지 않아요

평균이 음수이거나 NaN이 들어와도 에러 대신 NaN이에요. 결과에 NaN이 섞이지 않았는지는 직접 확인해야 해요.

```python
>>> sd.special.pdtr(3, -1.0)
nan
>>> sd.special.pdtr(sd.nan, 3.0)
nan
```

### 에러는 타입이 틀렸을 때만

복소수, 리스트, 문자열은 받지 않아요.

```python
>>> sd.special.pdtr(2, 3j)
Traceback (most recent call last):
    ...
TypeError: pdtr(): not supported for int64 and complex128
>>> sd.special.pdtr(2, 'a')
Traceback (most recent call last):
    ...
TypeError: pdtr(): 'm' must be an sd.ndarray or a bool, int, float or complex, not str
```

### 포아송 분포가 맞는지 먼저 보세요

포아송 분포는 사건이 서로 독립이고 빠르기가 일정하다고 가정해요. 점심시간에 몰리는 주문, 한 번 나면 연달아 나는 장애처럼 그렇지 않은 자료는 실제보다 꼬리가 두꺼워서, 이 함수로 구한 꼬리 확률이 지나치게 작게 나와요. 분산이 평균보다 뚜렷하게 크면 [음이항 분포](/api/special/nbdtr/)를 생각해 보세요.

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 시행 횟수가 정해진 성공 수 | [`bdtr`](/api/special/bdtr/) | 시행 횟수 `n`이 있어요. `n`이 크고 `p`가 작으면 `pdtr(k, n*p)`와 비슷해요. |
| 흩어짐이 평균보다 큰 횟수 | [`nbdtr`](/api/special/nbdtr/) | 음이항 분포는 꼬리가 더 두꺼워요. |
| 평균 `m`을 거꾸로 구하기 | [`gammainccinv`](/api/special/gammainc/) | `gammainccinv(k + 1, p)`가 `pdtr(k, m) = p`인 `m`이에요. |
| 실수 `k`로 매끄럽게 이어진 값 | [`gammaincc`](/api/special/gammainc/) | `gammaincc(k + 1, m)`은 `k`를 내리지 않아요. |
| 카이제곱과의 관계 | [`chdtrc`](/api/special/chdtr/) | `pdtr(k, m)`은 `chdtrc(2*(k+1), 2*m)`과 같아요. |

`sd.stats`에도 포아송 분포 객체가 있어요. 확률질량, 난수, 평균 같은 것을 한데 묶어 쓰고 싶으면 그쪽을 쓰고, 누적확률 하나만 빠르게 필요하면 이 함수들이 간단해요.

## scipy를 아는 분께

- 이름, 인자 순서, 뜻은 `scipy.special.pdtr`, `pdtrc`과 같아요. 정수가 아닌 `k`를 내리는 것도 같아요.
- 음수 `k`에서 `pdtr`은 0, `pdtrc`은 1이에요. scipy 1.18.1은 둘 다 NaN을 돌려줘요.
- 역함수 `pdtri`(평균을 구함)와 `pdtrik`(k를 구함)은 없어요. 평균은 `gammainccinv(k + 1, p)`로 구해요.
- 리스트, numpy 배열은 받지 않아요. `sd.ndarray`와 Python 숫자만 받아요. `out`은 keyword-only예요.
