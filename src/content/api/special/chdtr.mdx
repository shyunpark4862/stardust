## 한눈에 보기

**카이제곱 분포**(chi-square, χ² 분포)는 **표준정규분포를 따르는 값 여러 개를 제곱해서 더한 값**의 분포예요. 제곱해서 더했으니 언제나 0 이상이고, 오른쪽으로 꼬리가 길게 늘어진 모양이에요. 더한 값의 개수를 **자유도**(`v`)라고 불러요.

"관찰한 것과 기대한 것의 차이를 제곱해서 모은 값"이 이 분포를 따르는 경우가 많아서, 통계 검정 곳곳에 나와요.

- **적합도 검정**: 주사위가 공정한지, 고객 유입이 요일마다 고른지처럼 "관찰한 빈도가 기대한 비율과 맞나"를 볼 때
- **독립성 검정**: 성별과 선호 제품처럼 두 범주가 서로 관련이 있는지 볼 때(교차표 검정)
- **분산의 신뢰구간**: 공정의 흩어짐(표준편차)이 얼마인지 범위로 말할 때
- **이상치 탐지**: 여러 변수를 함께 본 거리(마할라노비스 거리)의 제곱이 너무 큰지 판단할 때
- **우도비 검정**: 두 통계 모형 중 복잡한 쪽이 정말 나은지 볼 때

세 함수가 한 묶음이에요.

- `chdtr(v, x)`: X가 `x` 이하일 확률 P(X ≤ x), 곧 **누적분포함수**(cdf)
- `chdtrc(v, x)`: X가 `x`보다 클 확률 P(X > x), 곧 **생존함수**(survival function). 이름 끝의 `c`는 보수(complement, 1에서 뺀 나머지)라는 뜻이에요.
- `chdtri(v, p)`: 위꼬리 확률이 `p`가 되는 지점 `x`. **`chdtrc`의 역함수**예요.

```python
>>> import stardust as sd
>>> sd.special.chdtr(2, 2.0)
0.6321205588285578
>>> sd.special.chdtrc(2, 2.0)
0.3678794411714422
>>> sd.special.chdtri(5, 0.05)
11.070497693516355
```

자유도 2일 때 누적확률은 $1 - e^{-x/2}$라서 첫 줄은 $1 - e^{-1}$이에요. 둘째 줄은 그 나머지 $e^{-1}$이고요. 마지막 줄은 "자유도 5에서 위쪽 5%를 자르는 지점은 약 11.07"이라는 뜻으로, 검정에서 기각 여부를 가르는 **임계값**이에요.

## 카이제곱 분포의 정의

$Z_1, \dots, Z_v$가 서로 독립이고 각각 표준정규분포를 따르면

$$
X = Z_1^2 + Z_2^2 + \cdots + Z_v^2
$$

는 자유도 $v$인 카이제곱 분포를 따라요. 밀도는

$$
f_v(s) = \frac{s^{v/2 - 1}\, e^{-s/2}}{2^{v/2}\, \Gamma(v/2)}, \qquad s > 0
$$

이고, `chdtr`은 이 곡선 아래 0부터 `x`까지의 넓이예요. 이 넓이는 [정칙화된 불완전 감마 함수](/api/special/gammainc/)로 바로 쓸 수 있어요.

$$
\mathrm{chdtr}(v, x) = \int_0^x f_v(s)\, ds = P\!\left(\tfrac{v}{2}, \tfrac{x}{2}\right) = \texttt{gammainc}(v/2,\ x/2)
$$

```python
>>> sd.special.chdtr(3, 2.5)
0.5247089166569794
>>> sd.special.gammainc(1.5, 1.25)
0.5247089166569794
```

`chdtrc`는 마찬가지로 `gammaincc(v/2, x/2)`예요. 감마 함수로 직접 써도 되지만, 자유도와 지점을 그대로 넣는 `chdtr` 쪽이 읽기 쉽고 반으로 나누는 실수를 막아 줘요.

자유도가 1이면 표준정규분포를 제곱한 값의 분포라, 정규분포의 양쪽 꼬리와 이어져요. `chdtrc(1, z**2)`는 `2 * ndtr(-abs(z))`와 같아요(실수 계산이라 마지막 자리는 다를 수 있어요).

```python
>>> sd.special.chdtrc(1, 1.96 ** 2)
0.049995790296440884
>>> 2 * sd.special.ndtr(-1.96)
0.04999579029644086
```

## 적합도 검정: 주사위가 공정할까요

주사위를 60번 던졌더니 1부터 6까지의 눈이 이만큼 나왔어요. 공정한 주사위라면 눈마다 10번씩 나와야 해요. 6이 유난히 많은데, 우연이라고 보기에는 너무 많은 걸까요?

**피어슨 카이제곱 통계량**은 칸마다 (관찰 − 기대)²/기대를 더한 값이에요. 공정한 주사위라면 이 값은 자유도 `칸 수 - 1 = 5`인 카이제곱 분포를 대략 따라요.

```python
>>> observed = sd.asarray([5.0, 8.0, 9.0, 8.0, 10.0, 20.0])
>>> expected = 10.0
>>> chi2 = sd.sum((observed - expected) ** 2 / expected)
>>> chi2
13.4
```

p값은 "공정한 주사위로 던져도 이만큼 이상 벗어날 확률"이에요. 통계량이 **클수록** 기대와 많이 어긋난 것이니, 위꼬리 확률을 봐요.

```python
>>> sd.special.chdtrc(5, chi2)
0.01990522033477438
```

약 2%예요. 기준을 5%로 잡으면 "공정하지 않다"고 판단해요. 임계값으로 봐도 같아요. 13.4는 앞에서 구한 5% 임계값 11.07보다 커요.

<Callout type="tip" title="p값에는 chdtrc">
  카이제곱 검정은 거의 언제나 위꼬리 검정이에요. p값은 `chdtrc(v, 통계량)`이고, `chdtr`(아래꼬리)을 쓰면 정반대의 확률이 나와요.
</Callout>

그렇다면 `chdtrc`가 왜 따로 있을까요? `1 - chdtr(v, x)`로 계산하면 **꼬리에서 자릿수를 잃기 때문**이에요. `x`가 크면 `chdtr`은 1에 아주 가까워지고, float64는 1 근처에서 약 1.1e-16 간격으로만 수를 나타내요. 1에서 빼면 그 간격보다 작은 부분은 남지 않아요.

```python
>>> sd.special.chdtrc(4, 60.0)
2.900863120340454e-12
>>> 1 - sd.special.chdtr(4, 60.0)
2.9009017410430715e-12
```

`chdtrc`가 참값이에요. `1 - chdtr`은 앞 네 자리만 맞아요. 더 먼 꼬리에서는 아예 0이 돼요.

```python
>>> sd.special.chdtrc(4, 200.0)
3.7572767357810436e-42
>>> 1 - sd.special.chdtr(4, 200.0)
0.0
```

`chdtrc`는 1에서 빼지 않고 꼬리의 작은 넓이를 **직접** 계산해서, 이런 값에서도 앞자리 14자리 정도가 맞아요. 아주 작은 p값을 비교하거나 로그를 씌워 쓰는 경우(유전자 수만 개를 한꺼번에 검정하는 경우 등)에는 꼭 `chdtrc`를 쓰세요.

## 임계값: `chdtri`는 위꼬리의 역함수

`chdtri(v, p)`는 **위꼬리 확률** `chdtrc(v, x)`가 `p`가 되는 `x`를 돌려줘요. 검정의 유의수준(보통 0.05)을 그대로 넣으면 임계값이 나와서 편해요.

```python
>>> x05 = sd.special.chdtri(5, 0.05)
>>> x05
11.070497693516355
>>> sd.special.chdtrc(5, x05)
0.04999999999999999
```

되돌려 넣으면 0.05가 돌아와요. 마지막 자리의 차이는 실수 계산의 반올림이에요.

<Callout type="warn" title="chdtr의 역함수가 아니에요">
  이름은 `chdtr` + `i`(inverse)지만 `chdtr`이 아니라 **`chdtrc`를 거꾸로** 푼 함수예요. `chdtri(5, 0.05)`는 아래 5% 지점이 아니라 **위** 5% 지점(11.07)이에요. 반면 F 분포의 [`fdtri`](/api/special/fdtr/)와 t 분포의 [`stdtrit`](/api/special/stdtr/)은 아래꼬리(누적확률)의 역함수라서, 두 영역을 오가며 쓸 때 헷갈리기 쉬워요.
</Callout>

### 아래꼬리 분위수가 필요하면

아래 5% 지점은 위꼬리 확률이 95%인 지점이라 `chdtri(5, 0.95)`로 구해요. 같은 값을 [`gammaincinv`](/api/special/gammainc/)로도 구할 수 있어요. 카이제곱의 누적확률이 `gammainc(v/2, x/2)`이니, 그 역함수에 2를 곱하면 돼요.

```python
>>> sd.special.chdtri(5, 0.95)
1.1454762260617692
>>> 2 * sd.special.gammaincinv(2.5, 0.05)
1.1454762260617692
```

아래꼬리 확률이 **아주 작을 때는** 둘째 방법을 써야 해요. `1 - 1e-20`은 float64로 정확히 1이 되어 버려서, `chdtri`에 넘기는 순간 정보가 사라지기 때문이에요.

```python
>>> sd.special.chdtri(5, 1 - 1e-20)
0.0
>>> 2 * sd.special.gammaincinv(2.5, 1e-20)
3.233407795518736e-08
```

## 분산의 신뢰구간

정규분포를 따르는 값을 `n`개 재서 표본 분산 $s^2$를 구하면, $(n-1)s^2/\sigma^2$은 자유도 $n-1$인 카이제곱 분포를 따라요($\sigma^2$은 참 분산). 이것을 뒤집으면 참 분산의 신뢰구간이 나와요.

부품 다섯 개의 길이 편차를 쟀다고 해 볼게요.

```python
>>> x = sd.asarray([4.0, 6.0, 5.0, 7.0, 3.0])
>>> s2 = sd.var(x, correction=1)
>>> s2
2.5
>>> lo = 4 * s2 / sd.special.chdtri(4, 0.025)
>>> hi = 4 * s2 / sd.special.chdtri(4, 0.975)
>>> (lo, hi)
(0.8974012960218244, 20.64330495535668)
```

`chdtri(4, 0.025)`는 위 2.5% 지점(큰 값), `chdtri(4, 0.975)`는 아래 2.5% 지점(작은 값)이에요. 큰 값으로 나눈 쪽이 하한이에요. 참 분산은 95% 신뢰도로 약 0.90에서 20.6 사이예요. 표본이 다섯 개뿐이라 구간이 아주 넓어요.

## 자유도에 대해

### 정수가 아니어도 돼요

자유도는 0 이상의 실수면 돼요. 검정에 따라 자유도를 보정해서 소수가 나오기도 하는데, 그대로 넣으면 돼요.

```python
>>> sd.special.chdtr(0.5, 1.0)
0.8464864041916775
```

### 자유도 0과 무한대

자유도 0은 "제곱해서 더한 값이 하나도 없는" 분포라, 값이 언제나 0이에요. 그래서 `x > 0`이면 누적확률이 1이에요. `x = 0`인 점에서는 값이 정해지지 않아서 NaN이에요.

```python
>>> sd.special.chdtr(0, 1.0)
1.0
>>> sd.special.chdtr(0, 0.0)
nan
```

자유도가 무한대이면 분포 전체가 무한대 쪽으로 가 버려서, 유한한 `x`의 누적확률은 0이에요.

```python
>>> sd.special.chdtr(sd.inf, 1.0)
0.0
```

## 여러 값을 한 번에

인자는 배열이어도 되고 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 같은 통계량 3.84가 자유도에 따라 얼마나 흔한 값인지 한 번에 볼게요.

```python
>>> sd.special.chdtrc(sd.asarray([1, 2, 3, 4]), 3.84)
array([ 0.0500435212487051, 0.14660696213035015,  0.2792676171186102,
       0.42809232942062236], dtype=float64)
```

자유도 1에서는 위꼬리 5%의 경계지만, 자유도 4에서는 43%나 되는 평범한 값이에요. 정수 배열도 float64로 계산하고, 결과는 언제나 float64예요. 결과를 미리 만든 배열에 받으려면 `out=`을 써요([특수함수의 기본](/api/special/basics/)).

## 정확도

- **보장 범위**: 자유도 0.01부터 1e5(10만)까지, `x`와 `p`는 모든 값
- **`chdtr`, `chdtrc`**: 정밀한 참값과의 상대오차가 1e-14 이하예요. 앞자리 14자리 정도가 맞는다는 뜻이고, `3.76e-42` 같은 먼 꼬리에서도 마찬가지예요.
- **`chdtri`**: 결과 x의 상대오차가 1e-14에 "입력 p가 마지막 자리만큼 흔들릴 때 x가 흔들리는 배율"을 곱한 값 이하예요. p가 실수로 저장되면서 생기는 불확실성이 허용하는 만큼은 정확하다는 뜻이에요. 대부분의 p에서 배율은 1 근처예요. 자유도가 아주 작으면 x가 p의 거듭제곱처럼 변해서 배율이 커질 수 있어요.

잰 최대 오차는 `chdtr` 6.1, `chdtrc` 9.7, `chdtri` 7.2 ULP(위의 배율로 나눈 값)예요. 1e-14는 약 45 ULP라 약속보다 한참 작아요. ULP는 [특수함수의 기본](/api/special/basics/)에서 풀어 놓았어요. 범위 밖(자유도 1e5 초과)도 값을 계산하지만 정확도를 약속하지는 않아요.

## 특수값

| 입력 | 결과 | 뜻 |
|---|:---:|---|
| `chdtr(v, 0)`, `chdtr(v, inf)` | 0, 1 | 분포의 양 끝 (`chdtrc`는 1, 0) |
| `chdtr(0, x)`, `x > 0` | 1 | 0에 몰린 분포 (`chdtrc`는 0) |
| `chdtr(0, 0)` | NaN | 정해지지 않아요 |
| `chdtr(inf, x)`, 유한한 `x` | 0 | 분포가 무한대로 가요 (`chdtrc`는 1) |
| `chdtri(v, 0)`, `chdtri(v, 1)` | inf, 0 | 위꼬리 0이면 오른쪽 끝, 1이면 왼쪽 끝 |
| `chdtri(0, p)`, `chdtri(inf, p)` | NaN | 근을 정할 수 없어요 |
| `v < 0` | NaN | 자유도는 0 이상이어야 해요 |
| `x < 0` | NaN | |
| `p < 0` 또는 `p > 1` | NaN | 확률이 아니에요 |
| 인자 중 NaN | NaN | |

## 조심할 점

### 음수 `x`는 0이 아니라 NaN

카이제곱 값은 음수가 될 수 없으니 수학적으로는 P(X ≤ −1) = 0이라고 말할 수도 있어요. 하지만 이 함수는 음수 `x`를 정의역 밖으로 보고 NaN을 돌려줘요. 계산 실수로 음수 통계량이 나왔을 때 조용히 0이 되어 묻히지 않게 하려는 거예요.

```python
>>> sd.special.chdtr(3, -1.0)
nan
```

### 값 때문에는 에러가 나지 않아요

자유도가 음수이거나 확률이 1보다 커도 에러 대신 NaN이에요. 배열 일부가 잘못돼도 나머지는 계산되지만, 결과에 NaN이 섞이지 않았는지는 직접 확인해야 해요.

```python
>>> sd.special.chdtr(-1, 1.0)
nan
>>> sd.special.chdtri(3, 1.5)
nan
```

### 에러는 타입이 틀렸을 때만

복소수, 리스트, 문자열은 받지 않아요.

```python
>>> sd.special.chdtr(2, 1j)
Traceback (most recent call last):
    ...
TypeError: chdtr(): not supported for int64 and complex128
>>> sd.special.chdtrc([1, 2], 3.84)
Traceback (most recent call last):
    ...
TypeError: chdtrc(): 'v' must be an sd.ndarray or a bool, int, float or complex, not list
```

### 자유도는 칸 수에서 빼요

적합도 검정의 자유도는 칸 수 − 1이에요. 기대 비율을 정할 때 자료에서 모수를 추정했다면 그 개수만큼 더 빼요. 교차표의 독립성 검정은 (행 수 − 1) × (열 수 − 1)이에요. 자유도를 잘못 넣어도 에러 없이 다른 p값이 나와요.

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 감마 분포의 누적확률 | [`gammainc`, `gammaincc`](/api/special/gammainc/) | `chdtr(v, x)`는 `gammainc(v/2, x/2)`예요. 모양 모수가 임의인 감마 분포는 이쪽을 써요. |
| 아래꼬리 분위수 | `chdtri(v, 1 - p)` 또는 `2 * gammaincinv(v/2, p)` | `chdtri`는 위꼬리의 역함수예요. 아주 작은 `p`는 뒤쪽이 정확해요. |
| 검정력 계산(가정이 틀렸을 때의 통계량 분포) | [`chndtr`](/api/special/chndtr/) | 비중심 카이제곱이에요. 비중심 모수가 0이면 `chdtr`과 같아요. |
| 분산 둘의 비율 | [`fdtr`](/api/special/fdtr/) | 카이제곱 둘을 각자 자유도로 나눈 비율의 분포예요. |
| 자유도 1의 꼬리 | [`ndtr`](/api/special/ndtr/) | `chdtrc(1, z**2)`는 `2 * ndtr(-abs(z))`예요. |

`sd.stats`에도 카이제곱 분포 객체가 있어요. 밀도, 난수, 평균 같은 것을 한데 묶어 쓰고 싶으면 그쪽을 쓰고, 누적확률이나 임계값 하나만 빠르게 필요하면 이 함수들이 간단해요.

## scipy를 아는 분께

- 이름, 인자 순서, 뜻은 `scipy.special.chdtr`, `chdtrc`, `chdtri`와 같아요. `chdtri`가 위꼬리의 역함수인 것도 같아요.
- 자유도를 거꾸로 구하는 `chdtriv`는 없어요.
- 특수값(자유도 0, 무한대, 음수 `x`)도 scipy 1.18.1과 같아요.
- 비중심판 [`chndtr`](/api/special/chndtr/)은 인자 순서가 scipy와 달라요(`chndtr(df, nc, x)`, 지점이 맨 뒤).
- 리스트, numpy 배열은 받지 않아요. `sd.ndarray`와 Python 숫자만 받아요. `out`은 keyword-only예요.
