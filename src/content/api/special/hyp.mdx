## 한눈에 보기

초기하 함수는 여러 특수함수를 한 지붕 아래 모은 급수예요. 지수함수, 로그, 오차함수, 불완전 감마·베타 함수, 타원적분, 여러 직교다항식이 모두 초기하 함수의 매개변수를 특정한 값으로 고른 경우예요. 그래서 어떤 공식이 "₁F₁"이나 "₂F₁"으로 적혀 있다면, 따로 함수를 찾지 않고 이 두 함수로 바로 계산할 수 있어요.

- 통계와 확률: 비중심 분포, 표본 상관계수의 분포, 베타·감마 분포의 모멘트과 누적분포함수가 초기하 함수로 표현돼요.
- 물리: 수소 원자의 파동함수(₁F₁), 쿨롱 파동, 양자역학의 여러 정확한 해.
- 수학과 공학: 미분방정식의 해, 직교다항식(Laguerre, Jacobi, Legendre), 등각사상.

이 페이지에는 두 함수가 있어요.

- `hyp1f1(a, b, x)`: Kummer의 **합류 초기하 함수** ${}_1F_1(a; b; x)$. 흔히 M(a, b, x)로도 써요.
- `hyp2f1(a, b, c, z)`: Gauss의 **초기하 함수** ${}_2F_1(a, b; c; z)$.

정의는 거듭제곱 급수예요. 먼저 "올라가는 곱" $(a)_n$(Pochhammer 기호)을 정해요.

$$(a)_0 = 1, \qquad (a)_n = a(a+1)(a+2)\cdots(a+n-1)$$

$$
{}_1F_1(a; b; x) = \sum_{n=0}^{\infty} \frac{(a)_n}{(b)_n}\,\frac{x^n}{n!},
\qquad
{}_2F_1(a, b; c; z) = \sum_{n=0}^{\infty} \frac{(a)_n\,(b)_n}{(c)_n}\,\frac{z^n}{n!}
$$

이름의 숫자는 분자와 분모에 있는 매개변수의 개수예요. ₁F₁은 분자에 a 하나, 분모에 b 하나, ₂F₁은 분자에 a, b 둘, 분모에 c 하나예요. 첫 항은 언제나 1이라서 x = 0(또는 z = 0)에서 값은 1이에요.

₁F₁의 급수는 모든 x에서 수렴해요. ₂F₁의 급수는 |z| &lt; 1에서만 수렴하지만, z ≤ −1 쪽으로도 값을 매끄럽게 이어서 정의할 수 있어서 `hyp2f1`은 z &lt; 1 전체에서 값을 내요.

```python
>>> import stardust as sd
>>> x = sd.asarray([0.0, 1.0, 2.0])
>>> sd.special.hyp1f1(1.0, 1.0, x)
array([              1.0, 2.718281828459045,  7.38905609893065], dtype=float64)
>>> sd.exp(x)
array([              1.0, 2.718281828459045,  7.38905609893065], dtype=float64)
>>> sd.special.hyp2f1(1.0, 1.0, 2.0, -1.0)
0.6931471805599453
>>> sd.log(2.0)
0.6931471805599453
```

첫째는 ${}_1F_1(1; 1; x) = e^x$, 둘째는 ${}_2F_1(1, 1; 2; -1) = \ln 2$예요.

## 급수를 직접 더해 보면

정의의 급수를 그대로 더해 보면 무엇을 계산하는지 감이 와요. 다음 항은 앞 항에 $\frac{a+n}{b+n}\cdot\frac{x}{n+1}$을 곱한 것이에요.

```python
>>> a, b, x = 0.5, 1.5, 0.3
>>> term, total = 1.0, 0.0
>>> for n in range(30):
...     total += term
...     term *= (a + n) / (b + n) * x / (n + 1)
>>> total
1.1096822789280743
>>> sd.special.hyp1f1(a, b, x)
1.1096822789280743
```

x가 작으면 이렇게 몇십 항이면 충분해요. 하지만 x가 크거나 음수이면 항이 엄청나게 커졌다가 서로 지워지거나 수천 항이 필요해져서, 급수를 그대로 더하는 방법은 금방 틀린 값을 내요. `hyp1f1`과 `hyp2f1`은 이런 영역에서도 정확한 값을 내도록 만들어져 있어요.

## 여러 함수가 특별한 경우로 들어 있어요

## a가 0 이하의 정수면 다항식이 돼요

$(a)_n$은 a가 0, −1, −2, … 같은 정수이면 어느 순간 0이 되고, 그 뒤의 항은 모두 0이에요. 그러면 무한 급수가 **유한한 다항식**으로 끝나요. 예를 들어 ${}_1F_1(-2; 1; x) = 1 - 2x + \tfrac{x^2}{2}$이에요.

```python
>>> sd.special.hyp1f1(-2.0, 1.0, sd.asarray([0.0, 1.0, 2.0, 4.0]))
array([ 1.0, -0.5, -1.0,  1.0], dtype=float64)
```

`hyp2f1`도 마찬가지예요. 다항식이면 급수가 수렴하는지를 따질 필요가 없어서, **z ≥ 1에서도 값을 내요.** ${}_2F_1(-2, 1; 1; z) = (1 - z)^2$이에요.

```python
>>> sd.special.hyp2f1(-2.0, 1.0, 1.0, 3.0)
4.0
```

차수가 높은 다항식도 값을 내요. 0 < z < 1에서 차수가 수십을 넘으면 부호가 번갈아 바뀌는 항들이 크게 지워질 수 있어요. a가 0 이하의 정수일 때 c > 0이고 c − b > 0이면(Jacobi·Gegenbauer 다항식이 이 꼴이에요) 그래도 정확한 값을 내요. b가 0 이하의 정수이면 a와 b를 바꿔 읽어요. 그 밖에서 지워짐이 너무 크면 NaN이에요.

```python
>>> sd.special.hyp2f1(-200.0, 1.0, 2.0, 0.3)
0.016583747927031506
```

## 분모 매개변수가 0 이하의 정수면 극점이에요

분모의 $(b)_n$(₂F₁에서는 $(c)_n$)이 0이 되면 그 항은 0으로 나누는 꼴이 돼요. 그래서 b(또는 c)가 0, −1, −2, …이면 함수가 무한대로 가는 **극점**이고, 결과는 `inf`예요.

단, **분자의 다항식이 먼저 끝나면** 0으로 나누는 항까지 가지 않으므로 그 다항식의 값을 내요. a도 0 이하의 정수이고 a ≥ b이면 그래요. 예를 들어 a = −1, b = −2이면 급수가 $1 + \frac{(-1)}{(-2)}x$에서 끝나요.

```python
>>> sd.special.hyp1f1(1.0, -2.0, 1.0)
inf
>>> sd.special.hyp1f1(-1.0, -2.0, 1.0)
1.5
>>> sd.special.hyp1f1(-3.0, -2.0, 1.0)
inf
>>> sd.special.hyp1f1(0.0, 0.0, 5.0)
1.0
>>> sd.special.hyp2f1(1.0, 1.0, 0.0, 0.5)
inf
>>> sd.special.hyp2f1(-1.0, 1.0, -2.0, 0.5)
1.25
```

`hyp1f1(0, 0, x)`가 1인 것도 같은 이유예요. a = 0이면 첫 항 1에서 급수가 끝나요.

## hyp1f1: x가 무한대일 때

x → +∞이면 ₁F₁은 지수함수처럼 커지고, 그 부호는 $\Gamma(b)/\Gamma(a)$의 부호를 따라요(다항식이면 최고차항의 부호). x → −∞이면 a > 0일 때 0으로 가요.

```python
>>> sd.special.hyp1f1(1.0, 2.0, sd.inf)
inf
>>> sd.special.hyp1f1(-1.0, 2.0, sd.inf)
-inf
>>> sd.special.hyp1f1(0.5, 2.0, -sd.inf)
0.0
```

둘째는 ${}_1F_1(-1; 2; x) = 1 - \tfrac{x}{2}$라서 −∞로 가요.

## hyp2f1: z ≥ 1일 때

z ≥ 1과 z = −∞에서 `hyp2f1`은 경우를 나눠요.

| 경우 | 결과 |
|---|---|
| a나 b가 0 이하의 정수(다항식) | 그 다항식의 값 |
| z = 1이고 c − a − b > 0 | Gauss 공식 $\dfrac{\Gamma(c)\,\Gamma(c-a-b)}{\Gamma(c-a)\,\Gamma(c-b)}$ |
| z = 1이고 c − a − b ≤ 0 | NaN (급수가 발산해요) |
| z > 1 | NaN (실수 값이 정해지지 않아요) |
| z = −∞ | a, b > 0이면 0 |

z > 1에서 ₂F₁의 값은 복소수가 되거나, z = 1을 어느 쪽으로 돌아가느냐에 따라 달라져요. 실수 하나로 답할 수 없으니 NaN을 내요.

```python
>>> sd.special.hyp2f1(1.0, 1.0, 3.0, 1.0)
2.0
>>> sd.special.gamma(3.0) * sd.special.gamma(1.0) / (sd.special.gamma(2.0) * sd.special.gamma(2.0))
2.0
>>> sd.special.hyp2f1(1.0, 1.0, 2.0, 1.0)
nan
>>> sd.special.hyp2f1(0.5, 0.5, 1.5, 2.0)
nan
>>> sd.special.hyp2f1(1.0, 1.0, 2.0, -sd.inf)
0.0
```

## 배열과 브로드캐스팅

모든 인자가 배열이나 Python 숫자일 수 있고, [브로드캐스팅](/api/array/broadcasting/) 규칙으로 모양을 맞춰요. 매개변수 하나만 바꿔 가며 계산할 때 편해요.

```python
>>> sd.special.hyp2f1(1.0, 1.0, sd.asarray([2.0, 3.0, 4.0]), 0.5)
array([1.3862943611198906, 1.2274112777602186,  1.158883083359672], dtype=float64)
>>> a = sd.asarray([0.0, 1.0, 2.0])
>>> x = sd.asarray([[0.5], [1.0]])
>>> sd.special.hyp1f1(a, 1.0, x).shape
(2, 3)
```

정수와 bool은 float64로 바꿔서 계산해요. 인자가 모두 Python 숫자면 결과는 Python `float`예요. `out=`의 규칙은 배열 영역의 [사칙연산](/api/array/arithmetic/)에서 설명한 것과 같아요.

```python
>>> sd.special.hyp1f1(2, 1, 1)
5.43656365691809
>>> type(sd.special.hyp2f1(1, 1, 2, 0.5))
<class 'float'>
```

## 정확도

초기하 함수는 매개변수가 넷(hyp2f1)이라 영역이 넓고, 어떤 곳에서는 큰 수끼리 서로 지워지는 계산을 피할 수 없어요. 그래서 정확도를 두 단계로 약속해요.

| 함수 | 상대오차 10⁻¹⁴ 이하를 약속하는 곳 |
|---|---|
| `hyp1f1` | a ≥ 0, b > 0이고 (x ≥ 0 또는 b ≥ a) |
| `hyp2f1` | a, b ≥ 0, c > 0, c ≥ min(a, b), −1 ≤ z ≤ 0.9 |

상대오차 10⁻¹⁴ 이하는 앞 14자리쯤이 맞는다는 뜻이에요. 이 영역에는 큰 수끼리 지워지는 일 없이 값을 계산할 수 있는 표현이 있어요. 실제로 잰 최대 오차는 `hyp1f1`이 16 ULP(상대오차로는 1.8 × 10⁻¹⁵), `hyp2f1`이 11 ULP예요.

그 밖의 정의역에서도 값을 계산하지만 약속은 느슨해요. 인자 크기 10⁶까지의 무작위 입력 1만 1천 개씩을 고정밀 참값과 비교해 잰 최대 상대오차는 `hyp1f1`이 9 × 10⁻¹², `hyp2f1`이 1.7 × 10⁻¹²였어요(앞 11자리쯤). 다만 이 값은 표본에서 잰 것이라 모든 입력에 대한 약속은 아니에요. a가 아주 큰 음수이고 x > 0인 `hyp1f1`처럼 지워짐이 심한 곳도 대개 끝자리까지 맞아요.

```python
>>> sd.special.hyp1f1(-1000.5, 2.0, 0.5)
-3.669285445620292e-05
```

이 값의 참값은 −3.669285445620292473…×10⁻⁵이라, 결과가 참값에 가장 가까운 float64예요.

### 값을 믿을 수 없으면 NaN

두 함수는 어떤 입력이든 정해진 시간 안에 끝나요. 급수나 반복이 정해진 횟수 안에 끝나지 않거나, 큰 수끼리 지워져서 남는 자릿수를 믿을 수 없으면 틀린 값을 내는 대신 NaN을 돌려줘요. 보장 영역 안에서는 이런 일이 없어요.

- `hyp1f1`: 인자 하나의 크기가 10⁶을 넘을 때(짧은 다항식이 되는 경우와 아주 큰 |x|는 값을 줘요), 그리고 |a|나 |b|가 100을 넘으면서 지워짐을 피하는 계산 방법이 없을 때예요. 대부분 b < 0이고 |a|나 |b|가 큰 곳이지만, b > 0이어도 a < 0이고 x가 |a|·b 근처인 좁은 띠가 있어요(`hyp1f1(-150.5, 1, 150)`).
- `hyp2f1`: 급수가 정해진 항 수 안에 끝나지 않을 때, 급수의 항이 서로 지워져서 자릿수가 거의 남지 않을 때, z가 1에 아주 가깝고 c − a − b가 정수에 아주 가까울 때예요.

```python
>>> sd.special.hyp1f1(137.5, -33.5, -4.3)
nan
>>> sd.special.hyp2f1(30.0, 30.0, 1.5, -5.0)
nan
```

두 값의 참값은 각각 약 −3.42 × 10⁹와 −1.28 × 10⁻²⁵예요. 이런 곳에서 급수를 그대로 더하면 큰 항들이 지워진 뒤 남는 자릿수를 믿을 수 없어서, 부호까지 틀린 값이 나올 수 있어요. 그런 값을 내는 대신 NaN으로 알려 줘요.

정확도를 재는 방법은 [특수함수의 기본](/api/special/basics/)에서 자세히 설명해요.

## 조심할 점

### 결과가 NaN이나 inf여도 에러는 없어요

z > 1, 극점, 발산처럼 값이 정해지지 않는 곳에서도 에러 없이 NaN이나 `inf`가 나와요. 배열의 다른 원소는 그대로 계산돼요. 결과에 NaN이 섞였다면 위의 표에서 z ≥ 1인 경우에 해당하는지, 아니면 [값을 믿을 수 없어 NaN을 내는 곳](#값을-믿을-수-없으면-nan)인지 확인해 보세요. NaN이 들어가면 NaN이 나와요(a = 0이어도 x가 NaN이면 NaN이에요).

```python
>>> sd.special.hyp2f1(1.0, 1.0, 2.0, sd.asarray([0.5, 1.5, sd.nan]))
array([1.3862943611198906,                nan,                nan], dtype=float64)
>>> sd.special.hyp1f1(0.0, 1.0, sd.nan)
nan
```

### 복소수와 리스트는 받지 않아요

인자 중 하나라도 복소수면 `TypeError`예요. 리스트도 받지 않으니 `sd.asarray`로 바꾸세요.

    ...
TypeError: hyp1f1(): not supported for float64, float64 and complex128

`hyp2f1(a, b, c, z)`에서 변수 z는 **맨 뒤**예요. a와 b는 바꿔도 값이 같지만(대칭), c와 z의 자리는 바꾸면 안 돼요. 모양이 맞지 않으면 `ValueError`예요.

## 비슷한 함수와의 차이

공식이 초기하 함수로 적혀 있어도, **같은 일을 하는 전용 함수가 있으면 전용 함수를 쓰세요.** 전용 함수는 더 빠르고, 정의역 전체에서 정확도를 약속하는 경우가 많아요. 초기하 함수는 전용 함수가 없을 때 쓰는 일반 도구예요.

| 공식 | 전용 함수 | 이유 |
|---|---|---|
| ${}_1F_1(a; a; x) = e^x$ | [`sd.exp`](/api/array/exp-log/) | 가장 빠르고 정확해요 |
| erf를 ₁F₁로 쓴 식 | [`erf`](/api/special/erf/) | 꼬리까지 정확해요 |
| 불완전 감마를 ₁F₁로 쓴 식 | [`gammainc`](/api/special/gammainc/) | 정의역 전체에서 정확도를 약속하고, 보수 함수와 역함수도 있어요 |
| 불완전 베타를 ₂F₁로 쓴 식 | [`betainc`](/api/special/betainc/) | 정의역 전체에서 정확도를 약속해요(₂F₁로 쓴 식은 x > 0.9에서 보장 영역을 벗어나요) |
| $z\,{}_2F_1(1, 1; 2; -z) = \ln(1+z)$ | [`sd.log1p`](/api/array/exp-log/) | |
| $\tfrac{\pi}{2}\,{}_2F_1(\tfrac12, \tfrac12; 1; m) = K(m)$ | [`ellipk`](/api/special/ellip/) | m → 1에서도 정확도를 약속해요 |

예를 들어 정칙화한 불완전 베타 함수는 ${}_2F_1$로 쓸 수 있어요. 값은 마지막 자리 근처까지 같아요.

$$I_x(a, b) = \frac{x^a (1-x)^b}{a\,B(a, b)}\;{}_2F_1(a+b, 1; a+1; x)$$

```python
>>> a, b, x = 2.0, 3.0, 0.4
>>> sd.special.betainc(a, b, x)
0.5247999999999999
>>> x ** a * (1 - x) ** b / (a * sd.special.beta(a, b)) * sd.special.hyp2f1(a + b, 1.0, a + 1, x)
0.5248000000000002
```

## scipy를 아는 분께

- 이름과 인자 순서는 `scipy.special.hyp1f1`, `hyp2f1`과 같아요. `out=`은 keyword-only예요.
- **복소수를 받지 않아요.** scipy는 `hyp1f1`의 x와 `hyp2f1`의 z에 복소수를 받아요.
- `hyp0f1`, `hyperu`(두 번째 종류의 합류 초기하 함수)는 없어요.
- 특수값이 다른 곳은 이래요(scipy 1.18.1 기준).
  - `hyp1f1(0, 0, x)`는 1이에요. scipy는 `inf`예요.
  - `hyp1f1(-1, 2, inf)`는 `-inf`예요(다항식 1 − x/2의 극한). scipy는 `inf`예요.
  - `hyp1f1(0.5, 2, -inf)`는 0이에요. scipy는 NaN이에요.
  - `hyp2f1(a, b, c, -inf)`는 a, b > 0이면 0이에요. scipy는 NaN이에요.
  - z > 1이거나, z = 1이고 c − a − b ≤ 0이면 NaN이에요(다항식 제외). scipy는 이런 곳에서 `inf`를 낼 때가 있어요. 예: `hyp2f1(0.5, 0.5, 1.5, 2.0)`, `hyp2f1(1, 1, 2, 1.0)`은 scipy에서 `inf`예요.
- **보장 영역 밖에서 값을 믿을 수 없으면 NaN이에요.** scipy는 이런 곳에서도 값을 내는데, 크게 틀릴 때가 있어요. 예: `hyp1f1(137.5, -33.5, -4.3)`은 scipy에서 −7.6 × 10¹⁹(참값 −3.42 × 10⁹), `hyp2f1(30.0, 30.0, 1.5, -5.0)`은 scipy에서 8.8 × 10⁻²³(참값 −1.28 × 10⁻²⁵)이에요.
- 보장 영역 밖의 정확도가 scipy보다 좋은 곳이 많아요. 예를 들어 `hyp2f1(4.88, 7.58, -9.97, -0.217)`의 scipy 값은 앞 8자리만 맞아요.
