## 한눈에 보기

베타 함수 B(a, b)는 **0과 1 사이에서 t^(a−1)(1−t)^(b−1)의 넓이**예요. a와 b가 0보다 크면 이 넓이는 언제나 유한한 양수예요.

$$B(a, b) = \int_0^1 t^{a-1} (1-t)^{b-1}\, dt = \frac{\Gamma(a)\,\Gamma(b)}{\Gamma(a+b)}$$

오른쪽의 감마 함수 식이 계산의 출발점이에요. 자연수에서는 팩토리얼로 쓸 수 있어서, 예를 들어 $B(2, 5) = \frac{1! \cdot 4!}{6!} = \frac{1}{30}$이에요.

```python
>>> import stardust as sd
>>> sd.special.beta(2.0, 5.0)
0.03333333333333333
>>> sd.special.beta(1.0, 4.0)
0.25
>>> sd.special.betaln(2.0, 5.0)
-3.4011973816621555
```

`betaln`은 $\log|B(a, b)|$예요. `log(1/30) ≈ -3.4012`이에요.

### 어디에 쓰나요

- **베타 분포**: 0과 1 사이의 값(확률, 비율, 전환율)을 나타내는 베타 분포의 확률밀도는 $t^{a-1}(1-t)^{b-1} / B(a, b)$예요. B(a, b)로 나눠서 넓이를 1로 맞춰요. A/B 테스트처럼 "성공 확률"을 베이즈 방식으로 추정할 때 흔히 써요.
- **이항계수**: $\binom{n}{k} = \frac{1}{(n+1)\,B(n-k+1,\, k+1)}$이에요. 그래서 [binom](/api/special/binom/)과 가까운 사이예요.
- **다른 분포**: t 분포, F 분포의 확률밀도에도 B가 상수로 들어 있고, 누적분포는 [불완전 베타 함수](/api/special/betainc/)예요.
- **순서 통계량**: n개의 균등분포 값 가운데 k번째로 작은 값의 분포가 베타 분포라서, 이 계산에도 B가 나와요.

## 대칭과 특별한 값

a와 b를 바꿔도 값이 같아요. 정의에서 t를 1 − t로 바꾸면 알 수 있어요.

```python
>>> sd.special.beta(sd.asarray([3.0, 4.0]), sd.asarray([4.0, 3.0]))
array([0.016666666666666666, 0.016666666666666666], dtype=float64)
```

몇 가지 값은 외워 두면 편해요.

| 식 | 값 |
|---|:---:|
| B(1, b) | 1/b |
| B(a, b), a, b가 자연수 | (a−1)! (b−1)! / (a+b−1)! |
| B(½, ½) | π |
| B(1, 1) | 1 |

```python
>>> sd.special.beta(sd.asarray([1.0, 1.0, 1.0]), sd.asarray([1.0, 2.0, 10.0]))
array([1.0, 0.5, 0.1], dtype=float64)
>>> sd.special.beta(0.5, 0.5)
3.1415926535897936
```

B(½, ½)의 마지막 자리가 π와 다른 것은 정확도 약속(상대오차 1e-14) 안의 반올림 차이예요.

`beta`는 [브로드캐스팅](/api/array/broadcasting/)을 해요. 행과 열로 놓으면 표 하나를 한 번에 계산해요.

```python
>>> sd.special.beta(sd.asarray([2.0, 3.0]), sd.asarray([[1.0], [2.0]]))
array([[               0.5, 0.3333333333333333],
       [0.1666666666666666, 0.0833333333333333]], dtype=float64)
```

## 큰 인자: beta는 0이 되고 betaln은 남아요

a와 b가 커지면 B(a, b)는 아주 빨리 작아져요. a = b = 500이면 약 1.5 × 10⁻³⁰²이고, a = b = 1000이면 float64가 담을 수 있는 가장 작은 수보다도 작아서 **0**이 돼요. 그러면 로그를 취해도 `-inf`예요. `betaln`은 처음부터 로그로 계산하므로 문제가 없어요.

```python
>>> x = sd.asarray([100.0, 500.0, 1000.0])
>>> sd.special.beta(x, x)
array([ 2.2087606931995024e-61, 1.4799015991256106e-302,
                           0.0], dtype=float64)
>>> sd.log(sd.special.beta(x, x))
array([-139.66525908670664,  -694.9887224857134,                -inf], dtype=float64)
>>> sd.special.betaln(x, x)
array([-139.66525908670664,  -694.9887224857134, -1388.4826016359023], dtype=float64)
```

<Callout type="warn" title="감마 함수로 직접 나누지 마세요">

`gamma(a) * gamma(b) / gamma(a + b)`는 수학적으로 같은 식이지만, a + b가 약 171.6을 넘으면 분모의 감마 함수가 `inf`가 되고, 분자도 넘치면 `inf / inf` = NaN이 돼요. 아래 예에서는 셋 다 NaN이에요. `beta`는 그런 일 없이 계산해요. 로그로 계산할 때도 `gammaln` 세 개를 더하고 빼기보다 `betaln`을 쓰세요.

</Callout>

```python
>>> sd.special.gamma(x) * sd.special.gamma(x) / sd.special.gamma(2 * x)
array([nan, nan, nan], dtype=float64)
```

## 0과 음수 인자

정의의 적분은 a, b > 0에서만 뜻이 있지만, 감마 함수 식 Γ(a)Γ(b)/Γ(a+b)는 음수에서도 값을 줘요. 그래서 `beta`는 음수 인자도 받아요. 감마 함수의 극점(0, −1, −2, …)이 끼면 다음처럼 정해요.

| 경우 | 결과 | 예 |
|---|---|---|
| a + b만 0 이하의 정수 | 분모가 무한대라서 0 | `beta(-1.5, -0.5)` = `-0.0` |
| a나 b가 0 이하의 정수이고, a + b는 아님 | `inf` | `beta(-1.0, 0.5)` = `inf` |
| 한쪽은 0 이하의 정수, 다른 쪽은 자연수, a + b도 0 이하의 정수 | 극점끼리 약분된 유한한 값 | `beta(-2.0, 1.0)` = `-0.5` |
| 둘 다 0 이하의 정수 | `inf` 또는 `-inf` | `beta(0.0, -1.0)` = `-inf` |
| 극점이 끼지 않은 음수 | Γ 식 그대로의 값(음수일 수도 있어요) | `beta(-0.5, 2.0)` ≈ `-4` |

```python
>>> sd.special.beta(sd.asarray([-1.5, -1.0, -2.0, 0.0]), sd.asarray([-0.5, 0.5, 1.0, -1.0]))
array([-0.0,  inf, -0.5, -inf], dtype=float64)
>>> sd.special.beta(-0.5, 2.0)
-3.999999999999999
```

셋째 경우는 Γ(−2)/Γ(−1)처럼 분자와 분모가 함께 무한대로 가는데, 그 비율의 극한은 1/(−2)로 유한해요. 그 극한값을 내요.

`betaln`은 이 값들의 절댓값에 로그를 취한 값이에요. 부호는 버려요.

```python
>>> sd.special.betaln(sd.asarray([-0.5, -2.0, -1.5]), sd.asarray([2.0, 1.0, -0.5]))
array([ 1.3862943611198904, -0.6931471805599453,                -inf], dtype=float64)
```

## 특수값

- **NaN**이 하나라도 있으면 NaN이에요. 0이나 음의 정수와 함께 들어와도 마찬가지예요.
- **무한대**: b > 0이면 `beta(inf, b)`는 0, `betaln(inf, b)`는 `-inf`예요. b가 아주 커도(예: 1e300) 마찬가지예요. `beta(inf, inf)`는 NaN이에요.
- **아주 작은 인자**: `beta(5e-324, 1.0)`은 1/5e-324라서 넘쳐 `inf`지만, `betaln`은 그 로그인 744.44를 그대로 내요.

```python
>>> sd.special.beta(sd.asarray([sd.nan, sd.inf, sd.inf, sd.inf]), sd.asarray([-1.0, 1.0, 1e300, sd.inf]))
array([nan, 0.0, 0.0, nan], dtype=float64)
>>> sd.special.betaln(5e-324, 1.0)
744.4400719213813
```

## 정확도

- `beta`는 a, b > 0에서 상대오차가 1e-14 이하예요. 결과의 앞자리 약 14자리가 참값과 같다는 뜻이에요. 실제로 잰 최대 오차는 마지막 자리로 9 [ULP](/api/special/basics/) 정도예요.
- 음수 인자의 `beta`와 모든 곳의 `betaln`은 오차의 크기가 `1e-14 × max(1, |값|)` 이하라고 약속해요. `betaln`은 B(a, b) = 1인 곳(예: a = b = 1)에서 정확히 0이 되고, 그런 점이 곡선을 이루며 끝없이 이어져요. 0 근처에서는 상대오차를 뜻 있게 잴 수 없어서, 값이 1보다 작은 곳에서는 절대오차로 재요.

같은 입력이면 배열 안의 위치나 스레드 수와 상관없이 언제나 같은 비트가 나와요. 자세한 내용은 [특수함수의 기본](/api/special/basics/)에 있어요.

## 입력과 결과의 종류

결과는 언제나 **float64**예요. 정수와 bool은 실수로 바꾸고, 둘 다 Python 숫자면 Python `float`예요.

```python
>>> sd.special.beta(sd.asarray([1, 2]), 2)
array([               0.5, 0.1666666666666666], dtype=float64)
>>> type(sd.special.beta(2, 3))
<class 'float'>
```

복소수, 리스트, 모양이 맞지 않는 배열은 에러예요.

```python
>>> sd.special.beta(sd.asarray([1 + 0j]), 1.0)
Traceback (most recent call last):
    ...
TypeError: beta(): not supported for complex128 and float64
>>> sd.special.beta(sd.asarray([1.0, 2.0]), sd.asarray([1.0, 2.0, 3.0]))
Traceback (most recent call last):
    ...
ValueError: beta(): shapes could not be broadcast together: (2,) (3,)
```

`out=`의 규칙은 [사칙연산의 `out`](/api/array/arithmetic/)과 같아요.

```python
>>> buf = sd.zeros(2)
>>> sd.special.betaln(sd.asarray([1.0, 2.0]), 1.0, out=buf) is buf
True
>>> buf
array([                0.0, -0.6931471805599453], dtype=float64)
```

## 조심할 점

- **a와 b가 커지면 `beta`는 0이 돼요.** 수백을 넘는 인자나 확률 계산에는 `betaln`을 쓰세요.
- **감마 함수로 직접 계산하지 마세요.** `gamma(a) * gamma(b) / gamma(a + b)`는 a + b가 약 171.6을 넘으면 0이나 NaN이 돼요.
- **`betaln`은 부호를 버려요.** 음수 인자에서 B가 음수일 수 있어요.
- **음수 인자도 에러가 나지 않아요.** 감마 함수의 극점이 끼면 `inf`, 0, 또는 약분된 극한값이 나와요. 베타 분포의 모수처럼 양수여야 하는 값이라면 미리 확인하세요.

## 비슷한 함수와의 차이

| 헷갈리는 것 | 차이 |
|---|---|
| `beta(a, b)`와 `betaln(a, b)` | `betaln`은 log\|B\|라서 큰 인자에서도 0이 되지 않지만 부호가 없어요. |
| `beta`와 [gamma](/api/special/gamma/)의 비율 | 같은 식이지만 `beta`는 중간값이 넘치지 않고, 극점이 끼는 경우도 극한으로 처리해요. |
| `beta`와 [binom](/api/special/binom/) | 이항계수는 `1 / ((n + 1) * beta(n - k + 1, k + 1))`이에요. 이항계수가 필요하면 `binom`을 바로 쓰세요. |
| `beta`와 [betainc](/api/special/betainc/) | `beta`는 0부터 1까지의 넓이 전체, `betainc`는 0부터 x까지의 넓이를 전체로 나눈 비율(베타 분포의 누적분포)이에요. |

## scipy를 아는 분께

- 이름과 대부분의 값은 `scipy.special.beta`, `betaln`과 같아요. 0과 음의 정수 인자의 규약도 같아요.
- **NaN이 있으면 언제나 NaN이에요.** scipy 1.18.1은 다른 인자가 0이나 음의 정수일 때 `beta(nan, -1.0)`처럼 NaN을 무시하고 `inf`를 내요.
- `beta(inf, 1e300)`은 0이에요(scipy는 NaN). 참값의 극한을 따른 결과예요.
- `betaln(5e-324, 1.0)`은 744.44예요(scipy는 `inf`).
- `beta(-inf, b)`는 scipy와 달라요. `beta(-inf, 1.0)`이 여기서는 `-0.0`, `betaln(-inf, 1.0)`이 `-inf`인데, scipy는 둘 다 `inf`예요.
- 복소수, 리스트, numpy 배열은 받지 않고, `out`은 keyword-only예요.
