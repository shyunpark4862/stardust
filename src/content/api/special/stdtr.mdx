## 한눈에 보기

**t 분포**(Student t 분포)는 "표본이 적을 때, 표본 평균이 참값에서 얼마나 떨어질 수 있나"를 나타내는 분포예요. 모양은 정규분포처럼 0을 가운데 둔 종 모양인데, **꼬리가 더 두꺼워요.** 표본이 적으면 표준편차도 어림값이라 불확실성이 하나 더 끼고, 그만큼 극단적인 값이 더 자주 나오기 때문이에요. 이 두께를 정하는 값이 **자유도**(degrees of freedom, `df`)예요. 자유도가 커질수록 꼬리가 얇아져서 표준정규분포에 가까워져요.

쓰임새는 대부분 통계 검정이에요.

- t 검정의 p값: "새 공정으로 바꾼 뒤 평균 무게가 달라졌나", "두 광고의 평균 체류 시간이 다른가"처럼 평균을 따질 때
- 신뢰구간: "평균은 95% 확률로 이 범위 안"이라고 말할 때 쓰는 임계값
- 회귀분석: 회귀계수가 0과 다른지 볼 때 쓰는 계수별 p값

이 페이지의 두 함수는 이렇게 짝을 이뤄요.

- `stdtr(df, t)`: t 분포를 따르는 값 T가 `t` 이하일 확률 P(T ≤ t)예요. 이런 "어떤 값 이하일 확률"을 **누적분포함수**(cdf, cumulative distribution function)라고 불러요.
- `stdtrit(df, p)`: 거꾸로, 누적확률이 `p`가 되는 지점 t를 돌려줘요.

```python
>>> import stardust as sd
>>> sd.special.stdtr(10, 0.0)
0.5
>>> sd.special.stdtr(1, 1.0)
0.75
>>> sd.special.stdtrit(10, 0.975)
2.2281388519862744
```

## t 분포의 정의

자유도가 $\nu$(뉴)인 t 분포의 밀도(확률이 어디에 얼마나 몰려 있는지 나타내는 곡선)는 이래요.

$$
f_\nu(s) = \frac{\Gamma\!\left(\frac{\nu+1}{2}\right)}{\sqrt{\nu\pi}\;\Gamma\!\left(\frac{\nu}{2}\right)} \left(1 + \frac{s^2}{\nu}\right)^{-\frac{\nu+1}{2}}
$$

$\Gamma$는 [감마 함수](/api/special/gamma/)예요. 앞의 분수는 넓이를 1로 맞추는 상수이고, 모양을 정하는 것은 뒤의 $\left(1 + s^2/\nu\right)^{-(\nu+1)/2}$예요. 정규분포의 $e^{-s^2/2}$는 꼬리에서 아주 빨리 0으로 가지만, 이 식은 $|s|$의 거듭제곱으로만 줄어서 꼬리가 두꺼워요.

`stdtr`은 이 곡선 아래에서 왼쪽 끝부터 `t`까지의 넓이예요.

$$
\mathrm{stdtr}(\nu, t) = P(T \le t) = \int_{-\infty}^{t} f_\nu(s)\, ds
$$

t 분포는 이런 상황에서 나와요. 정규분포를 따르는 값을 `n`개 재서 표본 평균 $\bar x$와 표본 표준편차 $s$를 구했다고 해 볼게요. 참 평균이 $\mu$라면

$$
T = \frac{\bar x - \mu}{s / \sqrt{n}}
$$

는 자유도 $n - 1$인 t 분포를 따라요. 이 $T$를 **t 통계량**이라고 불러요. 표준편차를 모르고 표본에서 어림했기 때문에 정규분포가 아니라 t 분포가 돼요.

## t 검정의 p값 구하기

다이어트 프로그램에 참가한 10명의 몸무게 변화(kg, 줄어든 양)를 쟀어요. "프로그램이 효과가 없다(평균 변화가 0이다)"는 가정 아래에서, 이만큼의 결과가 나올 확률이 얼마나 작은지 보려고 해요.

```python
>>> d = sd.asarray([2.0, -1.0, 3.0, 4.0, 1.0, 0.0, 3.0, 2.0, 5.0, 1.0])
>>> n = d.shape[0]
>>> mean = sd.mean(d)
>>> s = sd.std(d, correction=1)
>>> t = mean / (s / n ** 0.5)
>>> t
3.464101615137755
```

`correction=1`은 표본 표준편차를 `n - 1`로 나눠 구하라는 뜻이에요([var·std](/api/array/var/)). 이제 이 t 통계량이 자유도 9인 t 분포에서 얼마나 극단적인지 봐요. 평균이 **어느 쪽으로든** 달라졌는지 묻는 양측 검정이라면, 양쪽 꼬리의 넓이를 더해요. 분포가 대칭이라 한쪽 꼬리의 두 배예요.

```python
>>> p = 2 * sd.special.stdtr(n - 1, -abs(t))
>>> p
0.007114629229516661
```

p값이 약 0.007이에요. 효과가 없다면 이만큼 극단적인 결과가 나올 확률이 0.7% 정도라는 뜻이라, 보통 쓰는 기준 5%보다 훨씬 작아요. "몸무게가 줄었다"는 한쪽 방향만 묻는 단측 검정이면 두 배를 하지 않아요.

```python
>>> sd.special.stdtr(n - 1, -t)
0.0035573146147583304
```

<Callout type="warn" title="자유도는 표본 수에서 1을 빼요">
  평균 하나를 비교하는 t 검정의 자유도는 `n`이 아니라 `n - 1`이에요. 두 집단을 비교하면 `n1 + n2 - 2`, 회귀계수라면 `n - (계수의 수)`처럼 검정마다 달라요. 자유도를 잘못 넣어도 에러 없이 조금 다른 p값이 나오니 조심하세요.
</Callout>

## 위꼬리는 `stdtr(df, -t)`로

`stdtr`은 아래꼬리 P(T ≤ t)예요. p값처럼 위꼬리 P(T > t)가 필요할 때가 많은데, 이렇게 "어떤 값보다 클 확률"을 **생존함수**(survival function)라고 불러요. 다른 분포에는 생존함수를 따로 계산하는 `chdtrc`, `fdtrc` 같은 함수가 있지만, t 분포는 0을 중심으로 대칭이라 따로 필요 없어요.

$$
P(T > t) = 1 - \mathrm{stdtr}(\nu, t) = \mathrm{stdtr}(\nu, -t)
$$

수학으로는 왼쪽과 오른쪽이 같지만, 컴퓨터에서는 **`1 - stdtr(df, t)`로 계산하면 안 돼요.** `t`가 크면 `stdtr(df, t)`가 1에 아주 가까워지고, 1에서 그 값을 빼면 유효숫자가 거의 다 사라지기 때문이에요.

```python
>>> 1 - sd.special.stdtr(10, 20.0)
1.0730311084117261e-09
>>> sd.special.stdtr(10, -20.0)
1.073031158602126e-09
```

둘째 줄이 참값이에요. 첫째 줄은 앞 여덟 자리만 맞아요. `t`가 더 커지면 아예 0이 돼요.

```python
>>> 1 - sd.special.stdtr(10, 1000.0)
0.0
>>> sd.special.stdtr(10, -1000.0)
1.2304123550866355e-26
```

float64는 1 근처에서 약 1.1e-16 간격으로만 수를 나타내요. 그래서 1에 가까운 값에서 1을 빼면 그 간격보다 작은 차이는 남지 않아요. 반면 `stdtr(10, -1000.0)`은 아주 작은 넓이를 직접 계산하기 때문에 꼬리 끝까지 앞자리 14자리 정도가 맞아요. 여러 검정의 p값을 비교하거나 로그를 씌워 순위를 매기는 일(유전체 분석의 수많은 p값 등)에서는 이 차이가 결과를 바꿔요.

## 임계값과 신뢰구간: `stdtrit`

`stdtrit(df, p)`는 `stdtr(df, t) = p`가 되는 `t`를 찾아요. "아래에서 p만큼 자르는 지점", 곧 t 분포의 **분위수**예요. 신뢰구간과 기각역(이 값보다 크면 가정을 버린다는 경계)을 만들 때 써요.

앞의 다이어트 자료로 평균 변화의 95% 신뢰구간을 구해 볼게요. 가운데 95%를 남기려면 양쪽에서 2.5%씩 잘라요. 그래서 아래 97.5% 지점이 필요해요.

```python
>>> c = sd.special.stdtrit(n - 1, 0.975)
>>> c
2.262157162798205
>>> half = c * s / n ** 0.5
>>> (mean - half, mean + half)
(0.6939429531092163, 3.3060570468907837)
```

평균 감량은 95% 신뢰도로 약 0.69kg에서 3.31kg 사이예요. 구간이 0을 포함하지 않으니, 앞의 양측 검정에서 p값이 5%보다 작았던 것과 같은 이야기예요.

대칭이라 아래 2.5% 지점은 부호만 바뀌어요.

```python
>>> sd.special.stdtrit(n - 1, 0.025)
-2.262157162798205
```

### 끝점과 정의역 밖

`p = 0`은 왼쪽 끝 `-inf`, `p = 1`은 오른쪽 끝 `inf`예요. 확률이 아닌 값(0보다 작거나 1보다 큰 값)은 NaN이에요.

```python
>>> sd.special.stdtrit(10, 0.0)
-inf
>>> sd.special.stdtrit(10, 1.0)
inf
>>> sd.special.stdtrit(10, 1.5)
nan
```

### 되돌리면 원래 값

`stdtrit`은 `stdtr`의 역함수라 하나를 다른 하나에 넣으면 원래 값이 돌아와요. 다만 실수 계산이라 마지막 자리 하나쯤은 다를 수 있어요.

```python
>>> sd.special.stdtrit(10, sd.special.stdtr(10, 1.5))
1.4999999999999998
```

## 자유도에 따라 달라지는 것

### 자유도가 크면 정규분포

자유도가 커질수록 t 분포는 표준정규분포에 가까워지고, `df = inf`이면 정확히 같아져요. 그래서 `stdtr(inf, t)`는 [`ndtr(t)`](/api/special/ndtr/)와 같은 값을 돌려줘요.

```python
>>> sd.special.stdtr(30, 1.96)
0.9703288435519748
>>> sd.special.stdtr(1000, 1.96)
0.9748634075221256
>>> sd.special.stdtr(sd.inf, 1.96)
0.9750021048517795
>>> sd.special.ndtr(1.96)
0.9750021048517795
```

자유도 30에서도 정규분포의 0.975와 0.005쯤 차이가 나요. "표본이 30개 넘으면 정규분포를 써도 된다"는 말은 대략적인 기준일 뿐이에요. 자유도를 알면 `stdtr`을 그대로 쓰는 편이 정확해요.

### 정수가 아닌 자유도

`df`는 정수가 아니어도 돼요. 분산이 서로 다른 두 집단을 비교하는 Welch t 검정은 자유도를 공식으로 어림해서 `9.5`처럼 소수가 나오는데, 그 값을 그대로 넣으면 돼요.

```python
>>> sd.special.stdtr(9.5, 2.0)
0.9625568211260053
```

### 자유도 1은 Cauchy 분포

`df = 1`인 t 분포는 **Cauchy 분포**라는 이름이 따로 있어요. 꼬리가 아주 두꺼워서 평균조차 정의되지 않는 분포예요. 이때 누적확률은 $\tfrac12 + \tfrac{1}{\pi}\arctan t$라서, 처음 예의 `stdtr(1, 1.0) = 0.75`는 $\tfrac12 + \tfrac{1}{\pi}\cdot\tfrac{\pi}{4}$예요.

## 여러 값을 한 번에

인자는 배열이어도 되고, 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 자유도 셋과 지점 둘의 모든 조합을 한 번에 계산해 볼게요.

```python
>>> dfs = sd.asarray([1.0, 5.0, 30.0])
>>> ts = sd.asarray([[1.0], [2.0]])
>>> sd.special.stdtr(dfs, ts)
array([[              0.75, 0.8183912661754387, 0.8373456922869851],
       [0.8524163823495667, 0.9490302605850709, 0.9726874775185085]], dtype=float64)
```

행은 `t`, 열은 자유도예요. 같은 `t`에서도 자유도가 클수록 누적확률이 커져요(꼬리가 얇아지니 가운데로 몰리기 때문이에요). 정수 배열을 넣어도 float64로 계산하고, 결과는 언제나 float64예요. 결과를 미리 만든 배열에 받으려면 `out=`을 써요([특수함수의 기본](/api/special/basics/)).

## 정확도

두 함수는 아래 범위에서 정확도를 보장해요.

- **보장 영역**: 자유도 0.01부터 1e6(백만)까지, `t`와 `p`는 모든 값
- **`stdtr`**: 정밀한 참값과의 상대오차가 1e-14 이하예요. 결과의 앞자리 14자리 정도가 맞는다는 뜻이고, 꼬리의 아주 작은 확률(예: `1.23e-26`)에서도 마찬가지예요.
- **`stdtrit`**: 결과 t의 상대오차가 1e-14에 "입력 p가 마지막 자리만큼 흔들릴 때 t가 흔들리는 배율"을 곱한 값 이하예요. p 자체가 실수로 저장되면서 마지막 자리가 이미 불확실하니, 그 불확실성이 허용하는 만큼은 정확하다는 뜻이에요. 대부분의 p에서 이 배율은 1 근처라 앞자리 14자리가 맞아요. p가 0.5에 아주 가까우면 t가 0 근처라 배율이 커지는데, 이때는 상대오차보다 "t가 0에 아주 가깝다"는 사실이 중요해요.

```python
>>> sd.special.stdtrit(10, 0.5000001)
2.569978033880819e-07
```

잰 최대 오차는 `stdtr`이 9.0 ULP, `stdtrit`이 7.4 ULP(위의 배율로 나눈 값)예요. ULP는 실수의 마지막 자리 한 칸이라는 뜻이고, [특수함수의 기본](/api/special/basics/)에서 자세히 풀어 놓았어요. 1e-14는 약 45 ULP라서 잰 값은 약속보다 한참 작아요. 범위 밖(자유도가 1e6보다 큰 경우 등)도 값을 계산하지만 정확도를 약속하지는 않아요.

## 특수값

| 입력 | 결과 | 뜻 |
|---|:---:|---|
| `stdtr(df, 0)` | 0.5 | 대칭인 분포의 가운데 |
| `stdtr(df, -inf)`, `stdtr(df, inf)` | 0, 1 | 분포의 양 끝 |
| `stdtr(inf, t)` | `ndtr(t)` | 표준정규분포 |
| `stdtrit(df, 0)`, `stdtrit(df, 1)` | −inf, inf | 분포의 양 끝 |
| `stdtrit(df, 0.5)` | 0 | 가운데 |
| `df ≤ 0` | NaN | 자유도는 양수여야 해요 |
| `p < 0` 또는 `p > 1` | NaN | 확률이 아니에요 |
| 인자 중 NaN | NaN | |

## 조심할 점

### 값이 이상해도 에러가 나지 않아요

정의역 밖의 값은 에러 대신 NaN을 돌려줘요. 배열의 한 원소가 잘못돼도 나머지 원소는 정상적으로 계산되게 하려는 거예요. 대신 결과에 NaN이 섞여 있지 않은지 직접 확인해야 해요.

```python
>>> sd.special.stdtr(0, 1.0)
nan
>>> sd.special.stdtr(-3, 1.0)
nan
>>> sd.special.stdtr(10, sd.nan)
nan
```

### 에러는 타입이 틀렸을 때만

복소수는 받지 않아요. 리스트도 받지 않으니 `sd.asarray`로 바꿔서 넘기세요.

```python
>>> sd.special.stdtr(3, 1j)
Traceback (most recent call last):
    ...
TypeError: stdtr(): not supported for int64 and complex128
>>> sd.special.stdtr([1, 2], 1.0)
Traceback (most recent call last):
    ...
TypeError: stdtr(): 'df' must be an sd.ndarray or a bool, int, float or complex, not list
```

### 인자 순서: 자유도가 먼저

`stdtr(df, t)`는 자유도가 앞이에요. `stdtr(2.0, 10)`처럼 바꿔 쓰면 "자유도 2에서 t = 10"을 계산해서, 에러 없이 엉뚱한 값이 나와요. 이 영역의 분포 함수는 모두 **분포의 모양을 정하는 값이 앞, 확률을 잴 지점이 맨 뒤**예요.

### 양측 p값은 두 배

양측 검정의 p값은 `2 * stdtr(df, -abs(t))`예요. `abs`를 빼먹으면 `t`가 음수일 때 1보다 큰 값이 나오고, 두 배를 빼먹으면 단측 p값이 돼요.

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 표준편차를 **알 때**의 평균 검정, 자유도가 아주 클 때 | [`ndtr`](/api/special/ndtr/), [`ndtri`](/api/special/ndtr/) | 표준정규분포예요. `stdtr(inf, t)`와 같아요. |
| t 통계량의 제곱으로 검정 | [`fdtrc`](/api/special/fdtr/) | `fdtrc(1, df, t**2)`는 양측 p값 `2 * stdtr(df, -abs(t))`와 같아요. |
| 검정력 계산(효과가 있을 때 t 통계량의 분포) | [`nctdtr`](/api/special/nctdtr/) | 가운데가 0에서 밀려난 비중심 t 분포예요. 비중심 모수가 0이면 `stdtr`과 같아요. |
| 위꼬리 확률 | `stdtr(df, -t)` | `stdtrc`라는 함수는 없어요. 대칭을 쓰면 돼요. |

t 분포의 누적확률은 [불완전 베타 함수](/api/special/betainc/)로도 나타낼 수 있어요. 직접 조합하기보다 `stdtr`을 쓰는 편이 꼬리까지 정확해요.

`sd.stats`에도 t 분포 객체가 있어요. 밀도, 난수, 평균 같은 것을 한데 묶어 쓰고 싶으면 그쪽을 쓰고, 누적확률이나 분위수 하나만 빠르게 필요하면 이 함수가 간단해요.

## scipy를 아는 분께

- 이름, 인자 순서, 뜻은 `scipy.special.stdtr`, `stdtrit`과 같아요.
- 자유도를 거꾸로 구하는 `stdtridf`는 없어요.
- `stdtrit(df, 0)`은 `-inf`예요. scipy 1.18.1은 `inf`를 돌려줘요.
- 근이 아주 큰 음수인 꼬리도 계산해요. `stdtrit(3, 5e-324)`는 `-6.07e107`이고, scipy는 `inf`예요.
- 리스트, numpy 배열은 받지 않아요. `sd.ndarray`와 Python 숫자만 받아요. `out`은 keyword-only예요.
