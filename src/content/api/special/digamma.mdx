---
title: 디감마와 폴리감마
names: [digamma, polygamma]
group: 감마와 베타
order: 2
signatures:
  - "sd.special.digamma(x, /, *, out=None)"
  - "sd.special.polygamma(n, x, /, *, out=None)"
summary: 디감마 함수 ψ(x)는 log Γ(x)의 도함수이고, 폴리감마 함수 ψ⁽ⁿ⁾(x)는 그것을 n번 더 미분한 함수예요. 감마·베타·디리클레 분포의 추정에서 자주 나와요.
params:
  - name: x
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: 계산할 실수 값. bool·정수는 float64로 바꿔서 계산해요. 복소수는 받지 않아요.
  - name: n
    type: ndarray 또는 Python 숫자
    kind: positional-only, polygamma에만
    desc: 미분 차수. 0 이상의 정수 값이어야 해요(3.0처럼 정수인 실수도 돼요). 그 밖의 값이면 결과가 NaN이에요. x와 브로드캐스팅해요.
  - name: out
    type: ndarray 또는 None
    kind: keyword-only
    desc: 결과를 적어 넣을 배열. None이면 새 배열을 만들어요.
returns:
  type: ndarray 또는 Python float
  desc: 입력과 같은 모양(polygamma는 n과 x를 브로드캐스팅한 모양)의 float64 배열. 입력이 모두 Python 숫자면 Python float예요.
raises:
  - type: TypeError
    desc: 복소수를 넣었을 때, 배열도 숫자도 아닌 것(리스트 등)을 넣었을 때, polygamma에 인자를 하나만 줬을 때, out의 dtype이 float64 결과를 담을 수 없을 때.
  - type: ValueError
    desc: polygamma의 n과 x, 또는 out의 모양이 브로드캐스팅으로 맞지 않을 때.
  - type: OverflowError
    desc: int64 범위를 벗어난 Python 정수를 그대로 넣었을 때.
seeAlso: [gamma, beta, zeta, basics]

## 한눈에 보기

**디감마 함수** ψ(x)(읽기: 프사이)는 감마 함수의 로그를 미분한 함수예요. "log Γ(x)가 x에서 얼마나 가파르게 늘고 있나"를 알려 줘요.

$$\psi(x) = \frac{d}{dx} \log \Gamma(x) = \frac{\Gamma'(x)}{\Gamma(x)}$$

**폴리감마 함수** ψ⁽ⁿ⁾(x)는 디감마를 n번 더 미분한 함수예요. n = 0이면 디감마 자신이고, n = 1은 **트리감마**, n = 2는 테트라감마라고도 불러요.

$$\psi^{(n)}(x) = \frac{d^n}{dx^n}\, \psi(x) = (-1)^{n+1}\, n! \sum_{k=0}^{\infty} \frac{1}{(x+k)^{n+1}} \qquad (n \ge 1)$$

오른쪽 식은 n ≥ 1일 때 폴리감마가 "역수의 거듭제곱을 끝없이 더한 합"이라는 것을 보여 줘요. 그래서 이런 합이 나오면 폴리감마로 한 번에 계산할 수 있어요.

```python
>>> import stardust as sd
>>> sd.special.digamma(1.0)
-0.5772156649015329
>>> sd.special.polygamma(1, 1.0)
1.6449340668482266
>>> sd.pi ** 2 / 6
1.6449340668482264
```

`ψ(1)`은 오일러-마스케로니 상수 γ ≈ 0.5772에 음수를 붙인 값이고, `ψ⁽¹⁾(1)`은 1 + 1/4 + 1/9 + … = π²/6이에요. 마지막 자리가 다른 것은 `sd.pi ** 2 / 6` 쪽이 두 번 반올림했기 때문이에요.

### 어디에 쓰나요

- 분포의 모수 추정: 감마 분포, 베타 분포, 디리클레 분포의 로그 우도에는 `log Γ`가 들어 있어요. 최대우도로 모수를 찾으려고 미분하면 디감마가 나오고, 뉴턴 방법처럼 이계도함수가 필요하면 트리감마가 나와요.
- 베이즈 추론과 토픽 모형: 디리클레 분포를 따르는 X의 로그 기댓값 E[log Xᵢ] = ψ(αᵢ) − ψ(Σα)는 변분 추론(LDA 같은 토픽 모형)에서 핵심 식이에요.
- 분산과 정보량: 감마 분포를 따르는 X에서 log X의 분산은 ψ⁽¹⁾(α)예요. 피셔 정보 같은 양에서 트리감마가 나와요.
- 수열과 급수: 조화수 1 + 1/2 + … + 1/n, Σ 1/(x + k)² 같은 합을 닫힌 꼴로 계산할 때 써요.

## 조화수와 점화식

감마 함수의 $\Gamma(x+1) = x\,\Gamma(x)$에 로그를 취하고 미분하면 디감마의 점화식이 나와요.

$$\psi(x+1) = \psi(x) + \frac{1}{x}$$

x = 1에서 시작해 한 칸씩 올라가면 1, 1/2, 1/3, … 이 차례로 더해져요. 그래서 자연수 n에서 `ψ(n+1) − ψ(1)`은 **조화수** $H_n = 1 + \tfrac12 + \dots + \tfrac1n$이에요.

```python
>>> sd.special.digamma(sd.asarray([2.0, 3.0, 4.0, 5.0])) - sd.special.digamma(1.0)
array([              1.0,               1.5, 1.833333333333333,
       2.083333333333333], dtype=float64)
```

점화식은 자연수가 아닌 x에서도 성립해요.

```python
>>> x = sd.asarray([0.5, 2.0, 7.25])
>>> sd.special.digamma(x + 1) - sd.special.digamma(x)
array([                2.0,                 0.5, 0.13793103448275845], dtype=float64)
>>> 1 / x
array([                2.0,                 0.5, 0.13793103448275862], dtype=float64)
```

7.25에서 끝자리가 다른 것은 1.9 정도인 두 값을 빼면서 생긴 반올림 오차예요. 함수 자체는 정확해요.

### log Γ의 기울기

디감마는 정의 그대로 [gammaln](/api/special/gamma/)의 기울기예요. 아주 가까운 두 점의 차이로 기울기를 어림해 보면 디감마와 거의 같아요.

```python
>>> h = 1e-5
>>> (sd.special.gammaln(x + h) - sd.special.gammaln(x - h)) / (2 * h)
array([-1.9635100262982428,  0.4227843350945016,  1.9104535267988607], dtype=float64)
>>> sd.special.digamma(x)
array([-1.9635100260214235, 0.42278433509846713,  1.9104535268837362], dtype=float64)
```

어림한 값은 10자리 정도만 맞지만, `digamma`는 모든 자리가 정확해요. 그래서 도함수가 필요할 때는 차분 대신 `digamma`를 쓰세요.

x가 0보다 크면 ψ(x) = 0인 곳은 하나뿐이에요. x ≈ 1.4616이고, Γ(x)가 x > 0에서 가장 작아지는 곳이에요(기울기가 0이니까요).

```python
>>> sd.special.digamma(1.4616321449683622)
-9.241265521729427e-17
```

## 극점과 음수 쪽

감마 함수처럼 0과 음의 정수에서 극점이 있어요. 0 근처에서 ψ(x)는 대략 −1/x처럼 움직여서, 오른쪽(+0)에서는 `-inf`, 왼쪽(−0)에서는 `+inf`로 가요. 음의 정수에서는 양쪽 방향의 무한대가 달라 하나로 정할 수 없으므로 NaN이에요.

```python
>>> sd.special.digamma(sd.asarray([0.0, -0.0, -1.0, -2.0]))
array([-inf,  inf,  nan,  nan], dtype=float64)
>>> sd.special.digamma(sd.asarray([-0.5, -1.5, -2.5]))
array([0.03648997397857645,  0.7031566406452432,  1.1031566406452433], dtype=float64)
```

그래프에서 보듯 음수 쪽에서는 극점 사이마다 ψ가 한 번씩 0을 지나요. 영점이 무한히 많다는 점이 아래 정확도의 약속에 영향을 줘요.

## polygamma: 더 높은 도함수

`polygamma(n, x)`의 첫 인자 n은 미분 차수예요. n과 x는 둘 다 배열이 될 수 있고, 서로 [브로드캐스팅](/api/array/broadcasting/)해요.


### 역수 거듭제곱의 합

트리감마는 $\psi^{(1)}(x) = \sum_{k \ge 0} 1/(x+k)^2$이에요. 백만 항을 직접 더해도 꼬리가 남아서 6자리 정도만 맞지만, `polygamma`는 끝없는 합의 값을 바로 줘요.

```python
>>> k = sd.arange(0, 1000000)
>>> sd.sum(1 / (k + 2.0) ** 2)
0.6449330668497263
>>> sd.special.polygamma(1, 2.0)
0.6449340668482266
```

### n에 넣을 수 있는 값

n은 0 이상의 정수 값이어야 해요. `1.0`처럼 정수인 실수나 bool도 받아요. 정수가 아니거나 음수이거나 무한대이면 에러 대신 NaN이 나와요.

```python
>>> sd.special.polygamma(sd.asarray([0.0, 1.0, 1.5, -1.0, sd.inf]), 1.0)
array([-0.5772156649015329,  1.6449340668482266,                 nan,
                       nan,                 nan], dtype=float64)
```

n이 크면 앞에 붙는 `n!` 때문에 값이 아주 빨리 커져요. x = 1에서는 n이 171 이상이면 float64를 넘어 ±inf가 돼요.

```python
>>> sd.special.polygamma(sd.asarray([100, 170, 171]), 1.0)
array([-9.332621544394418e+157, -7.257415615307999e+306,
                           inf], dtype=float64)
```

## 디리클레 분포의 로그 기댓값

세 범주의 비율 (X₁, X₂, X₃)이 모수 α = (2, 3, 5)인 디리클레 분포를 따를 때, 각 log Xᵢ의 기댓값은 ψ(αᵢ) − ψ(α₁ + α₂ + α₃)예요.

```python
>>> alpha = sd.asarray([2.0, 3.0, 5.0])
>>> sd.special.digamma(alpha) - sd.special.digamma(sd.sum(alpha))
array([-1.8289682539682537, -1.3289682539682537, -0.7456349206349207], dtype=float64)
```

토픽 모형의 변분 추론은 이 계산을 문서와 단어마다 수없이 되풀이해요. 배열 하나로 한꺼번에 계산할 수 있어서 빨라요.

## 특수값

| 입력 | `digamma` | `polygamma(n, ·)`, n ≥ 1 |
|---|:---:|:---:|
| `0.0` | `-inf` | n이 홀수면 `inf`, 짝수면 `-inf` |
| `-0.0` | `inf` | n이 홀수면 `inf`, 짝수면 `-inf` |
| 음의 정수 | NaN | n이 홀수면 `inf`, 짝수면 `-inf` |
| `inf` | `inf` | n이 홀수면 `0.0`, 짝수면 `-0.0` |
| `-inf` | NaN | n이 홀수면 `inf`, 짝수면 `-inf` |
| NaN | NaN | NaN |

n이 0 이상의 정수가 아니면(음수, 1.5, `inf`, NaN) x와 상관없이 NaN이에요.

```python
>>> sd.special.polygamma(1, sd.asarray([0.0, -1.0, sd.inf]))
array([inf, inf, 0.0], dtype=float64)
>>> sd.special.polygamma(2, sd.asarray([0.0, -1.0, sd.inf]))
array([-inf, -inf, -0.0], dtype=float64)
```

## 정확도

- x > 0에서는 `digamma`, `polygamma` 모두 상대오차가 1e-14 이하예요. 결과의 앞자리 약 14자리가 참값과 같다는 뜻이에요. 실제로 잰 최대 오차는 `digamma`가 마지막 자리로 2 [ULP](/api/special/basics/), `polygamma`가 18 ULP 정도예요.
- `x < 0`에서는 오차의 크기가 `1e-14 × max(1, |값|)` 이하라고 약속해요. 디감마는 음수 쪽 극점 사이마다 0을 지나는데, 0 바로 근처에서는 아주 작은 절대오차도 상대오차로는 엄청나게 커 보여요. 그래서 값이 1보다 작은 곳에서는 절대오차로 재요.

```python
>>> sd.special.digamma(-0.5040830082644554)
0.0
```

−0.5040830082644554는 음수 쪽 첫 번째 영점에 가장 가까운 float64예요. 참값은 0이 아니라 약 7 × 10⁻¹⁷인 아주 작은 수지만, 절대오차로는 약속 안에 있어요.

## 입력과 결과의 종류

결과는 언제나 float64예요. bool·정수는 실수로 바꿔서 계산하고, 입력이 모두 Python 숫자면 결과도 Python `float`예요.

```python
>>> sd.special.digamma(sd.asarray([1, 2]))
array([-0.5772156649015329, 0.42278433509846713], dtype=float64)
>>> type(sd.special.polygamma(1, 2))
<class 'float'>
```

복소수나 리스트는 받지 않아요.

```python
>>> sd.special.digamma(1 + 1j)
Traceback (most recent call last):
    ...
TypeError: digamma(): not supported for complex128
>>> sd.special.polygamma(sd.asarray([1, 2]), sd.asarray([1.0, 2.0, 3.0]))
Traceback (most recent call last):
    ...
ValueError: polygamma(): shapes could not be broadcast together: (2,) (3,)
```

`out=`의 규칙은 [사칙연산의 `out`](/api/array/arithmetic/)과 같아요.

```python
>>> buf = sd.zeros(2)
>>> sd.special.digamma(sd.asarray([1.0, 2.0]), out=buf) is buf
True
```

## 조심할 점

- 인자 순서는 `polygamma(n, x)`예요. 차수가 먼저, 위치가 나중이에요.
- n이 정수가 아니어도 에러가 나지 않아요. `polygamma(1.5, x)`는 NaN이에요. 결과에 NaN이 섞였다면 n을 확인하세요.
- 0과 −0이 달라요. `digamma(0.0)`은 `-inf`, `digamma(-0.0)`은 `inf`예요.
- `x < 0`에서는 영점 근처의 상대오차가 커요. 값이 0에 가까운 곳에서는 절대오차 1e-14 수준만 약속해요.
- `psi`라는 이름은 없어요. 언제나 `digamma`예요.

## 비슷한 함수와의 차이

| 헷갈리는 것 | 차이 |
|---|---|
| `digamma(x)`와 `polygamma(0, x)` | 같은 값이에요. 차수를 배열로 바꿔 가며 계산할 때만 `polygamma`가 편해요. |
| `digamma`와 [gammaln](/api/special/gamma/) | `digamma`는 `gammaln`의 도함수예요. 차분으로 어림하지 말고 `digamma`를 쓰세요. |
| `polygamma(n, x)`와 [zeta](/api/special/zeta/) | n ≥ 1이면 `polygamma(n, x) = (-1)^(n+1) n! zeta(n+1, x)`예요. 같은 합을 다른 모양으로 쓴 것이에요. |

## scipy를 아는 분께

- 이름, 인자 순서, 극점의 값은 `scipy.special.digamma`, `polygamma`와 같아요.
- 별칭 `psi`가 없어요. `digamma`만 있어요.
- 복소수를 받지 않아요. scipy의 `digamma`는 복소수도 받지만 여기서는 `TypeError`예요.
- `polygamma(inf, x)`는 NaN이에요. scipy 1.18.1은 `polygamma(inf, 1.0)`에서 `inf`를 내요. 여기서는 무한대를 정수 차수로 보지 않아요.
- 음수 x에서 차수가 아주 커도 값이나 ±inf를 내요. `polygamma(7000, -0.5)`는 `-inf`, `polygamma(3000, -2.25)`는 `inf`예요(scipy는 둘 다 NaN).
- 리스트나 numpy 배열은 받지 않고, `out`은 keyword-only예요.
