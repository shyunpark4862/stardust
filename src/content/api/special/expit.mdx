## 한눈에 보기

`expit`는 **로지스틱 함수**예요. 아무리 크거나 작은 실수를 넣어도 결과가 0과 1 사이에 들어와요. 0을 넣으면 정확히 가운데인 0.5, 큰 양수는 1에 가깝고 큰 음수는 0에 가까워요. 그래서 "점수"를 "확률"로 바꿀 때 써요. 그래프가 S자 모양이라 **시그모이드**(S자 함수)라고도 불러요.

`logit`은 그 반대예요. 0과 1 사이의 확률을 받아서 실수로 되돌려요. 확률 0.5는 0, 0.5보다 크면 양수, 작으면 음수예요.

어디에 쓰나요?

- **로지스틱 회귀와 신경망**: 모델이 계산한 점수 z를 `expit(z)`로 "양성일 확률"로 바꿔요. 이진 분류의 가장 기본적인 출력이에요.
- **통계**: 확률 p의 **로그 오즈**(log-odds) `log(p / (1 - p))`가 `logit(p)`예요. "성공 확률이 실패 확률의 몇 배인가"를 로그로 잰 값이라, 확률을 다루는 회귀 모형에서 늘 나와요.
- **생물·인구 모형**: 처음엔 빠르게 늘다가 한계에 다가가며 느려지는 성장 곡선(로지스틱 성장)이 이 모양이에요.

정의는 이래요.

$$\operatorname{expit}(x) = \frac{1}{1 + e^{-x}}, \qquad \operatorname{logit}(p) = \log\frac{p}{1-p}, \qquad \operatorname{log\_expit}(x) = \log \operatorname{expit}(x)$$

```python
>>> import stardust as sd
>>> sd.special.expit(sd.asarray([-4.0, -1.0, 0.0, 1.0, 4.0]))
array([0.017986209962091555,   0.2689414213699951,                  0.5,
         0.7310585786300049,   0.9820137900379085], dtype=float64)
>>> sd.special.logit(sd.asarray([0.5, 0.75, 0.25, 0.9]))
array([                0.0,  1.0986122886681096, -1.0986122886681096,
        2.1972245773362196], dtype=float64)
```

`logit(0.75)`는 `log(0.75 / 0.25) = log 3`이에요. 확률 0.75는 "성공이 실패의 3배"라는 뜻이고, 그 로그가 1.0986…이에요. 0.25는 정확히 그 반대라서 부호만 바뀌어요.

## expit와 logit은 서로를 되돌려요

`logit(expit(x)) = x`, `expit(logit(p)) = p`예요. 하나를 계산하고 다른 하나를 적용하면 처음 값으로 돌아와요. 결과가 마지막 자리에서 조금 다른 것은 중간값이 반올림되기 때문이에요.

```python
>>> s = sd.special
>>> s.logit(s.expit(sd.asarray([-3.0, 0.5, 2.0])))
array([-2.9999999999999996,  0.5000000000000001,  1.9999999999999987], dtype=float64)
>>> s.expit(s.logit(sd.asarray([0.1, 0.5, 0.9])))
array([0.10000000000000002,                 0.5,  0.8999999999999999], dtype=float64)
```

expit에는 쓸모 있는 대칭이 하나 더 있어요. **`1 - expit(x)`는 `expit(-x)`와 같아요.** "양성일 확률"을 구했다면 "음성일 확률"은 부호를 뒤집은 점수로 바로 구할 수 있어요. 1에서 빼는 것보다 `expit(-x)`가 더 정확해요.

```python
>>> s.expit(-sd.asarray([1.0, 2.0]))
array([ 0.2689414213699951, 0.11920292202211755], dtype=float64)
>>> 1 - s.expit(sd.asarray([1.0, 2.0]))
array([ 0.2689414213699951, 0.11920292202211769], dtype=float64)
```

## 끝으로 갈수록: 범위 밖과 특수값

이 영역의 다른 함수처럼, 셋 다 **값 때문에 에러를 내지 않아요.** 정의되지 않는 곳은 NaN, 무한대로 가는 곳은 ±inf예요.

`expit`는 모든 실수에서 값이 있어요. ±inf에서는 그 극한인 1과 0이에요.

```python
>>> s.expit(sd.asarray([sd.inf, -sd.inf, sd.nan]))
array([1.0, 0.0, nan], dtype=float64)
```

`logit`은 확률만 받아요. 0과 1은 끝점이라 -inf와 inf, 0보다 작거나 1보다 큰 값은 NaN이에요.

```python
>>> s.logit(sd.asarray([0.0, 1.0, -0.1, 1.5, sd.nan]))
array([-inf,  inf,  nan,  nan,  nan], dtype=float64)
>>> s.logit(2)
nan
```

### 아주 큰 x에서 expit는 1이 돼요

float64는 1에 아주 가까운 수를 1과 구별하지 못해요. 1 바로 아래 수와 1의 간격이 약 1.1 × 10⁻¹⁶이라서, `expit(x)`와 1의 차이가 그보다 작아지는 x = 37 언저리부터는 결과가 정확히 `1.0`이에요. 반대쪽은 사정이 달라요. 0 근처의 아주 작은 수는 잘 나타낼 수 있어서, `expit(-40)`은 정확한 작은 값이 나와요.

```python
>>> s.expit(40.0)
1.0
>>> s.expit(-40.0)
4.24835425529159e-18
```

x가 −709.78보다 작아지면 결과가 float64가 정상적으로 담는 가장 작은 수(약 2.2 × 10⁻³⁰⁸)보다 작아져요. 그래도 바로 0이 되지 않고, 정밀도는 줄지만 값이 있는 **서브노멀 수**(0 바로 위의 아주 작은 수)로 이어지다가 x ≈ −745.13 아래에서 0이 돼요.

```python
>>> s.expit(-720.0)
2.0322308024e-313
>>> s.expit(-746.0)
0.0
```

## log_expit: expit의 로그

확률을 곱하는 계산(가능도, 교차 엔트로피)은 흔히 로그로 해요. 그래서 `log(expit(x))`가 자주 필요한데, 이것을 그대로 계산하면 양쪽 끝에서 문제가 생겨요.

- **큰 음수 x**: `expit(x)`가 먼저 0이 되어서 로그가 `-inf`가 돼요. 참값은 거의 `x` 그대로인데도요.
- **큰 양수 x**: `expit(x)`가 먼저 `1.0`으로 반올림돼서 로그가 `0.0`이 돼요. 참값은 아주 작은 음수예요.

`log_expit`는 `expit`를 거치지 않고 로그를 바로 계산해서, 양쪽 끝까지 정확해요.

```python
>>> s.log_expit(sd.asarray([-1000.0, -50.0, 0.0, 50.0, 1000.0]))
array([                -1000.0,                   -50.0,
           -0.6931471805599453, -1.9287498479639178e-22,
                          -0.0], dtype=float64)
>>> sd.log(s.expit(sd.asarray([-1000.0, -50.0, 0.0, 50.0])))
array([               -inf,               -50.0, -0.6931471805599453,
                       0.0], dtype=float64)
```

`log(1 - expit(x))`도 필요하다면 위의 대칭을 써서 `log_expit(-x)`로 계산해요. 1에서 빼는 단계가 없어서 더 정확해요.

```python
>>> sd.log(1 - s.expit(20.0))
-19.999999966169824
>>> s.log_expit(-20.0)
-20.000000002061153
```

참값은 `-20.0000000020611536…`이라, 1에서 뺀 쪽은 아홉째 자리부터 틀렸어요.

### 예: 이진 분류의 손실

점수 z와 정답 y(1 또는 0)로 **이진 교차 엔트로피**(로지스틱 회귀의 손실)를 계산하면 이렇게 돼요. 정답이 1이면 `log p`, 0이면 `log(1 - p)`를 쓰는데, 둘 다 `log_expit`로 바로 구해요.

```python
>>> z = sd.asarray([2.0, -1.0, 0.5])
>>> y = sd.asarray([1.0, 0.0, 1.0])
>>> -sd.mean(y * s.log_expit(z) + (1 - y) * s.log_expit(-z))
0.3047555609137674
```

`expit`로 확률을 먼저 만든 다음 `log`를 취하면, 점수가 아주 큰 표본 하나 때문에 손실 전체가 `inf`가 될 수 있어요. `log_expit`를 쓰면 그런 일이 없어요.

### log_expit의 특수값

`log_expit(+inf)`는 `-0.0`, `log_expit(-inf)`는 `-inf`예요. 결과가 언제나 0 이하라서, 0이 되는 곳에서도 음의 부호가 붙은 0이 나와요.

```python
>>> s.log_expit(sd.asarray([sd.inf, -sd.inf]))
array([-0.0, -inf], dtype=float64)
```

## 입력과 결과

배열과 Python 숫자를 받아요. 정수와 bool은 float64로 바꿔서 계산하고, 결과는 언제나 float64예요. 입력이 Python 숫자면 결과도 Python `float`예요. 원소마다 따로 계산하므로 모양은 입력과 같아요. 공통 규칙은 [특수함수의 기본](/api/special/basics/)에 있어요.

```python
>>> s.expit(sd.asarray([1, 2]))
array([0.7310585786300049, 0.8807970779778823], dtype=float64)
>>> s.expit(0)
0.5
>>> s.expit(sd.asarray([[0.0, 1.0], [2.0, 3.0]]))
array([[               0.5, 0.7310585786300049],
       [0.8807970779778823, 0.9525741268224334]], dtype=float64)
```

`out=`에 배열을 주면 그 배열에 결과를 적고 그 배열을 돌려줘요. 결과가 실수라서 정수 배열에는 담을 수 없어요. 규칙은 [사칙연산](/api/array/arithmetic/)의 `out`과 같아요.

```python
>>> buf = sd.zeros(3)
>>> s.expit(sd.asarray([0.0, 1.0, 2.0]), out=buf) is buf
True
>>> buf
array([               0.5, 0.7310585786300049, 0.8807970779778823], dtype=float64)
```

## 정확도

세 함수 모두 **정의역 전체**에서 정확도를 약속해요. `expit`와 `log_expit`는 유한한 모든 x, `logit`은 0과 1 사이의 모든 p예요. 그 안에서 참값과의 상대오차가 1e-14 이하예요. 앞에서부터 대략 14자리가 맞는다는 뜻이에요. 실제로 잰 최대 오차는 그보다 훨씬 작아서, `expit` 2.1 ULP, `logit` 2.8 ULP, `log_expit` 1.2 ULP예요. ULP는 "마지막 자리 한 칸"이라는 뜻이에요([특수함수의 기본](/api/special/basics/)). 결과가 서브노멀 수가 되는 곳(위의 `expit(-720)`)만은 상대오차 대신 아주 작은 절대오차로 따져요.

## 조심할 점

### 1 - expit(x)는 정밀도를 잃어요

x가 크면 `expit(x)`가 1에 아주 가까워지고, 1에서 빼면 앞자리가 모두 지워져 정밀도가 사라져요. x가 37 언저리를 넘으면 아예 `0.0`이 돼요. **"1에서 뺀 확률"이 필요하면 `expit(-x)`** 를 쓰세요.

```python
>>> 1 - s.expit(40.0)
0.0
>>> s.expit(-40.0)
4.24835425529159e-18
```

### 1에 아주 가까운 확률의 logit

`logit`은 정확하지만, **입력 p 자체가 이미 반올림된 값**일 수 있어요. 예를 들어 `1 - 1e-10`은 float64로 정확히 나타낼 수 없어서, 그 logit은 참값 23.02585092984…에서 아홉째 자리부터 어긋나요. 1에 가까운 확률은 "1에서 모자란 양" q로 들고 있다가 `logit(1 - q) = -logit(q)`로 계산하면 정확해요.

```python
>>> s.logit(sd.asarray([1e-10, 1 - 1e-10]))
array([-23.02585092984046, 23.025850847100088], dtype=float64)
>>> -s.logit(1e-10)
23.02585092984046
```

### 복소수와 리스트는 받지 않아요

복소수 배열은 `TypeError`예요. 리스트는 먼저 [`asarray`](/api/array/asarray/)로 배열로 바꾸세요.

```python
>>> s.expit(sd.asarray([1 + 0j]))
Traceback (most recent call last):
    ...
TypeError: expit(): not supported for complex128
>>> s.expit([1.0])
Traceback (most recent call last):
    ...
TypeError: expit(): 'x' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 설명 |
|---|---|---|
| 점수 하나를 확률로 | `expit(z)` | 두 갈래(양성·음성) 분류의 확률이에요. |
| 점수 여러 개를 확률 분포로 | [`softmax`](/api/special/softmax/) | 갈래가 셋 이상일 때예요. 점수가 `[0, z]` 두 개면 `softmax`의 둘째 값이 `expit(z)`와 같아요. |
| 확률의 로그 | `log_expit(z)` | `log(expit(z))`보다 양쪽 끝에서 정확해요. |
| 1 - 확률, 그 로그 | `expit(-z)`, `log_expit(-z)` | 1에서 빼지 않아서 정밀도를 잃지 않아요. |
| 확률을 점수로 되돌리기 | `logit(p)` | `expit`의 역함수예요. |
| `log(1 + exp(x))` | `-log_expit(-x)` | 흔히 softplus라고 부르는 함수예요. [`sd.logaddexp(0, x)`](/api/array/exp-log/)와도 같아요. |

```python
>>> s.softmax(sd.asarray([0.0, 2.0]))
array([0.11920292202211755,  0.8807970779778823], dtype=float64)
>>> s.expit(2.0)
0.8807970779778823
>>> s.log_expit(-2.0)
-2.1269280110429727
>>> -sd.logaddexp(0.0, 2.0)
-2.1269280110429727
```

## scipy를 아는 분께

- 이름과 정의, 특수값은 `scipy.special.expit`, `logit`, `log_expit`와 같아요. 다른 곳은 하나예요. **`-745.13 < x < -709.78`에서 `expit(x)`는 서브노멀 참값 eˣ예요.** scipy는 x가 약 −709.78보다 작으면 0을 돌려줘요(`expit(-720.0)`이 scipy는 `0.0`, stardust는 `2.0322308024e-313`).
- 리스트와 numpy 배열은 받지 않아요. Python 숫자를 넣으면 numpy 스칼라가 아니라 Python `float`가 나와요.
- `out`은 keyword-only예요. `where=`, `dtype=` 같은 ufunc 인자는 없어요.
- float32 같은 다른 실수 종류가 없어서, 결과는 언제나 float64예요.
