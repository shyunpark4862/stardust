## 한눈에 보기

`loggamma(z)`는 복소수에서의 log Γ(z)예요. [감마 함수](/api/special/gamma/)는 팩토리얼을 실수로 넓힌 함수인데, 같은 식으로 복소수까지 넓힐 수 있어요. 그 값의 로그를 바로 계산하는 함수가 `loggamma`예요.

```python
>>> import stardust as sd
>>> sd.special.loggamma(3 + 0j)
(0.6931471805599453+0j)
>>> sd.special.loggamma(1j)
(-0.6509231993018559-1.87243664726243j)
```

`Γ(3) = 2`이니 첫 결과는 `log 2 ≈ 0.6931`이에요. 둘째는 허수 i에서의 값이에요. `sd.exp`를 취하면 감마 함수 자체가 나와요. `sd.special.gamma`는 복소수를 받지 않으니, 복소수의 Γ(z)가 필요하면 이렇게 계산해요.

```python
>>> sd.exp(sd.special.loggamma(sd.asarray([4 + 0j, 2 + 1j])))
array([                                   (6+0j),
       (0.6529654964201669+0.34306583981654515j)], dtype=complex128)
```

### 어디에 쓰나요

- 물리: 쿨롱 파동함수, 산란 진폭, 양자역학의 여러 공식에 복소수 인자의 Γ가 나와요. 크기와 위상(각도)을 따로 써야 할 때가 많아서 로그 꼴이 편해요.
- 확률과 통계: 감마 분포를 따르는 X에서 E[X^(it)] 같은 특성함수, 로그-감마 분포, 멜린 변환을 계산할 때 Γ(α + it)가 나와요.
- 해석적 정수론과 특수함수: 리만 제타 함수의 함수방정식, 초기하 함수의 공식처럼 복소평면 전체에서 Γ를 다루는 식에 써요.
- 넘치지 않는 계산: |Γ(z)|는 금방 float64를 넘지만, 로그는 평범한 크기라서 비율이나 곱을 안전하게 계산할 수 있어요.

### 정의: 어떤 로그인가요

복소수의 로그는 하나로 정해지지 않아요. e^w = Γ(z)를 만족하는 w는 허수부가 2π씩 다른 것이 끝없이 많아요. `loggamma`는 그 가운데 **주가지**(principal branch)를 골라요.

- 양의 실수축에서는 실수 log Γ(x)와 같아요.
- 거기서부터 **끊기지 않게 이어 가요.** 음의 실수축(−∞, 0]만 잘라 낸(가지 자름) 평면 전체에서 연속이고 매끄러워요.

$$\exp\big(\mathrm{loggamma}(z)\big) = \Gamma(z), \qquad \mathrm{loggamma}(x) = \log\Gamma(x)\ \ (x > 0)$$

허수부가 (−π, π] 안으로 접히지 않고 계속 이어지므로, `log(Γ(z))`를 계산한 뒤 복소수 로그를 취한 것과는 허수부가 2π의 정수배만큼 다를 수 있어요.

## 실수 입력과 복소수 입력

`loggamma`는 입력의 종류에 따라 다르게 계산해요.

- **복소수 입력**(complex128 배열, Python `complex`): 복소수로 계산하고 결과도 complex128이에요.
- **실수 입력**(float64, 정수, bool): 실수로 계산하고 결과는 float64예요. x > 0에서는 [gammaln](/api/special/gamma/)과 같은 값이고, `loggamma(±0.0)`은 `inf`, **`x < 0`은 NaN**이에요.

```python
>>> sd.special.loggamma(sd.asarray([0.5, 3.0, 0.0, -0.5, -1.0]))
array([0.5723649429247001, 0.6931471805599453,                inf,
                      nan,                nan], dtype=float64)
>>> sd.special.loggamma(sd.asarray([-0.5 + 0j]))
array([(1.2655121234846454-3.141592653589793j)], dtype=complex128)
```

같은 −0.5라도 실수 배열이면 NaN, 복소수 배열이면 값이 나와요. 실수 `x < 0`에서는 Γ(x)가 음수일 수 있어서 실수 로그가 없기 때문이에요. 복소수로 계산하면 음수의 로그는 허수부가 ±π인 값이 돼요.

### gammaln과 비교: 부호가 허수부에 담겨요

[gammaln](/api/special/gamma/)은 `x < 0`에서도 log|Γ(x)|를 주지만 부호를 버려요. 복소수 `loggamma`는 실수부가 `gammaln`과 같고, **허수부에 부호가 담겨요.** 허수부가 π의 홀수배면 Γ(x)가 음수, 짝수배면 양수예요(e^(iπk) = (−1)^k).

```python
>>> x = sd.asarray([-0.5 + 0j, -1.5 + 0j, -2.5 + 0j])
>>> w = sd.special.loggamma(x)
>>> sd.real(w)
array([  1.2655121234846454,    0.860047015376481, -0.05624371649767412], dtype=float64)
>>> sd.imag(w) / sd.pi
array([-1.0, -2.0, -3.0], dtype=float64)
>>> sd.special.gamma(sd.asarray([-0.5, -1.5, -2.5]))
array([ -3.544907701811032,  2.3632718012073544, -0.9453087204829418], dtype=float64)
```

허수부가 −π, −2π, −3π이니 Γ의 부호는 −, +, − 예요. 실제 Γ 값의 부호와 맞아요.

## 가지 자름 위: +0i와 −0i

음의 실수축은 가지 자름이라서, 그 위의 점에서는 위쪽에서 다가갈 때와 아래쪽에서 다가갈 때 허수부가 달라요(위 그래프). float64에는 `0.0`과 `-0.0`이 따로 있으니, `loggamma`는 **허수부 0의 부호로 어느 쪽인지 골라요.** `x + 0.0i`는 위쪽, `x − 0.0i`는 아래쪽 극한이에요.

```python
>>> sd.special.loggamma(sd.asarray([complex(-1.5, 0.0), complex(-1.5, -0.0)]))
array([(0.860047015376481-6.283185307179586j),
       (0.860047015376481+6.283185307179586j)], dtype=complex128)
```

`-1.5 - 0j` 같은 식은 Python 버전에 따라 허수부가 `0.0`이 되기도 하고 `-0.0`이 되기도 해요. 아래쪽 값을 확실히 원하면 `complex(-1.5, -0.0)`처럼 직접 만드세요.

가지 자름 바로 근처의 점(허수부가 아주 작은 수)은 자름 위의 값으로 매끄럽게 다가가요. 그래서 계산 중에 아주 작은 허수부가 생겨도 결과가 튀지 않아요.

```python
>>> sd.special.loggamma(sd.asarray([complex(-1.5, 1e-8), complex(-1.5, -1e-8)]))
array([(0.8600470153764807-6.28318530014802j),
       (0.8600470153764807+6.28318530014802j)], dtype=complex128)
```

## 이어지는 허수부

z = 10 + 10i에서 `loggamma`의 허수부는 약 23.95예요. 이 값에 `exp`를 취해 Γ(z)를 만든 뒤 복소수 로그를 취하면, 허수부가 (−π, π] 안으로 접혀 −1.18이 돼요. 둘은 8π만큼 차이가 나요.

```python
>>> z = sd.asarray([10 + 10j])
>>> sd.special.loggamma(z)
array([(8.236131750448715+23.948703413782038j)], dtype=complex128)
>>> sd.log(sd.exp(sd.special.loggamma(z)))
array([(8.236131750448715-1.1840378149363078j)], dtype=complex128)
```

둘 다 e^w = Γ(z)를 만족하지만, `loggamma` 쪽은 z를 조금씩 움직일 때 값이 갑자기 2π 뛰지 않아요. 미분하거나, 적분 경로를 따라 더하거나, 위상을 이어 붙여야 하는 계산에서는 이 성질이 꼭 필요해요.

## 크기가 넘치지 않아요

|Γ(z)|는 |z|가 커지면 아주 빨리 커져서 float64를 넘지만, `loggamma`는 그 로그라서 평범한 크기예요.

```python
>>> sd.exp(sd.special.loggamma(sd.asarray([200 + 0j])))
array([(inf+0j)], dtype=complex128)
>>> sd.special.loggamma(200 + 0j)
(857.9336698258575+0j)
```

### 예: 허수축 위의 |Γ(iy)|

복소수 Γ에는 정확한 공식이 있는 경우가 있어요. 예를 들어 허수축 위에서는 $|\Gamma(iy)|^2 = \dfrac{\pi}{y \sinh(\pi y)}$예요. |Γ|² = exp(2 · Re loggamma)이니 확인해 볼 수 있어요.

```python
>>> y = sd.asarray([1.0, 2.0])
>>> sd.exp(2 * sd.real(sd.special.loggamma(1j * y)))
array([ 0.27202905498213337, 0.005866764826350944], dtype=float64)
>>> sd.pi / (y * sd.sinh(sd.pi * y))
array([  0.2720290549821332, 0.005866764826350947], dtype=float64)
```

끝자리가 조금 다른 것은 `exp`와 `sinh` 쪽 식의 반올림 오차예요.

## 극점과 무한대

z = 0, −1, −2, … 은 Γ의 극점이에요. |Γ|가 무한대라서 실수부는 `inf`이지만, 다가가는 방향마다 위상(허수부)이 달라서 허수부는 NaN이에요. `+0i`나 `−0i`를 붙여도 마찬가지예요.

```python
>>> sd.special.loggamma(sd.asarray([0j, complex(-1, 0.0), complex(-2, -0.0)]))
array([(inf+nanj), (inf+nanj), (inf+nanj)], dtype=complex128)
```

무한대 입력은 그 방향의 극한을 내요.

| 입력 | 결과 | 뜻 |
|---|:---:|---|
| `inf ± 0i` | `inf ± 0i` | 양의 실수축을 따라 Γ가 무한히 커져요 |
| `inf + iy`(y ≠ 0) | `inf ± inf·i` | 크기와 위상이 모두 무한히 커져요 |
| `x ± inf·i` | `-inf ± inf·i` | 허수 방향으로 멀어지면 \|Γ\|는 0으로 줄어요 |
| `-inf + iy`(y ≠ 0) | `-inf ∓ inf·i` | 음수 쪽으로 멀어지면 \|Γ\|는 0으로 줄어요 |
| `-inf ± 0i` | NaN | 극점이 끝없이 쌓여서 극한이 없어요 |
| NaN이 섞이면 | NaN | |

```python
>>> sd.special.loggamma(sd.asarray([complex(sd.inf, 0.0), complex(sd.inf, 1.0), complex(1.0, sd.inf), complex(-sd.inf, 1.0)]))
array([  (inf+0j),  (inf+infj), (-inf+infj), (-inf-infj)], dtype=complex128)
```

## 정확도

복소수 결과의 오차는 크기로 재요. 참값을 w, 계산값을 w'이라 하면 |w' − w| / |w|를 상대오차로 봐요. 실수부와 허수부를 따로 재지 않아요.

- **Re z > 0**: 상대오차가 1e-14 이하예요. 결과의 앞자리 약 14자리가 참값과 같다는 뜻이에요.
- **Re z ≤ 0**: 오차의 크기가 `1e-14 × max(1, |loggamma(z)|)` 이하라고 약속해요. 이 영역에는 극점이 끝없이 늘어서 있고 그 사이에서 값이 0에 가까워지는 곳이 있어서, 값이 1보다 작은 곳은 절대오차로 재요. 실수 `gammaln`의 음수 쪽 약속과 같은 꼴이에요.

실수 입력의 정확도는 [gammaln](/api/special/gamma/)과 같아요. 같은 입력이면 배열 안의 위치와 상관없이 같은 비트가 나오고, 지금은 스레드 수와도 상관없어요(약속은 아니에요). ULP 같은 용어는 [특수함수의 기본](/api/special/basics/)에 있어요.

## 입력과 결과의 종류

Python 숫자를 넣으면 결과도 Python 숫자예요. 복소수면 `complex`, 실수면 `float`예요.

```python
>>> type(sd.special.loggamma(2))
<class 'float'>
>>> type(sd.special.loggamma(2 + 0j))
<class 'complex'>
```

리스트는 받지 않아요. `out=`을 쓸 때는 결과의 dtype을 담을 수 있는 배열이어야 해요. 복소수 결과는 float64 배열에 담을 수 없어요. 규칙은 [사칙연산의 `out`](/api/array/arithmetic/)과 같아요.

```python
>>> sd.special.loggamma([1.0])
Traceback (most recent call last):
    ...
TypeError: loggamma(): 'z' must be an sd.ndarray or a bool, int, float or complex, not list
>>> sd.special.loggamma(sd.asarray([1 + 1j]), out=sd.zeros(1))
Traceback (most recent call last):
    ...
TypeError: loggamma(): cannot implicitly convert complex128 to float64 (that would lose information); convert explicitly with astype
>>> buf = sd.zeros(2, dtype=sd.complex128)
>>> sd.special.loggamma(sd.asarray([1.0, 3.0]), out=buf)
array([                     0j, (0.6931471805599453+0j)], dtype=complex128)
```

마지막 예처럼 실수 결과는 complex128 배열에 담을 수 있어요(허수부 0).

## 조심할 점

- **실수 `x < 0`은 NaN이에요.** 음수의 log Γ가 필요하면 복소수로 넣으세요(`sd.asarray([-0.5 + 0j])`). 절댓값의 로그만 필요하면 `gammaln`이에요.
- **음의 실수축 위에서는 허수부 0의 부호가 결과를 바꿔요.** `complex(x, 0.0)`과 `complex(x, -0.0)`은 허수부의 부호가 반대인 결과를 줘요.
- **허수부는 (−π, π]에 있지 않아요.** 주가지를 끊기지 않게 이은 값이라 |z|가 크면 허수부도 커요. 위상만 필요하면 직접 접으세요.
- **극점의 결과는 `inf + nan·i`예요.** 실수부만 보고 판단하면 `inf`라서 NaN 검사에 걸리지 않을 수 있어요.

## 비슷한 함수와의 차이

| 헷갈리는 것 | 차이 |
|---|---|
| `loggamma`와 [gammaln](/api/special/gamma/) | `gammaln`은 실수만 받고 log\|Γ(x)\|(부호 없음)를 줘요. `loggamma`는 복소수를 받고, 음수 쪽은 복소수로 넣어야 값이 나와요. x > 0에서는 같은 값이에요. |
| `loggamma`와 [gamma](/api/special/gamma/) | `gamma`는 복소수를 받지 않아요. 복소수 Γ(z)는 `sd.exp(loggamma(z))`로 계산해요. |
| `loggamma(z)`와 `sd.log(Γ(z))` | 둘 다 e^w = Γ(z)지만, `sd.log`는 허수부를 (−π, π]로 접어서 z를 움직이면 2π씩 뛰어요. `loggamma`는 이어져 있어요. |

## scipy를 아는 분께

- 이름, 주가지, 가지 자름 위의 ±0i 처리, 실수 입력의 결과(`x < 0`이면 NaN)는 `scipy.special.loggamma`와 같아요.
- **극점은 `inf + nan·i`예요.** scipy 1.18.1은 `nan + nan·i`예요. 실수부가 무한대라는 사실은 방향과 상관없이 정해져 있어서 남겨 둬요.
- **무한대 입력에서 극한을 내요.** `loggamma(inf + 0j)`는 `inf + 0j`, `loggamma(1 + inf·j)`는 `-inf + inf·j`예요. scipy는 모두 `nan + nan·j`예요. `loggamma(-inf ± 0j)`은 둘 다 NaN이에요.
- 실수부나 허수부가 정확히 0인 곳의 부호(+0과 −0)는 scipy와 비트까지 맞추지 않아요. 예를 들어 `loggamma(1 + 0j)`는 여기서 `0j`, scipy는 `-0 + 0j`예요.
- 리스트나 numpy 배열은 받지 않고, `out`은 keyword-only예요.
