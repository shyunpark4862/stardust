## 한눈에 보기

[베타 함수](/api/special/beta/) B(a, b)는 0에서 1 사이에 놓인 곡선 $t^{a-1}(1-t)^{b-1}$ 아래의 넓이예요. 이 넓이를 1까지 재지 않고 x에서 멈추면 전체 가운데 몇 퍼센트를 지났는지 알 수 있어요. 그 비율이 **불완전 베타 함수** `betainc(a, b, x)`예요. 결과는 언제나 0과 1 사이이고, 남은 비율은 `betaincc(a, b, x)`예요.

```python
>>> import stardust as sd
>>> sd.special.betainc(2.0, 3.0, 0.5)
0.6875
>>> sd.special.betainc(2.0, 3.0, sd.asarray([0.0, 0.25, 0.5, 0.75, 1.0]))
array([       0.0, 0.26171875,     0.6875, 0.94921875,        1.0], dtype=float64)
>>> sd.special.betaincc(2.0, 3.0, 0.5)
0.3125
```

a = 2, b = 3이면 x = 0.5까지 넓이의 68.75%가 쌓이고, 남은 31.25%는 그 뒤에 있어요. x = 0에서는 0, x = 1에서는 1이에요.

a = b = 1이면 곡선이 높이 1인 평평한 선이라서 비율이 x 그대로예요. b = 1이면 $x^a$예요.

```python
>>> sd.special.betainc(1.0, 1.0, sd.asarray([0.2, 0.7]))
array([0.2, 0.7], dtype=float64)
>>> sd.special.betainc(2.0, 1.0, 0.3)
0.09
```

### 어디에 쓰나요

`betainc`는 0과 1 사이의 비율·확률을 다루는 분포와, 성공 횟수를 세는 분포의 누적확률로 쓰여요.

- 베타 분포: 전환율, 불량률, 득표율처럼 0과 1 사이의 비율이 어느 값일지를 얼마나 믿는지 나타내는 분포예요. 베이즈 A/B 테스트에서 "B안의 전환율이 10%를 넘을 확률"이 `betaincc`예요.
- 이항 분포와 음이항 분포: "동전을 10번 던져 앞면이 3번 이하로 나올 확률" 같은 누적확률을 합 없이 한 번에 계산해요.
- t 검정과 F 검정: t 분포와 F 분포의 누적확률, 곧 평균 비교와 분산 분석의 p값이 불완전 베타 함수로 쓰여요.
- 신뢰구간: 역함수 `betaincinv`로 성공 비율의 정확한 신뢰구간(Clopper–Pearson 구간)을 구해요.
- 순서 통계량: 0과 1 사이에서 무작위로 뽑은 n개 가운데 k번째로 작은 값은 베타 분포를 따라요. 중앙값·사분위수의 분포를 다룰 때 나와요.

### 정의

`betainc`는 **정칙화된**(regularized) 불완전 베타 함수 $I_x(a, b)$예요. 0부터 x까지의 넓이를 전체 넓이 B(a, b)로 나눈 값이에요.

$$I_x(a, b) = \frac{1}{B(a, b)} \int_0^x t^{a-1} (1-t)^{b-1}\, dt, \qquad B(a, b) = \int_0^1 t^{a-1}(1-t)^{b-1}\, dt$$

"정칙화"는 B(a, b)로 나눠서 결과가 0에서 1 사이가 되게 맞췄다는 뜻이에요. 나누기 전의 넓이 자체가 필요하면 `beta(a, b)`를 곱하세요. 아래 예의 참값은 11/192예요(마지막 자리는 반올림으로 조금 달라요).

```python
>>> sd.special.betainc(2.0, 3.0, 0.5) * sd.special.beta(2.0, 3.0)
0.057291666666666644
>>> 11 / 192
0.057291666666666664
```

아래 첫 그림의 곡선은 넓이가 1이 되게 B(a, b)로 나눈 곡선(베타 분포의 확률밀도)이에요. a가 b보다 크면 봉우리가 오른쪽에, 작으면 왼쪽에 있어요. a, b가 1보다 작으면 양 끝에서 무한히 솟아요. 두 번째 그림의 $I_x(a, b)$는 이 곡선 아래를 0부터 x까지 모은 넓이예요.

네 함수의 관계는 이래요.

| 함수 | 계산 | 결과 |
|---|:---:|---|
| `betainc(a, b, x)` | $I_x(a, b)$ | 0부터 x까지의 비율 (누적확률) |
| `betaincc(a, b, x)` | $1 - I_x(a, b)$ | x부터 1까지의 비율 (꼬리 확률) |
| `betaincinv(a, b, p)` | $I_x(a, b) = p$인 x | 누적확률이 p가 되는 위치 (분위수) |
| `betainccinv(a, b, q)` | $1 - I_x(a, b) = q$인 x | 꼬리 확률이 q가 되는 위치 |

## a와 b를 바꾸면 거울에 비친 모양

곡선 $t^{a-1}(1-t)^{b-1}$에서 t를 1 − t로 바꾸면 a와 b가 자리를 바꿔요. 그래서 x부터 1까지의 꼬리는, a와 b를 바꾼 곡선의 0부터 1 − x까지의 넓이와 같아요.

$$1 - I_x(a, b) = I_{1-x}(b, a)$$

```python
>>> sd.special.betaincc(2.0, 3.0, 0.5)
0.3125
>>> sd.special.betainc(3.0, 2.0, 0.5)
0.3125
```

a = b이면 곡선이 가운데를 기준으로 대칭이라서 x = 0.5에서 언제나 정확히 0.5예요.

```python
>>> sd.special.betainc(3.0, 3.0, 0.5)
0.5
```

이 관계는 x가 1에 아주 가까울 때 쓸모가 있어요. 그런 x는 float64에 담는 순간 정보가 사라질 수 있거든요. 예를 들어 `1 - 1e-17`은 float64에서 정확히 `1.0`이라서, `betaincc`에 넣어도 "x = 1에서의 꼬리"인 0이 나와요. 1 − x(여기서는 1e-17)를 따로 알고 있다면, 그 값을 거울 관계로 `betainc(b, a, 1 - x)`에 직접 넣으세요.

```python
>>> 1 - 1e-17
1.0
>>> sd.special.betaincc(2.0, 3.0, 1 - 1e-17)
0.0
>>> sd.special.betainc(3.0, 2.0, 1e-17)
4.0000000000000024e-51
```

## 확률분포의 누적확률로 쓰기

`betainc` 하나로 여러 분포의 누적확률을 계산할 수 있어요.

| 분포 | 누적확률 | 전용 함수 |
|---|:---:|---|
| 베타 분포 (a, b), P(X ≤ x) | `betainc(a, b, x)` | |
| 이항 분포 (n번, 성공 확률 p), P(X ≤ k) | `betaincc(k + 1, n - k, p)` | [bdtr](/api/special/bdtr/)(k, n, p) |
| 음이항 분포 (n번째 성공, 확률 p), 실패 k번 이하 | `betainc(n, k + 1, p)` | [nbdtr](/api/special/nbdtr/)(k, n, p) |
| t 분포 (자유도 ν), `t > 0`에서 P(T ≤ t) | `1 - betainc(ν/2, 1/2, ν/(ν + t²)) / 2` | [stdtr](/api/special/stdtr/)(ν, t) |
| F 분포 (자유도 d₁, d₂), P(F ≤ f) | `betainc(d₁/2, d₂/2, d₁f/(d₁f + d₂))` | [fdtr](/api/special/fdtr/)(d₁, d₂, f) |

성공 확률 0.3인 시행을 10번 해서 성공이 3번 이하일 확률을 이항 분포의 예로 들면, 전용 함수 `bdtr`의 값이나 확률을 하나씩 더한 값과 같아요.

```python
>>> sd.special.betaincc(3 + 1, 10 - 3, 0.3)
0.6496107184
>>> sd.special.bdtr(3, 10, 0.3)
0.6496107184
>>> sum(sd.special.binom(10, i) * 0.3**i * 0.7**(10 - i) for i in range(4))
0.6496107183999996
```

거울 관계로 쓴 `betainc(10 - 3, 3 + 1, 1 - 0.3)`도 같은 값이어야 하지만 마지막 자리가 조금 달라요. `1 - 0.3`이 float64에서 정확히 0.7이 아니기 때문이에요. 확률 p를 그대로 넣을 수 있는 `betaincc` 쪽이 나아요.

```python
>>> sd.special.betainc(10 - 3, 3 + 1, 1 - 0.3)
0.6496107183999998
```

t 분포와 F 분포도 전용 함수와 값이 같아요.

```python
>>> t, nu = 2.0, 5.0
>>> 1 - 0.5 * sd.special.betainc(nu / 2, 0.5, nu / (nu + t**2))
0.9490302605850709
>>> sd.special.stdtr(nu, t)
0.9490302605850709
>>> d1, d2, f = 3.0, 10.0, 2.5
>>> sd.special.betainc(d1 / 2, d2 / 2, d1 * f / (d1 * f + d2))
0.8809604373417218
>>> sd.special.fdtr(d1, d2, f)
0.8809604373417218
```

베이즈 A/B 테스트에서는 이렇게 써요. 방문자 100명 중 12명이 전환했고 사전 믿음을 균등분포로 두면, 전환율의 사후분포는 a = 1 + 12, b = 1 + 88인 베타 분포예요. 전환율이 10%를 넘을 확률은 약 79%예요.

```python
>>> sd.special.betaincc(13.0, 89.0, 0.1)
0.7919423114052647
```

분포를 객체로 다루는 `sd.stats`에도 베타·이항·t·F 분포가 있어요. 함수 하나로 바로 계산하고 싶을 때는 이 페이지의 함수가 간편해요.

## betaincc: 꼬리를 1에서 빼지 않고 계산하기

`betaincc(a, b, x)`는 `1 - betainc(a, b, x)`와 같은 값이지만, 1에서 빼서 계산하지 않아요. x에서 1까지의 넓이를 직접 계산하므로, 꼬리가 아주 작아도 앞자리가 맞아요.

```python
>>> sd.special.betainc(2.0, 60.0, 0.5)
1.0
>>> 1 - sd.special.betainc(2.0, 60.0, 0.5)
0.0
>>> sd.special.betaincc(2.0, 60.0, 0.5)
2.6888213877640504e-17
```

`betainc`의 참값은 1 − 2.7 × 10⁻¹⁷인데, float64는 1 바로 아래를 약 1.1 × 10⁻¹⁶ 간격으로만 나타낼 수 있어서 `1.0`으로 반올림돼요. 거기서 1을 빼면 0이에요. `betaincc`는 꼬리를 직접 계산해서 2.7 × 10⁻¹⁷을 정확히 내요.

<Callout type="warn" title="작은 꼬리 확률은 betaincc로 구하세요">

이항 분포의 위쪽 꼬리, t·F 검정의 p값처럼 작을 수 있는 "남은 비율"은 `1 - betainc(...)`가 아니라 `betaincc(...)`로 구하세요. 1e-16보다 작은 꼬리는 `1 - betainc`로는 0이 되어 버려요.

</Callout>

## 역함수: 누적확률에서 위치 찾기

`betaincinv(a, b, p)`는 `betainc(a, b, x) = p`가 되는 x를 찾아요. 베타 분포의 **분위수**예요. `betainccinv(a, b, q)`는 `betaincc(a, b, x) = q`가 되는 x예요.

```python
>>> sd.special.betaincinv(2.0, 3.0, 0.5)
0.3857275681323896
>>> p = sd.asarray([0.1, 0.5, 0.9])
>>> sd.special.betainc(2.0, 3.0, sd.special.betaincinv(2.0, 3.0, p))
array([0.10000000000000005,  0.5000000000000002,  0.8999999999999999], dtype=float64)
```

첫 줄은 a = 2, b = 3인 베타 분포의 중앙값이에요. 다시 `betainc`에 넣으면 처음의 p로 돌아와요(마지막 자리는 반올림으로 조금 다를 수 있어요).

### 성공 비율의 신뢰구간

20번 중 7번 성공했을 때 성공 확률의 95% 신뢰구간(Clopper–Pearson 구간)은 두 역함수 값으로 바로 나와요. 아래 끝은 a = k, b = n − k + 1의 2.5% 분위수, 위 끝은 a = k + 1, b = n − k의 97.5% 분위수예요.

```python
>>> k, n = 7, 20
>>> lo = sd.special.betaincinv(k, n - k + 1, 0.025)
>>> hi = sd.special.betaincinv(k + 1, n - k, 0.975)
>>> lo, hi
(0.15390920478454115, 0.5921885345328282)
>>> sd.special.betainccinv(k + 1, n - k, 0.025)
0.5921885345328282
```

마지막 줄처럼 위쪽 97.5% 분위수는 "꼬리가 2.5%인 곳"이라서 `betainccinv`로도 같은 값이 나와요.

### 아주 작은 꼬리에는 betainccinv

꼬리 확률 q가 아주 작으면 `betaincinv(a, b, 1 - q)`로는 구할 수 없어요. `1 - 1e-20`이 정확히 `1.0`이 되어 "누적확률 1이 되는 곳", 곧 x = 1을 묻는 셈이 되기 때문이에요. q를 그대로 `betainccinv`에 넣으세요.

```python
>>> sd.special.betaincinv(2.0, 60.0, 1 - 1e-20)
1.0
>>> sd.special.betainccinv(2.0, 60.0, 1e-20)
0.5624938488531905
```

### 끝점과 범위 밖

p = 0이면 x = 0, p = 1이면 x = 1이에요. `betainccinv`는 반대예요. p나 q가 0과 1 사이를 벗어나거나 NaN이면 NaN이에요.

```python
>>> sd.special.betaincinv(2.0, 3.0, sd.asarray([0.0, 1.0]))
array([0.0, 1.0], dtype=float64)
>>> sd.special.betainccinv(2.0, 3.0, sd.asarray([0.0, 1.0]))
array([1.0, 0.0], dtype=float64)
>>> sd.special.betaincinv(2.0, 3.0, sd.asarray([-0.1, 1.5, sd.nan]))
array([nan, nan, nan], dtype=float64)
```

역함수는 "입력 p의 마지막 자리가 허용하는 만큼" 정확해요. 보통은 x도 앞자리 14자리 정도가 맞지만, `betainc`가 x에 아주 둔감한 곳(예: a가 아주 작아서 넓이가 0 바로 옆에 몰린 경우)에서는 p를 마지막 자리 하나만 바꿔도 x가 크게 움직여요. 그런 곳에서는 그 흔들림만큼만 x가 정해져요. 자세한 설명은 [불완전 감마 함수](/api/special/gammainc/)의 역함수 절에 있어요.

## 정의역 밖과 특수값

값 때문에 에러가 나는 일은 없어요. a나 b가 음수이거나, x가 0과 1 사이를 벗어나거나, NaN이 있으면 NaN이에요.

```python
>>> sd.special.betainc(2.0, 3.0, sd.asarray([-0.1, 1.1, sd.nan]))
array([nan, nan, nan], dtype=float64)
>>> sd.special.betainc(sd.asarray([-1.0, 2.0]), sd.asarray([2.0, -1.0]), 0.5)
array([nan, nan], dtype=float64)
```

경계에서의 값은 이래요. `betaincc`는 언제나 `1 - betainc`에 해당하는 값이에요.

| 입력 | `betainc` | 이유 |
|---|:---:|---|
| x = 0 | 0 | 아직 넓이를 하나도 지나지 않았어요. a나 b가 0이어도 이 규칙이 먼저예요 |
| x = 1 | 1 | 넓이를 모두 지났어요. a나 b가 0이어도 이 규칙이 먼저예요 |
| `a = 0`, `0 < x < 1` | 1 | a → 0이면 넓이가 모두 0 바로 옆에 몰려요 |
| `b = 0`, `0 < x < 1` | 0 | b → 0이면 넓이가 모두 1 바로 옆에 몰려요 |
| a = b = 0 | NaN | 두 극한이 충돌해요. x가 끝점이어도 NaN이에요 |
| `a = ∞`, `0 < x < 1` | 0 | 넓이가 모두 1 쪽으로 가요 |
| `b = ∞`, `0 < x < 1` | 1 | 넓이가 모두 0 쪽으로 가요 |
| a = b = ∞ | NaN | 두 극한이 충돌해요 |

```python
>>> sd.special.betainc(sd.asarray([0.0, 2.0]), sd.asarray([2.0, 0.0]), 0.5)
array([1.0, 0.0], dtype=float64)
>>> sd.special.betainc(sd.asarray([sd.inf, 2.0, sd.inf]), sd.asarray([2.0, sd.inf, sd.inf]), 0.5)
array([0.0, 1.0, nan], dtype=float64)
>>> sd.special.betainc(0.0, 1.0, 0.0)
0.0
```

역함수에서는 a나 b가 0이면 p가 끝점(0, 1)이어도 NaN이에요. a나 b가 ∞이면 위 표의 극한과 짝을 이뤄요. 0 < p < 1에서 a = ∞이면 넓이가 모두 1 쪽에 있으니 근은 1, b = ∞이면 0이에요. `betainccinv`도 같은 근을 내고, a = b = ∞이면 NaN이에요.

```python
>>> sd.special.betaincinv(sd.asarray([sd.inf, 2.0, sd.inf]), sd.asarray([2.0, sd.inf, sd.inf]), 0.3)
array([1.0, 0.0, nan], dtype=float64)
```

## 정확도

- `betainc`와 `betaincc`는 a, b ≥ 0, 0 ≤ x ≤ 1인 정의역 전체에서 상대오차가 1e-14 이하예요. 결과의 앞자리 약 14자리가 참값과 같다는 뜻이에요. 위의 2.7 × 10⁻¹⁷ 같은 아주 작은 꼬리도 마찬가지예요. 실제로 잰 최대 오차는 `betainc` 약 22 [ULP](/api/special/basics/), `betaincc` 약 19 ULP예요.
- 결과가 float64로 담을 수 있는 가장 작은 정규 수(약 2.2 × 10⁻³⁰⁸)보다 작으면 0으로 뭉개지 않고 서브노멀 값을 내요. 이 영역에서는 상대오차 대신 아주 작은 절대오차로 약속해요.
- 두 역함수는 p(또는 q)의 마지막 자리가 허용하는 만큼 정확해요. 보통의 a, b에서는 상대오차 1e-14 안팎이에요. 모양이 서브노멀 수처럼 아주 작아도 근을 내요. 예를 들어 `betaincinv(1, 5e-324, 5e-324)`는 1 − 1/e예요.
- 아주 작은 p(서브노멀 수)에서 근을 구하지 못하는 곳이 하나 있어요. 한 모양이 약 2.3 × 10⁶에서 1.2 × 10²⁴ 사이이고 다른 모양이 1보다 작을 때, 근이 x = 1 쪽에 붙는 `betaincinv(큰 모양, 작은 모양, p)`와 `betainccinv(작은 모양, 큰 모양, p)`는 NaN이에요. 두 모양이 모두 아주 크면(약 1.2 × 10¹⁸ 이상) 서브노멀 p에서도 근을 내요.

```python
>>> sd.special.betaincinv(1, 5e-324, 5e-324)
0.6321205588285577
>>> sd.special.betaincinv(1e7, 0.5, 5e-324)
nan
>>> sd.special.betaincinv(1e100, 1e100, 5e-324)
0.5
```

같은 입력이면 배열 안의 위치나 스레드 수와 상관없이 언제나 같은 비트가 나와요. 자세한 내용은 [특수함수의 기본](/api/special/basics/)에 있어요.

## 입력과 결과의 종류

결과는 언제나 float64예요. bool·정수를 넣어도 실수로 바꿔서 계산해요. 세 인자가 모두 Python 숫자면 결과도 Python `float`예요. 세 인자의 모양이 다르면 [브로드캐스팅](/api/array/broadcasting/) 규칙으로 맞춰요. 아래는 a 세 개와 x 두 개로 2×3 표를 만든 예예요.

```python
>>> sd.special.betainc(2, 3, 1)
1.0
>>> sd.special.betainc(sd.asarray([1.0, 2.0, 5.0]), 2.0, sd.asarray([[0.25], [0.75]]))
array([[0.43749999999999994,             0.15625,      0.004638671875],
       [             0.9375,             0.84375,      0.533935546875]], dtype=float64)
```

`out=`에 배열을 주면 그 배열에 결과를 적고 그 배열을 돌려줘요. 결과가 float64라서 정수 배열에는 담을 수 없어요. 규칙은 [사칙연산의 `out`](/api/array/arithmetic/)과 같아요.

```python
>>> buf = sd.zeros(2)
>>> sd.special.betainc(2.0, 3.0, sd.asarray([0.25, 0.75]), out=buf) is buf
True
```

에러는 값이 아니라 인자의 종류와 모양이 맞지 않을 때만 나요. 복소수와 리스트는 받지 않아요. 리스트는 먼저 [`asarray`](/api/array/asarray/)로 바꾸세요.

```python
>>> sd.special.betainc(2.0, 3.0, sd.asarray([0.5+0j]))

    ...
TypeError: betainc(): not supported for float64, float64 and complex128
>>> sd.special.betainc(2.0, 3.0, [0.5])

    ...

```

## 조심할 점

- 인자 순서는 (a, b, x)예요. 모양 매개변수 둘이 먼저, 위치 x가 맨 뒤예요.
- 이항 분포의 누적확률은 `betaincc(k + 1, n - k, p)`예요. a 자리에 k가 아니라 k + 1, b 자리에 n − k가 들어가요. 헷갈리면 [bdtr](/api/special/bdtr/)을 쓰세요.
- 작은 꼬리는 `1 - betainc`가 아니라 `betaincc`로 구하세요. 역함수도 작은 q는 `betainccinv(a, b, q)`예요.
- `1 - x`, `1 - p`도 반올림돼요. 거울 관계 $I_{1-x}(b, a)$를 쓰려고 `1 - x`를 만들면 x가 1에 가까울수록 정보가 사라져요. 가능하면 처음 값을 그대로 넣는 쪽을 고르세요.
- 정칙화된 값이에요. 나누기 전의 넓이가 필요하면 `beta(a, b)`를 곱하세요.
- 값 때문에 에러가 나지 않아요. 음수, 범위 밖의 x·p, NaN은 모두 조용히 NaN이 되니, 필요하면 `sd.isnan`으로 확인하세요.

## 비슷한 함수와의 차이

| 헷갈리는 것 | 차이 |
|---|---|
| `betainc`와 [beta](/api/special/beta/) | `beta(a, b)`는 0부터 1까지의 전체 넓이, `betainc(a, b, x)`는 그중 x까지의 비율이에요. |
| `betaincc(a, b, x)`와 `1 - betainc(a, b, x)` | 같은 값이지만 꼬리가 작으면 `betaincc`만 정확해요. |
| `betaincc(a, b, x)`와 `betainc(b, a, 1 - x)` | 수학적으로 같아요. 다만 `1 - x`를 계산할 때 반올림이 생겨요. |
| `betaincinv(a, b, 1 - q)`와 `betainccinv(a, b, q)` | 같은 x지만 q가 아주 작으면 `1 - q`가 1로 반올림되어 앞쪽은 1.0이 나와요. |
| `betainc`와 [bdtr](/api/special/bdtr/), [stdtr](/api/special/stdtr/), [fdtr](/api/special/fdtr/), [nbdtr](/api/special/nbdtr/) | 그 분포의 인자를 바로 받는 함수예요. 값은 같고, 변환식을 직접 쓰지 않아도 돼요. |
| `betainc`와 [gammainc](/api/special/gammainc/) | 불완전 감마 함수는 0부터 ∞까지 뻗은 곡선의 넓이 비율이에요. 감마·카이제곱·포아송 분포가 그쪽이에요. |

## scipy를 아는 분께

- 이름, 인자 순서 (a, b, x), 정칙화된 값이라는 점은 `scipy.special.betainc`, `betaincc`, `betaincinv`, `betainccinv`와 같아요. 끝점과 NaN의 규칙도 같아요.
- 모양이 ∞인 역함수는 `betainc`의 극한과 짝을 이루는 값을 내요. `betaincinv(inf, 2, 0.3)`이 stardust는 1.0, scipy는 NaN이에요(`betaincinv(2, inf, 0.3)`은 0.0과 NaN).
- 결과가 아주 작은 곳에서 NaN이나 엉뚱한 값 대신 참값을 내요. `betainc(2, 1e300, 5e-324)`는 `1.2205e-47`(scipy NaN), `betaincinv(2, 3, 5e-324)`는 `9.07e-163`(scipy NaN), `betainccinv(2, 3, 5e-324)`는 `1.0`(scipy NaN)이에요.
- 근이 float64로 담기지 않을 만큼 작으면 0을 내요. `betaincinv(0.0102, 36.2, 3.13e-169)`는 `0.0`이에요(scipy는 가장 작은 정규 수 `2.2e-308`).
- 그 밖의 값은 scipy와 마지막 몇 자리가 다를 수 있어요.
- 리스트나 numpy 배열은 받지 않고, `out`은 keyword-only예요. 경고를 내지 않아요.
