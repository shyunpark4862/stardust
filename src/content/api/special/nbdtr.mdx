## 한눈에 보기

**음이항 분포**(negative binomial distribution)는 성공을 기다리는 분포예요. 성공 확률이 `p`인 시도를 되풀이할 때, `n`번째 성공이 나오기 전까지 실패한 횟수를 세요. [이항 분포](/api/special/bdtr/)가 "시도 횟수를 정해 두고 성공을 센다"면, 음이항 분포는 "성공 횟수를 정해 두고 실패를 센다"예요.

이런 곳에 써요.

- 기다림의 확률: 주사위를 몇 번 던져야 6이 나오는지, 영업 전화를 몇 통 돌려야 계약 3건을 얻는지
- 재시도와 신뢰성: 네트워크 요청이 성공할 때까지 몇 번 실패하는지, 재시도 상한을 몇으로 잡을지
- 흩어짐이 큰 횟수 자료: 매장별 방문자 수, 보험 청구 건수, 생물 종의 개체 수, 유전자 발현량처럼 평균보다 분산이 훨씬 큰 횟수를 [포아송 분포](/api/special/pdtr/) 대신 나타낼 때. 이때는 `n`이 정수가 아닌 실수예요.

`n = 1`이면 첫 성공까지의 실패 수라서 **기하 분포**라는 이름이 따로 있어요.

두 함수가 짝이에요.

- `nbdtr(k, n, p)`: 실패 횟수 X가 `k` 이하일 확률 P(X ≤ k), 곧 **누적분포함수**(cdf)
- `nbdtrc(k, n, p)`: X가 `k`보다 클 확률 P(X > k), 곧 **생존함수**(survival function). 끝의 `c`는 보수(complement)라는 뜻이에요.

```python
>>> import stardust as sd
>>> sd.special.nbdtr(3, 2, 0.5)
0.8125
>>> sd.special.nbdtrc(3, 2, 0.5)
0.1875
```

동전을 던져 앞면 2번을 기다릴 때, 그동안 뒷면이 3번 이하로 나올 확률은 13/16 = 0.8125, 4번 이상 나올 확률은 3/16이에요.

## 음이항 분포의 정의

`n`번째 성공 전까지 정확히 $j$번 실패하려면, 처음 $j + n - 1$번 가운데 성공이 $n - 1$번이고 그다음 시도가 성공이어야 해요. 그래서

$$
P(X = j) = \binom{j + n - 1}{j}\, p^{n} (1 - p)^{j}, \qquad j = 0, 1, 2, \dots
$$

이고, `nbdtr`은 이것을 0부터 $k$까지 더한 값이에요. 이 합은 [정칙화된 불완전 베타 함수](/api/special/betainc/)와 정확히 같아요.

$$
\mathrm{nbdtr}(k, n, p) = \sum_{j=0}^{\lfloor k \rfloor} \binom{j + n - 1}{j}\, p^{n} (1 - p)^{j} = I_{p}(n,\ \lfloor k \rfloor + 1)
$$

```python
>>> sd.special.betainc(2.0, 4.0, 0.5)
0.8125
>>> sd.special.betaincc(2.0, 4.0, 0.5)
0.1875
```

`nbdtrc`은 `betaincc(n, k + 1, p)`예요. 베타 함수로 쓰면 `n`이 정수가 아니어도 식이 그대로 통해서, 실수 `n`도 받아요.

## 시도가 아니라 실패를 세요

<Callout type="warn" title="X는 시도 횟수가 아니라 실패 횟수예요">
  `nbdtr`의 X는 **실패만** 센 수예요. 성공 `n`번은 들어 있지 않아요. "시도를 모두 합쳐 T번 안에 n번 성공할 확률"은 실패가 `T - n`번 이하일 확률이라 `nbdtr(T - n, n, p)`예요. 책이나 다른 도구에 따라 X를 시도 횟수로 정의하기도 하니, 옮겨 쓸 때 꼭 확인하세요.
</Callout>

### 주사위로 첫 6 기다리기

주사위를 던져 **10번 안에** 6이 한 번이라도 나올 확률이에요. 첫 성공(`n = 1`) 전의 실패가 9번 이하인 경우예요.

```python
>>> sd.special.nbdtr(9, 1, 1 / 6)
0.8384944171101543
>>> 1 - (5 / 6) ** 10
0.8384944171101543
```

"10번 모두 6이 아닐 확률을 1에서 뺀 값"과 같아요. 10번이나 던져도 16% 정도는 6을 한 번도 못 봐요.

### 영업 전화로 계약 3건

전화 한 통에 계약할 확률이 20%예요. 계약 3건을 얻는 데 전화가 10통 이하로 들 확률은 이렇게 구해요. 시도 10통 중 3통이 성공이면 실패는 7통 이하예요.

```python
>>> sd.special.nbdtr(7, 3, 0.2)
0.3222004736
>>> sd.special.nbdtrc(7, 3, 0.2)
0.6777995264000001
```

10통 안에 끝날 확률은 32%뿐이고, 68%는 11통 이상 걸려요. 같은 질문을 이항 분포로 바꿀 수도 있어요. "10통 안에 3번째 성공이 나온다"는 "10통 중 성공이 3번 이상"과 같은 사건이에요.

```python
>>> sd.special.bdtrc(2, 10, 0.2)
0.3222004736
```

일반적으로 `nbdtr(k, n, p)`는 `bdtrc(n - 1, n + k, p)`와 같아요(`n`이 정수일 때).

## 위꼬리는 `nbdtrc`로 직접

`nbdtrc`을 `1 - nbdtr`로 계산하면 꼬리에서 자릿수를 잃어요. `nbdtr`이 1에 아주 가까워지면 1에서 뺀 값의 오차가 커져요. float64는 1 근처에서 약 1.1e-16 간격으로만 수를 담을 수 있기 때문이에요.

```python
>>> sd.special.nbdtrc(60, 3, 0.2)
0.00010891752308042034
>>> 1 - sd.special.nbdtr(60, 3, 0.2)
0.00010891752308039848
>>> sd.special.nbdtrc(200, 2, 0.5)
3.1581802535145285e-59
>>> 1 - sd.special.nbdtr(200, 2, 0.5)
0.0
```

첫 비교는 앞 열두 자리만 맞고, 먼 꼬리에서는 `1 - nbdtr`이 0이 돼요. `nbdtrc`은 1에서 빼지 않고 위꼬리를 직접 계산해서 이런 값도 앞자리 14자리 정도가 맞아요. "재시도가 60번 넘게 실패할 확률"처럼 드문 사건의 확률을 정확히 알고 싶을 때 차이가 나요.

## 실수 `n`: 흩어짐이 큰 횟수 자료

현실의 횟수 자료는 포아송 분포보다 흩어짐이 큰 경우가 많아요. 어떤 매장은 늘 붐비고 어떤 매장은 한산하듯, 평균 자체가 대상마다 다르기 때문이에요. 이럴 때 음이항 분포를 **평균** $\mu$와 **크기**(size) $r$로 바꿔 써요. 성공 확률을

$$
p = \frac{r}{r + \mu}
$$

로 잡고 `n = r`을 넣으면 평균이 $\mu$, 분산이 $\mu + \mu^2/r$인 분포가 돼요. $r$이 작을수록 흩어짐이 크고, $r$이 무한대로 가면 포아송 분포가 돼요. $r$은 자료에 맞춰 정하는 값이라 보통 정수가 아니에요.

하루 평균 4건인 고객 문의가 10건 이상 들어올 확률을 두 분포로 비교해 볼게요. 크기는 2.5로 잡았어요.

```python
>>> r, mu = 2.5, 4.0
>>> p = r / (r + mu)
>>> sd.special.nbdtrc(9, r, p)
0.06492704610094517
>>> sd.special.pdtrc(9, mu)
0.008132242796933866
```

평균은 같아도 음이항 분포에서는 10건 이상이 6.5%, 포아송 분포에서는 0.8%예요. 흩어짐이 큰 자료에 포아송 분포를 쓰면 드문 날의 확률을 여덟 배쯤 작게 보게 돼요.

## 정수 인자의 규칙

### `k`는 내림하고, 음수도 받아요

실패 횟수는 정수라서 `k`가 정수가 아니면 **내림해서** P(X ≤ ⌊k⌋)로 계산해요. 음수 `k`는 누적확률 0(위꼬리 1), `k`가 무한대이면 1이에요.

```python
>>> sd.special.nbdtr(2.9, 3, 0.5)
0.5
>>> sd.special.nbdtr(-1, 3, 0.5)
0.0
>>> sd.special.nbdtrc(-1, 3, 0.5)
1.0
```

### `n`은 0 이상의 실수

`n`은 정수가 아니어도 돼요. 정수가 아닌 `n`은 내리지 않고 그대로 계산해서, 위 식의 `betainc(n, k + 1, p)`와 같아요.

```python
>>> sd.special.nbdtr(3, 5.5, 0.5)
0.30504337948159893
>>> sd.special.betainc(5.5, 4.0, 0.5)
0.30504337948159893
```

`n = 0`이면 기다릴 성공이 없으니 실패도 0번이라 누적확률이 1이에요(`0 < p ≤ 1`일 때). `n`이 무한대이면 실패가 끝없이 쌓이니 유한한 `k`의 누적확률은 0이에요. 음수 `n`은 NaN이에요.

```python
>>> sd.special.nbdtr(3, 0, 0.5)
1.0
>>> sd.special.nbdtr(3, sd.inf, 0.5)
0.0
>>> sd.special.nbdtr(3, -1, 0.5)
nan
```

### `p`의 끝점

`p = 1`이면 매번 성공하니 실패는 0번이라 누적확률이 1이에요. `p = 0`이면 성공이 영영 오지 않으니 0이에요. 범위 밖은 NaN이에요.

```python
>>> sd.special.nbdtr(3, 2, 1.0)
1.0
>>> sd.special.nbdtr(3, 2, 0.0)
0.0
>>> sd.special.nbdtr(3, 2, 1.5)
nan
```

## 정확히 k번 실패할 확률

"정확히 k번"의 확률은 누적확률의 차이로 구해요. `k = 0`에서도 `nbdtr(-1, ...) = 0`이라 식이 그대로 맞아요. 동전으로 첫 앞면을 기다리는 기하 분포예요.

```python
>>> k = sd.arange(0, 6)
>>> sd.special.nbdtr(k, 1, 0.5) - sd.special.nbdtr(k - 1, 1, 0.5)
array([     0.5,     0.25,    0.125,   0.0625,  0.03125, 0.015625], dtype=float64)
```

첫 시도에 바로 앞면이 나와 실패가 0번일 확률이 1/2, 뒷면 한 번 뒤에 앞면이 나올 확률이 1/4, 이렇게 반씩 줄어요.

## 여러 값을 한 번에

인자는 배열이어도 되고 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 실패를 5번까지 허용할 때, 기다리는 성공 수에 따라 확률이 어떻게 바뀌는지 봐요.

```python
>>> sd.special.nbdtr(5, sd.asarray([1, 2, 3, 4]), 0.5)
array([  0.984375,     0.9375, 0.85546875, 0.74609375], dtype=float64)
```

성공을 많이 기다릴수록 그사이 실패도 많아지니, 실패 5번 이하로 끝날 확률이 줄어요. 정수 배열도 float64로 계산하고, 결과는 언제나 float64예요. 결과를 미리 만든 배열에 받으려면 `out=`을 써요([특수함수의 기본](/api/special/basics/)).

## 정확도

- **보장 영역**: `k`와 `n`이 1e4(1만) 이하인 범위, `p`는 모든 값
- **`nbdtr`, `nbdtrc`**: 정밀한 참값과의 상대오차가 1e-14 이하예요. 앞자리 14자리 정도가 맞는다는 뜻이고, `3.16e-59` 같은 먼 꼬리에서도 마찬가지예요.

잰 최대 오차는 `nbdtr` 7.2, `nbdtrc` 8.8 ULP예요. 1e-14가 약 45 ULP이니 약속보다 한참 작아요. ULP는 [특수함수의 기본](/api/special/basics/)에서 풀어 놓았어요. 범위 밖도 값을 계산하지만 정확도를 약속하지는 않아요.

| `k`가 정수가 아님 | `⌊k⌋`로 계산 | P(X ≤ k)의 뜻 그대로예요 |
| `k < 0` | 0 (`nbdtrc`은 1) | 실패 횟수는 음수가 될 수 없어요 |
| `k = inf` | 1 (`nbdtrc`은 0) | |
| `n`이 정수가 아님 | `betainc(n, ⌊k⌋+1, p)` | 내리지 않아요 |
| `n = 0`, `0 < p ≤ 1` | 1 (`nbdtrc`은 0) | 기다릴 성공이 없어요 |
| `n = inf` | 0 (`nbdtrc`은 1) | 실패가 끝없이 쌓여요 |
| `n < 0` | NaN | |
| `p = 1` | 1 (`nbdtrc`은 0) | 실패가 없어요 |
| `p = 0` | 0 (`nbdtrc`은 1) | 성공이 오지 않아요(`n = 0`이어도) |
| `p < 0` 또는 `p > 1` | NaN | 확률이 아니에요 |
| 인자 중 NaN | NaN | |

## 조심할 점

### 인자 순서: `k`, `n`, `p`

`nbdtr(k, n, p)`는 실패 횟수 경계, 기다리는 성공 수, 성공 확률 순서예요. `k`와 `n`을 바꿔 넣어도 에러 없이 다른 값이 나와요.

```python
>>> sd.special.nbdtr(3, 2, 0.5)
0.8125
>>> sd.special.nbdtr(2, 3, 0.5)
0.5
```

### `p`는 성공 확률이에요

`p`는 **성공** 확률이고, X는 **실패** 횟수예요. 실패 확률을 `p`로 쓰는 책도 있어서, 공식을 옮길 때 `p`와 `1 - p`가 뒤바뀌기 쉬워요. 평균 실패 수는 $n(1-p)/p$이니, 결과가 상식과 맞는지 평균으로 한번 확인해 보세요.

### 값 때문에는 에러가 나지 않아요

정의역 밖의 값은 에러 대신 NaN이에요. 결과에 NaN이 섞이지 않았는지는 직접 확인해야 해요.

```python
>>> sd.special.nbdtr(sd.nan, 1, 0.5)
nan
```

### 에러는 타입이 틀렸을 때만

복소수, 리스트, 문자열은 받지 않아요.

```python
>>> sd.special.nbdtr(3, 2, 0.5j)
Traceback (most recent call last):
    ...
TypeError: nbdtr(): not supported for int64, int64 and complex128
>>> sd.special.nbdtrc(3, [1, 2], 0.5)
Traceback (most recent call last):
    ...
TypeError: nbdtrc(): 'n' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 시행 횟수를 정해 두고 성공 수 세기 | [`bdtr`](/api/special/bdtr/) | `nbdtr(k, n, p)`는 `bdtrc(n - 1, n + k, p)`와 같아요. |
| 흩어짐이 평균과 같은 횟수 | [`pdtr`](/api/special/pdtr/) | 음이항 분포에서 크기 `r`이 무한대인 극한이에요. 꼬리가 더 얇아요. |
| 성공 확률 `p`를 거꾸로 구하기 | [`betaincinv`](/api/special/betainc/) | `nbdtr(k, n, p) = y`인 `p`는 `betaincinv(n, k + 1, y)`예요. |
| 정확히 k번의 확률 | [`binom`](/api/special/binom/) | `binom(k + n - 1, k) * p**n * (1 - p)**k`예요. |
| 실수 `k`로 매끄럽게 이어진 값 | [`betainc`](/api/special/betainc/) | `betainc(n, k + 1, p)`는 `k`를 내리지 않아요. |

`sd.stats`에도 음이항 분포 객체가 있어요. 확률질량, 난수, 평균 같은 것을 한데 묶어 쓰고 싶으면 그쪽을 쓰고, 누적확률 하나만 빠르게 필요하면 이 함수들이 간단해요.

## scipy를 아는 분께

- 이름, 인자 순서, 뜻은 `scipy.special.nbdtr`, `nbdtrc`과 같아요. 정수가 아닌 `k`를 내리는 것도 같아요.
- 정수가 아닌 `n`을 내리지 않고 그대로 계산해요. scipy 1.18.1은 `RuntimeWarning`을 내고 `n`을 내려요(`nbdtr(3, 5.5, 0.5)`가 stardust는 0.305, scipy는 0.363).
- `nbdtr(k, 0, p)`는 1이에요. scipy는 NaN이에요.
- 음수 `k`에서 `nbdtr`은 0, `nbdtrc`은 1이고, `k = inf`에서 `nbdtr`은 1이에요. scipy는 모두 NaN이에요.
- 역함수 `nbdtri`, `nbdtrik`, `nbdtrin`은 없어요. 성공 확률은 `betaincinv`로 구해요.
- 리스트, numpy 배열은 받지 않아요. `sd.ndarray`와 Python 숫자만 받아요. `out`은 keyword-only예요.
