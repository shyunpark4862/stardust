---
title: 비중심 F 분포 함수
names: [ncfdtr, ncfdtrc, ncfdtri]
group: 비중심 분포 함수
order: 3
signatures:
  - "sd.special.ncfdtr(dfn, dfd, nc, x, /, *, out=None)"
  - "sd.special.ncfdtrc(dfn, dfd, nc, x, /, *, out=None)"
  - "sd.special.ncfdtri(dfn, dfd, nc, p, /, *, out=None)"
summary: 비중심 F 분포의 아래꼬리 확률 P(F ≤ x), 위꼬리 확률 P(F > x), 아래꼬리 확률의 역함수예요. 분산분석과 회귀분석 F 검정의 검정력과 표본 크기를 계산할 때 써요. 경계값 x가 맨 뒤에 와요.
params:
  - name: dfn
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: 분자 자유도. 0보다 커야 해요(inf도 돼요). 0 이하면 결과가 NaN이에요.
  - name: dfd
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: 분모 자유도. 0보다 커야 해요(inf도 돼요). 0 이하면 결과가 NaN이에요.
  - name: nc
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: 비중심 모수 λ. 0 이상. 0이면 보통(중심) F 분포예요. 음수면 결과가 NaN이에요.
  - name: x
    type: ndarray 또는 Python 숫자
    kind: "positional-only (ncfdtr, ncfdtrc)"
    desc: 확률을 구할 경계값. 0 이상. 음수면 결과가 NaN이에요.
  - name: p
    type: ndarray 또는 Python 숫자
    kind: "positional-only (ncfdtri)"
    desc: 아래꼬리 확률. 0 이상 1 이하. 밖이면 결과가 NaN이에요.
  - name: out
    type: ndarray 또는 None
    kind: keyword-only
    desc: 결과를 담을 float64 배열. 주면 그 배열에 쓰고 그 배열을 돌려줘요.
returns:
  type: ndarray 또는 Python float
  desc: "ncfdtr: P(F ≤ x), ncfdtrc: P(F > x), ncfdtri: ncfdtr(dfn, dfd, nc, x) = p인 x. 인자가 모두 Python 숫자면 Python float, 하나라도 배열이면 브로드캐스팅한 모양의 float64 배열이에요."
raises:
  - type: TypeError
    desc: 인자가 배열도 숫자도 아닐 때(리스트 포함), 복소수가 섞였을 때, out이 float64 배열이 아닐 때. 값이 정의역 밖인 것은 에러가 아니라 NaN이에요.
  - type: ValueError
    desc: 인자끼리 브로드캐스팅으로 맞출 수 없거나 out의 모양이 결과와 맞지 않을 때.
seeAlso: [chndtr, nctdtr, fdtr, betainc, basics]

## 한눈에 보기

**비중심 F 분포**(noncentral F distribution)는 "집단 사이에 실제로 차이가 있을 때 F 통계량이 따르는 분포"예요.

분산분석(ANOVA)을 떠올려 볼게요. 세 집단 이상의 평균이 모두 같은지 볼 때, "집단 평균이 서로 얼마나 퍼져 있나"를 "집단 안에서 값이 얼마나 퍼져 있나"로 나눈 비율이 F 통계량이에요. 집단 평균이 모두 같으면 이 통계량은 보통의 F 분포인 **중심** F 분포를 따라요. 평균이 실제로 다르면 분자가 커져서 통계량이 오른쪽으로 밀려나는데, 그때의 분포가 비중심 F 분포예요. 얼마나 밀려나는지를 나타내는 숫자가 **비중심 모수** $\lambda$예요.

이 페이지의 세 함수는 그 분포의 확률을 계산해요.

| 함수 | 돌려주는 것 |
|---|---|
| `ncfdtr(dfn, dfd, nc, x)` | 아래꼬리 확률 $P(F \le x)$ (누적분포함수) |
| `ncfdtrc(dfn, dfd, nc, x)` | 위꼬리 확률 $P(F > x)$ |
| `ncfdtri(dfn, dfd, nc, p)` | `ncfdtr(dfn, dfd, nc, x) = p`가 되는 $x$ (아래꼬리의 역함수) |

```python
>>> import stardust as sd
>>> sd.special.ncfdtr(3, 20, 5, 2)
0.4031300850345886
>>> sd.special.ncfdtrc(3, 20, 5, 2)
0.5968699149654114
>>> sd.special.ncfdtri(3, 20, 5, 0.5)
2.4234834710663886
```

분자 자유도 3, 분모 자유도 20, $\lambda = 5$인 분포에서 값이 2 이하일 확률은 약 40%예요. 확률 0.5를 주면 중앙값 2.42가 나와요.

<Callout title="경계값 x가 맨 뒤예요">

세 함수 모두 **분포의 모수(`dfn`, `dfd`, `nc`)가 앞, 경계값(`x` 또는 `p`)이 맨 뒤**예요. 이 순서는 scipy의 `ncfdtr`, `ncfdtri`과 같아요. 다만 같은 비중심 함수인 [`chndtr`](/api/special/chndtr/)는 scipy가 `chndtr(x, df, nc)`로 경계값을 맨 앞에 두고, stardust는 맨 뒤에 둬요. stardust 안에서는 비중심 함수 모두 경계값이 맨 뒤라고 기억하면 돼요.

</Callout>

## 어디에 쓰나요

F 검정을 쓰는 곳이면 어디서나 **검정력과 표본 크기**를 계산할 때 이 분포가 나와요. 효과가 없을 때의 분포(중심 F)로 "유의하다"의 기준값을 정하고, 효과가 있을 때의 분포(비중심 F)가 그 기준값을 넘을 확률이 검정력이에요.

- 분산분석: 처리 방법 네 가지의 효과를 비교하는 실험에서 집단마다 몇 명이 필요한지 정해요. 일원·이원 분산분석, 반복측정 설계 모두 같은 틀이에요.
- 회귀분석: 예측변수 묶음이 결과를 설명하는지(전체 F 검정, $R^2$ 증가분 검정)를 볼 때 필요한 표본 수를 정해요.
- 선형 모형의 대비 검정: 여러 계수에 대한 가설을 한꺼번에 검정할 때의 검정력이에요.
- 양측 t 검정: 분자 자유도가 1이면 F 통계량은 t 통계량의 제곱이라서, 양측 t 검정의 검정력도 이 분포 하나로 계산할 수 있어요([`nctdtr`](/api/special/nctdtr/) 참고).

## 정의와 모양

분자에 비중심 카이제곱, 분모에 중심 카이제곱이 있는 비율이에요. $X_1$이 자유도 $d_1$, 비중심 모수 $\lambda$인 [비중심 카이제곱](/api/special/chndtr/)을, $X_2$가 자유도 $d_2$인 카이제곱을 따르고 서로 독립일 때

$$F = \frac{X_1 / d_1}{X_2 / d_2}$$

가 비중심 F 분포를 따라요. $\lambda = 0$이면 보통의 F 분포예요. 누적분포함수는 [정칙화된 불완전 베타 함수](/api/special/betainc/) $I_y(a, b)$를 포아송 확률로 섞은 꼴이에요.

$$\texttt{ncfdtr}(d_1, d_2, \lambda, x) = \sum_{j=0}^{\infty} e^{-\lambda/2}\,\frac{(\lambda/2)^j}{j!}\; I_{y}\!\left(\frac{d_1}{2} + j,\ \frac{d_2}{2}\right), \qquad y = \frac{d_1 x}{d_1 x + d_2}$$

아래 그래프는 분자 자유도 3, 분모 자유도 20에서 $\lambda$만 바꾼 밀도(값이 그 근처에 있을 가능성)예요.

$\lambda = 0$일 때는 중심 F의 [`fdtr`](/api/special/fdtr/), `fdtrc`, `fdtri`과 마지막 비트까지 같아요.

```python
>>> sd.special.ncfdtr(3, 20, 0, 2) == sd.special.fdtr(3, 20, 2)
True
>>> sd.special.ncfdtri(3, 20, 0, 0.95) == sd.special.fdtri(3, 20, 0.95)
True
```

## 세 함수: 아래꼬리, 위꼬리, 역함수

`ncfdtr`과 `ncfdtrc`은 서로 보수라서 수학적으로 더하면 1이에요. `ncfdtri`은 `ncfdtr`을 거꾸로 풀어요. 중심 F의 [`fdtri`](/api/special/fdtr/)와 같은 방향(아래꼬리)이에요.

```python
>>> f50 = sd.special.ncfdtri(3, 20, 5, 0.5)
>>> sd.special.ncfdtr(3, 20, 5, f50)
0.5000000000000001
```

마지막 자리가 1만큼 다른 것은 반올림 때문이에요.

## 검정력과 표본 크기 계산하기

### 일원 분산분석

처리 방법 4가지($k = 4$)를 비교하는 실험을 유의수준 5%로 분석한다고 해 볼게요. 집단 평균의 차이가 얼마나 큰지는 **효과 크기** $f$(Cohen의 $f$)로 나타내요. 집단 평균의 표준편차를 집단 안의 표준편차로 나눈 값이에요. 흔히 0.1은 작은 효과, 0.25는 중간 효과, 0.4는 큰 효과로 봐요.

전체 표본이 $N$명이면 F 통계량의 자유도와 비중심 모수는 이래요.

$$d_1 = k - 1, \qquad d_2 = N - k, \qquad \lambda = f^2 N$$

$\lambda$가 전체 표본 크기에 비례해요. 자료가 많을수록 같은 차이도 더 뚜렷하게 보여요. 계산은 두 단계예요.

1. 효과가 없을 때(중심 F) 위꼬리 5%가 되는 **기준값**을 구해요. `fdtri`은 아래꼬리의 역함수라서 0.95를 줘요.
2. 효과가 있을 때(비중심 F) 통계량이 그 기준값을 넘을 확률이 **검정력**이에요.

```python
>>> k, N, eff = 4, 100, 0.25
>>> crit = sd.special.fdtri(k - 1, N - k, 0.95)
>>> round(crit, 4)
2.6994
>>> round(sd.special.ncfdtrc(k - 1, N - k, eff ** 2 * N, crit), 4)
0.5182
```

100명(집단마다 25명)으로는 중간 효과를 잡아낼 확률이 52%쯤이에요. 80%에 필요한 인원은 여러 $N$을 배열로 한꺼번에 계산해서 찾아요. 검정력이 처음으로 0.8 이상이 되는 자리는 [`sd.argmax`](/api/array/argmin/)가 찾아 줘요. 집단 크기가 같도록 4명씩 늘려 볼게요.

```python
>>> N = sd.arange(8, 400, 4)
>>> crit = sd.special.fdtri(k - 1, N - k, 0.95)
>>> power = sd.special.ncfdtrc(k - 1, N - k, eff ** 2 * N, crit)
>>> i = sd.argmax(power >= 0.8)
>>> int(N[i])
180
>>> round(float(power[i]), 4)
0.804
```

전체 180명, 집단마다 45명이 필요해요. 아래 그래프는 효과 크기에 따라 이 곡선이 어떻게 바뀌는지 보여 줘요. 작은 효과($f = 0.1$)는 300명으로도 검정력이 30%에 못 미쳐요.

### 회귀분석의 전체 F 검정

예측변수 5개짜리 회귀식이 결과의 10%를 설명할 때($R^2 = 0.1$), 회귀식 전체가 유의한지 검정하는 데 필요한 인원을 구해요. 효과 크기는 $f^2 = R^2/(1 - R^2)$, 자유도는 $d_1 = 5$, $d_2 = N - 6$(표본 크기에서 예측변수 수 + 1을 뺀 값), 비중심 모수는 $\lambda = f^2 N$이에요.

```python
>>> f2 = 0.1 / 0.9
>>> N = sd.arange(10, 400)
>>> crit = sd.special.fdtri(5, N - 6, 0.95)
>>> power = sd.special.ncfdtrc(5, N - 6, f2 * N, crit)
>>> int(N[sd.argmax(power >= 0.8)])
122
```

122명이면 검정력이 80%를 넘어요.

## 작은 꼬리 확률은 ncfdtrc로

위꼬리 확률이 작을 때 `1 - ncfdtr(...)`로 계산하면 1에 가까운 수끼리 빼느라 앞자리가 망가져요. `ncfdtrc`은 1에서 빼지 않고 위꼬리를 직접 계산해요.

```python
>>> sd.special.ncfdtrc(3, 20, 5, 200)
1.7840806544079732e-12
>>> 1 - sd.special.ncfdtr(3, 20, 5, 200)
1.7841284005726266e-12
```

참값은 1.784080654407973e-12예요. 빼기로 구한 값은 다섯째 자리부터 틀렸고, 확률이 더 작아지면 아예 0이 돼요.

## 배열, 브로드캐스팅, `out=`

네 인자는 배열이든 Python 숫자든 섞어 쓸 수 있고, 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 정수와 bool은 float64로 바꿔 계산하고, 결과는 언제나 float64예요. 인자가 모두 Python 숫자면 결과는 Python `float`예요. 위의 표본 크기 예에서 `N - k`와 `eff ** 2 * N`이 배열이고 `k - 1`이 숫자였던 것처럼요.

`out=`에 float64 배열을 주면 그 배열에 결과를 써요. 규칙은 원소별 함수의 `out=`과 같아요([사칙연산](/api/array/arithmetic/) 참고).

```python
>>> buf = sd.zeros(3)
>>> r = sd.special.ncfdtr(3, 20, sd.asarray([0.0, 5.0, 15.0]), 2, out=buf)
>>> r is buf
True
```

## 특수값과 정의역

값 때문에 에러를 내지 않아요. 정의역 밖이면 NaN을, 끝점에서는 극한값을 돌려줘요.

| 입력 | 결과 | 뜻 |
|---|---|---|
| `nc = 0` | `fdtr`, `fdtrc`, `fdtri`과 비트까지 같음 | 중심 F 분포 |
| `x = 0` | `ncfdtr` 0, `ncfdtrc` 1 | 값은 0보다 작을 수 없어요 |
| `x = inf` | `ncfdtr` 1, `ncfdtrc` 0 | |
| `dfd = inf` | `chndtr(dfn, nc, dfn·x)` | 분모가 1로 고정돼서 비중심 카이제곱을 `dfn`으로 나눈 것이 돼요 |
| `dfn = inf` | `fdtr(inf, dfd, x)` | 분자가 1로 고정돼요 |
| `nc = inf` | `ncfdtr` 0, `ncfdtrc` 1 | 분포가 무한대로 밀려나요. `x`도 inf이면 NaN |
| `dfn`이 아주 작음(약 1e-300 아래) | $e^{-\lambda/2}$ × `fdtr(dfn, dfd, x)` | 확률 $e^{-\lambda/2}$만큼은 중심 F처럼 움직이고, 나머지는 아주 큰 `x` 쪽에 있어요. `ncfdtrc`은 그 나머지 |
| `ncfdtri`의 `p = 0`, `p = 1` | 0, inf | 정의역의 두 끝 |
| `ncfdtri`의 `p`가 0보다 크고 2.2e-308보다 작음(서브노멀), `nc > 0` | NaN | 이렇게 작은 확률에서는 근을 믿을 만하게 구할 수 없어요 |
| `ncfdtri`의 근이 float64로 나타낼 수 있는 범위 밖 | inf 또는 0 | 가장 큰 float64 값에서도 `ncfdtr`이 `p`에 못 미치면 inf, 가장 작은 양수에서 이미 `p`를 넘으면 0이에요 |
| `dfn ≤ 0`, `dfd ≤ 0`, `nc < 0`, `x < 0` | NaN | 정의역 밖 |
| `p < 0` 또는 `p > 1` | NaN | 확률이 아니에요 |
| 인자에 NaN | NaN | |

```python
>>> sd.special.ncfdtr(3, sd.inf, 5, 2)
0.4101075585254692
>>> sd.special.chndtr(3, 5, 6)
0.4101075585254692
>>> sd.special.ncfdtrc(3, 20, sd.inf, 2)
1.0
>>> sd.special.ncfdtr(1e-310, 5, 2, 1)
0.36787944117144233
>>> sd.special.ncfdtri(5e-324, 5, 2, 0.5)
inf
>>> sd.special.ncfdtr(3, 20, -1, 2)
nan
>>> sd.special.ncfdtri(3, 20, 5, 1.0)
inf
```

`dfn`이 아주 작으면 아래꼬리 확률은 가장 큰 float64 값에서도 $e^{-\lambda/2}$(위 예에서 $e^{-1} \approx 0.368$) 근처에 머물러요. 그래서 `ncfdtri(5e-324, 5, 2, 0.5)`의 근은 float64 범위를 넘어 inf예요.

## 정확도

**보장 영역**은 두 자유도 0.01–10⁴, 비중심 모수 0.001–10⁴이고, 확률은 1e-300까지예요. 이 안에서 약속하는 정확도는 이래요.

- `ncfdtr`, `ncfdtrc`: 참값 대비 상대오차 1e-14 이하. 결과의 앞자리 14자리 정도가 맞는다는 뜻이에요. 작은 꼬리 확률도 상대오차로 재므로 앞자리가 그만큼 맞아요.
- `ncfdtri`: 결과 $x$의 상대오차가 $10^{-14} \times \max(1, \kappa)$ 이하예요. $\kappa$는 "확률 $p$가 아주 조금 바뀔 때 $x$가 몇 배나 크게 바뀌는가"를 나타내는 수(조건수)예요. 입력 $p$ 자체가 마지막 자리에 반올림 오차를 품고 있으니 $\kappa$가 큰 곳에서는 그만큼은 어쩔 수 없어요.

잰 최대 오차는 `ncfdtr` 7 ULP, `ncfdtrc` 15 ULP, `ncfdtri` 9.9 ULP(조건수로 나눈 값)예요. ULP는 실수 한 칸의 간격으로, 1e-14는 45~90 ULP예요. 자세한 뜻은 [특수함수의 기본](/api/special/basics/)에 있어요. 보장 영역 밖도 값을 계산하지만 이 정확도를 약속하지는 않아요. 자유도가 10⁻¹⁰ 정도로 아주 작은 곳에서는, 한쪽 확률이 1에 너무 가까워서 다른 쪽을 믿을 만하게 구할 수 없으면 NaN을 내요. 비중심 모수가 아주 크면(약 $1.47 \times 10^9$ 이상) NaN인 곳이 넓어요. 어떤 입력이든 정해진 시간 안에 끝나는데, 그 안에 값을 구할 수 없는 곳이에요. 예를 들어 `dfn = 1`, `dfd = 10`, $\lambda = 1.5 \times 10^9$이면 $x \lesssim 10^6$에서 0, $x \gtrsim 10^{183}$에서 1이고, 그 사이($x \approx 10^7$–$10^{182}$, 값이 1로 반올림되는 위꼬리까지)는 모두 NaN이에요. 결과가 서브노멀(1e-308보다 작은 아주 작은 수)일 때는 상대오차 대신 절대오차로 따져요.

## 조심할 점

### 인자가 넷이라 자리를 헷갈리기 쉬워요

`dfd`와 `nc`는 둘 다 양수라서 자리를 바꿔 넣어도 에러도 NaN도 나지 않고 다른 숫자가 나와요.

```python
>>> sd.special.ncfdtr(3, 20, 5, 2)
0.4031300850345886
>>> sd.special.ncfdtr(3, 5, 20, 2)
0.029368700473405583
```

순서는 "분자 자유도, 분모 자유도, 비중심 모수, 경계값"이에요. 중심 F의 `fdtr(dfn, dfd, x)`에서 `x` 앞에 `nc`가 끼어든 모양이라고 기억하면 쉬워요.

### 비중심 모수는 효과 크기가 아니에요

Cohen의 $f$나 $f^2$를 `nc`에 그대로 넣으면 안 돼요. 분산분석과 회귀분석에서는 $\lambda = f^2 N$처럼 전체 표본 크기를 곱해야 해요. 그대로 넣으면 표본이 몇 명이든 검정력이 유의수준 근처로 아주 낮게 나와요.

### 모수의 역함수는 없어요

"검정력이 80%가 되는 $\lambda$"나 "분모 자유도"를 바로 푸는 함수는 없어요. 위의 표본 크기 예처럼 후보를 배열로 만들어 한꺼번에 계산하고 고르면 돼요. 분포를 객체로 다루는 통계 영역 `sd.stats`에도 분포가 있어요.

### 리스트와 복소수는 받지 않아요

인자는 `sd.ndarray`나 Python 숫자여야 해요. 리스트는 `sd.asarray`로 바꿔서 넘기세요. 복소수도 `TypeError`예요.

```python
>>> sd.special.ncfdtr(3, 20, 5, [1, 2])
Traceback (most recent call last):
    ...
TypeError: ncfdtr(): 'x' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 효과가 없을 때의 F 확률, p값, 기준값 | [`fdtr`, `fdtrc`, `fdtri`](/api/special/fdtr/) | 비중심 모수가 없어요. `ncfdtr(dfn, dfd, 0, x)`와 같아요 |
| 효과가 있을 때의 F 확률, 검정력 | `ncfdtr`, `ncfdtrc` | |
| 분모 자유도가 아주 클 때 | [`chndtr`](/api/special/chndtr/) | `ncfdtr(dfn, inf, nc, x) = chndtr(dfn, nc, dfn·x)` |
| t 검정의 검정력 | [`nctdtr`](/api/special/nctdtr/) | 양측이면 `ncfdtrc(1, df, δ², c²)`와 같아요 |
| 베타 분포 꼴의 일반 확률 | [`betainc`](/api/special/betainc/) | 중심 F는 불완전 베타 하나로 쓸 수 있어요 |

## scipy를 아는 분께

- **인자 순서는 scipy와 같아요.** `ncfdtr(dfn, dfd, nc, x)`, `ncfdtri(dfn, dfd, nc, p)`예요. 비중심 카이제곱만 scipy가 `chndtr(x, df, nc)`이고 stardust는 `chndtr(df, nc, x)`라서 달라요.
- 경계값 인자의 이름은 `x`예요(scipy는 `f`). 인자는 자리로만 넘기므로 이름은 `help()`와 에러 메시지에만 보여요.
- `ncfdtrc`은 scipy.special에 없는 함수예요. scipy에서 `1 - ncfdtr(...)`로 쓰던 계산을 이것으로 바꾸면 작은 꼬리가 정확해져요(`1 - scipy.special.ncfdtr(3, 20, 5, 200)`은 1.784017e-12로, 참값 1.784081e-12와 여섯째 자리부터 달라요).
- 모수를 푸는 `ncfdtridfd`, `ncfdtridfn`, `ncfdtrinc`는 없어요.
- 끝점의 값이 달라요. `dfd = inf`, `dfn = inf`, `nc = inf`에서 scipy는 NaN을, stardust는 위 표의 극한값을 돌려줘요.
- 근이 float64 범위 밖이면 scipy의 `ncfdtri`은 NaN, stardust는 inf나 0이에요. `ncfdtri(5e-324, 5, 2, 0.5)`가 그래요.
- `where=`, `dtype=` 같은 ufunc 인자는 없고 `out=`만 있어요. 인자는 모두 positional-only예요.
