## 한눈에 보기

완전 타원적분은 원에서 조금 찌그러진 문제를 풀 때 나오는 적분이에요. 원의 둘레는 2πr로 간단하지만, 타원의 둘레는 이런 간단한 식이 없어요. 그 둘레를 나타내는 적분이 제2종 완전 타원적분 E예요. 진자의 주기도 비슷해요. 아주 작게 흔들릴 때는 주기가 진폭과 상관없지만, 크게 흔들리면 주기가 길어지고, 그 길이를 나타내는 적분이 제1종 완전 타원적분 K예요.

- 역학: 크게 흔들리는 진자의 주기, 팽이·강체의 회전.
- 기하: 타원의 둘레, 곡면의 넓이.
- 전자기학: 원형 고리에 흐르는 전류가 만드는 자기장, 원판 축전기의 전기용량.
- 그 밖에: 통계물리(2차원 Ising 모형), 파동 방정식의 주기 해, 산술-기하 평균을 쓰는 계산.

정의는 이래요. 매개변수 m은 "얼마나 찌그러졌나"를 나타내고, m = 0이면 찌그러짐이 없는 원의 경우예요.

$$
K(m) = \int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - m\sin^2\theta}},
\qquad
E(m) = \int_0^{\pi/2} \sqrt{1 - m\sin^2\theta}\; d\theta
$$

m = 0이면 적분 안이 1이라 둘 다 π/2예요. m이 커지면 K의 분모가 작아져서 K는 커지고, E는 작아져요. m = 1에서 K는 무한대로 가고, E는 1이 돼요. m > 1이면 적분 안의 제곱근이 음수가 되는 구간이 생겨서 실수 값이 없어요.

## 매개변수 m: k가 아니라 k²예요

타원적분을 쓰는 책과 프로그램은 매개변수를 세 가지로 써요. 같은 적분인데 이름표만 달라요.

| 이름 | 기호 | 관계 | 적분 안의 모양 |
|---|:---:|:---:|:---:|
| 매개변수(parameter) | m | m | $1 - m\sin^2\theta$ |
| 모듈러스(modulus) | k | m = k² | $1 - k^2\sin^2\theta$ |
| 모듈러 각(modular angle) | α | m = sin²α | $1 - \sin^2\!\alpha\,\sin^2\theta$ |

`ellipk`와 `ellipe`는 **m**을 받아요. 공식이 $K(k)$로 적혀 있다면 `k ** 2`를 넣어야 해요. 이걸 놓치면 에러 없이 엉뚱한 값이 나와요.

```python
>>> k = 0.5
>>> sd.special.ellipk(k ** 2)
1.685750354812596
>>> sd.special.ellipk(k)
1.8540746773013719
```

첫째가 모듈러스 k = 0.5의 K이고, 둘째는 m = 0.5, 곧 k ≈ 0.707의 K예요.

## 진자의 주기

길이 L인 진자가 진폭(가장 크게 기운 각도) θ₀로 흔들릴 때, 한 번 왕복하는 주기는 정확히

$$T = 4\sqrt{\frac{L}{g}}\; K\!\left(\sin^2\frac{\theta_0}{2}\right)$$

예요. 아주 작게 흔들릴 때의 주기 $T_0 = 2\pi\sqrt{L/g}$와 비교하면, 비율은 $T/T_0 = \tfrac{2}{\pi}K(\sin^2(\theta_0/2))$예요. 진폭 90°로 흔들면 주기가 작은 진폭일 때보다 약 18% 길어요.

```python
>>> theta0 = sd.asarray([10.0, 45.0, 90.0, 170.0]) * sd.pi / 180
>>> 2 / sd.pi * sd.special.ellipk(sd.sin(theta0 / 2) ** 2)
array([1.0019071881432167,  1.039973343196804, 1.1803405990160962,

```

## 타원의 둘레

긴 반지름이 a, 짧은 반지름이 b인 타원의 둘레는

$$P = 4a\,E(e^2), \qquad e^2 = 1 - \frac{b^2}{a^2}$$

예요. e는 타원의 이심률(얼마나 납작한지)이에요. a = b인 원이면 e = 0이고 둘레가 $4a \cdot \pi/2 = 2\pi a$가 되어 원의 둘레와 같아져요.

```python
>>> a, b = 2.0, 1.0
>>> 4 * a * sd.special.ellipe(1 - b ** 2 / a ** 2)
9.688448220547675
>>> 4 * 3.0 * sd.special.ellipe(0.0) == 2 * sd.pi * 3.0
True
```

## m이 1에 가까울 때

m → 1에서 K는 무한대로 가지만 아주 천천히, 로그처럼 커져요.

$$K(m) \approx \frac{1}{2}\ln\frac{16}{1 - m}$$

```python
>>> sd.special.ellipk(sd.asarray([0.99, 0.999999, 1.0]))
array([3.6956373629898747,  8.294051463601061,                inf], dtype=float64)
>>> 0.5 * sd.log(16 / 1e-6)
8.294049640102028
```

`ellipk`는 m이 1에 아주 가까워도 그 m에서 정확한 값을 내요. 다만 m 자체를 만들 때 정보가 사라질 수 있다는 점을 조심하세요. float64에서 1 바로 아래의 수는 약 1.1 × 10⁻¹⁶ 간격으로만 있어요. 그래서 `1 - 1e-17`은 정확히 `1.0`이 되고, K는 `inf`가 돼요. `1 - 1e-12`도 1e-12를 정확히 담지 못하고 조금 다른 수로 반올림돼요.

```python
>>> 1 - 1e-17 == 1.0
True
>>> sd.special.ellipk(1 - 1e-17)
inf
```

1 − m(보수 매개변수라고 해요)을 작은 수 p로 이미 알고 있다면, 다음 항등식을 쓰면 반올림 없이 정확한 값을 얻을 수 있어요. 오른쪽의 $1 - 1/p$는 큰 음수라서 float64로 정확하게 나타낼 수 있기 때문이에요.

$$
K(1 - p) = \frac{1}{\sqrt{p}}\,K\!\left(1 - \frac{1}{p}\right),
\qquad
E(1 - p) = \sqrt{p}\;E\!\left(1 - \frac{1}{p}\right)
$$

```python
>>> p = 1e-17
>>> sd.special.ellipk(1 - 1 / p) / sd.sqrt(p)
20.958267651569276
```

참값 20.9582676515692789…와 앞 16자리가 맞아요.

## m이 음수일 때

m은 음수여도 돼요. 위의 항등식처럼 음수 m은 다른 문제를 바꿔 쓸 때 자주 나와요. m → −∞로 가면 K는 0으로, E는 무한대로 가요(대략 $\sqrt{-m}$처럼 커져요).

```python
>>> sd.special.ellipk(sd.asarray([-1.0, -100.0, -sd.inf]))
array([1.3110287771460598,  0.368219248609141,                0.0], dtype=float64)
>>> sd.special.ellipe(sd.asarray([-1.0, -100.0, -sd.inf]))
array([1.9100988945138562, 10.209260919814572,                inf], dtype=float64)
```

## 정확도

`ellipk`와 `ellipe`는 m ≤ 1 전체에서 상대오차 10⁻¹⁴ 이하를 약속해요. 앞 14자리쯤이 언제나 맞는다는 뜻이에요. 정의역 전체가 보장 영역이라, m이 1에 아주 가깝거나 큰 음수여도 같은 약속이 지켜져요. 실제로 잰 최대 오차는 `ellipk`가 2.3 ULP, `ellipe`가 2.0 ULP예요. ULP는 "float64에서 마지막 자리 한 칸"이라는 뜻이고, 2 ULP면 마지막 자리가 많아야 두 칸 틀린다는 뜻이에요. 자세한 설명은 [특수함수의 기본](/api/special/basics/)에 있어요.

두 함수 사이에는 Legendre 관계라는 항등식이 있어서, 계산을 확인하는 데 쓸 수 있어요.

$$E(m)K(1-m) + E(1-m)K(m) - K(m)K(1-m) = \frac{\pi}{2}$$

```python
>>> m = 0.3
>>> K, E = sd.special.ellipk, sd.special.ellipe
>>> E(m) * K(1 - m) + E(1 - m) * K(m) - K(m) * K(1 - m)
1.5707963267948974
>>> sd.pi / 2
1.5707963267948966
```

마지막 자리만 달라요. 세 항을 더하고 빼는 과정에서 생긴 반올림이에요.

## 특수값

| m | `ellipk(m)` | `ellipe(m)` |
|:---:|:---:|:---:|
| `0.0` | π/2 | π/2 |
| `1.0` | `inf` | `1.0` |
| `1`보다 큼, `inf` | `nan` | `nan` |
| `-inf` | `0.0` | `inf` |
| `nan` | `nan` | `nan` |

```python
>>> sd.special.ellipk(sd.asarray([1.0, 1.5, sd.inf, sd.nan]))
array([inf, nan, nan, nan], dtype=float64)
>>> sd.special.ellipe(sd.asarray([1.0, 1.5, sd.inf, sd.nan]))
array([1.0, nan, nan, nan], dtype=float64)
```

## 조심할 점

### m > 1은 에러가 아니라 NaN이에요

정의역 밖의 값을 넣어도 에러는 나지 않아요. 그 원소만 NaN이 되고 나머지 원소는 그대로 계산돼요. 그런데 공식이 모듈러스 k로 적혀 있는데 k를 그대로 넣는 실수는 에러로도 NaN으로도 드러나지 않을 때가 많아요(k &lt; 1이면 조용히 다른 값이 나와요). 결과가 이상하면 매개변수가 m인지 먼저 확인해 보세요.

### 복소수와 리스트는 받지 않아요

복소수를 넣으면 `TypeError`예요. 리스트도 받지 않으니 `sd.asarray`로 바꾸세요. Python 숫자는 그대로 받고, 결과도 Python `float`예요.

```python
>>> sd.special.ellipk(0.5 + 0j)
Traceback (most recent call last):
    ...
TypeError: ellipk(): not supported for complex128
>>> sd.special.ellipe([0.5])
Traceback (most recent call last):
    ...
TypeError: ellipe(): 'm' must be an sd.ndarray or a bool, int, float or complex, not list
>>> type(sd.special.ellipe(0.5))
<class 'float'>
```

### `out=`: 결과를 기존 배열에 쓰기

`out=`에 배열을 주면 새 배열을 만들지 않고 그 배열에 결과를 써요. 결과가 float64라서 int64 배열에는 쓸 수 없어요. 규칙은 배열 영역의 [사칙연산](/api/array/arithmetic/)에서 설명한 `out=`과 같아요.

```python
>>> buf = sd.empty(3)
>>> sd.special.ellipk(sd.asarray([0.0, 0.25, 0.5]), out=buf) is buf
True
>>> buf
array([1.5707963267948966,  1.685750354812596, 1.8540746773013719], dtype=float64)
>>> sd.special.ellipk(sd.asarray([0.0, 0.25, 0.5]), out=sd.empty(3, dtype=sd.int64))
Traceback (most recent call last):
    ...
TypeError: ellipk(): cannot implicitly convert float64 to int64 (that would lose information); convert explicitly with astype
```

## 비슷한 함수와의 차이

- [초기하 함수](/api/special/hyp/): K와 E는 Gauss 초기하 함수의 특별한 경우예요. $K(m) = \tfrac{\pi}{2}\,{}_2F_1(\tfrac12, \tfrac12; 1; m)$, $E(m) = \tfrac{\pi}{2}\,{}_2F_1(-\tfrac12, \tfrac12; 1; m)$. 값은 같지만 `ellipk`·`ellipe`가 더 빠르고, m → 1 근처에서도 정확도를 약속해요.

```python
>>> sd.special.hyp2f1(0.5, 0.5, 1.0, 0.5) * sd.pi / 2
1.8540746773013719
>>> sd.special.ellipk(0.5)
1.8540746773013719
```

- 불완전 타원적분: 적분의 위끝을 π/2 대신 임의의 각 φ로 둔 $F(\varphi \mid m)$, $E(\varphi \mid m)$은 stardust에 없어요. 이 페이지의 두 함수는 φ = π/2인 "완전한" 경우만 계산해요.

| 하고 싶은 일 | 쓸 것 |
|---|---|
| 진자의 주기, 제1종 적분 | `ellipk(m)` |
| 타원의 둘레, 제2종 적분 | `ellipe(m)` |
| 1 − m이 아주 작은 수로 주어질 때 | 위의 항등식으로 `ellipk(1 - 1/p) / sqrt(p)` |
| 같은 꼴의 더 일반적인 급수 | [`hyp2f1`](/api/special/hyp/) |

## scipy를 아는 분께

- 매개변수는 scipy와 같은 m(= k²)이에요. 특수값(`ellipk(1) = inf`, `m > 1`은 NaN, `ellipk(-inf) = 0`, `ellipe(-inf) = inf` 등)도 scipy와 비트까지 같아요. 그 밖의 값은 마지막 자리가 다를 수 있어요.
- `ellipkm1(p)`가 없어요. 1 − m을 직접 받는 함수 대신 위의 항등식 `ellipk(1 - 1/p) / sqrt(p)`를 쓰세요.
- 불완전 타원적분(`ellipkinc`, `ellipeinc`), Carlson 대칭형(`elliprf` 등), Jacobi 타원함수(`ellipj`)는 없어요.
- 복소수와 리스트는 받지 않아요(`TypeError`). `out=`은 keyword-only예요.
