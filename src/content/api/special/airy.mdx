## 한눈에 보기

Airy 함수 Ai와 Bi는 출렁이던 파동이 어느 경계를 넘으면서 사그라드는 모습을 나타내는 함수예요. x가 음수인 쪽에서는 물결처럼 출렁이고, x가 양수인 쪽으로 넘어가면 Ai는 아주 빠르게 0으로 줄어들고 Bi는 아주 빠르게 커져요. 그 경계(x = 0 근처)에서 무슨 일이 일어나는지를 가장 단순하게 담은 함수라서, 여러 분야에서 같은 모양으로 다시 나타나요.

- 광학: 무지개의 밝기. 무지개 가장자리 근처에서 빛의 세기가 줄어드는 모양이 Ai의 제곱으로 나타나요. Airy도 처음에 무지개를 설명하려고 이 함수를 만들었어요. 렌즈나 물결 아래로 빛이 모이는 밝은 선(집광선) 근처의 세기도 같은 꼴이에요.
- 양자역학: 고르게 미는 힘(중력, 균일한 전기장) 속에 있는 입자의 파동함수가 Ai예요. 또 입자가 고전적으로는 넘어갈 수 없는 경계(전환점) 근처에서 파동함수를 이어 붙일 때도 Airy 함수를 써요.
- 파동과 수학: 퍼지지 않고 휘어 나아가는 "Airy 빔", 차수가 큰 Bessel 함수의 근사, 경계층 문제처럼 해가 출렁임에서 지수적 감소로 바뀌는 곳마다 나와요.

수학적으로 Ai와 Bi는 미분방정식

$$y'' = x\,y$$

의 두 해예요. "곡률이 x에 비례한다"는 뜻이에요. x &lt; 0이면 y''와 y의 부호가 반대라서 해가 0 쪽으로 되돌아오며 출렁이고, x > 0이면 부호가 같아서 해가 한쪽으로 달아나거나(Bi) 0으로 붙어요(Ai). 적분으로 쓰면 이래요.

$$
\mathrm{Ai}(x) = \frac{1}{\pi}\int_0^\infty \cos\!\left(\frac{t^3}{3} + x t\right) dt,
\qquad
\mathrm{Bi}(x) = \frac{1}{\pi}\int_0^\infty \left[\exp\!\left(-\frac{t^3}{3} + x t\right) + \sin\!\left(\frac{t^3}{3} + x t\right)\right] dt
$$

Ai는 x가 커질 때 0으로 가는 해, Bi는 같은 방정식의 다른 해 가운데 x &lt; 0에서 Ai와 진폭이 같고 위상만 어긋난 해예요.

## 결과: 네 값을 담은 이름 있는 튜플

`airy`의 결과는 필드가 넷인 **이름 있는 튜플** `AiryResult`예요. 필드 이름의 `p`는 도함수를 뜻하는 프라임(′)이에요.

| 필드 | 값 | 뜻 |
|:---:|:---:|---|
| `ai` | Ai(x) | 첫째 해 |
| `aip` | Ai′(x) | Ai의 도함수 |
| `bi` | Bi(x) | 둘째 해 |
| `bip` | Bi′(x) | Bi의 도함수 |

이름으로 꺼내도 되고, 변수 넷에 한 번에 풀어 담아도 돼요. 순서는 언제나 `ai`, `aip`, `bi`, `bip`예요.

```python
>>> r = sd.special.airy(2.0)
>>> r.bi
3.298094999978215
>>> ai, aip, bi, bip = sd.special.airy(2.0)
>>> aip
-0.05309038443365365
```

배열을 넣으면 네 필드가 모두 입력과 같은 모양의 float64 배열이에요. Python 숫자를 넣으면 네 필드가 모두 Python `float`예요. 정수와 bool은 float64로 바꿔서 계산해요.

```python
>>> x = sd.asarray([-2.0, 0.0, 2.0])
>>> r = sd.special.airy(x)
>>> r.ai
array([0.22740742820168564,  0.3550280538878172, 0.03492413042327434], dtype=float64)
>>> r.bip.shape
(3,)
>>> type(sd.special.airy(1).ai)
<class 'float'>
```

네 값을 한 번에 돌려주는 이유는 미분방정식을 다룰 때 함수값과 도함수가 거의 언제나 함께 필요하기 때문이에요. 경계 조건을 맞추거나 두 해를 이어 붙일 때 y와 y′를 둘 다 써요. 따로 계산하는 것보다 한 번에 계산하는 편이 빠르기도 해요.

두 해와 도함수 사이에는 x와 상관없이 언제나 성립하는 관계가 있어요.

$$\mathrm{Ai}(x)\,\mathrm{Bi}'(x) - \mathrm{Ai}'(x)\,\mathrm{Bi}(x) = \frac{1}{\pi}$$

계산이 맞는지 확인하는 데 쓸 수 있어요.

```python
>>> x = sd.asarray([-7.0, -3.0, 0.5, 1.5])
>>> r = sd.special.airy(x)
>>> wr = r.ai * r.bip - r.aip * r.bi
>>> float(sd.max(sd.abs(wr - 1 / sd.pi))) < 1e-15
True
```

## x가 음수일 때: 출렁이는 파동

x가 음수인 쪽에서 Ai와 Bi는 끝없이 출렁여요. 왼쪽으로 갈수록 출렁임이 촘촘해지고(파장이 대략 $2\pi/\sqrt{|x|}$), 높이는 천천히 낮아져요(대략 $|x|^{-1/4}$에 비례).

```python
>>> sd.special.airy(sd.asarray([-1.0, -3.0, -5.0])).ai
array([ 0.5355608832923522, -0.3788142936776578,  0.3507610090241142], dtype=float64)
```

Ai가 0이 되는 곳(영점)은 모두 음수 쪽에 있어요. 첫 영점은 약 −2.33811이에요. 그 근처의 double을 넣으면 0에 아주 가까운 값이 나와요.

```python
>>> sd.special.airy(-2.338107410459767).ai
5.658759078729015e-17
```

이 값을 보고 "상대오차"를 따지면 곤란해요. 이 입력에서 Ai의 참값은 약 2.7 × 10⁻¹⁷이라 나온 값이 참값의 두 배쯤이거든요. 그런데 파동 전체의 높이(약 0.45)에 비하면 차이는 2.9 × 10⁻¹⁷, 높이의 약 6.5 × 10⁻¹⁷배밖에 안 돼요. 영점 근처에서는 값 자체가 0에 가까워서, 아주 작은 절대오차도 상대오차로는 엄청나게 커 보이는 거예요.

그래서 x &lt; 0에서는 파동의 높이, 곧 **포락선**을 기준으로 정확도를 약속해요. 포락선은 출렁이는 곡선을 위아래에서 감싸는 선이에요.

$$M(x) = \sqrt{\mathrm{Ai}(x)^2 + \mathrm{Bi}(x)^2}, \qquad N(x) = \sqrt{\mathrm{Ai}'(x)^2 + \mathrm{Bi}'(x)^2}$$

Ai와 Bi의 오차는 $10^{-14} \times M(x)$ 이하, Ai′와 Bi′의 오차는 $10^{-14} \times N(x)$ 이하예요. 말로 하면 "파동의 높이를 기준으로 앞 14자리쯤이 맞는다"는 뜻이에요. 이 약속은 $-10^{12} \le x < 0$에서 지켜져요. 정확도를 재는 방법은 [특수함수의 기본](/api/special/basics/)에서 더 자세히 설명해요.

### 아주 큰 음수

x가 $-10^{12}$보다 작으면 정확도가 조금씩 느슨해져요. 출렁임의 위상(지금 파동의 어느 지점에 있는지)이 대략 $\tfrac{2}{3}|x|^{3/2}$라는 엄청나게 큰 수가 되어서, 그 위상을 정확히 따라가기가 어려워지기 때문이에요. 포락선에 대한 오차는 $x = -10^{14}$에서 약 $10^{-12}$, $x = -10^{20}$에서 약 $2 \times 10^{-3}$까지 커져요.

다만 이 영역에서는 입력 자체가 더 큰 문제예요. float64의 x가 바로 옆의 표현 가능한 값으로 한 칸만 움직여도 위상은 $|x|^{3/2} \times 2^{-52}$쯤 움직여요. $x = -10^{12}$에서 이미 백 라디안이 넘어서, 옆 칸의 x에서 나오는 값은 전혀 다른 지점의 값이에요. x가 측정값처럼 반올림을 품고 있다면 이 영역의 결과는 위상에 관한 한 의미가 없어요. x가 정확히 그 double일 때만 결과가 뜻을 가져요.

```python
>>> sd.special.airy(-1e14).ai
-0.00017391172622898643
```

x가 $-10^{20}$보다 작으면 위상의 오차가 1000분의 1 라디안을 넘어서, 계산한 값이 파동의 어느 지점인지조차 믿을 수 없어요. 그래서 이곳에서는 네 값 모두 NaN을 돌려줘요. 에러는 나지 않아요.

```python
>>> sd.special.airy(-1e21)
AiryResult(ai=nan, aip=nan, bi=nan, bip=nan)
```

## x가 양수일 때: 줄어드는 Ai, 커지는 Bi

x가 양수인 쪽에서는 출렁임이 없어요. 큰 x에서 Ai와 Bi는 대략 이렇게 움직여요($\zeta = \tfrac{2}{3}x^{3/2}$).

$$\mathrm{Ai}(x) \approx \frac{e^{-\zeta}}{2\sqrt{\pi}\,x^{1/4}}, \qquad \mathrm{Bi}(x) \approx \frac{e^{\zeta}}{\sqrt{\pi}\,x^{1/4}}$$

지수 안에 $x^{3/2}$가 있어서 아주 빠르게 변해요. x = 100이면 Ai는 10⁻²⁹¹, Bi는 10²⁸⁸ 정도예요. 조금만 더 가면 float64가 나타낼 수 있는 범위를 넘어요.

```python
>>> r = sd.special.airy(sd.asarray([100.0, 105.0, 110.0]))
>>> r.ai
array([2.6344821520881846e-291,      2.70062041745e-313,
                           0.0], dtype=float64)
>>> r.bi
array([6.0412239966702e+288,                  inf,                  inf], dtype=float64)
```

- Bi는 x가 약 104.4를 넘으면 float64의 최댓값(약 1.8 × 10³⁰⁸)을 넘어서 `inf`가 돼요. Bi′는 그보다 조금 앞(약 104.2)에서 `inf`가 돼요.
- Ai는 x가 약 103.9를 넘으면 float64의 가장 작은 정규 수(약 2.2 × 10⁻³⁰⁸)보다 작아져요. 그 뒤로는 유효숫자가 점점 줄어드는 아주 작은 수(서브노멀)로 계속 나오다가, x가 약 107.5를 넘으면 `0.0`이 돼요. 음수인 Ai′는 0 대신 `-0.0`이 돼요.

어느 쪽도 에러는 나지 않아요. x ≥ 0에서는 네 값 모두 상대오차 10⁻¹⁴ 이하, 곧 앞 14자리쯤이 맞다고 약속해요(결과가 서브노멀일 때는 그 크기에 맞는 절대오차로 재요).

## 특수값

| x | `ai` | `aip` | `bi` | `bip` |
|:---:|:---:|:---:|:---:|:---:|
| `0.0` | 0.35503 | −0.25882 | 0.61493 | 0.44829 |
| `inf` | `0.0` | `-0.0` | `inf` | `inf` |
| `-inf` | `0.0` | `nan` | `0.0` | `nan` |
| `nan` | `nan` | `nan` | `nan` | `nan` |

- `inf`에서는 위의 극한을 그대로 따라요. Ai는 0으로, Bi는 무한대로 가요. Ai′는 음수 쪽에서 0으로 가므로 `-0.0`이에요.
- `-inf`에서 Ai와 Bi는 높이가 $|x|^{-1/4}$로 줄어들며 출렁이므로 극한이 0이에요. 하지만 도함수 Ai′, Bi′는 높이가 $|x|^{1/4}$로 커지면서 출렁여서 극한이 없어요. 그래서 NaN이에요.

```python
>>> sd.special.airy(sd.inf)
AiryResult(ai=0.0, aip=-0.0, bi=inf, bip=inf)
>>> sd.special.airy(-sd.inf)
AiryResult(ai=0.0, aip=nan, bi=0.0, bip=nan)
```

## 조심할 점

### 복소수와 리스트는 받지 않아요

`airy`는 실수만 받아요. 복소수를 넣으면 `TypeError`예요. 리스트도 받지 않으니 `sd.asarray`로 먼저 배열로 바꾸세요.

```python
>>> sd.special.airy(1 + 1j)
Traceback (most recent call last):
    ...
TypeError: airy(): not supported for complex128
>>> sd.special.airy([0.0, 1.0])
Traceback (most recent call last):
    ...
TypeError: airy(): 'x' must be an sd.ndarray or a bool, int, float or complex, not list
```

### `out=`이 없어요

다른 특수함수와 달리 `airy`에는 `out=`이 없어요. 결과가 네 개라서 출력 배열 하나를 받는 방식이 맞지 않기 때문이에요. `out=`을 넘기면 `TypeError`예요. 결과를 기존 배열에 담고 싶다면 계산한 뒤 슬라이스에 대입하세요(배열 영역의 [인덱싱](/api/array/indexing/) 참고).

```python
>>> buf = sd.zeros(3)
>>> buf[:] = sd.special.airy(sd.asarray([0.0, 1.0, 2.0])).ai
>>> buf
array([ 0.3550280538878172, 0.13529241631288147, 0.03492413042327434], dtype=float64)
```

### 영점 근처에서 상대오차로 비교하지 마세요

위에서 본 것처럼 x &lt; 0의 영점 근처에서는 아주 정확한 값도 상대오차로는 크게 틀려 보여요. 다른 프로그램의 결과와 비교하거나 테스트를 쓸 때는 $|a - b| \le \text{허용치} \times M(x)$처럼 포락선을 기준으로 비교하세요.

### 큰 x의 Bi는 금방 `inf`가 돼요

x가 약 104.4만 넘어도 Bi는 `inf`예요. Bi끼리 나누거나 Ai와 곱하는 계산을 해야 한다면, 위의 근사식을 써서 지수 부분 $e^{\pm\zeta}$를 따로 떼어 로그로 다루는 편이 안전해요. 예를 들어 Ai·Bi는 큰 x에서 대략 $1/(2\pi\sqrt{x})$이지만, 그대로 곱하면 `0.0 * inf`가 되어 NaN이 나와요.

```python
>>> r = sd.special.airy(110.0)
>>> r.ai * r.bi
nan
```

## 비슷한 함수와의 차이

Airy 함수는 차수가 1/3인 Bessel 함수로도 쓸 수 있어요. x > 0에서는 변형 Bessel 함수 K를, x &lt; 0에서는 Bessel 함수 J를 써요($\zeta = \tfrac{2}{3}|x|^{3/2}$).

$$\mathrm{Ai}(x) = \frac{1}{\pi}\sqrt{\frac{x}{3}}\,K_{1/3}(\zeta) \quad (x > 0)$$

```python
>>> x = 2.0
>>> zeta = 2 / 3 * x ** 1.5
>>> sd.special.kv(1 / 3, zeta) * (x / 3) ** 0.5 / sd.pi
0.03492413042327437
>>> sd.special.airy(x).ai
0.03492413042327434
```

마지막 몇 자리만 달라요. 그래도 Airy 함수가 필요하면 `airy`를 쓰세요. Bessel 함수로 쓴 식은 x = 0에서 `0 × inf` 꼴이 되어 값을 낼 수 없고, x의 부호에 따라 식을 바꿔야 하며, 계산도 여러 번 거쳐서 오차가 쌓여요.

| 하고 싶은 일 | 쓸 것 | 비고 |
|---|---|---|
| Ai, Bi와 도함수 | `airy` | 네 값을 한 번에. x의 부호와 상관없이 같은 함수 |
| 차수가 아무 실수인 J, Y | [`jv`, `yv`](/api/special/bessel-jy/) | x &lt; 0의 Airy와 같은 출렁임을 다른 차수로 |
| 차수가 아무 실수인 I, K | [`iv`, `kv`](/api/special/bessel-ik/) | x > 0의 Airy와 같은 지수적 증가·감소를 다른 차수로 |

## scipy를 아는 분께

- 결과가 평범한 튜플이 아니라 이름 있는 튜플 `AiryResult(ai, aip, bi, bip)`예요. `ai, aip, bi, bip = airy(x)`처럼 풀어 담는 코드는 그대로 동작해요. Python 숫자를 넣으면 numpy 스칼라가 아니라 Python `float`가 나와요.
- 복소수를 받지 않아요(`TypeError`). scipy의 `airy`는 복소수를 받아요.
- `out=`이 없어요. scipy처럼 출력 배열 네 개를 튜플로 넘길 수 없어요.
- 지수로 스케일한 `airye`, 영점을 구하는 `ai_zeros`·`bi_zeros`, 적분 `itairy`는 없어요.
- `airy(inf)`는 (0, −0, inf, inf)예요. scipy는 네 값 모두 NaN이에요. `airy(-inf)`도 scipy는 모두 NaN이고, stardust는 (0, NaN, 0, NaN)이에요.
- x가 약 103을 넘는 곳에서 scipy는 Ai를 0, Bi를 NaN으로 내요(scipy 1.18.1의 `airy(104.0)`은 (0, 0, NaN, NaN)). stardust는 Ai를 서브노멀까지 참값으로, Bi를 넘치기 전까지 유한한 값으로, 넘친 뒤에는 `inf`로 내요.
- x가 큰 음수인 곳에서 scipy는 정확도를 잃다가 NaN을 내요. 예를 들어 `airy(-1e6)`의 scipy 값은 앞 6자리 정도만 맞고, `airy(-2e6)`은 NaN이에요. stardust는 $-10^{12}$까지 포락선 기준 정확도를 지키고, $-10^{20}$까지 값을 내요. 그보다 작은 x에서는 stardust도 NaN이에요.
