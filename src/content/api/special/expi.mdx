---
title: 지수적분
names: [expi, expn]
group: 제타와 지수적분
order: 2
signatures:
  - "sd.special.expi(x, /, *, out=None)"
  - "sd.special.expn(n, x, /, *, out=None)"
summary: 지수함수를 t로 나눈 곡선의 넓이인 지수적분 Ei(x)와, 그 꼬리 쪽을 일반화한 Eₙ(x)예요. 지하수·열전도·복사 전달의 공식과 로그 적분 li(x)에 나와요.
params:
  - name: x
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: expi는 모든 실수, expn은 0 이상에서 값이 있어요(음수면 NaN).
  - name: n
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: expn의 차수. 0 이상의 정수 값이어야 해요(정수 dtype도, 2.0 같은 실수도 돼요). 음수이거나 정수가 아니면 NaN이에요.
  - name: out
    type: ndarray 또는 None
    kind: keyword-only
    desc: 결과를 적어 넣을 배열. None이면 새 배열을 만들어요.
returns:
  type: ndarray 또는 Python float
  desc: 인자를 브로드캐스팅한 모양의 float64 배열. 인자가 모두 Python 숫자면 Python float예요.
raises:
  - type: TypeError
    desc: 복소수를 넣었을 때, 배열도 숫자도 아닌 것(리스트 등)을 넣었을 때, 인자 개수가 맞지 않을 때, out의 dtype이 float64 결과를 담을 수 없을 때.
  - type: ValueError
    desc: expn의 두 인자나 out의 모양이 브로드캐스팅으로 맞지 않을 때.
  - type: OverflowError
    desc: int64 범위를 벗어난 Python 정수를 그대로 넣었을 때.
seeAlso: [zeta, gammainc, gamma, basics]

## 한눈에 보기

**지수적분** Ei(x)는 곡선 $e^t/t$ 아래의 넓이를 −∞부터 x까지 잰 값이에요. $e^t/t$는 손으로 적분할 수 있는 식이 없어서, 이 넓이에 따로 이름을 붙여 쓰는 함수예요. `expi(x)`가 Ei(x)를 계산해요.

```python
>>> import stardust as sd
>>> sd.special.expi(1.0)
1.8951178163559366
>>> sd.special.expi(sd.asarray([-2.0, -1.0, 0.5, 1.0, 2.0]))
array([-0.048900510708061125,  -0.21938393439552029,   0.45421990486317354,
          1.8951178163559366,      4.95423435600189], dtype=float64)
```

`expn(n, x)`는 **일반화 지수적분** Eₙ(x)예요. 물리 공식에 자주 나오는 꼴 $e^{-xt}/t^n$을 1부터 ∞까지 적분한 값이고, n = 1이면 Ei와 부호와 방향만 다른 같은 함수예요.

```python
>>> sd.special.expn(1, 1.0)
0.21938393439552029
>>> sd.special.expn(sd.asarray([0, 1, 2, 3]), 1.0)
array([0.36787944117144233, 0.21938393439552029, 0.14849550677592202,
       0.10969196719776013], dtype=float64)
```

### 어디에 쓰나요

- **지하수와 석유 공학**: 우물에서 물을 퍼 올릴 때 주변 지하수면이 얼마나 내려가는지 나타내는 테이스(Theis) 공식의 "우물 함수"가 E₁(u)예요. 유정의 압력 변화도 같은 식을 써요.
- **열전도**: 무한히 긴 선 모양 열원(전열선, 땅속 배관) 둘레의 온도 변화가 E₁으로 쓰여요.
- **복사 전달**: 별의 대기나 두꺼운 기체층을 빛이 지나가는 문제에서 E₁, E₂, E₃이 끊임없이 나와요.
- **소수의 개수**: x 이하의 소수 개수는 로그 적분 li(x) = Ei(ln x)로 아주 잘 근사돼요.
- **중성자 수송, 양자화학 적분**처럼 $e^{-t}/t$ 꼴이 나오는 계산 전반에 쓰여요.

### 정의

$$\mathrm{Ei}(x) = \int_{-\infty}^{x} \frac{e^{t}}{t}\, dt, \qquad E_n(x) = \int_{1}^{\infty} \frac{e^{-xt}}{t^n}\, dt \quad (x \ge 0)$$

x가 0보다 크면 Ei의 적분은 t = 0을 지나는데, 거기서 $e^t/t$가 왼쪽은 −∞, 오른쪽은 +∞로 치솟아요. 이때는 0 둘레를 좌우 같은 폭으로 잘라 내고 잰 값(코시 주값)을 써요. 좌우의 무한대가 서로 상쇄되어 유한한 값이 남아요.

n = 1이면 두 함수는 이렇게 이어져요.

$$E_1(x) = -\mathrm{Ei}(-x) \qquad (x > 0)$$

```python
>>> x = sd.asarray([0.5, 1.0, 3.0])
>>> sd.special.expn(1, x)
array([  0.5597735947761607,  0.21938393439552029, 0.013048381094197039], dtype=float64)
>>> -sd.special.expi(-x)
array([   0.559773594776161,  0.21938393439552029, 0.013048381094197035], dtype=float64)
```

## expi: 극점과 0점

### 0 근처

x가 0에 가까우면 Ei(x)는 $\gamma + \ln|x|$ 처럼 행동해요(γ ≈ 0.5772는 오일러–마스케로니 상수). 그래서 0에서는 양쪽 모두 −∞로 떨어져요.

```python
>>> sd.special.expi(sd.asarray([1e-10, -1e-10]))
array([-22.448635264938925, -22.448635265138922], dtype=float64)
>>> 0.5772156649015329 + sd.log(1e-10)
-22.448635265038924
```

### 양의 0점

Ei는 x₀ ≈ 0.37250741078136663에서 0을 지나요. 0점 근처는 값이 아주 작아서 상대오차를 지키기 어려운 곳이지만, `expi`는 이곳에서도 앞자리가 맞는 값을 내요. 아래의 첫 결과는 float64로 가장 가까운 x₀에서의 참값(−5.1197 × 10⁻¹⁷)과 같아요.

```python
>>> x0 = 0.37250741078136663
>>> sd.special.expi(x0)
-5.119698936555684e-17
>>> sd.special.expi(sd.asarray([0.3725, 0.3726]))
array([-2.8874183188745963e-05,  0.00036071944315775785], dtype=float64)
```

### 큰 x와 아주 작은 x

x가 크면 Ei(x)는 대략 $e^x/x$예요. x로 나눈 만큼 `exp`보다 조금 늦게 넘쳐요. `exp(710)`은 이미 `inf`지만 `expi(710)`은 유한한 값이고, 약 716.4를 넘어야 `inf`가 돼요.

```python
>>> sd.special.expi(sd.asarray([700.0, 710.0, 716.0, 717.0]))
array([1.4509787360525608e+301, 3.1509156882062018e+305,
       1.2605029106040893e+308,                     inf], dtype=float64)
>>> sd.exp(710.0)
inf
```

x가 음수로 크면 값은 $e^x/x$처럼 0에 가까워지는 음수예요. 너무 작아서 float64로 담을 수 없으면 `-0.0`이에요.

```python
>>> sd.special.expi(-700.0)
-1.4065187662340328e-307
>>> sd.special.expi(-750.0)
-0.0
```

### 로그 적분과 소수의 개수

로그 적분 $\mathrm{li}(x) = \int_0^x dt/\ln t$는 `expi(log(x))`예요. x 이하의 소수 개수를 아주 잘 근사해요. 100만 이하의 소수는 78,498개인데, li(10⁶)은 약 78,628이에요. 2부터 적분하는 판 Li(x) = li(x) − li(2)도 흔히 써요.

```python
>>> sd.special.expi(sd.log(sd.asarray([1e3, 1e6, 1e9])))
array([177.60965799015221,  78627.54915946216,  50849234.95700176], dtype=float64)
>>> sd.special.expi(sd.log(2.0))
1.0451637801174927
```

## expn: 일반화 지수적분

### 차수 n에 따라

n = 0이면 적분을 직접 할 수 있어서 $E_0(x) = e^{-x}/x$예요. n이 1씩 커질 때마다 아래 점화식으로 이어져요.

$$n\,E_{n+1}(x) = e^{-x} - x\,E_n(x)$$

```python
>>> sd.special.expn(0, sd.asarray([0.5, 1.0, 2.0]))
array([ 1.2130613194252668, 0.36787944117144233, 0.06766764161830635], dtype=float64)
>>> x = 1.5
>>> n = 3
>>> n * sd.special.expn(n + 1, x)
0.1380209248928984
>>> sd.exp(-x) - x * sd.special.expn(n, x)
0.1380209248928984
```

### x = 0에서

x = 0이면 적분이 $\int_1^\infty t^{-n} dt$라서 n ≥ 2이면 1/(n − 1)이고, n = 0, 1이면 무한대예요.

```python
>>> sd.special.expn(sd.asarray([2, 3, 4, 10]), 0.0)
array([               1.0,                0.5, 0.3333333333333333,
       0.1111111111111111], dtype=float64)
>>> sd.special.expn(sd.asarray([0, 1]), 0.0)
array([inf, inf], dtype=float64)
```

### n은 0 이상의 정수만

n에는 정수 dtype도, `2.0`처럼 정수 값을 가진 실수도 넣을 수 있어요. 하지만 `1.5`처럼 정수가 아니거나, 음수이거나, `inf`·NaN이면 NaN이에요. 값을 몰래 잘라서(1.5를 1로) 계산하지 않아요.

```python
>>> sd.special.expn(2.0, 1.0)
0.14849550677592202
>>> sd.special.expn(sd.asarray([1.5, -1.0, sd.inf, sd.nan]), 1.0)
array([nan, nan, nan, nan], dtype=float64)
```

n이 아주 커도 계산해요. n이 크면 Eₙ(x)는 대략 $e^{-x}/(x + n)$이에요.

```python
>>> sd.special.expn(2**31, 1.0)
1.7130721414994557e-10
```

### x가 크면

x가 커지면 Eₙ(x)는 $e^{-x}/x$처럼 0으로 내려가요. 결과가 float64의 정규 수 범위(약 2.2 × 10⁻³⁰⁸)보다 작아져도 0으로 뭉개지 않고 서브노멀 값을 내다가, 그보다도 작아지면 0이에요. x = ∞이면 0, x가 음수나 NaN이면 NaN이에요.

```python
>>> sd.special.expn(1, sd.asarray([700.0, 712.0, 745.0, 746.0]))
array([1.406518766234033e-307,     8.49650284055e-313,
                          0.0,                    0.0], dtype=float64)
>>> sd.special.expn(1, sd.asarray([-1.0, sd.inf, sd.nan]))
array([nan, 0.0, nan], dtype=float64)
```

### 테이스 우물 함수

우물에서 일정한 양 Q를 퍼 올릴 때, 거리 r, 시간 t에서 지하수면이 내려간 깊이는 $s = \frac{Q}{4\pi T} W(u)$, $u = \frac{r^2 S}{4 T t}$예요(T, S는 지층의 성질). 우물 함수 W(u)가 바로 E₁(u)예요. u가 작으면(오래 퍼 올렸거나 우물에 가까우면) W(u) ≈ −γ − ln u라는 근사를 흔히 쓰는데, u가 커지면 맞지 않아요.

```python
>>> u = sd.asarray([1e-4, 1e-2, 1.0])
>>> sd.special.expn(1, u)
array([  8.633224704574703,   4.037929576538114, 0.21938393439552029], dtype=float64)
>>> -0.5772156649015329 - sd.log(u)
array([  8.633124707074648,   4.027954521086558, -0.5772156649015329], dtype=float64)
```

## 특수값

| 입력 | 값 | 이유 |
|---|:---:|---|
| `expi(0.0)`, `expi(-0.0)` | `-inf` | 0 근처에서 γ + ln\|x\|처럼 떨어져요 |
| `expi(inf)` | `inf` | eˣ/x처럼 커져요 |
| `expi(-inf)` | `-0.0` | 음수 쪽에서 0에 다가가요 |
| `expi(x)`, x가 약 716.4보다 큼 | `inf` | float64의 범위를 넘어요 |
| `expn(0, 0)`, `expn(1, 0)` | `inf` | 적분이 발산해요 |
| `expn(n, 0)`, n ≥ 2 | 1/(n − 1) | |
| `expn(n, inf)` | 0 | |
| `expn(n, x)`, x가 음수 | NaN | 정의되지 않아요 |
| `expn(n, x)`, n이 음수·정수 아님·inf | NaN | n은 0 이상의 정수만 받아요 |
| NaN이 있으면 | NaN | |

```python
>>> sd.special.expi(sd.asarray([0.0, -0.0, sd.inf, -sd.inf, sd.nan]))
array([-inf, -inf,  inf, -0.0,  nan], dtype=float64)
```

## 정확도

- `expi`와 `expn`은 **정의역 전체**에서 상대오차가 1e-14 이하예요. 상대오차 1e-14는 결과의 **앞자리 약 14자리가 참값과 같다**는 뜻이에요. `expi`의 0점 x₀ ≈ 0.3725 근처처럼 값이 0에 가까운 곳도 상대오차로 약속해요. 실제로 잰 최대 오차는 `expi` 약 5 [ULP](/api/special/basics/), `expn` 약 6 ULP예요.
- 결과가 서브노멀 값이면 상대오차 대신 아주 작은 절대오차로 약속해요.

같은 입력이면 배열 안의 위치나 스레드 수와 상관없이 언제나 같은 비트가 나와요. 자세한 내용은 [특수함수의 기본](/api/special/basics/)에 있어요.

## 입력과 결과의 종류

결과는 언제나 **float64**예요. bool·정수를 넣어도 실수로 바꿔서 계산해요. 인자가 모두 Python 숫자면 결과도 Python `float`예요. `expn`의 두 인자는 [브로드캐스팅](/api/array/broadcasting/) 규칙으로 맞춰서, 여러 n과 여러 x의 표를 한 번에 만들 수 있어요.

```python
>>> sd.special.expi(2)
4.95423435600189
>>> sd.special.expn(sd.asarray([[1], [2]]), sd.asarray([0.5, 1.0, 2.0]))
array([[ 0.5597735947761607, 0.21938393439552029, 0.04890051070806112],
       [0.32664386232455295, 0.14849550677592202, 0.03753426182049045]], dtype=float64)
```

`out=`에 배열을 주면 그 배열에 결과를 적고 그 배열을 돌려줘요. 결과가 float64라서 정수 배열에는 담을 수 없어요. 규칙은 [사칙연산의 `out`](/api/array/arithmetic/)과 같아요.

```python
>>> buf = sd.zeros(3)
>>> sd.special.expi(sd.asarray([1.0, 2.0, 3.0]), out=buf) is buf
True
```

에러는 값이 아니라 **인자의 종류와 모양**이 맞지 않을 때만 나요. 복소수와 리스트는 받지 않아요. 리스트는 먼저 [`asarray`](/api/array/asarray/)로 바꾸세요.

```python
>>> sd.special.expi(sd.asarray([1+0j]))
Traceback (most recent call last):
    ...
TypeError: expi(): not supported for complex128
>>> sd.special.expi([1.0])
Traceback (most recent call last):
    ...
TypeError: expi(): 'x' must be an sd.ndarray or a bool, int, float or complex, not list
>>> sd.special.expn(sd.asarray([1, 2]), sd.asarray([1.0, 2.0, 3.0]))
Traceback (most recent call last):
    ...
ValueError: expn(): shapes could not be broadcast together: (2,) (3,)
```

## 조심할 점

- **`expi(x)`와 `expn(1, x)`는 부호와 방향이 반대예요.** E₁(x) = −Ei(−x)예요. 공식에 "E₁"이 있으면 `expn(1, x)`를 그대로 쓰는 편이 헷갈리지 않아요.
- **`expn`의 인자 순서는 (n, x)예요.** 차수가 먼저예요.
- **n은 0 이상의 정수만** 받아요. `1.5`를 넣으면 1로 잘리지 않고 NaN이에요.
- **0에서 극점이 있어요.** `expi(0)`은 `-inf`, `expn(0, 0)`과 `expn(1, 0)`은 `inf`예요.
- **값 때문에 에러가 나지 않아요.** 음수 x의 `expn`, 잘못된 n, NaN은 모두 조용히 NaN이 되니, 필요하면 `sd.isnan`으로 확인하세요.

## 비슷한 함수와의 차이

| 헷갈리는 것 | 차이 |
|---|---|
| `expi(x)`와 `expn(1, x)` | E₁(x) = −Ei(−x)예요. `expi`는 모든 실수, `expn`은 x ≥ 0에서 정의돼요. |
| `expn(0, x)`와 `sd.exp(-x) / x` | 같은 값이에요. |
| `expi`와 [`exp`](/api/array/exp-log/) | `exp`는 지수함수 자체, `expi`는 지수함수를 t로 나눈 곡선의 넓이예요. 큰 x에서 `expi`가 조금 늦게 넘쳐요. |
| `expn`과 [gammainc](/api/special/gammainc/) | 둘 다 $e^{-t}$가 들어간 적분이지만, 불완전 감마 함수는 전체 넓이에 대한 비율(0과 1 사이)이에요. |

## scipy를 아는 분께

- 이름과 인자 순서는 `scipy.special.expi`, `expn`과 같아요. ±0, ±inf, NaN의 결과도 같아요.
- **`expn`의 n이 정수가 아니면 NaN이에요.** scipy는 경고를 내고 n을 잘라서 계산해요(`expn(1.5, 1.0)`이 `expn(1, 1.0)`과 같은 값). `expn(inf, 1.0)`도 scipy는 `1.7e-10`, 여기서는 NaN이에요.
- `expn(2**31, 1.0)`은 `1.713e-10`이에요(scipy NaN).
- 큰 x에서 넘치거나 0이 되는 곳이 달라요. `expi(710)`은 `3.15e305`(scipy `inf`), `expn(1, 712)`는 `8.5e-313`(scipy `0.0`)이에요.
- `expi`의 0점 근처에서 scipy는 부호까지 틀릴 수 있어요. `expi(0.37250741078136663)`의 참값은 −5.12e-17인데, 여기서는 `-5.119698936555684e-17`, scipy는 `1.017e-17`이에요.
- 그 밖의 값은 scipy와 마지막 몇 자리가 다를 수 있어요.
- 리스트나 numpy 배열은 받지 않고, `out`은 keyword-only예요. 경고를 내지 않아요.
