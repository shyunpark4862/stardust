## 한눈에 보기

**비중심 t 분포**(noncentral t distribution)는 "실제로 차이가 있을 때 t 통계량이 따르는 분포"예요.

t 검정을 떠올려 볼게요. 표본 평균이 기준값에서 얼마나 떨어졌는지를 표준오차로 나눈 값이 t 통계량이에요. 실제 평균이 기준값과 같으면(차이가 없으면) 이 통계량은 보통의 t 분포인 **중심** t 분포를 따라요. 실제 평균이 기준값과 다르면 통계량이 그 방향으로 밀려나는데, 그때의 분포가 비중심 t 분포예요. 얼마나 밀려나는지를 나타내는 숫자가 **비중심 모수** $\delta$예요. 카이제곱·F와 달리 $\delta$에는 부호가 있어서, 음수면 왼쪽으로 밀려나요.

이 페이지의 세 함수는 그 분포의 확률을 계산해요.

| 함수 | 돌려주는 것 |
|---|---|
| `nctdtr(df, nc, t)` | 아래꼬리 확률 $P(T \le t)$ (누적분포함수) |
| `nctdtrc(df, nc, t)` | 위꼬리 확률 $P(T > t)$ |
| `nctdtrit(df, nc, p)` | `nctdtr(df, nc, t) = p`가 되는 $t$ (아래꼬리의 역함수) |

```python
>>> import stardust as sd
>>> sd.special.nctdtr(10, 2, 1)
0.1585150595377117
>>> sd.special.nctdtrc(10, 2, 1)
0.8414849404622883
>>> sd.special.nctdtrit(10, 2, 0.5)
2.0536911511184894
```

자유도 10, $\delta = 2$인 분포에서 값이 1 이하일 확률은 약 16%예요. 분포가 오른쪽(2 근처)으로 밀려 있어서 1 이하는 드물어요. 확률 0.5를 주면 중앙값 2.05가 나와요.

<Callout title="경계값 t가 맨 뒤예요">

세 함수 모두 **분포의 모수(`df`, `nc`)가 앞, 경계값(`t` 또는 `p`)이 맨 뒤**예요. 이 순서는 scipy의 `nctdtr`, `nctdtrit`와 같아요. 다만 같은 비중심 함수인 [`chndtr`](/api/special/chndtr/)는 scipy가 `chndtr(x, df, nc)`로 경계값을 맨 앞에 두고, stardust는 맨 뒤에 둬요. stardust 안에서는 비중심 함수 모두 경계값이 맨 뒤라고 기억하면 돼요.

## 어디에 쓰나요

가장 흔한 쓰임은 **t 검정의 검정력과 표본 크기 계산**이에요. 효과가 없을 때의 분포(중심 t)로 "유의하다"의 기준값을 정하고, 효과가 있을 때의 분포(비중심 t)가 그 기준값을 넘을 확률을 구하면 검정력이 돼요.

- 실험 설계: "두 집단의 평균 차이가 표준편차의 절반쯤이라면, 집단마다 몇 명을 모아야 80% 확률로 차이를 잡아낼까?" 임상시험, 심리학 실험, A/B 테스트에서 매번 하는 계산이에요.
- 효과 크기의 신뢰구간: 관측한 t 값으로 효과 크기(Cohen의 $d$)의 신뢰구간을 구할 때 비중심 t 분포를 거꾸로 풀어요.
- 품질 관리: 공정 능력 지수의 신뢰한계, 계량형 합격 판정 샘플링, 허용 구간(tolerance interval)의 계수가 비중심 t 분포에서 나와요.
- 금융: 수익률이 정규분포를 따른다고 볼 때, 표본으로 잰 샤프 비율에 $\sqrt{n}$을 곱한 값이 비중심 t 분포를 따라요. 샤프 비율이 우연인지 따질 때 써요.

## 정의와 모양

$Z$가 표준정규분포를, $V$가 자유도 $\nu$인 카이제곱 분포를 따르고 서로 독립일 때

$$T = \frac{Z + \delta}{\sqrt{V/\nu}}$$

가 자유도 $\nu$, 비중심 모수 $\delta$인 비중심 t 분포를 따라요. $\delta = 0$이면 보통의 t 분포예요. 누적분포함수는 $V$에 대해 평균한 꼴로 쓸 수 있어요($\Phi$는 표준정규분포의 누적분포 [`ndtr`](/api/special/ndtr/), $f_\nu$는 카이제곱 분포의 밀도예요).

$$\texttt{nctdtr}(\nu, \delta, t) = \int_0^\infty \Phi\!\left(t\sqrt{v/\nu} - \delta\right) f_\nu(v)\, dv$$

아래 그래프는 자유도 10에서 $\delta$만 바꾼 밀도(값이 그 근처에 있을 가능성)예요. $\delta$가 커지면 봉우리가 오른쪽으로 옮겨 갈 뿐 아니라 오른쪽 꼬리가 길어지면서 비대칭이 돼요. 분모 $\sqrt{V/\nu}$가 작게 뽑힐 때 큰 값이 나오기 때문이에요. 그래서 중앙값과 평균이 $\delta$보다 조금 커요.

$\delta = 0$일 때는 중심 t 분포 [`stdtr`](/api/special/stdtr/), [`stdtrit`](/api/special/stdtr/)와 마지막 비트까지 같아요.

```python
>>> sd.special.nctdtr(10, 0, 1.5) == sd.special.stdtr(10, 1.5)
True
>>> sd.special.nctdtrit(10, 0, 0.9) == sd.special.stdtrit(10, 0.9)
True
```

### 부호를 뒤집으면 꼬리가 바뀌어요

$\delta$와 $t$의 부호를 함께 뒤집으면 분포를 좌우로 뒤집은 것이라서, 아래꼬리와 위꼬리가 서로 바뀌어요.

$$\texttt{nctdtrc}(\nu, \delta, t) = \texttt{nctdtr}(\nu, -\delta, -t)$$

```python
>>> sd.special.nctdtrc(10, 1.5, 2)
0.3408459275578092
>>> sd.special.nctdtr(10, -1.5, -2)
0.3408459275578092
```

$t = 0$에서는 자유도와 상관없이 $\Phi(-\delta)$예요. 위 식의 $\Phi(t\sqrt{v/\nu} - \delta)$가 $v$와 상관없이 $\Phi(-\delta)$가 되기 때문이에요.

```python
>>> sd.special.nctdtr(10, 2, 0)
0.022750131948179212
>>> sd.special.ndtr(-2.0)
0.022750131948179212
```

## 세 함수: 아래꼬리, 위꼬리, 역함수

`nctdtr`과 `nctdtrc`은 서로 보수라서 수학적으로 더하면 1이에요. `nctdtrit`는 `nctdtr`을 거꾸로 풀어요. 중심 t의 [`stdtrit`](/api/special/stdtr/)과 같은 방향(아래꼬리)이에요.

```python
>>> t975 = sd.special.nctdtrit(10, 2, 0.975)
>>> t975
4.957835626374016
>>> sd.special.nctdtr(10, 2, t975)
0.975
```

"자유도 10, $\delta = 2$인 분포에서 값의 97.5%가 약 4.96 아래에 있다"는 뜻이에요.

## 검정력과 표본 크기 계산하기

### 한 표본 t 검정(대응 표본 포함)

어떤 처치 전후의 차이를 사람 $n$명에게서 재서, 평균 차이가 0인지 양측 유의수준 5%로 검정한다고 해 볼게요. 실제 평균 차이가 표준편차의 0.5배일 때(효과 크기 $d = 0.5$)의 검정력을 구해요.

이때 t 통계량은 자유도 $n - 1$, 비중심 모수

$$\delta = d\sqrt{n}$$

인 비중심 t 분포를 따라요. **효과 크기 $d$를 그대로 넣는 것이 아니라 $\sqrt{n}$을 곱해야** 해요. 표본이 많을수록 평균이 정밀해져서 같은 차이도 더 크게 보이기 때문이에요.

양측 검정은 통계량이 기준값 $c$보다 크거나 $-c$보다 작을 때 "유의하다"고 판단해요. 그래서 검정력은 두 꼬리를 더한 값이에요.

$$\text{검정력} = \texttt{nctdtrc}(\nu, \delta, c) + \texttt{nctdtr}(\nu, \delta, -c), \qquad c = \texttt{stdtrit}(\nu, 0.975)$$

```python
>>> n = 20
>>> c = sd.special.stdtrit(n - 1, 0.975)
>>> round(c, 4)
2.093
>>> delta = 0.5 * n ** 0.5
>>> power = sd.special.nctdtrc(n - 1, delta, c) + sd.special.nctdtr(n - 1, delta, -c)
>>> round(power, 4)
0.5645
```

20명으로는 검정력이 56% 정도예요. 80%가 되는 사람 수는 여러 $n$을 배열로 한꺼번에 계산해서 찾아요. 배열에서 검정력이 처음으로 0.8 이상이 되는 자리는 [`sd.argmax`](/api/array/argmin/)가 찾아 줘요.

```python
>>> n = sd.arange(5, 200)
>>> df = n - 1
>>> c = sd.special.stdtrit(df, 0.975)
>>> delta = 0.5 * sd.sqrt(n)
>>> power = sd.special.nctdtrc(df, delta, c) + sd.special.nctdtr(df, delta, -c)
>>> i = sd.argmax(power >= 0.8)
>>> int(n[i])
34
>>> round(float(power[i]), 4)
0.8078
```

34명이 필요해요. 아래 그래프는 효과 크기 $d$에 따라 이 곡선이 어떻게 바뀌는지 보여 줘요.

### 두 독립 표본 t 검정과 단측 검정

집단마다 $n$명씩 두 집단을 비교할 때는 자유도가 $2n - 2$, 비중심 모수가 $\delta = d\sqrt{n/2}$로 바뀌어요. 나머지는 같아요.

```python
>>> n = 64
>>> df = 2 * n - 2
>>> c = sd.special.stdtrit(df, 0.975)
>>> delta = 0.5 * (n / 2) ** 0.5
>>> round(sd.special.nctdtrc(df, delta, c) + sd.special.nctdtr(df, delta, -c), 4)
0.8015
```

효과 크기 0.5를 80% 검정력으로 잡으려면 집단마다 64명이 필요해요.

단측 검정("커졌는가"만 묻는 검정)이면 기준값을 위꼬리 5%로 정하고 한쪽 꼬리만 계산해요.

```python
>>> c1 = sd.special.stdtrit(df, 0.95)
>>> round(sd.special.nctdtrc(df, delta, c1), 4)
0.8787
```

## 작은 꼬리 확률은 nctdtrc로

위꼬리 확률이 작을 때 `1 - nctdtr(...)`로 계산하면 1에 가까운 수끼리 빼느라 앞자리가 망가져요. `nctdtrc`은 1에서 빼지 않고 위꼬리를 직접 계산해요.

```python
>>> sd.special.nctdtrc(10, 2, 100)
3.179712046646591e-14
>>> 1 - sd.special.nctdtr(10, 2, 100)
3.175237850427948e-14
```

참값은 3.179712046646591e-14예요. 빼기로 구한 값은 넷째 자리부터 틀렸어요. 확률이 더 작아지면 아예 0이 돼요. $\delta$와 반대쪽 꼬리(여기서는 아주 작은 $t$)도 `nctdtr`이 직접 계산하므로 정확해요.

```python
>>> sd.special.nctdtr(10, 2, -40)
5.732702898297934e-16
```

## 배열, 브로드캐스팅, `out=`

세 인자는 배열이든 Python 숫자든 섞어 쓸 수 있고, 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 정수와 bool은 float64로 바꿔 계산하고, 결과는 언제나 float64예요. 인자가 모두 Python 숫자면 결과는 Python `float`예요.

```python
>>> sd.special.nctdtrc(10, 2, sd.asarray([1, 2, 3]))
array([ 0.8414849404622883,  0.5190268471820928, 0.22082800102979128], dtype=float64)
```

`out=`에 float64 배열을 주면 그 배열에 결과를 써요. 규칙은 원소별 함수의 `out=`과 같아요([사칙연산](/api/array/arithmetic/) 참고).

```python
>>> buf = sd.zeros(3)
>>> r = sd.special.nctdtr(10, sd.asarray([0.0, 1.0, 2.0]), 1, out=buf)
>>> r is buf
True
```

## 특수값과 정의역

값 때문에 에러를 내지 않아요. 정의역 밖이면 NaN을, 끝점에서는 극한값을 돌려줘요.

| 입력 | 결과 | 뜻 |
|---|---|---|
| `nc = 0` | `stdtr`, `stdtrit`와 비트까지 같음 | 중심 t 분포 |
| `df = inf` | `ndtr(t - nc)` | 자유도가 무한하면 분모가 1로 고정돼서 정규분포를 옮긴 것이 돼요 |
| `t = 0` | `ndtr(-nc)` | |
| `t = inf`, `t = -inf` | `nctdtr` 1, 0 | |
| `nc = inf`, `nc = -inf` | `nctdtr` 0, 1 | 분포가 한쪽 끝으로 밀려나요. `t`도 같은 부호의 inf이면 NaN |
| `nctdtrit`의 `p = 0`, `p = 1` | -inf, inf | 정의역의 두 끝 |
| `nctdtrit`의 `p`가 0보다 크고 2.2e-308보다 작음(서브노멀), `nc ≠ 0` | NaN | 이렇게 작은 확률에서는 근을 믿을 만하게 구할 수 없어요 |
| `df`가 아주 작음(2⁻⁷¹, 약 4.2e-22 아래) | `nctdtr`은 `ndtr(-nc)`, `nctdtrc`은 `ndtr(nc)` | 분모가 거의 언제나 아주 커서 분포가 `t`에 거의 상관없어져요. 자유도에 비해 `ndtr(±nc)`의 작은 쪽이 아주 작으면 이 극한을 쓰지 않고 계산해요. `nctdtrit`은 이 극한에서 ±inf |
| `df ≤ 0` | NaN | 정의역 밖 |
| `p < 0` 또는 `p > 1` | NaN | 확률이 아니에요 |
| 인자에 NaN | NaN | |

```python
>>> sd.special.nctdtr(sd.inf, 1, 2)
0.8413447460685429
>>> sd.special.ndtr(1.0)
0.8413447460685429
>>> sd.special.nctdtr(10, sd.inf, 2)
0.0
>>> sd.special.nctdtr(1e-25, 1.5, 3.0), sd.special.ndtr(-1.5)
(0.06680720126885807, 0.06680720126885807)
>>> sd.special.nctdtr(0, 2, 1)
nan
>>> sd.special.nctdtrit(10, 2, 0.0)
-inf
```

## 정확도

**보장 영역**은 자유도 0.1–10⁵, $|\delta| \le 100$이고, 확률은 1e-300까지예요. 이 안에서 약속하는 정확도는 이래요.

- `nctdtr`, `nctdtrc`: 참값 대비 상대오차 1e-14 이하. 결과의 앞자리 14자리 정도가 맞는다는 뜻이에요. 작은 꼬리 확률도 상대오차로 재므로 앞자리가 그만큼 맞아요.
- `nctdtrit`: 결과 $t$의 상대오차가 $10^{-14} \times \max(1, \kappa)$ 이하예요. $\kappa$는 "확률 $p$가 아주 조금 바뀔 때 $t$가 몇 배나 크게 바뀌는가"를 나타내는 수(조건수)예요. 입력 $p$ 자체가 마지막 자리에 반올림 오차를 품고 있으니 $\kappa$가 큰 곳에서는 그만큼은 어쩔 수 없어요.

잰 최대 오차는 `nctdtr` 15 ULP, `nctdtrc` 10 ULP, `nctdtrit` 5.1 ULP(조건수로 나눈 값)예요. ULP는 실수 한 칸의 간격으로, 1e-14는 45~90 ULP예요. 자세한 뜻은 [특수함수의 기본](/api/special/basics/)에 있어요. 보장 영역 밖도 값을 계산하지만 이 정확도를 약속하지는 않아요. 다만 $|\delta|$가 아주 크면(약 $3.83 \times 10^4$ 이상) NaN인 곳이 있어요. 어떤 입력이든 정해진 시간 안에 끝나는데, 그 안에 값을 구할 수 없는 곳이에요. 분포의 가운데만이 아니에요. `nctdtr(10, 3.9e4, t)`는 $t \lesssim 2 \times 10^3$에서 0, $t \gtrsim 10^{92}$에서 1이고, 그 사이는 모두 NaN이에요. `nctdtrc`도 같은 구간이 NaN이고, $-10^{150} \lesssim t \lesssim -3 \times 10^3$에서도 NaN이에요. $\delta < 0$이면 좌우가 뒤집혀요. 경계는 자유도에 따라 움직여요. 자유도 1이면 NaN 구간이 $10^3$ 근처에서 $10^{151}$ 근처까지로 넓어지고, $10^4$이면 $3 \times 10^4$ 근처의 좁은 구간과 음수 쪽의 $-10^{150}$–$-10^{100}$ 근처만 남아요.

```python
>>> sd.special.nctdtr(10, 4e4, sd.asarray([1.0, 4e4, 1e152]))
array([0.0, nan, 1.0], dtype=float64)
>>> sd.special.nctdtrc(10, 4e4, sd.asarray([1.0, -1e4]))
array([1.0, nan], dtype=float64)
```

## 조심할 점

### 비중심 모수는 효과 크기가 아니에요

검정력 계산에서 가장 흔한 실수는 효과 크기 $d$를 `nc`에 그대로 넣는 것이에요. 한 표본 검정이면 $\delta = d\sqrt{n}$, 두 독립 표본이면 $\delta = d\sqrt{n/2}$(집단마다 $n$명)처럼 표본 크기를 반영해야 해요. $d = 0.5$를 그대로 넣으면 표본이 몇 명이든 검정력이 아주 낮게 나와요.

### 양측 검정은 두 꼬리를 더해요

양측 검정의 검정력을 `nctdtrc(df, delta, c)` 하나로 계산하면 반대쪽 꼬리가 빠져요. 효과가 클 때는 그 꼬리가 아주 작아서 차이가 없지만, 효과가 작을 때는 무시할 수 없어요. 두 꼬리를 더하세요.

### 모수의 역함수는 없어요

"검정력이 80%가 되는 $\delta$"나 "관측한 $t$로부터 $\delta$의 신뢰구간"을 바로 푸는 함수는 없어요. 위의 표본 크기 예처럼 후보를 배열로 만들어 한꺼번에 계산하고 고르면 돼요. 분포를 객체로 다루는 통계 영역 `sd.stats`에도 분포가 있어요.

### 리스트와 복소수는 받지 않아요

인자는 `sd.ndarray`나 Python 숫자여야 해요. 리스트는 `sd.asarray`로 바꿔서 넘기세요. 복소수도 `TypeError`예요.

```python
>>> sd.special.nctdtr(10, 2, [1, 2])
Traceback (most recent call last):
    ...
TypeError: nctdtr(): 't' must be an sd.ndarray or a bool, int, float or complex, not list
>>> sd.special.nctdtr(10, 2j, 1)
Traceback (most recent call last):
    ...
TypeError: nctdtr(): not supported for int64, complex128 and int64
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 효과가 없을 때의 t 확률, p값, 기준값 | [`stdtr`, `stdtrit`](/api/special/stdtr/) | 비중심 모수가 없어요. `nctdtr(df, 0, t)`와 같아요 |
| 효과가 있을 때의 t 확률, 검정력 | `nctdtr`, `nctdtrc` | |
| 표준편차를 아는 경우(z 검정)의 검정력 | [`ndtr`](/api/special/ndtr/) | `nctdtr(inf, nc, t) = ndtr(t - nc)` |
| 분산분석·회귀 F 검정의 검정력 | [`ncfdtr`](/api/special/ncfdtr/) | 비중심 F. $T^2$은 분자 자유도 1인 비중심 F를 따라요 |
| 카이제곱 검정의 검정력 | [`chndtr`](/api/special/chndtr/) | 비중심 카이제곱 |

마지막에서 둘째 줄의 관계를 쓰면 양측 t 검정의 검정력을 F 분포 하나로도 계산할 수 있어요. $|T| > c$와 $T^2 > c^2$이 같은 사건이기 때문이에요.

```python
>>> c = sd.special.stdtrit(19, 0.975)
>>> d = 0.5 * 20 ** 0.5
>>> sd.special.nctdtrc(19, d, c) + sd.special.nctdtr(19, d, -c)
0.5645044184390205
>>> sd.special.ncfdtrc(1, 19, d * d, c * c)
0.5645044184390207
```

두 값은 마지막 자리만 달라요. 계산 경로가 달라서 생기는 반올림 차이예요.

## scipy를 아는 분께

- **인자 순서는 scipy와 같아요.** `nctdtr(df, nc, t)`, `nctdtrit(df, nc, p)`예요. 비중심 카이제곱만 scipy가 `chndtr(x, df, nc)`이고 stardust는 `chndtr(df, nc, x)`라서 달라요.
- `nctdtrc`은 scipy.special에 없는 함수예요. scipy에서 `1 - nctdtr(...)`로 쓰던 계산을 이것으로 바꾸면 작은 꼬리가 정확해져요(`1 - scipy.special.nctdtr(10, 2, 100)`은 3.175e-14로, 참값 3.1797e-14와 넷째 자리부터 달라요).
- 모수를 푸는 `nctdtridf`, `nctdtrinc`는 없어요.
- `nc = ±inf`에서 scipy는 NaN을, stardust는 0 또는 1을 돌려줘요. `df = inf`(정규분포)는 둘이 같아요.
- `where=`, `dtype=` 같은 ufunc 인자는 없고 `out=`만 있어요. 인자는 모두 positional-only예요.
