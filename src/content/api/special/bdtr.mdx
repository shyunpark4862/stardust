## 한눈에 보기

**이항 분포**(binomial distribution)는 성공 확률이 `p`인 시도를 `n`번 했을 때 성공한 횟수의 분포예요. 동전을 10번 던져 앞면이 몇 번 나오는지가 가장 쉬운 예예요. 시도끼리 서로 영향을 주지 않고, 매번 성공 확률이 같다고 가정해요.

"n번 중 몇 번"으로 셀 수 있는 일은 거의 다 이 분포로 다뤄요.

- 동전과 주사위: 동전 10번 중 앞면이 8번 이상 나오면 동전을 의심해야 할까요
- 전환율과 A/B 테스트: 방문자 200명 중 18명이 구매했는데, 기존 전환율 5%보다 정말 높은 걸까요
- 품질 관리: 불량률 2%인 공정에서 50개를 뽑았을 때 불량이 몇 개까지 나올 수 있을까요
- 임상과 설문: 환자 30명 중 반응한 사람 수, 응답자 중 찬성한 사람 수와 그 비율의 신뢰구간

두 함수가 짝이에요.

- `bdtr(k, n, p)`: 성공 횟수 X가 `k` 이하일 확률 P(X ≤ k), 곧 **누적분포함수**(cdf)
- `bdtrc(k, n, p)`: X가 `k`보다 클 확률 P(X > k), 곧 **생존함수**(survival function). 끝의 `c`는 보수(complement)라는 뜻이에요.

```python
>>> import stardust as sd
>>> sd.special.bdtr(5, 10, 0.5)
0.623046875
>>> sd.special.bdtrc(7, 10, 0.5)
0.0546875
```

공정한 동전을 10번 던질 때 앞면이 5번 이하일 확률은 638/1024 = 0.623이에요. 둘째 줄은 앞면이 7번보다 많이, 곧 8번 이상 나올 확률 56/1024 ≈ 5.5%예요.

## 이항 분포의 정의

`n`번 중 정확히 $j$번 성공할 확률은

$$
P(X = j) = \binom{n}{j} p^j (1-p)^{n-j}, \qquad j = 0, 1, \dots, n
$$

이에요. $\binom{n}{j}$는 `n`번 중 성공할 $j$번을 고르는 경우의 수([binom](/api/special/binom/))예요. `bdtr`은 이것을 0부터 $k$까지 더한 값이에요.

$$
\mathrm{bdtr}(k, n, p) = \sum_{j=0}^{\lfloor k \rfloor} \binom{n}{j} p^j (1-p)^{n-j}
$$

이 합은 [정칙화된 불완전 베타 함수](/api/special/betainc/)와 정확히 같아서, `n`이 커도 항을 하나하나 더하지 않고 바로 계산해요($0 \le k < n$일 때).

$$
\mathrm{bdtr}(k, n, p) = I_{1-p}(n - k,\ k + 1), \qquad
\mathrm{bdtrc}(k, n, p) = I_{p}(k + 1,\ n - k)
$$

```python
>>> sd.special.betainc(5.0, 6.0, 0.5)
0.623046875
>>> sd.special.betainc(6.0, 5.0, 0.5)
0.376953125
```

## 동전이 공정할까요

동전을 10번 던졌더니 앞면이 9번 나왔어요. 공정한 동전에서 이만큼 이상 치우칠 확률을 구해요.

```python
>>> sd.special.bdtrc(8, 10, 0.5)
0.010742187500000002
```

9번 이상이니 `k`에는 8을 넣었어요. 앞면 쪽으로만 따지면 약 1.1%예요. 뒷면 쪽으로 치우친 경우(앞면 1번 이하)까지 같이 세는 양측 검정이면, 분포가 대칭이라 두 배인 약 2.1%예요. 참값은 11/1024 = 0.0107421875이고, 끝자리의 `2`는 실수 계산의 반올림이에요.

<Callout type="warn" title="bdtrc는 '초과'예요">
  `bdtrc(k, n, p)`는 P(X > k), 곧 k보다 많은 경우의 확률이에요. "k번 **이상**"의 확률 P(X ≥ k)는 `bdtrc(k - 1, n, p)`예요. 검정의 p값은 대개 "관찰한 값 이상"이라서, 관찰한 횟수에서 1을 뺀 값을 넣어야 해요.
</Callout>

## 전환율: 정말 올랐을까요

기존 전환율이 5%인 쇼핑몰에서 새 화면을 보여 준 방문자 200명 중 18명이 구매했어요. 기대값은 10명이에요. 전환율이 그대로일 때 18명 이상이 구매할 확률을 구해요.

```python
>>> sd.special.bdtrc(17, 200, 0.05)
0.012089443730889573
```

약 1.2%라서, 새 화면이 전환율을 높였다고 볼 근거가 돼요. 이렇게 이항 분포로 직접 p값을 구하는 방법을 **정확 이항 검정**이라고 불러요. 정규분포로 어림하는 방법보다 표본이 작거나 비율이 0이나 1에 가까울 때 믿을 만해요.

## 품질 관리: 불량은 몇 개까지 나올까요

불량률이 2%인 공정에서 50개를 뽑아 검사해요.

```python
>>> sd.special.bdtr(0, 50, 0.02)
0.3641696800871173
>>> sd.special.bdtrc(3, 50, 0.02)
0.017758080697971634
```

불량이 하나도 없을 확률은 약 36%예요. 불량이 3개보다 많을(4개 이상) 확률은 약 1.8%라서, "4개 이상 나오면 공정을 멈추고 점검한다"는 기준을 세우면 정상 공정을 잘못 멈추는 일은 2% 아래예요.

## 위꼬리는 `bdtrc`로 직접

`bdtrc`을 `1 - bdtr`로 계산하면 꼬리에서 자릿수를 잃어요. `bdtr`이 1에 아주 가까워지면, float64는 1 근처에서 약 1.1e-16 간격으로만 수를 담을 수 있어서 1에서 뺀 값에 오차가 커지기 때문이에요.

```python
>>> sd.special.bdtrc(60, 100, 0.5)
0.01760010010885241
>>> 1 - sd.special.bdtr(60, 100, 0.5)
0.01760010010885238
>>> sd.special.bdtrc(90, 100, 0.5)
1.6610244897268266e-18
>>> 1 - sd.special.bdtr(90, 100, 0.5)
0.0
```

앞의 두 줄은 끝자리가 이미 달라지고, 동전 100번 중 앞면이 91번 이상일 확률처럼 먼 꼬리에서는 `1 - bdtr`이 아예 0이 돼요. `bdtrc`은 1에서 빼지 않고 위꼬리를 직접 계산해서 이런 값도 앞자리 14자리 정도가 맞아요.

## 비율의 정확한 신뢰구간

50개 중 3개가 불량이었을 때 진짜 불량률이 있을 만한 범위를 구해요. **Clopper–Pearson 구간**은 "그 불량률이라면 관찰한 결과가 나올 확률이 양쪽으로 2.5%씩"인 두 값을 경계로 잡은 95% 구간이에요. 이항 분포의 누적확률이 불완전 베타 함수라서, 그 역함수 [`betaincinv`](/api/special/betainc/)로 경계를 바로 구해요.

```python
>>> k, n = 3, 50
>>> lo = sd.special.betaincinv(k, n - k + 1, 0.025)
>>> hi = sd.special.betaincinv(k + 1, n - k, 0.975)
>>> (lo, hi)
(0.012548587835334062, 0.16548194660377288)
```

불량률은 95% 신뢰도로 약 1.3%에서 16.5% 사이예요. 경계에서 정말 2.5%가 되는지 이 페이지의 함수로 확인할 수 있어요. 하한에서는 "3개 이상"의 확률이, 상한에서는 "3개 이하"의 확률이 2.5%예요.

```python
>>> sd.special.bdtrc(k - 1, n, lo)
0.025
>>> sd.special.bdtr(k, n, hi)
0.025000000000000012
```

이 영역에는 이항 분포의 역함수가 따로 없어요. 성공 확률 `p`를 거꾸로 구할 때는 이렇게 `betaincinv`를 써요.

## 정수 인자의 규칙

### `k`는 내림하고, 범위 밖도 받아요

성공 횟수는 정수라서 `k`가 정수가 아니면 내림해서 P(X ≤ ⌊k⌋)로 계산해요. 음수 `k`는 "음수 번 이하로 성공할 확률"이라 0이고, `k`가 `n` 이상이면 "n번 이하로 성공할 확률"이라 언제나 1이에요.

```python
>>> sd.special.bdtr(3.9, 10, 0.5)
0.17187499999999997
>>> sd.special.bdtr(-1, 10, 0.5)
0.0
>>> sd.special.bdtr(12, 10, 0.5)
1.0
>>> sd.special.bdtrc(12, 10, 0.5)
0.0
```

이 규칙 덕분에 `k`를 배열로 넘겨 계산할 때 경계를 따로 걸러 내지 않아도 돼요. 아래의 "정확히 k번" 계산도 그 덕분에 `k = 0`에서 그대로 맞아요.

### `n`은 0 이상의 정수여야 해요

시행 횟수는 셀 수 있는 정수라서, `n`이 정수가 아니거나 음수, 무한대이면 NaN이에요. `5.5`번 던진다는 것은 뜻이 없고, 이런 값은 대개 평균이나 비율을 잘못 넘긴 실수예요. 몰래 내려서 계산하면 그 실수가 그럴듯한 숫자 뒤에 숨어 버리니, NaN을 돌려줘서 바로 드러나게 해요.

```python
>>> sd.special.bdtr(3, 5.5, 0.5)
nan
>>> sd.special.bdtr(3, -1, 0.5)
nan
```

`n = 0`이면 한 번도 시도하지 않았으니 성공 횟수는 0이고, `bdtr(0, 0, p)`는 1이에요.

### `p`의 끝점

`p`는 0 이상 1 이하의 확률이에요. `p = 0`이면 성공이 절대 없으니 `bdtr`은 언제나 1, `p = 1`이면 언제나 `n`번 성공하니 `k < n`에서 0이에요. 범위 밖은 NaN이에요.

```python
>>> sd.special.bdtr(3, 10, 0.0)
1.0
>>> sd.special.bdtr(3, 10, 1.0)
0.0
>>> sd.special.bdtr(3, 10, 1.5)
nan
```

## 정확히 k번일 확률

"정확히 k번"의 확률을 주는 함수는 따로 없어요. 누적확률의 차이로 구하면 돼요.

```python
>>> k = sd.arange(0, 5)
>>> sd.special.bdtr(k, 4, 0.5) - sd.special.bdtr(k - 1, 4, 0.5)
array([0.0625,   0.25,  0.375,   0.25, 0.0625], dtype=float64)
```

동전 4번에서 앞면이 0, 1, 2, 3, 4번 나올 확률은 1/16, 4/16, 6/16, 4/16, 1/16이에요. `k - 1`이 음수가 되는 맨 앞 칸도 `bdtr(-1, ...) = 0` 덕분에 맞아요. 정의 식 그대로 `binom(n, k) * p**k * (1 - p)**(n - k)`로 계산해도 돼요.

## 여러 값을 한 번에

인자는 배열이어도 되고 서로 [브로드캐스팅](/api/array/broadcasting/)해요. 동전 10번에서 "앞면이 몇 번 이상이면 의심할까"를 정하려고 기준마다 확률을 봐요.

```python
>>> cut = sd.asarray([6, 7, 8, 9])
>>> sd.special.bdtrc(cut - 1, 10, 0.5)
array([         0.376953125,  0.17187499999999997,            0.0546875,
       0.010742187500000002], dtype=float64)
```

8번 이상으로 기준을 잡으면 공정한 동전을 잘못 의심할 확률이 약 5.5%예요. 정수 배열도 float64로 계산하고, 결과는 언제나 float64예요. 결과를 미리 만든 배열에 받으려면 `out=`을 써요([특수함수의 기본](/api/special/basics/)).

## 정확도

- 보장 영역: `n`이 1e4(1만) 이하인 범위, `p`는 모든 값
- `bdtr`, `bdtrc`: 정밀한 참값과의 상대오차가 1e-14 이하예요. 앞자리 14자리 정도가 맞는다는 뜻이고, `1.66e-18` 같은 먼 꼬리에서도 마찬가지예요.

잰 최대 오차는 `bdtr` 4.9, `bdtrc` 7.4 ULP예요. 1e-14가 약 45 ULP이니 약속보다 한참 작아요. ULP는 [특수함수의 기본](/api/special/basics/)에서 풀어 놓았어요. 범위 밖(`n`이 1만 초과)도 값을 계산하지만 정확도를 약속하지는 않아요.

## 특수값

| 입력 | 결과 | 뜻 |
|---|:---:|---|
| `k`가 정수가 아님 | `⌊k⌋`로 계산 | P(X ≤ k)의 뜻 그대로예요 |
| `k < 0` | 0 (`bdtrc`은 1) | 성공 횟수는 음수가 될 수 없어요 |
| `k ≥ n` | 1 (`bdtrc`은 0) | 성공은 n번을 넘을 수 없어요 |
| `n`이 정수가 아님, 음수, inf | NaN | 시행 횟수는 0 이상의 정수예요 |
| `p = 0` | 1 (`bdtrc`은 0) | 성공이 없어요 |
| `p = 1`, `k < n` | 0 (`bdtrc`은 1) | 언제나 n번 성공해요 |
| `p < 0` 또는 `p > 1` | NaN | 확률이 아니에요 |
| 인자 중 NaN | NaN | |

## 조심할 점

### 인자 순서: `k`, `n`, `p`

`bdtr(k, n, p)`는 성공 횟수 경계, 시행 횟수, 성공 확률 순서예요. `k`와 `n`을 바꿔 넣으면 `k ≥ n`이 되어 1이 나오거나, 엉뚱한 값이 나와요. 에러는 나지 않아요.

```python
>>> sd.special.bdtr(3, 10, 0.2)
0.8791261184
>>> sd.special.bdtr(10, 3, 0.2)
1.0
```

### 값 때문에는 에러가 나지 않아요

정의역 밖의 값은 에러 대신 NaN이에요. 배열 일부가 잘못돼도 나머지는 계산되지만, 결과에 NaN이 섞이지 않았는지는 직접 확인해야 해요. 특히 `n`에 `n * 0.8`처럼 계산한 값을 넘기면 정수가 아니어서 NaN이 될 수 있어요.

### 에러는 타입이 틀렸을 때만

복소수, 리스트, 문자열은 받지 않아요.

```python
>>> sd.special.bdtr(3, 10, 0.5j)
Traceback (most recent call last):
    ...
TypeError: bdtr(): not supported for int64, int64 and complex128
>>> sd.special.bdtr([3, 4], 10, 0.5)
Traceback (most recent call last):
    ...
TypeError: bdtr(): 'k' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | 차이 |
|---|---|---|
| 시행 횟수 없이 평균만 아는 횟수 | [`pdtr`](/api/special/pdtr/) | `n`이 크고 `p`가 작으면 `bdtr(k, n, p)`는 `pdtr(k, n*p)`와 비슷해요. |
| 정해진 성공 수까지의 실패 수 | [`nbdtr`](/api/special/nbdtr/) | 시도 횟수가 아니라 성공 횟수를 정해 두고 기다려요. |
| 성공 확률 `p`를 거꾸로 구하기 | [`betaincinv`, `betainccinv`](/api/special/betainc/) | `bdtr(k, n, p) = y`인 `p`는 `betainccinv(k + 1, n - k, y)`예요. |
| 정확히 k번의 확률 | [`binom`](/api/special/binom/) | `binom(n, k) * p**k * (1 - p)**(n - k)`예요. |
| 실수 `k`로 매끄럽게 이어진 값 | [`betainc`](/api/special/betainc/) | `betainc(n - k, k + 1, 1 - p)`는 `k`를 내리지 않아요. |

`sd.stats`에도 이항 분포 객체가 있어요. 확률질량, 난수, 평균 같은 것을 한데 묶어 쓰고 싶으면 그쪽을 쓰고, 누적확률 하나만 빠르게 필요하면 이 함수들이 간단해요.

## scipy를 아는 분께

- 이름, 인자 순서, 뜻은 `scipy.special.bdtr`, `bdtrc`과 같아요. 정수가 아닌 `k`를 내리는 것도 같아요.
- 음수 `k`에서 `bdtr`은 0이에요. scipy 1.18.1은 NaN을 돌려줘요(`bdtrc`은 scipy도 1).
- `k > n`에서 `bdtr`은 1, `bdtrc`은 0이에요. scipy는 둘 다 NaN이에요.
- 정수가 아닌 `n`은 NaN이에요. scipy는 `DeprecationWarning`을 내고 `n`을 내려서 계산해요(`bdtr(3, 5.5, 0.5)`가 scipy에서는 `bdtr(3, 5, 0.5)`인 0.8125).
- 역함수 `bdtri`, `bdtrik`, `bdtrin`은 없어요. 성공 확률은 `betainccinv`로 구해요.
- 리스트, numpy 배열은 받지 않아요. `sd.ndarray`와 Python 숫자만 받아요. `out`은 keyword-only예요.
