---
title: 불완전 감마 함수
names: [gammainc, gammaincc, gammaincinv, gammainccinv]
group: 불완전 감마와 베타
order: 1
signatures:
  - "sd.special.gammainc(a, x, /, *, out=None)"
  - "sd.special.gammaincc(a, x, /, *, out=None)"
  - "sd.special.gammaincinv(a, p, /, *, out=None)"
  - "sd.special.gammainccinv(a, q, /, *, out=None)"
summary: 감마 함수의 적분을 x에서 자른 비율 P(a, x)와 그 나머지 Q(a, x) = 1 − P, 그리고 둘의 역함수예요. 감마·카이제곱·포아송 분포의 누적확률과 분위수가 이 함수들로 계산돼요.
params:
  - name: a
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: 모양 매개변수. 0 이상이어야 값이 있어요(음수면 NaN).
  - name: x
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: gammainc, gammaincc에서 적분을 자르는 위치. 0 이상이어야 값이 있어요(음수면 NaN).
  - name: p
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: gammaincinv에서 찾을 P의 값. 0 이상 1 이하(밖이면 NaN).
  - name: q
    type: ndarray 또는 Python 숫자
    kind: positional-only
    desc: gammainccinv에서 찾을 Q의 값. 0 이상 1 이하(밖이면 NaN).
  - name: out
    type: ndarray 또는 None
    kind: keyword-only
    desc: 결과를 적어 넣을 배열. None이면 새 배열을 만들어요.
returns:
  type: ndarray 또는 Python float
  desc: 두 인자를 브로드캐스팅한 모양의 float64 배열. 두 인자가 모두 Python 숫자면 Python float예요. gammainc·gammaincc는 0과 1 사이의 확률, 두 역함수는 0 이상의 x예요.
raises:
  - type: TypeError
    desc: 복소수를 넣었을 때, 배열도 숫자도 아닌 것(리스트 등)을 넣었을 때, 인자가 둘이 아닐 때, out의 dtype이 float64 결과를 담을 수 없을 때.
  - type: ValueError
    desc: 두 인자나 out의 모양이 브로드캐스팅으로 맞지 않을 때.
  - type: OverflowError
    desc: 두 인자가 모두 정수인데 int64 범위를 벗어난 Python 정수가 있을 때.
seeAlso: [betainc, gamma, chdtr, pdtr, basics]

## 한눈에 보기

[감마 함수](/api/special/gamma/) Γ(a)는 곡선 $t^{a-1}e^{-t}$ 아래의 넓이를 0부터 끝(∞)까지 잰 값이에요. 이 넓이를 끝까지 재지 않고 x에서 멈추면 전체 가운데 몇 퍼센트를 지났는지 알 수 있어요. 그 비율이 **불완전 감마 함수** `gammainc(a, x)`예요. 결과는 언제나 0과 1 사이이고, 남은 비율은 `gammaincc(a, x)`예요.

```python
>>> import stardust as sd
>>> sd.special.gammainc(3.0, sd.asarray([0.0, 1.0, 3.0, 10.0, sd.inf]))
array([                0.0, 0.08030139707139419,  0.5768099188731564,
        0.9972306042844884,                 1.0], dtype=float64)
>>> sd.special.gammaincc(3.0, 3.0)
0.42319008112684364
>>> sd.special.gammainc(3.0, 3.0) + sd.special.gammaincc(3.0, 3.0)
1.0
```

a = 3이면 x = 3까지 넓이의 약 58%가 쌓이고, 남은 42%는 그 뒤에 있어요. 0에서는 0, 무한대에서는 1이에요.

a = 1이면 곡선이 $e^{-t}$라서 식이 간단해져요. `gammainc(1, x)`는 `1 - exp(-x)`예요.

```python
>>> sd.special.gammainc(1.0, 2.0)
0.8646647167633873
>>> 1 - sd.exp(-2.0)
0.8646647167633873
```

### 어디에 쓰나요

`gammainc`는 확률분포의 **누적확률**(어떤 값 이하가 나올 확률)로 가장 많이 쓰여요.

- 감마 분포와 지수분포: "사건이 k번 일어날 때까지 기다리는 시간", "부품이 고장 날 때까지의 수명"처럼 0 이상인 대기 시간을 다루는 분포예요. 그 누적확률이 `gammainc`예요.
- 카이제곱 검정: 관찰한 빈도가 기대와 얼마나 다른지 검정할 때 쓰는 카이제곱 분포의 누적확률과 p값이 `gammainc`·`gammaincc`예요.
- 포아송 분포: "한 시간에 손님이 3명 이하로 올 확률" 같은 횟수의 누적확률도 `gammaincc`로 계산해요.
- 분위수와 신뢰구간: 역함수 `gammaincinv`, `gammainccinv`로 "누적확률이 95%가 되는 값"을 구해요. 검정의 임계값, 포아송 평균의 신뢰구간이 여기서 나와요.
- 물리와 공학: 열복사, 기체 분자의 에너지 분포처럼 $t^{a-1}e^{-t}$ 꼴의 적분이 나오는 곳에 쓰여요.

### 정의

`gammainc`는 **정칙화된**(regularized) 하부 불완전 감마 함수 P(a, x)예요. 0부터 x까지의 넓이를 전체 넓이 Γ(a)로 나눈 값이에요.

$$P(a, x) = \frac{1}{\Gamma(a)} \int_0^x t^{a-1} e^{-t}\, dt, \qquad Q(a, x) = \frac{1}{\Gamma(a)} \int_x^\infty t^{a-1} e^{-t}\, dt = 1 - P(a, x)$$

"정칙화"는 Γ(a)로 나눠서 결과가 0에서 1 사이가 되게 맞췄다는 뜻이에요. 나누기 전의 넓이 자체 $\gamma(a, x) = \int_0^x t^{a-1}e^{-t}dt$가 필요하면 `gamma(a)`를 곱하세요.

```python
>>> sd.special.gammainc(3.0, 2.0) * sd.special.gamma(3.0)
0.6466471676338731
```

아래 첫 그림의 곡선 $t^{a-1}e^{-t}/\Gamma(a)$는 넓이가 1인 곡선(감마 분포의 확률밀도)이에요. P(a, x)는 이 곡선 아래를 0부터 x까지 모은 넓이라서, 둘째 그림처럼 0에서 시작해 1까지 올라가요. a가 클수록 넓이가 오른쪽에 몰려 있어서 늦게 올라가요.

네 함수가 계산하는 값은 이래요.

| 함수 | 계산 | 결과 |
|---|:---:|---|
| `gammainc(a, x)` | P(a, x) | 0부터 x까지의 비율 (누적확률) |
| `gammaincc(a, x)` | Q(a, x) = 1 − P | x부터 끝까지의 비율 (꼬리 확률, p값) |
| `gammaincinv(a, p)` | P(a, x) = p인 x | 누적확률이 p가 되는 위치 (분위수) |
| `gammainccinv(a, q)` | Q(a, x) = q인 x | 꼬리 확률이 q가 되는 위치 |

## 확률분포의 누적확률로 쓰기

`gammainc` 하나로 여러 분포의 누적확률을 계산할 수 있어요. 모양을 정하는 수를 a에, 값을 x에 알맞게 넣으면 돼요.

| 분포 | 누적확률 P(X ≤ x) | 비고 |
|---|:---:|---|
| 감마 분포 (모양 k, 척도 θ) | `gammainc(k, x / θ)` | 사건 k번까지의 대기 시간 |
| 지수분포 (척도 θ) | `gammainc(1, x / θ)` | k = 1인 감마 분포. `1 - exp(-x/θ)`와 같아요 |
| 카이제곱 분포 (자유도 ν) | `gammainc(ν / 2, x / 2)` | [chdtr](/api/special/chdtr/)(ν, x)와 같아요 |
| 포아송 분포 (평균 λ), P(N ≤ k) | `gammaincc(k + 1, λ)` | [pdtr](/api/special/pdtr/)(k, λ)와 같아요. **c가 붙은 쪽**이에요 |

예를 들어 평균 3분마다 손님이 오는 가게에서 두 번째 손님이 6분 안에 올 확률은 모양 2, 척도 3인 감마 분포의 누적확률이에요.

```python
>>> k, theta = 2.0, 3.0
>>> sd.special.gammainc(k, 6.0 / theta)
0.5939941502901617
```

자유도 4인 카이제곱 분포에서 9.49 이하가 나올 확률은 약 95%이고, 9.49보다 클 확률(p값)은 약 5%예요. 전용 함수 `chdtr`과 값이 같아요.

```python
>>> sd.special.gammainc(4 / 2, 9.49 / 2)
0.9500468687767051
>>> sd.special.chdtr(4, 9.49)
0.9500468687767051
>>> sd.special.gammaincc(4 / 2, 9.49 / 2)
0.049953131223294894
```

평균 2인 포아송 분포에서 3 이하가 나올 확률은 `gammaincc(4, 2)`예요. 확률을 하나씩 더한 값과 같아요.

```python
>>> sd.special.gammaincc(3 + 1, 2.0)
0.857123460498547
>>> sd.special.pdtr(3, 2.0)
0.857123460498547
>>> lam = 2.0
>>> sum(lam**i * sd.exp(-lam) / sd.special.gamma(i + 1) for i in range(4))
0.8571234604985472
```

분포를 객체로 다루는 `sd.stats`에도 감마·카이제곱·포아송 분포가 있어요. 함수 하나로 바로 계산하고 싶을 때는 이 페이지의 함수가 간편해요.

## gammaincc: 꼬리를 1에서 빼지 않고 계산하기

`gammaincc(a, x)`는 `1 - gammainc(a, x)`와 같은 값이지만, **1에서 빼서 계산하지 않아요.** x에서 끝까지의 넓이를 직접 계산해요. 이 차이는 꼬리 확률이 아주 작을 때 드러나요.

```python
>>> x = sd.asarray([10.0, 30.0, 100.0, 700.0])
>>> 1 - sd.special.gammainc(1.0, x)
array([4.539992976249074e-05,  9.35918009759007e-14,                   0.0,
                         0.0], dtype=float64)
>>> sd.special.gammaincc(1.0, x)
array([4.5399929762484854e-05,  9.357622968840175e-14,
       3.7200759760208366e-44,  9.85967654375977e-305], dtype=float64)
>>> sd.exp(-x)
array([ 4.539992976248485e-05,  9.357622968840175e-14,
       3.7200759760208356e-44,  9.85967654375977e-305], dtype=float64)
```

a = 1이면 참값은 $e^{-x}$예요. `1 - gammainc`는 x = 10에서 이미 열셋째 자리가 틀렸고, x = 30에서는 넷째 자리가, x = 100부터는 0이 돼요. float64는 1 바로 아래의 수를 대략 1.1 × 10⁻¹⁶ 간격으로만 나타낼 수 있어서, 1에 아주 가까운 `gammainc`의 결과를 1에서 빼면 그 간격보다 작은 정보가 모두 사라져요. `gammaincc`는 1e-305 같은 아주 작은 꼬리도 앞자리 14자리 정도까지 맞아요.

`gammainc` 쪽도 작은 값을 0으로 뭉개지 않아요. x가 아주 작으면 결과도 아주 작지만 앞자리가 맞게 나와요.

```python
>>> sd.special.gammainc(0.5, 1e-10)
1.1283791670579e-05
>>> sd.special.gammainc(1.0, 1e-300)
1e-300
```

## 역함수: 누적확률에서 위치 찾기

`gammaincinv(a, p)`는 `gammainc(a, x) = p`가 되는 x를 찾아요. "누적확률이 p가 되는 지점", 곧 **분위수**예요. `gammainccinv(a, q)`는 `gammaincc(a, x) = q`가 되는 x예요.

```python
>>> sd.special.gammaincinv(3.0, 0.5)
2.674060313723561
>>> p = sd.asarray([0.1, 0.5, 0.9])
>>> sd.special.gammainc(3.0, sd.special.gammaincinv(3.0, p))
array([0.1, 0.5, 0.9], dtype=float64)
```

다시 `gammainc`에 넣으면 처음의 p로 돌아와요(마지막 자리는 반올림으로 조금 다를 수 있어요).

검정의 임계값이 대표적인 쓰임이에요. 자유도 4인 카이제곱 분포에서 "위쪽 5%"가 시작되는 값은 이렇게 구해요. 두 방법의 결과는 마지막 자리 하나(반올림 한 단계)만 달라요.

```python
>>> 2 * sd.special.gammaincinv(4 / 2, 0.95)
9.487729036781154
>>> 2 * sd.special.gammainccinv(4 / 2, 0.05)
9.487729036781156
```

### 아주 작은 꼬리에는 gammainccinv

꼬리 확률 q가 아주 작으면 `gammaincinv(a, 1 - q)`로는 구할 수 없어요. `1 - 1e-20`은 float64에서 정확히 `1.0`이 되므로, "누적확률이 1이 되는 지점", 곧 무한대를 묻는 셈이 되기 때문이에요. 이럴 때는 q를 그대로 `gammainccinv`에 넣으세요.

```python
>>> 2 * sd.special.gammaincinv(4 / 2, 1 - 1e-20)
inf
>>> 2 * sd.special.gammainccinv(4 / 2, 1e-20)
99.9663959741815
```

### 끝점과 범위 밖

p = 0이면 x = 0, p = 1이면 x = ∞예요. `gammainccinv`는 반대예요. p나 q가 0과 1 사이를 벗어나거나 NaN이면 NaN이에요.

```python
>>> sd.special.gammaincinv(3.0, sd.asarray([0.0, 1.0]))
array([0.0, inf], dtype=float64)
>>> sd.special.gammainccinv(3.0, sd.asarray([0.0, 1.0]))
array([inf, 0.0], dtype=float64)
>>> sd.special.gammaincinv(3.0, sd.asarray([-0.1, 1.5, sd.nan]))
array([nan, nan, nan], dtype=float64)
```

a가 서브노멀(약 2.2e-308보다 작은 수)이거나 그 근처(약 1e-271 아래)일 만큼 0에 가까우면 질량 거의 전부가 0에 붙어요. 이때 Q(a, x)는 float64에서 a·E₁(x)와 같아서(E₁은 [지수 적분](/api/special/expi/)), `gammainccinv(a, q)`는 E₁(x) = q/a가 되는 x예요. q가 a의 700배이면 x는 약 5.5e-305이고, 근이 가장 작은 양수(약 5e-324)의 절반보다 작으면 0이에요. q가 1e-300보다 작아도, q와 a가 둘 다 서브노멀이어도 같은 식으로 근을 찾아요. `gammaincinv(a, p)`는 a가 서브노멀이면 p < 1에서 0이에요. 참값이 p^(1/a) 꼴이라 float64가 담을 수 있는 어떤 수보다도 작아요.

```python
>>> sd.special.gammainccinv(1e-310, sd.asarray([1e-310, 5e-310, 700e-310, 760e-310]))
array([   0.26473701045154324,  0.0037974640015846885,
       5.535808900383636e-305,                    0.0], dtype=float64)
>>> sd.special.gammainccinv(2.0**-1022, sd.asarray([1e-305, 1e-320]))
array([3.6920388759008e-196,   25.167662090818315], dtype=float64)
>>> sd.special.gammaincinv(1e-310, sd.asarray([0.3, 0.999, 1.0]))
array([0.0, 0.0, inf], dtype=float64)
```

### 역함수의 정확도는 p가 허용하는 만큼

역함수는 "입력 p의 마지막 자리가 허용하는 만큼" 정확해요. 보통은 x도 앞자리 14자리 정도가 맞아요. 그런데 a가 아주 작으면 P(a, x)가 x에 아주 둔감해져요. 아래처럼 a = 0.01이면 x가 1e-30에서 1e-10으로 10²⁰배 바뀌어도 P는 0.50에서 0.80으로밖에 안 움직여요.

```python
>>> sd.special.gammainc(0.01, sd.asarray([1e-30, 1e-20, 1e-10]))
array([0.5040472728599955, 0.6345579205489968, 0.7988610914336052], dtype=float64)
```

이런 곳에서는 거꾸로 p를 마지막 자리 하나만 바꿔도 x가 크게 움직여요. a = 0.01에서 p를 0.5 바로 다음 수로 바꾸면 x가 열넷째 자리에서 달라지고, a = 3에서는 마지막 자리 하나만 달라져요.

```python
>>> p = sd.asarray([0.5, sd.nextafter(0.5, 1.0)])
>>> sd.special.gammaincinv(0.01, p)
array([4.465535018910265e-31, 4.465535018910365e-31], dtype=float64)
>>> sd.special.gammaincinv(3.0, p)
array([ 2.674060313723561, 2.6740603137235612], dtype=float64)
```

p 자체가 이미 반올림된 값이므로, 이 정도의 흔들림은 어떤 방법으로도 피할 수 없어요. 역함수는 그 피할 수 없는 흔들림 안에서 정확하다고 약속해요.

## 정의역 밖과 특수값

값 때문에 에러가 나는 일은 없어요. a나 x가 음수이거나 NaN이면 NaN이에요.

```python
>>> sd.special.gammainc(sd.asarray([-1.0, 2.0, 2.0, sd.nan]), sd.asarray([1.0, -1.0, sd.nan, 1.0]))
array([nan, nan, nan, nan], dtype=float64)
```

경계에서의 값은 이래요. `gammaincc`는 언제나 `1 - gammainc`에 해당하는 값이에요.

| 입력 | `gammainc` | `gammaincc` | 이유 |
|---|:---:|:---:|---|
| `x = 0` (`a > 0`) | 0 | 1 | 아직 넓이를 하나도 지나지 않았어요 |
| x = ∞ (a는 유한) | 1 | 0 | 넓이를 모두 지났어요 |
| `a = 0`, `x > 0` | 1 | 0 | a → 0이면 넓이가 모두 0 바로 옆에 몰려요 |
| a = 0, x = 0 | NaN | NaN | 두 극한이 충돌해요 |
| a = ∞, x는 유한 | 0 | 1 | a → ∞이면 넓이가 모두 무한히 먼 곳으로 가요 |
| a = ∞, x = ∞ | NaN | NaN | 두 극한이 충돌해요 |
| `a < 0`, `x < 0`, NaN | NaN | NaN | 정의되지 않아요 |

```python
>>> sd.special.gammainc(0.0, sd.asarray([0.0, 0.5, 5.0]))
array([nan, 1.0, 1.0], dtype=float64)
>>> sd.special.gammainc(sd.inf, sd.asarray([3.0, sd.inf]))
array([0.0, nan], dtype=float64)
```

역함수에서는 p = 0, 1(`gammainccinv`는 q = 1, 0)이 x = 0, ∞이에요. a가 0이나 ∞이면 p가 0과 1 사이일 때 NaN이에요.

## 정확도

- `gammainc`와 `gammaincc`는 a ≥ 0, x ≥ 0인 정의역 전체에서 상대오차가 1e-14 이하예요. 상대오차 1e-14는 결과의 앞자리 약 14자리가 참값과 같다는 뜻이에요. 위에서 본 것처럼 1e-305 같은 아주 작은 꼬리도 마찬가지예요. 실제로 잰 최대 오차는 `gammainc` 약 9 [ULP](/api/special/basics/), `gammaincc` 약 13 ULP예요.
- 결과가 float64로 담을 수 있는 가장 작은 정규 수(약 2.2 × 10⁻³⁰⁸)보다 작으면 0으로 뭉개지 않고 서브노멀 값을 내요. 이 영역에서는 상대오차 대신 아주 작은 절대오차로 약속해요.
- 두 역함수는 위에서 설명한 대로 p(또는 q)의 마지막 자리가 허용하는 만큼 정확해요. 보통의 a에서는 상대오차 1e-14 안팎이에요.

같은 입력이면 배열 안의 위치나 스레드 수와 상관없이 언제나 같은 비트가 나와요. 자세한 내용은 [특수함수의 기본](/api/special/basics/)에 있어요.

## 입력과 결과의 종류

결과는 언제나 **float64**예요. bool·정수를 넣어도 실수로 바꿔서 계산해요. 두 인자가 모두 Python 숫자면 결과도 Python `float`예요. 두 인자의 모양이 다르면 [브로드캐스팅](/api/array/broadcasting/) 규칙으로 맞춰서, 여러 a와 여러 x의 표를 한 번에 만들 수 있어요.

```python
>>> sd.special.gammainc(2, 1)
0.2642411176571153
>>> sd.special.gammainc(sd.asarray([[1.0], [2.0]]), sd.asarray([0.5, 1.0, 2.0]))
array([[ 0.3934693402873665,  0.6321205588285578,  0.8646647167633873],
       [0.09020401043104986,  0.2642411176571153,  0.5939941502901617]], dtype=float64)
```

`out=`에 배열을 주면 그 배열에 결과를 적고 그 배열을 돌려줘요. 결과가 float64라서 정수 배열에는 담을 수 없어요. 규칙은 [사칙연산의 `out`](/api/array/arithmetic/)과 같아요.

```python
>>> buf = sd.zeros(3)
>>> sd.special.gammaincc(2.0, sd.asarray([0.5, 1.0, 2.0]), out=buf) is buf
True
>>> buf
array([ 0.9097959895689501,  0.7357588823428847, 0.40600584970983833], dtype=float64)
```

에러는 값이 아니라 **인자의 종류와 모양**이 맞지 않을 때만 나요. 복소수와 리스트는 받지 않아요. 리스트는 먼저 [`asarray`](/api/array/asarray/)로 바꾸세요.

## 조심할 점

- **인자 순서는 (a, x)예요.** 모양 a가 먼저, 위치 x가 나중이에요. 분포 함수 `chdtr(ν, x)`도 같은 순서예요.
- **포아송의 누적확률은 `gammaincc`예요.** P(N ≤ k) = `gammaincc(k + 1, λ)`이고, a 자리에 k가 아니라 **k + 1**이 들어가요.
- **작은 꼬리는 `1 - gammainc`가 아니라 `gammaincc`로** 구하세요. 역함수도 마찬가지로 작은 q는 `gammainccinv(a, q)`예요.
- **정칙화된 값이에요.** 결과는 Γ(a)로 나눈 비율이에요. 나누기 전의 넓이가 필요하면 `gamma(a)`를 곱하세요(a가 크면 넘칠 수 있어요).
- **값 때문에 에러가 나지 않아요.** 음수, 범위 밖의 p, NaN은 모두 조용히 NaN이 되니, 필요하면 `sd.isnan`으로 확인하세요.

## 비슷한 함수와의 차이

| 헷갈리는 것 | 차이 |
|---|---|
| `gammainc`와 [gamma](/api/special/gamma/) | `gamma(a)`는 0부터 ∞까지의 전체 넓이, `gammainc(a, x)`는 그중 x까지의 **비율**이에요. |
| `gammaincc(a, x)`와 `1 - gammainc(a, x)` | 같은 값이지만 꼬리가 작으면 `gammaincc`만 정확해요. 1e-16보다 작은 꼬리는 `1 - gammainc`로는 0이 돼요. |
| `gammaincinv(a, 1 - q)`와 `gammainccinv(a, q)` | 같은 x지만 q가 아주 작으면 `1 - q`가 1로 반올림되어 앞쪽은 `inf`가 나와요. |
| `gammainc`와 [chdtr](/api/special/chdtr/), [pdtr](/api/special/pdtr/) | 카이제곱·포아송 분포의 누적확률을 그 분포의 인자로 바로 받는 함수예요. 값은 같아요. |
| `gammainc`와 [betainc](/api/special/betainc/) | 불완전 베타 함수는 0에서 1 사이의 곡선 넓이를 비율로 낸 것이에요. 이항·t·F 분포가 그쪽이에요. |

## scipy를 아는 분께

- 이름, 인자 순서, 정칙화된 값이라는 점은 `scipy.special.gammainc`, `gammaincc`, `gammaincinv`, `gammainccinv`와 같아요. 끝점과 ±inf, NaN의 규칙도 같아요.
- 결과가 아주 작은 곳에서 0 대신 참값을 내요. `gammainc(1, 5e-324)`는 `5e-324`(scipy `0.0`), `gammaincc(1, 740)`은 `4.2e-322`(scipy `0.0`)예요.
- a가 거의 0인 곳의 값이 달라요. `gammainc(5e-324, 0.5)`는 `1.0`(scipy `0.0`), `gammainc(1e-300, 5e-324)`는 `1.0`이에요(scipy는 1보다 큰 `1.0000000000000238`).
- `gammaincinv(5e-324, 0.5)`는 `0.0`이에요(scipy는 NaN). 참값이 float64로 담기지 않을 만큼 작아서 0이 돼요.
- a가 아주 작은 `gammainccinv`가 달라요. `gammainccinv(1e-310, 5e-310)`은 `0.0037974640015846885`이고(참값 0.00379746400158469267…), scipy는 `0.003797450316862619`로 여섯째 자리부터 틀려요. 정규수 a에서 q가 아주 작을 때도 그래요. `gammainccinv(2**-1022, 1e-320)`은 `25.167662090818315`이고(참값 25.1676620908183162…), scipy는 `25.167662398832793`으로 여덟째 자리부터 틀려요.
- 그 밖의 값은 scipy와 마지막 몇 자리가 다를 수 있어요.
- 리스트나 numpy 배열은 받지 않고, `out`은 keyword-only예요. 경고를 내지 않아요.
