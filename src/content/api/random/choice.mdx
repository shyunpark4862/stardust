## 한눈에 보기

`choice`는 **주머니에서 공을 꺼내듯** 정해진 후보 가운데 무작위로 골라요. 후보는 배열로 주거나, 정수 `n`으로 주면 `0`부터 `n-1`까지의 정수가 후보가 돼요.

`rng`는 [default_rng](/api/random/default_rng/)로 만든 [Generator](/api/random/generator/)예요. stardust의 난수는 모두 이 생성기의 메서드로 받아요. 예제는 언제나 같은 결과가 나오도록 시드(난수 수열의 출발점을 정하는 수) `42`로 만들었어요. 시드와 재현성은 [난수의 기본](/api/random/basics/)에서 자세히 설명해요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(42)
>>> balls = sd.asarray([1, 2, 3, 4, 5])
>>> rng.choice(balls)
3
>>> rng.choice(balls, shape=8)
array([3, 4, 4, 1, 1, 2, 5, 1], dtype=int64)
```

첫 줄은 공 하나를 꺼냈어요. 둘째 줄은 `shape=8`로 여덟 번 꺼냈는데, `4`가 두 번, `1`이 세 번 나왔어요. 기본값은 **꺼낸 공을 주머니에 다시 넣고** 다음 공을 꺼내는 방식이라서 같은 공이 또 나올 수 있어요. 이것을 **복원 추출**이라고 해요.

`replace=False`를 주면 **꺼낸 공은 빼 둔 채로** 다음 공을 꺼내요. 그래서 같은 공이 두 번 나오지 않아요. 이것을 **비복원 추출**이라고 해요.

```python
>>> rng.choice(balls, shape=3, replace=False)
array([3, 1, 5], dtype=int64)
```

## 무엇에서 고를까: 배열 또는 정수

### 배열을 주면 그 원소 가운데서

`a`에 1차원 배열을 주면 그 원소를 골라요. 결과의 dtype은 `a`와 같아요. 실수 배열이면 실수를, bool 배열이면 bool을 골라요.

```python
>>> rng = sd.random.default_rng(42)
>>> prices = sd.asarray([0.5, 1.5, 2.5])
>>> rng.choice(prices, shape=4)
array([1.5, 1.5, 2.5, 2.5], dtype=float64)
>>> rng.choice(sd.asarray([True, False]), shape=5)
array([ True,  True,  True, False,  True], dtype=bool)
```

### 정수 n을 주면 0부터 n-1까지에서

`a`에 정수 `n`을 주면 `0, 1, …, n-1` 가운데서 골라요. `sd.arange(n)`을 만들어 넘기는 것과 같은 뜻이지만, 그 배열을 만들 필요가 없어요. 결과는 int64예요.

```python
>>> rng.choice(6, shape=5)
array([3, 1, 5, 2, 4], dtype=int64)
```

정수 후보는 **위치를 고를 때** 특히 쓸모가 있어요. 배열이 아닌 것(문자열 리스트 등)에서 고르고 싶을 때도 위치를 고른 다음 그 위치로 꺼내면 돼요.

```python
>>> names = ["민지", "서준", "하은", "도윤"]
>>> names[rng.choice(len(names))]
'민지'
>>> picked = rng.choice(len(names), shape=2, replace=False)
>>> [names[i] for i in picked]
['하은', '도윤']
```

2차원 표에서 **행을 무작위로 몇 개** 고를 때도 같은 방법을 써요. `a`는 1차원만 받기 때문에 표를 직접 넘길 수는 없지만, 행 번호를 고르고 그 번호로 인덱싱하면 돼요.

```python
>>> table = sd.asarray([[1, 2], [3, 4], [5, 6], [7, 8]])
>>> table[rng.choice(4, shape=2, replace=False)]
array([[5, 6],
       [7, 8]], dtype=int64)
```

## `shape`: 몇 개를, 어떤 모양으로

`shape`를 주지 않으면(`None`) **하나만** 골라서 배열이 아닌 Python 숫자로 돌려줘요. 정수를 주면 그 길이의 1차원 배열, tuple을 주면 그 모양의 배열이에요.

```python
>>> rng = sd.random.default_rng(42)
>>> rng.choice(6)
2
>>> type(rng.choice(prices))
<class 'float'>
>>> rng.choice(6, shape=(2, 3))
array([[4, 4, 0],
       [0, 1, 5]], dtype=int64)
```

`shape=1`은 원소 하나짜리 **배열**이라서 `shape=None`과 달라요. 크기가 0인 모양도 돼요. 이때는 아무것도 고르지 않은 빈 배열이 나와요.

```python
>>> rng.choice(6, shape=1)
array([1], dtype=int64)
>>> rng.choice(6, shape=0)
array([], dtype=int64)
```

`shape` 규칙은 다른 난수 메서드와 같아요. 자세한 것은 [난수의 기본](/api/random/basics/)에 있어요.

## `replace`: 다시 넣을까, 빼 둘까

### 복원 추출 (기본값)

`replace=True`면 매번 **모든 후보**가 다시 후보가 돼요. 앞에서 무엇이 나왔든 다음 번에 무엇이 나올지에 영향을 주지 않아요. 주사위를 여러 번 던지는 일이 이것이에요. 그래서 후보보다 더 많이 고를 수 있어요.

```python
>>> rng = sd.random.default_rng(42)
>>> rolls = rng.choice(6, shape=10) + 1
>>> rolls
array([3, 4, 5, 5, 1, 1, 2, 6, 2, 4], dtype=int64)
```

### 비복원 추출

`replace=False`면 **한 번 고른 것은 후보에서 빠져요.** 제비뽑기, 카드 나눠 주기, 설문 대상자 뽑기처럼 같은 것이 두 번 나오면 안 되는 일에 써요.

```python
>>> rng.choice(10, shape=4, replace=False)
array([3, 8, 5, 1], dtype=int64)
```

그래서 후보 수보다 많이 고를 수는 없어요. 후보가 다섯 개인데 여섯 개를 고르려 하면 `ValueError`예요.

```python
>>> rng.choice(5, shape=6, replace=False)
Traceback (most recent call last):
    ...
ValueError: choice(): cannot take a larger sample than the population when replace=False
```

후보를 **전부** 고르면 모든 후보가 한 번씩, 무작위 순서로 나와요. 이것은 순서를 섞는 일이고, 그 일에는 뜻이 분명한 [permutation](/api/random/permutation/)이 따로 있어요.

후보가 아주 많고 고를 개수가 적어도 빨라요. 10억 개 가운데 다섯 개를 고를 때 10억 개짜리 배열을 만들지 않아요.

```python
>>> rng.choice(10**9, shape=5, replace=False)
array([224887150, 662879715, 729072087, 701260746, 922468939], dtype=int64)
```

## `p`: 원소마다 다른 확률로

`p`는 원소마다 **뽑힐 확률**을 적은 배열이에요. `p[i]`가 클수록 `i`번째 원소가 자주 나와요. 길이는 원소 수와 같아야 하고, 모두 0 이상이고, 합이 1이어야 해요.

세 가지 결과가 70%, 20%, 10%의 확률로 나오는 일을 10만 번 해 볼게요. 결과마다 몇 번 나왔는지는 [bincount](/api/array/bincount/)로 세요.

```python
>>> rng = sd.random.default_rng(42)
>>> p = sd.asarray([0.7, 0.2, 0.1])
>>> draws = rng.choice(3, shape=100_000, p=p)
>>> sd.bincount(draws) / 100_000
array([0.69874, 0.20014, 0.10112], dtype=float64)
```

나온 비율이 정한 확률과 거의 같아요. 무작위라서 정확히 같지는 않지만, 많이 뽑을수록 정한 확률에 가까워져요.

<Fig caption="p는 원소마다 뽑힐 확률이에요. 10만 번 뽑으면 나온 비율이 p와 거의 같아져요.">
  <ArrayFig name="p" data={[0.7, 0.2, 0.1]} tones={['b', 'a', '']} note="원소 0, 1, 2의 확률" />
  <Op note="10만 번 뽑기">→</Op>
  <ArrayFig name="나온 비율" data={[0.69874, 0.20014, 0.10112]} tones={['b', 'a', '']} note="bincount / 100000" />
</Fig>

확률이 0인 원소는 **한 번도** 나오지 않아요.

```python
>>> draws = rng.choice(4, shape=10_000, p=sd.asarray([0.5, 0.0, 0.5, 0.0]))
>>> sd.bincount(draws, minlength=4)
array([5026,    0, 4974,    0], dtype=int64)
```

### 개수나 무게로 확률 만들기

확률 대신 "빨간 공 3개, 파란 공 1개, 노란 공 1개"처럼 **개수나 무게**가 있다면, 전체 합으로 나눠서 확률로 바꿔요.

```python
>>> counts = sd.asarray([3, 1, 1])
>>> rng.choice(3, shape=10, p=counts / sd.sum(counts))
array([0, 1, 2, 1, 0, 2, 2, 2, 0, 0], dtype=int64)
```

`p`는 실수 배열이 아니어도 돼요. 정수나 bool 배열도 받지만, 합이 1이어야 한다는 조건은 같아요. 그래서 `counts`를 그대로 넘기면 합이 5라서 에러예요. 나누는 것을 잊지 마세요.

### 합이 1인지는 조금 너그럽게 봐요

`1/3`을 세 번 더하면 컴퓨터의 실수로는 정확히 1이 되지 않을 때가 많아요. 그래서 합이 1에서 아주 조금(약 `1.5e-8`, 10억 분의 15 정도) 벗어나는 것까지는 받아 주고, 안에서 합으로 나눠서 써요. 하지만 그보다 크게 벗어나면 `ValueError`예요.

```python
>>> rng.choice(3, p=sd.asarray([1/3, 1/3, 1/3]))
1
>>> rng.choice(3, p=sd.asarray([0.333, 0.333, 0.333]))
Traceback (most recent call last):
    ...
ValueError: choice(): the probabilities 'p' must sum to 1
```

`0.333`을 세 번 더하면 `0.999`라서 1과 `0.001`이나 차이 나요. 반올림한 확률을 손으로 적었다면 `p / sd.sum(p)`로 합을 1로 맞춘 다음 넘기세요.

### 확률과 비복원 추출을 함께 쓰면

`p`와 `replace=False`를 함께 주면, **매번 남아 있는 후보 가운데서 확률에 비례해** 골라요. 첫 번째는 `p` 그대로의 확률로 고르고, 고른 것을 뺀 뒤 남은 후보들의 확률을 다시 합이 1이 되게 키워서 두 번째를 고르는 식이에요. 결과는 **고른 차례대로** 놓여요.

```python
>>> rng = sd.random.default_rng(42)
>>> rng.choice(5, shape=3, replace=False, p=sd.asarray([0.4, 0.3, 0.1, 0.1, 0.1]))
array([0, 1, 2], dtype=int64)
```

그래서 결과의 **첫 원소**만 보면 `p`의 확률대로 나와요. `p = [0.7, 0.2, 0.1]`로 같은 일을 2000번 해서 첫 원소를 세어 볼게요.

```python
>>> first = [int(rng.choice(3, shape=2, replace=False, p=p)[0]) for _ in range(2000)]
>>> sd.bincount(sd.asarray(first)) / 2000
array([ 0.699, 0.2115, 0.0895], dtype=float64)
```

확률이 0인 원소는 비복원 추출에서도 뽑히지 않아요. 그래서 고를 개수가 **확률이 0이 아닌 원소 수**보다 많으면 `ValueError`예요.

```python
>>> rng.choice(3, shape=3, replace=False, p=sd.asarray([0.5, 0.5, 0.0]))
Traceback (most recent call last):
    ...
ValueError: choice(): fewer non-zero probabilities in 'p' than the sample size
```

반대로 확률이 0보다 크면 **아무리 작아도** 확률이 0인 원소보다 먼저 뽑혀요. 아래에서 1번의 확률 `1e-310`은 0에 아주 가까운 값이지만, 2번을 고른 뒤 남은 0번(확률 0)과 1번 가운데서는 언제나 1번이 뽑혀요.

```python
>>> sd.random.default_rng(42).choice(3, shape=2, replace=False, p=sd.asarray([0.0, 1e-310, 1.0]))
array([2, 1], dtype=int64)
```

## 같은 시드면 같은 결과

시드가 같고 부르는 순서가 같으면 `choice`의 결과는 언제나 같아요. 컴퓨터가 바뀌어도, 스레드 수를 바꿔도 같아요. 실험을 다시 돌리거나 다른 사람이 결과를 확인할 수 있는 것은 이 성질 덕분이에요.

```python
>>> sd.random.default_rng(1).choice(10, shape=4)
array([0, 2, 3, 0], dtype=int64)
>>> sd.random.default_rng(1).choice(10, shape=4)
array([0, 2, 3, 0], dtype=int64)
```

복원 추출은 **한 번에 여섯 개를 뽑든 세 개씩 두 번 뽑든** 같은 값이 나와요.

```python
>>> r = sd.random.default_rng(3)
>>> r.choice(10, shape=3), r.choice(10, shape=3)
(array([2, 3, 1], dtype=int64), array([1, 0, 1], dtype=int64))
>>> sd.random.default_rng(3).choice(10, shape=6)
array([2, 3, 1, 1, 0, 1], dtype=int64)
```

## 조심할 점

### `replace=False`는 한 번의 호출 안에서만이에요

같은 것이 두 번 나오지 않는다는 약속은 **한 번 부른 결과 안**에서만 지켜져요. 생성기는 앞에서 무엇을 골랐는지 기억하지 않아서, 두 번 나눠 부르면 둘 사이에는 겹칠 수 있어요.

```python
>>> r = sd.random.default_rng(3)
>>> r.choice(10, shape=3, replace=False)
array([2, 4, 3], dtype=int64)
>>> r.choice(10, shape=3, replace=False)
array([1, 0, 3], dtype=int64)
```

`3`이 두 번 나왔어요. 여러 묶음으로 나눌 사람이나 물건을 겹치지 않게 고르려면, **필요한 만큼 한 번에** 고른 다음 잘라 쓰세요.

```python
>>> both = sd.random.default_rng(3).choice(10, shape=6, replace=False)
>>> both[:3], both[3:]
(array([2, 4, 3], dtype=int64), array([1, 0, 5], dtype=int64))
```

### 리스트와 여러 차원 배열은 받지 않아요

`a`는 1차원 `sd.ndarray`이거나 정수여야 해요. Python 리스트를 넘기면 `TypeError`, 2차원 배열을 넘기면 `ValueError`예요. 리스트는 `sd.asarray`로 바꾸거나 앞에서 본 것처럼 위치를 고르고, 표의 행은 행 번호를 골라서 인덱싱하세요.

```python
>>> rng.choice([1, 2, 3])
Traceback (most recent call last):
    ...
TypeError: choice(): 'a' must be an int or a 1-dimensional array, not list
>>> rng.choice(table)
Traceback (most recent call last):
    ...
ValueError: choice(): 'a' must be 1-dimensional, not 2-dimensional
```

정수 `a`는 int64로 담을 수 있는 수까지예요. $2^{63}$ 이상은 `OverflowError`예요.

```python
>>> rng.choice(2**63)
Traceback (most recent call last):
    ...
OverflowError: choice(): 'a' is out of range
```

`p`도 배열만 받아요. 리스트로 적었다면 `sd.asarray`로 감싸세요.

```python
>>> rng.choice(3, p=[0.7, 0.2, 0.1])
Traceback (most recent call last):
    ...
TypeError: choice(): 'p' must be an array, not list
```

확률은 실수라서 복소수 배열도 `TypeError`예요. 정수·bool 배열은 받아요.

```python
>>> rng.choice(3, p=sd.asarray([0.5 + 0j, 0.5, 0.0]))
Traceback (most recent call last):
    ...
TypeError: choice(): 'p' must be a real array, not an array of complex128
```

### `p`의 길이, 음수, NaN

`p`의 길이가 원소 수와 다르거나 1차원이 아니면 `ValueError`예요. 음수나 NaN이 있어도 `ValueError`예요. 확률은 0 이상이어야 하니까요.

```python
>>> rng.choice(3, p=sd.asarray([0.5, 0.5]))
Traceback (most recent call last):
    ...
ValueError: choice(): 'p' must be 1-dimensional of length 3
>>> rng.choice(3, p=sd.asarray([0.6, 0.5, -0.1]))
Traceback (most recent call last):
    ...
ValueError: choice(): 'p' must be non-negative
```

NaN이 섞인 경우도 같은 메시지예요. 확률을 계산해서 만들었다면 `sd.isnan`으로 먼저 확인해 보세요.

### 빈 후보에서는 고를 수 없어요

후보가 하나도 없는데 하나 이상 고르려 하면 `ValueError`예요. 고를 개수도 0이면 빈 배열이 나와요.

```python
>>> rng.choice(0)
Traceback (most recent call last):
    ...
ValueError: choice(): cannot choose from an empty population
>>> rng.choice(0, shape=0)
array([], dtype=int64)
```

### 옵션은 이름을 붙여서

`shape`, `replace`, `p`는 반드시 이름을 붙여야 해요. `rng.choice(6, 3)`처럼 쓰면 `TypeError`예요. 반대로 `a`는 이름 없이 맨 앞에 써요. `replace`에는 `True`나 `False`만 쓸 수 있어요.

```python
>>> rng.choice(6, 3)
Traceback (most recent call last):
    ...
TypeError: Generator.choice() takes 2 positional arguments but 3 were given
>>> rng.choice(6, shape=3, replace=0)
Traceback (most recent call last):
    ...
TypeError: choice(): 'replace' must be True or False, not int
```

## 비슷한 함수와의 차이

무작위로 무언가를 고르는 메서드는 넷이에요. 고르려는 것이 무엇인지에 따라 골라요.

| 하고 싶은 일 | 쓸 것 | 예 |
|---|---|---|
| 0과 1 사이의 실수 | [`rng.random`](/api/random/random/) | 확률 실험, 다른 분포의 재료 |
| 범위 안의 정수, 범위가 원소마다 달라도 | [`rng.integers`](/api/random/integers/) | 주사위 `rng.integers(1, 7)` |
| 정해진 후보 가운데, 겹치지 않게, 또는 확률을 정해서 | `rng.choice` | 제비뽑기, 가중치 있는 선택 |
| 모든 원소를 한 번씩 무작위 순서로 | [`rng.permutation`](/api/random/permutation/) | 카드 섞기, 데이터 순서 섞기 |

- **`choice(n)` 대 `integers(n)`**: 확률을 정하지 않은 복원 추출이라면 둘은 같은 일을 해요. 같은 시드면 값도 같아요. 범위의 시작이 0이 아니거나 원소마다 범위가 다르면 `integers`, 후보가 배열이거나 겹치지 않게 고르거나 확률을 정하려면 `choice`예요.

  ```python
  >>> sd.random.default_rng(42).choice(6, shape=5)
  array([2, 3, 4, 4, 0], dtype=int64)
  >>> sd.random.default_rng(42).integers(6, shape=5)
  array([2, 3, 4, 4, 0], dtype=int64)
  ```

- **`choice(n, shape=n, replace=False)` 대 `permutation(n)`**: 둘 다 모든 후보를 한 번씩 섞어서 내요. `permutation`은 배열을 받으면 **여러 차원 배열의 행**도 통째로 섞어 줘요. 일부만 고를 때는 `choice`, 전부 섞을 때는 `permutation`이 뜻이 더 분명해요.
- **분포에서 뽑기**: 정규분포처럼 특정한 분포를 따르는 값은 `sd.stats`의 분포가 맡아요(`X.sample(shape, rng=rng)`). `choice`의 `p`는 후보가 몇 개로 정해져 있을 때 쓰는 것이에요.

## numpy를 아는 분께

- numpy의 `Generator.choice`에 해당해요. **값은 numpy와 달라요.** 생성기 종류가 달라서, 같은 시드를 줘도 다른 원소를 골라요. 확률을 정한 비복원 추출도 뽑히는 확률(분포)은 numpy와 같지만 값은 달라요.
- `size=` 대신 **`shape=`**이고, `shape`·`replace`·`p`는 이름을 붙여야만 해요.
- `a`는 1차원 `sd.ndarray`이거나 정수만 받아요. 리스트, 여러 차원 배열, `axis=`는 없어요. 행을 고르려면 `x[rng.choice(len(x), ...)]`처럼 행 번호를 고르세요.
- `shuffle=` 인자는 없어요. `replace=False`의 결과는 언제나 고른 차례대로예요.
- `p`도 배열만 받아요(리스트 안 됨). 합의 허용치(약 `1.5e-8`)는 numpy와 같아요.
- `shape=None`일 때 배열에서 고른 값은 numpy 스칼라(`np.int64` 등)가 아니라 Python 숫자예요.
