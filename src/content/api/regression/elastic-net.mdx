## 한눈에 보기

[`lasso`](/api/regression/lasso/)는 쓸모없는 열을 0으로 만들어 주지만, 서로 비슷한 열이 여럿이면 그 가운데 하나만 골라요. [`ridge`](/api/regression/ridge/)는 비슷한 열에 효과를 고르게 나눠 주지만 어떤 계수도 0으로 만들지 않아요. **엘라스틱 넷**은 두 벌점을 섞어서 둘의 좋은 점을 함께 얻어요. 쓸모없는 열은 0으로 만들고, 비슷한 열들은 함께 남겨요.

예를 들어 볼게요. `x2`는 `x1`에 작은 잡음을 더한 열이라 둘이 거의 같고, `x3`은 효과가 작아요(참값: 절편 1, `x1`·`x2` 1씩, `x3` 0.5). 여기에 효과가 전혀 없는 잡음 열 둘을 더해요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(1)
>>> Z = sd.stats.Normal().sample((40, 3), rng=rng)
>>> x1 = Z[:, 0]
>>> x2 = x1 + 0.05 * Z[:, 1]
>>> x3 = Z[:, 2]
>>> X = sd.stack([x1, x2, x3], axis=1)
>>> y = 1.0 + x1 + x2 + 0.5 * x3 + sd.stats.Normal().sample(40, rng=rng)
>>> noise = sd.stats.Normal().sample((40, 2), rng=sd.random.default_rng(9))
>>> X5 = sd.concat([X, noise], axis=1)
>>> R = sd.regression
>>> [round(v, 3) for v in R.elastic_net(y, X5, alpha=0.3).params.tolist()]
[1.151, 0.788, 0.906, 0.0, 0.0, 0.0]
>>> [round(v, 3) for v in R.lasso(y, X5, alpha=0.3).params.tolist()]
[1.138, 0.0, 1.664, 0.0, 0.0, 0.0]
>>> [round(v, 3) for v in R.ridge(y, X5, alpha=0.3).params.tolist()]
[1.114, 0.831, 0.886, 0.047, 0.058, 0.088]
```

- 엘라스틱 넷: `x1`과 `x2`를 함께 남기고(0.79, 0.91), 잡음 열 둘을 정확히 0으로 뒀어요.
- 라소: 잡음 열은 0이지만 `x1`까지 0으로 두고 `x2` 하나에 몰아 줬어요.
- 릿지: `x1`과 `x2`를 나눠 가졌지만 잡음 열에도 작은 계수를 줬어요.

이 `alpha`에서는 작은 효과의 `x3`도 0이 됐어요. `alpha`를 줄이면 다시 들어와요.

## 목적함수

`elastic_net`은 다음을 최소화해요.

$$
\frac{1}{2\,s_w}\sum_{i=1}^{n} w_i\,\bigl(y_i - b_0 - x_i^\top\beta\bigr)^2
\;+\; \alpha\Bigl(\rho\,\lVert S\beta\rVert_1 + \frac{1 - \rho}{2}\,\lVert S\beta\rVert_2^2\Bigr)
$$

- $\rho$가 `l1_ratio`예요. 벌점 전체의 세기는 `alpha`가, 그 안에서 절댓값(L1)과 제곱(L2)의 몫은 `l1_ratio`가 정해요.
- $w_i$는 `weights`(없으면 1), $s_w = \sum_i w_i$예요. $S$는 `standardize`의 척도(기본은 단위행렬)이고, 절편 $b_0$는 벌점 밖이에요.

양 끝은 다른 함수와 같아요.

- `l1_ratio=1`은 [`lasso`](/api/regression/lasso/)의 목적함수예요. 결과도 비트까지 같아요.
- `l1_ratio=0`은 [`ridge`](/api/regression/ridge/)의 목적함수예요. 푸는 방법이 달라서 결과는 반올림 수준에서 다를 수 있어요. 순수한 릿지라면 반복 없이 푸는 `ridge`가 더 빠르고 경로도 싸요.

```python
>>> R.elastic_net(y, X, alpha=0.1, l1_ratio=1.0).params.tolist() == R.lasso(y, X, alpha=0.1).params.tolist()
True
>>> [round(v, 10) for v in R.elastic_net(y, X, alpha=0.1, l1_ratio=0.0).params.tolist()]
[1.1364487002, 0.9011101674, 1.0507462061, 0.1196367354]
>>> [round(v, 10) for v in R.ridge(y, X, alpha=0.1).params.tolist()]
[1.1364487002, 0.9011101674, 1.0507462061, 0.1196367354]
```

## `l1_ratio`: 얼마나 섞을까요

`l1_ratio`를 1에서 0으로 줄이면 라소에서 릿지로 옮겨 가요. 거의 같은 `x1`, `x2`의 계수가 점점 고르게 나뉘는 것을 볼 수 있어요.

```python
>>> for rho in (1.0, 0.9, 0.5, 0.2, 0.0):
...     e = R.elastic_net(y, X, alpha=0.1, l1_ratio=rho)
...     print(rho, [round(v, 3) for v in e.params.tolist()], round(e.df_model, 3))
1.0 [1.134, 0.0, 1.917, 0.025] 2.0
0.9 [1.137, 0.268, 1.647, 0.033] 2.074
0.5 [1.141, 0.82, 1.117, 0.074] 1.936
0.2 [1.138, 0.88, 1.066, 0.102] 1.882
0.0 [1.136, 0.901, 1.051, 0.12] 1.85
```

L2 쪽이 조금만 있어도(0.9) `x1`이 0에서 나와요. 제곱 벌점은 비슷한 두 계수를 고르게 나눌 때 가장 작아서, 서로 비슷한 열을 함께 끌어올리기 때문이에요(**묶음 효과**). L1 쪽은 계수를 정확히 0으로 만드는 힘이에요.

<Callout type="tip">
어떤 값이 좋은지 모르면 기본값 0.5로 시작하세요. 열의 일부만 쓸모 있다고 믿으면 1에 가깝게, 비슷한 열이 많고 모두 조금씩 쓸모 있다고 보면 0에 가깝게 해요. `alpha`는 [교차검증](/api/regression/cross-validation/)(`elastic_net_cv`)으로 고를 수 있어요. `elastic_net_cv`는 `l1_ratio`를 하나만 받으므로, 여러 값을 비교하려면 값마다 한 번씩 부르세요.
</Callout>

## 결과 읽기: `ElasticNetResult`

필드는 [`lasso`](/api/regression/lasso/)의 `LassoResult`와 같아요. 다른 것은 `l1_ratio`(준 값)와 `df_model`의 뜻이에요.

| 필드 | 뜻 |
|---|---|
| `params`, `param_names` | 계수(절편이 `params[0]`, 0인 계수는 정확히 0.0)와 이름 |
| `alpha`, `l1_ratio`, `standardize` | 준 값 |
| `nobs` | 적합에 쓴 행 수(가중치 > 0) |
| `df_model` | 유효 자유도(아래) |
| `converged`, `n_iter`, `dual_gap` | 수렴했는지, 반복 횟수, 쌍대 간격([`lasso`](/api/regression/lasso/)의 수렴 절) |
| `fittedvalues`, `resid`, `ssr`, `rsquared` | 적합값, 잔차, $\sum_i w_i r_i^2$, R² |
| `predict(X_new, /)` | 새 행의 예측 |

```python
>>> e = R.elastic_net(y, X, alpha=0.1)
>>> e
ElasticNetResult(alpha=0.1, nobs=40, df_model=1.93573, params=[ 1.1407982453866132  0.8198986162605268  1.1167746333823467
 0.07381508286361539])
>>> e.l1_ratio, e.converged, e.n_iter
(0.5, True, 2)
>>> round(e.rsquared, 4)
0.7509
>>> [round(v, 4) for v in e.predict(sd.asarray([[1.0, 1.0, 0.0]])).tolist()]
[3.0775]
```

### 유효 자유도 `df_model`

0이 아닌 계수의 열 집합을 A라고 할 때, 엘라스틱 넷의 유효 자유도는 다음이에요(Zou–Hastie, 2005).

$$
\text{df} = \operatorname{tr}\Bigl[Z_A\bigl(Z_A^\top \Omega Z_A + \alpha(1 - \rho)\,I\bigr)^{-1} Z_A^\top \Omega\Bigr]
$$

$Z_A$는 A의 열에서 평균을 뺀 것(`standardize`면 표준화한 것), $\Omega$는 대각이 $w_i/s_w$인 행렬이에요. 절편은 세지 않아요.

- `l1_ratio=1`(라소)이면 0 아닌 계수의 수예요.
- `l1_ratio=0`(릿지)이면 A가 모든 열이고 릿지의 $\sum s^2/(s^2 + \alpha)$예요.
- 그 사이에서는 0 아닌 계수의 수보다 작아요. L2 벌점이 남은 계수도 묶어 두기 때문이에요.

```python
>>> e.df_model
1.9357283803393746
>>> int(sum(1 for v in e.params.tolist()[1:] if v != 0.0))
3
```

계수 셋이 0이 아니지만 유효 자유도는 1.94예요.

표준오차·p값·`summary()`가 없는 것도 [`ridge`](/api/regression/ridge/), [`lasso`](/api/regression/lasso/)와 같아요. 결과는 예측을 위한 것이에요.

## 다른 인자

`alpha`의 경로, `standardize`, `weights`, `intercept`, `max_iter`, `tol`, `nan_policy`는 [`lasso`](/api/regression/lasso/)와 같은 뜻이에요.

- **경로**: `alpha`에 1차원 배열을 주면 큰 값부터 앞의 해에서 시작해 풀고, 결과는 준 순서예요. 각 해는 그 `alpha`로 따로 부른 것과 비트까지 같아요.
- **수렴**: 수렴한 해를 최적성 조건으로 다듬으므로 계수는 `tol`과 상관없이 정확한 해에 반올림 수준으로 가까워요. `max_iter`에 닿으면 `converged=False`이고 경고는 없어요.
- **표준화**: 열의 단위가 서로 다르면 `standardize=True`를 쓰세요. 단위만 바꿔도 고르는 열이 달라지는 것을 막아 줘요.

```python
>>> pe = R.elastic_net(y, X, alpha=[1.0, 0.1, 0.01])
>>> pe.params.shape, pe.df_model.shape, pe.converged.shape
((3, 4), (3,), (3,))
>>> pe.params[1].tolist() == e.params.tolist()
True
```

상수 열, NaN과 inf, 배치는 [`lasso`](/api/regression/lasso/)와 같아요. `l1_ratio`의 에러는 이래요.

## 정확도

계수 벡터의 상대오차는 정확한 해(Arb 구간 산술로 풀고 최적성 조건을 증명한 참값)와 견줘 조건이 좋은 문제에서 1.7e-15 안, 평균을 뺀 설계의 조건수가 10²–10⁶이면 8.6e-15 안이에요. 같은 입력이면 스레드 수와 상관없이 같은 비트예요. 구현은 [정규화의 구현](/internals/regression/penalized/)에 있어요.

## scikit-learn·glmnet을 아는 분께

- **목적함수, `alpha`, `l1_ratio`는 scikit-learn의 `ElasticNet`과 같아요.** `l1_ratio`의 기본값 0.5, `tol` 1e-4, `max_iter` 1000도 같아요.
- scikit-learn은 쌍대 간격이 `tol`에 닿으면 멈추므로, 열끼리 상관이 크면 기본 설정의 계수가 정확한 해와 눈에 띄게 달라요.

  ```python
  >>> import numpy as np
  >>> from sklearn.linear_model import ElasticNet
  >>> Xn, yn = np.array(X.tolist()), np.array(y.tolist())
  >>> m = ElasticNet(alpha=0.1, l1_ratio=0.5).fit(Xn, yn)
  >>> [round(v, 4) for v in m.coef_.tolist()]
  [0.8207, 1.116, 0.0738]
  >>> [round(v, 4) for v in e.params.tolist()[1:]]
  [0.8199, 1.1168, 0.0738]
  >>> mt = ElasticNet(alpha=0.1, l1_ratio=0.5, tol=1e-14, max_iter=10**6).fit(Xn, yn)
  >>> [round(v, 4) for v in mt.coef_.tolist()]
  [0.8199, 1.1168, 0.0738]
  ```

- scikit-learn의 `ElasticNetCV`는 `l1_ratio`를 여러 개 받아 함께 고르지만, 여기의 `elastic_net_cv`는 하나만 받아요.
- **R의 glmnet은 이름이 엇갈려요.** glmnet의 `lambda`가 여기의 `alpha`, glmnet의 `alpha`가 여기의 `l1_ratio`예요. 또 정규분포에서 glmnet은 `y`를 모표준편차 $s_y$로 나눠 풀고 되돌리므로, glmnet의 (`lambda`, `alpha`)를 $(\lambda, a)$라 하면 L2 쪽 세기가 $\lambda(1 - a)/s_y$가 돼요. 그래서 glmnet의 $(\lambda, a)$는 여기의 `alpha` $= \lambda a + \lambda(1 - a)/s_y$, `l1_ratio` $= \lambda a / (\lambda a + \lambda(1 - a)/s_y)$와 같은 해예요(같은 표준화 설정에서). $s_y = 1$이거나 라소(glmnet의 `alpha = 1`)면 glmnet의 `lambda`와 `alpha`가 그대로 여기의 `alpha`와 `l1_ratio`예요.
- glmnet의 `df`는 0 아닌 계수의 수라서, 엘라스틱 넷에서는 여기 `df_model`보다 크거나 같아요. glmnet은 기본으로 열을 표준화해요(`standardize = TRUE`).
