## 한눈에 보기

[`theilslopes`](/api/regression/theilslopes/)는 모든 쌍의 기울기를 한 줄로 모아 중앙값을 구해요. Siegel의 **반복 중앙값**은 중앙값을 두 번 써요.

1. 점 $i$마다, 그 점에서 다른 모든 점으로 그은 기울기들의 중앙값 $m_i$를 구해요.
2. 그 $n$개의 중앙값 $m_1, \dots, m_n$의 중앙값을 기울기로 써요.

$$
\text{slope} = \operatorname*{median}_i \; \operatorname*{median}_{j \ne i} \frac{y_i - y_j}{x_i - x_j}
$$

멀쩡한 점이 절반을 넘으면, 멀쩡한 점 $i$의 $m_i$는 멀쩡한 점들로의 기울기가 다수라서 제대로 나와요. 그리고 그런 점이 절반을 넘으니 바깥 중앙값도 제대로 나와요. 그래서 **붕괴점이 50%** 예요. Theil–Sen의 약 29%보다 훨씬 많은 이상값을 견뎌요.

스무 점 가운데 일곱(35%)이 고장 난 예를 볼게요.

```python
>>> import stardust as sd
>>> x = [float(i) for i in range(1, 21)]
>>> y = [3.1, 5.3, 6.4, 9.0, 11.7, 13.7, 15.4, 17.5, 18.4, 21.2,
...      23.5, 24.5, 27.0, 2.0, 2.1, 2.2, 2.3, 2.4, 2.5, 2.6]
>>> sd.regression.theilslopes(y, x).slope
0.09999999999999994
>>> r = sd.regression.siegelslopes(y, x)
>>> r
SiegelslopesResult(slope=1.81, intercept=1.7199999999999998)
```

진짜 기울기는 2 정도예요. Theil–Sen은 0.1로 무너졌고 Siegel은 1.81로 버텼어요.

## Theil–Sen보다 언제 더 강건한가요

고장 난 점의 수 k를 0부터 10까지 늘려 보면 차이가 보여요.

```python
>>> y_clean = y[:13] + [28.8, 30.6, 33.4, 34.8, 36.7, 39.7, 41.0]
>>> def broken(k):
...     return y_clean[:20 - k] + [2.0 + 0.1 * j for j in range(k)]
>>> [round(sd.regression.theilslopes(broken(k), x).slope, 2) for k in range(11)]
[1.99, 1.97, 1.94, 1.91, 1.88, 1.75, 0.1, 0.1, -0.02, -0.04, -0.05]
>>> [round(sd.regression.siegelslopes(broken(k), x).slope, 2) for k in range(11)]
[1.98, 1.95, 1.94, 1.93, 1.9, 1.89, 1.88, 1.81, 1.65, 0.9, -0.1]
```

| 고장 난 점 | 0–5 (25%까지) | 6–7 (30–35%) | 8 (40%) | 9–10 (45–50%) |
|---|---|---|---|---|
| Theil–Sen | 버텨요 | 무너져요 | 무너져요 | 무너져요 |
| Siegel | 버텨요 | 버텨요 | 흔들리지만 버텨요 | 무너져요 |

Siegel도 이상값 쪽으로 조금씩 끌리고, 이상값이 절반에 가까워지면 무너져요. 이 예처럼 이상값이 따로 한 줄을 이루면 이상값끼리 서로를 지지하니, 절반에 조금 못 미쳐서도 무너질 수 있어요.

대신 이상값이 없을 때는 Siegel이 덜 정확해요. 기울기 2인 직선에 정규 오차를 더한 데이터(n = 40)를 2,000번 만들어서 기울기가 흔들린 정도(분산)를 최소제곱과 견주면 이래요. 1에 가까울수록 최소제곱만큼 정확해요.

```python
>>> xs = sd.arange(40, dtype=sd.float64)
>>> E = sd.stats.Normal(mu=0.0, sigma=1.0).sample((2000, 40), rng=sd.random.default_rng(1))
>>> Y = 2.0 * xs + E
>>> v_ols = sd.var(sd.regression.ols(Y, xs).params[:, 1])
>>> round(v_ols / sd.var(sd.regression.theilslopes(Y, xs).slope), 2)
0.92
>>> round(v_ols / sd.var(sd.regression.siegelslopes(Y, xs).slope), 2)
0.71
```

정리하면 이래요.

- 이상값이 적거나 없을 것 같으면 Theil–Sen이 더 정확해요. 기울기의 신뢰구간도 줘요.
- 이상값이 30%를 넘을 수 있으면 Siegel을 쓰세요.
- 설명 변수가 여럿이면 [`rlm`](/api/regression/rlm/)의 MM이 붕괴점 50%와 높은 효율을 함께 가져요.

## `method`: 절편 구하기

- **`'hierarchical'`**(기본값): $\operatorname{median}_i(y_i - \text{slope}\cdot x_i)$. 기울기를 정한 뒤 남은 높이의 중앙값이에요.
- **`'separate'`**: 기울기처럼 반복 중앙값으로 구해요. 점 $i$마다 다른 점 $j$로 그은 직선의 절편 $y_i - s_{ij} x_i$의 중앙값을 구하고, 그 중앙값들의 중앙값을 써요.

$$
\text{intercept}_\text{separate} = \operatorname*{median}_i \; \operatorname*{median}_{j \ne i} \left(y_i - \frac{y_i - y_j}{x_i - x_j}\, x_i\right)
$$

`'separate'`는 기울기를 쓰지 않고 절편을 따로 어림해요. 그래서 둘이 정확히 한 직선을 이루지는 않아요.

```python
>>> sd.regression.siegelslopes(y, x, method='separate')
SiegelslopesResult(slope=1.81, intercept=2.8000000000000007)
>>> sd.regression.siegelslopes(y_clean, x)
SiegelslopesResult(slope=1.9775, intercept=1.31875)
>>> sd.regression.siegelslopes(y_clean, x, method='separate')
SiegelslopesResult(slope=1.9775, intercept=1.241666666666664)
```

`method`는 기울기에 영향을 주지 않아요. 이 예처럼 이상값이 한쪽에 몰려 있으면 `'hierarchical'`이 진짜 절편(1.2 정도)에 더 가까웠어요. 보통은 기본값을 쓰면 돼요.

## `x=None`, 같은 x, NaN

규칙은 [`theilslopes`](/api/regression/theilslopes/)와 같아요.

- `x`를 주지 않으면 0, 1, …, n − 1이에요. `nan_policy='omit'`으로 점을 빼도 나머지 점의 위치는 그대로예요.
- x가 같은 두 점의 기울기는 없으니 각 점의 중앙값에서 빼요. x가 모두 같으면 모든 값이 NaN이에요.
- x와 y가 ±1e308 근처까지 퍼져 두 점의 차가 모두 inf로 넘치면, 그 쌍의 기울기는 inf/inf라 값이 없어요. x가 같은 쌍처럼 각 점의 중앙값에서 빼요.
- 기울기가 0이면 +0.0을 내요.

```python
>>> sd.regression.siegelslopes([10.2, 10.8, 11.1, 11.9, 30.0, 12.6, 13.1, 13.4])
SiegelslopesResult(slope=0.47166666666666657, intercept=10.255833333333333)
>>> sd.regression.siegelslopes([1.0, 2.0, 2.0, 3.0, 3.0, 5.0], [1.0, 1.0, 2.0, 2.0, 3.0, 3.0])
SiegelslopesResult(slope=1.25, intercept=0.125)
>>> sd.regression.siegelslopes([1.0, 2.0, 3.0], [2.0, 2.0, 2.0])
SiegelslopesResult(slope=nan, intercept=nan)
>>> yn = [1.0, 2.0, float('nan'), 4.0, 5.0]
>>> sd.regression.siegelslopes(yn)
SiegelslopesResult(slope=nan, intercept=nan)
>>> sd.regression.siegelslopes(yn, nan_policy='omit')
SiegelslopesResult(slope=1.0, intercept=1.0)
>>> xb = [-1e308, 0.0, 1.0, 2.0, 3.0, 1e308]
>>> yb = [-1e308, 0.5, 1.4, 2.6, 3.5, 1e308]
>>> sd.regression.siegelslopes(yb, xb)
SiegelslopesResult(slope=1.0, intercept=0.44999999999999996)
```

마지막 예에서 양 끝 두 점을 잇는 쌍만 inf/inf라, 두 끝점은 나머지 네 점으로의 기울기로 중앙값을 구해요.

inf는 `nan_policy`와 상관없이 에러예요. `'omit'`도 점을 빼기 전에 inf를 보므로 NaN이 든 점의 inf도 에러예요. 점이 2개보다 적으면(NaN을 뺀 뒤도) 에러예요.

```python
>>> sd.regression.siegelslopes([1.0, 2.0, float('inf'), 4.0])
Traceback (most recent call last):
    ...
ValueError: siegelslopes(): 'y' contains infinity
>>> sd.regression.siegelslopes([1.0])
Traceback (most recent call last):
    ...
ValueError: siegelslopes(): 'x' and 'y' must have length at least 2
>>> sd.regression.siegelslopes([1.0, float('nan')], nan_policy='omit')
Traceback (most recent call last):
    ...
ValueError: siegelslopes(): 'x' and 'y' must have length at least 2
>>> sd.regression.siegelslopes(y, x, method='joint')
Traceback (most recent call last):
    ...
ValueError: siegelslopes(): 'method' must be 'hierarchical' or 'separate', not 'joint'
```

## 배치

마지막 축이 점의 축이고 앞 축은 배치예요. `y`와 `x`는 서로 브로드캐스트해요. 하나씩 부른 것과 비트까지 같아요.

```python
>>> rb = sd.regression.siegelslopes(sd.asarray([y, y_clean]), x)
>>> rb.slope
array([ 1.81, 1.9775], dtype=float64)
```

앞 축이 서로 브로드캐스트하지 않으면 두 인자의 배치 모양을 적은 `ValueError`예요.

```python
>>> sd.regression.siegelslopes([y, y_clean, y], [x, x])
Traceback (most recent call last):
    ...
ValueError: siegelslopes(): the batch shapes of 'y' (3,), 'x' (2,) do not broadcast
```

배치에서는 `nan_policy='omit'`을 쓸 수 없어요. 공통 규칙은 [기본 개념](/api/regression/basics/)에 있어요.

## 정확도와 큰 데이터

- 안쪽과 바깥쪽 중앙값을 모두 정확히 골라요. 결과는 쌍 기울기들로 만든 정확한 중앙값이고, 스레드 수와 상관없이 같은 비트예요.
- 점마다 다른 점들로의 기울기만 잠깐 모으므로 메모리가 n에 비례해요. 시간은 $n^2$에 비례해요. n = 10⁵도 다룰 수 있어요.

구현은 [Theil–Sen과 Siegel의 구현](/internals/regression/slopes/)에 있어요.

## scipy를 아는 분께

`scipy.stats.siegelslopes`와 인자 순서(`y`가 먼저, 그다음 `x`), 기본값, 결과(필드 순서까지 같은 `SiegelslopesResult`)가 같아요. 값은 0의 부호를 빼고 비트까지 같아요.

```python
>>> import scipy.stats
>>> scipy.stats.siegelslopes(y, x)
SiegelslopesResult(slope=np.float64(1.81), intercept=np.float64(1.7199999999999998))
```

다른 점은 [`theilslopes`](/api/regression/theilslopes/)와 같아요.

- 기울기가 0이면 sd는 언제나 +0.0을 내요.
- scipy는 inf를 받고(이때 결과가 NaN일 수 있어요), sd는 `ValueError`예요.

  ```python
  >>> scipy.stats.siegelslopes([1.0, 2.0, float('inf'), 4.0])
  SiegelslopesResult(slope=np.float64(nan), intercept=np.float64(nan))
  ```

- 차가 넘쳐 기울기가 inf/inf인 쌍은 둘 다 빼고 셈해서 값이 같아요(위의 ±1e308 예; scipy는 넘침의 `RuntimeWarning`도 내요).

  ```python
  >>> scipy.stats.siegelslopes(yb, xb)
  SiegelslopesResult(slope=np.float64(1.0), intercept=np.float64(0.44999999999999996))
  ```

- `method`는 키워드로만 받아요.
- sd는 마지막 축을 점의 축으로 보는 배치를 받아요. scipy의 기본 `axis=None`은 모든 원소를 펴고, `axis=-1`이 sd와 같아요. sd에는 `axis`, `keepdims`가 없어요.
- `x=None`에 `nan_policy='omit'`이면 sd는 빼기 전의 위치를 x로 쓰고, scipy는 뺀 뒤의 점에 0, 1, 2, …를 다시 매겨요.

  ```python
  >>> scipy.stats.siegelslopes(yn, nan_policy='omit')
  SiegelslopesResult(slope=np.float64(1.4166666666666665), intercept=np.float64(0.875))
  ```

- 점이 2개보다 적으면 sd는 `ValueError`, scipy는 경고와 함께 NaN이에요.
- 결과는 Python `float`(배치면 `sd.ndarray`)예요. scipy는 numpy의 `float64`예요.
- scipy는 n × n 배열을 만들어요. sd는 점 하나의 기울기만 잠깐 모아요.
