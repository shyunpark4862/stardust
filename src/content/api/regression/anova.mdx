## 무엇을 하나요

**분산분석표**는 반응이 흩어진 정도(제곱합)를 설명변수마다 나눠 적은 표예요. 어느 설명변수가 반응을 얼마나 설명하는지, 그 몫이 우연으로 보기에는 큰지를 한눈에 보여 줘요. `anova`는 두 가지 표를 만들어요.

| 부르는 꼴 | 표 | 묻는 질문 |
|---|---|---|
| `anova(r1, r2, r3)` | 모형 여럿의 표 | 모형을 하나씩 키울 때마다 늘어난 열들이 필요한가 |
| `anova(r)`, `anova(r, typ=1)` | Type I 항의 표 | 항을 순서대로 하나씩 넣을 때 그 항이 더 설명하는 몫이 있는가 |
| `anova(r, typ=3)` | Type III 항의 표 | 다른 항이 모두 있을 때 이 항을 빼도 되는가 |

[`ols`](/api/regression/ols/), [`wls`](/api/regression/wls/), [`gls`](/api/regression/gls/), [`glm`](/api/regression/glm/)의 결과를 받아요. GLM에서는 제곱합 대신 편차를 나눠서 **편차 분석표**가 돼요. 두 모형만 견줄 때는 [모형 비교](/api/regression/model-comparison/)의 `compare_f_test`와 같은 검정이에요.

## 모형 여럿: 이웃끼리 견준 표

[선형 가설 검정](/api/regression/hypothesis-tests/)과 같은 광고 데이터로 모형 셋을 맞춰요. TV만 쓴 모형, TV와 라디오를 쓴 모형, 네 광고를 모두 쓴 모형이에요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(6)
>>> n = 30
>>> U = sd.stats.Uniform(a=0.0, b=10.0)
>>> tv, radio, paper, sns = (U.sample(n, rng=rng) for _ in range(4))
>>> sales = 10.0 + 3.0 * tv + 2.0 * radio + sd.stats.Normal(sigma=4.0).sample(n, rng=rng)
>>> df = sd.frame.DataFrame({'tv': tv, 'radio': radio, 'paper': paper, 'sns': sns, 'sales': sales})
>>> m1 = sd.regression.ols(df['sales'], df[['tv']])
>>> m2 = sd.regression.ols(df['sales'], df[['tv', 'radio']])
>>> m4 = sd.regression.ols(df['sales'], df[['tv', 'radio', 'paper', 'sns']])
>>> a = sd.regression.anova(m1, m2, m4)
>>> a
AnovaResult(models=3, test='F')
>>> print(a.summary())
Analysis of Variance Table (models)

   df_resid      ssr  df_diff  ss_diff        F       Pr(>F)
1        28  1230.18                                        
2        27  292.264        1  937.914  92.0511  7.34661e-10
3        25  254.727        2  37.5378  1.84206     0.179362
```

줄 하나가 모형 하나예요. 둘째 줄부터는 바로 앞 줄의 모형과 견준 값이에요.

| 필드 | 뜻 |
|---|---|
| `df_resid`, `ssr` | 그 모형의 잔차 자유도와 잔차 제곱합(GLM은 편차) |
| `df_diff` | 앞 줄의 `df_resid` − 이 줄의 `df_resid`. 늘어난 계수의 수예요 |
| `ss_diff` | 앞 줄의 `ssr` − 이 줄의 `ssr`. 늘어난 열들이 더 설명한 제곱합이에요 |
| `statistic`, `pvalue` | F(또는 카이제곱) 통계량과 p값 |

첫 줄은 견줄 앞 모형이 없어서 비교 필드가 NaN이에요(`summary()`에서는 빈칸).

```python
>>> a.df_diff
array([nan, 1.0, 2.0], dtype=float64)
>>> a.ss_diff
array([              nan, 937.9144743034867, 37.53778899974077], dtype=float64)
>>> a.pvalue
array([                  nan, 7.346614154818949e-10,   0.17936185532426896], dtype=float64)
```

라디오를 더한 둘째 줄은 p값이 아주 작고, 신문과 SNS를 더한 셋째 줄은 0.18이에요. TV와 라디오까지는 필요하고 신문과 SNS는 필요하지 않다는 판단이에요.

### 척도는 가장 큰 모형의 것

F의 분모, 곧 오차 분산의 어림은 줄마다 다르게 쓰지 않고 `df_resid`가 가장 작은 모형(가장 큰 모형)의 것을 모든 줄에 써요. 분모의 자유도도 그 모형의 `df_resid`예요. 가장 큰 모형이 맞다면 그 모형의 잔차가 오차 분산의 가장 믿을 만한 어림이기 때문이에요. 그래서 셋째 줄은 `m4.compare_f_test(m2)`와 같지만, 둘째 줄은 두 모형만 견준 `m2.compare_f_test(m1)`과 달라요.

```python
>>> m4.compare_f_test(m2).fvalue, a.statistic[2]
(1.8420623432880894, 1.8420623432880894)
>>> m2.compare_f_test(m1).fvalue, a.statistic[1]
(86.6465014910695, 92.05107601575727)
```

### 순서와 검정

모형은 작은 것부터 줘도, 큰 것부터 줘도 돼요. 큰 것부터 주면 `df_diff`와 `ss_diff`가 음수로 나오고, 통계량과 p값은 같아요. 이웃한 두 모형은 어느 쪽이 크든 [모형 비교](/api/regression/model-comparison/#작은-모형은-큰-모형-안에-있어야-해요)처럼 같은 자료인지, 내포인지를 확인해요.

```python
>>> print(sd.regression.anova(m4, m2, m1).summary())
Analysis of Variance Table (models)

   df_resid      ssr  df_diff   ss_diff        F       Pr(>F)
1        25  254.727                                         
2        27  292.264       -2  -37.5378  1.84206     0.179362
3        28  1230.18       -1  -937.914  92.0511  7.34661e-10
```

`test='Chisq'`를 주면 `ss_diff`를 척도로 나눈 값을 자유도 `df_diff`의 카이제곱 분포로 재요. 선형 모형에서는 보통 기본값 `'F'`를 써요.

```python
>>> sd.regression.anova(m1, m2, m4, test='Chisq').pvalue
array([                  nan, 8.446800243958934e-22,   0.15849022756798448], dtype=float64)
```

## 모형 하나: 항의 표

결과를 하나만 주면 설명변수(**항**)마다 줄이 하나인 표예요. 마지막 줄 `'Residual'`은 잔차의 자유도와 제곱합이에요.

| 필드 | 뜻 |
|---|---|
| `terms` | 항의 이름. 마지막은 `'Residual'` |
| `df` | 항의 자유도(그 항이 더하는 계수의 수) |
| `sum_sq` | 항이 맡은 제곱합 |
| `mean_sq` | `sum_sq / df` |
| `statistic`, `pvalue` | 항의 F(또는 카이제곱)와 p값. `'Residual'` 줄은 NaN |

### Type I: 순서대로 더하기

Type I(`typ=1`, 기본값)은 절편만의 모형에서 시작해 항을 주어진 순서로 하나씩 더하면서, 잔차 제곱합이 줄어드는 양을 그 항의 몫으로 적어요. 그래서 항들의 `sum_sq`와 잔차 제곱합을 모두 더하면 반응의 전체 제곱합(`centered_tss`)이에요.

```python
>>> t1 = sd.regression.anova(m4)
>>> print(t1.summary())
Analysis of Variance Table (Type I)

          df   sum_sq  mean_sq         F       Pr(>F)
tv         1  872.203  872.203   85.6019  1.50279e-09
radio      1  937.914  937.914   92.0511  7.34661e-10
paper      1  2.23554  2.23554  0.219406     0.643551
sns        1  35.3022  35.3022   3.46472    0.0744897
Residual  25  254.727  10.1891                       
>>> float(sd.sum(t1.sum_sq)), m4.centered_tss
(2102.3823430053876, 2102.3823430053876)
```

`radio` 줄은 TV가 이미 들어 있을 때 라디오가 더 설명하는 몫이에요. 위 모형 여럿의 표의 둘째 줄과 같은 값인 것도 그래서예요.

Type I의 몫은 **순서에 달려 있어요**. 설명변수끼리 상관이 있으면, 앞에 넣은 항이 뒤의 항과 겹치는 몫까지 가져가요. 이 데이터에서 신문 광고비는 우연히 TV(상관 0.24)와 라디오(0.22)와 함께 움직였어요. 신문을 맨 앞에 넣으면 TV와 라디오가 설명할 몫의 일부를 신문이 가져가서, 효과가 없는 신문의 p값이 0.0003이 돼요.

```python
>>> print(sd.regression.anova(m4, terms=['paper', 'sns', 'tv', 'radio']).summary())
Analysis of Variance Table (Type I)

          df   sum_sq  mean_sq         F       Pr(>F)
paper      1  177.007  177.007   17.3722  0.000321489
sns        1  7.53633  7.53633  0.739648     0.397946
tv         1  732.563  732.563    71.897  8.00504e-09
radio      1   930.55   930.55   91.3283  7.94416e-10
Residual  25  254.727  10.1891                       
```

`terms`의 순서가 넣는 순서예요. Type I은 "이 순서로 쌓는다"는 물음에 맞는 표라서, 순서에 뜻이 있을 때(통제할 변수를 먼저, 관심 있는 변수를 나중에) 써요.

### Type III: 마지막에 빼기

Type III(`typ=3`)은 항마다 "다른 항이 모두 있을 때 이 항의 계수가 모두 0인가"를 검정해요. 항마다 그 항을 마지막에 넣은 셈이라 순서와 상관없어요. 열 하나짜리 항의 F는 그 계수의 t값의 제곱이고, 그 항만 뺀 모형과 [`compare_f_test`](/api/regression/model-comparison/)로 견준 F와 같아요.

```python
>>> t3 = sd.regression.anova(m4, typ=3)
>>> print(t3.summary())
Analysis of Variance Table (Type III)

          df   sum_sq  mean_sq         F       Pr(>F)
tv         1  1048.11  1048.11   102.866  2.40897e-10
radio      1   930.55   930.55   91.3283  7.94416e-10
paper      1  1.11313  1.11313  0.109247     0.743757
sns        1  35.3022  35.3022   3.46472    0.0744897
Residual  25  254.727  10.1891                       
>>> t3.statistic[0], m4.tvalues[1] ** 2
(102.86641834938669, 102.86641834938666)
>>> drop_tv = sd.regression.ols(df['sales'], df[['radio', 'paper', 'sns']])
>>> m4.compare_f_test(drop_tv).fvalue, t3.sum_sq[0], drop_tv.ssr - m4.ssr
(102.86641834938663, 1048.1127094389658, 1048.1127094389653)
```

Type III의 `sum_sq`는 그 항을 뺐을 때 늘어나는 잔차 제곱합이에요. 항들이 서로 겹치는 몫은 어느 항에도 들어가지 않아서, Type I과 달리 모두 더해도 전체 제곱합이 되지 않아요.

<Callout type="tip" title="Type II는 없어요">
Type II는 항마다 "그 항을 품는 항(상호작용)을 뺀 나머지가 모두 있을 때"를 검정해요. 어느 항이 어느 항을 품는지는 열 값만으로 알 수 없어서 두지 않았어요. 상호작용이 없는 모형에서는 Type II와 Type III가 같은 검정이에요.
</Callout>

### 열 묶음을 한 항으로

`terms`로 여러 열을 한 항으로 묶을 수 있어요. 항마다 열의 이름이나 위치(0부터)의 목록을 주고, 항의 이름은 열 이름을 `' + '`로 이어 붙여요. 묶은 항의 F는 그 열들을 한꺼번에 검정해요. 아래 `paper + sns` 줄은 [`compare_f_test`의 예](/api/regression/model-comparison/#compare_f_test-f-검정)의 F = 1.84와 같아요.

```python
>>> g = sd.regression.anova(m4, terms=[['tv', 'radio'], [2, 3]])
>>> print(g.summary())
Analysis of Variance Table (Type I)

             df   sum_sq  mean_sq        F       Pr(>F)
tv + radio    2  1810.12  905.059  88.8265  4.36353e-12
paper + sns   2  37.5378  18.7689  1.84206     0.179362
Residual     25  254.727  10.1891                      
>>> g.terms
['tv + radio', 'paper + sns', 'Residual']
```

`terms`는 X의 모든 열을 한 번씩 덮어야 해요. 빠뜨리거나 두 번 쓰면 에러예요.

```python
>>> sd.regression.anova(m4, terms=['tv', 'radio', 'paper'])
Traceback (most recent call last):
    ...
ValueError: anova(): 'terms' must put every column of 'X' in a term; missing ['sns']
>>> sd.regression.anova(m4, terms=['tv', 'radio', ['paper', 'tv'], 'sns'])
Traceback (most recent call last):
    ...
ValueError: anova(): the column 'tv' is in more than one term
```

## 범주형 설명변수

비료 셋(A, B, C)과 물 주기 두 가지(적게, 많이)로 키운 작물의 수확량이에요. 칸마다 그루 수가 달라요. 물을 많이 주면 B가 특히 많이 늘도록(상호작용) 만들었어요.

범주형 변수는 **더미 열**로 바꿔서 넣어요. 수준이 셋인 비료는 기준 수준(A)을 뺀 두 열 `fB`, `fC`(그 수준이면 1, 아니면 0)가 되고, 물은 `water`(많이 주면 1) 한 열이 돼요. 상호작용은 더미끼리 곱한 열이에요. 더미 둘이 비료라는 하나의 변수이니 `terms`로 묶어요.

```python
>>> rng = sd.random.default_rng(7)
>>> cells = [('A', 0, 5, 20.0), ('A', 1, 3, 22.0), ('B', 0, 4, 23.0), ('B', 1, 6, 32.0), ('C', 0, 4, 21.0), ('C', 1, 3, 24.0)]
>>> fert = [f for f, w, k, m in cells for _ in range(k)]
>>> water = sd.asarray([float(w) for f, w, k, m in cells for _ in range(k)])
>>> mean = sd.asarray([m for f, w, k, m in cells for _ in range(k)])
>>> yld = mean + sd.stats.Normal(sigma=2.0).sample(len(fert), rng=rng)
>>> fB = sd.asarray([float(f == 'B') for f in fert])
>>> fC = sd.asarray([float(f == 'C') for f in fert])
>>> d = sd.frame.DataFrame({'fB': fB, 'fC': fC, 'water': water, 'fB:water': fB * water, 'fC:water': fC * water})
>>> crop = sd.regression.ols(yld, d)
>>> terms = [['fB', 'fC'], ['water'], ['fB:water', 'fC:water']]
>>> print(sd.regression.anova(crop, terms=terms).summary())
Analysis of Variance Table (Type I)

                     df   sum_sq  mean_sq        F       Pr(>F)
fB + fC               2  345.169  172.584  35.8027  3.59086e-07
water                 1  172.833  172.833  35.8542  9.21413e-06
fB:water + fC:water   2  19.9253  9.96264  2.06675     0.154122
Residual             19  91.5882  4.82043                      
>>> print(sd.regression.anova(crop, typ=3, terms=terms).summary())
Analysis of Variance Table (Type III)

                     df   sum_sq  mean_sq        F      Pr(>F)
fB + fC               2  60.0093  30.0046  6.22447  0.00833494
water                 1  25.7408  25.7408  5.33993   0.0322288
```

칸의 그루 수가 달라서(균형이 맞지 않아서) 비료와 물이 서로 겹치는 몫이 있고, Type I과 Type III의 주효과 줄이 달라요. 상호작용 줄은 마지막 항이라 둘에서 같아요.

### 일원 분산분석

항이 비료 하나뿐인 표는 세 집단의 평균이 같은지 보는 **일원 분산분석**이에요. 집단을 따로 받는 `sd.htest.f_oneway`와 같은 F와 p값이 나와요.

```python
>>> one = sd.regression.anova(sd.regression.ols(yld, d[['fB', 'fC']]), terms=[['fB', 'fC']])
>>> print(one.summary())
Analysis of Variance Table (Type I)

          df   sum_sq  mean_sq        F       Pr(>F)
fB + fC    2  345.169  172.584  13.3529  0.000159682
Residual  22  284.346  12.9248                      
>>> sd.htest.f_oneway(*[yld[[i for i, f in enumerate(fert) if f == L]] for L in 'ABC'])
FOnewayResult(statistic=13.3529, pvalue=0.000159682, df_num=2, df_denom=22)
```

### Type III는 더미 부호화에 달려 있어요

<Callout type="warn" title="상호작용이 있는 Type III는 부호화부터 확인해요">
위의 0/1 더미(**처리 대비**)에서 `water`의 계수는 "비료 A일 때 물을 많이 준 효과"예요. 상호작용 열이 B와 C에서의 차이를 따로 맡기 때문이에요. 그래서 Type III의 `water` 줄은 물 주기의 평균적인 효과가 아니라 **기준 수준(A)에서의** 효과를 검정해요. 비료 줄도 "물을 적게 줄 때의" 비료 차이예요. 주효과를 "다른 변수의 수준에 걸친 평균적인 효과"로 읽으려면 **합 대비**로 부호화해요.
</Callout>

처리 대비의 `water` 줄의 F는 `water` 계수의 t값의 제곱이에요. 이 계수는 A에서의 물의 효과(참값 2)예요.

```python
>>> names = crop.param_names
>>> crop.params[names.index('water')]
3.7051870178021336
>>> crop.t_test([float(nm == 'water') for nm in names]).tvalue ** 2
5.339929806845698
```

합 대비는 수준마다 1, 0과 마지막 수준의 −1로 부호화해요. 비료는 `fA`(A면 1, C면 −1), `fB`(B면 1, C면 −1) 두 열이고, 물은 적게면 1, 많이면 −1이에요. 열 공간은 처리 대비와 같아서 적합(`ssr`, 적합값)과 Type I 표는 그대로이고, Type III의 주효과 줄만 바뀌어요.

```python
>>> code = {'A': (1.0, 0.0), 'B': (0.0, 1.0), 'C': (-1.0, -1.0)}
>>> sA = sd.asarray([code[f][0] for f in fert])
>>> sB = sd.asarray([code[f][1] for f in fert])
>>> sw = 1.0 - 2.0 * water
>>> ds = sd.frame.DataFrame({'fA': sA, 'fB': sB, 'water': sw, 'fA:water': sA * sw, 'fB:water': sB * sw})
>>> crop_s = sd.regression.ols(yld, ds)
>>> crop_s.ssr, crop.ssr
(91.58821440633955, 91.58821440633955)
>>> terms_s = [['fA', 'fB'], ['water'], ['fA:water', 'fB:water']]
>>> print(sd.regression.anova(crop_s, typ=3, terms=terms_s).summary())
Analysis of Variance Table (Type III)

                     df   sum_sq  mean_sq        F       Pr(>F)
fA + fB               2  237.136  118.568   24.597  5.34042e-06
water                 1  154.318  154.318  32.0133  1.86903e-05
fA:water + fB:water   2  19.9253  9.96264  2.06675     0.154122
Residual             19  91.5882  4.82043                      
```

물 주기의 F가 5.34에서 32.0으로 커졌어요. B에서 물의 효과가 크니, 세 비료에 걸친 평균적인 효과는 A에서의 효과보다 커요. 상호작용 줄은 두 부호화에서 같아요.

상호작용이 없는 모형에서는 Type III 표가 부호화와 상관없어요.

```python
>>> add = sd.regression.ols(yld, d[['fB', 'fC', 'water']])
>>> add_s = sd.regression.ols(yld, ds[['fA', 'fB', 'water']])
>>> sd.regression.anova(add, typ=3, terms=[['fB', 'fC'], 'water']).statistic
array([22.820849298334615, 32.547534730088394,                nan], dtype=float64)
>>> sd.regression.anova(add_s, typ=3, terms=[['fA', 'fB'], 'water']).statistic
array([ 22.82084929833459, 32.547534730088394,                nan], dtype=float64)
```

더미는 사용자가 만들어 넘겨요. `anova`는 열 값만 보고, 그 열이 어느 부호화인지 알지 못해요.

## GLM: 편차 분석

[`glm`](/api/regression/glm/)의 결과를 주면 잔차 제곱합 대신 편차(`deviance`)를 나눠요.

- **Type I**: 항을 순서대로 하나씩 더한 모형을 같은 설정으로 다시 적합해서 편차가 줄어드는 양을 적어요. 첫 항은 절편만의 모형의 편차(`null_deviance`)에서 시작해요.
- **Type III**: 항마다 그 계수가 모두 0인지 묻는 Wald 검정([`wald_test`](/api/regression/hypothesis-tests/))이에요. 그 항을 빼고 다시 적합하지 않아요.
- 척도가 고정인 모형(기본값의 이항·포아송)은 기본이 `'Chisq'`, 척도를 추정하는 모형(기본값의 정규·감마, `scale='X2'`·`'dev'`)은 `'F'`예요.

투약량과 나이로 반응 여부를 설명한 로지스틱 회귀예요.

```python
>>> rng = sd.random.default_rng(3)
>>> dose = sd.stats.Uniform(a=0.0, b=4.0).sample(100, rng=rng)
>>> age = sd.stats.Uniform(a=20.0, b=60.0).sample(100, rng=rng)
>>> p = 1.0 / (1.0 + sd.exp(-(-2.0 + 1.0 * dose)))
>>> yb = (rng.random(100) < p) * 1.0
>>> gl = sd.regression.glm(yb, sd.frame.DataFrame({'dose': dose, 'age': age}), family='binomial')
>>> ga = sd.regression.anova(gl)
>>> print(ga.summary())
Analysis of Variance Table (Type I)

          df     sum_sq    mean_sq      Chisq     Pr(>Chi)
dose       1    34.2464    34.2464    34.2464  4.85574e-09
age        1  0.0268217  0.0268217  0.0268217      0.86991
Residual  97    95.2161   0.981609                        
>>> gl.null_deviance - gl.deviance, float(sd.sum(ga.sum_sq[:2]))
(34.27321886412231, 34.27321886412231)
>>> print(sd.regression.anova(gl, typ=3).summary())
Analysis of Variance Table (Type III)

          df     sum_sq    mean_sq      Chisq     Pr(>Chi)
dose       1     23.047     23.047     23.047  1.58091e-06
age        1  0.0268219  0.0268219  0.0268219     0.869909
Residual  97    95.2161   0.981609                        
>>> gl.tvalues ** 2
array([   3.938737025754865,    23.04697596085645, 0.026821894469078306], dtype=float64)
```

Type I의 `dose` 줄(34.2)은 절편만의 모형에 투약량을 더할 때 줄어든 편차, 곧 우도비 통계량이에요. Type III의 `dose` 줄(23.0)은 나이가 들어 있을 때 투약량의 계수가 0인지 묻는 Wald 통계량이고, 그 계수의 z값의 제곱이에요. 묻는 모형도 통계량의 꼴도 달라서 값이 달라요.

척도를 추정하는 분포족에서는 편차의 감소를 항의 자유도와 척도(`scale`)로 나눈 F예요. F의 분모는 표의 `'Residual'` 줄의 `mean_sq`(편차 ÷ `df_resid`)가 아니라 모형의 `scale`이에요. 감마 분포처럼 `scale`이 Pearson 통계량으로 어림한 값이면 둘이 달라요.

```python
>>> rng = sd.random.default_rng(5)
>>> x1 = sd.stats.Uniform(a=0.0, b=2.0).sample(60, rng=rng)
>>> x2 = sd.stats.Uniform(a=0.0, b=2.0).sample(60, rng=rng)
>>> cost = sd.stats.Gamma(a=4.0).sample(60, rng=rng) * sd.exp(0.5 + 0.8 * x1) / 4.0
>>> gm = sd.regression.glm(cost, sd.stack([x1, x2], axis=-1), family='gamma', link='log')
>>> gt = sd.regression.anova(gm)
>>> print(gt.summary())
Analysis of Variance Table (Type I)

          df     sum_sq    mean_sq         F       Pr(>F)
x1         1    10.2344    10.2344   47.2125  5.21504e-09
x2         1  0.0769961  0.0769961  0.355194     0.553547
Residual  57    11.4649   0.201139                       
>>> gt.sum_sq[0] / gm.scale, gt.mean_sq[2], gm.scale
(47.21253034846571, 0.20113895387891895, 0.21677217507770194)
```

척도가 고정인 GLM에 `test='F'`를 주면 에러예요.

```python
>>> sd.regression.anova(gl, test='F')

    ...
ValueError: anova(): the binomial model's scale is fixed: its deviance test is test='Chisq' (or None)
```

- **겹친 열**: Type I에서 앞의 열들과 겹친 열은 더하는 것이 없어서 `df`가 0, `sum_sq`가 0이에요. Type III에서는 겹친 열을 빼고 검정하고, 항의 열이 모두 겹치면 `df`가 0이고 나머지가 NaN이에요. 어느 열이 겹친 것으로 남는지는 열 순서로 정해져요.

## 결과 클래스

`AnovaResult`는 `sd.regression`에 있는 결과 클래스예요. 표의 열 하나가 필드 하나예요.

- 배열 필드는 표의 줄 수만큼의 쓰기 금지 배열이고, `terms`는 읽을 때마다 새 리스트예요.

- `test`는 `'F'` 또는 `'Chisq'`, `typ`은 모형 여럿의 표면 None, 항의 표면 1 또는 3이에요.

## statsmodels·R을 아는 분께

statsmodels 0.15.0, R 4.6.2와 car 3.1.5 기준이에요.

| sd | statsmodels | R |
|---|---|---|
| `anova(r1, r2, r3)` | `anova_lm(r1, r2, r3)` | `anova(m1, m2, m3)` |
| `anova(r)`, `anova(r, terms=...)` | `anova_lm(r, typ=1)` | `anova(m)` |
| `anova(r, typ=3)` | `anova_lm(r, typ=3)` | `car::Anova(m, type = 3)`, `drop1(m, test = "F")`(lm) |
| `anova(r, typ=3)`, 강건 공분산 | `anova_lm(r, typ=3, robust='hc3')` | `car::Anova(m, type = 3, white.adjust = "hc3")` |
| `anova(g)`(GLM) | | `anova(g)` |
| `anova(g, typ=3)`(GLM) | | `car::Anova(g, type = 3, test.statistic = "Wald")` |

- 이 페이지의 표는 R의 같은 표와 반올림 차이 안에서 같아요(비료 예의 Type III는 R에서 `options(contrasts = ...)`로 같은 부호화를 골랐을 때). Type III의 `sum_sq`는 statsmodels처럼 F × 자유도 × 척도로 적어요(그 항을 뺀 적합과의 잔차 제곱합 차이와 같아요).
- car `Anova(type = 3)`와 statsmodels `anova_lm(typ=3)`의 표에는 절편 줄이 있어요. sd에서 절편은 항이 아니라서 그 줄이 없어요. 절편의 검정은 결과의 `tvalues`, `pvalues`에 있어요.
- 모형 여럿의 표에서 statsmodels의 p값은 줄마다 그 줄 모형의 `df_resid`를 분모 자유도로 써서, 모형이 셋 이상이면 가운데 줄이 달라요. 위 광고 예의 둘째 줄은 statsmodels가 3.43e-10, sd와 R이 7.35e-10이에요(F는 셋이 모두 92.05).
- statsmodels의 한 모형 표는 공식(`ols('y ~ C(f) * w', data)`)으로 만든 모형에서만 항을 알아요. sd는 공식이 없어서 `terms`로 열을 묶어 항을 알려 줘요. 이름도 공식의 항 이름이 아니라 열 이름을 이은 것이에요.
- R과 statsmodels에는 Type II가 있지만(car `Anova`의 기본, `anova_lm(typ=2)`), sd에는 없어요. 항의 포함 관계를 공식에서 읽기 때문이에요.
- GLM의 Type III는 Wald 검정이에요. R의 `drop1(g, test = "Chisq")`와 car `Anova(g, type = 3)`의 기본(`test.statistic = "LR"`)은 항을 빼고 다시 적합한 우도비라서 값이 달라요. 위 로지스틱 예의 `dose`는 그 우도비가 33.8, sd의 Wald가 23.0이에요.
- `test`의 이름 `'F'`, `'Chisq'`와 GLM의 기본값은 R의 `anova.glm`과 같아요. R은 척도가 고정인 GLM에 `test = "F"`를 주면 경고하고 계산하지만, sd는 에러예요.
