## 한 문단 소개

stardust는 배열, 선형대수, 데이터프레임을 처음부터 다시 만든 Python 라이브러리다. 이 문단은 본문 서체와 줄 간격, 문단 사이 여백을 보여주는 자리이고, 실제 소개 글은 나중에 쓴다. 영문과 숫자가 섞인 문장도 확인한다: C++20 core, Python 3.15, 12,424 golden outputs.

<Callout>
  이 페이지의 글은 모두 자리 채움이다. 제목, 문단, 목록, 코드, 표, 콜아웃이 어떻게 보이는지만 확인한다.
</Callout>

## 설치

코드 블록은 Cascadia Code로 그린다. 합자(`!=`, `->`, `>=`)도 켜져 있다.

```bash
python3.15 -m venv .venv
.venv/bin/pip install --no-build-isolation -e .
```

## 첫 예제

```python
import stardust as sd

x = sd.arange(12.0).reshape((3, 4))
y = sd.sin(x.T) @ x
x[x > 5] = 0.0
```

### 목록

- 첫째 항목은 한 줄이다.
- 둘째 항목은 `sd.linalg`처럼 인라인 코드를 품는다.
  - 안쪽 목록의 들여쓰기와 간격.
- 셋째 항목은 [링크](/api/)를 품는다.

### 표

| 영역 | 이름공간 | 상태 |
|---|---|---|
| 배열 | `sd` | 구현 완료 |
| 선형대수 | `sd.linalg` | 구현 완료 |
| 통계 | `sd.stats` | 설계 중 |
