## 문제

구현 상세 글은 문제에서 출발한다. 이 문단은 자리 채움이며, 실제 글은 나중에 쓴다. 긴 문단이 본문 폭 안에서 어떻게 흐르는지 보려고 문장을 조금 더 잇는다. 결과는 스레드 수와 무관하게 비트까지 같아야 한다는 조건이 설계를 어떻게 묶는지 설명하는 자리다.

> 병렬화는 속도만 바꾸고 답은 바꾸지 않는다.

## 설계

### 작업의 분할

C++ 코드 블록의 견본이다.

```cpp
// Splits [0, n) into fixed-size chunks so the result does not depend
// on how many threads run them.
template <typename F>
void parallel_for(std::size_t n, std::size_t grain, F&& body) {
    const std::size_t chunks = (n + grain - 1) / grain;
    pool().run(chunks, [&](std::size_t c) {
        body(c * grain, std::min(n, (c + 1) * grain));
    });
}
```
