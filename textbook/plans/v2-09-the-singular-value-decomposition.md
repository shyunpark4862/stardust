# 1권 21장 The Singular Value Decomposition — 얼개

예비 권(리뷰 방식). Part III의 아홉째 장. 특이값 분해의 존재, 기하적 의미, 낮은 계수 근사(Eckart–Young), 유사역행렬, 행렬 노름과 조건수를 다룬다. plans/PROMISES.md에서 21장 앞으로 온 약속을 모두 지킨다(10·13·14·15·16·17·18·19·20장에서): ‖A‖₂ = 가장 큰 특이값(10장), 13장 예의 유사역행렬 (1,2)/5와 ‖A‖₂ = (15+5√5)^{1/2}·조건수 κ·Eckart–Young·외적의 합으로서의 SVD(13장), 최소 노름 해와 κ₂(14장), 수치 계수의 정확한 꼴(허용오차 τ 위의 특이값 수 = ‖A − B‖₂ ≤ τ인 B의 최소 계수)과 A + E의 특이값이 ‖E‖₂ 넘게 움직이지 않음(15장), 정규직교 기저를 양쪽에서 고른 계수 표준형(16장), 1/κ₂ = 가장 가까운 특이 행렬까지의 상대 거리(17장), x⁺ = A⁺b·모든 행렬에서 κ₂(AᴴA) = κ₂(A)²·κ₂의 정식 정의(18장의 임시 정의 "단위 벡터 상의 최장/최단 비"를 갈음)(18장), 단위원의 상인 타원의 축·κ₂(T_n)(19장), 특이값은 내림차순이고 σ_i(A)² = λ_{n+1−i}(AᴴA)(20장이 고윳값을 오름차순으로 정했으므로 이 관계를 명시)·AᴴA의 스펙트럼 정리에서 SVD·‖A‖₂² = λ_max(AᴴA)·극분해·주성분(20장). PROMISES.md를 직접 읽고 빠뜨리지 않는다. Schur·Jordan(22장)은 쓰지 않는다. 𝔽 = ℝ, ℂ 함께(Aᴴ).

## Abstract (한 문단, 120단어 이내, 동기부여)
모든 행렬은 — 정사각이든 아니든, 대칭이든 아니든 — 직교 좌표를 양쪽에서 잘 고르면 대각 행렬이 된다. 이 분해가 계수, 노름, 조건수, 가장 가까운 낮은 계수 행렬, 최소제곱의 최소 노름 해를 한꺼번에 준다. 자료 행렬에서는 "가장 중요한 방향"을 순서대로 뽑아내는 도구이고, 수치 계산에서는 "거의 특이함"을 재는 유일하게 믿을 만한 자라는 점.

## 절 구성
21.1 The Geometry of a Linear Map — 2×2 예로 단위원의 상이 타원임을 보이고(19·20장 그림과 이어서: 대칭이 아니면 고유벡터는 축이 아니다), 타원의 반축 길이 = 특이값, 축 방향 = 왼쪽 특이벡터, 그 원상 = 오른쪽 특이벡터. A = (회전/반사)(축별 늘이기)(회전/반사). 그림: V^ᴴ, Σ, U 세 단계 패널(20장 그림 20.2의 QᵀΛQ 그림과 짝).
21.2 Existence of the SVD — 정리: 모든 A ∈ 𝔽^{m×n}에 A = UΣVᴴ(U, V 유니터리, Σ 대각, σ₁ ≥ … ≥ σ_r > 0 = …). 증명: AᴴA(반정치)의 스펙트럼 정리(20장)에서 V와 σ_i = √λ, u_i = Av_i/σ_i가 정규직교임, U의 완성. 둘째 증명(변분: ‖Ax‖의 최대점에서 귀납)을 주면 좋다(한쪽은 완전히, 다른 쪽은 줄거리여도 됨). 유일성: 특이값은 유일, 특이벡터는 단순 특이값에서 위상 인자까지(증명). 얇은(thin)·축약(compact) 꼴과 외적 전개 A = Σσ_i u_i v_iᴴ(13장 연결), 손 계산 예(2×2, 3×2), 13장의 예 행렬. 특이값과 고윳값의 관계: σ_i(A)² = λ(AᴴA) = λ(AAᴴ)의 0 아닌 것들(19장 AB·BA), Hermite이면 σ = |λ|, 정규이면 σ = |λ|, 일반으로는 |λ| ≤ σ₁(19장 ρ ≤ ‖·‖), |det A| = ∏σ_i(17장), ‖A‖_F² = Σσ_i²(13장 대각합).
21.3 The Four Subspaces Again — U, V의 열이 네 기본 부분공간의 정규직교 기저(증명; 15·18장 그림의 완결), 계수 = 0 아닌 특이값의 수, 16장 계수 표준형의 직교판(동치 불변량이 계수뿐이었던 것이 유니터리 동치에서는 특이값 전체가 됨; 증명), 직교 사영 P_{C(A)} = U_r U_rᴴ 등.
21.4 Norms — ‖A‖₂ = σ₁(증명; 10·13·18·20장의 정의들과 일치 확인), ‖A‖₂² = λ_max(AᴴA), 유니터리 불변 노름(2-노름·Frobenius), ‖A‖₂ ≤ ‖A‖_F ≤ √r ‖A‖₂와 13장 1·∞-노름과의 부등식(증명), ‖Aᴴ‖₂ = ‖A‖₂, ‖AᴴA‖₂ = ‖A‖₂², σ_min과 min‖Ax‖/‖x‖(완전 열 계수), 핵 노름 Σσ_i는 정의와 한 문단(쌍대성은 note), 13장 예의 ‖A‖₂ 값 확인.
21.5 Low-Rank Approximation — 절단 SVD A_k = Σ_{i≤k}σ_i u_i v_iᴴ, Eckart–Young–Mirsky: 2-노름에서 min_{rank B ≤ k}‖A − B‖₂ = σ_{k+1}(증명: 차원 세기), Frobenius 노름에서 = (Σ_{i>k}σ_i²)^{1/2}(증명 — Weyl 부등식의 특이값 꼴 또는 사영 논증으로 완전히), 최적해의 유일성 조건, 따름: 가장 가까운 특이 행렬까지의 거리 = σ_n(17장 약속: 1/κ₂ = 상대 거리)·가장 가까운 계수 k 행렬까지의 거리, 수치 계수의 정확한 뜻(15장 약속 완결), 예: 작은 행렬의 계수 1·2 근사, 그림(그레이스케일 무늬 행렬 — 직접 만든 합성 무늬 — 의 k = 1, 2, 5, 20 근사와 특이값 감소 그래프; 저장량 k(m+n+1) 대 mn).
21.6 Perturbation of Singular Values — 특이값의 min–max 표현(20장 Courant–Fischer를 AᴴA 또는 [0 A; Aᴴ 0]에 적용; 증명), Weyl: |σ_i(A + E) − σ_i(A)| ≤ ‖E‖₂(증명; 15장 약속), 엇갈림(행·열을 지울 때; 진술 + 증명 짧으면), Mirsky(Frobenius 꼴)는 진술 + 참고, Hermite 확대 행렬 [0 A; Aᴴ 0]의 고윳값이 ±σ_i(증명).
21.7 The Pseudoinverse — A⁺ = VΣ⁺Uᴴ의 정의, Moore–Penrose 네 조건과 유일성(증명), A⁺b가 최소제곱의 최소 노름 해(18장 prop:minimum-norm과 연결; 증명), 완전 열 계수면 A⁺ = (AᴴA)⁻¹Aᴴ·완전 행 계수면 Aᴴ(AAᴴ)⁻¹·가역이면 A⁻¹(증명), AA⁺·A⁺A가 직교 사영(네 부분공간), 13장 예 (1,2)/5 확인, 불연속성: 계수가 바뀌는 섭동에서 A⁺가 튄다(예: diag(1, ε))와 절단 유사역행렬·Tikhonov 정칙화 x_μ = (AᴴA + μI)⁻¹Aᴴb = Σ σ_i/(σ_i² + μ) … (증명; 필터 인자 그림), (AB)⁺ ≠ B⁺A⁺ 반례.
21.8 Condition Numbers — κ₂(A) = σ₁/σ_n(정사각 가역)과 일반 κ₂ = σ₁/σ_r, 18장의 임시 정의와 일치(증명), 14장 prop:perturbed-solution의 2-노름 꼴과 한계가 달성됨(최악의 b, δb가 특이벡터; 증명), κ₂(AᴴA) = κ₂(A)²(모든 완전 열 계수 행렬; 18장 약속; 증명)과 정규방정식의 손실, 최소제곱 문제의 민감도(진술: κ와 κ²·잔차 항 — 18장이 Higham을 인용해 적은 꼴과 일치시키고, 증명은 8권으로; 작은 잔차 경우의 간단한 한계는 증명), κ₂(T_n)(20장 값 인용)·Hilbert 행렬(장 안에서만 쓰는 기호로)의 κ₂ 증가, 유니터리 행렬은 κ₂ = 1이고 그것들뿐(스칼라배까지; 증명), 조건수와 행렬식의 무관함(17장 예 재론).
21.9 Polar Decomposition and Principal Components — 극분해 A = UP(P = (AᴴA)^{1/2} 반정치 — 20장 thm:square-root, U 유니터리/부분 등거리; 존재·가역일 때 유일성; 증명), 가장 가까운 유니터리 행렬 = 극 인자(직교 Procrustes 문제; 증명 — 대각합 부등식으로), 주성분: 중심화한 자료 행렬 X의 SVD와 표본 공분산 XᵀX/(N−1)의 스펙트럼 분해가 같은 것(증명), 첫 주성분 = 분산을 최대화하는 방향(20장 Rayleigh), k개 주성분 = 최적 계수 k 근사(Eckart–Young), 예: 2차원 상관 자료 산점도와 주축(그림), 총최소제곱은 note 또는 한 문단(18장의 수직 거리 대 세로 잔차와 연결).
21.10 The SVD in Computation: A First Look — 공용 빌드(API 이름은 API-INVENTORY.md에서 확인: sd.linalg.svd, svdvals, pinv, matrix_rank, cond, lstsq 등)로 작은 실험: (1) AᴴA의 고윳값으로 특이값을 구하면 작은 특이값을 잃는다(Läuchli 행렬: 정확값 대 eigvalsh(AᵀA)^{1/2} 대 svdvals; 직접 계산해 표), (2) 15장 계수 실험 표를 특이값으로 다시 읽기(matrix_rank의 허용오차와 특이값), (3) Hilbert 계의 절단 SVD·Tikhonov 해와 보통 해의 오차 표(우변에 작은 잡음을 넣어), (4) 합성 무늬 행렬의 계수 k 근사 오차가 σ_{k+1}과 같은지(Eckart–Young의 수치 확인). 실제 알고리즘(이중대각화, Golub–Kahan, 분할 정복)은 8권. 수치는 직접 잰 것만(시험 행렬을 어떻게 만들었는지 밝히고), 원인 추측 없이.
