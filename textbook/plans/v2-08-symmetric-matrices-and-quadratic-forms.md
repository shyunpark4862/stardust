# 1권 20장 Symmetric Matrices and Quadratic Forms — 얼개

예비 권(리뷰 방식). Part III의 여덟째 장. 스펙트럼 정리, 이차 형식, 양정치 행렬, Rayleigh 몫과 min–max 원리, Cholesky 분해를 다룬다. plans/PROMISES.md에서 20장 앞으로 온 약속을 모두 지킨다(10·11·13·14·17·18·19장에서): 스펙트럼 정리와 양정치의 고윳값 판정(10장 thm:definiteness-criteria (i)), Sylvester 판정과 LDLᵀ((ii)), 반정치 A에서 ⟨w,Aw⟩ = 0 ⇒ Aw = 0, 구면 위 이차 형식의 최대·최소 = 최대·최소 고윳값과 Rayleigh 몫(10장의 Lagrange 승수 길 포함), 양정치 A의 Gauss 적분 ∫e^{−⟨x,Ax⟩}dx = π^{n/2}/√det A의 일반 n 증명(11장), 양정치 행렬의 Schur 여원이 양정치(13장), 양정치 ⇔ 피벗이 모두 양수 ⇔ 선행 주 소행렬식 Δ_k > 0(14·17장), Cholesky, 양정치 G의 내적 xᴴGy와 일반 W의 가중 최소제곱·AᴴA = RᴴR이 Cholesky 분해·부정부호 형식(18장), Hermite 행렬에서 ρ(A) = ‖A‖₂·min–max·Hermite 행렬의 고윳값 섭동·κ₂(T_n)(19장). PROMISES.md를 직접 읽고 빠뜨리지 않는다. SVD(21장)와 Schur·Jordan(22장)은 쓰지 않는다. 실대칭과 Hermite를 함께 다루되(𝔽 = ℝ, ℂ), 진술은 Hermite 꼴로 하고 실수 경우를 따름으로.

## Abstract (한 문단, 120단어 이내, 동기부여)
대칭 행렬은 계산 과학에서 가장 자주 만나는 행렬이다: Hessian, 공분산, Gram 행렬, 강성 행렬, 그래프 Laplace 행렬. 대칭이면 고윳값이 실수이고 고유벡터가 직교 기저를 이루므로, 좌표를 돌리기만 하면 이차 형식이 제곱의 합이 된다. 극값의 판정, 최소제곱의 유일성, 타원체의 모양, 최적화의 수렴이 모두 이 한 정리에서 읽힌다는 점.

## 절 구성
20.1 Quadratic Forms — 이차 형식 q(x) = xᴴAx와 대칭(Hermite) 행렬의 일대일 대응(실수: 반대칭 부분은 기여하지 않음 — 13장; 복소: xᴴAx가 모든 x에서 실수 ⇔ A Hermite; 증명), 쌍선형(반쌍선형) 형식과 편극, 변수 변환 x = Sy에서 A ↦ SᴴAS(합동; 닮음과의 차이를 분명히), 예: 2변수 이차 형식의 등위선(타원·쌍곡선·포물선 꼴), Hessian과 2차 Taylor(10장 연결), 운동 에너지·분산. 그림: 정치·부정치·반정치 형식의 곡면과 등위선 패널.
20.2 The Spectral Theorem — 진술: Hermite(실대칭) 행렬은 유니터리(직교) 대각화 가능, A = QΛQᴴ, 고윳값 실수(19장에서 증명됨을 인용). 증명: 귀납 — 고윳값 하나의 존재(복소: 대수학의 기본 정리; 실대칭: 10장 약속대로 구면 위에서 이차 형식의 최대점이 고유벡터임을 Lagrange 승수 또는 직접 변분으로 보이는 둘째 증명을 준다) + 고유벡터의 직교 여공간이 불변(증명) + 18장의 직교 여공간. 스펙트럼 분해 A = Σλ_i q_i q_iᴴ = Σ λ P_λ(직교 사영의 합; 13장 외적의 합, 18장 사영), 역으로 직교 대각화 가능한 실행렬은 대칭, 유니터리 대각화 가능 ⇔ 정규(진술; 증명은 22장 — 또는 여기서 귀납 증명이 같은 꼴이면 증명하고 22장 약속을 줄임), 교환하는 Hermite 행렬의 동시 직교 대각화(19장 동시 대각화의 직교판; 증명), 손 계산 예 3×3. 그림: 대칭 행렬에 의한 단위원의 상(주축이 고유벡터) — 19장 그림과 대비.
20.3 Principal Axes — 이차 형식의 주축 변환 q = Σλ_i y_i²(증명), 이차 곡선·곡면의 분류(타원, 쌍곡선; 타원체의 반축 1/√λ_i), 타원체의 부피 = V_n/√det A(11·17장 연결), 일반 이차식 xᵀAx + bᵀx + c의 완전제곱과 중심(가역 A), 볼록 이차 함수의 최소점 ↔ 선형계 A x = −b/2(10장·9권 예고 연결), 다변량 정규 밀도의 등위면(3권 예고). 그림: 타원과 주축·반축 길이.
20.4 Positive Definite Matrices — 정의(정치·반정치·부정치·음정치), 동치 조건의 정리: (i) xᴴAx > 0, (ii) 고윳값이 모두 양수, (iii) A = BᴴB(B 가역; 또는 완전 열 계수), (iv) 선행 주 소행렬식이 모두 양수(Sylvester 판정), (v) 교환 없는 소거의 피벗이 모두 양수, (vi) A = LDLᴴ(D 양수), (vii) Cholesky A = RᴴR — 모두 증명(10장 thm:definiteness-criteria (i)·(ii)를 완결; 14·17장의 한 방향 증명과 Δ_k = 피벗의 곱을 인용); 반정치의 대응 조건들과 주의점(선행 주 소행렬식 ≥ 0은 충분하지 않음 — 반례; 모든 주 소행렬식 ≥ 0이어야 함: 진술 + 증명 또는 참고), 반정치 A에서 xᴴAx = 0 ⇒ Ax = 0(증명; 10장 약속), 성질: 주 부분행렬·대각 성분이 양수, 합·양수배·합동 SᴴAS(S 완전 열 계수)에 닫힘, 역행렬도 양정치, Schur 여원이 양정치이고 블록 판정(13장 약속; 증명), Gram 행렬은 반정치이고 독립 ⇔ 정치(13·17장 연결), 양정치 G가 내적 ⟨x,y⟩_G = xᴴGy를 정함 ⇔ G 양정치(18장 약속; 증명), Loewner 순서 A ⪰ B 한 문단.
20.5 The Cholesky Factorization — 존재와 유일성(R 상삼각, 대각 양수; 증명 — 귀납 또는 LDLᴴ에서), 알고리즘(유사코드)과 비용 n³/3(LU의 절반; 유도), 손 계산 예, 알고리즘이 끝까지 가는 것 ⇔ 양정치(판정법으로서의 Cholesky), 18장의 QR과의 관계: A = QR이면 AᴴA = RᴴR(18장 약속; 증명), 정규방정식을 Cholesky로 풀기, 양정치 제곱근 A^{1/2}(스펙트럼 정리로 존재, 유일성 증명)와 Cholesky 인자의 차이, 일반 양정치 W의 가중 최소제곱 min (b − Ax)ᴴW(b − Ax)(18장 약속; W = RᴴR로 보통 최소제곱으로 환원; 증명), 안정성은 8권 예고(양정치에서는 피벗이 필요 없다는 진술 + 인용).
20.6 The Rayleigh Quotient — R_A(x) = xᴴAx/xᴴx, 값의 범위 [λ_min, λ_max]와 극값점 = 고유벡터(증명; 10장의 Lagrange 승수 예 완결), 임계점 = 고유벡터·임계값 = 고윳값(기울기 계산; 증명), 고유벡터 근사의 오차가 ε이면 Rayleigh 몫의 오차는 ε²(증명; 19장 거듭제곱법 표의 0.3431 = 0.5858²를 설명 — 19장이 대각화 가능성 가정으로 둔 것을 스펙트럼 정리로 완결), Hermite 행렬에서 ‖A‖₂ = ρ(A) = max|λ|(19장 약속; 증명 — 2-노름을 max‖Ax‖/‖x‖로; 일반 행렬의 ‖A‖₂는 21장), κ₂(A) = λ_max/λ_min(양정치)와 κ₂(T_n) ≈ 4(n+1)²/π²(19장 약속; 계산).
20.7 Min–Max Principles — Courant–Fischer 정리(증명: 차원 세기), 따름: Weyl 부등식 λ_k(A) + λ_min(E) ≤ λ_k(A + E) ≤ λ_k(A) + λ_max(E)와 |λ_k(A + E) − λ_k(A)| ≤ ‖E‖₂(Hermite 행렬의 고윳값은 잘 조건화됨 — 19장의 Jordan 블록 민감도와 대비; 19장 약속), Cauchy 엇갈림 정리(주 부분행렬; 증명), 단조성 A ⪯ B ⇒ λ_k(A) ≤ λ_k(B), 계수 1 갱신의 엇갈림(진술 + 증명 짧으면). 그림: 엇갈림을 수직선 위 점으로.
20.8 Inertia and Indefinite Forms — 합동과 Sylvester의 관성 법칙(증명), 관성 (n₊, n₋, n₀)을 LDLᴴ의 D 부호로 읽기(교환 없는 소거가 될 때; 증명), 안장점 판정(10장 연결: Hessian의 관성), 부정부호 형식(18장 약속: Minkowski 형식 한 문단), 이동 A − σI의 관성으로 σ보다 작은 고윳값의 수 세기(스펙트럼 자르기; T_n으로 예 — Sturm 수열 한 문단, 8권 예고), 블록 2×2 KKT 행렬의 관성 한 문단(12권 예고), 일반화 고윳값 문제 Ax = λBx(B 양정치): 동시 대각화 SᴴAS = Λ, SᴴBS = I(증명; Cholesky로 환원)와 진동 문제 한 문단.
20.9 Gaussian Integrals and Other Uses — ∫_{ℝⁿ} e^{−xᵀAx} dx = π^{n/2}/√det A(11장 약속; 증명: 직교 변수 변환 — 11장 thm:change-variables의 선형 경우 thm:linear-volume만 필요함을 확인), 선형 항이 있는 꼴 ∫e^{−xᵀAx + bᵀx}와 다변량 정규 밀도의 정규화(3권 예고), 공분산 행렬이 반정치(13장의 3권 약속과 연결; 표본 공분산 = Gram), 주성분 한 문단(공분산의 스펙트럼 분해 — 21장·15권 예고; 속표지 그림이 바로 이것이라는 언급은 하지 않는다), 양정치 선형계와 이차 함수 최소화의 동치(10장의 9권 약속 연결), 2차 충분조건의 완결(10장 thm:second-derivative-test류를 인용하고 판정 조건을 이 장의 정리로 갈음).
20.10 Symmetric Matrices in Computation: A First Look — 공용 빌드(API 이름은 API-INVENTORY.md에서 확인: sd.linalg.cholesky, eigh, eigvalsh, solve 등)로 작은 실험: (1) Cholesky 대 LU 풀이 시간(n 몇 가지; 연산 수 비 1/2와 비교 — 수치만), (2) Cholesky가 실패하는 지점: 거의 특이한 양정치 행렬(Hilbert H_n — 장 안에서만 쓰는 기호라고 밝힘 — 이 binary64에서 몇 n부터 실패하는가)과 최소 고윳값, (3) Weyl 한계의 확인: 대칭 섭동 E에 대한 고윳값 변화 ≤ ‖E‖₂를 무작위 예로 표, 19장의 비대칭 예와 대비, (4) Rayleigh 몫의 제곱 수렴 수치. 실제 알고리즘(삼중대각화, QR, 분할 정복)은 8권. 수치는 직접 잰 것만, 원인 추측 없이.
