# 1권 16장 Linear Maps — 얼개

예비 권(리뷰 방식). Part III의 넷째 장. 15장의 벡터 공간 위에서 선형 사상을 다룬다: 핵과 상, 계수–퇴화차수 정리, 동형, 사상의 행렬, 기저 변환과 닮음. 13장은 R^n → R^m의 사상과 행렬의 대응을 세웠고(prop:linear-matrix 등), 이 장은 그것을 임의의 유한 차원 공간과 임의의 기저로 넓힌다. plans/PROMISES.md에서 16장(과 "15·16장") 앞으로 온 약속을 모두 지킨다 — 15장 검토 뒤의 PROMISES.md가 16장이 아직 갚아야 할 것을 정확히 적고 있다(핵과 상, 사상 꼴 계수–퇴화차수, 동형, 기저 변환과 닮음, rank(AB)의 영공간 증명과 Sylvester 부등식, 몫공간, 사상의 단사 ⇔ 전사 등). 행렬식과 고윳값은 쓰지 않는다(17·19장). 스칼라 체는 15장처럼 F(R 또는 C).

## Abstract (한 문단, 120단어 이내, 동기부여)
미분, 적분, 회전, 사영, 표본 추출, 차분 — 계산이 다루는 연산의 대부분은 선형 사상이다. 행렬은 사상 그 자체가 아니라 기저를 정했을 때의 기록이므로, 기저를 잘 고르면 같은 사상이 훨씬 단순한 행렬이 된다. 이 관찰이 뒤의 대각화·SVD·표준형 전체의 동기라는 점.

## 절 구성
16.1 Linear Maps — 정의, 바로 따르는 사실(T0 = 0, 일차 결합 보존), 예: 행렬 곱 x ↦ Ax, 미분 D: P_n → P_{n−1}, 적분 연산자, 평가 사상 p ↦ (p(t_1), …, p(t_k))(14장 보간과 연결), 이동 연산자(수열), 좌표 사상(15장), 전치·대각합, 선형이 아닌 예(평행 이동, 노름). 기저 위의 값으로 사상이 유일하게 정해진다(증명). L(V, W)가 벡터 공간이고 합성이 선형(증명).
16.2 Kernel and Image — 정의, 둘 다 부분공간(증명), 단사 ⇔ ker = {0}(증명), 예마다 핵과 상 계산(미분의 핵 = 상수, 평가 사상의 핵 = 점들에서 0인 다항식), A x = b의 해집합을 ker와 한 원상으로(14·15장의 말을 사상의 말로), 원상 T^{-1}(w)는 아핀 부분공간. 그림: 핵이 한 점으로 눌리고 올(fibre)들이 평행한 그림.
16.3 The Rank–Nullity Theorem — dim V = dim ker T + dim im T(증명: 핵의 기저를 늘려서; 15장 행렬 꼴 thm:four-dimensions와의 관계), 따름: dim V = dim W일 때 단사 ⇔ 전사 ⇔ 전단사(증명; 13·15장 약속), dim V > dim W이면 단사 불가·dim V < dim W이면 전사 불가(비둘기집; 4장), 응용: 보간 다항식의 존재 ⇔ 유일성(14장 thm:interpolation을 차원 세기로 다시), Hermite 보간이나 부분분수 분해의 존재를 차원 세기로(7장 부분분수 연결 — 하나만 완전히), 무한 차원에서는 깨진다(이동 연산자: 단사이나 전사 아님).
16.4 Isomorphisms — 정의, 역사상이 선형(증명), 유한 차원 공간이 동형 ⇔ 차원이 같다(증명), V ≅ F^n과 15장의 좌표, 동형이 보존하는 것(독립, 생성, 기저, 차원), 예: P_n ≅ F^{n+1}, F^{m×n} ≅ F^{mn}(vec; 13장 Frobenius 내적 연결), 대칭 행렬 공간, C ≅ R²(13장의 2×2 실 표현).
16.5 The Matrix of a Linear Map — 기저 𝓑, 𝓒를 정했을 때 [T]의 정의(열 = 기저 벡터의 상의 좌표), [T v]_𝓒 = [T] [v]_𝓑(증명), L(V, W) ≅ F^{m×n}이고 dim L(V,W) = mn(증명), 합성 ↔ 행렬 곱(증명; 13장이 곱을 합성으로 정의한 이유의 완결), 역 ↔ 역행렬, 예: 단항 기저에서 미분의 행렬·적분의 행렬, 평가 사상의 행렬이 Vandermonde, 차분 연산자. 그림: 가환 도표(V → W, F^n → F^m)를 TikZ로.
16.6 Change of Basis — 기저를 바꾸면 [T]' = Q^{-1} [T] P(증명; 15장 기저 바꿈 행렬 사용), 동치 행렬(equivalence)과 계수 표준형: 적당한 기저에서 모든 사상의 행렬이 [I_r 0; 0 0] — 두 행렬이 동치 ⇔ 같은 크기와 같은 계수(증명; 14장 소거의 행·열 연산 꼴과 연결), 따라서 계수가 동치의 유일한 불변량이라는 것.
16.7 Similarity — V → V의 연산자와 한 기저: [T]' = P^{-1} [T] P, 닮음은 동치 관계(증명; 2장), 닮음 불변량: 계수, 대각합(13장 tr(AB) = tr(BA)로 증명), 행렬식·고윳값은 17·19장 예고, 닮음 표준형 문제의 제기("좋은 기저 찾기": 대각화는 19장, Jordan은 22장), 예: 사영을 그 상과 핵에 맞춘 기저로 보면 diag(1,…,1,0,…,0)(멱등 ⇒ V = im ⊕ ker; 증명 — 13장 멱등 행렬, 대각합 = 계수의 증명도 여기서 가능하면 갚는다: PROMISES.md에서 18장 앞으로 간 "사영의 대각합 = 상의 차원"은 일반 멱등 행렬에 대해 여기서 증명하고 18장 항목을 고친다), 회전·반사의 다른 기저 표현.
16.8 Rank Inequalities and Compositions — rank(ST) ≤ min, 영공간 쪽 증명(ker T ⊆ ker ST), Sylvester 부등식 rank A + rank B − n ≤ rank(AB)(증명), Frobenius 부등식은 진술 + 증명 짧으면, dim ker(ST) ≤ dim ker S + dim ker T, 가역 사상과의 합성은 계수 보존(14장 결과의 사상 꼴), 거듭제곱의 핵 사슬 ker T ⊆ ker T² ⊆ …가 멈춘다(증명; 22장 Jordan 꼴의 준비)와 Fitting 분해 V = ker T^k ⊕ im T^k(증명; 22장 약속으로 적음).
16.9 Invariant Subspaces, Quotients, and Duals: A Brief Look — 불변 부분공간과 블록 삼각 행렬(증명; 13장 블록 행렬 연결, 19·22장 준비), 몫공간 V/U(정의, 잘 정의됨, dim V/U = dim V − dim U; 15장 note를 본문으로), 제1 동형 정리 V/ker T ≅ im T(증명; 계수–퇴화차수의 다른 얼굴), 쌍대 공간 V* 와 쌍대 기저, 전치 사상의 행렬이 전치 행렬(증명 짧게) — rank Aᵀ = rank A의 사상 꼴 해석 한 문단. 이 절은 간결하게.
16.10 Linear Maps in Computation: A First Look — "행렬을 만들지 않는 사상": 사상을 x ↦ T x를 계산하는 절차로만 가지는 경우(차분, 누적합, FFT 예고, 미분 연산자), 행렬 표현을 e_j에 적용해 복원(n번 적용), 비용 비교 표(누적합: 행렬로 n², 절차로 n), 다항식의 미분·평가를 계수 벡터 위의 선형 사상으로 실제 계산(공용 빌드에서 작은 확인: 미분 행렬 곱과 직접 계수 계산이 일치 — 이름은 API-INVENTORY.md에서 확인하고, 마땅한 API가 없으면 배열 연산만으로), 9권(희소·연산자)·11권(FFT, 미분 행렬) 예고. 수치는 직접 잰 것만, 원인 추측 없이.
