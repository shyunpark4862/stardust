## 다룰 API (stardust)
- `sd.linalg.lu(x)` → `LUResult(L, U, perm)`, `x[perm] = L @ U`, 직사각 허용, 특이여도 에러 없음 — 절 Factorization in stardust
- `sd.linalg.solve(a, b)` — getrf + (k ≤ 2: 행 교환 + trsv 두 번 / k ≥ 3: getrs) — 절 Solving with the Factors, Implementation
- `sd.linalg.lu_solve(l, u, perm, b, *, trans)` — b[perm] 모으기, 삼각 둘, 전치 풀이, perm 검증, 그 자리 읽기
- `sd.linalg.inv(x)` — getrf + 단위행렬 우변(getri 아님), inv(a) == solve(a, I)
- `sd.linalg.det(x)`, `sd.linalg.slogdet(x)` — U 대각 곱, 교환 부호, 넘침 없는 2의 거듭제곱 분리, 특이 → 0 / (0, −inf)

## 절 배치와 세 축
1. Elimination as Factorization (Theory) — 소거 = 단위 하삼각 곱, LU의 존재·유일성(선행 주소행렬식), Schur 보수, 직사각 LU
2. Pivoting and Stability Theory (Theory) — 부분 피벗의 존재 PA=LU, 성장 인자, 2^{n−1} 상한과 Wilkinson 행렬, 무작위 행렬의 실제 성장, 완전·rook 피벗, complex의 |re|+|im| 피벗과 √2
3. Backward Error Analysis (Theory) — Wilkinson 정리 |ΔA| ≤ γ_n|L||U|, 삼각 풀이의 후진 오차, 해의 후진 오차와 전진 오차·조건수, 반복 개선(이론, stardust는 하지 않음)
4. Unblocked Algorithms (Algorithms) — kij/jki/ijk 여섯 순서, right-looking·left-looking·Crout, 유사코드 2–3개, 연산 수 2n³/3, 메모리 접근과 열 우선
5. Blocked and Recursive LU (Algorithms) — BLAS 층(1/2/3), 블록 right-looking(getrf: 패널 getrf2 + laswp + trsm + gemm), 재귀 LU(getrf2), gemm 비율, 유사코드
6. Using the Factors (Algorithms) — 전진·후진 대입, 행 교환(laswp, ipiv의 뜻), 여러 우변, 역행렬(getri vs 풀이), 행렬식과 slogdet 알고리즘(넘침 없는 곱)
7. From Arrays to LAPACK (Implementation) — 열 우선 작업 버퍼, pack(strided → F-order, 32×32 타일 전치, 4×4 레지스터 전치, 비트 유한성 검사), 출력 자리에 바로 패킹, 16바이트 정렬과 비트 재현성
8. The LU Family in stardust (Implementation) — lu(ipiv→perm, L/U 풀어 쓰기), solve, lu_solve(검증 순서, 그 자리 읽기, trans), inv, det/slogdet, 빈 행렬, 에러 순서
9. Batches, Threads, and Hardware (Implementation) — run_batch, Scratch(캐시 줄 128B), 결정적 실패 보고, 비용 모형 a+cw, AMX 직렬 경로(getf2 32–46, task cap), trsv vs trsm
10. Testing and Accuracy (Implementation) — 후진 오차 측정, 비트 관계 테스트, scipy와의 차이
11. APIs in This Chapter (표)
12. Concluding Remarks
