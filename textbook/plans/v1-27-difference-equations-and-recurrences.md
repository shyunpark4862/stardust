# 1권 27장 Difference Equations and Recurrences — 얼개

예비 권(리뷰 방식). Part IV의 마지막 장이자 **1권의 마지막 장**. 이산 시간의 선형 방정식 — 점화식 — 을 미분방정식과 나란히 다룬다: 차분 연산자, 상수 계수 선형 점화식과 특성근, 생성함수, 연립 점화식과 안정성, 3항 점화식의 지배해·열세해와 계산 방향. plans/PROMISES.md에서 27장 앞으로 온 약속을 모두 지킨다(4·13·17·18·19·22·23·24·25·26장에서): k계 선형 점화식의 일반 풀이(4장 prop:linear-recurrence-k; 완전한 증명은 22장 cor:linear-recurrence에 있으므로 그것을 인용하고 여기서는 연산자 꼴로 다시 본다), 점화식을 행렬 거듭제곱·동반 행렬로(13·19장), 삼중대각 행렬식의 3항 점화식(17장), 3항 점화식 일반론과 직교 다항식(18장), 중근 n^jr^n·생성함수·유계 조건(22장), Euler 방법이 만드는 점화식의 안정성(23·25장: |1 + hλ| < 1, 연속 시간 Re λ < 0과 이산 시간 |μ| < 1의 대응 μ = e^{hλ}), 특성근·이산 미정계수법(24장), 3항 점화식의 안정성 — Bessel 점화의 방향, Legendre 점화, 지배해·열세해(26장). PROMISES.md를 직접 읽고 빠뜨리지 않는다. 수열은 (y_n)_{n≥0}, 독립 변수는 n으로 쓴다(26장의 x 관례·23–25장의 t 관례와 구별; 첫머리에서 밝힘). 비선형 점화식(로지스틱 사상)은 한 절로 맛보기만.

## Abstract (한 문단, 120단어 이내, 동기부여)
컴퓨터는 연속을 모른다: 미분방정식을 풀든, 급수를 합하든, 직교 다항식을 계산하든 실제로 실행되는 것은 "앞의 몇 값에서 다음 값을 만드는" 점화식이다. 선형 점화식의 이론은 선형 미분방정식의 이론과 한 줄 한 줄 대응하고(지수 함수 대신 거듭제곱, Re λ < 0 대신 |μ| < 1), 그 안정성 — 작은 오차가 커지는가 — 이 알고리즘이 쓸 만한지를 정한다. 이 책의 뒤 권들이 다루는 수치 알고리즘의 첫 관문이라는 점.

## 절 구성
27.1 Sequences and Difference Operators — 이동 연산자 E, 전진 차분 Δ = E − I(16장의 Δ와 같음), 차분과 미분의 대응 표(Δ ↔ D, 합 ↔ 적분, 하강 계승 n^{\underline{k}} ↔ x^k; 16장), 합의 기본 정리 Σ_{n=a}^{b−1}Δf(n) = f(b) − f(a)와 부분합 공식(Abel 변환; 증명), Newton 전진 차분 공식과 다항식 수열 ⇔ Δ^{k+1}y = 0(증명), 예: Σn^k의 닫힌 꼴을 하강 계승으로(4·7장 연결), 점화식의 용어(계수, 선형, 동차, 상수 계수), 초기값 문제는 항상 유일한 해(자명 — 미분방정식과의 대비).
27.2 First-Order Recurrences — y_{n+1} = a y_n + b: 닫힌 꼴, 고정점 b/(1 − a), |a| < 1이면 수렴(증명), 변수 계수 y_{n+1} = a_ny_n + b_n의 풀이 공식(곱과 합; 23장 적분 인자의 이산판; 증명), 예: 복리와 상환(대출 잔액), Newton 냉각의 Euler 이산화(23장), Horner 방법이 1계 점화식임(8·13장), 거미줄 그림(cobweb)으로 보는 수렴(6장 고정점 반복 prop:fixed-point-contraction 연결). 그림: 거미줄 도표 a의 네 경우.
27.3 Linear Recurrences with Constant Coefficients — p(E)y = 0, 해 공간은 k차원(초기값 사상이 동형; 증명), 특성다항식과 일반해 n^jr_i^n(j < m_i)(22장 cor:linear-recurrence 인용 + 연산자 증명: (E − r)^m의 핵, 이동 공식 p(E)(r^nu_n) = r^np(rE)u_n — 24장 지수 이동 공식의 이산판; 0이 근인 경우(c_k = 0)의 주의), 실계수의 실수 해 ρ^n cos nθ, ρ^n sin nθ, Casorati 행렬식(Wronskian의 이산판)과 독립성 판정·Abel 공식의 이산판(증명), 예: Fibonacci와 Binet(13·19장), Lucas 수, Chebyshev 다항식 T_{n+1} = 2xT_n − T_{n−1}의 닫힌 꼴 cos(n arccos x), 삼중대각 행렬식 D_n = aD_{n−1} − bcD_{n−2}(17장 약속: T_n(2, −1)의 n + 1, 일반 꼴), 도박꾼의 파산 확률(경계값 문제로서의 점화식; Excursions 예고는 하지 않음 — 별권은 이름으로만 한 번 언급 가능), 미정계수법의 이산판(우변 q(n)μ^n; 24장 약속; 공명은 μ가 특성근일 때 n^s; 증명은 24장과 같은 유한 차원 논증), 예: 하노이 탑·분할 정복 점화식 T(n) = 2T(n/2) + n은 변수 변환 n = 2^m으로(4권 예고).
27.4 Generating Functions — 수열 ↔ 거듭제곱 급수(4장 형식 급수·8장 prop:formal-analytic), 상수 계수 점화식 ⇔ 유리 생성함수(증명: 분모가 뒤집은 특성다항식), 부분분수 분해에서 일반해 n^jr^n이 다시 나옴(7·16장 부분분수; 증명), 수렴 반지름 = 1/max|r_i|와 성장률(8장), 비동차 항 처리, 합성곱과 Catalan 수(비선형 점화식의 예: C(x) = (1 − √(1 − 4x))/(2x); 8장 이항 급수), 지수 생성함수 한 문단, z-변환이라는 이름 한 문단(Laplace 변환의 이산판; 다루지 않음).
27.5 Systems and Stability — 𝐱_{n+1} = A𝐱_n: 해 A^n𝐱₀, 고윳값 방법(19·22장 인용), 안정성 정리: 점근 안정 ⇔ ρ(A) < 1, 유계 ⇔ ρ(A) ≤ 1이고 절댓값 1인 고윳값이 반단순(22장 정리 인용; 25장 연속판과의 대응 표: Re λ < 0 ↔ |μ| < 1, e^{tA} ↔ A^n, Lyapunov 방정식 AᵀP + PA = −Q ↔ AᵀPA − P = −Q(Stein 방정식; 진술 + 증명 짧으면)), 연속계의 정확한 이산화 μ = e^{hλ}는 안정성을 보존하고 Euler 이산화 μ = 1 + hλ는 조건부로만(25장 약속; 증명), 스칼라 점화식의 안정성: 특성근이 모두 단위원 안 — Schur–Cohn/Jury 판정(2·3차 증명, 일반은 진술), 비동차 𝐱_{n+1} = A𝐱_n + 𝐛_n의 풀이(이산 Duhamel; 증명)와 유계 입력–유계 출력, 일시적 증가(13·22장의 ‖A^k‖ 그림 연결), 반복법 𝐱_{n+1} = G𝐱_n + 𝐜의 수렴 ⇔ ρ(G) < 1(14장 Jacobi·Gauss–Seidel note, 19장 Neumann 급수 인용; 9권 예고), Markov 연쇄 𝐩_{n+1} = P𝐩_n(19장)·인구 모형(Leslie 행렬; Perron 고윳값) 예.
27.6 Three-Term Recurrences — y_{n+1} + a_ny_n + b_ny_{n−1} = 0(변수 계수 2계): 해 공간 2차원, Casorati 행렬식의 점화식, 지배해와 열세해(최소해)의 정의, 정리: 전진 점화는 지배해 계산에 안정하고 열세해 계산에는 불안정(초기 오차가 지배해 비율로 증폭; 증명 — 오차가 같은 점화식을 따르므로), 열세해는 후진 점화로(Miller 알고리즘의 생각: 큰 N에서 임의로 시작해 뒤로 내려온 뒤 정규화; 알고리즘 유사코드와 수렴의 증명 — 열세해 비율 f_N/g_N → 0이면; Gautschi 1967은 26장 서지에 있음), 예 1: Bessel J_n(x) — n > x에서 J_n이 열세해, Y_n이 지배해(26장 급수의 n → ∞ 꼴로 확인; 증명은 성장률 비교), 전진 점화의 실패와 후진 점화의 성공을 표로(26장 약속), 예 2: Legendre P_n(x), |x| ≤ 1에서 전진 점화가 안정(P_n, Q_n이 같은 크기; 26장 표 26.5의 근거), |x| > 1에서는 P_n이 지배해·Q_n이 열세해, 예 3: 적분 I_n = ∫₀¹xⁿe^{x−1}dx = 1 − nI_{n−1}(1계지만 같은 현상: 전진 불안정·후진 안정; 고전적 예 — 직접 계산해 표), 연분수와의 관계(Pincherle 정리: 진술 + sketch; 10권 예고), 직교 다항식의 3항 점화식(Favard 정리: 진술; 18장 note·11권 예고)과 Jacobi 행렬(삼중대각; 고윳값 = 영점 — 20장 연결, 11권 Golub–Welsch 예고).
27.7 From Differential to Difference Equations — 미분방정식의 이산화가 점화식을 낳는다: Euler(1단계), 중점법 y_{n+1} = y_{n−1} + 2hf_n(2단계)의 기생해(parasitic root): y′ = −y에서 특성근 −h ± √(1 + h²), 하나는 e^{−h}를 따라가고 다른 하나는 −(1 + h)로 커짐(증명과 직접 계산 표 — 약한 불안정성), 선형 다단계법의 영 안정성(root condition)과 Dahlquist 동치 정리는 진술(참고 문헌; 뒤 권에서 약속하지 않음), 2계 차분 −y_{n−1} + 2y_n − y_{n+1} = h²f_n과 T_n(13·14·19장: 이산 경계값 문제 = 삼중대각계; 고유벡터 sin), 차분방정식의 해가 미분방정식의 해로 수렴하는 한 예(23장 Euler 수렴 정리를 점화식의 말로), 연속 극한에서 대응이 깨지는 곳: 이산에서는 진동하는 음의 근(r < 0)이 있지만 1계 연속계에는 없다.
27.8 Nonlinear Recurrences: A Glimpse — 고정점과 선형화 |f′(x*)| < 1(6장 prop:fixed-point-contraction 인용; 증명은 거기), Newton 반복이 2차 수렴하는 점화식임(6·8장), 로지스틱 사상 x_{n+1} = rx_n(1 − x_n): 고정점의 안정성 구간, 주기 배가의 처음 두 번(r = 3, 1 + √6; 증명), 혼돈은 그림과 진술만(분기 도표; r = 4에서 x_n = sin²(2ⁿθ)의 닫힌 꼴 — 증명 — 과 초기값 민감성; 인용: May 1976, Feigenbaum), 23장 로지스틱 미분방정식과의 대비(연속은 단조 수렴, 이산은 혼돈 가능 — Euler 보폭이 크면 같은 일이 생김; 27.7과 연결). 그림: 분기 도표(회색 점; 점 수를 빌드 시간이 늘지 않게 제한), 거미줄 도표 둘.
27.9 Computing with Recurrences: A First Look — 실험(공용 빌드 인터프리터, 기준값은 python-flint; sd.special에 있는 함수는 API-INVENTORY.md에서 확인해 비교): (1) Fibonacci를 Binet 공식으로 binary64 계산하면 어디서 틀리기 시작하는가 대 정수 점화식(22장 matrix_power의 k = 77 결과와 연결), (2) I_n = 1 − nI_{n−1} 전진 대 후진 표, (3) J_n(1), J_n(10)을 전진·후진(Miller) 점화로 — 오차 표, sd.special과 비교, (4) 중점법의 기생해 표(27.7), (5) Chebyshev T_n(x)를 점화식·cos(n arccos x)·단항 계수로 계산한 오차(26장 Legendre 표와 짝; Clenshaw 합산은 한 문단 + 알고리즘 유사코드, 11권 예고). 교훈 정리: 점화식의 방향이 정확도를 정한다. 수치는 직접 계산한 것만, 원인 추측 없이. 라이브러리가 이상하게 동작하면 보고의 "Library observations"에.
