## Abstract (한 문단, 120단어 이내, 동기부여)
상수 계수 방정식의 해는 지수 함수와 삼각 함수였다. 계수가 변하면 — 원통의 진동, 구면 위의 퍼텐셜, 양자 우물 — 해는 대개 초등 함수가 아니고, 방정식 자체가 새 함수를 정의한다. 그 함수들을 손에 넣는 첫 방법이 거듭제곱 급수이다: 계수의 점화식이 해를 한 항씩 만들어 내고, 같은 점화식이 그 함수를 계산하는 알고리즘의 출발점이 된다는 점.

## 절 구성
26.1 Power Series Solutions: The Idea — y′ = y와 y″ + y = 0을 급수로 다시 풀어 e^x, cos, sin의 급수가 나옴(8·9장), 방법의 얼개: 대입 → 계수 비교(8장 cor:power-series-unique) → 점화식 → 수렴 확인, 해석적 함수의 정의(실해석적: 각 점 근방에서 수렴하는 거듭제곱 급수로 표현; 8장), 정상점과 특이점의 정의.
26.2 Solutions Near an Ordinary Point — 정리: p, q가 x₀ 중심 수렴 반지름 ≥ R인 급수이면 모든 초기값에 대해 급수 해가 있고 |x − x₀| < R에서 수렴한다(증명: 점화식에서 계수의 크기를 우급수(majorant)로 눌러 수렴을 보임 — Cauchy의 우급수 논법; 8장의 수렴 판정만 사용. 완전한 증명을 주되, 복소해석 없이 실변수로), 24장 thm:linear-existence의 해와 같은 해임(유일성), 해 공간의 기저 y₁, y₂(y(x₀) = 1, y′(x₀) = 0 등), 수렴 반지름의 하한이 "가장 가까운 복소 특이점까지의 거리"라는 해석은 진술(예: (1 + x²)y″ + … 에서 R = 1; 2권 예고), k계와 연립계 𝐲′ = A(x)𝐲로의 확장은 진술 + 같은 증명이 통함을 한 문단.
26.3 Airy's Equation — y″ = xy(24장 그림의 방정식): 3항 건너뛰는 점화식, 두 급수 해와 수렴 반지름 ∞(증명), Ai, Bi는 이 두 해의 특정한 일차 결합이라는 것(정규화 상수는 Γ(1/3), Γ(2/3) — 7·9·11장 감마; 값은 인용), x > 0에서 지수적·x < 0에서 진동(24장 Sturm 비교 정리로 설명됨을 인용), 영점(24장 표의 값과 급수로 다시 계산), w″ + t²w = 0(23장 약속): 급수 해와 y′ = t² + y²의 해 y = −w′/w, 폭발 시각 = w의 첫 영점 2.003147…(23장 값과 대조; Bessel J_{−1/4}와의 관계는 26.6에서).
26.4 Legendre's Equation — (1 − x²)y″ − 2xy′ + ν(ν + 1)y = 0: x = 0은 정상점, 급수 해의 점화식, ν = n(자연수)일 때 한 급수가 끊겨 다항식 P_n(증명), 정규화 P_n(1) = 1, Rodrigues 공식(증명), 직교성 ∫_{−1}^{1}P_mP_n = 2δ_{mn}/(2n + 1)(증명: 방정식의 자기 수반 꼴 — 24장 Sturm–Liouville note; 18장에서 Gram–Schmidt로 얻은 Legendre 다항식과 같은 것임을 확인), 3항 점화식 (n + 1)P_{n+1} = (2n + 1)xP_n − nP_{n−1}(증명; 18장 note·27장 예고), 끊기지 않는 해는 x → ±1에서 발산(로그 특이성; 24장의 Q₁ = (x/2)ln((1+x)/(1−x)) − 1과 연결; 증명은 Q₀, Q₁에서 직접, 일반은 진술), 왜 물리에서 ν가 정수여야 하는가(구면 위에서 유계인 해 — 한 문단; Laplace 방정식의 변수 분리는 note), 그림: P₀–P₅.
26.5 Regular Singular Points and the Method of Frobenius — 특이점의 분류: x²y″ + xP(x)y′ + Q(x)y = 0에서 P, Q가 해석적이면 x = 0이 정칙 특이점, 원형은 Euler–Cauchy(24장)이고 그 지표 다항식이 일반 경우의 지표 방정식 r(r − 1) + P(0)r + Q(0) = 0, Frobenius 급수 y = x^rΣa_nx^n, 점화식 F(r + n)a_n = −Σ(…)(유도), 정리(Frobenius): 지표 근 r₁ ≥ r₂(실수 경우)에 대해 (i) r₁에 대한 급수 해는 항상 존재하고 P, Q의 수렴 반지름 안에서 수렴(증명 — 26.2와 같은 우급수 논법; 완전히), (ii) r₁ − r₂가 정수가 아니면 r₂에 대한 둘째 급수 해(증명), (iii) r₁ = r₂이면 둘째 해에 ln x 항(증명: ∂/∂r 논법 또는 24장 계수 낮추기 — 한 길을 완전히), (iv) r₁ − r₂가 양의 정수이면 둘째 해는 C y₁ ln x + x^{r₂}Σb_nx^n 꼴이고 C가 0일 수도 아닐 수도 있음(진술 + sketch 또는 완전 증명 — 분량과 엄밀성을 따져 정하고 sketch면 `\begin{proof}[sketch]`), 복소 지표 근은 한 문단(x^{α ± iβ} = x^α(cos(β ln x) ± i sin(β ln x)); 24장 Euler–Cauchy), 비정칙 특이점에서는 급수가 발산할 수 있음(예: x²y′ = y − x에서 Σn!x^{n+1} — 8장의 Euler 급수·10권 점근 급수 예고), 무한대에서의 점(변환 x = 1/s) 한 문단, 예 둘(지표 근 차가 비정수·정수).
26.6 Bessel's Equation — x²y″ + xy′ + (x² − ν²)y = 0: 지표 근 ±ν, J_ν(x) = Σ(−1)^m(x/2)^{2m+ν}/(m!Γ(m + ν + 1))(유도와 수렴; Γ는 7·9·11장), ν가 정수가 아니면 J_ν, J_{−ν}가 기저(증명: Wronskian 2 sin νπ/(πx) — Abel 공식 24장과 x → 0 극한; 감마 반사 공식은 9장 note·2권 약속이므로 그 부분은 인용임을 밝힘), ν = n이면 J_{−n} = (−1)^nJ_n(증명)이고 둘째 해 Y_n에 로그(Frobenius (iv); 정의와 꼴은 진술, 유도는 sketch), 반정수 차수: J_{1/2} = √(2/(πx)) sin x(증명; 24장 정규형 예 완결), 점화 관계 (x^νJ_ν)′ = x^νJ_{ν−1} 등과 3항 점화식 J_{ν−1} + J_{ν+1} = (2ν/x)J_ν(증명; 27장의 3항 점화식 안정성 예고 — 전진 점화가 불안정하다는 것은 27장), 영점: 무한히 많고 간격이 π로 수렴(24장 Sturm 비교와 정규형 w″ + (1 + (1/4 − ν²)/x²)w = 0으로 증명), 큰 x에서의 꼴 √(2/(πx))cos(x − νπ/2 − π/4)(진술 + sketch: 정규형에서의 발견적 유도; 10권 예고), 응용 한 문단(원형 북의 진동 모드: J_0의 영점), 23장 약속 완결: w″ + t²w = 0의 해 = √t J_{±1/4}(t²/2)(증명: 변수 변환)와 폭발 시각 = J_{−1/4}의 첫 영점에서 나온 값. 그림: J₀, J₁, J₂와 Y₀; 표: J₀의 처음 영점 몇 개와 (n − 1/4)π 어림.
26.7 Other Classical Equations: A Brief Look — Hermite y″ − 2xy′ + 2ny = 0, Laguerre, Chebyshev (1 − x²)y″ − xy′ + n²y = 0: 다항식 해가 생기는 같은 기제(급수가 끊김), 직교성과 가중 함수 표(18장 가중 내적; 11권 직교 다항식 예고), 초기하 방정식이 정칙 특이점 셋을 가진 일반형이라는 것(진술; 10권 예고), Sturm–Liouville 관점 한 문단(24장 note; 2권).
26.8 Computing with Series: A First Look — 점화식으로 급수를 합하는 알고리즘(유사코드: 항을 점화식으로 갱신하며 더하고, 항이 반올림 수준 아래로 내려가면 멈춤), 정확도 실험: J₀(x)의 급수를 binary64로 x = 1, 5, 10, 20, 40에서 합하면 큰 x에서 자릿수를 잃는다(가장 큰 항 ≈ e^x/√(2πx) 대 값 ≈ x^{−1/2}; 8장의 e^{−20} 예·22장 Taylor expm 예와 같은 상쇄 — 직접 계산해 표: 가장 큰 항, 급수 합의 오차, 기준값은 python-flint), Airy Ai(x)도 같은 표(큰 양의 x에서), 공용 빌드의 sd.special(API 이름은 API-INVENTORY.md에서 확인: jv 또는 j0, airy, eval_legendre 등 있는 것만)와 급수 합의 비교, Legendre 다항식은 3항 점화식으로 안정적으로 계산됨(표: n = 50까지 P_n(x)를 점화식 대 단항 계수 합 — 계수 합은 큰 n에서 상쇄), 교훈: "급수는 정의이지 언제나 알고리즘은 아니다" — 실제 구현(점근 전개, 점화식의 방향, 연분수)은 10권. 수치는 직접 계산한 것만, 원인 추측 없이(상쇄의 크기는 가장 큰 항과 값의 비로 "측정"해 적는다).
