# 1권 23장 First-Order Equations — 얼개

예비 권(리뷰 방식). Part IV Differential Equations의 첫 장이므로 vol1.tex에서 장 앞에 `\part{Differential Equations}`를 연다. 1계 상미분방정식 y′ = f(t, y)를 다룬다: 풀이 기법(변수 분리, 선형, 완전), 기하(방향장, 적분 곡선), 질적 이론(자율 방정식의 평형과 안정성), 존재와 유일성(진술; 증명은 2권에서 축약 사상 정리의 응용 — GUIDE·OUTLINE의 결정), 수치 풀이의 맛보기(Euler 방법). plans/PROMISES.md에서 23장 앞으로 온 약속을 모두 지킨다(9장: 지수적 성장·감쇠와 반감기, 현수선의 미분방정식 y″ = (1/a)√(1+y′²)의 풀이; 그 밖에 PROMISES.md에 23장이나 "Part IV" 앞으로 온 것이 있으면 모두). 앞 장에서 쓸 것: 9장 thm:exp-ode(f′ = λf의 유일성), 7장 적분 기법과 미적분의 기본 정리, 10장 편미분·연쇄 법칙·음함수 정리(thm:implicit-scalar), 12장 보존장과 퍼텐셜·Poincaré 보조정리(완전 방정식이 바로 이것), 6장 평균값 정리와 Lipschitz 조건, 8장 Taylor 정리, 22장 e^{tA}(1차원 경우의 대조). 편미분방정식과 Laplace 변환은 다루지 않는다(OUTLINE). 독립 변수는 t, 미지 함수는 y(또는 x)로 하되 기하적 문제에서는 x, y — 장 첫머리에서 관례를 정하고 24–27장이 따르도록 PROMISES.md에 적는다.

## Abstract (한 문단, 120단어 이내, 동기부여)
자연 법칙은 대개 "지금 상태가 변화율을 정한다"는 꼴로 쓰인다: 방사성 붕괴, 냉각, 인구, 회로, 낙하. 미분방정식을 푼다는 것은 이 국소 법칙에서 전체 궤적을 되찾는 일이다. 공식으로 풀리는 방정식은 소수이고, 그 밖에는 해가 존재하고 유일한지 알고, 그림으로 행동을 읽고, 수치로 따라가야 한다는 점 — 이 세 가지 길이 이 부 전체의 줄거리.

## 절 구성
23.1 Differential Equations and Their Solutions — 용어(계수, 상·편, 선형·비선형, 자율), 해의 정의(구간 위의 미분 가능 함수), 일반해·특수해·초기값 문제, 예: y′ = ky(9장), y′ = f(t)는 적분(7장), 낙하와 저항, 해가 구간 전체로 뻗지 않는 예(y′ = y²의 폭발)와 유일하지 않은 예(y′ = √|y|) — 뒤 절의 동기. 미분방정식을 적분방정식 y(t) = y₀ + ∫f(s, y(s))ds로 고쳐 쓰기(증명; 2권 Picard 예고).
23.2 Direction Fields and Integral Curves — 방향장, 등경사선, 적분 곡선, 예 몇 개를 그림으로(y′ = t − y, y′ = y(1 − y), y′ = t² + y² — 마지막은 초등 함수로 안 풀림을 언급: Riccati·Liouville 인용 검증), 해 곡선이 서로 만나지 않는다는 것(유일성의 기하적 뜻). 그림: 방향장 패널(TikZ/pgfplots quiver, 회색조).
23.3 Separable Equations — y′ = g(t)h(y)의 풀이와 그 정당화(정리: h(y₀) ≠ 0이면 국소적으로 유일한 해가 H(y) = G(t) + C로 주어진다; 증명 — 치환 적분과 역함수; h의 영점은 평형해이고 잃어버리기 쉽다), 예: 지수 성장·감쇠와 반감기·배가 시간(9장 약속; 탄소 연대 측정 수치 예), Newton 냉각, 로지스틱 방정식의 풀이(부분분수 — 7·16장)와 S자 곡선, y′ = y²의 폭발 시간, 현수선(9장 약속: y″ = (1/a)√(1 + y′²)를 p = y′로 낮춰 분리형으로; 풀이 전체 — 9장 sec:hyperbolic의 cosh와 연결), 추적 곡선이나 Torricelli 배수(유일성이 깨지는 물리적 예) 중 하나. 그림: 로지스틱 해 곡선들, 현수선.
23.4 Linear Equations — y′ + p(t)y = q(t): 동차 방정식의 해 공간은 1차원(15·16장의 말로: 해 공간 = 선형 연산자 L = D + p의 핵; 9장 thm:exp-ode의 일반화 — 증명), 적분 인자 e^{∫p}와 풀이 공식(증명; 구간 전체에서 해가 존재하고 유일 — 선형 방정식에서는 대역적 존재·유일성을 완전히 증명), 상수 변화법으로 같은 공식, 해의 구조 = 특수해 + 동차해(14·16장의 일반해 구조와 같은 꼴), 중첩 원리, 예: RC 회로·혼합 문제·종단 속도, 주기적 강제 y′ + ay = cos ωt의 과도 해와 정상 해(진폭과 위상; 24장 공명 예고), 입력에 대한 해의 연속 의존(부등식으로).
23.5 Exact Equations and Integrating Factors — M dx + N dy = 0, 완전 ⇔ M_y = N_x(단순 연결·별꼴 영역에서; 12장 thm:poincare-lemma·thm:simply-connected를 인용해 증명), 퍼텐셜 F의 등위선이 해(10장 음함수 정리로 국소 해; 증명), 풀이 절차와 예, 적분 인자: μ(x)·μ(y)만의 함수인 경우의 조건과 공식(증명), 분리형·선형이 완전형의 특수한 경우임, 등위선과 직교 궤적(예: 원족과 직선족, 포물선족), 12장의 보존장·일과 연결(에너지 보존 한 문단).
23.6 Substitutions — 동차형 y′ = F(y/t), Bernoulli 방정식(로지스틱을 다시), Riccati 방정식(특수해 하나를 알면 선형으로; 일반적으로 구적 불가 — 인용), 축척과 차원 분석으로 방정식을 무차원화하는 법 한 문단(로지스틱 예), 2계 방정식 가운데 1계로 낮아지는 것(y가 없거나 t가 없는 경우: 현수선·낙하·탈출 속도).
23.7 Autonomous Equations and Stability — y′ = f(y): 위상 직선, 평형점, 단조성(해는 평형 사이에서 단조이고 평형으로 수렴하거나 무한대로 간다; 증명 — 유일성을 가정에 두고), 선형화: f′(y*) < 0이면 점근 안정·> 0이면 불안정(증명; 6장 평균값 정리), 예: 로지스틱·Allee 효과·수확이 있는 인구 모형 y′ = ry(1 − y/K) − h와 분기(saddle-node; h가 rK/4를 넘으면 평형이 사라짐 — 분기 도표 그림), 유한 시간 폭발의 판정(∫dy/f(y) 수렴), 잠재 함수 V(y′ = −V′(y))로 보는 안정성, 25장(평면계의 위상 평면) 예고. 그림: 위상 직선과 해 곡선, 분기 도표.
23.8 Existence and Uniqueness — Peano 존재 정리(f 연속; 진술), Picard–Lindelöf 정리(f가 y에 대해 Lipschitz이면 국소 유일 해; 진술 + 줄거리: 적분방정식, Picard 반복, 축약 — 증명은 2권이라고 가리키되 생략 이유는 말하지 않는다), Picard 반복을 y′ = y에 실제로 돌려 e^t의 Taylor 부분합이 나옴을 보임(8·9장), Lipschitz 조건의 판정(∂f/∂y 유계; 6장), 유일성 증명은 여기서 완전히 줄 수 있다: Grönwall 부등식(증명)과 그것으로 유일성·초기값에 대한 연속 의존 |y(t) − z(t)| ≤ |y₀ − z₀|e^{L|t − t₀|}(증명), 반례 재론(y′ = √|y|, y′ = y^{2/3}), 최대 존재 구간과 폭발 양자택일(진술 + 줄거리), 선형 방정식에서는 대역적(23.4), 비교 정리(진술 + 증명 짧으면).
23.9 Euler's Method: A First Look at Numerical Solution — 방향장을 따라 걷기, 알고리즘(유사코드), 국소 절단 오차 O(h²)와 전역 오차 O(h)의 증명(f가 Lipschitz, 해가 C²; Grönwall의 이산 꼴 — 8장 Taylor), 예: y′ = y에서 (1 + h)^{1/h} → e(9장 thm:exp-limit과 같은 극한)와 오차 표(직접 계산: h를 반으로 줄일 때 오차 비 ≈ 2), 안정성 문제의 첫 모습: y′ = −50y에서 h가 크면 발산(|1 − 50h| < 1; 후진 Euler와 대비 — "stiff"라는 말만 소개), 개선된 Euler(Heun)·중점법은 오차 표에 한 열로 맛보기(차수 2; 증명은 하지 않고 측정만, 이론은 뒤 권 — stardust에 ODE 풀이가 아직 없다는 사실은 본문에 쓰지 않는다; 단지 "이 책의 뒤 권이 다루는 범위 밖"이면 약속하지 않는다: OUTLINE.md에서 ODE 수치 풀이를 다루는 권이 있는지 확인하고, 없으면 참고 문헌(Hairer–Nørsett–Wanner, Iserles 등)을 가리킨다), 반올림 오차와 h의 하한 한 문단(5권 예고). 실험은 순수 Python(공용 빌드 인터프리터)으로 충분; 수치는 직접 계산한 것만, 원인 추측 없이.
