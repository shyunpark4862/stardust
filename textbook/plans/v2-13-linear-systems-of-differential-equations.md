# 1권 25장 Linear Systems (of Differential Equations) — 얼개

예비 권(리뷰 방식). Part IV의 셋째 장. 장 제목은 OUTLINE.md대로 "Linear Systems"이지만 14장의 제목과 같으므로 "Linear Systems of Differential Equations"로 한다(이름이 바뀌는 것이므로 OUTLINE.md의 25장 줄을 고치고 보고에 적는다 — 메인이 기록 세션에 알린다). 1계 선형 연립계 𝐲′ = A(t)𝐲 + 𝐛(t), 특히 상수 계수 𝐲′ = A𝐲를 다룬다: 기본 행렬, 고윳값 방법, 행렬 지수, 평면계의 위상 초상, 안정성, 비동차계와 Duhamel 공식, 그리고 비선형계의 평형점 근처 선형화(진술 중심). plans/PROMISES.md에서 25장 앞으로 온 약속을 모두 지킨다(9·16·19·20·22·23·24장에서): f′ = Af와 e^{tA}(9·22장의 남은 몫: 고윳값·Jordan 꼴로 푸는 법), 위상 평면과 평형점의 분류, 안정성(Re λ < 0 ⇔ e^{tA} → 0; 유계 ⇔ Re λ ≤ 0이고 허수축 고윳값의 블록이 1×1), 비동차계와 상수 변화법·Duhamel 공식 e^{tA}∫e^{−sA}𝐛(s)ds, 일시적 증가(22장 prop:exp-norm-bounds와 그림), 연립계의 존재·유일성(24장 thm:linear-existence 위에 세움; 비선형계는 23장의 진술과 조건 — Euclid 노름, 평균값 부등식 — 그대로), 고윳값에 의한 선형화 안정성과 진자의 위상 초상(23장), 기본 행렬·Liouville 공식(Abel 공식의 행렬판)·위상 평면에서 본 감쇠 진동자·대각화 가능한 중복 고윳값(24장), M𝐲″ + K𝐲 = 0의 정규 모드(20장: 일반화 고윳값 문제), "특수해 + 핵"(16장의 25장 몫). ## Abstract (한 문단, 120단어 이내, 동기부여)
여러 양이 서로 영향을 주며 변하는 계 — 연결된 용수철, 화학 반응, 포식자와 먹이, 회로망 — 는 연립 미분방정식이고, 평형 근처에서는 선형계 𝐲′ = A𝐲로 근사된다. 이 계의 모든 것은 행렬 A의 고윳값에 있다: 실수부의 부호가 해가 평형으로 돌아오는지 달아나는지를, 허수부가 진동을 정한다. Part III의 선형대수 전체가 여기서 쓰인다는 점.

## 절 구성
25.1 Systems of First-Order Equations — 연립계의 예(연결된 탱크, 두 질량–용수철, RLC 회로망, 선형화한 포식자–먹이), 고계 방정식의 환원(24장 동반 연립계)과 그 역은 언제나 되지는 않는다는 것(한 문단), 벡터 값 함수의 미적분(24장 lem:vector-functions 인용), 초기값 문제의 존재·유일성(24장 thm:linear-existence를 인용; 선형계는 구간 전체에서), 해 공간의 구조: 동차계의 해 공간은 n차원(초기값 사상이 동형; 증명 — 24장과 같은 논증의 연립계 꼴), 비동차 = 특수해 + 동차(16장).
25.2 Fundamental Matrices — 기본 해 집합과 기본 행렬 Φ(t)(Φ′ = A(t)Φ, 가역), 모든 해 = Φ(t)𝐜, 상태 전이 행렬 Φ(t)Φ(s)⁻¹과 그 성질(반군 성질·역; 증명), Wronskian det Φ와 Liouville 공식 det Φ(t) = det Φ(t₀)exp(∫tr A)(24장 약속; 증명 — 17장 Jacobi 공식; 24장 Abel 공식이 동반 행렬의 경우임을 확인), 상수 계수이면 Φ(t) = e^{tA}(22장), 변수 계수에서는 일반적으로 exp(∫A)가 해가 아님(A(t)와 A(s)가 교환하지 않으면; 반례와 교환하는 경우의 증명).
25.3 The Eigenvalue Method — 𝐲 = e^{λt}𝐯가 해 ⇔ A𝐯 = λ𝐯(증명), A가 대각화 가능하면 일반해 Σc_ie^{λ_it}𝐯_i(중복 고윳값이어도 대각화 가능하면 t 인자가 없음 — 24장 약속; 예: 2I, 대칭 행렬), 좌표 변환 𝐲 = S𝐳로 계가 풀린다(decoupling; 16·19장), 복소 고윳값과 실수 해(19장 thm:real-block-diagonal; e^{αt}(cos βt 𝐚 − sin βt 𝐛) 꼴; 증명), 결함 행렬: 일반화 고유벡터 사슬과 해 e^{λt}(𝐯₂ + t𝐯₁) 등(22장 Jordan 꼴·prop:exp-jordan에서; 증명), 일반 정리: 모든 해의 성분은 Σp_i(t)e^{λ_it}(22장), 손 계산 예 넷(실수 서로 다른 고윳값·복소·결함 2×2·3×3), 대칭 A의 경우 정규직교 고유기저와 에너지(20장), e^{tA}를 계산하는 실용적 길 요약(22장을 가리킴).
25.4 The Phase Plane — 2×2 실계수 𝐲′ = A𝐲의 궤적: 평형점의 분류(안장점, 안정·불안정 마디, 나선점, 중심, 퇴화 마디·별 마디, 선(線) 평형) — 고윳값으로, 그리고 tr A·det A 평면의 그림(판별식 포물선 tr² = 4 det; 증명: 고윳값과 tr·det의 관계 19장), 고유벡터 방향이 직선 궤적이고 느린·빠른 방향에 접하는 법, 나선의 회전 방향 판정, 24장 감쇠 진동자 my″ + cy′ + ky = 0를 위상 평면에서(세 감쇠 경우 = 나선·퇴화 마디·마디; 24장 약속), 닮음 변환에 따른 초상의 선형 변형(실 표준 꼴 세 가지; 19·22장). 그림: 여섯 가지 위상 초상 패널(TikZ/pgfplots로 궤적을 식에서 직접 그림, 회색조), tr–det 도표, 감쇠 진동자의 세 초상.
25.5 Stability of Linear Systems — 정의(Lyapunov 안정, 점근 안정, 불안정), 정리: 𝐲′ = A𝐲의 영해가 점근 안정 ⇔ 모든 Re λ < 0, 안정 ⇔ Re λ ≤ 0이고 Re λ = 0인 고윳값이 반단순(semisimple), 그 밖에는 불안정(증명: 22장 e^{tJ}의 꼴; 22장 thm 거듭제곱판과 나란히), 감쇠율: Re λ < −σ이면 ‖e^{tA}‖ ≤ Ce^{−σt}(증명)와 C가 클 수 있다는 것 — 일시적 증가(22장 prop:exp-norm-bounds·그림과 연결; 정규 행렬이면 C = 1), 스펙트럼 가로좌표 α(A)와 22장의 ω(A), 2×2 판정: tr < 0이고 det > 0, 3×3 Routh–Hurwitz 조건(진술 + 2·3차 증명; 일반은 참고 문헌), Lyapunov 방정식 AᵀP + PA = −Q와 이차 Lyapunov 함수(존재 정리: A가 안정이면 P = ∫e^{tAᵀ}Qe^{tA}dt가 유일한 양정치 해 — 증명; 22장 Sylvester 방정식 정리와 20장 양정치 사용), 대칭 A이면 Re가 아니라 고윳값의 부호 그대로(20장), 주기 계수(Floquet)는 note.
25.6 Nonhomogeneous Systems — 상수 변화법 𝐲 = Φ(t)𝐜(t)와 Duhamel 공식 𝐲(t) = e^{(t−t₀)A}𝐲₀ + ∫_{t₀}^t e^{(t−s)A}𝐛(s)ds(22·23·24장 약속; 증명), 변수 계수 꼴(전이 행렬로), 24장의 Cauchy 함수가 이 공식의 첫 성분임을 확인, 미정계수법의 연립계 꼴(지수·삼각 강제; 공명은 μ가 고윳값일 때), 입력–출력 안정성: A가 안정이고 𝐛가 유계이면 해도 유계(증명), 주기 강제의 주기 해와 주파수 응답 (iωI − A)⁻¹(증명: iω가 고윳값이 아닐 때; 24장 진폭 응답의 일반화), 정상 상태 −A⁻¹𝐛.
25.7 Second-Order Systems and Normal Modes — M𝐲″ + K𝐲 = 0(M, K 대칭 양정치): 일반화 고윳값 문제 K𝐯 = ω²M𝐯(20장 동시 대각화 정리)와 정규 모드, 일반해 = 모드의 합(증명), 에너지 보존, 예: 두 질량 세 용수철(대칭·반대칭 모드, 맥놀이 — 24장), n개 질량 사슬과 T_n의 고유벡터 sin(19·20장: 모드 모양이 사인이고 진동수가 2 sin(jπ/(2(n+1))) 꼴 — 연속 극한이 진동하는 현이라는 한 문단), 감쇠가 있을 때는 1계로 고쳐 25.5로, Rayleigh 몫과 기본 진동수의 어림(20장). 그림: 두 모드의 모양, 사슬의 처음 몇 모드.
25.8 Nonlinear Systems Near an Equilibrium — 자율계 𝐲′ = 𝐟(𝐲), 평형점, 궤도, 위상 초상, 존재·유일성(23장 진술과 연립계 조건을 인용), 선형화 𝐟(𝐲*) = 0, A = D𝐟(𝐲*)(10장), 선형화 안정성 정리: 모든 Re λ < 0이면 점근 안정(증명 — 25.5의 이차 Lyapunov 함수로 완전히 증명), Re λ > 0인 고윳값이 있으면 불안정(진술 + 줄거리 + 참고 문헌; [sketch]), 쌍곡 평형에서 선형계와 위상 동치(Hartman–Grobman; 진술, 참고 문헌)이고 중심은 선형화로 판정되지 않음(예: 𝐲′ = A𝐲 ± |𝐲|²𝐲), 예: 진자 θ″ + sin θ = 0의 위상 초상(23장 약속: 에너지 등위선으로 궤적을 완전히 그림 — 중심·안장·분리선; 감쇠 진자는 나선으로), Lotka–Volterra(보존량과 닫힌 궤도; 증명은 보존량 계산과 등위선이 닫힌 곡선임), 경쟁 모형 한 예(평형 넷의 분류), 보존계와 기울기계의 대비(12장 퍼텐셜; 23장 잠재 함수), 극한 주기 궤도·Poincaré–Bendixson·혼돈은 note로 진술만. 그림: 진자와 감쇠 진자의 위상 초상, Lotka–Volterra 궤도, 경쟁 모형.
25.9 Solving Systems Numerically: A First Look — Euler 방법의 연립계 꼴과 수렴(23장 정리가 노름으로 그대로; 인용), 선형 시험 방정식과 안정 영역: 전진 Euler는 |1 + hλ| < 1(복소 평면의 원), 후진 Euler는 그 바깥 — 모든 고윳값에 대해 hλ가 영역 안이어야 함(증명: 대각화 가능한 경우; 19장), 강성: 고윳값의 크기 차가 큰 계의 예(λ = −1, −1000)에서 전진 Euler의 보폭 제한을 직접 계산(표), 정확한 해 e^{hA}로 한 걸음씩 가는 것과의 비교(22장 expm; 공용 빌드 sd.linalg.expm·eig — API 이름 확인), 중심(조화 진동자)에서 전진 Euler가 나선으로 벌어지는 것(24장 에너지 표와 연결; 고윳값 1 + ihω의 절댓값), 진자의 주기를 수치로 재어 작은 진폭 근사 2π와 비교(진폭에 따른 주기 표; 정확한 값은 타원 적분 — 7장·10권 예고 — python-flint로). 수치는 직접 계산한 것만, 원인 추측 없이. ODE 수치 풀이는 뒤 권에서 약속하지 않는다(23·24장과 같은 방침).
