## Abstract (한 문단, 120단어 이내, 동기부여)
용수철에 매단 추, 흔들리는 다리, 전기 회로, 건물의 진동 — Newton의 법칙이 가속도에 관한 것이므로 역학의 방정식은 2계이고, 평형 근처에서는 선형이다. 선형 방정식의 해는 벡터 공간을 이루므로 선형대수의 말이 그대로 통하고, 상수 계수일 때는 다항식 하나(특성다항식)의 근이 해의 모든 것 — 진동, 감쇠, 공명 — 을 정한다는 점.

## 절 구성
24.1 Linear Differential Operators — L = D^k + a_{k−1}D^{k−1} + … + a_0(계수는 구간 I 위의 연속 함수), L이 C^k(I) → C(I)의 선형 사상(16장), 동차 방정식의 해 집합 = ker L, 비동차 방정식의 해 = 특수해 + ker L(16장 약속), 중첩 원리, 예: 조화 진동자 y″ + ω²y = 0(9장), y″ − y = 0, Airy y″ = ty(26장 예고), Euler–Cauchy t²y″ + aty′ + by = 0.
24.2 Existence, Uniqueness, and the Dimension of the Solution Space — 초기값 문제 y(t₀) = c₀, …, y^{(k−1)}(t₀) = c_{k−1}의 존재와 유일성(구간 전체에서): 1계 연립계 x′ = A(t)x + b(t)로 환원(동반 행렬; 19·22장), 상수 계수는 22장 정리에서 완전히, 변수 계수는 유일성을 Grönwall(23장)로 완전히 증명하고 존재는 Picard 반복이 선형계에서 구간 전체로 수렴함을 직접 증명(선형이므로 가능: Σ(M|t − t₀|)^j/j! 우급수 — 8장; 연속 함수열의 고른 수렴에 관해 필요한 사실은 8장의 것만 쓰고, 모자라면 진술 + 2권 가리킴 — 어디까지가 증명인지 분명히), 따름: 초기값 사상 y ↦ (y(t₀), …, y^{(k−1)}(t₀))가 ker L → 𝔽^k의 동형 ⇒ dim ker L = k(15·23장 약속; 증명), 기본 해 집합(기저), 9장 lem:harmonic-unique가 k = 2, ω의 경우임.
24.3 The Wronskian — 정의(17장), 해 y₁, …, y_k에 대해: W(t₀) ≠ 0인 점이 하나 있음 ⇔ 독립 ⇔ 모든 점에서 W ≠ 0(증명; 15장이 예고한 조건 — k개의 해, 계수 연속, 최고차 계수 0 아님 — 과 맞춤), Abel 공식 W(t) = W(t₀)exp(−∫a_{k−1})(17장 약속; 증명 — 17장 행렬식의 미분 또는 Jacobi 공식, 22장 det e^{tA} = e^{t tr A}가 상수 계수 경우), 해가 아닌 함수들에서는 W ≡ 0이어도 독립일 수 있음(17장 예 x², x|x| 재론), 2계에서 해 하나를 알 때 둘째 해 구하기(계수 낮추기; 증명과 예: Euler–Cauchy의 중근, Legendre 한 문단).
24.4 Constant Coefficients: The Characteristic Polynomial — L = p(D), e^{λt}가 D의 고유함수이고 p(D)e^{λt} = p(λ)e^{λt}(19장 약속), 서로 다른 근: e^{λ_it}가 기저(15장의 지수 함수 독립성 인용), 중근: (D − λ)^m의 핵 = {q(t)e^{λt}: deg q < m}(증명: 지수 이동 공식 p(D)(e^{λt}u) = e^{λt}p(D + λ)u), 일반 정리: ker p(D)의 기저는 t^je^{λ_it}(j < m_i)(증명: 차원 세기 + 독립성; 16장의 핵 분해 ker p(D) = ⊕ker(D − λ_i)^{m_i} — 서로소 인수; 19장 lem:spectral-projections의 꼴), 이것이 동반 행렬의 Jordan 블록에 해당함(22장 약속: 동반 행렬은 nonderogatory이므로 근마다 블록 하나 — t^j가 생기는 이유), 실계수 방정식의 실수 해: 켤레 근 α ± iβ에서 e^{αt}cos βt, e^{αt}sin βt(증명; 9장 Euler 공식), 예 여럿(2·3·4계), Euler–Cauchy 방정식을 t = e^s로 상수 계수로 바꾸기.
24.5 Undetermined Coefficients — 우변이 q(t)e^{μt}(다항식 × 지수; 삼각 함수 포함) 꼴일 때 특수해의 꼴 t^s r(t)e^{μt}(s = μ의 근으로서의 중복도; 증명: p(D)가 유한 차원 공간 {다항식 차수 ≤ d} × e^{μt} 위에서 가역 ⇔ p(μ) ≠ 0 — 16장의 선형 사상 논증; 공명 경우는 중복도만큼 t를 곱함 — annihilator 방법으로 같은 결론), 표: 우변의 꼴과 시도할 해, 예 여럿, 복소 지수로 삼각 강제를 다루는 요령(실수부 취하기), 중첩.
24.6 Variation of Parameters — 2계: y_p = −y₁∫y₂g/W + y₂∫y₁g/W(증명), k계 일반 공식(Cramer; 17장)과 Green 함수(Cauchy 함수) K(t, s): y_p(t) = ∫_{t₀}^t K(t, s)g(s)ds(증명; 상수 계수에서는 K(t, s) = k(t − s) — 합성곱; 22·25장의 e^{(t−s)A} Duhamel 꼴과 같음을 밝힘), 예: y″ + y = sec t, y″ + y = g(t) 일반(∫sin(t − s)g(s)ds), 미정계수법과의 비교(언제 어느 것).
24.7 Oscillations — 질량–용수철–감쇠기 my″ + cy′ + ky = F(t)(RLC 회로와의 대응 표), 자유 진동: 과감쇠·임계 감쇠·저감쇠(판별식 c² − 4mk; 위상 평면 예고는 25장), 진폭–위상 꼴 A cos(ωt − φ), 로그 감쇠율, 에너지 E = (my′² + ky²)/2와 dE/dt = −cy′² ≤ 0(증명; 23장의 잠재 함수·12장 일과 연결), 강제 진동: 정상 상태 응답과 과도 응답(23.4의 2계판), 진폭 응답 곡선 R(ω) = 1/√((k − mω²)² + c²ω²)과 공명 진동수(증명: 최대점), 위상 지연, 무감쇠 공명 y″ + ω₀²y = cos ω₀t의 해 t sin ω₀t/(2ω₀)(23장 약속: 공명; 24.5의 중복도 규칙이 물리로 나타난 것), 맥놀이(ω ≈ ω₀), 품질 인자 Q 한 문단. 그림: 세 가지 감쇠 응답, 진폭·위상 응답 곡선(감쇠비 여러 개), 공명에서의 선형 증가, 맥놀이.
24.8 Equations with Variable Coefficients: A Brief Look — 일반 공식이 없다는 것, 풀리는 부류: Euler–Cauchy(24.4), 계수 낮추기(24.3), 정규형 w″ + q(t)w = 0으로의 변환(y = w·exp(−∫a₁/2); 증명)과 Riccati 방정식과의 대응(23장 약속: u = w′/w), Sturm 비교 정리(진술 + 증명: q가 클수록 영점이 촘촘 — Wronskian 논증으로 완전히 증명할 수 있으면 증명)와 영점의 분리 정리(증명), 경계값 문제는 초기값 문제와 다르다(y″ + λy = 0, y(0) = y(π) = 0: λ = n²에서만 0 아닌 해 — 고윳값 문제; 19·20장의 T_n 고유벡터 sin과 연결; Sturm–Liouville은 note와 2권 예고), 26장(급수 해) 예고.
24.9 Solving Linear Equations Numerically: A First Look — 2계 방정식을 1계 연립계로 고쳐 Euler 방법(23장)을 적용: 조화 진동자에서 Euler 방법의 에너지가 (1 + h²ω²)배씩 커짐(증명과 직접 계산 표; 후진 Euler는 줄어들고, 한 줄 바꾼 symplectic Euler는 유계 — 측정만, 이론은 참고 문헌: Hairer–Lubich–Wanner 인용 검증), 공명 응답 곡선을 수치 해에서 재어 공식과 비교(작은 표), 특성다항식의 근을 수치로 구해 일반해를 쓰는 길과 그 위험(중근 근처의 민감도 — 19장 Wilkinson·Jordan 예와 연결; 한 문단). 실험은 공용 빌드 인터프리터의 순수 Python 또는 sd 배열 연산으로 충분; 수치는 직접 계산한 것만, 원인 추측 없이. ODE 수치 풀이는 뒤 권에서 약속하지 않는다(23장과 같은 방침).
