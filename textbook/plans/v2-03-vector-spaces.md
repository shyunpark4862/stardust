# 1권 15장 Vector Spaces — 얼개

예비 권(리뷰 방식). Part III의 셋째 장. 13장(R^n과 행렬 대수)과 14장(소거, 계수 = 피벗 수)을 추상 벡터 공간의 말로 다시 묶는다: 부분공간, 일차 독립, 기저, 차원, 좌표, 그리고 행렬의 네 기본 부분공간. plans/PROMISES.md에서 15장(과 "15·16장") 앞으로 온 약속을 모두 지킨다: 벡터 공간의 공리(10장), 일차 독립(10장 thm:lagrange에서 정의만), 행이 일차 독립인 m×n 행렬에서 m개의 열이 가역 부분행렬을 이룸(10장), span이 가장 작은 부분공간·k차원 flat·열 읽기로 계수 비교(13장), rank Aᵀ = rank A의 완전한 증명·차원이 잘 정의됨(14장 thm:more-unknowns를 써서)·특수해가 N(A)의 기저·N(A)가 부분공간(14장). 16장과 나눈 약속은 PROMISES.md를 읽고, 선형 사상이 꼭 필요한 것(계수–퇴화차수의 사상 꼴, rank(AB)의 차원 증명, 기저 변환과 닮음)은 16장에 남긴다. 스칼라 체는 R과 C를 함께 F로 쓰되(3장), 일반 체는 note로. 14장의 증명과 순환하지 않게 한다: rank Aᵀ = rank A의 증명은 14장에서 이 정리에 기대어 끌어낸 결과(rank(AB) ≤ rank B 등)를 쓰지 않는다.

## Abstract (한 문단, 120단어 이내, 동기부여)
다항식, 함수, 수열, 행렬, 미분방정식의 해 — 더하고 스칼라를 곱할 수 있는 것들은 모두 같은 규칙을 따르므로 한 번의 증명이 모두에 통한다. 차원이라는 한 수가 "자유도"를 세고, 행렬의 네 부분공간이 A x = b에 관한 모든 물음(풀리는가, 유일한가)에 답한다는 점.

## 절 구성
15.1 Vector Spaces — 공리(여덟 규칙; 13장의 R^n 규칙이 그대로 공리가 됨), 바로 따르는 사실(0의 유일성, 0v = 0, (−1)v = −v; 증명), 예: F^n, 행렬 공간 F^{m×n}, 다항식 공간 P와 P_n, 함수 공간 C[a,b]·C^k, 수열 공간, 동차 선형 미분방정식의 해(9장 f'' = −ω² f 예; 24장 예고), 벡터 공간이 아닌 예. 표: 예와 그 차원(뒤 절을 가리킴).
15.2 Subspaces — 정의와 판정(닫힘 세 가지; 증명), 예: N(A), 열공간 C(A), 대칭 행렬, 짝함수, 차수 ≤ n 다항식, 교집합은 부분공간(증명)·합집합은 아님(예), 합 U + W와 직합(유일 분해 ⇔ U ∩ W = {0}; 증명), 아핀 부분공간(flat) x₀ + U와 A x = b의 해집합(14장의 일반해 구조를 이 말로). 그림: R³의 부분공간들, 두 평면의 교선.
15.3 Span and Linear Independence — span은 가장 작은 부분공간(증명), 일차 독립·종속의 정의와 동치 표현(어느 하나가 나머지의 결합; 표현의 유일성; 증명), R^n에서의 판정: 열을 행렬에 놓고 소거(피벗 열이 독립; 14장), 함수의 독립성 예(1, x, x², …; e^{λ₁x}, …, e^{λ_k x}는 서로 다른 λ에서 독립 — 증명; sin, cos), Wronskian은 한 문단(24장 예고). 그림: 평면에서 독립·종속인 세 벡터.
15.4 Bases and Dimension — 기저 = 독립 + 생성, 좌표의 유일성, 교환 보조정리(Steinitz; 증명 — 14장 thm:more-unknowns "미지수가 더 많은 동차계는 0 아닌 해를 가진다"로 독립 집합의 크기 ≤ 생성 집합의 크기), 차원이 잘 정의됨(증명), 유한 생성 공간에서: 독립 집합은 기저로 늘릴 수 있고 생성 집합은 기저로 줄일 수 있다(증명), dim n인 공간에서 n개의 독립 벡터는 기저·n개의 생성 벡터는 기저(증명), 부분공간의 차원 ≤ 전체(같으면 전체; 증명), 차원 공식 dim(U+W) = dim U + dim W − dim(U∩W)(증명), 예의 차원: P_n은 n+1, F^{m×n}은 mn, 대칭 행렬 n(n+1)/2, 반대칭 n(n−1)/2. 무한 차원 공간(P, C[a,b])은 정의와 예만, Hamel 기저는 note(2권 약속과 연결).
15.5 Coordinates — 기저를 정하면 V ≅ F^n(좌표 사상이 선형 전단사; "동형"이라는 말은 16장), 기저 바꿈 행렬과 그 가역성(증명), 예: P_2의 단항 기저와 Lagrange 기저·Newton 기저 사이의 좌표 변환(14장 Vandermonde·thm:interpolation 연결; 11권 예고), R²의 기울어진 기저 그림.
15.6 The Four Fundamental Subspaces — C(A), N(A), C(Aᵀ)(행공간), N(Aᵀ)(왼쪽 영공간); 행 연산은 행공간과 영공간을 보존하고 열 사이의 일차 관계를 보존한다(증명); 기약 행 사다리꼴에서 네 공간의 기저 읽기(피벗 열 = C(A)의 기저 — 원래 행렬의 열로, 0 아닌 행 = 행공간의 기저, 특수해 = N(A)의 기저; 증명); 따라서 dim C(A) = dim C(Aᵀ) = r(rank Aᵀ = rank A의 완전한 증명), dim N(A) = n − r, dim N(Aᵀ) = m − r(계수–퇴화차수 정리의 행렬 꼴; 사상 꼴은 16장); 완전한 손 계산 예(3×4 행렬 하나로 네 공간 모두); 그림: 네 부분공간 도식(Strang의 그림에 해당하는 것을 TikZ로 새로 — 직교성은 18장에서 채운다고 적음).
15.7 Rank Revisited — 계수의 여러 얼굴: 피벗 수 = 열공간 차원 = 행공간 차원 = 가장 큰 가역 부분행렬의 크기(증명; 10장 thm:lagrange가 인용한 "행이 독립인 m×n 행렬에서 m개의 열이 가역 부분행렬"을 여기서 갚는다), 계수 분해 A = CR(C는 피벗 열, R은 기약 꼴의 0 아닌 행; 증명)과 계수 r 행렬 = r개의 계수 1 행렬의 합(13장 외적의 합 읽기 연결), 계수 1 행렬 u vᵀ, rank(A+B) ≤ rank A + rank B(증명), rank(AB) 부등식의 열공간·행공간 증명은 여기서 주어도 되는 한쪽만(C(AB) ⊆ C(A)), 나머지와 Sylvester 부등식은 16장, 완전 열 계수 ⇔ 단사(N(A) = {0}) ⇔ 왼쪽 역 존재, 완전 행 계수 ⇔ 모든 b에 해 ⇔ 오른쪽 역 존재(증명; AᵀA의 가역성은 18장 예고지만 N(AᵀA) = N(A)는 13장의 ⟨x,AᵀAx⟩ = ‖Ax‖²로 여기서 증명).
15.8 Solvability and the Fredholm Alternative — A x = b가 풀림 ⇔ b ∈ C(A) ⇔ N(Aᵀ)의 모든 y에 yᵀb = 0(증명: 차원 세기 또는 소거; 직교 여공간의 말은 18장), "둘 중 정확히 하나" 꼴의 진술, 14장 prop:singular-image의 일반화라는 것, 예: 그래프의 접속 행렬(4장 그래프 용어)에서 네 부분공간 — Kirchhoff 법칙, 연결 성분의 수 = dim N(A), 순환(cycle)의 수 = m − n + c(증명은 간단한 경우; 9권 예고). 그림: 작은 유향 그래프와 접속 행렬.
15.9 Computing Bases and Rank: A First Look — 기약 꼴로 기저를 읽는 알고리즘(유사코드 하나: 네 부분공간의 기저), 부동소수 계산에서 계수가 불안정하다는 예(성분을 10⁻¹⁶만큼 흔들면 계수가 바뀜; 공용 빌드의 sd.linalg.matrix_rank로 작은 실험 표 — API 이름은 API-INVENTORY.md에서 확인), 수치 계수는 특이값으로 정한다는 예고(21장, 8권). 수치는 직접 잰 것만, 원인 추측 없이.
