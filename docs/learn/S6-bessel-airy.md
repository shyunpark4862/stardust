사용자 결정 (2026-11-14, S6를 시작하기 전)
- scipy가 틀린 값을 내는 다섯 갈래(무한대 인자의 NaN, 오버플로·서브노멀, `k1(5e-324)`, 차수 극한, 음의 차수의 x = 0)를 참값으로 한다.
- 진동 함수: 첫 양의 영점 z₁의 0.99배 앞은 상대 1e-14, 그 뒤는 |오차| ≤ 1e-14·M(x)다. M은 정확한 진폭 √(J² + Y²)(Airy는 √(Ai² + Bi²), 도함수는 √(Ai′² + Bi′²))다. 처음에는 "첫 영점 앞 상대"였는데, 영점 바로 앞에서는 값이 0으로 가서 상대오차를 지킬 수 없어 0.99·z₁로 구체화했다(일반 ν는 영점을 미리 알 수 없어 인수분해할 수 없다).
- 보장 영역은 전 영역이다. 음의 비정수 차수의 `iv`는 두 항 크기의 합을 기준으로 한다.

## 2. 0·1차: Cephes에서 바꾼 것
- 계수는 SciPy 1.15.1 xsf의 Cephes 헤더에서 스크립트로 뽑았다. 처음 정규식이 지수에 부호가 없는 수(`E9`)를 놓쳐 개수가 모자랐다. 코드가 쓰는 개수와 맞춰 보고 찾았다.
- **Hankel 위상**: Cephes는 `xn = x − 3π/4`를 반올림한 뒤 sin, cos를 부른다. 반올림이 위상을 ulp(x)/2 옮겨서 scipy의 `y1`은 x = 3828에서 포락선의 932 ULP, 큰 x에서 8e13을 잃는다. libm의 sin x, cos x는 인자를 정확히 줄이므로 덧셈정리로 `cos(x − π/4) = (cos x + sin x)/√2`처럼 쓴다. 우리는 3.8이다.
- `e^±x`는 m·2^e라서 `i0`, `i1`이 713.98까지 유한하고 `k0`, `k1`의 서브노멀 꼬리가 산다.
- `log(x/2)`는 `log x − log 2`다. x = 5e-324에서 x/2가 0이 되어 scipy의 `k0(5e-324)`는 inf다(참값 744.56). 결정 목록에 없던 곳이라 같은 원칙으로 처리했다(§9).

## 3. 실수 차수: Temme 방법을 고친 곳
NR의 `bessjy`·`bessik`(Temme 급수, Steed의 CF2, CF1 + Wronskian)에서 시작해 재 가며 다섯 군데를 고쳤다.

1. **Γ₁, Γ₂**: NR은 맞춘 Chebyshev 계수(`beschb`)를 쓴다. 1/Γ(1+z)의 Taylor 계수를 정의에서 생성해 홀짝으로 나눠 쓴다(`tools/gen_rgamma_taylor.py`).
2. **진동 영역의 CF1**: x > ν에서 J의 비를 주는 CF1은 나쁜 조건이다. 꼬리부터 계산해도 대략 0.3·x ULP를 잃었다(x = 500에서 186 ULP). 이 영역은 재귀가 중립적으로 안정하다(특성근의 크기가 1). 그래서 x ≥ 30, ν < x이면 작은 차수 μ와 μ+1에서 Hankel로 J, Y를 정확히 구하고 위로 ν까지 재귀한다.
3. **재귀를 double-double로**: n단계의 float64 재귀는 곱과 계수 v/x의 반올림으로 n/2 ULP 정도를 잃는다(ν = 286, x = 100에서 86 ULP). 차수 v = ν − k는 정확하고(k는 정수), 1/x를 double-double로 두어 계수까지 정확하게 했다. J 아래, Y 위, I 아래, K 위, 위의 2번까지 다섯 재귀 모두 그렇다. 큰 ν에서 넘치지 않게 지수를 따로 들고 다닌다.
4. **작은 x의 거듭제곱급수**: x² < ν + 1이면 J와 I를 (x/2)^ν/Γ(ν+1)·Σ(±x²/4)^k/(k!(ν+1)_k)로 계산한다. 앞 인자는 `pow_scaled`와 scaled Γ다. 처음에는 Γ(ν+1)에 반올림된 ν + 1을 넘겨 53 ULP를 잃었다. S3에서 배운 것(Γ의 인자를 반올림하지 않는다)을 다시 밟았다. ν·Γ(ν)로 고쳤다.
5. **Hankel 점근식의 수용 판정**: 처음에는 항이 커지기 시작하면 바로 포기해서 쓸 수 있는 곳을 놓쳤다. 다음에는 항이 16까지 커져도 받아서, 항마다 쌓이는 곱셈 반올림(k·ε)이 400 ULP가 됐다. 항이 inf까지 커지자 inf끼리 비교해 통과하는 버그도 있었다. 지금은 앞항 1 대비 2 이하인 동안만 받는다.

- Hankel 위상 `x − (ν/2 + 1/4)π`도 반올림하지 않는다. ν/2 + 1/4을 반올림하면 ν = 1000에서 780 ULP다. cospi(ν/2), sinpi(ν/2)와 libm의 sin x, cos x로 덧셈정리를 쓴다.
- 음의 차수는 sinpi, cospi로 반사한다. 반정수에서 cos(aπ)가 정확히 0이라 `yv(−½, 0) = 0`이 나온다(scipy −inf).
- I와 K는 처음부터 e-스케일(e^−x I, e^x K)로 계산한다. `ive`, `kve`는 그대로, `iv`, `kv`는 exp를 m·2^e로 곱한다.

## 4. Airy
- 구간 넷: −2 ≤ x ≤ 1 Maclaurin, x > 1은 K와 I(모든 항이 양수, 상쇄 없음), −9.7 < x < −2는 J와 Y, x ≤ −9.7은 진동 점근식(DLMF 9.7.9).
- **위상을 double-double로**: ζ = (2/3)|x|^(3/2)를 반올림하면 위상이 ζ·2⁻⁵³ 움직인다. scipy는 x = −1e4에서 포락선의 5e5를 잃는다. ζ를 double-double로 만들고, Bessel 경로는 도함수로 1차 보정, 점근식은 libm의 sin, cos(ζ_hi)와 ζ_lo − π/4의 덧셈정리로 계산한다. 1e11까지 포락선 대비 0.1 미만이다.
- **한계**: double-double ζ의 절대 오차는 ζ·2⁻¹⁰⁶이다. |x| ≈ 1e12에서 22, 1e14에서 6e3, 1e20에서 8e12다(포락선 대비 2⁻⁵² 단위). 이 영역은 따로 여쭌다(§9).

## 5. 정답지 도구가 틀린 곳
- **mpmath의 `besselk`·`bessely`가 큰 ν에서 틀린 값을 낸다**: 비정수 ν의 K를 (π/2)(I₋ν − I_ν)/sin(νπ)로 계산하는데, ν = 806, x = 626이면 I가 K보다 10¹¹⁶배 커서 116자리가 상쇄된다. 기본 정밀도에서 `besselk(806.7, 626.3) = −4.3e66`(K는 양수다. 참값 2.2e-70)을 냈다. 두 배 정밀도에서도 같은 틀린 값이 나와서 우리 검증을 통과했다. mpmath 안의 적응 정밀도가 같은 오답으로 수렴한 것이다. 큰 |ν|는 0.9·|ν| + 20자리를 더해 구한다(`_wide`).
- 진동 함수의 기준은 S4 역함수의 `scale` 장치를 그대로 썼다. 상대오차의 허용을 max(1, M/|f|)배로 늘리면 포락선 기준과 같다. 첫 영점은 mpmath의 `besseljzero`, `besselyzero`로 구한다.
- `airy`는 출력이 넷이라 `airy_ai`, `airy_aip`, `airy_bi`, `airy_bip` 넷의 참값 파일로 나눴다(`refdata.PART`).

## 6. 작업 방식
- 큰 ν의 측정과 참값에서 mpmath가 느려 시간 제한에 많이 걸렸다. mpmath의 적분으로 확인하려다 시간 제한 없이 10분을 쓴 일이 한 번 더 있었다. 점마다 alarm을 거는 스크립트로 바꿔 다시 했다.

## 9. 확인 부탁
- **Airy의 |x| > 1e12** (§4): double-double 위상의 한계로 포락선 기준을 넘는다(1e14에서 6e3, 1e20에서 8e12). 더 높은 정밀도(삼중 double이나 다배정도)로 위상을 만들거나, 이 영역을 느슨한 영역으로 문서화하는 것 중에서 정해야 한다.
- **`k0(5e-324)`** (§2): 결정 목록에 없던 scipy 오류다(inf, 참값 744.56). 같은 원칙으로 참값을 냈다.
- **큰 차수의 I·K 속도** (§7): ν ∈ [50, 1000]에서 scipy보다 5–20배 느리다(1스레드). Debye 전개를 후속으로 넣을지.
- **실수 차수의 구간 수**: 설계의 3구간에 "작은 차수의 Hankel에서 위로 재귀"를 더해 4구간이다(진동 영역의 CF1이 정확도를 잃어서).
- **ν = −inf**: `jv(-inf, x)`, `iv(-inf, x)`는 scipy의 0을 따랐다(수학적으로는 극한이 없다). `kv(-inf, x) = inf`는 결정 ④와 같은 원칙이다.
