## 2. 리덕션: 배열의 리덕션 위에 원소별 연산 몇 개
- 두 패스다. `m = max(x)`(배열의 max, NaN 전파), 그다음 `exp(x − m)`의 pairwise 합(배열의 sum)이다. 그 사이의 원소별 단계는 n항 디스패처로 돈다(`m`과 합을 keepdims=True로 두면 x와 broadcast된다). 그래서 결과는 스레드 수와 무관하게 같은 비트다.
- **x − m을 정확히**: TwoSum으로 d = hi + lo를 만들고 `exp(d) = exp(hi)·(1 + lo)`다. d를 반올림하면 exp가 |d|·2⁻⁵³의 상대오차를 받는다(d = −700에서 1.5e-13). scipy의 `softmax`가 257 ULP인 이유다. 우리는 2.1이다. S2의 exp(−x²) 분할과 같은 생각이다.
- `log_softmax`는 `(hi − log s) + lo`다. 값이 0 근처일 때도 lo가 살아 있다.
- **무한대**: scipy의 규약을 그대로 따른다. `logsumexp`·`log_softmax`는 무한인 최댓값을 0으로 바꿔 빼고, `softmax`는 바꾸지 않는다. 그래서 `softmax([inf, 1])`은 [nan, nan], `log_softmax([inf, 1])`은 [nan, −inf]다.
- **빈 배열**: `log(sum(x))`로 처리해 −inf가 shape에 맞게 나온다(max는 빈 축에서 에러를 낸다).
- `logsumexp`는 결과 shape의 m을 얻으려고 max를 한 번 더 돈다. exp 패스에 비해 싸다.

### 한 패스와 두 패스 (ROADMAP S5의 비교)
- 한 패스(온라인 logsumexp): 최댓값이 커질 때마다 누적합을 `s·exp(m − x) + 1`로 다시 척도 조정한다. 메모리를 한 번만 읽는다.
- 단순 루프, 1스레드로 쟀다:

  | n | 입력 | 두 패스 (ms) | 한 패스 (ms) | 결과 차이 |
  |---|---|---:|---:|---:|
  | 10⁶ | 무작위 | 0.85 | 0.68 | 2.8e-16 |
  | 10⁸ | 무작위 | 84.7 | 68.0 | 8.6e-16 |
  | 10⁸ | 증가 (매번 척도 조정) | 59.4 | 67.9 | 0 |

- 무작위 입력에서는 최댓값이 O(log n)번만 바뀌어 한 패스가 20% 빠르다. 증가하는 입력에서는 원소마다 exp를 하나 더 해서 느리다.
- 공개 함수는 설계대로 두 패스다. 배열의 pairwise 합을 그대로 써서 오차가 log n으로 자라고, 블록 분할이 고정돼 스레드 수와 무관한 비트가 나온다. 한 패스로 같은 결정성을 얻으려면 (m, s) 쌍의 결합 트리를 따로 만들어야 한다.

## 3. 지수적분
- **Eₙ**(Numerical Recipes `expint`): x ≤ 1은 거듭제곱급수, x > 1은 연분수(S4의 `lentz_backward`, e^(−x)는 m·2^e). 설계의 세 번째 구간(큰 n의 균등 점근)은 넣지 않았다. 연분수의 b = x + n이 크면 바로 수렴하고, 급수는 x^k/k!로 준다. n = 1e5까지 6.3 ULP다. scipy(Cephes)는 n이 크면 257 ULP다.
  - 급수의 ψ(n) 항: NR은 1/i를 n번 더한다. S3의 `digamma_pos`로 바꿨다(n = 1e5에서 루프 10만 번).
  - x > 750이면 바로 0이다. 그렇지 않으면 `exp_scaled(−1e300)`의 정수 변환이 넘친다(`expi(−1e300)`이 −inf가 됐다).
- **Ei**:
  - x < 0은 −E₁(−x)다.
  - 0 < x < 40은 γ + log x + Σ xᵏ/(k·k!)다(양의 항뿐).
  - 이 급수는 Ei의 양의 0점 x₀ = 0.3725… 근처에서 γ + log x와 상쇄한다. scipy는 5e15 ULP를 잃는다. 그래서 [0.3, 0.45]에서는 x₀ 둘레의 Taylor 급수를 정확한 d = (x − x₀_hi) − x₀_lo로 계산한다(x − x₀_hi는 Sterbenz로 정확하다). 계수는 `tools/gen_ei_taylor.py`가 mpmath로 만든 급수 자체의 값이다(S3의 lgamma, S4의 Temme와 같은 원칙). 수렴 반지름은 x₀(0의 특이점)라서 |d| ≤ 0.0775에서 항이 0.21ᵏ로 줄고, 27항이면 된다.
  - x ≥ 40은 점근급수(가장 작은 항이 40에서 약 1e-17), eˣ는 m·2^e로 716.4까지 유한하다(scipy는 709.8부터 inf).

## 4. 타원적분
- **K**: AGM, `K = π/(2·AGM(1, √(1−m)))`. 1 − m은 m ≥ ½에서 정확하다. m = −1e300에서도 약 10번이면 수렴한다.
- **E**: 설계는 Carlson의 `E = R_F(0, y, 1) − (m/3)·R_D(0, y, 1)`(y = 1 − m)가 m → 1의 소거를 피한다고 적었다. 틀렸다. 이 식은 K − (K − E)라서 두 항이 log(1/y)로 커지는 동안 E → 1이다(y = 1e-16에서 약 20배의 상쇄).
  - 두 항이 모두 양수인 `E = (y/3)·(R_D(0, y, 1) + R_D(0, 1, y))`(DLMF 19.25.1)를 쓴다. mpmath로 20자리까지 같은 것을 먼저 확인했다.
  - y < 2⁻³⁴은 m = 1 둘레의 전개 `1 + (y/4)(log(16/y) − 1) + (3y²/32)(log(16/y) − 13/6)`다. R_D의 복제는 인자의 차이를 한 번에 4배씩 줄여서 y가 작으면 log₄(1/y)번이 걸린다.
  - m < 0은 `E(m) = √(1−m)·E(m/(m−1))`이다. 1 − m/(m−1) = 1/(1−m)를 직접 만든다.
  - R_D는 Carlson(1995)의 복제다. 허용치 계수 (r/4)^(−1/6)을 처음에 잘못 계산했다(472, 바른 값은 r = 2⁻⁵⁶에서 812.7).
  - `ellipe(0)`이 복제로는 π/2보다 2 ULP 작아서, m = 0은 특수값으로 둔다(scipy와 같다).

## 7. 확인 부탁
- **타원적분의 방법**: 설계는 AGM과 Carlson이었다(두 방법의 대비가 해설의 주제). 재 보니 Cephes의 다항식이 같은 정확도로 4–8배 빠르다(§6). §1.3의 규칙(정확도 다음 속도)만으로는 Cephes 쪽이다. 설계에서 정한 것을 바꾸는 일이라 여쭌다. 바꾸면 AGM·Carlson은 비교용 비공개 함수로 남긴다.
- **`expn`의 구간**: 설계의 3구간(큰 n 균등 점근) 대신 2구간이다(§3).
- **`expi`의 구간**: 설계의 2구간에 0점 둘레 Taylor를 더해 3구간이다(사용자 결정의 보장 영역을 지키려고).
