# S9. 최종 보고서: `sd.special`

> scipy.special의 부분집합 65개 함수를 C++20 `_core` 위에 다시 만들었다(S0–S9, 2026-11-12 – 2026-11-14). **참값 파일 72개(함수 65개, 복소 입력과 가지별 파일 포함)의 보장 영역에서 최대 오차가 모두 상대 1e-14 안이다**(중앙값 6.8 ULP). 같은 입력에서 scipy는 50개 파일이 45 ULP를 넘거나 inf·NaN을 낸다. 속도는 10⁶개 배열에서 scipy 대비 기하평균 1스레드 0.91배, 10스레드 7.1배다. 1스레드에서 72개 중 38개가 빠르고 32개가 느리며, 크게 느린 것은 초기하와 큰 차수의 I·K다(§5).

> S10(docs/learn/S10-boost.md)에서 20개 함수의 일부 구간을 Boost.Math로 바꿔 그 함수들의 속도와 정확도가 바뀌었다. 이 보고서는 S9 시점의 기록으로 둔다.

이 보고서의 수치는 저장소에 있는 측정에서 가져왔다. 정확도와 속도는 S9에서 지금의 빌드로 전 함수를 다시 쟀다(`bench/special/final/`). 줄마다 출처를 적는다.

## 2. 정확도
`bench/special/final/accuracy.md`. 값은 참값 대비 최대 ULP다. 오차를 포락선이나 κ로 재는 함수(14장 §3.2)는 그 배율로 나눈 값이다. ULP 한 칸은 상대 1.1e-16–2.2e-16이라, 계약(상대 1e-14)은 약 45–90 ULP에 해당한다. 테스트는 ULP가 아니라 상대오차로 본다.

| 묶음 | sd 최대 (보장 영역) | scipy 최대 (같은 입력) |
|---|---|---|
| 로지스틱·정보 (`expit` 등 7) | 1.2–2.8 | `expit` 1.1e15(서브노멀 꼬리를 0으로), 나머지 1.2–2.1 |
| 오차함수 (`erf` 등 8) | 2.3–7.8 | `erfc`·`ndtr`·`log_ndtr` 1e13(서브노멀 꼬리), `erfcx` 500, `erfcinv` inf |
| 감마·베타·제타 | 2.1–24.2 (`zeta` 24.2) | `gamma`·`polygamma` 8e15–9e15, `zeta` 5.5e15, `beta` 3.1e8, `gammaln`·`rgamma` inf |
| 불완전 감마·베타 | 8.9–33.3, 역함수 6.7–59(κ로 나눔) | 2.4e10–inf, 역함수 inf |
| 지수적분·타원적분 | 2.0–13.6 | `expi` inf, `expn` 3.4e18, 타원 2.3–4.0 |
| 리덕션 | `logsumexp` 0.69, `softmax` 2.1, `log_softmax` 1.3 (`bench/special/s5/accuracy.md`) | 0.5 안팎 |
| Bessel 0·1차 | 3.97–46.4 (`y1`) | `y1` 1.6e16, `i0`·`i1` inf |
| Bessel 실수 차수 | 8.1–23.2 (포락선) | `yv` 2.3e5, `ive` 5.2e15, 나머지 inf |
| Airy | 34.8–57.3 (포락선, \|x\| ≤ 1e12) | inf |
| 초기하 | `hyp1f1` 6.9, `hyp2f1` 11 | 248, 208 |

| 복소수 | `wofz` 2.0, `erf erfc erfcx` 1.9–3.4, `loggamma` 8.2, `lambertw` 0.9–1.9 | 224–255, inf, 1e8 |

- 참값 파일 72개 중 scipy가 45 ULP를 넘거나 inf·NaN을 내는 것이 50개다. 대부분 우리가 일부러 넣은 어려운 점(서브노멀 꼬리, 분기점, 큰 인자, 상보 상쇄, 영점 근처)에서다. 보통 인자에서는 scipy도 몇 ULP다.
- **느슨한 영역**(보장 밖, 잰 값을 문서화): `hyp1f1`의 a < 0, x > 0(상대 3.9e-3; scipy 2.9e-13로 여기만 scipy가 낫다), `hyp2f1`의 z > 0.9 등(6.6e-13; scipy 3.2e-4), Airy의 \|x\| > 1e12.

## 3. 성능
`bench/special/final/speed.md`. 10⁶개 배열, 표본은 참값 파일의 보장 영역 입력, 3라운드 중 가장 빠른 값. scipy / sd이므로 1보다 크면 sd가 빠르다. scipy.special의 ufunc는 1스레드다.

| 묶음 | 파일 | 1스레드 기하평균 (범위) | 10스레드 기하평균 (범위) |
|---|---:|---|---|
| 로지스틱·정보 | 7 | 1.49 (1.09–5.00) | 10.3 (7.8–32.2) |
| 오차함수 | 8 | 1.76 (1.06–2.14) | 12.4 (7.9–15.3) |
| 감마·베타·제타 | 10 | 0.66 (0.18–1.23) | 5.2 (1.5–9.2) |
| 불완전 감마·베타 | 8 | 0.65 (0.29–1.45) | 5.6 (2.5–12.4) |
| 지수적분·타원적분 | 4 | 1.14 (0.79–2.45) | 8.4 (6.0–18.1) |
| Bessel 0·1차 | 12 | 0.88 (0.74–1.15) | 6.4 (5.3–8.5) |
| Bessel 실수 차수 | 6 | 0.34 (0.10–1.79) | 3.0 (0.9–15.8) |
| Airy | 1 | 1.35 | 11.7 |
| 초기하 | 2 | 0.08 (0.05–0.14) | 0.8 (0.5–1.2) |
| Lambert W (실수) | 2 | 5.44 (3.84–7.71) | 40.4 (28.5–57.1) |
| 복소수 | 9 | 1.20 (0.70–2.31) | 9.5 (5.8–19.4) |
| **전체** | **72** | **0.91** | **7.1** |

- 10스레드에서 scipy보다 느린 것은 `hyp2f1`(0.47배)과 `iv`(0.92배) 둘이다.
- 1스레드에서 크게 느린 것(0.6배 아래): `hyp2f1` 0.05, `iv` 0.10, `ive` 0.13, `hyp1f1` 0.14, `zeta` 0.18, `kve` 0.21, `kv` 0.23, `betainc`·`betaincc` 0.29, `betaln` 0.34, `binom` 0.47, `gammainccinv` 0.49, `beta` 0.54, `betainccinv` 0.59. 원인은 §5.
- 가장 빠른 것: `lambertw(k=-1)` 7.7배, `expit` 5.0배, `lambertw` 3.8배(분기점 근처의 정확도를 고친 같은 식이 scipy의 반복보다 짧다).
- 리덕션(`logsumexp`, `softmax`, `log_softmax`)은 S5에서 따로 쟀다: 10⁶개에서 scipy 대비 1스레드 0.9–3.6배(`logsumexp`가 빠르고 `softmax`·`log_softmax`는 비슷), 10스레드 2–22배 (`bench/special/s5/reduce.md`).
- 스칼라 한 번 호출의 중앙값은 sd 0.20 µs, scipy 0.26 µs다(`bench/special/final/speed.md`의 마지막 두 열).
- 원소 하나의 비용(`bench/special/final/cost.md`)과 `cost.hpp`의 가중치는 두 배 안에서 맞는다. 상한(256)에 걸린 함수는 원소 16개마다 작업을 나눌 수 있다.

## 4. scipy와 다른 것
- 특수값: docs/design/special.md §2.4의 표. 원칙은 하나다: scipy가 틀리거나 NaN을 내는 곳은 참값이나 극한(마일스톤마다 사용자 결정).
- API: 입력은 위치로만, `out=`은 키워드로만, complex는 S8 함수만, `lambertw`는 실수 입력에 float64, `airy`는 `AiryResult`, 경고와 별칭이 없다 (docs/design/special.md §2.4 아래 표).

## 6. 과정에서 배운 것
안내서 15장 §8에 모았다. 짧게:
- 정확도는 반올림이 **쌓이는** 곳(급수, 점화식, 지수의 인자)과 **상쇄하는** 곳(반사식, 영점 근처)을 찾는 일이었다. 쌓이는 곳은 double-double, 상쇄하는 곳은 식을 바꾸거나 계약을 포락선으로 정했다.
- 참값 도구도 틀린다(mpmath의 큰 차수 Bessel). 두 자릿수 비교가 지켰다.
- 긴 측정은 점마다 시간 제한과 즉시 출력. 알고리즘 실험은 C++로.
- scipy를 따라 하기 전에 먼저 잰다.

## 7. 승인
