# sd.regression API

> 상태: **G1–G6 구현** (2026-11-18): §2의 `ols wls gls linregress`, 고전형·HC0–HC3·HAC·군집 공분산, 랭크 부족, 배치, 진단, `summary(*, alpha=0.05)`; §3의 `glm`; §4의 `ridge lasso elastic_net`, 경로, `ridge_cv lasso_cv elastic_net_cv`, 정규화 GLM `penalized_glm`; §5의 `rlm theilslopes siegelslopes`; §6의 `quantreg`; §7의 `nls`(G6, 2026-11-19).

## §1. 공통 규칙
- 입력은 위치로만(`y`, `X`), 옵션은 키워드로만. 별칭은 없다.
- `y`는 (..., n), `X`는 (..., n, k) 또는 (n,)이다(1차원 `X`는 설명변수 하나). `sd.ndarray`, 실수의 시퀀스, `sd.frame`의 `Series`·`DataFrame`을 받는다. frame의 결측값은 NaN이 되어 `nan_policy`를 따른다. 0차원(Python 스칼라)은 `ValueError`다.
- float64로 계산한다(bool·int64는 바꿔서). complex는 `TypeError`다(`ols(): 'X' must be real, not a complex128 array`).
- **절편은 기본으로 넣는다**(사용자 결정 2026-11-18). `intercept=False`로 끈다. 절편이 있는지는 이 옵션만 보고 정한다. statsmodels처럼 `X`의 상수 열을 찾아 절편으로 보지 않는다(절편 없이 상수 열을 주면 R²는 비중심이다).
- **NaN** (`nan_policy`, sd.stats의 기술통계와 같은 세 값과 같은 메시지): `'propagate'`(기본)는 그 회귀의 모든 값이 NaN이다(`nobs`·`df_model`·`df_resid`도 NaN, `rank`는 0). `'omit'`은 `y`, `X`의 행, 가중치 가운데 NaN이 있는 행을 빼고(적합값·잔차도 남은 행만), `'raise'`는 `ValueError`(`ols(): the input contains NaN (nan_policy='raise')`)다.
- inf는 `nan_policy`와 상관없이 `ValueError`다(`ols(): 'X' contains infinity`; 사용자 결정 2026-11-18).
- **배치**: 앞 축을 배치로 받아 같은 모양의 회귀를 한 번에 푼다. `y`, `X`, `weights`, `sigma`의 배치 모양은 서로 브로드캐스트한다(`X` 하나에 `y` 여럿도 된다). 결과 필드의 앞에 배치 모양이 붙는다. 배치에서 `nan_policy='omit'`은 `ValueError`다. 배치의 결과는 회귀 하나씩 부른 결과와 비트까지 같다. 배치 모양이 브로드캐스트하지 않으면 인자 이름과 모양을 적은 `ValueError`다(`wls(): the batch shapes of 'y' (3,), 'X' (), 'weights' (2,) do not broadcast`; `linregress`·`theilslopes`·`siegelslopes`·`glm`·정규화도 같은 꼴).
- 결과 필드는 입력과 상관없이 `sd.ndarray`다. 회귀 하나의 스칼라는 Python 수다(`rank`는 `int`, 나머지는 `float`; statsmodels처럼 `nobs`·`df_model`·`df_resid`도 `float`). 배치면 `rank`는 int64, 나머지는 float64 배열이다.
- 계수(`params`, 경로의 계수도)가 정확히 0이면 +0.0이다(G84; −0.0은 풀이의 반올림이 남긴 부호라 데이터에 뜻이 없다. `theilslopes`의 기울기와 같은 규칙).
- **입력의 복사** (G86): 나중에 계산하는 필드(지렛대, 스튜던트화 잔차, Cook 거리, `jarque_bera()`·`breusch_pagan()`, 정규화의 `fittedvalues`·`resid`)가 읽는 `y`, `X`, `weights`는 적합할 때 복사해 둔다. 그래서 적합 뒤에 넘긴 배열(또는 그 배열이 보는 numpy 배열)을 고쳐도 결과는 그대로다(statsmodels는 바뀐 배열로 계산한다). 그만큼 메모리가 더 든다: `ols`·`wls`·정규화는 `X`의 크기(n·k·8바이트)와 `y`·`weights`. `gls`는 백색화한 L⁻¹y·L⁻¹X를 원래 만들어 두므로 더 들지 않는다.
- **예측의 입력** (G90, G91): `predict`·`predict_interval`의 `X_new`는 적합의 `X`와 열 수가 같아야 한다. 적합의 `X`가 frame `DataFrame`이고 `X_new`도 `DataFrame`이면 열 이름과 순서가 적합과 같아야 하고, 다르면 `ValueError`다(`predict(): 'X_new' must have the columns ['a', 'b'] in the fit's order, not ['b', 'a']`; 이름이 다르면 `... like the fit's 'X', not ['a', 'c']`). 순서를 맞춰 주지 않는 것은 scikit-learn과 같다: 어느 쪽이 맞는지 짐작하지 않는다. 한쪽만 `DataFrame`이면(배열로 적합하고 `DataFrame`으로 예측, 또는 그 반대) 열을 위치로 맞춘다(scikit-learn은 이때 경고를 내고 같은 일을 한다; 이 라이브러리는 경고를 내지 않는다). `X_new`의 inf는 적합의 입력처럼 `ValueError`다(`predict(): 'X_new' contains infinity`), NaN은 그 행의 예측이 NaN이다.
- 같은 입력이면 스레드 수와 상관없이 같은 비트다. 경고는 내지 않는다.
- 에러는 함수 이름으로 시작한다(`ols(): 'X' must have 100 rows like 'y', not 99`). 옵션의 메시지는 다른 영역과 같은 꼴이다(`ols(): 'rtol' must be a finite number >= 0`, `ols(): 'cov_type' must be 'nonrobust', 'HC0', 'HC1', 'HC2', 'HC3', 'HAC' or 'cluster', not 'x'`).
- **정확도** (G15, 사용자 결정 2026-11-18): 계수 벡터의 상대오차(노름) ≤ 1e-14를 κ(X) ≤ 10¹¹에서 약속한다(잔차가 ‖Xβ‖의 100배까지 잰 값). 반복 개선을 필요할 때까지 최대 3번 한다. 그 밖은 잰 값이다: κ 10¹²에서 1.6e-12, 10¹³에서 3.4e-9, 10¹⁴에서 2.5e-7(설계 §3.1). 표준오차는 R에서 계산하므로 상대오차가 κ·u 정도다. 닫힌 꼴은 Arb 참값과 비교한다.

## §2. 선형 (G1)
```
ols(y, X, /, *, intercept=True, cov_type='nonrobust', maxlags=None, groups=None, rtol=None, nan_policy='propagate')
wls(y, X, /, *, weights, intercept=True, cov_type='nonrobust', maxlags=None, groups=None, rtol=None, nan_policy='propagate')
gls(y, X, /, *, sigma, intercept=True, cov_type='nonrobust', maxlags=None, groups=None, rtol=None, nan_policy='propagate')
linregress(x, y, /)                       # -> LinregressResult(slope, intercept, rvalue, pvalue, stderr, intercept_stderr)
```
- 결과는 `OLSResult`, `WLSResult`, `GLSResult`이고 필드 이름은 statsmodels의 것이다(G10).
  - 계수와 추론: `params bse tvalues pvalues`, `conf_int(alpha=0.05)`(…, k, 2: 아래·위 끝), `cov_params()`(…, k, k)
  - 적합: `fittedvalues resid nobs df_model df_resid ssr ess centered_tss uncentered_tss rsquared rsquared_adj fvalue f_pvalue llf aic bic scale`
  - 상태: `rank condition_number param_names cov_type`
  - 예측: `predict(X_new, /)`, `predict_interval(X_new, /, *, alpha=0.05, kind='mean')`(…, m, 2: 아래·위 끝; `kind='observation'`이면 새 관측의 구간)
  - 진단: `leverage resid_studentized_internal resid_studentized_external cooks_distance durbin_watson`, `jarque_bera()`(→ `JarqueBeraResult(statistic, pvalue)`), `breusch_pagan(*, studentize=True)`(→ `BreuschPaganResult(lm, lm_pvalue, fvalue, f_pvalue)`, statsmodels `het_breuschpagan`의 필드와 순서)
  - `summary(*, alpha=0.05)`: 글(`str`)
- 절편은 `params[0]`이다(추론 필드도 같은 자리). 계수 이름 `param_names`는 절편 `'const'`, frame이면 컬럼 이름(`Series`는 그 이름), 그 밖에는 `'x1'…'xk'`다.
- 추론 필드는 처음 읽을 때 계산한다. p값은 t의 두 꼬리 2·`StudentT(df_resid).ccdf(|t|)`, 구간은 `iccdf`, F의 p값은 `F(df_model, df_resid).ccdf`다(sd.stats).
- `rsquared`, `ess`는 R² < 1/2이면 ESS를 직접 더한 값으로, 그 밖은 1 − SSR/TSS로 계산한다(R² ≈ 0에서도 상대 정확도). TSS는 절편이 있으면 `centered_tss`, 없으면 `uncentered_tss`다. `rsquared_adj`는 1 − (nobs − 절편 수)/df_resid·(1 − R²)다. 절편만 남은 모형은 ESS와 R²가 0이고 `fvalue`, `f_pvalue`는 NaN이다(statsmodels와 같다). 절편이 있고 y가 적합에 쓰인 행(가중치 > 0)에서 정확히 모두 같으면(y₀) 해는 정확히 (y₀, 0, …, 0)이다(G92; 겹친 열은 그대로 NaN). 계수, `fittedvalues`(모든 행에서 y₀), `resid`(y − y₀: 쓰인 행에서 0, 가중치 0인 행은 그 차), `ssr`·TSS·ESS(0)를 그 값으로 낸다(QR의 해는 기울기 6e-32 같은 반올림을 남긴다). 그래서 완전 적합(G22)이다: `scale` 0, `bse` 0(강건 공분산도 0), t는 절편 ±inf·기울기 NaN(0/0), `llf` +inf, 스튜던트화 잔차는 NaN. GLS도 같다(절편 열이 모형에 있으므로 백색화한 문제에서도 y₀·L⁻¹1이 L⁻¹y의 정확한 해다; 백색화한 잔차도 0으로 둔다). 절편이 없으면 해가 자명하지 않아 이 규칙이 없다. TSS가 정확히 0이면(y가 모두 같다) 설명할 변동이 없어 `rsquared`, `rsquared_adj`, `fvalue`, `f_pvalue`(강건 공분산의 Wald F도)는 0/0이라 NaN이고 `ess`는 0이다(G85; statsmodels는 R² −inf, F −4 같은 반올림의 값을 낸다). 정규화의 `rsquared`와 `deviance_ratio`도 TSS·귀무 편차가 0이면 NaN이다.
- `llf`는 정규 우도의 최댓값이다(statsmodels와 같다; WLS는 ½Σlog w를, GLS는 −½log|Σ|를 더한다). `aic` = −2·llf + 2·rank, `bic` = −2·llf + log(nobs)·rank다.
- `condition_number`는 쓰인 열(가중·백색화한, 절편 열 포함)의 2-노름 조건수다(R의 특이값으로). 겹친 열은 들어가지 않는다.
- **`cov_type`**: `'nonrobust'`(σ̂²(XᵀX)⁻¹), `'HC0'`–`'HC3'`(statsmodels와 같은 샌드위치와 보정), `'HAC'`, `'cluster'`. 강건 공분산에서도 p값과 구간은 t(`df_resid`)로 계산하고(사용자 결정 2026-11-18; R의 coeftest와 같고, statsmodels의 `use_t=True`와 같다), `fvalue`는 절편을 뺀 계수 전부의 Wald 검정 F(분자 자유도는 그 계수 수, 분모는 `df_resid`)다. 군집만 자유도가 다르다(아래).
  - **`'HAC'`** (Newey–West, G26): 지연 수는 `maxlags`(0 이상의 int)이고, None이면 floor(4(nobs/100)^(2/9))다(statsmodels의 `S_hac_simple`과 같은 식). 커널은 Bartlett(가중치 1 − l/(L+1))이고 소표본 보정은 하지 않는다(statsmodels의 기본 `use_correction=False`, R `sandwich::NeweyWest(adjust=FALSE)`와 같다; Stata의 `newey`는 n/(n−k)를 곱한다). 자동 대역폭 선택은 없다. 행은 주어진 순서가 시간 순서다. `maxlags`를 다른 `cov_type`과 주면 `ValueError`(`ols(): 'maxlags' is only used when cov_type='HAC'`)다.
  - **`'cluster'`** (일원 군집, G27): `groups`는 행마다 군집 레이블이다. int·bool·float의 `sd.ndarray`(배치 축이 있으면 회귀마다 다른 레이블), 정수·실수·문자열의 시퀀스, frame `Series`를 받고, 같은지만 본다. 소표본 보정 G/(G−1)·(nobs−1)/(nobs−rank)를 곱하고, t의 p값·구간·`predict_interval`과 F 검정의 분모 자유도는 G − 1이다(Stata와 같고, statsmodels의 `use_t=True`와 같다; statsmodels의 `get_prediction`은 이때도 `df_resid`를 쓴다). `df_resid`는 그대로 nobs − rank다. G는 적합에 쓰인 행(가중치 > 0)에 나오는 군집 수다. 군집이 하나면 공분산은 NaN이다. 군집 수 − 1이 검정할 계수 수보다 작으면 공분산이 특이해서(군집 점수의 합은 Xᵀe = 0이라 고기 행렬의 랭크가 G − 1 이하다) `fvalue`·`f_pvalue`가 NaN이다(반올림 때문에 Cholesky가 통과해도). `groups` 없이 `'cluster'`면 `ValueError`(`ols(): 'groups' is required when cov_type='cluster'`), 다른 `cov_type`에 `groups`를 주면 `ValueError`(`ols(): 'groups' is only used when cov_type='cluster'`), 길이가 다르면 `ValueError`(`ols(): 'groups' must have 100 values like 'y', not 99`)다. 레이블이 없는 행(float의 NaN, 시퀀스의 None·NaN, frame의 NA)은 NaN 데이터처럼 `nan_policy`를 따른다.
  - 가중치 0인 행은 HAC의 지연 합과 군집 합에서도 빠진다(적합에 쓰인 행이 그 순서로 이어진다). 그래서 0인 행이 있는 WLS는 그 행을 뺀 WLS와 비트까지 같다(statsmodels는 그 행을 점수 0인 시점으로 두고, 그 행에만 있는 군집도 센다).
- **가중치** (`wls`): 0인 행은 적합과 `nobs`·자유도에서 빠지고 적합값·잔차만 계산한다(R의 `lm`과 같다; statsmodels는 `nobs`에 센다). 음수는 `ValueError`(`wls(): 'weights' must be >= 0`), NaN은 `nan_policy`를 따른다. 가중치가 모두 1이면 `ols`와 비트까지 같다.
- **GLS**: `sigma`는 (…, n, n)인 오차 공분산이고 아래 삼각만 읽는다. Cholesky Σ = LLᵀ로 L⁻¹y, L⁻¹X를 만들어 푼다. `fittedvalues`·`resid`는 원래 척도(y − Xβ)이고, `ssr`과 TSS는 백색화한 값이다(statsmodels와 같다). 양정치가 아니면 `sd.linalg.LinAlgError`(`gls(): 'sigma' is not positive definite`)다. `nan_policy='omit'`은 `sigma`의 i행이나 i열에 NaN이 있으면 관측 i도 뺀다. NaN·inf 검사는 읽지 않는 위 삼각까지 행렬 전체에 한다(위 삼각의 NaN 하나도 `propagate`면 모든 값이 NaN, `omit`이면 그 행과 열의 관측 둘이 빠지고, inf는 `ValueError`): `sigma`는 대칭 행렬이어야 하기 때문이다.
- **랭크 부족** (G9, G21): 피벗 없는 QR에서 |R_jj| ≤ rtol·‖x_j‖인 열(가중·백색화한 열)을 겹친다고 보고 빼서 다시 분해한다(R `dqrdc2`와 같은 선택: 앞 열이 남는다). `rtol`의 기본은 max(nobs, k)·eps다(R의 허용오차는 `rtol=1e-7`). 겹친 열의 계수·표준오차·t·p는 NaN이고, `cov_params()`의 그 행과 열도 NaN이다. 나머지 값은 그 열을 뺀 적합과 비트까지 같다. 적합값·잔차·예측은 정상이고(예측에서 겹친 열은 쓰지 않는다), `rank`는 남은 열 수, `df_model`·`df_resid`·`aic`·`bic`는 `rank`로 센다. 절편과 X의 상수 열이 겹치면 절편이 남는다. 열이 행보다 많으면 앞의 nobs개 열까지만 남는다.
- **완전 적합** (잔차가 정확히 0): `bse` 0, `tvalues` ±inf(계수가 0이면 NaN), `pvalues` 0, `llf` +inf다(IEEE의 극한; statsmodels는 잔차가 반올림 수준이라 아주 큰 t와 아주 작은 p를 낸다). `df_resid`가 0이면 `scale`은 inf(또는 0/0이면 NaN)다.
- **`linregress`**: scipy와 같은 꼴(G18). 결과는 Python `float`, `x`와 `y`가 (…, n)이면 배치 모양의 배열이다(§1처럼 배치 모양이 서로 브로드캐스트한다: `x` 하나에 `y` 여럿, 또는 그 반대). NaN은 전파한다. scipy처럼 `x`가 모두 같으면 모든 값이 NaN이고, `y`가 모두 같으면 `rvalue`, `pvalue`, `stderr`, `intercept_stderr`가 NaN이다(기울기 0, 절편 ȳ). 점이 한 직선 위에 있으면 `pvalue`는 0이다(scipy는 1e-20을 더해 9e-11 같은 값을 낸다). `x`가 정확히 같을 때만 기울기가 없다고 본다(`rtol=0`).
- **진단** (G17, G28, G29): 모두 커널이 푸는 백색화한 문제의 것이다(WLS는 √w y와 √w X, GLS는 L⁻¹y와 L⁻¹X; 강건 공분산과 같다). ẽ는 백색화한 잔차(OLS는 `resid`, WLS는 √w·`resid`, GLS는 L⁻¹`resid`)다.
  - `leverage`: 지렛대 h_t(hat 행렬의 대각, …, n). 적합의 QR에서 얇은 Q를 만들어 h_t = ‖q_t‖²로 구한다(XᵀX를 만들지 않는다). 처음 읽을 때 같은 열로 QR을 한 번 더 한다.
  - `resid_studentized_internal`: ẽ_t / (s√(1 − h_t)), s² = `scale`(statsmodels의 이름, R의 `rstandard`). `resid_studentized_external`: 행 t를 뺀 척도 s_(t)로 나눈 값으로, r√((df − 1)/(df − r²))로 계산한다(r은 내적, df는 `df_resid`; R의 `rstudent`).
  - `cooks_distance`: r_t²/rank · h_t/(1 − h_t)(R의 `cooks.distance`; statsmodels의 `cooks_distance[0]`은 rank 대신 X의 열 수로 나눠 겹친 열이 있을 때만 다르다).
  - `durbin_watson`: Σ(ẽ_t − ẽ_{t−1})² / Σẽ_t², 적합에 쓰인 행의 순서로(double-double 합).
  - `jarque_bera()`: n/6·(S² + (K − 3)²/4), S·K는 ẽ의 중심 적률(n으로 나눈)로 만든 왜도·첨도, p값은 자유도 2의 카이제곱이다(statsmodels의 `jarque_bera(wresid)`와 같다; 절편이 있으면 ẽ의 평균은 0이다).
  - `breusch_pagan(*, studentize=True)`: ẽ²를 상수와 백색화한 설계의 열(OLS는 X; WLS는 √w와 √w X; GLS는 L⁻¹1과 L⁻¹X)에 회귀하는 보조 회귀다. `studentize=True`(Koenker, statsmodels·R lmtest의 기본)는 lm = n·R², `False`(원래 판)는 lm = ESS/(2σ̂⁴), σ̂² = `ssr`/n다. lm의 p값은 자유도가 보조 회귀의 `df_model`인 카이제곱이고, `fvalue`·`f_pvalue`는 보조 회귀의 F 검정이다. 보조 회귀는 모형의 절편과 상관없이 상수를 넣는다(statsmodels의 `het_breuschpagan`과 R `lmtest::bptest`의 기본은 주어진 설계를 그대로 쓰므로 절편이 있는 모형에서 같다; `bptest`는 `varformula = ~ X`면 절편이 없는 모형에서도 같다. 가중 적합의 `bptest`는 다른 통계량이다). 보조 회귀의 열이 겹치면 G1의 규칙대로 빠지고 자유도도 줄어든다.
  - 가중치 0인 행: `leverage`, 두 스튜던트화 잔차, `cooks_distance`는 가중 식대로 0이고, `durbin_watson`, `jarque_bera()`, `breusch_pagan()`의 합에서는 빠진다(그 행을 뺀 WLS와 같다).
  - 겹친 열: 그 열을 뺀 적합과 같다. 완전 적합(잔차가 정확히 0): 스튜던트화 잔차, Cook 거리, `durbin_watson`, `jarque_bera()`, `breusch_pagan()`은 0/0이라 NaN이고 `leverage`는 정상이다. NaN이 있는 회귀(propagate)는 모두 NaN이다. 배치는 필드가 배치 모양을 갖는다(`jarque_bera()`·`breusch_pagan()`의 각 값도).
- **`summary(*, alpha=0.05)`** (G13): statsmodels의 OLS summary와 같은 꼴의 글이다. 계수 표의 구간은 1 − alpha다. 위에 모형(OLS·WLS·GLS), 방법, 관측 수, 자유도, 공분산 종류, R²·수정 R², F와 p값, 로그우도, AIC, BIC; 가운데에 계수 표(`param_names`, 계수, 표준오차, t, P>|t|, 95% 구간); 아래에 Durbin–Watson, Jarque–Bera와 그 p값, 조건수(`condition_number`); 끝에 공분산 종류의 설명(HAC는 지연 수, 군집은 군집 수와 자유도)과 겹친 열의 이름이 있다. 숫자의 꼴은 statsmodels와 같다(R² `%.3f`, 계수 소수 4자리 등). 폭은 78자이고 계수 이름이 길면 넓어진다. 날짜·시각은 넣지 않는다. 배치 결과는 `ValueError`(`summary(): takes one regression, not a batch of shape (7,)`)다. `repr`는 한 줄 요약 그대로다.
- 다항식 적합은 따로 없다: 거듭제곱 열을 만들어 `ols`를 부른다.

- `df_resid_inference`: p값과 구간에 쓰는 t의 자유도(F의 분모 자유도). 보통 `df_resid`, `cov_type='cluster'`이면 군집 수 − 1이다.

## §3. 일반화 선형 (G2)
```
glm(y, X, /, *, family, link=None, var_weights=None, freq_weights=None, trials=None, offset=None, exposure=None, intercept=True, scale=None, cov_type='nonrobust', maxlags=None, groups=None, max_iter=100, tol=1e-08, rtol=None, nan_policy='propagate')
```
- 결과는 `GLMResult`이고 필드 이름은 statsmodels의 것이다(G10). §1의 공통 규칙(입력, 절편, NaN, inf, 배치, 스레드, 에러의 꼴)을 따른다.
- **분포족과 링크** (G31): `family`는 `'gaussian'`, `'binomial'`, `'poisson'`, `'gamma'`이고 `link`는 분포족마다 다음 가운데 하나다. None이면 정준 링크(맨 앞)다.

  | `family` | `link` | 분산 V(μ) | `y` |
  |---|---|---|---|
  | `'gaussian'` | `'identity'`, `'log'` | 1 | 실수 |
  | `'binomial'` | `'logit'`, `'probit'`, `'cloglog'`, `'log'` | μ(1 − μ) | 0 또는 1, `trials`가 있으면 [0, 1]의 비율 |
  | `'poisson'` | `'log'`, `'identity'`, `'sqrt'` | μ | ≥ 0 (정수가 아니어도 된다) |
  | `'gamma'` | `'inverse'`, `'log'`, `'identity'` | μ² | > 0 |

  - 이름은 문자열로만 받는다(`family='binomial', link='probit'`; statsmodels처럼 객체를 받지 않는다). 다른 이름은 `ValueError`(`glm(): 'link' must be None, 'logit', 'probit', 'cloglog' or 'log' for the binomial family, not 'identity'`)다.
  - `y`가 분포족의 범위 밖이면 가중치와 상관없이 `ValueError`다(`glm(): 'y' must be 0 or 1 for the binomial family without 'trials'`). 범위 밖(이항 [0, 1] 밖, 포아송 음수, 감마 0 이하)은 R도 에러이고, R은 시행 수 없는 이항의 0과 1 사이 `y`를 경고("non-integer #successes")와 함께 받는다.
- **가중치** (G36): `var_weights`(분산이 V(μ)/w, R의 `weights`)와 `freq_weights`(행마다 같은 관측의 수). 둘 다 ≥ 0이고 정수가 아니어도 된다. `freq_weights`는 행을 그 수만큼 반복한 적합과 같다: `nobs`는 적합에 쓰인 행의 `freq_weights` 합이고 `df_resid`, `llf`, `aic`, `bic`, 강건 공분산도 반복한 자료의 값이다(statsmodels의 `nobs`는 행 수이고 이 합은 `wnobs`다). 가중치(`var_weights`·`freq_weights`·`trials`의 곱)가 0인 행은 적합과 `nobs`·자유도에서 빠지고 적합값·잔차만 계산한다(G20; statsmodels는 `var_weights`가 0인 행을 `nobs`에 센다). 음수는 `ValueError`, NaN은 `nan_policy`를 따른다.
- **이항 반응** (G35): `trials`(> 0, 이항 분포족만)를 주면 `y`는 성공의 비율이다. 시행 수는 R의 사전 가중치처럼 분산과 편차에 곱해지고, `llf`에는 log C(n, ny)가 들어간다(statsmodels의 (성공, 실패) 두 열 반응과 같은 값).
- **오프셋과 노출**: η = Xβ + `offset` + log(`exposure`)다. `exposure`는 > 0이고 log 링크에서만 받는다(statsmodels와 같다). `predict`·`predict_interval`에도 새 행의 `offset`·`exposure`를 준다(없으면 0).
- **척도** (G34): `scale=None`은 이항·포아송 1, 정규·감마 Pearson χ²/`df_resid`다. `'X2'`는 Pearson χ²/`df_resid`, `'dev'`는 편차/`df_resid`, 양수는 그 값으로 고정한다(이항·포아송에도 준다: 과대산포의 준우도).
- **검정 분포** (G38, G39): 척도가 고정이면(이항·포아송의 기본, 또는 수로 준 `scale`) 정규분포(z), 추정하면(정규·감마의 기본, `'X2'`, `'dev'`) t(`df_resid`)다(R의 `summary.glm`과 같다). 강건 공분산(G39)은 HC0–HC3·HAC에서 척도가 고정인 이항·포아송이면 정규분포(R의 `coeftest`·Stata와 같고, statsmodels의 `use_t=False`와 같다), 정규·감마와 척도를 추정하는 이항·포아송(`'X2'`, `'dev'`)이면 t(`df_resid`)이고(R의 `coeftest`는 glm이면 이때도 정규분포다), 군집은 분포족과 상관없이 t(G − 1)다(G27). `df_resid_inference`는 그 자유도이고 정규분포면 inf다. `summary()`의 표 머리는 `z`·`P>|z|` 또는 `t`·`P>|t|`다.
- **결과 필드**:
  - 계수와 추론: `params bse tvalues pvalues`, `conf_int(alpha=0.05)`, `cov_params()`(척도 × (XᵀWX)⁻¹, W는 기대 정보(Fisher)의 가중치), `df_resid_inference`
  - 적합: `fittedvalues`(μ), `linear_predictor`(η), `resid_response`(y − μ, `y`의 척도), `resid_pearson`((y − μ)√(m/V(μ)), m = `var_weights` × `trials`), `resid_deviance`(sign(y − μ)√(m·d(y, μ))), `resid_working`((y − μ)g′(μ))
  - 적합도: `deviance null_deviance pearson_chi2 scale llf llnull llr llr_pvalue aic bic nobs df_model df_resid`
  - 상태: `rank condition_number converged n_iter separation param_names family link cov_type`
  - 예측: `predict(X_new, /, *, offset=None, exposure=None, which='mean')`(`'linear'`이면 η), `predict_interval(X_new, /, *, offset=None, exposure=None, alpha=0.05, which='mean')`: η ± q·se(η)를 역링크로 옮긴 구간(…, m, 2; 역링크가 감소하는 inverse 링크에서도 아래·위 순서)
  - `summary(*, alpha=0.05)`: statsmodels의 GLM summary와 같은 꼴의 글(날짜·시각은 넣지 않는다)
- `llf`는 statsmodels의 `loglike`(상수항 포함, 척도는 `scale`)다. 정규·identity는 척도를 편차/`nobs`로 둔 집중 로그우도라 `ols`의 `llf`와 같다. `aic` = −2·`llf` + 2·`rank`, `bic` = −2·`llf` + log(`nobs`)·`rank`(statsmodels의 `bic_llf`; 편차로 만든 `bic_deviance`는 두지 않는다). 척도는 모수로 세지 않는다(statsmodels와 같다; R의 AIC는 정규·감마에서 1을 더 센다).
- 귀무 모형은 절편만 있는 모형이다(오프셋이 있으면 그 오프셋과 함께 다시 적합한다). `intercept=False`이면 귀무 모형은 모수가 없는 η = `offset`이다(R의 `glm`; statsmodels는 이때도 상수를 적합한다). `null_deviance`, `llnull`(같은 척도, 정규·identity는 집중 로그우도)이 그 값이고, `llr` = 2(`llf` − `llnull`), `llr_pvalue`는 자유도 `df_model`의 카이제곱이다.
- **`cov_type`** (G37): §2와 같은 이름과 옵션이다. 강건 공분산은 점수 s_i = x_i·m_i(y_i − μ_i)μ′_i/V(μ_i)의 샌드위치이고, 빵은 관측 정보(로그우도의 헤시안)의 역행렬이다(statsmodels와 같다; 정준 링크에서는 기대 정보와 같다). `'HC1'`은 `'HC0'`에 nobs/(nobs − rank)를, `'HC2'`·`'HC3'`는 √W X의 지렛대 h로 1/(1 − h)·1/(1 − h)²를 곱한다(§2의 OLS와 같은 뜻; statsmodels의 GLM은 `'HC1'`–`'HC3'`에도 `'HC0'`을 낸다). `freq_weights`는 반복한 행이 각각 점수를 내는 것으로 센다(HC·HAC, 군집은 같은 군집의 합).
- **수렴** (G32): IRLS가 편차의 상대 변화 |D − D_old|/(|D| + 0.1) < `tol`(R의 `glm.fit`과 같은 판정, 기본 1e-8)에 닿으면 `converged=True`다. 판정 전의 반복은 정규방정식(Cholesky; 조건이 나쁘거나 G21이 열을 뺄 때, 또 행 수 × 열 수가 512 미만이면 QR)으로 푼다(G40, G43). 판정 뒤에도 계수가 반올림보다 크게 움직이는 동안 QR로 반복을 이어 가고 마지막에 반복 개선을 한 최소제곱을 한 번 더 풀므로(정준이 아닌 링크는 이 둘이 관측 정보의 뉴턴 걸음이고 얇은 Q로 푼다, G42; 판정 전에도 Fisher 걸음이 직전의 1/2 아래로 줄지 않는 반복이 3번 이어지면 그때부터 뉴턴 걸음이다, G44), 계수는 그 판정의 정밀도가 아니라 최대우도 추정에 반올림 수준으로 가깝다(설계 §3.4). `n_iter`는 최소제곱을 푼 횟수다(마지막 풀이와, 분리되면 나머지 행의 다시 적합 포함; R은 마지막 풀이를 세지 않는다). `max_iter`(≥ 1)는 그 수의 상한이고, 닿으면 마지막 값을 내고 `converged=False`, `n_iter`는 `max_iter`다. `max_iter`에 닿은 것만으로는 분리가 아니다(분리는 아래 증명서로만 판정한다). 경고는 없다.
- **분리** (G33, 이항과 로그 링크의 포아송): 최대우도 추정이 존재하지 않으면(완전·준완전 분리, 0만 있는 포아송 군 등) `separation=True`이고 `params`·`bse`·`tvalues`·`pvalues`·`cov_params()`는 NaN이다. 경계로 가는 행의 `fittedvalues`는 y(0 또는 1, 포아송은 0), `linear_predictor`는 ±inf, 잔차는 0이다. 나머지 행은 그 행들만의 적합(가능도 최대화의 극한)이고 `deviance`·`llf`·`pearson_chi2`도 그 극한의 값이다. 판정은 설계 §3.4의 증명서다. 이항·포아송 밖이나 다른 링크(경계에서 유한한 최대우도 추정, 예: 포아송 identity에서 μ = 0)는 분리가 아니다.
- 겹친 열(G9, G21)·`rtol`·배치·`nan_policy`는 §2와 같다. 겹친 열의 계수와 추론은 NaN이고 `rank`, `df_model`, `df_resid`, `aic`, `bic`는 남은 열로 센다.
- **정확도** (잰 값, 설계 §3.4): 계수 벡터의 상대오차(노름)는 Arb 참값과 견줘 분포족·링크 12개와 가중치·시행 수·노출·절편 없음·`scale='dev'`의 무작위 문제 17개에서 최대 1.1e-16이다. √W X의 조건수 κ가 클 때는 정준 링크(로지스틱·포아송 log) κ ≤ 10¹⁰에서 1.3e-15, 10¹²에서 9e-12, 정준이 아닌 링크 8개(probit, cloglog, 이항 log, 포아송 identity·sqrt, 감마 log·identity, 정규 log) κ ≤ 10⁸에서 3.5e-15, 10¹⁰에서 4e-14다. 같은 17개에서 표준오차·편차·Pearson χ²·로그우도·강건 표준오차는 1e-15 안, p값은 2e-13 안이다. 표준오차는 G1처럼 R에서 계산하므로 상대오차가 κ·u 정도다.

## §4. 정규화 (G3)
```
ridge(y, X, /, *, alpha, weights=None, intercept=True, standardize=False, nan_policy='propagate')
lasso(y, X, /, *, alpha, weights=None, intercept=True, standardize=False, max_iter=1000, tol=0.0001, nan_policy='propagate')
elastic_net(y, X, /, *, alpha, l1_ratio=0.5, weights=None, intercept=True, standardize=False, max_iter=1000, tol=0.0001, nan_policy='propagate')
ridge_cv(y, X, /, *, rng=None, cv=5, alphas=100, eps=1e-06, select='min', weights=None, intercept=True, standardize=False, nan_policy='propagate')
lasso_cv(y, X, /, *, rng, cv=5, alphas=100, eps=0.001, select='min', weights=None, intercept=True, standardize=False, max_iter=1000, tol=0.0001, nan_policy='propagate')
elastic_net_cv(y, X, /, *, rng, l1_ratio=0.5, cv=5, alphas=100, eps=0.001, select='min', weights=None, intercept=True, standardize=False, max_iter=1000, tol=0.0001, nan_policy='propagate')
penalized_glm(y, X, /, *, family, alpha, l1_ratio=0.5, weights=None, intercept=True, standardize=False, max_iter=100, tol=1e-08, nan_policy='propagate')
```
- §1의 공통 규칙(입력, 절편, NaN, inf, 배치, 스레드, 에러의 꼴)을 따른다. 정규화 GLM의 이름은 `penalized_glm`, 결과는 `PenalizedGLMResult`다(G49).
- **목적함수** (G45, scikit-learn과 같다): (1/(2·sw))·Σ wᵢ(yᵢ − b₀ − xᵢβ)² + alpha·(l1_ratio·‖Sβ‖₁ + (1 − l1_ratio)/2·‖Sβ‖²). sw = Σw이고, 가중치가 없으면 wᵢ = 1(sw = n)이다. `ridge`는 l1_ratio = 0, `lasso`는 1이다. 절편 b₀은 벌점 밖이다(가중 평균으로 중심화한다). S는 `standardize=False`이면 I, `True`이면 열의 표준편차의 대각이다(아래).
  - 가중치는 scikit-learn의 `sample_weight`와 같은 뜻이다(scikit-learn은 가중치를 합이 n이 되게 다시 맞추므로 같은 목적함수다). 0인 행은 적합과 `nobs`에서 빠지고 적합값·잔차만 계산한다(G20). 음수는 `ValueError`, NaN은 `nan_policy`를 따른다.
  - scikit-learn과의 대응: `Lasso`·`ElasticNet`·`enet_path`의 `alpha`는 같다. `Ridge`는 Σw r² + alpha‖β‖²을 풀므로 그 `alpha`는 여기의 sw배다. `LogisticRegression`의 `C`는 1/(sw·alpha), `PoissonRegressor`의 `alpha`는 l1_ratio = 0에서 같다.
- **`standardize=True`** (glmnet처럼 X를 표준화한다): 표준화한 계수 sⱼβⱼ에 벌점을 주고 원래 척도의 계수를 돌려준다. sⱼ는 모표준편차 √(Σw(xⱼ − x̄ⱼ)²/sw)이고, 절편이 없으면 RMS √(Σw xⱼ²/sw)다. 그래서 X의 열에 상수를 곱해도 예측은 바뀌지 않는다 (사용자 결정 2026-11-18).
  - glmnet(5.2)과의 관계: 절편이 있으면 sⱼ가 같다. glmnet은 절편이 없어도 중심화한 모표준편차로 나눈다(여기서는 중심화하지 않는 적합이라 RMS를 쓰고, 절편 없는 모형의 0이 아닌 상수 열도 쓸 수 있다).
  - 목적함수는 G45(scikit-learn과 같다)다. glmnet은 정규 분포에서 y도 내부에서 표준화하므로, 엘라스틱 넷·ridge는 y의 모표준편차 s_y가 1일 때만 같은 `alpha`로 glmnet과 같은 해다. 일반적으로 glmnet의 (λ, α)는 여기의 `alpha = λ`, `l1_ratio = α`에서 L2 항이 λ(1 − α)/s_y가 되는 꼴이다(라소는 s_y와 무관하게 같다). 이항·포아송의 `penalized_glm`은 glmnet과 같다.
- 상수 열(절편이 없으면 0인 열)은 적합에서 빠지고 그 계수는 0이다.
- **`alpha`**: 0 이상의 유한한 수, 또는 그런 수의 1차원 배열(경로, G46). 배열이면 큰 값부터 앞의 해에서 시작해(따뜻한 시작) 모두 풀고, 결과는 준 순서다. 그때 회귀 하나의 필드마다 배치 축 뒤, 자기 축 앞에 길이 L의 축이 붙는다: `params` (..., L, k), 스칼라 필드 (..., L), `fittedvalues`·`resid` (..., L, n), `predict` (..., L, m). 결과의 `alpha`는 준 값(수 또는 배열)이다. `ridge`·`lasso`·`elastic_net`의 경로의 각 해는 같은 alpha로 따로 푼 것과 비트까지 같다(lasso·엘라스틱 넷은 연마한 해의 활성 집합과 부호가 같으면; 아래 연마). 정규화 GLM은 시작점에 따라 반올림 수준에서 다를 수 있다.
- **`ridge`의 풀이** (G52): 정규방정식 XᵀX를 만들지 않고 중심화한 설계의 QR과 R의 SVD 하나로 모든 alpha를 푼다(설계 §3.5). 해의 조건수가 크면 double-double 잔차로 개선한다(G51).
- **결과** (G48, 예측 중심): `RidgeResult`, `LassoResult`, `ElasticNetResult`, `PenalizedGLMResult`와 교차검증의 `RidgeCVResult`, `LassoCVResult`, `ElasticNetCVResult`(각각 앞의 것에 교차검증 필드를 더한 것).
  - 공통: `params`(절편 `params[0]`), `param_names`(§2와 같다), `alpha`, `l1_ratio`, `standardize`, `nobs`(가중치가 0보다 큰 행 수, `float`), `df_model`, `predict(X_new, /)`
  - 선형(`ridge`·`lasso`·`elastic_net`): `fittedvalues`, `resid`(y − 적합값, double-double로 한 번 반올림), `ssr`(Σw r², 적합에 쓰인 행), `rsquared`(1 − `ssr`/TSS, TSS는 가중 평균에 대한 Σw(y − ȳ)²이고 절편이 없으면 Σw y²: `ols`와 같은 규칙. 절편이 있으면 scikit-learn의 `score(X, y, sample_weight=w)`와 같다)
  - 좌표 하강(`lasso`·`elastic_net`·정규화 GLM): `converged`, `n_iter`, `dual_gap`. `ridge`는 닫힌 꼴이라 이 셋이 없다.
  - 정규화 GLM: `family`, `separation`, `fittedvalues`(μ), `linear_predictor`(η), `resid_response`(y − μ), `deviance`, `null_deviance`(절편만의 모형, 곧 μ = ȳ에서 직접 잰 편차: y가 모두 같으면 정확히 0이라 `deviance_ratio`는 NaN(G85); 절편이 없으면 η = 0), `deviance_ratio`(1 − `deviance`/`null_deviance`, glmnet의 `dev.ratio`), `predict(X_new, /, *, which='mean')`(`'linear'`이면 η)
  - 표준오차·p값·구간 필드와 `summary()`는 없다(G48, G52).
- **`df_model`** (유효 자유도, 절편은 세지 않는다): 0 아닌 계수의 집합 A에 대해 tr Z_A(Z_AᵀΩZ_A + alpha(1 − l1_ratio)I)⁻¹Z_AᵀΩ다(Z는 중심화한 열, `standardize`면 표준화한 열, Ω = diag(w/sw); 정규화 GLM은 Ω에 작업 가중치를 곱한다). lasso(l1_ratio = 1)는 0 아닌 계수의 수, ridge(A가 모든 열)는 Σ s²/(s² + alpha)(s는 Ω^½Z의 특이값)다. 엘라스틱 넷의 이 식은 Zou–Hastie(2005)의 것이다(glmnet의 `df`는 0 아닌 계수의 수).
- **`lasso`·`elastic_net`의 수렴** (scikit-learn과 같은 판정): 열 순서의 좌표 하강이고, 쌍대 간격이 `tol` × Σω(y − ȳ)²(절편이 없으면 Σω y²) 이하이면 수렴이다. scikit-learn의 tol·‖y‖²(중심화·가중한 y, 그 목적함수의 n배 척도)와 같은 뜻이다. 간격은 가장 큰 계수 변화가 `tol` × 가장 큰 계수 이하인 전체 스윕 뒤에 잰다(scikit-learn과 같다). `n_iter`는 스윕 수(전체 스윕과 0 아닌 계수만의 스윕을 모두 센다; 연마가 실패해 더 좁은 판정으로 다시 도는 스윕도 센다. 그래서 `tol`이 아주 크면 첫 스윕에서 판정을 통과한 뒤 다시 돌아 `n_iter`가 오히려 클 수 있다), `max_iter`는 그 상한이다(alpha마다). 상한에 닿으면 마지막 값을 내고 `converged=False`다(G32). 경고는 없다. 간격 판정을 통과한 뒤 KKT 연마가 실패해 더 좁은 판정으로 다시 돈 스윕이 상한에 닿아도 같다: 연마하지 않은 마지막 반복의 계수와 그 `dual_gap`을 내고 `converged=False`다(처음의 간격 판정을 통과했어도). 경로에서는 alpha마다, CV에서는 겹의 적합이 수렴하지 않았어도 그 계수로 `cv_error`를 계산하고(scikit-learn과 같다), 결과의 `converged`는 다시 맞춘 적합의 것이다.
  - 수렴한 해는 KKT 연마를 거친다: 그 해의 0 아닌 계수와 부호로 정상 조건의 연립방정식을 풀고, 부호가 그대로이고 0인 계수마다 |zⱼᵀΩr| ≤ alpha·l1_ratio이면 그 해를 낸다(아니면 좌표 하강을 더 작은 허용오차로 이어 간 뒤 다시 연마하고, 끝내 통과하지 못하면 좌표 하강의 해를 낸다). 그래서 계수는 `tol`의 정밀도가 아니라 정확한 해에 반올림 수준으로 가깝고(아래 정확도), 해가 0인 계수는 정확히 0이다.
  - `dual_gap`은 목적함수 단위의 쌍대 간격이다(scikit-learn 1.9.1의 `dual_gap_`과 같은 단위: 그쪽도 n_samples로 나눈다). 연마한 해에서는 반올림 수준이고 그 크기의 음수일 수도 있다.
- **정규화 GLM** (G47): `family`는 `'binomial'`(logit 링크, `y`는 0 또는 1)과 `'poisson'`(log 링크, `y` ≥ 0)이다. 정준 링크만이다. 목적함수는 편차/(2·sw) + 같은 벌점이다(glmnet과 같다; 가중 편차는 Σwᵢdᵢ). 바깥은 IRLS(현재 계수에서 이차 근사)이고 안쪽은 같은 좌표 하강이다. 목적함수 F의 상대 변화 |F − F_old|/(|F| + 0.1)가 `tol`(기본 1e-8, `glm`과 같은 꼴) 아래면 수렴이다. 목적함수가 오르면 걸음을 반씩 줄인다. 수렴한 해는 0 아닌 계수와 부호를 고정한 뉴턴법으로 연마한다(선형과 같은 KKT 검사). `n_iter`는 IRLS 반복 수이고 `max_iter`(기본 100)가 그 상한이다. `dual_gap`은 돌려준 계수에서의 마지막 이차 근사 문제의 쌍대 간격(목적함수 단위)이다. y가 모두 0(이항은 모두 0 또는 모두 1)이면 유한한 해가 없어 계수가 NaN이고 `converged=False`다. 링크 인자와 `offset`·`trials`는 없다(G52).
  - **alpha = 0** (G50): 벌점이 없으면 `glm`의 적합 그대로다(`var_weights=weights`; 같은 `max_iter`·`tol`). 분리는 `glm`의 증명서로 판정하고(G33), 그때 `params`는 NaN, `separation=True`, `linear_predictor`·`fittedvalues`·`deviance`는 `glm`의 극한값(경계 행의 η = ±inf, μ = 0 또는 1)이며 `dual_gap`은 NaN이다. 분리가 없으면 `params`·`deviance`·`n_iter`·`converged`·`df_model`이 `glm`의 것이다(겹친 열도 G9대로 NaN). 경로에서는 alpha가 0인 자리만 그렇다. alpha > 0이면 목적함수가 계수와 함께 커져 분리돼도 해가 유한하므로 판정하지 않고 `separation`은 False다.
- **교차검증** (G46): k겹으로 alpha를 고르고 모든 데이터로 다시 적합한다.
  - `cv`는 겹 수(2 이상, 행 수 이하; 기본 5, scikit-learn의 기본과 같다; glmnet은 10)다. 겹은 `rng`(`sd.random.default_rng(seed)`의 Generator, `sample`처럼 꼭 준다: `lasso_cv`·`elastic_net_cv`는 키워드 인자에 기본값이 없고, `ridge_cv`는 `cv='gcv'`일 때만 없어도 된다)의 `rng.permutation(n)`로 나눈다: 행 i의 겹은 (0, 1, …, n − 1 mod cv)를 그 순열로 섞은 값이다(glmnet의 `sample(rep(1:K, length = n))`과 같은 꼴, 겹 크기의 차이는 1 이하). 행은 `nan_policy='omit'`이 뺀 뒤의 행이다. 가중치 0인 행도 겹을 받지만 적합과 오차에는 들지 않는다. 배치면 모든 회귀가 같은 겹을 쓴다(배치는 같은 시드의 새 Generator로 하나씩 부른 것과 비트까지 같다).
  - `alphas`: int이면 그 길이의 격자 alpha_max·`eps`^(i/(L − 1))(i = 0 … L − 1; scikit-learn의 `LassoCV`와 같은 격자, alpha_max는 해가 0이 되는 가장 작은 alpha, 1e-15 아래면 1e-15), 배열이면 그 값을 큰 것부터 정렬한 것이다. `ridge_cv`의 격자는 l1_ratio = 1e-3으로 계산한 alpha_max에서 시작한다(glmnet의 ridge 규칙; scikit-learn은 l1_ratio = 0의 자동 격자가 없다). `ridge_cv`의 `eps` 기본은 1e-6이다(G87; `lasso_cv`·`elastic_net_cv`는 1e-3): 1e-3이면 격자의 끝이 lasso의 alpha_max라 신호가 뚜렷한 자료에서 최적 alpha가 격자 끝에 걸리고, ridge는 SVD 한 번으로 모든 alpha를 풀어 격자를 넓혀도 비용이 같다(glmnet의 최소 비율은 1e-4). `elastic_net_cv`의 l1_ratio = 0은 `alphas`를 배열로 줘야 한다.
  - 겹마다 나머지로 경로 전체를 적합하고(배치로 함께 푼다), 그 겹의 가중 평균 제곱오차 Σw(y − ŷ)²/Σw를 잰다. `cv_error`는 겹들의 평균(scikit-learn의 `mse_path_.mean(axis=1)`과 같다), `cv_se`는 겹들의 표준편차(자유도 cv − 1)/√cv다.
  - `alpha_min`은 `cv_error`가 가장 작은 alpha(같으면 큰 쪽), `alpha_1se`는 `cv_error` ≤ 최솟값 + 그 점의 `cv_se`인 가장 큰 alpha다(1-SE 규칙). `select='min'`(기본, scikit-learn과 같다)이면 `alpha_min`, `'1se'`면 `alpha_1se`로 다시 적합한다(glmnet의 `predict`는 `lambda.1se`가 기본). 결과의 `alpha`가 고른 값이고, 나머지 필드는 그 alpha의 적합(`ridge`·`lasso`·`elastic_net`을 그 alpha로 부른 것과 비트까지 같다)이다.
  - 교차검증 필드: `alphas` (..., L), `cv_error` (..., L), `cv_se` (..., L), `alpha_min`, `alpha_1se`
  - `elastic_net_cv`는 l1_ratio 하나를 받는다(scikit-learn의 `ElasticNetCV`처럼 여러 값을 함께 고르지 않는다, G52).
  - `ridge_cv(cv='gcv')`: 일반화 교차검증(Golub–Heath–Wahba) GCV = (`ssr`/sw)/(1 − tr H/`nobs`)², tr H = `df_model` + 절편 수. 모든 데이터의 한 SVD로 닫힌 꼴이다. `cv_se`와 `alpha_1se`는 NaN이고 `select='1se'`는 `ValueError`다.
- **정확도** (잰 값, 설계 §3.5): Arb 참값(정해진 활성 집합의 KKT 연립방정식을 정확히 풀고 0인 계수의 KKT 부등식으로 증명한 해)과 견준 계수 벡터의 상대오차(노름)는 조건이 좋은 문제(n = 60 – 20,000)에서 lasso·엘라스틱 넷·ridge 1.7e-15 안, 정규화 GLM 3e-16 안이다. 중심화한 설계의 조건수가 10²–10⁶이면 lasso·엘라스틱 넷 8.6e-15 안이다(연마가 개선한 칸은 3e-16 안). 조건이 나쁘면 ridge와 lasso·엘라스틱 넷의 연마는 double-double 잔차로 개선하고(G51), ridge는 조건수 10¹⁰, alpha 1e-18(최소제곱 가까이)까지 1.7e-15 안이다. scikit-learn은 기본 `tol=1e-4`에서 4e-6–2e-4(조건수 10²–10⁶에서 2e-4–0.34), `tol=1e-12`에서 5e-14–1e-12다.
- **에러**: `lasso(): 'alpha' must be finite and >= 0`, `elastic_net(): 'l1_ratio' must be between 0 and 1 (inclusive)`, `lasso_cv(): 'rng' must be an sd.random.Generator (sd.random.default_rng(seed)), not int`, `lasso_cv(): 'cv' must be <= the number of rows (30), not 31`, `ridge_cv(): 'cv' must be an int or 'gcv', not 'x'`, `penalized_glm(): 'family' must be 'binomial' or 'poisson', not 'gamma'`, `penalized_glm(): 'y' must be 0 or 1 for the binomial family`.

## §5. 강건 (G4)
```
rlm(y, X, /, *, method='M', norm=None, c=None, scale_est=None, intercept=True, max_iter=50, tol=1e-08, rng=None, rtol=None, nan_policy='propagate')
theilslopes(y, x=None, /, *, alpha=0.95, method='separate', nan_policy='propagate')   # -> TheilslopesResult(slope, intercept, low_slope, high_slope)
siegelslopes(y, x=None, /, *, method='hierarchical', nan_policy='propagate')          # -> SiegelslopesResult(slope, intercept)
```
- `rlm`의 결과는 `RLMResult`이고 필드 이름은 statsmodels의 것이다(G10). §1의 공통 규칙(입력, 절편, NaN, inf, 배치, 스레드, 에러의 꼴)을 따른다. 가중치 인자(`weights`)는 없다(statsmodels RLM과 같다; G59).
- **방식** (G53): `method='M'`(기본)은 최소제곱에서 시작하는 IRLS로 statsmodels `RLM(...).fit()`과 같은 추정이다. `method='MM'`은 S 추정에서 시작해 bisquare M 추정으로 가는 R robustbase `lmrob`의 방식이다.
- **ψ 함수** (G54): `norm`은 `'huber'`, `'bisquare'`, `'hampel'`이고 None이면 M은 `'huber'`, MM은 `'bisquare'`다(MM은 bisquare만 받는다). `c`는 조율 상수로, None이면 statsmodels의 기본값이다: Huber t = 1.345, bisquare c = 4.685(둘 다 정규 효율 95%), Hampel (a, b, c) = (2, 4, 8)(정규 효율 0.990; statsmodels의 `HuberT()`, `TukeyBiweight()`, `Hampel()`). Huber·bisquare는 수 하나(> 0), Hampel은 수 세 개(0 < a ≤ b < c)다. MM의 `c`는 M 단계의 bisquare 상수이고 기본은 4.685061(`lmrob.control()`의 `tuning.psi`)이다.

  | `norm` | ψ(z) | 가중치 w(z) = ψ(z)/z | ρ(z) |
  |---|---|---|---|
  | `'huber'` | z (\|z\| ≤ t), t·sign z | 1, t/\|z\| | z²/2, t\|z\| − t²/2 |
  | `'bisquare'` | z(1 − (z/c)²)² (\|z\| ≤ c), 0 | (1 − (z/c)²)², 0 | c²/6·(1 − (1 − (z/c)²)³), c²/6 |
  | `'hampel'` | z, a·sign z, a(c − \|z\|)/(c − b)·sign z, 0 (\|z\| ≤ a, ≤ b, ≤ c, 그 밖) | 1, a/\|z\|, a(c − \|z\|)/(\|z\|(c − b)), 0 | z²/2, a\|z\| − a²/2, a(b + c − a)/2 − a(c − \|z\|)²/(2(c − b)), a(b + c − a)/2 |

- **척도** (G55): z = r/s의 s다. M의 `scale_est`는 `'mad'`(None과 같다)와 `'huber'`이고, 반복마다 새 잔차로 다시 구한다(statsmodels의 `update_scale=True`).
  - `'mad'`: 0을 중심으로 한 MAD, median(\|r_i\|/0.6744897501960817)이다. 나누는 수는 Φ⁻¹(3/4)의 double(statsmodels의 `mad(center=0)`; 짝수 개면 가운데 둘의 평균)이고, 곱으로 쓰면 1.482602218505602다. R `MASS::rlm`의 MAD는 0.6745로 나눠서 척도가 1.5×10⁻⁵, 계수가 10⁻⁶ 정도 다르다.
  - `'huber'`: Huber의 제안 2. Σ χ(r_i/s) = (nobs − rank)·E χ(Z), χ(z) = min(z², d²)/2, d = 2.5(고정, 옵션이 아니다), Z는 표준정규다(statsmodels `HuberScale()`의 방정식; R `MASS::rlm(scale.est='proposal 2', k2=2.5)`와 같은 해). 반복마다 이 방정식을 정확히 푼다(statsmodels는 MAD에서 시작한 고정점 반복 30번까지).
  - MM에는 `scale_est`가 없다(주면 `ValueError`): 척도는 S 추정의 척도이고 M 단계 동안 고정이다.
- **M의 반복과 수렴** (G32): 반복마다 직전 잔차의 가중치로 y를 가중 최소제곱한다(정규방정식, 안 되면 QR; G1의 최소제곱 핵심). 목적함수 D = Σ ρ(r_i/s)의 상대 변화 \|D − D_old\|/(\|D\| + 0.1)가 `tol`(기본 1e-8) 아래면 `converged=True`다(GLM과 같은 꼴; statsmodels는 절대 변화 ≤ 1e-8). 그 뒤에도 계수가 반올림보다 크게 움직이는 동안 추정방정식 Σ ψ(r_i/s) x_i = 0의 뉴턴 걸음(척도가 계수에 따라 바뀌는 것까지 넣은 야코비안)을 이어 가고(IRLS의 걸음이 직전의 1/2 아래로 줄지 않는 반복이 3번 이어지면 그때부터), 마지막 최소제곱은 반복 개선한 QR이다. 그래서 계수는 `tol`의 정밀도가 아니라 해에 반올림 수준으로 가깝다. `n_iter`는 반복(최소제곱 또는 뉴턴 걸음) 수이고 `max_iter`(≥ 1, 기본 50: statsmodels의 `maxiter`)에 닿으면 마지막 값을 내고 `converged=False`, `n_iter`는 `max_iter`다. 경고는 없다.
- **MM** (G53, `lmrob.control()`의 기본값):
  - S 추정: 기본 부분표본 500개. 후보 j는 행을 무작위 순서로 뽑아, 앞서 고른 행들과 선형 독립인 행만 p개(쓰인 열 수)까지 모은 기본 부분집합(앞 행들에 직교하는 성분이 그 행의 노름의 10⁻⁷보다 클 때만 받는다, `solve.tol`)의 정확한 해에서, 척도 1.4826·median\|r\|로 한 걸음 개선한다(`k.fast.s` = 1). 척도 방정식은 (1/(n − p)) Σ ρ̃(r_i/s) = 1/2, ρ̃는 상수 1.54764의 bisquare를 1로 정규화한 것이다(`tuning.chi`, `bb`; 붕괴점 50%). 후보를 순서대로 보며 가장 작은 척도 2개를 남기고(`best.r.s`; 지금 남긴 것보다 척도가 작을 때만 척도를 구한다), 둘을 상대 변화 10⁻⁷까지 다듬어(`k.max` 200, `refine.tol`) 척도가 작은 쪽을 고른 뒤, 그 고정점까지 더 반복한다(robustbase는 10⁻⁷에서 멈춘다). 부분표본 수 500은 옵션이 아니다.
  - **큰 n** (G58, n > 2000; `fast.s.large.n`): robustbase처럼 행 2,000개(`groups` 5 × `n.group` 400)를 비복원으로 뽑아 400개씩 5묶음으로 나누고, 묶음마다 위의 탐색(후보 500개, 가장 좋은 2개)을 한다. 그 10개를 뽑은 2,000행 전체에서 묶음의 척도로 한 걸음 개선해(`k.fast.s`) 그 2,000행의 척도로 가장 좋은 2개를 고르고, 그 둘을 모든 행에서 위처럼 다듬는다. 뽑은 행 수보다 열이 많으면(p ≥ 400) 작은 n의 방식이다. `k.m_s`는 M-S 추정의 것이라 쓰지 않는다(R의 추적 출력에서도 병합 단계는 한 걸음이다).
  - M 단계: bisquare(`c`)로 S 계수에서 시작하고 S 척도를 고정한 M과 같은 IRLS다.
  - 난수: `rng`(`sd.random.default_rng(seed)`의 Generator)를 꼭 준다(없으면 `TypeError`, M에 주면 `ValueError`). 회귀마다 64비트 두 단어를 `rng.integers(-2**63, 2**63 - 1, endpoint=True, shape=batch_shape + (2,))`로 배치의 C 순서대로 뽑고, 후보 j의 행은 그 두 단어를 키로 한 Philox4×64-10의 원소 j·2³² + t(t = 0, 1, …)로 뽑는다. 큰 n의 행 2,000개는 같은 키의 원소 2⁶³ + t(t = 0 … 1,999)로 하는 부분 Fisher–Yates 섞기로 뽑고, 묶음 g의 후보 j는 원소 (g·500 + j)·2³² + t를 쓴다. 그래서 같은 상태의 `rng`면 같은 비트이고, 스레드 수와 상관없으며, 배치는 같은 `rng`로 하나씩 부른 것과 비트까지 같다. 부분표본의 수가 R과 다르므로 robustbase와 S 계수가 같지는 않다(아래 정확도).
- **추론** (G57): 공분산은 M이 Huber의 H1(statsmodels의 기본 `cov='H1'`): K²·(Σψ(z_i)²/df_resid)·s²/m²·(XᵀX)⁻¹, m = mean ψ′(z), K = 1 + rank/nobs·var ψ′(z)/m²(var는 n으로 나눈다; R `MASS`의 `summary.rlm`은 n − 1로 나눠 그만큼 다르다). (XᵀX)⁻¹은 시작 최소제곱의 R에서 구한다. MM은 robustbase의 `.vcov.avar1`(Croux–Dhaene–Hoorelbeke 2003의 점근 공분산, `lmrob.control()`의 MM 기본)이고, 음의 고윳값은 그 `posdefify`처럼 0으로 두고 대각을 되돌린다. p값과 구간은 t(`df_resid`)다(R의 요약과 같다; statsmodels는 정규분포). `cov_type`은 `'H1'` 또는 `'avar1'`이다.
- **결과 필드**: `params bse tvalues pvalues`, `conf_int(alpha=0.05)`, `cov_params()`, `fittedvalues resid`, `scale`(M은 마지막 잔차의 척도, MM은 S 척도), `weights`(마지막 잔차의 w(r_i/s), statsmodels의 `weights`, lmrob의 `rweights`), `nobs df_model df_resid`(nobs는 행 수, df_resid = nobs − rank), `rank condition_number converged n_iter param_names method norm cov_type`, `predict(X_new, /)`, `summary(*, alpha=0.05)`(statsmodels RLM summary의 꼴: 모형, 방법, ψ, 척도, 공분산, 반복 수와 관측 수, 자유도, 척도; 계수 표는 `t`·`P>|t|`).
- 겹친 열(G9, G21)은 시작 최소제곱의 QR이 정하고(그 뒤 가중치가 어떤 열의 행을 모두 0으로 만들면 그 열도 빠진다), 그 계수와 추론은 NaN이다. 나머지는 그 열을 뺀 적합과 비트까지 같다.
- **완전 적합**: 척도를 정하는 행들의 잔차가 0이면(`'mad'`는 절반 넘게, `'huber'`는 0이 아닌 잔차가 2T/d² 개 이하로 제안 2의 방정식에 근이 없을 때, T = (nobs − rank)·E χ(Z); MM의 S는 (n + p)/2 개 이상) 척도는 0이고, 반복을 멈추고 `converged=True`, 공분산은 0(`bse` 0, p 0)이며, 가중치는 잔차가 0인 행 1, 그 밖 0이다. 여기서 잔차가 0이라는 것은 반올림 수준 안, \|r_i\| ≤ (k + 16)u(\|y_i\| + ‖x_i‖₁‖β‖∞)라는 뜻이다(분위 회귀와 같은 기준, §6). IRLS는 직선 위 행들의 잔차를 정확히 0으로 만들지 못하고 척도와 함께 반올림 수준까지 다가가기만 하는데, 거기서는 r_i/s가 반올림 잡음이라 ψ·가중치·뉴턴 걸음이 뜻을 잃기 때문이다. 그때 계수는 그 행들(가중치 1)의 최소제곱(반복 개선한 QR)이다. MM은 S 척도가 0이면 M 단계 없이 S 계수를 내고 `n_iter`는 0이다. Huber처럼 다시 내려가지 않는 ψ는 척도가 천천히 줄면 반올림 수준에 닿기 전에 `max_iter`에 닿을 수 있다(`converged=False`, 계수는 직선에 다가가는 중의 값). statsmodels는 이런 문제에서 반올림 수준의 척도(10⁻¹⁵ 정도)와 표준오차를 낸다.
- **정확도** (잰 값, 설계 §3.6): Arb 참값(추정방정식을 해의 ψ 조각과 중앙값 행에서 풀고 그 조각이 확실한 상자에서 Krawczyk로 증명한 해)과 견준 계수 벡터의 상대오차는 ψ 세 개 × 척도 두 개, 절편 없음, n = 400, 스택 손실, MM의 M 단계 19개 문제에서 1.1×10⁻¹⁶ 안이고, 척도 1.4×10⁻¹⁵, 표준오차 1.2×10⁻¹⁵, 가중치 1.1×10⁻¹⁵ 안이다. statsmodels(tol 1e-15)와는 계수·척도·표준오차가 2.3×10⁻¹⁵ 안이다. R의 `MASS::rlm`(proposal 2, k2 = 2.5)과는 계수 4.1×10⁻¹⁵, 척도 1.7×10⁻¹⁴ 안이고, robustbase의 M 단계(`lmrob..M..fit`, `rel.tol` 1e-15)와 `.vcov.avar1`을 같은 S 시작에서 부르면 계수 1.1×10⁻¹⁵, 표준오차 7.2×10⁻¹⁵ 안이다(스택 손실만 1.5×10⁻¹³: robustbase가 XᵀΨ′X를 직접 역행렬로 만들어 κ²u이고, sd는 Arb와 6.7×10⁻¹⁶). `lmrob` 자체와는 자기 부분표본과 10⁻⁷의 S 정밀도 때문에 계수가 10⁻⁹–10⁻⁷ 다르다(큰 n의 n = 5,000, 10⁴, 10⁵, 10⁶에서도 10⁻⁸ 수준).
- **에러**: `rlm(): 'rng' must be an sd.random.Generator (sd.random.default_rng(seed)), not NoneType`, `rlm(): 'rng' is only used with method='MM'`, `rlm(): method='MM' takes the bisquare norm, not 'huber'`, `rlm(): 'scale_est' is only used with method='M' (MM's scale is the S estimate's)`, `rlm(): 'c' must be three numbers 0 < a <= b < c for the hampel norm`, `rlm(): the model has no parameters (no columns in 'X' and intercept=False)`.

- **`theilslopes`·`siegelslopes`** (G56): scipy 1.18.1과 인자 이름·순서·기본값과 결과(namedtuple, 필드 순서도 같다)가 같다. 다른 점: `y`, `x` 뒤의 옵션(`alpha`, `method`, `nan_policy`)은 키워드로만 받고(scipy는 `alpha`·`method`를 위치로도 받는다), `axis`·`keepdims`가 없으며(scipy의 `axis=None`은 펴서 하나로 푼다), 앞 축은 §1처럼 배치다(마지막 축을 따라 푼다). `x`가 None이면 0, 1, …, n − 1이다. 결과는 Python `float`이고 `y`·`x`가 (…, n)이면 배치 모양의 배열이다(브로드캐스트한다).
  - 기울기는 x_i ≠ x_j인 쌍의 (y_i − y_j)/(x_i − x_j)를 scipy처럼 double로 만든 값들의 중앙값이다(짝수 개면 0.5a + 0.5b, scipy `quantile`의 기본). 중앙값과 순위 통계량을 정확히 고르므로 값이 scipy와 비트까지 같다. 다른 것은 0의 부호뿐이다: 기울기가 0이면 +0을 낸다(scipy의 −0·+0은 정렬 순서에 따른다).
  - `theilslopes`: 절편은 `method='separate'`(기본) median(y) − 기울기·median(x), `'joint'`는 median(y − 기울기·x)다. `low_slope`·`high_slope`는 Sen(1968)의 신뢰구간으로, `alpha`가 신뢰수준이다(scipy처럼 0.5보다 크면 1 − alpha로 접어서 0.1과 0.9가 같은 90% 구간이다; 0 < alpha < 1). 분산 σ² = (n(n − 1)(2n + 5) − Σ동률 x − Σ동률 y)/18, 순위는 round((N ∓ zσ)/2)(짝수로 반올림, N은 유한한 기울기 수)로 scipy의 식 그대로다.
  - `siegelslopes`: 점마다 다른 점들로의 기울기의 중앙값, 그 중앙값들의 중앙값이다. 절편은 `method='hierarchical'`(기본) median(y − 기울기·x), `'separate'`는 점마다 다른 점들로의 절편 y_i − 기울기_ij·x_i의 중앙값들의 중앙값이다.
  - 계산: Siegel은 점마다 선택(O(n²) 시간, 작업마다 O(n) 메모리). Theil–Sen은 기울기가 2²³개까지 한 배열에 모아 선택하고, 그보다 많으면 쌍을 저장하지 않고 훑는다: 쌍의 표본에서 구한 피벗 사이의 기울기 수를 정확히 세고, 사이에 든 값만(많으면 해시로 고른 부분표본만) 모아 다음 훑기의 피벗을 좁힌다. 보통 2–3번 훑고(O(n²) 시간, 메모리 O(n + 2²²)), 세는 수가 정확하므로 결과는 표본과 상관없다. scipy는 n × n 배열을 만든다(n = 10⁴에 GB 단위, 10⁵은 만들지 못한다).
  - NaN: `nan_policy`(scipy 1.18의 `nan_policy`와 같은 세 값, 기본 'propagate'): 'propagate'는 모든 값이 NaN, 'omit'은 y나 x가 NaN인 점을 뺀다(배치에서는 `ValueError`), 'raise'는 `ValueError`다. `x`가 None이면 'omit'은 원래 위치를 x로 둔 채 점을 뺀다(G83, [scipy와 다름]: scipy는 뺀 뒤 0, 1, …로 다시 번호를 매긴다; y = [1, 2, NaN, 4, 5]의 기울기가 여기는 1, scipy는 1.4167이다). 빠진 점이 있어도 남은 점의 x는 그 점이 놓인 자리라서다. inf는 `ValueError`다(G24; scipy는 받는다). 점이 2개보다 적으면 `ValueError`다([scipy와 다름]: scipy 1.18.1은 `SmallSampleWarning`과 함께 NaN을 낸다; 이 라이브러리는 경고를 내지 않는다). x가 모두 같으면 모든 값이 NaN이다(scipy와 같다).

## §6. 분위 (G5)
```
quantreg(y, X, /, *, q=0.5, intercept=True, cov_type='nid', bandwidth='hall-sheather', max_iter=100, tol=1e-05, rtol=None, nan_policy='propagate')
```
- 결과는 `QuantRegResult`이고 필드 이름은 statsmodels의 것이다(G10). §1의 공통 규칙(입력, 절편, NaN, inf, 배치, 스레드, 에러의 꼴)을 따른다. 가중치 인자(`weights`)는 없다(statsmodels QuantReg와 같다; R의 `rq`에는 있다).
- **목적함수**: Σ ρ_q(y_i − x_iβ), ρ_q(r) = r(q − [r < 0])(Koenker–Bassett 1978). `q`는 0 < q < 1인 수, 또는 그런 수의 1차원 배열(아래 여러 분위)이다.
- **풀이** (G60): Frisch–Newton 내부점법(R quantreg의 `rq.fit.fnb`: 쌍대 선형계획, Mehrotra의 예측–보정, 경계까지의 0.99995만큼 걸음)의 계수에서 |r_i|가 작은 행부터(같으면 행 순서) 선형 독립인 k행을 기저로 잡고, 심플렉스(Barrodale–Roberts의 걸음: 기저 행 하나를 떼는 모서리를 따라 꺾이는 점들 위의 정확한 직선 탐색)로 최적 꼭짓점까지 간다. 내는 `params`는 기저 행 k개의 연립방정식 X_Bβ = y_B를 QR과 double-double 잔차의 보정(최대 3번)으로 푼 꼭짓점이고, 최적성 증명서(기저 행마다 쌍대 변수가 [q − 1, q] 안)를 갖춘다. 모든 n에서 같은 방법이다.
  - 내부점법은 최소제곱 계수의 절편을 그 잔차의 q분위수만큼 옮긴 점에서 시작하고, 상대 쌍대 간격이 `tol`(> 0, 기본 1e-5) 아래거나 `max_iter`(≥ 1, 기본 100)에 닿거나 뉴턴 행렬을 분해할 수 없으면 멈춘다. 이 정밀도는 결과에 들어가지 않는다: 어디서 멈추든 심플렉스가 같은 꼭짓점에 간다(멈추는 곳은 피벗 수만 바꾼다).
  - `converged`는 돌려준 꼭짓점이 증명서를 갖췄는지다. `n_iter`는 내부점법의 반복 수, `n_pivots`는 그 뒤의 심플렉스 피벗 수다. 피벗은 4n + 64k + 1000번까지이고, 닿으면 그때의 꼭짓점을 내고 `converged=False`다(G32). 경고는 없다.
  - y와 x가 같은 행(비트까지, 0의 부호는 빼고)은 한 행으로 합쳐 그 개수를 곱해 푼다(같은 목적함수다).
  - 잔차가 반올림 수준((k + 16)u(|y_i| + ‖x_i‖₁‖β‖∞) 안)이면 0으로 본다. 그래서 반올림한 값들로 만든 평면 위의 점들(완전 적합)은 그 수준에서 최적이다.
- **유일하지 않은 해** (G63): 목적함수의 최솟값은 유일하지만 최소점이 여럿일 수 있다(짝수 개의 중앙값, 정수 반응과 더미 설계 등). 그때 `nonunique=True`이고, `params`는 최소점들 가운데 사전식으로 가장 작은 점(`params[0]`이 가장 작은 것, 그 가운데 `params[1]`이 가장 작은 것, …)이다. 그 점은 꼭짓점이고, 시작점(내부점법이든 앞 분위의 기저든)이나 스레드 수와 상관없다. 절편만 있으면 type-1 표본 분위수(R의 `quantile(type = 1)`; 짝수 개의 중앙값이면 아래쪽 값)다. R의 `rq(method = "br")`도 이때 아래쪽 값을 내지만, 일반적으로는 다른 최적 꼭짓점일 수 있다.
  - 최적 기저의 쌍대 변수가 경계에서 32u(그 행의 크기를 곱한) 안이면 경계에 있다고 본다. q가 10진 수의 double이라서 생기는 차이는 동률로 본다: n = 10, q = 0.3이면 double의 nq가 3보다 1.1×10⁻¹⁶ 작아 정확한 계산으로는 최소점이 하나지만, `nonunique=True`다.
  - 경계에 있는 쌍대 변수가 있으면 증명서의 부호 조건이 정하는 최소점 집합 안에서 Bland 규칙의 피벗으로 사전식 최소점까지 가고, 그 집합에 다른 점이 있는지(사전식 최대 쪽으로 길이가 있는 피벗이 있는지)로 `nonunique`를 정한다.
  - 꼭짓점의 기저는 잔차가 0인 행 가운데 행 순서로 처음의 선형 독립인 k행으로 다시 고르고 그 행들로 β를 푼다. 그래서 같은 꼭짓점이면 비트까지 같다.
- **여러 분위** (G62): `q`가 1차원 배열(길이 L)이면 배치 축 뒤에 분위 축이 붙는다(G52의 경로 축과 같은 자리): `params` (…, L, k), 스칼라 필드 (…, L), `fittedvalues`·`resid` (…, L, n), `cov_params()` (…, L, k, k), `conf_int` (…, L, k, 2), `predict` (…, L, m). 준 순서대로 풀고, 둘째부터는 앞 분위의 기저에서 심플렉스로 시작한다(내부점법 없이; `n_iter`는 0). 결과는 분위마다 따로 부른 것과 비트까지 같다(위의 규칙). 결과의 `q`는 준 값(수 또는 배열)이다.
- **표준오차** (G61): `cov_type`은 R의 `summary.rq`(quantreg 6.1)의 같은 이름이고 계산도 같다. p값과 구간은 t(`df_resid`)다(R과 같다).
  - `'nid'`(기본; Hendricks–Koenker): 대역폭 h(아래; q − h < 0이거나 q + h > 1이면 반씩 줄인다)로 q ± h에서 다시 적합하고, f_i = max(0, 2h/(x_i(β̂_{q+h} − β̂_{q−h}) − ε)), ε = 2⁻²⁶·max\|y_i\|(적합에 쓰인 행; y가 모두 0이면 2⁻²⁶. G67), 공분산 q(1 − q)H⁻¹JH⁻¹, H = XᵀFX, J = XᵀX다. H와 J는 √f·X와 X의 QR의 R로 만든다(XᵀX를 곱해 만들지 않는다). 다시 적합은 그 분위의 기저에서 시작하고 위 규칙의 꼭짓점이다(R의 `br` 적합의 요약과 같은 것; R의 `fn` 적합의 요약은 내부점법의 근사 계수를 쓴다).
  - `'iid'`(Koenker–Bassett): \|r_i\| < ε(위와 같은 ε)인 잔차의 수 pz와 h = max(k + 1, ⌈n·대역폭⌉)(줄이지 않는다)로, |r|의 순서(같으면 행 순서)에서 pz + 1번째부터 pz + h + 1번째까지의 잔차를 정렬해 (pz + 1, …, pz + h + 1)/(n − k)에 q = 1/2로 회귀한 기울기가 희소도 s이고, 공분산은 s²q(1 − q)(XᵀX)⁻¹다(R과 같은 식). 이 중앙값 회귀가 유일하지 않으면 위 규칙의 꼭짓점이라 R의 `br`과 다를 수 있다(아래 정확도). pz + h + 1이 n을 넘으면 NaN이다.
  - `'ker'`(Powell): h′ = (Φ⁻¹(q + h) − Φ⁻¹(q − h))·min(sd(r), IQR(r)/1.34)(sd는 n − 1로 나눈다, IQR은 R의 type 7 분위수), f_i = φ(r_i/h′)/h′, 공분산은 `'nid'`와 같은 샌드위치다.
  - ε가 y의 크기에 비례하므로 y에 c를 곱하면 `params`와 `bse`가 정확히 c배(반올림 수준에서)다. R의 `summary.rq`는 ε = 2⁻²⁶을 y의 단위 그대로 쓴다: y가 작은 단위면(y × 10⁻⁹) 'nid'의 f가 0으로 잘리고 'iid'가 모든 잔차를 0으로 센다. 그래서 R과는 max\|y_i\| = 1일 때(또는 y를 max\|y_i\|로 나눠 부르고 표준오차에 그 값을 곱하면) 같고, 그 밖에는 'nid'에서 대략 ε의 차이/x_i(β̂_{q+h} − β̂_{q−h})만큼 다르다. 'ker'에는 절대적인 상수가 없다(h′가 잔차의 척도를 따른다).
  - `bandwidth`: `'hall-sheather'`(기본; R `bandwidth.rq(hs = TRUE)`: n^(−1/3)·Φ⁻¹(0.975)^(2/3)·(1.5φ(z)²/(2z² + 1))^(1/3), z = Φ⁻¹(q)) 또는 `'bofinger'`(`hs = FALSE`: n^(−1/5)·(4.5φ(z)⁴/(2z² + 1)²)^(1/5)). 결과의 `bandwidth`는 쓴 h다(q의 단위; `'nid'`·`'ker'`는 줄인 뒤).
  - 정의되지 않는 곳은 NaN이다: `df_resid` ≤ 0, 모든 잔차가 0인 완전 적합(`'nid'`의 f가 모두 0, `'iid'`의 창이 n을 넘는다), q가 0이나 1에 아주 가까워 q ± h의 적합이 같은 꼭짓점일 때(R도 같은 곳에서 특이 행렬이다).
- **결과 필드**: `params bse tvalues pvalues`, `conf_int(alpha=0.05)`, `cov_params()`, `fittedvalues resid`(double-double로 한 번 반올림), `q`, `objective`(Σρ_q(resid), double-double 합), `prsquared`(Koenker–Machado의 R¹ = 1 − `objective`/절편만인 모형의 최소 목적함수(type-1 표본 분위수에서); 절편이 없으면 Σρ_q(y)), `nobs df_model df_resid`, `rank condition_number`, `converged nonunique n_iter n_pivots`, `cov_type bandwidth param_names`, `predict(X_new, /)`, `summary(*, alpha=0.05)`(statsmodels QuantReg summary의 꼴: 모형, 방법, 분위, 공분산, 대역폭 규칙, R¹, 대역폭, 관측 수, 자유도; 계수 표는 `t`·`P>|t|`. 회귀 하나, 분위 하나만).
  - statsmodels의 `prsquared`는 절편만인 모형을 보간한 백분위수(`scoreatpercentile`)에서 재므로 그 점이 최소점이 아니면 조금 다르다.
- 겹친 열(G9, G21)은 최소제곱의 QR이 정하고, 그 계수와 추론은 NaN, 나머지는 그 열을 뺀 적합과 비트까지 같다. `rank`, `df_model`, `df_resid`는 남은 열로 센다.
- **정확도** (잰 값, 설계 §3.6): 돌려준 기저를 유리수로 다시 푼 정확한 꼭짓점과 견줘 78개 적합(R 대조의 문제, n 50–5,000·k 2–10의 무작위 설계, 5차 다항식, 더미 설계의 정수 반응)에서 계수 벡터의 상대오차(노름) 8.6×10⁻¹⁷, 목적함수 1.9×10⁻¹⁶ 안이고, 모두 증명서가 정확히 성립하며 `nonunique`가 정확한 판정과 같다. R `rq(method = "br")`와 유일한 해에서 계수 1.0×10⁻¹⁴(R 쪽의 기저 풀이 오차), 유일하지 않은 해에서 목적함수가 같다. `summary.rq`와 'nid'(두 대역폭) 7.8×10⁻¹⁴, sd의 꼭짓점에서 'ker' 4.0×10⁻¹⁴, 'iid' 1.3×10⁻¹⁴ 안이다('iid'의 중앙값 회귀가 유일하지 않은 세 경우만 R의 br과 다른 꼭짓점이라 다르다). statsmodels의 IRLS는 정확한 해에서 계수가 1.2×10⁻⁷–9.6×10⁻², 목적함수가 10⁻¹⁰–10⁻⁴ 떨어져 있다.
- **에러**: `quantreg(): 'q' must be a number or a 1-dimensional array of numbers strictly between 0 and 1`, `quantreg(): 'cov_type' must be 'iid', 'nid' or 'ker', not 'boot'`, `quantreg(): 'bandwidth' must be 'hall-sheather' or 'bofinger', not 'x'`, `quantreg(): the model has no parameters (no columns in 'X' and intercept=False)`.

## §7. 비선형 최소제곱 (G6)
```
nls(f, x, y, /, *, p0, jac=None, bounds=None, method=None, weights=None, ftol=1e-08, xtol=1e-08, gtol=1e-08, max_nfev=None, rtol=None, nan_policy='propagate')
```
- 결과는 `NLSResult`이고 필드 이름은 다른 결과 객체와 같다(G10; 모형과 척도는 R `nls`의 것, G68). 회귀 하나만 받는다: 배치는 없고 `y`가 1차원이 아니면 `ValueError`(`nls(): 'y' must be 1-dimensional (nls fits one regression, not a batch)`)다. 절편 옵션은 없다(모형이 사용자의 것이다).
- **모형** (G68, G71): Σ w_i (y_i − f(x, θ)_i)²를 θ에 대해 최소화한다. `f(x, *theta)`는 scipy `curve_fit`의 꼴이다: x는 float64 `sd.ndarray`, θ는 Python `float` 인자들이고, n개의 값(`sd.ndarray`나 실수의 시퀀스)을 돌려준다. f는 늘 모든 행(`nan_policy='omit'`이 뺀 뒤, 가중치 0인 행 포함)의 x를 받는다. 모수의 수는 `p0`의 길이다. f가 낸 에러는 그대로 나간다. `least_squares` 꼴(잔차 함수)의 일반 풀이는 두지 않는다.
- **입력** (G75): `x`는 (n,) 또는 (n, d)(첫 축이 관측), `y`는 (n,)이다. `sd.ndarray`, 실수의 시퀀스, frame을 받는다(§1). `p0`는 유한한 실수의 1차원 시퀀스다(필수 키워드).
- **방법** (G69): `method=None`이면 `bounds`에 유한한 끝이 하나라도 있을 때 `'trf'`, 없으면 `'lm'`이다(scipy `curve_fit`의 규칙).
  - `'lm'`: MINPACK `lmder`의 Levenberg–Marquardt(신뢰 영역 꼴; 열 피벗 QR, 척도는 야코비안의 열 노름, factor 100). scipy `leastsq`와 같은 걸음과 판정이다. `bounds`와 함께 주면 `ValueError`(`nls(): method='lm' takes no bounds (method='trf' does)`)다.
  - `'trf'`: scipy `least_squares(method='trf')`의 신뢰 영역 반사법(Coleman–Li 척도, SVD로 푸는 부분문제, 반사 걸음과 기울기 걸음, 엄격히 안쪽인 반복점; x_scale = 1). `p0`가 경계에서 10⁻¹⁰·max(1, |경계|) 안이면 scipy처럼 그만큼 안으로 옮겨 시작한다.
  - `bounds=(lower, upper)`: 각각 수 하나(모든 모수) 또는 p개의 수이고 ±inf는 경계 없음이다. lower < upper이고 `p0`가 그 안이어야 한다(`ValueError`).
- **야코비안** (G70): `jac(x, *theta)`는 (n, p)를 돌려준다(p = 1이면 (n,)도 받는다). 없으면 반복은 MINPACK `fdjac2`의 전진 차분(h = √u·|θ_j|, θ_j = 0이면 √u; 'trf'에서 경계를 넘으면 뒤로)이고, 해의 야코비안(공분산과 다듬기)은 5점 중앙 차분이다. 그 간격은 모수마다 처음 한 번 고른다: 2⁻⁸|θ_j|에서 4배씩 줄이며 이웃한 두 추정의 차이가 8배 넘게 줄어드는 동안(절단 오차 O(h⁴)이 앞서는 동안) 이어 가고 마지막 추정의 간격을 그 뒤에도 쓴다. 경계에 걸리거나 한쪽에서 f가 유한하지 않으면 한쪽 5점 차분이다. NIST 27개에서 해석적 야코비안과의 차이는 열마다 상대 1.4×10⁻¹¹ 안이다(고정 간격 2⁻¹⁰|θ_j|면 위치 모수의 척도가 |θ_j|보다 훨씬 작은 Eckerle4에서 7×10⁻⁵).
- **가중치** (G72): `weights`(≥ 0)는 wls(G20)와 같은 뜻이다: 0인 행은 적합과 `nobs`·자유도에서 빠지고 `fittedvalues`·`resid`만 계산한다(그 행에서는 f가 유한하지 않아도 된다; R `summary.nls`의 n과 같다). 음수는 `ValueError`(`nls(): 'weights' must be >= 0`), NaN은 `nan_policy`를 따른다. scipy `curve_fit`의 `sigma`(`absolute_sigma=False`)는 `weights=1/sigma**2`다.
- **NaN과 inf**: `nan_policy`(§1): `'propagate'`는 f를 부르지 않고 모든 값이 NaN이다(`nobs` NaN, `rank` 0, `converged` False, `nfev` 0; `predict`도 NaN). `'omit'`은 y, x의 어느 열, 가중치가 NaN인 행을 빼고, `'raise'`는 `ValueError`다. y·x·가중치의 inf는 `ValueError`다(G24).
- **유한하지 않은 함수값** (G74): 반복의 시험점에서 f가 쓰인 행에서 유한하지 않으면 그 걸음을 거절하고 신뢰 영역을 줄인다('lm'은 잔차 노름을 +inf로 보아 lmder의 규칙대로 1/10로, 'trf'는 scipy처럼 걸음 길이의 1/4로). `p0`에서 유한하지 않으면 `ValueError`(`nls(): 'f' is not finite at 'p0' (rows used)`)이고, 차분이나 `jac`이 유한하지 않으면 `ValueError`다.
- **수렴** (G73, G32): 반복은 scipy와 같은 판정으로 멈춘다. 'lm'은 lmder의 ftol(실제·예측 감소가 모두 ftol 이하), xtol(신뢰 영역 Δ ≤ xtol·‖Dθ‖), gtol(잔차와 야코비안의 각 열의 코사인의 최댓값 ≤ gtol)과 그 기계 정밀도 판(lmder의 info 6–8)이고, 'trf'는 least_squares의 ftol(dF < ftol·F이고 비율 > 1/4), xtol(‖Δθ‖ < xtol(xtol + ‖θ‖)), gtol(‖g ∘ v‖∞ < gtol)이다. 세 값이 모두 u보다 작으면 `ValueError`다. 판정을 통과해도 `ssr`이 유한하지 않으면(넘침) `converged=False`다(G89, [scipy와 다름]: 야코비안의 열 척도가 극단적이면 xtol 판정이 해에서 먼 곳에서 성립한다; a·exp(−kt) + c를 p0 = [1, −50, 0]에서 풀면 scipy lm도 `xtol`로 멈추고 성공을 알린다).
  - `converged`는 반복이 이 판정 가운데 하나로 멈췄는지다. `max_nfev`(None이면 `jac`이 있을 때 100p, 없을 때 100p(p + 1); least_squares의 기본이고 차분의 호출도 센다)에 닿으면 마지막 반복점을 내고 `converged=False`, 경고는 없다. 이때는 아래 다듬기를 하지 않는다(공분산은 그 점의 정확한 야코비안이다).
  - **다듬기**: 수렴한 반복점에서 정확한 야코비안(사용자의 것 또는 5점 차분)의 가우스–뉴턴 걸음을 계수가 반올림보다 크게 움직이는 동안 잇는다. 걸음은 선형 모형의 QR과 반복 개선(G15)으로 푼다(정규방정식이 아니다). 걸음이 모수의 2⁻⁵⁰ 밑(성분마다 상대)이거나, 두 걸음의 비로 내다본 나머지가 그 밑이거나, 2⁻⁴⁰ 밑에서 절반 넘게 줄지 않으면(반올림의 바닥) 멈춘다. 걸음이 줄지 않거나 남은 걸음이 비싸게 천천히 줄면(잔차가 커서 가우스–뉴턴의 수렴비가 크면) 잔차의 곡률 항 S = Σ w_i r_i ∇²f_i를 2차 차분으로 한 번 구해 뉴턴 걸음 (JᵀWJ + S)d = −JᵀWr로 바꾼다(GLM의 G44와 같은 생각). 모두 10걸음까지다. 고정점은 정확한 야코비안의 JᵀWr = 0이라 S의 정확도는 속도만 바꾼다.
  - 그래서 `ftol`·`xtol`·`gtol`은 언제 다듬기로 넘어가는지만 정하고, 계수는 f와 야코비안이 정확하면 해에 반올림 수준으로 가깝다(아래 정확도).
- **추론** (G72): 공분산은 σ̂²(JᵀWJ)⁻¹, σ̂² = `scale` = `ssr`/`df_resid`, `df_resid` = `nobs` − `rank`다(R `nls`와 같다). J는 해의 정확한 야코비안이고 (JᵀWJ)⁻¹은 √W J의 QR의 R에서 구한다. p값과 구간은 t(`df_resid`)다(ols와 같다). `bounds`의 경계에 걸린 모수가 있어도 같은 J의 전체 공분산이다(scipy와 R의 `algorithm = "port"`와 같다; 경계에서는 이 점근 근사가 맞지 않는다). 경계에 걸린 모수(scipy의 `find_active_constraints`의 거리(rtol = xtol) 안이고 기울기가 바깥을 향하는 모수)는 경계값으로 맞추고 다듬기에서 고정한다.
- **겹친 모수** (G9, G21, G76, G77): 해의 √W J에서 피벗 없는 QR의 |R_jj| ≤ rtol·‖J_j‖인 열의 모수는 `bse`·`tvalues`·`pvalues`·`conf_int`·`cov_params()`의 그 행과 열이 NaN이다. `params`는 반복이 닿은 값 그대로다(f를 계산하는 데 필요하므로 NaN으로 두지 않는다; 그 값은 유일하지 않다). `rank`, `df_model`, `df_resid`는 남은 열로 센다. `rtol`의 기본은 `jac`이 있으면 max(nobs, p)·u(선형 모형과 같다), 차분이면 2⁻³⁰이다(G77; 차분 야코비안의 열은 상대 10⁻¹²–10⁻¹¹ 정확도라 정확히 겹친 열도 그 크기의 |R_jj|를 갖는다; NIST 27개의 가장 작은 |R_jj|/‖J_j‖는 Bennett5의 4.9×10⁻⁵다). 차분 야코비안의 열이 그 차분의 반올림 수준 안이면(‖J_j‖₂ ≤ 16·(Σ|w_o|/(12h_j))·u·‖√w·max_o|f(θ + o·h_j·e_j)|‖₂, w_o는 5점 공식의 가중치, h_j는 그 모수의 간격) 그 열은 미분이 없다고 보고 0으로 둔다. 그래서 그 모수가 겹친 모수가 되고, 식별되는 모수가 대신 빠지지 않는다(G88; a·exp(−kt) + c를 p0 = [1, 100, 0]에서 풀면 k = 100에서 exp(−kt)가 t > 0의 모든 행에서 c의 ulp보다 작아 k가 식별되지 않는다: 예전에는 k 열의 반올림 잡음이 c 열과 같은 방향이라 c가 빠지고 k의 `bse`가 10¹⁵였다).
- **결과 필드**: `params bse tvalues pvalues`, `conf_int(alpha=0.05)`(p, 2), `cov_params()`(p, p), `fittedvalues`(f(x, *params), 모든 행), `resid`(y − `fittedvalues`), `ssr`(쓰인 행의 Σw r²), `scale`, `llf aic bic`, `nobs df_model df_resid`(`df_model`은 `rank`), `rank condition_number`(√W J의 쓰인 열), `converged n_iter nfev njev`, `method param_names cov_type`(`'nonrobust'`), `predict(x_new, /)`, `summary(*, alpha=0.05)`.
  - `llf`·`aic`·`bic` (G78): ols·wls와 같은 식과 모수 수다. `llf`는 정규 우도의 최댓값 −nobs/2·(log 2π + log(ssr/nobs) + 1) + ½Σlog w(가중치가 있으면, 쓰인 행)이고, `aic` = −2·`llf` + 2·`rank`, `bic` = −2·`llf` + log(`nobs`)·`rank`다(척도는 세지 않는다). R `logLik.nls`와 같은 `llf`이고, R의 `AIC`·`BIC`는 σ를 모수로 세어 2, log(nobs)만큼 크다(R의 `lm`과 `ols`의 관계와 같다).
  - `param_names`: f의 x 뒤 위치 인자가 정확히 p개면 그 이름(`f(x, a, b)` → `['a', 'b']`), 아니면 `'b1'…'bp'`.
  - `n_iter`는 반복(신뢰 영역 방법)이 계산한 야코비안 수(`p0`의 것 포함), `nfev`는 f의 모든 호출(반복의 차분, 다듬기, 해의 야코비안과 간격 고르기 포함), `njev`는 야코비안 수(`jac`의 호출 또는 차분 야코비안)다.
  - `predict(x_new)`는 f(x_new, *params)다. x_new는 적합의 x와 같은 꼴(1차원, 또는 같은 열 수의 2차원)이다.
  - `summary()`는 모형, 방법, 관측 수, 자유도, 잔차 표준오차, 제곱합, 수렴, 반복·호출 수와 계수 표(`t`·`P>|t|`)이고, 끝에 야코비안의 출처, 멈춘 판정, 겹친 모수, 경계에 걸린 모수를 적는다.
- **비용** (G79): 차분 야코비안이면 `nls`는 f를 scipy `curve_fit`보다 여러 배(잰 모형에서 5–7배) 부른다. 해의 정확한 야코비안(모수마다 간격을 처음 한 번 고르는 데 약 16번, 그 뒤 야코비안마다 4p번)과 다듬기의 걸음(보통 2–4번, 걸음마다 야코비안 하나) 때문이고, 그만큼 계수와 표준오차가 정확하다(아래 정확도). 이 비용을 끄는 옵션은 없다. 사용자 `jac`을 주면 그 비용의 대부분이 없어진다(잰 모형에서 f 호출 7–13번, scipy는 4–6번; n = 10⁶이면 scipy와 같거나 빠르다; `bench/regression/g6/speed.md`).
- **GIL**: f가 Python이라 반복은 GIL을 쥔 채 돈다(API.md §3). 큰 QR과 f 안의 큰 sd 연산은 GIL을 놓는다.
- **정확도** (잰 값, 설계 §3.7): NIST StRD 27개 × 시작점 2개에서, 기본값(차분)은 수렴한 50개 적합 모두 인증값(11자리)과 계수 LRE 9.5 이상(중앙값 10.7), 표준오차 LRE 9.0 이상(Lanczos1 빼고)이고, 해석적 `jac`이면 계수 10.3, 표준오차 10.4 이상이다. 같은 double 자료의 Arb 참값과는 `jac`이면 계수 3.1×10⁻¹³ 안(중앙값 1×10⁻¹⁵), 차분이면 3.0×10⁻¹⁰ 안(중앙값 3–6×10⁻¹³)이다. scipy `curve_fit`·R `nls`·minpack.lm `nlsLM`의 기본값은 계수 LRE 중앙값 5.9–6.8, 표준오차 5.0–6.3이다. Lanczos1은 잔차가 f의 반올림 크기라 표준오차가 3–4자리다.
- **에러**: `nls(): 'f' must be callable, not int`, `nls(): 'p0' must be within 'bounds'`, `nls(): each lower bound must be less than its upper bound`, `nls(): 'f' must return 40 values (one per row of 'x'), not shape (39,)`, `nls(): 'jac' must return shape (40, 3), not (40, 2)`, `nls(): 'p0' has 3 parameters, more than the 2 observations used`, `nls(): at least one of 'ftol', 'xtol' and 'gtol' must be >= 2.2e-16 (the machine epsilon)`, `predict(): 'x_new' must be 1-dimensional like the fit's 'x', not shape (3, 2)`.
