# 1권 14장 Linear Systems — 얼개

예비 권(리뷰 방식). Part III의 둘째 장. 13장의 행렬 대수 위에서 "A x = b를 푼다"는 한 문제를 끝까지 다룬다: 소거법, 행 사다리꼴, 해의 구조, 계수, 역행렬의 존재 이론, LU의 생각. plans/PROMISES.md에서 14장 앞으로 온 약속(10·11·13장)을 모두 지킨다. 추상 벡터 공간의 말(부분공간, 기저, 차원)은 15장에서 세우므로, 이 장은 R^n(과 C^n; 증명이 그대로 통한다는 것을 한 번 말한다) 안에서 열과 행의 말로만 쓴다. 계수는 여기서 "피벗의 수"로 정의하고, 그것이 소거 방법에 의존하지 않는다는 것(기약 행 사다리꼴의 유일성)을 증명한다. 행 계수 = 열 계수의 차원 해석은 15장으로 넘긴다. 행렬식은 쓰지 않는다(17장).

## Abstract (한 문단, 120단어 이내, 동기부여)
선형계는 과학 계산이 가장 자주 푸는 문제이고, 비선형 문제(Newton 방법, 10장)와 맞춤(최소제곱)도 결국 선형계로 돌아온다. 소거법은 이천 년 된 방법이지만, 그것을 행렬의 분해 A = LU로 읽으면 "언제 풀리는가, 해가 몇 개인가, 얼마나 드는가"가 한꺼번에 답해진다는 점.

## 절 구성
14.1 Systems of Linear Equations — 계와 A x = b, 행 그림(초평면의 교집합)과 열 그림(열의 일차 결합으로 b 만들기), 2×2·3×3 예로 해가 하나·없음·무한한 세 경우(그림 패널), 동차계와 일반해 = 특수해 + 동차해(증명).
14.2 Triangular Systems — 앞·뒤 대입(알고리즘, 유사코드), 비용 n²/2, 대각 성분이 0이 아니면 유일한 해(증명), 13장 삼각 행렬의 역과 연결.
14.3 Gaussian Elimination — 세 가지 행 연산과 기본 행렬(교환·배율·전단; 왼쪽에서 곱하는 것이 행 연산임을 증명, 각각 가역), 행 연산이 해집합을 바꾸지 않음(증명), 소거 과정(알고리즘, 유사코드), 피벗과 행 교환이 필요한 경우, 손으로 푸는 3×3 예 전체, 연산 수 (2/3)n³의 유도(7·8장의 합 공식; 표로 n³ 항과 낮은 차수 항).
14.4 Row Echelon Form — 행 사다리꼴과 기약 행 사다리꼴(정의, 그림: 계단 모양), 모든 행렬이 기약 꼴로 간다(증명: 알고리즘의 종료), 기약 꼴의 유일성(증명), 피벗 열·자유 열, 해집합의 매개 표현(자유 변수마다 특수한 동차해 하나), 풀림 판정: 덧붙인 행렬의 마지막 열이 피벗 열이 아닐 때(증명).
14.5 Rank — 계수 = 피벗 수(유일성 덕에 잘 정의됨), rank A ≤ min(m,n), 해의 개수 판정표(계수와 m, n의 관계: 유일·무한·없음; 표), n > m인 동차계는 0 아닌 해를 가진다(증명; 15장 차원 이론의 바탕 보조정리로 쓰인다고 예고), 계수와 곱: rank(AB) ≤ min(rank A, rank B)는 진술하고 15·16장으로, 가역 행렬을 곱해도 계수가 안 바뀜(증명), rank Aᵀ = rank A는 진술하고 15장.
14.6 Invertible Matrices — 가역 행렬 정리(증명): 정사각 A에 대해 A 가역 ⇔ Ax = 0의 해는 0뿐 ⇔ 기약 꼴이 I ⇔ 모든 b에 해 존재 ⇔ 기본 행렬의 곱 ⇔ rank n ⇔ 왼쪽 역 존재 ⇔ 오른쪽 역 존재 (10장 thm:invertible-matrices (i)의 det 뺀 부분, 13장 thm:one-sided-square, 11장 thm:linear-volume이 인용한 "교환·배율·전단의 곱"을 모두 여기서 갚는다; det ≠ 0은 17장), 특이 행렬의 상이 초평면 안에 들어간다는 것(11장 약속; 증명: 0 아닌 y로 yᵀA = 0), Gauss–Jordan으로 A⁻¹ 계산(예)과 비용 n³쯤, "역행렬을 만들지 말고 풀어라"의 이유(비용과 정확도; 정확도는 5·8권).
14.7 The LU Factorization — 교환 없는 소거 = 단위 아래 삼각 L과 위 삼각 U로 A = LU(증명: 승수를 L에 모으면 된다는 것; 전단 행렬의 곱 구조), 존재 조건: 선행 주 부분행렬이 모두 가역(증명), 유일성(증명), LDU와 대칭 행렬의 LDLᵀ(존재는 같은 조건에서; 20장 예고), 행 교환이 있을 때 PA = LU(모든 가역 행렬, 실제로는 모든 정사각 행렬에 존재; 증명), 한 번 분해하고 여러 b에 대해 풀기(비용 표: 분해 (2/3)n³, 풀이 2n²), 블록 소거와 Schur 여원이 블록 LU라는 것(13장 연결).
14.8 Pivoting and What Can Go Wrong — 작은 피벗 예(ε 예: 10⁻²⁰ 피벗으로 소거하면 binary64에서 틀린 답; 직접 계산해 싣는다), 부분 피벗의 규칙과 승수 ≤ 1, 완전한 오차 분석은 8권으로 넘긴다는 한 문단, 나쁜 조건의 계 예(Hilbert 행렬 작은 n: 공용 빌드로 풀어 오차 표; 13장이 예고한 κ와 연결하되 이론은 21장·8권).
14.9 Special Systems — 삼중대각계의 O(n) 풀이(Thomas 알고리즘; 유사코드, 13장의 T_n으로 예; 13장 약속), 띠 행렬에서 채움이 띠 안에 머묾(진술·짧은 증명), 대각 우세 행렬은 교환 없이 소거 가능(증명), Vandermonde 계와 다항식 보간의 유일성(13장 약속; 가역성은 다항식의 근 수로 증명 — 3장 인용), 양정치계는 20장 예고.
14.10 Solving Linear Systems in Practice: A First Look — 공용 빌드의 sd.linalg.solve(이름은 API-INVENTORY.md에서 확인)로 n에 따른 시간이 n³을 따르는지 표 하나, 분해 재사용의 이득, 잔차 ‖b − A x‖와 오차는 다르다는 것(Hilbert 예로 숫자), 과잉결정·부족결정계는 18·21장으로. 수치는 직접 잰 것만.
