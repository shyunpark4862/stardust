# 앞 장이 뒤 장에 한 약속 (집필 에이전트가 갱신한다)

장을 쓰는 에이전트는 자기 장 앞으로 온 약속을 모두 지키고, 자기가 뒤 장에 한 약속을 여기에 더한다. 지킨 약속에는 [완료]를 붙인다.

## 1권
- [완료] 6장 (Differentiation): Newton 방법과 Heron 방법의 관계; sin의 도함수; 평균값 정리로 Lipschitz 상수 얻기 (5장) — 6장 sec:newton, thm:trig-derivatives, cor:lipschitz-derivative
- 7장 (Integration): 고른 연속에서 Riemann 적분 가능성으로 (5장); 미적분의 기본 정리의 유일성 절반은 6장 cor:zero-derivative를 인용; 기본 정리는 도함수의 적분 가능성을 가정(6장 Volterra 상자); arctan·arcsin을 1/(1+x²)·1/√(1−x²)의 적분으로 (6장)
- 8장 (Sequences, Series, and Approximation): e = Σ 1/k!; H_n이 ln n처럼 자람; Stirling 공식; sin x / x의 편차 x²/6을 Taylor로 설명 (5장). 급수의 수렴·비교와 기하급수 (2장). 무한합의 극한 (3장 1223행 부근). 교란 순열 비율의 극한 1/e, 가운데 이항 계수의 Stirling 어림 (4장). Landau 기호 o·O를 본격적으로(무한대 극한 포함; 6장 def:landau는 h→0만); Taylor로 Newton 오차비 (x_{k+1}−c)/(x_k−c)² → f''(c)/(2f'(c)) 증명; sin·cos 부등식 사다리(6장 prop:sin-cos-ladder)를 Taylor 급수로 잇기; 차분몫 오차를 Taylor로 다시; arctan·arcsin의 거듭제곱 급수; 매끄러움 차수와 정확도 차수 (6장)
- 9장 (Elementary Transcendental Functions): 삼각함수의 엄밀한 정의와 Assumption(3장의 삼각 가정, 5장 asm:trig-geometry: 홀짝성, sin(π/2)=1, sin(kπ)=0, 주기, π>3, (0,π/2)에서 sin·cos>0, 부채꼴 넓이 x/2, 단조성)의 증명; 0<x<π/2에서 sin x < x < tan x를 정의에서 직접(5장 lem:sin-bounds가 삼각형 넓이·넓이의 단조성을 학교 기하로 썼으므로); 부채꼴 넓이를 적분으로; ln을 exp의 역함수로; e^{iθ}의 정의 (3·5장). 1 − t ≤ e^{−t} (4장). exp'=exp, ln'=1/x, 실수 지수 x^s의 도함수 s x^{s−1}과 실수 지수 Bernoulli 부등식(6장 prop:bernoulli-rational과 같은 증명); exp의 강볼록·ln의 강오목, e^x ≥ 1+x를 접선 부등식으로; ln의 오목성과 Jensen으로 AM–GM과 가중 꼴(6장 cor:power-means 뒤 문단); l'Hôpital로 ln x/x^p → 0, x^k/e^x → 0 (6장)
- 10장 (Differential Calculus in Several Variables): 여러 변수의 연쇄 법칙(자동 미분의 역방향 모드가 쓰는 꼴); 벡터 값 함수에서는 평균값 정리가 부등식 꼴로만 남음; 최선의 선형 근사로서의 미분 (6장)
- 27장 (Difference Equations and Recurrences): k계 선형 점화식의 일반 풀이 (4장)
