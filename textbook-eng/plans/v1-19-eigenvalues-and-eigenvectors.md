## Abstract (한 문단, 120단어 이내, 동기부여)
행렬을 거듭 곱하면 무슨 일이 일어나는가 — 인구 모형, Markov 연쇄, 점화식, 반복법의 수렴, 미분방정식의 안정성이 모두 이 물음이다. 사상이 방향을 바꾸지 않고 늘이기만 하는 벡터들을 기저로 잡으면 사상은 대각 행렬이 되고, 거듭제곱은 수의 거듭제곱이 된다. 고윳값은 그 늘임 비율이고, 가장 큰 것이 긴 시간의 행동을 지배한다는 점.

## 절 구성
19.1 Eigenvalues and Eigenvectors — 정의(연산자와 행렬), 고유공간 E_λ = N(A − λI), 기하적 예(평면의 사영·반사·전단·확대·회전; 13장 그림과 연결 — 회전은 실 고유벡터가 없다), 미분 연산자의 고유함수 e^{λx}(16장 연결; 24장 예고), 닮음 불변(16장 약속), 삼각 행렬의 고윳값 = 대각 성분. 그림: 고유벡터 방향이 보존되는 단위원의 상(타원)과 고유 방향 패널.
19.2 The Characteristic Polynomial — p_A(λ) = det(λI − A)(17장), 차수 n의 monic 다항식(증명), 계수: λ^{n−1}의 계수 = −tr A, 상수항 = (−1)ⁿ det A(증명), 닮음 불변(증명), 2×2·3×3 공식, 대수학의 기본 정리로 C 위에서 n개의 고윳값(중복도 포함)·실행렬의 복소 고윳값은 켤레 쌍(증명), det A = ∏λ_i, tr A = Σλ_i(증명), p_{AB} = p_{BA}(정사각; 증명 — 17장 Sylvester 항등식)와 AB·BA의 0 아닌 고윳값이 같음(직사각), 동반 행렬: 모든 monic 다항식은 특성다항식(증명) — 따라서 "고윳값 계산 = 다항식 근 찾기"이고 5차 이상에 공식이 없다는 것(Abel–Ruffini 인용)에서 고윳값 알고리즘은 반드시 반복법이라는 관찰, 특성다항식을 거쳐 고윳값을 계산하면 안 되는 이유는 19.10으로.
19.3 Eigenspaces and Multiplicity — 서로 다른 고윳값의 고유벡터는 독립(증명), 고유공간들의 합은 직합(15장 약속; 증명), 대수적·기하적 중복도와 1 ≤ 기하 ≤ 대수(증명), 결함 행렬의 예(Jordan 블록, 전단).
19.4 Diagonalization — A = SΛS⁻¹ ⇔ 고유벡터 기저 ⇔ 기하 중복도의 합 = n ⇔ (C 위에서) 모든 고윳값에서 기하 = 대수(증명), 서로 다른 n개의 고윳값이면 대각화 가능(증명), 손 계산 예 전체(3×3), 대각화 가능 행렬은 조밀하다는 것은 note(22장 Schur로 증명 예고), 동시 대각화: 대각화 가능한 두 행렬이 교환 ⇔ 공통 고유벡터 기저(증명), 왼쪽 고유벡터와 A = Σ λ_i x_i y_iᴴ 꼴의 스펙트럼 분해(쌍직교성 증명; 13장 외적의 합 읽기 연결).
19.5 Powers of a Matrix — A^k = SΛ^kS⁻¹, Fibonacci 행렬과 Binet 공식(13장 약속; 4·8장의 Fibonacci 연결; 27장 예고), 선형 점화식 x_{k+1} = A x_k의 일반해와 지배적 고윳값, 스펙트럼 반지름 ρ(A), A^k → 0 ⇔ ρ(A) < 1(대각화 가능한 경우 증명; 일반 경우는 진술 + 22장에서 Jordan/Schur로 증명한다고 가리킴 — 13장 Neumann 급수·‖A^k‖ 그림과 연결: ρ < 1이지만 ‖A^k‖가 먼저 커지는 예), ρ(A) ≤ ‖A‖(모든 유도 노름; 증명), 다항식 p(A)의 고윳값 = p(λ)(증명)와 A⁻¹의 고윳값, 이동 A − σI.
19.6 The Cayley–Hamilton Theorem — 진술, 증명(수반 행렬 adj(λI − A)를 쓰는 증명 — 17장; "λ에 A를 대입"하는 틀린 증명이 왜 틀렸는지 한 문단), 응용: A⁻¹과 A^k를 낮은 차수 다항식으로, 최소다항식의 정의와 최소다항식이 특성다항식을 나눔(증명), 대각화 가능 ⇔ 최소다항식이 서로 다른 일차식의 곱(증명; 22장에서 다시), 멱등·대합·멱영 행렬의 고윳값(13·16장 연결).
19.7 Complex Eigenvalues of Real Matrices — 실 2×2 행렬의 복소 켤레 고윳값 a ± ib와 실 표준 꼴 [a −b; b a] = 회전 × 확대(증명; 13장의 복소수 2×2 표현, 16장 회전의 복소 대각화 약속), 일반 실행렬의 실 블록 대각 꼴(대각화 가능한 경우; 증명), 직교·유니터리 행렬의 고윳값은 절댓값 1(18장 약속; 증명), 3×3 회전: 고윳값 1, e^{±iθ}와 축·각 — tr Q = 1 + 2cos θ(18장 약속 완결), Hermite 행렬의 고윳값은 실수이고 서로 다른 고윳값의 고유벡터는 직교(증명; 스펙트럼 정리는 20장), 반대칭 행렬의 고윳값은 순허수.
19.8 Structured Examples — 삼중대각 T_n(2, −1): 고유벡터 sin(ijπ/(n+1)), 고윳값 2 − 2cos(jπ/(n+1))(13장 약속; 증명 — 삼각 항등식 9장; 이것이 이산 사인 변환의 기저이고 −u'' 의 고유함수 sin의 이산판이라는 것; 11권 예고), 순환 행렬: 고유벡터 = Fourier 벡터, 고윳값 = 첫 행의 DFT(증명; 9장 단위근, 18장 Fourier 벡터의 직교성), 치환 행렬·이동 행렬의 고윳값, 계수 1 행렬 uvᴴ의 고윳값, 블록 삼각 행렬의 고윳값 = 블록 고윳값의 합집합(17장), 그래프 인접 행렬 한 문단(9권 예고).
19.9 Markov Matrices and the Dominant Eigenvalue — 확률 행렬(열 합 1): 고윳값 1이 있고 모든 |λ| ≤ 1(증명), 양의 확률 행렬에서 1은 단순하고 나머지는 |λ| < 1, 정상 분포로의 수렴(Perron 정리의 이 경우: 증명은 수축 논증으로 할 수 있으면 완전히, 아니면 진술 + 줄거리 + 참고 문헌; 일반 Perron–Frobenius는 진술만), 작은 예(2·3 상태)와 PageRank 한 문단(인용), Gershgorin 원판 정리(증명)와 대각 우세 ⇒ 가역(14장 연결), 3권 Markov 연쇄 예고. 그림: Gershgorin 원판과 실제 고윳값.
19.10 Computing Eigenvalues: A First Look — 거듭제곱법(알고리즘, 유사코드; 수렴 속도 |λ₂/λ₁|의 증명 — 대각화 가능한 경우), Rayleigh 몫으로 고윳값 추정(대칭이면 오차 제곱; 20장 예고), 역반복과 이동(한 문단), 특성다항식의 근으로 구하면 안 되는 이유: Wilkinson 다항식 예(계수 섭동에 대한 근의 민감도; 직접 계산해 표), 고윳값의 민감도: 대칭이 아니면 나쁠 수 있다(Jordan 블록을 ε만큼 흔들면 고윳값이 ε^{1/n}만큼 움직임 — 직접 계산; Bauer–Fike는 진술 + 증명이 짧으면 증명), 공용 빌드(API 이름은 API-INVENTORY.md에서 확인: sd.linalg.eig, eigvals 등)로 작은 실험: (1) T_n의 계산된 고윳값과 공식의 차이, (2) 거듭제곱법의 반복 횟수와 오차 표(비율이 |λ₂/λ₁|를 따르는지), (3) 흔든 Jordan 블록의 고윳값. 실제 알고리즘(QR 반복)은 8권으로. 수치는 직접 잰 것만, 원인 추측 없이.
