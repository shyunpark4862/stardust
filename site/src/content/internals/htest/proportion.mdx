## 한눈에 보기

비율과 이항의 함수는 `src/stardust/htest/_proportion.py`가 인자를 검사하고 개수를 브로드캐스트한 뒤, C++(`csrc/htest/proportion.cpp`)의 커널 하나를 불러요. 배치는 줄마다 독립이라 스레드풀이 나눠 맡고, 줄 하나는 혼자서나 배치 안에서나 같은 비트예요.

| 함수 | 커널 | 정확하게 다루는 부분 |
|---|---|---|
| [`binomtest`](/api/htest/binomtest/) | `binomtest`, `binom_ci` | 양쪽 규칙의 비교를 double-double log pmf로, $pn$과 정수의 비교를 fma로 |
| [`proportion_confint`](/api/htest/proportion_confint/) | `binom_ci` | Wilson의 두 근을 상쇄 없이, `'binom_test'`의 끝을 조각마다 |
| [`quantile_test`](/api/htest/quantile_test/) | `quantile_test`, `quantile_ci` | 개수와 순서통계량 |
| [`poisson_means_test`](/api/htest/poisson_means_test/) | `poisson_means` | 이중 합을 포아송 꼬리의 한 겹 합으로 |
| [`proportions_ztest`](/api/htest/proportions_ztest/), [`proportions_chisquare`](/api/htest/proportions_chisquare/) | `prop_ztest`, `prop_chisquare` | 귀무값 근처의 차를 double-double로 |
| [`test_proportions_2indep`](/api/htest/test_proportions_2indep/), [`confint_proportions_2indep`](/api/htest/confint_proportions_2indep/) | `prop2_test`, `prop2_ci` | 점수 검정의 제한된 최우추정과 구간의 뒤집기 |

공통 원칙은 [분할표](/internals/htest/contingency/)와 같아요. 비율과 차는 정수 개수에서 정확한 값을 만들어 끝에 한 번 반올림해요. 그래서 귀무값에 아주 가까운 차도 자릿수를 잃지 않아요. 두 표본의 개수의 곱 $n_1n_2$가 $2^{53}$ 아래이면 차의 분자 $c_1n_2 - c_2n_1$과 분모 $n_1n_2$가 double로 정확한 정수라, 나눗셈 한 번이 올바르게 반올림한 차예요. 그때는 double로 계산하고, 그 위의 개수에서는 double-double로 해요. 분산과 반폭은 양수의 합이라 double이어도 몇 ulp예요.

## 이항 검정

### 꼬리와 양쪽 규칙

$X \sim \text{Binomial}(n, p)$에서 `'less'`는 $P(X \le k)$, `'greater'`는 $P(X \ge k)$이고, sd.stats `Binomial`의 `cdf`·`ccdf`(special의 `bdtr`·`bdtrc`)를 C++에서 불러요.

양쪽 p값은 scipy의 규칙이에요. $k < pn$이면 $P(X \le k)$에, 반대편 $x \ge \lceil pn \rceil$ 가운데 $\text{pmf}(x) \le (1 + 10^{-7})\,\text{pmf}(k)$인 결과의 확률을 더해요. 반대편에서 pmf는 단조 감소하므로 조건을 만족하는 첫 $x$를 이분으로 찾고, 그 위의 꼬리 $P(X \ge x)$를 한 번에 더해요. $k \ge pn$이면 방향을 뒤집어요. pmf끼리의 비교는 double-double log pmf로 해요.

한 가지 미묘한 곳이 $pn$과 정수의 비교예요. $p = 0.1$은 double로 정확히 1/10이 아니라 조금 크므로, $n = 30$에서 정확한 곱 $pn$은 3보다 약간 커요. double 곱 `p * n`은 반올림된 값이라 이런 판정을 맡길 수 없어요. 그래서 $\lceil pn \rceil$과 $\lfloor pn \rfloor$은 fma로 정해요. `fma(p, n, -c)`는 $pn - c$를 한 번만 반올림하므로 부호가 정확해요.

```cpp
// csrc/htest/proportion.cpp
// ceil and floor of the exact product p n (fma gives its sign against an integer exactly)
double ceil_prod(double p, double n) {
    double c = std::ceil(p * n);
    while (std::fma(p, n, -(c - 1.0)) <= 0.0) c -= 1.0;
    while (std::fma(p, n, -c) > 0.0) c += 1.0;
    return c;
}
```

```python
>>> import math
>>> from fractions import Fraction
>>> math.fma(0.1, 30, -3), Fraction(0.1) * 30 - 3
(1.6653345369377348e-16, Fraction(3, 18014398509481984))
>>> sd.htest.binomtest(3, 30, p=0.1)
BinomtestResult(k=3, n=30, alternative='two-sided', statistic=0.1, pvalue=1)
```

$p = 0$과 $p = 1$은 점질량이에요. 관측이 그 점이면 p값이 1, 아니면 0이에요.

$n$은 $2^{53}$ 아래여야 해요. 그 위의 정수는 double로 정확하지 않아서 Python 쪽이 `binomtest(): 'n' must be below 2**53`(`ValueError`)를 내요. `proportion_confint`의 `nobs`도 같아요. 그 아래에서도 sd.stats `Binomial`의 꼬리는 $n \le 2^{52}$까지라, $2^{52} < n < 2^{53}$의 p값은 NaN이에요. 이분 탐색은 경계가 움직이지 않으면 NaN으로 멈추고, 마지막에 p값을 1로 자를 때도 NaN은 그대로 남겨요. 꼬리가 정의되지 않은 자리를 p값 1로 가리지 않으려는 거예요.

```python
>>> sd.htest.binomtest(2**51, 2**52 + 10).pvalue
nan
```

### 한 비율의 구간

- **`'exact'`(Clopper–Pearson)**: Beta 분포의 분위수예요. 아래 끝은 Beta$(k, n - k + 1)$의 `icdf`$(\alpha/2)$, 위 끝은 Beta$(k + 1, n - k)$의 `iccdf`$(\alpha/2)$로, 위쪽 꼬리를 1에서 빼지 않고 직접 뒤집어요.
- **`'jeffreys'`**: Beta$(k + 1/2, n - k + 1/2)$의 분위수예요.
- **`'normal'`, `'agresti_coull'`**: $\hat q \mp z\cdot\text{se}$를 double-double로 만들고 [0, 1]로 잘라요.
- **`'wilson'`, `'wilsoncc'`**: Wilson 구간의 끝은 이차식 $(n + z^2)t^2 - (2x + z^2)t + x^2/n = 0$의 두 근이에요(`'wilsoncc'`는 $x$를 $k \mp 1/2$로). 근의 공식을 그대로 쓰면 작은 근에서 $-b - \sqrt{b^2 - 4ac}$처럼 비슷한 두 수를 빼게 돼요. 그래서 큰 근은 양수의 합으로, 작은 근은 근의 곱 $c/a$를 큰 근으로 나눠 만들어요. 그러면 모든 연산이 양수의 덧셈, 곱셈, 나눗셈, 제곱근이라 반올림 여섯 번(제곱근은 인자의 오차를 반으로 줄여요)으로 끝마다 자기 값의 약 4 ulp 안이에요. 계약(끝마다 상대 $10^{-14}$)보다 훨씬 작아서 double로 계산해요.

```cpp
// csrc/htest/proportion.cpp
double wilson_big(double x, double n, double z, double z2) {
    const double disc = z2 + 4.0 * (x * (n - x)) / n;
    return (2.0 * x + z2 + std::sqrt(disc) * z) / (2.0 * (z2 + n));
}
double wilson_small(double x, double n, double z, double z2) {
    return x * x / ((z2 + n) * n) / wilson_big(x, n, z, z2);
}
```

### 양쪽 이항 검정을 뒤집은 구간

`method='binom_test'`의 구간은 양쪽 이항 검정의 p값 $p(q)$가 $\alpha$보다 큰 $q$의 집합이에요. 어려운 점은 $p(q)$가 $q$에 대해 단조가 아니라는 거예요. 반대편에서 더하는 결과의 수가 $q$에 따라 바뀌어서 $p(q)$가 계단처럼 뛰어요.

$q < k/n$ 쪽을 보면, $p(q) = P(X \ge k) + P(X \le j)$이고 반대편의 마지막 개수 $j$는 $q$가 커질수록 하나씩 올라가요. $j$가 바뀌는 점은 $\text{pmf}(j) = (1 + 10^{-7})\text{pmf}(k)$를 푼 점인데, 두 pmf의 비는 $\binom{n}{j}/\binom{n}{k}\cdot\big(q/(1-q)\big)^{j - k}$라서 로지트로 닫힌 꼴이에요.

$$
\operatorname{logit} t_j = \frac{\log\binom{n}{j} - \log\binom{n}{k} - \log(1 + 10^{-7})}{k - j}
$$

계단점은 $s_j = \max(j/n, t_j)$예요. 한 조각($j$가 고정된 구간) 안에서는 $p'(q) = n\big(\text{pmf}_{n-1}(k - 1) - \text{pmf}_{n-1}(j)\big)$이고, 두 pmf의 비가 $q$에 대해 단조라서 $p$는 감소하다 증가해요. 최솟점도 로지트로 닫힌 꼴이에요. 그래서 $k/n$에서 바깥쪽으로 조각을 하나씩 보며, 처음으로 기각($p \le \alpha$)이 생기는 조각에서 끝을 정해요. 조각의 오른쪽 끝에서 이미 기각되면 그 끝이고, 아니면 증가 구간에서 $p = \alpha$를 이분으로 풀어요. 이분은 double의 비트 순서로 하므로 많아야 64번이에요. 위 끝도 같은 방법이에요.

```python
>>> lo, hi = sd.htest.proportion_confint(48, 48, method='binom_test')
>>> lo, hi
(0.9300718083893805, 1.0)
>>> sd.htest.binomtest(48, 48, p=lo).pvalue
0.07903043968425646
>>> sd.htest.binomtest(48, 48, p=math.nextafter(lo, 0)).pvalue
0.04821338626233737
```

끝점 $0.93007$은 계단점이에요. 그 점에서 p값은 0.079로 채택이고, 바로 아래 double에서는 0.048로 기각이에요.

## 분위수 검정

`quantile_test`는 $T_1 = \#(x \le q)$, $T_2 = \#(x < q)$를 세고 Binomial$(n, p)$의 꼬리를 써요(scipy의 정의). `'less'`는 $T_2$로 $P(Y \ge T_2)$, `'greater'`는 $T_1$로 $P(Y \le T_1)$, 양쪽은 작은 쪽의 두 배예요. 구간은 정렬한 표본의 순서통계량 $x_{[\text{ppf}(a) - 1]}$, $x_{[\text{isf}(a)]}$예요. 분위수는 sd.stats `Binomial`의 `icdf`·`iccdf`이고, 결과가 표본을 복사해 두므로 `conf_int`는 다시 세지 않아요.

## 두 포아송 평균의 E-test

`poisson_means_test`는 Krishnamoorthy와 Thomson의 E-test예요. 귀무가설 아래의 추정 $\hat\lambda_2 = (k_1 + k_2 - d\,n_1)/(n_1 + n_2)$($d$는 `diff`)에서 두 포아송 $X_1 \sim \text{Poisson}\big(n_1(\hat\lambda_2 + d)\big)$, $X_2 \sim \text{Poisson}(n_2\hat\lambda_2)$를 정하고, 통계량

$$
T(x_1, x_2) = \frac{x_1/n_1 - x_2/n_2 - d}{\sqrt{x_1/n_1^2 + x_2/n_2^2}}
$$

가 관측 $T(k_1, k_2)$만큼 극단인 모든 $(x_1, x_2)$의 확률을 더해요. 정의는 이중 합이에요.

### 이중 합을 한 겹으로

$x_2$를 고정하면 $T$는 $x_1$에 대해 증가해요. 그래서 $x_2$마다 기각역은 $x_1$의 한쪽 꼬리(양쪽 검정은 두 꼬리)이고, 이중 합은 $\sum_{x_2}\text{pmf}_2(x_2)\cdot P(X_1 \ge a(x_2))$ 꼴의 한 겹 합이 돼요. 포아송 꼬리는 double-double 평균을 받는 불완전 감마 함수예요.

경계 $a(x_2)$는 앞 $x_2$의 경계에서 출발해 걸음을 두 배씩 늘려(galloping) 괄호를 잡고 이분으로 찾아요. 이웃한 $x_2$의 경계는 가까우므로 대부분 몇 번의 평가로 끝나요. $T$는 double-double로 계산하고, 관측과의 차가 $T$의 크기의 $2^{-90}$ 안이면 같은 값으로 세요. double-double $T$의 오차는 $2^{-104}$쯤이라, 수학적으로 같은 $T$를 빠뜨리지 않으면서 다른 $T$를 같다고 보지도 않아요.

### 어디서 멈추나

합은 $X_2$의 최빈값에서 위아래로 가요. $x_2$가 평균을 지나면 남은 꼬리의 질량은 pmf의 기하급수로 위에서 묶여요($\text{pmf}(x_2 + 1)/\text{pmf}(x_2) = \mu_2/(x_2 + 1)$이 줄어들기 때문이에요). 그 상한이 지금까지 합의 $2^{-60}$ 아래가 되면 멈춰요.

```cpp
    // csrc/htest/proportion.cpp
    for (double x2 = mode;; x2 += 1.0) {
        const double pm = pmf2(x2);
        sum += term(x2, pm, gup, glo);
        if (++steps > cap) return {stat, kNaN, true};
        if (x2 + 1.0 > mu2.hi) {  // the mass above x2: at most pmf(x2 + 1) / (1 - mu2 / (x2 + 2))
            const double rest = pm * (mu2.hi / (x2 + 1.0)) / (1.0 - mu2.hi / (x2 + 2.0));
            if (rest <= 0x1p-60 * sum || rest < 1e-320) break;
        }
    }
```

걸음 수는 대략 $\sqrt{\mu_2}$에 비례해요(최빈값 양쪽으로 약 $9.2\sqrt{\mu_2}$씩). 걸음이 $2 \times 10^7$을 넘으면 합을 그만두고 `ValueError`를 내요. $16\sqrt{\mu_2}$가 그 상한의 1.5배를 넘는 문제는 합을 시작하지도 않고 바로 내요. 개수가 $10^{13}$쯤이면 이 상한에 닿아요.

```python
>>> sd.htest.poisson_means_test(10**13, 1.0, 10**13 + 10**7, 1.0)
Traceback (most recent call last):
    ...
ValueError: poisson_means_test(): the counts are too large for the exact sum (it needs more than 2e+07 steps)
```

합은 Python 객체를 건드리지 않으므로, 걸음이 많을 문제($400\sqrt{\mu_2}$가 $2^{15}$ 이상)는 GIL을 놓고 계산해요. 개수가 $10^{11}$쯤이면 합이 꽤 길어지는데, 그동안에도 다른 Python 스레드가 돌 수 있어요.

정의의 가장자리는 scipy를 따라요. $\hat\lambda_2 \le 0$이면 결과는 (0, 1)이에요. $T(0, 0)$은 분산이 0인데, $d > 0$이면 분자가 음수라 $-\infty$로 보고 세고, $d = 0$이면 정할 수 없어 세지 않아요. 관측 $T$가 0인 양쪽 검정은 $(0, 0)$ 하나만 빠질 수 있으므로 $1 - P(0, 0)$이에요.

```python
>>> sd.htest.poisson_means_test(15, 10, 34, 10)
PoissonMeansTestResult(statistic=-2.71429, pvalue=0.00639324)
```

## z 검정과 카이제곱 검정

`proportions_ztest`와 `proportions_chisquare`는 statsmodels의 식이에요. 한 표본은 $(c/n - v)/\sqrt{\hat p(1 - \hat p)/n}$(분산의 비율은 표본 비율이나 `prop_var`), 두 표본은 합동 비율의 분산을 써요. 차 $c_1/n_1 - c_2/n_2 - v$는 정수의 몫을 double-double로 만들어 빼요. 분산이 0이면 통계량을 정할 수 없어 NaN이에요. `value`가 있는 카이제곱은 $\sum(c - nv)^2/\big(nv(1 - v)\big)$이고, 자유도는 표본의 수 $k$예요. `value`가 없으면 [분할표](/internals/htest/contingency/)의 `chi2_contingency` 커널을 그대로 불러요.

## 두 독립 비율

### Wald 꼴

`test_proportions_2indep`와 `confint_proportions_2indep`의 Wald 꼴(`wald`, `agresti-caffo`, `log`, `log-adjusted`, `logit`, `logit-adjusted`, `logit-smoothed`)은 조정한 개수(Agresti–Caffo는 각 칸에 1, adjusted는 1/2, smoothed는 독립 표의 두 배)에서 비율·비·오즈비를 double-double로 만들어요. 다만 차의 `wald`·`agresti-caffo`에서 귀무값이 0이고 개수의 곱이 $2^{53}$ 아래이면 정확한 정수 분자를 한 번 나누는 double 길이에요. 결과의 표본 차·비·오즈비도 같은 조건에서 정수의 몫 한 번이에요.

```cpp
        // csrc/htest/proportion.cpp
        if (v == 0.0 && n1 * n2 < 0x1p53) {
            // integer counts whose products are exact in double: the difference is one rounded
            // quotient of exact integers (no cancellation left), the variance a sum of positive
            // terms, z within a few ulp
            const double d = (c1 * n2 - c2 * n1) / (n1 * n2);
            const double vv = c1 * (n1 - c1) / n1 / n1 / n1 + c2 * (n2 - c2) / n2 / n2 / n2;
            z = vv > 0.0 ? d / std::sqrt(vv) : kNaN, var = vv;
            return;
        }
```

비와 오즈비는 귀무값으로 나눈 double-double의 log를 통계량에 써요. 0인 개수는 IEEE의 끝을 그대로 따라요($\log 0 = -\infty$, 분산 inf).

### 점수 검정과 제한된 최우추정

점수 검정(Miettinen–Nurminen)은 귀무가설 $p_1 - p_0 = v$ 아래에서 두 비율을 최우추정하고 그 분산으로 표준화해요. 제한된 최우추정은 삼차식의 근이지만, 삼차식의 세 근 가운데 어느 것이 최우추정인지 고르는 일이 까다로워요. 그래서 근을 고르는 대신 로그우도를 직접 봐요.

$$
\ell(p_0) = c_1\log(p_0 + v) + (n_1 - c_1)\log(1 - p_0 - v) + c_0\log p_0 + (n_0 - c_0)\log(1 - p_0)
$$

은 가능한 구간 $(\max(0, -v), \min(1, 1 - v))$에서 오목하므로 도함수의 근이 많아야 하나예요. 도함수의 부호로 이분해 근을 잡고(없으면 부호가 가리키는 끝이 최우추정이에요), 그 근에서 삼차식에 대해 double-double 뉴턴으로 다듬어요.

```cpp
            // csrc/htest/proportion.cpp
            auto dl = [&](double x) {  // the log likelihood's derivative in p0
                const double x1 = x + v;
                double s_ = 0.0;
                if (c1 > 0.0) s_ += c1 / x1;
                if (n1 > c1) s_ -= (n1 - c1) / (1.0 - x1);
                if (c0 > 0.0) s_ += c0 / x;
                if (n0 > c0) s_ -= (n0 - c0) / (1.0 - x);
                return s_;
            };
            const double lo = std::max(0.0, -v), hi = std::min(1.0, 1.0 - v);
            const double ilo = std::nextafter(lo, hi), ihi = std::nextafter(hi, lo);
            double r0;
            bool interior = false;
            if (!(dl(ilo) > 0.0)) {
                r0 = lo;
            } else if (!(dl(ihi) < 0.0)) {
                r0 = hi;
            } else {
                r0 = last_true(ilo, ihi, [&](double x) { return dl(x) > 0.0; });
                interior = true;
            }
```

비와 오즈비의 제한된 추정은 이차식의 근이에요. 상쇄가 생기지 않는 쪽의 공식($2c/(-b + \sqrt{\Delta})$처럼)을 골라 쓰고 뉴턴으로 다듬어요. 오즈비의 추정은 statsmodels처럼 $[10^{-10}, 1 - 10^{-10}]$으로 잘라요. `correction`이면 분산에 $N/(N - 1)$을 곱해요.

```python
>>> r = sd.htest.test_proportions_2indep(30, 100, 20, 100, value=0.1, method='score')
>>> r.statistic, r.prop1_null, r.prop2_null
(-9.103133513758337e-17, 0.3, 0.2)
>>> Fraction(30, 100) - Fraction(20, 100) - Fraction(0.1)
Fraction(-1, 180143985094819840)
```

표본의 차는 정확히 0.1인데 double 0.1은 1/10보다 조금 커요. 그래서 참 통계량은 0이 아니라 아주 작은 음수이고, 결과는 그 값이에요.

### 구간

점수 구간은 $|z(v)| = z_{\alpha/2}$의 두 근이에요. $z$는 $v$에 대해 감소하므로, 표본값에서 바깥으로 걸음을 두 배씩 늘려(차는 Wald 반폭의 1/4에서, 오즈비는 $e^h$배씩) 경계를 건너는 첫 점을 찾고 이분해요. 경계에 닿지 않으면 정의역의 끝이 구간의 끝이에요. 비의 점수 구간은 statsmodels처럼 Koopman의 삼차식(Nam의 식)의 근에서 만들어요. 삼각함수 꼴로 시작해 double-double로 다듬고, `count2 = nobs2`일 때 이중근이 되는 $p_0 = 1$은 정확히 넣어요. Newcombe의 차 구간은 두 Wilson 구간(위 커널)의 조합이에요. 개수의 곱이 $2^{53}$ 아래이면 차는 정수의 몫 한 번, 비율은 몫 $q_i$와 나눗셈의 정확한 나머지 $r_i$(FMA 하나)의 합 $q_i + r_i$로 들고, 반폭은 양수 제곱의 합의 제곱근이라 double로 계산해요. 끝마다 자기 값과 반폭의 몇 ulp 안이고, 대개는 Wilson 끝의 약 4 ulp가 그 크기를 정해요.

## statsmodels·scipy와 다른 곳

- statsmodels 0.15.0의 차의 점수 검정은 삼차식의 일차 계수에 $n_0v$ 자리에 $c_0v$를 써요(`score_test_proportions_2indep`의 `tmp1`). 그래서 $v \ne 0$이면 그 근이 최우추정이 아니고, 통계량이 $3.7 \times 10^{-4}$(상대)까지 달라요. 여기서는 로그우도의 정류점을 직접 찾아요.
- statsmodels의 `'binom_test'` 구간은 `brentq`로 $p(q) = \alpha$의 근 하나를 찾아요. $p(q)$가 단조가 아닌 곳에서는 채택 영역 바깥의 다른 교차점에 닿기도 해요. 48/48의 아래 끝은 0.92675로 나오고, 그 점의 p값은 0.0483이라 기각돼요.
- scipy의 E-test는 이중 합을 $[\text{ppf}(10^{-10}), \text{ppf}(1 - 10^{-16})]$로 잘라 깊은 꼬리의 p값이 낮게 나와요(꼬리 $1.75 \times 10^{-16}$에서 41%). 격자의 $T$와 관측의 $T$를 다른 부동소수 식으로 계산해 관측 자체를 빠뜨리기도 해요.
- statsmodels의 `proportions_ztest`는 분산 0에서 $-\infty$와 0을 내고, 귀무값 근처의 차에서 부호까지 틀릴 수 있어요. 여기서는 NaN과 double-double의 차예요.
