## 한눈에 보기

[`make_splrep`](/api/smooth/make_splrep/), `make_splprep`, [`generate_knots`](/api/smooth/generate_knots/)는 FITPACK(Dierckx)의 평활 스플라인이에요. 무게 붙은 잔차 제곱합이 주어진 값 $s$ 아래가 되는 $k$차 스플라인 가운데 가장 매끄러운 것을 찾아요.

$$
\min_g\ \sum_j \bigl(\text{내부 매듭 } t_j\text{에서 } g^{(k)}\text{의 뜀}\bigr)^2
\quad\text{조건}\quad \sum_i \bigl(w_i(y_i - g(x_i))\bigr)^2 \le s.
$$

일은 두 단계예요. 먼저 매듭이 없는 곳에서 시작해 잔차가 큰 구간에 매듭을 더해 가며, 그 매듭의 최소제곱 스플라인이 $s$에 닿을 만큼 매듭을 늘려요(`generate_knots`). 그다음 그 매듭에서 뜀의 무게를 정하는 모수 $p$를, 잔차 제곱합이 정확히 $s$(허용오차 $0.001s$)가 되도록 찾아요. 규칙은 scipy 1.18.1의 `_fitpack_repro`(FITPACK의 `fpcurf`, `fppara`, `fpperi`를 Python으로 옮긴 것)를 그대로 C++로 옮긴 것이고, 풀이는 [벌점 스플라인](/internals/smooth/penalized-spline/)과 같은 띠 Givens QR이에요.

무게 `w`는 FITPACK의 뜻($1/\sigma$)이라 잔차에 곱한 뒤 제곱해요. 평활 스플라인의 `weights`($\sum w r^2$)와 다른 점이에요.

걸음마다 하는 일은 이래요.

1. 지금 매듭의 최소제곱 스플라인을 맞추고 점마다의 잔차 $(w_i(y_i - g(x_i)))^2$와 그 합 $f_p$를 구해요. 잔차는 맞춘 스플라인을 자료점에서 평가해서 구해요(scipy의 `fpback`과 같은 방식). QR이 덤으로 주는 잔차 제곱합을 쓰지 않는 까닭은 매듭 걷기가 점마다의 잔차를 읽기 때문이에요.
2. $\lvert f_p - s\rvert \lt 0.001s$이거나 $f_p \lt s$이면 멈춰요.
3. 한 번에 넣을 매듭의 수를 정하고, 그 수만큼 매듭 걷기로 하나씩 넣어요. 하나 넣을 때마다 다시 맞춰 잔차를 고쳐요.
4. 매듭이 보간의 수($m + k + 1$)에 닿으면 보간 매듭으로 끝내고, `nest`에 닿으면 거기서 멈춰요.

### 매듭 걷기

어디에 넣을지는 FITPACK의 `fpknot`이에요.

```cpp
// csrc/smooth/fitpack.cpp
double fpknot(const double* x, std::int64_t m, const std::vector<double>& t, std::int64_t k, const double* res) {
    const std::int64_t n = static_cast<std::int64_t>(t.size()), nk1 = n - k - 1;
    std::vector<double> fpint;
    std::vector<std::int64_t> nrdata, starts;
    std::int64_t l = k + 1, start = 0;
    double fpart = 0.0;
    for (std::int64_t it = 0; it < m; ++it) {
        bool fresh = false;
        if (l < nk1 && x[it] >= t[l]) {
            fresh = true;
            ++l;
        }
        const double term = res[it];
        fpart += term;
        if (fresh) {
            const double store = term * 0.5;
            fpint.push_back(fpart - store);
            fpart = store;
            nrdata.push_back(it - start - 1);
            starts.push_back(start);
            start = it;
        }
    }
    fpint.push_back(fpart);
    nrdata.push_back(m - 1 - start - 1);
    starts.push_back(start);
    double fpmax = 0.0;
    std::int64_t number = -1;
    for (std::size_t j = 0; j < fpint.size(); ++j) {
        if (fpmax >= fpint[j] || nrdata[j] <= 0) continue;
        fpmax = fpint[j];
        number = static_cast<std::int64_t>(j);
    }
    if (number < 0) return kNaN;
    return x[starts[number] + nrdata[number] / 2 + 1];
}
```

자료를 차례로 걸으며 매듭 구간마다 잔차를 모아요. $x \ge t_l$인 첫 점이 그 매듭의 "매듭 점"이고, 그 점의 잔차는 양쪽 구간에 반씩 나눠요. 구간마다 안쪽 자료점의 수(`nrdata`, 매듭 점은 빼요)도 세어 두고, 안쪽에 점이 있는 구간 가운데 잔차 합이 가장 큰 구간을 골라 그 안쪽 점들의 가운데 점을 새 매듭으로 해요. 새 매듭이 언제나 자료점이라 매듭과 자료가 엇갈리지 않고(Schoenberg–Whitney 조건이 쉽게 서요), 첫 매듭은 자료의 한가운데 점이에요. 위 예의 5.277이 정렬한 200점의 101번째 점이에요.

같은 비교, 같은 순서라서 이 걷기는 scipy의 `_dierckx.fpknot`과 무작위 2000건(같은 $x$ 포함)에서 모두 같은 값을 냈어요.

## 뜀의 벌점과 p

매듭이 정해지면 $g$는 그 매듭의 $k$차 스플라인이고, 뜀의 벌점은 계수의 일차식이에요. $k$차 B-스플라인의 $k$차 도함수는 조각마다 상수라서 내부 매듭 $t_j$에서의 뜀이 계수의 일차결합이고, $B_i$가 $t_j$를 지지집합 안에 둔 $k + 2$개 계수만 걸쳐요.

```cpp
// csrc/smooth/fitpack.cpp
std::vector<double> disc(const std::vector<double>& t, std::int64_t k, std::int64_t& rows) {
    const std::int64_t n = static_cast<std::int64_t>(t.size());
    const double delta = t[n - k - 1] - t[k];
    const std::int64_t nrint = n - 2 * k - 1;
    rows = std::max<std::int64_t>(0, nrint - 1);
    std::vector<double> matr(static_cast<std::size_t>(rows * (k + 2)));
    const double fac = std::pow(delta / static_cast<double>(nrint), static_cast<double>(k));
    for (std::int64_t jj = 0; jj < rows; ++jj) {
        const std::int64_t j = jj + k + 1;
        for (std::int64_t ii = 0; ii < k + 2; ++ii) {
            const std::int64_t i = jj + ii;
            double prod = 1.0;
            for (std::int64_t q = 0; q < k + 2; ++q)
                if (i + q != j) prod *= (t[j] - t[i + q]);
            matr[jj * (k + 2) + ii] = (t[i + k + 1] - t[i]) / prod;
        }
    }
    for (double& v : matr) v *= fac;
    return matr;
}
```

식의 근거는 B-스플라인의 나눗셈 차분 표현이에요. $B_i(x) = (t_{i+k+1} - t_i)\,[t_i, \ldots, t_{i+k+1}]\,(\cdot - x)_+^k$이고, 나눗셈 차분은 $\sum_q f(t_{i+q})/\omega'(t_{i+q})$, $\omega(t) = \prod_q(t - t_{i+q})$예요. $(\tau - x)_+^k$의 $x$에 대한 $k$차 도함수는 $x = \tau$에서 $(-1)^kk!$만큼 뛰니, $B_i^{(k)}$의 $t_j$에서의 뜀은 상수 $k!$을 빼면 $(t_{i+k+1} - t_i)/\prod_{q:\,i+q \ne j}(t_j - t_{i+q})$예요. 모든 행에 같은 상수는 문제를 바꾸지 않아요. 마지막의 `fac` $= (\delta/\mathit{nrint})^k$(평균 매듭 간격의 $k$제곱)는 뜀 행을 자료 행과 같은 크기로 맞추는 눈금이에요.

평활 문제는 라그랑주 승수 꼴로 바꿔 풀어요. 모수 $p \gt 0$마다

$$
\min_c\ \sum_i\bigl(w_i(y_i - g(x_i))\bigr)^2 + \frac{1}{p^2}\sum_j\bigl(\text{뜀}_j\bigr)^2
$$

의 해 $g_p$를 구하고, $F(p) = f_p(p) - s$의 근을 찾아요. $p \to \infty$이면 벌점이 사라져 최소제곱 스플라인(가장 작은 $f_p$), $p \to 0$이면 뜀이 모두 0이라 다항식(가장 큰 $f_p$)이고, $F$는 그 사이에서 단조 감소예요.

자료의 삼각형(띠 너비 $k + 1$)은 한 번만 만들고, $p$마다 그 행과 뜀 행$/p$(너비 $k + 2$)를 첫 열의 순서로 새 QR에 넣어요. [벌점 스플라인](/internals/smooth/penalized-spline/)이 $\lambda$마다 하는 일과 같은 구조예요. FITPACK은 뜀 행을 자료 삼각형에 바로 회전해 넣는데 그 채움이 행렬 끝까지 번져 $p$ 하나가 $O(n_c^2k)$예요. 여기서는 첫 열의 순서를 지켜 채움이 띠 안에 머물러 $O(n_cb^2)$예요. 그다음 스플라인을 자료점에서 평가해 $f_p$를 구해요.

### 근 찾기

FITPACK의 근 찾기는 $F$를 유리함수 $(ap + b)/(p + c)$로 어림해요. 세 점 $(p_1, f_1)$, $(p_2, f_2)$, $(p_3, f_3)$을 지나는 그런 함수의 근이 다음 $p$예요.

```cpp
// csrc/smooth/fitpack.cpp
double fprati(double p1, double f1, double p2, double f2, double p3, double f3) {
    const double h1 = f1 * (f2 - f3), h2 = f2 * (f3 - f1), h3 = f3 * (f1 - f2);
    if (p3 == kInf) return -(p2 * h1 + p1 * h2) / h3;
    return -(p1 * p2 * h3 + p2 * p3 * h1 + p1 * p3 * h2) / (p1 * h1 + p2 * h2 + p3 * h3);
}
```

$F(p)$는 $p$가 커질수록 $f_p(\infty) - s$로 다가가는 꼴이라 유리함수가 다항식보다 잘 맞아요. $p_3 = \infty$이면 $F(\infty)$를 그 극한으로 두고 식의 극한을 써요. 반복(`root`)은 이래요.

- 괄호 $p_1 \lt p \lt p_3$을 쥐고 $F(p_1) \gt 0 \gt F(p_3)$을 지켜요. 시작은 $p_1 = 0$, $p_3 = \infty$이고 $p_0 = n_c/\sum_j R_{jj}$(scipy와 같은 시작값)예요.
- 새 값이 아직 한쪽 부호만 보였으면 $p$를 0.04배나 25배로 크게 움직여 괄호를 찾아요.
- 괄호가 있으면 `fprati`로 다음 $p$를 구해요. $\lvert F\rvert \lt 0.001s$이면 멈춰요.
- 20번 안에 멈추지 않으면 괄호 $[p_1, p_3]$에서 이분해요. $p_3 = \infty$이면 4배씩 키워 괄호를 만들고, 가운데는 기하평균 $\sqrt{p_1}\sqrt{p_3}$이에요($p$가 여러 자릿수를 오가니 로그 눈금의 가운데). 합쳐 100번이에요.

scipy는 20번 뒤에 경고와 함께 그때의 스플라인을 내요. 여기서는 $F$가 단조라는 사실로 이분까지 가서 경고할 일이 없고, 그래도 못 찾으면 `ValueError`예요.

### 닿지 않는 s와 다항식

| 경우 | 결과 |
|---|---|
| $f_p(\infty) - s \gt 0.001s$ | 그 매듭으로는 $s$에 닿지 않아요(매듭이 `nest`에 닿았거나 사용자가 준 `t`). `ValueError` |
| $f_p(0) \le s$ | 최소제곱 다항식이 이미 $s$ 안이에요. 다항식(주기면 상수)을 맞추고 매듭 삽입으로 주어진 매듭에 옮겨 돌려줘요 |
| 잔차가 NaN | `ValueError`($s$가 자료의 척도에 비해 너무 작아요) |

```python
>>> sd.smooth.make_splrep(x, y, s=1.0, nest=12)
Traceback (most recent call last):
    ...
ValueError: make_splrep(): s = 1.0 cannot be reached with these knots: the least-squares spline on them has sum (w r)^2 = 16.200207418036282 (more knots: a larger 'nest', or other 't')
```

## 주기 스플라인

`bc_type='periodic'`이면 계수가 되풀이돼요. 자유 계수가 $n_f = n_c - k$개이고 $c_{n_f + j} = c_j$예요. 어느 행이든 열 번호를 $n_f$로 접으면 마지막 몇 열이 처음 몇 열로 돌아오니 띠가 깨져요. 그래서 자유 계수 $k, \ldots, n_f - 1$을 띠로, $0, \ldots, k - 1$을 $k$개의 밀집 테두리 열로 둬요.

```cpp
// csrc/smooth/fitpack.cpp
std::int64_t place_row(
    const Layout& L, std::int64_t o, const double* v, std::int64_t width, std::int64_t bw, double* h, double* hb
) {
    std::fill(h, h + bw, 0.0);
    std::fill(hb, hb + L.kb, 0.0);
    if (!L.periodic) {
        for (std::int64_t e = 0; e < width; ++e) h[e] = v[e];
        return o;
    }
    std::int64_t ob = L.nb;
    for (std::int64_t e = 0; e < width; ++e) {
        const std::int64_t j = (o + e) % L.nf;
        if (j >= L.kb) ob = std::min(ob, j - L.kb);
    }
    for (std::int64_t e = 0; e < width; ++e) {
        const std::int64_t j = (o + e) % L.nf;
        if (j < L.kb) hb[j] += v[e];
        else h[j - L.kb - ob] += v[e];
    }
    return ob;
}
```

`BandQR`은 테두리를 함께 다뤄요. 띠의 각 행이 테두리 열 $k$개를 갖고, 띠의 행 $n_b$개 뒤에 테두리의 밀집 위 삼각 $T$($k \times k$)가 붙어요. 들어온 행의 테두리 원소는 띠와 함께 회전되고, 띠를 다 지난 뒤 $T$로 회전돼 들어가요. 대입은 $T$를 먼저 풀고 띠를 아래에서 위로 풀어요. 마지막 자료점은 첫 점의 복사라서 행으로 넣지 않아요(FITPACK의 `fpperi`).

주기에서는 열의 순서가 FITPACK과 달라 삼각형의 대각이 달라요. 시작값 $p_0 = n_f/\sum R_{jj}$가 달라지니 근 찾기의 길도 달라요. 매듭은 같지만 스플라인은 scipy와 최대 $3.1 \times 10^{-4}$ 달라요. 두 쪽 모두 $\lvert f_p - s\rvert \le 0.001s$를 만족하는 다른 $p$에서 멈춘 것이에요.

## scipy와 같은 매듭

매듭을 놓는 일은 잔차 제곱합의 비교로 내리는 이산 결정이에요(어느 구간에 넣나, 몇 개를 넣나, 언제 멈추나). 반올림이 하나만 달라도 비교가 갈려 다른 매듭 벡터가 나올 수 있어요. 그래서 scipy의 계산과 같은 연산을 같은 순서로 해요. 잔차는 스플라인 평가로, 합은 자료의 순서로, 매듭 걷기와 넣을 수의 규칙은 글자 그대로예요.

```python
>>> import numpy as np, scipy.interpolate as si
>>> sp = sd.smooth.make_splrep(x, y, s=16.0)
>>> ref = si.make_splrep(np.asarray(x.tolist()), np.asarray(y.tolist()), s=16.0)
>>> ref.t.tolist() == sp.t.tolist()
True
```

무작위 자료 300벌($k = 1$–5, 세 가지 모양, $s$ 세 가지), 주기 150벌, 곡선(`make_splprep`) 100벌, 정렬된 시험 자료에서 매듭 벡터가 모두 비트까지 같았어요. 같은 매듭에서 스플라인의 차는 비주기 최대 $1.8 \times 10^{-12}$, 곡선 $6.1 \times 10^{-15}$예요. 근 찾기의 $p$와 QR의 순서가 달라서 생기는 차이예요. 매듭이 같다는 것은 약속이 아니라 측정이에요. 테스트는 갈리는 자료가 생기면 실패해서 알려 줘요.

`make_splprep`의 현의 길이 매개변수 $u_i = \sum_{j \le i}\lVert X_j - X_{j-1}\rVert / \text{전체}$도 같은 이유로 scipy(numpy의 `sum`과 `cumulative_sum`)와 같은 차례로 더해요. 배열 영역의 `cumulative_sum`은 다른 순서로 더해 $n = 10^4$에서 끝자리가 달라지고, 그 차이가 매듭을 가를 수 있어요.

계약은 매듭의 일치가 아니라 결과의 성질이에요. 돌려준 스플라인이 (1) 그 매듭에서 돌려준 $p$의 벌점 최소제곱 해이고(벌점 스플라인과 같은 계수 한계), (2) $\lvert\sum(wr)^2 - s\rvert \le 0.001s$라는 것이에요. 34점에서 잰 최대가 계약 단위 0.82예요.

## 입력과 극한

- $x$(`make_splprep`은 $u$)는 비감소여야 해요. 매듭 규칙이 자료의 순서에 기대니 정렬하지 않아요.
- $k$는 1–5(FITPACK의 차수), $s$는 유한한 0 이상이에요.
- $s = 0$은 보간이라 `make_splrep(s=0)`은 `make_interp_spline(x, y, k=k)`(주기는 `bc_type='periodic'`), `make_splprep(s=0)`은 `make_interp_spline(u, x, axis=1)` 그 자체예요. 같은 비트예요.
- 사용자가 준 `t`는 scipy의 `fpcheck`(FITPACK의 `fpchec`, `fpchep`)로 검사해요. 끝 매듭의 순서, 내부 매듭의 증가, 자료가 $[t_k, t_{n-k-1}]$ 안인지, 그리고 Schoenberg–Whitney 조건이에요.
