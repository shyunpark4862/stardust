## 값은 배열의 연산이에요

희소 연산이 만드는 값은 모두 배열의 같은 연산이에요. C++ 커널은 배열 영역의 스칼라 연산(`array/kernels/scalar_ops.hpp`의 `ops::Add`, `ops::Multiply`, `ops::Maximum`, `ops::Less` …)을 그대로 부르고, Python 층은 `sd.multiply`, `sd.sin` 같은 배열 함수를 `data`에 한 번 불러요. 그래서 저장된 자리의 값은 그 자리의 밀집 연산과 비트까지 같고, 결과 dtype도 배열의 승격 규칙이에요(bool + bool은 int64, 정수는 wrap).

```python
>>> import stardust as sd
>>> A = sd.sparse.csr_array(sd.asarray([[1.0, 0.0, 2.0], [0.0, 0.0, 3.0]]))
>>> B = sd.sparse.csr_array(sd.asarray([[0.5, float('nan'), 0.0], [0.0, 0.0, -3.0]]))
>>> (A + B).toarray().tolist()
[[1.5, nan, 2.0], [0.0, 0.0, 0.0]]
>>> (A.toarray() + B.toarray()).tolist()
[[1.5, nan, 2.0], [0.0, 0.0, 0.0]]
>>> A.sin().data.tolist() == sd.sin(A.data).tolist()
True
```

## 희소끼리: 두 줄의 병합

희소끼리의 연산은 모양이 같아야 해요(희소끼리의 브로드캐스트는 없어요). 두 피연산자를 같은 방향의 압축 배열로 맞춘 뒤(왼쪽이 CSC면 둘 다 CSC, 아니면 둘 다 CSR), `_binop`이 줄마다 두 정렬된 색인 목록을 병합해요.

```cpp
// csrc/sparse/binop.cpp
template <class Op, bool Intersect, class T, class Emit>
inline void merge_line(
    const int64_t* ai,
    const T* av,
    int64_t ab,
    int64_t ae,
    const int64_t* bi,
    const T* bv,
    int64_t bb,
    int64_t be,
    Emit&& emit
) {
    const T zero{};
    int64_t i = ab, j = bb;
    while (i < ae || j < be) {
        if (j >= be || (i < ae && ai[i] < bi[j])) {
            if constexpr (!Intersect) emit(ai[i], Op::f(av[i], zero));
            ++i;
        } else if (i >= ae || bi[j] < ai[i]) {
            if constexpr (!Intersect) emit(bi[j], Op::f(zero, bv[j]));
            ++j;
        } else {
            emit(ai[i], Op::f(av[i], bv[j]));
            ++i;
            ++j;
        }
    }
}
```

한쪽에만 있는 자리는 다른 쪽의 암시적 0과의 연산 `op(a, 0)`, `op(0, b)`예요. 표준 꼴이라 줄이 이미 정렬되어 있으므로 병합은 두 줄 길이의 합에 비례해요. 결과의 줄도 정렬된 채로 나와 다시 표준 꼴이에요.

### 곱은 교집합

`Intersect`가 참인 것은 `multiply` 하나예요. 두 쪽이 다 저장한 자리만 결과에 들어가요. 암시적 0은 강한 0이라, 한쪽이 NaN이나 inf여도 다른 쪽이 저장하지 않은 자리는 0이에요. 밀집 곱이라면 0 × NaN이 NaN이 될 자리예요.

```python
>>> M = A * B
>>> M.nnz, M.toarray().tolist()
(2, [[0.5, 0.0, 0.0], [0.0, 0.0, -9.0]])
>>> (A.toarray() * B.toarray()).tolist()
[[0.5, nan, 0.0], [0.0, 0.0, -9.0]]
```

### 만든 0은 지워요

희소끼리의 `+`, `-`, `*`, `maximum`, `minimum`, 비교는 결과의 정확한 0을 지워요(scipy의 `csr_binop_csr`과 같아요). 그래서 `A - A`는 아무것도 저장하지 않아요. 반면 스칼라 곱은 패턴을 그대로 둬요. 둘이 다른 것도 scipy의 규칙이고, `nnz`는 사용자에게 보이는 값이라 따라요.

```python
>>> (A - A).nnz, (A * 0).nnz
(0, 3)
```

### 비교와 True가 많은 결과

두 암시적 0 사이에서 참인 비교(`==`, `<=`, `>=`)는 저장되지 않은 모든 자리가 True예요. 이때 `_binop`은 `keep_all`로 모든 병합 결과(False 포함)를 남기고, `_fill_true`가 줄마다 "저장된 자리면 그 값, 아니면 True"인 자리만 다시 모아요.

```python
>>> E = A == B
>>> E.format, E.nnz, E.toarray().tolist()
('csr', 2, [[False, False, False], [True, True, False]])
```

### 결과의 형식과 병렬

결과는 왼쪽이 CSC면 CSC, 아니면 CSR이에요(scipy의 규칙). COO나 DOK가 왼쪽이면 CSR이에요.

```python
>>> (A.tocsc() + B).format, (A + B.tocsc()).format, (A.todok() + B).format
('csc', 'csr', 'csr')
```

줄은 서로 독립이에요. 두 쪽의 원소 수와 줄 수의 합이 2¹⁵ 이상이고 스레드가 둘 이상이면 줄을 세는 패스와 채우는 패스로 나눠 줄 구간마다 병렬로 돌아요. 그보다 작거나 한 스레드면 scipy처럼 가장 큰 크기의 배열에 한 번에 쓰고 잘라요. 두 길은 같은 줄을 같은 병합으로 만들므로 결과가 같아요.

## 스칼라와

`A * c`, `c * A`, `A / c`, `-A`는 저장된 값에만 하고 패턴과 형식(DOK 포함)을 지켜요. COO의 중복도 그대로 둬요. 곱과 나눗셈은 선형이라 중복을 먼저 더하든 나중에 더하든 같은 뜻이기 때문이에요. 값은 배열의 곱과 나눗셈이에요. 연산자(`A * c`, `A / c`)는 배열의 연산자 `v * c`, `v / c`를 불러 에러에 함수 이름이 없고(`A * 2**70`은 밀집 `x * 2**70`과 같은 `OverflowError: Python int too large to convert to int64`), 메서드 `A.multiply(c)`는 배열의 함수 `sd.multiply`를 불러 `multiply(): `로 시작해요. `A ** n`과 `A.power(n)`도 같은 나눔이에요. 값은 어느 길이든 같아요. `A / 0`도 같은 규칙이라 저장된 원소만 ±inf·NaN이 되고 암시적 0은 0이에요.

```python
>>> (A / 0).toarray().tolist()
[[inf, 0.0, inf], [0.0, 0.0, inf]]
```

비교, `maximum`, `minimum`은 op(0, c)를 한 번 계산해 봐요. 0(False)이면 저장된 값에만 하고 만든 0을 지워요. 0이 아니면 저장되지 않은 모든 자리도 결과에 들어가요. 비교는 `_fill_true`로, `maximum(A, c > 0)`·`minimum(A, c < 0)`은 `A.toarray()`에 한 결과를 A의 형식으로 담아요.

```python
# src/stardust/sparse/_ops.py
def scalar_compare(A, c, op):
    cs = compressed(A)
    flags = _OPERATORS[op](cs._data, c)
    if _OPERATORS[op](one(A.dtype), c).tolist()[0]:  # true at 0: every unstored position is True
        return filled_true(cs, flags)
    return dropped_zeros(cs, flags)
```

`A + c`(c ≠ 0)와 `A ** 0`은 결과가 희소가 아니므로 `ValueError`예요. 밀집 결과가 필요하면 `A.toarray() + c`라고 쓰라는 메시지예요.

## 밀집 배열과

밀집 피연산자 D는 A의 모양으로 브로드캐스트되어야 해요. 결과의 모양이 언제나 A의 모양이에요. 연산은 둘로 나뉘어요.

- `A * D`, `D * A`, `A.multiply(D)`, `A / D`: 결과가 A의 패턴 안이에요. D를 A가 저장한 자리에서만 읽어(`_gather_compressed`, `_gather_coo`: 저장 순서의 연속 배열) 배열의 곱·나눗셈을 해요. 브로드캐스트한 D는 복사 없는 뷰로 읽어요. 결과는 A의 형식이고, 암시적 0은 D가 NaN이나 inf여도 0이에요.
- `A ± D`, 비교, `maximum`·`minimum`: 결과가 밀집이므로 `A.toarray()`와 D의 배열 연산과 같은 비트예요. 비교와 `maximum`·`minimum`은 정의 그대로 그렇게 계산해요. CSR·CSC의 `A + D`, `D + A`, `A - D`, `D - A`는 밀집 배열을 두 번 만들지 않고, D와 0의 배열 연산($D + 0$, $0 - D$, $D - 0$) 하나를 한 뒤 저장된 값을 그 자리에 더하거나 빼요(`_dense_update`). `A.toarray()`의 값은 $0 + v$라 −0.0이 없고, $v + d = (d + 0) + v$처럼 0과 먼저 계산해도 같은 값이 나와서, 0의 부호까지 `A.toarray() ± D`와 같아요. 줄마다 출력의 다른 자리에 쓰므로 줄 구간으로 나눠 병렬로 해요.

```python
>>> D = sd.asarray([[1.0, float('inf'), 2.0], [0.5, 0.5, 0.5]])
>>> P = A * D
>>> P.format, P.toarray().tolist()
('csr', [[1.0, 0.0, 4.0], [0.0, 0.0, 1.5]])
>>> type(A + D).__name__
'ndarray'
```

numpy 배열과 리스트는 피연산자가 아니에요. 연산자는 `NotImplemented`를 돌려 Python이 `TypeError`를 내게 해요. 상대가 numpy 배열이면 numpy의 반사 연산이 자기 글로 답하므로, 그때는 Python과 같은 글(`unsupported operand type(s) for *: 'csr_array' and 'numpy.ndarray'`)의 `TypeError`를 직접 던져요([영역의 구조](/internals/sparse/overview/#밀집으로-몰래-바뀌지-않아요)). `==`·`!=`는 다른 쪽의 비교를 물어 본 뒤 그것도 받지 않으면 `TypeError`예요. Python이 조용히 `False`(객체가 같은지)로 넘어가지 않게 하려는 것이에요.

## 원소별 함수

원소별 함수는 메서드로만 있어요(`A.sin()`). f(0) = 0인 함수만이라 결과가 A의 패턴 안이에요. 함수 열여덟 개의 이름은 배열의 것이고(`asin`, `atan`, `asinh`, `atanh`, `round`), 메서드는 모듈을 들여올 때 표에서 만들어 붙여요. 모두 `with_values`로 같은 배열 함수를 `data`에 한 번 불러요.

```python
# src/stardust/sparse/_ops.py
def with_values(A, f, *, dedupe, dok_csr=False):
    """A new array of A's pattern whose values are f(values). dedupe: a COO array's repeated
    positions are summed first (a nonlinear f; scipy does it in place, this does not change A).
    A dok_array stays DOK unless dok_csr (scipy's result for abs, power and the functions)."""
    coo_array, csr_array, _, dok_array = _sparse_classes()
    fmt = A.format
    if fmt in ("csr", "csc"):
        return A._with_data(f(A._data))
    if fmt == "coo":
        if dedupe and not A.has_canonical_format:
            major, minor, data = A._summed()
            coords = (major, minor) if major is not None else (minor,)
            return coo_array._new(A._shape, coords, f(data), True)
        return A._with_data(f(A._data))
    major, minor, data = A._parts()
    values = f(data)
    if dok_csr:
        n_major = A._shape[0] if major is not None else 1
        return csr_array._new(A._shape, *_core._compress(n_major, major, minor, values, share=True))
    return dok_array._from_coo(A._shape, major, minor, values)
```

함수가 비선형이면 COO의 중복을 먼저 더해야 해요. √2 + √3과 √5가 다르니까요. 그래서 원소별 함수, `abs`, `power`는 `dedupe=True`이고 COO의 결과는 중복을 더한 표준 꼴이에요. 이때 A 자신은 바꾸지 않아요. `-A`는 선형이라 중복을 그대로 둬요. DOK의 원소별 함수, `abs`, `power`는 CSR을 돌려줘요(scipy의 `abs`와 `power`가 CSR이라 그것을 따랐어요).

```python
>>> C = sd.sparse.coo_array(([2.0, 3.0], ([0, 0], [1, 1])), shape=(1, 2))
>>> C.sqrt().nnz, C.sqrt().data.tolist(), (-C).nnz
(1, [2.23606797749979], 2)
```

`power(n)`과 `A ** n`은 n > 0인 실수만 받아요. 0 ** n이 0이 아닌 지수(0, 음수, NaN)는 결과가 희소가 아니라 `ValueError`예요.

`sd.sin(A)`처럼 배열의 함수에 희소 배열을 주면 메서드를 짚는 `TypeError`예요([영역의 구조](/internals/sparse/overview/#다른-영역과-만나는-자리)).

## scipy를 아는 분께

- scipy의 `csr_elmul_csr`는 합집합에서 a × 0을 계산해 한쪽의 NaN·inf가 NaN으로 저장돼요. 이쪽의 희소 × 희소는 교집합이에요.
- scipy의 `<=`·`>=`는 `>`·`<`의 부정이라 NaN과의 비교가 True가 돼요. 이쪽은 IEEE대로예요.
- scipy의 `A / c`는 `A * (1/c)`라 끝자리가 다를 수 있고 c = 0이면 `ZeroDivisionError`예요. 이쪽은 배열의 나눗셈이에요.
- scipy의 `A * 밀집`은 COO를, `dok + 희소`는 DOK를 돌려줘요. 이쪽은 각각 A의 형식, CSR이에요.
- scipy의 `multiply`는 결과가 A보다 커지는 브로드캐스트와 희소끼리의 브로드캐스트를 받아요. 이쪽은 결과가 A의 모양인 것만 받아요.
- scipy의 원소별 메서드 이름은 `arcsin`, `arctan`, `arcsinh`, `arctanh`, `rint`이고, COO에서는 A를 제자리에서 바꿔요.
