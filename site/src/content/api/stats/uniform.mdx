## 한눈에 보기

**균등분포**는 정해진 구간 안의 모든 값이 똑같은 가능성으로 나오는 분포예요. 구간 밖의 값은 나오지 않아요. 밀도를 그리면 구간 위에 평평한 직사각형이 서요.

이럴 때 써요.

- 범위만 알 때: 버스가 10분 간격으로 오는데 언제 정류장에 도착할지 모른다면, 기다리는 시간은 0분에서 10분 사이의 균등분포예요.
- 반올림 오차: 값을 정수로 반올림할 때 생기는 오차는 대체로 −0.5에서 0.5 사이에 고르게 퍼져 있어요.
- 다른 분포의 출발점: 0과 1 사이의 균등한 난수를 분포의 `icdf`에 넣으면 그 분포의 표본이 돼요(아래 [다른 분포와의 관계](#다른-분포와의-관계)).

```python
>>> import stardust as sd
>>> B = sd.stats.Uniform(a=0.0, b=10.0)
>>> B.cdf(3.0)
0.3
>>> B.ccdf(7.0)
0.3
>>> B.mean()
5.0
```

기다리는 시간이 0분에서 10분 사이의 균등분포라면, 3분 안에 버스가 올 확률은 30%, 7분보다 오래 기다릴 확률도 30%이고, 평균 5분을 기다려요.

## 만들기와 매개변수

균등분포는 구간의 두 끝 `a`, `b`로 정해요. 두 끝에는 기본값이 없어서 꼭 이름을 붙여 줘야 해요.

```python
>>> sd.stats.Uniform(a=2.0, b=6.0)
Uniform(a=2.0, b=6.0)
>>> sd.stats.Uniform()
Traceback (most recent call last):
    ...
TypeError: Uniform(): missing 2 required keyword-only arguments: 'a' and 'b'
```

| 매개변수 | 뜻 | 정의역 | 기본값 |
|---|---|---|:---:|
| `a` | 구간의 왼쪽 끝 | 유한한 실수 | 없음 |
| `b` | 구간의 오른쪽 끝 | `a`보다 큰 유한한 실수 | 없음 |

두 번째 매개변수는 폭이 아니라 오른쪽 끝이에요. 2에서 6 사이라면 `Uniform(a=2.0, b=6.0)`이에요.

### 정의역 밖이면 NaN

`a ≥ b`(폭이 0이거나 음수)이거나, 어느 끝이든 inf나 NaN이면 에러 대신 그 원소의 모든 메서드가 NaN이에요. 두 끝을 거꾸로 주어도 바꿔 주지 않아요.

```python
>>> sd.stats.Uniform(a=1.0, b=0.0).cdf(0.5)
nan
>>> sd.stats.Uniform(a=sd.asarray([0.0, 1.0, 0.0, sd.nan]), b=sd.asarray([1.0, 1.0, sd.inf, 1.0])).pdf(0.5)
array([1.0, nan, nan, nan], dtype=float64)
```

끝이 무한대인 균등분포는 넓이를 1로 맞출 수 없어서 뜻이 없어요.

### 배열 매개변수

`a`, `b`에 배열을 주면 구간 여러 개를 한꺼번에 다뤄요. 두 매개변수끼리, 그리고 입력과 [브로드캐스트](/api/stats/basics/#매개변수와-입력은-함께-브로드캐스트해요)해요.

```python
>>> R = sd.stats.Uniform(a=sd.asarray([0.0, 10.0]), b=sd.asarray([1.0, 20.0]))
>>> R.mean(), R.pdf(0.5)
(array([ 0.5, 15.0], dtype=float64), array([1.0, 0.0], dtype=float64))
```

## 밀도와 누적분포

### 밀도

밀도는 구간 위에서 일정하고, 넓이가 1이 되도록 높이가 $1/(b-a)$예요. 지지집합은 두 끝을 포함한 닫힌 구간 $[a, b]$이고, 끝점에서도 밀도는 $1/(b-a)$예요.

$$
f(x) = \begin{cases} \dfrac{1}{b-a} & a \le x \le b \\[4pt] 0 & \text{그 밖} \end{cases}
$$

```python
>>> x = sd.asarray([-1.0, 0.0, 2.5, 10.0, 11.0])
>>> B.pdf(x)
array([0.0, 0.1, 0.1, 0.1, 0.0], dtype=float64)
>>> B.logpdf(x)
array([              -inf, -2.302585092994046, -2.302585092994046,
       -2.302585092994046,               -inf], dtype=float64)
>>> B.support()
(0.0, 10.0)
```

### 누적분포

누적확률은 구간 안에서 직선으로 0에서 1까지 올라가요. 구간의 몇 분의 몇 지점인가가 곧 확률이에요.

$$
\mathrm{cdf}(x) = \frac{x-a}{b-a}, \qquad \mathrm{ccdf}(x) = \frac{b-x}{b-a} \qquad (a \le x \le b)
$$

`a`보다 작으면 `cdf`는 0, `b`보다 크면 1이에요.

```python
>>> B.cdf(x)
array([ 0.0,  0.0, 0.25,  1.0,  1.0], dtype=float64)
>>> B.ccdf(x)
array([ 1.0,  1.0, 0.75,  0.0,  0.0], dtype=float64)
```

`ccdf`도 `1 - cdf`가 아니라 $(b-x)/(b-a)$를 직접 계산해요. 그래서 `b` 바로 옆에서도 작은 위꼬리 확률의 자릿수를 잃지 않아요. 아주 작은 확률의 로그는 `logcdf`, `logccdf`로 구해요. x가 `a`에 아주 가까워 확률이 1e-300보다 작아져도 로그는 정확해요.

```python
>>> B.logcdf(sd.asarray([1e-300, 5.0]))
array([ -693.0781129912077, -0.6931471805599453], dtype=float64)
```

### 분위수

`icdf(p)`는 구간을 p : (1 − p)로 나누는 점 $a + p\,(b - a)$예요. `iccdf(p)`는 위에서 p만큼 자르는 점 $b - p\,(b-a)$예요. p가 0이면 `a`, 1이면 `b`이고(`iccdf`는 반대), [0, 1] 밖이면 NaN이에요.

```python
>>> B.icdf(sd.asarray([0.0, 0.25, 0.5, 1.0, 1.5]))
array([ 0.0,  2.5,  5.0, 10.0,  nan], dtype=float64)
>>> B.iccdf(sd.asarray([0.0, 0.25, 1.0]))
array([10.0,  7.5,  0.0], dtype=float64)
```

`ilogcdf(logp)`, `ilogccdf(logp)`는 확률의 로그에서 거꾸로 풀어요. 확률이 아주 작으면 결과는 구간의 끝과 구별할 수 없을 만큼 끝에 붙어요.

```python
>>> sd.stats.Uniform(a=5.0, b=6.0).ilogcdf(-800.0)
5.0
```

$e^{-800}$은 약 3.7e-348이라, 5에 그만큼 더한 값은 float64에서 5와 같아요.

## 요약값

| 메서드 | 값 |
|---|---|
| `mean()`, `median()` | $(a + b)/2$ |
| `variance()` | $(b - a)^2 / 12$ |
| `standard_deviation()` | $(b - a)/\sqrt{12}$ |
| `skewness()` | 0 (좌우 대칭) |
| `kurtosis()` | −1.2 (초과 첨도) |
| `mode()` | NaN (구간의 모든 점이 같아요) |
| `entropy()` | $\log(b - a)$ |

```python
>>> V = sd.stats.Uniform(a=2.0, b=6.0)
>>> V.mean(), V.median()
(4.0, 4.0)
>>> V.variance(), V.standard_deviation()
(1.3333333333333333, 1.1547005383792515)
>>> V.skewness(), V.kurtosis()
(0.0, -1.2)
>>> V.mode()
nan
>>> V.entropy()
1.3862943611198906
```

- 첨도가 음수예요. 균등분포는 꼬리가 아예 없어서 정규분포(초과 첨도 0)보다 꼬리가 얇아요.
- 최빈값은 NaN이에요. 구간의 모든 점에서 밀도가 같아서 "가장 큰 점"을 하나로 정할 수 없기 때문이에요. 구간의 가운데가 필요하면 `median()`이나 `mean()`을 쓰세요.
- 엔트로피는 음수가 될 수 있어요. 폭이 1보다 좁으면 $\log(b-a) < 0$이에요. 연속 분포의 엔트로피는 이렇게 단위에 따라 음수도 돼요.

```python
>>> sd.stats.Uniform(a=0.0, b=0.5).entropy()
-0.6931471805599453
```

## 표본

`sample`로 구간 안의 난수를 뽑아요. 생성기 `rng`는 꼭 넘겨야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요. 매개변수가 배열이면 결과의 마지막 축이 구간 하나씩이에요.

```python
>>> R.sample(3, rng=sd.random.default_rng(42))
array([[ 0.4513007976393718,  15.280337747949366],
       [  0.794826025358168,    17.6757718906206],
       [0.08607763073528474,  11.415573237791323]], dtype=float64)
```

0 이상 1 미만의 난수만 필요하면 생성기의 [`rng.random`](/api/random/random/)이 더 간단해요. 정수가 필요하면 [`rng.integers`](/api/random/integers/)나 [이산 균등분포](/api/stats/discrete-uniform/)를 쓰세요.

## 다른 분포와의 관계

### 베타 분포

`Beta(a=1, b=1)`은 `Uniform(a=0, b=1)`과 같은 분포예요. [베타 분포](/api/stats/beta/)는 0과 1 사이의 비율을 나타내는데, 두 모양 매개변수가 모두 1이면 밀도가 평평해져요.

```python
>>> U = sd.stats.Uniform(a=0.0, b=1.0)
>>> Be = sd.stats.Beta(a=1.0, b=1.0)
>>> U.cdf(0.3), Be.cdf(0.3)
(0.3, 0.3)
>>> U.variance(), Be.variance()
(0.08333333333333333, 0.08333333333333333)
>>> U.mode(), Be.mode()
(nan, nan)
```

### 역변환: 균등한 난수에서 다른 분포로

$U$가 `Uniform(a=0, b=1)`을 따르면, 어떤 분포 `X`에서든 `X.icdf(U)`는 `X`를 따라요. 누적확률이 u인 점을 고르는 일이 곧 그 분포에서 값을 뽑는 일이기 때문이에요. 아래는 균등한 난수를 [지수분포](/api/stats/exponential/)의 `icdf`에 넣은 것이에요. 평균과 분산이 지수분포의 값(1, 1)과 거의 같아요.

```python
>>> u = U.sample(100_000, rng=sd.random.default_rng(0))
>>> e = sd.stats.Exponential().icdf(u)
>>> round(float(sd.mean(e)), 2), round(float(sd.var(e)), 2)
(1.0, 0.99)
```

### 확률적분변환: 다른 분포에서 균등으로

거꾸로, `X`의 표본을 `X.cdf`에 넣으면 0과 1 사이의 균등분포를 따라요. 평균은 1/2, 분산은 1/12 ≈ 0.0833에 가까워요. 데이터가 정말 그 분포를 따르는지 확인할 때 이 성질을 써요.

```python
>>> Z = sd.stats.Normal()
>>> w = Z.cdf(Z.sample(100_000, rng=sd.random.default_rng(1)))
>>> round(float(sd.mean(w)), 3), round(float(sd.var(w)), 4)
(0.501, 0.0833)
```

### 이산 균등분포

[이산 균등분포](/api/stats/discrete-uniform/) `DiscreteUniform(low=..., high=...)`는 `low` 이상 `high` 미만의 정수가 같은 가능성으로 나와요. 오른쪽 끝을 포함하지 않는 점이 이 분포(닫힌 구간 $[a, b]$)와 달라요. 그래서 같은 0과 10을 주어도 평균이 달라요.

```python
>>> sd.stats.DiscreteUniform(low=0.0, high=10.0).mean()
4.5
>>> sd.stats.Uniform(a=0.0, b=10.0).mean()
5.0
```

## 정확도와 범위

균등분포는 매개변수와 입력의 정의역 전체가 보장 영역이에요. 어떤 `a`, `b`, `x`에서든 모든 메서드가 [통계의 기본](/api/stats/basics/#정확도-약속)의 약속(상대오차 1e-14, `logpdf`·`entropy`는 $10^{-14}\max(1, \lvert\text{값}\rvert)$, 역함수는 입력의 반올림이 허용하는 만큼)을 지켜요. 정밀한 참값과 비교해 잰 최대 상대오차는 역함수를 빼면 약 4e-16이고, 역함수까지 모든 메서드가 약속한 한계의 4% 안이에요.

폭 $b - a$가 float64의 최댓값(약 1.8e308)을 넘을 만큼 넓은 구간도 계산해요. 이때도 밀도, 누적확률, 분위수, 평균이 제대로 나와요. 분산은 참값(약 3.3e615)이 float64를 넘으니 inf예요.

```python
>>> Wd = sd.stats.Uniform(a=-1e308, b=1e308)
>>> Wd.pdf(0.0), Wd.cdf(5e307), Wd.icdf(0.75)
(5e-309, 0.75, 5e+307)
>>> Wd.mean(), Wd.variance(), Wd.standard_deviation()
(0.0, inf, 5.773502691896257e+307)
>>> Wd.entropy()
709.889355822726
```

반대로 아주 좁은 구간에서는 밀도가 float64를 넘어서 inf예요. 엔트로피는 밀도의 로그에 −를 붙인 값이라 제대로 나와요.

```python
>>> Nr = sd.stats.Uniform(a=0.0, b=5e-324)
>>> Nr.pdf(0.0), Nr.entropy()
(inf, -744.4400719213812)
```

## scipy를 아는 분께

- scipy 신형의 `scipy.stats.Uniform(a=..., b=...)`와 이름과 뜻이 같아요. 고전형 `scipy.stats.uniform(loc, scale)`은 구간 `[loc, loc + scale]`이라서 두 번째 값이 폭이에요. 여기서는 두 번째 값이 오른쪽 끝 `b`예요.
- `mode()`는 NaN이에요. scipy 신형은 0.5(구간의 가운데)를 내요.
- `kurtosis()`는 초과 첨도 −1.2예요. scipy 신형의 기본은 첨도 1.8이에요.
- 폭이 float64를 넘는 구간에서 값이 달라요(scipy 1.18.1과 비교). `Uniform(a=-1e308, b=1e308)`에서 scipy는 `mean()`이 NaN, `pdf(0.0)`과 `cdf(5e307)`이 0.0, `icdf(0.75)`와 `entropy()`가 inf예요.
- 확률이 아주 작은 로그 분위수가 달라요. `Uniform(a=0, b=1).ilogcdf(-800.0)`의 참값 $e^{-800} \approx 3.7 \times 10^{-348}$은 float64로 0이고, 결과도 0.0이에요. scipy는 8.900295434028806e-308이에요.
- 결과는 Python `float`이거나 `sd.ndarray`예요. scipy는 `numpy.float64`를 돌려줘요.
