## 어떤 분포인가요

**기하 분포**(geometric distribution)는 첫 성공을 기다리는 분포예요. 성공 확률이 `p`인 시도를 성공할 때까지 되풀이하고, 첫 성공이 나온 시도가 몇 번째인지를 세요. 그래서 값은 1, 2, 3, …이에요. 첫 시도에 바로 성공하면 1이에요.

- 주사위: 6이 처음 나올 때까지 몇 번 던질까요
- 재시도: 성공률 90%인 요청이 처음 성공할 때까지 몇 번 보낼까요, 재시도 상한을 몇으로 둘까요
- 영업: 계약 확률이 5%인 전화를 몇 통째에 처음 계약할까요
- 신뢰성: 날마다 고장 확률이 같은 장비가 며칠째에 처음 고장 날까요

```python
>>> import stardust as sd
>>> X = sd.stats.Geometric(p=1/6)
>>> X.pmf(1)
0.16666666666666666
>>> X.pmf(3)
0.11574074074074074
>>> X.cdf(6)
0.6651020233196159
>>> X.ccdf(10)
0.16150558288984573
>>> X.mean()
6.0
```

주사위를 던져 첫 번째에 6이 나올 확률은 1/6, 정확히 세 번째에 처음 나올 확률은 (5/6)²·(1/6) ≈ 11.6%예요. 여섯 번 안에 6이 나올 확률은 약 66.5%로, "평균 6번"이라는 말과 달리 여섯 번 던져도 셋 중 한 번꼴로 6이 안 나와요. 열 번을 던져도 6이 한 번도 안 나올 확률이 약 16%예요.

<Callout type="warn" title="시도 횟수예요, 실패 횟수가 아니에요">

</Callout>

## 만들기와 매개변수

매개변수는 `p` 하나이고, 이름을 붙여서 줘요. 기본값은 없어요.

```python
>>> X
Geometric(p=0.16666666666666666)
```

`p`는 0보다 크고 1 이하예요. `p = 0`이면 성공이 영영 오지 않아서 분포가 되지 않으므로 NaN이에요. `p = 1`은 첫 시도에 반드시 성공하는 점질량이에요(아래 점질량 절).

```python
>>> sd.stats.Geometric(p=0.0).pmf(1)
nan
>>> sd.stats.Geometric(p=1.5).mean()
nan
```

`p`에 배열을 주면 원소마다 다른 분포가 돼요. 성공률이 50%, 20%, 5%일 때 평균 시도 횟수와 "90%의 경우 이 안에 성공하는" 횟수예요.

```python
>>> X = sd.stats.Geometric(p=sd.asarray([0.5, 0.2, 0.05]))
>>> X.mean()
array([ 2.0,  5.0, 20.0], dtype=float64)
>>> X.icdf(0.9)
array([ 4.0, 11.0, 45.0], dtype=float64)
```

## 확률질량과 누적분포

첫 성공이 $k$번째이려면 앞의 $k-1$번이 모두 실패하고 $k$번째에 성공해야 해요. $q = 1 - p$라고 하면

$$
P(X = k) = q^{k-1} p, \qquad
P(X \le k) = 1 - q^k, \qquad
P(X > k) = q^k, \qquad k = 1, 2, \dots
$$

이에요. `ccdf(k)` = $q^k$는 "처음 $k$번이 모두 실패"할 확률이라 식이 가장 단순해요. 지지집합은 1 이상의 정수라서 0에서 `pmf`는 0이에요. 정수가 아닌 값에서 `pmf`는 0이고 `cdf`는 내림한 정수의 값이에요.

```python
>>> X = sd.stats.Geometric(p=1/6)
>>> X.support()
(1.0, inf)
>>> X.pmf(0)
0.0
>>> X.logpmf(0)
-inf
>>> X.cdf(0.5)
0.0
>>> X.pmf(2.5)
0.0
>>> X.cdf(2.5)
0.3055555555555555
```

분위수 `icdf(p)`는 cdf(k) ≥ p인 가장 작은 정수예요. "주사위를 몇 번까지 던지면 50%, 90%, 99%의 확률로 6을 볼까요?"의 답이에요. `icdf(0)`은 지지집합의 왼쪽 끝 1이고, 위쪽 끝이 없어서 `icdf(1)`은 inf예요.

```python
>>> X.icdf(0.5)
4.0
>>> X.icdf(0.9)
13.0
>>> X.icdf(0.99)
26.0
>>> X.icdf(0.0)
1.0
>>> X.icdf(1.0)
inf
```

평균은 6번이지만, 99% 확실하게 6을 보려면 26번까지 각오해야 해요. 오른쪽 꼬리가 길기 때문이에요.

### 기억 없음

기하 분포의 가장 큰 특징은 **기억이 없다**는 것이에요. 이미 5번 실패했다는 사실은 앞으로 남은 횟수에 아무 영향을 주지 않아요.

$$
P(X > m + n \mid X > m) = \frac{q^{m+n}}{q^m} = q^n = P(X > n)
$$

```python
>>> X = sd.stats.Geometric(p=0.2)
>>> X.ccdf(8) / X.ccdf(5)
0.512
>>> X.ccdf(3)
0.512
```

5번 실패한 뒤 3번 더 실패할 확률은, 처음부터 3번 실패할 확률과 같아요. "이번엔 될 때가 됐다"는 기대는 독립 시도에서는 근거가 없어요. 1 이상의 정수에서 이 성질이 있는 분포는 기하 분포뿐이에요.

### 꼬리와 log 메서드

`ccdf`는 $q^k$를 직접 계산해서 작은 꼬리도 상대 정확도를 지켜요. 더 작아 float64로 나타낼 수 없으면 `logccdf`와 `ilogccdf`를 써요.

```python
>>> G = sd.stats.Geometric(p=0.2)
>>> G.ccdf(1e6)
0.0
>>> G.logccdf(1e6)
-223143.55131420976
>>> G.iccdf(1e-300)
3096.0
>>> G.ilogccdf(-1e6)
4481421.0
```

성공률이 아주 낮아도 분위수는 정의대로 정확한 정수예요. 아래 예에서는 23025840번까지 가야 "아직 성공 못 했을" 확률이 처음으로 1e-10 이하가 돼요.

```python
>>> G = sd.stats.Geometric(p=1e-6)
>>> G.iccdf(1e-10)
23025840.0
>>> G.ccdf(23025840)
9.999994170129525e-11
>>> G.ccdf(23025839)
1.0000004170133696e-10
```

메서드의 공통 뜻은 [분포의 메서드](/api/stats/methods/)에 있어요.

## 요약값

$q = 1 - p$라고 하면

| 메서드 | 값 |
|---|---|
| `mean()` | $1/p$ |
| `variance()` | $q/p^2$ |
| `standard_deviation()` | $\sqrt{q}/p$ |
| `skewness()` | $\dfrac{2 - p}{\sqrt{q}}$ |
| `kurtosis()` | $6 + \dfrac{p^2}{q}$ (초과 첨도) |
| `median()` | `icdf(0.5)` |
| `mode()` | 1 (언제나) |
| `entropy()` | $\dfrac{-q\log q - p\log p}{p}$ (nat) |

```python
>>> X = sd.stats.Geometric(p=0.2)
>>> X.mean()
5.0
>>> X.variance()
19.999999999999996
>>> X.standard_deviation()
4.472135954999579
>>> X.skewness()
2.0124611797498106
>>> X.kurtosis()
6.05
>>> X.median()
4.0
>>> X.mode()
1.0
>>> X.entropy()
2.5020121176909393
```

최빈값은 `p`와 상관없이 언제나 1이에요. 확률질량이 k = 1에서 가장 크고 계속 줄기 때문이에요. 평균(5)보다 중앙값(4)이 작은 것도 오른쪽 꼬리가 길어서예요.

### 점질량: p = 1

`p = 1`이면 첫 시도에 반드시 성공해서 X는 언제나 1이에요. 분산과 엔트로피는 0이고, 왜도와 첨도는 분산으로 나누는 값이라 NaN이에요.

```python
>>> Z = sd.stats.Geometric(p=1.0)
>>> Z.pmf(1)
1.0
>>> Z.mean()
1.0
>>> Z.variance()
0.0
>>> Z.skewness()
nan
>>> Z.kurtosis()
nan
>>> Z.mode()
1.0
>>> Z.entropy()
0.0
```

`support()`는 `p = 1`이어도 기하 분포 족의 지지집합 (1, inf)이에요. 그래서 `icdf(1)`도 그 위 끝 inf예요.

```python
>>> Z.support()
(1.0, inf)
>>> Z.icdf(1.0)
inf
>>> Z.icdf(0.5)
1.0
```

## 실패 횟수로 쓰기

첫 성공 전의 실패 횟수 Y(0, 1, 2, …)가 필요하면 $Y = X - 1$이에요. 이 분포는 `n = 1`인 [음이항 분포](/api/stats/negative-binomial/)와 같아요. 음이항 분포는 실패 횟수를 세기 때문이에요.

```python
>>> G = sd.stats.Geometric(p=0.2)
>>> k = sd.asarray([1, 2, 3, 4])
>>> G.cdf(k)
array([                0.2,                0.36, 0.48800000000000004,
                    0.5904], dtype=float64)
>>> sd.stats.NegativeBinomial(n=1, p=0.2).cdf(k - 1)
array([                0.2,                0.36, 0.48800000000000004,
                    0.5904], dtype=float64)
>>> sd.stats.NegativeBinomial(n=1, p=0.2).mean()
4.0
```

평균도 1만큼 차이 나요. 시도 횟수의 평균은 $1/p = 5$, 실패 횟수의 평균은 $q/p = 4$예요. 분산, 왜도, 첨도처럼 위치를 옮겨도 그대로인 값은 둘이 같아요.

<Callout type="tip" title="어느 정의인지 먼저 확인해요">
  다른 자료에서 기하 분포의 평균이 $(1-p)/p$로 적혀 있거나 0에서 확률이 $p$라면, 그 자료는 실패 횟수 정의를 쓰고 있어요. 그 식을 이 페이지의 `Geometric`에 옮길 때는 k를 1 늘리거나, `NegativeBinomial(n=1, p=p)`를 쓰세요.
</Callout>

## 표본

`sample`은 기하 분포의 난수를 정수인 float64로 뽑아요. 값은 1 이상이에요. 생성기 `rng`를 꼭 줘야 해요. 공통 규칙은 [표본 뽑기](/api/stats/sample/)에 있어요.

```python
>>> rng = sd.random.default_rng(0)
>>> sd.stats.Geometric(p=0.2).sample((6,), rng=rng)
array([ 2.0,  3.0,  4.0,  1.0, 20.0,  7.0], dtype=float64)
>>> x = sd.stats.Geometric(p=0.2).sample((100000,), rng=sd.random.default_rng(7))
>>> sd.mean(x)
4.99656
>>> sd.min(x)
1.0
```

## 다른 분포와의 관계

**베르누이**: 기하 분포는 [베르누이](/api/stats/bernoulli/) 시도를 첫 1이 나올 때까지 되풀이한 횟수예요.

**음이항 분포**: 첫 성공이 아니라 `n`번째 성공까지 기다리면 [음이항 분포](/api/stats/negative-binomial/)예요. 위의 절처럼 `NegativeBinomial(n=1, p)`가 실패 횟수로 센 기하 분포예요.

**지수분포**: 기하 분포는 [지수분포](/api/stats/exponential/)의 이산판이에요. 둘 다 기억이 없는 유일한 분포(각각 정수와 양의 실수에서)이고, 척도가 $-1/\log(1-p)$인 지수분포 E를 올림한 $\lceil E \rceil$이 `Geometric(p)`예요. 그래서 정수 k에서 ccdf가 같아요.

```python
>>> sd.stats.Geometric(p=0.2).ccdf(3)
0.512
>>> sd.stats.Exponential(scale=-1 / sd.log1p(-0.2)).ccdf(3.0)
0.512
```

## 정확도와 범위

- **보장 영역**: `p` ≥ 1e-9예요. 여기서 pmf, cdf, ccdf와 그 log, 모멘트는 참값 대비 상대오차 1e-14 이하이고(`entropy`는 오차가 1e-14·max(1, |값|) 이하), 위의 먼 꼬리에서도 마찬가지예요.
- **분위수**: 늘 위의 정의대로 정수를 찾아요. 목표 확률이 계단 경계에 아주 가깝다면(상대 1e-14 안), 그만큼 움직였을 때의 답인 이웃 정수가 나올 수 있어요. 답이 float64의 최댓값을 넘으면 inf예요.
- **보장 영역 밖**: `p`가 1e-9보다 작아도 값을 계산하지만 정확도는 약속하지 않아요. 아주 작은 `p`에서도 값이 나오고, 평균 $1/p$가 float64를 넘으면 inf예요.

```python
>>> G = sd.stats.Geometric(p=1e-300)
>>> G.median()
6.931471805599452e+299
>>> G.cdf(1e300)
0.6321205588285577
>>> sd.stats.Geometric(p=5e-324).mean()
inf
```

모든 호출은 정해진 시간 안에 끝나요. 계산 방법은 [이산 분포의 구현](/internals/stats/discrete/)에 있어요.

## scipy를 아는 분께

- `scipy.stats.geom(p)`와 같은 정의예요(시도 횟수, k ≥ 1). numpy의 `Generator.geometric`도 시도 횟수를 뽑아요.
- `icdf(0)`은 지지집합의 왼쪽 끝 1이에요. `geom.ppf(0, p)`는 0이에요.
- `p = 1`의 왜도와 첨도는 NaN이에요. `geom.stats(1.0, moments='sk')`는 둘 다 inf예요. `support()`와 `icdf(1)`은 `geom.support(1.0)`, `geom.ppf(1, 1.0)`과 같은 (1, inf)와 inf예요.
- 먼 꼬리의 분위수가 정확해요. `geom.isf(1e-100, 0.2)`는 inf이지만 답은 1032예요. `geom.isf(1e-10, 1e-6)`은 23025839로, 그 점의 ccdf가 아직 1e-10보다 커서 한 칸 모자라요(답은 23025840).
