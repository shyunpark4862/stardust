## 한눈에 보기

핵 회귀도 자리마다 가까운 점에 무게를 주어 값을 정해요. [`lowess`](/api/smooth/lowess/)와 다른 점은 무게예요. 창을 잘라 이웃 몇 개만 쓰지 않고, 모든 점에 가우스 종 모양의 무게 $e^{-(x_j - x_0)^2/(2h^2)}$를 줘요. 종의 폭 $h$가 **대역폭**이고, 이것이 매끄러움을 정해요.

- `degree=0`(Nadaraya–Watson): 무게 평균 $\hat y(x_0) = \sum_j v_j y_j / \sum_j v_j$.
- `degree=1`(국소 선형, 기본): 무게 붙은 직선의 $x_0$에서의 값. 자료의 끝과 고르지 않은 x에서 평균보다 덜 치우쳐요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> x = sd.sort(rng.random(60)) * 10
>>> y = sd.sin(x) + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> kr = sd.smooth.kernel_regression(x, y)
>>> kr
KernelRegressionResult(nobs=60, df=10.3123, bw=0.440789, degree=1)
>>> kr.predict([2.0, 5.0, 8.0])
array([ 0.8337519696590016, -0.9949578388961875,  0.7947233764628282], dtype=float64)
>>> kr.bw, kr.criterion, kr.converged
(0.4407886047572557, 'cv_ls', True)
```

대역폭을 주지 않으면 하나씩 빼는 교차검증으로 골라요.

## 대역폭 `bw`

`bw`는 가우스 핵의 표준편차예요. 수로 주면 그 값을 써요.

```python
>>> for h in (0.1, 0.4, 2.0):
...     kh = sd.smooth.kernel_regression(x, y, bw=h)
...     print(h, round(kh.df, 3), round(kh.scale, 4))
0.1 35.112 0.2603
0.4 11.213 0.2883
2.0 3.432 0.6141
```

이름으로 주면 기준을 가장 작게 하는 대역폭을 찾아요.

| `bw` | 기준 |
|---|---|
| `'cv_ls'`(기본) | 하나씩 뺀 예측의 제곱 오차 $\mathrm{CV}(h) = \frac{1}{n}\sum_i w_i (y_i - \hat y_{-i})^2$ |
| `'aicc'` | Hurvich–Simonoff–Tsai의 보정 AIC $\log(\mathrm{RSS}/n) + \frac{1 + \mathrm{tr}\,L/n}{1 - (\mathrm{tr}\,L + 2)/n}$ |
| `'dpill'` | Ruppert–Sheather–Wand의 직접 대입(한 변수, 국소 선형, 무게 없음) |

$\hat y_{-i}$는 점 $i$를 빼고 맞춘 값, $L$은 모자 행렬이에요. 찾기는 정해진 시작점(자료의 퍼짐으로 정한 기준 대역폭)에서 그 $1/64$배부터 64배까지를 봐요. 한 변수는 격자 33점 뒤 Brent 방법, 여러 변수는 Nelder–Mead예요. 반복의 상한이 있어 언제나 끝나요.

```python
>>> ka = sd.smooth.kernel_regression(x, y, bw='aicc')
>>> round(ka.bw, 6), ka.criterion, round(ka.criterion_value, 6)
(0.496111, 'aicc', -1.195691)
>>> kd = sd.smooth.kernel_regression(x, y, bw='dpill')
>>> round(kd.bw, 6), kd.criterion
(0.384279, 'dpill')
>>> sd.smooth.bw_dpill(x, y)
0.3842793290421749
```

`criterion_value`는 고른 점의 기준 값이에요. `status`는 0(구간 안), $-1$·$1$(작은·큰 끝에서 끝남, `converged=False`), 2(평가 상한)예요. 대역폭을 수로 주거나 `'dpill'`이면 `criterion_value`가 NaN이고 `status`는 0이에요.

### `bw_dpill`

`bw_dpill(x, y)`은 국소 선형 회귀의 대역폭을 공식으로 어림해요. 자료를 블록으로 나눠 4차식을 맞춰 잡음의 분산과 곡률을 재고, 점근 평균제곱오차를 가장 작게 하는 $h$를 대입으로 구해요. 교차검증보다 덜 흔들려요. NaN이 있거나 점이 여섯보다 적으면 에러예요.

```python
>>> sd.smooth.bw_dpill(x[:5], y[:5])
Traceback (most recent call last):
    ...
ValueError: bw_dpill(): the direct plug-in bandwidth needs at least 6 points after trimming 1% at each end
```

## 여러 변수

`X`가 (n, p)이면 핵은 변수마다의 가우스 핵의 곱이고 `bw`는 (p,) 배열이에요. 고를 때도 변수마다 따로 골라요.

```python
>>> X = rng.random((150, 2)) * sd.asarray([4.0, 1.0])
>>> z = sd.sin(X[:, 0]) + 3 * X[:, 1] + sd.stats.Normal(sigma=0.2).sample(150, rng=rng)
>>> k2 = sd.smooth.kernel_regression(X, z)
>>> k2.bw
array([ 0.3007327694033831, 0.09965953598112307], dtype=float64)
>>> k2.predict([[1.0, 0.5], [3.0, 0.5]])
array([ 2.290077075639703, 1.7281327223305012], dtype=float64)
>>> k2.predict([1.0, 0.5])
2.290077075639703
>>> sd.smooth.kernel_regression(X, z, bw=sd.asarray([0.3, 0.1])).bw
array([0.3, 0.1], dtype=float64)
```

## 기울기: `gradient`

`degree=1`의 국소 직선은 값과 함께 기울기도 줘요. `gradient(X_new)`는 평가점마다의 국소 기울기예요. 한 변수는 평가점과 같은 모양, 여러 변수는 (m, p)예요. 아래에서 참 기울기 $\cos x$와 견주면 방향은 맞지만 크기가 작아요. 대역폭만큼 평균을 내는 평활이 봉우리를 낮추는 것처럼 기울기도 눌러요.

```python
>>> kr.gradient([2.0, 5.0])
array([-0.29333982795763175,  0.24961624560762974], dtype=float64)
>>> sd.cos(sd.asarray([2.0, 5.0]))
array([-0.4161468365471424, 0.28366218546322625], dtype=float64)
>>> k2.gradient([[1.0, 0.5]])
array([[0.560882324345329, 3.097626266021617]], dtype=float64)
```

## 결과 읽기

| 필드 | 뜻 |
|---|---|
| `bw` | 쓴 대역폭. 한 변수는 float, 여러 변수는 (p,) |
| `degree`, `kernel` | 받은 값 |
| `criterion` | 고른 규칙(`'cv_ls'`, `'aicc'`, `'dpill'`). 수로 준 `bw`는 `None` |
| `criterion_value`, `status`, `converged` | 고른 기준의 값과 찾기의 상태 |

공통 필드는 [결과 객체 읽기](/api/smooth/results/)에 있어요. 자료점의 `fittedvalues`와 `leverage`는 점 하나를 뺀 적합에서 그 점의 몫을 되돌려 넣어 구해요. 그래서 `predict`를 자료점에서 부른 값과 끝자리가 다를 수 있어요(둘 다 같은 정확도 약속 안이에요).

```python

                                        Criterion value:                0.1010
                                        Converged:                        True

>>> float(sd.max(sd.abs(kr.predict(x) - kr.fittedvalues)))
```

## 먼 평가점

평가점이 자료에서 아주 멀면 가우스 무게가 모두 0으로 언더플로해서 $0/0$이 되기 쉬워요. sd는 가장 가까운 점의 무게로 나눠 놓고 계산해서, 그런 자리에서도 가장 가까운 점들이 정하는 값을 내요.

```python
>>> kn = sd.smooth.kernel_regression(x, y, degree=0, bw=0.1)
>>> kn.predict([100.0, -100.0])
array([ -0.5788514417195317, -0.07338841117042032], dtype=float64)
>>> float(y[-1]), float(y[0])
(-0.5788514417195317, -0.07338841117042032)
```

## 조심할 점

- 기준으로 고르는 일은 모든 점 쌍을 보므로 점의 수의 제곱에 비례해 시간이 걸려요. 점이 아주 많으면 `bw`를 수로 주거나 `'dpill'`을 써요.
- 같은 입력이면 스레드 수와 상관없이 같은 비트예요. 입력의 순서를 바꾸면 같은 값이 그 순서로 나와요.

## statsmodels·R을 아는 분께

- statsmodels의 `KernelReg(endog, exog, var_type, reg_type, bw)`는 (y, x) 순서이고 sd는 (X, y)예요. `reg_type='lc'`·`'ll'`은 `degree=0`·`1`, `bw='aic'`는 `'aicc'`, `fit(X_new)`는 `predict`와 `gradient`예요. `var_type`은 없어요(연속 변수만). 무게를 받아요.
- 국소 선형의 `'aicc'`는 국소 선형 평활기의 $\mathrm{tr}\,L$을 써요. statsmodels는 국소 선형에서도 Nadaraya–Watson의 대각합을 써서 값이 달라요. 국소 상수와 `'cv_ls'`는 같은 기준이에요.
- 고르는 절차가 달라서 고른 대역폭이 statsmodels와 유효숫자 몇 자리에서 다를 수 있어요. sd가 고른 점의 기준 값은 statsmodels가 고른 점의 값보다 크지 않아요.
- statsmodels는 모든 무게가 언더플로하는 먼 평가점에서 NaN($0/0$)을 내요.
- R의 `ksmooth(x, y, kernel='normal', bandwidth)`는 `kernel_regression(x, y, degree=0, bw=0.3706506 * bandwidth)`와 같은 일이에요. `ksmooth`의 대역폭은 핵의 사분위수가 ±0.25·bandwidth인 눈금이고, 핵을 4 표준편차에서 잘라요. sd는 결과를 바꾸지 않는 범위에서만 잘라요.
- `KernSmooth::dpill`은 격자 401점에 구간화해 어림해요. `bw_dpill`은 같은 식을 구간화 없이 계산해서 값이 조금 달라요(시험 자료에서 0.31% 안). R이 `NA`와 경고를 내는 자료에서 `bw_dpill`은 `ValueError`예요.
