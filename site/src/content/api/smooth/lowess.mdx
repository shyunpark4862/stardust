## 한눈에 보기

`lowess`는 흩어진 점들 사이로 매끄러운 곡선을 그려요. 곡선의 한 점을 정할 때 그 자리 가까이의 점들만 보고, 가까운 점일수록 무게를 크게 주어 직선 하나를 맞춰요. 그 직선이 그 자리에서 갖는 값이 곡선의 값이에요. 자리를 옮겨 가며 이 일을 되풀이하면, 전체 모양을 미리 정하지 않아도 자료가 따르는 추세가 드러나요. 이름은 locally weighted scatterplot smoothing(국소 무게 산점도 평활)에서 왔어요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> x = sd.sort(rng.random(60)) * 10
>>> y = sd.sin(x) + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> r = sd.smooth.lowess(x, y, frac=0.3)
>>> r
LowessResult(nobs=60, df=6.92569, frac=0.3, it=3)
>>> r.fittedvalues[:4]
array([0.22430599295370934, 0.27605778762602434, 0.32431700480681386,
        0.5271567043160277], dtype=float64)
>>> r.predict([2.0, 5.0, 8.0])
array([  0.723651235987644, -0.9401910389826731,  0.7835118182765225], dtype=float64)
```

`r.fittedvalues`는 자료점마다의 곡선 값이고 입력과 같은 순서예요. `predict`는 새 자리의 값이에요. 결과의 필드와 메서드는 [결과 객체 읽기](/api/smooth/results/)에서 함께 설명해요.

## 하는 일

자리 $x_0$의 값은 이렇게 정해요.

1. 자료에서 $x_0$에 가장 가까운 점 $k$개를 골라요. 이것이 **창**이에요. 창의 점 수는 $k = \min(n, \max(2, \lfloor \mathit{frac} \cdot n \rfloor))$이에요.
2. 창에서 가장 먼 점까지의 거리를 $h$라 하고, 창의 점마다 **tricube** 무게 $(1 - (\lvert x_j - x_0\rvert/h)^3)^3$을 줘요. $x_0$ 바로 옆의 점은 1에 가깝고, 창의 끝으로 갈수록 0으로 줄어요. 거리가 $h$인 점의 무게는 0이에요.
3. 이 무게(와 `weights`, 강건 무게를 곱한 것)로 직선을 최소제곱으로 맞추고, 그 직선의 $x_0$에서의 값을 곡선의 값으로 써요.

자료점마다 이 일을 해서 `fittedvalues`를 만들어요. 결과는 전체 자료를 한 식으로 맞춘 곡선이 아니라, 자리마다 다른 직선의 값을 모은 것이에요. 그래서 자리마다 다른 기울기를 따라갈 수 있어요.

창이 어느 점을 고르는지는 결과에 닿지 않아요. 거리가 $h$인 점의 무게가 0이라, 같은 거리의 점 둘 가운데 어느 것이 창에 들어가든 값이 같아요. 같은 x가 여러 번 나와도, 입력의 순서를 바꿔도 같은 값이 그 순서로 나와요.

```python
>>> perm = rng.permutation(60)
>>> r2 = sd.smooth.lowess(x[perm], y[perm], frac=0.3)
>>> bool(sd.all(r2.fittedvalues == r.fittedvalues[perm]))
True
```

## `frac`: 창의 크기

`frac`이 매끄러움을 정해요. 작으면 창이 좁아 곡선이 자료의 작은 출렁임까지 따라가고, 크면 창이 넓어 곡선이 펴져요. 기본 2/3은 넓은 쪽이라, 자료의 한 주기보다 좁은 변화가 있으면 줄여야 해요.

```python
>>> for f in (0.1, 0.3, 0.6, 1.0):
...     rf = sd.smooth.lowess(x, y, frac=f)
...     print(f, rf.k, round(rf.df, 3), round(rf.scale, 4))
0.1 6 25.005 0.2721
0.3 18 6.926 0.3149
0.6 36 3.813 0.489
1.0 60 2.498 0.7182
```

`k`는 창의 점 수, `df`는 곡선이 쓴 유효 자유도예요. 창이 좁을수록 자유도가 크고 잔차 척도 `scale`이 작아요. 잔차 척도만 보고 가장 작은 `frac`을 고르면 잡음까지 따라가는 곡선이 되니, 그림을 보며 고르거나 교차검증 같은 기준을 따로 둬요. 기준으로 조절 모수를 스스로 고르는 평활기가 필요하면 [`smoothing_spline`](/api/smooth/smoothing_spline/)이나 [`kernel_regression`](/api/smooth/kernel_regression/)을 써요.

창에는 언제나 점이 둘 이상 들어가요. `frac=0`이어도 $k = 2$예요.

```python
>>> sd.smooth.lowess(x, y, frac=0.0).k
2
>>> sd.smooth.lowess(x, y, frac=1.5)
Traceback (most recent call last):
    ...
ValueError: lowess(): 'frac' must be in [0, 1]
```

## `it`: 강건 반복

자료에 크게 튄 점(이상점)이 있으면 최소제곱 직선이 그쪽으로 끌려가요. 강건 반복은 맞춘 뒤 잔차가 큰 점의 무게를 줄이고 다시 맞추는 일을 `it`번 되풀이해요. 잔차의 중앙 절댓값을 $m$이라 할 때 점의 무게는 bisquare $(1 - (r/6m)^2)^2$이고, 잔차가 $6m$ 이상이면 0이에요.

```python
>>> yo = y.copy()
>>> yo[30] = 8.0
>>> plain = sd.smooth.lowess(x, yo, frac=0.3, it=0)
>>> robust = sd.smooth.lowess(x, yo, frac=0.3)
>>> float(plain.fittedvalues[30]), float(robust.fittedvalues[30]), float(r.fittedvalues[30])
(0.13836302981716656, -0.6935158479292952, -0.7360479472966657)
>>> float(robust.robust_weights[30])
0.0
```

`it=0`의 곡선은 튄 점 쪽으로 크게 올라갔지만, 기본 `it=3`은 그 점의 무게를 0으로 만들어 이상점이 없는 자료의 곡선과 거의 같아요. 마지막 반복에서 쓴 무게는 `robust_weights`에 있어요.

반복은 수렴을 따지지 않고 언제나 `it`번이에요. 그래서 걸리는 시간이 자료와 무관하게 정해져요. 잔차의 중앙 절댓값이 0이면(점의 절반 넘게 곡선 위에 있으면) 잔차가 0인 점만 무게 1이고 나머지는 0이에요.

## `delta`: 맞추는 점 건너뛰기

점이 아주 많으면 모든 점에서 맞추는 일이 시간이 걸려요. `delta`를 주면 마지막으로 맞춘 점에서 x가 `delta` 안인 점은 건너뛰고, 건너뛴 점의 값은 양옆 두 적합 사이의 선형 보간으로 채워요.

```python
>>> fast = sd.smooth.lowess(x, y, frac=0.3, delta=0.3)
>>> float(sd.max(sd.abs(fast.fittedvalues - r.fittedvalues)))
0.022921475909362554
```

기본은 0이라 모든 점에서 맞춰요. 곡선이 `delta` 길이 안에서 거의 직선이면 차이가 작아요.

| `nobs` | 맞춤에 든 점의 수 |
| `df` | 유효 자유도. 곡선이 자료를 얼마나 따라가는지를 매개변수의 수처럼 센 값 |
| `leverage` | 점마다 자기 값이 자기 적합값에 주는 무게 |
| `scale` | 잔차 척도 $\sqrt{\sum w_i r_i^2 / (\mathit{nobs} - \mathit{df})}$ |
| `frac`, `k`, `it`, `delta` | 받은 값과 창의 점 수 |
| `robust_weights` | 마지막 반복의 강건 무게 (n,). `it=0`이면 모두 1 |

```python
>>> print(r.summary())
                                Lowess Results
==============================================================================
Method:                         LOWESS  Frac:                           0.3000
No. Observations:                   60  Window points:                      18
Df (effective):                  6.926  Robust iterations:                   3
Scale:                          0.3149  Delta:                           0.000
==============================================================================
```

## 새 점의 값: `predict`

`predict(x_new)`는 새 점마다 자료에서 가장 가까운 $k$개로 같은 국소 직선을 맞춰요. 강건 무게는 맞출 때의 마지막 것을 그대로 써요. 자료 범위 밖도 계산하고, 그때는 끝 창의 직선을 늘인 값이에요. 어떤 모양의 배열이든 받아 같은 모양으로 돌려주고, 수 하나는 float예요.

```python
>>> r.predict(4.25)
-0.7754687618381602
>>> r.predict([[1.0, 2.0], [3.0, 4.0]]).shape
(2, 2)
>>> r.predict([-1.0, 11.0])
array([-0.24226233066917754,  -0.9442867039177942], dtype=float64)
>>> r.predict(float('nan'))
nan
```

`predict`를 자료점에서 부르면 `fittedvalues`와 같은 값이에요.

```python
>>> bool(sd.all(r.predict(x) == r.fittedvalues))
True
```

## 곡선의 구간: `predict_interval`

`predict_interval(x_new, alpha=0.05)`은 곡선 값의 점별 신뢰 구간 (m, 2)이에요. 같은 자리에서 자료를 다시 뽑아 다시 맞추면 곡선 값이 얼마나 흔들리는지를 나타내요. 곡선의 편향은 넣지 않아요. 계산법은 [결과 객체 읽기](/api/smooth/results/)에 있어요.

```python
>>> r.predict_interval([2.0, 5.0, 8.0])
array([[ 0.5443433995290277,  0.9029590724462604],
       [-1.1132454071594622, -0.7671366708058841],
       [ 0.5459660448484976,  1.0210575917045475]], dtype=float64)
>>> r.predict_interval([5.0], alpha=0.5)
array([[-0.9987887161334966, -0.8815933618318496]], dtype=float64)
```

강건 반복을 한 적합의 구간은 마지막 강건 무게를 고정된 것으로 본 어림이에요.

## 무게와 NaN

`weights`는 점마다의 무게예요. 무게가 2인 점은 같은 점이 두 번 있는 것처럼 국소 적합에 들어가요. 0인 점은 맞춤에 들지 않지만 그 자리의 `fittedvalues`는 계산하고, `nobs`, `df`에서 빠지며 `leverage`가 0이에요.

```python
>>> w = sd.ones(60)
>>> w[:10] = 0.0
>>> rw = sd.smooth.lowess(x, y, frac=0.3, weights=w)
>>> rw.nobs, float(rw.leverage[0]), float(rw.fittedvalues[0])
(50, 0.0, 2.853514154245931)
>>> sd.smooth.lowess(x, y, weights=-w)
Traceback (most recent call last):
    ...
ValueError: lowess(): 'weights' must be >= 0
```

NaN은 `nan_policy`가 정해요. 기본 `'propagate'`는 NaN이 하나라도 있으면 결과의 값이 모두 NaN이라 빠뜨린 것을 놓치지 않아요. `'omit'`은 그 점을 빼고 맞추고 그 자리를 NaN으로 둬요. ±inf는 언제나 에러예요.

```python
>>> yn = y.copy()
>>> yn[5] = float('nan')
>>> sd.smooth.lowess(x, yn).fittedvalues[:3]
array([nan, nan, nan], dtype=float64)
>>> ro = sd.smooth.lowess(x, yn, frac=0.3, nan_policy='omit')
>>> ro.nobs, ro.fittedvalues[4:7]
(59, array([0.4871154106180544,                nan, 0.6026096075197619], dtype=float64))
>>> sd.smooth.lowess(x, yn, nan_policy='raise')
Traceback (most recent call last):
    ...
ValueError: lowess(): the input contains NaN (nan_policy='raise')
>>> yn[5] = float('inf')
>>> sd.smooth.lowess(x, yn, nan_policy='omit')
Traceback (most recent call last):
    ...
ValueError: lowess(): 'y' contains infinity
```

## 퇴화한 창

- 창의 점이 모두 같은 x이면 직선이 정해지지 않아서 그 점들의 무게 평균을 써요. 이 판정은 x의 단위와 무관해요. x에 2의 거듭제곱을 곱하면(`delta`도 함께) 같은 비트가 나와요.
- 양수 무게의 점이 둘보다 적은 창에서는 그 자료점의 값이 `y` 그대로이고, `predict`에서는 NaN이에요. 강건 무게가 거의 모두 0이 되었거나, 창의 다른 점이 모두 거리 $h$에 있어 무게가 0일 때예요.

아래 둘째 예에서 $k = 2$예요. x = 1의 세 점은 창이 모두 x = 1이라 무게 평균 2가 되고, x = 2의 점은 창의 다른 점이 거리 $h$에 있어 무게가 0이라 자기 값 9가 그대로 남아요.

```python
>>> rs = sd.smooth.lowess(x * 2.0**-40, y, frac=0.3)
>>> bool(sd.all(rs.fittedvalues == r.fittedvalues))
True
>>> sd.smooth.lowess([1.0, 1.0, 1.0, 2.0], [1.0, 2.0, 3.0, 9.0], frac=0.5, it=0).fittedvalues
array([2.0, 2.0, 2.0, 9.0], dtype=float64)
```

### 인자 순서는 (x, y)

가로축이 먼저예요. 순서를 바꿔 주면 에러 없이 다른 곡선이 나오니 조심해요.

### 같은 비트

같은 입력이면 스레드 수와 상관없이 같은 비트예요. 반복도 고정이고 합의 순서도 정렬한 자료의 순서로 정해져 있어요.

## statsmodels·R을 아는 분께

- 인자 순서가 (x, y)예요. statsmodels의 `lowess(endog, exog)`는 (y, x)예요. 결과는 정렬한 (n, 2) 표가 아니라 `LowessResult`이고 배열은 입력의 순서예요. 정렬된 표가 필요하면 x로 정렬해 만들어요. `xvals`는 `predict(x_new)`, `missing`은 `nan_policy`예요. `is_sorted`, `return_sorted`는 없어요.
- statsmodels는 NaN이 있는 점을 조용히 빼서 결과의 줄 수가 줄어요. sd의 기본은 모든 값이 NaN이고, 빼려면 `nan_policy='omit'`을 줘요.
- 창의 점 수 `int(frac·n + 1e-10)`, tricube와 bisquare 무게, 강건 무게의 식, `delta`의 건너뛰기 규칙은 statsmodels와 같아요. 다른 곳은 퇴화한 창의 판정이에요. statsmodels는 무게 붙은 제곱합을 절댓값 $10^{-12}$로 막아서 x의 단위를 바꾸면 값이 달라져요(시험 자료에서 x에 $10^{-8}$을 곱하면 `frac=0.1, it=0`의 적합이 0.34 달라져요). sd는 양수 무게의 점이 모두 같은 x일 때만 국소 평균으로 바꿔요.
- R의 `lowess(x, y, f, iter, delta)`와 인자 순서가 같아요. 다른 곳은 셋이에요. R은 거리가 $0.001h$ 이하인 점의 무게를 1로, $0.999h$ 이상을 0으로 자르는데 sd는 자르지 않아서 적합값이 $10^{-9}$ 크기로 달라요. R은 잔차가 아주 작아지면 반복을 일찍 멈추지만 sd는 언제나 `it`번이에요. `delta`의 기본이 R은 x 범위의 0.01배, sd는 0이에요.
