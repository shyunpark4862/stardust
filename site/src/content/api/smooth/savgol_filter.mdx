## 한눈에 보기

고른 간격으로 잰 신호(분광 스펙트럼, 센서 값)에 섞인 잡음을 줄이는 가장 쉬운 방법은 이동 평균이에요. 그런데 이동 평균은 봉우리를 낮추고 넓혀요. **Savitzky–Golay** 필터는 창마다 낮은 차수의 다항식을 최소제곱으로 맞추고 그 다항식의 가운데 값을 써요. 2차나 3차 다항식은 봉우리의 굽은 모양을 따라갈 수 있어서 높이를 덜 깎아요.

```python
>>> import stardust as sd
>>> t = sd.linspace(0, 10, 201)
>>> peak = sd.exp(-((t - 5.0) / 0.4) ** 2)
>>> rng = sd.random.default_rng(5)
>>> sig = peak + sd.stats.Normal(sigma=0.05).sample(201, rng=rng)
>>> sm = sd.smooth.savgol_filter(sig, 21, 3)
>>> sm.shape
(201,)
>>> float(sd.max(peak)), round(float(sd.max(sm)), 4)
(1.0, 0.9378)
>>> box = sd.smooth.savgol_filter(sig, 21, 0)
>>> round(float(sd.max(box)), 4)
0.6234
```

`polyorder=0`은 창의 평균, 곧 이동 평균이에요. 같은 창에서 3차 필터는 봉우리를 조금(1에서 0.94로) 깎지만 이동 평균은 0.62로 크게 깎아요.

## 필터의 계수: `savgol_coeffs`

창 안의 점이 고른 간격이면, 다항식을 맞춰 가운데 값을 읽는 일은 창의 값에 정해진 계수를 곱해 더하는 일과 같아요. 그래서 이 필터는 선형 필터이고, 계수는 창의 길이와 차수로만 정해져요.

```python
>>> sd.smooth.savgol_coeffs(5, 2)
array([-0.08571428571428572,  0.34285714285714286,   0.4857142857142857,
        0.34285714285714286, -0.08571428571428572], dtype=float64)
>>> sd.smooth.savgol_coeffs(5, 2) * 35
array([-3.0, 12.0, 17.0, 12.0, -3.0], dtype=float64)
>>> float(sd.sum(sd.smooth.savgol_coeffs(5, 2)))
1.0000000000000002
```

창 5, 2차의 계수는 $(-3, 12, 17, 12, -3)/35$예요. 합이 1이라 상수 신호를 그대로 두고, 2차 이하의 다항식 신호도 그대로 돌려줘요.

```python
>>> q = 0.5 * t ** 2 - 3 * t + 1
>>> float(sd.max(sd.abs(sd.smooth.savgol_filter(q, 11, 2) - q)))
7.105427357601002e-15
```

`pos`는 창 안에서 값을 읽을 자리예요(기본은 가운데). `use='conv'`(기본)는 합성곱에 바로 쓰도록 뒤집은 순서, `'dot'`은 창의 순서 그대로예요. 가운데 자리의 계수는 대칭이라 두 순서가 같아요.

```python
>>> sd.smooth.savgol_coeffs(5, 2, pos=0, use='dot')
array([  0.8857142857142857,   0.2571428571428571, -0.08571428571428572,
       -0.14285714285714285,  0.08571428571428572], dtype=float64)
>>> sd.smooth.savgol_coeffs(5, 2, pos=0)
array([ 0.08571428571428572, -0.14285714285714285, -0.08571428571428572,
         0.2571428571428571,   0.8857142857142857], dtype=float64)
```

### 계수는 정확해요

계수는 창의 점에서 정규직교인 이산 다항식(Gram 다항식)으로 만들어요. 계수마다 거의 두 배 정밀도로 계산해 한 번만 반올림해서, 정확한 유리수 계수와의 차가 가장 큰 계수의 $8u$ 이하예요($u = 2^{-53}$). 창이 1001점까지라면 차수가 아무리 높아도 이 약속이 서요.

```python
>>> c = sd.smooth.savgol_coeffs(101, 30)
>>> float(sd.sum(c))
0.9999999999999998
>>> c[50]
0.2019354048157915
```

## 도함수: `deriv`와 `delta`

맞춘 다항식의 도함수를 읽으면 잡음이 덜 증폭된 미분이 돼요. `delta`는 표본 간격이고 $\mathit{deriv}$차 도함수를 $\mathit{delta}^{\mathit{deriv}}$로 나눠요.

```python
>>> dt = float(t[1] - t[0])
>>> d1 = sd.smooth.savgol_filter(sig, 21, 3, deriv=1, delta=dt)
>>> true = -2 * (t - 5.0) / 0.16 * peak
>>> round(float(d1[90]), 3), round(float(true[90]), 3)
(1.404, 1.31)
>>> sd.smooth.savgol_coeffs(5, 2, deriv=1)
array([ 0.2,  0.1,  0.0, -0.1, -0.2], dtype=float64)
>>> sd.smooth.savgol_filter(sig, 5, 2, deriv=3)[:3]
array([0.0, 0.0, 0.0], dtype=float64)
```

`deriv`가 `polyorder`보다 크면 다항식의 그 도함수가 0이라 결과가 0이에요(창에 NaN이나 inf가 있는 자리는 NaN).

## 끝 처리: `mode`

창이 신호 끝을 넘는 자리는 `mode`가 정해요.

| `mode` | 창 밖의 값 |
|---|---|
| `'interp'`(기본) | 끝의 `window_length // 2`점은 끝 창 전체에 맞춘 다항식의 값 |
| `'mirror'` | 끝점을 되풀이하지 않고 거울처럼 접은 값 |
| `'nearest'` | 끝값을 되풀이 |
| `'constant'` | `cval` |
| `'wrap'` | 반대쪽 끝에서 이어진 값(주기) |

```python
>>> s5 = sd.asarray([1.0, 2.0, 4.0, 7.0, 11.0, 16.0, 22.0])
>>> for m in ('interp', 'mirror', 'nearest', 'constant', 'wrap'):
...     print(m, sd.smooth.savgol_filter(s5, 5, 2, mode=m)[:2])
interp [1.0 2.0]
mirror [1.1714285714285713 1.9142857142857141]
nearest [1.0857142857142859                2.0]
constant [0.8285714285714286  2.085714285714286]
wrap [  7.000000000000001 0.20000000000000015]
```

`s5`는 2차 수열이라 `'interp'`가 끝까지 그대로 돌려줘요. 다른 `mode`는 창 밖을 지어낸 값으로 채워서 끝이 조금 달라져요. `'interp'`은 창이 축보다 길면 쓸 수 없고, 다른 `mode`는 창이 축보다 길어도 돼요.

```python
>>> sd.smooth.savgol_filter(s5, 9, 2)
Traceback (most recent call last):
    ...
ValueError: savgol_filter(): 'window_length' must not exceed the length of the axis for mode 'interp' (9 > 7)
>>> sd.smooth.savgol_filter(s5, 9, 2, mode='nearest')
array([1.1948051948051948,  2.212121212121212,  4.090909090909091,
        7.636363636363637,  11.93939393939394,  16.09090909090909,
       19.467532467532468], dtype=float64)
```

## 여러 줄과 복소수

`x`가 2차원 이상이면 `axis` 축을 따라 줄마다 걸러요. 한 줄의 결과는 그 줄만 거른 것과 같은 비트예요. 복소수는 실수부와 허수부를 따로 걸러요.

```python
>>> M = sd.stack([sig, 2 * sig], axis=0)
>>> R = sd.smooth.savgol_filter(M, 21, 3)
>>> bool(sd.all(R[1] == sd.smooth.savgol_filter(2 * sig, 21, 3)))
True
>>> sd.smooth.savgol_filter(M.T, 21, 3, axis=0).shape
(201, 2)
>>> sd.smooth.savgol_filter(s5 + 1j * s5, 5, 2)[:2]
array([(1+1j), (2+2j)], dtype=complex128)
```

## NaN과 에러

NaN은 그 점이 든 창의 출력으로 번져요. 창 하나의 출력은 그 창의 값과 계수만으로 정해져서, 다른 자리에는 닿지 않아요.

```python
>>> sn = s5.copy()
>>> sn[3] = float('nan')
>>> sd.smooth.savgol_filter(sn, 3, 1, mode='nearest')
array([1.3333333333333333,  2.333333333333333,                nan,
                      nan,                nan, 16.333333333333332,
                     20.0], dtype=float64)
```

```python
>>> sd.smooth.savgol_filter(s5, 5, 5)
Traceback (most recent call last):
    ...
ValueError: savgol_filter(): 'polyorder' must be less than 'window_length' (5 >= 5)
>>> sd.smooth.savgol_coeffs(5, 2, pos=2.0)
Traceback (most recent call last):
    ...
TypeError: savgol_coeffs(): 'pos' must be an int, not float
>>> sd.smooth.savgol_coeffs(5, 2, delta=0.0)
Traceback (most recent call last):
    ...
ValueError: savgol_coeffs(): 'delta' must be finite and nonzero, not 0.0
>>> sd.smooth.savgol_filter(s5, 5, 2, mode='reflect')
Traceback (most recent call last):
    ...
ValueError: savgol_filter(): 'mode' must be 'interp', 'mirror', 'nearest', 'constant' or 'wrap', not 'reflect'
```

같은 입력이면 스레드 수와 배열의 배치에 상관없이 같은 비트예요.

## scipy를 아는 분께

- `scipy.signal.savgol_filter`, `savgol_coeffs`와 같은 뜻이에요. `window_length`, `polyorder`는 자리로, 나머지는 이름으로만 받아요.
- **계수가 정확해요.** scipy는 Vandermonde 행렬의 최소제곱으로 계수를 구해서 차수가 높으면 에러도 경고도 없이 다른 필터가 돼요(`savgol_coeffs(101, 8)`의 합이 $1 + 8.9 \times 10^{-4}$이고, `(101, 10)`, `(51, 45)`, `(301, 30)`은 계수 전체가 틀려요).
- 복소수 입력은 실수부와 허수부를 따로 거른 complex128이에요. scipy는 경고와 함께 허수부를 버려요.
- NaN은 어느 `mode`에서나 창으로 번져요. scipy의 `'interp'`는 끝 창에 NaN이 있으면 `ValueError`예요.
- 음수 `deriv`, 0이거나 유한하지 않은 `delta`는 `ValueError`예요(scipy는 조용히 다른 값을 내요). float의 `pos`는 `TypeError`예요(scipy는 받아요).
- numpy의 float32 입력도 float64로 계산해 float64를 돌려줘요(scipy는 float32를 돌려줘요).
