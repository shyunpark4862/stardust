## 한눈에 보기

**평활 스플라인**은 자료를 정확히 지나지 않고 자료 가까이를 매끄럽게 지나는 곡선이에요. 곡선 $f$가 다음 값을 가장 작게 하도록 골라요.

$$
\sum_i w_i \bigl(y_i - f(x_i)\bigr)^2 + \lambda \int f''(x)^2\,dx
$$

앞 항은 자료에서 얼마나 떨어졌는지, 뒤 항은 곡선이 얼마나 굽었는지예요. $\lambda$가 작으면 자료를 따라가 출렁이고, 크면 곧게 펴져요. 이 문제의 답은 언제나 서로 다른 x마다 매듭을 둔 **자연 3차 스플라인**(양 끝 밖에서 직선으로 이어지는 3차 스플라인)이에요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> x = sd.sort(rng.random(60)) * 10
>>> y = sd.sin(x) + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> r = sd.smooth.smoothing_spline(x, y)
>>> r
SmoothingSplineResult(nobs=60, df=8.40871, lam=0.277509)
>>> r.spline
BSpline(degree=3, knots=66, extrapolate=True)
>>> r.predict([2.0, 5.0, 8.0])
array([ 0.8426530367536844, -1.0307640993835183,   0.856301319630272], dtype=float64)
>>> r.spline([2.0, 5.0, 8.0])
array([ 0.8426530367536844, -1.0307640993835183,   0.856301319630272], dtype=float64)
```

$\lambda$를 주지 않으면 GCV로 골라요. 결과의 `spline`은 [`sd.interpolate.BSpline`](/api/interpolate/BSpline/)이라 도함수와 적분도 그대로 돼요.

```python
>>> r.spline.derivative()(5.0)
0.2200246431370707
>>> r.spline.integrate(0.0, 10.0)
1.2509144326499
```

## λ 정하기

세 가지 길이 있어요. 하나만 줘요.

### 직접 주기: `lam`

```python
>>> for lam in (0.0, 0.01, 1.0, 100.0, float('inf')):
...     rl = sd.smooth.smoothing_spline(x, y, lam=lam)
...     print(lam, round(rl.df, 3), round(float(rl.scale), 4))
0.0 60.0 nan
0.01 16.775 0.2785
1.0 6.429 0.3066
100.0 2.745 0.6906
inf 2.0 0.7684
```

- $\lambda = 0$은 모든 점을 지나는 자연 3차 보간 스플라인이에요. [`make_interp_spline(bc_type='natural')`](/api/interpolate/make_interp_spline/)과 같은 비트예요.
- $\lambda = \infty$는 굽음을 전혀 허락하지 않아 무게 붙은 최소제곱 직선이에요.

$\lambda$의 단위는 x의 단위의 세제곱에 비례해요. x를 10배로 늘리면 같은 곡선을 내는 $\lambda$는 1000배예요. 그래서 $\lambda$의 크기 자체보다 아래의 `df`나 기준으로 정하는 편이 쉬워요.

```python
>>> r1 = sd.smooth.smoothing_spline(x, y, lam=0.5)
>>> r10 = sd.smooth.smoothing_spline(x * 10, y, lam=500.0)
>>> float(sd.max(sd.abs(r1.fittedvalues - r10.fittedvalues)))
5.88418203051333e-15
```

### 자유도로 주기: `df`

`df`는 유효 자유도예요. 곡선이 매개변수 몇 개만큼 자유로운지를 뜻해요(직선이 2, 보간이 서로 다른 x의 수). `df=6`이면 대략 5차 다항식만큼의 자유를 주는 셈이에요. 그 자유도가 되는 $\lambda$를 찾아요.

```python
>>> rd = sd.smooth.smoothing_spline(x, y, df=6)
>>> round(rd.df, 8), rd.lam
(6.0, 1.4055756320414339)
>>> sd.smooth.smoothing_spline(x, y, df=2)
Traceback (most recent call last):
    ...
ValueError: smoothing_spline(): 'df' must be in (2, 60] (the distinct x of positive weight), not 2.0
>>> sd.smooth.smoothing_spline(x, y, df=6, lam=1.0)
Traceback (most recent call last):
    ...
ValueError: smoothing_spline(): give 'lam' or 'df', not both
```

### 기준으로 고르기: `criterion`

$\lambda$도 `df`도 주지 않으면 기준을 가장 작게 하는 $\lambda$를 골라요.

- `'gcv'`(기본): 일반화 교차검증 $n \cdot \mathrm{RSS}_w / (n - \mathrm{tr}\,L)^2$.
- `'cv'`: 하나씩 빼는 교차검증 $\frac{1}{n}\sum_i w_i \bigl((y_i - \hat f_i)/(1 - L_{ii})\bigr)^2$.

$L$은 자료를 적합값으로 보내는 모자 행렬, $\mathrm{tr}\,L$이 `df`예요. 두 기준 모두 "점 하나를 빼고 맞췄을 때 그 점을 얼마나 잘 맞히는가"를 재서, 잡음까지 따라가는 $\lambda$와 추세를 놓치는 $\lambda$를 둘 다 벌줘요.

```python
>>> rc = sd.smooth.smoothing_spline(x, y, criterion='cv')
>>> rc.lam, r.lam
(0.24602804698927133, 0.2775091412414661)
>>> round(r.gcv, 6), round(r.cv, 6), r.criterion, r.status, r.converged
(0.095128, 0.094883, 'gcv', 0, True)
```

결과에는 고르지 않은 기준의 값도 있어요. 찾기는 x, y, 무게의 단위와 무관한 고정 구간에서 해요. 구간 안 격자 53점에서 기준을 재고, 가장 작은 점 둘레를 Brent 방법으로 다듬어요. 기준이 가장 작은 곳이 구간의 끝이면 그 끝이 답이고 `converged=False`예요. `status`는 $-1$(작은 $\lambda$의 끝, 보간 쪽)이나 $1$(큰 $\lambda$의 끝, 직선 쪽)이에요. 직선에 가까운 자료가 그런 예예요.

```python
>>> yl = 2 * x + sd.stats.Normal(sigma=0.3).sample(60, rng=rng)
>>> rl = sd.smooth.smoothing_spline(x, yl)
>>> rl.status, rl.converged, round(rl.df, 4)
(1, False, 2.1567)
```

이것은 에러가 아니에요. 고른 곡선은 그 끝의 곡선이고, 위 경우는 직선이에요.

## 여러 열: `axis`

`y`가 2차원 이상이면 `axis` 축이 x와 짝이고 나머지 축의 열을 같은 분해로 함께 풀어요. $\lambda$를 고를 때는 모든 열의 기준을 더한 값으로 $\lambda$ 하나를 골라요. 열마다 따로 고르려면 열마다 불러요. `scale`은 열마다, `gcv`·`cv`는 열의 합이에요.

```python
>>> Y = sd.stack([y, 2 * y], axis=1)
>>> rb = sd.smooth.smoothing_spline(x, Y)
>>> rb.fittedvalues.shape, rb.scale, rb.lam
((60, 2), array([0.2860000994925745,  0.572000198985149], dtype=float64), 0.27750914126957343)
>>> rb.predict(5.0)
array([-1.030764099378159, -2.061528198756318], dtype=float64)
```

## 무게와 NaN

`weights`는 점마다의 무게이고 잔차 제곱합이 $\sum w_i r_i^2$이에요. 0인 점은 맞춤에 들지 않아요. NaN은 `nan_policy`를 따라요. `'propagate'`의 `spline`은 어디서나 NaN을 내요.

```python
>>> yn = y.copy()
>>> yn[3] = float('nan')
>>> rn = sd.smooth.smoothing_spline(x, yn)
>>> rn.df, rn.spline(5.0)
(nan, nan)
>>> sd.smooth.smoothing_spline(x, yn, nan_policy='omit').nobs
59
```

## scipy·R을 아는 분께

- scipy의 `make_smoothing_spline(x, y, w, lam)`과 같은 문제, 같은 매듭, 같은 $\lambda$의 단위예요. 그 함수도 [`make_smoothing_spline`](/api/smooth/make_smoothing_spline/)으로 있어요. `smoothing_spline`은 거기에 기준과 진단을 더한 것이에요.
- scipy는 GCV의 $\lambda$를 $(0, n)$에서 찾아서 x의 단위가 바뀌면 다른 곡선을 골라요(시험 자료에서 x에 0.01, 10, 100, 1000을 곱하면 고른 곡선이 1.20, 0.038, 0.39, 0.71만큼 달라졌어요). sd의 찾기는 단위와 무관해요. scipy는 $n = 10^4$의 고르지 않은 x에서 `ValueError`를 내지만 sd는 풀어요.
- scipy는 $\lambda = \infty$, 같은 x, 정렬되지 않은 x를 받지 않아요. sd는 받아요.
- R의 `smooth.spline`과는 $\lambda$의 눈금이 달라요. R은 x를 [0, 1]로 옮기고 무게를 평균 1로 맞춘 문제의 $\lambda$라서 $\lambda_{\mathrm{sd}} = \lambda_R \cdot (x_n - x_1)^3 \cdot (\sum w / n)$이에요. `smooth.spline(all.knots=TRUE, lambda=…)`와 같은 곡선이에요. R의 `spar`는 없어요(자료에 달린 다른 눈금이에요). `cv=TRUE`는 `criterion='cv'`, `df`는 같은 뜻이에요.
- R의 기본(`all.knots=FALSE`)은 점이 50개를 넘으면 매듭을 줄여요. 그와 비슷한 일은 [`pspline`](/api/smooth/pspline/)이 해요.
