## 한눈에 보기

`scatter3d(x, y, z)`는 점 $(x_i, y_i, z_i)$를 3D 칸에 찍어요. 2D의 [`scatter`](/api/plot/scatter/)에 좌표 하나를 더한 판이에요. 아래는 정규분포에서 뽑은 두 무리의 점 150개씩이에요.

```python
>>> rng = sd.random.default_rng(7)
>>> a = sd.stats.Normal().sample((3, 150), rng=rng)
>>> b = sd.stats.Normal(mu=2.5, sigma=0.6).sample((3, 150), rng=rng)
>>> x, y, z = (sd.concat([a[i], b[i]]) for i in range(3))
>>> kind = ["A"] * 150 + ["B"] * 150
>>> fig = sd.plot.scatter3d(x, y, z, group=kind)
```

점은 화면을 향한 둥근 원이에요. 깊이를 견줘 찍으므로 가까운 점이 먼 점을 가려요. 곡면이나 곡선([`curve3d`](/api/plot/curve3d/))과 함께 그려도 같아요. 뒤에 있는 점은 가려지고 앞에 있는 점은 그 위에 보여요.

## 자료 넘기기

좌표는 수의 시퀀스, `sd.ndarray`, numpy 배열, frame의 `Series`예요. 셋의 길이가 같아야 해요. 표의 열을 쓸 때는 `data=`에 `DataFrame`을 주고 좌표 자리에 열 이름을 써요. `group=`도 열 이름일 수 있어요.

```python
>>> df = sd.frame.DataFrame({"x": [1.0, 2.0, 3.0, 4.0], "y": [2.0, 1.0, 0.0, 1.0],
...                          "z": [0.0, 1.0, 4.0, 2.0], "kind": ["a", "b", "a", "b"]})
>>> fig = sd.plot.scatter3d("x", "y", "z", data=df, group="kind")
```

`data=` 없이 문자열을 주면 에러예요.

```python
>>> sd.plot.scatter3d("x", "y", "z")
Traceback (most recent call last):
    ...
TypeError: scatter3d(): 'x' is a column name ('x'), which needs 'data'
```

좌표 가운데 하나라도 NaN인 점은 찍지 않아요. 축의 범위는 유한한 좌표로만 잡아요. 곡면이 없는 칸의 상자는 2D 그림처럼 자료의 범위를 4%씩 넓혀서, 가장 바깥의 점이 상자의 모서리와 눈금 위에 놓이지 않아요.

## 색, 크기, 범례

- `color`를 주지 않으면 모든 점이 팔레트의 다음 색이에요. `group=`을 주면 무리마다 팔레트의 색을 차례로 받아요. 둘을 함께 줄 수는 없어요.
- `size`는 점의 지름(pt)이에요. 기본은 테마의 점 크기 3.8 pt예요.

```python
>>> sd.plot.scatter3d([1.0, 2.0], [1.0, 2.0], [1.0, 2.0], group=["a", "b"], color="red")
Traceback (most recent call last):
    ...
ValueError: scatter3d(): 'color' and 'group' cannot both be given (a group takes the palette's colours)
```

범례는 두 가지로 생겨요. `group=`을 주면 무리의 값이 이름이 되고, 무리 없이 `label=`을 주면 그 이름이 돼요. 범례는 상자를 가리지 않게 상자의 오른쪽 밖에 서요. 여러 번 나눠 찍은 점들에 이름을 붙일 때 `label`을 써요.

```python
>>> fig = sd.plot.scatter3d(a[0], a[1], a[2], label="control")
>>> fig = fig.scatter3d(b[0], b[1], b[2], label="treated")
```

`group`과 `label`을 함께 줄 수는 없어요. 범례가 필요 없으면 `fig.legend(loc=None)`으로 없애요.

```python
>>> sd.plot.scatter3d([1.0, 2.0], [1.0, 2.0], [1.0, 2.0], group=["a", "b"], label="x")
Traceback (most recent call last):
    ...
ValueError: scatter3d(): 'label' and 'group' cannot both be given (a group is named by its value)
```

2D의 `scatter`가 받는 점의 꼴(`shape`)과 불투명도(`alpha`)는 받지 않아요. 점은 언제나 둥근 원이에요.

## 상자와 시점

점만 든 칸의 상자는 자료의 비율을 따라요. 세 축에서 자료의 한 단위가 같은 길이라서, 거리를 눈으로 견줄 수 있어요. 한 좌표의 범위가 다른 좌표보다 아주 좁으면 상자가 그만큼 납작해요. 단위가 서로 다른 좌표(키, 몸무게, 나이)를 찍을 때는 미리 표준화하면 상자가 고르게 서요.

시점을 주지 않으면 점들이 화면에 가장 넓게 퍼지는 방향을 골라요. 평면에 가깝게 모인 점 구름을 그 평면과 나란한 방향에서 봐서 한 줄로 겹쳐 보이게 하는 일이 없어요. 시점 고르기의 자세한 규칙은 [3D 칸과 시점](/api/plot/view3d/#시점-azimuth와-elevation)에 있어요.

## 다른 층과 겹치기

곡면 위에 자료의 점을 찍어 맞춘 모양과 견줄 수 있어요. 메서드로 더하면 한 상자 안에 들어가요.

```python
>>> xs = [-0.8, -0.3, 0.1, 0.5, 0.9, -0.6, 0.7]
>>> ys = [0.2, -0.7, 0.4, -0.2, 0.8, 0.9, -0.5]
>>> zs = [x * y + 0.1 for x, y in zip(xs, ys)]
>>> fig = sd.plot.surface(lambda x, y: x * y, -1, 1, -1, 1, alpha=0.5)
>>> fig = fig.scatter3d(xs, ys, zs, color="black", size=4)
```

반투명한 곡면 뒤의 점은 곡면을 통해 비쳐 보여요. 시점은 첫 층(여기서는 곡면)이 정하고, 상자는 곡면이 든 칸이라 그래프의 비율이에요.

## matplotlib을 아는 분께

- matplotlib의 `ax.scatter(x, y, z)`는 점을 깊이로 정렬하지 않고 준 순서로 찍어서, 무리를 나눠 여러 번 부르면 뒤의 무리가 앞의 무리를 덮어요. `scatter3d`는 점마다 깊이를 견줘요.
- matplotlib의 `depthshade`(먼 점을 옅게)는 없어요. 점의 색은 거리와 무관하게 같아요.
- `s=`(넓이, pt²) 대신 `size=`(지름, pt)예요. `c=`로 값에 따라 칠하는 꼴은 없고, 무리는 `group=`이에요. `ax.legend()`를 따로 부르지 않아도 무리나 `label`이 있으면 범례가 서요.
