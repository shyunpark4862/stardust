## 무엇을 하나요

`bar(x, height)`는 자리 `x`마다 0에서 `height`까지의 막대를 세워요. `x`가 문자열이면 범주 축이에요. 범주는 처음 나온 차례로 왼쪽부터 놓이고, 눈금 라벨이 범주의 이름이에요.

막대는 그 색을 옅게 한 채움에 그 색의 가는 테두리로 그려요. 값의 축은 0에서 시작해요. 막대의 바닥이 0이므로 0 아래로 여유를 두지 않아요.

무리를 나란히 세우거나 쌓고, 막대 끝에 오차 막대와 값의 숫자를 얹는 일까지 `bar` 하나가 해요.

```python
>>> import stardust as sd
>>> fig = sd.plot.bar(["control", "low", "mid", "high"], [3.1, 4.2, 6.5, 7.9])
>>> fig = fig.xlabel("dose").ylabel("response (a.u.)")
```

## 무리를 나란히: group과 gap

`group=`을 주면 한 자리에 무리의 막대가 나란히 서요. 무리마다 팔레트의 색을 받고 범례가 생겨요. 한 자리의 막대들이 모두 합쳐 `width` 안에 들어가요.

```python
>>> doses = ["control", "low", "mid", "high"] * 2
>>> response = [3.1, 4.2, 6.5, 7.9, 2.2, 3.9, 5.1, 8.8]
>>> year = ["2024"] * 4 + ["2025"] * 4
>>> fig = sd.plot.bar(doses, response, group=year)
>>> fig = fig.ylabel("response (a.u.)")
```

<PlotImage name="bar-group" alt="네 범주마다 2024년(파랑)과 2025년(노랑) 막대 두 개가 좁은 틈을 두고 나란히 선 막대그림. 왼쪽 위에 범례가 있어요." caption="group의 무리 둘이 한 범주의 자리에 나란히 섰어요. 범주는 처음 나온 차례로, 무리도 처음 나온 차례로 놓여요." />

무리가 $k$개면 막대 하나가 받는 너비는 `width / k`예요. 막대는 그 가운데 `gap`의 몫을 틈으로 비우고 나머지를 채워요. 기본값 0.1이면 받은 너비의 90%가 막대예요. `gap=0`이면 한 자리의 막대들이 서로 붙고, 값을 키우면 막대가 가늘어져요.

긴 꼴의 표라면 `data=`와 열 이름으로 같은 그림을 그려요.

```python
>>> df = sd.frame.DataFrame({"dose": doses, "response": response, "year": year})
>>> fig = sd.plot.bar("dose", "response", data=df, group="year", gap=0.25)
```

## 쌓기: stack

`stack=True`면 무리의 막대를 나란히 세우는 대신 한 자리에 쌓아요. 무리의 차례대로 아래에서부터 올라가고, 막대 전체의 높이가 무리 값의 합이에요. 전체와 그 구성을 함께 보일 때 써요.

```python
>>> quarter = ["Q1", "Q2", "Q3", "Q4"] * 3
>>> plan = ["basic"] * 4 + ["plus"] * 4 + ["pro"] * 4
>>> sales = [12, 14, 13, 17, 8, 9, 12, 14, 3, 5, 8, 11]
>>> fig = sd.plot.bar(quarter, sales, group=plan, stack=True, annotate=True)
>>> fig = fig.ylabel("sales")
```

<PlotImage name="bar-stack" alt="분기 넷마다 basic(파랑), plus(노랑), pro(회색) 세 조각이 아래에서부터 쌓인 막대. 조각마다 가운데에 값이 적혀 있고 전체 높이가 23에서 42로 커져요. 왼쪽 위에 범례가 있어요." caption="stack=True로 쌓은 막대. annotate=True를 함께 줘서 조각마다 가운데에 값을 적었어요." />

양수와 음수는 따로 쌓여요. 양수 조각은 0에서 위로, 음수 조각은 0에서 아래로 차례로 붙어요. 들어온 것과 나간 것처럼 부호가 다른 양을 한 자리에 그릴 때 0의 선을 사이에 두고 갈라져요.

```python
>>> flow = sd.plot.bar(["A", "B", "C"] * 2, [3.0, 2.0, 4.0, -1.0, -2.5, 1.5],
...                    group=["in"] * 3 + ["out"] * 3, stack=True)
>>> flow = flow.hline(0.0)
```

A와 B에서는 `out`의 음수 조각이 0 아래로 내려가고, C에서는 `out`의 양수 조각이 `in` 위에 올라가요. 쌓을 때는 `gap`을 쓰지 않아요.

## 오차 막대: err

`err=`는 막대 끝에 오차 막대를 얹어요. 막대의 값에서 위아래로 뻗는 길이를 줘요. 길이는 그림이 계산하지 않아요. 표준오차든 신뢰구간의 반폭이든 준 값 그대로예요. 아래는 무리마다 표본 6개의 평균과 표준오차예요.

```python
>>> rng = sd.random.default_rng(11)
>>> N = sd.stats.Normal()
>>> rows = []
>>> for arm, shift in (("placebo", 0.0), ("drug", 1.2)):
...     for week, mu in (("week 1", 3.0), ("week 2", 4.2), ("week 4", 6.1)):
...         s = N.sample(6, rng=rng) * 0.9 + mu + shift
...         rows.append((week, float(sd.mean(s)), float(sd.stats.sem(s)), arm))
>>> df = sd.frame.DataFrame({"week": [r[0] for r in rows], "mean": [r[1] for r in rows],
...                          "sem": [r[2] for r in rows], "arm": [r[3] for r in rows]})
>>> fig = sd.plot.bar("week", "mean", data=df, group="arm", err="sem")
>>> fig = fig.ylabel("mean score")
```

<PlotImage name="bar-err" alt="세 주마다 placebo(파랑)와 drug(노랑) 막대가 나란히 서고, 막대마다 끝에 위아래로 뻗은 검은 오차 막대와 짧은 끝선이 있는 막대그림" caption="err에 표준오차의 열을 줬어요. 오차 막대는 무리마다 제 막대의 가운데에 서고, 값의 축은 오차 막대의 끝까지 들어가게 잡혀요." />

`err`의 꼴은 둘이에요.

| 꼴 | 뜻 |
|---|---|
| 시퀀스 하나(또는 열 이름) | 위아래가 같은 길이 |
| `(아래, 위)` 튜플 | 아래로 뻗는 길이와 위로 뻗는 길이를 따로. 둘 다 시퀀스나 열 이름 |

오차 막대는 축 선과 같은 짙은 잉크색이고 끝에 짧은 끝선이 붙어요. 길이는 0 이상이어야 해요. 구간의 끝 값 $[l_i, u_i]$를 가졌다면 `(h - l, u - h)`를 줘요.

```python
>>> sd.plot.bar(["A", "B"], [2.0, 3.0], err=[-0.5, 0.2])
Traceback (most recent call last):
    ...
ValueError: bar(): 'err' must be >= 0
```

쌓은 막대에는 조각마다의 오차를 얹을 자리가 없어서 `stack=True`와 함께 주면 에러예요.

```python
>>> sd.plot.bar(quarter, sales, group=plan, stack=True, err=[1.0] * 12)
Traceback (most recent call last):
    ...
ValueError: bar(): 'err' cannot be given for stacked bars
```

## 값 적기: annotate

`annotate=True`는 막대마다 그 값을 유효숫자 세 자리로 적어요. 문자열을 주면 Python의 서식 문자열로 읽어요. `'.1f'`는 소수 한 자리, `'.0%'`는 백분율, `',.0f'`는 세 자리마다 쉼표예요.

```python
>>> share = [0.412, 0.273, 0.188, 0.127]
>>> names = ["search", "direct", "social", "email"]
>>> fig = sd.plot.bar(names[::-1], share[::-1], horizontal=True, annotate=".1%",
...                   err=([0.03, 0.02, 0.03, 0.04], [0.02, 0.03, 0.04, 0.05]))
>>> fig = fig.xlabel("share of visits")
```

<PlotImage name="bar-annotate" alt="위에서부터 search, direct, social, email 네 가로 막대. 막대 끝마다 좌우 길이가 다른 오차 막대가 있고 그 오른쪽에 41.2%, 27.3%, 18.8%, 12.7%가 적혀 있어요." caption="가로 막대에 annotate='.1%'로 값을 백분율로 적고, err에 (아래, 위) 튜플을 줬어요. 숫자는 오차 막대의 끝 바깥에 서요." />

숫자가 서는 자리는 이래요.

- 막대의 끝 바깥이에요. 양수 막대는 위(가로 막대면 오른쪽), 음수 막대는 아래(왼쪽)에 적어요.
- 오차 막대가 있으면 그 끝의 바깥으로 물러나요.
- 쌓은 막대는 조각마다 그 가운데에 적어요.

값의 축은 숫자가 들어갈 만큼 조금 더 늘어나요. 값이 NaN인 막대에는 아무것도 적지 않아요. 서식이 수에 맞지 않으면 에러예요.

```python
>>> sd.plot.bar(["A", "B"], [2.0, 3.0], annotate="q")
Traceback (most recent call last):
    ...
ValueError: bar(): 'annotate' is not a format spec for numbers: 'q'
```

## 수의 자리와 음수

`x`가 수면 막대는 그 값의 자리에 서요. 축은 보통의 수 축이고, `width`도 그 축의 단위예요. `height`가 음수인 막대는 0에서 아래로 뻗어요.

```python
>>> years = [float(y) for y in range(2011, 2025)]
>>> anomaly = [-0.12, -0.08, 0.05, -0.02, 0.18, 0.31, 0.12, -0.04, 0.22, 0.35, 0.09, 0.27, 0.41, 0.52]
>>> fig = sd.plot.bar(years, anomaly, width=0.7).hline(0.0, width=0.5)
>>> fig = fig.xlabel("year").ylabel(r"anomaly ($^\circ$C)")
```

<PlotImage name="bar-signed" alt="2011년부터 2024년까지 해마다 막대 하나. 몇 해는 0 아래로, 나머지는 0 위로 뻗고 0에 가는 가로선이 있어요." caption="음수 값의 막대는 0에서 아래로 뻗어요. 0의 기준선은 hline으로 더했어요." />

값이 모두 양수이거나 모두 음수일 때만 축이 0에서 바로 시작하고, 부호가 섞이면 양쪽에 조금씩 여유를 둬요.

## 가로 막대: horizontal

`horizontal=True`면 `x`가 세로 축의 자리, `height`가 가로 축의 값이에요. 이름이 긴 범주는 가로 막대가 읽기 좋아요. 범주는 위에서 아래가 아니라 아래에서 위로 0, 1, 2, …의 자리에 놓이므로, 위에서부터 읽히게 하려면 거꾸로 줘요. 위의 방문 비율 그림이 그렇게 그린 거예요.

```python
>>> names = ["linear algebra", "special functions", "statistics", "optimization", "plotting"]
>>> pages = [41, 63, 88, 37, 52]
>>> fig = sd.plot.bar(names[::-1], pages[::-1], horizontal=True, color="C3")
>>> fig = fig.xlabel("pages")
```

`err`와 `annotate`는 가로 막대에서도 값의 방향을 따라요. 오차 막대는 좌우로 뻗고 숫자는 막대의 오른쪽에 서요.

## 범주의 자리에 다른 층 얹기

범주 축의 자리는 0, 1, 2, …예요. 그래서 수의 `x`를 받는 다른 층을 그 자리의 수로 얹을 수 있어요. 둘째와 셋째 범주 사이의 세로선은 `vline(1.5)`이고, 막대 위의 점은 `scatter([0, 1, 2], ...)`예요.

```python
>>> fig = sd.plot.bar(["A", "B", "C"], [3.4, 4.3, 5.9], width=0.6)
>>> fig = fig.scatter([0, 1, 2], [3.0, 4.6, 5.5], color="black").vline(1.5, style=":")
```

반대로, 범주 축이 생긴 칸에 수의 `x`로 막대를 더하면 어느 범주인지 알 수 없으므로 `ValueError`예요.

```python
>>> fig.bar([0, 1, 2], [1.0, 2.0, 3.0])
```

같은 칸에 범주의 막대를 더 부르면 새 범주는 축의 끝에 붙고, 있는 범주는 제자리에 그려요.

## 로그 축

값의 축을 [로그 척도](/api/plot/customize/)로 바꾸면 0을 그릴 수 없으므로 막대의 바닥이 축의 아래 끝이에요. 0 이하의 값의 막대는 그리지 않아요.

## 조심할 점

- `width`는 막대의 너비(자료의 단위)예요. 선의 굵기나 그림의 너비가 아니에요.
- `err`의 길이는 막대의 값에서 끝까지의 거리예요. 구간의 끝 값을 그대로 넘기지 않게 조심해요.
- 쌓은 막대의 조각이 얇으면 가운데에 적은 숫자가 조각보다 클 수 있어요. 그럴 때는 `annotate`를 빼거나 값이 큰 무리만 따로 적어요.
- 수를 세어 막대로 보이려면 [`histogram`](/api/plot/histogram/)을 써요. 구간과 높이를 `sd.histogram`으로 계산해 줘요.
- 무리 사이의 검정 결과(괄호와 p값)를 막대 위에 얹으려면 [`Figure.compare`](/api/plot/compare/)를 써요.

## matplotlib을 아는 분께

- `plt.bar`와 `plt.barh`가 `bar(..., horizontal=True)` 하나예요.
- 무리의 막대를 나란히 세우려고 자리를 손으로 옮길 필요가 없어요. `group=`이 나눠 줘요. `bottom=`을 손으로 더해 쌓는 대신 `stack=True`예요.
- `yerr=`와 `xerr=` 대신 `err=` 하나예요. 가로 막대에서도 값의 방향으로 뻗어요.
- `ax.bar_label(bars, fmt=...)` 대신 `annotate=`예요.
- 막대의 채움은 색을 옅게 한 것이고 테두리가 그 색이에요. ggplot2의 `geom_col`과 비슷하게 `x`가 문자열이면 범주 축이에요.
