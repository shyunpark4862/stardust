## 한눈에 보기

칸 하나에는 축이 한 벌이에요. 그런데 한 칸에 두 가지를 함께 보이고 싶을 때가 있어요. 단위가 다른 두 양을 같은 가로축 위에 견주거나, 큰 그림의 한 구석을 키워서 같이 보일 때예요. 앞의 것이 `fig.twin()`, 뒤의 것이 `fig.inset()`이에요.

어느 도시의 달마다 강수량(mm)과 평균 기온(°C)을 한 칸에 그려 볼게요. 두 양은 단위도 크기도 달라서 세로축을 따로 써야 해요.

```python
>>> import stardust as sd
>>> month = list(range(1, 13))
>>> rain = [21, 25, 47, 65, 106, 133, 395, 364, 169, 52, 53, 22]
>>> temp = [-2.4, 0.4, 5.7, 12.5, 17.8, 22.2, 24.9, 25.7, 21.2, 14.8, 7.2, 0.4]
>>> fig = sd.plot.bar(month, rain, label="Precipitation")
>>> fig = fig.xlabel("Month").ylabel("Precipitation (mm)")
>>> right = fig.twin()
>>> right = right.line(month, temp, label="Temperature").ylabel(r"Temperature ($^\circ$C)")
```

## 둘째 y축: twin

`fig.twin()`은 칸의 오른쪽에 둘째 y축을 두고, 그 축을 가리키는 **보기**를 돌려줘요. 보기는 `fig`와 같은 그림이에요. 다만 보기에서 부른 메서드가 가는 곳이 달라요.

| 보기 `right = fig.twin()`에서 | 하는 일 |
|---|---|
| 그림 메서드(`right.line`, `right.scatter`, `right.bar`, …) | 오른쪽 축의 눈금으로 그려요 |
| `right.ylabel`, `right.ylim`, `right.yscale`, `right.yticks` | 오른쪽 축의 이름, 범위, 척도, 눈금을 정해요 |
| `right.title`, `right.xlabel`, `right.xlim`, `right.xscale`, `right.xticks`, `right.legend`, `right.inset` | 칸의 것을 정해요. `fig`에서 부른 것과 같아요 |

제목, x축의 이름·범위·눈금, 범례, 작은 그림은 칸에 하나씩이라 어느 쪽에서 불러도 같은 칸의 것을 고쳐요. 그래서 둘째 축을 그린 뒤 이어서 `right.title(...)`이나 `right.legend(...)`를 불러도 돼요. 내보내기(`save`, `to_svg` 등)도 어느 쪽에서 불러도 그림 전체예요.

- **x축은 하나예요.** 가로 범위는 두 축의 층을 모두 덮게 잡혀요.
- **y축은 서로 남남이에요.** 범위와 눈금을 저마다의 자료로 잡아요. 왼쪽 축의 눈금과 오른쪽 축의 눈금이 같은 높이에 서도록 맞추지 않아요.
- **색이 이어져요.** 오른쪽 축의 첫 층은 왼쪽 축의 층들 다음 색을 받아요. 위 그림에서 막대가 팔레트의 첫 색, 선이 둘째 색이에요.
- **범례는 하나예요.** 두 축에서 `label`을 준 층들이 한 범례에 모여요.
- **보기는 몇 번 불러도 같은 축이에요.** `fig.twin()`을 다시 부르면 이미 있는 둘째 축의 보기를 줘요. 셋째 축은 없어요.

<Callout type="note" title="보기를 fig에 받지 않아요">

보기의 메서드는 보기 자신을 돌려줘요. `fig = fig.twin().line(...)`처럼 쓰면 그 뒤로 `fig`가 오른쪽 축의 보기가 돼서, `fig.ylabel(...)`과 `fig.line(...)`이 오른쪽 축의 것이 돼요. 위의 예처럼 보기는 다른 이름(`right`)에 받아요.

</Callout>

히스토그램에 누적 비율을 겹치는 그림도 축이 둘이어야 해요. 막대의 높이는 개수이고 누적 비율은 0에서 1 사이라서예요. 오른쪽 축의 범위는 `right.ylim`으로 정해요.

```python
>>> rng = sd.random.default_rng(11)
>>> z = sd.stats.Gamma(a=3.0).sample(400, rng=rng)
>>> hist = sd.plot.histogram(z, bins=24).xlabel(r"$x$").ylabel("Count")
>>> right = hist.twin().ecdf(z).ylim(0, 1).ylabel("Cumulative share")
```

<PlotImage name="twin-ecdf" of="hist" alt="오른쪽으로 꼬리가 긴 파란 히스토그램 위에 노란 계단 꼴의 누적 곡선이 왼쪽 아래에서 오른쪽 위로 올라가요. 왼쪽 축은 개수, 오른쪽 축은 0에서 1까지의 누적 비율이에요" caption="히스토그램은 왼쪽 축의 개수로, 경험 분포 함수는 오른쪽 축의 0에서 1로 읽어요. 막대가 높은 곳에서 누적 곡선이 가파르게 올라요." />

둘째 축은 2D 그림의 칸에만 둘 수 있어요. 칸이 여럿인 그림에서는 `fig[i, j].twin()`이 그 칸의 둘째 축이에요.

```python
>>> right.twin()
Traceback (most recent call last):
    ...
ValueError: twin(): this is already the second y axis
>>> sd.plot.surface(lambda x, y: x * y, 0, 1, 0, 1).twin()
Traceback (most recent call last):
    ...
ValueError: twin(): a second y axis needs a 2D plot's cell
```

<Callout type="warning" title="두 축의 그림은 읽는 사람이 헷갈리기 쉬워요">

두 축의 범위를 어떻게 잡느냐에 따라 두 곡선이 만나는 자리와 벌어지는 정도가 달라 보여요. 만나는 점에는 아무 뜻이 없어요. 어느 층이 어느 축의 것인지 축 이름과 범례로 분명히 하고, 두 양을 견주는 것이 목적이 아니라면 칸을 둘로 나누는 쪽([`grid`](/api/plot/figure/#grid-그린-그림을-모으기))도 생각해 보세요.

</Callout>

## 끼워 넣은 작은 그림: inset

`fig.inset(figure, rect)`는 따로 그린 그림 `figure`를 `fig`의 칸 안에 작게 얹어요. 큰 그림에서 잘 보이지 않는 한 구석을 키워 보이거나, 본 그림에 딸린 작은 그림(잔차의 분포, 로그 축으로 본 같은 자료)을 한 칸에 담을 때 써요.

줄어드는 진동 $y = e^{-t/3}\cos 4t$는 뒤쪽의 진폭이 작아서 큰 그림에서는 거의 평평해 보여요. $8 \le t \le 10$을 키운 그림을 오른쪽 위에 끼워 넣어 볼게요. 작은 그림은 같은 자료를 그린 뒤 [`xlim`, `ylim`](/api/plot/customize/)으로 범위를 좁힌 것이에요.

```python
>>> t = sd.linspace(0, 10, 400)
>>> y = sd.exp(-t / 3) * sd.cos(4 * t)
>>> fig = sd.plot.line(t, y).xlabel(r"$t$").ylabel(r"$y$")
>>> fig = fig.line([8, 10, 10, 8, 8], [-0.08, -0.08, 0.08, 0.08, -0.08], color="gray", width=0.5)
>>> zoom = sd.plot.line(t, y).xlim(8, 10).ylim(-0.08, 0.08)
>>> fig = fig.inset(zoom, (0.5, 0.52, 0.5, 0.46))
```

<PlotImage name="inset-zoom" alt="왼쪽에서 크게 흔들리다 오른쪽으로 갈수록 잦아드는 파란 곡선. 오른쪽 끝의 작은 구간에 회색 사각형이 있고, 오른쪽 위에 그 구간을 키운 작은 그림이 자기 눈금과 함께 들어 있어요" caption="오른쪽 위의 작은 그림은 회색 사각형(8 ≤ t ≤ 10)을 키운 것이에요. 작은 그림은 자기 축과 눈금을 가져요." />

### rect: 어디에, 얼마나 크게

`rect = (x, y, w, h)`는 칸의 **그림 사각형**(축이 둘러싼 곳)에 대한 몫이에요. 자료의 좌표가 아니에요. `(x, y)`는 작은 그림의 왼쪽 아래 구석이고, 그림 사각형의 왼쪽 아래가 `(0, 0)`, 오른쪽 위가 `(1, 1)`이에요. `w`, `h`는 너비와 높이예요. 위의 `(0.5, 0.52, 0.5, 0.46)`은 가로로 절반부터 오른쪽 끝까지, 세로로 가운데 조금 위부터 꼭대기 가까이까지예요.

사각형은 작은 그림의 **바깥 크기**예요. 작은 그림의 눈금 숫자와 축 이름, 제목이 모두 이 사각형 안에 들어가고, 그만큼 작은 그림의 그림 영역이 줄어요. 그래서 사각형을 칸의 가장자리에 붙여도 글자가 칸 밖으로 나가지 않아요.

- **흰 바탕이에요.** 사각형 안은 흰색으로 덮고 그 위에 작은 그림을 그려요. 사각형 밑에 깔린 큰 그림의 선과 점은 가려져요. 자료가 없는 구석을 골라요.
- **글자 크기는 그대로예요.** 작은 그림의 눈금과 이름은 큰 그림과 같은 크기의 글자예요. 사각형이 작으면 눈금이 몇 개만 서요. 축 이름과 제목은 꼭 필요할 때만 붙여요.
- **테마와 글꼴은 큰 그림을 따라요.** 층의 색은 작은 그림을 그릴 때 정해진 그대로예요.
- **복사해 넣어요.** 끼워 넣은 뒤에 `zoom`을 고쳐도 `fig` 안의 작은 그림은 바뀌지 않아요. 고치려면 고친 그림을 새 큰 그림에 다시 넣어요.
- **여럿을 넣을 수 있어요.** `inset`을 부를 때마다 하나씩 더해져요. 서로 겹치면 나중 것이 위에 와요.
- 작은 그림이 가로세로 같은 비율의 칸([`parametric`](/api/plot/parametric/) 등)이면 사각형 안에서 그 비율을 지켜요. 작은 그림에 준 `width`, `height`는 쓰이지 않아요.

키운 구간을 큰 그림에 표시하는 일은 알아서 하지 않아요. 위의 예처럼 [`line`](/api/plot/line/)으로 사각형을 그려 넣어요.

칸이 여럿인 그림에서는 `fig[i, j].inset(...)`이 그 칸에 얹어요. 둘째 y축이 있는 칸에서는 원래 그림 `fig`에서 부르든 보기 `right`에서 부르든 같은 칸에 얹어요.

### 에러

끼워 넣을 그림은 칸이 하나여야 하고, 사각형은 수 넷이며 그림 사각형 안에 있어야 해요.

```python
>>> fig.inset(zoom, (0.5, 0.5, 0.4))
Traceback (most recent call last):
    ...
ValueError: inset(): 'rect' must hold 4 numbers (x, y, w, h), not 3
>>> fig.inset(zoom, (0.8, 0.8, 0.5, 0.5))
Traceback (most recent call last):
    ...
ValueError: inset(): 'rect' must lie in the plot: shares in [0, 1] with x + w and y + h at most 1
>>> fig.inset(sd.plot.Figure(ncols=2), (0.5, 0.5, 0.4, 0.4))
Traceback (most recent call last):
    ...
TypeError: inset(): 'figure' must be a Figure of one cell, not Figure
>>> sd.plot.surface(lambda x, y: x * y, 0, 1, 0, 1).inset(zoom, (0.5, 0.5, 0.4, 0.4))
Traceback (most recent call last):
    ...
ValueError: inset(): an inset goes over a 2D plot's cell
```

## 다른 것과 함께 쓰기

둘째 축과 작은 그림은 칸에 딸린 것이라, 그 칸을 [`grid`](/api/plot/figure/#grid-그린-그림을-모으기)로 다른 그림에 모을 때 함께 따라가요. `grid`에는 원래 그림(`hist`)을 넘겨도, 둘째 축의 보기(`right`)를 넘겨도 두 축을 다 가진 칸이 들어가요.

```python
>>> both = sd.plot.grid([hist, fig], labels="a", width=183)
>>> both.shape
(1, 2)
```

## matplotlib을 아는 분께

| matplotlib | sd.plot |
|---|---|
| `ax2 = ax.twinx()` | `right = fig.twin()` |
| `ax2.plot(...)`, `ax2.set_ylabel(...)` | `right.line(...)`, `right.ylabel(...)` |
| 두 축의 범례를 손으로 합쳐요(`lines1 + lines2`) | 범례 하나에 알아서 모여요 |
| 둘째 축의 색 순환이 처음부터 다시 시작해요 | 첫 축의 다음 색으로 이어져요 |
| `ax.twiny()`(둘째 x축) | 없어요 |
| `axins = ax.inset_axes([x, y, w, h])` 뒤에 `axins.plot(...)` | 그림을 따로 그려 `fig.inset(figure, (x, y, w, h))` |
| `ax.indicate_inset_zoom(axins)` | 없어요. `line`으로 사각형을 그려요 |
