A `float64` number stores its sign in one bit. `signbit` returns `True` where that bit is set: for negative numbers,
`-inf`, negative zero `-0.0`, and a NaN whose sign bit is set. It differs from `x < 0` in two cases. `-0.0 < 0` is
`False`, since negative zero equals zero, but its sign bit is set. A comparison with NaN is `False`, but a NaN can
carry either sign.

The sign of a zero is visible in results such as `1 / -0.0`, which is `-inf`, and in the branch cuts of the complex
functions. `signbit` is the test that tells `-0.0` from `0.0`.

`bool` and `int64` input is converted to `float64` first (see
[functions with floating-point results](/api/array/dtypes/#functions-with-floating-point-results)), so the
result is `True` exactly for the negative integers.

## Examples

`signbit` and `x < 0` agree except at negative zero:

```python
>>> import stardust as sd
>>> x = sd.asarray([-2.0, -0.0, 0.0, 3.0, -sd.inf, sd.inf])
>>> sd.signbit(x)
array([ True,  True, False, False,  True, False], dtype=bool)
>>> x < 0
array([ True, False, False, False,  True, False], dtype=bool)
>>> 1.0 / sd.asarray([-0.0, 0.0])
array([-inf,  inf], dtype=float64)
```

Negative zero appears, for example, when a small negative number is rounded:

```python
>>> sd.round(sd.asarray([-0.4, 0.4]))
array([-0.0,  0.0], dtype=float64)
>>> sd.signbit(sd.round(sd.asarray([-0.4, 0.4])))
array([ True, False], dtype=bool)
```

The sign bit of a NaN. Python's `-` flips it:

```python
>>> sd.signbit(sd.asarray([sd.nan, -sd.nan]))
array([False,  True], dtype=bool)
```

Integers, and the error for complex input:

```python
>>> sd.signbit(sd.asarray([-3, 0, 5]))
array([ True, False, False], dtype=bool)
>>> sd.signbit(sd.asarray([-1 + 0j]))
Traceback (most recent call last):
    ...
TypeError: signbit(): not supported for complex128
```

## Notes

The sign of a NaN carries no numerical meaning, and operations that produce NaN do not promise a particular sign;
`signbit` only reports the bit that is stored. For a complex number, apply `signbit` to its
[real or imaginary part](/api/array/complex/).

## For NumPy, SciPy and R users

The nearest equivalent is `numpy.signbit`. Base R has no such function; `1 / x < 0` tells the sign of a zero.

- The results agree with NumPy's, for `bool` and `int64` input as well.
- Complex input raises `TypeError`, as in NumPy.
