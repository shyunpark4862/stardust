A quantile with probability $q$ is a value that a fraction $q$ of the elements lie below: $q = 0.25$ gives the lower
quartile, $q = 0.5$ the median and $q = 0.9$ the 90th percentile. `quantile` sorts the elements of each output
position and reads the quantile off the sorted values. `nanquantile` does the same after leaving out the NaN
elements.

Most probabilities fall between two sorted elements. The `method` argument decides what is returned there: an
interpolated value (the default `"linear"` and five other methods) or one of the elements (`"lower"`, `"higher"`,
`"nearest"`, `"inverted_cdf"`, `"closest_observation"`), or the mean of two (`"midpoint"`,
`"averaged_inverted_cdf"`). The thirteen methods are the nine sample quantile definitions of Hyndman and Fan [1] and
four simpler rules. For finite data, all of them return the smallest element for $q = 0$ and the largest for $q = 1$,
and for large samples they differ little.

With `quantile`, an output position that contains a NaN gives NaN. With `nanquantile`, it gives the quantile of the
other elements. An output position without elements, or with only NaN for `nanquantile`, gives NaN without an error or
a warning.

## Examples

The lower quartile of four values, and the three quartiles at once:

```python
>>> import stardust as sd
>>> x = sd.asarray([7, 1, 4, 2])
>>> sd.quantile(x, 0.25)
1.75
>>> sd.quantile(x, sd.asarray([0.25, 0.5, 0.75]))
array([1.75,  3.0, 4.75], dtype=float64)
```

The same probabilities with other methods. The discrete methods return elements of `x`:

```python
>>> q = sd.asarray([0.25, 0.5, 0.75])
>>> sd.quantile(x, q, method="lower")
array([1.0, 2.0, 4.0], dtype=float64)
>>> sd.quantile(x, q, method="nearest")
array([2.0, 4.0, 4.0], dtype=float64)
>>> sd.quantile(x, q, method="midpoint")
array([1.5, 3.0, 5.5], dtype=float64)
>>> sd.quantile(x, q, method="weibull")
array([1.25,  3.0, 6.25], dtype=float64)
```

Along an axis, with a NaN in the second row. With an array `q`, the axis of `q` comes first in the result:

```python
>>> m = sd.asarray([[1.0, 2.0, 3.0, 4.0],
...                 [10.0, sd.nan, 30.0, 40.0]])
>>> sd.quantile(m, 0.5, axis=1)
array([2.5, nan], dtype=float64)
>>> sd.nanquantile(m, 0.5, axis=1)
array([ 2.5, 30.0], dtype=float64)
>>> sd.nanquantile(m, sd.asarray([0.25, 0.75]), axis=1)
array([[1.75, 20.0],
       [3.25, 35.0]], dtype=float64)
```

No elements give NaN. A list for `q`, or a percentage instead of a probability, raises:

```python
>>> sd.quantile(sd.zeros(0), 0.5)
nan
>>> sd.nanquantile(sd.asarray([sd.nan, sd.nan]), 0.5)
nan
>>> sd.quantile(x, [0.25, 0.75])
Traceback (most recent call last):
    ...
TypeError: quantile(): 'q' must be an int, a float or an sd.ndarray, not list
>>> sd.quantile(x, 90)
Traceback (most recent call last):
    ...
ValueError: quantile(): 'q' must be in the range [0, 1]
```

## Notes

Let $x_{(0)} \le x_{(1)} \le \dots \le x_{(n-1)}$ be the sorted elements of one output position. The six
interpolating methods compute a position $v$ from $n$ and $q$ and return

$$
Q = x_{(j)} + g \, \bigl(x_{(j+1)} - x_{(j)}\bigr), \qquad j = \lfloor v \rfloor, \quad g = v - j,
$$

with $Q = x_{(0)}$ when $v \lt 0$ and $Q = x_{(n-1)}$ when $v \ge n - 1$:

| `method` | Position $v$ | Hyndman–Fan type |
|---|---|---|
| `"interpolated_inverted_cdf"` | $nq - 1$ | 4 |
| `"hazen"` | $nq - \tfrac{1}{2}$ | 5 |
| `"weibull"` | $(n + 1) q - 1$ | 6 |
| `"linear"` | $(n - 1) q$ | 7 |
| `"median_unbiased"` | $(n + \tfrac{1}{3}) q - \tfrac{2}{3}$ | 8 |
| `"normal_unbiased"` | $(n + \tfrac{1}{4}) q - \tfrac{5}{8}$ | 9 |

The other methods return an element or the mean of two. With $h = (n - 1) q$:

| `method` | Result | Hyndman–Fan type |
|---|---|---|
| `"inverted_cdf"` | $x_{(k)}$, $k = \max(\lceil nq \rceil - 1, 0)$ | 1 |
| `"averaged_inverted_cdf"` | as `"inverted_cdf"`, except $\tfrac{1}{2}(x_{(j-1)} + x_{(j)})$ when $nq = j$ is an integer with $1 \le j \le n - 1$ | 2 |
| `"closest_observation"` | $x_{(k)}$, with $k + 1$ the integer nearest to $nq$ (ties to even), clipped to $0 \le k \le n - 1$ | 3 |
| `"lower"` | $x_{(\lfloor h \rfloor)}$ | |
| `"higher"` | $x_{(\lceil h \rceil)}$ | |
| `"midpoint"` | $\tfrac{1}{2}(x_{(\lfloor h \rfloor)} + x_{(\lceil h \rceil)})$ | |
| `"nearest"` | $x_{(r)}$, $r$ the integer nearest to $h$ (ties to even) | |

For `x = [7, 1, 4, 2]` and $q = 0.25$, the sorted values are $1, 2, 4, 7$ and `"linear"` gives $v = 0.75$, so
$Q = 1 + 0.75 \cdot (2 - 1) = 1.75$.

**Ranking.** The elements are converted to `float64` first, so `int64` values larger than $2^{53}$ in magnitude may
be rounded. In the ranking, `-0.0` comes before `0.0`.

**Infinite elements.** The six interpolating methods, `"midpoint"` and `"averaged_inverted_cdf"` evaluate the
formula above even when $g = 0$ or when both elements are the same one, and $\infty \cdot 0$ and $\infty - \infty$ are
NaN. An infinite element among the two the formula combines therefore gives NaN for most $q$, also at $q = 0$ or
$q = 1$ when the smallest or largest element is infinite. The methods that return an element unchanged
(`"inverted_cdf"`, `"closest_observation"`, `"lower"`, `"higher"`, `"nearest"`) return the infinite element:

```python
>>> big = sd.asarray([1.0, 2.0, sd.inf])
>>> sd.quantile(big, 1.0)
nan
>>> sd.quantile(big, 1.0, method="higher")
inf
```

**Median.** [`median`](/api/array/median/) computes the mean of the middle one or two elements directly. It agrees
with `quantile(x, 0.5)` up to rounding in the last digit.

## Comparison with other libraries

The nearest equivalents are `numpy.quantile` and `numpy.nanquantile`.

- The thirteen `method` names are NumPy's.
- The result is always `float64`. NumPy keeps an integer dtype for `"lower"`, `"higher"`, `"nearest"`,
  `"inverted_cdf"` and `"closest_observation"`.
- `q` must be a Python number or an `sd.ndarray`; NumPy also accepts a list.
- An empty input gives NaN. `numpy.quantile` raises `IndexError` for it.
- There are no `out=`, `overwrite_input=` or `weights=` arguments, and no `percentile` function: pass `q / 100`.
