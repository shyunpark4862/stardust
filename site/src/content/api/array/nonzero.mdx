`nonzero` lists the positions of the elements of `x` that are not zero. For a 2-D `x` it returns two arrays, the row
positions and the column positions; the `k`-th nonzero element is `x[rows[k], cols[k]]`. The elements are listed in
row-major order (the last axis varies fastest), the order in which they appear in the flattened array.

An element counts as nonzero by the same rule as in [`any`](/api/array/any-all/): `True`, any nonzero number, a
complex number with a nonzero real or imaginary part, and NaN are nonzero; `False`, `0`, `0.0`, `-0.0` and `0j` are
zero. For a Boolean `x`, typically the result of a comparison, the result lists the positions where the condition
holds.

The tuple is an index: `x[sd.nonzero(x)]` gives the nonzero elements as a 1-D array (see
[Indexing](/api/array/indexing/)). [`count_nonzero`](/api/array/count_nonzero/) gives only their number.

## Examples

Positions of the nonzero elements of a 1-D array. NaN is nonzero; `-0.0` is zero:

```python
>>> import stardust as sd
>>> v = sd.asarray([0.0, 1.5, 0.0, -2.0, sd.nan, -0.0])
>>> sd.nonzero(v)
(array([1, 3, 4], dtype=int64),)
>>> sd.nonzero(v)[0]
array([1, 3, 4], dtype=int64)
```

A 2-D array gives row and column positions. The tuple selects the elements:

```python
>>> x = sd.asarray([[0, 3, 0], [4, 0, 5]])
>>> rows, cols = sd.nonzero(x)
>>> rows
array([0, 1, 1], dtype=int64)
>>> cols
array([1, 0, 2], dtype=int64)
>>> x[sd.nonzero(x)]
array([3, 4, 5], dtype=int64)
```

The positions where a condition holds, as one (row, column) pair per line:

```python
>>> sd.stack(sd.nonzero(x > 3), axis=1)
array([[1, 0],
       [1, 2]], dtype=int64)
```

## Notes

The result is the same for any memory layout of `x`: for the transpose `x.T`, the positions are those of the
elements of `x.T` in its own row-major order. An array without nonzero elements gives empty arrays, one per axis.
The arrays of the result are new and writable.

## Comparison with other libraries

The nearest equivalent is `numpy.nonzero` (also `numpy.where` with one argument).

- [`where`](/api/array/where/) always takes three arguments; the one-argument form `numpy.where(c)` is `nonzero(c)`.
- `x` must be an `sd.ndarray`; lists and Python scalars raise `TypeError`.
