`any` tests whether at least one element of `x` is true along the axes given by `axis`, and `all` whether every
element is. The reduced axes are removed from the shape, or kept with length 1 when `keepdims=True` (see
[`axis` and `keepdims`](/start/conventions/#axis-and-keepdims)). With the default `axis=None`, the result is one
Python `bool`. The methods `x.any(...)` and `x.all(...)` are the same functions.

`x` may have any dtype. An element counts as true when it is not equal to zero: a nonzero number, a complex number
with a nonzero real or imaginary part, and NaN are true; `0`, `0.0`, `-0.0` and `0j` are false. The same rule
converts numbers to `bool` (see [explicit conversion](/api/array/dtypes/#explicit-conversion)).

Over no elements, `any` is `False` and `all` is `True`: no element is true, and no element is false.

An array has no truth value of its own, so `if x == y:` raises `TypeError` (see [`ndarray`](/api/array/ndarray/)).
`all` and `any` turn such a comparison into one `bool`.

## Examples

Tests over all elements, and per row and column:

```python
>>> import stardust as sd
>>> x = sd.asarray([[1, 0, 3], [4, 5, 6]])
>>> sd.any(x == 0), sd.all(x > 0)
(True, False)
>>> sd.all(x, axis=1)
array([False,  True], dtype=bool)
>>> (x > 4).any(axis=0)
array([False,  True,  True], dtype=bool)
```

A condition on whole arrays, such as equality:

```python
>>> a = sd.asarray([1.0, 2.0, 3.0])
>>> b = sd.asarray([1.0, 2.0, 3.5])
>>> (a == b).all()
False
>>> if (a == b).any():
...     print("some elements are equal")
some elements are equal
```

Numbers count as true when they are nonzero. NaN is nonzero:

```python
>>> sd.any(sd.asarray([0.0, -0.0, 0j]))
False
>>> sd.all(sd.asarray([1.0, sd.nan, -2.0]))
True
```

Empty arrays and empty axes:

```python
>>> e = sd.zeros((2, 0))
>>> sd.any(e), sd.all(e)
(False, True)
>>> sd.all(e, axis=1)
array([True, True], dtype=bool)
```

## Comparison with other libraries

The nearest equivalents are `numpy.any` and `numpy.all`, and the methods of `numpy.ndarray`.

- The results agree with NumPy's, including NaN counting as true. There are no `out=` or `where=` arguments, and a
  result over all axes is a Python `bool`, not a NumPy scalar.
