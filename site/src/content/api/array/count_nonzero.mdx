## 한눈에 보기

`count_nonzero`는 배열에서 **0이 아닌 원소가 몇 개인지** 세요.

```python
>>> import stardust as sd
>>> x = sd.asarray([[0, 1, 2], [3, 0, 0]])
>>> sd.count_nonzero(x)
3
```

`axis`를 주면 그 방향으로만 세요. `axis=0`이면 열마다, `axis=1`이면 행마다 센 개수가 나와요.

```python
>>> sd.count_nonzero(x, axis=0)
array([1, 1, 1], dtype=int64)
>>> sd.count_nonzero(x, axis=1)
array([2, 1], dtype=int64)
```

  <Op note="axis=1">→</Op>
  <ArrayFig name="sd.count_nonzero(x, axis=1)" data={[[2], [1]]} tones={[['b'], ['b']]} note="shape (2,)" />

`axis`와 `keepdims`의 뜻은 [`sum`](/api/array/sum/)과 똑같아요. tuple이나 list로 여러 축을 한꺼번에 셀 수 있고, `keepdims=True`면 센 축이 길이 1로 남아요. 자세한 설명과 그림은 `sum` 문서에 있어요.

```python
>>> sd.count_nonzero(x, axis=1, keepdims=True)
array([[2],
       [1]], dtype=int64)
```

결과는 정수(int64)예요. 모든 축으로 세면 Python `int`예요.

## 조건에 맞는 원소 세기

`count_nonzero`는 조건을 만족하는 원소의 개수를 셀 때 가장 많이 써요. 비교 연산의 결과는 bool 배열이고, bool 배열에서는 `True`가 "0이 아닌 값"이에요. 그래서 `count_nonzero(조건)`은 조건이 참인 원소의 개수예요.

```python
>>> scores = sd.asarray([[72, 58, 91], [45, 66, 80]])
>>> sd.count_nonzero(scores >= 60)
4
>>> sd.count_nonzero(scores >= 60, axis=1)
array([2, 2], dtype=int64)
```

60점 이상이 모두 4개, 행마다 2개씩이에요.

NaN(숫자가 아님)의 개수도 같은 방법으로 세요.

```python
>>> v = sd.asarray([1.0, sd.nan, 3.0, sd.nan])
>>> sd.count_nonzero(sd.isnan(v))
2
```

### `sum`으로 세는 것과의 차이

bool 배열은 [`sum`](/api/array/sum/)으로도 셀 수 있어요. `True`를 1로 보고 더하기 때문이에요. bool 배열에서는 두 방법의 결과가 같아요.

```python
>>> sd.sum(scores >= 60)
4
```

차이는 bool이 아닌 배열에서 드러나요. `sum`은 값을 더하고, `count_nonzero`는 0이 아닌 원소의 개수를 세요.

```python
>>> w = sd.asarray([0, 5, 0, 7])
>>> sd.sum(w)
12
>>> sd.count_nonzero(w)
2
```

"조건에 맞는 개수"라는 뜻을 드러내고 싶을 때는 `count_nonzero`가 읽기 쉬워요.

## 무엇을 0으로 볼까요

기준은 모든 dtype에서 `x != 0` 하나예요. [`any`, `all`](/api/array/any-all/)과 같은 기준이에요.

| dtype | 세지 않는 값 | 세는 값 |
|---|---|---|
| bool | `False` | `True` |
| int64 | `0` | 0이 아닌 모든 정수 |
| float64 | `0.0`, `-0.0` | 0이 아닌 모든 실수, `inf`, **NaN** |
| complex128 | `0j` | 실수부나 허수부 중 하나라도 0이 아닌 값 |

```python
>>> sd.count_nonzero(sd.asarray([0.0, sd.nan, -0.0, 1e-300]))
2
>>> sd.count_nonzero(sd.asarray([0j, 1j, 1 + 0j]))
2
```

`1e-300`처럼 아주 작아도 0이 아니면 세요. `-0.0`은 0이라서 세지 않아요.

<Callout type="warn" title="NaN도 세요">

NaN은 0이 아니므로 `count_nonzero`가 세요. 그래서 `count_nonzero(v)`는 "값이 있는 원소의 개수"가 아니에요. NaN이 아닌 원소의 개수가 필요하면 `v.size - sd.count_nonzero(sd.isnan(v))`처럼 구하세요.

</Callout>

```python
>>> sd.count_nonzero(v)
4
>>> v.size - sd.count_nonzero(sd.isnan(v))
2
```

## 조심할 점

### 빈 배열은 0이에요

셀 원소가 없으면 결과는 `0`이에요. 에러가 아니에요.

```python
>>> sd.count_nonzero(sd.asarray([]))
0
>>> sd.count_nonzero(sd.zeros((2, 0)), axis=1)
array([0, 0], dtype=int64)
```

### 메서드는 없어요

`sum`, `any` 같은 집계 함수와 달리 `count_nonzero`에는 같은 이름의 메서드가 없어요. 언제나 `sd.count_nonzero(x)`로 써요.

```python
>>> x.count_nonzero()
Traceback (most recent call last):
    ...
AttributeError: 'ndarray' object has no attribute 'count_nonzero'
```

### 옵션은 이름을 붙여서

`axis`와 `keepdims`는 이름과 함께 써야 해요. `sd.count_nonzero(x, 0)`이 아니라 `sd.count_nonzero(x, axis=0)`이에요. 없는 축을 주면 `ValueError`예요.

```python
>>> sd.count_nonzero(x, axis=2)
Traceback (most recent call last):
    ...
ValueError: count_nonzero(): axis 2 is out of bounds for an array of dimension 2
```

## 비슷한 함수와의 차이

| 하고 싶은 일 | 쓸 것 | `count_nonzero`와 다른 점 |
|---|---|---|
| 0이 아닌 원소가 **어디** 있는지 | `nonzero` | 개수가 아니라 자리를 모두 돌려줘요. |
| 하나라도 있는지, 모두 그런지 | `any`, `all` | 개수가 아니라 참·거짓을 돌려줘요. |
| 값의 합 | `sum` | bool 배열에서는 결과가 같지만, 다른 배열에서는 값을 더해요. |
| 조건에 맞는 비율 | `mean` | bool 배열의 평균은 `True`의 비율이에요. |
| 값마다 몇 번 나오는지 | `unique_counts`, `bincount` | 0인지 아닌지가 아니라 값별로 세요. |

[`nonzero`](/api/array/nonzero/)는 이름이 비슷해서 헷갈리기 쉬워요. `nonzero`는 0이 아닌 원소의 **자리**를, `count_nonzero`는 그 **개수**를 돌려줘요. 1차원 배열이라면 `nonzero`가 돌려주는 자리의 개수가 `count_nonzero`의 결과예요.

```python
>>> sd.nonzero(w)
(array([1, 3], dtype=int64),)
>>> sd.count_nonzero(w)
2
```

## numpy를 아는 분께

- `axis`, `keepdims`는 keyword-only예요. `np.count_nonzero(x, 0)`처럼 자리로 넘길 수 없어요.
- NaN을 세는 것(0이 아니므로)은 numpy와 같아요.
- 축을 따라 센 결과는 int64 배열(numpy는 플랫폼에 따라 정수 크기가 달라요), 모든 축으로 센 결과는 Python `int`예요.
