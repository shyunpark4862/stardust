An axis of length 1 does not change the number of elements, only how they are indexed. `squeeze` removes such axes and
`expand_dims` inserts them. Both return a [view](/api/array/views/) of `x`, so writing to the result changes `x`.

`expand_dims` is most often used to line up arrays for [broadcasting](/api/array/broadcasting/): a 1-D array of
length `n` becomes a row of shape `(1, n)` with `axis=0`, or a column of shape `(n, 1)` with `axis=1`. Indexing with
`None` or `sd.newaxis` inserts axes in the same way (see [indexing](/api/array/indexing/)).

`axis` is required for both functions. `squeeze` cannot remove every axis, because stardust has no 0-D arrays; a
single element is read by indexing instead.

## Examples

Remove the first and the last axis of an array of shape `(1, 3, 1)`, or only one of them:

```python
>>> import stardust as sd
>>> c = sd.asarray([[[1.0], [2.0], [3.0]]])
>>> c.shape
(1, 3, 1)
>>> sd.squeeze(c, axis=(0, 2))
array([1.0, 2.0, 3.0], dtype=float64)
>>> sd.squeeze(c, axis=0).shape
(3, 1)
```

A 1-D array as a row and as a column. Their difference broadcasts to a 3-by-3 table of all pairwise differences:

```python
>>> v = sd.asarray([1.0, 2.0, 3.0])
>>> row = sd.expand_dims(v, axis=0)
>>> col = sd.expand_dims(v, axis=1)
>>> row.shape, col.shape
((1, 3), (3, 1))
>>> col - row
array([[ 0.0, -1.0, -2.0],
       [ 1.0,  0.0, -1.0],
       [ 2.0,  1.0,  0.0]], dtype=float64)
```

Several new axes at once. The positions refer to the result, which has three dimensions here:

```python
>>> sd.expand_dims(v, axis=(0, 2)).shape
(1, 3, 1)
>>> sd.expand_dims(v, axis=(0, -1)).shape
(1, 3, 1)
```

An axis whose length is not 1 cannot be removed, and neither can every axis:

```python
>>> sd.squeeze(c, axis=1)
Traceback (most recent call last):
    ...
ValueError: squeeze(): cannot squeeze axis 1: its size is 3, not 1
>>> sd.squeeze(sd.asarray([[5.0]]), axis=(0, 1))
Traceback (most recent call last):
    ...
ValueError: squeeze(): squeezing every axis would give a 0-dimensional array (stardust has none)
```

## Comparison with other libraries

The nearest equivalents are `numpy.squeeze` and `numpy.expand_dims`.

- `squeeze` requires `axis`. `numpy.squeeze` defaults to removing every axis of length 1.
- Removing every axis raises `ValueError`; NumPy returns a 0-D array.
- `expand_dims` matches `numpy.expand_dims`, except that `x` must be an `sd.ndarray`.
