`repeat` makes consecutive copies of each element: the copies of an element stand next to it, before the next element
begins. Along an axis of a 2-D array, it repeats whole rows (`axis=0`) or whole columns (`axis=1`). With an array of
counts, each element can be repeated a different number of times, including 0 to drop it.

[`tile`](/api/array/tile/) repeats the array as a whole instead, so its copies follow one another. The result of
`repeat` is always a new array.

## Examples

Every element twice, and each element its own number of times:

```python
>>> import stardust as sd
>>> v = sd.asarray([1, 2, 3])
>>> sd.repeat(v, 2)
array([1, 1, 2, 2, 3, 3], dtype=int64)
>>> sd.repeat(v, sd.asarray([1, 0, 3]))
array([1, 3, 3, 3], dtype=int64)
```

Rows and columns of a 2-D array. Without `axis`, the array is flattened first:

```python
>>> m = sd.asarray([[1, 2], [3, 4]])
>>> sd.repeat(m, 2, axis=0)
array([[1, 2],
       [1, 2],
       [3, 4],
       [3, 4]], dtype=int64)
>>> sd.repeat(m, sd.asarray([1, 2]), axis=1)
array([[1, 2, 2],
       [3, 4, 4]], dtype=int64)
>>> sd.repeat(m, 2)
array([1, 1, 2, 2, 3, 3, 4, 4], dtype=int64)
```

Counts must be an `int` or an `int64` array; a list is rejected:

```python
>>> sd.repeat(v, [1, 0, 3])
Traceback (most recent call last):
    ...
TypeError: repeat(): 'repeats' must be an int or an int64 array, not list
```

## For NumPy, SciPy and R users

The nearest equivalents are `numpy.repeat` and R's `rep(x, each = n)` (one count for all) or `rep(x, times = counts)`
(one count per element).

- `repeats` must be an `int` or an `int64` `sd.ndarray`. NumPy also accepts lists and tuples of counts.
- `x` must be an `sd.ndarray`; lists raise `TypeError`.
