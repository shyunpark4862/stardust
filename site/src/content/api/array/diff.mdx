`diff` returns the differences of neighboring elements along `axis`: element $k$ of the result is
`x[k + 1] - x[k]` along that axis, so the result is one element shorter than `x`. With `n` greater than 1, the
differences are taken again, `n` times in total; `n=2` gives the second differences.

The subtraction follows [`subtract`](/api/array/arithmetic/): Booleans count as 0 and 1 and give `int64` (see
[arithmetic on Booleans](/api/array/dtypes/#arithmetic-on-booleans)), and `int64` differences wrap around when they
leave the `int64` range (see [integer overflow](/api/array/dtypes/#integer-overflow)). A NaN element makes the
differences on both sides of it NaN.

`prepend` and `append` add elements before and after `x` along `axis`, joined as by [`concat`](/api/array/concat/),
so the dtype is promoted with theirs. A scalar stands for one element along `axis`. With `prepend=0`, the result has
the length of `x` and its first element is `x[0]`; for integers, [`cumulative_sum`](/api/array/cumulative/) of that
result gives back `x`.

## Examples

First and second differences of a 1-D array:

```python
>>> import stardust as sd
>>> v = sd.asarray([1, 4, 9, 16, 25])
>>> sd.diff(v)
array([3, 5, 7, 9], dtype=int64)
>>> sd.diff(v, n=2)
array([2, 2, 2], dtype=int64)
```

With a value joined in front, the result has the length of `x`, and the running sum undoes it:

```python
>>> d = sd.diff(v, prepend=0)
>>> d
array([1, 3, 5, 7, 9], dtype=int64)
>>> sd.cumulative_sum(d)
array([ 1,  4,  9, 16, 25], dtype=int64)
>>> sd.diff(sd.asarray([1.0, 2.5, 4.5]), append=sd.asarray([10.0, 20.0]))
array([ 1.5,  2.0,  5.5, 10.0], dtype=float64)
```

Along each axis of a 2-D array. A scalar `prepend` is repeated over the other axis:

```python
>>> x = sd.asarray([[1, 2, 4], [7, 11, 16]])
>>> sd.diff(x)
array([[1, 2],
       [4, 5]], dtype=int64)
>>> sd.diff(x, axis=0, prepend=0)
array([[ 1,  2,  4],
       [ 6,  9, 12]], dtype=int64)
```

Booleans give `int64`, so a change from `False` to `True` is 1 and the reverse is -1. An array `prepend` must have
the dimensions of `x`:

```python
>>> sd.diff(sd.asarray([True, False, False, True]))
array([-1,  0,  1], dtype=int64)
>>> sd.diff(x, axis=1, prepend=sd.asarray([0, 0]))
Traceback (most recent call last):
    ...
ValueError: diff(): 'prepend' must have as many dimensions as 'x' (2), not 1
>>> sd.diff(x, axis=1, prepend=sd.asarray([[0], [0]]))
array([[1, 1, 2],
       [7, 4, 5]], dtype=int64)
```

## Notes

For the elements $x_0, \dots, x_{m-1}$ along `axis`, the first differences are $d_k = x_{k+1} - x_k$ for
$0 \le k \lt m - 1$, and the $n$-th differences are

$$
d^{(n)}_k = \sum_{j=0}^{n} (-1)^{n-j} \binom{n}{j} \, x_{k+j}, \qquad 0 \le k \lt m - n,
$$

computed as $n$ repeated first differences. When $n \ge m$, the axis has length 0 in the result.

With `n=0` the function returns `x` itself, the same object, without joining `prepend` and `append` and without
checking them (see [Views and copies](/api/array/views/)). When `x` has length 0 along `axis` and neither `prepend`
nor `append` is given, the result is also `x` itself, so a Boolean `x` then stays `bool`. In all other cases the
result is a new array.

## For NumPy, SciPy and R users

The nearest equivalents are `numpy.diff` and R's `diff(x, lag = 1, differences = n)`.

- A Boolean `x` gives `int64` differences (-1, 0, 1). `numpy.diff` gives a Boolean array that is `True` where
  neighbors differ.
- `x`, and array values of `prepend` and `append`, must be `sd.ndarray`; lists raise `TypeError`.
- R's `diff` of a matrix works down the columns, like `axis=0` here; the default `axis=-1` works along the rows.
- R's `lag` takes differences between elements `lag` apart; there is no such argument here.
