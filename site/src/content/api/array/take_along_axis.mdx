`take_along_axis` selects one element of `x` for every element of `indices`. The element `indices[i, j]` with
`axis=1` names a position along axis 1, and the result holds `x[i, indices[i, j]]` at `[i, j]`. Every row (or, in
general, every position on the other axes) thus has its own list of positions, whereas [`take`](/api/array/take/)
applies one list of positions to all of them.

This is the companion of the functions that return positions along an axis: the result of
[`argsort`](/api/array/sort-argsort/) gives the sorted values, and the result of
[`argmax`](/api/array/argmin-argmax/) with `keepdims=True` gives the largest values. The same positions can then
select from another array of the same shape, for example to sort one array by the values of another.

`indices` must have as many dimensions as `x`. On the axes other than `axis`, a length of 1 in either array is
repeated to match the other.

## Examples

The sorted values of each row, through the positions that sort it:

```python
>>> import stardust as sd
>>> x = sd.asarray([[30, 10, 20], [5, 15, 0]])
>>> i = sd.argsort(x, axis=1)
>>> i
array([[1, 2, 0],
       [2, 0, 1]], dtype=int64)
>>> sd.take_along_axis(x, i, axis=1)
array([[10, 20, 30],
       [ 0,  5, 15]], dtype=int64)
```

The largest element of each row, with the positions from `argmax`. With `keepdims=True` they have the required
number of dimensions:

```python
>>> j = sd.argmax(x, axis=1, keepdims=True)
>>> j
array([[0],
       [1]], dtype=int64)
>>> sd.take_along_axis(x, j, axis=1)
array([[30],
       [15]], dtype=int64)
```

A column of positions per row, and one row of positions for all rows. Negative positions count from the end:

```python
>>> sd.take_along_axis(x, sd.asarray([[0], [2]]), axis=1)
array([[30],
       [ 0]], dtype=int64)
>>> sd.take_along_axis(x, sd.asarray([[0, -1]]), axis=1)
array([[30, 20],
       [ 5,  0]], dtype=int64)
```

Positions without the axis raise `ValueError`; `argmax` without `keepdims=True` gives such positions:

```python
>>> sd.take_along_axis(x, sd.argmax(x, axis=1), axis=1)
Traceback (most recent call last):
    ...
ValueError: take_along_axis(): 'indices' must have as many dimensions as 'x' (2), not 1
```

## Notes

For 2-D arrays and `axis=1`, the result is $r_{ij} = x_{i, k_{ij}}$ with $k_{ij}$ the element `indices[i, j]`; for
`axis=0` it is $r_{ij} = x_{k_{ij}, j}$. In more dimensions the position replaces the index on `axis` in the same way.
A position $k$ is valid when $-n \le k \lt n$ for an axis of length $n$. When the result is empty, the positions are
not checked.

## For NumPy, SciPy and R users

The nearest equivalent is `numpy.take_along_axis`. R has no direct equivalent; a matrix of (row, column) pairs used
as an index, `x[cbind(i, j)]`, selects the same elements.

- `axis=None` is rejected. NumPy then selects from the flattened array; [`ravel`](/api/array/ravel/) gives that
  array.
- `indices` must be an `int64` `sd.ndarray`; NumPy accepts any integer array.
