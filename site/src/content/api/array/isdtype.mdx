`isdtype` classifies dtypes by kind. It lets code branch on the kind of data an array holds, for example to accept any
numeric array but reject `bool`, without listing dtypes one by one. Each kind name stands for a set of dtypes; the
table under the `kind` parameter lists them. A dtype or dtype name in `kind` matches only that dtype.

`"numeric"` excludes `bool`, although arithmetic treats `bool` values as the integers 0 and 1.

## Examples

Kind names:

```python
>>> import stardust as sd
>>> sd.isdtype(sd.float64, "real floating")
True
>>> sd.isdtype(sd.int64, "numeric")
True
>>> sd.isdtype(sd.bool, "numeric")
False
```

A tuple matches any of its entries; dtypes and names can be mixed:

```python
>>> sd.isdtype(sd.complex128, ("real floating", "complex floating"))
True
>>> sd.isdtype("int64", (sd.bool, "integral"))
True
```

An array is tested through its `dtype` attribute:

```python
>>> x = sd.asarray([1.0, 2.0])
>>> sd.isdtype(x.dtype, "real floating")
True
>>> sd.isdtype(x, "real floating")
Traceback (most recent call last):
    ...
TypeError: isdtype(): 'dtype' must be sd.bool, sd.int64, sd.float64 or sd.complex128 (or their names), not ndarray
```

Kind names must be spelled exactly:

```python
>>> sd.isdtype(sd.int64, "integer")
Traceback (most recent call last):
    ...
ValueError: isdtype(): 'kind' must be 'bool', 'signed integer', 'unsigned integer', 'integral', 'real floating', 'complex floating' or 'numeric', not 'integer'
```

## Notes

The entries of a tuple are checked in order, and the check stops at the first match. An invalid entry after a matching
one raises no error: `isdtype(sd.float64, ("real floating", "bogus"))` is `True`.

## Comparison with other libraries

The nearest equivalent is `numpy.isdtype`, with the same kind names.

- `dtype` may also be a dtype name such as `"float64"`; `numpy.isdtype` accepts only dtype objects.
- `"unsigned integer"` never matches, because there is no unsigned array dtype.
- `numpy.isdtype` checks every entry of a tuple and raises `ValueError` for `("real floating", "bogus")` even with
  `float64`.
