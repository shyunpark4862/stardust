`square(x)` computes $x^2$ as `x * x` for each element. Integers stay integers and Booleans give `int64` (see
[arithmetic on Booleans](/api/array/dtypes/#arithmetic-on-booleans)); `int64` squares wrap around when they leave the
`int64` range (see [integer overflow](/api/array/dtypes/#integer-overflow)).

`sqrt(x)` computes the square root $\sqrt{x}$. `bool` and `int64` input is converted to `float64` first (see
[functions with floating-point results](/api/array/dtypes/#functions-with-floating-point-results)). A negative real
number has no real square root, and `sqrt` returns NaN for it; the result dtype depends only on the dtype of `x`, never
on its values. Converting `x` to `complex128` first gives the complex square root instead.

## Examples

Squares keep the dtype of the input:

```python
>>> import stardust as sd
>>> sd.square(sd.asarray([3, -4, 5]))
array([ 9, 16, 25], dtype=int64)
>>> sd.square(sd.asarray([1.5, -0.5]))
array([2.25, 0.25], dtype=float64)
>>> sd.square(sd.asarray([1 + 2j, 1j]))
array([(-3+4j), (-1+0j)], dtype=complex128)
```

Square roots of integers are `float64`:

```python
>>> sd.sqrt(sd.asarray([4, 2, 0]))
array([               2.0, 1.4142135623730951,                0.0], dtype=float64)
```

A negative `float64` gives NaN. After conversion to `complex128`, the result is the imaginary square root:

```python
>>> neg = sd.asarray([-1.0, -4.0])
>>> sd.sqrt(neg)
array([nan, nan], dtype=float64)
>>> sd.sqrt(neg.astype(sd.complex128))
array([1j, 2j], dtype=complex128)
```

Special values. The square root of `-0.0` is `-0.0`:

```python
>>> sd.sqrt(sd.asarray([-0.0, sd.inf, -sd.inf, sd.nan]))
array([-0.0,  inf,  nan,  nan], dtype=float64)
```

## Notes

**square.** For `float64`, `square(x)` is exactly `x * x`: it overflows to `inf` above about $1.3 \times 10^{154}$ in
magnitude, and NaN stays NaN. For a complex number $a + bi$ it is $(a^2 - b^2) + 2abi$.

**sqrt of real numbers.** The `float64` square root is correctly rounded. `sqrt(+0.0)` is `0.0`, `sqrt(-0.0)` is
`-0.0`, `sqrt(inf)` is `inf`, and every negative number, $-\infty$ included, gives NaN.

**sqrt of complex numbers.** The result is the principal square root, whose real part is nonnegative. Its branch cut
lies along the negative real axis, where the sign of a zero imaginary part chooses the side: $-4 + 0i$ gives $2i$ and
$-4 - 0i$ gives $-2i$.

```python
>>> sd.sqrt(sd.asarray([complex(-4.0, 0.0), complex(-4.0, -0.0)]))
array([ 2j, -2j], dtype=complex128)
```

An infinite imaginary part gives $\infty + \infty i$ with the sign of that part, even if the real part is NaN. The other
special values follow the C function `csqrt`.

`x ** 0.5` computes the square root too, but it differs from `sqrt` at `-0.0` and $-\infty$; see
[`pow`](/api/array/pow/).

## For NumPy, SciPy and R users

The nearest equivalents are `numpy.square` and `numpy.sqrt`, and R's `x^2` and `sqrt`.

- `square` of a Boolean array gives `int64`. NumPy returns `int8`.
- The square root of a negative number is NaN without a warning. NumPy issues a `RuntimeWarning`, and R warns "NaNs produced".
- In R, `sqrt(as.complex(-1))` gives the complex root, as `sqrt(x.astype(sd.complex128))` does here.
