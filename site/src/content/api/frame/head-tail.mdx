## 한눈에 보기

`head`는 표의 맨 앞 몇 행을, `tail`은 맨 뒤 몇 행을 떼어 내요. 몇 행인지 주지 않으면 5행이에요.

파일에서 수천 행짜리 표를 읽었다면, 전부 출력하기 전에 앞의 몇 행만 보고 컬럼이 제대로 읽혔는지, 값이 어떻게 생겼는지 확인하게 돼요. 시간 순서로 쌓인 기록에서 가장 최근 몇 건을 볼 때는 `tail`을 써요. 아래는 엿새 동안의 날씨 기록이에요.

```python
>>> import stardust as sd
>>> df = sd.frame.DataFrame({
...     "day": [1, 2, 3, 4, 5, 6],
...     "temp": [12.5, 14.0, 13.5, 15.0, 16.5, 15.5],
...     "rain": [0, 3, 0, 0, 12, 4],
... })
>>> df.head()
   day  temp  rain
0    1  12.5     0
1    2  14.0     3
2    3  13.5     0
3    4  15.0     0
4    5  16.5    12
>>> df.head(2)
   day  temp  rain
0    1  12.5     0
1    2  14.0     3
>>> df.tail(2)
   day  temp  rain
4    5  16.5    12
5    6  15.5     4
```

## 행 라벨은 그대로예요

`head`와 `tail`은 행을 골라낼 뿐, 라벨을 새로 매기지 않아요. 위 `tail(2)` 결과의 라벨이 `0, 1`이 아니라 `4, 5`인 이유예요. 라벨이 문자열이어도 마찬가지예요.

```python
>>> df.tail(2).index
RangeIndex(start=4, stop=6, step=1)
>>> temp = sd.frame.Series([12.5, 15.0, 18.5], index=["Seoul", "Busan", "Jeju"], name="temp")
>>> temp.head(2)
Seoul    12.5
Busan    15.0
Name: temp, dtype: float64
```

컬럼, dtype, Series의 이름도 그대로예요. 라벨이 무엇인지는 [라벨과 정렬](/api/frame/alignment/)에 있어요.

## `n`이 음수면: 끝의 몇 행을 빼고 전부

`n`에 음수를 주면 뜻이 뒤집혀요. `head(-2)`는 "맨 뒤 2행을 뺀 나머지 전부", `tail(-2)`는 "맨 앞 2행을 뺀 나머지 전부"예요.

```python
>>> df.head(-2)
   day  temp  rain
0    1  12.5     0
1    2  14.0     3
2    3  13.5     0
3    4  15.0     0
>>> df.tail(-2)
   day  temp  rain
2    3  13.5     0
3    4  15.0     0
4    5  16.5    12
5    6  15.5     4
```

맨 앞의 머리글 줄이나 맨 뒤의 합계 줄처럼, 끝에 붙은 몇 행을 떼어 버릴 때 편해요.

| 부르기 | 고르는 행 (전체 6행일 때) |
|---|---|
| `head(2)` | 앞 2행 (0, 1) |
| `head(-2)` | 뒤 2행을 뺀 나머지 (0 ~ 3) |
| `tail(2)` | 뒤 2행 (4, 5) |
| `tail(-2)` | 앞 2행을 뺀 나머지 (2 ~ 5) |

## 행이 모자라거나 `n`이 0일 때

표의 행 수보다 큰 `n`을 주면 에러 없이 있는 행을 모두 돌려줘요. 음수 쪽으로 너무 커도(`head(-100)`) 에러 없이 빈 표예요.

```python
>>> df.head(100).shape
(6, 3)
>>> df.head(-100).shape
(0, 3)
```

`n=0`이면 행이 없는 표예요. 컬럼과 dtype은 그대로 남아요.

```python
>>> empty = df.head(0)
>>> empty
Empty DataFrame
Columns: [day, temp, rain]
Index: []
>>> empty.dtypes
{'day': int64, 'temp': float64, 'rain': int64}
```

컬럼 구성만 같고 행이 없는 표가 필요할 때 이렇게 만들 수 있어요.

## 결과는 따로 움직여요

`head`와 `tail`의 결과는 새 Series나 DataFrame이에요. 결과의 값을 고쳐도 원래 표는 바뀌지 않아요.

```python
>>> top = df["rain"].head(2)
>>> top.iloc[0] = 99
>>> top
0    99
1     3
Name: rain, dtype: int64
>>> df["rain"].head(2)
0    0
1    3
Name: rain, dtype: int64
```

결과를 만드는 순간에 값을 모두 복사하지는 않아요. 둘 중 한쪽을 고칠 때 비로소 그쪽만 따로 복사해요. 그래서 큰 표의 `head`도 가볍고, 고쳐도 다른 쪽에 번지지 않아요. 이 방식(Copy-on-Write)은 [대입과 복사](/api/frame/assign/)에서 자세히 다뤄요.

## 조심할 점

### `n`은 자리로만 줘요

`n`은 이름 없이 자리로 넘겨요. `head(n=3)`처럼 이름을 붙이면 에러예요. 데이터프레임 메서드의 주 인자는 모두 이렇게 자리로만 받아요([데이터프레임의 기본](/api/frame/basics/)).

```python
>>> df.head(n=3)
Traceback (most recent call last):
    ...
TypeError: DataFrame.head() got some positional-only arguments passed as keyword arguments: 'n'
```

### `n`은 정수만 돼요

`n`에는 정수만 쓸 수 있어요. 값이 정수와 같은 실수(`2.0`)도, `True`도, `None`도 안 돼요. 배열의 [`eye`](/api/array/eye/)나 `zeros`가 크기를 받는 규칙과 같아요. numpy의 정수(`np.int64(2)`)는 받아요.

```python
>>> df.head(2.0)
Traceback (most recent call last):
    ...
TypeError: head(): 'n' must be an int, not float
>>> df.tail(True)
Traceback (most recent call last):
    ...
TypeError: tail(): 'n' must be an int, not bool
>>> df.head(2**70)
Traceback (most recent call last):
    ...
OverflowError: head(): 'n' is out of range
```

계산해서 얻은 수가 실수라면 `int(...)`로 바꿔서 넘겨요.

### `tail(n)`과 `iloc[-n:]`은 `n=0`에서 달라요

`head(n)`은 위치 슬라이스 `iloc[:n]`과 같은 행을 골라요. `tail(n)`도 보통은 `iloc[-n:]`과 같지만, `n`이 0이면 달라요. `-0`은 그냥 `0`이라서 `iloc[-0:]`은 `iloc[0:]`, 곧 전체예요. `tail(0)`은 빈 표예요.

```python
>>> n = 0
>>> df.tail(n).shape
(0, 3)
>>> df.iloc[-n:].shape
(6, 3)
```

`n`이 변수일 때 "뒤에서 n행"을 원하면 `tail(n)`을 쓰는 편이 안전해요. `.iloc`은 [loc과 iloc](/api/frame/loc-iloc/)에 있어요.

## 비슷한 기능과의 차이

| 하고 싶은 일 | 쓸 것 |
|---|---|
| 앞이나 뒤의 몇 행 보기 | `head(n)`, `tail(n)` |
| 위치로 아무 구간이나 자르기 | `df.iloc[2:5]` ([loc과 iloc](/api/frame/loc-iloc/)) |
| 라벨로 행 고르기 | `df.loc[...]` |
| 조건에 맞는 행만 | `df[mask]` ([조건으로 행 거르기](/api/frame/mask/)) |
| 값이 큰 순서로 앞의 몇 행 | `df.sort_values(...)` 뒤에 `head(n)` ([sort_values](/api/frame/sort_values/)) |
| 그룹마다 첫 값이나 마지막 값 | groupby 뒤의 `first`, `last` ([그룹 집계](/api/frame/groupby-agg/)) |
| 크기만 알기 | [`shape`, `len`](/api/frame/attributes/) |

표를 그냥 출력해도 60행이 넘으면 앞 5행과 뒤 5행만 보여 줘요. 출력은 화면에서 줄여 보여 줄 뿐이고, `head`와 `tail`은 실제로 행을 골라낸 새 표를 돌려줘요.

## pandas를 아는 분께

- `n`은 자리로만 받아요. pandas의 `df.head(n=3)`은 `TypeError`예요.
- 음수 `n`, 행보다 큰 `n`, `n=0`의 결과는 pandas와 같아요.
- `head`에 `2.0`이나 `True`를 주면 `TypeError`인 점은 pandas와 같아요. 다만 pandas의 `tail(True)`는 에러 없이 1행을 돌려주고, 여기서는 `tail`도 `TypeError`예요. 메시지는 `head(): 'n' must be an int, not float`처럼 인자를 말해요.
- `tail(0)`의 Index는 `RangeIndex(start=6, stop=6, step=1)`처럼 끝 위치에 있어요. pandas는 `RangeIndex(start=0, stop=0, step=1)`이에요. 둘 다 빈 범위예요.
