## 한눈에 보기

희소 배열에 `sin`이나 `sqrt` 같은 함수를 원소마다 적용하려면 메서드로 불러요. 저장한 값에만 함수를 적용하고, 저장하지 않은 자리는 0으로 둬요.

```python
>>> import stardust as sd
>>> A = sd.sparse.csr_array(sd.asarray([[0.25, 0.0, 9.0], [0.0, 4.0, 0.0]]))
>>> A.sqrt()
<csr_array of shape (2, 3), float64, 3 stored elements>
>>> A.sqrt().toarray()
array([[0.5, 0.0, 3.0],
       [0.0, 2.0, 0.0]], dtype=float64)
```

<Fig caption="함수는 저장한 세 값에만 적용돼요. 저장하지 않은 자리는 sqrt(0) = 0이라 계산할 필요가 없어요.">
  <ArrayFig name="A.data" data={['0.25', '9.0', '4.0']} tones={['a', 'a', 'a']} />
  <Op note="sqrt">→</Op>
  <ArrayFig name="A.sqrt().data" data={['0.5', '3.0', '2.0']} tones={['b', 'b', 'b']} />
</Fig>

이렇게 할 수 있는 것은 함수가 0을 0으로 보낼 때뿐이에요. sin(0) = 0, √0 = 0이라 저장하지 않은 자리의 결과도 0이고, 결과가 같은 패턴의 희소 배열이 돼요. cos(0) = 1, e⁰ = 1인 함수는 모든 칸이 0이 아니게 되므로 메서드로 두지 않았어요.

## 함수 목록

| 묶음 | 메서드 | 같은 이름의 배열 함수 |
|---|---|---|
| 삼각함수 | `sin()`, `tan()`, `asin()`, `atan()` | [삼각함수](/api/array/trig/) |
| 쌍곡선함수 | `sinh()`, `tanh()`, `asinh()`, `atanh()` | [쌍곡선함수](/api/array/hyperbolic/) |
| 제곱근, 지수·로그 | `sqrt()`, `expm1()`, `log1p()` | [sqrt](/api/array/pow/), [지수와 로그](/api/array/exp-log/) |
| 각도 단위 | `deg2rad()`, `rad2deg()` | [`sd.deg2rad`, `sd.rad2deg`](/api/array/deg2rad/) |
| 반올림 | `floor()`, `ceil()`, `trunc()`, `round()` | [반올림](/api/array/rounding/) |
| 부호 | `sign()` | [sign](/api/array/sign/) |
| 거듭제곱 | `power(n)`, `A ** n` | [pow](/api/array/pow/) |
| 절댓값 | `abs(A)` | `sd.abs` |

`expm1(x)` = eˣ − 1과 `log1p(x)` = ln(1 + x)는 eˣ, ln x와 달리 0에서 0이라 목록에 있어요. `deg2rad`는 도를 라디안으로(x · π/180), `rad2deg`는 라디안을 도로(x · 180/π) 바꿔요.

```python
>>> A.expm1().data
array([0.2840254166877415, 8102.083927575384, 53.598150033144236], dtype=float64)
>>> sd.sparse.csr_array(sd.asarray([[180.0, 0.0, 90.0]])).deg2rad().data
array([ 3.141592653589793, 1.5707963267948966], dtype=float64)
```

### 값은 배열 함수와 같아요

메서드의 값은 같은 이름의 배열 함수를 저장한 값에 적용한 것과 마지막 한 자리까지 같아요. 결과의 dtype, 정의역 밖의 값(√−1 = NaN), 무한대도 배열 함수의 규칙이에요.

```python
>>> B = sd.sparse.csr_array(sd.asarray([[0.5, 0.0, -2.25], [0.0, 4.0, 0.0]]))
>>> bool(sd.all(B.sin().data == sd.sin(B.data)))
True
>>> B.sqrt().data
array([0.7071067811865476,                nan,                2.0], dtype=float64)
>>> B.round().data
array([ 0.0, -2.0,  4.0], dtype=float64)
```

`round()`는 가장 가까운 정수로, 딱 가운데이면 짝수 쪽으로 반올림해요(0.5 → 0, 2.5 → 2). 배열의 [`round`](/api/array/rounding/)와 같아요. 소수 자리를 고르는 인자는 없어요.

```python
>>> sd.sparse.csr_array(sd.asarray([[2.5, -0.5, 1.5]])).round().data
array([ 2.0, -0.0,  2.0], dtype=float64)
```

dtype은 배열 함수를 따라요. int64 배열의 `sqrt()`나 `sin()`은 float64이고, `floor()`, `sign()`처럼 정수에서 정수가 되는 함수는 int64 그대로예요. 복소수는 배열 함수가 받지 않는 것(`floor`, `ceil`, `trunc`, `deg2rad`, `rad2deg`)이 `TypeError`예요.

```python
>>> I = sd.sparse.csr_array(sd.asarray([[4, 0, -9]]))
>>> I.sqrt().dtype, I.floor().dtype
(float64, int64)
>>> sd.sparse.csr_array(sd.asarray([[1 + 1j, 0]])).floor()
Traceback (most recent call last):
    ...
TypeError: floor(): not supported for complex128
```

### 결과의 형식과 패턴

결과는 A와 같은 자리를 저장한 희소 배열이에요. 함수가 0을 만들어도 지우지 않아요(위의 `round()`에서 0.5가 0.0이 되었지만 저장된 원소로 남았어요). 지우려면 결과에 `eliminate_zeros()`를 써요.

```python
>>> r = B.round()
>>> r.nnz, r.count_nonzero()
(3, 2)
```

형식은 이래요.

| A의 형식 | 결과 |
|---|---|
| CSR, CSC | 같은 형식 |
| COO | COO. 같은 자리의 중복을 먼저 더한 표준 꼴이에요(A는 그대로예요) |
| DOK | CSR |

```python
>>> A.tocsc().sqrt().format, A.tocoo().sqrt().format, A.todok().sqrt().format
('csc', 'coo', 'csr')
```

COO의 중복을 먼저 더하는 것은 함수가 선형이 아니라서예요. 같은 자리에 1과 3이 저장되어 있으면 그 자리의 값은 4이고 √4 = 2예요. 따로 적용해서 √1 + √3으로 만들면 틀려요.

```python
>>> C = sd.sparse.coo_array(([1.0, 3.0], ([0, 0], [0, 0])), shape=(1, 1))
>>> C.sqrt().data
array([2.0], dtype=float64)
>>> C.nnz
2
```

### 배열 함수에 희소 배열을 넣으면

`sd.sin(A)`처럼 배열의 함수에 희소 배열을 넣으면 `TypeError`예요. 메시지가 쓸 메서드를 알려 줘요. 메서드가 없는 함수면 `toarray()`로 바꿔 쓰라고 해요.

```python
>>> sd.sin(A)
Traceback (most recent call last):
    ...
TypeError: sin(): 'x' must be an sd.ndarray or a bool, int, float or complex, not csr_array; for a sparse array use A.sin()
>>> sd.cos(A)
Traceback (most recent call last):
    ...
TypeError: cos(): 'x' must be an sd.ndarray or a bool, int, float or complex, not csr_array; a sparse array has no cos: use cos(A.toarray())
>>> A.cos()
Traceback (most recent call last):
    ...
AttributeError: 'csr_array' object has no attribute 'cos'
```

## 거듭제곱 power

`A.power(n)`과 `A ** n`은 저장한 값마다 n제곱해요. n은 0보다 큰 실수예요. 정수가 아니어도 돼요.

```python
>>> A.power(2).toarray()
array([[0.0625,    0.0,   81.0],
       [   0.0,   16.0,    0.0]], dtype=float64)
>>> (A ** 0.5).data
array([0.5, 3.0, 2.0], dtype=float64)
```

n이 0 이하이거나 NaN이면 0ⁿ이 0이 아니라서(0⁰ = 1, 0⁻¹ = ∞) 결과가 희소가 아니에요. 그래서 `ValueError`예요. 복소수 지수는 `TypeError`예요.

```python
>>> A.power(0)
Traceback (most recent call last):
    ...
ValueError: power(): the power 0 is not supported: the result would not be sparse (0 ** 0 is 1); use A.toarray() ** 0
>>> A.power(-1)
Traceback (most recent call last):
    ...
ValueError: power(): 'n' must be positive: 0 ** -1 is not 0, the result would not be sparse
>>> A.power(1j)
Traceback (most recent call last):
    ...
TypeError: power(): 'n' must be a real number, not complex
```

저장한 값의 역수가 필요하면(0인 자리는 0으로 두고) `A.power(-1)` 대신 값 배열을 바꿔요.

```python
>>> R = A.copy()
>>> R.data = 1 / R.data
>>> R.toarray()
array([[ 4.0,  0.0, 0.1111111111111111],
       [ 0.0, 0.25,                0.0]], dtype=float64)
```

결과의 dtype은 배열의 [pow](/api/array/pow/)와 같아요. int64를 정수로 거듭제곱하면 int64, 정수가 아닌 지수면 float64예요. 형식의 규칙은 단항 함수와 같아요.

## 짝지어 계산하기 multiply, maximum, minimum

`A.multiply(other)`는 원소별 곱 `A * other`와 같아요. `A.maximum(other)`, `A.minimum(other)`는 원소마다 큰 쪽, 작은 쪽을 골라요. `other`는 희소 배열, 밀집 `sd.ndarray`, 수 가운데 하나예요.

| `other` | `multiply` | `maximum`, `minimum` |
|---|---|---|
| 희소 배열 (같은 모양) | 희소. 둘 다 저장한 자리만 | 희소. 둘 중 하나라도 저장한 자리, 만든 0은 지워요 |
| 밀집 `sd.ndarray` | 희소, A의 형식. A가 저장한 자리만 | 밀집 `sd.ndarray` |
| 수 c | 희소, A의 형식과 패턴 | max(0, c)·min(0, c)가 0이면 희소, 아니면 꽉 찬 희소 배열 |

```python
>>> P = sd.sparse.csr_array(sd.asarray([[0.5, 0.0, -2.0], [0.0, 4.0, 0.0]]))
>>> Q = sd.sparse.csr_array(sd.asarray([[1.0, 3.0, 0.0], [0.0, -1.0, 0.0]]))
>>> P.maximum(Q).toarray()
array([[1.0, 3.0, 0.0],
       [0.0, 4.0, 0.0]], dtype=float64)
>>> P.minimum(Q).toarray()
array([[ 0.5,  0.0, -2.0],
       [ 0.0, -1.0,  0.0]], dtype=float64)
>>> P.multiply(Q).toarray()
array([[ 0.5,  0.0,  0.0],
       [ 0.0, -4.0,  0.0]], dtype=float64)
```

`multiply`의 (0, 2)는 P에만 저장된 자리라서 곱하지 않았어요. 결과에 저장되지 않고 `toarray()`가 0으로 채운 자리예요. 그래서 저장한 원소는 둘 다 저장한 (0, 0)과 (1, 1) 두 개예요.

```python
>>> P.multiply(Q).nnz
2
```

### 수와의 maximum, minimum

수 c와 견줄 때는 저장하지 않은 자리(0)의 결과 max(0, c)가 0인지가 중요해요.

- `A.maximum(c)`에서 c ≤ 0이거나 `A.minimum(c)`에서 c ≥ 0이면 0의 결과가 0이에요. 그래서 저장한 값만 계산하고 결과는 희소 배열이에요. 결과에 생긴 0은 지워요.
- 그 밖에는(c > 0의 `maximum`, c < 0의 `minimum`, NaN) 모든 자리가 0이 아니게 돼요. 결과는 모든 칸을 저장한 희소 배열(A의 형식)이에요. 큰 행렬이면 메모리를 많이 쓰므로 조심해요.

```python
>>> P.maximum(0)
<csr_array of shape (2, 3), float64, 2 stored elements>
>>> P.maximum(0).toarray()
array([[0.5, 0.0, 0.0],
       [0.0, 4.0, 0.0]], dtype=float64)
>>> P.maximum(1.0)
<csr_array of shape (2, 3), float64, 6 stored elements>
>>> P.maximum(1.0).toarray()
array([[1.0, 1.0, 1.0],
       [1.0, 4.0, 1.0]], dtype=float64)
```

`P.maximum(0)`은 음수를 0으로 바꾸는 일(ReLU)이에요. 결과에 생긴 0(−2.0의 자리)은 지워져요. 복소 배열은 크기를 견줄 수 없어서 `maximum`, `minimum`이 `TypeError`예요.

### 받지 않는 짝

리스트와 numpy 배열은 받지 않아요. [`sd.asarray`](/api/array/asarray/)로 바꿔서 넘겨요.

```python
>>> P.multiply([1.0, 2.0, 3.0])
Traceback (most recent call last):
    ...
TypeError: multiply(): 'other' must be a sparse array, an sd.ndarray or a number, not list
>>> P.multiply(sd.asarray([1.0, 2.0, 3.0])).toarray()
array([[ 0.5,  0.0, -6.0],
       [ 0.0,  8.0,  0.0]], dtype=float64)
```

## 밀집의 짝

메서드는 모두 같은 이름의 배열 함수가 짝이에요. `A.sin().toarray()`는 `sd.sin(A.toarray())`와, `A.power(n).toarray()`는 `sd.pow(A.toarray(), n)`과 같아요(저장된 −0.0의 부호만 다를 수 있어요).

```python
>>> bool(sd.all(B.atan().toarray() == sd.atan(B.toarray())))
True
```

## scipy를 아는 분께

- **메서드 이름이 배열의 이름이에요.** scipy의 `arcsin`, `arctan`, `arcsinh`, `arctanh`, `rint`는 `asin`, `atan`, `asinh`, `atanh`, `round`예요. 옛 이름의 별칭은 없어요.
- **`np.sin(A)` 꼴은 안 돼요.** scipy의 희소 배열은 numpy ufunc을 받지만, 여기서는 메서드만 있어요. `sd.sin(A)`는 메서드를 알려 주는 `TypeError`예요.
- **DOK에도 메서드가 있어요.** 결과는 CSR이에요(scipy의 DOK에는 이 메서드들이 없어요).
- **COO의 원래 배열을 바꾸지 않아요.** scipy는 함수를 적용하기 전에 A를 제자리에서 `sum_duplicates()`해요.
- **`power`는 n > 0만 받고 `dtype=` 인자가 없어요.** scipy는 음수 지수도 받아서 저장하지 않은 자리를 0으로 둬요. dtype은 `astype`으로 바꿔요.
- **`multiply(밀집)`의 결과가 A의 형식이에요.** scipy는 COO예요. 결과가 A보다 커지는 브로드캐스트도 받지 않아요.
- **`maximum(c)`·`minimum(c)`가 꽉 차도 경고가 없어요.** scipy는 `SparseEfficiencyWarning`을 낼 수 있어요.
