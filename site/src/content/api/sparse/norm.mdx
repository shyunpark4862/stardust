## 한눈에 보기

노름은 벡터나 행렬의 "크기"를 숫자 하나로 잰 것이에요. 오차가 얼마나 큰지, 반복이 수렴했는지, 두 행렬이 얼마나 다른지를 잴 때 써요. 노름의 여러 종류와 그 뜻은 밀집 배열의 [노름](/api/linalg/norms/) 페이지가 그림과 함께 설명해요. `sd.sparse.norm`은 같은 노름을 희소 배열에서 재요.

```python
>>> A = sd.sparse.csr_array(sd.asarray([[1.0, 0.0, -2.0],
...                                     [0.0, 0.0, 3.0],
...                                     [4.0, 0.0, 0.0]]))
>>> sd.sparse.norm(A)
5.477225575051661
```

2차원 희소 배열의 기본은 Frobenius 노름, 곧 모든 원소의 제곱합의 제곱근 $\sqrt{1 + 4 + 9 + 16} = \sqrt{30}$이에요. 저장되지 않은 0은 더해도 0이라 저장된 원소만 읽어요.

## 행렬 노름

2차원 배열에 `axis`를 주지 않으면(또는 두 축을 주면) 행렬 노름이에요. `ord`로 종류를 골라요.

| `ord` | 뜻 | 위의 `A` |
|---|---|---:|
| `'fro'`(기본값) | 모든 원소의 제곱합의 제곱근 | 5.4772… |
| `1` | 열마다 절댓값의 합, 그 가운데 가장 큰 것 | 5 |
| `-1` | 열마다 절댓값의 합, 그 가운데 가장 작은 것 | 0 |
| `sd.inf` | 행마다 절댓값의 합, 그 가운데 가장 큰 것 | 4 |
| `-sd.inf` | 행마다 절댓값의 합, 그 가운데 가장 작은 것 | 3 |
| `2` | 가장 큰 특이값(벡터를 가장 크게 늘이는 배율) | 4.2223… |

```python
>>> sd.sparse.norm(A, ord=1)
5.0
>>> sd.sparse.norm(A, ord=-1)
0.0
>>> sd.sparse.norm(A, ord=sd.inf)
4.0
>>> sd.sparse.norm(A, ord=-sd.inf)
3.0
>>> sd.sparse.norm(A, ord=2)
4.222372215324721
```

`ord=-1`이 0인 것은 가운데 열이 모두 0이라서예요.

`1`, `-1`, `inf`, `-inf`, `'fro'`는 저장된 원소의 절댓값을 줄마다 더하는 것이라 저장된 원소 수에 비례하는 일이에요. `ord=2`는 다르게, 가장 큰 특이값을 반복으로 구해요([svds](/api/sparse/svds/)의 `k=1`). 그래서 다른 노름보다 일이 많고, 저장된 값에 NaN이나 inf가 있으면 `ValueError`예요. 행이나 열이 하나뿐인 행렬의 `ord=2`는 그 벡터의 2-노름이에요.

`axis=(1, 0)`은 전치의 노름이에요. 열과 행의 역할이 바뀌므로 `ord=1`이 행의 합이 돼요.

```python
>>> Z = sd.sparse.csr_array(sd.asarray([[1.0, 2.0], [3.0, 4.0]]))
>>> sd.sparse.norm(Z, ord=1), sd.sparse.norm(Z, axis=(1, 0), ord=1)
(6.0, 7.0)
```

## 벡터 노름

1차원 희소 배열이면 벡터 노름이에요. `ord`의 기본값은 2(유클리드 길이)예요.

```python
>>> x = sd.sparse.coo_array(sd.asarray([3.0, 0.0, 4.0]))
>>> sd.sparse.norm(x)
5.0
>>> sd.sparse.norm(x, ord=1)
7.0
>>> sd.sparse.norm(x, ord=sd.inf)
4.0
>>> sd.sparse.norm(x, ord=0)
2.0
```

| `ord` | 뜻 |
|---|---|
| None(= 2) | $\sqrt{\sum \lvert x_i\rvert^2}$ |
| p(실수) | $\big(\sum \lvert x_i\rvert^p\big)^{1/p}$ |
| `sd.inf` | 절댓값이 가장 큰 원소의 절댓값 |
| `-sd.inf` | 절댓값이 가장 작은 원소의 절댓값 |
| `0` | 0이 아닌 원소의 수(float) |

**저장되지 않은 0도 원소예요.** 그래서 0이 하나라도 있는 벡터의 `-sd.inf`와 음수 p의 노름은 0이에요. 밀집 배열에서 같은 벡터를 잰 것과 같아요.

```python
>>> sd.sparse.norm(x, ord=-sd.inf), sd.sparse.norm(x, ord=-1)
(0.0, 0.0)
```

## `axis`: 줄마다의 노름

2차원 배열에 축 하나를 주면 그 축을 따라 줄마다 벡터 노름을 재서 밀집 float64 배열로 돌려줘요. `axis=0`은 열마다, `axis=1`은 행마다예요.

```python
>>> sd.sparse.norm(A, axis=0)
array([4.123105625617661,               0.0, 3.605551275463989], dtype=float64)
>>> sd.sparse.norm(A, axis=1, ord=sd.inf)
array([2.0, 3.0, 4.0], dtype=float64)
>>> sd.sparse.norm(A, axis=0, ord=0)
array([2.0, 0.0, 2.0], dtype=float64)
```

축 하나의 노름은 벡터 노름이라 `ord`에 `'fro'` 같은 문자열을 줄 수 없어요(`TypeError`).

## 0, NaN, dtype

저장된 0과 NaN, dtype의 공통 규칙은 [기본 개념](/api/sparse/basics/)에 있어요.

- 제곱하면 넘치는 큰 값도, 결과가 float64로 표현되면 inf가 되지 않아요. 합이 넘치거나 모든 항이 아주 작으면 그 줄의 최댓값으로 나눠서 다시 더해요.

  ```python
  >>> big = sd.sparse.csr_array(sd.asarray([[1e200, 0.0], [0.0, 1e200]]))
  >>> sd.sparse.norm(big)
  1.414213562373095e+200
  ```

- NaN이 있으면 결과가 NaN이에요. `ord=0`은 NaN도 0이 아닌 원소로 세요. `ord=2`의 행렬 노름만 `ValueError`예요.

  ```python
  >>> B = sd.sparse.csr_array(sd.asarray([[sd.nan, 1.0], [0.0, 2.0]]))
  >>> sd.sparse.norm(B, axis=0)
  array([             nan, 2.23606797749979], dtype=float64)
  >>> sd.sparse.norm(B, ord=2)
  Traceback (most recent call last):
      ...
  ValueError: norm(): 'x' contains NaN or infinity
  ```

- 중복이 있는 COO는 중복을 더한 값(`toarray()`에서 보이는 값)의 노름이에요.

  ```python
  >>> C = sd.sparse.coo_array((sd.asarray([1.0, 2.0]), (sd.asarray([0, 0]), sd.asarray([1, 1]))), shape=(2, 2))
  >>> sd.sparse.norm(C)
  3.0
  ```

- 복소수는 절댓값으로 재요. 결과는 언제나 실수예요. bool과 int64는 float64로 계산해요.
- 원소가 없는 배열(모두 0이거나 크기가 0)의 노름은 0이에요.

## `ord`의 규칙과 에러

```python
>>> sd.sparse.norm(A, ord=3)
Traceback (most recent call last):
    ...
ValueError: norm(): 'ord' must be 'fro', 1, -1, 2, inf or -inf, not 3
>>> sd.sparse.norm(A, ord='nuc')
Traceback (most recent call last):
    ...
ValueError: norm(): 'ord' must be 'fro', 1, -1, 2, inf or -inf, not 'nuc'
>>> sd.sparse.norm(A, ord=True)
Traceback (most recent call last):
    ...
TypeError: norm(): 'ord' must be a str, an int or a float, not bool
>>> sd.sparse.norm(A, axis=0, ord='fro')
Traceback (most recent call last):
    ...
TypeError: norm(): 'ord' must be an int or a float, not str
>>> sd.sparse.norm(A, axis=(0, 0))
Traceback (most recent call last):
    ...
ValueError: norm(): repeated axis
```

- 행렬 노름의 `'nuc'`(특이값의 합)과 −2(가장 작은 특이값)는 없어요. 가장 작은 특이값은 [svds](/api/sparse/svds/)의 `which='SM'`으로 구해요.
- 같은 값이면 float(`2.0`, `float('inf')`)도 받아요.
- `ord`, `axis`는 키워드로 줘요.

## 밀집 배열의 노름과 언제 무엇을

희소 배열에는 `sd.sparse.norm`, 밀집 배열에는 [sd.linalg.matrix_norm과 vector_norm](/api/linalg/norms/)이에요. 두 쪽의 `ord`의 뜻, 받는 값, 메시지가 같고, 같은 행렬이면 값이 반올림 차이 안에서 같아요. 서로 바꿔 주면 맞는 쪽을 짚는 `TypeError`예요.

```python
>>> sd.linalg.matrix_norm(A.toarray(), ord=2)
4.222372215324721
>>> sd.sparse.norm(A.toarray())
Traceback (most recent call last):
    ...
TypeError: norm(): 'x' must be a sparse array, not ndarray; for a dense array use sd.linalg.matrix_norm or sd.linalg.vector_norm
>>> sd.linalg.matrix_norm(A)
Traceback (most recent call last):
    ...
TypeError: matrix_norm(): 'x' must be an sd.ndarray, not csr_array; for a sparse array use sd.sparse.norm
```

| 상황 | 쓸 것 |
|---|---|
| 희소 배열의 노름 | `sd.sparse.norm` |
| 밀집 배열, 여러 행렬을 한 번에(배치), `'nuc'`·−2 | `sd.linalg.matrix_norm`, `vector_norm` |
| 원소가 보이지 않는 연산자(역행렬 등)의 1-노름 | [onenormest](/api/sparse/onenormest/) |

## 정확도

합으로 재는 노름(1, −1, inf, −inf, Frobenius, 벡터의 p-노름)은 참값 $v$와 $|\hat v - v| \le (\gamma_m + 2\varepsilon)\,v$ 안이에요. $m$은 가장 긴 줄의 항 수(Frobenius는 저장된 원소 수), $\gamma_m = m\,u/(1 - m\,u)$, $u = 2^{-53}$, $\varepsilon = 2^{-52}$예요. `ord=2`는 [svds](/api/sparse/svds/)의 약속($1000\,\varepsilon\,\lVert A\rVert_2$)이에요. Arb(구간 산술)로 만든 참값과 견준 시험에서 가장 큰 오차는 이 한계의 0.17배(합의 노름), 0.007배(Frobenius), 0.014배(2-노름)예요.

## scipy를 아는 분께

- `scipy.sparse.linalg.norm`과 같은 함수예요. `sd.sparse.norm`으로 불러요.
- `ord`는 키워드로만 받아요(scipy는 위치 인자도 돼요). `'f'` 별칭은 없어요.
- 벡터의 `ord=0`은 float이에요(scipy는 int).
- 음수 p는 저장되지 않은 0도 원소로 세요. scipy는 저장된 값만 거듭제곱해요.
- 중복이 있는 COO의 `'fro'`는 중복을 더한 값의 노름이에요. scipy는 저장된 값을 그대로 써요.
- 0인 행이 있는 행렬의 `ord=2`도 계산해요. scipy는 그런 행렬에서 시작 벡터 때문에 `ArpackError`를 낼 수 있어요.
