## 한눈에 보기

[`fft`](/api/fft/fft/)의 결과는 수의 배열일 뿐이고 어느 칸이 어떤 진동수인지는 적혀 있지 않아요. `fftfreq(n)`이 그 대응을 만들어요. 표본 `n`개를 간격 `d`로 쟀다면 $k$번째 칸의 진동수는 $k/(n d)$이고, 뒤쪽 절반은 음의 진동수예요.

```python
>>> import stardust as sd
>>> sd.fft.fftfreq(8)
array([   0.0,  0.125,   0.25,  0.375,   -0.5, -0.375,  -0.25, -0.125], dtype=float64)
>>> sd.fft.fftfreq(8, d=0.1)
array([  0.0,  1.25,   2.5,  3.75,  -5.0, -3.75,  -2.5, -1.25], dtype=float64)
>>> sd.fft.rfftfreq(8, d=0.1)
array([ 0.0, 1.25,  2.5, 3.75,  5.0], dtype=float64)
```

`d=0.1`은 0.1초마다 쟀다는 뜻이고 결과는 Hz예요. 표본 8개가 0.8초를 덮으므로 칸 사이의 간격이 $1/0.8 = 1.25$ Hz예요.

## 칸의 순서

`fft` 결과의 칸은 0에서 시작해 양의 진동수가 커지는 순서로 가다가, 가운데에서 가장 낮은 음의 진동수로 넘어가 다시 0 쪽으로 올라와요.

  <ArrayFig name="fftfreq(8)" data={[0, 0.125, 0.25, 0.375, -0.5, -0.375, -0.25, -0.125]} tones={['', '', '', '', 'a', 'a', 'a', 'a']} />
</Fig>

길이 `n`의 변환은 진동수를 $1/(nd)$의 정수배로만 가려내요. 그리고 표본 간격이 `d`이면 $1/(2d)$보다 빠른 떨림은 더 느린 떨림과 구별되지 않아요. 한 칸에 $k$번 도는 것과 $k - n$번 도는 것이 표본 위에서 같은 값이라서, 뒤쪽 절반의 칸을 음의 진동수로 읽어요.

| | `fftfreq(n, d=d)`의 값 |
|---|---|
| `n`이 짝수 | $0, 1, \dots, \frac{n}{2} - 1, -\frac{n}{2}, \dots, -1$을 $nd$로 나눈 것 |
| `n`이 홀수 | $0, 1, \dots, \frac{n-1}{2}, -\frac{n-1}{2}, \dots, -1$을 $nd$로 나눈 것 |

짝수 `n`에서 가운데 칸 $n/2$는 $+1/(2d)$와 $-1/(2d)$가 겹치는 칸이고, `fftfreq`는 음수로 적어요.

```python
>>> sd.fft.fftfreq(7)
array([                 0.0,  0.14285714285714285,   0.2857142857142857,
        0.42857142857142855, -0.42857142857142855,  -0.2857142857142857,
       -0.14285714285714285], dtype=float64)
>>> sd.fft.fftfreq(6)
array([                 0.0,  0.16666666666666666,   0.3333333333333333,
                       -0.5,  -0.3333333333333333, -0.16666666666666666], dtype=float64)
```

낮은 진동수부터 차례로 늘어놓으려면 [`fftshift`](/api/fft/fftshift/)를 써요.

```python
>>> sd.fft.fftshift(sd.fft.fftfreq(6))
array([                -0.5,  -0.3333333333333333, -0.16666666666666666,
                        0.0,  0.16666666666666666,   0.3333333333333333], dtype=float64)
```

## `rfftfreq`

실수 신호의 스펙트럼은 음의 진동수 쪽이 양의 쪽의 켤레라서 [`rfft`](/api/fft/rfft/)는 앞의 $n//2 + 1$칸만 돌려줘요. `rfftfreq(n)`이 그 칸들의 진동수예요. 모두 0 이상이고, 짝수 `n`의 마지막 칸은 $+1/(2d)$예요.

```python
>>> sd.fft.rfftfreq(8)
array([  0.0, 0.125,  0.25, 0.375,   0.5], dtype=float64)
>>> sd.fft.rfftfreq(7)
array([                0.0, 0.14285714285714285,  0.2857142857142857,
       0.42857142857142855], dtype=float64)
```

`n`에는 신호의 길이를 줘요. `rfft` 결과의 길이 5를 주면 안 돼요. 길이 8과 9의 신호가 모두 5칸의 결과를 내지만 진동수는 달라요.

```python
>>> sd.fft.rfftfreq(9)
array([               0.0, 0.1111111111111111, 0.2222222222222222,
       0.3333333333333333, 0.4444444444444444], dtype=float64)
```

## 신호에서 진동수 찾기

1초 동안 100번(0.01초 간격) 잰 신호에 12 Hz와 30 Hz의 떨림이 섞여 있어요. `rfft`의 크기가 큰 칸을 찾고 `rfftfreq`로 그 칸의 진동수를 읽어요.

```python
>>> n, d = 100, 0.01
>>> t = sd.arange(n) * d
>>> x = sd.sin(2 * sd.pi * 12 * t) + 0.5 * sd.sin(2 * sd.pi * 30 * t)
>>> amp = sd.abs(sd.fft.rfft(x, norm='forward')) * 2
>>> freq = sd.fft.rfftfreq(n, d=d)
>>> k = int(sd.argmax(amp))
>>> k, float(freq[k])
(12, 12.0)
>>> round(float(amp[12]), 6), round(float(amp[30]), 6)
(1.0, 0.5)
```

`norm='forward'`의 결과에 2를 곱하면 사인의 진폭이 돼요(양과 음의 진동수에 반씩 나뉘어 있기 때문이에요). 칸 사이의 간격은 $1/(nd) = 1$ Hz예요.

## 값을 만드는 방법과 경계

값은 정수 $k$에 $1/(nd)$를 곱해서 만들어요. $1/(nd)$를 먼저 한 번 계산하므로 $k/(nd)$를 바로 나눈 값과 끝자리가 다를 수 있어요.

| 입력 | 결과 |
|---|---|
| `n = 1` | `[0.0]` |
| `d`가 음수 | 부호가 모두 뒤집혀요(첫 칸은 `-0.0`) |
| `d`가 int | float로 바꿔 써요 |
| `n = 0`, `d = 0`, `d`가 NaN·inf | `ValueError` |

```python
>>> sd.fft.fftfreq(1)
array([0.0], dtype=float64)
>>> sd.fft.fftfreq(4, d=-0.5)
array([-0.0, -0.5,  1.0,  0.5], dtype=float64)
>>> sd.fft.fftfreq(4, d=2)
array([   0.0,  0.125,  -0.25, -0.125], dtype=float64)
```

## numpy·scipy를 아는 분께

- `numpy.fft.fftfreq`·`rfftfreq`, `scipy.fft.fftfreq`·`rfftfreq`와 이름과 뜻이 같아요. 지금은 numpy와 비트까지 같은 값을 내요(약속은 아니에요).
- `d`는 키워드로만 받아요. `fftfreq(8, 0.1)`은 `TypeError`예요.
- `n = 0`과 `d = 0`은 `ValueError`예요. numpy와 scipy는 `ZeroDivisionError`예요.
- `n`에 float나 bool을 주면 `TypeError`예요.
- `device` 인자가 없어요. 결과는 언제나 float64의 `sd.ndarray`예요.
