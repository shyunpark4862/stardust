## 한눈에 보기

주사위를 60번 던져서 눈마다 나온 횟수를 셌어요. 주사위가 공정하다면 눈마다 10번쯤 나와야 해요. 카이제곱 적합도 검정은 관측한 횟수가 기대한 횟수와 우연이라고 보기 어려울 만큼 다른지를 물어요.

- **귀무가설**: 범주마다의 확률이 기대한 값이에요(여기서는 모든 눈이 1/6).
- **대립가설**: 적어도 한 범주의 확률이 달라요.

```python
>>> import stardust as sd
>>> die = [8, 9, 12, 7, 11, 13]
>>> r = sd.htest.chisquare(die)
>>> r
ChisquareResult(statistic=2.8, pvalue=0.730786, df=5)
```

$\chi^2 = 2.8$, 자유도 5, p = 0.73이라 주사위가 공정하지 않다는 근거가 없어요. `f_exp`를 주지 않으면 모든 범주의 기대 빈도가 관측 빈도의 평균(여기서는 10)이에요.

## 통계량

범주가 $k$개, 관측 빈도가 $O_i$, 기대 빈도가 $E_i$면

$$
\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}
$$

이고, 귀무가설에서 빈도가 클 때 자유도 $k - 1 - \text{ddof}$의 카이제곱 분포를 따라요. p값은 그 위 꼬리 $P(\chi^2_{\nu} \ge \chi^2)$예요. 차의 제곱을 기대 빈도로 나누니, 같은 차라도 기대 빈도가 작은 범주에서 더 크게 쳐요.

```python
>>> sum((o - 10) ** 2 / 10 for o in die)
2.8000000000000003
>>> sd.stats.ChiSquared(df=5).ccdf(2.8) == r.pvalue
True
```

## `f_exp`: 기대 빈도

이론이 범주마다 다른 확률을 예측하면 그 확률에 전체 개수를 곱한 기대 빈도를 줘요. 멘델 유전에서 잡종끼리 교배한 자손은 세 유전자형이 1 : 2 : 1로 나와야 해요. 자손 100개체를 셌어요.

```python
>>> obs = [30, 50, 20]
>>> sd.htest.chisquare(obs, [25.0, 50.0, 25.0])
ChisquareResult(statistic=2, pvalue=0.367879, df=2)
```

기대 빈도 대신 확률을 주면 두 합이 달라서 에러예요. 합을 보는 검사를 끄면(`sum_check=False`) 계산은 하지만 뜻이 없는 값이 나와요.

```python
>>> sd.htest.chisquare(obs, [0.25, 0.5, 0.25])
Traceback (most recent call last):
    ...
ValueError: chisquare(): the sums of 'f_obs' and 'f_exp' must agree to a relative tolerance of 1.49e-08 in each sample, not 99 (sum_check)
>>> sd.htest.chisquare(obs, [0.25, 0.5, 0.25], sum_check=False)
ChisquareResult(statistic=10001, pvalue=0, df=2)
>>> sd.htest.chisquare(obs, [100 * p for p in (0.25, 0.5, 0.25)])
ChisquareResult(statistic=2, pvalue=0.367879, df=2)
```

`sum_check`는 표본마다 두 합이 상대 2⁻²⁶(약 1.5e-8) 안에서 같은지만 봐요. 반올림 크기의 차는 통과해요.

## `ddof`: 데이터에서 맞춘 모수

기대 빈도를 데이터에서 추정한 모수로 만들었다면 그 수만큼 자유도를 줄여요. 모수를 맞추면 기대 빈도가 관측에 가까워져서 $\chi^2$가 작아지기 때문이에요.

제품 200개에서 흠의 개수를 셌어요(0개, 1개, 2개, 3개, 4개 이상). 흠의 수가 포아송 분포를 따르는지 보는데, 평균 $\lambda$를 데이터에서 구했으니(4개 이상은 4로 셌어요) `ddof=1`이에요.

```python
>>> counts = [52, 70, 48, 20, 10]
>>> lam = (0 * 52 + 1 * 70 + 2 * 48 + 3 * 20 + 4 * 10) / 200
>>> P = sd.stats.Poisson(mu=lam)
>>> probs = [P.pmf(0), P.pmf(1), P.pmf(2), P.pmf(3), P.ccdf(3)]
>>> expected = [200 * p for p in probs]
>>> sd.htest.chisquare(counts, expected, ddof=1)
ChisquareResult(statistic=0.139305, pvalue=0.986736, df=3)
```

자유도는 $5 - 1 - 1 = 3$이에요. 자유도가 0 이하가 되면 p값은 NaN이에요.

```python
>>> sd.htest.chisquare(die, ddof=5)
ChisquareResult(statistic=2.8, pvalue=nan, df=0)
>>> sd.htest.chisquare(die, ddof=1.0)
Traceback (most recent call last):
    ...
TypeError: chisquare(): 'ddof' must be an int, not float
```

<Callout type="note" title="기대 빈도가 작으면">
카이제곱 분포는 빈도가 클 때의 근사예요. 흔히 모든 기대 빈도가 5 이상이기를 바라요. 기대 빈도가 작은 범주가 있으면 이웃 범주와 합치거나, 범주가 둘이면 [`binomtest`](/api/htest/binomtest/) 같은 정확한 검정을 써요.
</Callout>

## 결과 읽기

결과는 `statistic`, `pvalue`, `df` 세 필드예요. 튜플로 풀면 앞의 둘이 나와요. `df`는 자유도이고 언제나 float예요. 필드는 읽기만 해요.

```python
>>> chi2, p = r
>>> r.df
5.0
>>> print(r.summary())
                       Chi-squared goodness-of-fit test
==============================================================================
Statistic:                       2.800  No. Categories:                      6
P-value:                         0.731
Df:                                  5
==============================================================================
```

머리 오른쪽의 `No. Categories`는 범주의 수예요. 빈도 자체가 데이터라서 관측 수를 따로 적지 않아요. 결과 객체의 공통 규칙은 [결과 객체 읽기](/api/htest/results/)에 있어요.

## 여러 표본을 한 번에

`axis`를 주면 그 축을 따라 범주를 읽고 나머지 축의 칸마다 따로 검정해요. `f_exp`는 `f_obs`와 브로드캐스트돼요.

```python
>>> two = [[8, 9, 12], [7, 11, 13]]
>>> sd.htest.chisquare(two, axis=1).pvalue
array([ 0.6387284587719573, 0.40526025778326935], dtype=float64)
>>> sd.htest.chisquare(two)
ChisquareResult(statistic=2.8, pvalue=0.730786, df=5)
```

`axis=None`(기본값)은 2차원 배열도 범주 여섯 개로 펼쳐서 검정 하나예요. 행과 열이 두 변수인 분할표에서 두 변수가 독립인지 묻는 것은 다른 검정이고 [`chi2_contingency`](/api/htest/chi2_contingency/)예요.

NaN은 `nan_policy`를 따라요. `'omit'`은 NaN인 범주를 빼고, `f_exp`가 있으면 그 쌍을 함께 빼요. 공통 규칙은 [가설검정의 기본](/api/htest/basics/)에 있어요.

```python
>>> sd.htest.chisquare([10, 20, float('nan'), 15])
ChisquareResult(statistic=nan, pvalue=nan, df=nan)
>>> sd.htest.chisquare([10, 20, float('nan'), 15], nan_policy='omit')
ChisquareResult(statistic=3.33333, pvalue=0.188876, df=2)
```

## 특수한 경우

- **범주가 하나**면 통계량은 0이고 자유도가 0이라 p값은 NaN이에요. 빈 입력은 모두 NaN이에요.
- **기대 빈도가 0인 범주**: 관측도 0이면 0 ÷ 0이라 NaN, 관측이 있으면 inf(p = 0)예요.

```python
>>> sd.htest.chisquare([5]), sd.htest.chisquare([])
(ChisquareResult(statistic=0, pvalue=nan, df=0), ChisquareResult(statistic=nan, pvalue=nan, df=nan))
>>> sd.htest.chisquare([5, 1, 4], [5, 0, 5])
ChisquareResult(statistic=inf, pvalue=0, df=2)
```

## 정확도

- 통계량과 p값은 Arb(구간 산술)로 계산한 참값과 견줘 Cressie–Read 계열 25문제에서 통계량의 상대오차가 2.4e-16, p값이 6.7e-14 안이에요(정확도 약속의 0.024배와 0.017배). 자유도는 정확해요.
- `f_exp=None`의 기대 빈도인 평균을 정확하게 구해서 $\sum (O_i - E_i)$가 0에 가깝게 남아요.
- 같은 입력이면 실행마다 같은 비트예요. 지금은 스레드 수와도 상관없이 같아요(약속은 아니에요).

## scipy를 아는 분께

scipy 1.18.1, R 4.6.2 기준이에요.

- `scipy.stats.chisquare(f_obs, f_exp)`, R의 `chisq.test(x, p = )`와 같은 통계량과 p값이에요.
- 기본 `axis`가 None이에요. scipy는 0이라 2차원 입력에서 열마다 검정하지만, 여기서는 배열 전체가 검정 하나예요. scipy처럼 열마다 하려면 `axis=0`을 줘요.
- 결과에 자유도 `df`가 있어요(scipy의 결과에는 없어요). 튜플로 풀면 scipy처럼 둘이에요.
- `f_exp`는 위치로만(둘째 인자), `ddof`와 나머지 옵션은 키워드로만 받아요. scipy는 `chisquare(obs, exp, 1)`처럼 `ddof`를 위치로도, `f_exp=`를 키워드로도 받아요.
- `sum_check`는 scipy와 같은 허용오차(√ε)예요. R의 `p =`는 확률을 받아요. 여기서는 빈도예요.
