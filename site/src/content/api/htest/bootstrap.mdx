어느 동네 12가구의 한 달 전기 요금(만 원)이에요. 한 집(12.4)이 유난히 많이 써요.

```python
>>> x = [3.1, 4.7, 2.2, 8.9, 5.0, 3.8, 12.4, 4.1, 6.3, 2.9, 5.6, 7.2]
```

평균은 5.52예요. 이 평균이 동네 전체의 평균과 얼마나 다를 수 있을까요? 모집단에서 12가구를 또 뽑을 수는 없지만, **가진 표본을 모집단 대신 쓸 수는 있어요**. 12개에서 복원 추출로 12개를 뽑으면(같은 집이 두 번 뽑히기도 해요) "다시 뽑은 표본" 하나가 돼요. 이것을 수천 번 하고 평균을 계산하면, 평균이 표본마다 얼마나 흔들리는지 보여 주는 **붓스트랩 분포**를 얻어요.

## 기본 사용

통계량은 표본을 받아 수를 돌려주는 함수예요. `axis`를 받게 만들면 많은 재표본을 한 번에 계산해요. 무작위로 뽑으므로 `rng`가 꼭 필요해요.

```python
>>> def mean(a, axis):
...     return sd.mean(a, axis=axis)
>>> r = sd.htest.bootstrap((x,), mean, n_resamples=2000, rng=sd.random.default_rng(42))
>>> r
BootstrapResult(bootstrap_distribution=<array of shape (2000,)>, standard_error=0.799729)
>>> r.conf_int()
array([4.3083873453182795,  7.601199040810908], dtype=float64)
```

평균의 표준오차는 0.80이고, BCa 95% 구간은 [4.31, 7.60]이에요. 구간은 결과가 들고 있는 붓스트랩 분포에서 만들어요. 그래서 다른 수준의 구간은 다시 뽑지 않고 바로 나와요.

```python
>>> r.conf_int(alpha=0.1)
array([ 4.456710088214021, 7.2749999999999995], dtype=float64)
>>> print(r.summary())
                               Bootstrap (BCa)
==============================================================================
Standard error:                 0.7997  Alternative:                 two-sided
                                        No. Observations:                   12
                                        Resamples:                        2000
==============================================================================
               [0.025     0.975]
------------------------------------------------------------------------------
statistic       4.308      7.601
==============================================================================
```

표본 하나도 `(x,)`처럼 튜플로 줘요. `data`는 언제나 표본의 묶음이에요.

## 구간을 만드는 방법

| method | 구간 | 성질 |
|---|---|---|
| `'percentile'` | 붓스트랩 분포의 alpha/2와 1 − alpha/2 분위수 | 가장 단순해요 |
| `'basic'` | 관측 θ̂에 대해 percentile 구간을 뒤집은 [2θ̂ − 위, 2θ̂ − 아래] | 붓스트랩 분포의 치우침을 반대로 보정해요 |
| `'BCa'`(기본값) | 치우침(z₀)과 가속(a)으로 고친 분위수 | 대개 가장 정확해요. 가속을 잭나이프로 구하느라 관측 하나씩을 뺀 n개의 표본에서도 통계량을 계산해요 |

```python
>>> for m in ['percentile', 'basic', 'BCa']:
...     rm = sd.htest.bootstrap((x,), mean, n_resamples=2000, method=m, rng=sd.random.default_rng(42))
...     print(f"{m:10s}", [round(v, 3) for v in rm.conf_int().tolist()])
percentile [4.1, 7.25]
basic      [3.783, 6.934]
BCa        [4.308, 7.601]
```

같은 시드라서 세 방법이 같은 붓스트랩 분포를 써요. BCa는 두 가지를 고쳐요. 붓스트랩 분포의 가운데가 관측과 어긋난 정도(z₀: 관측보다 작은 재표본의 몫을 정규분포의 분위수로 바꾼 값, 같은 값은 반만 세요)와, 통계량의 표준오차가 참값에 따라 변하는 정도(가속 a: 하나씩 빼고 계산한 잭나이프 값의 치우침)예요. 이 자료처럼 분포가 치우친 경우에 차이가 커요. 분위수는 numpy의 `'linear'` 방법(가까운 두 값 사이의 직선 보간)으로 구해요.

## 한쪽 구간

`alternative='greater'`는 아래 끝만 있는 구간 [아래 끝, ∞]이에요. 그 꼬리에 alpha를 다 둬요.

```python
>>> sd.htest.bootstrap((x,), mean, n_resamples=2000, alternative='greater', rng=sd.random.default_rng(42)).conf_int()
array([4.456710088214021,               inf], dtype=float64)
```

## 여러 표본과 짝

통계량이 표본 여럿을 받으면 표본마다 따로 복원 추출해요. 두 집단의 평균 차의 구간이에요.

```python
>>> a = [1.2, 2.3, 2.9, 4.1, 5.0, 6.2, 6.8, 8.0]
>>> b = [2.0, 1.9, 3.5, 3.9, 5.8, 5.5, 7.4, 7.7]
>>> def mean_diff(p, q, axis):
...     return sd.mean(p, axis=axis) - sd.mean(q, axis=axis)
>>> sd.htest.bootstrap((a, b), mean_diff, n_resamples=2000, rng=sd.random.default_rng(1)).conf_int()
array([           -2.2375, 2.0874999999999995], dtype=float64)
```

상관계수처럼 두 값이 한 관측의 짝이면 `paired=True`로 관측 번호를 함께 뽑아요. 그래야 짝이 깨지지 않아요.

```python
>>> def corr(p, q, axis):
...     return sd.htest.pearsonr(p, q, axis=axis).statistic
>>> rc = sd.htest.bootstrap((a, b), corr, paired=True, n_resamples=2000, rng=sd.random.default_rng(1))
>>> rc.conf_int()
array([0.8849481091023371, 0.9886268470681132], dtype=float64)
```

[pearsonr](/api/htest/pearsonr/)의 `conf_int(method=BootstrapMethod(...))`가 같은 계산을 해요.

```python
>>> bm = sd.htest.BootstrapMethod(n_resamples=2000, rng=sd.random.default_rng(1))
>>> sd.htest.pearsonr(a, b).conf_int(method=bm)
array([0.8849481091023371, 0.9886268470681132], dtype=float64)
```

## 통계량 함수와 배치

통계량은 표본마다 배열 하나를 받아요. 벡터화한 함수는 재표본을 (B, n) 배열로 받아 `axis=-1`을 따라 계산하고 (B,)를 돌려줘요. `axis`가 없는 함수는 1차원 표본마다 불러요. BCa는 관측 하나씩을 뺀 n개의 표본에 대해서도 통계량을 불러요.

```python
>>> def median_1d(a):
...     return float(sd.median(a))
>>> sd.htest.bootstrap((x,), median_1d, n_resamples=2000, rng=sd.random.default_rng(42)).conf_int()
array([3.45, 6.75], dtype=float64)
```

`axis`를 주면 그 축을 따라 표본을 읽고 나머지 축이 배치예요. `bootstrap_distribution`은 (배치 모양, n_resamples), `conf_int()`는 (배치 모양, 2)예요.

```python
>>> X = sd.asarray([x, [v * 2 for v in x]])
>>> rb = sd.htest.bootstrap((X,), mean, axis=1, n_resamples=500, rng=sd.random.default_rng(42))
>>> rb.bootstrap_distribution.shape, rb.standard_error
((2, 500), array([0.8040977376047141, 1.6081954752094283], dtype=float64))
```

같은 `rng` 상태면 `batch`에 상관없이 같은 비트예요. 지금은 스레드 수와도 상관없이 같아요(약속은 아니에요).

## 퇴화한 입력

통계량이 상수이면 BCa의 가속을 정할 수 없어 구간이 NaN이에요. 경고는 없어요.

```python
>>> rk = sd.htest.bootstrap(([2., 2, 2, 2],), mean, n_resamples=100, rng=sd.random.default_rng(1))
>>> rk.conf_int(), rk.standard_error
(array([nan, nan], dtype=float64), 0.0)
```

## 붓스트랩의 한계

- 표본이 아주 작으면 표본이 모집단을 잘 대신하지 못해 구간이 너무 좁아지기 쉬워요.
- 최댓값·최솟값처럼 표본의 극단에 기대는 통계량은 붓스트랩이 잘 맞지 않아요.
- 붓스트랩 구간은 근사예요. 무작위 재표본이라 시드마다 끝이 조금씩 달라요. `n_resamples`를 늘리면 흔들림이 줄어요.

## 정확도

붓스트랩 구간에는 참값이 없어요. 같은 `rng` 상태면 `batch`에 상관없이 비트까지 같고(지금은 스레드 수와도 상관없어요), BCa 90% 구간의 포함률이 이항 한계 안에 드는지를 고정한 시드로 200번 시험해요.

## scipy를 아는 분께

- `rng`가 꼭 필요해요(`random_state`는 없어요). `axis`의 기본값은 None이에요.
- 구간은 결과의 `confidence_interval` 필드가 아니라 메서드 `conf_int(alpha=0.05)`이고 (…, 2) 배열이에요. `confidence_level` 인자가 없고, 한 번 뽑은 분포에서 수준마다 구간을 만들어요. 그래서 `bootstrap_result`로 이어 뽑는 기능은 없어요.
- BCa의 식, 분위수의 보간은 scipy의 것과 같아요. 퇴화한 BCa는 경고 대신 NaN이에요.
