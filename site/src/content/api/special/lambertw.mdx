## 한눈에 보기

Lambert W 함수는 w·eʷ = x를 w에 대해 푼 답이에요. 곱셈의 반대가 나눗셈이고 지수함수의 반대가 로그이듯, "w에 eʷ를 곱하는 함수"의 반대가 W예요.

$$W(x)\,e^{W(x)} = x$$

미지수가 지수의 안과 밖에 함께 있는 방정식(예: $x e^x = 5$, $x = e^{-x}$, $x^x = 100$)은 덧셈·곱셈·로그만으로는 풀 수 없어요. 이런 방정식을 $w e^w = (\text{어떤 값})$ 꼴로 바꾸면 W 한 번으로 답이 나와요.

- 물리와 공학: 직렬 저항이 있는 다이오드의 전류, Wien의 변위 법칙(흑체 복사가 가장 센 파장)의 상수, 지연이 있는 미분방정식의 해.
- 생물과 화학: 효소 반응 속도식(Michaelis–Menten)을 시간에 대해 푼 식, 개체군 모형.
- 수학과 컴퓨터 과학: 나무 구조의 개수를 세는 조합론, 알고리즘의 복잡도 분석, $x\log x$ 꼴의 식을 뒤집을 때.
- 통계: 무거운 꼬리를 만드는 Lambert W 변환 분포, 일부 분위수와 최적화 문제의 닫힌 해.

```python
>>> import stardust as sd
>>> w = sd.special.lambertw(sd.asarray([0.0, 1.0, sd.e]))
>>> w
array([               0.0, 0.5671432904097838,                1.0], dtype=float64)
>>> w * sd.exp(w)
array([              0.0,               1.0, 2.718281828459045], dtype=float64)
```

W(e) = 1인 이유는 1·e¹ = e이기 때문이에요. W(1) ≈ 0.567143은 "오메가 상수"라고 불러요.

## 방정식 풀기

W를 쓰는 요령은 방정식을 $(\text{무엇}) \cdot e^{(\text{같은 무엇})} = (\text{값})$ 꼴로 바꾸는 거예요. 그러면 "무엇" = W(값)이에요.

**$x e^x = 5$**: 이미 그 꼴이라 $x = W(5)$예요.

```python
>>> x = sd.special.lambertw(5.0)
>>> x
1.3267246652422002
>>> x * sd.exp(x)
5.0
```

**$x = e^{-x}$**: 양변에 $e^x$를 곱하면 $x e^x = 1$이라 $x = W(1)$, 오메가 상수예요.

```python
>>> x = sd.special.lambertw(1.0)
>>> x - sd.exp(-x)
0.0
```

**$x^x = 100$**: 로그를 취하면 $x \ln x = \ln 100$이에요. $x = e^u$로 놓으면 $u e^u = \ln 100$이라 $u = W(\ln 100)$, 그리고 $x = e^{u} = \ln 100 / W(\ln 100)$이에요.

```python
>>> y = sd.log(100.0)
>>> x = y / sd.special.lambertw(y)
>>> x
3.5972850235404175
>>> x ** x
99.99999999999999
```

**Wien의 변위 법칙**: 흑체 복사가 가장 센 파장을 구할 때 $\frac{x e^x}{e^x - 1} = 5$를 풀어야 해요. 정리하면 $(x - 5)e^{x-5} = -5e^{-5}$라서 $x = 5 + W(-5e^{-5})$예요.

```python
>>> 5 + sd.special.lambertw(-5 * sd.exp(-5.0))
4.965114231744276
```

이 값이 흑체 복사의 "가장 밝은 파장 × 온도 = 일정"이라는 법칙에 들어가는 상수예요.

## 두 가지(branch): `k=0`과 `k=-1`

$y = w e^w$의 그래프는 w = −1에서 가장 낮은 값 −1/e(약 −0.3679)를 찍고 양쪽으로 올라가요. 그래서 −1/e &lt; x &lt; 0인 x에는 $w e^w = x$를 만족하는 w가 **둘** 있어요. 하나는 −1보다 크고, 하나는 −1보다 작아요. 이 둘을 구분하는 번호가 `k`예요.

| `k` | 이름 | 정의되는 x | 값의 범위 |
|:---:|---|:---:|:---:|
| `0` (기본값) | 주가지 W₀ | x ≥ −1/e | W ≥ −1 |
| `-1` | 가지 W₋₁ | −1/e ≤ x &lt; 0 | W ≤ −1 |

```python
>>> sd.special.lambertw(-0.1)
-0.11183255915896295
>>> w = sd.special.lambertw(-0.1, k=-1)
>>> w
-3.577152063957297
>>> w * sd.exp(w)
-0.10000000000000002
```

두 답 모두 $w e^w = -0.1$을 만족해요. 어느 쪽이 필요한지는 문제가 정해요. 예를 들어 $x e^x = -0.1$에서 x가 −1보다 작아야 한다면 `k=-1`이에요.

### 정의역 밖은 NaN이에요

x &lt; −1/e이면 실수 해가 없어서 두 가지 모두 NaN이에요. `k=-1`은 x ≥ 0에서도 NaN이에요. 에러는 나지 않아요.

```python
>>> sd.special.lambertw(sd.asarray([-0.5, -1.0]))
array([nan, nan], dtype=float64)
>>> sd.special.lambertw(sd.asarray([0.5, 2.0]), k=-1)
array([nan, nan], dtype=float64)
```

### 분기점 −1/e

두 가지가 만나는 점 x = −1/e에서는 둘 다 −1이에요. 그런데 −1/e는 float64로 정확히 나타낼 수 없어요. `-1 / sd.e`로 만든 수(−0.36787944117144233)는 참 −1/e보다 아주 조금(약 8 × 10⁻¹⁸) 작아서, 엄밀히는 정의역 밖이에요. 그래도 이 수는 분기점으로 보고 두 가지 모두 −1을 내요. −1/e를 계산해서 넣는 흔한 코드가 NaN을 받지 않게 하기 위해서예요. 이보다 작은 float64 값은 NaN이에요.

```python
>>> b = -1 / sd.e
>>> b
-0.36787944117144233
>>> sd.special.lambertw(b), sd.special.lambertw(b, k=-1)
(-1.0, -1.0)
>>> sd.special.lambertw(sd.nextafter(b, -1.0))
nan
```

### `k`는 int로

`k`는 반드시 int여야 해요(numpy 정수도 돼요). `True`나 `0.0`처럼 int가 아닌 값은 `TypeError`예요. 실수 입력에 0과 −1이 아닌 정수를 주면 `ValueError`예요. 실수 입력에는 실수 가지가 그 둘뿐이기 때문이에요. 다른 가지는 아래의 복소수 입력에서 쓸 수 있어요.

```python
>>> sd.special.lambertw(1.0, k=1)
Traceback (most recent call last):
    ...
ValueError: lambertw(): 'k' must be 0 or -1 for a real argument
>>> sd.special.lambertw(1.0, k=0.0)
Traceback (most recent call last):
    ...
TypeError: lambertw(): 'k' must be an int, not float
```

## 특수값과 정확도

| x | `k=0` | `k=-1` |
|:---:|:---:|:---:|
| `0.0` | `0.0` | `-inf` |
| `-0.0` | `-0.0` | `-inf` |
| `-1/e`(가장 가까운 float64 값) | `-1.0` | `-1.0` |
| `inf` | `inf` | `nan` |
| `-inf`, −1/e보다 작은 수 | `nan` | `nan` |
| `nan` | `nan` | `nan` |

```python
>>> sd.special.lambertw(sd.asarray([0.0, -0.0, sd.inf, sd.nan]))
array([ 0.0, -0.0,  inf,  nan], dtype=float64)
>>> sd.special.lambertw(0.0, k=-1)
-inf
```

`k=-1`에서 x → 0⁻이면 W는 −∞로 가요(대략 $\ln(-x)$처럼). 그래서 `lambertw(0, k=-1)`은 `-inf`예요.

두 실수 가지 모두 정의역 전체에서 상대오차 10⁻¹⁴ 이하를 약속해요. 앞 14자리쯤이 언제나 맞는다는 뜻이에요. 분기점 바로 옆처럼 W가 급하게 변하는 곳도 포함이에요. 분기점 근처에서는 x에서 −1/e까지의 거리를 정확하게 다뤄야 하는데, 이 거리를 계산할 때 생기는 반올림까지 피하도록 만들어져 있어요.

```python
>>> sd.special.lambertw(-0.36787944117144)
-0.9999998877164061
```

이 값은 참값 −0.99999988771640…와 끝자리까지 맞아요. 정확도를 재는 방법은 [특수함수의 기본](/api/special/basics/)에 있어요.

## 복소수 입력

x에 복소수(complex128 배열이나 Python `complex`)를 넣으면 복소수 W를 계산하고 결과도 complex128이에요. 실수를 넣으면 결과가 float64인 것과 달라요.

복소수에서는 $w e^w = z$의 해가 무한히 많아요. 그 해를 정수 `k`로 번호 붙인 것이 가지예요. 그래서 복소수 입력은 <strong>모든 정수 `k`</strong>를 받아요(크기 2⁵³까지).

```python
>>> sd.special.lambertw(-1.0)
nan
>>> sd.special.lambertw(-1.0 + 0j)
(-0.3181315052047641+1.3372357014306895j)
>>> z = sd.asarray([1 + 2j, -3 + 0.5j])
>>> w = sd.special.lambertw(z, k=2)
>>> float(sd.max(sd.abs(w * sd.exp(w) - z))) < 1e-14
True
```

실수 −1은 정의역 밖이라 NaN이지만, `-1.0 + 0j`로 넣으면 복소수 답이 나와요. 실수 가지(`k=0`의 x ≥ −1/e 등)에 해당하는 곳에서는 실수 입력과 같은 값이 허수부 0으로 나와요.

```python
>>> sd.special.lambertw(sd.e + 0j)
(1+0j)
>>> type(sd.special.lambertw(1 + 0j))
<class 'complex'>
```

### 가지 자름 위의 값: 허수부 0의 부호

복소수 W는 어떤 선을 가로지르면 값이 갑자기 뛰어요. 이 선을 **가지 자름**이라고 해요. `k=0`은 음의 실수축의 (−∞, −1/e] 부분, `k≠0`은 (−∞, 0)이에요. 가지 자름 바로 위의 점에서는 허수부 0의 부호로 위쪽(+0)에서 다가온 값인지 아래쪽(−0)에서 다가온 값인지를 골라요.

```python
>>> sd.special.lambertw(complex(-1.0, 0.0))
(-0.3181315052047641+1.3372357014306895j)
>>> sd.special.lambertw(complex(-1.0, -0.0))
(-0.3181315052047641-1.3372357014306895j)
```

위와 아래의 값은 서로 켤레예요. 특히 −1/e &lt; x &lt; 0에서 `k=-1`은 위쪽(+0)이면 실수 가지 W₋₁의 값, 아래쪽(−0)이면 `k=1` 위쪽 값의 켤레예요.

```python
>>> sd.special.lambertw(complex(-0.1, 0.0), k=-1)
(-3.577152063957297+0j)
>>> sd.special.lambertw(complex(-0.1, -0.0), k=-1)
(-4.44909817870089-7.3070607892176085j)
```

복소수 입력도 모든 가지, 정의역 전체에서 상대오차 10⁻¹⁴ 이하를 약속해요. 복소수의 상대오차는 실수부와 허수부를 따로 재지 않고 크기의 비 $|\text{오차}| / |W|$로 재요.

복소수의 특수값은 이래요.

| z | 결과 |
|:---:|---|
| `0j` | `0j` (`k=0`, 0의 부호를 유지) |
| `0j`, `k≠0` | `-inf + 0j` |
| 무한대(어느 방향이든) | `inf + i(arg z + 2πk)` |
| `-1/e`(가장 가까운 float64 값) `± 0j` | 참값 −1 ± 8.2 × 10⁻⁹i |

```python
>>> sd.special.lambertw(0j, k=1)
(-inf+0j)
>>> sd.special.lambertw(complex(0.0, sd.inf))
(inf+1.5707963267948966j)
>>> sd.special.lambertw(complex(b, 0.0))
(-1+8.220079714836618e-09j)
```

마지막 줄은 실수 입력과 달라요. 실수 입력은 이 값을 분기점으로 보고 −1을 내지만, 복소수 입력은 참 −1/e보다 조금 바깥인 그 점의 참값(허수부가 아주 작은 복소수)을 내요.

## 조심할 점

### 실수 입력의 결과는 float64예요

실수를 넣으면 결과는 언제나 float64이고, 해가 없으면 NaN이에요. 복소수 해가 필요하면 `x + 0j`처럼 복소수로 바꿔서 넣으세요.

### `out=`의 dtype

`out=`의 규칙은 배열 영역의 [사칙연산](/api/array/arithmetic/)에서 설명한 것과 같아요. 복소수 입력의 결과는 complex128이라 float64 배열에 쓸 수 없어요.

```python
>>> sd.special.lambertw(sd.asarray([1 + 1j]), out=sd.empty(1))
Traceback (most recent call last):
    ...
TypeError: lambertw(): cannot implicitly convert complex128 to float64 (that would lose information); convert explicitly with astype
```

### 리스트는 받지 않아요

```python
>>> sd.special.lambertw([1.0])
Traceback (most recent call last):
    ...
TypeError: lambertw(): 'x' must be an sd.ndarray or a bool, int, float or complex, not list
```

## 비슷한 함수와의 차이

- **로그**: $\ln x$는 $e^w = x$의 해이고, $W(x)$는 $w e^w = x$의 해예요. 큰 x에서 W는 로그와 비슷하게 천천히 자라요($W(x) \approx \ln x - \ln\ln x$).
- **[loggamma](/api/special/loggamma/)**, **[wofz](/api/special/wofz/)**: `lambertw`와 함께 복소수를 받는 특수함수예요. `erf`, `erfc`, `erfcx`도 복소수를 받아요([오차함수](/api/special/erf/)).

```python
>>> x = 1e10
>>> sd.special.lambertw(x), sd.log(x) - sd.log(sd.log(x))
(20.028685413304952, 19.889233391698454)
```

## scipy를 아는 분께

- **실수를 넣으면 결과가 float64예요.** `scipy.special.lambertw`는 언제나 complex를 돌려줘요. 실수 입력에서 정의역 밖은 scipy가 복소수 답을 주지만 stardust는 NaN이에요(scipy의 `lambertw(-1.0)`은 −0.318 + 1.337i). 복소수 답이 필요하면 `x + 0j`를 넣으세요.
- `k`는 keyword-only이고 int만 받아요. 실수 입력에는 0과 −1만 돼요. `tol=` 인자는 없어요.
- **−1/e에 가장 가까운 float64 값을 분기점으로 봐요**(두 가지 모두 −1). scipy는 NaN이에요. 그 값에 `0j`를 더한 복소수 입력도 scipy는 NaN, stardust는 참값이에요.
- 분기점 근처의 정확도가 달라요. 예를 들어 `lambertw(-0.36787944117144)`의 scipy 값은 앞 9자리 정도만 맞아요.
- **(−1/e, 0) 위의 x − 0j에서 `k=-1`은 아래쪽 극한(복소수)이에요.** scipy는 이곳에서도 실수 값(위쪽 극한)을 내요.
- 복소수의 특수값이 다른 곳: `lambertw(5e-324 + 0j, k=1)`은 참값 −751.06 + 3.146i(scipy는 inf + nan·i), 무한대 입력(예: `infj`)은 `inf + i(arg z + 2πk)`(scipy는 NaN이 섞여요).
- `wrightomega`는 없어요.
