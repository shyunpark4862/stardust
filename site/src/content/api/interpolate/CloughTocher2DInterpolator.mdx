## 한눈에 보기

[`LinearNDInterpolator`](/api/interpolate/LinearNDInterpolator/)는 흩어진 점을 삼각형으로 잇고 삼각형마다 평면을 놓아요. 값은 이어지지만 삼각형의 변을 건널 때 기울기가 꺾여요. `CloughTocher2DInterpolator`는 같은 삼각분할 위에 삼각형마다 3차 곡면 조각을 놓아서 **기울기까지** 이어지게 해요. 매끄러운 현상에서 잰 자료(지형의 높이, 온도, 농도)라면 같은 자료점으로 참 곡면에 더 가까운 값을 내요.

```python
>>> import stardust as sd
>>> rng = sd.random.default_rng(7)
>>> X = rng.random((40, 2))
>>> z = sd.sin(3 * X[:, 0]) * sd.cos(2 * X[:, 1])
>>> ct = sd.interpolate.CloughTocher2DInterpolator(X, z)
>>> ct
CloughTocher2DInterpolator(points=40, dimensions=2)
>>> q = sd.asarray([[0.3, 0.6], [0.5, 0.5], [0.7, 0.2]])
>>> ct(q)
array([0.28349226295844976,  0.5388784500960837,  0.7999791730381254], dtype=float64)
>>> sd.interpolate.LinearNDInterpolator(X, z)(q)
array([0.2791825849881682,  0.532818573404182, 0.7671654792169101], dtype=float64)
>>> sd.sin(3 * q[:, 0]) * sd.cos(2 * q[:, 1])
array([0.28384457999376717, 0.5389488413540798, 0.7950684772782127], dtype=float64)
```

무작위 40점에서 $\sin 3x \cos 2y$의 값을 받아, 세 평가점에서 참값과 견줬어요. 선형보다 Clough–Tocher가 참값에 훨씬 가까워요.

## 어떻게 곡면을 만드나요

1. 자료점으로 [Delaunay 삼각분할](/api/spatial/Delaunay/)을 만들어요.
2. 자료점마다 **기울기**를 어림해요. 곡면 전체가 가장 덜 휘도록(삼각형 변마다 놓은 3차 곡선의 굽은 정도를 모두 더한 것이 가장 작도록) 기울기를 정하는 문제를 반복으로 풀어요. 만들 때 한 번이에요.
3. 삼각형마다 무게중심을 꼭짓점으로 세 개의 작은 삼각형으로 나누고, 작은 삼각형마다 3차 다항식을 놓아요. 꼭짓점의 값과 기울기, 그리고 이웃 삼각형과 기울기가 이어진다는 조건이 계수를 정해요.
4. 평가점마다 품은 삼각형을 찾아 그 3차 다항식으로 값을 계산해요.

그래서 곡면은 이런 성질을 가져요.

- **자료점을 지나요.** 자료점에서는 자료 그대로예요(비트까지, −0.0도).
- **기울기까지 이어져요**(C¹). 삼각형의 변을 건너도 꺾이지 않아요. 굽은 정도(2차 도함수)는 변에서 뛸 수 있어요.
- 값이 자료의 범위를 조금 넘을 수 있어요. 3차 곡면이라 봉우리 둘레에서 자료보다 높게 솟기도 해요. 범위를 꼭 지켜야 하면 선형 보간을 써요.

```python
>>> bool(sd.all(ct(X) == z))
True
```

## 기울기 어림: `tol`, `maxiter`, `converged`, `niter`

꼭짓점의 기울기는 꼭짓점마다 차례로, 이웃 꼭짓점의 지금 기울기를 써서 다시 정하는 일을 되풀이해서 구해요(Gauss–Seidel 반복). 모든 꼭짓점을 한 번 다시 정하는 것을 **훑기** 한 번이라고 해요.

- 한 훑기에서 기울기 성분이 바뀐 가장 큰 양이 `tol` × (그 훑기 뒤 기울기 성분의 가장 큰 크기)보다 작으면 멈춰요. 그때 `converged`는 `True`예요.
- `maxiter`번 훑을 때까지 그 기준을 지키지 못하면 거기서 멈추고 `converged`는 `False`예요. 에러나 경고는 없어요.
- `niter`는 실제로 훑은 횟수예요.

```python
>>> ct.converged, ct.niter
(True, 11)
>>> rough = sd.interpolate.CloughTocher2DInterpolator(X, z, maxiter=1)
>>> rough.converged, rough.niter
(False, 1)
>>> strict = sd.interpolate.CloughTocher2DInterpolator(X, z, tol=1e-12)
>>> strict.converged, strict.niter
(True, 21)
```

멈춤 기준은 상대적이라 자료점의 단위와 상관없어요. 좌표를 $10^6$배 해도(킬로미터를 밀리미터로) 같은 횟수를 훑고 같은 곡면을 만들어요.

```python
>>> big = sd.interpolate.CloughTocher2DInterpolator(X * 1e6, z)
>>> big.niter, big([0.3e6, 0.6e6])
(11, 0.28349226295844965)
```

`tol=0`이면 기준을 지킬 수 없으니 언제나 `maxiter`번 훑어요. `tol`은 0 이상의 유한한 수, `maxiter`는 1 이상의 int예요.

```python
>>> sd.interpolate.CloughTocher2DInterpolator(X, z, tol=-1)
Traceback (most recent call last):
    ...
ValueError: CloughTocher2DInterpolator(): 'tol' must be a finite number >= 0, not -1.0
>>> sd.interpolate.CloughTocher2DInterpolator(X, z, maxiter=0)
Traceback (most recent call last):
    ...
ValueError: CloughTocher2DInterpolator(): 'maxiter' must be >= 1, not 0
```

기울기는 반복의 허용오차만큼만 맞아요. 그래서 1차식 자료를 넣어도 곡면은 1차식과 아주 조금 달라요. 더 정확한 기울기가 필요하면 `tol`을 줄여요.

```python
>>> p = 2 * X[:, 0] + 3 * X[:, 1] + 1
>>> plane = sd.interpolate.CloughTocher2DInterpolator(X, p)
>>> plane([0.4, 0.6])
3.6000000020996725
>>> plane.grad[0]
array([ 2.00000011169311, 3.0000000206565596], dtype=float64)
```

어림한 기울기는 `grad` 속성으로 읽어요. 모양은 (n, …, 2)이고 마지막 축이 $(\partial f/\partial x, \partial f/\partial y)$예요.

## 자료점 `points`와 값 `values`

자료점은 (n, 2) 배열이거나 좌표 배열 두 개의 튜플, 또는 이미 만든 2차원 [`Delaunay`](/api/spatial/Delaunay/)예요. 3차원 자료는 받지 않아요(3차원은 [`LinearNDInterpolator`](/api/interpolate/LinearNDInterpolator/)나 [`RBFInterpolator`](/api/interpolate/RBFInterpolator/)를 써요). 삼각분할의 조건과 같은 자료점의 규칙은 `LinearNDInterpolator`와 같아요.

```python
>>> sd.interpolate.CloughTocher2DInterpolator(rng.random((10, 3)), rng.random(10))
Traceback (most recent call last):
    ...
ValueError: CloughTocher2DInterpolator(): 'points' must have 2 columns, not 3
```

값은 모두 유한해야 해요. 기울기가 모든 꼭짓점을 함께 푸는 반복이라, NaN 하나가 모든 기울기로 퍼지기 때문이에요.

```python
>>> bad = z.copy()
>>> bad[3] = sd.nan
>>> sd.interpolate.CloughTocher2DInterpolator(X, bad)
Traceback (most recent call last):
    ...
ValueError: CloughTocher2DInterpolator(): 'values' must be finite
```

값이 여러 열이거나 복소수면 열마다(복소수는 실수부와 허수부를 따로) 기울기를 어림해요. `niter`는 가장 많이 훑은 열의 횟수, `converged`는 모든 열이 `tol`로 멈췄는지예요.

```python
>>> both = sd.interpolate.CloughTocher2DInterpolator(X, sd.stack([z, 2 * z], axis=1))
>>> both([0.3, 0.6]), both.grad.shape
(array([0.28349226295844976,  0.5669845259168995], dtype=float64), (40, 2, 2))
```

## 바깥, `rescale`, 평가점

[`LinearNDInterpolator`](/api/interpolate/LinearNDInterpolator/)와 같아요.

- 자료점의 볼록 껍질 밖은 `fill_value`(기본 NaN)이고, 안팎은 정확한 판정이에요.
- 좌표에 NaN이 있는 평가점은 NaN이고, 무한한 좌표의 점은 바깥이에요.
- `rescale=True`면 축마다 평균과 범위로 옮긴 좌표에서 삼각분할하고 기울기를 어림해요. 이때 `grad`는 옮긴 좌표에서의 기울기예요.
- 평가점은 (…, 2) 배열이거나 좌표 두 개의 튜플이고, 점 하나에 스칼라 값이면 Python `float`예요.

```python
>>> ct([[2.0, 2.0], [sd.nan, 0.5]])
array([nan, nan], dtype=float64)
>>> ct((0.3, 0.6))
0.28349226295844976
```

## 속성

| 속성 | 뜻 |
|---|---|
| `points` | 준 그대로의 자료점(옮기기 전), 읽기 전용 (n, 2) float64 |
| `values` | 준 그대로의 값, 읽기 전용 (n, …) |
| `tri` | 보간이 쓰는 [`sd.spatial.Delaunay`](/api/spatial/Delaunay/). `rescale=True`면 옮긴 점의 삼각분할 |
| `fill_value` | 바깥의 값(`float`, 복소수 값이면 `complex`) |
| `grad` | 자료점마다 어림한 기울기, 읽기 전용 (n, …, 2), 값의 dtype |
| `converged` | 모든 열이 `tol`로 멈췄으면 `True` |
| `niter` | 기울기 반복의 훑기 수(열 가운데 가장 많은 것) |

```python
>>> ct.tri, ct.values.shape, ct.grad.shape
(Delaunay(n=40, d=2, nsimplex=68), (40,), (40, 2))
```

## 결과는 언제나 같아요

기울기의 반복은 꼭짓점의 색인 차례 하나로 돌고, 열 하나는 한 스레드가 처음부터 끝까지 계산해요. 그래서 기울기는 [스레드 수](/api/array/threads/)와 상관없이 같은 비트이고, 평가도 평가점마다 정의로 정해져 같은 비트예요.

평가의 오차는 주어진 기울기로 만든 3차 곡면의 정확한 값과 견줘요. 계산한 값과 그 정확한 값의 차이는 $256u \cdot K$ 이하예요($u = 2^{-53}$, $K$는 삼각형의 값과 기울기의 크기로 정한 척도). 기울기 자체는 반복의 `tol`만큼만 정해지므로 이 계약 밖이에요. 자세한 것은 [흩어진 점의 보간](/internals/interpolate/scattered/)에 있어요.

## 복사와 저장(pickle)

`copy.copy`, `copy.deepcopy`, `pickle`이 돼요. 삼각분할은 점으로 다시 만들고, 기울기는 다시 어림하지 않고 그대로 되돌려요. 되살린 객체는 같은 점에서 같은 비트를 내요.

```python
>>> import pickle
>>> back = pickle.loads(pickle.dumps(ct))
>>> back([0.3, 0.6]), back.niter
(0.28349226295844976, 11)
```

## 조심할 점

### 껍질 밖은 값이 없어요

바깥까지 값이 필요하면 [`NearestNDInterpolator`](/api/interpolate/NearestNDInterpolator/)로 채우거나 [`RBFInterpolator`](/api/interpolate/RBFInterpolator/)를 써요.

### `converged`를 확인해요

자료점이 아주 많거나 삼각형의 크기가 크게 섞여 있으면 기본 `maxiter`로 수렴하지 못할 수 있어요. 경고가 없으니, 정확한 기울기가 중요하면 `converged`를 보고 필요하면 `maxiter`를 늘려요.

### 옵션은 이름으로 줘요

```python
>>> sd.interpolate.CloughTocher2DInterpolator(X, z, 1e-6)
Traceback (most recent call last):
    ...
TypeError: CloughTocher2DInterpolator(): takes 2 positional arguments but 3 were given
```

<Callout type="note" title="어느 흩어진 점 보간을 쓸까요">

빠르고 자료의 범위를 벗어나지 않는 답은 [`LinearNDInterpolator`](/api/interpolate/LinearNDInterpolator/), 2차원에서 매끄러운 곡면은 `CloughTocher2DInterpolator`, 껍질 밖까지 값이 필요하거나 3차원 이상에서 매끄러운 곡면은 [`RBFInterpolator`](/api/interpolate/RBFInterpolator/)예요. 한 번만 부를 때는 [`griddata`](/api/interpolate/griddata/)가 간편해요.

</Callout>

## scipy·numpy를 아는 분께

- 기울기 반복이 수렴하지 못하면 경고(`GradientEstimationWarning`) 대신 `converged=False`예요. 훑은 횟수는 `niter`로 알려 줘요.
- 멈춤 기준이 상대적이라 단위와 상관없어요. scipy는 점마다 $\max(1, \lvert\text{기울기}\rvert)$로 나눈 변화를 봐서 기울기가 1보다 작은 자료에서 일찍 멈춰요. 좌표를 $10^6$배 하면 scipy의 값이 엄격한 `tol`의 값과 $8 \times 10^{-4}$ 달라지지만, 여기서는 배율과 상관없이 같은 훑기 수예요.
- 반복의 식과 기본값(`tol=1e-6`, `maxiter=400`)은 scipy와 같아요. 무작위 점에서 기울기는 scipy와 상대 $2 \times 10^{-7}$ 안이에요.
- `grad` 속성으로 기울기를 바로 읽어요. scipy의 `estimate_gradients_2d_global` 함수는 없어요.
- 값은 유한해야 해요. 값이 다른 같은 자료점은 에러예요(scipy는 말없이 한 값을 써요).
- 삼각분할이 정확한 Delaunay이고 껍질 안팎이 정확한 판정이에요. 자료점에서 자료 그대로예요(scipy는 무작위 2,000점에서 757점이 끝자리가 달라요). `__call__`의 `simplex_tolerance`는 없어요.
- `points`는 옮기기 전의 좌표, `values`는 준 모양 그대로, `grad`는 (n, …, 2)예요(scipy는 (n, 곱, 2)).
