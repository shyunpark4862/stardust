## 무엇을 계산하나요

친구 관계망에서 서로 많이 얽힌 무리를 찾고 싶어요. 친구가 많은 사람만 고르는 것으로는 부족해요. 친구는 많지만 그 친구들끼리는 서로 모르는 사람도 있기 때문이에요. 무리 **안에서** 서로 이어진 정도를 봐야 해요.

**k-코어**는 모든 노드가 그 안에서 이웃을 $k$개 이상 가진 가장 큰 부분 그래프예요. 그래프에서 이웃이 $k$개보다 적은 노드를 지우고, 그 때문에 이웃이 줄어든 노드도 다시 지우기를 더 지울 것이 없을 때까지 하면 남는 것이 k-코어예요. 노드의 **코어 수**는 그 노드가 남는 가장 큰 $k$예요.

```python
>>> import stardust as sd
>>> friends = [(0, 1), (0, 2), (0, 3), (1, 2), (1, 3), (2, 3),
...            (0, 4), (1, 4), (4, 5), (5, 6)]
>>> G = sd.zeros((8, 8))
>>> for i, j in friends:
...     G[i, j] = 1
>>> core = sd.graph.core_number(G)
>>> core
array([3, 3, 3, 3, 2, 1, 1, 0], dtype=int64)
```

0–3은 넷이 서로 모두 아는 무리라 저마다 무리 안에 이웃이 셋이고 코어 수가 3이에요. 노드 4는 이웃이 셋(0, 1, 5)이지만 5가 2-코어에서 빠지고 나면 이웃이 둘만 남아서 코어 수가 2예요. 노드 7은 이웃이 없어서 0이에요.

## 결과 읽기

결과는 노드마다 코어 수를 담은 int64 배열이에요. 몇 가지를 바로 읽을 수 있어요.

- 코어 수는 노드의 이웃 수(차수)보다 크지 않아요. 둘이 같으면 그 노드의 이웃이 모두 적어도 그만큼 촘촘한 무리에 있다는 뜻이에요.
- k-코어의 노드는 `core >= k`인 노드예요. 2-코어는 코어 수가 2 이상인 노드 전부예요.
- 가장 큰 코어 수는 그래프의 **퇴화 차수**(degeneracy)라고 해요. 그래프가 얼마나 촘촘한 속을 가졌는지 나타내는 수예요.

```python
>>> degree = ((G + G.T) != 0).sum(axis=1)
>>> degree
array([4, 4, 3, 3, 3, 2, 1, 0], dtype=int64)
>>> int(core.max())
3
```

## k-코어 꺼내기

k-코어를 그래프로 꺼내려면 `core >= k`인 노드의 번호를 골라 그 행과 열만 잘라요.

```python
>>> keep = sd.nonzero(core >= 2)[0]
>>> keep
array([0, 1, 2, 3, 4], dtype=int64)
>>> sub = G[keep][:, keep]
>>> sub.shape
(5, 5)
>>> sd.graph.core_number(sub)
array([3, 3, 3, 3, 2], dtype=int64)
```

2-코어는 노드 0–4예요. 꺼낸 그래프에서 다시 코어 수를 구해도 값이 같아요. 코어 수는 그 노드가 든 가장 촘촘한 무리로 정해져서, 바깥의 성긴 노드를 떼어도 바뀌지 않아요.

## 방향과 값은 보지 않아요

그래프를 언제나 무향으로 읽어요. `G[i, j]`와 `G[j, i]` 가운데 하나라도 있으면 $i$와 $j$가 이웃이에요. 무게도 읽지 않아요. 무게가 큰 변도 작은 변도 이웃 하나예요.

```python
>>> W = G * 7.5
>>> bool((sd.graph.core_number(W) == core).all())
True
>>> bool((sd.graph.core_number(G.T) == core).all())
True
```

희소 배열에서는 저장된 원소가 모두 변이라 0으로 저장된 원소도 변이에요. 대각 원소(자기 고리)는 이웃으로 세지 않아요.

```python
>>> loops = G + sd.eye(8)
>>> sd.graph.core_number(loops)
array([3, 3, 3, 3, 2, 1, 1, 0], dtype=int64)
```

## 경계의 값

| 입력 | 결과 |
|---|---|
| 노드가 없는 (0, 0) 행렬 | 빈 int64 배열 |
| 변이 없는 그래프 | 모두 0 |
| 완전 그래프(노드 $m$개가 서로 모두 이어짐) | 모두 $m - 1$ |
| 트리, 숲 | 변이 있는 노드는 모두 1 |
| 순환 하나 | 모두 2 |

```python
>>> sd.graph.core_number(sd.zeros((0, 0)))
array([], dtype=int64)
>>> sd.graph.core_number(sd.ones((4, 4)))
array([3, 3, 3, 3], dtype=int64)
>>> ring = sd.zeros((5, 5))
>>> for i in range(5):
...     ring[i, (i + 1) % 5] = 1
>>> sd.graph.core_number(ring)
array([2, 2, 2, 2, 2], dtype=int64)
>>> sd.graph.core_number(sd.ones((2, 3)))
Traceback (most recent call last):
    ...
ValueError: core_number(): 'csgraph' must be a square matrix, not of shape (2, 3)
```

<Callout type="note" title="답은 하나예요">

코어 수는 그래프가 정하는 하나의 값이에요. 노드를 지우는 차례가 달라도 같은 답이 나와요. 정수 계산이라 오차도 없어요.

</Callout>

## scipy·networkx를 아는 분께

- scipy에는 없는 함수예요. 이름과 뜻은 networkx의 `core_number`를 따랐어요.
- networkx는 노드에서 코어 수로 가는 사전을 돌려줘요. 여기서는 노드 번호 차례의 int64 배열을 돌려줘요.
- networkx의 `k_core(G, k)`에 해당하는 함수는 따로 없어요. `core_number(G) >= k`인 노드를 골라 잘라요.
- networkx는 자기 고리가 있는 그래프에서 에러를 내요. 여기서는 자기 고리를 읽지 않고 답을 내요.
- 유향 그래프도 받고, 방향을 지운 그래프로 읽어요.
